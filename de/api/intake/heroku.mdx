```http
POST /api/v1/_heroku
```

Der Endpunkt akzeptiert Log-Drain-Daten als Text und verwendet kein Bearer-Token. Erstellen Sie einen Konnektor des Typs `heroku_drain` mit einem `pushToken` aus mindestens 16 Zeichen und einem `target_stream`. Heroku kann keine benutzerdefinierten Header setzen. Übergeben Sie das Token deshalb mit `?token=` in der URL. Alternativ akzeptiert der Endpunkt den Header `X-Connector-Token`. Bei einem falschen Token gibt der Endpunkt `401` zurück.

Jede Zeile wird zu einem Log-Ereignis im `target_stream` (Standard: `heroku`). Der Endpunkt speichert die vollständige Zeile im Feld `message` und setzt das Feld `source` auf `heroku`. Bei Erfolg gibt der Endpunkt `204` zurück.

<RequestExample>
```bash Heroku CLI
heroku drains:add "https://molesignal.example.com/api/v1/_heroku?token=<pushToken>"
```
</RequestExample>

Die Einrichtung ist unter [Konnektoren](/de/connectors) beschrieben.

## Zustellung und Stream-Auswahl prüfen

1. Prüfen Sie, ob der Konnektor aktiviert ist und der Absender das Push-Token des Konnektors verwendet. Ein reguläres API-Token ersetzt kein Push-Token.
2. Verwenden Sie beim Setzen von `configJson` im Rohformat über die Konnektor-API den Schlüssel `target_stream` für den Zielstream, nicht `targetStream`. Der Token-Schlüssel bleibt in CamelCase: `pushToken`.
3. Senden Sie ein Testereignis mit einer eindeutigen Markierung und notieren Sie den Empfangszeitpunkt. Wählen Sie unter **Logs** den vorgesehenen Stream und einen Zeitraum aus, der den Empfangszeitpunkt einschließt. Suchen Sie dann nach der Markierung.
4. Wenn die Anfrage erfolgreich ist, der vorgesehene Stream aber leer bleibt, prüfen Sie den zugehörigen Standardstream und das gespeicherte Zielfeld. Eine HTTP-Bestätigung ersetzt keine Abfrage im vorgesehenen Zielstream.

Schützen Sie das Token wie andere Zugangsdaten. Wenn Sie das Token als URL-Abfrageparameter übergeben, halten Sie die vollständige URL aus Logs, Tickets und Screenshots heraus. Prüfen Sie vor dem erneuten Senden einer fehlgeschlagenen Anfrage, ob das Problem am Token oder am Status des Konnektors liegt oder ob das Nutzdatenformat oder die Komprimierung fehlerhaft ist.
