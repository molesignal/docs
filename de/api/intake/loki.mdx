```http
POST /api/v1/loki/api/v1/push
```

Akzeptiert das Loki-JSON-Push-Format. Der Aufruf erfordert `logs.write` und antwortet bei Erfolg mit `204`. Wenn der Stream einige Zeilen ablehnt, weil ein Wert nicht zum Typ seines Felds passt, werden die übrigen Zeilen geschrieben und die Antwort lautet `400`; sie nennt, wie viele abgelehnt wurden, und den ersten Grund. Ein Body mit `Content-Encoding: gzip` wird akzeptiert.

Der Endpoint dekodiert nur JSON. Sender, die snappy-komprimiertes Protobuf nutzen, wie Promtail und Grafana Alloy, können nicht an den Endpoint pushen. Verwenden Sie stattdessen den OpenTelemetry Collector, Vector oder Fluent Bit.

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

Jeder Wert wird zu einem Log-Event. Die Labels werden zu Feldern, die Zeile wird zum Feld `message`, und der Zeitstempel in Nanosekunden wird in Mikrosekunden umgerechnet. Der Header `stream-name` wählt den Zielstream aus, der Standardwert ist `default`.

## Beispiel überprüfen

Das Beispiel erzeugt einen aktuellen Nanosekunden-Zeitstempel in einer macOS- oder Linux-Shell. Öffnen Sie nach dem Empfang von `204` **Logs**, wählen Sie `app` und die letzte Stunde aus und suchen Sie die `message` für `service = 'api'`. Wenn Sie einen historischen Zeitstempel einsetzen, wählen Sie ein Fenster, das diese Ereigniszeit abdeckt, und bestätigen Sie, dass es innerhalb der Aufbewahrungsfrist liegt.

Unterscheiden Sie drei Felder: `streams` ist die Loki-Batch-Struktur, das Label `service` wird zu einem Event-Feld und der Header `stream-name` wählt den Zielstream in MoleSignal aus. Überprüfen Sie diesen Stream und dieses Zeitfenster mit einer Abfrage, bevor Sie einen Batch erneut senden.
