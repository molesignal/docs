```http
POST /api/v1/loki/api/v1/push
```

Der Endpunkt akzeptiert das JSON-Push-Format von Loki. Der Aufruf erfordert `logs.write` und gibt bei Erfolg `204` zurück. Der Endpunkt akzeptiert einen Request-Body mit `Content-Encoding: gzip`.

Der Endpunkt dekodiert nur JSON. Sender wie Promtail und Grafana Alloy, die mit Snappy komprimiertes Protobuf verwenden, können keine Logs an den Endpunkt senden. Verwenden Sie stattdessen OpenTelemetry Collector, Vector oder Fluent Bit.

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

Aus jedem Wert entsteht ein Log-Ereignis. Die Labels werden zu Feldern, die Logzeile wird zum Feld `message`, und der Endpunkt rechnet den Nanosekunden-Zeitstempel in Mikrosekunden um. Der Header `stream-name` legt den Zielstream fest. Standardmäßig gilt `default`.

## Beispiel überprüfen

Das Beispiel erzeugt in einer macOS- oder Linux-Shell einen aktuellen Nanosekunden-Zeitstempel. Sobald der Endpunkt `204` zurückgibt, öffnen Sie **Logs**, wählen Sie `app` und die letzte Stunde aus und suchen Sie nach `message` für `service = 'api'`. Falls Sie stattdessen einen älteren Zeitstempel verwenden, wählen Sie ein Zeitfenster, das den Ereigniszeitpunkt umfasst. Prüfen Sie, ob der Zeitpunkt innerhalb der Aufbewahrungsdauer liegt.

Unterscheiden Sie drei Elemente: `streams` ist die Batch-Struktur von Loki, das Label `service` wird zu einem Ereignisfeld, und der Header `stream-name` legt den Zielstream in MoleSignal fest. Prüfen Sie den Stream und das Zeitfenster mit einer Abfrage, bevor Sie einen Batch erneut senden.
