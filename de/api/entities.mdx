```http
GET /api/v1/entities
GET /api/v1/entities/detail?kind={kind}&key={key}
```

Entitäten werden alle fünf Minuten aus den Instanzen gelesen, die APM erfasst, und aus den Ressourcenfeldern von
Metriken und Logs; Felder und Schlüssel sind unter [Infrastruktur](/de/infrastructure) beschrieben. Beide Aufrufe benötigen
eine der Berechtigungen `apm.services.read`, `metrics.read`, `logs.read` oder `sys.telemetry.read`.

## Entitäten auflisten

| Parameter | Hinweise |
|---|---|
| `kind` | `cluster`, `node`, `host`, `pod` oder `container`. Ohne Angabe werden alle Arten berücksichtigt. |
| `search` | Teil des Namens oder des Schlüssels, ohne Beachtung der Groß-/Kleinschreibung. |
| `seenSince` | Nur seit diesem Zeitpunkt gesehene Entitäten, in Mikrosekunden. |
| `limit` | Höchstens 500, der Standardwert. |

Entitäten werden mit der zuletzt gesehenen zuerst zurückgegeben. `services` zählt die Services, die direkt auf der jeweiligen Entität laufen.

<ResponseExample>
```json 200
[
  {
    "kind": "pod",
    "key": "prod-eu/shop/checkout-7d9f-abcde",
    "name": "checkout-7d9f-abcde",
    "attributes": {
      "k8s.cluster.name": "prod-eu",
      "k8s.namespace.name": "shop",
      "k8s.node.name": "node-3",
      "k8s.pod.name": "checkout-7d9f-abcde"
    },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000,
    "services": 1
  }
]
```
</ResponseExample>

## Eine Entität lesen

`kind` und `key` sind erforderlich; der Schlüssel ist der aus der Liste. Die Antwort enthält die Entität, worauf sie
läuft oder wovon sie Teil ist (`parents`), was auf ihr läuft oder Teil von ihr ist (`children`, bis zu 200), und die
Services auf ihr und auf den Komponenten, die auf ihr laufen (`services`, bis zu 200); die Suche reicht drei Ebenen tief: die
Nodes eines Clusters, deren Pods und die Services darauf.

<ResponseExample>
```json 200
{
  "entity": {
    "kind": "node",
    "key": "prod-eu/node-3",
    "name": "node-3",
    "attributes": { "k8s.cluster.name": "prod-eu", "k8s.node.name": "node-3" },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000
  },
  "parents": [{ "kind": "cluster", "key": "prod-eu", "name": "prod-eu" }],
  "children": [{ "kind": "pod", "key": "prod-eu/shop/checkout-7d9f-abcde", "name": "checkout-7d9f-abcde" }],
  "services": [{ "namespace": "shop", "name": "checkout", "environment": "production" }]
}
```
</ResponseExample>

**Fehler**

| Status | Ursache |
|---|---|
| `400` | `kind` ist keine der fünf Arten. |
| `404` | In der letzten Woche wurde keine Entität dieser Art und dieses Schlüssels gesehen. |
