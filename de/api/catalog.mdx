## Autorisierungsmodell

Ein Endpunkt kann Folgendes erfordern:

- eine Organisationsberechtigung wie `streams.query` oder `alerts.rules.manage`;
- eine Plattformberechtigung wie `sys.telemetry.read`;
- Eigentümerschaft auf Ressourcenebene oder eine Beziehung bzw. Zuweisung;
- eine öffentliche Freigabesitzung, die auf eine Ressource beschränkt ist.

Leiten Sie Berechtigungen nicht aus einer Anzeigerolle ab. Fragen Sie `/api/v1/iam/capabilities` ab, um die effektiven
Berechtigungen und den Feature-Snapshot zu erhalten.

## Anfrage auswählen und überprüfen

Beginnen Sie mit dem verlinkten Leitfaden für die relevante Familie. Prüfen Sie HTTP-Methode, erforderliche Berechtigung, Organisationsbereich, Anfragefelder und Antwortformat, bevor Sie einen Endpunkt verwenden. Eine Familie kann sowohl Verwaltungsanfragen als auch Datenabfragen mit unterschiedlichen Berechtigungen enthalten.

Verwenden Sie die dokumentierte Leseanfrage, um die ausgewählte Organisation und Ressource zu prüfen, bevor Sie die Konfiguration ändern. Lesen Sie nach einem Schreibvorgang die Ressource erneut oder fragen Sie ein kontrolliertes Testereignis ab, um das beabsichtigte Ergebnis zu bestätigen. Ein HTTP-Erfolg allein belegt nicht, dass die Telemetrie den vorgesehenen Stream erreicht hat oder dass sich ein Incident erholt hat.

Bei Fehlern folgen Sie der [API-Einführung](/de/api-reference) und den endpunktspezifischen Hinweisen. Geben Sie beim [Melden einer Dokumentationsabweichung](/de/support) die laufende Version, eine bereinigte Anfrage und Anfrage-IDs an; lassen Sie Zugangsdaten und sensible Ereignisdaten weg.
