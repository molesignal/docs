```http
GET /api/v1/business-context
PUT /api/v1/business-context
```

Die Business-Keys – etwa ein Tenant, ein Plan oder eine Experimentgruppe – und das Feld, das jeweils in
Spans, Logs und RUM-Events jeden davon trägt. Siehe [Business-Kontext](/de/business-context). Zum Lesen genügt eine der Berechtigungen
`apm.services.read`, `traces.read`, `logs.read`, `rum.events.read`, `apm.settings.read` oder
`sys.telemetry.read`; zum Setzen ist `apm.settings.manage` nötig, und die Änderung wird im Aktivitätslog protokolliert.

## Keys festlegen

`PUT` ersetzt alle Keys. Leere Felder benennen nichts, ein leeres `label` entspricht dem Key, und Werte in
`important` werden getrimmt und jeweils nur einmal aufgeführt; die Antwort zeigt den gespeicherten Stand.

| Feld | Hinweise |
|---|---|
| `key` | Beginnt mit einem Kleinbuchstaben und enthält nur Kleinbuchstaben, Ziffern und `_`, höchstens 64 Zeichen. Eindeutig. |
| `label` | Der Anzeigename für Leser, höchstens 80 Zeichen. |
| `span` | Das Span-Attribut, so wie der Traces-Stream das Feld nennt. |
| `log` | Das Log-Feld. |
| `rum` | Das RUM-Feld, ein Key eines einbezogenen JSON-Felds, etwa `context.tenant`. |
| `important` | Werte, die am wichtigsten sind, höchstens 50 mit bis zu 200 Zeichen. |

Ein Key benennt mindestens eines von `span`, `log` und `rum`. Höchstens 8 Keys.

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/business-context \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"keys":[{"key":"tenant","label":"Tenant","span":"tenant.id","log":"tenant_id","rum":"context.tenant","important":["acme"]}]}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "keys": [
    {
      "key": "tenant",
      "label": "Tenant",
      "span": "tenant.id",
      "log": "tenant_id",
      "rum": "context.tenant",
      "important": ["acme"]
    }
  ]
}
```
</ResponseExample>

**Fehler**

| Status | Grund |
|---|---|
| `400` | Ein Key ist fehlerhaft benannt oder doppelt, benennt kein Feld, oder es gibt mehr Keys bzw. Werte als erlaubt. |
| `403` | Dem Token fehlt die Berechtigung des Aufrufs. |
