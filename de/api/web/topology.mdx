```http
GET /api/v1/web/topology
```

Aggregiert die Kanten des Servicegraphen in einem Zeitfenster zu Knoten und Kanten mit Anfragerate, Fehlerrate und Latenz. MoleSignal leitet den Servicegraphen und seine Kanten aus den Spans der Traces ab. Siehe [Servicekarte](/de/apm/service-map). Der Aufruf erfordert `traces.read` oder `sys.telemetry.read` im Systembereich.

**Abfrageparameter**

| Parameter | Typ | Erforderlich | Hinweise |
|---|---|---|---|
| `from` | string | Ja | Beginn des Zeitfensters als Zeitstempel nach RFC 3339. |
| `to` | string | Ja | Ende des Zeitfensters als Zeitstempel nach RFC 3339. Darf nicht vor `from` liegen. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/topology?from=2026-10-04T09:00:00Z&to=2026-10-04T10:00:00Z" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "nodes": [
    { "id": "checkout", "name": "checkout", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 },
    { "id": "frontend", "name": "frontend", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 }
  ],
  "edges": [
    { "source": "frontend", "target": "checkout", "rps": 0.1, "errRate": 0.0278, "p95Ms": 90.0 }
  ]
}
```
</ResponseExample>

**Antwort**

| Feld | Hinweise |
|---|---|
| `nodes[].id`, `nodes[].name` | Name des Dienstes. Die Knoten sind nach Namen sortiert. |
| `nodes[].span_count` | Anzahl der Anfragen auf allen Kanten, an denen der Dienst als Client oder Server beteiligt ist. |
| `nodes[].error_rate`, `edges[].err_rate` | Anzahl der Fehler geteilt durch die Anzahl der Anfragen, als Wert von 0 bis 1. |
| `nodes[].rps`, `edges[].rps` | Anzahl der Anfragen geteilt durch die Dauer des Zeitfensters in Sekunden. |
| `nodes[].p95_ms`, `edges[].p95_ms` | Höchste p95-Latenz unter den aggregierten Zeitintervallen, in Millisekunden. Dies ist nicht die p95-Latenz des gesamten Zeitfensters. |
| `edges[].source`, `edges[].target` | Clientdienst und Serverdienst. Die Kanten sind zuerst nach Quelle und dann nach Ziel sortiert. |

Für ein Zeitfenster ohne Kanten gibt der Aufruf leere Arrays zurück.

**Fehler**

| Status | Ursache |
|---|---|
| `400` | `from` oder `to` fehlt oder ist kein Zeitstempel nach RFC 3339, oder `to` liegt vor `from`. |
| `403` | Dem Token fehlt die Berechtigung `traces.read`. |
