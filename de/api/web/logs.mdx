These calls read one logs stream of the organization, the way the **Logs** page reads it. A stream that does not exist answers an empty result. All calls require `logs.read`, or `sys.telemetry.read` in the system scope.

Each call but the pattern grouping takes `POST` with a JSON body, or `GET` with the same fields in the query string: `filters` and `freeText` as the text of a JSON list, and `where` as the text of a JSON object. Send a query too long for an address as a `POST`.

## Welche Datensätze ein Aufruf trifft

Ein Aufruf trifft die Datensätze des Streams im Zeitfenster, die alle folgenden Bedingungen erfüllen:

| Feld | Typ | Hinweise |
|---|---|---|
| `filters` | Liste | Filter, die alle zutreffen. Höchstens 32, zusammen mit den Filtern von `where` gezählt. |
| `freeText` | Liste | Wörter oder Phrasen, die im Feld `message` gesucht werden, jeweils bis zu 512 Bytes. Ein kleingeschriebenes Wort aus Buchstaben und Ziffern, bis zu 40 Bytes, trifft unabhängig von der Groß-/Kleinschreibung; anderer Text trifft nur exakt wie geschrieben. Höchstens 8, zusammen mit dem Text von `where` gezählt. |
| `where` | Objekt | Ein Bedingungsbaum für Alternativen: ein Filter, `{"text": "..."}`, `{"and": [...]}` oder `{"or": [...]}`. |
| `expression` | String | Eine Feldabfrage, wie sie die Seite **Logs** schreibt. Sie steht für `filters`, `freeText` und `where`: Senden Sie das eine oder das andere. |

Ein Filter ist ein Objekt mit `field`, `op`, `value` und `quoted`. Er benennt sein Feld so, wie der Stream es benennt.

| Operator | Felder | Trifft |
|---|---|---|
| `=`, `!=` | Jedes skalare Feld | Den Wert oder jeden anderen Wert. Mit einem leeren Wert: ob das Feld überhaupt einen Wert hat: `=` trifft die Datensätze ohne Wert. |
| `>`, `>=`, `<`, `<=` | Zahlen und Zeitstempel | Den Vergleich. |
| `contains` | Text | Den Wert irgendwo im Feld. |
| `match` | Jedes Feld | Den Wert als Teilstring, unabhängig von der Groß-/Kleinschreibung. Ein leerer Wert trifft nichts. |
| `match_text` | Text mit Volltextindex | Eine Volltextsuche: Wörter, Phrasen und Wildcards. Ein Feld ohne Volltextindex antwortet mit `400`. |

`eq`, `ne` und `like` sind Aliase von `=`, `!=` und `contains`. `quoted` ist `true` für einen in Anführungszeichen geschriebenen Wert: ein Wort, nie eine Zahl. Ein JSON-Feld ist hier nicht filterbar; fragen Sie es mit SQL ab.

`expression` nimmt den Text der Seite **Logs**: Vergleiche, `MATCH(field, 'text')` und `MATCH_TEXT(field, 'words')`, zu findende Wörter, eine Phrase in Anführungszeichen, `AND` und `OR` in beliebiger Schreibweise, wobei `AND` stärker bindet, und Klammern. Der Server liest ihn in die `filters`, `freeText` und `where` ein, die die Seite sendet, und prüft sie wie oben. Der Text ist höchstens 8 KiB groß und verschachtelt Klammern höchstens 32 Ebenen tief. Einen Teil, den er nicht lesen kann – etwa eine nicht geschlossene Klammer oder einen Vergleich ohne Inhalt –, beantwortet er mit `400` und nennt den Teil.

```bash
curl -G "http://localhost:5080/api/v1/web/logs" \
  -H "authorization: Bearer $MS_TOKEN" \
  --data-urlencode 'stream=app' \
  --data-urlencode "expression=level = 'error' AND (service.name = 'checkout' OR timeout)"
```

## Datensätze auflisten

```http
POST /api/v1/web/logs
GET  /api/v1/web/logs
```

Gibt die passenden Datensätze zurück, neueste zuerst, mit Cursor-Paginierung.

| Feld | Typ | Hinweise |
|---|---|---|
| `stream` | String | Erforderlich. Der Logs-Stream. |
| `from`, `to` | Integer | Das Zeitfenster in Mikrosekunden. Standard sind die letzten 24 Stunden bis jetzt. `to` muss größer als `from` sein. |
| `filters`, `freeText`, `where`, `expression` | | Was der Aufruf trifft. |
| `limit` | Integer | Seitengröße. Standard `20`, begrenzt auf 1 bis 5000. |
| `cursor` | String | Der `nextCursor` oder `previousCursor` einer früheren Seite. Er behält das Zeitfenster und die Treffermenge der ersten Seite bei. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/logs \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"stream":"app","expression":"level = '\''error'\''","limit":2}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "items": [
    { "_timestamp": 1790000000000000, "level": "error", "message": "db pool exhausted", "trace_id": "0af7651916cd43dd8448eb211c80319c" }
  ],
  "nextCursor": "eyJ2IjoxLC...",
  "previousCursor": null,
  "hasMore": true
}
```
</ResponseExample>

Jedes Element enthält die Felder eines Datensatzes. `_timestamp` ist in Mikrosekunden. Eine Anfrage mit einem `cursor` und einem anderen Stream, Zeitfenster, `limit` oder einer anderen Treffermenge antwortet mit `400`.

## Datensätze über die Zeit zählen

```http
POST /api/v1/web/logs/histogram
GET  /api/v1/web/logs/histogram
```

Zählt die passenden Datensätze in Zeit-Buckets.

| Feld | Typ | Hinweise |
|---|---|---|
| `stream` | String | Erforderlich. |
| `from`, `to` | Integer | Erforderlich. Das Zeitfenster in Mikrosekunden. |
| `filters`, `freeText`, `where`, `expression` | | Was der Aufruf trifft. |
| `bucketTime` | Integer | Die Länge eines Buckets in Mikrosekunden. Mindestens `1000`. |
| `originTime` | Integer | Der Start des ersten Buckets. Nicht nach `from`. |

Eine Anfrage umfasst höchstens 512 Buckets von `originTime` bis `to`.

```json
{
  "bucketTime": 60000000,
  "originTime": 1790000100000000,
  "buckets": [{ "startTime": 1790000100000000, "total": 120, "errors": 4 }],
  "split": true
}
```

`buckets` listet die Buckets, die einen Datensatz enthalten, älteste zuerst. `errors` zählt die Datensätze der Stufe `ERROR`, gelesen aus `level` oder `body_level`. `split` ist `false`, wenn der Stream keines der beiden Felder hat oder die Stufe für den Leser maskiert ist; `errors` ist dann `0`. Ist die Zählung nicht verfügbar, antwortet der Aufruf mit `200` und leeren `buckets` sowie `unavailable`: `time_budget`, `busy` oder `scan_limit`, wie bei der [Trace-Zählung](/de/api/web/trace#traces-über-die-zeit-zählen).

## Ein Feld beschreiben

```http
POST /api/v1/web/logs/field-stats
GET  /api/v1/web/logs/field-stats
```

Beschreibt die Werte, die ein Feld in den passenden Datensätzen annimmt.

| Feld | Typ | Hinweise |
|---|---|---|
| `stream` | String | Erforderlich. |
| `from`, `to` | Integer | Das Zeitfenster in Mikrosekunden. |
| `filters`, `freeText`, `where`, `expression` | | Was der Aufruf trifft. |
| `field` | String | Erforderlich. Das Feld, so wie der Stream es benennt. |

```json
{
  "kind": "text",
  "total": 1840,
  "present": 1840,
  "distinct": 3,
  "distinctExact": true,
  "top": [{ "value": "info", "count": 1500 }, { "value": "warn", "count": 300 }, { "value": "error", "count": 40 }],
  "topSkipped": false
}
```

`kind` ist `number`, `time`, `text` oder `bool`. `total` zählt die passenden Datensätze und `present` die mit einem Wert. `top` listet die häufigsten Werte, häufigste zuerst; `topSkipped` ist `true`, wenn fast jeder Wert abweicht und keiner gelistet wird. `range` gibt den kleinsten und den größten Wert als Text an. Ein Zahlenfeld ergänzt `spread` und `bars`. `trend` zählt die häufigsten Werte über das Zeitfenster und fehlt, wenn kein Wert häufiger ist als die übrigen.

## In Patterns gruppieren

```http
POST /api/v1/web/logs/patterns
```

Gruppiert die passenden Datensätze über das gesamte Zeitfenster in Nachrichten-Patterns und vergleicht jedes mit einem Baseline-Abschnitt. Ein Zeitfenster mit mehr als 5.000 passenden Datensätzen wird als Stichprobe der neuesten Datensätze aus vier gleich großen Teilen gelesen, und `estimatedCount` jedes Patterns skaliert seine Anzahl auf das Zeitfenster. Der Aufruf benötigt `logs.read`.

| Feld | Typ | Hinweise |
|---|---|---|
| `stream` | String | Erforderlich. |
| `from`, `to` | Integer | Erforderlich. Das Zeitfenster in Mikrosekunden. |
| `filters`, `freeText`, `where`, `expression` | | Was der Aufruf trifft. |
| `field` | String | Das Feld, das die Nachricht enthält; wenn es fehlt, das erste aus `message`, `body`, `summary`, `log`, `event`, `error`, `msg`, `content` und `text`, das der Stream hat. |
| `baseline` | String | `previous` (der Standard, der gleich lange Abschnitt direkt davor), `week_before` oder `none`. |
| `limit` | Integer | Die maximale Anzahl gelisteter Patterns: standardmäßig 100, höchstens 200. |

```json
{
  "stream": "app_logs",
  "field": "message",
  "levelField": "level",
  "timeRange": { "startTime": 1795510800000000, "endTime": 1795514399999999 },
  "logs": 48210,
  "read": 5000,
  "unread": 0,
  "sampled": true,
  "baseline": { "kind": "previous", "startTime": 1795507199999999, "endTime": 1795510799999999, "logs": 40102, "read": 5000, "sampled": true },
  "newPatterns": 1,
  "surgingPatterns": 0,
  "droppingPatterns": 0,
  "patternCount": 37,
  "patterns": [
    {
      "pattern": "upstream timeout after <number>ms",
      "tokens": [{ "lead": "", "trail": "", "text": "upstream", "wild": null, "unit": "" }],
      "count": 41,
      "share": 0.0082,
      "estimatedCount": 395,
      "firstSeen": 1795513020000000,
      "lastSeen": 1795514390000000,
      "levels": [{ "level": "ERROR", "count": 41 }],
      "baselineCount": 0,
      "change": "new",
      "fragment": "upstream timeout after",
      "example": "upstream timeout after 3000ms"
    }
  ]
}
```

Neue und stark ansteigende Patterns stehen zuerst, Patterns, die das Zeitfenster nicht mehr enthält, zuletzt. `change` ist `new` (die Baseline hatte keines), `surging` (mindestens doppelt so viele und mindestens fünf mehr), `dropping` (die Hälfte oder weniger und mindestens fünf weniger) oder `steady`; `ratio` ist die geschätzte Anzahl im Zeitfenster geteilt durch die der Baseline. `tokens` sind die Wörter des Patterns, wobei `wild` benennt, was sich an einer offenen Stelle ändert. Ein at rest verschlüsseltes Feld antwortet mit `400`. Ein Stream, in den nichts geschrieben wurde, liefert einen leeren Bericht.

## Fehler

| Status | Ursache |
|---|---|
| `400` | Ein Parameter ist ungültig: `stream` fehlt, `to` ist nicht größer als `from`, ein Filter nennt ein unbekanntes Feld oder verwendet einen Operator, den sein Typ nicht zulässt, die Listen oder der Baum überschreiten ihre Grenzen, `expression` kommt zusammen mit `filters`, `freeText` oder `where` oder enthält einen Teil, der nicht gelesen werden kann, der Cursor passt nicht zur Abfrage, oder ein Histogramm-Parameter fehlt oder umfasst mehr als 512 Buckets. |
| `403` | Dem Token fehlt `logs.read`. |
