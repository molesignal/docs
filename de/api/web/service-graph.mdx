```http
GET /api/v1/traces/service_graph
```

Gibt die Rohkanten des Servicegraphen zurück, die die [Servicetopologie](/de/api/web/topology) aggregiert. Jede Kante erfasst die Anzahl der Aufrufe von einem Client-Service an einen Server-Service innerhalb einer Minute. Der Aufruf erfordert `traces.read` oder im System-Scope `sys.telemetry.read`.

**Abfrageparameter**

| Parameter | Typ | Erforderlich | Hinweise |
|---|---|---|---|
| `from` | Ganzzahl | Ja | Beginn des Zeitfensters in Mikrosekunden seit der Unix-Epoche. |
| `to` | Ganzzahl | Ja | Ende des Zeitfensters in Mikrosekunden. |
| `service` | Zeichenfolge | Nein | Beschränkt das Ergebnis auf Kanten, bei denen dieser Service als Client oder Server beteiligt ist. |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000
curl "http://localhost:5080/api/v1/traces/service_graph?from=$((NOW-3600000000))&to=$NOW&service=checkout" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "edges": [
    {
      "id": "3KBCiQWW0TtpDu7D4pH7LMtZsRh",
      "orgId": "<organization-id>",
      "clientService": "frontend",
      "serverService": "checkout",
      "bucketAt": 1790000000000000,
      "requestCount": 12,
      "errorCount": 1,
      "p50Us": 90000,
      "p95Us": 210000,
      "p99Us": 240000
    }
  ],
  "count": 1
}
```
</ResponseExample>

**Antwort**

| Feld | Hinweise |
|---|---|
| `edges[].client_service`, `edges[].server_service` | Der aufrufende und der aufgerufene Service. |
| `edges[].bucketAt` | Beginn des Minutenintervalls in Mikrosekunden. |
| `edges[].request_count`, `edges[].error_count` | Anzahl aller Aufrufe und Anzahl der fehlgeschlagenen Aufrufe im Intervall. |
| `edges[].p50_us`, `edges[].p95_us`, `edges[].p99_us` | Latenzperzentile des Intervalls in Mikrosekunden. Ein Perzentil kann `null` sein. |
| `count` | Anzahl der zurückgegebenen Kanten. |

Die API gibt `{"edges": [], "count": 0}` zurück, wenn das Zeitfenster keine passenden Kanten enthält oder `to` vor `from` liegt.

**Fehler**

| Status | Ursache |
|---|---|
| `400` | `from` oder `to` fehlt oder ist keine Ganzzahl. Die Antwort ist Klartext. |
| `403` | Dem Token fehlt `traces.read`. |
