```http
GET /api/v1/web/search
```

Dieser Aufruf stellt die Suche für die Befehlspalette **⌘K** bereit. Er durchsucht sechs Entitätstypen der Organisation anhand ähnlicher Namen und gibt die besten Treffer zuerst zurück. Der Aufruf erfordert `streams.query` oder im Systemkontext `sys.telemetry.read`.

**Abfrageparameter**

| Parameter | Typ | Erforderlich | Hinweise |
|---|---|---|---|
| `q` | Zeichenfolge | Ja | Suchtext mit bis zu 256 Zeichen. Die Suche nutzt die Trigramm-Ähnlichkeit von PostgreSQL. Sehr kurze Suchtexte, etwa einzelne Buchstaben, liefern daher selten Treffer. Ein leeres `q` liefert eine leere Liste. |
| `types` | Zeichenfolge | Nein | Eine kommagetrennte Auswahl aus `stream`, `dashboard`, `savedView`, `alert`, `incident` und `service`. Lassen Sie den Parameter weg, um alle Typen zu durchsuchen. Ein unbekannter Wert liefert keine Treffer. |
| `limit` | Ganzzahl | Nein | Standardwert: `20`. Werte unter 1 werden auf 1 angehoben, Werte über 50 auf 50 gesenkt. |

Wenn `q` nur Leerzeichen enthält und `types=stream` gesetzt ist, listet der Aufruf die Streams alphabetisch auf, statt sie zu durchsuchen.

Jeder Treffer beschreibt die Entität mit diesen Feldern:

| `kind` | `id` | `label` | `subtitle` |
|---|---|---|---|
| `stream` | Stream-ID | Stream-Name | Interne Bezeichnung des Stream-Typs, etwa `builtin.logs`. |
| `dashboard` | Dashboard-ID | Titel | `uid` des Dashboards. |
| `savedView` | ID der gespeicherten Ansicht | Name | Abfragesprache. |
| `alert` | Regel-ID | Regelname | `enabled` oder `disabled`. |
| `incident` | Incident-ID | Incident-Fingerabdruck | Incident-Status. |
| `service` | Kanten-ID | Name des Service aus dem Service-Graphen | Keine Angabe. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/search?q=app&types=stream&limit=5" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "items": [
    { "kind": "stream", "id": "3KDXoznFWyKPsch4ETi37U3GdxM", "label": "app", "subtitle": "builtin.logs" },
    { "kind": "stream", "id": "3JtcZGko1Q5czEBK9nBJjiFxpo1", "label": "app_logs", "subtitle": "builtin.logs" }
  ]
}
```
</ResponseExample>

**Fehler**

| Status | Ursache |
|---|---|
| `400` | `q` fehlt (Klartext) oder ist länger als 256 Zeichen (`invalid_argument`). |
| `403` | Dem Token fehlt `streams.query`. |
