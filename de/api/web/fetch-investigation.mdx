```http
GET /api/v1/web/investigation/blob/{id}
```

Gibt das JSON-Dokument zurück, das [Untersuchungsstack speichern](/de/api/web/store-investigation) unter `blobId` gespeichert hat. Die Suche ist auf die Organisation beschränkt, aus der der Aufruf stammt. Bei einer Kennung aus einer anderen Organisation gibt die API daher `404` zurück. Der Aufruf erfordert `streams.query` oder im Systembereich `sys.telemetry.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/web/investigation/blob/$BLOB_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "version": 1,
  "stack": [
    { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
    { "kind": "log", "query": "level = error" }
  ]
}
```
</ResponseExample>

Die API gibt das gespeicherte Dokument unverändert zurück. Hat der Kompaktor das Dokument nach 7 Tagen entfernt, gibt die API ebenfalls `404` zurück.

**Fehler**

| Status | Ursache |
|---|---|
| `403` | Dem Token fehlt die Berechtigung `streams.query`. |
| `404` | Die Kennung ist unbekannt, gehört zu einer anderen Organisation oder ist abgelaufen. |
