```http
POST /api/v1/web/investigation/blob
```

Speichert ein JSON-Dokument im Objektspeicher und gibt eine Kennung zurück. Bei umfangreichen Untersuchungen nutzt die Weboberfläche diesen Aufruf, damit die Seiten-URL nur die Kennung statt des gesamten Untersuchungsstapels enthält. Rufen Sie das Dokument mit [Untersuchungsstapel abrufen](/de/api/web/fetch-investigation) ab. Der Aufruf erfordert `streams.query` oder `sys.telemetry.read` im System-Scope.

Der Request-Body kann einen beliebigen JSON-Wert mit einer Größe von bis zu 1 MiB (1.048.576 Byte) enthalten. Das Dokument gehört zur Organisation, aus der der Aufruf stammt. Der Kompaktor löscht es nach 7 Tagen.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/investigation/blob \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "version": 1,
    "stack": [
      { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
      { "kind": "log", "query": "level = error" }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "blobId": "3KEZAC5JXc0P0HjrTdARfCgH1Y3"
}
```
</ResponseExample>

**Fehler**

| Status | Ursache |
|---|---|
| `400` | Der Request-Body enthält kein gültiges JSON (Klartext) oder das Dokument ist größer als 1 MiB (`payload exceeds 1048576 bytes`). |
| `403` | Dem Token fehlt die Berechtigung `streams.query`. |
