```http
PUT /api/v1/streams/{id}/settings
```

Das Schema eines Streams erweitert sich, wenn bei der Datenerfassung neue Felder hinzukommen. Die API ändert keine bestehenden Feldtypen. Legen Sie über diesen Endpunkt den Indextyp für Felder fest, die bereits im Schema vorhanden sind. Der Aufruf erfordert `streams.configure` und für den Stream `_audit` zusätzlich `audit.read`. Über denselben Endpunkt lassen sich auch die Aufbewahrung und die Einstellungen ändern. Siehe [Aufbewahrung und Einstellungen ändern](/de/api/streams/edit-retention).

**Anfragetext**

| Feld | Typ | Hinweise |
|---|---|---|
| `fields` | array | Ein Eintrag pro zu konfigurierendem Feld. |

Jeder Eintrag in `fields`:

| Eigenschaft | Typ | Hinweise |
|---|---|---|
| `name` | string | Ein Feld, das bereits im Schema vorhanden ist. |
| `indexType` | string | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value` oder `range`. Siehe [Streams](/de/streams#schema-und-felder). |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexType": "exact" },
      { "name": "msg", "indexType": "full_text" }
    ]
  }'
```
</RequestExample>

Die Antwort enthält den aktualisierten Stream in der unter [Stream abrufen](/de/api/streams/get) beschriebenen Struktur. Die Änderung gilt sofort für alle neu geschriebenen Daten. MoleSignal indexiert bereits geschriebene Daten im Hintergrund neu. Siehe [Streams](/de/streams#schema-und-felder). Die Indextypen `full_text`, `ngram` und `ip` sind nur für `utf8`-Felder verfügbar, `key_value` nur für `json`-Felder.
