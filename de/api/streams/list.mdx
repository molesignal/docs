```http
GET /api/v1/streams
```

Gibt alle Streams der Organisation als JSON-Array zurück, sortiert nach Name und Typ. Jeder Eintrag hat die unter [Stream abrufen](/de/api/streams/get) gezeigte Struktur. Dazu gehören das Schema, die explizite Aufbewahrungsdauer `retention`, die berechnete effektive Aufbewahrungsdauer `effectiveRetention`, die Einstellungen und Zeitstempel in Mikrosekunden. Der Aufruf erfordert `streams.read` oder `sys.telemetry.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Die Antwort enthält geschützte Systemstreams wie `_molesignal`. Fehlt dem Token die Berechtigung `audit.read`, enthält die Antwort `_audit` nicht. Name und Typ identifizieren einen Stream gemeinsam. Derselbe Name kann daher bei mehreren Typen vorkommen.

## Antwort verwenden

Dieser Endpunkt gibt Stream-Definitionen zurück, keine Telemetriedatensätze. Ermitteln Sie damit die ID eines Streams, bevor Sie sein Schema abrufen oder seine Konfiguration ändern. Fragen Sie Ereignisse über die [Abfrage-API](/de/api/query/execute) ab.

| Feld | Bedeutung |
|---|---|
| `id` | Stabile ID für API-Aufrufe zu einem einzelnen Stream. |
| `name` und `streamType` | Identifizieren gemeinsam den Datensatz. Verwenden Sie für ein Inventar nicht nur den Namen als Schlüssel. |
| `schema` | Felddefinitionen zum Erstellen von Abfragen. |
| `retention` | Explizite Aufbewahrungsdauer des Streams. Bei `null` gilt der Standardwert. |
| `effectiveRetention` | Aufbewahrungsdauer, die für den Stream tatsächlich gilt. |
| `createdAt`, `updatedAt` | Unix-Zeitstempel in Mikrosekunden, nicht in Millisekunden. |

## Zugriff und Datenumfang prüfen

Verwenden Sie Zugangsdaten für die gewünschte Organisation. Für die Listenabfrage genügt `streams.read` oder `sys.telemetry.read`. Ohne `audit.read` enthält die Antwort `_audit` nicht. Das Fehlen von `_audit` bedeutet nicht, dass die Erfassung von Audit-Ereignissen deaktiviert ist.

Die Antwort ist direkt ein JSON-Array und kein umschließendes Objekt mit einem Feld `items`. Dieser Endpunkt hat keinen Paginierungsparameter. Ein leeres Array bedeutet, dass die Anfrage für die angegebene Organisation bei den geltenden Zugriffsrechten keine Streams zurückgegeben hat. Daraus lässt sich nicht ableiten, dass eine andere Organisation keine Daten hat.

Suchen Sie die gewünschte Kombination aus `(name, streamType)` und übergeben Sie die zugehörige `id` an [Stream abrufen](/de/api/streams/get). Prüfen Sie mit einer [Beispielabfrage](/de/api/query/execute), ob tatsächlich Ereignisse vorliegen. Eine Stream-Definition allein sagt darüber nichts aus.
