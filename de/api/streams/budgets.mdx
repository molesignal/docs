Ein Budget löst nur eine Benachrichtigung aus, wenn sich die Nutzung einer Quelle dem Limit nähert oder es überschreitet. Die Datenaufnahme beantwortet Anfragen und speichert Daten unverändert. Siehe [Nutzung und Budgets der Datenaufnahme](/de/streams#dateneingang-und-budgets).

## Budgets auflisten

```http
GET /api/v1/streams/budgets
```

Gibt alle Budgets der Organisation mit der Bezeichnung der jeweiligen Quelle und dem Nutzungsstand im laufenden Zeitraum zurück. Erfordert `intake_usage.read` oder in der Organisation `_sys` die Berechtigung `sys.telemetry.read`. Unbekannte Werte gibt die API als `null` zurück.

## Budget festlegen

```http
POST /api/v1/streams/budgets
```

Legt das Budget einer Quelle fest. Jede Quelle hat höchstens ein Budget. Erneutes Festlegen aktualisiert das vorhandene Budget. Erfordert `intake_budgets.manage`. Die Organisation `_sys` kann keine Budgets festlegen.

| Feld | Erforderlich | Hinweise |
|---|---|---|
| `dimension` | Ja | `credential`, `stream` oder `service`. |
| `sourceKey` | Ja | Die Quelle, wie sie unter [Nutzung der Datenaufnahme](/de/api/streams/usage) angegeben ist. Für die plattformeigene Telemetrie, Ereignisse ohne Serviceangabe und Services jenseits des Limits lässt sich kein Budget festlegen. |
| `period` | Ja | `day` oder `month`, nach Kalender in UTC. |
| `limitSize` | Ja | In MiB, von 1 bis 1073741824. |
| `warnPercent` | Nein | Warnschwelle in Prozent des Limits, von 0 bis 99. Bei `0` erfolgt die Warnung erst, wenn das Budget vollständig ausgeschöpft ist. Standard: 80. |
| `notifyUserIds` | Nein | Zu benachrichtigende Mitglieder der Organisation, höchstens 50. Standard: das Mitglied, das das Budget festlegt. Bei einem Dienstkonto ist die Angabe der Mitglieder erforderlich. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/streams/budgets" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"dimension":"stream","sourceKey":"logs:app","period":"day","limitSize":102400}'
```
</RequestExample>

## Budget entfernen

```http
DELETE /api/v1/streams/budgets/{budgetId}
```

Gibt `204` zurück. Erfordert `intake_budgets.manage`.
