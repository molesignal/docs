```http
POST /api/v1/streams
```

Beim ersten Schreibvorgang entsteht ebenfalls ein Stream. Verwenden Sie diesen Aufruf, um vorab einen Stream mit einem expliziten Schema, Indizes, verschlüsselten Feldern oder einer Aufbewahrungsdauer anzulegen. Der Aufruf erfordert `streams.create`.

**Anfragetext**

| Feld | Typ | Pflichtfeld | Hinweise |
|---|---|---|---|
| `name` | string | Ja | Buchstaben, Ziffern, `_`, `-` und `.`. Die Namen der [Plattform-Streams](/de/streams#plattform-streams), etwa `_molesignal` und `_audit`, sind reserviert. |
| `streamType` | string | Ja | `logs`, `metrics`, `traces`, `profiles` oder `extend`. |
| `fields` | array | Nein | Felddefinitionen. Siehe unten. |
| `retentionDays` | integer | Nein | 1 bis 3650. Lassen Sie dieses Feld weg, um den Standardwert der Plattform unter **Einstellungen → Datenaufbewahrung** zu verwenden. |
| `settings` | object | Nein | Stream-Einstellungen wie `description` und `queryable`. Siehe [Aufbewahrungsdauer und Einstellungen bearbeiten](/de/api/streams/edit-retention). |

Ein Feld hat folgende Eigenschaften:

| Eigenschaft | Typ | Hinweise |
|---|---|---|
| `name` | string | Feldname. |
| `dataType` | string | `bool`, `int64`, `float64`, `utf8`, `timestamp` oder `json`. |
| `nullable` | boolean | Standardwert: `true`. |
| `indexType` | string | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value` oder `range`. Standardwert: `none`. |
| `encrypted` | boolean | Verschlüsselt das Feld bei der Speicherung. Diese Einstellung lässt sich nachträglich nicht ändern. Siehe [Streams](/de/streams#verschlüsselte-felder). |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "app",
    "streamType": "logs",
    "fields": [
      { "name": "trace_id", "dataType": "utf8", "nullable": true,
        "indexType": "exact", "encrypted": false }
    ],
    "retentionDays": 30
  }'
```
</RequestExample>

**Fehler**

| Status | Ursache |
|---|---|
| `403` | Der Name gehört zu einem Plattform-Stream oder dem Token fehlt die Berechtigung `streams.create`. |
| `409` | Ein Stream mit demselben Namen und Typ existiert bereits. |
| `422` | Im Anfragetext fehlt ein Feld oder ein Feld ist ungültig, etwa bei einem unbekannten `dataType`. Die Antwort besteht aus reinem Text. |
