```http
DELETE /api/v1/streams/{id}
```

Löscht die Stream-Definition. Der Compactor gibt den von den gespeicherten Daten belegten Speicherplatz frei. Der geschützte System-Stream `_molesignal` lässt sich nicht löschen. Das Löschen eines Streams kann die Funktion von Dashboards, gespeicherten Ansichten, Alarmregeln, Berichten und Pipelines beeinträchtigen, die auf den Stream verweisen. Der Aufruf erfordert `streams.delete` und für den Stream `_audit` zusätzlich `audit.read`. Ohne `audit.read` gibt der Aufruf für `_audit` den Statuscode `403` zurück.

**Pfadparameter**

| Parameter | Typ | Hinweise |
|---|---|---|
| `id` | string | Die `id` des Streams. Bei einer unbekannten ID gibt der Aufruf den Statuscode `404` zurück. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/streams/$STREAM_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>
