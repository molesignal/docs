```http
GET /api/v1/streams/runtime
```

Gibt den Laufzeitstatus aller Streams zurück: gespeicherte Zeilen und Bytes, den Zeitpunkt des letzten Datenempfangs, den Status der Datenaufnahme und eine Zeitreihe aus Buckets. Der Aufruf erfordert `streams.read`, für Systemtelemetrie hingegen `sys.telemetry.read`. Fehlt dem Token die Berechtigung `audit.read`, enthält die Antwort den Stream `_audit` nicht.

**Abfrageparameter**

| Parameter | Standardwert | Hinweise |
|---|---|---|
| `windowSecs` | 86400 | Länge des Zeitfensters. Zulässig sind Werte von 3600 bis 604800. |
| `bucketCount` | 24 | Anzahl der Buckets in der Zeitreihe. Zulässig sind Werte von 6 bis 48. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/runtime?windowSecs=3600" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

| `status` | Bedeutung |
|---|---|
| `healthy` | Der Stream hat in den letzten 15 Minuten Daten empfangen. |
| `delayed` | Der letzte Datenempfang liegt mehr als 15 Minuten und weniger als 2 Stunden zurück. |
| `interrupted` | Der letzte Datenempfang liegt mehr als 2 Stunden zurück. |
| `idle` | Der Stream ist planmäßig inaktiv, etwa der Trace-Stream von Mole Agent. |
| `unused` | Der Stream hat noch nie Daten empfangen. |
| `unknown` | Es liegen keine Statistiken vor. |

`staleIndexFiles` zählt die Dateien, deren Index noch auf den Einstellungen vor der letzten Änderung eines Indextyps des Streams basiert. Der Wert sinkt auf 0, sobald ein Hintergrundprozess alle betroffenen Dateien neu indiziert hat.
