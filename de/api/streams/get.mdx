```http
GET /api/v1/streams/{id}
```

Gibt die Stream-Definition mit ihrem Schema, dem explizit festgelegten Wert `retention`, dem berechneten Wert `effectiveRetention` und den Stream-Einstellungen zurück. Der Aufruf erfordert `streams.read`, für Systemtelemetrie stattdessen `sys.telemetry.read`. Der Zugriff auf den Stream `_audit` erfordert zusätzlich `audit.read`. Ohne diese Berechtigung gibt der Aufruf `403` zurück.

**Pfadparameter**

| Parameter | Typ | Hinweise |
|---|---|---|
| `id` | string | Die `id` des Streams aus [Streams auflisten](/de/api/streams/list). Bei einer unbekannten ID gibt der Aufruf `404` zurück. |
