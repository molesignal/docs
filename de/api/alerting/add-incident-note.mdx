```http
POST /api/v1/alerts/incidents/{id}/notes
```

Fügt der [Zeitleiste](/de/api/alerting/incident-timeline) eines Incidents unabhängig vom Status eine Notiz hinzu. Mole
Agent liest beim Abruf des Incidents auch die neuesten Notizen. Der Aufruf erfordert `alerts.incidents.update`.

**Anfragetext**

| Feld | Typ | Erforderlich | Hinweise |
|---|---|---|---|
| `text` | string | Ja | 1 bis 4.000 Zeichen. Der Aufruf entfernt führende und nachgestellte Leerzeichen. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/notes \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"text": "Rolled back the edge proxy."}'
```
</RequestExample>

Die Antwort enthält den Zeitleisteneintrag für die Notiz.

<ResponseExample>
```json 200
{
  "id": "3KEE1aXy7pRtGd2s9Lm4Qv8bNcE",
  "orgId": "<organization-id>",
  "incidentId": "3KEDNEyqouYJeBDTLTMTBui7XHW",
  "at": 1790000300000000,
  "kind": "note",
  "actor": "<user-id>",
  "detail": {
    "text": "Rolled back the edge proxy.",
    "via": "api"
  }
}
```
</ResponseExample>

**Fehler**

| Status | Ursache |
|---|---|
| `400` | `text` ist leer oder länger als 4.000 Zeichen. |
| `403` | Dem Token fehlt `alerts.incidents.update` oder das Token erlaubt keinen Zugriff auf den Incident. |
| `404` | Der Incident existiert nicht. |
