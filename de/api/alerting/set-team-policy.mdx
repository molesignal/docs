```http
PUT /api/v1/alerts/routing/teams/{teamId}
```

Legt die [Rufbereitschaftsrichtlinie](/de/alerting/routing#bereitschaftsrichtlinien-der-teams) eines Teams fest oder entfernt sie. Erfordert `alerts.routing.manage`. Neue Incidents, die an das Team weitergeleitet werden, eskalieren nach dieser Richtlinie. Ohne eigene Richtlinie gilt die Standardrichtlinie.

| Feld | Typ | Beschreibung |
|---|---|---|
| `escalationPolicyId` | string \| null | ID einer Eskalationsrichtlinie der Organisation. Der Wert `null` oder das Weglassen des Felds entfernt die Rufbereitschaftsrichtlinie des Teams. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/teams/$TEAM_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"escalationPolicyId": "<policy-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "teamId": "<team-id>", "escalationPolicyId": "<policy-id>" }
```
</ResponseExample>

**Fehler**

| Status | Ursache |
|---|---|
| `400` | Das Team existiert nicht oder gehört zu einer anderen Organisation, oder die Eskalationsrichtlinie existiert nicht. |
| `403` | Dem Token fehlt die Berechtigung `alerts.routing.manage`. |
| `422` | Die Anfrage enthält ein weiteres Feld. Die Antwort liegt als Klartext vor. |
