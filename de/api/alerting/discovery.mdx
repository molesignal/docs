```http
GET /api/v1/alerts/discovery/findings
GET /api/v1/alerts/discovery/findings/{id}
```

Listet die Befunde der [Erkennung](/de/alerting/discovery) auf, beginnend mit dem zuletzt erkannten, oder liest einen einzelnen
Befund aus. Erfordert `alerts.discovery.read`.

**Abfrageparameter**

| Parameter | Beschreibung |
|---|---|
| `status` | `open` (Standard), `ended` oder `all`. |
| `kind` | `apm_anomaly`, `apm_regression`, `rum_new_issue` oder `rum_regressed_issue`. |
| `limit` | Standardmäßig 100, höchstens 500. |

**Befundfelder**

| Feld | Beschreibung |
|---|---|
| `kind` | Wie oben. |
| `key` | Identifiziert dasselbe Problem anhand von Typ, betroffenem Objekt und Metrik. |
| `severity` | `warning`, `error` oder `critical`. |
| `subject` | Ein APM-Dienst (`namespace/name`) oder die ID einer RUM-Anwendung. |
| `environment`, `metric` | Die Umgebung und die Metrik, die sich im APM geändert hat: `errorRate`, `p95` (Mikrosekunden) oder `throughput` (Anfragen pro Sekunde). |
| `title` | Ein Satz. |
| `value`, `baseline` | Der aktuelle Wert und der Vergleichswert. |
| `startedAt`, `lastSeenAt`, `endedAt` | Zeitpunkt des Beginns, der letzten Erkennung und des Endes (Mikrosekunden). Ohne `endedAt` bleibt der Befund offen. |
| `missedRounds` | Anzahl aufeinanderfolgender Prüfrunden ohne erneute Erkennung. Nach 3 solchen Runden endet der Befund. |
| `detail` | Ein APM-Befund enthält `previous`, `lastWeek`, `version`, `previousVersion` und zeitlich naheliegende Änderungen (`changes`). Ein RUM-Befund enthält `issueId`, `application`, `errorType`, `location` und `version`. |

Um aus Befunden Incidents zu erstellen, [erstellen Sie eine Regel](/de/api/alerting/create-rule) mit `query.discovery`:
`{"kinds": [...], "subjects": [...], "environments": [...], "minSeverity": "warning"}`. Lassen Sie einen Parameter weg, um nach diesem Kriterium
nicht zu filtern. Beim Speichern erhält die Regel eine feste Konfiguration: Sie erstellt pro passendem Befund einen Incident mit
demselben Schweregrad wie der Befund und niedriger Dringlichkeit, sofern `trigger.urgency` nichts anderes vorgibt.
