```http
DELETE /api/v1/alerts/sources/{id}
```

Löscht eine [Alarmquelle](/de/alerting/sources). Der Aufruf erfordert `alerts.sources.manage`. Das Token der Quelle verliert sofort seine Gültigkeit. Die zuletzt empfangenen Anfragen werden ebenfalls gelöscht. MoleSignal löst die offenen Incidents der Quelle im Namen des aufrufenden Benutzerkontos, da ohne die Quelle keine Entwarnung mehr eintreffen würde. Bei aktivierter Föderation lösen auch die anderen Cluster ihre offenen Incidents dieser Quelle, sobald sie die Löschung synchronisiert haben.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Bei Erfolg gibt der Aufruf den Status `200` mit dem Text `deleted` zurück.

**Fehler**

| Status | Ursache |
|---|---|
| `403` | Dem Token fehlt die Berechtigung `alerts.sources.manage`. |
| `404` | Die Quelle existiert nicht. |
