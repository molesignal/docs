```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

Der erste Aufruf listet die [Alert-Quellen](/de/alerting/sources) der Organisation auf, der zweite gibt eine Quelle zurück und der dritte gibt die Föderations-ID dieses Clusters (`local`, ohne Föderation leer) und die Cluster zurück, die eine Quelle als ihren empfangenden Cluster auswählen kann. Alle drei erfordern `alerts.sources.read`. Die API gibt niemals ein Token oder dessen Hash zurück.

| Feld | Typ | Beschreibung |
|---|---|---|
| `id` | string | Quellen-ID. |
| `name` | string | Name. |
| `kind` | string | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` oder `email`. |
| `enabled` | boolean | Eine deaktivierte Quelle weist Alerts ab. |
| `escalationPolicyId` | string \| null | Die Eskalationsrichtlinie, der ihre Incidents folgen; `default` ist die Standardrichtlinie, und `null` eskaliert nichts und benachrichtigt nur. |
| `severity` | string | Wird verwendet, wenn ein Alert keinen Schweregrad enthält. |
| `labels` | object | Zusätzliche Labels, die jedem von ihr geöffneten Incident hinzugefügt werden. |
| `tokenPrefix` | string | Das Token-Präfix `mspat-<10>`. Das vollständige Token wird einmalig bei der Erstellung und bei der Rotation zurückgegeben. |
| `homeCluster` | string | Der Föderationscluster, auf dem ihre Incidents geöffnet werden; leer für diesen Cluster. |
| `intakePath` | string | Der Pfad der Intake-Adresse, für jede Quelle identisch. |
| `lastIntakeAt` | integer \| null | Wann dieser Cluster zuletzt eine Anfrage von ihr empfangen hat, in Mikrosekunden. |
| `createdBy`, `createdAt`, `updatedAt` | | Wer sie erstellt hat und wann sowie wann sie zuletzt geändert wurde, in Mikrosekunden. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Die Cluster, die eine Quelle als ihren empfangenden Cluster auswählen kann:

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
