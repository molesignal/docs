```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

Der erste Aufruf listet die [Alarmquellen](/de/alerting/sources) der Organisation auf. Der zweite gibt eine einzelne Quelle zurück. Der dritte gibt die Föderations-ID dieses Clusters (`local`, ohne Föderation leer) und die Cluster zurück, die als Empfangscluster für eine Quelle zur Auswahl stehen. Alle drei Aufrufe erfordern `alerts.sources.read`. Die API gibt weder ein Token noch dessen Hash zurück.

| Feld | Typ | Beschreibung |
|---|---|---|
| `id` | string | ID der Quelle. |
| `name` | string | Name. |
| `kind` | string | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix` oder `email`. |
| `enabled` | boolean | Eine deaktivierte Quelle lehnt Alarme ab. |
| `escalationPolicyId` | string \| null | Eskalationsrichtlinie für die Incidents der Quelle. `default` steht für die Standardrichtlinie. Bei `null` sendet das System nur Benachrichtigungen und eskaliert nicht. |
| `severity` | string | Schweregrad für Alarme ohne eigenen Schweregrad. |
| `labels` | object | Zusätzliche Labels für jeden Incident, den die Quelle eröffnet. |
| `tokenPrefix` | string | Token-Präfix `mspat-<10>`. Die API gibt das vollständige Token bei der Erstellung und bei jeder Rotation jeweils einmal zurück. |
| `homeCluster` | string | Cluster der Föderation, auf dem die Quelle ihre Incidents eröffnet. Für diesen Cluster ist das Feld leer. |
| `intakePath` | string | Pfad der Empfangsadresse. Er ist für alle Quellen gleich. |
| `lastIntakeAt` | integer \| null | Zeitpunkt in Mikrosekunden, zu dem dieser Cluster zuletzt eine Anfrage von der Quelle empfangen hat. |
| `createdBy`, `createdAt`, `updatedAt` | | Wer die Quelle erstellt hat sowie der Zeitpunkt der Erstellung und der letzten Änderung, jeweils in Mikrosekunden. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Verfügbare Empfangscluster für eine Quelle:

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
