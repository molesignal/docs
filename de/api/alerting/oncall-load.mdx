```http
GET /api/v1/alerts/insights/oncall-load
```

Misst die Belastung durch Bereitschaftsdienste pro Person im gewählten Zeitraum und sortiert absteigend nach Anzahl der Benachrichtigungen. Der Aufruf erfordert
`alerts.incidents.read`.

Als Benachrichtigung zählt jede zugestellte Meldung zu einem ausgelösten Alarm oder einer Eskalation, einmal pro Person
und Benachrichtigung. Fehlgeschlagene Zustellungen zählen nicht. Die Nacht dauert von 22:00 bis 08:00 Uhr Ortszeit am Folgetag. Das
Wochenende umfasst Samstag und Sonntag nach Ortszeit. Für die Ortszeit gilt die Zeitzone des jeweiligen Bereitschaftsplans. Ohne Bereitschaftsplan
gilt die Zeitzone der [Ruhezeiten](/de/account#benachrichtigungen) der jeweiligen Person, andernfalls UTC. Eine
Benachrichtigung nach Mitternacht und vor 08:00 Uhr zählt zur Nacht des Vortags.

**Abfrageparameter**

| Parameter | Typ | Hinweise |
|---|---|---|
| `windowSecs` | Ganzzahl | Rückblick in Sekunden. Der Standardwert ist `2592000` (30 Tage). Die API begrenzt den Wert auf 1 bis 90 Tage. |
| `scheduleId` | Zeichenfolge | Berücksichtigt nur Mitglieder und Schichten dieses Bereitschaftsplans. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/insights/oncall-load?windowSecs=604800" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>

</ResponseExample>

**Antwort**

| Feld | Hinweise |
|---|---|
| `windowSecs` | Zeitraum nach Anwendung der Grenzwerte. |
| `nightStartHour`, `nightEndHour` | Uhrzeiten für Beginn und Ende der Nacht. |
| `people[].oncall_secs` | Sekunden im Bereitschaftsdienst laut Plan im gewählten Zeitraum, einschließlich Überschreibungen und Schichttausch. |
| `people[].pages` | Anzahl der empfangenen Alarmbenachrichtigungen. |
| `people[].night_pages`, `people[].weekend_pages` | Anzahl der nachts bzw. am Wochenende empfangenen Alarmbenachrichtigungen. |
| `people[].interrupted_nights` | Anzahl der Nächte mit mindestens einer Benachrichtigung. |
| `people[].timezone` | Zeitzone für die Zuordnung zu Nacht und Wochenende. |
| `people[].responded`, `people[].mtta_secs` | Anzahl der Incidents, die diese Person im Zeitraum als Erste übernommen hat, und mittlere Zeit vom Auslösen bis zur Übernahme in Sekunden. Für die Übernahme gelten dieselben Zählregeln wie unter [Incident-Analysen](/de/api/alerting/insights). |
