```http
DELETE /api/v1/alerts/routing/rules/{id}
```

Löscht eine [Routing-Regel](/de/alerting/routing#routing-regeln). Dafür ist `alerts.routing.manage` erforderlich. Die nachfolgenden Regeln leiten neue Incidents weiter, die der gelöschten Regel entsprochen hätten. Bereits offene Incidents behalten das Routing vom Zeitpunkt der Eröffnung einschließlich des gespeicherten Regelnamens bei.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/routing/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "deleted": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1" }
```
</ResponseExample>

**Fehler**

| Status | Ursache |
|---|---|
| `403` | Dem Token fehlt `alerts.routing.manage`. |
| `404` | Die Regel existiert nicht oder gehört zu einer anderen Organisation. |
