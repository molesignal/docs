```http
GET /api/v1/alerts/incidents/{id}/source
```

Gibt die Informationen zurück, die auf Quellseite zu einem von einer [Alarmquelle](/de/alerting/sources) eröffneten Vorfall vorliegen. Der Aufruf erfordert `alerts.incidents.read`. Ein solcher Vorfall trägt das Label `alert.source=external`, und seine `ruleId` entspricht der ID der Quelle.

| Feld | Beschreibung |
|---|---|
| `source` | Die Quelle wie unter [Alarmquellen auflisten](/de/api/alerting/list-sources) beschrieben; nach dem Löschen der Quelle `null`. |
| `dedupKey` | Der Deduplizierungsschlüssel. |
| `lastEventAt` | Der neueste für diesen Deduplizierungsschlüssel verarbeitete Absenderzeitstempel in Mikrosekunden. Ältere Nachrichten ignoriert MoleSignal. Für den Typ API ist der Wert `null`. |
| `lastIntakeAt` | Zeitpunkt des letzten Alarmeingangs in Mikrosekunden. |
| `members` | Bis zu 100 Alarme einer Benachrichtigungsgruppe von Alertmanager oder Grafana, jeweils mit `status` (`firing` oder `resolved`), `labels`, `summary`, `startsAt`, `endsAt` und der `url` zum Absender. Bei anderen Typen bleibt das Feld leer. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/source \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Fehler**

| Status | Ursache |
|---|---|
| `404` | Der Vorfall existiert nicht oder keine Alarmquelle hat ihn eröffnet. |
