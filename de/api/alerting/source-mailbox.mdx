```http
GET    /api/v1/alerts/sources/{id}/mailbox
PUT    /api/v1/alerts/sources/{id}/mailbox
DELETE /api/v1/alerts/sources/{id}/mailbox
POST   /api/v1/alerts/sources/{id}/mailbox/test
```

Das IMAP-Postfach, das eine [E-Mail-Quelle](/de/alerting/sources#e-mail) ausliest. Zum Lesen ist `alerts.sources.read` erforderlich, zum Ändern und Testen `alerts.sources.manage`. Nur Quellen vom Typ `email` haben ein solches Postfach. Die Konfiguration liegt auf dem empfangenden Cluster der Quelle. Die Föderation synchronisiert sie nicht. Hinterlegen Sie vor einem `PUT` die Absenderliste in der Quelle (`email.allowed_senders`).

**Anfrage-Body für `PUT` und `test`**

| Feld | Typ | Beschreibung |
|---|---|---|
| `host` | Zeichenfolge | Pflichtfeld: Hostname ohne URL-Schema oder Port. |
| `port` | Ganzzahl | Standard: 993. |
| `security` | Zeichenfolge | `tls` (Standard), `starttls` oder `none`. |
| `username` | Zeichenfolge | Pflichtfeld. |
| `secret` | Zeichenfolge | Passwort oder Client-Secret. Die API gibt den Wert nie zurück. Ein leerer Wert behält den gespeicherten Wert bei. |
| `auth` | Objekt | `{"kind": "password"}` (Standard) oder `{"kind": "oauth2", "tokenUrl": "https://…", "clientId": "…", "scope": "…"}` für ein per Client-Credentials-Flow bezogenes Token zur Anmeldung über `XOAUTH2`. |
| `folder` | Zeichenfolge | Standard: `INBOX`. |
| `pollSecs` | Ganzzahl | Abrufintervall in Sekunden: 15 bis 3600, Standard: 60. |

Verbindungen nutzen nur die IP-Adresse, zu der der Host zum Verbindungszeitpunkt aufgelöst wird, und nie eine Cloud-Metadatenadresse. Ändert sich der Host, das Konto oder der Ordner, setzt MoleSignal die Leseposition beim nächsten Verbindungsaufbau zurück.

**Antwort von `GET` und `PUT`** (`GET` gibt `null` zurück, wenn kein Postfach konfiguriert ist)

| Feld | Beschreibung |
|---|---|
| `settings` | Die obigen Einstellungen ohne `secret`. |
| `secretSet` | Gibt an, ob ein Passwort oder Client-Secret hinterlegt ist. |
| `reading` | Der Verbindungsaufbau war erfolgreich. MoleSignal liest Nachrichten, die seitdem eingehen. |
| `lastPolledAt`, `lastSuccessAt` | Zeitpunkt des letzten Abrufs und des letzten erfolgreichen Abrufs (in Mikrosekunden). |
| `lastError` | Grund für den letzten fehlgeschlagenen Abruf. Ein erfolgreicher Abruf löscht den Fehler. |

`test` stellt mit den Einstellungen aus dem Anfrage-Body einmal eine Verbindung her (bei leerem `secret` nutzt der Test den gespeicherten Wert) und gibt `{"ok": true, "messages": 3}` oder `503` mit der Meldung des Mailservers zurück.

<RequestExample>
```bash cURL
curl -X PUT "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/mailbox" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"host": "imap.example.com", "username": "alerts@example.com", "secret": "<password>"}'
```
</RequestExample>
