```http
POST /api/v1/alerts/sources/{id}/token
```

Erstellt ein neues Token für eine [Alarmquelle](/de/alerting/sources). Der Aufruf erfordert `alerts.sources.manage` und hat einen leeren Request-Body. Das alte Token wird sofort ungültig. Bei aktivierter Föderation wird es auf den anderen Clustern ungültig, sobald die Änderung synchronisiert ist. Sender, die noch das alte Token verwenden, benötigen das neue.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/token \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Die Antwort enthält die Quelle mit dem neuen `token`. Das neue Token erscheint nur in dieser Antwort.

```json 200
{

```
</ResponseExample>

**Fehler**

| Status | Ursache |
|---|---|
| `403` | Dem Token fehlt die Berechtigung `alerts.sources.manage`. |
| `404` | Die Quelle existiert nicht. |
