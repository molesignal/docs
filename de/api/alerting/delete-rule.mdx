```http
DELETE /api/v1/alerts/rules/{id}
```

Löscht eine Regel. Der Aufruf erfordert `alerts.rules.delete`. Bereits von der Regel eröffnete Vorfälle bleiben lesbar und haben einen eigenen Lebenszyklus. Die gelöschte Regel löst keinen dieser Vorfälle mehr.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>

Der Antworttext lautet `deleted` und wird als Klartext ausgegeben. Bei einer unbekannten `id` gibt der Aufruf `404` zurück.
