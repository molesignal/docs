```http
GET /api/v1/alerts/routing/teams
```

Listet die Teams der Organisation nach Namen auf (ohne Beachtung der Groß- und Kleinschreibung), jeweils mit ihrer [Bereitschaftsrichtlinie](/de/alerting/routing#bereitschaftsrichtlinien-der-teams) und den Diensten, für die sie im APM-Dienstkatalog verantwortlich sind. Erfordert `alerts.routing.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/teams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "teamId": "<team-id>",
    "name": "Payments",
    "memberCount": 4,
    "escalationPolicyId": "<policy-id>",
    "services": ["default/checkout", "default/cart"]
  }
]
```
</ResponseExample>

| Feld | Beschreibung |
|---|---|
| `teamId`, `name` | ID und Name des Teams. |
| `memberCount` | Anzahl der Teammitglieder. |
| `escalationPolicyId` | Bereitschaftsrichtlinie des Teams. Ohne eigene Richtlinie ist der Wert `null` und für Incidents, die an das Team weitergeleitet werden, gilt die Standardrichtlinie. |
| `services` | Nicht archivierte Dienste, die im Dienstkatalog dem Team zugeordnet sind, im Format `namespace/name`. |
