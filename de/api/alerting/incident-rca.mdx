```http
GET /api/v1/alerts/incidents/{id}/rca
POST /api/v1/alerts/incidents/{id}/rca
```

[Mole Agent](/de/agent) erstellt anhand des Vorfallkontexts eine Ursachenanalyse (RCA). Pro Vorfall gibt es höchstens eine Analyse.

Die Rolle `alert` erstellt Analysen automatisch. Wenn die Organisation einen aktivierten Modellanbieter mit API-Schlüssel hat, erstellt die Rolle alle drei Minuten Analysen für aktive Vorfälle, für die noch keine Analyse vorliegt. Pro Durchlauf verarbeitet sie bis zu 20 Vorfälle. Der `GET`-Aufruf ruft die gespeicherte Analyse ab. Der `POST`-Aufruf erstellt sofort eine neue Analyse und ersetzt die gespeicherte.

| Aufruf | Berechtigung | Hinweise |
|---|---|---|
| `GET` | `alerts.incidents.read` | Gibt `404` mit `no root-cause analysis for this incident yet` zurück, solange keine Analyse vorliegt. |
| `POST` | `alerts.incidents.rca` | Wartet auf die Antwort des Modells und gibt die neue Analyse zurück. Der optionale Abfrageparameter `locale` legt die Ausgabesprache fest: `en-us` oder `zh-cn`. Standardmäßig gilt die Spracheinstellung des aufrufenden Kontos. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/rca?locale=en-us" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Antwort**

| Feld | Hinweise |
|---|---|
| `incidentId`, `orgId` | Die IDs des Vorfalls und der Organisation. |
| `summary` | Die Analyse als Markdown-Text. |
| `provider`, `model` | Der Typ des Modellanbieters, etwa `openai`, `anthropic` oder `openai_compatible`, und der Modellname. |
| `promptBuiltinKey`, `promptHash` | Die Prompt-Vorlage und ein Hash des daraus erzeugten Prompts für Audits. |
| `promptTokens`, `completionTokens`, `finishReason` | Der Tokenverbrauch und der Grund für das Ende der Generierung, wie vom Anbieter gemeldet. |
| `createdAt`, `updatedAt` | Mikrosekunden seit der Unix-Epoche. `updatedAt` ändert sich bei jeder Neuerstellung der Analyse. |

**Fehler**

| Status | Ursache |
|---|---|
| `400` | Der `POST`-Aufruf hat für die Organisation keinen aktivierten Modellanbieter mit API-Schlüssel gefunden. |
| `403` | Dem Token fehlt die für den Aufruf erforderliche Berechtigung. |
| `404` | Der Vorfall existiert nicht oder der `GET`-Aufruf hat noch keine Analyse gefunden. |
