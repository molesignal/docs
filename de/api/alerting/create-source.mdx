```http
POST /api/v1/alerts/sources
```

Erstellt eine [Alarmquelle](/de/alerting/sources). Erfordert `alerts.sources.manage`. Der `token` in der Antwort erscheint nur dieses eine Mal; verwenden Sie ihn, um [Alarme senden](/de/api/alerting/send-alerts) aufzurufen. Bei aktivierter Föderation wird die Quelle mit den anderen Clustern synchronisiert.

| Feld | Typ | Beschreibung |
|---|---|---|
| `kind` | string | Bei der Erstellung erforderlich: `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` oder `email`. |
| `name` | string | Erforderlich, bis zu 128 Zeichen. |
| `enabled` | boolean | Standardwert `true`. |
| `escalationPolicyId` | string \| null | Eine ID einer Eskalationsrichtlinie der Organisation oder `default`. Ohne diese Angabe oder mit `null` wird nichts eskaliert, und nur Benachrichtigungsrichtlinien benachrichtigen. |
| `severity` | string | Wird verwendet, wenn ein Alarm keinen Schweregrad enthält: `critical`, `error`, `warning` (der Standard) oder `info`. |
| `labels` | object | Bis zu 32 zusätzliche Labels. Ein Schlüssel besteht aus Buchstaben, Ziffern und `_ . - : /`, darf nicht mit `alert.` beginnen und nicht `external.kind` sein. |
| `email` | object | Wie eine E-Mail-Quelle eine Mail liest: `allowedSenders` (Adressen, `@domain` oder `*`), `resolvePattern`, `dedupPattern` und `ignorePattern`; siehe [E-Mail](/de/alerting/sources#e-mail). Wird die Angabe bei einer Aktualisierung weggelassen, bleibt sie unverändert. |
| `homeCluster` | string | Der Föderations-Cluster, auf dem Incidents geöffnet werden: dieser Cluster oder ein aktivierter Remote-Cluster. Eine neue Quelle ohne diese Angabe verwendet diesen Cluster; ohne Föderation hat sie keine Wirkung. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

Die Antwort ist die Quelle mit ihrem `token`. [Alarmquellen auflisten](/de/api/alerting/list-sources) beschreibt die übrigen Felder.

**Fehler**

| Status | Ursache |
|---|---|
| `400` | Ein Feld ist fehlerhaft, etwa ein leerer Name, eine nicht vorhandene Eskalationsrichtlinie oder ein empfangender Cluster, der weder dieser Cluster noch ein aktivierter Remote-Cluster ist. |
| `403` | Dem Token fehlt `alerts.sources.manage`. |
