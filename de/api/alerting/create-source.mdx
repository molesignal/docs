```http
POST /api/v1/alerts/sources
```

Erstellt eine [Alarmquelle](/de/alerting/sources). Dafür ist die Berechtigung `alerts.sources.manage` erforderlich. Die Antwort enthält `token` nur dieses eine Mal. Verwenden Sie dieses Token für den Aufruf von [Alarme senden](/de/api/alerting/send-alerts). Bei aktivierter Föderation synchronisiert MoleSignal die Quelle mit den anderen Clustern.

| Feld | Typ | Beschreibung |
|---|---|---|
| `kind` | string | Beim Erstellen erforderlich: `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix` oder `email`. |
| `name` | string | Erforderlich, maximal 128 Zeichen. |
| `enabled` | boolean | Standardwert: `true`. |
| `escalationPolicyId` | string \| null | ID einer Eskalationsrichtlinie der Organisation oder `default`. Fehlt das Feld oder ist es `null`, löst MoleSignal keine Eskalation aus. Nur Benachrichtigungsrichtlinien lösen dann Benachrichtigungen aus. |
| `severity` | string | Schweregrad für Alarme ohne eigenen Schweregrad: `critical`, `error`, `warning` (Standardwert) oder `info`. |
| `labels` | object | Bis zu 32 zusätzliche Labels. Ein Schlüssel darf nur Buchstaben, Ziffern und die Zeichen `_ . - : /` enthalten, nicht mit `alert.` beginnen und nicht `external.kind` lauten. |
| `email` | object | Legt fest, wie eine E-Mail-Quelle eingehende E-Mails verarbeitet: `allowedSenders` (Adressen, `@domain` oder `*`), `resolvePattern`, `dedupPattern` und `ignorePattern`. Siehe [E-Mail](/de/alerting/sources#e-mail). Lassen Sie das Feld bei einer Aktualisierung weg, um den bisherigen Wert beizubehalten. |
| `homeCluster` | string | Cluster der Föderation, auf dem MoleSignal Incidents eröffnet: dieser Cluster oder ein aktivierter Remote-Cluster. Fehlt das Feld beim Erstellen einer Quelle, verwendet MoleSignal diesen Cluster. Ohne Föderation hat das Feld keine Auswirkung. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

Die Antwort enthält die Quelle samt `token`. Eine Beschreibung der übrigen Felder finden Sie unter [Alarmquellen auflisten](/de/api/alerting/list-sources).

**Fehler**

| Status | Ursache |
|---|---|
| `400` | Ein Feld enthält einen ungültigen Wert, etwa einen leeren Namen, eine nicht vorhandene Eskalationsrichtlinie oder einen Zielcluster, der weder dieser Cluster noch ein aktivierter Remote-Cluster ist. |
| `403` | Dem Token fehlt die Berechtigung `alerts.sources.manage`. |
