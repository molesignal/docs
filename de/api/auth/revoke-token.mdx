```http
DELETE /api/v1/auth/tokens/{id}
```

Widerruft ein beliebiges Token der Organisation sofort. Eine spätere Anfrage mit dem Token schlägt mit `401` und der Meldung `api token revoked` fehl. Der Aufruf erfordert `api_tokens.revoke`.

**Pfadparameter**

| Parameter | Typ | Hinweise |
|---|---|---|
| `id` | string | Die `id`, die der Aufruf zum Ausstellen oder Auflisten des Tokens zurückgegeben hat. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

Bei einer unbekannten ID gibt der Aufruf `404` zurück. Wenn Sie ein Token widerrufen, das ein Sender zur Datenübermittlung nutzt, stoppt der Sender die Übermittlung. Ersetzen Sie das Token daher zuerst im Sender.

## Eigenes Token

```http
DELETE /api/v1/me/api-tokens/{id}
```

Widerruft eines der persönlichen Tokens oder das Standard-Token für die Datenaufnahme. Der Aufruf erfordert eine authentifizierte Sitzung und `personal_tokens.manage`. Bei einem fremden Token gibt der Aufruf `404` zurück.
