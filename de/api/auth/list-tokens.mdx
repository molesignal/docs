```http
GET /api/v1/auth/tokens
```

Gibt die Metadaten aller API-Token der aktiven Organisation zurück, einschließlich Standard-Intake-Token, RUM-Client-Token und Token von Dienstkonten. Der Aufruf gibt weder das Token im Klartext noch den geheimen Hash zurück. Der Aufruf erfordert `api_tokens.read`.

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "k7m2q9xv4b",
    "name": "grafana-readonly",
    "tokenKind": "personal",
    "userId": "<user-id>",
    "policyId": null,
    "permissions": ["dashboards.read", "streams.query", "streams.read"],
    "applicationId": null,
    "serviceAccountId": null,
    "expiresAt": 1798000000000000,
    "lastUsedAt": null,
    "revoked": false,
    "createdAt": 1790000000000000
  }
]
```
</ResponseExample>

| Feld | Hinweise |
|---|---|
| `tokenKind` | `personal`, `serviceAccount`, `default_intake` oder `rum_client`. |
| `userId` | Das Benutzerkonto, das das Token ausgestellt hat. Ein persönliches Token oder ein Standard-Intake-Token handelt im Namen dieses Kontos. |
| `policyId` | Die Berechtigungsrichtlinie, die für das Token gilt, andernfalls `null`. |
| `permissions` | Die für das Token festgelegten Berechtigungen, andernfalls `null`. Gilt auch keine Richtlinie, hat das Token dieselben Berechtigungen wie das Benutzer- oder Dienstkonto, in dessen Namen es handelt. |
| `applicationId` | Die Anwendung, an die ein `rum_client`-Token gebunden ist, andernfalls `null`. |
| `serviceAccountId` | Das Dienstkonto, in dessen Namen das Token handelt, andernfalls `null`. |
| `expiresAt` | `null`, wenn das Token nie abläuft. |
| `lastUsedAt` | `null` bis zur ersten Verwendung. |
| `revoked` | `true`, sobald das Token widerrufen ist. |

## Eigene Token

```http
GET /api/v1/me/api-tokens
```

Gibt die persönlichen Token und das Standard-Intake-Token des angemeldeten Kontos mit denselben Feldern zurück. Der Aufruf erfordert eine authentifizierte Sitzung und `personal_tokens.manage`.
