```http
GET /api/v1/me/api-tokens/default
```

Gibt das Standardtoken für die Datenerfassung des angemeldeten Kontos zurück und erstellt es beim ersten Aufruf. Im Gegensatz zu anderen Tokens gibt der Aufruf dieses Token jedes Mal im Klartext zurück. So kann die Seite **Datenquelle** ein sofort einsatzbereites Token anzeigen. Das Token handelt im Namen des angemeldeten Kontos und unterliegt der integrierten Richtlinie **Datenerfassung** mit den Berechtigungen `logs.write`, `metrics.write`, `traces.write`, `profiles.write` und `apm.deploy`. Es läuft nie ab und hat den `tokenKind` `default_intake`. Der Aufruf setzt eine authentifizierte Sitzung, `personal_tokens.manage` und beide Berechtigungen der Richtlinie voraus.

<RequestExample>
```bash cURL
curl -b ms-cookies.txt http://localhost:5080/api/v1/me/api-tokens/default
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3JtzUbBKtQCD7mFELKp2zDRum9f",
  "prefix": "r4fp1xwgpe",
  "token": "mspat-r4fp1xwgpe<secret>",
  "tokenKind": "default_intake",
  "policyId": "builtin:data_intake",
  "permissions": null,
  "applicationId": null,
  "createdAt": 1790000000000000
}
```
</ResponseExample>

Verwenden Sie das Token in Collectors, Agenten und SDK-Exportern. Siehe [Datenquelle](/de/intake#token-für-die-datenerfassung).
