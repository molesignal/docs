```http
POST /api/v1/saved_views
```

Speichert eine Abfrage mit einem relativen Zeitraum. Der Aufruf erfordert `saved_views.create`.

**Anfragetext**

| Feld | Typ | Erforderlich | Hinweise |
|---|---|---|---|
| `name` | Zeichenfolge | Ja | Anzeigename. |
| `language` | Zeichenfolge | Ja | `sql` oder `promql`. |
| `statement` | Zeichenfolge | Ja | Abfragetext. |
| `timeRangeSecs` | Ganzzahl | Ja | Relatives Zeitfenster von 1 bis 31.622.400 Sekunden. Bei einem Wert außerhalb dieses Bereichs gibt die API `400` zurück. |
| `stream` | Zeichenfolge | Nein | Name des primären Streams. |
| `tags` | Array aus Zeichenfolgen | Nein | Labels zum Filtern. |
| `pinned` | Boolescher Wert | Nein | Zeigt die Ansicht an erster Stelle an. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/saved_views \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = '"'"'error'"'"'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true
  }'
```
</RequestExample>

Die Antwort enthält die erstellte Ansicht im selben Format wie unter [Gespeicherte Ansichten auflisten](/de/api/query/list-saved-views).
