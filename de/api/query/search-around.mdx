```http
POST /api/v1/query/search_around
```

Liefert die Ereignisse unmittelbar vor und nach einem Ereignis in einem Zeitfenster von jeweils 24 Stunden. Die Standardanzahl beträgt 50. Zulässig sind Werte von 1 bis 1000. Der Aufruf erfordert `streams.query`, für Systemtelemetrie `sys.telemetry.read`.

`before` enthält die Ereignisse mit einem Zeitstempel am oder vor dem durch den Zeiger angegebenen Zeitpunkt, mit dem neuesten zuerst. Wenn das Ereignis selbst gespeichert ist, steht es daher in der ersten Zeile. `after` enthält die Ereignisse nach dem angegebenen Zeitpunkt, mit dem ältesten zuerst. Wenn der Stream nicht existiert, liefert der Aufruf statt eines Fehlers leere Werte für `before` und `after`.

**Anfragetext**

| Feld | Typ | Erforderlich | Standardwert |
|---|---|---|---|
| `eventTimestampUs` | Ganzzahl | Ja | |
| `stream` | Zeichenfolge | Ja | |
| `streamType` | Zeichenfolge | Ja | |
| `eventFingerprint` | Zeichenfolge | Nein | Der Server gibt den Wert in `pointer` zurück, verwendet ihn aber nicht zur Auswahl der Ereignisse. |
| `before` | Ganzzahl | Nein | 50 |
| `after` | Ganzzahl | Nein | 50 |
