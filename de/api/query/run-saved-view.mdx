```http
GET  /api/v1/saved_views/{id}
POST /api/v1/query
```

Eine gespeicherte Ansicht speichert `language`, `statement`, `stream` und einen relativen Zeitraum in `timeRangeSecs`. Es gibt keinen separaten Endpunkt zum Ausführen der Abfrage. Die Webanwendung verwendet den folgenden Ablauf mit zwei Anfragen. Dafür sind `saved_views.read` und `streams.query` erforderlich:

1. Laden Sie die Ansicht mit `GET /api/v1/saved_views/{id}`.
2. Berechnen Sie einen absoluten Zeitraum, der zum aktuellen Zeitpunkt endet: `end` ist die aktuelle Zeit in Mikrosekunden. Für `start` ziehen Sie von `end` das Produkt aus `timeRangeSecs` und 1.000.000 ab.
3. Senden Sie die gespeicherten Werte `language` und `statement`, den berechneten Zeitraum `timeRange` und den Stream an den Endpunkt [Abfrage ausführen](/de/api/query/execute).

<RequestExample>
```bash cURL
VIEW=$(curl -s http://localhost:5080/api/v1/saved_views/$VIEW_ID \
  -H "authorization: Bearer $MS_TOKEN")

END=$(date +%s)000000
START=$((END - $(echo "$VIEW" | jq .timeRangeSecs) * 1000000))

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "{\"orgId\":\"$MS_ORG\",
       \"language\":$(echo "$VIEW" | jq .language),
       \"statement\":$(echo "$VIEW" | jq .statement),
       \"timeRange\":{\"start\":$START,\"end\":$END},
       \"stream\":{\"name\":$(echo "$VIEW" | jq .stream),\"streamType\":\"logs\"}}"
```
</RequestExample>

Die gespeicherte Ansicht enthält nur den Stream-Namen, nicht den Typ. Geben Sie daher den Stream-Typ an, zu dem die Ansicht gehört.
