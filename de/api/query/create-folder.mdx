```http
POST /api/v1/folders
```

Erstellt einen Dashboard-Ordner. Der Aufruf erfordert `dashboards.folders.manage`. Zum Auflisten, Bearbeiten und Löschen sind `dashboards.folders.read`, `dashboards.folders.manage` bzw. `dashboards.folders.delete` erforderlich.

**Anfragetext**

| Feld | Typ | Pflichtfeld | Hinweise |
|---|---|---|---|
| `name` | string | Ja | Name des Ordners. |
| `parentId` | string oder `null` | Nein | ID des übergeordneten Ordners in derselben Organisation. `null` erstellt einen Ordner auf oberster Ebene. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parentId":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "orgId": "<organization-id>",
  "name": "Operations",
  "parentId": null
}
```
</ResponseExample>

`GET /api/v1/folders` listet die Ordner auf. `DELETE /api/v1/folders/{id}` gibt `{"deleted": "<id>"}` zurück. Enthält der Ordner noch Dashboards oder Unterordner, gibt der Aufruf `409` zurück.
