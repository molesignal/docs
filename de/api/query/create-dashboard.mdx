```http
POST /api/v1/dashboards
```

Erstellt ein Dashboard. Der Request-Body enthält das vollständige Dashboard-Modell unter `model` und kann eine `folderId` angeben. Die `uid` muss innerhalb der Organisation eindeutig sein. Andernfalls gibt der Aufruf `409` zurück. Der Aufruf erfordert `dashboards.create`.

**Pflichteigenschaften des Modells**

| Eigenschaft | Hinweise |
|---|---|
| `engine` | `molesignal-dashboard`. |
| `schemaVersion` | `2`. |
| `uid`, `title`, `tags` | Identifikation. `uid` und `title` dürfen nicht leer sein. `tags` ist ein Array. |
| `editable`, `defaultDashboard` | Boolesche Werte. |
| `timeSettings` | `timezone`, `defaultFrom` und `defaultTo`. |
| `refreshSettings` | `mode`, `enabled`, `defaultInterval` und `allowedIntervals`. |
| `variables`, `annotations`, `links`, `elements` | Arrays. Bei einem leeren Dashboard sind sie leer. |
| `layout` | Ein Raster mit `type`, `columns`, `rowHeight` und `gap`. |

Fehlen Pflichteigenschaften im Modell, gibt der Aufruf `400` mit `validation_failed` und je einem Eintrag in `issues` pro fehlender Eigenschaft zurück.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/dashboards \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "model": {
      "engine": "molesignal-dashboard",
      "schemaVersion": 2,
      "uid": "service-overview",
      "title": "Service overview",
      "tags": ["operations"],
      "editable": true,
      "defaultDashboard": false,
      "timeSettings": { "timezone": "browser", "defaultFrom": "now-6h", "defaultTo": "now" },
      "refreshSettings": { "mode": "interval", "enabled": true, "defaultInterval": "30s",
                           "allowedIntervals": ["off", "30s", "1m", "5m"] },
      "variables": [],
      "annotations": [],
      "links": [],
      "layout": { "type": "grid", "columns": 24, "rowHeight": 8, "gap": 8 },
      "elements": []
    },
    "folderId": null
  }'
```
</RequestExample>

<ResponseExample>

Erstellen Sie zuerst Panels im Editor. Exportieren Sie dann das Modell eines vorhandenen Dashboards mit `GET /api/v1/dashboards/{id}`, um es als Vorlage zu verwenden. Weitere Routen: `GET /api/v1/dashboards`, `PUT` und `DELETE /api/v1/dashboards/{id}`.
