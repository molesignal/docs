```http
GET /api/v1/saved_views
```

Gibt die gespeicherten Ansichten der Organisation zurück. Fügen Sie `?pinned=true` hinzu, um nur angeheftete Ansichten abzurufen. Der Aufruf erfordert `saved_views.read`.

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/saved_views?pinned=true" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KE7RbW5ShK8cbrZZq4I4O3XUge",
    "orgId": "<organization-id>",
    "ownerUserId": "<user-id>",
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = 'error'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true,
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

Weitere Routen: `GET /api/v1/saved_views/{id}` gibt eine einzelne Ansicht zurück, und `DELETE /api/v1/saved_views/{id}` antwortet mit `deleted`.

## Alle oder nur angeheftete Ansichten auflisten

Lassen Sie `pinned` weg oder setzen Sie `pinned=false`, um alle Ansichten unabhängig davon aufzulisten, ob sie angeheftet sind. `pinned=false` bedeutet nicht „nur nicht angeheftete Ansichten“. Setzen Sie `pinned=true`, wenn Sie eine Schnellzugriffsliste für angeheftete Ansichten erstellen.

Die Anfrage gibt die Definitionen der aktuellen Organisation zurück, keine Abfrageergebnisse. Die Antwort ist ein JSON-Array. Wenn keine Ansicht dem Filter entspricht, ist `[]` ein gültiges Ergebnis. Wenn eine erwartete Ansicht fehlt, prüfen Sie die den Zugangsdaten zugeordnete Organisation und entfernen Sie den Filter für angeheftete Ansichten, bevor Sie davon ausgehen, dass die Ansicht gelöscht wurde.

## Gespeicherte Abfrage lesen

| Feld | Verwendung |
|---|---|
| `id` | Übergeben Sie die ID an den Detail- oder Ausführungsendpunkt. |
| `language`, `statement` | Abfragesprache und Text der gespeicherten Abfrage. |
| `stream` | Gespeicherter Stream-Kontext, sofern vorhanden. |
| `timeRangeSecs` | Gespeicherte Dauer des Zeitfensters in Sekunden. |
| `tags`, `pinned` | Metadaten zum Organisieren von Ansichten und zur Navigation, keine Abfragefilter. |
| `createdAt`, `updatedAt` | Zeitstempel in Mikrosekunden. |

Das Lesen einer Definition führt die Abfrage nicht aus und erteilt keine Berechtigung zum Abfragen der Daten. Folgen Sie der Anleitung [Gespeicherte Ansicht ausführen](/de/api/query/run-saved-view), um eine Ansicht mit den erforderlichen Berechtigungen auszuführen. Unter [Gespeicherte Ansicht erstellen](/de/api/query/create-saved-view) erfahren Sie, wie Sie eine Abfrage speichern. Die Anleitung für die Benutzeroberfläche finden Sie unter [Gespeicherte Ansichten](/de/saved-views).
