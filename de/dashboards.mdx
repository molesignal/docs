Ein Dashboard ist ein Raster aus Panels, das ein Team gemeinsam im Blick behält. Jedes Panel führt eine eigene Abfrage für die
Datenströme des Arbeitsbereichs aus und stellt das Ergebnis dar. Variablen über dem Raster stellen alle Panels gleichzeitig auf einen anderen
Service, Host oder eine andere Umgebung um.

Diese Seite erklärt, wie Sie Dashboards finden und verwenden. Informationen zum Erstellen oder Bearbeiten finden Sie unter
[Dashboard erstellen](/de/dashboards/edit) und [Variablen](/de/dashboards/variables).

## Dashboard-Liste

Öffnen Sie **Dashboards**. Im Kopfbereich steht die Anzahl der Dashboards und Ordner. Grenzen Sie die Liste ein über:

- das Filterfeld für die Suche nach Namen;
- die Bereiche **Alle**, **Meine**, **Favoriten** und **Tags**;
- einen bestimmten Ordner oder **Alle** Ordner;
- das Layout **Raster** oder **Liste**.

Im Kopfbereich finden Sie auch **Neues Dashboard**, **JSON importieren** und **Ordner verwalten**. Klicken Sie auf das Sternsymbol eines
Dashboards, um es zu den **Favoriten** hinzuzufügen. Das Menü am Ende jedes Dashboard-Eintrags bietet diese Aktionen:

| Aktion | Wirkung |
|---|---|
| **Öffnen**, **Bearbeiten**, **Teilen** | Öffnet das Dashboard, den Editor oder den Dialog zum Teilen. |
| **In Ordner verschieben** | Verschiebt das Dashboard in einen anderen Ordner. |
| **Kopie erstellen** | Erstellt eine bearbeitbare Kopie mit dem Namen `<title> copy`. |
| **JSON exportieren** | Lädt das Dashboard-Modell herunter. Über **JSON importieren** lässt es sich wieder importieren. |
| **Als NOC-Anzeige festlegen** | Zeigt das Dashboard auf dem [NOC-Wallboard](#noc-wallboard) dieses Browsers an. |
| **Löschen** | Löscht das Dashboard und seine Panels. Diese Aktion lässt sich nicht rückgängig machen. |

## Ordner

Ordner gruppieren Dashboards auf bis zu drei Ebenen. Wählen Sie **Ordner verwalten** und dann **Neuer Ordner** für einen
Ordner auf der obersten Ebene oder **Neuer Unterordner** für einen Unterordner im ausgewählten Ordner.

Dashboards ohne Ordnerzuordnung liegen im Ordner **Standard**. Dieser Ordner lässt sich weder umbenennen noch löschen und kann keine
Unterordner enthalten. Verschieben Sie vor dem Löschen eines Ordners alle enthaltenen Dashboards und Unterordner aus diesem Ordner.

## Dashboard lesen

Der Kopfbereich eines Dashboards zeigt den Ordner, die Anzahl der Panels und die letzte Änderung sowie diese Bedienelemente:

| Bedienelement | Funktion |
|---|---|
| Zeitauswahl | Legt den Zeitraum für alle Panels fest. Die Zeiten erscheinen in der persönlich eingestellten Standardzeitzone. Wählen Sie unten in der Zeitauswahl **Ändern**, um eine andere Zeitzone anzuzeigen. |
| **Aktualisieren** | Führt die Abfragen aller Panels erneut aus. Legen Sie im danebenliegenden Menü die automatische Aktualisierung fest: **Aus**, **Automatisch** oder ein festes Intervall. **Automatisch** passt das Intervall an den Zeitraum und die Panelbreite an. |
| Variablen | Wählen Sie Werte für die [Variablen](/de/dashboards/variables). Die URL speichert sie als `var-<name>=<value>`, damit ein kopierter Link dieselbe Ansicht öffnet. |
| **Teilen** | Öffnet den [Dialog zum Teilen](/de/resource-sharing). |
| **Bearbeiten** | Öffnet den [Editor](/de/dashboards/edit). Bei einem schreibgeschützten Dashboard steht stattdessen **Kopie erstellen** zur Verfügung. |
| Mehr | **Dashboard-Details anzeigen** mit ID, UID, Eigentümer und Schema; **NOC-Anzeige**; **Kopie erstellen** und **JSON exportieren**. |

Bewegen Sie den Mauszeiger über ein Panel, um dessen Beschreibung zu sehen. Das Panelmenü bietet diese Aktionen:

| Aktion | Wirkung |
|---|---|
| **Ansicht** | Zeigt nur dieses Panel in voller Größe an. |
| **Bearbeiten** | Öffnet das Panel im Editor. |
| **Daten erkunden** | Öffnet die Abfrage des Panels im Explorer mit den gesetzten Variablenwerten und demselben Zeitraum. |
| **Abfragen untersuchen** | Zeigt die Abfragedefinitionen des Panels als JSON an. |
| **Teilen** | Kopiert einen Link zum Panel. |
| **Daten exportieren** | Lädt die Daten des Panels als CSV herunter. |
| **Bild exportieren** | Lädt ein Bild des Panels herunter. |
| **Kopieren** | Kopiert das Panel als JSON zum Einfügen in ein anderes Dashboard. |
| Datenlinks | Öffnet die [Datenlinks](/de/dashboards/edit#datenlinks) des Panels. |
| **Alarm erstellen** | Öffnet eine neue [Alarmregel](/de/alerting/rules) auf Basis der Panelabfrage. |
| **Analyse durch Mole Agent** | Beauftragt [Mole Agent](/de/agent) mit der Analyse der im Panel angezeigten Daten. |

## Dashboard importieren

Wählen Sie **JSON importieren**. Fügen Sie dann das JSON eines MoleSignal-Dashboards ein oder laden Sie eine `.json`-Datei hoch. Wählen Sie einen Ordner
und klicken Sie auf **Importieren**. Verwenden Sie das JSON aus **JSON exportieren** oder das JSON, das
`GET /api/v1/dashboards/{id}` als `model` zurückgibt. Das Feld `engine` muss den Wert `molesignal-dashboard` haben.

Grafana-Dashboards lassen sich nicht als JSON importieren. Bauen Sie das Dashboard im Editor nach. PromQL-Ausdrücke können Sie
unverändert in Metrik-Panels einfügen. Wenn das Dashboard in Grafana bleiben soll, greifen Sie auf MoleSignal
über die [Grafana-Datenquelle](/de/query/grafana) zu.

## Dashboard mit Mole Agent entwerfen

Bitten Sie [Mole Agent](/de/agent) um einen Dashboard-Entwurf, zum Beispiel: „Ein Dashboard für den
Checkout-Service“. Mole Agent bereitet einen Entwurf vor, ohne ein Dashboard anzulegen, und verlinkt auf **KI-Dashboard-Entwurf**:

1. Prüfen Sie die **Schreibgeschützte Vorschau**. Sie nutzt dieselbe Darstellung wie ein reguläres Dashboard.
2. Prüfen Sie unter **Vorabprüfung der Abfragen** das Ergebnis des einmaligen Laufs jeder Panelabfrage: **Bestanden**, **Leeres Ergebnis** oder
   **Übersprungen**. Prüfen Sie auch etwaige **Warnungen bei der Generierung** oder **Zu behebende Probleme**.
3. Wählen Sie **Erstellungsvorschlag einreichen**. Wenn die Richtlinie für die Erstellung eine Prüfung verlangt, bleibt der Entwurf bis zur
   Freigabe offen. Wählen Sie andernfalls **Bestätigen und erstellen**.

Ein Entwurf ist an sein Modell gebunden und läuft nach einiger Zeit ab. Stellen Sie für Änderungen eine neue Anfrage.

## Integrierte RUM-Dashboards

Ein Arbeitsbereich mit RUM-Anwendungen enthält für jeden Anwendungstyp ein schreibgeschütztes Dashboard mit den Tags `内置` und
`rum`:

| Dashboard | Für | Anzeige |
|---|---|---|
| `RUM · 浏览器应用` | Browseranwendungen | Sitzungen, fehlerfreie Sitzungen und Sitzungen mit Frustrationssignalen; LCP, INP und CLS jeweils als 75. Perzentil mit Trend; Fehler nach Quelle; Seiten, Versionen, Elemente mit Frustrationssignalen und langsame Hosts; Länder und Browser. |
| `RUM · 移动应用` | Anwendungen für Android, iOS, Flutter und React Native | Sitzungen, Sitzungen ohne Absturz oder Fehler und Sitzungen mit Frustrationssignalen; Sitzungen ohne Absturz, Fehler und Abstürze im Zeitverlauf; Bildschirme, Versionen, Abstürze nach Version, Elemente mit Frustrationssignalen und langsame Hosts; Geräte und Betriebssysteme. |

Der Server installiert das jeweilige Dashboard beim Erstellen der ersten Anwendung dieses Typs sowie beim Start, wenn
der Arbeitsbereich bereits eine passende Anwendung enthält. Änderungen an einem Dashboard durch ein Upgrade übernimmt der Server auf dieselbe
Weise. Die Variablen sind **应用** (Anwendung), **环境** (eine Umgebung oder **全部** für alle
Umgebungen) und **间隔** (die Breite der Balken im Zeitdiagramm). **Im Dashboard öffnen** in der
[RUM-Übersicht](/de/rum#übersicht) öffnet das Dashboard mit der Anwendung und der Umgebung, die auf der
Übersichtsseite ausgewählt sind.

Jedes Panel verwendet eine kurze SQL-Anweisung. Es liest Aufrufe und Sitzungen über `rum_views_latest` und
`rum_sessions_latest`. Beide enthalten die jeweils [neueste Version](/de/query#aktuelle-versionen-von-rum-zeilen).
In ein Perzentil fließen nur Aufrufe ein, für die der jeweilige Wert vorliegt. Die Zahlen entsprechen denen in der Übersicht.
Die Dashboards sind schreibgeschützt. Wählen Sie im Kopfbereich des Dashboards oder in der
Dashboard-Liste **Kopie erstellen**, um eine bearbeitbare Version zu erhalten.

## NOC-Wallboard

Wählen Sie **NOC-Wallboard** in der oberen Leiste, um eine dunkle Vollbildansicht für einen Wandbildschirm zu öffnen.
Drücken Sie `Esc` oder wählen Sie **Zurück zur Konsole**, um die Ansicht zu verlassen.

Die Statusleiste fasst den Arbeitsbereich zusammen: aktive Vorfälle mit Schweregrad, den Status der Live-Daten,
die Anzahl der Services, die Anfragerate und die P95-Latenz. Die Panels zeigen:

| Panel | Anzeige |
|---|---|
| **Vorfälle** | Aktive Vorfälle. |
| **Topologie** | Service-Topologie der letzten Stunde. |
| **Zustand** | Jeden Service mit Anfragerate, P95-Latenz und Fehlerrate. |
| **Traffic** | Die Services mit den meisten Anfragen in den letzten 60 Minuten. |

Wählen Sie **Layout konfigurieren**, um das Wallboard anzupassen. Wenden Sie eine Vorlage an (**Plattformbetrieb**, **SRE** oder
**Management**), blenden Sie ein Panel ein oder aus, ändern Sie seine Breite oder Position oder wählen Sie **Zurücksetzen**.
Der Browser speichert das Layout.

Wenn ein Dashboard als NOC-Anzeige festgelegt ist, zeigt das Wallboard stattdessen dieses Dashboard an: den Titel und
alle Panels mit der jeweiligen Abfrage. Das Wallboard stellt die Panels nicht als Diagramme dar. Öffnen Sie für die Diagramme
das Dashboard selbst.

## Berichte und Freigaben

Erstellen Sie aus einem Dashboard einen geplanten [Bericht](/de/reports) für den Versand als PDF, PNG, CSV, SVG oder JSON.
Nutzen Sie **Teilen** für Zugriff mit Anmeldung, workspaceübergreifenden Zugriff oder eingeschränkten öffentlichen Zugriff. Ein öffentliches Dashboard führt nur
die gespeicherten Abfragen seiner Panels aus und befolgt die [Freigaberichtlinie](/de/settings/organization#freigaben-und-öffentlicher-zugriff)
des Workspace.

## Berechtigungen

| Berechtigung | Erlaubt |
|---|---|
| `dashboards.read` | Dashboards und Ordner öffnen. |
| `dashboards.create` | Dashboards erstellen, importieren und kopieren. |
| `dashboards.edit` | Dashboards und Ordner ändern. |
| `dashboards.delete` | Dashboards löschen. |
| `dashboards.share` | Freigaben erstellen und erneuern. |
