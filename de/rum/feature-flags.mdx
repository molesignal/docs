Übergeben Sie dem SDK den ermittelten Wert eines Feature-Flags. Jedes Ereignis des Seitenaufrufs enthält dann diesen Wert:

```ts
molesignalRum.addFeatureFlagEvaluation('checkout_v2', 'treatment');
```

Um die Auswertungen eines Feature-Flag-Dienstes zu erfassen, geben Sie die Ergebnisse an das SDK weiter. LaunchDarkly bietet dafür Inspectors, OpenFeature bietet Hooks:

```ts
LDClient.initialize(id, user, {
  inspectors: [{
    type: 'flag-used',
    name: 'molesignal',
    method: (key, detail) => molesignalRum.addFeatureFlagEvaluation(key, detail.value),
  }],
});

OpenFeature.addHooks({
  after: (context, details) => molesignalRum.addFeatureFlagEvaluation(context.flagKey, details.value),
});
```

## Der Tab „Feature-Flags“

**Feature-Flags** listet die Flags auf, die in Sitzungen im ausgewählten Zeitraum ausgewertet wurden. Das Flag, das in den meisten Sitzungen ausgewertet wurde, steht an erster Stelle. Wählen Sie ein Flag aus, um die Kennzahlen für seine Werte direkt zu vergleichen: die Anzahl der Sitzungen, den Anteil der Seitenaufrufe mit einem Fehler, den Anteil mit einem Anzeichen von Frustration und bei Browseranwendungen das 75. Perzentil von LCP, INP und CLS. Der Wert mit den meisten Seitenaufrufen mit einem Fehler ist rot markiert. **Diese Seitenaufrufe anzeigen** öffnet die entsprechenden Seitenaufrufe im Explorer.

## Feature-Flags abfragen

Verwenden Sie `feature_flags.<key>` wie einen Spaltennamen überall dort, wo der [Explorer](/de/rum/explorer) oder die API ein Feld akzeptiert:

```text
feature_flags.checkout_v2 = 'treatment' AND error.type = 'TypeError'
```

```http
POST /api/v1/rum/aggregate
{ "type": "views", "measures": [{ "fn": "p75", "field": "view.performance.lcp.timestamp" }], "groupBy": ["feature_flags.checkout_v2"] }
```

Das gilt auch für die anderen Schlüssel einer JSON-Spalte: `context.<key>`, `usr.extra.<key>` und `view.custom_timings.<key>`. `GET /api/v1/rum/keys` listet die vorhandenen Schlüssel auf.

Lesen Sie in SQL den Wert eines Schlüssels mit `json_text("feature_flags", 'checkout_v2')` aus. Die Funktion gibt den Wert als Text zurück oder NULL, wenn der Schlüssel in der Zeile fehlt. `json_keys("feature_flags")` listet die Schlüssel einer Zeile auf.

## Mole Agent

Das Tool `get_rum_feature_flags` listet die Feature-Flags auf. Geben Sie `flag` an, um die Werte eines Flags anhand derselben Kennzahlen zu vergleichen.
