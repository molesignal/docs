Eine Variable setzt den oberhalb des Rasters ausgewählten Wert in die Abfragen, Titel und Links aller Panels ein. So genügt ein
Dashboard für alle Dienste, Hosts und Umgebungen, ohne für jeden eine Kopie anzulegen.

## Variable hinzufügen

Öffnen Sie den Editor, wählen Sie **Einstellungen → Variablen** und fügen Sie eine Variable hinzu:

| Feld | Regel |
|---|---|
| **Name** | Name für Abfragen, zum Beispiel `service`. Verwenden Sie nur Buchstaben, Ziffern und `_`. Beginnen Sie mit einem Buchstaben oder `_`: Andere Namen werden nicht ersetzt. |
| **Bezeichnung** | Text oberhalb des Auswahlfelds. |
| **Typ** | Quelle der Werte. Siehe [Typen](#typen). |
| **Abfrage / Optionen** | Je nach Typ die Abfrage oder die Werte. |
| **Mehrfachauswahl** | Erlaubt die gleichzeitige Auswahl mehrerer Werte. |
| **Alle einschließen** | Fügt **Alle** als Option für sämtliche Werte der Liste hinzu. |
| **Ausblenden** | **Keine** zeigt das Auswahlfeld an, **Bezeichnung** blendet dessen Bezeichnung aus, **Variable** blendet das Auswahlfeld aus. |
| **Aktualisieren** | Legt fest, wann eine Abfragevariable ihre Werte erneut abruft: **Nie**, **Beim Laden** oder bei jeder Änderung von **Zeitraum**. |

Speichern Sie das Dashboard, um die Variable zu übernehmen.

## Typen

| Typ | Werte |
|---|---|
| **Abfrage** | Werte aus den Daten. Siehe [Abfragevariablen](#abfragevariablen). |
| **Benutzerdefiniert** | Feste, kommagetrennte Liste, zum Beispiel `prod, staging, dev`. |
| **Text** | Eingabe im Textfeld oberhalb des Rasters. |
| **Konstante** | Fester Wert im Dashboard-Modell. Er erscheint nicht oberhalb des Rasters. |
| **Intervall**, **Datenquelle** | Liste im Dashboard-Modell, zum Beispiel aus importiertem JSON. |

### Abfragevariablen

Eine Abfragevariable ruft ihre Werte für den aktuellen Zeitraum ab. Wählen Sie den **Abfragetyp**:

| Abfragetyp | Felder | Werte |
|---|---|---|
| **Labelwerte** | **Metrik** und **Bezeichnung**, zum Beispiel `http_requests_total` und `service`. | Werte des Labels in den Zeitreihen der Metrik, über alle Metrik-Streams hinweg, die diese Metrik enthalten. |
| **Klassische Abfrage** | Ausdruck wie `label_values(http_requests_total, service)`. | Dieselben Werte wie bei **Labelwerte**. |
| **SQL** | **Stream-Name**, **Stream-Typ** und eine SQL-Anweisung. | Werte der ersten Spalte. |

Der erste Wert ist der Standardwert. Eine Abfrage kann eine andere Variable verwenden, zum Beispiel eine SQL-Anweisung
mit `WHERE environment = '$env'`. So grenzt die Auswahl einer Umgebung die verfügbaren Dienste ein.

## Variable verwenden

Schreiben Sie `$name` oder `${name}` in eine Abfrage, einen Panel-Titel, ein Textelement oder einen Link. Verwenden Sie geschweifte Klammern,
wenn auf den Namen Buchstaben folgen, zum Beispiel `${service}_errors`. Bei mehreren Werten trennt ein Komma
die einzelnen Werte. Geben Sie ein Format an, um die Ausgabe zu ändern:

| Syntax | Ergebnis für `checkout` und `payment` |
|---|---|
| `${service}` | `checkout,payment` |
| `${service:csv}` | `checkout,payment` |
| `${service:pipe}` | `checkout\|payment` |
| `${service:regex}` | `checkout\|payment`, wobei jeder Wert für einen regulären Ausdruck maskiert ist. |
| `${service:sqlstring}` | `'checkout','payment'`, mit einfachen Anführungszeichen für SQL, zum Beispiel in `IN (${service:sqlstring})`. |
| `${service:json}` | `["checkout","payment"]` |

Ein PromQL-Panel mit `sum(rate(http_requests_total{service=~"${service:regex}"}[5m]))` berücksichtigt beispielsweise
nur die ausgewählten Dienste.

## Werte in der URL

Die Dashboard-URL enthält die ausgewählten Werte als `var-<name>=<value>`. Bei einer Variable mit Mehrfachauswahl steht für jeden
Wert ein eigener Parameter in der URL. Kopieren Sie die URL oder erstellen Sie einen Link mit diesen Parametern, um das
Dashboard mit derselben Auswahl zu öffnen. Auch ein [Datenlink](/de/dashboards/edit#datenlinks) kann die
Variablen weitergeben.

## Panels anhand einer Variable wiederholen

Wählen Sie auf der Registerkarte **Panel** des Panels eine **Wiederholungsvariable** aus. Das Dashboard zeigt dann für jeden
ausgewählten Wert eine Kopie des Panels an und setzt die Variable darin auf diesen Wert. Wählen Sie die
**Wiederholungsrichtung** (**Horizontal**, **Vertikal** oder **Raster**) und legen Sie **Max. pro Zeile** fest. Das Dashboard speichert nur das ursprüngliche
Panel und zeigt die Kopien entsprechend der Auswahl an.
