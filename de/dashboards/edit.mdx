Wählen Sie auf **Dashboards** **Neues Dashboard** oder bei einem Dashboard **Bearbeiten**, um den Editor zu öffnen. Das Erstellen
eines Dashboards erfordert `dashboards.create`, und das Ändern eines Dashboards erfordert `dashboards.edit`. Ein Dashboard,
dessen Einstellung **Bearbeitbar** deaktiviert ist, etwa ein integriertes, kann nicht geändert werden: Erstellen Sie stattdessen eine Kopie.

## Der Editor

| Steuerelement | Verwendung |
|---|---|
| **Zurück zum Dashboard** | Verlässt den Editor. |
| Dashboard-Titel | Benennt das Dashboard direkt um. |
| **Rückgängig** / **Wiederholen** | Geht in den Änderungen seit dem Öffnen des Editors schrittweise zurück oder vor. |
| **Hinzufügen** | Fügt ein **Panel**, **Text**, **Zeile**, **Gruppe** oder **Tabs** hinzu. |
| **Einstellungen** | Öffnet die [Dashboard-Einstellungen](#dashboard-einstellungen). |
| **Speichern** | Speichert das Dashboard. Vorher wird nichts gespeichert. |

Ziehen Sie ein Element am Griff, um es zu verschieben, und ziehen Sie an seiner Ecke, um seine Größe zu ändern. Wählen Sie ein Element aus, um
seine Position und Struktur in der Seitenleiste zu bearbeiten. Neue Dashboards verwenden ein Raster mit 24 Spalten; ändern Sie es unter
[Einstellungen → Allgemein](#dashboard-einstellungen).

## Elemente

| Element | Verwendung |
|---|---|
| **Panel** | Eine oder mehrere Abfragen, die von einer Visualisierung gezeichnet werden. |
| **Text** | Statisches Markdown oder reiner Text für Notizen, Überschriften und Links. |
| **Zeile** | Eine Kopfzeile über die volle Breite, die die darunterliegenden Elemente enthält. Eine Zeile kann **Anfangs eingeklappt** starten. |
| **Gruppe** | Ein Kasten, der zusammengehörige Elemente zusammenhält. |
| **Tabs** | Mehrere Tabs, jeweils mit eigenen Elementen. Wählen Sie den Tab aus, der zuerst geöffnet wird. |

## Ein Panel bearbeiten

Wählen Sie im Menü eines Panels **Bearbeiten** oder fügen Sie ein Panel hinzu. Der Panel-Editor zeigt eine **Live-Vorschau** des
Panels mit dem aktuellen Zeitraum und den Variablen sowie zwei Gruppen von Tabs:

| Tabs | Inhalt |
|---|---|
| **Abfragen**, **Transformationen**, **Datenlinks** | Was das Panel liest, wie das Ergebnis umgeformt wird und wohin ein Klick führt. |
| **Panel**, **Feld**, **Überschreibungen** | Wie das Panel aussieht, wie Werte angezeigt werden und Ausnahmen für bestimmte Felder. |

### Abfragen

Wählen Sie für jede Abfrage des Panels **Abfrage hinzufügen**. Jede Abfrage hat eine **Ref-ID**, z. B. `A`, eine
**Datenquelle**, eine **Sprache** – **PromQL** oder **SQL** – und den **Ausdruck**. Die Datenquelle
legt die Standardsprache und die anderen Felder fest:

| Datenquelle | Standardsprache | Weitere Felder |
|---|---|---|
| **Metriken** | PromQL | |
| **Logs**, **Traces**, **SQL** | SQL | **Stream-Name** und **Stream-Typ** (**Logs**, **Metriken** oder **Traces**). |
| **Profile** | SQL | **Dienst** und **Profiltyp**, z. B. `cpu`. |

**Legende** benennt die Zeitreihe mit einer Vorlage wie `{{service}}`. **Gemeinsame Abfrage** verwendet eine Abfrage eines
anderen Panels, geschrieben `<panel-id>:<ref-id>`, sodass die Daten nur einmal gelesen werden. Abfragen können
[Variablen](/de/dashboards/variables) wie `$service` verwenden. Unter [Abfragen](/de/query) finden Sie Informationen zu SQL und
PromQL.

Eine SQL-Abfrage, deren `format` `time_series` ist, wie bei den Panels, die der [RUM-Explorer](/de/rum/explorer#zum-dashboard-hinzufügen) hinzufügt,
kann in Langform antworten, eine Zeile pro Zeitpunkt und Gruppe: Eine Zeitreihe zeichnet eine Serie für jede Kombination von Werten ihrer Textspalten
und benennt sie danach.

### Transformationen

Transformationen formen das Ergebnis um, bevor es gezeichnet wird. Sie werden der Reihe nach ausgeführt, und jede kann deaktiviert werden.

| Transformation | Wirkung |
|---|---|
| **Felder filtern**, **Felder organisieren**, **Felder umbenennen** | Felder behalten, ordnen, ausblenden oder umbenennen. |
| **Feld berechnen** | Fügt ein aus anderen berechnetes Feld hinzu. |
| **Reduzieren** | Reduziert jede Zeitreihe auf Werte wie letzter Wert, Mittelwert, Max. oder Summe. |
| **Gruppieren nach**, **Sortieren nach**, **Begrenzen** | Aggregiert nach einem Feld, sortiert und behält die ersten Zeilen. |
| **Beitreten**, **Zusammenführen** | Kombiniert die Ergebnisse mehrerer Abfragen. |
| **Labels in Felder umwandeln**, **Zeilen in Felder umwandeln**, **Zeitreihen in Tabelle umwandeln** | Wandelt Labels, Zeilen oder Zeitreihen in Spalten um. |

### Panel-Optionen

Der Tab **Panel** legt den **Titel**, die beim Überfahren angezeigte **Beschreibung**, die **Breite** und **Höhe**,
die **Visualisierung**, ihre Optionen und ob das Panel **Transparent** ist, fest.

| Visualisierung | Zeichnet |
|---|---|
| **Zeitreihe** | Linien, Balken oder Punkte über die Zeit, mit Optionen für Legende, Tooltip, Füllung und Stapelung. |
| **Balkendiagramm** | Werte, verglichen nach Kategorie. |
| **Balkenanzeige** | Reduzierte Werte als horizontale oder vertikale Balken. |
| **Kennzahl** | Ein Wert, z. B. der letzte, mit optionaler Sparkline. |
| **Messanzeige** | Ein Wert auf einer radialen Skala mit Schwellenwertfarben. |
| **Tabelle** | Zeilen, mit Paginierung. |
| **Logs** | Eine kompakte Log-Liste mit Zeit und Level. |
| **Heatmap** | Die Intensität von Werten über die Zeit. |
| **Zustandsverlauf** | Zustandsänderungen über die Zeit. |
| **Text** | Markdown. |

**Wiederholungsvariable** zeichnet eine Kopie des Panels für jeden Wert einer Variable, in einer **Wiederholungsrichtung**
mit **Horizontal**, **Vertikal** oder **Raster**, bis zu **Max. pro Zeile** Kopien pro Zeile. Weitere Informationen finden Sie unter
[Panels wiederholen](/de/dashboards/variables#panels-anhand-einer-variable-wiederholen).

### Feldoptionen

Der Tab **Feld** legt fest, wie Werte angezeigt werden:

| Option | Verwendung |
|---|---|
| **Einheit**, **Dezimalstellen** | Die Einheit, z. B. Bytes, Prozent oder Sekunden, und die Anzahl der Dezimalstellen. |
| **Min.**, **Max.** | Die Enden der Skala. |
| **Anzeigename** | Ersetzt den Namen des Felds. |
| **Farbschema** | Eine feste Farbe, eine Palette, die Schwellenwertfarben oder eine kontinuierliche Skala. |
| **Schwellenwerte** | Werte, bei denen sich die Farbe ändert, im Modus **Absolut** oder **Prozent**, beginnend bei **Basis**. |
| **Wertzuordnungen** | Zeigt Text, eine Farbe oder ein Symbol für einen Wert, einen Bereich, einen Regex-Treffer oder einen besonderen Wert wie null an. |
| **Text bei fehlendem Wert** | Was das Panel anzeigt, wenn kein Wert vorhanden ist. |

**Überschreibungen** wenden andere Feldoptionen nur auf bestimmte Felder an. Wählen Sie **Überschreibung hinzufügen**, wählen Sie einen Matcher
(**Feldname**, **Regulärer Ausdruck für das Feld**, **Feldtyp** oder **Abfragereferenz**) und **Eigenschaft hinzufügen** für jede Option
zum Ändern.

### Datenlinks

Ein Datenlink macht aus einem Klick auf einen Wert einen Sprung. Wählen Sie **Datenlink hinzufügen**, geben Sie einen **Titel** ein und wählen Sie
das Ziel: **Logs**, **Metriken**, **Traces**, **Profile**, ein anderes **Dashboard** oder eine **Externe**
URL. Legen Sie fest, ob der Link den Zeitraum und die Dashboard-Variablen überträgt und ob er in
einem neuen Tab geöffnet wird. Die Links erscheinen im Menü des Panels.

## Dashboard-Einstellungen

**Einstellungen** hat vier Tabs.

| Tab | Inhalt |
|---|---|
| **Allgemein** | **Titel**, **Beschreibung** und **Tags**. Der Standardzeitraum (**Von**, **Bis**) und **Zeitzone**. Das **Raster**: **Spalten** von 1 bis 48, **Zeilenhöhe** und **Abstand**. **Aktualisieren**: **Aus**, **Intervall** mit einem **Standardintervall** oder **Automatisch**. **Diagramm-Tooltip**: aus oder ein gemeinsames Fadenkreuz über Panels hinweg. **Bearbeitbar**. |
| **Variablen** | Die Variablen des Dashboards. Siehe [Variablen](/de/dashboards/variables). |
| **Annotationen** | Ereignisse, die auf Zeitreihen-Panels gezeichnet werden. |
| **Links** | Links im Kopf des Dashboards. |

Eine Annotation hat einen **Namen**, eine **Quelle**, eine **Anzeige** als **Linie**, **Region** oder **Markierung**, eine
**Farbe** und **Aktiviert**. Listen Sie ihre Ereignisse unter **Ereignisse** mit **Event hinzufügen** auf: eine **Bezeichnung**, einen
**Startzeitstempel (ms)** und für eine Region einen **Endzeitstempel (ms)**.

Eine Annotation der Quelle **Deployments** listet keine Ereignisse auf: Sie markiert die Änderungen der
[Änderungsliste](/de/api/changes) auf jedem Zeitreihen-Panel, Deployments und andere gemeldete Änderungen
und die Versionen, die APM zuerst gesehen hat, der Dienste unter **Dienste** (durch Kommas getrennt) oder aller
Dienste. Annotationen, die mit [`POST /api/v1/changes`](/de/api/changes#annotationen-verwalten) für dieses
Dashboard oder für kein Dashboard aufbewahrt werden, werden ebenfalls auf seinen Zeitreihen-Panels gezeichnet.

Ein Link hat einen **Titel**, einen **Typ** **Dashboard** oder **Extern**, eine **URL** und Schalter, um den
**Zeitraum** und die **Variablen** zu übernehmen und in einem **Neuen Tab** zu öffnen.

## Speichern und wiederverwenden

Wählen Sie **Speichern**. Um ein Panel wiederzuverwenden, wählen Sie in seinem Menü **Kopieren**, um sein JSON zu kopieren, und fügen Sie es in
ein anderes Dashboard ein. Um ein ganzes Dashboard wiederzuverwenden, exportieren Sie es mit **JSON exportieren** und importieren Sie es an anderer Stelle. Weitere Informationen finden Sie unter
[Ein Dashboard importieren](/de/dashboards#dashboard-importieren).
