Wählen Sie unter **Dashboards** die Option **Neues Dashboard** oder in einem Dashboard **Bearbeiten**, um den Editor zu öffnen. Zum Erstellen
eines Dashboards ist `dashboards.create` erforderlich, zum Ändern `dashboards.edit`. Ist **Bearbeitbar**
ausgeschaltet, etwa bei einem integrierten Dashboard, erstellen Sie stattdessen eine Kopie.

## Der Editor

| Bedienelement | Funktion |
|---|---|
| **Zurück zum Dashboard** | Schließt den Editor. |
| Dashboard-Titel | Benennt das Dashboard direkt um. |
| **Rückgängig** / **Wiederholen** | Macht Änderungen seit dem Öffnen des Editors rückgängig oder stellt sie wieder her. |
| **Hinzufügen** | Fügt ein **Panel**, **Text**, eine **Zeile**, eine **Gruppe** oder **Tabs** hinzu. |
| **Einstellungen** | Öffnet die [Dashboard-Einstellungen](#dashboard-einstellungen). |
| **Speichern** | Speichert das Dashboard. Bis dahin bleiben alle Änderungen ungespeichert. |

Ziehen Sie ein Element am Griff, um es zu verschieben, oder an einer Ecke, um seine Größe zu ändern. Wählen Sie ein Element aus, um
seine Position und Struktur in der Seitenleiste zu bearbeiten. Neue Dashboards verwenden ein Raster mit 24 Spalten. Ändern Sie das Raster unter
[Einstellungen → Allgemein](#dashboard-einstellungen).

## Elemente

| Element | Funktion |
|---|---|
| **Panel** | Zeigt die Ergebnisse einer oder mehrerer Abfragen in einer Visualisierung an. |
| **Text** | Statisches Markdown oder Klartext für Notizen, Überschriften und Links. |
| **Zeile** | Eine Kopfzeile über die gesamte Breite, der die darunterliegenden Elemente zugeordnet sind. Für die Zeile lässt sich **Anfangs eingeklappt** aktivieren. |
| **Gruppe** | Ein Container, der zusammengehörige Elemente bündelt. |
| **Tabs** | Mehrere Tabs mit jeweils eigenen Elementen. Wählen Sie den Tab aus, der sich zuerst öffnet. |

## Panel bearbeiten

Wählen Sie im Menü eines Panels **Bearbeiten** oder fügen Sie ein Panel hinzu. Der Panel-Editor zeigt eine **Live-Vorschau** des
Panels mit dem aktuellen Zeitraum und den aktuellen Variablen sowie zwei Gruppen von Tabs:

| Tabs | Inhalt |
|---|---|
| **Abfragen**, **Transformationen**, **Datenlinks** | Welche Daten das Panel abruft, wie es die Ergebnisse umformt und wohin ein Klick führt. |
| **Panel**, **Feld**, **Überschreibungen** | Darstellung des Panels und seiner Werte sowie Ausnahmen für einzelne Felder. |

### Abfragen

Wählen Sie für jede Abfrage des Panels **Abfrage hinzufügen**. Jede Abfrage hat eine **Ref-ID** wie `A`, eine
**Datenquelle**, eine **Sprache** (**PromQL** oder **SQL**) und einen **Ausdruck**. Die Datenquelle
bestimmt die Standardsprache und die weiteren Felder:

| Datenquelle | Standardsprache | Weitere Felder |
|---|---|---|
| **Metriken** | PromQL | |
| **Logs**, **Traces**, **SQL** | SQL | **Stream-Name** und **Stream-Typ** (**Logs**, **Metriken** oder **Traces**). |
| **Profile** | SQL | **Dienst** und **Profiltyp**, zum Beispiel `cpu`. |

**Legende** benennt die Reihen anhand einer Vorlage wie `{{service}}`. **Gemeinsame Abfrage** verwendet eine Abfrage aus
einem anderen Panel erneut. Geben Sie sie als `<panel-id>:<ref-id>` an, damit die Daten nur einmal abgerufen werden. Abfragen können
[Variablen](/de/dashboards/variables) wie `$service` verwenden. Mehr zu SQL und
PromQL finden Sie unter [Abfragen](/de/query).

Eine SQL-Abfrage mit `format` gleich `time_series`, wie in Panels aus dem [RUM-Explorer](/de/rum/explorer#zum-dashboard-hinzufügen),
kann Daten im Langformat liefern: eine Zeile pro Zeitpunkt und Gruppe. Die Zeitreihenvisualisierung zeichnet für jede Wertekombination in den
Textspalten eine eigene Reihe und benennt sie nach diesen Werten.

### Transformationen

Transformationen formen das Ergebnis vor der Darstellung um. Sie laufen der Reihe nach ab und lassen sich einzeln deaktivieren.

| Transformation | Effekt |
|---|---|
| **Felder filtern**, **Felder organisieren**, **Felder umbenennen** | Felder beibehalten, anordnen, ausblenden oder umbenennen. |
| **Feld berechnen** | Ein Feld aus anderen Feldern berechnen und hinzufügen. |
| **Reduzieren** | Jede Reihe auf Werte wie den letzten Wert, den Mittelwert, das Maximum oder die Summe reduzieren. |
| **Gruppieren nach**, **Sortieren nach**, **Begrenzen** | Nach einem Feld aggregieren, sortieren und die ersten Zeilen beibehalten. |
| **Beitreten**, **Zusammenführen** | Die Ergebnisse mehrerer Abfragen kombinieren. |
| **Labels in Felder umwandeln**, **Zeilen in Felder umwandeln**, **Zeitreihen in Tabelle umwandeln** | Labels, Zeilen oder Reihen in Spalten umwandeln. |

### Panel-Optionen

Legen Sie im Tab **Panel** den **Titel**, die **Beschreibung** beim Zeigen mit der Maus, die **Breite** und **Höhe**,
die **Visualisierung** und ihre Optionen fest. Stellen Sie dort auch ein, ob das Panel **Transparent** ist.

| Visualisierung | Darstellung |
|---|---|
| **Zeitreihe** | Linien, Balken oder Punkte im Zeitverlauf, mit Optionen für Legende, Tooltip, Füllung und Stapelung. |
| **Balkendiagramm** | Vergleich von Werten nach Kategorie. |
| **Balkenanzeige** | Reduzierte Werte als horizontale oder vertikale Balken. |
| **Kennzahl** | Ein einzelner Wert, etwa der letzte, mit optionaler Sparkline. |
| **Messanzeige** | Ein einzelner Wert auf einer radialen Skala mit Schwellenwertfarben. |
| **Tabelle** | Zeilen mit Seitennavigation. |
| **Logs** | Eine kompakte Log-Liste mit Uhrzeit und Log-Level. |
| **Heatmap** | Die Intensität von Werten im Zeitverlauf. |
| **Zustandsverlauf** | Zustandsänderungen im Zeitverlauf. |
| **Text** | Markdown. |

**Wiederholungsvariable** erzeugt für jeden Wert einer Variablen eine Kopie des Panels. Als **Wiederholungsrichtung**
stehen **Horizontal**, **Vertikal** und **Raster** zur Wahl. **Max. pro Zeile** begrenzt die Anzahl der Kopien in einer Zeile. Siehe
[Panels wiederholen](/de/dashboards/variables#panels-anhand-einer-variable-wiederholen).

### Feldoptionen

Legen Sie im Tab **Feld** fest, wie das Panel Werte anzeigt:

| Option | Funktion |
|---|---|
| **Einheit**, **Dezimalstellen** | Die Einheit, etwa Byte, Prozent oder Sekunden, und die Anzahl der Dezimalstellen. |
| **Min.**, **Max.** | Die untere und obere Grenze der Skala. |
| **Anzeigename** | Ersetzt den Namen des Felds. |
| **Farbschema** | Eine feste Farbe, eine Palette, die Schwellenwertfarben oder eine kontinuierliche Farbskala. |
| **Schwellenwerte** | Werte, bei denen die Farbe wechselt. Die Skala beginnt bei **Basis** und verwendet den Modus **Absolut** oder **Prozent**. |
| **Wertzuordnungen** | Zeigen Text, eine Farbe oder ein Symbol für einen Wert, einen Wertebereich, eine Übereinstimmung mit einem regulären Ausdruck oder einen Sonderwert wie null an. |
| **Text bei fehlendem Wert** | Text, den das Panel anzeigt, wenn kein Wert vorliegt. |

Mit **Überschreibungen** ändern Sie Feldoptionen nur für bestimmte Felder. Wählen Sie **Überschreibung hinzufügen**, wählen Sie ein Auswahlkriterium
(**Feldname**, **Regulärer Ausdruck für das Feld**, **Feldtyp** oder **Abfragereferenz**) und dann für jede zu ändernde Option **Eigenschaft hinzufügen**.
 
### Datenlinks

Ein Datenlink führt beim Klick auf einen Wert zum festgelegten Ziel. Wählen Sie **Datenlink hinzufügen**, geben Sie einen **Titel** ein und wählen Sie
das Ziel: **Logs**, **Metriken**, **Traces**, **Profile**, ein anderes **Dashboard** oder eine URL vom Typ **Extern**.
Legen Sie fest, ob der Link den Zeitraum und die Dashboard-Variablen übergibt und ob er sich
in einem neuen Tab öffnet. Die Links erscheinen im Menü des Panels.

## Dashboard-Einstellungen

Unter **Einstellungen** stehen vier Tabs zur Verfügung.

| Tab | Inhalt |
|---|---|
| **Allgemein** | **Titel**, **Beschreibung** und **Tags**. Der Standardzeitraum (**Von**, **Bis**) und die **Zeitzone**. Das **Raster**: **Spalten** (1 bis 48), **Zeilenhöhe** und **Abstand**. **Aktualisieren**: **Aus**, **Intervall** mit **Standardintervall** oder **Automatisch**. **Diagramm-Tooltip**: aus oder ein gemeinsames Fadenkreuz für alle Panels. **Bearbeitbar**. |
| **Variablen** | Die Variablen des Dashboards. Siehe [Variablen](/de/dashboards/variables). |
| **Annotationen** | Ereignisse, die in Zeitreihen-Panels erscheinen. |
| **Links** | Links im Kopfbereich des Dashboards. |

Eine Annotation hat einen **Namen**, eine **Quelle**, eine **Anzeige** als **Linie**, **Bereich** oder **Markierung**,
eine **Farbe** und den Schalter **Aktiviert**. Erfassen Sie unter **Ereignisse** mit **Event hinzufügen** für jedes Ereignis eine **Bezeichnung**, einen
**Startzeitstempel (ms)** und bei einem Bereich einen **Endzeitstempel (ms)**.

Ein Link hat einen **Titel**, den **Typ** **Dashboard** oder **Extern** und eine **URL**. Legen Sie über die Schalter fest, ob der Link
den **Zeitraum** und die **Variablen** übergibt und ob er sich in einem **Neuen Tab** öffnet.

## Speichern und wiederverwenden

Wählen Sie **Speichern**. Um ein Panel wiederzuverwenden, wählen Sie in dessen Menü **Kopieren** und fügen Sie das kopierte JSON in
ein anderes Dashboard ein. Um ein ganzes Dashboard wiederzuverwenden, wählen Sie **JSON exportieren** und importieren Sie die Datei am gewünschten Ort. Siehe
[Dashboard importieren](/de/dashboards#dashboard-importieren).
