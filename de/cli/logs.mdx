## Streams auflisten

```bash
molesignal streams
```

Die Liste zeigt alle lesbaren Log-Streams mit der Anzahl ihrer Felder, ihrer Aufbewahrungsdauer und
ihrer Beschreibung. `--type` listet Streams eines anderen Typs auf: `metrics`, `traces`, `profiles` oder
`extend`. `--names` gibt nur die Namen aus, und `--json` gibt pro Zeile einen Stream als JSON aus.

## Neueste Logs ausgeben

```bash
molesignal logs app_logs
```

Der Befehl gibt die neuesten 100 Logs der letzten 15 Minuten aus, beginnend mit dem ältesten. Jede Zeile enthält
die Uhrzeit, die Protokollstufe, den Dienst und die Meldung.

```text
2026-10-18 03:14:15.361 INFO  checkout order 4812 created
2026-10-18 03:14:25.361 ERROR payment gateway timeout after 3 retries
```

Der Befehl liest die Protokollstufe aus einem Feld wie `level`, `severity` oder `severity_text`, den Dienst aus
`service` oder `service.name` und die Meldung aus `message`, `msg`, `body` oder `log`. Bei einem Log
ohne Meldungsfeld gibt er die übrigen Felder als `name=value` aus. Im Terminal erscheint die Ausgabe farbig;
`NO_COLOR` deaktiviert die Farben, und `FORCE_COLOR` behält sie bei der Ausgabe über eine Pipe bei.

| Option | Standardwert | Bedeutung |
|---|---|---|
| `-n`, `--lines <count>` | `100` | Anzahl der neuesten Logs für die erste Ausgabe, höchstens `5000`. |
| `--since <duration>` | `15m` | Zeitraum rückwirkend ab jetzt: `30s`, `10m`, `2h`, `1d`, `1w`. |
| `--from <time>`, `--to <time>` | keiner | Zeitfenster statt `--since`: ISO-Zeitangabe, Ortszeit wie `2026-10-26 14:00` oder relative Zeitangabe wie `2h` vor jetzt. |
| `-q`, `--query <query>` | keiner | Feldabfrage im selben Format wie auf der Seite **Logs**. |
| `--where <condition>` | keiner | SQL-Bedingung für die Felder des Streams. |
| `--fields <a,b,c>` | alle | Gibt die Uhrzeit und nur diese Felder als `name=value` aus. |
| `--json` | aus | Gibt jedes Log als eine JSON-Zeile aus. |
| `--utc` | aus | Gibt Zeitangaben in UTC statt in Ortszeit aus. |
| `--web` | aus | Öffnet dieselben Logs auf der Seite **Logs**, statt sie auszugeben. |

## Logs filtern

`-q` erwartet eine Feldabfrage in derselben Syntax wie auf der Seite **Logs**: Vergleiche wie
`level = 'error'`, `contains`, `MATCH` und `MATCH_TEXT` lassen sich mit `AND` und `OR` verknüpfen und
mit Klammern gruppieren. Ohne Feldangabe sucht der Befehl den Text in `message`:

```bash
molesignal logs app_logs --since 1h -q "level = 'error' AND (service = 'payment' OR timeout)"
```

`--where` erwartet eine SQL-Bedingung für die Felder des Streams, wie in der `WHERE`-Klausel einer Abfrage:

```bash
molesignal logs app_logs --where "status >= 500 AND duration_ms > 2000"
```

Bei Angabe beider Optionen muss ein Log beide Bedingungen erfüllen. Verweist eine Bedingung auf ein fehlendes Feld oder enthält sie ungültiges SQL,
bricht der Befehl ab und gibt den Grund aus.

## Neue Logs live verfolgen

```bash
molesignal logs app_logs -f
```

Nach den neuesten Logs gibt der Befehl weiterhin eingehende Logs aus, bis Sie **Strg+C** drücken:

- Der Befehl ruft alle 2 Sekunden neue Logs ab. Mit `--interval` ändern Sie das Intervall.
- Jeder Abruf beginnt 10 Sekunden vor dem Ende des vorherigen Abrufs. So erscheint auch ein Log, das
  MoleSignal einige Sekunden verspätet erreicht. Jedes Log erscheint nur einmal.
- Gehen mehr Logs ein, als ein Abruf erfassen kann, startet sofort der nächste Abruf.
- Bei einem Verbindungsabbruch versucht die CLI, die Verbindung mit Wartezeiten von bis zu 30 Sekunden wiederherzustellen. Die CLI meldet den Abbruch
  und die Wiederherstellung über die Standardfehlerausgabe.

Die Live-Ausgabe richtet sich nach den Zeitstempeln der Logs. Ein eingehendes Log mit einem Zeitstempel vor dem Beginn
des aktuellen Abrufs erscheint nicht. `--to` lässt sich nicht mit `-f` kombinieren.

## Logs rund um einen Zeitpunkt lesen

`--around` gibt die Logs unmittelbar vor und nach einem Zeitpunkt aus und markiert den Zeitpunkt mit einer Zeile
dazwischen. `-B` und `-A` legen die jeweilige Anzahl fest: standardmäßig je 10, höchstens je 250. `-q` und `--where`
schränken die Auswahl ein:

```bash
molesignal logs app_logs --around "2026-10-26 14:03:12.345" -B 20 -A 20
```

Für `--around` können Sie einen Zeitstempel aus der Ausgabe von `molesignal logs` übernehmen.

## SQL-Abfrage für einen Stream ausführen

`molesignal query` führt eine einzelne schreibgeschützte SQL-Anweisung mit Ausdrücken, Joins und Aggregaten aus und
gibt das Ergebnis als Tabelle aus:

```bash
molesignal query "SELECT level, COUNT(*) AS logs FROM app_logs GROUP BY level ORDER BY logs DESC"
```

Die Abfrage verwendet den ersten Stream nach `FROM`. Mit `--stream` geben Sie einen anderen an. Standardmäßig umfasst das Zeitfenster
die letzte Stunde. `--since`, `--from` und `--to` ändern es. `-n` begrenzt die Anzahl der Zeilen auf standardmäßig `1000` und
höchstens `5000`. `--csv` gibt CSV mit Kopfzeile aus, `--json` jede Zeile als JSON, und
`--web` öffnet die Anweisung auf der Seite **Logs**.

## Felder eines Streams anzeigen

```bash
molesignal fields app_logs
```

Die Liste zeigt jedes Feld mit seinem Typ und seinem Index. Bei Angabe eines Felds listet der Befehl die
häufigsten Werte der letzten Stunde mit ihrer jeweiligen Anzahl auf:

```bash
molesignal fields app_logs service --since 1d
```

`--match` filtert nach Werten, die einen bestimmten Text enthalten. `-n` legt die Anzahl fest, standardmäßig `20`.
`--type` liest einen Stream eines anderen Typs.

## Ausgabe über eine Pipe weiterleiten

`--json` gibt jedes Log mit allen seinen Feldern aus:

```bash
molesignal logs app_logs -n 1000 --since 2h --json | jq -r .message
```

Beendet ein Programm wie `head` das Lesen vorzeitig, endet der Befehl ohne Meldung.

## Zugriff

Die CLI liest Daten mit den MoleSignal-Tools `list_streams`, `query_logs`, `get_stream_schema`,
`search_field_values` und `search_around`. Dabei gelten die Berechtigungen des angemeldeten Kontos oder des Kontos, dem das
API-Token gehört. Das Konto benötigt `streams.query`. Die Tool-Richtlinie der Organisation darf
diese Tools nicht deaktivieren.
