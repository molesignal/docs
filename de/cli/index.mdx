Die MoleSignal-CLI ist der Befehl `molesignal`, der auf npm als `@molesignal/cli` verfügbar ist. Die CLI
meldet sich bei einer MoleSignal-Instanz an und führt dann folgende Aufgaben aus:

- liest und verfolgt Logs, führt SQL- und PromQL-Abfragen aus, zeigt Traces als Wasserfalldiagramme an und fasst APM-
  Services zusammen;
- listet Incidents und die aktuelle Rufbereitschaft auf, bestätigt und behebt Incidents, führt synthetische Checks aus
  und setzt genehmigte Änderungen um;
- meldet in CI Deployments, lädt RUM-Source-Maps und Symbole hoch und sendet Skriptausgaben an einen
  Stream;
- ruft beliebige Tools aus dem MoleSignal-Katalog auf;
- stellt die MCP-Tools von MoleSignal über stdio bereit, sodass Claude Code, Cursor, Codex, VS Code und
  Gemini CLI die CLI als MCP-Server starten können.

Die CLI nutzt für Lesezugriffe und Änderungen die Tools von MoleSignal. Daher gelten dieselben Berechtigungen des angemeldeten Kontos, dieselbe
Tool-Richtlinie der Organisation und dieselben Genehmigungen wie für Mole Agent.
Für Deployment-Meldungen, den Upload von Debug-Artefakten und das Senden von Logs nutzt die CLI die MoleSignal-API und
benötigt ein API-Token.

## Voraussetzungen

- Node.js 20 oder neuer.
- Eine vom Rechner aus erreichbare MoleSignal-Instanz mit einem Konto.

## Installieren

```bash
npm install -g @molesignal/cli
```

Prüfen Sie die Installation:

```bash
molesignal --version
```

Jeder Befehl lässt sich auch ohne Installation ausführen:

```bash
npx -y @molesignal/cli --help
```

## Erste Schritte

<Steps>
  <Step title="Anmelden">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    Der Browser öffnet die Autorisierungsseite von MoleSignal. Klicken Sie dort auf **Autorisieren**. Siehe
    [Anmelden](/de/cli/sign-in).
  </Step>
  <Step title="Einrichtung prüfen">
    ```bash
    molesignal doctor
    ```
  </Step>
  <Step title="Logs lesen">
    ```bash
    molesignal logs app_logs -f
    ```

    Siehe [Logs lesen und verfolgen](/de/cli/logs).
  </Step>
</Steps>

## Befehle

| Gruppe | Befehle |
|---|---|
| Anmeldung | `login`, `logout`, `profiles`, `use`, `status`, `whoami`, `doctor`. Siehe [Anmelden](/de/cli/sign-in). |
| Logs und Abfragen | `streams`, `logs`, `query`, `fields`. Siehe [Logs lesen und verfolgen](/de/cli/logs). |
| Metriken, Traces und Services | `metrics`, `traces`, `services`, `search-jobs`. Siehe [Metriken, Traces und Services](/de/cli/observe). |
| Rufbereitschaft und Änderungen | `incidents`, `oncall`, `approvals`, `annotate`, `synthetics`. Siehe [Incidents und Änderungen](/de/cli/changes). |
| Releases und Daten | `deploy`, `source-maps`, `symbols`, `send`, `run`. Siehe [CI und Releases](/de/cli/ci). |
| Tools und Einrichtung | `tools`, `call`, `mcp`, `open`, `completion`. Siehe [Beliebige Tools aufrufen](/de/cli/tools) und [MCP über stdio bereitstellen](/de/cli/mcp). |

`molesignal <command> --help` beschreibt einen Befehl und seine Optionen. Alle Optionen finden Sie auch in der
[Befehlsreferenz](/de/cli/reference).
