Die CLI-Befehle decken häufige Aufgaben ab. Alle weiteren Tools im MoleSignal-Katalog, etwa die
Tools für RUM, Profiling oder Statusseiten, lassen sich mit `molesignal call` aufrufen.

## Tool finden

```bash
molesignal tools incident
```

Die Liste zeigt die Tools, die am besten zu den Suchbegriffen passen. Für jedes Tool zeigt sie, was der Aufruf tut (`read` oder
`change`), wie die Tool-Richtlinie der Organisation Änderungen steuert und wozu das Tool dient.
Ohne Suchbegriffe listet der Befehl alle Tools auf, die aufgerufen werden dürfen. `--domain` beschränkt die Liste auf einen Bereich, etwa
`observability` oder `alerts_on_call`.

`molesignal tools show` gibt ein einzelnes Tool mit den unterstützten Argumenten als JSON Schema aus:

```bash
molesignal tools show list_rum_sessions
```

## Tool aufrufen

```bash
molesignal call list_rum_sessions --since 1h limit=20
```

Der Befehl gibt das Ergebnis des Tools als JSON aus. Geben Sie Argumente wie folgt an:

| Eingabe | Übergabewert |
|---|---|
| `name=value` | Der Wert im vom Tool-Schema erwarteten Typ: Text, eine Zahl, `true` oder `false` oder eine Liste aus `a,b`. |
| `name:=json` | Das JSON unverändert, etwa `match:='{"service":"checkout"}'`. |
| `parent.child=value` | Ein Feld innerhalb eines Objekts, etwa `timeRange.startTime=…`. |
| `--input <file>` | Ein JSON-Objekt mit Argumenten aus einer Datei oder `-` für die Standardeingabe. Nachfolgende Schlüssel-Wert-Paare ergänzen das Objekt. |
| `--since`, `--from`, `--to` | Legt `timeRange` für Tools fest, die dieses Argument unterstützen. |

Bei Tool-Aufrufen, die Änderungen vornehmen, gilt die Tool-Richtlinie. Details unter
[Ablauf einer Änderung](/de/cli/changes#so-führt-molesignal-eine-änderung-aus). Die Optionen `--reason`, `--wait`, `--timeout` und
`--yes` gelten dabei. Der Befehl übernimmt die Argumente `reason` und `impact` unverändert in die Genehmigungsanfrage.

```bash
molesignal call trigger_alert_rule rule_id=<rule> --reason "Testing the pager"
```

## Seite öffnen

`molesignal open` öffnet eine MoleSignal-Seite im Browser. Ohne Seitenangabe öffnet der Befehl die Startseite:

```bash
molesignal open logs app_logs
```

Verfügbare Seiten: `home`, `logs`, `metrics`, `traces`, `services`, `incidents`, `oncall`,
`synthetics`, `dashboards`, `approvals`, `jobs`, `streams` und `agent`. Für die meisten Seiten können Sie eine ID angeben, etwa
die eines Traces, eines Incidents oder eines Dashboards. `--print` gibt stattdessen die URL aus.

Verwenden Sie bei `logs`, `query`, `traces show`, `incidents show` und `services show` die Option `--web`, um das Ergebnis
im Browser zu öffnen, statt es im Terminal auszugeben.

## Befehle in der Shell vervollständigen

`molesignal completion` gibt ein Skript aus, das Befehle, Unterbefehle, Profile und
Stream-Namen vervollständigt. Das Skript ruft die Stream-Namen alle paar Minuten ab. Für bash:

```bash
echo 'source <(molesignal completion bash)' >> ~/.bashrc
```

Für zsh:

```bash
echo 'source <(molesignal completion zsh)' >> ~/.zshrc
```

Für fish:

```bash
molesignal completion fish > ~/.config/fish/completions/molesignal.fish
```
