VS Code unterstützt MCP-Server über stdio und Remote-HTTP sowie OAuth-Autorisierung, Ressourcen, Prompts und Tools.

## Verbindung über stdio herstellen (empfohlen)

Der Client startet die MoleSignal-CLI. Die CLI leitet Nachrichten an MoleSignal weiter und benötigt
Node.js 20 oder höher.

<Steps>
  <Step title="Einmalig anmelden">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

Der Browser öffnet MoleSignal zur Bestätigung der Anmeldung. Die CLI speichert und erneuert die Anmeldung.

  </Step>
  <Step title="MoleSignal hinzufügen">

In `.vscode/mcp.json`:

```json
{
  "servers": {
    "molesignal": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

Starten Sie den Server aus der Datei oder der MCP-Ansicht und bestätigen Sie die Vertrauensabfrage.

  </Step>
</Steps>

Falls kein Browser verfügbar ist, setzen Sie statt der Anmeldung `MOLESIGNAL_URL` und `MOLESIGNAL_TOKEN` (ein API-Token) in der
Serverumgebung. Siehe [Verbindung über stdio herstellen](/de/inbound-mcp#über-stdio-verbinden).

Die folgenden Abschnitte beschreiben die Verbindung über Streamable HTTP ohne CLI.

## Server konfigurieren

Erstellen Sie `.vscode/mcp.json` für eine gemeinsame Arbeitsbereichskonfiguration. Führen Sie für eine private globale
Konfiguration in der Befehlspalette **MCP: Benutzerkonfiguration öffnen** aus.

```json
{
  "servers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Server starten">
    Öffnen Sie `mcp.json` und wählen Sie direkt in der Datei die Aktion **Beginn** aus oder führen Sie **MCP: Server auflisten** aus und wählen Sie
    `molesignal` aus.
  </Step>
  <Step title="Vertrauen bestätigen">
    Prüfen Sie den Endpunkt und bestätigen Sie die Vertrauensabfrage für den MCP-Server. Eine Arbeitsbereichskonfiguration kann
    mit allen Mitwirkenden geteilt werden. Speichern Sie daher keine Zugangsdaten in der Datei.
  </Step>
  <Step title="OAuth-Autorisierung abschließen">
    VS Code ermittelt die OAuth-Konfiguration von MoleSignal und öffnet die Autorisierungsseite im Browser. Erteilen Sie
    die Freigabe und kehren Sie dann zum Agentenmodus im Chat zurück.
  </Step>
  <Step title="Verbindung prüfen">
    Führen Sie **MCP: Server auflisten** aus und prüfen Sie den Status von `molesignal`. Prüfen Sie anschließend, ob die Tools in der
    Chat-Ansicht verfügbar sind.
  </Step>
</Steps>

Fügen Sie über **Kontext hinzufügen → MCP-Ressourcen** eine MoleSignal-Ressource hinzu oder rufen Sie einen veröffentlichten Prompt
mit `/molesignal.<prompt>` auf.

Siehe die [offizielle VS Code-Dokumentation zu MCP](https://code.visualstudio.com/docs/agent-customization/mcp-servers).
