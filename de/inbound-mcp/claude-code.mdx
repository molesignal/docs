Claude Code unterstützt stdio-Server, Remote-Server über Streamable HTTP mit OAuth-Discovery sowie
Konfigurationen auf lokaler, Projekt- oder Benutzerebene.

## Über stdio verbinden (empfohlen)

Der Client startet die MoleSignal-CLI, die Nachrichten an MoleSignal weiterleitet. Die CLI benötigt
Node.js 20 oder höher.

<Steps>
  <Step title="Einmalig anmelden">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

MoleSignal öffnet sich im Browser. Bestätigen Sie dort die Anmeldung. Die CLI speichert und erneuert die Anmeldedaten.

  </Step>
  <Step title="MoleSignal hinzufügen">

```bash
claude mcp add --scope user molesignal -- npx -y @molesignal/cli mcp
claude mcp get molesignal
```

  </Step>
</Steps>

Falls kein Browser verfügbar ist, setzen Sie statt der Anmeldung `MOLESIGNAL_URL` und `MOLESIGNAL_TOKEN` (ein API-Token) in der
Serverumgebung. Siehe [Über stdio verbinden](/de/inbound-mcp#über-stdio-verbinden).

Die folgenden Abschnitte zeigen, wie Sie sich ohne CLI über Streamable HTTP verbinden.

## Mit OAuth 2.1 verbinden

<Steps>
  <Step title="Remote-Server hinzufügen">

    ```bash
    claude mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    `--scope user` macht den Server projektübergreifend verfügbar. Lassen Sie das Flag für eine nur lokal gültige
    Projektkonfiguration weg oder verwenden Sie `--scope project`, um einen Eintrag in der gemeinsamen `.mcp.json` anzulegen.

  </Step>
  <Step title="MoleSignal autorisieren">

    ```bash
    claude mcp login molesignal
    ```

    Alternativ öffnen Sie Claude Code, führen Sie `/mcp` aus, wählen Sie `molesignal` aus und schließen Sie die Authentifizierung ab.

  </Step>
  <Step title="Server überprüfen">

    ```bash
    claude mcp get molesignal
    claude mcp list
    ```

  </Step>
</Steps>

Geben Sie in einer SSH-Sitzung oder einem Terminal ohne grafische Oberfläche die Autorisierungs-URL aus
und fügen Sie die abschließende Callback-URL wieder in Claude Code ein:

```bash
claude mcp login molesignal --no-browser
```

## Mit einem API-Token verbinden

Lassen Sie in der `.mcp.json` des Projekts eine Umgebungsvariable auflösen, statt ein Token einzuchecken:

```json
{
  "mcpServers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer ${MOLESIGNAL_MCP_TOKEN}"
      }
    }
  }
}
```

Setzen Sie `MOLESIGNAL_MCP_TOKEN`, bevor Sie Claude Code starten. Bestätigen Sie vor dem ersten Verbindungsaufbau ausdrücklich,
dass Sie dem auf Projektebene konfigurierten Server vertrauen.

Siehe die [offizielle MCP-Dokumentation von Claude Code](https://code.claude.com/docs/en/mcp).
