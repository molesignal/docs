Gemini CLI unterstützt stdio- und Streamable-HTTP-Server, die Erkennung von OAuth-Endpunkten sowie MCP-Tools, -Ressourcen und -Prompts.

## Über stdio verbinden (empfohlen)

Der Client startet die MoleSignal CLI, die Nachrichten an MoleSignal weiterleitet. Dafür ist
Node.js 20 oder höher erforderlich.

<Steps>
  <Step title="Einmalig anmelden">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

Im Browser öffnet sich MoleSignal zur Bestätigung der Anmeldung. Die CLI speichert und erneuert die Anmeldedaten.

  </Step>
  <Step title="MoleSignal hinzufügen">

```bash
gemini mcp add molesignal npx -y @molesignal/cli mcp
```

  </Step>
</Steps>

Wenn kein Browser verfügbar ist, setzen Sie statt der Anmeldung `MOLESIGNAL_URL` und `MOLESIGNAL_TOKEN` (ein API-Token) in der
Serverumgebung. Siehe [Über stdio verbinden](/de/inbound-mcp#über-stdio-verbinden).

Die folgenden Abschnitte beschreiben die Verbindung über Streamable HTTP ohne CLI.

## Mit OAuth 2.1 verbinden

<Steps>
  <Step title="MoleSignal hinzufügen">

    ```bash
    gemini mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    Lassen Sie `--scope user` weg, damit der Eintrag in der Datei `.gemini/settings.json` des aktuellen Projekts bleibt.

  </Step>
  <Step title="Authentifizieren">
    Starten Sie eine interaktive Sitzung in Gemini CLI und führen Sie dann folgenden Befehl aus:

    ```text
    /mcp auth molesignal
    ```

    Schließen Sie die Autorisierung im Browser ab. Gemini CLI erkennt die OAuth-Endpunkte und
    registriert den Client automatisch per dynamischer Clientregistrierung.

  </Step>
  <Step title="Server überprüfen">

    ```bash
    gemini mcp list
    ```

    Führen Sie `/mcp` in der interaktiven Sitzung aus, um die verbundenen Tools, Ressourcen und Prompts zu prüfen.

  </Step>
</Steps>

## Mit JSON konfigurieren

Der entsprechende Eintrag für Streamable HTTP in `~/.gemini/settings.json` oder
`.gemini/settings.json` lautet:

```json
{
  "mcpServers": {
    "molesignal": {
      "httpUrl": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

Setzen Sie `trust: true` für einen verwalteten Betriebsserver nur dann, wenn die lokale Gemini-Richtlinie
die Bestätigungsabfrage des Clients umgehen soll. Die Freigaberichtlinie von MoleSignal gilt weiterhin auf dem
Server.

Siehe die [offizielle MCP-Dokumentation für Gemini CLI](https://geminicli.com/docs/tools/mcp-server/).
