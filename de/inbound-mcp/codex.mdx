Codex startet MCP-Server über stdio und unterstützt den Streamable-HTTP-Endpunkt von MoleSignal sowie OAuth-Discovery.

## Über stdio verbinden (empfohlen)

Der Client startet die MoleSignal-CLI, die Nachrichten an MoleSignal weiterleitet. Die CLI benötigt
Node.js 20 oder neuer.

<Steps>
  <Step title="Einmalig anmelden">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

MoleSignal öffnet sich im Browser. Bestätigen Sie dort die Anmeldung. Die CLI speichert und erneuert die Sitzung.

  </Step>
  <Step title="MoleSignal hinzufügen">

```bash
codex mcp add molesignal -- npx -y @molesignal/cli mcp
```

Oder in `~/.codex/config.toml`:

```toml
[mcp_servers.molesignal]
command = "npx"
args = ["-y", "@molesignal/cli", "mcp"]
```

  </Step>
</Steps>

Falls kein Browser verfügbar ist, setzen Sie statt der Anmeldung `MOLESIGNAL_URL` und `MOLESIGNAL_TOKEN` (ein API-Token) in der
Umgebung des Servers. Siehe [Über stdio verbinden](/de/inbound-mcp#über-stdio-verbinden).

Die folgenden Abschnitte zeigen, wie Sie die Verbindung über Streamable HTTP ohne CLI herstellen.

## Mit OAuth 2.1 verbinden

<Steps>
  <Step title="MoleSignal registrieren">

    ```bash
    codex mcp add molesignal \
      --url https://molesignal.example.com/api/v1/mcp
    ```

  </Step>
  <Step title="Verbindung autorisieren">

    ```bash
    codex mcp login molesignal
    ```

    Schließen Sie die Autorisierung auf der MoleSignal-Seite im Browser ab.

  </Step>
  <Step title="Server überprüfen">

    ```bash
    codex mcp get molesignal
    codex mcp list
    ```

    Starten Sie die aktive Codex-Aufgabe neu oder öffnen Sie eine neue Aufgabe, um die Liste der MCP-Tools zu aktualisieren.

  </Step>
</Steps>

<Warning>
  Fügen Sie `--oauth-resource` nicht hinzu. MoleSignal veröffentlicht die geschützte Ressource bereits über
  OAuth-Discovery. Wenn Sie denselben Wert erneut hinzufügen, kann der Fehler `duplicate field resource` auftreten.
</Warning>

## Mit einem API-Token verbinden

Verwenden Sie für einen nicht interaktiven Codex-Prozess ein persönliches API-Token oder ein API-Token für ein Dienstkonto:

```bash
export MOLESIGNAL_MCP_TOKEN="<api-token>"

codex mcp add molesignal \
  --url https://molesignal.example.com/api/v1/mcp \
  --bearer-token-env-var MOLESIGNAL_MCP_TOKEN
```

Codex speichert den Namen der Umgebungsvariable statt des Token-Werts. Stellen Sie die Variable
dem Prozess zur Verfügung, der Codex startet.

## Tool-Erkennung überprüfen

Geben Sie in Codex Folgendes ein:

> Verwenden Sie den MoleSignal-MCP-Server. Suchen Sie nach Incident-Tools und listen Sie aktive Incidents auf. Nehmen Sie
> keine Änderungen vor.

Die erste Anfrage sollte `tool_search` und anschließend `call_read_tool` für den verzögerten Lesezugriff verwenden.

Weitere Informationen finden Sie in der [offiziellen Codex-MCP-Dokumentation](https://developers.openai.com/codex/mcp/).
