Cursor unterstützt MCP-Server über stdio sowie Remote-MCP-Server über Streamable HTTP mit OAuth-Authentifizierung.

## Verbindung über stdio (empfohlen)

Der Client startet die MoleSignal-CLI, die Nachrichten an MoleSignal weiterleitet. Die CLI benötigt
Node.js 20 oder höher.

<Steps>
  <Step title="Einmalig anmelden">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

MoleSignal öffnet sich im Browser. Bestätigen Sie dort die Anmeldung. Die CLI speichert und erneuert die Sitzung.

  </Step>
  <Step title="MoleSignal hinzufügen">

Fügen Sie die Konfiguration für das aktuelle Projekt in `.cursor/mcp.json` oder für alle Projekte in `~/.cursor/mcp.json` ein:

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

Aktivieren Sie anschließend `molesignal` unter **Tools & MCP**.

  </Step>
</Steps>

Wenn kein Browser verfügbar ist, setzen Sie statt der Anmeldung `MOLESIGNAL_URL` und `MOLESIGNAL_TOKEN` (ein API-Token) in der
Serverumgebung. Siehe [Verbindung über stdio](/de/inbound-mcp#über-stdio-verbinden).

Die folgenden Abschnitte beschreiben den Verbindungsaufbau über Streamable HTTP ohne CLI.

## Server konfigurieren

Erstellen Sie `.cursor/mcp.json` für das aktuelle Projekt oder `~/.cursor/mcp.json` für eine globale
Konfiguration:

```json
{
  "mcpServers": {
    "molesignal": {
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Tools & MCP öffnen">
    Öffnen Sie **Cursor Settings → Tools & MCP** und suchen Sie nach `molesignal`.
  </Step>
  <Step title="Verbindung mit OAuth herstellen">
    Wählen Sie **Verbindungsaufbau** und schließen Sie die Autorisierung auf der MoleSignal-Seite ab. Cursor ermittelt die OAuth-
    Endpunkte anhand der MCP-Metadaten für geschützte Ressourcen.
  </Step>
  <Step title="Tools überprüfen">
    Prüfen Sie, ob `tool_search`, `call_read_tool` und `call_managed_tool` in der Liste der verfügbaren
    Tools erscheinen. Starten Sie den Server nach einer Konfigurationsänderung unter **Tools & MCP** neu.
  </Step>
</Steps>

<Warning>
  Committen Sie kein Bearer-Token in `.cursor/mcp.json`. Verwenden Sie für interaktive Cursor-Sitzungen
  vorzugsweise OAuth. Stellen Sie nicht interaktive Zugangsdaten über einen vom Client unterstützten Mechanismus zur Secret-Injektion bereit.
</Warning>

Siehe die [offizielle MCP-Dokumentation von Cursor](https://cursor.com/docs/mcp).
