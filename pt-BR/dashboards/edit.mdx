Selecione **Novo dashboard** em **Dashboards**, ou **Editar** em um dashboard, para abrir o editor. Criar
um dashboard exige `dashboards.create`, e alterar um exige `dashboards.edit`. Um dashboard
com a configuração **Editável** desativada, como um nativo, não pode ser alterado: crie uma cópia.

## O editor

| Controle | Uso |
|---|---|
| **Voltar ao dashboard** | Sai do editor. |
| Título do dashboard | Renomeia o dashboard no local. |
| **Desfazer** / **Refazer** | Retrocede ou avança pelas alterações desde que o editor foi aberto. |
| **Adicionar** | Adiciona um **Painel**, **Texto**, **Linha**, **Grupo** ou **Abas**. |
| **Configurações** | Abre as [configurações do dashboard](#configurações-do-dashboard). |
| **Salvar** | Salva o dashboard. Nada é salvo antes disso. |

Arraste um elemento pela alça para movê-lo e arraste o canto para redimensioná-lo. Selecione um elemento para editar
sua posição e estrutura no painel lateral. Novos dashboards usam uma grade de 24 colunas; altere-a em
[Configurações → Geral](#configurações-do-dashboard).

## Elementos

| Elemento | Uso |
|---|---|
| **Painel** | Uma ou mais consultas desenhadas por uma visualização. |
| **Texto** | Markdown estático ou texto simples, para notas, títulos e links. |
| **Linha** | Um cabeçalho de largura total que contém os elementos abaixo dele. Uma linha pode começar **Recolhida inicialmente**. |
| **Grupo** | Uma caixa que mantém elementos relacionados juntos. |
| **Abas** | Várias abas, cada uma com seus próprios elementos. Escolha a aba que abre primeiro. |

## Editar um painel

Selecione **Editar** no menu de um painel ou adicione um painel. O editor de painel mostra uma **Prévia ao vivo** do
painel com o intervalo de tempo e as variáveis atuais, e dois conjuntos de abas:

| Abas | Conteúdo |
|---|---|
| **Consultas**, **Transformações**, **Links de dados** | O que o painel lê, como o resultado é remodelado e para onde um clique leva. |
| **Painel**, **Campo**, **Substituições** | Como o painel aparece, como os valores são exibidos e exceções para alguns campos. |

### Consultas

Selecione **Adicionar consulta** para cada consulta do painel. Cada consulta tem um **ID de referência**, como `A`, uma
**Fonte de dados**, uma **Linguagem** **PromQL** ou **SQL**, e a **Expressão**. A fonte de dados
decide a linguagem padrão e os demais campos:

| Fonte de dados | Linguagem padrão | Outros campos |
|---|---|---|
| **Métricas** | PromQL | |
| **Logs**, **Rastreamentos**, **SQL** | SQL | **Nome do fluxo** e **Tipo de fluxo** (**Logs**, **Métricas** ou **Rastreamentos**). |
| **Perfis** | SQL | **Serviço** e **Tipo de perfil**, por exemplo `cpu`. |

A **Legenda** nomeia a série com um template como `{{service}}`. A **Consulta compartilhada** reutiliza uma consulta de
outro painel, escrita como `<panel-id>:<ref-id>`, para que os dados sejam lidos uma única vez. As consultas podem usar
[variáveis](/pt-BR/dashboards/variables) como `$service`. Consulte [Consultas](/pt-BR/query) para SQL e
PromQL.

Uma consulta SQL cujo `format` é `time_series`, como nos painéis que o [explorador de RUM](/pt-BR/rum/explorer#adicionar-ao-dashboard) adiciona,
pode responder no formato longo, uma linha para cada tempo e grupo: uma série temporal desenha uma série para cada conjunto de valores de suas colunas
de texto, com o nome dado por esses valores.

### Transformações

As transformações remodelam o resultado antes de ele ser desenhado. Elas são executadas em ordem, e cada uma pode ser desativada.

| Transformação | Efeito |
|---|---|
| **Filtrar campos**, **Organizar campos**, **Renomear campos** | Mantém, ordena, oculta ou renomeia campos. |
| **Calcular campo** | Adiciona um campo calculado a partir de outros. |
| **Reduzir** | Reduz cada série a valores como último, média, máx. ou total. |
| **Agrupar por**, **Ordenar por**, **Limitar** | Agrega por um campo, ordena e mantém as primeiras linhas. |
| **Participar**, **Mesclar** | Combina os resultados de várias consultas. |
| **Converter rótulos em campos**, **Converter linhas em campos**, **Converter séries temporais em tabela** | Converte rótulos, linhas ou séries em colunas. |

### Opções do painel

A aba **Painel** define o **Título**, a **Descrição** exibida ao passar o mouse, a **Largura** e a **Altura**,
a **Visualização**, suas opções e se o painel é **Transparente**.

| Visualização | Desenha |
|---|---|
| **Série temporal** | Linhas, barras ou pontos ao longo do tempo, com opções de legenda, dica, preenchimento e empilhamento. |
| **Gráfico de barras** | Valores comparados por categoria. |
| **Medidor de barras** | Valores reduzidos como barras horizontais ou verticais. |
| **Estatística** | Um valor, como o último, com um sparkline opcional. |
| **Medidor** | Um valor em uma escala radial com cores de limite. |
| **Tabela** | Linhas, com paginação. |
| **Logs** | Uma lista compacta de logs com hora e nível. |
| **Mapa de calor** | A intensidade dos valores ao longo do tempo. |
| **Linha do tempo de estados** | Mudanças de estado ao longo do tempo. |
| **Texto** | Markdown. |

A **Variável de repetição** desenha uma cópia do painel para cada valor de uma variável, em uma **Direção da repetição**
**Horizontal**, **Vertical** ou **Grade**, até **Máx. por linha** cópias em uma linha. Consulte
[Repetir painéis](/pt-BR/dashboards/variables#repetir-painéis-com-uma-variável).

### Opções de campo

A aba **Campo** define como os valores são exibidos:

| Opção | Uso |
|---|---|
| **Unidade**, **Casas decimais** | A unidade, como bytes, porcentagem ou segundos, e o número de casas decimais. |
| **Mín.**, **Máx.** | Os extremos da escala. |
| **Nome de exibição** | Substitui o nome do campo. |
| **Esquema de cores** | Uma cor fixa, uma paleta, as cores de limite ou uma escala contínua. |
| **Limites** | Valores em que a cor muda, no modo **Absoluto** ou **Porcentagem**, começando em **Base**. |
| **Mapeamentos de valores** | Exibe texto, uma cor ou um ícone para um valor, um intervalo, uma correspondência de regex ou um valor especial como null. |
| **Texto para quando não houver valor** | O que o painel exibe quando não há valor. |

As **Substituições** aplicam outras opções de campo apenas a alguns campos. Selecione **Adicionar substituição**, escolha um critério
(**Nome do campo**, **Expressão regular do campo**, **Tipo de campo** ou **Referência da consulta**) e **Adicionar propriedade** para cada opção
a alterar.

### Links de dados

Um link de dados transforma um clique em um valor em um salto. Selecione **Adicionar link de dados**, insira um **Título** e escolha
o destino: **Logs**, **Métricas**, **Rastreamentos**, **Perfis**, outro **Dashboard** ou uma **URL externa**.
Escolha se o link carrega o intervalo de tempo e as variáveis do dashboard e se abre em
uma nova aba. Os links aparecem no menu do painel.

## Configurações do dashboard

**Configurações** tem quatro abas.

| Aba | Conteúdo |
|---|---|
| **Geral** | **Título**, **Descrição** e **Tags**. O intervalo de tempo padrão (**De**, **Até**) e o **Fuso horário**. A **Grade**: **Colunas** de 1 a 48, **Altura da linha** e **Espaçamento**. **Atualizar**: **Desativado**, **Intervalo** com um **Intervalo padrão** ou **Automático**. **Dica do gráfico**: desativada, ou uma mira compartilhada entre painéis. **Editável**. |
| **Variáveis** | As variáveis do dashboard. Consulte [Variáveis](/pt-BR/dashboards/variables). |
| **Anotações** | Eventos desenhados nos painéis de série temporal. |
| **Links** | Links no cabeçalho do dashboard. |

Uma anotação tem um **Nome**, uma **Origem**, uma **Exibição** **Linha**, **Região** ou **Marcador**, uma
**Cor** e **Ativado**. Liste seus eventos em **Eventos** com **Adicionar evento**: um **Rótulo**, um
**Carimbo de data/hora inicial (ms)** e, para uma região, um **Carimbo de data/hora final (ms)**.

Uma anotação com origem **Implantações** não lista eventos: ela marca as mudanças da
[lista de mudanças](/pt-BR/api/changes) em todos os painéis de série temporal, implantações e outras mudanças relatadas
e as versões que o APM viu pela primeira vez, dos serviços em **Serviços** (separados por vírgula) ou de todos os
serviços. As anotações mantidas com [`POST /api/v1/changes`](/pt-BR/api/changes#gerenciar-anotações) para este
dashboard, ou para nenhum dashboard, também são desenhadas em seus painéis de série temporal.

Um link tem um **Título**, um **Tipo** de **Dashboard** ou **Externo**, uma **URL** e interruptores para carregar o
**Intervalo de tempo** e as **Variáveis** e para abrir em uma **Nova aba**.

## Salvar e reutilizar

Selecione **Salvar**. Para reutilizar um painel, selecione **Copiar** em seu menu para copiar o JSON e cole-o em
outro dashboard. Para reutilizar um dashboard inteiro, use **Exportar JSON** e importe-o em outro lugar. Consulte
[Importar um dashboard](/pt-BR/dashboards#importar-um-dashboard).
