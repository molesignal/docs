Selecione **Novo dashboard** em **Dashboards** ou **Editar** em um dashboard para abrir o editor. Para criar
um dashboard, é preciso ter a permissão `dashboards.create`. Para alterá-lo, é preciso ter `dashboards.edit`. Se a opção
**Editável** estiver desativada, como nos dashboards integrados, crie uma cópia para fazer alterações.

## O editor

| Controle | Uso |
|---|---|
| **Voltar ao dashboard** | Fecha o editor. |
| Título do dashboard | Permite renomear o dashboard diretamente no editor. |
| **Desfazer** / **Refazer** | Desfaz ou refaz as alterações feitas desde a abertura do editor. |
| **Adicionar** | Adiciona um **Painel**, **Texto**, **Linha**, **Grupo** ou **Abas**. |
| **Configurações** | Abre as [configurações do dashboard](#configurações-do-dashboard). |
| **Salvar** | Salva o dashboard. Até clicar nesse botão, nenhuma alteração fica salva. |

Arraste um elemento pela alça para movê-lo ou pelo canto para redimensioná-lo. Selecione um elemento para editar
sua posição e estrutura no painel lateral. Novos dashboards usam uma grade de 24 colunas. Altere a grade em
[Configurações → Geral](#configurações-do-dashboard).

## Elementos

| Elemento | Uso |
|---|---|
| **Painel** | Exibe os resultados de uma ou mais consultas em uma visualização. |
| **Texto** | Exibe conteúdo estático em Markdown ou texto simples, como notas, títulos e links. |
| **Linha** | Cabeçalho que ocupa toda a largura e agrupa os elementos abaixo dele. Use **Recolhido inicialmente** para começar com a linha recolhida. |
| **Grupo** | Caixa que mantém elementos relacionados juntos. |
| **Abas** | Várias abas, cada uma com seus próprios elementos. Escolha qual aba abre primeiro. |

## Editar um painel

Selecione **Editar** no menu de um painel ou adicione um painel. O editor mostra uma **Prévia ao vivo** do
painel com o intervalo de tempo e as variáveis atuais, além de dois conjuntos de abas:

| Abas | Conteúdo |
|---|---|
| **Consultas**, **Transformações**, **Links de dados** | Quais dados o painel consulta, como transforma o resultado e para onde um clique leva. |
| **Painel**, **Campo**, **Substituições** | Aparência do painel, exibição dos valores e exceções para determinados campos. |

### Consultas

Selecione **Adicionar consulta** para cada consulta do painel. Cada consulta tem um **ID de referência**, como `A`, uma
**Fonte de dados**, uma **Linguagem** (**PromQL** ou **SQL**) e uma **Expressão**. A fonte de dados
define a linguagem padrão e os demais campos:

| Fonte de dados | Linguagem padrão | Outros campos |
|---|---|---|
| **Métricas** | PromQL | |
| **Logs**, **Rastreamentos**, **SQL** | SQL | **Nome do fluxo** e **Tipo de fluxo** (**Logs**, **Métricas** ou **Rastreamentos**). |
| **Perfis** | SQL | **Serviço** e **Tipo de perfil**, como `cpu`. |

**Legenda** dá nome às séries com um modelo como `{{service}}`. **Consulta compartilhada** reutiliza uma consulta de
outro painel no formato `<panel-id>:<ref-id>`, sem ler os dados novamente. As consultas podem usar
[variáveis](/pt-BR/dashboards/variables) como `$service`. Consulte [Consultas](/pt-BR/query) para saber mais sobre SQL e
PromQL.

Uma consulta SQL com `format` definido como `time_series`, como nos painéis que o [explorador de RUM](/pt-BR/rum/explorer#adicionar-ao-dashboard) adiciona,
pode retornar dados no formato longo, com uma linha por instante e grupo. A visualização de série temporal exibe uma série para cada combinação de valores das
colunas de texto e usa esses valores para nomeá-la.

### Transformações

As transformações reorganizam o resultado antes de exibi-lo. O painel executa as transformações em ordem. Desative qualquer uma delas conforme necessário.

| Transformação | Efeito |
|---|---|
| **Filtrar campos**, **Organizar campos**, **Renomear campos** | Mantêm, ordenam, ocultam ou renomeiam campos. |
| **Calcular campo** | Adiciona um campo calculado a partir de outros campos. |
| **Reduzir** | Resume cada série com valores como o último valor, a média, o máximo ou o total. |
| **Agrupar por**, **Ordenar por**, **Limitar** | Agregam por campo, ordenam e mantêm as primeiras linhas. |
| **Participar**, **Mesclar** | Combinam os resultados de várias consultas. |
| **Converter rótulos em campos**, **Converter linhas em campos**, **Converter séries temporais em tabela** | Convertem rótulos, linhas ou séries em colunas. |

### Opções do painel

Na aba **Painel**, defina o **Título**, a **Descrição** que aparece ao passar o cursor, a **Largura** e a **Altura**,
a **Visualização** e suas opções. Escolha também se o painel é **Transparente**.

| Visualização | O que exibe |
|---|---|
| **Série temporal** | Linhas, barras ou pontos ao longo do tempo, com opções de legenda, dica, preenchimento e empilhamento. |
| **Gráfico de barras** | Comparação de valores por categoria. |
| **Medidor de barras** | Valores resumidos em barras horizontais ou verticais. |
| **Estatística** | Um valor, como o último, com um minigráfico opcional. |
| **Medidor** | Um valor em uma escala radial com as cores dos limites. |
| **Tabela** | Linhas com paginação. |
| **Logs** | Uma lista compacta de logs com horário e nível. |
| **Mapa de calor** | A intensidade dos valores ao longo do tempo. |
| **Linha do tempo de estados** | Mudanças de estado ao longo do tempo. |
| **Texto** | Markdown. |

**Variável de repetição** exibe uma cópia do painel para cada valor de uma variável. Em **Direção da repetição**, escolha
**Horizontal**, **Vertical** ou **Grade**. Use **Máx. por linha** para limitar o número de cópias por linha. Consulte
[Repetir painéis](/pt-BR/dashboards/variables#repetir-painéis-com-uma-variável).

### Opções de campo

Na aba **Campo**, defina como o painel exibe os valores:

| Opção | Uso |
|---|---|
| **Unidade**, **Casas decimais** | A unidade, como bytes, porcentagem ou segundos, e o número de casas decimais. |
| **Mín.**, **Máx.** | Os extremos da escala. |
| **Nome de exibição** | Substitui o nome do campo. |
| **Esquema de cores** | Uma cor fixa, uma paleta, as cores dos limites ou uma escala contínua. |
| **Limites** | Valores em que a cor muda, no modo **Absoluto** ou **Porcentagem**, a partir de **Base**. |
| **Mapeamentos de valores** | Exibem um texto, uma cor ou um ícone para um valor, um intervalo, uma correspondência com uma expressão regular ou um valor especial, como nulo. |
| **Texto para quando não houver valor** | O que o painel exibe na ausência de um valor. |

**Substituições** aplicam opções diferentes apenas a determinados campos. Selecione **Adicionar substituição**, escolha um critério de correspondência
(**Nome do campo**, **Expressão regular do campo**, **Tipo de campo** ou **Referência da consulta**) e selecione **Adicionar propriedade** para cada opção
que quiser alterar.

### Links de dados

Um link de dados leva a um destino ao clicar em um valor. Selecione **Adicionar link de dados**, informe um **Título** e escolha
o destino: **Logs**, **Métricas**, **Rastreamentos**, **Perfis**, outro **Dashboard** ou uma URL do tipo **Externo**.
Escolha se o link inclui o intervalo de tempo e as variáveis do dashboard e se abre em
uma nova aba. Os links aparecem no menu do painel.

## Configurações do dashboard

**Configurações** tem quatro abas.

| Aba | Conteúdo |
|---|---|
| **Geral** | **Título**, **Descrição** e **Tags**. O intervalo de tempo padrão (**De**, **Até**) e o **Fuso horário**. A **Grade**: **Colunas** de 1 a 48, **Altura da linha** e **Espaçamento**. **Atualizar**: **Desativado**, **Intervalo** com um **Intervalo padrão** ou **Automático**. **Dica do gráfico**: desativada ou com um cursor em cruz compartilhado entre os painéis. **Editável**. |
| **Variáveis** | As variáveis do dashboard. Consulte [Variáveis](/pt-BR/dashboards/variables). |
| **Anotações** | Eventos exibidos em painéis de série temporal. |
| **Links** | Links no cabeçalho do dashboard. |

Uma anotação tem um **Nome**, uma **Origem**, uma **Exibição** do tipo **Linha**, **Região** ou **Marcador**, uma
**Cor** e a opção **Ativado**. Em **Eventos**, selecione **Adicionar evento** e informe um **Rótulo**, um
**Carimbo de data/hora inicial (ms)** e, para uma região, um **Carimbo de data/hora final (ms)**.

Um link tem um **Título**, um **Tipo** (**Dashboard** ou **Externo**), uma **URL** e opções para incluir o
**Intervalo de tempo** e as **Variáveis** e abrir em uma **Nova aba**.

## Salvar e reutilizar

Selecione **Salvar**. Para reutilizar um painel, selecione **Copiar** no menu e cole o JSON em
outro dashboard. Para reutilizar um dashboard inteiro, selecione **Exportar JSON** e importe o arquivo em outro local. Consulte
[Importar um dashboard](/pt-BR/dashboards#importar-um-dashboard).
