Uma variável insere um valor selecionado acima da grade nas consultas, nos títulos e nos links de todos os painéis. Assim, um único
dashboard atende a todos os serviços, hosts ou ambientes, sem precisar de uma cópia para cada um.

## Adicionar uma variável

Abra o editor, selecione **Configurações → Variáveis** e adicione uma variável:

| Campo | Regra |
|---|---|
| **Nome** | O nome usado nas consultas, como `service`. Use letras, dígitos e `_` e comece com uma letra ou `_`. Nomes fora desse padrão não são substituídos. |
| **Rótulo** | O texto exibido acima do seletor. |
| **Tipo** | A origem dos valores. Consulte [Tipos](#tipos). |
| **Consulta / opções** | A consulta ou os valores, conforme o tipo. |
| **Seleção múltipla** | Permite selecionar vários valores de uma vez. |
| **Incluir todos** | Adiciona **Todos**, que representa todos os valores da lista. |
| **Ocultar** | **Nenhum** exibe o seletor, **Rótulo** oculta o rótulo e **Variável** oculta o seletor. |
| **Atualizar** | Define quando a variável de consulta volta a ler seus valores: **Nunca**, **Ao carregar** ou a cada alteração do **Intervalo de tempo**. |

Salve o dashboard para manter a variável.

## Tipos

| Tipo | Valores |
|---|---|
| **Consulta** | Valores obtidos dos dados. Consulte [Variáveis de consulta](#variáveis-de-consulta). |
| **Personalizado** | Uma lista fixa de valores separados por vírgulas, como `prod, staging, dev`. |
| **Texto** | O texto digitado no campo acima da grade. |
| **Constante** | Um valor fixo armazenado no modelo do dashboard. Nunca aparece acima da grade. |
| **Intervalo**, **Fonte de dados** | Uma lista armazenada no modelo do dashboard, como uma lista de um JSON importado. |

### Variáveis de consulta

Uma variável de consulta lê os valores no intervalo de tempo atual. Escolha o **Tipo de consulta**:

| Tipo de consulta | Campos | Valores |
|---|---|---|
| **Valores dos rótulos** | **Métrica** e **Rótulo**, por exemplo, `http_requests_total` e `service`. | Os valores do rótulo nas séries da métrica, em todos os fluxos de métricas que contêm essa métrica. |
| **Consulta clássica** | Uma expressão como `label_values(http_requests_total, service)`. | Os mesmos de **Valores dos rótulos**. |
| **SQL** | **Nome do fluxo**, **Tipo de fluxo** e uma instrução SQL. | Os valores da primeira coluna. |

O primeiro valor vira o padrão. Uma consulta pode usar outra variável. Por exemplo, em uma instrução SQL
com `WHERE environment = '$env'`, a seleção de um ambiente limita a lista de serviços.

## Usar uma variável

Escreva `$name` ou `${name}` em uma consulta, no título de um painel, em um elemento de texto ou em um link. Use chaves
quando houver letras depois do nome, como em `${service}_errors`. Uma variável com vários valores retorna esses valores
separados por vírgulas. Adicione um formato para mudar esse comportamento:

| Sintaxe | Resultado para `checkout` e `payment` |
|---|---|
| `${service}` | `checkout,payment` |
| `${service:csv}` | `checkout,payment` |
| `${service:pipe}` | `checkout\|payment` |
| `${service:regex}` | `checkout\|payment`, com os caracteres especiais de cada valor escapados para uso em uma expressão regular. |
| `${service:sqlstring}` | `'checkout','payment'`, com aspas simples para uso em SQL, por exemplo, em `IN (${service:sqlstring})`. |
| `${service:json}` | `["checkout","payment"]` |

Por exemplo, um painel com a consulta PromQL `sum(rate(http_requests_total{service=~"${service:regex}"}[5m]))` acompanha
os serviços selecionados.

## Valores no endereço

O endereço do dashboard armazena os valores selecionados como `var-<name>=<value>`, com um parâmetro para cada
valor de uma variável de seleção múltipla. Copie o endereço ou crie um link com esses parâmetros para abrir o
dashboard com a mesma seleção. Um [link de dados](/pt-BR/dashboards/edit#links-de-dados) também pode encaminhar as
variáveis.

## Repetir painéis com uma variável

Na aba **Painel**, escolha uma **Variável de repetição**. O dashboard exibe uma cópia do
painel para cada valor selecionado e usa esse valor para a variável na respectiva cópia. Escolha a
**Direção da repetição**: **Horizontal**, **Vertical** ou **Grade**, e defina **Máx. por linha**. O dashboard salva apenas o
painel original. As cópias acompanham a seleção.
