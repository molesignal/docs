<Warning>
O MoleSignal Cloud está em fase de lista de espera. Esta página é um guia de avaliação, não um guia de ativação ou conexão para um serviço de disponibilidade geral.
</Warning>

O MoleSignal Cloud é a oferta gerenciada planejada para equipes que querem avaliar a observabilidade sem precisar operar a infraestrutura de armazenamento e de serviços. Inscreva-se na [lista de espera do Cloud](https://www.molesignal.com/cloud). Use o [guia de início rápido para hospedagem própria](/pt-BR/quickstart) para implantar uma instância e começar a avaliação agora.

## Prepare a avaliação do Cloud

| Requisito | Informações a coletar |
|---|---|
| Telemetria | Logs, métricas, traces, perfis, volume diário esperado e taxas de pico. |
| Retenção | Histórico necessário para cada sinal e consultas que precisam continuar funcionando. |
| Acesso | Tamanho da equipe, limites entre organizações, requisitos de identidade e uso de tokens de API. |
| Localização | Região exigida para os dados, acesso à rede e restrições ao tratamento de dados. |
| Operações | Expectativas de suporte, objetivos de recuperação e responsabilidades durante um incidente. |

Confirme a disponibilidade por região, os métodos de acesso, os limites de retenção, as condições comerciais e os compromissos de suporte durante a avaliação. Não presuma que as opções de configuração da hospedagem própria também estejam disponíveis no serviço gerenciado.

## Valide primeiro o fluxo de dados

1. Inicie uma instância com hospedagem própria e escolha um serviço representativo.
2. Envie telemetria usando os [protocolos de ingestão](/pt-BR/intake/integrations) documentados.
3. Verifique os carimbos de data e hora dos eventos, a seleção de fluxos, a identidade do serviço e as permissões.
4. Execute consultas representativas e investigue um incidente. Registre o volume e a retenção necessários para o fluxo de trabalho.
5. Discuta os requisitos identificados antes de fechar um plano de adoção do Cloud ou de migração.

Um endereço de API ou token de API de uma instância com hospedagem própria não se torna automaticamente um endereço ou uma credencial do Cloud. Use apenas o endpoint e as credenciais fornecidos para o ambiente em uso.
