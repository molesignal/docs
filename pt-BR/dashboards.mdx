Um dashboard é uma grade de painéis que uma equipe monitora em conjunto. Cada painel executa sua própria consulta nos
fluxos de dados do espaço de trabalho e exibe o resultado. Use as variáveis acima da grade para alternar todos os painéis de uma vez para outro
serviço, host ou ambiente.

Esta página explica como encontrar e usar dashboards. Para criar ou alterar um dashboard, consulte
[Criar um dashboard](/pt-BR/dashboards/edit) e [Variáveis](/pt-BR/dashboards/variables).

## Lista de dashboards

Abra **Dashboards**. O cabeçalho mostra o total de dashboards e pastas. Restrinja a lista com:

- o campo de filtro, que busca por nome;
- as opções **Todos**, **Minha**, **Favoritos** e **Tags**;
- uma pasta específica ou **Todos** para incluir todas as pastas;
- o layout **Grade** ou **Lista**.

O cabeçalho também inclui **Novo dashboard**, **Importar JSON** e **Gerenciar pastas**. Selecione a estrela de um
dashboard para adicioná-lo aos **Favoritos**. O menu no fim de cada dashboard oferece estas ações:

| Ação | Efeito |
|---|---|
| **Abrir**, **Editar**, **Compartilhar** | Abre o dashboard, o editor ou a caixa de diálogo de compartilhamento. |
| **Mover para pasta** | Move o dashboard para outra pasta. |
| **Criar cópia** | Cria uma cópia editável com o nome `<title> copy`. |
| **Exportar JSON** | Baixa o modelo do dashboard no formato aceito por **Importar JSON**. |
| **Definir como tela NOC** | Exibe o dashboard no [painel do NOC](#painel-do-noc) deste navegador. |
| **Excluir** | Exclui o dashboard e seus painéis. Não é possível desfazer essa ação. |

## Pastas

As pastas agrupam dashboards em até três níveis. Selecione **Gerenciar pastas** e depois **Nova pasta** para criar uma
pasta no nível raiz ou **Nova subpasta** para criar uma subpasta dentro da pasta selecionada.

Os dashboards sem pasta ficam na pasta **Padrão**. Essa pasta não aceita subpastas e não permite
renomeação nem exclusão. Para excluir outra pasta, primeiro mova todos os dashboards e subpastas para fora dela.

## Consultar um dashboard

O cabeçalho do dashboard mostra a pasta, o número de painéis, a última alteração e estes controles:

| Controle | Uso |
|---|---|
| Seletor de período | Define o período de todos os painéis. Os horários seguem o fuso horário padrão do usuário. Selecione **Alterar** na parte inferior do seletor para exibi-los em outro fuso. |
| **Atualizar** | Executa novamente as consultas de todos os painéis. O menu ao lado configura a atualização automática: **Desativado**, **Automático** ou um intervalo. **Automático** ajusta o intervalo ao período e à largura do painel. |
| Variáveis | Selecione os valores das [variáveis](/pt-BR/dashboards/variables). O endereço armazena os valores como `var-<name>=<value>`, assim o link copiado abre a mesma visualização. |
| **Compartilhar** | Abre a [caixa de diálogo de compartilhamento](/pt-BR/resource-sharing). |
| **Editar** | Abre o [editor](/pt-BR/dashboards/edit). Um dashboard somente leitura oferece **Criar cópia** no lugar dessa opção. |
| Mais | **Ver detalhes do dashboard**, incluindo ID, UID, proprietário e esquema; **Tela NOC**; **Criar cópia**; e **Exportar JSON**. |

Passe o cursor sobre um painel para ver a descrição. O menu do painel oferece estas ações:

| Ação | Efeito |
|---|---|
| **Visualizar** | Exibe apenas o painel, em tamanho real. |
| **Editar** | Abre o painel no editor. |
| **Explorar dados** | Abre a consulta do painel no explorador correspondente, com as variáveis preenchidas e o mesmo período. |
| **Inspecionar consultas** | Exibe as definições de consulta do painel em JSON. |
| **Compartilhar** | Copia um link para o painel. |
| **Exportar dados** | Baixa os dados do painel em CSV. |
| **Exportar imagem** | Baixa uma imagem do painel. |
| **Copiar** | Copia o JSON do painel para colar em outro dashboard. |
| Links de dados | Abre os [links de dados](/pt-BR/dashboards/edit#links-de-dados) do painel. |
| **Criar alerta** | Abre uma nova [regra de alerta](/pt-BR/alerting/rules) com base na consulta do painel. |
| **Análise do Mole Agent** | Solicita ao [Mole Agent](/pt-BR/agent) uma análise do que o painel exibe. |

## Importar um dashboard

Selecione **Importar JSON**, cole o JSON de um dashboard do MoleSignal ou envie um arquivo `.json`, escolha uma pasta
e selecione **Importar**. Use o JSON baixado com **Exportar JSON** ou o JSON que
`GET /api/v1/dashboards/{id}` retorna em `model`. O valor de `engine` deve ser `molesignal-dashboard`.

O MoleSignal não aceita JSON de dashboards do Grafana. Recrie o dashboard no editor: cole as expressões PromQL
nos painéis de métricas sem alterações. Para manter o dashboard no Grafana, consulte os dados do MoleSignal
pela [fonte de dados do Grafana](/pt-BR/query/grafana).

## Solicitar um dashboard ao Mole Agent

Peça ao [Mole Agent](/pt-BR/agent) um rascunho de dashboard, por exemplo: "um dashboard para o serviço de
checkout". O Mole Agent prepara um rascunho sem criar o dashboard e fornece um link para **Rascunho de dashboard gerado por IA**:

1. Revise a **Prévia somente leitura**, que usa o mesmo renderizador de um dashboard real.
2. Consulte a **Verificação prévia de consultas**, que executa uma vez a consulta de cada painel. Confira o resultado: **Aprovado**, **Resultado vazio** ou
   **Ignorado**. Confira também os **Avisos de geração** e os **Problemas a corrigir**.
3. Selecione **Enviar proposta de criação**. Se a política de criação exigir revisão, o rascunho fica pendente até
   a aprovação. Caso contrário, selecione **Confirmar e criar**.

O rascunho fica vinculado ao respectivo modelo e expira após algum tempo. Faça um novo pedido para alterá-lo.

## Dashboards integrados de RUM

Um espaço de trabalho com aplicativos RUM inclui dashboards somente leitura com as tags `内置` e `rum`, um para cada tipo
de aplicativo:

| Dashboard | Para | Exibe |
|---|---|---|
| `RUM · 浏览器应用` | Aplicativos de navegador | Sessões, sessões sem erros e sessões com frustração; LCP, INP e CLS no percentil 75, cada um com sua tendência; erros por origem; páginas, versões, elementos que causam frustração e hosts lentos; países e navegadores. |
| `RUM · 移动应用` | Aplicativos Android, iOS, Flutter e React Native | Sessões, sessões sem falhas nem erros e sessões com frustração; sessões sem falhas, erros e falhas ao longo do tempo; telas, versões, falhas por versão, elementos que causam frustração e hosts lentos; dispositivos e sistemas operacionais. |

O MoleSignal instala cada dashboard na criação do primeiro aplicativo do tipo correspondente. O servidor também instala o dashboard ao
iniciar, se o espaço de trabalho já tiver um aplicativo desse tipo. As atualizações que alteram um dashboard seguem o mesmo
processo. As variáveis são **应用** (o aplicativo), **环境** (um ambiente ou **全部** para incluir todos os
ambientes) e **间隔** (a largura das barras de um gráfico ao longo do tempo). A opção **Abrir no dashboard** na
[visão geral do RUM](/pt-BR/rum#visão-geral) abre o dashboard com o aplicativo e o ambiente da
página já selecionados.

Cada painel usa uma instrução SQL curta. As consultas leem as visualizações e as sessões em `rum_views_latest` e
`rum_sessions_latest`, que armazenam a [versão mais recente](/pt-BR/query#versões-atuais-das-linhas-de-rum) de cada registro.
O cálculo do percentil inclui apenas as visualizações que têm o valor. Os números são os mesmos da visão geral.
Esses dashboards não permitem edição. Selecione **Criar cópia** no cabeçalho do dashboard ou na
lista de dashboards para obter uma versão editável.

## Painel do NOC

Selecione **Painel do NOC** na barra superior para abrir em tela cheia uma visualização escura, própria para monitores de parede.
Pressione `Esc` ou selecione **Voltar ao console** para sair.

A barra de status resume o espaço de trabalho: incidentes ativos e suas severidades, o estado dos dados em tempo real,
o número de serviços, a taxa de requisições e a latência P95. Os painéis exibem:

| Painel | Exibe |
|---|---|
| **Incidentes** | Os incidentes ativos no momento. |
| **Topologia** | A topologia dos serviços na última hora. |
| **Integridade** | Cada serviço com a taxa de requisições, a latência P95 e a taxa de erros. |
| **Tráfego** | Os serviços com mais tráfego nos últimos 60 minutos. |

Selecione **Configurar layout** para alterar o painel do NOC: aplique uma predefinição (**Operações de plataforma**, **SRE** ou
**Executivo**), mostre ou oculte um painel, ajuste a largura ou a posição de um painel ou selecione **Redefinir**.
O navegador salva o layout.

Ao definir um dashboard como tela NOC, o painel do NOC passa a exibir o título do dashboard e
cada um dos seus painéis com a respectiva consulta. O painel do NOC não renderiza os gráficos. Abra o
dashboard para ver os gráficos.

## Relatórios e compartilhamento

Crie um [relatório](/pt-BR/reports) agendado a partir de um dashboard para envio em PDF, PNG, CSV, SVG ou JSON.
Use **Compartilhar** para permitir o acesso de usuários autenticados, o acesso entre espaços de trabalho ou o acesso público restrito. Um dashboard público executa apenas
as consultas salvas dos painéis e segue a [política de compartilhamento](/pt-BR/settings/organization#compartilhamento-e-acesso-público)
do espaço de trabalho.

| Permissão | Permite |

| `dashboards.share` | Criar e renovar links de compartilhamento. |
