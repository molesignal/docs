```http
GET /api/v1/web/topology
```

Agrega as arestas do grafo de serviços em uma janela de tempo e retorna nós e arestas com taxa de requisições, taxa de erros e latência. As arestas vêm do grafo de serviços que o MoleSignal deriva dos spans dos traces. Consulte [Mapa de serviços](/pt-BR/apm/service-map). A chamada exige `traces.read` ou `sys.telemetry.read` no escopo do sistema.

**Parâmetros de consulta**

| Parâmetro | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `from` | string | Sim | O início da janela, como um carimbo de data e hora no formato RFC 3339. |
| `to` | string | Sim | O fim da janela, como um carimbo de data e hora no formato RFC 3339. Não pode ser anterior a `from`. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/topology?from=2026-10-04T09:00:00Z&to=2026-10-04T10:00:00Z" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "nodes": [
    { "id": "checkout", "name": "checkout", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 },
    { "id": "frontend", "name": "frontend", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 }
  ],
  "edges": [
    { "source": "frontend", "target": "checkout", "rps": 0.1, "errRate": 0.0278, "p95Ms": 90.0 }
  ]
}
```
</ResponseExample>

**Resposta**

| Campo | Observações |
|---|---|
| `nodes[].id`, `nodes[].name` | O nome do serviço. A resposta ordena os nós por nome. |
| `nodes[].span_count` | O total de requisições em todas as arestas que conectam o serviço, seja como cliente ou como servidor. |
| `nodes[].error_rate`, `edges[].err_rate` | O número de erros dividido pelo número de requisições, de 0 a 1. |
| `nodes[].rps`, `edges[].rps` | O número de requisições dividido pela duração da janela em segundos. |
| `nodes[].p95_ms`, `edges[].p95_ms` | A maior latência p95 entre os intervalos agregados, em milissegundos. Esse valor não representa o p95 da janela inteira. |
| `edges[].source`, `edges[].target` | O serviço cliente e o serviço servidor. A resposta ordena as arestas primeiro pela origem e depois pelo destino. |

Quando a janela não contém arestas, a chamada retorna arrays vazios.

**Erros**

| Status | Causa |
|---|---|
| `400` | Falta `from` ou `to`, um deles não segue o formato RFC 3339, ou `to` é anterior a `from`. |
| `403` | O token não tem a permissão `traces.read`. |
