```http
GET /api/v1/web/investigation/blob/{id}
```

Retorna o documento JSON que [Armazenar pilha de investigação](/pt-BR/api/web/store-investigation) salvou com o identificador `blobId`. A busca se restringe à organização de origem da chamada. Por isso, a API retorna `404` para um identificador de outra organização. A chamada exige `streams.query` ou `sys.telemetry.read` no escopo do sistema.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/web/investigation/blob/$BLOB_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "version": 1,
  "stack": [
    { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
    { "kind": "log", "query": "level = error" }
  ]
}
```
</ResponseExample>

A resposta contém o documento armazenado, sem alterações. Se o compactador remover o documento após 7 dias, a API também retorna `404`.

**Erros**

| Status | Causa |
|---|---|
| `403` | O token não tem a permissão `streams.query`. |
| `404` | O identificador é desconhecido, pertence a outra organização ou expirou. |
