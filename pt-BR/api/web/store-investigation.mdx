```http
POST /api/v1/web/investigation/blob
```

Armazena um documento JSON no armazenamento de objetos e retorna um identificador. A interface web usa essa chamada para manter a pilha de uma investigação extensa fora da URL da página. A URL passa a conter apenas o identificador. Leia o documento com [Buscar pilha de investigação](/pt-BR/api/web/fetch-investigation). A chamada exige `streams.query` ou, no escopo do sistema, `sys.telemetry.read`.

O corpo aceita qualquer valor JSON de até 1 MiB (1.048.576 bytes). O documento pertence à organização de origem da chamada. O compactador remove o documento após 7 dias.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/investigation/blob \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "version": 1,
    "stack": [
      { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
      { "kind": "log", "query": "level = error" }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "blobId": "3KEZAC5JXc0P0HjrTdARfCgH1Y3"
}
```
</ResponseExample>

**Erros**

| Status | Causa |
|---|---|
| `400` | O corpo não é um JSON válido (texto simples) ou o documento excede 1 MiB (`payload exceeds 1048576 bytes`). |
| `403` | O token não tem a permissão `streams.query`. |
