```http
GET /api/v1/traces/service_graph
```

Retorna as arestas brutas do grafo de serviços que a [Topologia de serviços](/pt-BR/api/web/topology) agrega. Cada aresta contabiliza as chamadas de um serviço cliente para um serviço servidor durante um minuto. A chamada exige `traces.read` ou `sys.telemetry.read` no escopo do sistema.

**Parâmetros de consulta**

| Parâmetro | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `from` | inteiro | Sim | Início da janela, em microssegundos desde a época Unix. |
| `to` | inteiro | Sim | Fim da janela, em microssegundos. |
| `service` | string | Não | Mantém apenas as arestas em que esse serviço é cliente ou servidor. |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000
curl "http://localhost:5080/api/v1/traces/service_graph?from=$((NOW-3600000000))&to=$NOW&service=checkout" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "edges": [
    {
      "id": "3KBCiQWW0TtpDu7D4pH7LMtZsRh",
      "orgId": "<organization-id>",
      "clientService": "frontend",
      "serverService": "checkout",
      "bucketAt": 1790000000000000,
      "requestCount": 12,
      "errorCount": 1,
      "p50Us": 90000,
      "p95Us": 210000,
      "p99Us": 240000
    }
  ],
  "count": 1
}
```
</ResponseExample>

**Resposta**

| Campo | Observações |
|---|---|
| `edges[].client_service`, `edges[].server_service` | O serviço que faz a chamada e o serviço que a recebe. |
| `edges[].bucketAt` | Início do intervalo de um minuto, em microssegundos. |
| `edges[].request_count`, `edges[].error_count` | Total de chamadas e total de chamadas com falha no intervalo. |
| `edges[].p50_us`, `edges[].p95_us`, `edges[].p99_us` | Percentis de latência do intervalo, em microssegundos. Um percentil pode ser `null`. |
| `count` | Número de arestas retornadas. |

A API retorna `{"edges": [], "count": 0}` quando não há arestas correspondentes na janela ou quando `to` é anterior a `from`.

**Erros**

| Status | Causa |
|---|---|
| `400` | `from` ou `to` está ausente ou não é um inteiro. A API responde em texto simples. |
| `403` | O token não tem a permissão `traces.read`. |
