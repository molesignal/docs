```http
GET /api/v1/web/search
```

Fornece a busca da paleta de comandos **⌘K**. A chamada busca seis tipos de entidades da organização por similaridade de nome e retorna primeiro as melhores correspondências. A chamada exige `streams.query` ou, no escopo do sistema, `sys.telemetry.read`.

**Parâmetros de consulta**

| Parâmetro | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `q` | string | Sim | Texto da busca, com até 256 caracteres. A busca usa a similaridade por trigramas do PostgreSQL, por isso um texto muito curto, como uma única letra, raramente encontra correspondências. Se `q` estiver vazio, a chamada retorna uma lista vazia. |
| `types` | string | Não | Subconjunto de `stream`, `dashboard`, `savedView`, `alert`, `incident` e `service`, com valores separados por vírgulas. Omita o parâmetro para buscar em todos os tipos. Um valor desconhecido não retorna correspondências. |
| `limit` | inteiro | Não | Padrão: `20`. A chamada ajusta valores abaixo de 1 para 1 e acima de 50 para 50. |

Se `q` contiver apenas espaços e `types=stream`, a chamada lista os streams em ordem alfabética em vez de fazer uma busca.

Cada resultado identifica a entidade com os seguintes campos:

| `kind` | `id` | `label` | `subtitle` |
|---|---|---|---|
| `stream` | Identificador do stream | Nome do stream | Tipo do stream no formato interno, como `builtin.logs`. |
| `dashboard` | Identificador do dashboard | Título | `uid` do dashboard. |
| `savedView` | Identificador da visualização salva | Nome | Linguagem de consulta. |
| `alert` | Identificador da regra | Nome da regra | `enabled` ou `disabled`. |
| `incident` | Identificador do incidente | Impressão digital do incidente | Status do incidente. |
| `service` | Identificador da aresta | Nome do serviço no grafo de serviços | Nenhum. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/search?q=app&types=stream&limit=5" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "items": [
    { "kind": "stream", "id": "3KDXoznFWyKPsch4ETi37U3GdxM", "label": "app", "subtitle": "builtin.logs" },
    { "kind": "stream", "id": "3JtcZGko1Q5czEBK9nBJjiFxpo1", "label": "app_logs", "subtitle": "builtin.logs" }
  ]
}
```
</ResponseExample>

**Erros**

| Status | Causa |
|---|---|
| `400` | `q` está ausente (texto simples) ou tem mais de 256 caracteres (`invalid_argument`). |
| `403` | O token não tem a permissão `streams.query`. |
