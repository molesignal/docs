```http
POST /api/v1/dashboards
```

Cria um dashboard. O corpo da solicitação inclui o modelo completo do dashboard em `model` e pode especificar um `folderId`. O `uid` deve ser único na organização. Caso contrário, a chamada retorna `409`. A chamada exige a permissão `dashboards.create`.

**Propriedades obrigatórias do modelo**

| Propriedade | Observações |
|---|---|
| `engine` | `molesignal-dashboard`. |
| `schemaVersion` | `2`. |
| `uid`, `title`, `tags` | Identificação. `uid` e `title` não podem estar vazios, e `tags` é um array. |
| `editable`, `defaultDashboard` | Valores booleanos. |
| `timeSettings` | `timezone`, `defaultFrom` e `defaultTo`. |
| `refreshSettings` | `mode`, `enabled`, `defaultInterval` e `allowedIntervals`. |
| `variables`, `annotations`, `links`, `elements` | Arrays, vazios em um dashboard em branco. |
| `layout` | Uma grade: `type`, `columns`, `rowHeight` e `gap`. |

Se faltar alguma propriedade obrigatória no modelo, a chamada retorna `400` com `validation_failed` e uma entrada em `issues` para cada propriedade ausente.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/dashboards \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "model": {
      "engine": "molesignal-dashboard",
      "schemaVersion": 2,
      "uid": "service-overview",
      "title": "Service overview",
      "tags": ["operations"],
      "editable": true,
      "defaultDashboard": false,
      "timeSettings": { "timezone": "browser", "defaultFrom": "now-6h", "defaultTo": "now" },
      "refreshSettings": { "mode": "interval", "enabled": true, "defaultInterval": "30s",
                           "allowedIntervals": ["off", "30s", "1m", "5m"] },
      "variables": [],
      "annotations": [],
      "links": [],
      "layout": { "type": "grid", "columns": 24, "rowHeight": 8, "gap": 8 },
      "elements": []
    },
    "folderId": null
  }'
```
</RequestExample>

Primeiro, crie os painéis no editor. Depois, exporte o modelo de um dashboard existente com `GET /api/v1/dashboards/{id}` para usá-lo como base. Outras rotas: `GET /api/v1/dashboards`, `PUT` e `DELETE /api/v1/dashboards/{id}`.
