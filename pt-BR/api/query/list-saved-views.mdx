```http
GET /api/v1/saved_views
```

Retorna as visualizações salvas da organização. Adicione `?pinned=true` para retornar apenas as visualizações fixadas. A chamada exige `saved_views.read`.

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/saved_views?pinned=true" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KE7RbW5ShK8cbrZZq4I4O3XUge",
    "orgId": "<organization-id>",
    "ownerUserId": "<user-id>",
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = 'error'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true,
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

Outras rotas: `GET /api/v1/saved_views/{id}` retorna uma visualização, e `DELETE /api/v1/saved_views/{id}` retorna `deleted`.

## Listar todas as visualizações ou apenas as fixadas

Omita `pinned` ou defina `pinned=false` para listar as visualizações sem restringir a lista às fixadas. `pinned=false` não significa “apenas as não fixadas”. Defina `pinned=true` ao montar uma lista de atalhos para visualizações fixadas.

A solicitação retorna as definições da organização atual, não os resultados das consultas. A resposta é um array JSON. `[]` é um resultado válido quando nenhuma visualização corresponde ao filtro. Se uma visualização conhecida não aparecer, verifique a organização associada à credencial e remova o filtro de visualizações fixadas antes de concluir que alguém excluiu a visualização.

## Ler a consulta salva

| Campo | Uso |
|---|---|
| `id` | Passe ao endpoint de detalhes ou de execução. |
| `language`, `statement` | Linguagem e texto da consulta salva. |
| `stream` | Contexto salvo do fluxo de dados, quando presente. |
| `timeRangeSecs` | Duração da janela de tempo salva, em segundos. |
| `tags`, `pinned` | Metadados de organização e navegação, não filtros de consulta. |
| `createdAt`, `updatedAt` | Carimbos de data e hora em microssegundos. |

Ler uma definição não executa a consulta nem concede permissão para consultar os dados. Siga as instruções em [Executar uma visualização salva](/pt-BR/api/query/run-saved-view) para executar uma visualização com as permissões necessárias. Consulte [Criar uma visualização salva](/pt-BR/api/query/create-saved-view) para salvar uma consulta e [Visualizações salvas](/pt-BR/saved-views) para ver como fazer isso na interface.
