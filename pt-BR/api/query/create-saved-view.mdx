```http
POST /api/v1/saved_views
```

Salva uma consulta com um intervalo de tempo relativo. A chamada exige `saved_views.create`.

**Corpo**

| Campo | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `name` | string | Sim | Nome de exibição. |
| `language` | string | Sim | `sql` ou `promql`. |
| `statement` | string | Sim | Texto da consulta. |
| `timeRangeSecs` | inteiro | Sim | Intervalo relativo de 1 a 31.622.400 segundos. Um valor fora do intervalo retorna `400`. |
| `stream` | string | Não | Nome do fluxo principal. |
| `tags` | array de strings | Não | Rótulos para filtragem. |
| `pinned` | booleano | Não | Exibe a visualização primeiro. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/saved_views \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = '"'"'error'"'"'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true
  }'
```
</RequestExample>

A resposta retorna a visualização criada no formato exibido em [Listar visualizações salvas](/pt-BR/api/query/list-saved-views).
