```http
GET  /api/v1/saved_views/{id}
POST /api/v1/query
```

Uma visualização salva armazena `language`, `statement`, `stream` e um intervalo relativo em `timeRangeSecs`. Não há um endpoint separado para executar a consulta. A aplicação web segue este fluxo de duas requisições, que exige `saved_views.read` e `streams.query`:

1. Carregue a visualização com `GET /api/v1/saved_views/{id}`.
2. Calcule um intervalo absoluto que termine no momento atual: `end` é o horário atual em microssegundos, e `start` é `end` menos o produto de `timeRangeSecs` por 1.000.000.
3. Envie `language` e `statement` armazenados, o `timeRange` calculado e o stream para [Executar uma consulta](/pt-BR/api/query/execute).

<RequestExample>
```bash cURL
VIEW=$(curl -s http://localhost:5080/api/v1/saved_views/$VIEW_ID \
  -H "authorization: Bearer $MS_TOKEN")

END=$(date +%s)000000
START=$((END - $(echo "$VIEW" | jq .timeRangeSecs) * 1000000))

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "{\"orgId\":\"$MS_ORG\",
       \"language\":$(echo "$VIEW" | jq .language),
       \"statement\":$(echo "$VIEW" | jq .statement),
       \"timeRange\":{\"start\":$START,\"end\":$END},
       \"stream\":{\"name\":$(echo "$VIEW" | jq .stream),\"streamType\":\"logs\"}}"
```
</RequestExample>

A visualização salva armazena o nome do stream sem o tipo. Por isso, informe o tipo do stream ao qual a visualização pertence.
