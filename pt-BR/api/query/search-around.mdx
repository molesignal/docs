```http
POST /api/v1/query/search_around
```

Retorna os eventos imediatamente anteriores e posteriores a um evento, em uma janela de 24 horas de cada lado. A quantidade padrão é 50, com limites de 1 a 1000. A chamada exige `streams.query` ou, para telemetria do sistema, `sys.telemetry.read`.

`before` contém os eventos com carimbo de data e hora igual ou anterior ao do ponteiro, do mais recente ao mais antigo. Se o próprio evento estiver armazenado, ele aparece na primeira linha. `after` contém os eventos com carimbo de data e hora posterior ao do ponteiro, do mais antigo ao mais recente. Se o fluxo não existir, a chamada retorna `before` e `after` vazios em vez de um erro.

**Corpo**

| Campo | Tipo | Obrigatório | Padrão |
|---|---|---|---|
| `eventTimestampUs` | inteiro | Sim | |
| `stream` | string | Sim | |
| `streamType` | string | Sim | |
| `eventFingerprint` | string | Não | A resposta repete esse valor em `pointer`. O servidor não usa esse valor para selecionar eventos. |
| `before` | inteiro | Não | 50 |
| `after` | inteiro | Não | 50 |

<ResponseExample>
```json 200
{
  "pointer": { "ts": 1790000000000000, "fingerprint": null },
  "before": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1789999999500000, "..."]],
    "scannedRows": 100,
    "tookMs": 4
  },
  "after": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1790000000500000, "..."]],
    "scannedRows": 100,
    "tookMs": 4
  }
}
```
</ResponseExample>
