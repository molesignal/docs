```http
POST /api/v1/folders
```

Cria uma pasta de dashboards. A chamada exige `dashboards.folders.manage`. Para listar, editar e excluir, use `dashboards.folders.read`, `dashboards.folders.manage` e `dashboards.folders.delete`, respectivamente.

**Corpo**

| Campo | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `name` | string | Sim | Nome da pasta. |
| `parentId` | string ou `null` | Não | ID da pasta pai na mesma organização. `null` cria uma pasta no nível raiz. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parentId":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "orgId": "<organization-id>",
  "name": "Operations",
  "parentId": null
}
```
</ResponseExample>

`GET /api/v1/folders` lista as pastas. `DELETE /api/v1/folders/{id}` retorna `{"deleted": "<id>"}`, ou `409` se a pasta ainda contiver dashboards ou subpastas.
