```http
DELETE /api/v1/auth/tokens/{id}
```

Revoga imediatamente qualquer token da organização. Uma solicitação posterior com esse token falha com `401` e a mensagem `api token revoked`. A chamada exige `api_tokens.revoke`.

**Parâmetros de caminho**

| Parâmetro | Tipo | Observações |
|---|---|---|
| `id` | string | O `id` retornado ao emitir ou listar o token. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

A chamada retorna `404` se o ID for desconhecido. Revogar um token usado para enviar dados interrompe o envio. Por isso, substitua primeiro o token na origem do envio.

## Token próprio

```http
DELETE /api/v1/me/api-tokens/{id}
```

Revoga um token pessoal da conta ou o token padrão de ingestão. Faça a chamada em uma sessão autenticada com a permissão `personal_tokens.manage`. A chamada retorna `404` se o token não pertencer à conta autenticada.
