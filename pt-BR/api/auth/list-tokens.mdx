```http
GET /api/v1/auth/tokens
```

Retorna os metadados de todos os tokens de API da organização ativa, incluindo tokens padrão de ingestão, tokens de cliente RUM e tokens de contas de serviço. A chamada nunca retorna o token em texto simples nem o hash do segredo. A chamada exige `api_tokens.read`.

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "k7m2q9xv4b",
    "name": "grafana-readonly",
    "tokenKind": "personal",
    "userId": "<user-id>",
    "policyId": null,
    "permissions": ["dashboards.read", "streams.query", "streams.read"],
    "applicationId": null,
    "serviceAccountId": null,
    "expiresAt": 1798000000000000,
    "lastUsedAt": null,
    "revoked": false,
    "createdAt": 1790000000000000
  }
]
```
</ResponseExample>

| Campo | Observações |
|---|---|
| `tokenKind` | `personal`, `serviceAccount`, `default_intake` ou `rum_client`. |
| `userId` | Usuário que emitiu o token. Um token pessoal ou padrão de ingestão atua em nome desse usuário. |
| `policyId` | Política de permissões que o token segue ou `null` se não houver política. |
| `permissions` | Permissões definidas para o token ou `null` se não houver permissões definidas. Se também não houver uma política, o token tem todas as permissões do usuário ou da conta de serviço que representa. |
| `applicationId` | Aplicativo vinculado a um token `rum_client` ou `null` se não houver vínculo. |
| `serviceAccountId` | Conta de serviço que o token representa ou `null` se não houver conta de serviço. |
| `expiresAt` | `null` para um token que nunca expira. |
| `lastUsedAt` | `null` até o primeiro uso. |
| `revoked` | `true` após a revogação do token. |

## Tokens do próprio usuário

```http
GET /api/v1/me/api-tokens
```

Retorna os tokens pessoais e o token padrão de ingestão do usuário autenticado, com os mesmos campos. A chamada exige uma sessão autenticada e a permissão `personal_tokens.manage`.
