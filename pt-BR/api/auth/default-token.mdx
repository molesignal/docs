```http
GET /api/v1/me/api-tokens/default
```

Retorna o token padrão de ingestão do usuário autenticado e o cria na primeira chamada. Ao contrário dos outros tokens, o token padrão é retornado em texto simples a cada chamada. Assim, a página **Fonte de dados** pode exibir um token pronto para uso. O token atua em nome do usuário, segue a política integrada **Ingestão de dados**, que inclui `logs.write`, `metrics.write`, `traces.write`, `profiles.write` e `apm.deploy`, nunca expira e tem o valor `default_intake` no campo `tokenKind`. A chamada parte de uma sessão autenticada e exige `personal_tokens.manage` e ambas as permissões da política.

<RequestExample>
```bash cURL
curl -b ms-cookies.txt http://localhost:5080/api/v1/me/api-tokens/default
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3JtzUbBKtQCD7mFELKp2zDRum9f",
  "prefix": "r4fp1xwgpe",
  "token": "mspat-r4fp1xwgpe<secret>",
  "tokenKind": "default_intake",
  "policyId": "builtin:data_intake",
  "permissions": null,
  "applicationId": null,
  "createdAt": 1790000000000000
}
```
</ResponseExample>

Use o token em coletores, agentes e exportadores de SDKs. Consulte [Fonte de dados](/pt-BR/intake#tokens-de-ingestão).
