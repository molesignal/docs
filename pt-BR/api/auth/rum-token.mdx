```http
GET /api/v1/auth/tokens/rum?applicationId=<id>
```

Retorna o token de cliente RUM de uma [aplicação RUM](/pt-BR/rum/applications) e o cria na primeira chamada. A aplicação precisa existir: crie-a primeiro. O token tem o formato `mspat-<36>` e pertence à aplicação, não a quem o solicitou. Ele concede apenas a permissão `rum.write` para essa aplicação, não dá acesso a outros recursos e nunca expira. Inclua o token no código do navegador ou do aplicativo móvel, onde os usuários finais podem lê-lo. A chamada exige `api_tokens.issue`.

**Parâmetros de consulta**

| Parâmetro | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `applicationId` | string | Sim | O identificador de uma aplicação do espaço de trabalho. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/auth/tokens/rum?applicationId=checkout-web" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KDZpGNwn5vO9dhXyE3am4qhihX",
  "prefix": "c16jb8m5zr",
  "token": "mspat-c16jb8m5zr<secret>",
  "tokenKind": "rum_client",
  "policyId": null,
  "permissions": ["rum.write"],
  "applicationId": "checkout-web",
  "createdAt": 1790000000000000
}
```
</ResponseExample>

A chamada retorna `400` se `applicationId` não for um identificador válido e `404` se o identificador não corresponder a nenhuma aplicação. Use o mesmo identificador no campo `applicationId` do SDK. Consulte [Aplicações RUM](/pt-BR/rum/applications#token-de-cliente).
