```http
DELETE /api/v1/alerts/rules/{id}
```

Exclui uma regra. A chamada exige `alerts.rules.delete`. Os incidentes que a regra já abriu continuam disponíveis para leitura e seguem um ciclo de vida independente. A regra excluída não resolve mais nenhum desses incidentes.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>

O corpo da resposta contém o texto simples `deleted`. A chamada retorna `404` para um `id` desconhecido.
