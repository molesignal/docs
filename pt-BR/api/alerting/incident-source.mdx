```http
GET /api/v1/alerts/incidents/{id}/source
```

Retorna as informações que a origem tem sobre um incidente aberto por uma [origem de alertas](/pt-BR/alerting/sources). Requer `alerts.incidents.read`. Esse incidente tem o rótulo `alert.source=external`, e seu `ruleId` é o ID da origem.

| Campo | Descrição |
|---|---|
| `source` | A origem, conforme descrito em [Listar origens de alertas](/pt-BR/api/alerting/list-sources); `null` após a exclusão da origem. |
| `dedupKey` | A chave de desduplicação. |
| `lastEventAt` | O horário mais recente informado pelo remetente para essa chave de desduplicação, em microssegundos. O sistema ignora mensagens mais antigas. `null` para o tipo API. |
| `lastIntakeAt` | O horário do último recebimento do alerta, em microssegundos. |
| `members` | Até 100 alertas de um grupo de notificações do Alertmanager ou do Grafana: `status` (`firing` ou `resolved`), `labels`, `summary`, `startsAt`, `endsAt` e a `url` que aponta para o remetente. Vazio para os demais tipos. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/source \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Erros**

| Status | Causa |
|---|---|
| `404` | O incidente não existe ou nenhuma origem de alertas o abriu. |
