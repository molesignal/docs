```http
POST /api/v1/alerts/sources
```

Cria uma [fonte de alertas](/pt-BR/alerting/sources). Requer `alerts.sources.manage`. O `token` aparece na resposta apenas uma vez. Use-o para chamar [Enviar alertas](/pt-BR/api/alerting/send-alerts). Com a federação ativada, a fonte é sincronizada com os outros clusters.

| Campo | Tipo | Descrição |
|---|---|---|
| `kind` | string | Obrigatório na criação: `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix` ou `email`. |
| `name` | string | Obrigatório, com até 128 caracteres. |
| `enabled` | boolean | Padrão: `true`. |
| `escalationPolicyId` | string \| null | ID de uma política de escalonamento da organização ou `default`. Se o campo for omitido ou definido como `null`, não há escalonamento e apenas as políticas de notificação enviam notificações. |
| `severity` | string | Gravidade aplicada quando o alerta não especifica uma: `critical`, `error`, `warning` (padrão) ou `info`. |
| `labels` | object | Até 32 rótulos adicionais. A chave pode conter letras, dígitos e os caracteres `_ . - : /`, mas não pode começar com `alert.` nem ser `external.kind`. |
| `email` | object | Define como uma fonte de e-mail processa uma mensagem: `allowedSenders` (endereços, `@domain` ou `*`), `resolvePattern`, `dedupPattern` e `ignorePattern`. Consulte [E-mail](/pt-BR/alerting/sources#e-mail). Se o campo for omitido em uma atualização, o valor atual não muda. |
| `homeCluster` | string | Cluster da federação onde os incidentes são abertos: este cluster ou um cluster remoto habilitado. Uma nova fonte sem esse campo usa este cluster. Sem federação, o campo não tem efeito. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

A resposta contém a fonte com seu `token`. [Listar fontes de alertas](/pt-BR/api/alerting/list-sources) descreve os outros campos.

**Erros**

| Status | Causa |
|---|---|
| `400` | Um campo é inválido, como um nome vazio, uma política de escalonamento inexistente ou um cluster de destino que não seja este cluster nem um cluster remoto habilitado. |
| `403` | O token não tem a permissão `alerts.sources.manage`. |
