```http
POST /api/v1/alerts/sources
```

Cria uma [fonte de alertas](/pt-BR/alerting/sources). Requer `alerts.sources.manage`. O `token` na resposta aparece apenas desta vez; use-o para chamar [Enviar alertas](/pt-BR/api/alerting/send-alerts). Com a federação ativada, a fonte é sincronizada com os outros clusters.

| Campo | Tipo | Descrição |
|---|---|---|
| `kind` | string | Obrigatório na criação: `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` ou `email`. |
| `name` | string | Obrigatório, com até 128 caracteres. |
| `enabled` | boolean | Padrão `true`. |
| `escalationPolicyId` | string \| null | Um ID de política de escalonamento da organização, ou `default`. Sem ele, ou com `null`, nada é escalonado e apenas as políticas de notificação notificam. |
| `severity` | string | Usado quando um alerta não traz severidade: `critical`, `error`, `warning` (o padrão) ou `info`. |
| `labels` | object | Até 32 rótulos extras. A chave é composta por letras, dígitos e `_ . - : /`, não pode começar com `alert.` e não pode ser `external.kind`. |
| `email` | object | Como uma fonte de e-mail lê uma mensagem: `allowedSenders` (endereços, `@domain` ou `*`), `resolvePattern`, `dedupPattern` e `ignorePattern`; consulte [E-mail](/pt-BR/alerting/sources#e-mail). Se omitido em uma atualização, permanece como está. |
| `homeCluster` | string | O cluster de federação em que os incidentes são abertos: este cluster ou um cluster remoto ativado. Uma nova fonte sem ele usa este cluster; sem federação, não tem efeito. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

A resposta é a fonte com seu `token`. [Listar fontes de alertas](/pt-BR/api/alerting/list-sources) descreve os outros campos.

**Erros**

| Status | Causa |
|---|---|
| `400` | Um campo está inválido, como um nome vazio, uma política de escalonamento inexistente ou um cluster de recebimento que não é este cluster nem um cluster remoto ativado. |
| `403` | O token não tem `alerts.sources.manage`. |
