```http
GET /api/v1/alerts/insights/oncall-load
```

Mede a carga de plantão de cada pessoa em um período, em ordem decrescente de notificações. A chamada exige
`alerts.incidents.read`.

O cálculo inclui notificações de disparo ou escalonamento de alertas entregues, uma vez por pessoa
a cada notificação, e exclui falhas de envio. A noite vai das 22:00 às 08:00 do dia seguinte no horário local, e o
fim de semana corresponde ao sábado e ao domingo locais. O horário local segue o fuso horário da escala de plantão. Sem escala,
usa o fuso do [horário de silêncio](/pt-BR/account#notificações) da pessoa, se configurado, ou UTC. Uma
notificação na madrugada conta para a noite anterior.

**Parâmetros de consulta**

| Parâmetro | Tipo | Observações |
|---|---|---|
| `windowSecs` | inteiro | Quantos segundos retroceder. O padrão é `2592000` (30 dias), com limite mínimo de 1 dia e máximo de 90 dias. |
| `scheduleId` | string | Considera apenas os membros e os turnos desta escala. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/insights/oncall-load?windowSecs=604800" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "windowSecs": 604800,
  "nightStartHour": 22,
  "nightEndHour": 8,
  "people": [
    {
      "userId": "<user-id>",
      "oncallSecs": 302400,
      "pages": 9,
      "nightPages": 3,
      "weekendPages": 2,
      "interruptedNights": 2,
      "timezone": "Asia/Shanghai",
      "responded": 6,
      "mttaSecs": 214.0
    }
  ]
}
```
</ResponseExample>

**Resposta**

| Campo | Observações |
|---|---|
| `windowSecs` | O intervalo após aplicar os limites. |
| `nightStartHour`, `nightEndHour` | Os horários de início e fim da noite. |
| `people[].oncall_secs` | Segundos de plantão em uma escala durante o período, incluindo substituições e trocas de turno. |
| `people[].pages` | Notificações de alerta recebidas. |
| `people[].night_pages`, `people[].weekend_pages` | Quantas notificações chegaram à noite e quantas chegaram no fim de semana. |
| `people[].interrupted_nights` | Noites com pelo menos uma notificação. |
| `people[].timezone` | Fuso horário usado para determinar a noite e o fim de semana. |
| `people[].responded`, `people[].mtta_secs` | Número de incidentes que a pessoa assumiu antes de qualquer outra no período e tempo médio, em segundos, entre o disparo e o momento em que assumiu esses incidentes. A contagem segue o critério de [Análise de incidentes](/pt-BR/api/alerting/insights). |
