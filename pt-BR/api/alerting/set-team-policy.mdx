```http
PUT /api/v1/alerts/routing/teams/{teamId}
```

Define ou remove a [política de plantão](/pt-BR/alerting/routing#políticas-de-plantão-das-equipes) de uma equipe. Requer `alerts.routing.manage`. O MoleSignal escala novos incidentes encaminhados à equipe de acordo com essa política. Se a equipe não tiver uma política de plantão, o MoleSignal usa a política padrão.

| Campo | Tipo | Descrição |
|---|---|---|
| `escalationPolicyId` | string \| null | ID de uma política de escalonamento da organização. Para remover a política de plantão da equipe, informe `null` ou omita o campo. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/teams/$TEAM_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"escalationPolicyId": "<policy-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "teamId": "<team-id>", "escalationPolicyId": "<policy-id>" }
```
</ResponseExample>

**Erros**

| Status | Causa |
|---|---|
| `400` | A equipe não existe ou pertence a outra organização, ou a política de escalonamento não existe. |
| `403` | O token não tem a permissão `alerts.routing.manage`. |
| `422` | A solicitação inclui outro campo. A resposta é em texto simples. |
