```http
POST /api/v1/alerts/incidents/bulk
```

Executa uma ação em cada incidente em `ids`, um de cada vez: se a chamada não conseguir processar um incidente,
ela continua processando os demais. `action` indica a ação a executar. Inclua os campos que ela exige:

| `action` | Campos | O que faz |
|---|---|---|
| `acknowledge` | Nenhum | Equivale a [Confirmar um incidente](/pt-BR/api/alerting/ack-incident). |
| `resolve` | Nenhum | Equivale a [Resolver um incidente](/pt-BR/api/alerting/resolve-incident). |
| `snooze` | `durationSecs` | Equivale a [Adiar um incidente](/pt-BR/api/alerting/snooze-incident). |
| `reassign` | `to`, o corpo de [Reatribuir um incidente](/pt-BR/api/alerting/reassign-incident) | Equivale a essa chamada. |
| `set_severity` | `severity` | Equivale a [Definir a severidade de um incidente](/pt-BR/api/alerting/set-incident-severity). |

A chamada exige `alerts.incidents.acknowledge` e aplica a cada incidente as mesmas verificações das chamadas individuais.
A mesclagem não é uma ação em lote. Use [Mesclar incidentes](/pt-BR/api/alerting/merge-incidents).

**Corpo**

| Campo | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `ids` | array | Sim | De 1 a 100 IDs de incidentes. Conte cada ID repetido uma única vez. |
| `action` | string | Sim | `acknowledge`, `resolve`, `snooze`, `reassign` ou `set_severity`. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/bulk \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"ids": ["<incident-id>", "<another-incident-id>"], "action": "snooze", "durationSecs": 3600}'
```
</RequestExample>

A resposta inclui um resultado por incidente: `id` e, se a ação falhar, `error`. Isso pode acontecer, por exemplo, quando o incidente já voltou ao normal ou quando `durationSecs` está fora do intervalo permitido.

<ResponseExample>
```json 200
{
  "results": [
    {
      "id": "3KEDNEyqouYJeBDTLTMTBui7XHW"
    },
    {
      "id": "3KEDQ4mJ8sLp2Xv6Nc1Rt9bYwHe",
      "error": "this incident is no longer active"
    }
  ]
}
```
</ResponseExample>

**Erros**

| Status | Causa |
|---|---|
| `400` | `ids` está vazio ou contém mais de 100 incidentes. |
| `403` | O token não tem a permissão `alerts.incidents.acknowledge`. |
| `422` | `action` está ausente ou tem um valor desconhecido, ou falta um campo que a ação exige. |
