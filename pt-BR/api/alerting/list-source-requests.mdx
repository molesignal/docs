```http
GET /api/v1/alerts/sources/{id}/requests
```

Retorna as solicitações que uma [fonte de alertas](/pt-BR/alerting/sources) recebeu recentemente, da mais recente à mais antiga. Requer `alerts.sources.read`. O cluster que processou as solicitações guarda as últimas 500 de cada fonte por até 7 dias.

**Parâmetros de consulta**

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `limit` | inteiro | Número de solicitações a retornar, de 1 a 200. Padrão: 50. |

| Campo | Descrição |
|---|---|
| `receivedAt` | Momento do recebimento, em microssegundos. |
| `viaCluster` | Cluster da federação que encaminhou a solicitação. Fica vazio quando o cluster atual recebe a solicitação diretamente. |
| `status` | `accepted` (aceita), `rejected` (rejeitada) ou `forwarded` (encaminhada ao cluster de destino). |
| `httpStatus` | Código de status HTTP retornado ao remetente. |
| `message` | Motivo da rejeição ou da falta de ação. |
| `alertCount` | Número de alertas na solicitação. |
| `alerts` | Para até 100 alertas: ação, chave de desduplicação, título, gravidade, resultado (consulte [Enviar alertas](/pt-BR/api/alerting/send-alerts)), motivo e ID do incidente. |
| `bodyExcerpt` | Trecho inicial do corpo de uma solicitação rejeitada, limitado a 16 KiB. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/requests?limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>
