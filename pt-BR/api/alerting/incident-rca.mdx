```http
GET /api/v1/alerts/incidents/{id}/rca
POST /api/v1/alerts/incidents/{id}/rca
```

O [Mole Agent](/pt-BR/agent) gera uma análise de causa raiz (RCA) com base no contexto do incidente. Cada incidente tem no máximo uma análise.

A função `alert` gera análises automaticamente. A cada três minutos, a função gera análises para até 20 incidentes ativos que ainda não têm análise, desde que a organização tenha um provedor de modelos habilitado com uma chave de API. A chamada `GET` lê a análise armazenada. A chamada `POST` gera uma nova análise imediatamente e substitui a análise armazenada.

| Chamada | Permissão | Observações |
|---|---|---|
| `GET` | `alerts.incidents.read` | Retorna `404` com `no root-cause analysis for this incident yet` enquanto não houver uma análise. |
| `POST` | `alerts.incidents.rca` | Aguarda a resposta do modelo e retorna a nova análise. O parâmetro de consulta opcional `locale` define o idioma da análise: `en-us` ou `zh-cn`. Por padrão, usa o idioma de preferência do usuário que faz a chamada. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/rca?locale=en-us" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Resposta**

| Campo | Observações |
|---|---|
| `incidentId`, `orgId` | Identificadores do incidente e da organização. |
| `summary` | Análise em formato Markdown. |
| `provider`, `model` | Tipo de provedor de modelos, como `openai`, `anthropic` ou `openai_compatible`, e nome do modelo. |
| `promptBuiltinKey`, `promptHash` | Modelo de prompt e hash do prompt renderizado, para fins de auditoria. |
| `promptTokens`, `completionTokens`, `finishReason` | Uso de tokens e motivo do encerramento informados pelo provedor. |
| `createdAt`, `updatedAt` | Microssegundos desde a época Unix. O campo `updatedAt` muda quando o sistema gera a análise novamente. |

**Erros**

| Status | Causa |
|---|---|
| `400` | A chamada `POST` não encontrou um provedor de modelos habilitado com uma chave de API para a organização. |
| `403` | O token não tem a permissão exigida pela chamada. |
| `404` | O incidente não existe ou a chamada `GET` ainda não encontrou uma análise. |
