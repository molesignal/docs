```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

A primeira chamada lista as [fontes de alerta](/pt-BR/alerting/sources) da organização. A segunda retorna uma fonte. A terceira retorna o ID deste cluster na federação (`local`, ou vazio se não houver federação) e os clusters que a fonte pode usar para receber alertas. As três chamadas exigem `alerts.sources.read`. A API nunca retorna o token nem seu hash.

| Campo | Tipo | Descrição |
|---|---|---|
| `id` | string | ID da fonte. |
| `name` | string | Nome. |
| `kind` | string | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix` ou `email`. |
| `enabled` | boolean | Uma fonte desativada rejeita alertas. |
| `escalationPolicyId` | string \| null | Política de escalonamento que os incidentes da fonte seguem. `default` usa a política padrão; `null` apenas envia notificações, sem escalonar. |
| `severity` | string | Gravidade aplicada quando o alerta não informa uma. |
| `labels` | object | Rótulos adicionais que a fonte inclui em cada incidente que abre. |
| `tokenPrefix` | string | Prefixo do token: `mspat-<10>`. A API retorna o token completo apenas uma vez a cada criação ou rotação. |
| `homeCluster` | string | Cluster da federação em que a fonte abre incidentes. O campo fica vazio quando a fonte usa este cluster. |
| `intakePath` | string | Caminho do endereço de recebimento, igual para todas as fontes. |
| `lastIntakeAt` | integer \| null | Momento em que este cluster recebeu a solicitação mais recente da fonte, em microssegundos. |
| `createdBy`, `createdAt`, `updatedAt` | | Identificação de quem criou a fonte e datas de criação e da última alteração, em microssegundos. |

Clusters que a fonte pode usar para receber alertas:

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
