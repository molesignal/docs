```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

A primeira chamada lista as [fontes de alerta](/pt-BR/alerting/sources) da organização, a segunda retorna uma fonte e a terceira retorna o ID de federação deste cluster (`local`, vazio sem federação) e os clusters que uma fonte pode escolher como cluster de recebimento. As três exigem `alerts.sources.read`. A API nunca retorna um token nem seu hash.

| Campo | Tipo | Descrição |
|---|---|---|
| `id` | string | ID da fonte. |
| `name` | string | Nome. |
| `kind` | string | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` ou `email`. |
| `enabled` | boolean | Uma fonte desativada recusa alertas. |
| `escalationPolicyId` | string \| null | A política de escalonamento que seus incidentes seguem; `default` é a política padrão, e `null` não escala nada e apenas notifica. |
| `severity` | string | Usada quando um alerta não traz severidade. |
| `labels` | object | Rótulos extras adicionados a cada incidente que ela abre. |
| `tokenPrefix` | string | O prefixo do token `mspat-<10>`. O token completo é retornado uma única vez, na criação e na rotação. |
| `homeCluster` | string | O cluster de federação em que seus incidentes são abertos; vazio para este cluster. |
| `intakePath` | string | O caminho do endereço de entrada, igual para todas as fontes. |
| `lastIntakeAt` | integer \| null | Quando este cluster recebeu pela última vez uma requisição dela, em microssegundos. |
| `createdBy`, `createdAt`, `updatedAt` | | Quem a criou e quando, e quando ela mudou pela última vez, em microssegundos. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Os clusters que uma fonte pode escolher como cluster de recebimento:

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
