```http
GET /api/v1/alerts/routing/teams
```

Lista as equipes da organização por nome (sem distinguir maiúsculas de minúsculas), com a [política de plantão](/pt-BR/alerting/routing#políticas-de-plantão-das-equipes) de cada equipe e os serviços sob sua responsabilidade no catálogo de serviços do APM. Requer `alerts.routing.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/teams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "teamId": "<team-id>",
    "name": "Payments",
    "memberCount": 4,
    "escalationPolicyId": "<policy-id>",
    "services": ["default/checkout", "default/cart"]
  }
]
```
</ResponseExample>

| Campo | Descrição |
|---|---|
| `teamId`, `name` | ID e nome da equipe. |
| `memberCount` | Número de membros da equipe. |
| `escalationPolicyId` | Política de plantão da equipe. Se a equipe não tiver uma política definida, o valor será `null` e os incidentes encaminhados à equipe seguirão a política padrão. |
| `services` | Serviços não arquivados vinculados à equipe no catálogo de serviços, no formato `namespace/name`. |
