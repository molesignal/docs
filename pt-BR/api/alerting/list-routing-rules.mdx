```http
GET /api/v1/alerts/routing/rules
```

Lista as [regras de roteamento](/pt-BR/alerting/routing#regras-de-roteamento) da organização na ordem de avaliação (`position` crescente). Requer `alerts.routing.read`. A lista também inclui regras desativadas.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/rules \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1",
    "orgId": "<organization-id>",
    "name": "Payments in production",
    "enabled": true,
    "position": 0,
    "conditions": [
      { "key": "env", "operator": "equals", "values": ["prod"] },
      { "key": "service.name", "operator": "in", "values": ["checkout", "cart"] }
    ],
    "minSeverity": "error",
    "origins": [],
    "target": { "kind": "team", "teamId": "<team-id>" },
    "createdBy": "<user-id>",
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

## Campos da regra

| Campo | Descrição |
|---|---|
| `id`, `orgId` | Identificadores da regra e da organização. |
| `name` | Nome da regra. |
| `enabled` | A avaliação ignora regras desativadas. |
| `position` | Ordem de avaliação: os menores valores vêm primeiro. |
| `conditions` | Condições que os rótulos do incidente devem satisfazer em conjunto. Uma lista vazia corresponde a todos os incidentes. Cada condição tem `key`, `operator` e `values`. |
| `minSeverity` | Severidade mínima do incidente: `info`, `warning`, `error` ou `critical`. Use `null` para aceitar qualquer severidade. |
| `origins` | Origens às quais a regra se aplica: `rule` (regras de alerta), `external` (fontes de alerta), `synthetic` (verificações sintéticas). Uma lista vazia inclui todas as origens. |
| `target` | Destino do incidente que atende à regra: `{"kind": "team", "teamId": …}` ou `{"kind": "policy", "policyId": …}`. |
| `createdBy` | Usuário que criou a regra. |
| `createdAt`, `updatedAt` | Data e hora de criação e da última alteração da regra, em microssegundos. |

Valores de `operator`:

| `operator` | `values` | Há correspondência quando |
|---|---|---|
| `equals` | Um valor | O valor do rótulo é igual ao valor informado. |
| `not_equals` | Um valor | O valor do rótulo difere do valor informado ou o incidente não tem esse rótulo. |
| `in` | Um ou mais valores | O valor do rótulo é igual a um dos valores informados. |
| `matches` | Uma expressão regular | O valor inteiro do rótulo corresponde à expressão regular. |
