```http
PUT /api/v1/alerts/rules/{id}
```

Substitui a configuração de uma regra. Envie o corpo completo de [Criar uma regra](/pt-BR/api/alerting/create-rule). A chamada mantém o `id` da regra, a organização, `createdAt`, `lastEvalAt` e `lastState`. Se alterar `escalationPolicyId`, indique uma política da organização ou use `default`. A chamada exige `alerts.rules.manage`.

<Warning>
  A chamada substitui a regra sem mesclar os campos. Os campos omitidos assumem os valores padrão,
  inclusive `enabled`, que passa a ser `true`, e `kind`, que passa a ser `scheduled`. Se omitir
  `labels`, `annotations` e `thresholds`, esses campos ficam vazios. Apenas a omissão de `escalationPolicyId`
  preserva a política atual. Consulte a regra primeiro e reenvie o corpo completo com a alteração.
</Warning>

A impressão digital de um incidente deriva do `id` e de `labels` da regra. Após uma alteração em `labels`, um incidente que já está aberto mantém a impressão digital anterior e não é mais resolvido automaticamente. Use [Resolver um incidente](/pt-BR/api/alerting/resolve-incident) para resolver esse incidente.

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  --data-binary @- <<'EOF'
{
  "name": "High error rate",
  "description": "More than 200 errors in five minutes",
  "enabled": true,
  "kind": "scheduled",
  "query": {
    "language": "sql",
    "statement": "SELECT count(*) AS c FROM app WHERE level = 'error'",
    "periodSecs": 300,
    "stream": { "name": "app", "streamType": "logs" }
  },
  "trigger": { "operator": "gt", "threshold": 200, "forPeriods": 2, "silenceSecs": 0 },
  "severity": "critical",
  "labels": { "team": "checkout" }
}
EOF
```
</RequestExample>

A resposta contém a regra atualizada no formato mostrado em [Listar regras](/pt-BR/api/alerting/list-rules).

**Erros**

| Status | Causa |
|---|---|
| `400` | O corpo não passa pelas mesmas validações de [Criar uma regra](/pt-BR/api/alerting/create-rule) ou o novo valor de `escalationPolicyId` não identifica nenhuma política da organização. |
| `404` | A regra não existe. |
| `422` | Falta um campo obrigatório ou um valor tem o tipo incorreto. A resposta está em texto simples. |
