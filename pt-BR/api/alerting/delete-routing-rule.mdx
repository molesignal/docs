```http
DELETE /api/v1/alerts/routing/rules/{id}
```

Exclui uma [regra de roteamento](/pt-BR/alerting/routing#regras-de-roteamento). Requer a permissão `alerts.routing.manage`. As regras seguintes encaminham os novos incidentes que corresponderiam à regra excluída. Os incidentes já abertos mantêm o roteamento definido na abertura, incluindo o nome da regra registrado em cada incidente.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/routing/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "deleted": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1" }
```
</ResponseExample>

**Erros**

| Status | Causa |
|---|---|
| `403` | O token não tem a permissão `alerts.routing.manage`. |
| `404` | A regra não existe ou pertence a outra organização. |
