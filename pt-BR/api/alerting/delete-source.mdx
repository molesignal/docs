```http
DELETE /api/v1/alerts/sources/{id}
```

Exclui uma [fonte de alertas](/pt-BR/alerting/sources). A operação exige `alerts.sources.manage`. O token da fonte deixa de funcionar imediatamente, e a exclusão também remove as solicitações que a fonte recebeu recentemente. A operação resolve os incidentes abertos da fonte em nome do usuário que fez a chamada, pois, sem a fonte, esses incidentes nunca receberiam um sinal de recuperação. Com a federação ativada, os outros clusters resolvem os incidentes abertos da fonte em seus próprios ambientes assim que a exclusão é sincronizada.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Em caso de sucesso, a resposta retorna `200` com o texto `deleted`.

**Erros**

| Status | Causa |
|---|---|
| `403` | O token não tem a permissão `alerts.sources.manage`. |
| `404` | A fonte não existe. |
