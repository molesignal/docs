```http
POST /api/v1/alerts/incidents/{id}/merge
```

Mescla os incidentes de `sourceIds` com o incidente `{id}`. Cada incidente mesclado registra o incidente principal
em `mergedInto` e, a partir daí, não envia notificações, não é escalado e não aparece em
[Listar incidentes](/pt-BR/api/alerting/list-incidents) nem nas análises. Ele permanece ativo, portanto sua regra ou
origem não abre outro incidente para o mesmo problema. Resolver o incidente principal também resolve os incidentes mesclados. Se um incidente mesclado
se recuperar primeiro, a recuperação fica registrada na
[linha do tempo](/pt-BR/api/alerting/incident-timeline) do incidente principal. Os incidentes que já estavam mesclados a um incidente mesclado passam
para o incidente principal. Não é possível desfazer a mesclagem.

O incidente principal e todos os incidentes a mesclar devem estar ativos e não podem já estar mesclados a outro incidente. A chamada ignora o
ID do próprio incidente principal e os IDs repetidos em `sourceIds`. A chamada exige `alerts.incidents.escalate` no incidente
principal.

**Corpo**

| Campo | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `sourceIds` | array | Sim | De 1 a 50 IDs dos incidentes a mesclar. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/merge \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"sourceIds": ["<incident-id>", "<another-incident-id>"]}'
```
</RequestExample>

A resposta retorna o incidente principal. Consulte [Listar incidentes](/pt-BR/api/alerting/list-incidents) para ver a descrição de cada campo.

**Erros**

| Status | Causa |
|---|---|
| `400` | `sourceIds` não indica nenhum outro incidente ou indica mais de 50. |
| `403` | O token não tem a permissão `alerts.incidents.escalate` ou o incidente está fora do escopo do token. |
| `404` | O incidente principal ou um dos incidentes em `sourceIds` não existe. |
| `409` | O incidente principal ou um dos incidentes em `sourceIds` se recuperou ou foi mesclado a outro, ou um incidente continuou mudando durante a atualização. Tente novamente. |
