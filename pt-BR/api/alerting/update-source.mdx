```http
PUT /api/v1/alerts/sources/{id}
```

Salva todas as configurações de uma [fonte de alertas](/pt-BR/alerting/sources). Requer a permissão `alerts.sources.manage`. Os campos são os mesmos de [Criar uma fonte de alertas](/pt-BR/api/alerting/create-source). O tipo não pode mudar: se informar `kind`, use o valor atual. O token permanece o mesmo. Para alterá-lo, use [Rotacionar um token](/pt-BR/api/alerting/rotate-source-token). Se omitir `homeCluster`, o cluster receptor não muda. Os incidentes já abertos mantêm a política de escalonamento e os rótulos.

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"name": "Production Prometheus", "enabled": false, "escalationPolicyId": "default", "severity": "error"}'
```
</RequestExample>

A resposta retorna a fonte atualizada, sem o campo `token`.

**Erros**

| Status | Causa |
|---|---|
| `400` | Um campo é inválido ou o tipo informado difere do atual. |
| `403` | O token não tem a permissão `alerts.sources.manage`. |
| `404` | A fonte não existe. |
