```http
POST /api/v1/alerts/incidents/{id}/notes
```

Adiciona uma nota à [linha do tempo](/pt-BR/api/alerting/incident-timeline) de um incidente, independentemente do status. Mole
Agent lê as notas mais recentes junto com o incidente. A chamada exige `alerts.incidents.update`.

**Corpo**

| Campo | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `text` | string | Sim | De 1 a 4.000 caracteres. A API remove os espaços no início e no fim. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/notes \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"text": "Rolled back the edge proxy."}'
```
</RequestExample>

A resposta contém a entrada da nota na linha do tempo.

<ResponseExample>
```json 200
{
  "id": "3KEE1aXy7pRtGd2s9Lm4Qv8bNcE",
  "orgId": "<organization-id>",
  "incidentId": "3KEDNEyqouYJeBDTLTMTBui7XHW",
  "at": 1790000300000000,
  "kind": "note",
  "actor": "<user-id>",
  "detail": {
    "text": "Rolled back the edge proxy.",
    "via": "api"
  }
}
```
</ResponseExample>

**Erros**

| Status | Causa |
|---|---|
| `400` | `text` está vazio ou tem mais de 4.000 caracteres. |
| `403` | O token não tem a permissão `alerts.incidents.update` ou não tem acesso ao incidente. |
| `404` | O incidente não existe. |
