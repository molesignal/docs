```http
GET /api/v1/audit
```

Retorna os eventos de auditoria da organização, dos mais recentes aos mais antigos, com paginação por cursor. A chamada exige `audit.read`.

Cada evento também ocupa uma linha no stream `_audit` da organização. É possível consultar essa linha e enviá-la a outro destino por meio de um pipeline. Esta API consulta a fonte oficial dos registros. Consulte [Stream de auditoria](/pt-BR/settings/data-security#fluxo-de-auditoria).

A trilha de auditoria registra operações sensíveis do ciclo de vida. Ela não registra todas as alterações. Os nomes das ações da versão atual começam com estes prefixos:

| Prefixo | Operações |
|---|---|
| `agent.` | Provedores de modelos do Mole Agent, prompts, ferramentas e chamadas de ferramentas, servidores MCP, aprovações, conversas, investigações e execuções. |
| `iam.` | Vínculos de funções, relacionamentos e concessões de acesso entre organizações. |
| `resource_share.` | Criação, rotação, revogação e abertura de links de compartilhamento, além de tentativas malsucedidas de autenticação por senha. |
| `status_page.` | Páginas de status, componentes, regras de automação e logotipos. |
| `synthetic.` | Locais de monitoramento sintético, agentes e tokens de agentes. |
| `schedule.` | Escalas de plantão e substituições. |
| `trace_debug_token.` | Uso de um token de depuração de traces. |
| `dashboard.` | Dashboards criados a partir de um rascunho gerado por IA. |

A trilha não registra alterações em streams, regras de alerta, incidentes e conectores.

**Parâmetros de consulta**

| Parâmetro | Tipo | Observações |
|---|---|---|
| `from`, `to` | string | O intervalo de tempo. Cada valor corresponde a microssegundos desde a época Unix ou a um valor relativo: `now` ou `now-<N><unit>` com a unidade `s`, `m`, `h` ou `d`, como em `now-30m`. |
| `actorKind` | string | O tipo de entidade, por exemplo, `user`. |
| `actor` | string | O identificador da entidade. |
| `action` | string | O nome exato da ação, como `agent.model_provider.created`. |
| `targetKind`, `targetId` | string | O tipo e o identificador do alvo. |
| `limit` | integer | Tamanho da página. O padrão é `50`. A API ajusta o valor para o intervalo de 1 a 200. |
| `cursor` | string | O `nextCursor` da página anterior. O valor é opaco. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/audit?from=now-7d&action=agent.model_provider.created&limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Resposta**

| Campo | Observações |
|---|---|
| `items[].actor_kind`, `items[].actor_id` | A entidade que fez a alteração. |
| `items[].action` | O nome da ação, como `iam.role_binding.create`. |
| `items[].target_kind`, `items[].target_id` | O objeto afetado. Ambos podem ser `null`. |
| `items[].ip`, `items[].user_agent` | O endereço do cliente e o agente do usuário, quando a operação registra esses valores. Ambos podem ser `null`. |
| `items[].payload` | Detalhes da operação. Os payloads não incluem segredos, conteúdo dos prompts nem resultados das ferramentas. |
| `items[].ts` | O horário do evento em microssegundos. |
| `nextCursor` | O cursor da próxima página ou `null` na última página. |
| `retentionDays` | O número de dias durante os quais a API mantém os registros de auditoria, tanto para cada organização quanto para a plataforma. A API exclui os registros mais antigos uma vez por dia. Use `0` para mantê-los indefinidamente. |

**Erros**

| Status | Causa |
|---|---|
| `400` | `from` ou `to` não é um número nem um valor relativo válido (`unparseable time: yesterday`, `bad time unit in: now-3x`), ou `cursor` é inválido. |
| `403` | O token não tem a permissão `audit.read`. |

## Rotas de auditoria relacionadas

| Endpoint | Permissão | Finalidade |
|---|---|---|
| `GET /api/v1/system/audit` | `sys.telemetry.read`, no escopo do sistema | Executa a mesma consulta para os eventos de auditoria da organização do sistema. Esses eventos abrangem operações como ativar ou desativar uma organização, alterar a política de traces e alterar a retenção dos registros de auditoria. |
| `GET /api/v1/settings/audit_retention` | `sys.settings.retention.manage`, no escopo do sistema | Retorna a retenção dos registros de auditoria: `{ "retentionDays": 90 }`. |
| `PUT /api/v1/settings/audit_retention` | `sys.settings.retention.manage`, no escopo do sistema | Define a retenção dos registros de auditoria com o mesmo corpo da requisição. `retentionDays` é um número inteiro de `0` (manter indefinidamente) a `3650`; a API retorna `400` para valores maiores. |
| `GET /api/v1/settings/audit_retention/preview?retentionDays=30` | `sys.settings.retention.manage`, no escopo do sistema | Mostra quantos registros um período de retenção menor excluiria: `{ "retentionDays": 30, "previousRetentionDays": 90, "rows": 2400, "earliestAt": 1780000000000000 }`. A API conta os registros, sem estimativas. Para um período de retenção maior ou `0`, a API retorna `"rows": 0`. |
| `GET /api/v1/agent/audit/chat/{id}` | `audit.read` | Retorna a transcrição completa de uma conversa do Mole Agent: o registro `chat` e suas `messages`, com hashes dos prompts, contagens de tokens e evidências. Se a conversa não existir, a API retorna `404`. |

<Warning>
  A transcrição de uma conversa contém as perguntas dos usuários e as respostas do modelo. Conceda `audit.read` apenas a contas com autorização para ler esse conteúdo.
</Warning>
