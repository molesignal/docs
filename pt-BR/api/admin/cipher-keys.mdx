As chaves de criptografia criptografam os campos que os fluxos marcam como criptografados. Cada chave é uma chave AES-256-GCM de 32 bytes. O MoleSignal protege o material da chave com a chave raiz de `MS_CIPHER_KEY` e nunca retorna esse material. Consulte [Segurança](/pt-BR/security#criptografia-no-nível-de-campo).

Novos valores criptografados sempre usam a versão mais recente da chave padrão `__field_default__`. O MoleSignal cria essa chave quando um fluxo precisa dela pela primeira vez. As outras chaves nomeadas e as versões anteriores de cada chave continuam disponíveis para descriptografar os valores gravados com elas.

| Operação | Endpoint | Permissão |
|---|---|---|
| Listar chaves | `GET /api/v1/cipher_keys` | `org.cipher_keys.read` |
| Obter uma chave | `GET /api/v1/cipher_keys/{name}` | `org.cipher_keys.read` |
| Criar uma chave | `POST /api/v1/cipher_keys` | `org.cipher_keys.manage` |
| Rotacionar uma chave | `POST /api/v1/cipher_keys/{name}/rotate` | `org.cipher_keys.rotate` |
| Excluir uma chave | `DELETE /api/v1/cipher_keys/{name}` | `org.cipher_keys.manage` |
| Rotacionar a chave padrão | `POST /api/v1/field_encryption/rotate` | `org.cipher_keys.rotate` |

## Metadados das chaves

As chamadas de listagem, consulta, criação e rotação retornam os metadados das versões das chaves. A listagem retorna todas as versões de todas as chaves, começando pela versão mais recente de cada nome.

```json
{
  "id": "3KEZizkQsvBwoWQihNO6OdxRiSf",
  "name": "payments-key",
  "alg": "aes-256-gcm",
  "version": 1,
  "createdAt": 1790000000000000,
  "rotatedAt": null
}
```

`rotatedAt` é `null` para uma chave que nunca passou por rotação. A chamada de consulta retorna a versão mais recente.

## Crie uma chave

```http
POST /api/v1/cipher_keys
```

| Campo | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `name` | string | Sim | Nome da chave. Se o nome já existir, a chamada retorna `409` e a mensagem indica a chamada de rotação. |
| `keyMaterialB64` | string | Sim | 32 bytes aleatórios em base64 padrão com preenchimento. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/cipher_keys \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "{\"name\": \"payments-key\", \"key_material_b64\": \"$(openssl rand -base64 32)\"}"
```
</RequestExample>

A resposta contém os metadados da chave mostrados acima.

## Rotacione uma chave

```http
POST /api/v1/cipher_keys/{name}/rotate
```

O corpo contém `keyMaterialB64`, como na chamada de criação. A chamada adiciona uma versão com o novo material e mantém as versões anteriores para descriptografia. Se não houver uma chave com o nome informado, a chamada retorna `404`. Crie a chave primeiro com a chamada de criação.

## Exclua uma chave

```http
DELETE /api/v1/cipher_keys/{name}
```

A chamada exclui todas as versões da chave com o nome informado e retorna `{"deleted": true}`. Se o nome não existir, a chamada retorna `404`. A chamada não verifica se os dados armazenados ainda dependem da chave.

<Warning>
  Após a exclusão de uma chave, não é mais possível descriptografar os valores criptografados com ela. Verifique os campos criptografados
  que dependem da chave antes de excluí-la.
</Warning>

## Rotacione a chave padrão

```http
POST /api/v1/field_encryption/rotate
```

A chamada gera novo material de chave no servidor, adiciona uma versão de `__field_default__` e atualiza imediatamente o cache de descriptografia. Novas gravações usam a nova versão, e os valores existentes continuam legíveis. Se a organização ainda não tiver uma chave padrão, a chamada cria a versão 1. O corpo da solicitação fica vazio, e a resposta contém o identificador e a versão da nova chave:

```json
{
  "keyId": "3KEZj3uxMx5OOFX6NiYv3VFnfmD",
  "version": 2
}
```

**Erros**

| Status | Causa |
|---|---|
| `400` | `keyMaterialB64` não está em base64 válido ou não resulta em exatamente 32 bytes após a decodificação (`key_material must be 32 bytes, got 5`). |
| `403` | O token não tem a permissão exigida pela chamada. |
| `404` | A chamada de consulta, rotação ou exclusão não encontrou uma chave com esse nome. |
| `409` | Já existe uma chave com esse nome. |
| `422` | Falta um campo obrigatório. A resposta é em texto simples. |
