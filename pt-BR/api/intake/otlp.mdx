Aponte um SDK ou Collector do OpenTelemetry para o MoleSignal. Ambos os transportes exigem uma credencial bearer com a permissão de gravação do sinal: `logs.write`, `metrics.write` ou `traces.write`.

| Transporte | Endpoint |
|---|---|
| OTLP sobre HTTP | `POST /api/v1/logs`, `POST /api/v1/metrics`, `POST /api/v1/traces` |
| OTLP sobre gRPC | `:4317` |

A porta `5082` é a porta interna confiável do cluster e não recebe OTLP.

## OTLP sobre HTTP

Configure o endpoint do exportador com o caminho base `/api`. Os exportadores acrescentam `/v1/logs`, `/v1/metrics` e `/v1/traces` automaticamente.

| Cabeçalho | Observações |
|---|---|
| `Authorization` | `Bearer <token>`. |
| `Content-Type` | `application/x-protobuf` ou `application/json`. A codificação JSON grava inteiros de 64 bits como strings, e o MoleSignal aceita tanto strings quanto números. |
| `stream-name` | Opcional. O stream de destino. O valor padrão é `default`. |

Envie o corpo sem compactação: o MoleSignal retorna `400` se o corpo estiver compactado. Desative a compactação no exportador. O limite do corpo é de 2 MiB. Para uma solicitação bem-sucedida, o MoleSignal retorna `200` com `{"partialSuccess":null}`.

<RequestExample>
```yaml OpenTelemetry Collector
exporters:
  otlphttp/molesignal:
    endpoint: http://localhost:5080/api
    compression: none
    headers:
      authorization: "Bearer ${env:MS_TOKEN}"
```

```bash SDK environment variables
export OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5080/api
export OTEL_EXPORTER_OTLP_HEADERS="authorization=Bearer ${MS_TOKEN}"
```
</RequestExample>

## OTLP sobre gRPC

O receptor em `:4317` oferece os serviços de logs, métricas, traces e perfis sem TLS. Envie `authorization: Bearer <token>` e, opcionalmente, `stream-name` como metadados do gRPC. Para tráfego que sai de uma rede confiável, faça a terminação TLS antes de encaminhá-lo para a porta.

```yaml
exporters:
  otlp/molesignal:
    endpoint: localhost:4317
    tls:
      insecure: true
    headers:
      authorization: "Bearer ${env:MS_TOKEN}"
```

## Campos armazenados

Os atributos de recursos e registros se tornam campos de nível superior e mantêm as chaves originais. Consulte [Campos armazenados](/pt-BR/query#campos-armazenados) para ver as colunas de logs, spans e métricas.

## Erros

| Status | Causa |
|---|---|
| `400` | O corpo está compactado ou não contém dados OTLP válidos. |
| `401` | O token está ausente ou é inválido. |
| `403` | O token não tem permissão de gravação para o sinal ou a solicitação envia os dados para um [stream da plataforma](/pt-BR/streams#fluxos-da-plataforma). |
| `404` | O endpoint do exportador não inclui `/api`, então a solicitação chega a `/v1/logs`. |
| `413` | O corpo excede 2 MiB. |

No gRPC, o MoleSignal retorna `PERMISSION_DENIED` para uma solicitação que, via HTTP, receberia `403`.
