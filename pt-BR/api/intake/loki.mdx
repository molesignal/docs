```http
POST /api/v1/loki/api/v1/push
```

Aceita o formato de push JSON do Loki. A chamada exige `logs.write` e responde `204` em caso de sucesso. Quando o stream recusa algumas linhas porque um valor não se encaixa no tipo do campo, as demais linhas são gravadas e a resposta é `400`, informando quantas foram recusadas e o primeiro motivo. Um corpo com `Content-Encoding: gzip` é aceito.

O endpoint decodifica apenas JSON. Remetentes que usam protobuf comprimido com snappy, como Promtail e Grafana Alloy, não conseguem enviar para ele. Use o OpenTelemetry Collector, o Vector ou o Fluent Bit.

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

Cada valor se torna um evento de log. Os rótulos se tornam campos, a linha se torna o campo `message` e o timestamp em nanossegundos é convertido para microssegundos. O cabeçalho `stream-name` seleciona o stream de destino, e o padrão é `default`.

## Verifique o exemplo

O exemplo gera um timestamp atual em nanossegundos em um shell macOS ou Linux. Depois de receber `204`, abra **Logs**, selecione `app` e a última hora e encontre a `message` para `service = 'api'`. Se substituir por um timestamp histórico, selecione uma janela que cubra esse horário do evento e confirme que está dentro da retenção.

Distinga três campos: `streams` é a estrutura do lote do Loki, o rótulo `service` se torna um campo do evento e o cabeçalho `stream-name` seleciona o stream de destino do MoleSignal. Verifique esse stream e a janela de tempo com uma consulta antes de reenviar um lote.
