```http
POST /api/v1/loki/api/v1/push
```

Aceita o formato JSON de envio do Loki. A chamada exige `logs.write` e retorna `204` em caso de sucesso. O endpoint aceita um corpo com `Content-Encoding: gzip`.

O endpoint decodifica apenas JSON. Clientes que usam protobuf compactado com Snappy, como Promtail e Grafana Alloy, não conseguem enviar dados para esse endpoint. Use o OpenTelemetry Collector, o Vector ou o Fluent Bit.

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

Cada valor se torna um evento de log. Os rótulos viram campos, a linha vira o campo `message` e o endpoint converte o carimbo de data/hora de nanossegundos para microssegundos. O cabeçalho `stream-name` seleciona o fluxo de destino, que por padrão é `default`.

## Verifique o exemplo

O exemplo gera um carimbo de data/hora atual em nanossegundos em um shell do macOS ou do Linux. Após receber `204`, abra **Logs**, selecione `app` e a última hora e localize o campo `message` do evento com `service = 'api'`. Se usar um carimbo de data/hora anterior, selecione um intervalo que inclua o momento do evento e confirme que ele está dentro do período de retenção.

Diferencie os três elementos: `streams` é a estrutura de lote do Loki, o rótulo `service` vira um campo do evento e o cabeçalho `stream-name` seleciona o fluxo de destino no MoleSignal. Use uma consulta para verificar o fluxo e o intervalo de tempo antes de reenviar um lote.
