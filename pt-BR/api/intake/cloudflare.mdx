```http
POST /api/v1/_cloudflare
```

Aceita NDJSON, inclusive o corpo compactado com gzip que o Cloudflare Logpush costuma enviar. O endpoint não usa token do tipo bearer. Crie um conector do tipo `cloudflare_logpush` com um `pushToken` de pelo menos 16 caracteres e um `target_stream`. Envie o token no cabeçalho `X-Connector-Token`. O parâmetro de consulta `?token=` também funciona. Se o token estiver incorreto, o endpoint retorna `401`.

Cada linha gera um evento de log no `target_stream` (padrão: `cloudflare`). O endpoint armazena os campos da linha sem alterações e usa o horário de recebimento como horário do evento. Em caso de sucesso, o endpoint retorna `204`.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/_cloudflare \
  -H 'X-Connector-Token: <pushToken>' \
  -H 'content-encoding: gzip' \
  --data-binary @logs.ndjson.gz
```
</RequestExample>

Consulte [Conectores](/pt-BR/connectors) para configurar o conector.

## Verifique a entrega e a seleção do stream

1. Confirme se o conector está ativado e se o remetente usa o token de push do conector. Um token de API comum não substitui um token de push.
2. Ao definir `configJson` diretamente pela API de conectores, use `target_stream` para indicar o stream de destino, não `targetStream`. Mantenha a chave do token em camelCase: `pushToken`.
3. Envie um evento de teste com um marcador exclusivo e anote o horário de recebimento. Em **Logs**, selecione o stream de destino e um intervalo que inclua esse horário. Depois, pesquise pelo marcador.
4. Se a solicitação for bem-sucedida, mas o stream de destino estiver vazio, verifique o stream padrão correspondente e o valor salvo no campo de destino. Uma confirmação via HTTP não substitui uma consulta ao destino esperado.

Proteja o token como uma credencial. Ao enviar o token como parâmetro de consulta da URL, não inclua a URL completa em logs, chamados ou capturas de tela. Antes de repetir uma solicitação que falhou, diferencie problemas de token ou de estado do conector de erros no formato ou na compactação da carga útil.
