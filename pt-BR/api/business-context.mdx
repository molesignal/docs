```http
GET /api/v1/business-context
PUT /api/v1/business-context
```

As chaves de negócio, como um tenant, um plano ou um grupo de experimento, e o campo que carrega cada uma em
spans, logs e eventos de RUM. Consulte [Contexto de negócio](/pt-BR/business-context). A leitura exige qualquer uma de
`apm.services.read`, `traces.read`, `logs.read`, `rum.events.read`, `apm.settings.read` ou
`sys.telemetry.read`; a definição exige `apm.settings.manage` e é registrada no log de atividades.

## Definir as chaves

`PUT` substitui todas as chaves. Campos em branco não nomeiam nada, um `label` em branco é a própria chave, e os valores importantes são
aparados e listados uma vez cada; a resposta é o que foi salvo.

| Campo | Observações |
|---|---|
| `key` | Começa com uma letra minúscula e contém apenas letras minúsculas, dígitos e `_`, no máximo 64. Único. |
| `label` | Como os leitores veem o nome da chave, no máximo 80 caracteres. |
| `span` | O atributo do span, conforme o stream de traces nomeia o campo. |
| `log` | O campo do log. |
| `rum` | O campo de RUM, uma chave de um campo JSON incluído, como `context.tenant`. |
| `important` | Valores que mais importam, no máximo 50 de até 200 caracteres. |

Uma chave nomeia pelo menos um de `span`, `log` e `rum`. No máximo 8 chaves.

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/business-context \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"keys":[{"key":"tenant","label":"Tenant","span":"tenant.id","log":"tenant_id","rum":"context.tenant","important":["acme"]}]}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "keys": [
    {
      "key": "tenant",
      "label": "Tenant",
      "span": "tenant.id",
      "log": "tenant_id",
      "rum": "context.tenant",
      "important": ["acme"]
    }
  ]
}
```
</ResponseExample>

**Erros**

| Status | Motivo |
|---|---|
| `400` | Uma chave tem nome inválido ou repetido, não nomeia nenhum campo, ou há mais chaves ou valores do que o permitido. |
| `403` | O token não tem a permissão da chamada. |
