```http
GET /api/v1/streams/runtime
```

Retorna o estado de execução de cada fluxo: linhas e bytes armazenados, horário do último recebimento, status de ingestão e uma série temporal de intervalos. A chamada exige `streams.read` ou, para a telemetria do sistema, `sys.telemetry.read`. A resposta não inclui o fluxo `_audit` se o token não tiver `audit.read`.

**Parâmetros de consulta**

| Parâmetro | Padrão | Observações |
|---|---|---|
| `windowSecs` | 86400 | Duração da janela, de 3600 a 604800. |
| `bucketCount` | 24 | Número de intervalos na série, de 6 a 48. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/runtime?windowSecs=3600" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

| `status` | Significado |
|---|---|
| `healthy` | O fluxo recebeu dados nos últimos 15 minutos. |
| `delayed` | O fluxo recebeu os últimos dados há mais de 15 minutos e há menos de 2 horas. |
| `interrupted` | O fluxo recebeu os últimos dados há mais de 2 horas. |
| `idle` | O fluxo fica inativo por definição, como o fluxo de traces do Mole Agent. |
| `unused` | O fluxo nunca recebeu dados. |
| `unknown` | As estatísticas não estão disponíveis. |

`staleIndexFiles` conta os arquivos que ainda usam os índices com as configurações que estavam em vigor antes da última alteração de um tipo de índice do fluxo. A contagem cai até 0 à medida que o sistema reindexa os arquivos em segundo plano.
