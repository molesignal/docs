```http
GET /api/v1/streams/{id}
```

Retorna a definição do stream com seu esquema, o valor explícito de `retention`, o valor calculado de `effectiveRetention` e as configurações do stream. A chamada exige `streams.read` ou, para a telemetria do sistema, `sys.telemetry.read`. O stream `_audit` também exige `audit.read` e retorna `403` sem essa permissão.

**Parâmetros de caminho**

| Parâmetro | Tipo | Observações |
|---|---|---|
| `id` | string | O `id` do stream obtido em [Listar streams](/pt-BR/api/streams/list). Se o ID for desconhecido, a chamada retorna `404`. |
