```http
GET /api/v1/streams
```

Retorna todos os streams da organização, ordenados por nome e tipo, em um array JSON. Cada item segue a estrutura mostrada em [Obter um stream](/pt-BR/api/streams/get), incluindo o esquema, a retenção explícita (`retention`), a retenção efetiva calculada (`effectiveRetention`), as configurações e os carimbos de data e hora em microssegundos. A chamada exige `streams.read` ou `sys.telemetry.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

A resposta inclui os streams protegidos do sistema, como `_molesignal`. A resposta omite `_audit` quando o token não tem `audit.read`. O nome e o tipo identificam o stream em conjunto, portanto o mesmo nome pode aparecer em vários tipos.

## Use a resposta

Este endpoint retorna definições de streams, não registros de telemetria. Use-o para encontrar o ID de um stream antes de consultar seu esquema ou alterar sua configuração. Para consultar eventos, use a [API de consultas](/pt-BR/api/query/execute).

| Campo | Interpretação |
|---|---|
| `id` | Identificador estável que a API usa para acessar um único stream. |
| `name` e `streamType` | Identificam o conjunto de dados em conjunto. Não use apenas o nome como chave do inventário. |
| `schema` | Definições de campos para montar consultas. |
| `retention` | Retenção explícita do stream. Se o valor for `null`, vale o padrão. |
| `effectiveRetention` | Retenção efetiva que o stream aplica. |
| `createdAt`, `updatedAt` | Carimbos de data e hora Unix em microssegundos, não em milissegundos. |

## Verifique o acesso e o escopo dos dados

Use uma credencial associada à organização desejada. As permissões `streams.read` ou `sys.telemetry.read` permitem fazer a solicitação de listagem. Sem `audit.read`, a resposta omite `_audit`. A ausência de `_audit` não significa que a coleta de auditoria esteja desativada.

A resposta é um array JSON, não um objeto que contém um campo `items`. Esta rota não tem parâmetro de paginação. Um array vazio indica que a solicitação não retornou streams no escopo da organização e das permissões de acesso. Isso não comprova que outra organização esteja sem dados.

Depois de localizar o par `(name, streamType)` desejado, passe o `id` correspondente para [Obter um stream](/pt-BR/api/streams/get). Use uma [consulta de exemplo](/pt-BR/api/query/execute) para verificar a disponibilidade real de eventos, independentemente da presença de uma definição de stream.
