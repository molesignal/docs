```http
GET /api/v1/streams/usage
```

Retorna quanto cada fonte ingeriu em uma janela e como esse volume se compara ao respectivo orçamento. Requer `intake_usage.read` ou `sys.telemetry.read` na organização `_sys`.

Um valor desconhecido é `null`, não zero. Quando não é possível ler os registros, `available` é `false` e todos os valores são `null`. Quando a medição começa dentro da janela, `complete` é `false` e os valores são limites inferiores.

**Parâmetros de consulta**

| Parâmetro | Padrão | Observações |
|---|---|---|
| `dimension` | `credential` | `credential`, `stream` ou `service`. |
| `windowSecs` | 86400 | Duração da janela, de 3600 a 2678400. A janela começa em uma hora cheia. |

`sourceKey` tem o formato `<credential_kind>:<id>` para uma credencial (`apiToken`, `connector`, `user`, `internal`) e `<stream_type>:<name>` para um fluxo. Para um serviço, é o nome do serviço. Uma string vazia representa eventos sem serviço informado, e `*` representa os serviços que excedem o limite.

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/usage?dimension=credential&windowSecs=86400" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

## Uma fonte

```http
GET /api/v1/streams/usage/detail
```

Retorna os dados de uma fonte na janela: os totais, os valores horários agrupados em intervalos e o detalhamento pelas outras duas dimensões, com até 20 fontes por dimensão.

| Parâmetro | Padrão | Observações |
|---|---|---|
| `dimension` | Obrigatório | `credential`, `stream` ou `service`. |
| `sourceKey` | Obrigatório | A fonte, conforme retornada por `GET /api/v1/streams/usage`. |
| `windowSecs` | 86400 | De 3600 a 2678400. |
| `bucketCount` | 24 | Número de intervalos na série, de 6 a 48. |
