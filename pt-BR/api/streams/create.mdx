```http
POST /api/v1/streams
```

A primeira gravação também cria um stream. Use esta chamada para declarar um stream com antecedência e especificar o esquema, os índices, os campos criptografados ou a retenção. A chamada exige `streams.create`.

**Corpo**

| Campo | Tipo | Obrigatório | Observações |
|---|---|---|---|
| `name` | string | Sim | Letras, números, `_`, `-` e `.`. Os nomes dos [streams da plataforma](/pt-BR/streams#fluxos-da-plataforma), como `_molesignal` e `_audit`, são reservados. |
| `streamType` | string | Sim | `logs`, `metrics`, `traces`, `profiles` ou `extend`. |
| `fields` | array | Não | Definições dos campos. Consulte as propriedades abaixo. |
| `retentionDays` | integer | Não | De 1 a 3650. Omita o campo para usar o padrão da plataforma em **Configurações → Retenção de dados**. |
| `settings` | object | Não | Configurações do stream, como `description` e `queryable`. Consulte [Editar retenção e configurações](/pt-BR/api/streams/edit-retention). |

Cada campo tem as seguintes propriedades:

| Propriedade | Tipo | Observações |
|---|---|---|
| `name` | string | Nome do campo. |
| `dataType` | string | `bool`, `int64`, `float64`, `utf8`, `timestamp` ou `json`. |
| `nullable` | boolean | Padrão: `true`. |
| `indexType` | string | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value` ou `range`. Padrão: `none`. |
| `encrypted` | boolean | Criptografa o campo em repouso. Não é possível alterar essa propriedade depois. Consulte [Streams](/pt-BR/streams#campos-criptografados). |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "app",
    "streamType": "logs",
    "fields": [
      { "name": "trace_id", "dataType": "utf8", "nullable": true,
        "indexType": "exact", "encrypted": false }
    ],
    "retentionDays": 30
  }'
```
</RequestExample>

**Erros**

| Status | Causa |
|---|---|
| `403` | O nome pertence a um stream da plataforma ou o token não tem a permissão `streams.create`. |
| `409` | Já existe um stream com o mesmo nome e tipo. |
| `422` | Falta um campo no corpo ou um campo é inválido, como no caso de um `dataType` desconhecido. A resposta é em texto simples. |
