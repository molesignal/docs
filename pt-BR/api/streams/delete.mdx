```http
DELETE /api/v1/streams/{id}
```

Exclui a definição do fluxo. O compactador libera o espaço ocupado pelos dados armazenados. Não é possível excluir o fluxo protegido do sistema `_molesignal`. Excluir um fluxo pode comprometer o funcionamento de dashboards, visualizações salvas, regras de alerta, relatórios e pipelines que fazem referência a ele. A chamada exige `streams.delete` e, para o fluxo `_audit`, também exige `audit.read`. Sem `audit.read`, a chamada para esse fluxo retorna `403`.

**Parâmetros de caminho**

| Parâmetro | Tipo | Observações |
|---|---|---|
| `id` | string | O `id` do fluxo. A chamada retorna `404` se o ID for desconhecido. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/streams/$STREAM_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>
