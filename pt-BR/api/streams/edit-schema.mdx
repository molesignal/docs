```http
PUT /api/v1/streams/{id}/settings
```

O esquema de um fluxo evolui à medida que novos campos chegam pela ingestão, e a API não altera os tipos dos campos. Use este endpoint para escolher o tipo de índice dos campos que já estão no esquema. A chamada exige `streams.configure` e, para o fluxo `_audit`, também exige `audit.read`. O mesmo endpoint também altera a retenção e as configurações. Consulte [Editar retenção e configurações](/pt-BR/api/streams/edit-retention).

**Corpo**

| Campo | Tipo | Observações |
|---|---|---|
| `fields` | array | Uma entrada por campo a configurar. |

Cada entrada de `fields`:

| Propriedade | Tipo | Observações |
|---|---|---|
| `name` | string | Um campo que já está no esquema. |
| `indexType` | string | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value` ou `range`. Consulte [Fluxos](/pt-BR/streams#esquema-e-campos). |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexType": "exact" },
      { "name": "msg", "indexType": "full_text" }
    ]
  }'
```
</RequestExample>

A resposta contém o fluxo atualizado, no formato mostrado em [Obter um fluxo](/pt-BR/api/streams/get). A alteração entra em vigor imediatamente para os dados gravados a partir desse momento. O MoleSignal reindexa os dados anteriores em segundo plano. Consulte [Fluxos](/pt-BR/streams#esquema-e-campos). Os índices `full_text`, `ngram` e `ip` aceitam apenas campos `utf8`, e o índice `key_value` aceita apenas campos `json`.
