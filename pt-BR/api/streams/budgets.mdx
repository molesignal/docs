Um orçamento apenas envia notificações quando uma fonte se aproxima do limite ou o ultrapassa: a ingestão continua respondendo e armazenando dados da mesma forma. Consulte [Uso e orçamentos de ingestão](/pt-BR/streams#uso-de-ingestão-e-orçamentos).

## Listar orçamentos

```http
GET /api/v1/streams/budgets
```

Retorna todos os orçamentos da organização com o rótulo da fonte e a situação de cada orçamento no período atual. Requer `intake_usage.read` ou, na organização `_sys`, `sys.telemetry.read`. Valores desconhecidos aparecem como `null`.

## Definir um orçamento

```http
POST /api/v1/streams/budgets
```

Define o orçamento de uma fonte. Cada fonte pode ter no máximo um orçamento. Definir o orçamento novamente atualiza o existente. Requer `intake_budgets.manage`. A organização `_sys` não pode definir orçamentos.

| Campo | Obrigatório | Observações |
|---|---|---|
| `dimension` | Sim | `credential`, `stream` ou `service`. |
| `sourceKey` | Sim | A fonte, conforme retornada por [Uso de ingestão](/pt-BR/api/streams/usage). Não é possível definir orçamentos para a telemetria da própria plataforma, eventos sem serviço identificado ou serviços além do limite. |
| `period` | Sim | `day` ou `month`, de acordo com o calendário em UTC. |
| `limitSize` | Sim | Em MiB, de 1 a 1073741824. |
| `warnPercent` | Não | Percentual do limite que dispara o aviso, de 0 a 99. Com `0`, o aviso só é enviado quando o consumo atinge o limite. Padrão: 80. |
| `notifyUserIds` | Não | Membros da organização a notificar, até 50. Por padrão, a notificação vai para o usuário que define o orçamento. Contas de serviço devem especificar os destinatários. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/streams/budgets" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"dimension":"stream","sourceKey":"logs:app","period":"day","limitSize":102400}'
```
</RequestExample>

## Remover um orçamento

```http
DELETE /api/v1/streams/budgets/{budgetId}
```

Retorna `204`. Requer `intake_budgets.manage`.
