```http
GET /api/v1/entities
GET /api/v1/entities/detail?kind={kind}&key={key}
```

As entidades são lidas a cada cinco minutos das instâncias que o APM vê e dos campos de recurso de
métricas e logs; consulte [Infraestrutura](/pt-BR/infrastructure) para os campos e chaves. As duas chamadas exigem
qualquer uma das permissões `apm.services.read`, `metrics.read`, `logs.read` ou `sys.telemetry.read`.

## Listar entidades

| Parâmetro | Observações |
|---|---|
| `kind` | `cluster`, `node`, `host`, `pod`, ou `container`. Todos os tipos quando omitido. |
| `search` | Parte do nome ou da chave, sem diferenciar maiúsculas de minúsculas. |
| `seenSince` | Apenas entidades vistas desde este momento, em microssegundos. |
| `limit` | No máximo 500, valor padrão. |

As entidades são retornadas da mais recente para a mais antiga. `services` conta os serviços que rodam diretamente em cada uma.

<ResponseExample>
```json 200
[
  {
    "kind": "pod",
    "key": "prod-eu/shop/checkout-7d9f-abcde",
    "name": "checkout-7d9f-abcde",
    "attributes": {
      "k8s.cluster.name": "prod-eu",
      "k8s.namespace.name": "shop",
      "k8s.node.name": "node-3",
      "k8s.pod.name": "checkout-7d9f-abcde"
    },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000,
    "services": 1
  }
]
```
</ResponseExample>

## Ler uma entidade

`kind` e `key` são obrigatórios; a chave é a que a lista fornece. A resposta contém a entidade, em que ela
é executada ou do que faz parte (`parents`), o que é executado nela ou faz parte dela (`children`, até 200), e os
serviços nela e no que é executado nela (`services`, até 200), procurados três níveis abaixo: os
nós de um cluster, os pods deles e os serviços nesses.

<ResponseExample>
```json 200
{
  "entity": {
    "kind": "node",
    "key": "prod-eu/node-3",
    "name": "node-3",
    "attributes": { "k8s.cluster.name": "prod-eu", "k8s.node.name": "node-3" },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000
  },
  "parents": [{ "kind": "cluster", "key": "prod-eu", "name": "prod-eu" }],
  "children": [{ "kind": "pod", "key": "prod-eu/shop/checkout-7d9f-abcde", "name": "checkout-7d9f-abcde" }],
  "services": [{ "namespace": "shop", "name": "checkout", "environment": "production" }]
}
```
</ResponseExample>

**Erros**

| Status | Causa |
|---|---|
| `400` | `kind` não é um dos cinco tipos. |
| `404` | Nenhuma entidade deste tipo e chave foi vista na última semana. |
