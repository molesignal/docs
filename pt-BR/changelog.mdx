## Notas da versão e preparação para a atualização

As [versões no GitHub](https://github.com/molesignal/molesignal/releases) são a fonte oficial das notas da versão. A lista abaixo carrega os detalhes das versões no navegador. Se o JavaScript ou a solicitação ao GitHub estiver indisponível, use esse link para consultar as versões, as datas de publicação, as alterações e os arquivos disponíveis para download.

### Antes de atualizar

1. Registre a versão em execução com `molesignal --version` e localize a versão de destino nas notas da versão.
2. Leia as notas de compatibilidade e migração entre as duas versões. Diferencie as prévias das versões estáveis.
3. Proteja o PostgreSQL, o armazenamento de objetos, a configuração e as chaves de criptografia conforme as instruções em [Backup e restauração](/pt-BR/backup-restore).
4. Valide as consultas a dados históricos, a ingestão controlada de novos dados, as permissões e o comportamento das notificações em um ambiente isolado antes de atualizar em produção.

Use a [lista de verificação de produção](/pt-BR/deployment/production-checklist) e o [guia de preparação para recuperação](/pt-BR/best-practices/recovery-readiness) para seguir as etapas de aceitação. Os recursos planejados para a edição Enterprise ainda não foram lançados. Consulte a página do recurso e as notas da versão de destino para verificar a disponibilidade.
