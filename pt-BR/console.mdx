Todas as páginas do MoleSignal têm a mesma estrutura: a barra superior, com o menu que reúne todas as áreas do
produto, e o conteúdo. Esta página explica os controles em comum. O restante do manual descreve as páginas de cada área do
produto.

## Entrar

Abra o endereço da instância do MoleSignal e entre com um destes métodos:

| Método | Como entrar |
|---|---|
| E-mail e senha | Selecione **Entrar com e-mail**, digite o e-mail, selecione **Continuar** e digite a senha. Se não houver outro método de entrada, a página abre direto no campo de e-mail. |
| Login único | Selecione a linha de um provedor habilitado. Para um provedor LDAP, digite primeiro o nome de usuário do diretório e depois a senha. Consulte [Login único](/pt-BR/identity/sso). |
| Chave de acesso | Selecione **Continuar com uma chave de acesso**. Consulte [Autenticação multifator](/pt-BR/identity/mfa). |
| Cadastro | **Cadastre-se →** só aparece quando a instância permite o autocadastro. Se a instância enviar e-mails, digite o e-mail, abra o link recebido e informe um nome e uma senha. O link expira em 30 minutos. A nova conta pode entrar na hora ou precisa aguardar a aprovação de um administrador. Se a instância não enviar e-mails, informe o e-mail, o nome e a senha de uma vez. A nova conta precisa aguardar a aprovação de um administrador. A página dá a mesma resposta, mesmo que o e-mail não esteja associado a uma conta. |

A página guarda o último método de entrada e a última conta usados neste navegador, mas nunca guarda a senha, e
marca a linha correspondente com **Último uso**. Após uma entrada com e-mail e senha, uma linha extra no topo,
**Continuar com e-mail**, abre direto o campo de senha.

Para redefinir uma senha esquecida, selecione **Esqueceu a senha?** e digite o e-mail da conta. A
página dá a mesma resposta, mesmo que o e-mail não exista. O link no e-mail expira em 30
minutos e funciona uma única vez. A nova senha precisa ter pelo menos 8 caracteres. Cada endereço recebe no máximo 5 e-mails de cadastro e
redefinição de senha por hora.

Após várias tentativas com a senha incorreta, a página informa quanto tempo é preciso esperar. Consulte
[Limites de login](/pt-BR/settings/platform#limites-de-login).

Após a entrada, o MoleSignal abre a página definida em **Abrir ao entrar no espaço de trabalho**, nas
[preferências](/pt-BR/account#preferências) da conta. Por padrão, essa página é **Início**.

## Escolher um espaço de trabalho

A interface chama a organização selecionada de **espaço de trabalho**. O seletor de espaços de trabalho, à esquerda na
barra superior, mostra o logotipo e o nome do espaço de trabalho. Um espaço de trabalho
sem [logotipo](/pt-BR/settings/organization#informações-da-organização) próprio mostra o
logotipo do MoleSignal.

Selecione o seletor para abrir o menu do espaço de trabalho. O cabeçalho do menu mostra o nome e a descrição do espaço,
além da função da conta nesse espaço.
**Configurações da organização** abre **Configurações → Geral**, e **Membros** abre a lista de membros do
espaço de trabalho. **Trocar para** lista as outras organizações das quais a conta faz parte, cada uma com seu
logotipo ou sua inicial. Selecione uma para trocar de espaço de trabalho. **Gerenciar organizações…** aparece para contas que
administram organizações.

A troca de espaço de trabalho carrega as permissões da conta na organização selecionada. A navegação oculta as páginas que a
nova função não permite acessar.

<Note>
  A interface usa **espaço de trabalho**. Os campos da API e as chaves de permissão usam `organization` e `org_id`.
</Note>

## A barra superior

| Controle | Finalidade |
|---|---|
| Seletor de espaços de trabalho | Mostra o logotipo e o nome do espaço de trabalho atual e abre o [menu do espaço de trabalho](#escolher-um-espaço-de-trabalho). |
| Menu | Abre o [menu](#o-menu) com todas as áreas do produto. |
| Campo de busca | Abre a [paleta de comandos](#pesquise-com-a-paleta-de-comandos). |
| Mole Agent | Abre o painel do [Mole Agent](/pt-BR/agent) em qualquer página. Aparece quando a conta tem permissão para usar o Mole Agent. |
| **Painel do NOC** | Abre o modo de exibição do painel para telas grandes. Consulte [Painel do NOC](/pt-BR/dashboards#painel-do-noc). |
| **Notificações** | Lista cadastros e rascunhos de páginas de status que aguardam aprovação, além de automações de páginas de status que precisam de atenção. O número no sino indica quantas notificações ainda não foram lidas, até **99+**. |
| **Ajuda** | Dá acesso a esta documentação, aos atalhos de teclado e à seção **Sobre**, que mostra a versão da instância. |
| Tema | Alterna entre os temas escuro e claro e salva a escolha na conta. |
| Avatar do usuário | Abre as opções **Configurações da conta**, **Preferências**, **Notificações**, **Linguagem** e **Sair**. A opção **Sair** encerra a sessão em todas as abas do navegador. |

## O menu

Para abrir o menu com todas as áreas do produto sobre a página, passe o cursor sobre o botão de menu ou selecione-o.
O botão fica depois do seletor de espaços de trabalho, na barra superior. O menu agrupa as áreas da mesma forma que este
manual.

| Grupo | Área | Finalidade |
|---|---|---|
| Início | [**Início**](/pt-BR/home) | Status do sistema: incidentes, regras, serviços, verificações, taxa de erros e latência, ingestão de dados e plantões. |
| Observabilidade | [**Dashboards**](/pt-BR/dashboards) | Painéis e variáveis que a equipe acompanha em conjunto. |
| | [**Métricas**](/pt-BR/metrics) | PromQL, séries, cardinalidade e qualidade dos dados. |
| | [**Logs**](/pt-BR/logs) | Busque eventos, explore campos e abra o contexto de um evento. |
| | [**Rastreamentos**](/pt-BR/traces) | Encontre rastreamentos, inspecione spans e compare dois rastreamentos. |
| | [**APM**](/pt-BR/apm) | Integridade dos serviços, endpoints, dependências, erros, SLOs e implantações. |
| | [**RUM**](/pt-BR/rum) | Sessões, gravações de sessões, erros de frontend, Web Vitals e análises. |
| | [**Perfis**](/pt-BR/profiles) | Gráficos de chama de CPU, memória e contenção. |
| Confiabilidade | [**Alertas**](/pt-BR/alerting) | Incidentes, regras, escalas de plantão, escalonamentos e silenciamentos. |
| | [**Monitoramento sintético**](/pt-BR/synthetics) | Verificações programadas a partir dos locais das sondas. |
| | [**Páginas de status**](/pt-BR/status-pages) | Publicação de incidentes e manutenções para clientes. |
| Operações com IA | [**Mole Agent**](/pt-BR/agent) | Conversas, investigações, automações, conhecimento e habilidades. |
| Dados | [**Fonte de dados**](/pt-BR/intake) | Conecte uma fonte e verifique se os dados chegam. |
| | [**Fluxos**](/pt-BR/streams) | Esquemas, retenção e tarefas de busca. |
| | [**Pipelines**](/pt-BR/pipelines) | Transforme e encaminhe dados e preencha lacunas no histórico. |
| | [**Funções**](/pt-BR/functions) | Transformações reutilizáveis em VRL e JavaScript. |
| | [**Tabelas de extensão**](/pt-BR/extend-tables) | Tabelas de consulta que enriquecem eventos. |
| Colaboração | [**Relatórios**](/pt-BR/reports) | Relatórios programados e compartilhados. |
| Administração | [**Identidade e acesso**](/pt-BR/identity) | Usuários, funções, grupos, equipes, tokens e login único. |
| | [**Configurações**](/pt-BR/settings) | Configurações do espaço de trabalho, das notificações, dos dados, da segurança e da plataforma. |

O menu mostra apenas as áreas que as permissões da conta permitem acessar. Ocultar uma área nunca
substitui a verificação no servidor.

**Recentes**, à esquerda no menu, lista as últimas áreas acessadas, da mais recente para a mais antiga, sem incluir a área
aberta no momento. A lista fica salva na conta e aparece também em outros navegadores.

Cada item abre na aba atual. Para abrir um item em uma nova aba, clique com Ctrl pressionado (⌘ no Mac) ou com o botão do meio,
ou passe o cursor sobre o item e selecione a seta no fim da linha. Ative **Sempre abrir em uma nova aba** na parte inferior
do menu para abrir todos os itens em novas abas. A conta salva essa preferência.

Ao abrir o menu com o cursor, ele fecha assim que o cursor sai do botão e do menu. Para mantê-lo aberto, selecione o botão
enquanto o menu estiver aberto. Para fechar o menu, pressione Esc, selecione qualquer ponto fora do menu ou selecione o botão
de menu novamente. Em telas estreitas, o menu ocupa toda a área abaixo da barra superior.

## Mantenha o contexto temporal

O seletor de tempo no cabeçalho da página de consulta define o intervalo de tempo da página.

- Na parte inferior do seletor, confira o fuso horário usado na página. O fuso padrão da conta vale até
  selecionar outro em **Alterar**. O fuso escolhido vale para a página ou para a aba de consulta
  em Logs, Traces e Métricas. Selecione **Definir como meu fuso horário padrão** para torná-lo o padrão da conta.
- Ao navegar para outro sinal, mantenha o intervalo de tempo e adicione os identificadores da origem. Por
  exemplo, ao passar de um trace para os logs relacionados, mantenha o intervalo do trace e adicione o filtro
  `trace_id`.
- Fixe o horário atual como âncora e copie um link para a investigação atual com o intervalo
  de tempo pela paleta de comandos ou pelos [atalhos](#atalhos-de-teclado).

## Pesquise com a paleta de comandos

Pressione `⌘K` ou `Ctrl+K` ou selecione a caixa de pesquisa. Digite para encontrar:

- páginas, streams, serviços, dashboards, visualizações salvas, regras de alerta e incidentes;
- ações: abrir uma página, executar SQL ou PromQL, definir um intervalo de tempo dos últimos 5 minutos aos
  últimos 7 dias, fixar o horário atual, copiar o link da investigação, alterar o tema ou a densidade,
  abrir as configurações, criar um dashboard, um alerta ou um pipeline, conectar uma fonte de dados, exibir os
  atalhos de teclado e sair da conta.

Pressione `Enter` para abrir um resultado. O rodapé da paleta mostra as teclas para abrir um resultado em uma nova
[pilha de investigação](/pt-BR/correlation#pilha-de-investigação-na-interface) ou adicioná-lo ao topo da
pilha atual.

## Atalhos de teclado

Pressione `⌘/` ou `Ctrl+/` ou abra **Ajuda → Atalhos de teclado** para listar os atalhos. No Windows e no
Linux, use `Ctrl` no lugar de `⌘` e `Alt` no lugar de `⌥`.

| Atalho | Ação |
|---|---|
| `⌘K` | Abra a paleta de comandos. |
| `⌘/` | Exiba os atalhos de teclado. |
| `⌘J` | Abra ou feche o painel do Mole Agent. |
| `⌘⌥E` | Abra o seletor de tempo. |
| `⌘⌥P` | Fixe ou solte a âncora temporal. |
| `⌘⌥Y` | Copie o link da investigação. |
| `⌘[` / `⌘]` | Volte ou avance na pilha de investigação. |
| `⌘⌥S` | Acesse os serviços de APM. |
| `⌘⌥A` | Acesse os incidentes de alerta. |
| `⌘⌥D` | Acesse os dashboards. |
| `⌘⌥T` / `⌘⌥L` | Abra a pilha de investigação com um trace ou uma pesquisa de logs. |
| `⌘⌥R` | Acesse a visão geral de RUM. |
| `⌘⌥F` | Acesse as funções. |
| `⌘⌥I` | Acesse Identidade e acesso. |
| `⌘Esc` | Feche a sobreposição em primeiro plano. |

Para desativar os atalhos, desmarque **Ativar atalhos de teclado** nas
[preferências](/pt-BR/account#preferências) pessoais.

## Investigue um problema

Siga estas etapas em uma investigação típica:

<Steps>
  <Step title="Comece pelo sintoma">
    Abra um incidente, um painel de dashboard, um trace lento, um erro de frontend ou um perfil com alto consumo de recursos.
  </Step>
  <Step title="Restrinja o intervalo de tempo e o recurso">
    Escolha o menor intervalo de tempo útil e filtre por serviço, stream, ambiente ou sessão.
  </Step>
  <Step title="Navegue entre os sinais">
    Use as ações de correlação para abrir os traces, logs, métricas, perfis ou sessões de RUM
    relacionados. Consulte [Correlação entre sinais](/pt-BR/correlation).
  </Step>
  <Step title="Registre as descobertas">
    Salve a consulta como uma visualização, adicione um painel ao dashboard, crie uma regra de alerta ou peça ao Mole Agent que
    investigue e salve o resultado.
  </Step>
</Steps>

## Linguagem e configurações pessoais

Escolha a linguagem da interface em **Linguagem**, no menu do usuário. A alteração entra em vigor imediatamente e
fica salva na conta, mantendo a mesma linguagem em outros navegadores.

Em **Configurações da conta**, gerencie o perfil, o tema e a densidade, o fuso horário e o formato de data, a página inicial, as
notificações pessoais e as sessões. Consulte
[Configurações da conta](/pt-BR/account).
