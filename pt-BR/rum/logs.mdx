O SDK do navegador registra os logs com a sessão e a visualização em que foram gerados. Assim, é possível abrir a reprodução a partir de um log e ver, na sessão, o que a página registrou. O SDK só envia dados quando um log é registrado ou quando a captura do console é solicitada. Os logs exigem o [SDK do navegador](/pt-BR/rum/browser-sdk) 0.3.0 ou posterior.

```ts
import { molesignalRum } from '@molesignal/browser-rum';

molesignalRum.logger.info('cart opened', { items: 3 });

const payments = molesignalRum.createLogger({ name: 'payments', level: 'warn', context: { provider: 'stripe' } });
payments.error('payment declined', { code: 402 }, error);
```

Um logger ignora as mensagens abaixo do nível configurado e aceita `debug`, `info`, `warn` e `error`. Ao receber um erro como terceiro argumento, o logger preserva no log o tipo e o rastreamento de pilha do erro.

Para encaminhar também o que a página escreve no console:

```ts
init({ /* … */ forwardConsoleLogs: ['warn', 'error'] }); // or 'all'
```

O SDK encaminha a saída do console sem alterações. Mantenha a captura desativada onde o console puder conter dados pessoais ou verifique o que o aplicativo [remove na ingestão](/pt-BR/rum/privacy#remova-texto-sensível-na-ingestão), inclusive do texto e do rastreamento de pilha dos logs.

## Onde encontrar os logs

- Na [página da sessão](/pt-BR/rum/explorer#abra-uma-sessão), a aba **Logs**, abaixo da reprodução, lista os logs em ordem e destaca o log correspondente ao ponto atual da reprodução. Clique em uma linha para ir ao momento do log.
- No [explorador](/pt-BR/rum/explorer), **Logs** é um tipo de linha.
- Em **Logs**, o fluxo `rum_logs` é um fluxo de logs comum, com `level` e `message`. O histograma por nível e os demais recursos funcionam como em qualquer outro fluxo.

Se o aplicativo [não retiver uma sessão](/pt-BR/rum/sampling), nenhum log dela será armazenado. A contagem da visualização não inclui os logs.

## Erros no SDK

Quando ocorre um erro no próprio SDK (por exemplo, o servidor rejeita um evento ou `beforeSend` lança uma exceção), o SDK registra um log com o logger `molesignal-rum` e a origem `sdk`. O SDK registra cada erro uma única vez e limita a quantidade de logs por carregamento de página. O SDK não registra falhas de comunicação com o servidor, pois o log também não chegaria ao destino. Desative esse registro com `trackSdkErrors: false`. O SDK chama `onError` em ambos os casos.

## Campos

| Coluna | Descrição |
|---|---|
| `level` | `debug`, `info`, `warn` ou `error`. |
| `message` | Mensagem do log. |
| `log.id` | ID do log. |
| `log.logger` | Nome do logger: `console` para o console e `molesignal-rum` para o próprio SDK. |
| `log.origin` | `logger`, `console`, `report` ou `sdk`. |
| `log.error_type`, `log.stack` | Tipo e rastreamento de pilha do erro registrado no log. |
