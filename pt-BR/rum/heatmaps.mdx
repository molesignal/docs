Um mapa de calor mostra como os usuários interagem com uma página de um aplicativo no navegador. **Análises → Mapa de calor** oferece dois mapas:

- **Cliques**: mostra onde os usuários clicam. As áreas mais quentes concentram mais cliques, e uma lista ao lado mostra os elementos clicados.
- **Rolagem**: mostra até onde os usuários rolam a página. A página escurece conforme a profundidade aumenta. Linhas tracejadas marcam até onde chegaram 75%, 50% e 25% das visitas.

Os mapas de calor exigem a versão 0.3.0 ou posterior do [SDK para navegador](/pt-BR/rum/browser-sdk), que informa onde ocorreu cada clique e até onde a rolagem chegou em cada visualização.

Cada mapa corresponde a uma página e a uma categoria de janela (desktop a partir de 1024 pixels de largura, tablet a partir de 600 e celular abaixo de 600), pois o layout da página varia conforme a largura. O endereço inclui todas as opções selecionadas, então basta compartilhá-lo para enviar o mapa como está.

## Requisitos

Os mapas usam dados do SDK para navegador.

| Mapa | Requisito |
|---|---|
| Cliques | `trackUserInteractions: true` |
| Rolagem | Nenhum: `trackScroll` vem ativado por padrão |
| A página sob o mapa | [Replay de sessão](/pt-BR/rum/session-replay) em pelo menos algumas sessões dessa página |

Cliques fora de controles também contam: eles mostram onde os usuários esperam encontrar um controle.

## A página sob o mapa

O mapa usa uma [gravação](/pt-BR/rum/session-replay) de uma sessão que abriu a página e mostra toda a sua extensão no momento em que o carregamento terminou. Use **Gravação** para selecionar uma das últimas 20 sessões que gravaram a página nessa categoria de janela e **Abrir esta sessão** para acessar a sessão exibida.

A página preserva o mascaramento do replay e só fica visível com a permissão `rum.replay.read`. Mesmo sem gravação ou sem essa permissão, a lista ainda mostra os elementos e a tabela mostra as profundidades de rolagem.

## Como o mapa posiciona os cliques

Cada clique indica o elemento atingido e a posição dentro dele. Assim, o mapa mostra o clique no mesmo elemento, independentemente do tamanho da janela. O mapa localiza o elemento na gravação pelo caminho dentro da página (`action.target.path`, que contém apenas tags e posições, sem texto digitado por usuários). Se uma mudança na página fez com que o elemento não apareça na gravação, o mapa usa as posições dos cliques na página, e a lista mostra **Não aparece nesta gravação da página**.

Para registros de versões do SDK anteriores à introdução desse campo, o mapa agrupa os cliques por seletor e os exibe no centro do elemento quando o seletor encontra uma correspondência.

## Como os mapas calculam os números

Os mapas contam apenas os registros armazenados. Se um aplicativo [armazena apenas uma parte das sessões](/pt-BR/rum/sampling), o mapa mostra onde os usuários clicam, mas não o total de cliques de todas as sessões. Os mapas excluem [sessões geradas por testes](/pt-BR/rum/test-traffic).

A profundidade vai do topo da página até a borda inferior da janela. Uma visualização que chega a certo ponto também passa por tudo que fica acima. Por isso, a proporção de visualizações que atingem cada profundidade nunca aumenta à medida que se avança pela página.

## Mole Agent

A ferramenta `get_rum_heatmap` retorna os dados de uma página em números: os elementos com mais cliques, a altura total da página e a proporção de visualizações que atingiram cada profundidade.
