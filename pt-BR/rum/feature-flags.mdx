Informe ao SDK o valor resultante da avaliação de uma flag. Todos os eventos da visualização incluirão esse valor:

```ts
molesignalRum.addFeatureFlagEvaluation('checkout_v2', 'treatment');
```

Para integrar um serviço de flags, repasse os resultados das avaliações. O LaunchDarkly oferece inspetores, e o OpenFeature oferece hooks:

```ts
LDClient.initialize(id, user, {
  inspectors: [{
    type: 'flag-used',
    name: 'molesignal',
    method: (key, detail) => molesignalRum.addFeatureFlagEvaluation(key, detail.value),
  }],
});

OpenFeature.addHooks({
  after: (context, details) => molesignalRum.addFeatureFlagEvaluation(context.flagKey, details.value),
});
```

## A aba de flags de recurso

**Flags de recurso** lista as flags avaliadas nas sessões do período, começando pela que apareceu em mais sessões. Selecione uma flag para comparar seus valores lado a lado: o número de sessões, os percentuais de visualizações com erro e com sinais de frustração e, para aplicações de navegador, o 75º percentil de LCP, INP e CLS. O valor com mais visualizações com erro aparece em vermelho. **Ver estas visualizações** abre essas visualizações no explorador.

## Consulte uma flag em qualquer lugar

Use `feature_flags.<key>` como nome da flag, da mesma forma que faria com uma coluna, sempre que o [explorador](/pt-BR/rum/explorer) ou a API aceitar um campo:

```text
feature_flags.checkout_v2 = 'treatment' AND error.type = 'TypeError'
```

```http
POST /api/v1/rum/aggregate
{ "type": "views", "measures": [{ "fn": "p75", "field": "view.performance.lcp.timestamp" }], "groupBy": ["feature_flags.checkout_v2"] }
```

O mesmo vale para as outras chaves de uma coluna JSON: `context.<key>`, `usr.extra.<key>` e `view.custom_timings.<key>`. `GET /api/v1/rum/keys` lista as chaves disponíveis.

Em SQL, use `json_text("feature_flags", 'checkout_v2')` para ler uma chave. A função retorna texto ou NULL se a linha não contiver a chave. `json_keys("feature_flags")` lista as chaves de uma linha.

## Mole Agent

A ferramenta `get_rum_feature_flags` lista as flags. Use `flag` para comparar os valores de uma flag com as mesmas métricas.
