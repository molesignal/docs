Abra **Logs** para pesquisar fluxos de logs no espaço de trabalho ativo.

## Escolha um fluxo e um intervalo de tempo

Selecione um fluxo de logs e defina a menor janela de tempo que contém o evento. Janelas estreitas
reduzem as linhas verificadas e tornam a exploração de campos mais rápida.

O MoleSignal pode inferir o esquema de um fluxo à medida que os eventos chegam. O painel **Campos** lista os campos do
fluxo e adiciona filtros sem reescrever a consulta inteira.

## Abas de consulta

Cada consulta roda em uma aba própria. Uma aba mantém seu fluxo, consulta e intervalo de tempo, e uma consulta em
uma aba não afeta outra.

- Selecione **Nova aba** para abrir outra consulta. Até 10 abas podem ficar abertas ao mesmo tempo.
- Abra o menu de uma aba para **Renomear**, **Duplicar** ou **Fechar**.
- Selecione **Dividir em duas partes** para mostrar duas abas lado a lado. Cada metade lista suas próprias abas, e uma aba
  se move entre elas pelo menu. **Voltar para uma única página** encerra a divisão.

O navegador mantém as abas abertas por usuário e espaço de trabalho.

## Escreva uma consulta

O editor tem dois modos, **Código** e **Editor visual**, alternados pelos dois ícones ao lado do título (`</>` para
Código, os blocos para o Editor visual); cada um exibe o próprio nome ao passar o mouse.

**Código** aceita uma consulta de campos ou SQL. Uma instrução que começa com `SELECT` ou `WITH` roda como SQL.
Qualquer outra instrução roda como consulta de campos:

| Consulta de campos | Significado |
|---|---|
| `service = 'checkout'` | O campo tem exatamente este valor. |
| `message contains 'timeout'` | O campo contém o texto. |
| `MATCH(message, 'timeout')` | Pesquisa de substring sem diferenciar maiúsculas e minúsculas. |
| `MATCH_TEXT(message, 'timeout disk')` | Pesquisa de texto completo em um campo com índice de texto completo. |

Combine condições com `AND` e `OR`, sem diferenciar maiúsculas e minúsculas. `AND` tem precedência sobre `OR`, e os parênteses
agrupam condições: `level = 'error' AND (service = 'checkout' OR service = 'payments')`. Texto
sem um campo é pesquisado no campo `message` e pode ser uma das alternativas:
`timeout OR "connection reset"`. As aspas mantêm uma frase inteira, mesmo com uma palavra como `or` nela.
Compare com `=`, `!=`, `>`, `>=`, `<` e `<=`.

**Editor visual** mostra a mesma consulta de campos como linhas de filtros, uma linha para cada alternativa: todos os
filtros de uma linha precisam ser atendidos, e **OU** aparece antes de cada linha após a primeira. Selecione **Filtrar** para
adicionar um filtro a uma linha, ou **OU** para adicionar uma linha, e então escolha um campo, uma comparação e um valor. Cada
linha tem seu próprio texto de pesquisa. Uma parte entre parênteses dentro de uma linha, como o `OR` do exemplo
acima, é mantida como escrita e alterada em **Código**. Uma instrução que seja SQL não pode ser exibida como
filtros.

Use SQL para junções, expressões, CTEs ou agregações:

```sql
SELECT "_timestamp", level, msg, trace_id
FROM app
WHERE level = 'error'
ORDER BY "_timestamp" DESC
LIMIT 200;
```

```sql
SELECT level, COUNT(*) AS events
FROM app
GROUP BY level
ORDER BY events DESC;
```

Execute a consulta com **Executar**, ou pressione `⌘ Enter` ou `Ctrl+Enter` no editor. **Referência de sintaxe
da consulta** lista exemplos para o modo atual. Consulte [Consulta](/pt-BR/query#busca-de-texto) para as funções
de busca textual.

O planejador de consultas aplica o limite atual da organização mesmo para SQL personalizado.

## Explore campos

O painel **Campos** tem três partes: **Campos exibidos**, **Campos indexados** e **Outros
campos**. Campos que compartilham a primeira parte de um nome com pontos, como `http.method` e
`http.route`, abrem como um único grupo.

- Abra um campo para ver seus valores mais comuns no resultado. Adicione um valor como filtro de inclusão ou
  de exclusão. O filtro restringe a consulta inteira: uma consulta de alternativas é colocada entre parênteses
  antes dele.
- Mostre ou oculte um campo como uma coluna do resultado.
- Selecione **Analisar** em um campo para abrir a análise do campo: o número de valores distintos, as linhas
  com e sem um valor, estatísticas de um campo numérico, a distribuição de valores e os valores mais
  comuns ao longo do tempo.

## Leia os resultados

O histograma sobre os resultados conta todos os eventos que correspondem à consulta no intervalo de tempo, não
apenas a página carregada. Quatro visualizações interpretam o resultado:

| Visualização | Conteúdo |
|---|---|
| **Logs** | Os eventos correspondentes, uma linha cada. |
| **Estatísticas** | Um gráfico de uma agregação. Escolha a medida (contagem, contagem distinta, média, soma, mínimo, máximo, P50, P95 ou P99), o agrupamento e o tipo de gráfico, ou desenhe o resultado de uma agregação SQL. **Criar dashboard** salva o gráfico como um painel de um novo dashboard. |
| **Inspeção por IA** | Um relatório que o Mole Agent escreve sobre os logs correspondentes à consulta. Consulte [Inspeções de logs](/pt-BR/logs/inspections). |
| **Padrões** | Os eventos agrupados por padrão, com a contagem e a participação de cada padrão. |

A visualização **Padrões** conta os padrões de todo o intervalo de tempo no servidor. Um intervalo com mais
de 5.000 eventos é lido como uma amostra distribuída por ele, e cada contagem é ajustada proporcionalmente ao intervalo e
escrita com `≈`; a linha abaixo dos padrões informa quantos eventos o intervalo tem e quantos foram
lidos. **Alterar** compara cada padrão com uma linha de base escolhida ao lado: o trecho de mesmo
comprimento anterior (a opção padrão), o mesmo trecho uma semana antes, ou nenhum. **Novo** marca um padrão que a
linha de base não tinha, `×N` um que cresceu ao menos duas vezes e com pelo menos cinco eventos a mais, e **Menos** um
que caiu pela metade. Abrir um padrão mostra os eventos carregados que pertencem a ele, ou uma de suas mensagens quando
nenhum está carregado. Uma instrução escrita em SQL é agrupada a partir dos eventos que ela retornou.

Na visualização **Logs**:

- **Colunas** seleciona e ordena as colunas. As colunas padrão vêm dos campos do
  fluxo: o horário e, em seguida, os campos de nível, serviço e mensagem quando o fluxo os tiver.
- O tamanho da página é de 100, 200, 500, 1.000, 2.000 ou 5.000 eventos.
- Clique em um evento para abri-lo em um painel lateral ao lado dos resultados; arraste a borda esquerda do painel para redimensioná-lo,
  e a largura é mantida. O cabeçalho mostra o nível, o horário, a mensagem e os atributos que
  identificam o evento (serviço, host, ambiente, versão, rastreamento), cada um com as mesmas ações de um
  campo. As visualizações são **Campos**, **Rastreamento** quando o evento tem um ID de rastreamento, **Contexto** e
  **JSON bruto**. **Rastreamento** mostra o waterfall do rastreamento com o span do evento selecionado. **Contexto**
  mostra cinco linhas antes e cinco depois. Em um campo, adicione um filtro, copie o valor ou mostre o
  campo como uma coluna.
- Pivote para um rastreamento, serviço, métrica ou outro sinal correlacionado quando houver identificadores.
- Baixe o resultado como CSV, texto ou JSON.

## Compartilhe uma consulta

O endereço da página é a consulta na tela. Quando uma consulta roda, a página grava seu fluxo, sua
instrução (`q` para uma consulta de campos, `sql` para SQL) e a visualização dos resultados no endereço, para que uma
cópia da barra de endereços compartilhe a consulta, no intervalo de tempo que o seletor mostra, como a última
hora. Recarregar a página mantém a consulta e o editor como estavam.

Selecione **Compartilhar** para copiar um link para a consulta na tela. O link abre para membros autenticados da
organização que podem ler os dados. Escolha o intervalo de tempo do link: **Intervalo selecionado**
fixa o intervalo para os momentos na tela, e a outra opção mantém um intervalo relativo, como a
última hora, contado a partir do momento em que o link é aberto.

## Tarefas de busca

Uma busca grande demais para uma solicitação interativa roda como uma tarefa de busca. Abra
**Fluxos → Tarefas de busca** para acompanhar a tarefa e baixar o resultado. Consulte
[Fluxos](/pt-BR/streams#tarefas-de-busca).

## Visualizações salvas

Salve uma consulta SQL com um nome como uma [visualização salva](/pt-BR/saved-views). Reabra a visualização, execute a consulta
em outra janela de tempo ou anexe a visualização a um relatório.

<Tip>
  Preserve dimensões estáveis como `service.name`, `deployment.environment`, `trace_id` e
  `host.name` durante a ingestão. Esses campos tornam os pivôs entre sinais confiáveis.
</Tip>

## Permissões

- `streams.read` descobre streams e esquemas.
- `logs.read` lê logs: a lista, o histograma e as estatísticas de campos.
- `streams.query` executa uma instrução SQL e abre o contexto.
- `agent.use` executa uma inspeção de IA, que também exige um modelo de IA habilitado.
- `saved_views.create`, `saved_views.edit` e `saved_views.delete` controlam as visualizações salvas.
