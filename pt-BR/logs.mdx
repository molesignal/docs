Abra **Logs** para pesquisar fluxos de logs no espaço de trabalho ativo.

## Escolha um fluxo e um intervalo de tempo

Selecione um fluxo de logs e defina o menor intervalo de tempo que contenha o evento. Intervalos curtos
reduzem o número de linhas lidas e agilizam a exploração dos campos.

O MoleSignal pode inferir o esquema de um fluxo à medida que os eventos chegam. O painel **Campos** lista os campos do
fluxo e permite adicionar filtros sem reescrever toda a consulta.

## Abas de consulta

Cada consulta é executada na própria aba. A aba mantém o fluxo, a consulta e o intervalo de tempo. A consulta de
uma aba não afeta as demais.

- Selecione **Nova aba** para abrir outra consulta. É possível manter até 10 abas abertas de uma vez.
- Abra o menu da aba para selecionar **Renomear**, **Duplicar** ou **Fechar**.
- Selecione **Dividir em duas partes** para exibir duas abas lado a lado. Cada parte tem sua própria lista de abas. Para mover uma aba
  para a outra parte, use o menu da aba. Selecione **Voltar para uma única página** para encerrar a divisão.

O navegador mantém as abas abertas para cada usuário e espaço de trabalho.

## Escreva uma consulta

O editor tem dois modos, **Código** e **Editor visual**. Use os dois ícones ao lado do título para alternar entre eles (`</>` para
Código e o ícone de blocos para Editor visual). Passe o cursor sobre um ícone para ver o nome do modo.

O modo **Código** aceita consultas por campos ou SQL. Uma instrução que começa com `SELECT` ou `WITH` é executada como SQL.
Qualquer outra instrução é executada como uma consulta por campos:

| Consulta por campos | Significado |
|---|---|
| `service = 'checkout'` | O campo tem exatamente esse valor. |
| `message contains 'timeout'` | O campo contém o texto. |
| `MATCH(message, 'timeout')` | Busca por trecho de texto sem diferenciar maiúsculas de minúsculas. |
| `MATCH_TEXT(message, 'timeout disk')` | Busca de texto completo em um campo com índice de texto completo. |

Combine condições com `AND` e `OR`, em maiúsculas ou minúsculas. `AND` tem precedência sobre `OR`. Use parênteses
para agrupar condições: `level = 'error' AND (service = 'checkout' OR service = 'payments')`. Um texto
sem campo especificado é buscado no campo `message` e pode ser uma das alternativas:
`timeout OR "connection reset"`. Use aspas para manter uma expressão inteira, mesmo que contenha uma palavra como `or`.
Use `=`, `!=`, `>`, `>=`, `<` e `<=` para fazer comparações.

O **Editor visual** exibe a mesma consulta por campos em linhas de filtros, uma para cada alternativa:
todos os filtros de uma linha precisam corresponder, e **OU** aparece antes de cada linha após a primeira. Selecione **Filtrar** para
adicionar um filtro a uma linha ou **OU** para adicionar uma linha. Depois, escolha um campo, um operador de comparação e um valor. Cada
linha tem seu próprio texto de busca. Uma expressão entre parênteses em uma linha, como a que contém `OR` no exemplo
acima, permanece como foi escrita. Edite essa expressão em **Código**. O editor não exibe instruções SQL como
filtros.

Use SQL para junções, expressões, CTEs ou agregações:

```sql
SELECT "_timestamp", level, msg, trace_id
FROM app
WHERE level = 'error'
ORDER BY "_timestamp" DESC
LIMIT 200;
```

```sql
SELECT level, COUNT(*) AS events
FROM app
GROUP BY level
ORDER BY events DESC;
```

Selecione **Executar** para rodar a consulta ou pressione `⌘ Enter` ou `Ctrl+Enter` no editor. A **Referência de sintaxe
de consultas** lista exemplos para o modo atual. Consulte [Consultas](/pt-BR/query#busca-de-texto) para conhecer as funções de busca
de texto.

O planejador de consultas restringe o acesso à organização atual, mesmo em consultas SQL personalizadas.

## Explore os campos

O painel **Campos** tem três seções: **Campos exibidos**, **Campos indexados** e **Outros
campos**. Campos com o mesmo prefixo antes do primeiro ponto, como `http.method` e
`http.route`, abrem em um único grupo.

- Abra um campo para ver os valores mais frequentes no resultado. Adicione um valor como filtro de inclusão ou
  exclusão. O filtro restringe toda a consulta: se houver alternativas, o editor coloca a consulta entre parênteses
  antes de aplicar o filtro.
- Exiba ou oculte um campo como coluna no resultado.
- Selecione **Analisar** em um campo para ver a análise: número de valores distintos, linhas
  com e sem valor, estatísticas para campos numéricos, distribuição dos valores e valores mais
  frequentes ao longo do tempo.

## Leia os resultados

O histograma acima dos resultados conta todos os eventos que correspondem à consulta no intervalo de tempo, não
apenas os da página carregada. Há quatro visualizações dos resultados:

| Visualização | Conteúdo |
|---|---|
| **Logs** | Os eventos correspondentes, um por linha. |
| **Estatísticas** | Um gráfico de agregação. Escolha a medida (contagem, contagem distinta, média, soma, mínimo, máximo, P50, P95 ou P99), o agrupamento e o tipo de gráfico ou gere um gráfico com o resultado de uma agregação em SQL. Selecione **Criar dashboard** para salvar o gráfico como painel de um novo dashboard. |
| **Inspeção por IA** | Um relatório que o Mole Agent escreve sobre os logs que correspondem à consulta. Consulte [Inspeções de logs](/pt-BR/logs/inspections). |
| **Padrões** | Os eventos agrupados por padrão, com a contagem e a proporção de cada padrão. |

Na visualização **Logs**:

- Use **Colunas** para selecionar e ordenar as colunas. As colunas padrão vêm dos campos do
  fluxo: primeiro o horário, depois o nível, o serviço e a mensagem, se o fluxo tiver esses campos.
- Cada página exibe 100, 200, 500, 1.000, 2.000 ou 5.000 eventos.
- Clique em um evento para abrir um painel lateral ao lado dos resultados. Arraste a borda esquerda do painel para
  redimensioná-lo. O painel mantém a largura escolhida. O cabeçalho mostra o nível, o horário, a mensagem e os atributos que
  identificam o contexto do evento (serviço, host, ambiente, versão, rastreamento). Cada atributo oferece as mesmas ações de um
  campo. As visualizações são **Campos**, **Rastreamento** quando o evento tem um ID de rastreamento, **Contexto** e
  **JSON bruto**. **Rastreamento** exibe o gráfico em cascata do rastreamento com o span do evento selecionado. **Contexto**
  exibe cinco linhas antes e cinco depois do evento. Use as ações de um campo para adicionar um filtro, copiar o valor ou exibir o
  campo como coluna.
- Navegue até um rastreamento, serviço, métrica ou outro sinal correlacionado quando houver identificadores.
- Baixe o resultado em CSV, texto ou JSON.

## Compartilhe uma consulta

O endereço da página representa a consulta na tela. Ao executar uma consulta, a página inclui no endereço o fluxo, a
instrução (`q` para consultas por campos, `sql` para SQL) e a visualização dos resultados. Assim,
copie o endereço da barra do navegador para compartilhar a consulta com o intervalo de tempo do seletor, como a última
hora. Recarregue a página para voltar à mesma consulta e ao mesmo estado do editor.

Selecione **Compartilhar** para copiar um link para a consulta na tela. O link funciona para membros autenticados da
organização com permissão para ler os dados. Escolha o intervalo de tempo do link: **Intervalo selecionado**
fixa o início e o fim nos horários exibidos na tela. A outra opção mantém um intervalo relativo, como a
última hora, contado a partir da abertura do link.

## Tarefas de busca

Uma busca grande demais para uma solicitação interativa é executada como uma tarefa de busca. Abra
**Fluxos → Tarefas de busca** para acompanhar a tarefa e baixar o resultado. Consulte
[Fluxos](/pt-BR/streams#tarefas-de-busca).

## Visualizações salvas

Salve uma consulta SQL com um nome como [visualização salva](/pt-BR/saved-views). Reabra a visualização, execute a consulta
em outro intervalo de tempo ou anexe a visualização a um relatório.

<Tip>
  Preserve dimensões estáveis, como `service.name`, `deployment.environment`, `trace_id` e
  `host.name` durante a ingestão. Esses campos garantem uma navegação confiável entre sinais correlacionados.
</Tip>

## Permissões

- `streams.read` permite localizar fluxos e esquemas.
- `logs.read` permite ler logs: a lista, o histograma e as estatísticas dos campos.
- `streams.query` permite executar instruções SQL e abrir o contexto.
- `agent.use` permite executar uma inspeção por IA, que também exige um modelo de IA habilitado.
- `saved_views.create`, `saved_views.edit` e `saved_views.delete` controlam a criação, a edição e a exclusão de visualizações salvas.
