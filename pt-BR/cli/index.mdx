A CLI do MoleSignal é o comando `molesignal`, publicado no npm como `@molesignal/cli`. A CLI
autentica o acesso a uma instância do MoleSignal e, em seguida:

- lê e acompanha logs, executa consultas SQL e PromQL, exibe traces em gráficos de cascata e resume
  serviços de APM;
- lista incidentes e responsáveis pelo plantão, confirma o recebimento de incidentes, resolve incidentes, executa verificações sintéticas
  e aplica alterações aprovadas;
- informa implantações, carrega mapas de origem e símbolos de RUM e envia a saída de scripts para um
  fluxo de dados em CI;
- chama qualquer ferramenta do catálogo do MoleSignal;
- disponibiliza as ferramentas MCP do MoleSignal via stdio para que Claude Code, Cursor, Codex, VS Code e
  Gemini CLI possam iniciar a CLI como servidor MCP.

As operações de leitura e alteração passam pelas ferramentas do MoleSignal. As permissões do usuário autenticado, a
política de ferramentas e as aprovações da organização se aplicam à CLI da mesma forma que ao Mole Agent.
A CLI usa a API do MoleSignal para informar implantações, carregar artefatos de depuração e enviar logs. Essas operações
exigem um token de API.

## Requisitos

- Node.js 20 ou posterior.
- Uma instância do MoleSignal acessível a partir da máquina e uma conta nessa instância.

## Instalação

```bash
npm install -g @molesignal/cli
```

Verifique a instalação:

```bash
molesignal --version
```

Para executar qualquer comando sem instalar a CLI, use:

```bash
npx -y @molesignal/cli --help
```

## Primeiros passos

<Steps>
  <Step title="Entrar">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    O navegador abre a página de autorização do MoleSignal. Nessa página, clique em **Autorizar**. Consulte
    [Entrar](/pt-BR/cli/sign-in).
  </Step>
  <Step title="Verificar a configuração">
    ```bash
    molesignal doctor
    ```
  </Step>
  <Step title="Ler logs">
    ```bash
    molesignal logs app_logs -f
    ```

    Consulte [Ler e acompanhar logs](/pt-BR/cli/logs).
  </Step>
</Steps>

| Grupo | Comandos |

| Plantão e alterações | `incidents`, `oncall`, `approvals`, `annotate`, `synthetics`. Consulte [Incidentes e alterações](/pt-BR/cli/changes). |
| Versões e dados | `deploy`, `source-maps`, `symbols`, `send`, `run`. Consulte [CI e versões](/pt-BR/cli/ci). |
| Ferramentas e configuração | `tools`, `call`, `mcp`, `open`, `completion`. Consulte [Chamar qualquer ferramenta](/pt-BR/cli/tools) e [Disponibilizar MCP via stdio](/pt-BR/cli/mcp). |
