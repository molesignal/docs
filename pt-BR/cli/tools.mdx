Os comandos da CLI cobrem as tarefas mais comuns. Para usar qualquer outra ferramenta do catálogo do MoleSignal, como as
ferramentas de RUM, profiling ou páginas de status, execute `molesignal call`.

## Encontre uma ferramenta

```bash
molesignal tools incident
```

A lista mostra as ferramentas que melhor correspondem aos termos da busca, o que cada chamada faz (`read` ou
`change`), como a política de ferramentas da organização rege cada alteração e para que serve cada ferramenta.
Sem termos de busca, o comando lista todas as ferramentas que o usuário tem permissão para chamar. Use `--domain` para limitar a lista a um domínio, como
`observability` ou `alerts_on_call`.

`molesignal tools show` exibe uma ferramenta e os argumentos que ela aceita no formato JSON Schema:

```bash
molesignal tools show list_rum_sessions
```

## Chame uma ferramenta

```bash
molesignal call list_rum_sessions --since 1h limit=20
```

O comando exibe o resultado da ferramenta em JSON. Escreva os argumentos assim:

| Sintaxe | Valor passado |
|---|---|
| `name=value` | O valor no tipo exigido pelo esquema da ferramenta: texto, número, `true` ou `false`, ou uma lista a partir de `a,b`. |
| `name:=json` | O JSON exatamente como foi escrito, por exemplo, `match:='{"service":"checkout"}'`. |
| `parent.child=value` | Um campo dentro de um objeto, por exemplo, `timeRange.startTime=…`. |
| `--input <file>` | Um objeto JSON com argumentos de um arquivo ou `-` para ler da entrada padrão. Os pares que vêm depois acrescentam argumentos ao objeto. |
| `--since`, `--from`, `--to` | Define `timeRange` para uma ferramenta que aceita esse campo. |

As ferramentas que fazem alterações seguem a política de ferramentas, conforme descrito em
[Como uma alteração é executada](/pt-BR/cli/changes#como-funciona-a-execução-de-uma-alteração). As opções `--reason`, `--wait`, `--timeout` e
`--yes` se aplicam. O comando encaminha o argumento `reason` ou `impact` sem alterações para aprovação.

```bash
molesignal call trigger_alert_rule rule_id=<rule> --reason "Testing the pager"
```

## Abra uma página

`molesignal open` abre uma página do MoleSignal no navegador. Sem indicar uma página, o comando abre a página inicial:

```bash
molesignal open logs app_logs
```

As páginas disponíveis são `home`, `logs`, `metrics`, `traces`, `services`, `incidents`, `oncall`,
`synthetics`, `dashboards`, `approvals`, `jobs`, `streams` e `agent`. A maioria aceita um ID, como o de
um trace, de um incidente ou de um dashboard. Use `--print` para exibir o endereço em vez de abrir a página.

Use `--web` com `logs`, `query`, `traces show`, `incidents show` ou `services show` para abrir no navegador o conteúdo
que esses comandos exibiriam no terminal.

## Use o preenchimento automático de comandos no shell

`molesignal completion` exibe um script que completa comandos, subcomandos, perfis e nomes de
streams. O script consulta os nomes dos streams a cada poucos minutos. Para bash:

```bash
echo 'source <(molesignal completion bash)' >> ~/.bashrc
```

Para zsh:

```bash
echo 'source <(molesignal completion zsh)' >> ~/.zshrc
```

Para fish:

```bash
molesignal completion fish > ~/.config/fish/completions/molesignal.fish
```
