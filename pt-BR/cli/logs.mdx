## Liste os streams

```bash
molesignal streams
```

A lista mostra cada stream de logs que o usuário pode ler, com o número de campos, o período de retenção e
a descrição. `--type` lista os streams de outro tipo: `metrics`, `traces`, `profiles` ou
`extend`. `--names` exibe apenas os nomes, e `--json` exibe um stream por linha em JSON.

## Exiba os logs mais recentes

```bash
molesignal logs app_logs
```

O comando exibe os 100 logs mais recentes dos últimos 15 minutos, do mais antigo ao mais novo, um por linha:
horário, nível, serviço e mensagem.

```text
2026-10-18 03:14:15.361 INFO  checkout order 4812 created
2026-10-18 03:14:25.361 ERROR payment gateway timeout after 3 retries
```

O comando lê o nível de um campo como `level`, `severity` ou `severity_text`, o serviço de
`service` ou `service.name` e a mensagem de `message`, `msg`, `body` ou `log`. Para um log
sem campo de mensagem, o comando exibe os outros campos como `name=value`. A saída no terminal usa cores;
`NO_COLOR` desativa as cores e `FORCE_COLOR` mantém as cores no pipe.

| Opção | Padrão | Descrição |
|---|---|---|
| `-n`, `--lines <count>` | `100` | Número de logs mais recentes a exibir inicialmente, até `5000`. |
| `--since <duration>` | `15m` | Até onde retroceder na busca: `30s`, `10m`, `2h`, `1d`, `1w`. |
| `--from <time>`, `--to <time>` | nenhum | Intervalo em vez de `--since`: um horário em formato ISO, `2026-10-26 14:00` no horário local ou uma duração retroativa como `2h`. |
| `-q`, `--query <query>` | nenhum | Consulta por campos no mesmo formato aceito pela página **Logs**. |
| `--where <condition>` | nenhum | Condição SQL sobre os campos do stream. |
| `--fields <a,b,c>` | todos | Exibe o horário e apenas os campos especificados, como `name=value`. |
| `--json` | desativado | Exibe cada log em uma linha de JSON. |
| `--utc` | desativado | Exibe os horários em UTC em vez do horário local. |
| `--web` | desativado | Abre os mesmos logs na página **Logs** em vez de exibi-los no terminal. |

## Filtre os logs

`-q` aceita uma consulta por campos na linguagem da página **Logs**: combine comparações como
`level = 'error'`, `contains`, `MATCH` e `MATCH_TEXT` com `AND` e `OR` e agrupe as expressões
com parênteses. Se a consulta não especificar um campo, o comando busca o texto em `message`:

```bash
molesignal logs app_logs --since 1h -q "level = 'error' AND (service = 'payment' OR timeout)"
```

`--where` aceita uma condição SQL sobre os campos do stream, como na cláusula `WHERE` de uma consulta:

```bash
molesignal logs app_logs --where "status >= 500 AND duration_ms > 2000"
```

Ao usar as duas opções, cada log deve atender aos dois filtros. Se a condição mencionar um campo inexistente ou contiver SQL inválido,
o comando é encerrado e informa o motivo.

## Acompanhe os novos logs

```bash
molesignal logs app_logs -f
```

Depois de exibir os logs mais recentes, o comando continua exibindo os novos logs até que seja pressionado **Ctrl+C**:

- O comando faz uma nova leitura a cada 2 segundos. Use `--interval` para alterar esse intervalo.
- Cada leitura começa 10 segundos antes do fim da anterior. Assim, mesmo um log que chegue ao
  MoleSignal com alguns segundos de atraso aparece. Cada log aparece uma única vez.
- Se uma rajada de logs exceder a capacidade de uma leitura, o comando continua lendo sem esperar.
- Se a conexão cair, o comando tenta reconectar com pausas cada vez maiores, de até 30 segundos. A CLI informa a queda
  e o restabelecimento da conexão na saída de erro padrão.

O acompanhamento usa o horário registrado nos próprios logs. Se um log chegar com horário anterior ao início
da leitura atual, o comando não o exibe. Não use `--to` com `-f`.

## Leia os logs próximos a um horário

`--around` exibe os logs imediatamente anteriores e posteriores a um horário, com uma linha que marca esse horário
entre os dois grupos. `-B` e `-A` definem quantos logs exibir de cada lado: 10 por padrão e no máximo 250. Use `-q` e `--where`
para filtrar os resultados:

```bash
molesignal logs app_logs --around "2026-10-26 14:03:12.345" -B 20 -A 20
```

Use um horário copiado da saída de `molesignal logs` como valor de `--around`.

## Execute SQL em um stream

`molesignal query` executa uma única instrução SQL somente leitura, com expressões, junções e agregações, e
exibe o resultado em uma tabela:

```bash
molesignal query "SELECT level, COUNT(*) AS logs FROM app_logs GROUP BY level ORDER BY logs DESC"
```

O comando usa o primeiro stream após `FROM`. Use `--stream` para indicar outro. O intervalo padrão é a última
hora. Use `--since`, `--from` e `--to` para alterá-lo. `-n` limita o número de linhas a `1000` por padrão e
a `5000` no máximo. `--csv` exibe a saída em CSV com cabeçalho, `--json` exibe cada linha em JSON e
`--web` abre a instrução na página **Logs**.

## Veja os campos de um stream

```bash
molesignal fields app_logs
```

A lista mostra cada campo com seu tipo e índice. Ao especificar um campo, o comando lista os valores
mais frequentes na última hora e o número de ocorrências de cada um:

```bash
molesignal fields app_logs service --since 1d
```

`--match` mantém os valores que contêm o texto especificado, e `-n` define quantos exibir: `20` por padrão.
`--type` lê um stream de outro tipo.

## Use a saída em um pipe

`--json` exibe cada log com todos os seus campos:

```bash
molesignal logs app_logs -n 1000 --since 2h --json | jq -r .message
```

Se um programa como `head` parar de ler a saída antes do fim, o comando termina sem emitir mensagens.

## Acesso

A CLI usa as ferramentas `list_streams`, `query_logs`, `get_stream_schema`,
`search_field_values` e `search_around` do MoleSignal com as permissões do usuário conectado ou do
proprietário do token de API. O usuário precisa da permissão `streams.query`, e a política de ferramentas da organização deve
permitir o uso dessas ferramentas.
