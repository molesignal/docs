## Consulte métricas

`molesignal metrics query` executa uma consulta de intervalo em PromQL e exibe uma linha por série: o último valor,
os valores mínimo e máximo no intervalo, um minigráfico da série e seus rótulos.

```bash
molesignal metrics query 'sum by (service) (rate(http_server_requests_total[5m]))' --since 6h
```

```text
LAST   MIN    MAX    TREND                           SERIES
12.4   3.1    14.9   ▁▂▂▃▅▆▇█▇▆▆▅▅▆▇▇█▇▆▅▄▄▅▅▆▆▇▇▇▆   {service="checkout"}
```

Por padrão, o intervalo é a última hora. Use `--since`, `--from` e `--to` para alterá-lo. `-n` limita o número de
pontos a `1000` por padrão. `--json` exibe cada série com seus pontos, e `--csv` exibe os
pontos em linhas.

Outros quatro subcomandos ajudam a encontrar o que consultar:

| Comando | Lista |
|---|---|
| `molesignal metrics names [text]` | Nomes de métricas que contêm o texto. |
| `molesignal metrics labels <metric>` | Rótulos de uma métrica. |
| `molesignal metrics values <metric> <label>` | Valores de um rótulo e a frequência de cada um. |
| `molesignal metrics series <metric>` | Séries de uma métrica. Use `--match label=value` para filtrá-las. |

## Encontre traces

```bash
molesignal traces --service checkout --errors --since 6h
```

A lista mostra os traces mais recentes com o horário de início, a duração, o número de spans e o serviço.

| Opção | Significado |
|---|---|
| `--service <name>` | Apenas traces desse serviço. |
| `--errors` | Apenas traces com pelo menos um span com falha. |
| `--min-duration <time>` | Apenas traces que duraram pelo menos o tempo indicado, como `500ms`. |
| `--since`, `--from`, `--to` | Intervalo de tempo. O padrão é a última hora. |
| `-n`, `--limit <count>` | Número de traces: `20` por padrão e `200` no máximo. |

## Visualize um trace

`molesignal traces show` exibe um trace em um gráfico em cascata: uma linha por span, abaixo do respectivo span pai,
com uma barra que indica quando o span ocorreu no trace e quanto tempo durou. O comando marca spans com falha com
`!` e os exibe em vermelho no terminal.

```bash
molesignal traces show 4bf92f3577b34da6a3ce929d0e0e4736
```

```text
checkout POST /orders          ████████████████████████████████████████  1.24s
├─ checkout SELECT orders       ███                                       98ms
└─ ! payments POST /charge         ███████████████████████████████████    1.1s
```

`--web` abre o trace no MoleSignal, e `--json` exibe seus spans.

## Veja um resumo dos serviços

```bash
molesignal services --env production --sort errors
```

A lista mostra cada serviço de APM com suas requisições, taxa de erros, latência p95, estado de integridade e
versão atual. `--sort` ordena a lista por `requests`, `errors`, `p95` ou `name`.

`molesignal services show` resume um serviço: primeiro, a taxa de requisições, os erros e a latência. Depois, lista
os endpoints, as dependências, os erros e as versões:

```bash
molesignal services show checkout --since 2h
```

## Compare duas versões

`molesignal services compare` coloca duas versões de um serviço lado a lado e indica se a
versão candidata piorou, melhorou, manteve o desempenho ou recebeu poucas requisições para uma conclusão. Com
`--fail-on-regression`, o comando retorna o código `1` em caso de regressão, permitindo que o pipeline interrompa a
publicação da versão:

```bash
molesignal services compare checkout 2.3.9 2.4.0 --since 1h --fail-on-regression
```

## Execute consultas longas como tarefas de busca

Uma tarefa de busca executa uma consulta em segundo plano com mais dados e um intervalo maior do que uma consulta
imediata e mantém o resultado por algum tempo. O envio e o cancelamento de tarefas seguem a
política de ferramentas da organização, assim como qualquer alteração. Consulte
[Incidentes e alterações](/pt-BR/cli/changes#como-funciona-a-execução-de-uma-alteração).

```bash
molesignal search-jobs submit "SELECT * FROM app_logs WHERE level = 'error'" --since 30d --wait
```

O fluxo é o primeiro após `FROM`. Use `--stream` para indicar outro fluxo e `--promql` para enviar uma
expressão PromQL. A avaliação ocorre no fim do intervalo ou a cada passo definido por `--step`, como `1m`. Use `--limit` para limitar
as linhas que a tarefa mantém a no máximo `100000` e `--keep` para definir por quanto tempo. Use `--wait` para aguardar
a conclusão da tarefa. O comando exibe o ID da tarefa.

| Comando | Efeito |
|---|---|
| `molesignal search-jobs` | Lista as tarefas de busca com o estado, o número de linhas e a instrução de consulta. |
| `molesignal search-jobs show <job>` | Exibe o estado, o número de linhas, os horários e o erro de uma tarefa. |
| `molesignal search-jobs results <job>` | Grava as linhas de uma tarefa concluída, com um objeto JSON por linha. Use `--csv` para gravar em CSV e `-o <file>` para gravar em um arquivo. |
| `molesignal search-jobs cancel <job>` | Cancela uma tarefa pendente ou em execução. |

## Acesso

Métricas exigem `streams.query`, traces exigem `traces.read`, APM exige `apm.services.read` e tarefas de busca exigem `query.jobs.read` e
`query.jobs.run`. A permissão `sys.telemetry.read` permite ler todos esses dados no escopo `_sys`. A política de ferramentas da organização deve manter
as ferramentas habilitadas.
