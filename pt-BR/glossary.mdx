| Termo | Definição |
|---|---|
| **Alerta** | A função que avalia regras de alerta, aciona escalonamentos, gera relatórios agendados e executa conectores. Consulte [Implantação baseada em funções](/pt-BR/deployment/role-based). |
| **Token de API** | Uma credencial do tipo bearer no formato `mspat-<36>` que representa um usuário ou uma conta de serviço. Consulte [Identidade e acesso](/pt-BR/identity). |
| **APM** | Monitoramento de desempenho de aplicações. Inclui agregações limitadas de serviços, transações, dependências, erros e versões, derivadas de spans de rastreamento. Consulte [APM](/pt-BR/apm). |
| **Arrow Flight SQL** | O protocolo SQL na porta `5083` para clientes de banco de dados como DBeaver, JDBC e ADBC. Por padrão, o protocolo fica desativado. Consulte [Conecte-se com um cliente de banco de dados](/pt-BR/query/database-clients). |
| **Catálogo** | O registro no PostgreSQL que indica quais arquivos Parquet e índices pertencem a cada fluxo. |
| **Chave de criptografia** | A chave raiz em `MS_CIPHER_KEY` que criptografa os segredos que o MoleSignal armazena no PostgreSQL. Consulte [Lista de verificação para produção](/pt-BR/deployment/production-checklist). |
| **Compactação** | A junção de arquivos Parquet pequenos em arquivos maiores. A função `compactor` executa a compactação e aplica a política de retenção. |
| **Conector** | Uma integração gerenciada com uma plataforma externa. Uma origem recebe logs por coleta agendada ou por envio da plataforma. Um destino recebe a saída do pipeline. Consulte [Conectores](/pt-BR/connectors). |
| **Fonte de dados** | Uma entrada no catálogo de fontes de dados que gera o endpoint, o token e o trecho de configuração de uma origem. Consulte [Fonte de dados](/pt-BR/intake). |
| **Política de escalonamento** | Uma lista ordenada de destinatários de notificações, com prazos para confirmação. Consulte [Alertas](/pt-BR/alerting). |
| **Tabela de extensão** | Uma tabela que associa chaves a registros. Os pipelines consultam a tabela para enriquecer eventos e também podem gravar linhas nela. Consulte [Tabelas de extensão](/pt-BR/extend-tables). |
| **Consulta federada** | Uma consulta que também examina clusters remotos. Selecione os clusters com `?clusters=local,<name>`. Consulte [Implantação baseada em funções](/pt-BR/deployment/role-based). |
| **Gravação do buffer** | A gravação do conteúdo do buffer em memória de um nó de recebimento em arquivos Parquet e índices no armazenamento de objetos. |
| **Função** | Uma transformação reutilizável em VRL ou JavaScript. Consulte [Funções](/pt-BR/functions). |
| **Incidente** | Uma ocorrência de alerta que passa pelas etapas de confirmação e resolução. Consulte [Alertas](/pt-BR/alerting). |
| **Recebimento** | O caminho por onde entra a telemetria. Também é a função que valida a telemetria, armazena os dados em buffer e grava o conteúdo do buffer. Consulte [Fonte de dados](/pt-BR/intake). |
| **Token de ingestão** | Um token para remetentes e pipelines de implantação que segue a política de permissões **Ingestão de dados**: `logs.write`, `metrics.write`, `traces.write`, `profiles.write` e `apm.deploy`. Consulte [Fonte de dados](/pt-BR/intake#tokens-de-ingestão). |
| **Inspeção de logs** | Um relatório que o Mole Agent gera sob demanda ou de forma agendada sobre os logs de um período. Consulte [Inspeções de logs](/pt-BR/logs/inspections). |
| **Mole Agent** | O agente de operações integrado que usa o catálogo de ferramentas para investigar problemas. Consulte [Mole Agent](/pt-BR/agent). |
| **Escala de plantão** | Um rodízio que considera fusos horários e permite substituições. Os escalonamentos usam essa escala para definir quem recebe as notificações. Consulte [Alertas](/pt-BR/alerting). |
| **Organização** | O limite de isolamento do locatário e de aplicação das políticas. A interface web usa o nome espaço de trabalho. Consulte [Conceitos principais](/pt-BR/concepts). |
| **Parquet** | O formato de arquivo colunar no qual o MoleSignal armazena logs, métricas e rastreamentos. |
| **Pipeline** | Uma sequência de etapas que encaminha, normaliza, oculta dados sensíveis e enriquece eventos durante o recebimento em tempo real ou em horários agendados. Também pode alterar eventos de alerta antes da abertura dos incidentes correspondentes. Consulte [Pipelines](/pt-BR/pipelines). |
| **Administrador da plataforma** | O usuário que gerencia as configurações de toda a plataforma. A chave `[auth].root_email` identifica esse usuário. |
| **Fluxo da plataforma** | Um fluxo em que apenas o MoleSignal grava dados, como `_audit` ou `_synthetic_results`. Consulte [Fluxos](/pt-BR/streams#fluxos-da-plataforma). |
| **Agente de sondagem** | Um processo que executa verificações sintéticas a partir de um local. Um agente integrado é executado nos nós `standalone`. Consulte [Monitoramento sintético](/pt-BR/synthetics). |
| **Função** | Uma função de processo configurada em `[node].roles`: `standalone`, `router`, `intake`, `querier`, `compactor` ou `alert`. No IAM, também é um conjunto nomeado que reúne políticas de permissões e permissões próprias. |
| **RUM** | Monitoramento de usuários reais em sessões de navegador e de aplicativos móveis. Consulte [RUM](/pt-BR/rum). |
| **Token de cliente RUM** | Um token com a permissão `rum.write` e vínculo a uma única aplicação. O código do navegador e dos aplicativos móveis envia esse token. |
| **Visualização salva** | Uma consulta armazenada com seu intervalo de tempo e suas opções. |
| **Tarefa de busca** | Uma consulta assíncrona persistente. Consultas que excedem o limite de tamanho viram tarefas de busca e aparecem em **Fluxos → Tarefas de busca**. Consulte [Consultas](/pt-BR/query). |
| **Telemetria própria** | As métricas, os rastreamentos e os perfis que o MoleSignal registra sobre si no fluxo reservado `_molesignal`. Consulte [Auto-observabilidade](/pt-BR/self-observability). |
| **Conta de serviço** | Uma identidade não humana para coletores e automações. Não permite login. Consulte [Identidade e acesso](/pt-BR/identity). |
| **Silenciar** | Uma regra com duração definida que pausa as notificações dos alertas que atendem aos critérios. Consulte [Alertas](/pt-BR/alerting). |
| **Standalone** | A função padrão que executa todas as funções em um único processo. |
| **Página de status** | Uma página pública ou privada que mostra o status dos componentes e os incidentes. Consulte [Páginas de status](/pt-BR/status-pages). |
| **Fluxo** | O contrato tipado de um sinal: nome, tipo, esquema e retenção. Consulte [Fluxos](/pt-BR/streams). |
| **Tipo de fluxo** | Um dos seguintes tipos: `logs`, `metrics`, `traces`, `profiles` ou `extend`. |
| **Monitor sintético** | Uma verificação agendada, como uma requisição HTTP, que registra a disponibilidade e a latência. Consulte [Monitoramento sintético](/pt-BR/synthetics). |
| **VRL** | Vector Remap Language, uma das linguagens usadas nas funções de pipeline. |
| **WAL** | O log de escrita antecipada: objetos no armazenamento de objetos que mantêm os registros cujo recebimento já foi confirmado até a gravação definitiva. |
| **Espaço de trabalho** | O nome que a interface web usa para a organização selecionada. |
