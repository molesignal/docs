O Codex inicia servidores MCP via stdio e oferece suporte ao endpoint Streamable HTTP do MoleSignal e à descoberta via OAuth.

## Conecte-se via stdio (recomendado)

O cliente inicia a CLI do MoleSignal, que encaminha as mensagens ao MoleSignal. A CLI requer
Node.js 20 ou posterior.

<Steps>
  <Step title="Faça login uma vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

Aprove o login no MoleSignal no navegador. A CLI mantém e renova a sessão.

  </Step>
  <Step title="Adicione o MoleSignal">

```bash
codex mcp add molesignal -- npx -y @molesignal/cli mcp
```

Ou adicione em `~/.codex/config.toml`:

```toml
[mcp_servers.molesignal]
command = "npx"
args = ["-y", "@molesignal/cli", "mcp"]
```

  </Step>
</Steps>

Se não houver um navegador disponível, configure `MOLESIGNAL_URL` e `MOLESIGNAL_TOKEN` (um token de API) no
ambiente do servidor em vez de fazer login. Consulte [Conecte-se via stdio](/pt-BR/inbound-mcp#conecte-se-via-stdio).

As seções a seguir mostram como se conectar via Streamable HTTP, sem a CLI.

## Conecte-se com OAuth 2.1

<Steps>
  <Step title="Registre o MoleSignal">

    ```bash
    codex mcp add molesignal \
      --url https://molesignal.example.com/api/v1/mcp
    ```

  </Step>
  <Step title="Autorize a conexão">

    ```bash
    codex mcp login molesignal
    ```

    Conclua a autorização na página do MoleSignal no navegador.

  </Step>
  <Step title="Verifique o servidor">

    ```bash
    codex mcp get molesignal
    codex mcp list
    ```

    Reinicie a tarefa ativa do Codex ou abra uma nova tarefa para atualizar a lista de ferramentas MCP.

  </Step>
</Steps>

<Warning>
  Não adicione `--oauth-resource`. O MoleSignal já publica o recurso protegido por meio da
  descoberta via OAuth. Adicionar o mesmo valor novamente pode gerar o erro `duplicate field resource`.
</Warning>

## Conecte-se com um token de API

Use um token de API pessoal ou de conta de serviço para um processo não interativo do Codex:

```bash
export MOLESIGNAL_MCP_TOKEN="<api-token>"

codex mcp add molesignal \
  --url https://molesignal.example.com/api/v1/mcp \
  --bearer-token-env-var MOLESIGNAL_MCP_TOKEN
```

O Codex armazena o nome da variável de ambiente, não o valor do token. Disponibilize a variável
para o processo que inicia o Codex.

## Verifique a descoberta de ferramentas

Peça ao Codex:

> Use o servidor MCP do MoleSignal. Procure ferramentas de incidentes e liste os incidentes ativos. Não faça
> alterações.

A primeira solicitação deve usar `tool_search` e, em seguida, `call_read_tool` para uma leitura adiada.

Consulte a [documentação oficial do Codex sobre MCP](https://developers.openai.com/codex/mcp/).
