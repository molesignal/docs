Gemini CLI oferece suporte a servidores stdio e Streamable HTTP, descoberta de endpoints OAuth, ferramentas, recursos e prompts do MCP.

## Conecte via stdio (recomendado)

O cliente inicia a CLI do MoleSignal, que encaminha as mensagens ao MoleSignal. A CLI requer
Node.js 20 ou posterior.

<Steps>
  <Step title="Faça login uma vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

O navegador abre o MoleSignal para aprovar o login. A CLI mantém e renova a sessão.

  </Step>
  <Step title="Adicione o MoleSignal">

```bash
gemini mcp add molesignal npx -y @molesignal/cli mcp
```

  </Step>
</Steps>

Se não houver um navegador disponível, em vez de fazer login, defina `MOLESIGNAL_URL` e `MOLESIGNAL_TOKEN` (um token de API) no
ambiente do servidor. Consulte [Conecte via stdio](/pt-BR/inbound-mcp#conecte-se-via-stdio).

As seções a seguir mostram como conectar via Streamable HTTP, sem usar a CLI.

## Conecte com OAuth 2.1

<Steps>
  <Step title="Adicione o MoleSignal">

    ```bash
    gemini mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    Omita `--scope user` para manter a entrada no arquivo `.gemini/settings.json` do projeto atual.

  </Step>
  <Step title="Autentique">
    Inicie uma sessão interativa do Gemini CLI e execute:

    ```text
    /mcp auth molesignal
    ```

    Conclua o fluxo de autorização no navegador. Gemini CLI descobre os endpoints OAuth e
    registra o cliente dinamicamente de forma automática.

  </Step>
  <Step title="Verifique o servidor">

    ```bash
    gemini mcp list
    ```

    Execute `/mcp` na sessão interativa para inspecionar as ferramentas, os recursos e os prompts conectados.

  </Step>
</Steps>

## Configure com JSON

A entrada equivalente para Streamable HTTP em `~/.gemini/settings.json` ou
`.gemini/settings.json` é:

```json
{
  "mcpServers": {
    "molesignal": {
      "httpUrl": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

Não defina `trust: true` para um servidor de operações gerenciadas, a menos que a política local do Gemini preveja
ignorar a solicitação de confirmação do próprio cliente. A política de aprovação do MoleSignal continua valendo no
servidor.

Consulte a [documentação oficial do Gemini CLI sobre MCP](https://geminicli.com/docs/tools/mcp-server/).
