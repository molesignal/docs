O Cursor oferece suporte a servidores MCP via stdio e a servidores MCP remotos via Streamable HTTP com autenticação OAuth.

## Conecte via stdio (recomendado)

O cliente inicia a CLI do MoleSignal, que encaminha as mensagens ao MoleSignal. A CLI requer
Node.js 20 ou posterior.

<Steps>
  <Step title="Faça login uma vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

O navegador abre o MoleSignal para autorizar o login. A CLI mantém e renova a sessão.

  </Step>
  <Step title="Adicione o MoleSignal">

Use `.cursor/mcp.json` para o projeto ou `~/.cursor/mcp.json` para todos os projetos:

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

Em seguida, ative `molesignal` em **Ferramentas e MCP**.

  </Step>
</Steps>

Se não houver um navegador disponível, defina `MOLESIGNAL_URL` e `MOLESIGNAL_TOKEN` (um token de API) no
ambiente do servidor em vez de fazer login. Consulte [Conecte via stdio](/pt-BR/inbound-mcp#conecte-se-via-stdio).

Nas seções a seguir, conecte via Streamable HTTP, sem usar a CLI.

## Configure o servidor

Crie `.cursor/mcp.json` para o projeto atual ou `~/.cursor/mcp.json` para uma
configuração global:

```json
{
  "mcpServers": {
    "molesignal": {
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Abra Ferramentas e MCP">
    Abra **Configurações do Cursor → Ferramentas e MCP** e localize `molesignal`.
  </Step>
  <Step title="Conecte com OAuth">
    Selecione **Conexão** e conclua a autorização na página do MoleSignal. O Cursor localiza os
    endpoints OAuth nos metadados do recurso protegido do MCP.
  </Step>
  <Step title="Verifique as ferramentas">
    Confirme que `tool_search`, `call_read_tool` e `call_managed_tool` aparecem na lista de
    ferramentas disponíveis. Reinicie o servidor em **Ferramentas e MCP** após alterar a configuração.
  </Step>
</Steps>

<Warning>
  Não inclua um token Bearer em commits de `.cursor/mcp.json`. Prefira OAuth para sessões
  interativas do Cursor. Para credenciais não interativas, use um mecanismo de injeção de segredos compatível com o cliente.
</Warning>

Consulte a [documentação oficial do Cursor sobre MCP](https://cursor.com/docs/mcp).
