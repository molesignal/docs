O VS Code oferece suporte a servidores MCP via stdio e HTTP remoto, autorização OAuth, recursos, prompts e ferramentas.

## Conecte-se via stdio (recomendado)

O cliente inicia a CLI do MoleSignal, que encaminha as mensagens ao MoleSignal. A CLI requer
Node.js 20 ou posterior.

<Steps>
  <Step title="Faça login uma vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

O navegador abre o MoleSignal para aprovar o login. A CLI mantém e renova a sessão.

  </Step>
  <Step title="Adicione o MoleSignal">

Em `.vscode/mcp.json`:

```json
{
  "servers": {
    "molesignal": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

Inicie o servidor pelo arquivo ou pela visualização MCP e confirme que confia no servidor.

  </Step>
</Steps>

Se não houver um navegador disponível, defina `MOLESIGNAL_URL` e `MOLESIGNAL_TOKEN` (um token de API) no
ambiente do servidor em vez de fazer login. Consulte [Conecte-se via stdio](/pt-BR/inbound-mcp#conecte-se-via-stdio).

As seções abaixo usam Streamable HTTP para a conexão, sem a CLI.

## Configure o servidor

Crie `.vscode/mcp.json` para compartilhar a configuração no espaço de trabalho. Para uma configuração
global privada, execute **MCP: Abrir Configuração do Usuário** na Paleta de Comandos.

```json
{
  "servers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Inicie o servidor">
    Abra `mcp.json` e selecione a ação **Início** no próprio arquivo ou execute **MCP: Listar Servidores** e selecione
    `molesignal`.
  </Step>
  <Step title="Confirme a confiança no servidor">
    Revise o endpoint e confirme que confia no servidor MCP. Como a configuração do espaço de trabalho pode ser
    compartilhada com todas as pessoas que contribuem para o projeto, não inclua credenciais no arquivo.
  </Step>
  <Step title="Conclua a autorização OAuth">
    O VS Code usa a descoberta OAuth do MoleSignal e abre a página de autorização no navegador. Conceda
    a autorização e volte ao modo de agente do Chat.
  </Step>
  <Step title="Verifique a conexão">
    Execute **MCP: Listar Servidores**, verifique o status de `molesignal` e confirme se as ferramentas aparecem na visualização
    do Chat.
  </Step>
</Steps>

Use **Adicionar Contexto → Recursos MCP** para anexar um recurso do MoleSignal ou invoque um prompt publicado
com `/molesignal.<prompt>`.

Consulte a [documentação oficial do VS Code sobre MCP](https://code.visualstudio.com/docs/agent-customization/mcp-servers).
