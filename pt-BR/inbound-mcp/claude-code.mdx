O Claude Code é compatível com servidores stdio, servidores remotos Streamable HTTP com descoberta via OAuth e
escopos de configuração local, de projeto ou de usuário.

## Conecte-se via stdio (recomendado)

O cliente inicia a CLI do MoleSignal, que encaminha as mensagens ao MoleSignal. A CLI exige
Node.js 20 ou posterior.

<Steps>
  <Step title="Faça login uma vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

O navegador abre o MoleSignal para aprovar o login. A CLI mantém e renova a sessão.

  </Step>
  <Step title="Adicione o MoleSignal">

```bash
claude mcp add --scope user molesignal -- npx -y @molesignal/cli mcp
claude mcp get molesignal
```

  </Step>
</Steps>

Se não houver um navegador disponível, defina `MOLESIGNAL_URL` e `MOLESIGNAL_TOKEN` (um token de API) no
ambiente do servidor em vez de fazer login. Consulte [Conecte-se via stdio](/pt-BR/inbound-mcp#conecte-se-via-stdio).

As seções a seguir mostram como se conectar via Streamable HTTP, sem a CLI.

## Conecte-se com OAuth 2.1

<Steps>
  <Step title="Adicione o servidor remoto">

    ```bash
    claude mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    `--scope user` disponibiliza o servidor em vários projetos. Omita a opção para manter a configuração
    no estado local do projeto ou use `--scope project` para gravar uma entrada compartilhada em `.mcp.json`.

  </Step>
  <Step title="Autorize o MoleSignal">

    ```bash
    claude mcp login molesignal
    ```

    Como alternativa, abra o Claude Code, execute `/mcp`, selecione `molesignal` e conclua a autenticação.

  </Step>
  <Step title="Verifique o servidor">

    ```bash
    claude mcp get molesignal
    claude mcp list
    ```

  </Step>
</Steps>

Em uma sessão SSH ou em um terminal sem interface gráfica, exiba a URL de autorização e cole a URL final de retorno
no Claude Code:

```bash
claude mcp login molesignal --no-browser
```

## Conecte-se com um token de API

Use a expansão de variáveis de ambiente no `.mcp.json` do projeto em vez de incluir o token em um commit:

```json
{
  "mcpServers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer ${MOLESIGNAL_MCP_TOKEN}"
      }
    }
  }
}
```

Defina `MOLESIGNAL_MCP_TOKEN` antes de iniciar o Claude Code. Servidores no escopo do projeto exigem
uma confirmação explícita de confiança antes da primeira conexão.

Consulte a [documentação oficial do MCP no Claude Code](https://code.claude.com/docs/en/mcp).
