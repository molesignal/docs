真实用户监控（RUM）记录 Web 与移动端用户体验，并将前端遥测与后端可观测性关联。

## 数据模型

Browser SDK 与 Flutter App SDK 将通过身份验证的事件发送到同一组写入端点：

| 端点 | 数据流或存储 | 采集内容 |
|---|---|---|
| `POST /api/v1/rum/sessions` | `logs/rum_sessions` | 会话身份、设备、平台、地理与时长。 |
| `POST /api/v1/rum/actions` | `logs/rum_actions` | 页面、用户动作、资源、API 与前端性能。 |
| `POST /api/v1/rum/errors` | `logs/rum_errors` | JavaScript 或 Dart 错误与堆栈帧。 |
| `POST /api/v1/rum/replay` | 回放事件存储 | 浏览器 DOM 或 Flutter 屏幕回放事件。 |

三个数据流会在首次写入时创建。因此新部署在 SDK 发送第一条事件前会显示空状态。

## 概览

通过主导航打开 **用户体验**。每个页签都位于标题 **用户体验** 之下，并读取所选的时间范围。

**概览** 展示用户数、会话数、无错误会话的占比，以及 LCP、INP 和 CLS 的 P75 及其阈值；其下依次是用户体验趋势、用户满意度、最慢页面、高频前端错误，以及按浏览器、设备和地区的分布。

页签下方的一行用于按 **应用**、**环境**、**版本**、**地区** 和 **设备** 缩小概览的范围。**与上一周期对比** 会给出相对于紧邻的上一个等长周期的变化。

## 应用与页面

**应用** 按版本、活跃用户、会话数、无错误会话率和 LCP P75 比较上报 RUM 数据的各个应用。列表可以按环境和版本筛选。

**页面** 按体验、会话数以及 LCP、INP 和 CLS 的 P75 比较各个页面。没有样本的指标显示为 `—`。

## 会话与回放

**会话** 列出近期 RUM 会话，每个会话带有体验、用户与设备、行为摘要和问题。已录制回放的会话带有回放标记，**会话回放** 只列出这些会话。打开会话可以检查动作时间线、回放事件、错误、设备上下文与关联后端链路。

请将回放视为敏感用户数据。在 SDK 中应用采集控制，避免记录 Secret 或个人字段，并使用尽可能短的保留时间。

## 错误、Source Maps 与 Symbols

**错误**按指纹归并反复出现的 JavaScript 失败，并显示发生次数、受影响用户、堆栈帧和示例会话。

通过 **用户体验 → RUM 设置 → Source Maps 与 Symbols** 上传 Browser Source Map 或移动端 Symbols。
MoleSignal 使用已上传的调试产物还原压缩、混淆或原生堆栈帧。读取调试产物元数据需要
`streams.read`；上传和删除需要 `streams.configure`。

## 性能

**性能** 有四个视图：

| 视图 | 内容 |
|---|---|
| **总览** | 各项指标的 P75，以及时间范围内的 Web Vitals 趋势。 |
| **Web Vitals** | 针对单项指标：按阈值划分的真实用户样本占比、趋势、按 P75 排序的最差页面，以及浏览器、版本和地区之间的差异。 |
| **错误** | 时间范围内的前端错误数量。 |
| **API** | 按 URL 展示次数、P50、P95 与错误率。 |

耗时按合适的单位显示，例如 `390 ms` 和 `2.2 s`。浏览器应用上报 Core Web Vitals；Flutter 应用上报首次渲染、build、raster、vsync 与慢帧数据。

## 关联后端链路

当动作携带 W3C `traceparent` 时，动作 `trace_id` 会直接关联后端 Span。如果没有直接 ID，会话详情可以在会话时间窗口中搜索相关链路。

慢前端动作可以直接跳转到对应的服务链路、日志与指标，同时保留调查上下文。

## 代理之后的客户端 IP

RUM 事件来自公网上的浏览器和设备。默认情况下，MoleSignal 记录直接连接的地址。当反向代理或 CDN 位于 MoleSignal 之前时，所有事件都会带上代理的地址，地理信息也就不准确。请打开 **设置 → 客户端 IP 识别**，选择单值请求头或转发链，并列出受信任的代理 CIDR。只有来自这些网络的连接，MoleSignal 才会信任该请求头。该设置对整个部署生效，无需重启。

## 权限

- `rum.write` 用于发送 RUM 事件。应用绑定的 `msrum_` Token 只为一个应用授予此权限。
- `streams.query` 用于打开组织 RUM 视图与关联查询。
- `streams.read` 用于列出调试产物元数据。
- `streams.configure` 用于上传或删除 Source Map 与移动端 Symbols。
