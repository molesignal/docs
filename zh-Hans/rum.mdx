真实用户监控（RUM）记录浏览器用户体验，并将浏览器遥测与后端可观测性关联。

## 数据模型

浏览器 SDK 将通过身份验证的事件发送到写入端点：

| 端点 | 数据流或存储 | 采集内容 |
|---|---|---|
| `POST /api/v1/rum/v1/sessions` | `logs/rum_sessions` | 会话身份、设备、浏览器、地理与时长。 |
| `POST /api/v1/rum/v1/actions` | `logs/rum_actions` | 页面、用户动作、资源、API 与 Web Vitals。 |
| `POST /api/v1/rum/v1/errors` | `logs/rum_errors` | JavaScript 错误与堆栈帧。 |
| `POST /api/v1/rum/v1/replay` | 回放事件存储 | 会话回放事件。 |

三个数据流会在首次写入时创建。因此新部署在 SDK 发送第一条事件前会显示空状态。

## 概览

打开 **RUM → 概览**，在所选时间范围内查看会话、用户、错误、页面性能，以及浏览器或地理分布。

## 会话与回放

**会话**列出近期浏览器会话。打开会话可以检查动作时间线、回放事件、错误、设备上下文与关联后端链路。

请将回放视为敏感用户数据。在 SDK 中应用采集控制，避免记录 Secret 或个人字段，并使用尽可能短的保留时间。

## 错误与 Source Map

**错误**按指纹归并反复出现的 JavaScript 失败，并显示发生次数、受影响用户、堆栈帧和示例会话。

通过 **RUM → Source Map** 或上传路由提交 Source Map。MoleSignal 会用已上传的 Source Map 将压缩后的堆栈帧还原到原始文件与行位置。读取 Source Map 元数据需要 `streams.read`；上传和删除需要 `streams.configure`。

## 性能

性能工作区分为：

- 概览趋势；
- Core Web Vitals；
- 浏览器错误性能；
- API 与资源耗时。

API 表按 URL 展示数量、延迟百分位与错误率。使用全局时间范围和分面比较不同发布、浏览器、国家或页面。

## 关联后端链路

当动作携带 W3C `traceparent` 时，动作 `trace_id` 会直接关联后端 Span。如果没有直接 ID，会话详情可以在会话时间窗口中搜索相关链路。

慢浏览器动作可以直接跳转到对应的服务链路、日志与指标，同时保留调查上下文。

## 权限

- `streams.write` 用于发送 RUM 事件。
- `streams.query` 用于打开组织 RUM 视图与关联查询。
- `streams.read` 用于列出 Source Map 元数据。
- `streams.configure` 用于上传或删除 Source Map。
