在进入具体信号页面前，先用本手册熟悉产品外壳与通用操作。

## 登录并选择工作区

使用邮箱密码或已启用的 SSO Provider 登录。MoleSignal 会打开个人偏好中保存的
默认首页。

存在多个组织成员关系时，通过顶部栏的工作区切换器切换上下文。切换后，系统会刷新签名
上下文和 capability snapshot。若新工作区中的角色权限不同，原先可见的页面可能消失。

<Note>
  用户界面用**工作区**表示当前组织；API 字段和 IAM 权限仍使用 `organization` 与
  `org_id`。
</Note>

## 产品区域

| 区域 | 主要用途 |
|---|---|
| **首页** | 查看信号健康、活动事件、接入状态与快速入口。 |
| **日志** | 搜索事件、检查字段并查看上下文。 |
| **指标** | 执行 PromQL，分析序列、基数与数据质量。 |
| **链路** | 浏览 trace、检查 span、查看服务图和服务目录。 |
| **APM** | 分析服务 RED 指标、事务、依赖、后端错误与部署版本。 |
| **持续剖析** | 分析 CPU、内存和锁竞争火焰图。 |
| **RUM** | 查看浏览器会话、前端错误、Web Vitals 和 Source Map。 |
| **仪表盘** | 构建可复用面板与变量驱动的视图。 |
| **告警** | 管理事件、规则、通知渠道、排班和响应策略。 |
| **Mole Intelligence** | 让 Mole Agent 调查问题并审核受控操作。 |
| **数据流与流水线** | 管理数据契约、转换、路由和回填。 |
| **IAM 与设置** | 管理成员、权限、工作区策略、安全和平台配置。 |

导航由 capability 驱动。MoleSignal 会隐藏当前作用域无法使用的路由，而不是展示必然失败
的操作。

## 保持时间上下文

全局时间选择器控制当前查询窗口。查询页可以临时覆盖默认时区、日期格式和时间范围。

跨信号下钻时，MoleSignal 会携带时间锚点和关联字段。例如从 trace 跳转到日志时，会保留
trace 时间窗口并添加 `trace_id` 过滤条件。

## 搜索与调查

按 `⌘K` 或 `Ctrl+K` 打开命令面板。命令面板可以搜索产品路由、数据流、仪表盘、保存视图、
告警、事件和服务。

典型调查流程如下：

<Steps>
  <Step title="从症状开始">
    打开事件、仪表盘面板、慢 trace、前端错误或热点 profile。
  </Step>
  <Step title="收窄时间与资源">
    选择包含问题的最小时间窗口，并固定服务、数据流、环境或会话。
  </Step>
  <Step title="跨信号跳转">
    使用关联操作打开相关 trace、日志、指标、profile 或 RUM 会话。
  </Step>
  <Step title="保存或自动化">
    保存查询、添加仪表盘面板、创建告警，或把重复流程变成 Mole Intelligence 调查与自动化。
  </Step>
</Steps>

## 个人账户偏好

打开用户菜单并选择**账户设置**，可以管理：

- 个人资料、头像与简介；
- 主题、密度、语言、时区和日期时间格式；
- 默认首页与键盘快捷键；
- 密码重置入口和当前浏览器会话；
- 工作区成员关系与稳定标识。

个人偏好的优先级高于工作区默认值。查询页仍可对当前调查应用临时时间显示设置。
