仪表盘是一组面板，每个面板由各自的查询（SQL 或 PromQL）驱动，作用于对应数据流。可以导入 Grafana
JSON；MoleSignal 会把受支持内容迁移到自己的仪表盘模型。

## 面板

每个面板独立查询并由可视化插件渲染。新仪表盘默认使用 24 列栅格，模型允许 1–48 列。支持的类型：

| 类型 | 渲染 |
|---|---|
| `time_series` | 时间序列折线/面积图。 |
| `bar_chart` | 分类数值比较。 |
| `bar_gauge` | 以水平或垂直条比较归约值。 |
| `stat` | 单个标量（最后一个值），可带单位。 |
| `gauge` | 带 min/max 与阈值配色的环形仪表。 |
| `table` | 原始行。 |
| `logs` | 紧凑日志列表（时间 · 级别 · 消息）。 |
| `heatmap` | 数值强度网格。 |
| `state_timeline` | 随时间变化的离散状态。 |
| `text` | 静态 Markdown——标题、说明、链接。 |

每个面板查询都可设置可选的图例模板（如 `{{service}}`），用标签为序列命名。Grafana 导入会把
`legendFormat` 映射到该字段。

## 变量

仪表盘可声明**模板变量**，显示在栅格上方的变量栏。变量值在运行时代入每个面板的查询，因此同一个仪表盘
无需逐面板编辑即可切到不同的 service、host 或环境。

## 时间范围与时区

仪表盘的时间范围作用于所有面板。图表坐标轴与 tooltip 按**偏好时区**渲染——在时区选择器里设置一次，
所有面板随之跟随。该偏好与应用其余部分（表格、详情视图）共享，时间戳处处一致。

## 文件夹

把相关仪表盘归入**文件夹**便于导航与访问。仪表盘列表可按文件夹筛选、按名称搜索。

## 从 Grafana 导入

在**仪表盘 → 导入**粘贴或上传 Grafana 仪表盘 JSON。面板、栅格位置、变量与时间范围会映射到
MoleSignal 模型。受支持的查询 Target 会保留 SQL 或 PromQL；旧 `graph`/`line`、`bar` 与
`bargauge` 会映射到当前插件，不支持的可视化会回退为 `time_series`，导入后应逐项检查。

## 导出、报告与共享

如果需要投递 PDF、PNG、CSV、SVG 或 JSON，请从仪表盘创建定时[报告](/zh-Hans/reports)。使用
**共享**提供登录访问、跨工作区访问或受限公开访问。公开面板只能执行已保存查询，并继续受工作区共享策略约束。

## 权限

- `dashboards.read` 用于打开仪表盘与文件夹。
- `dashboards.create`、`dashboards.edit` 与 `dashboards.delete` 用于管理内容。
- `dashboards.share` 用于创建或轮换资源共享。
