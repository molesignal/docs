仪表盘是团队共同查看的一组面板。每个面板对工作区的数据流运行自己的查询并绘制结果。网格上方的变量可以让所有面板一次切换到另一个服务、主机或环境。

本页介绍如何查找和使用仪表盘。要创建或修改仪表盘，参见[编辑仪表盘](/zh-Hans/dashboards/edit)和[变量](/zh-Hans/dashboards/variables)。

## 仪表盘列表

打开 **仪表盘**。页面顶部统计仪表盘和目录的数量。可以用以下方式缩小列表：

- 过滤框，按名称匹配；
- **全部**、**我的**、**已收藏** 和 **标签** 范围；
- 某个目录，或 **全部** 目录；
- **网格** 或 **列表** 布局。

页面顶部还有 **新建仪表盘**、**导入 JSON** 和 **目录管理**。点击仪表盘的星标即可加入 **已收藏**。每个仪表盘末尾的菜单提供以下操作：

| 操作 | 效果 |
|---|---|
| **打开**、**编辑**、**分享** | 打开仪表盘、它的编辑器或分享对话框。 |
| **移动到文件夹** | 把仪表盘移到另一个目录。 |
| **创建副本** | 创建一个名为 `<标题> copy` 的可编辑副本。 |
| **导出 JSON** | 下载仪表盘模型，**导入 JSON** 可以导入它。 |
| **设为 NOC 大屏** | 在当前浏览器的 [NOC 大屏](#noc-大屏)上展示这个仪表盘。 |
| **删除** | 删除仪表盘及其面板，无法撤回。 |

## 目录

目录最多三层，用于归类仪表盘。点击 **目录管理**，再点击 **新建文件夹** 在根级创建目录，或点击 **新建子目录** 在所选目录下创建子目录。

不属于任何目录的仪表盘位于 **默认目录**。默认目录不能重命名、删除，也不能包含子目录。只有把目录中的仪表盘和子目录都移出后，才能删除该目录。

## 查看仪表盘

仪表盘页头显示所在目录、面板数和最近修改时间，并提供以下控件：

| 控件 | 用法 |
|---|---|
| 时间选择器 | 设置所有面板的时间范围。时间按个人默认时区显示；在选择器底部点击 **更改** 可以切换时区。 |
| **刷新所有面板** | 重新运行每个面板。旁边的菜单设置自动刷新：**关闭**、**自动** 或某个间隔。**自动** 会根据时间范围和面板宽度调整间隔。 |
| 变量 | 为[变量](/zh-Hans/dashboards/variables)选择取值。地址栏以 `var-<name>=<value>` 保存取值，复制的链接会打开同样的视图。 |
| **分享** | 打开[分享对话框](/zh-Hans/resource-sharing)。 |
| **编辑** | 打开[编辑器](/zh-Hans/dashboards/edit)。只读仪表盘改为提供 **创建副本**。 |
| 更多操作 | **查看仪表盘详情**（ID、UID、负责人和 Schema）、**NOC 大屏**、**创建副本** 和 **导出 JSON**。 |

鼠标移到面板上可以看到它的描述。面板菜单提供：

| 操作 | 效果 |
|---|---|
| **查看** | 单独放大显示该面板。 |
| **编辑** | 在编辑器中打开该面板。 |
| **探索数据** | 在对应的探索页中打开面板的查询，代入变量值，并保持相同的时间范围。 |
| **检查查询** | 以 JSON 显示面板的查询定义。 |
| **分享** | 复制该面板的链接。 |
| **导出数据** | 把面板数据下载为 CSV。 |
| **导出图片** | 下载面板的图片。 |
| **复制** | 复制面板的 JSON，以便粘贴到其他仪表盘。 |
| 数据链接 | 打开面板的[数据链接](/zh-Hans/dashboards/edit#数据链接)。 |
| **创建告警** | 用面板的查询新建一条[告警规则](/zh-Hans/alerting/rules)。 |
| **Mole Agent 分析** | 让 [Mole Agent](/zh-Hans/agent) 分析面板展示的内容。 |

## 导入仪表盘

点击 **导入 JSON**，粘贴 MoleSignal 仪表盘 JSON 或上传 `.json` 文件，选择目录后点击 **导入**。这份 JSON 就是 **导出 JSON** 下载的内容，或 `GET /api/v1/dashboards/{id}` 返回的 `model`，其中的 `engine` 必须是 `molesignal-dashboard`。

不支持导入 Grafana 仪表盘 JSON。请在编辑器中重建这类仪表盘，PromQL 表达式可以原样粘贴到指标面板中。

## 让 Mole Agent 生成仪表盘

让 [Mole Agent](/zh-Hans/agent) 起草一个仪表盘，例如“为 checkout 服务做一个仪表盘”。Mole Agent 只生成草稿，不会创建任何东西，并给出 **AI Dashboard 草稿** 的链接：

1. 查看 **只读预览**，它由正式的仪表盘渲染器绘制。
2. 检查 **查询预检**：每个面板的查询都运行过一次，结果为 **已通过**、**结果为空** 或 **已跳过**；同时查看 **生成警告** 和 **需要修复的问题**。
3. 点击 **提交创建建议**。创建策略需要审核人时，草稿会等待审核通过；否则点击 **确认并创建**。

草稿与它的模型绑定，过一段时间会过期。需要修改时，重新向 Mole Agent 提出要求即可。

## 内置 RUM 仪表盘

有 RUM 应用的工作区里有只读的仪表盘，带标签 `内置` 和 `rum`，每一类应用一张：

| 仪表盘 | 面向 | 内容 |
|---|---|---|
| `RUM · 浏览器应用` | 浏览器应用 | 会话、无错误会话和受挫会话；LCP、INP、CLS 的第 75 百分位及各自的趋势；按来源分的错误；页面、版本、受挫元素和慢资源主机；国家和浏览器。 |
| `RUM · 移动应用` | Android、iOS、Flutter 与 React Native 应用 | 会话、无崩溃会话、无错误会话和受挫会话；无崩溃会话趋势、错误与崩溃趋势；屏幕、版本、按版本的崩溃、受挫元素和慢资源主机；设备和操作系统。 |

每张仪表盘在这一类的第一个应用创建时安装；已有这类应用的工作区，由服务器在启动时安装。升级改动了仪表盘，也在启动时写入新版本。变量是 **应用**、**环境**（一个环境，或 **全部**）和 **间隔**（时间图中柱子的宽度）。[RUM 概览](/zh-Hans/rum#概览)上的 **在大盘中打开** 会打开这张仪表盘，并选好页面当前的应用和环境。

面板是一段简短的 SQL。视图和会话读取 `rum_views_latest` 与 `rum_sessions_latest`，它们只保留每个视图或会话的[最新版本](/zh-Hans/query#rum-行的当前版本)；百分位只统计有该值的视图，所以数字与概览一致。这些仪表盘不能直接编辑。在仪表盘页头或仪表盘列表里选 **创建副本**，得到一张可以修改的仪表盘。

## NOC 大屏

点击顶栏的 **NOC 大屏**，即可进入面向墙面显示的全屏深色视图。按 `Esc` 或点击 **返回控制台** 退出。

状态栏汇总工作区情况：进行中的事件及其级别、实时数据状态、服务数、请求速率和 P95 延迟。面板显示：

| 面板 | 显示内容 |
|---|---|
| **事件** | 正在触发的事件。 |
| **拓扑** | 最近一小时的服务拓扑。 |
| **健康** | 每个服务的请求速率、P95 延迟和错误率。 |
| **流量** | 最近 60 分钟最繁忙的服务。 |

**配置布局** 用于调整大屏：应用预设（**平台运维**、**SRE** 或 **高管视图**），显示或隐藏面板，切换宽窄，前移或后移面板，或 **重置**。布局保存在浏览器中。

把某个仪表盘设为 NOC 大屏后，大屏改为展示该仪表盘：显示它的标题，以及每个面板和面板的查询。大屏上不会把这些面板绘制成图表，要看图表请打开仪表盘本身。

## 报告与分享

可以基于仪表盘创建定时[报告](/zh-Hans/reports)，以 PDF、PNG、CSV、SVG 或 JSON 投递。**分享** 支持登录后访问、跨工作区访问和受限的公开访问。公开的仪表盘只运行面板已保存的查询，并遵循工作区的[共享策略](/zh-Hans/settings/organization#共享与公开访问)。

| 权限 | 允许 |
|---|---|
| `dashboards.read` | 打开仪表盘和目录。 |
| `dashboards.create` | 创建、导入和复制仪表盘。 |
| `dashboards.edit` | 修改仪表盘和目录。 |
| `dashboards.delete` | 删除仪表盘。 |
| `dashboards.share` | 创建和轮换分享。 |
