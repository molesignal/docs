打开 **指标**，用 PromQL 查询指标数据流中的时间序列。查询在标签页中运行，标签页可以并排显示，**分享** 可以复制查询的链接，与[日志](/zh-Hans/logs#查询标签页)相同。地址栏保存上次运行的语句，复制地址即可分享查询。

## 查找指标

打开编辑器旁的 **指标浏览器** 或 **搜索指标**，输入名称的一部分。每个指标显示其类型（**计数器**、**直方图** 或 **仪表**）以及标签数和字段数。选择指标后会写入查询并立即执行。还没有数据的工作区会提供 **接入指标数据源**，参见[数据源](/zh-Hans/intake)。

在数据流保留期内未再出现的指标会从列表中消失。

## 编写查询

编辑器有两种模式：

- **代码**：直接编写 PromQL。**常用 PromQL 函数** 列出常用函数，[PromQL 支持矩阵](/zh-Hans/query/promql-subset)列出全部已实现的函数。
- **构造器**：选择 **指标**，为每个要匹配的标签点击 **添加标签过滤**，再选择 **函数**（**原始指标**、**速率**、**瞬时速率** 或 **增量**）、**聚合**（**求和**、**平均值**、**最大值** 或 **最小值**）和 **时间窗口**。生成的 PromQL 显示在下方。构造器无法表示的表达式（例如带额外参数的函数）会原样保留，直到修改构造器中的字段。

```promql
sum by (service_name) (
  rate(http_server_request_duration_seconds_count[5m])
)
```

点击 **查询**。**选项** 决定查询如何运行：

| 选项 | 取值 |
|---|---|
| **图例** | **自动**、**详细**（显示所有标签），或使用 `{{service}}` 这类模板的 **自定义**。 |
| **格式** | **时间序列** 或 **表格**。 |
| **步长** | **auto**，或 `30s`、`5m` 这类时长。 |
| **类型** | **范围查询** 在时间范围内绘制图表，**即时查询** 取时间范围末尾的值。 |
| **Exemplar** | **开启** 后绘制把数据点关联到链路的 Exemplar。 |

**添加到仪表盘** 会打开一个新仪表盘，并以当前查询作为第一个面板。**清空查询** 清空编辑器。查询有效却没有结果时，可以先用 **扩大时间范围 4 倍** 和 **清除过滤并重试**，再考虑修改表达式。

## 阅读图表

- 在图上拖拽可以框选时间范围，拖动 X 轴可以平移，双击可以缩小。**恢复时间范围** 回到操作图表之前的时间范围。
- 选择 **绘制样式**（**折线**、**柱状** 或 **点**）和 **堆叠**（**关闭**、**普通** 或 **百分比**；堆叠至少需要两个序列）。
- 用图例隔离或比较序列。
- 开启 Exemplar 后，点击菱形标记查看对应链路，**查看 Trace** 可以检查该数据点背后的请求。

跳转到链路或日志时，会带上框选的时间范围。

## 分析结果

**图表**、**表格** 和 **查询检查器** 分别以图表、原始行和实际执行的查询展示结果。结果旁的各个面板帮助理解数据：

| 面板 | 显示内容 |
|---|---|
| **序列** | 每个序列的标签及其最后值、当前值、平均值和最大值。 |
| **查询统计** | 序列数、数据点数、扫描行数、查询耗时、时间范围和步长。 |
| **数据质量** | 负值点、缺失数据和时间戳异常。Counter 出现负速率，说明它被重置、乱序到达或类型声明有误：可以 **查看异常点**、**查看原始数据** 或 **检查指标类型**。 |
| **主要标签** | 在结果中占比最大的标签值。 |
| **统计摘要** | 所有序列取值的分布。 |
| **基数** | 该指标的活跃序列数以及扫描行数，用于找出产生过多序列的标签。 |
| **结果 schema** | 结果中的时间列、数值列和标签列。 |

实例的[指标基数上限](/zh-Hans/settings/platform#指标基数)会拒绝超出上限的新序列，因此在添加取值很多的标签之前，先查看 **基数**。

## 关联指标尖峰

框选尖峰所在的时间窗口，保留服务和环境标签，再打开相关的链路或日志。MoleSignal 会把选中的时间范围带到下一种信号。参见[跨信号关联](/zh-Hans/correlation)。

## 权限

列出指标需要 `streams.read`，执行 PromQL 需要 `streams.query`，**添加到仪表盘** 需要 `dashboards.create`。
