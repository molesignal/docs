打开**指标**，查询指标数据流中的时间序列。

## 从指标目录开始

指标目录会列出指标名、类型、标签和已索引维度。选择指标可填充编辑器，也可以打开
**PromQL 构建器**，通过界面组合标签匹配和聚合。

```promql
sum by (service_name) (
  rate(http_server_request_duration_seconds_count[5m])
)
```

完整实现范围见 [PromQL 支持矩阵](/zh-Hans/query/promql-subset)。

## 使用图表

- 在图上拖动以放大时间范围。
- 拖动 X 轴进行平移。
- 双击恢复更宽时间范围。
- 通过图例隔离或比较序列。
- 跳转到 trace 或日志时保留当前缩放窗口。

## 分析结果

指标工作区不只有图表：

| 视图 | 说明 |
|---|---|
| **序列概览** | 当前值、标签与序列数量。 |
| **统计摘要** | 返回序列的整体分布。 |
| **基数** | 可能增加成本或查询负载的标签组合。 |
| **数据质量** | Counter 回退、乱序点或类型不匹配。 |
| **相关指标** | 共享有用标签的其他指标。 |
| **查询统计** | 扫描规模与执行时间。 |

## 关联指标尖峰

选中尖峰窗口，保留服务和环境标签，然后打开相关 trace 或日志。MoleSignal 会把选中的
时间范围带到下一个信号。

## 权限

发现指标目录需要 `streams.read`；执行 PromQL 或 SQL 需要 `streams.query`。
