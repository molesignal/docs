OpenSource Edition 是开源 Runtime。它采用自托管方式，不需要 MoleSignal 账号或托管控制平面。

## 内置能力

- 日志、指标、链路和性能剖析的采集、存储与查询；
- trace 派生 APM、RUM 调查、跨信号关联与服务拓扑；
- 仪表盘、数据流、流水线、可复用函数与扩展表；
- 告警、事件、通知发送、拨测与状态页；
- 组织隔离、IAM、服务账户、API Token、审计事件与平台设置；
- 使用 Docker 或 Kubernetes 的单体与多角色自托管部署。

完整 API 范围位于 **API 参考**。权限仍然决定用户、服务账户或 API Token 可以执行哪些操作。

## 开始自托管

1. 按照[快速开始](/zh-Hans/quickstart)运行本地实例。
2. 在[部署](/zh-Hans/deployment)中选择生产拓扑。
3. 上线前阅读[安全](/zh-Hans/security)与[自可观测性](/zh-Hans/self-observability)。
