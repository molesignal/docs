开源版是完整的自托管引擎。它基于 [Apache License 2.0](https://github.com/molesignal/molesignal/blob/main/LICENSE) 许可证，运行在运维方自行掌控的基础设施上，不需要 MoleSignal 账号或托管控制平面。

## 内置能力

- 日志、指标、链路和 Profile 的接入、存储与查询；
- 由链路派生的 APM、RUM 调查、跨信号关联与服务拓扑；
- 仪表盘、数据流、流水线、可复用函数与扩展表；
- 告警、事件、通知投递、拨测与状态页；
- Mole Agent，以及通过 Inbound MCP 访问同一套工具目录；
- 组织隔离、IAM、SSO、服务账号、API Token、审计事件与平台设置；
- 使用 Docker Compose、二进制或 Kubernetes 的单节点部署，以及由 router、intake、querier、compactor 与 alert 进程组成的分角色部署。

完整 API 范围位于 **API 参考**。权限仍然决定用户、服务账号或 API Token 可以执行哪些操作。

## 部署需要什么

元数据使用 PostgreSQL，数据使用兼容 S3、Azure 或 Google Cloud 的对象存储。单节点的开发场景可以用本地磁盘充当对象存储，参见[部署 MoleSignal](/zh-Hans/deployment)。

## 开始自托管

1. 按照[快速开始](/zh-Hans/quickstart)运行本地实例。
2. 在[部署 MoleSignal](/zh-Hans/deployment)中选择拓扑。
3. 真实数据到达之前，完成[生产检查清单](/zh-Hans/production-checklist)。
4. 阅读[安全与多租户](/zh-Hans/security)与[自身可观测性](/zh-Hans/self-observability)。
