<Warning>
MoleSignal Cloud 目前处于候补名单阶段。本页用于评估准备，不是已全面开放服务的开通或接入教程。
</Warning>

MoleSignal Cloud 是规划中的托管方案，面向希望评估可观测性平台、同时减少存储与服务基础设施运维工作的团队。通过 [Cloud 候补名单](https://www.molesignal.com/zh-Hans/cloud)登记需求。需要立即开始评估时，使用[自托管快速开始](/zh-Hans/quickstart)。

## 准备 Cloud 评估

| 要求 | 需要收集的信息 |
|---|---|
| 遥测 | 日志、指标、链路、Profile、预计每日用量与写入峰值。 |
| 保留期 | 各信号所需的历史范围，以及必须保持可用的查询。 |
| 访问 | 团队规模、组织边界、身份认证要求和 API Token 使用方式。 |
| 部署位置 | 所需数据区域、网络访问方式和数据处理限制。 |
| 运维 | 支持要求、恢复目标与事件发生时的责任分工。 |

评估期间确认可用区域、访问方式、保留限制、商业条款和支持承诺。自托管配置项不代表托管服务一定提供同名设置。

## 先验证数据链路

1. 启动自托管实例，选择一个具有代表性的服务。
2. 按文档中的[接入协议](/zh-Hans/intake/integrations)发送遥测。
3. 核对事件时间、数据流、服务身份和权限。
4. 执行代表性查询并完成一次事件调查，记录所需用量与保留期。
5. 根据结果讨论需求，再约定 Cloud 开通或迁移计划。

自托管实例的 API 地址或 API Token 不会自动变成 Cloud 地址或凭据。仅使用实际环境提供的接入地址与凭据。
