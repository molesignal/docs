MoleSignal Cloud 是规划中的托管模式，面向不希望自行运维控制平面、数据库、存储生命周期、升级与平台监控的团队。

## 规划模式

- 与自托管版本使用相同的 MoleSignal 遥测引擎、Schema 与查询语言；
- 全托管多租户与 Bring-your-own-cloud 方案仍在评估；
- 由 MoleSignal 负责升级、备份、平台监控与服务恢复；
- 产品内账单与账号支持页面仅面向 Cloud 组织；
- 提供从自托管部署迁移的协助，并保持遥测与查询模型可移植。

Cloud 的功能、区域、限额、价格、合规范围与迁移保证会在实际可用后补充。在此之前，已实现的产品行为以开源版或企业版文档为准。
