设置导航会感知访问能力，只显示当前组织或系统范围允许访问的分区。

## 账户组

| 分区 | 用途 | 主要权限 |
|---|---|---|
| **通用** | 工作区名称、Slug/ID、注册、共享策略与偏好默认值。 | `org.settings.read` / `org.settings.manage` |
| **组织管理** | 全局组织清单与成员关系操作。 | `sys.organizations.manage` |
| **许可证** | 当前许可证、不可变版本、上传与激活。 | `sys.licenses.read` / `sys.licenses.manage` |
| **计费** | 支持该能力的部署中的 Stripe 与订阅策略。 | `org.billing.read` / `org.billing.manage` |

## 通知管理组

| 分区 | 用途 | 主要权限 |
|---|---|---|
| **企业连接器** | 配置加密保存的 SMTP、Slack、飞书与 Webhook 服务商凭证。 | `alerts.read` / `alerts.manage` |
| **用户通知** | 绑定各平台身份并排列个人投递方式。 | 管理其他用户时需要 `org.members.read` / `org.members.manage` |
| **通知策略** | 匹配事件、解析接收人、选择投递模式并配置升级。 | `alerts.read` / `alerts.manage` |
| **通知模板** | 创建并预览可复用通知消息。 | `alerts.read` / `alerts.manage` |
| **兜底路由** | 按通知类别定义有序的团队与组织路由。 | `alerts.read` / `alerts.manage` |
| **投递记录** | 查看完整投递链路、确认事件并重试失败路由。 | 按操作使用 `alerts.read`、`alerts.acknowledge` 或 `alerts.manage` |

服务商配置和完整路由流程见[通知渠道与投递](/zh-Hans/notification-channels)。

## 数据平面组

- **节点**用于管理本地或远程集群定义与组织映射。
- **关联**用于查看跨信号跳转所使用的供应商。

远程集群参与联合搜索时，需要 `federated_search` 授权能力。

## 安全组

- **加密密钥**用于管理字段加密密钥及轮换。
- **正则表达式**用于维护可复用匹配模式。
- **域名管理**用于管理自定义域名与 ACME 续期。
- **审计**用于查询组织审计事件。

域名管理需要 `domain_management` 授权能力。审计访问需要 `audit.read`。

## AI 与机器学习组

- **模型定价**用于保存各供应商输入与输出 Token 单价，以估算成本。
- **查询管理**用于列出运行中或慢查询，并允许授权用户取消任务。

Mole Agent 的模型、提示词、工具、MCP 服务器、网络策略与审批规则位于 **Mole Agent → Agent 设置**。

## 账户设置是独立区域

个人资料、主题、语言、时区、启动页面、登录设置、活动会话与个人通知身份位于**账户设置**，不属于
工作区设置。打开**账号设置 → 通知设置**，可以管理个人端点、投递顺序和免打扰时段。
