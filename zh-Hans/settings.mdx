设置导航会感知访问能力，只显示当前组织或系统范围允许访问的分区。

## 当前组织

| 分区 | 用途 | 主要权限 |
|---|---|---|
| **通用** | 组织名称、稳定标识、注册与共享策略，以及偏好默认值。 | `org.settings.read` / `org.settings.manage` |

## 通知

| 分区 | 用途 | 主要权限 |
|---|---|---|
| **连接器** | 配置加密保存的 SMTP、Slack、飞书与 Webhook 服务商凭证。 | `alerts.read` / `alerts.manage` |
| **用户通知** | 绑定各平台身份并排列个人投递方式。 | 管理其他用户时需要 `org.members.read` / `org.members.manage` |
| **通知策略** | 匹配事件、解析接收人、选择投递模式并配置升级。 | `alerts.read` / `alerts.manage` |
| **通知模板** | 创建并预览可复用通知消息。 | `alerts.read` / `alerts.manage` |
| **兜底路由** | 按通知类别定义有序的团队与组织路由。 | `alerts.read` / `alerts.manage` |
| **投递记录** | 查看完整投递链路、确认事件并重试失败路由。 | 按操作使用 `alerts.read`、`alerts.acknowledge` 或 `alerts.manage` |

服务商配置和完整路由流程见[通知渠道与投递](/zh-Hans/notification-channels)。

## 数据面

- **客户端 IP 识别** 设置 RUM 接入如何识别客户端地址。默认使用直接连接的地址。位于代理或 CDN 之后时，选择请求头或转发链，并列出受信任的代理 CIDR，因为只有来自这些网络的请求头才会被信任。
- **节点 / 远程集群** 用于管理本地数据面、跨集群联邦、远程查询目标与组织映射。

## 数据安全

- **加密密钥** 用于管理字段加密密钥及轮换，仅限 Owner。
- **正则模式** 用于维护可复用匹配模式，也用于敏感数据脱敏。
- **字段遮掩** 按顺序匹配全局规则。数据流可以覆盖或关闭继承的遮掩。查询基于原始值计算，只在返回结果前遮掩，Metrics 指标流不参与遮掩。
- **域名管理** 用于管理带托管 TLS 证书的自定义域名。
- **审计** 用于按时间、操作者、动作和目标搜索组织审计记录，访问需要 `audit.read`。

## AI 与 ML

- **活动查询管理** 用于列出运行中的查询和最近的 inspector 活动，并允许授权用户取消任务。

Mole Agent 的模型、提示词、工具、MCP 服务器、网络策略与审批规则位于 **Mole Agent → 设置**。

## 平台

- **组织管理** 用于在 `_sys` 工作区统一管理租户组织及其成员，需要 `sys.organizations.manage`。

## 账户设置是独立区域

个人资料、主题、语言、时区、启动页面、登录设置、活动会话与个人通知身份位于 **账户设置**，不属于工作区设置。打开 **账户设置 → 通知设置**，可以管理个人端点、投递顺序和免打扰时段。
