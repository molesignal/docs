MoleSignal 每次分享一个仪表盘或一份报告。分享链接永远不会变成用户 Token：公开链接只会开启一个短时的受限分享会话，其他分享方式仍会检查访问者的权限。

## 分享仪表盘或报告

在仪表盘、仪表盘列表或报告上点击 **分享**。**分享资源** 对话框先询问 **访问范围**：

| 范围 | 访问者 | 规则 |
|---|---|---|
| **当前工作区成员** | 登录的成员。 | 他们仍需要在工作区中拥有该资源的权限。 |
| **指定组织成员** | **目标组织** 中登录的成员。 | 创建一个显式的跨组织授权，只有能管理跨组织授权的成员可以创建。 |
| **任何拥有链接的人** | 持有链接的任何人，无需账号。 | 链接是可撤销的受限凭证，工作区策略可以禁止它。 |

然后设置限制条件，并点击 **创建分享链接**：

| 设置 | 适用于 | 效果 |
|---|---|---|
| **有效期** | 所有范围 | **1 天**、**7 天**、**30 天** 或永不过期，不超过工作区为公开链接设置的上限。到期后链接立即失效。 |
| **最大访问次数** | 公开链接 | 每次创建新的分享会话计一次，留空表示不限制。 |
| **访问密码** | 公开链接 | 密码验证通过后才开启受限会话。公开仪表盘必须设置密码，工作区策略也可以要求公开报告设置密码。 |
| **允许下载** | 公开报告 | 关闭后报告只能在线预览。工作区策略可以禁止公开下载 CSV。 |
| **最大数据时间范围** | 公开仪表盘 | 1、6 或 24 小时。**允许调整时间范围** 让访问者在该范围内选择预设时间。 |
| **可公开的变量** | 公开仪表盘 | 未选中的变量会从公开模型及其请求中移除。**允许修改白名单变量** 让访问者修改选中的变量。 |

**复制链接** 复制链接。对话框会保存链接，之后可以再次复制。

## 公开访问者看到什么

公开仪表盘只通过受限代理运行面板中已保存的查询：查询表达式和探索页都不可见，浏览器也不能自行发送 SQL 或 PromQL。公开报告是创建链接时生成的固定快照，打开时不会运行实时查询。页面带有 **公开访问** 水印和有效期。

已过期、已停用或访问次数已用完的链接会显示 **链接不可用**。

<Warning>
  公开链接是 Bearer 凭证：任何拿到链接的人都能看到分享的内容。即使设置了有效期或密码，也不要分享敏感数据。
</Warning>

## 管理现有分享

对话框中的 **现有分享** 列出该资源的链接，以及访问次数和有效期。

| 操作 | 效果 |
|---|---|
| **复制链接** | 再次复制链接。 |
| **轮换** | 在旧链接可能泄露时，用新链接替换它，旧链接随即失效。 |
| **停用** | 立即停用链接。 |

在保存链接功能启用之前创建的分享不会显示链接，轮换一次后才会显示。

## 工作区策略

管理员在[设置 → 通用 → 共享与公开访问](/zh-Hans/settings/organization#共享与公开访问)中设置成员可以公开分享什么：是否允许公开链接、是否允许公开实时仪表盘、公开链接的最长有效期、公开报告是否必须设置密码、是否禁止公开分享带 `production` 或 `prod` 标签的资源，以及是否允许公开下载 CSV。策略阻止某个范围时，对话框会给出说明并提供设置入口。此时请改用工作区内分享或跨组织分享。

## 审计与权限

创建、打开、轮换和停用分享都会记录到[审计记录](/zh-Hans/settings/data-security#审计)中。分享需要该资源的分享权限，例如 `dashboards.share` 或 `reports.share`，MoleSignal 在创建分享前还会再次检查对资源的访问权限。
