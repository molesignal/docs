## 通用

### MoleSignal 是什么？

MoleSignal 是自托管、原生支持 OpenTelemetry 的可观测性平台。它把日志、指标、链路和 Profile 以 Parquet 文件的形式存放在对象存储中，并用 SQL 和兼容 PromQL 的查询来检索，参见[核心概念](/zh-Hans/concepts)。

### 适用什么许可证？

MoleSignal 是基于 Apache License 2.0 的开源软件，参见[开源版](/zh-Hans/editions/open-source)。

### 有托管版本吗？

MoleSignal Cloud 是托管版本，详情参见 [molesignal.com/cloud](https://www.molesignal.com/cloud)。

### 部署需要哪些服务？

PostgreSQL 与对象存储。单节点和开发场景可以用 `local` 对象后端代替对象存储。不涉及 Kafka、Redis 或共识服务，参见[部署 MoleSignal](/zh-Hans/deployment)。

### 元数据保存在哪个数据库？

PostgreSQL。把 `[meta_database].dsn` 设为它的连接串，参见[配置](/zh-Hans/configuration#元数据库)。

### 可以不用容器运行吗？

可以。MoleSignal 以单个二进制文件交付，[部署指南](/zh-Hans/deployment)涵盖 Docker Compose、二进制加 systemd 以及 Kubernetes。

## 数据

### 数据存放在哪里？

日志、指标和链路以 Parquet 文件的形式存放在对象存储中。PostgreSQL 保存元数据、身份、文件目录与产品资源。尚未刷写的记录保存在 intake 节点本地磁盘的预写日志中，参见[备份与恢复](/zh-Hans/backup-restore)。

### 数据保留多久？

默认 30 天。`[compactor].retention_days` 设置全局默认值，每个数据流也可以单独设置保留期，参见[数据流](/zh-Hans/streams)。

### 哪些协议可以接入数据？

OTLP over HTTP 与 gRPC、Prometheus `remote_write`、Elasticsearch `_bulk` 协议、JSON 形式的 Loki push、原生 JSON over HTTP，以及 Kinesis Firehose、Cloudflare Logpush 与 Heroku 日志投递，参见[数据源](/zh-Hans/intake)。

### 为什么记录出现在错误的时间？

`_timestamp` 是自 Unix 纪元起的微秒数。以秒、毫秒或纳秒表示的值会落在错误的时间，参见[故障排查](/zh-Hans/troubleshooting#数据缺失或异常)。

### 如何用 SQL 客户端查询？

启用 `[flight_sql]`，让 DBeaver、JDBC 或 ADBC 客户端使用 API Token 连接 `5083` 端口，参见[用数据库客户端连接](/zh-Hans/query/database-clients)。

## 账号与安全

### 第一次如何登录？

全新部署会根据 `[auth].root_email` 与 `[auth].root_password` 创建 root 账号。示例配置使用 `admin@example.com` 和 `admin`，实际使用前请修改这两项，参见[生产检查清单](/zh-Hans/production-checklist)。

### 忘记密码如何重置？

使用登录页面上的密码重置链接。MoleSignal 通过邮件发送该链接，因此必须配置 `[notify.smtp]` 与 `[http].external_url`。

### 支持单点登录吗？

支持。OIDC、SAML 与 LDAP 服务商在网页界面的 **身份与访问 → SSO 服务商** 中配置，并保存在 PostgreSQL 中，参见[身份与访问](/zh-Hans/identity)。

### `MS_CIPHER_KEY` 保护什么？

它是 MoleSignal 保存在 PostgreSQL 中的密文的根密钥，例如 API Token、通知连接器凭据与 Mole Agent 服务商密钥。请备份该密钥，参见[生产检查清单](/zh-Hans/production-checklist)。

## 运维

### 如何扩展部署？

先从单个 `standalone` 节点开始。要让接入、查询与后台任务独立扩缩容，请把角色拆分到多个进程：`router` 角色提供网页界面与 API，把写入转发给 `intake` 节点，把查询交给 `querier` 节点。参见[分角色部署](/zh-Hans/distributed-deployment)与[已知限制](/zh-Hans/limitations)。

### 如何查看运行的版本？

运行 `molesignal --version`，或使用 Bearer Token 调用 `GET /api/v1/version`。
