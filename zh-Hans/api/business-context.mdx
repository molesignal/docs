```http
GET /api/v1/business-context
PUT /api/v1/business-context
```

业务键，例如租户、套餐或实验分组，以及 Span、日志和 RUM 事件里承载每个键的字段。参见[业务上下文](/zh-Hans/business-context)。读取需要 `apm.services.read`、`traces.read`、`logs.read`、`rum.events.read`、`apm.settings.read` 或 `sys.telemetry.read` 之一；设置需要 `apm.settings.manage`，并记入操作日志。

## 设置业务键

`PUT` 整体替换所有键。留空的字段表示不指定，`label` 留空时取键名，重点取值会去掉两端空白并去重；返回保存后的内容。

| 字段 | 说明 |
|---|---|
| `key` | 以小写字母开头，只含小写字母、数字和 `_`，最多 64 个字符，不能重复。 |
| `label` | 读者看到的名字，最多 80 个字符。 |
| `span` | Span 属性，按 Trace 流里的字段名填写。 |
| `log` | 日志字段。 |
| `rum` | RUM 字段，可以是 JSON 字段里的键，例如 `context.tenant`。 |
| `important` | 最重要的取值，最多 50 个，每个最多 200 个字符。 |

每个键至少指定 `span`、`log`、`rum` 中的一个。最多 8 个键。

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/business-context \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"keys":[{"key":"tenant","label":"租户","span":"tenant.id","log":"tenant_id","rum":"context.tenant","important":["acme"]}]}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "keys": [
    {
      "key": "tenant",
      "label": "租户",
      "span": "tenant.id",
      "log": "tenant_id",
      "rum": "context.tenant",
      "important": ["acme"]
    }
  ]
}
```
</ResponseExample>

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | 键名不合规或重复、没有指定任何字段，或键、取值超过上限。 |
| `403` | Token 缺少该调用需要的权限。 |
