---
title: "Heroku log drain"
description: "Heroku log drain 目标。"
---

```http
POST /api/v1/_heroku
```

接受文本 Log Drain 请求体，每行成为一条日志事件，并写入 connector 的 `target_stream`
（默认 `heroku`）。成功返回 `204`。

<Note>
  该端点不使用 Bearer Token。请把已启用的 Heroku connector Token 放入 `?token=...`；
  能设置自定义请求头的客户端也可使用 `X-Connector-Token`。
</Note>
