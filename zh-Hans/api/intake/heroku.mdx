---
title: "Heroku 日志投递"
description: "接收 Heroku 日志投递。"
"en_link": "/en-US/api/intake/heroku"
---

```http
POST /api/v1/_heroku
```

接受文本形式的日志投递请求体。该端点不使用 Bearer Token。请创建 `heroku_drain` 类型的连接器，设置 `push_token` 与 `target_stream`。Heroku 无法设置自定义请求头，因此 Token 以 `?token=` 的形式放在 URL 中，请求头 `X-Connector-Token` 同样可用。Token 错误时返回 `401`。

每一行成为 `target_stream`（默认 `heroku`）中的一条日志事件。整行保存在字段 `message` 中，字段 `source` 为 `heroku`。成功时返回 `204`。

<RequestExample>
```bash Heroku CLI
heroku drains:add "https://molesignal.example.com/api/v1/_heroku?token=<push_token>"
```
</RequestExample>

连接器的配置参见[连接器](/zh-Hans/connectors)。
