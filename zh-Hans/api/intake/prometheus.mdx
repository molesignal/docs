```http
POST /api/v1/prometheus/api/v1/write
```

接受 Prometheus 与 VictoriaMetrics 的 `remote_write` 第 1 版请求，即 snappy 压缩的 protobuf。该调用需要 `streams.write`，成功时返回 `204`。

每条时间序列写入以其 `__name__` 标签命名的指标数据流。其余标签成为字段，样本成为 `value` 字段。原生直方图与指标元数据会被跳过，exemplar 与样本一起保存。

<RequestExample>
```yaml prometheus.yml
remote_write:
  - url: http://localhost:5080/api/v1/prometheus/api/v1/write
    authorization:
      credentials: "${MS_TOKEN}"
```
</RequestExample>

用 PromQL 查询时，把数据流名称当作指标名。带有 `service` 与 `status` 标签的 `http_requests_total` 序列会得到：

```json
{
  "columns": ["value", "service", "status"],
  "rows": [[25.0, "checkout", "200"]],
  "scanned_rows": 1,
  "took_ms": 154
}
```

**限制** 按序列与按组织生效：每个序列最多 64 个标签，标签名最长 128 字节，标签值最长 2048 字节，并对活跃序列与新序列设有基数限制，参见[配置](/zh-Hans/configuration#接入缓冲)中的 `[intake.prometheus]`。
