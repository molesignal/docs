---
title: "Elasticsearch _bulk"
description: "用 Elasticsearch bulk 协议发送日志。"
---

```http
POST /api/v1/_bulk
```

兼容 Elasticsearch `_bulk` 的 NDJSON 接入，适用于 Filebeat、Logstash 与 Vector 的 `elasticsearch` sink。该调用需要 `streams.write`，接受带有 `Content-Encoding: gzip` 的请求体。

| 动作 | 处理方式 |
|---|---|
| `index`、`create`、`update` | 源文档作为日志事件保存。 |
| `delete` | 被确认并忽略。该端点不会删除任何遥测数据。 |

动作中的 `_index` 选择目标日志数据流。没有它时使用 `stream-name` 请求头，再缺省为 `default`。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/_bulk \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/x-ndjson' \
  --data-binary $'{"index":{"_index":"app"}}\n{"level":"info","msg":"hello"}\n'
```
</RequestExample>

<ResponseExample>
```json 200
{ "took": 0, "errors": false, "items": [ { "index": { "status": 201 } } ] }
```
</ResponseExample>
