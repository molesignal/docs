---
title: "Kinesis Firehose"
description: "接收 AWS Data Firehose 的 HTTP 投递。"
---

```http
POST /api/v1/_kinesis_firehose
```

接受 AWS Data Firehose HTTP 端点的投递。该端点不使用 Bearer Token。请创建 `aws_kinesis_firehose` 类型的连接器，设置 `push_token` 与 `target_stream`，并把该 Token 作为访问密钥交给 Firehose。端点从 `X-Amz-Firehose-Access-Key` 读取 Token，也接受 `X-Connector-Token` 与 `?token=`。Token 错误时返回 `401`。

每条记录都带有 base64 编码的 `data`。端点会解码、按行拆分，并把每个非空行变成 `target_stream`（默认 `kinesis`）中的一条日志事件。JSON 对象的行会变成字段，纯文本的行会变成字段 `message`。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/_kinesis_firehose \
  -H 'X-Amz-Firehose-Access-Key: <push_token>' \
  -H 'content-type: application/json' \
  -d '{"requestId":"req-1","timestamp":1790000000000,"records":[{"data":"eyJsZXZlbCI6ImluZm8ifQo="}]}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "requestId": "req-1", "timestamp": 1790000000123 }
```
</ResponseExample>

响应会回显 `requestId`，并带有毫秒级 `timestamp`，这是 Firehose 的要求。连接器的配置参见[连接器](/zh-Hans/connectors)。
