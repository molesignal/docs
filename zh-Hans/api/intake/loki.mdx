---
title: "Loki push"
description: "以 Loki JSON push 格式发送日志。"
"en_link": "/en-US/api/intake/loki"
---

```http
POST /api/v1/loki/api/v1/push
```

接受 Loki JSON push 格式。该调用需要 `streams.write`，成功时返回 `204`，并接受带有 `Content-Encoding: gzip` 的请求体。

该端点只解码 JSON。使用 snappy 压缩 protobuf 的发送端（例如 Promtail 与 Grafana Alloy）无法向它推送，请改用 OpenTelemetry Collector、Vector 或 Fluent Bit。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["1790000000000000000","started"]]}]}'
```
</RequestExample>

每个 value 成为一条日志事件。标签成为字段，日志行成为字段 `message`，纳秒时间戳会转换为微秒。`stream-name` 请求头选择目标数据流，默认为 `default`。
