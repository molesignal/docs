title: "Cloudflare Logpush"
description: "接收 Cloudflare Logpush 的投递。"

---

```http
POST /api/v1/_cloudflare
```

接受 NDJSON，包括 Cloudflare Logpush 通常发送的 gzip 编码请求体。该端点不使用 Bearer Token。请创建 `cloudflare_logpush` 类型的连接器，设置 `push_token` 与 `target_stream`，并在请求头 `X-Connector-Token` 中发送该 Token，查询参数 `?token=` 同样可用。Token 错误时返回 `401`。

每一行成为 `target_stream`（默认 `cloudflare`）中的一条日志事件。行中的字段按原样保存，事件时间为接收时间。成功时返回 `204`。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/_cloudflare \
  -H 'X-Connector-Token: <push_token>' \
  -H 'content-encoding: gzip' \
  --data-binary @logs.ndjson.gz
```
</RequestExample>

连接器的配置参见[连接器](/zh-Hans/connectors)。
