---
title: "数据流运行状态"
description: "读取每个数据流的接入状态与数据量。"
"enLink": "/en-US/api/streams/runtime"
---

```http
GET /api/v1/streams/runtime
```

返回每个数据流的运行状态：存储的行数与字节数、最近接收时间、接入状态，以及分桶的时间序列。该调用需要 `streams.read`，系统遥测需要 `sys.telemetry.read`。Token 缺少 `audit.read` 时结果中不含 `_audit` 数据流。

**查询参数**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `windowSecs` | 86400 | 窗口长度，限制在 3600 到 604800 之间。 |
| `bucketCount` | 24 | 时间序列的分桶数，限制在 6 到 48 之间。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/runtime?windowSecs=3600" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

| `status` | 含义 |
|---|---|
| `healthy` | 最近 15 分钟内有数据到达。 |
| `delayed` | 最近一条数据早于 15 分钟，但晚于 2 小时。 |
| `interrupted` | 最近一条数据早于 2 小时。 |
| `idle` | 按设计就比较安静的数据流，例如 Mole Agent 的链路数据流。 |
| `unused` | 数据流从未收到过数据。 |
| `unknown` | 统计信息不可用。 |

`staleIndexFiles` 是数据流最近一次改索引类型之后，还按之前的设置建索引的文件数，后台补建时降到 0。
