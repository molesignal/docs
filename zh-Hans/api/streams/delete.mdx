---
title: "删除数据流"
description: "按 id 删除数据流。"
"en_link": "/en-US/api/streams/delete"
---

```http
DELETE /api/v1/streams/{id}
```

删除数据流的定义，已存储的数据由 compactor 回收。受保护的系统数据流 `_molesignal` 不能删除。删除数据流可能让引用它的仪表盘、保存的视图、告警规则、报告与流水线失效。该调用需要 `streams.delete`。

**路径参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `id` | string | 数据流的 `id`。未知的 id 返回 `404`。 |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/streams/$STREAM_ID \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>
