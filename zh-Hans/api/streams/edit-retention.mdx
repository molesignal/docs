---
title: "编辑保留期与设置"
description: "设置数据流保留数据的时长，并修改它的设置。"
---

```http
PUT /api/v1/streams/{id}/settings
```

更新数据流的保留期与设置，只发送需要修改的属性。该调用需要 `streams.configure`。

**请求体**

| 字段 | 类型 | 说明 |
|---|---|---|
| `retention_days` | integer 或 `null` | 1 到 3650 天。`null` 会清除显式值，数据流沿用 `[compactor].retention_days`。超出范围返回 `400`。 |
| `settings` | object | 数据流设置，见下文。 |
| `fields` | array | 字段索引，参见[配置字段索引](/zh-Hans/api/streams/edit-schema)。 |

有实际效果的设置：

| 设置 | 说明 |
|---|---|
| `description` | 在网页界面中显示的自由文本。 |
| `queryable` | `false` 时数据流仍然接收并保留数据，但会从查询选择器中隐藏，查询会失败并返回 `403`（`stream is not queryable`）。 |
| `field_masking` | 数据流级别对全局[字段遮掩](/zh-Hans/settings#数据安全)规则的覆盖。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "retention_days": 30,
    "settings": { "description": "Application logs", "queryable": true }
  }'
```
</RequestExample>

响应是更新后的数据流。保留期决定 compactor 何时删除数据，修改只影响之后的清理，不会恢复已经删除的文件。`settings` 的其他属性（`retention_filter`、`keep_conditions`、`max_query_range_hours`、`flatten_level`、`use_stream_stats_for_partitioning`、`store_original_data` 与 `enable_distinct_values`）会被接受并保存，当前版本不会应用它们。
