---
title: "列出数据流"
description: "列出组织中的数据流。"
---

```http
GET /api/v1/streams
```

以 JSON 数组返回组织中的每个数据流，按名称和类型排序。每一项的结构与[获取数据流](/zh-Hans/api/streams/get)中展示的相同，包含 schema、显式的 `retention`、计算得出的 `effective_retention`、设置以及微秒级时间戳。该调用需要 `streams.read`。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

响应中包含受保护的系统数据流，例如 `_molesignal`。数据流由名称和类型共同标识，因此同一个名称可以在多个类型下出现。
