```http
GET /api/v1/streams
```

以 JSON 数组返回组织中的每个数据流，按名称和类型排序。每一项的结构与[获取数据流](/zh-Hans/api/streams/get)中展示的相同，包含 schema、显式的 `retention`、计算得出的 `effectiveRetention`、设置以及微秒级时间戳。该调用需要 `streams.read` 或 `sys.telemetry.read`。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

响应中包含受保护的系统数据流，例如 `_molesignal`；Token 缺少 `audit.read` 时不包含 `_audit`。数据流由名称和类型共同标识，因此同一个名称可以在多个类型下出现。

## 使用响应

此接口返回数据流定义，不返回遥测记录。读取单个数据流的 Schema 或修改配置前，先用它查找数据流 ID。查询事件使用[查询 API](/zh-Hans/api/query/execute)。

| 字段 | 含义 |
|---|---|
| `id` | 单个数据流 API 使用的稳定标识。 |
| `name` 与 `streamType` | 两者共同标识数据集，不要只按名称构造清单。 |
| `schema` | 构造查询所依据的字段定义。 |
| `retention` | 数据流显式保留设置；`null` 表示使用默认值。 |
| `effectiveRetention` | 数据流实际采用的保留设置。 |
| `createdAt`、`updatedAt` | 微秒级 Unix 时间戳，不是毫秒。 |

## 验证权限与数据范围

使用关联到目标组织的凭据。`streams.read` 或 `sys.telemetry.read` 可访问列表接口；缺少 `audit.read` 时不返回 `_audit`。列表中没有 `_audit` 不代表审计采集已关闭。

响应是 JSON 数组，不是含 `items` 的包装对象，此路由没有分页参数。空数组表示当前请求的组织与可见范围内没有返回数据流，不能据此判断其他组织没有数据。

找到目标 `(name, streamType)` 后，将其 `id` 传给[获取数据流](/zh-Hans/api/streams/get)。另用[示例查询](/zh-Hans/api/query/execute)验证实际事件，区分数据流定义存在与已有可查询数据。
