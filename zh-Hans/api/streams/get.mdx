---
title: "获取数据流"
description: "按 id 获取一个数据流。"
"en_link": "/en-US/api/streams/get"
---

```http
GET /api/v1/streams/{id}
```

返回数据流的定义，包括 schema、显式的 `retention`、计算得出的 `effective_retention` 以及数据流设置。该调用需要 `streams.read`，系统遥测需要 `sys.telemetry.read`。

**路径参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `id` | string | [列出数据流](/zh-Hans/api/streams/list)返回的数据流 `id`。未知的 id 返回 `404`。 |

<ResponseExample>
```json 200
{
  "id": "3KE0ot1NtfCTJ3V3XxBNbqx9Y62",
  "org_id": "<organization-id>",
  "name": "app",
  "stream_type": "logs",
  "schema": {
    "fields": [
      { "name": "level", "data_type": "utf8", "nullable": true, "index_type": "none",
        "indexed": false, "encrypted": false, "exact": false },
      { "name": "trace_id", "data_type": "utf8", "nullable": true, "index_type": "exact",
        "indexed": true, "encrypted": false, "exact": true }
    ]
  },
  "retention": null,
  "effective_retention": { "days": 30 },
  "settings": {
    "description": null,
    "index_rules": [],
    "queryable": true,
    "field_masking": []
  },
  "created_at_micros": 1790000000000000,
  "updated_at_micros": 1790000000000000
}
```
</ResponseExample>

数据流使用默认保留期时，`retention` 为 `null`，`effective_retention` 则始终给出实际生效的天数。`settings` 对象中还有 `retention_filter`、`keep_conditions`、`max_query_range_hours`、`flatten_level`、`use_stream_stats_for_partitioning`、`store_original_data` 与 `enable_distinct_values`。当前版本会保存这些值，但不会应用它们。
