---
title: "获取数据流"
description: "按 id 获取一个数据流。"
"en_link": "/en-US/api/streams/get"
---

```http
GET /api/v1/streams/{id}
```

返回数据流的定义，包括 schema、显式的 `retention`、计算得出的 `effective_retention` 以及数据流设置。该调用需要 `streams.read`，系统遥测需要 `sys.telemetry.read`。`_audit` 数据流还需要 `audit.read`，没有时返回 `403`。

**路径参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `id` | string | [列出数据流](/zh-Hans/api/streams/list)返回的数据流 `id`。未知的 id 返回 `404`。 |
