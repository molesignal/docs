```http
GET /api/v1/streams/usage
```

返回每个来源在一段时间内接入了多少数据，以及预算用到了哪里。需要 `intake_usage.read`；在 `_sys` 组织中也可以用 `sys.telemetry.read`。

未知的数值是 `null`，不是 0。读不出记录时，`available` 为 `false`，所有数值都是 `null`。计量在这段时间内才开始时，`complete` 为 `false`，数值是下限。

**查询参数**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `dimension` | `credential` | `credential`、`stream` 或 `service`。 |
| `window_secs` | 86400 | 时间窗口长度，范围 3600 到 2678400。窗口从整点开始。 |

`source_key` 的形式：凭证是 `<credential_kind>:<id>`（`api_token`、`connector`、`user`、`internal`），数据流是 `<stream_type>:<name>`，服务是服务名；没有标注服务的事件是空字符串，超出上限的服务是 `*`。

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/usage?dimension=credential&window_secs=86400" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

## 单个来源

```http
GET /api/v1/streams/usage/detail
```

返回单个来源在这段时间内的合计、按桶聚合的小时数据，以及它在另外两个维度上的拆分，每个维度最多 20 个来源。

| 参数 | 默认值 | 说明 |
|---|---|---|
| `dimension` | 必填 | `credential`、`stream` 或 `service`。 |
| `source_key` | 必填 | 来源，取值同 `GET /api/v1/streams/usage` 返回的。 |
| `window_secs` | 86400 | 范围 3600 到 2678400。 |
| `bucket_count` | 24 | 桶数，范围 6 到 48。 |
