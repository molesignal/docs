---
title: "配置字段索引"
description: "选择数据流中每个字段的索引。"
"en_link": "/en-US/api/streams/edit-schema"
---

```http
PUT /api/v1/streams/{id}/settings
```

数据流的 schema 会随新字段通过接入到达而演进，API 不会替换字段类型。使用该端点为已经在 schema 中的字段选择索引类型。该调用需要 `streams.configure`，`_audit` 数据流还需要 `audit.read`。同一个端点也用于编辑保留期与设置，参见[编辑保留期与设置](/zh-Hans/api/streams/edit-retention)。

**请求体**

| 字段 | 类型 | 说明 |
|---|---|---|
| `fields` | array | 每个需要配置的字段一项。 |

`fields` 中的每一项：

| 属性 | 类型 | 说明 |
|---|---|---|
| `name` | string | 已经在 schema 中的字段。 |
| `indexed` | boolean | 启用索引。 |
| `indexType` | string | `none`、`exact`、`full_text`、`bloom`、`skip`、`ngram`、`ip` 或 `key_value`，参见[数据流](/zh-Hans/streams#schema-与字段)。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexed": true, "indexType": "exact" },
      { "name": "msg", "indexed": true, "indexType": "full_text" }
    ]
  }'
```
</RequestExample>

响应是更新后的数据流，结构与[获取数据流](/zh-Hans/api/streams/get)中展示的相同。变更立即作用于之后写入的数据，之前写入的数据由后台按新设置补建索引，参见[数据流](/zh-Hans/streams#schema-与字段)。`full_text`、`ngram` 与 `ip` 索引只限 `utf8` 字段，`key_value` 只限 `json` 字段。
