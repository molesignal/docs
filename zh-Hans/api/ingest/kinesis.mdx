---
title: "Kinesis Firehose"
description: "AWS Kinesis Firehose HTTP 投递。"
---

```http
POST /api/v1/_kinesis_firehose
```

接受 AWS Data Firehose JSON 投递请求。每条记录的 base64 `data` 解码后按行切分，每个非空行成为
一条日志事件，并写入 connector 的 `target_stream`（默认 `kinesis`）。JSON 对象展开为字段，
纯文本写入 `message`。响应会回显 `requestId` 并包含毫秒时间戳，符合 Firehose ACK 契约。

该端点使用已启用的 Kinesis push connector 认证，而非 Bearer Token。通过
`X-Amz-Firehose-Access-Key` 发送 connector Token；也支持 `X-Connector-Token` 和
`?token=...`。
