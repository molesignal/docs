---
title: "配置服务限额"
description: "了解部署限流与不可变许可证限额。"
---

当前 API 不提供 `PUT /api/v1/orgs/{id}/quota`。

请在部署配置中设置请求限流：

```toml
[router.rate_limit]
ingest_qps = 1000
query_qps = 100
burst_multiplier = 2
```

签名许可证还可以包含 `max_ingest_bytes_per_day`。许可证版本不可修改：请上传并激活新的签名版本，而不是通过组织端点编辑限额。

```http
POST /api/v1/system/license/versions
POST /api/v1/system/license/versions/{id}/activate
```

这些系统操作需要 `sys.licenses.manage`。
