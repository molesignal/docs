| 端点 | 身份验证 |
|---|---|
| `GET /api/v1/healthz` | 无 |
| `GET /metrics` | 无 |
| `GET /api/v1/readyz` | Bearer Token |
| `GET /api/v1/version` | Bearer Token |

## 存活

```http
GET /api/v1/healthz
```

综合健康探针。节点健康时返回 `200`；WAL 重放期间或对象存储不可达时返回 `503`，并附带 `reason`。容器与负载均衡器探针使用它。

<ResponseExample>
```json 200
{ "status": "ok" }
```
</ResponseExample>

## 就绪

```http
GET /api/v1/readyz
Authorization: Bearer <token>
```

流量就绪探针。仅在 WAL 重放期间返回 `503`，对象存储降级不会让只读流量变为未就绪。该请求需要 Bearer Token，不带凭据的探针会收到 `401`。探针无法携带 Token 时，请改为探测 `/api/v1/healthz`。

<ResponseExample>
```json 200
{ "status": "ready" }
```
</ResponseExample>

## 版本

```http
GET /api/v1/version
Authorization: Bearer <token>
```

返回产品版本、commit 与分支、构建时间、构建 id、发布通道与版本类型。

<ResponseExample>
```json 200
{
  "version": "26.1.0.0",
  "commit": "<git-sha>",
  "branch": "main",
  "build_epoch_secs": 1790000000,
  "build_id": "<build-id>",
  "release_channel": "alpha",
  "edition": "oss"
}
```
</ResponseExample>

## 指标

```http
GET /metrics
```

Prometheus exposition（`text/plain; version=0.0.4`），包含进程与各子系统指标，例如 `cache_*` 命中率、`wal_*`、`object_store_*` 与 `storage_reconciler_issues_total`。请在代理或网络层限制该路由，参见[自身可观测性](/zh-Hans/self-observability)。
