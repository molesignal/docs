title: "审计日志"
description: "查询敏感操作的审计轨迹。"
"en_link": "/en-US/api/admin/audit"
---

```http
GET /api/v1/audit
```

按时间倒序返回组织的审计事件，使用游标分页。该调用需要 `audit.read`。

审计轨迹记录敏感的生命周期操作，并不记录每一项变更。当前版本的操作名称以下列前缀开头：

| 前缀 | 操作 |
|---|---|
| `agent.` | Mole Agent 的模型服务商、提示词、工具与工具调用、MCP 服务、审批、对话、调查和执行。 |
| `iam.` | 角色绑定、关系和跨组织授权。 |
| `resource_share.` | 创建、轮换、撤销和打开分享链接，以及密码失败。 |
| `status_page.` | 状态页、组件、自动化规则和 Logo。 |
| `synthetic.` | 拨测的探测点、探测器和探测器 Token。 |
| `schedule.` | 值班排班及其临时覆盖。 |
| `trace_debug_token.` | 使用链路调试 Token。 |
| `dashboard.` | 由 AI 草稿创建的仪表盘。 |

数据流、告警规则、事件和连接器的变更不会被记录。

**查询参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `from`、`to` | string | 时间窗口。取值为 epoch 微秒值，或相对值：`now`，以及 `now-<N><单位>`（单位为 `s`、`m`、`h` 或 `d`），例如 `now-30m`。 |
| `actor_kind` | string | 主体类型，例如 `user`。 |
| `actor` | string | 主体标识符。 |
| `action` | string | 精确的操作名称，例如 `agent.model_provider.created`。 |
| `target_kind`、`target_id` | string | 目标的类型与标识符。 |
| `limit` | integer | 页大小。默认 `50`。取值限制在 1 到 200 之间。 |
| `cursor` | string | 上一页返回的 `next_cursor`，其值不透明。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/audit?from=now-7d&action=agent.model_provider.created&limit=20" \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

**响应**

| 字段 | 说明 |
|---|---|
| `items[].actor_kind`、`items[].actor_id` | 做出变更的主体。 |
| `items[].action` | 操作名称，例如 `iam.role_binding.create`。 |
| `items[].target_kind`、`items[].target_id` | 受影响的对象。两者都可能为 `null`。 |
| `items[].ip`、`items[].user_agent` | 操作记录了客户端地址与客户端标识时的值，两者都可能为 `null`。 |
| `items[].payload` | 操作详情。负载不包含密钥、提示词正文和工具结果。 |
| `items[].ts_micros` | 事件时间，单位为微秒。 |
| `next_cursor` | 下一页的游标，最后一页为 `null`。 |

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | `from` 或 `to` 既不是数字，也不是有效的相对值（`unparseable time: yesterday`、`bad time unit in: now-3x`），或 `cursor` 无效。 |
| `403` | Token 缺少 `audit.read`。 |

## 相关审计路由

| 端点 | 权限 | 用途 |
|---|---|---|
| `GET /api/v1/system/audit` | `sys.telemetry.read`，系统范围 | 对系统组织的审计事件执行相同的查询。这些事件涵盖启用或停用组织、修改链路策略等操作。 |
| `GET /api/v1/agent/audit/chat/{id}` | `audit.read` | Mole Agent 对话的完整记录：`chat` 记录及其 `messages`，包含提示词哈希、Token 数量和证据。对话不存在时返回 `404`。 |

<Warning>
  对话记录包含用户的提问和模型的回答。只把 `audit.read` 授予有权阅读这些内容的账号。
</Warning>
