## 授权模型

端点可以要求：

- `streams.query` 或 `alerts.rules.manage` 等组织权限；
- `sys.telemetry.read` 等平台权限；
- 资源级所有权或关系/授权；
- 仅能访问一个资源的公开共享会话。

不要根据展示角色推断授权。请查询 `/api/v1/iam/capabilities` 获取实际生效的权限与功能快照。

## 选择并验证请求

先打开对应家族的指南，确认 HTTP 方法、所需权限、组织范围、请求字段与响应格式。同一个家族可能同时包含管理请求和数据查询，两者需要的权限可能不同。

修改配置前，使用文档中的读取请求确认目标组织和资源。写入后，重新读取资源或查询一条受控测试事件，确认实际结果。HTTP 成功不代表遥测已经进入预期数据流，也不代表事件已经恢复。

遇到错误时，参照 [API 入门](/zh-Hans/api-reference)和具体端点的说明。[反馈文档不一致](/zh-Hans/support)时，附上运行版本、脱敏后的请求与请求标识，不要附带凭据或敏感事件数据。
