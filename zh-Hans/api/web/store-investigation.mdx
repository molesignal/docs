---
title: "存储调查栈"
description: "用一个简短的标识符保存调查的状态。"
---

```http
POST /api/v1/web/investigation/blob
```

把一份 JSON 文档存入对象存储，并返回标识符。网页界面用该调用把大型调查的调查栈移出页面 URL，URL 中只保留标识符。读取文档请使用[拉取调查栈](/zh-Hans/api/web/fetch-investigation)。该调用需要 `streams.query`，系统范围可使用 `sys.telemetry.read`。

请求体可以是任意不超过 1 MiB（1,048,576 字节）的 JSON 值。文档归调用者所在的组织所有，compactor 会在 7 天后将其清理。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/investigation/blob \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "version": 1,
    "stack": [
      { "kind": "trace", "trace_id": "0af7651916cd43dd8448eb211c80319c" },
      { "kind": "log", "query": "level = error" }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "blob_id": "3KEZAC5JXc0P0HjrTdARfCgH1Y3"
}
```
</ResponseExample>

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | 请求体不是有效的 JSON（纯文本），或文档超过 1 MiB（`payload exceeds 1048576 bytes`）。 |
| `403` | Token 缺少 `streams.query`。 |
