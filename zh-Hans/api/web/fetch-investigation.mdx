---
title: "拉取调查栈"
description: "读取通过调查 blob 调用保存的文档。"
---

```http
GET /api/v1/web/investigation/blob/{id}
```

返回[存储调查栈](/zh-Hans/api/web/store-investigation)以 `blob_id` 保存的 JSON 文档。查询仅限调用者所在的组织，因此其他组织的标识符会返回 `404`。该调用需要 `streams.query`，系统范围可使用 `sys.telemetry.read`。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/web/investigation/blob/$BLOB_ID \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "version": 1,
  "stack": [
    { "kind": "trace", "trace_id": "0af7651916cd43dd8448eb211c80319c" },
    { "kind": "log", "query": "level = error" }
  ]
}
```
</ResponseExample>

响应是原样保存的文档。已被 compactor 在 7 天后清理的文档同样返回 `404`。

**错误**

| 状态码 | 原因 |
|---|---|
| `403` | Token 缺少 `streams.query`。 |
| `404` | 标识符未知、属于其他组织，或已过期。 |
