---
title: "服务图边"
description: "读取某个时间窗口内的原始服务图边。"
---

```http
GET /api/v1/traces/service_graph
```

返回[服务拓扑](/zh-Hans/api/web/topology)所聚合的原始服务图边。每条边统计一个一分钟时间桶内从客户端服务到服务端服务的调用。该调用需要 `streams.query`，系统范围可使用 `sys.telemetry.read`。

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `from` | integer | 是 | 窗口起点，自 Unix 纪元起的微秒数。 |
| `to` | integer | 是 | 窗口终点，单位为微秒。 |
| `service` | string | 否 | 只保留以该服务作为客户端或服务端的边。 |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000
curl "http://localhost:5080/api/v1/traces/service_graph?from=$((NOW-3600000000))&to=$NOW&service=checkout" \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "edges": [
    {
      "id": "3KBCiQWW0TtpDu7D4pH7LMtZsRh",
      "org_id": "<organization-id>",
      "client_service": "frontend",
      "server_service": "checkout",
      "bucket_at_micros": 1790000000000000,
      "request_count": 12,
      "error_count": 1,
      "p50_us": 90000,
      "p95_us": 210000,
      "p99_us": 240000
    }
  ],
  "count": 1
}
```
</ResponseExample>

**响应**

| 字段 | 说明 |
|---|---|
| `edges[].client_service`、`edges[].server_service` | 发起调用的服务与被调用的服务。 |
| `edges[].bucket_at_micros` | 一分钟时间桶的起点，单位为微秒。 |
| `edges[].request_count`、`edges[].error_count` | 时间桶内的调用数与失败调用数。 |
| `edges[].p50_us`、`edges[].p95_us`、`edges[].p99_us` | 时间桶的延迟百分位，单位为微秒。百分位可能为 `null`。 |
| `count` | 返回的边数量。 |

窗口内没有匹配的边时返回 `{"edges": [], "count": 0}`，`to` 早于 `from` 时也一样。

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | `from` 或 `to` 缺失或不是整数。响应为纯文本。 |
| `403` | Token 缺少 `streams.query`。 |
