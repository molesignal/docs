---
title: "命令面板搜索"
description: "按名称搜索数据流、仪表盘、已保存视图、规则、事件和服务。"
---

```http
GET /api/v1/web/search
```

为 **⌘K** 命令面板提供搜索。该调用对组织内六类实体做名称模糊匹配，并把最佳匹配排在前面。调用需要 `streams.query`，系统范围可使用 `sys.telemetry.read`。

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `q` | string | 是 | 搜索文本，最长 256 个字符。匹配使用 PostgreSQL 的 trigram 相似度，因此很短的文本（例如一个字母）很少能匹配到结果。`q` 为空时返回空列表。 |
| `types` | string | 否 | `stream`、`dashboard`、`saved_view`、`alert`、`incident` 和 `service` 的逗号分隔子集。省略则搜索所有类型。未知的值不匹配任何内容。 |
| `limit` | integer | 否 | 默认 `20`。取值限制在 1 到 50 之间。 |

`q` 只包含空格并与 `types=stream` 一起使用时，不做搜索，而是按字母顺序列出数据流。

每条命中用以下字段描述实体：

| `kind` | `id` | `label` | `subtitle` |
|---|---|---|---|
| `stream` | 数据流标识符 | 数据流名称 | 内部形式的数据流类型，例如 `builtin.logs`。 |
| `dashboard` | 仪表盘标识符 | 标题 | 仪表盘 `uid`。 |
| `saved_view` | 已保存视图标识符 | 名称 | 查询语言。 |
| `alert` | 规则标识符 | 规则名称 | `enabled` 或 `disabled`。 |
| `incident` | 事件标识符 | 事件指纹 | 事件状态。 |
| `service` | 边标识符 | 服务图中的服务名称 | 无。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/search?q=app&types=stream&limit=5" \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "items": [
    { "kind": "stream", "id": "3KDXoznFWyKPsch4ETi37U3GdxM", "label": "app", "subtitle": "builtin.logs" },
    { "kind": "stream", "id": "3JtcZGko1Q5czEBK9nBJjiFxpo1", "label": "app_logs", "subtitle": "builtin.logs" }
  ]
}
```
</ResponseExample>

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | 缺少 `q`（纯文本），或 `q` 超过 256 个字符（`invalid_argument`）。 |
| `403` | Token 缺少 `streams.query`。 |
