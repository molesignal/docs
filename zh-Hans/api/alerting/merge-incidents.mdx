---
title: "合并事件"
description: "把其他进行中的事件并入一个主事件。"
"en_link": "/en-US/api/alerting/merge-incidents"
---

```http
POST /api/v1/alerts/incidents/{id}/merge
```

把 `source_ids` 里的事件并入事件 `{id}`。并入的事件在 `merged_into` 里记下主事件，此后不再发通知、不再升级，也不再出现在[列出事件](/zh-Hans/api/alerting/list-incidents)和洞察里；它仍算进行中，所以它的规则或来源不会为它再开新事件。主事件解决时，并入的事件一并解决；并入的事件先自行恢复时，主事件的[时间线](/zh-Hans/api/alerting/incident-timeline)记一笔。先前并入被并入事件的事件，一起改挂到主事件下。合并不能撤销。

主事件和每个并入的事件都要是进行中、且没有并入别处的。`source_ids` 里主事件自己的 ID 和重复的 ID 会被忽略。该调用需要对主事件的 `alerts.incidents.escalate`。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `source_ids` | array | 是 | 要并入的 1 到 50 个事件 ID。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/merge \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"source_ids": ["<incident-id>", "<another-incident-id>"]}'
```
</RequestExample>

响应是主事件，各字段说明见[列出事件](/zh-Hans/api/alerting/list-incidents)。

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | `source_ids` 里没有别的事件，或超过 50 个。 |
| `403` | Token 缺少 `alerts.incidents.escalate`，或无权访问这个事件。 |
| `404` | 主事件或 `source_ids` 里的某个事件不存在。 |
| `409` | 主事件或 `source_ids` 里的某个事件已恢复或已并入别处，或者更新时事件一直在变；重试即可。 |
