---
title: "删除路由规则"
description: "删除一条告警路由规则。"
"en_link": "/en-US/api/alerting/delete-routing-rule"
---

```http
DELETE /api/v1/alerts/routing/rules/{id}
```

删除一条[路由规则](/zh-Hans/alerting/routing#路由规则)，需要 `alerts.routing.manage`。原本命中它的新事件改按后面的规则分派；已经开启的事件保留开启时的分派，事件上记下的规则名称也不变。

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/routing/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "deleted": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1" }
```
</ResponseExample>

**错误**

| 状态码 | 原因 |
|---|---|
| `403` | Token 缺少 `alerts.routing.manage`。 |
| `404` | 规则不存在，或属于其他组织。 |
