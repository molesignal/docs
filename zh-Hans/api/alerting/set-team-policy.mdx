title: "设置团队的值班策略"
description: "为团队设置或去掉值班策略。"
"en_link": "/en-US/api/alerting/set-team-policy"
---

```http
PUT /api/v1/alerts/routing/teams/{team_id}
```

设置或去掉一个团队的[值班策略](/zh-Hans/alerting/routing#团队的值班策略)，需要 `alerts.routing.manage`。分派给这个团队的新事件按它升级；去掉后用默认策略。

| 字段 | 类型 | 说明 |
|---|---|---|
| `escalation_policy_id` | string \| null | 本组织的升级策略 ID；`null` 或不带时去掉团队的值班策略。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/teams/$TEAM_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"escalation_policy_id": "<policy-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "team_id": "<team-id>", "escalation_policy_id": "<policy-id>" }
```
</ResponseExample>

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | 团队不存在或属于其他组织，或升级策略不存在。 |
| `403` | Token 缺少 `alerts.routing.manage`。 |
| `422` | 带了别的字段。响应为纯文本。 |
