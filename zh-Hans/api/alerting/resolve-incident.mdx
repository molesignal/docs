---
title: "解决事件"
description: "把事件标记为已解决。"
---

```http
POST /api/v1/alerts/incidents/{id}/resolve
```

解决一个处于 `open` 或 `acknowledged` 状态的事件。调用会把状态设为 `resolved`，在 `resolved_by` 与 `resolved_at` 中记录调用用户与时间，并停止升级。调用还会把触发通知标记为已确认，并发送 `alert.resolved` 事件。该调用需要 `alerts.acknowledge`，请求体为空。

仍然命中的规则会在下一次评估时开启新的事件。解决事件不会停用规则。

<Note>
  解决一个已经是 `resolved` 或 `closed` 的事件会原样返回它。`resolved_by` 与 `resolved_at` 保留第一次的用户与时间，也不会再次发送事件。
</Note>

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/resolve \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

响应是更新后的事件，各字段说明见[列出事件](/zh-Hans/api/alerting/list-incidents)。

**错误**

| 状态码 | 原因 |
|---|---|
| `403` | Token 缺少 `alerts.acknowledge`。 |
| `404` | 事件不存在。 |
