---
title: "轮换来源 Token"
description: "给告警来源换一个新 Token，旧的立即失效。"
"en_link": "/en-US/api/alerting/rotate-source-token"
---

```http
POST /api/v1/alerts/sources/{id}/token
```

给一个[告警来源](/zh-Hans/alerting/sources)换一个新 Token，需要 `alerts.sources.manage`，请求体为空。旧 Token 立即失效；开了联邦时，其他集群同步到以后失效。还在用旧 Token 的发送方要换上新的。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/token \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

响应是来源加上新的 `token`，`token` 只出现这一次。

**错误**

| 状态码 | 原因 |
|---|---|
| `403` | Token 缺少 `alerts.sources.manage`。 |
| `404` | 来源不存在。 |
