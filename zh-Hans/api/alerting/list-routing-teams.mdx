---
title: "列出团队的值班策略"
description: "列出组织的团队、它们的值班策略和负责的服务。"
"en_link": "/en-US/api/alerting/list-routing-teams"
---

```http
GET /api/v1/alerts/routing/teams
```

按团队名（不区分大小写）列出组织的团队，以及每个团队的[值班策略](/zh-Hans/alerting/routing#团队的值班策略)和在 APM 服务目录中负责的服务，需要 `alerts.routing.read`。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/teams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "team_id": "<team-id>",
    "name": "Payments",
    "member_count": 4,
    "escalation_policy_id": "<policy-id>",
    "services": ["default/checkout", "default/cart"]
  }
]
```
</ResponseExample>

| 字段 | 说明 |
|---|---|
| `team_id`、`name` | 团队的 ID 和名称。 |
| `member_count` | 团队的成员数。 |
| `escalation_policy_id` | 团队的值班策略；`null` 表示没设，分派给这个团队的事件用默认策略。 |
| `services` | 服务目录中登记给这个团队、没有归档的服务，写成 `命名空间/服务名`。 |
