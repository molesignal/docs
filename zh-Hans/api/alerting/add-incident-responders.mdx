---

```http
POST /api/v1/alerts/incidents/{id}/responders
```

把 `user_ids` 里的人加进进行中事件的负责人，并给新加入的每个人发一条升级通知，`escalation.reason` 是 `responder_added`。事件状态不变，已经是负责人的不会再收到通知。该调用需要 `alerts.incidents.update`。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `user_ids` | array | 是 | 1 到 10 个组织成员的用户 ID。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/responders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"user_ids": ["<another-user-id>"]}'
```
</RequestExample>

响应是更新后的事件，各字段说明见[列出事件](/zh-Hans/api/alerting/list-incidents)。

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | `user_ids` 为空、超过 10 个或含有组织外的用户。 |
| `403` | Token 缺少 `alerts.incidents.update`，或无权访问这个事件。 |
| `404` | 事件不存在。 |
| `409` | 事件已恢复或已并入别的事件，或者更新时事件一直在变；重试即可。 |
