---
title: "更新规则"
description: "替换告警规则的配置。"
---

```http
PUT /api/v1/alerts/rules/{id}
```

替换规则的配置。请求体是[创建规则](/zh-Hans/api/alerting/create-rule)的完整请求体。调用会保留规则的 `id`、组织、`created_at`、`last_eval_at` 与 `last_state`。修改后的 `escalation_policy_id` 必须是该组织的某个策略，或者是 `default`。该调用需要 `alerts.manage`。

<Warning>
  该调用替换整条规则，不会合并字段。省略的字段回落为默认值，包括变为 `true` 的 `enabled` 和变为
  `scheduled` 的 `kind`。省略的 `labels`、`annotations` 与 `thresholds` 变为空。只有省略
  `escalation_policy_id` 时会保留当前策略。请先读取规则，再把完整请求体连同修改一起发送。
</Warning>

事件的指纹由规则 `id` 与规则 `labels` 派生。修改 `labels` 后，已开启的事件保留旧指纹，不再自动解决。请通过[解决事件](/zh-Hans/api/alerting/resolve-incident)手动解决。

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  --data-binary @- <<'EOF'
{
  "name": "High error rate",
  "description": "More than 200 errors in five minutes",
  "enabled": true,
  "kind": "scheduled",
  "query": {
    "language": "sql",
    "statement": "SELECT count(*) AS c FROM app WHERE level = 'error'",
    "period_secs": 300,
    "stream": { "name": "app", "stream_type": "logs" }
  },
  "trigger": { "operator": "gt", "threshold": 200, "for_periods": 2, "silence_secs": 0 },
  "severity": "critical",
  "labels": { "team": "checkout" }
}
EOF
```
</RequestExample>

响应是更新后的规则，格式见[列出规则](/zh-Hans/api/alerting/list-rules)。

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | 请求体未通过与[创建规则](/zh-Hans/api/alerting/create-rule)相同的检查，或者修改后的 `escalation_policy_id` 不属于该组织的任何策略。 |
| `404` | 规则不存在。 |
| `422` | 必填字段缺失或取值类型错误，响应为纯文本。 |
