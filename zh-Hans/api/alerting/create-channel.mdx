---
title: "创建通知渠道"
description: "Slack、webhook 或 email 渠道。"
---

```http
POST /api/v1/alerts/channels
```

渠道通过 Slack、webhook 或 email 发送，也可关联通知模板。创建需要 `alerts.manage`。

```json
{
  "name": "Operations Slack",
  "kind": {
    "type": "slack",
    "webhook_url": "https://hooks.slack.com/services/...",
    "channel": "#operations",
    "mentions": []
  },
  "enabled": true,
  "template_id": null
}
```

通用 webhook 还支持 `post`、`put` 或 `patch`、供应商适配负载、引用 secret 的 header，以及
Lark/Feishu 或 DingTalk 签名。
