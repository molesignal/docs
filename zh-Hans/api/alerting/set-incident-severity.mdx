---
title: "设置事件严重度"
description: "手动修改事件的严重度。"
"en_link": "/en-US/api/alerting/set-incident-severity"
---

```http
PUT /api/v1/alerts/incidents/{id}/severity
```

设置进行中事件的严重度，并把调用者记在 `severity_set_by`；此后规则评估不再改它。调高 `open` 事件的严重度时，从适用于新严重度的第一级重新开始升级，`escalation.reason` 是 `severity_raised`；调低，或修改已确认的事件，只改严重度。该调用需要 `alerts.incidents.update`。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `severity` | string | 是 | `info`、`warning`、`error` 或 `critical`。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/severity \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"severity": "critical"}'
```
</RequestExample>

响应是更新后的事件，各字段说明见[列出事件](/zh-Hans/api/alerting/list-incidents)。

**错误**

| 状态码 | 原因 |
|---|---|
| `422` | 缺少 `severity`，或不是这四个值之一。 |
| `403` | Token 缺少 `alerts.incidents.update`，或无权访问这个事件。 |
| `404` | 事件不存在。 |
| `409` | 事件已恢复或已并入别的事件，或者更新时事件一直在变；重试即可。 |
