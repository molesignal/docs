---
title: "列出规则"
description: "列出组织内的告警规则，或读取单条规则。"
"en_link": "/en-US/api/alerting/list-rules"
---

```http
GET /api/v1/alerts/rules
GET /api/v1/alerts/rules/{id}
```

第一个调用以数组形式返回组织内的所有告警规则，第二个调用返回单条规则。两个调用都需要 `alerts.read`。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/rules \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KEDBLvTYO6DnWi8H9S9MNLpPT7",
    "org_id": "<organization-id>",
    "name": "High error rate",
    "description": "More than 100 errors in five minutes",
    "enabled": true,
    "kind": "scheduled",
    "query": {
      "language": "sql",
      "statement": "SELECT count(*) AS c FROM app WHERE level = 'error'",
      "period_secs": 300,
      "stream": { "name": "app", "stream_type": "logs" }
    },
    "trigger": { "operator": "gt", "threshold": 100.0, "for_periods": 2, "silence_secs": 0 },
    "anomaly_params": null,
    "thresholds": [],
    "severity": "critical",
    "escalation_policy_id": "default",
    "labels": { "team": "checkout" },
    "annotations": {},
    "last_eval_at": null,
    "last_state": { "kind": "healthy" },
    "created_at": 1790000000000000,
    "updated_at": 1790000000000000
  }
]
```
</ResponseExample>

规则包含[创建规则](/zh-Hans/api/alerting/create-rule)的字段，以及以下只读字段：

| 字段 | 说明 |
|---|---|
| `id`、`org_id` | 规则与组织的标识符。 |
| `created_at`、`updated_at` | 自 Unix 纪元起的微秒数。 |
| `last_eval_at` | 最近一次完成评估的时间，单位为微秒。第一次评估之前为 `null`。查询失败或超时时保持不变。 |
| `last_state` | 那次评估的结果：条件未命中时为 `{"kind": "healthy"}`，命中但不足 `for_periods` 次时为 `{"kind": "pending", "consecutive": 1}`，命中足够久之后为 `{"kind": "firing"}`。处于 `silence_secs` 冷却期内的 `firing` 规则不会开启新事件。 |

`id` 不存在时返回 `404`。
