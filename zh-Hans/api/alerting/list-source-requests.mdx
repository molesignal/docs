---
title: "来源最近收到的请求"
description: "读取告警来源最近收到的请求，以及每条告警被怎么处理了。"
"en_link": "/en-US/api/alerting/list-source-requests"
---

```http
GET /api/v1/alerts/sources/{id}/requests
```

按时间倒序返回一个[告警来源](/zh-Hans/alerting/sources)最近收到的请求，需要 `alerts.sources.read`。每个来源保留最近 500 次请求，最长 7 天；记在处理请求的集群上。

**查询参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `limit` | integer | 最多返回几条，1 到 200，默认 50。 |

| 字段 | 说明 |
|---|---|
| `receivedAt` | 收到的时间（微秒）。 |
| `viaCluster` | 转来它的联邦集群；本集群直接收到的为空。 |
| `status` | `accepted`（已处理）、`rejected`（已拒收）或 `forwarded`（已转给接收集群）。 |
| `httpStatus` | 回给发送方的状态码。 |
| `message` | 为什么被拒，或为什么什么都没做。 |
| `alertCount` | 请求里一共几条告警。 |
| `alerts` | 每条告警的动作、去重键、标题、严重度、结果（见[接入外部告警](/zh-Hans/api/alerting/send-alerts)）、原因和事件 ID，最多 100 条。 |
| `bodyExcerpt` | 被拒收的请求体开头，最多 16 KiB。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/requests?limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>
