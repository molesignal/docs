```http
DELETE /api/v1/alerts/rules/{id}
```

删除一条规则。该调用需要 `alerts.rules.delete`。规则已经开启的事件仍可读取，并保持各自的生命周期，已删除的规则不再解决这些事件。

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>

响应体是纯文本 `deleted`。`id` 不存在时返回 `404`。
