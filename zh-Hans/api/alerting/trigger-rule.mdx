title: "触发规则"

```http
POST /api/v1/alerts/rules/{id}/trigger
```

不评估条件，直接为规则开启一个事件。该调用适合演练通知与升级，或手动提出事件。已停用的规则也可以使用。调用需要 `alerts.manage`，请求体为空。

- 规则已有处于 `open` 或 `acknowledged` 状态的事件时，调用原样返回该事件。重复调用是安全的。
- 否则，调用创建状态为 `open` 的事件，并发送触发通知事件。
- 严重程度依次取规则的 `severity`、名为 `severity` 的标签，最后是 `warning`。调用忽略 `thresholds`。
- 注解 `manual_triggered_by` 保存调用用户的标识符，`triggering_query.sample_values` 为空。

已启用的规则在下一次评估时，如果条件未命中，会解决该事件。已停用的规则会让事件保持开启，直到用户将其解决。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/rules/$RULE_ID/trigger \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

**错误**

| 状态码 | 原因 |
|---|---|
| `403` | Token 缺少 `alerts.manage`。 |
| `404` | 规则不存在。 |
