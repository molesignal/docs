---
title: "登录"
description: "用邮箱和密码换取 JWT。"
---

```http
POST /api/v1/auth/login
```

用邮箱 + 密码换取 JWT。该路由**免认证**。

**请求体**

| 字段 | 类型 | 必填 |
|---|---|---|
| `email` | string | ✅ |
| `password` | string | ✅ |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/auth/login \
  -H 'content-type: application/json' \
  -d '{"email":"admin@example.com","password":"admin"}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "token": "eyJhbGciOi...",
  "user_id": "u_2abc...",
  "org_id": "o_2def...",
  "role": "owner"
}
```
</ResponseExample>
