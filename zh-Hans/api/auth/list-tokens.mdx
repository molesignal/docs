---
title: "列出 API token"
description: "列出 API token 元数据（不含 secret）。"
---

```http
GET /api/v1/auth/tokens
```

返回组织内每个 API token 的元数据。明文 token 与 secret hash 永不返回。列出 token 需要
`api_tokens.read`。

<ResponseExample>
```json 200
[
  {
    "id": "<token-id>",
    "prefix": "a1b2c3",
    "name": "collector-production",
    "role_id": "<organization-role-id>",
    "role_key": "viewer",
    "role_name": "Viewer",
    "expires_at_micros": 1735689600000000,
    "last_used_at_micros": 1700000000000000,
    "revoked": false,
    "created_at_micros": 1690000000000000
  }
]
```
</ResponseExample>
