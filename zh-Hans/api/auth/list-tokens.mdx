---
title: "列出 API Token"
description: "列出组织中每个 API Token 的元数据。"
---

```http
GET /api/v1/auth/tokens
```

返回当前组织中每个 API Token 的元数据，包括默认接入 Token、RUM Client Token 与服务账号的 Token。明文 Token 与 Secret 哈希永远不会返回。该调用需要 `api_tokens.read`。

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "l2XcQd8UoQzK3pLm",
    "name": "grafana-readonly",
    "role_id": "<viewer-role-id>",
    "role_key": "viewer",
    "role_name": "Viewer",
    "token_kind": "personal",
    "application_id": null,
    "service_account_id": null,
    "expires_at_micros": 1798000000000000,
    "last_used_at_micros": null,
    "revoked": false,
    "created_at_micros": 1790000000000000
  }
]
```
</ResponseExample>

| 字段 | 说明 |
|---|---|
| `token_kind` | `personal`、`service_account`、`default_intake` 或 `rum_client`。 |
| `application_id` | `rum_client` Token 绑定的应用，其他情况为 `null`。 |
| `service_account_id` | Token 所属的服务账号，其他情况为 `null`。 |
| `expires_at_micros` | 永不过期的 Token 为 `null`。 |
| `last_used_at_micros` | 首次使用之前为 `null`。 |
| `revoked` | Token 被撤销后为 `true`。 |
