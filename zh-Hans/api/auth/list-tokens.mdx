---
title: "列出 API Token"
description: "列出组织中每个 API Token 的元数据，或只列出你自己的。"
"en_link": "/en-US/api/auth/list-tokens"
---

```http
GET /api/v1/auth/tokens
```

返回当前组织中每个 API Token 的元数据，包括默认接入 Token、RUM 客户端 Token 与服务账号的 Token。明文 Token 与 Secret 哈希永远不会返回。该调用需要 `api_tokens.read`。

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "l2XcQd8UoQzK3pLm",
    "name": "grafana-readonly",
    "token_kind": "personal",
    "user_id": "<user-id>",
    "policy_id": null,
    "permissions": ["dashboards.read", "streams.query", "streams.read"],
    "application_id": null,
    "service_account_id": null,
    "expires_at_micros": 1798000000000000,
    "last_used_at_micros": null,
    "revoked": false,
    "created_at_micros": 1790000000000000
  }
]
```
</ResponseExample>

| 字段 | 说明 |
|---|---|
| `token_kind` | `personal`、`service_account`、`default_intake` 或 `rum_client`。 |
| `user_id` | 签发 Token 的用户。个人 Token 与默认接入 Token 以该用户的身份执行。 |
| `policy_id` | Token 跟随的权限策略，其他情况为 `null`。 |
| `permissions` | 为 Token 固定的权限，其他情况为 `null`。策略也为空时，Token 能做它所代表的用户或服务账号能做的一切。 |
| `application_id` | `rum_client` Token 绑定的应用，其他情况为 `null`。 |
| `service_account_id` | Token 代表的服务账号，其他情况为 `null`。 |
| `expires_at_micros` | 永不过期的 Token 为 `null`。 |
| `last_used_at_micros` | 首次使用之前为 `null`。 |
| `revoked` | Token 被撤销后为 `true`。 |

## 你自己的 Token

```http
GET /api/v1/me/api-tokens
```

返回你的个人 Token 与默认接入 Token，字段相同。该调用必须来自登录会话，并且需要 `personal_tokens.manage`。
