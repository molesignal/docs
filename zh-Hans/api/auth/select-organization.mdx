```http
POST /api/v1/orgs/{id}/select
```

把已登录的浏览器会话切换到用户所属的另一个组织。响应为该组织重写会话 Cookie，会话结束时间不变，Cookie 参见[登录](/zh-Hans/api/auth/login)。只有会话可以切换，API Token 会收到 `403`。平台管理员可以选择受保护的 `_sys` 组织，[轮换 JWT 签名密钥](/zh-Hans/api/auth/rotate-jwt)这类平台级调用需要它。在 `_sys` 中的会话自进入起最长一小时。

**路径参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `id` | string | `GET /api/v1/orgs` 返回的组织 id。 |

<RequestExample>
```bash cURL
curl -b ms-cookies.txt -c ms-cookies.txt \
  -X POST http://localhost:5080/api/v1/orgs/<organization-id>/select
```
</RequestExample>

<ResponseExample>
```json 200
{
  "user_id": "<user-id>",
  "org_id": "<organization-id>",
  "org_name": "default",
  "display_role": "Owner",
  "roles": [
    { "id": "<role-id>", "key": "owner", "name": "Owner", "builtin": true }
  ],
  "system": false
}
```
</ResponseExample>

同一浏览器的标签页共用 Cookie，所有打开的标签页都会进入所选的组织。

## 登录要求

组织的[登录要求](/zh-Hans/identity/sso#登录要求)超出这次登录已有的条件时，仍返回 `200`，不写新的 Cookie，并说明还差什么：

| 回答 | 含义 |
|---|---|
| `{"mfa": {"organization_name", "methods"}}` | 当场验证一次第二因素：请求体带上 `{"proof": {…}}` 再请求一次。`proof` 是 `method`（`totp` 或 `recovery_code`）加 `code`，或者 `method` 为 `passkey` 加 `ceremony` 和 `credential`，后两者来自 `POST /api/v1/me/mfa/passkey-proof`。 |
| `{"mfa_setup": {"organization_name"}}` | 账号还没有第二因素。先通过 `/api/v1/me/mfa` 或 `/api/v1/me/passkeys` 开启。 |
| `{"sso": {"organization_name", "providers"}}` | 只能经这个组织的单点登录进入。`providers` 列出 `id`、`name`、`kind` 和 `platform`。 |
