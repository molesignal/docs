---
title: "撤销 API Token"
description: "按 id 撤销 API Token。"
---

```http
DELETE /api/v1/auth/tokens/{id}
```

立即撤销 Token。之后使用该 Token 的请求会失败，返回 `401` 与消息 `api token revoked`。该调用需要 `api_tokens.manage`。

**路径参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `id` | string | 签发或列出 Token 时返回的 `id`。 |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

未知的 id 返回 `404`。撤销正在发送数据的 Token 会让对应的发送端中断，请先在发送端替换 Token。
