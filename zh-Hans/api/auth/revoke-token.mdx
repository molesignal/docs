---
title: "撤销 API Token"
description: "按 id 撤销 API Token。"
"en_link": "/en-US/api/auth/revoke-token"
---

```http
DELETE /api/v1/auth/tokens/{id}
```

立即撤销组织中的任意 Token。之后使用该 Token 的请求会失败，返回 `401` 与消息 `api token revoked`。该调用需要 `api_tokens.revoke`。

**路径参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `id` | string | 签发或列出 Token 时返回的 `id`。 |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

未知的 id 返回 `404`。撤销正在发送数据的 Token 会让对应的发送端中断，请先在发送端替换 Token。

## 撤销自己的 Token

```http
DELETE /api/v1/me/api-tokens/{id}
```

撤销你的某个个人 Token 或你的默认接入 Token。该调用必须来自登录会话，并且需要 `personal_tokens.manage`。不属于你的 Token 返回 `404`。
