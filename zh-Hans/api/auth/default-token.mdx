---
title: "默认接入 Token"
description: "获取或创建发送端用来写入遥测数据的默认 Token。"
"en_link": "/en-US/api/auth/default-token"
---

```http
GET /api/v1/auth/tokens/default
```

返回已登录用户的默认接入 Token，首次调用时会创建它。与其他 Token 不同，每次调用都会返回明文，这让 **数据源** 页面可以直接展示一个开箱即用的 Token。该 Token 只有 `streams.write` 权限，永不过期，`token_kind` 为 `default_intake`。该调用需要 `api_tokens.manage`。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/auth/tokens/default \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3JtzUbBKtQCD7mFELKp2zDRum9f",
  "prefix": "QAi4CAoAAqY5izlY",
  "token": "ms_QAi4CAoAAqY5izlY_<secret>",
  "role_id": "<intake-role-id>",
  "role_key": "intake",
  "role_name": "Intake token",
  "token_kind": "default_intake",
  "application_id": null,
  "service_account_id": null,
  "expires_at_micros": null,
  "created_at_micros": 1790000000000000
}
```
</ResponseExample>

把它用于采集器、Agent 与 SDK 导出端，参见[数据源](/zh-Hans/intake#接入-token)。
