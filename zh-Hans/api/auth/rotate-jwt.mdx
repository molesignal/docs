---
title: "轮换 JWT 签名密钥"
description: "列出并轮换平台 JWT 签名密钥元数据。"
---

两个路由都需要具备 `sys.settings.manage` 的系统范围会话：

```http
GET  /api/v1/auth/jwt/secrets
POST /api/v1/auth/jwt/rotate
```

列表响应包含密钥 ID、是否为主密钥、创建时间与退役时间，永远不会返回原始密钥字节。

轮换会创建新的主密钥并退役旧主密钥，同时服务会保留轮换窗口所需的活动验证集合。只有部署策略要求时，才通过 TOML 外部的 `MS_AUTH_JWT_SECRET_OVERRIDE` 固定引导材料。
