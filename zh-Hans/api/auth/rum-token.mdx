---
title: "RUM 客户端 Token"
description: "获取或创建内嵌在浏览器与移动端代码中、与应用绑定的 Token。"
"en_link": "/en-US/api/auth/rum-token"
---

```http
GET /api/v1/auth/tokens/rum?application_id=<id>
```

返回某个 [RUM 应用](/zh-Hans/rum/applications)的 RUM 客户端 Token，首次调用时会创建它。应用必须已经存在，请先创建应用。Token 形如 `msrum_<prefix>_<secret>`，属于应用而不属于获取它的人：它只拥有针对该应用的 `rum.write` 权限，其他什么都做不了，永不过期。请把它内嵌在浏览器或移动端代码中，终端用户可以看到它。该调用需要 `api_tokens.issue`。

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `application_id` | string | 是 | 工作区中某个应用的标识符。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/auth/tokens/rum?application_id=checkout-web" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KDZpGNwn5vO9dhXyE3am4qhihX",
  "prefix": "dYrZbAh2UcL2HL7g",
  "token": "msrum_dYrZbAh2UcL2HL7g_<secret>",
  "token_kind": "rum_client",
  "policy_id": null,
  "permissions": ["rum.write"],
  "application_id": "checkout-web",
  "created_at_micros": 1790000000000000
}
```
</ResponseExample>

不是标识符的 `application_id` 返回 `400`，没有任何应用使用的 `application_id` 返回 `404`。请在 SDK 中把同一个标识用作 `applicationId`，参见 [RUM 应用](/zh-Hans/rum/applications#client-token)。
