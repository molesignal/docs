---
title: "RUM Client Token"
description: "获取或创建内嵌在浏览器与移动端代码中、与应用绑定的 Token。"
"en_link": "/en-US/api/auth/rum-token"
---

```http
GET /api/v1/auth/tokens/rum?application_id=<id>
```

返回某个应用的 RUM Client Token，首次调用时会创建它。Token 形如 `msrum_<prefix>_<secret>`，只拥有针对该应用的 `rum.write` 权限，永不过期。请把它内嵌在浏览器或移动端代码中，终端用户可以看到它。该调用需要 `api_tokens.manage`。

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `application_id` | string | 是 | 1 到 128 个字符，可使用 `A-Z`、`a-z`、`0-9`、`.`、`_`、`:` 与 `-`。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/auth/tokens/rum?application_id=checkout-web" \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KDZpGNwn5vO9dhXyE3am4qhihX",
  "prefix": "dYrZbAh2UcL2HL7g",
  "token": "msrum_dYrZbAh2UcL2HL7g_<secret>",
  "role_id": "<rum-client-role-id>",
  "role_key": "rum_client",
  "role_name": "RUM client",
  "token_kind": "rum_client",
  "application_id": "checkout-web",
  "service_account_id": null,
  "expires_at_micros": null,
  "created_at_micros": 1790000000000000
}
```
</ResponseExample>

无效的 `application_id` 返回 `400`。请在 SDK 中把同一个标识用作 `applicationId`，参见 [Browser RUM SDK](/zh-Hans/rum/browser-sdk#创建-client-token)。
