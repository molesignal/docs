```http
GET /api/v1/entities
GET /api/v1/entities/detail?kind={kind}&key={key}
```

实体每五分钟从 APM 看到的实例以及指标、日志的资源字段中读取；字段和键参见[基础设施](/zh-Hans/infrastructure)。两个调用都需要 `apm.services.read`、`metrics.read`、`logs.read` 或 `sys.telemetry.read` 之一。

## 列出实体

| 参数 | 说明 |
|---|---|
| `kind` | `cluster`、`node`、`host`、`pod` 或 `container`。不填表示全部类型。 |
| `search` | 名称或键的一部分，不区分大小写。 |
| `seenSince` | 只返回此时间之后出现过的实体，单位为微秒。 |
| `limit` | 最多 500，也是默认值。 |

实体按最后出现时间倒序返回。`services` 是直接运行在它上面的服务数。

<ResponseExample>
```json 200
[
  {
    "kind": "pod",
    "key": "prod-eu/shop/checkout-7d9f-abcde",
    "name": "checkout-7d9f-abcde",
    "attributes": {
      "k8s.cluster.name": "prod-eu",
      "k8s.namespace.name": "shop",
      "k8s.node.name": "node-3",
      "k8s.pod.name": "checkout-7d9f-abcde"
    },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000,
    "services": 1
  }
]
```
</ResponseExample>

## 读取单个实体

`kind` 和 `key` 必填，键取自列表。返回实体本身、它运行在或属于的实体（`parents`）、运行在或属于它的实体（`children`，最多 200 个），以及它上面和运行在它上面的实体上的服务（`services`，最多 200 个），向下查找三层：集群的节点、节点的 Pod、Pod 上的服务。

<ResponseExample>
```json 200
{
  "entity": {
    "kind": "node",
    "key": "prod-eu/node-3",
    "name": "node-3",
    "attributes": { "k8s.cluster.name": "prod-eu", "k8s.node.name": "node-3" },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000
  },
  "parents": [{ "kind": "cluster", "key": "prod-eu", "name": "prod-eu" }],
  "children": [{ "kind": "pod", "key": "prod-eu/shop/checkout-7d9f-abcde", "name": "checkout-7d9f-abcde" }],
  "services": [{ "namespace": "shop", "name": "checkout", "environment": "production" }]
}
```
</ResponseExample>

**错误**

| 状态码 | 原因 |
|---|---|
| `400` | `kind` 不是五种类型之一。 |
| `404` | 最近一周没有看到这个类型和键的实体。 |
