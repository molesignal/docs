---
title: "运行保存的视图"
description: "加载保存的视图并执行其中的查询。"
---

```http
GET  /api/v1/saved_views/{id}
POST /api/v1/query
```

保存的视图存放 `language`、`statement`、`stream` 以及相对的 `time_range_secs`。没有单独的运行端点，网页应用采用下面的两步流程，需要 `saved_views.read` 与 `streams.query`：

1. 用 `GET /api/v1/saved_views/{id}` 加载视图。
2. 计算一个以当前时间结束的绝对范围：`end` 是以微秒表示的当前时间，`start` 是 `end` 减去 `time_range_secs` 乘以 1,000,000。
3. 把保存的 `language` 与 `statement`、算出的 `time_range` 以及数据流发送给[执行查询](/zh-Hans/api/query/execute)。

<RequestExample>
```bash cURL
VIEW=$(curl -s http://localhost:5080/api/v1/saved_views/$VIEW_ID \
  -H "authorization: Bearer $MS_JWT")

END=$(date +%s)000000
START=$((END - $(echo "$VIEW" | jq .time_range_secs) * 1000000))

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d "{\"org_id\":\"$MS_ORG\",
       \"language\":$(echo "$VIEW" | jq .language),
       \"statement\":$(echo "$VIEW" | jq .statement),
       \"time_range\":{\"start\":$START,\"end\":$END},
       \"stream\":{\"name\":$(echo "$VIEW" | jq .stream),\"stream_type\":\"logs\"}}"
```
</RequestExample>

保存的视图只存放数据流名称而不含类型，因此请传入视图所属的数据流类型。
