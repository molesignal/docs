---
title: "事件上下文"
description: "获取某条事件前后的事件。"
"en_link": "/en-US/api/query/search-around"
---

```http
POST /api/v1/query/search_around
```

返回某条事件前后紧邻的事件，两侧各有 24 小时的窗口。数量默认 50，限制在 1 到 1000 之间。该调用需要 `streams.query`，系统遥测需要 `sys.telemetry.read`。

`before` 包含时间戳不晚于指针的事件，最新的在前，因此事件本身已存储时就是第一行。`after` 包含晚于指针的事件，最早的在前。数据流不存在时，`before` 与 `after` 返回空结果，而不是错误。

**请求体**

| 字段 | 类型 | 必填 | 默认值 |
|---|---|---|---|
| `event_timestamp_us` | integer | 是 | |
| `stream` | string | 是 | |
| `stream_type` | string | 是 | |
| `event_fingerprint` | string | 否 | 原样出现在 `pointer` 中。服务端不用它来挑选事件。 |
| `before` | integer | 否 | 50 |
| `after` | integer | 否 | 50 |

<ResponseExample>
```json 200
{
  "pointer": { "ts": 1790000000000000, "fingerprint": null },
  "before": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1789999999500000, "..."]],
    "scanned_rows": 100,
    "took_ms": 4
  },
  "after": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1790000000500000, "..."]],
    "scanned_rows": 100,
    "took_ms": 4
  }
}
```
</ResponseExample>
