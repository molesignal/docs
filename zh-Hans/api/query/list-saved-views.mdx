```http
GET /api/v1/saved_views
```

返回组织中保存的视图。添加 `?pinned=true` 只返回已固定的视图。该调用需要 `saved_views.read`。

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/saved_views?pinned=true" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KE7RbW5ShK8cbrZZq4I4O3XUge",
    "orgId": "<organization-id>",
    "ownerUserId": "<user-id>",
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = 'error'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true,
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

其他路由：`GET /api/v1/saved_views/{id}` 返回单个视图，`DELETE /api/v1/saved_views/{id}` 返回 `deleted`。

## 列出全部视图或已固定视图

省略 `pinned` 或设置 `pinned=false`，均表示不启用“仅已固定”筛选；`pinned=false` 不表示“仅未固定”。构建固定视图快捷入口时，使用 `pinned=true`。

请求返回当前组织中的视图定义，不返回查询结果。响应为 JSON 数组；没有视图匹配筛选时，`[]` 是有效结果。已知视图未出现时，先核对凭据所属组织，并去掉固定筛选，再判断视图是否被删除。

## 读取保存的查询

| 字段 | 用途 |
|---|---|
| `id` | 传给详情或执行接口。 |
| `language`、`statement` | 保存的查询语言与查询文本。 |
| `stream` | 保存的数据流上下文（存在时）。 |
| `timeRangeSecs` | 保存的时间窗口长度，单位为秒。 |
| `tags`、`pinned` | 分类与导航元数据，不是查询条件。 |
| `createdAt`、`updatedAt` | 微秒时间戳。 |

读取定义不会执行查询，也不会授予底层数据查询权限。按[运行保存的视图](/zh-Hans/api/query/run-saved-view)在所需权限下执行查询；按[创建保存的视图](/zh-Hans/api/query/create-saved-view)保存查询；界面操作见[保存的视图](/zh-Hans/saved-views)。
