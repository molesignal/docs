---
title: "流式查询"
description: "以 NDJSON 流式返回查询的行。"
---

```http
GET  /api/v1/query/stream
POST /api/v1/query/stream
```

始终以分块 NDJSON（`application/x-ndjson`）响应。每一行是以列名为键的 JSON 对象，最后一行是 `{"__meta__":{"scanned_rows":...,"took_ms":...}}`。该端点不会把查询转为异步任务。该调用需要 `streams.query`，系统范围下需要 `sys.telemetry.read`。

`POST` 形式的请求体与[执行查询](/zh-Hans/api/query/execute)相同。`GET` 形式使用查询参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `sql` | 是 | 查询语句，缺失时返回 `400`。 |
| `stream` | 是 | 主数据流名称。 |
| `stream_type` | 是 | `logs`、`metrics`、`traces`、`profiles` 或 `extend`。 |
| `from`、`to` | 是 | 时间范围，单位微秒。 |
| `limit` | 否 | 行数上限。 |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000

curl -G http://localhost:5080/api/v1/query/stream \
  -H "authorization: Bearer $MS_JWT" \
  --data-urlencode "sql=SELECT level, msg FROM app ORDER BY _timestamp DESC" \
  --data-urlencode "stream=app" \
  --data-urlencode "stream_type=logs" \
  --data-urlencode "from=$((NOW-3600000000))" \
  --data-urlencode "to=$((NOW+60000000))" \
  --data-urlencode "limit=3"
```
</RequestExample>

<ResponseExample>
```text 200
{"level":"info","msg":"fine"}
{"level":"error","msg":"db pool exhausted"}
{"__meta__":{"scanned_rows":5,"took_ms":173}}
```
</ResponseExample>

请在代理处关闭响应缓冲（`proxy_buffering off`），让行在产生时就到达，并允许较长的读取时间。停止读取即可取消该流。
