---
title: "创建保存的视图"
description: "把查询保存为可复用的视图。"
---

```http
POST /api/v1/saved_views
```

保存一条查询及其相对时间范围。该调用需要 `saved_views.create`。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 显示名称。 |
| `language` | string | 是 | `sql` 或 `promql`。 |
| `statement` | string | 是 | 查询语句。 |
| `time_range_secs` | integer | 是 | 相对窗口，1 到 31,622,400 秒，超出范围返回 `400`。 |
| `stream` | string | 否 | 主数据流名称。 |
| `tags` | array of strings | 否 | 用于筛选的标签。 |
| `pinned` | boolean | 否 | 让视图排在前面。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/saved_views \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = '"'"'error'"'"'",
    "time_range_secs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true
  }'
```
</RequestExample>

响应是创建出的视图，结构与[列出保存的视图](/zh-Hans/api/query/list-saved-views)中的相同。
