---
title: "创建文件夹"
description: "创建用于组织仪表盘的文件夹。"
"en_link": "/en-US/api/query/create-folder"
---

```http
POST /api/v1/folders
```

创建仪表盘文件夹。该调用需要 `dashboards.create`。列出、编辑与删除分别使用 `dashboards.read`、`dashboards.edit` 与 `dashboards.delete`。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 文件夹名称。 |
| `parent_id` | string 或 `null` | 否 | 同一组织内父文件夹的 id。`null` 创建顶层文件夹。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parent_id":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "org_id": "<organization-id>",
  "name": "Operations",
  "parent_id": null
}
```
</ResponseExample>

`GET /api/v1/folders` 列出文件夹。`DELETE /api/v1/folders/{id}` 返回 `{"deleted": "<id>"}`，文件夹中仍有仪表盘或子文件夹时返回 `409`。
