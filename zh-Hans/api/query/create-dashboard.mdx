---
title: "创建仪表盘"
description: "根据仪表盘模型创建仪表盘。"
"en_link": "/en-US/api/query/create-dashboard"
---

```http
POST /api/v1/dashboards
```

创建仪表盘。请求体把完整的仪表盘模型包在 `model` 中，并可以指定 `folder_id`。`uid` 在组织内必须唯一，否则调用返回 `409`。该调用需要 `dashboards.create`。

**模型的必填属性**

| 属性 | 说明 |
|---|---|
| `engine` | `molesignal-dashboard`。 |
| `schemaVersion` | `2`。 |
| `uid`、`title`、`tags` | 标识信息。`uid` 与 `title` 不能为空，`tags` 是数组。 |
| `editable`、`defaultDashboard` | 布尔值。 |
| `timeSettings` | `timezone`、`defaultFrom` 与 `defaultTo`。 |
| `refreshSettings` | `mode`、`enabled`、`defaultInterval` 与 `allowedIntervals`。 |
| `variables`、`annotations`、`links`、`elements` | 数组，空白仪表盘使用空数组。 |
| `layout` | 栅格：`type`、`columns`、`rowHeight` 与 `gap`。 |

缺少必填属性的模型会返回 `400` 与 `validation_failed`，`issues` 中每个缺失的属性对应一项。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/dashboards \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "model": {
      "engine": "molesignal-dashboard",
      "schemaVersion": 2,
      "uid": "service-overview",
      "title": "Service overview",
      "tags": ["operations"],
      "editable": true,
      "defaultDashboard": false,
      "timeSettings": { "timezone": "browser", "defaultFrom": "now-6h", "defaultTo": "now" },
      "refreshSettings": { "mode": "interval", "enabled": true, "defaultInterval": "30s",
                           "allowedIntervals": ["off", "30s", "1m", "5m"] },
      "variables": [],
      "annotations": [],
      "links": [],
      "layout": { "type": "grid", "columns": 24, "rowHeight": 8, "gap": 8 },
      "elements": []
    },
    "folder_id": null
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7XebQcmZojtDim7ZVdGVw594",
  "org_id": "<organization-id>",
  "folder_id": null,
  "uid": "service-overview",
  "title": "Service overview",
  "tags": ["operations"],
  "model": { "engine": "molesignal-dashboard", "...": "..." },
  "version": 1
}
```
</ResponseExample>

建议先在编辑器里搭建面板，再用 `GET /api/v1/dashboards/{id}` 导出已有仪表盘的模型作为模板。其他路由：`GET /api/v1/dashboards`，以及 `PUT` 与 `DELETE /api/v1/dashboards/{id}`。
