未修改个人起始页时，登录后打开的第一个页面就是 **首页**。它为当前工作区回答三个问题：数据是否在到达、有没有告警在触发、谁在值班。每个部分只显示账号权限允许查看的内容。

## 页面顶部

| 控件 | 用途 |
|---|---|
| **快速开始** | 打开工作区的设置步骤。参见[快速开始](#快速开始)。 |
| **最近 24 小时** / **最近 7 天** | 数据量、健康图表和数据流速率所统计的时段。 |
| **刷新** | 重新加载所有部分。**更新于** 显示数据读取的时间。 |
| **新建** | 新建仪表盘、告警规则、数据流、流水线或函数。 |

有严重级别的事件触发时，页面上方的横幅会列出它们。**查看全部** 打开[告警](/zh-Hans/alerting)。

## 接入结论与关键指标

顶部区域用一句话总结数据接入情况，并给出下一步操作。结论取所有数据流中最差的[状态](#系统健康与重点数据流)，按以下顺序判断：

| 结论 | 含义 | 操作 |
|---|---|---|
| **尚未接入数据** | 工作区中没有数据流。 | **接入数据源** 打开[数据源](/zh-Hans/intake)。 |
| **数据流已断流** | 至少一个数据流处于断流状态。 | **排查数据接入** |
| **部分数据流延迟** | 至少一个数据流接收延迟。 | **查看延迟的数据流** |
| **数据长期断流** | 至少一个数据流处于长期断流状态。 | **检查数据接入** |
| **状态未知** | 无法读取数据流的状态。 | **重新获取** |
| **数据接入正常** | 有数据的数据流都处于正常状态。 | **查看数据流** |
| **尚无数据** | 已有数据流，但都还没有收到数据。 | **接入数据源** |

**让 Mole Agent 分析** 会把当前结论交给 [Mole Agent](/zh-Hans/agent)，请它分析可能的原因并给出首先要检查的地方。

结论旁边的指标：

| 指标 | 显示内容 |
|---|---|
| **当前告警** | 正在触发的事件数，以及其中已确认的数量。 |
| **原始摄入量** | 时段内接入的解压后字节数、速率和事件数。 |
| **压缩后数据量** | 存储后的大小，以及相比原始摄入减少的比例。 |

## 快速开始

快速开始提示条在所有步骤完成之前显示下一个步骤。**完成设置** 打开步骤列表：

| 步骤 | 完成条件 |
|---|---|
| **接入数据源** | 工作区中有数据流。 |
| **创建仪表盘** | 工作区中有仪表盘。 |
| **创建告警** | 工作区中有告警规则。 |
| **自动化流水线** | 工作区中有流水线。 |
| **加载示例数据** | 示例数据流已存在。 |

**加载** 会向三个数据流写入一小批相互关联的示例数据：`sample_app_logs`、`sample_app_metrics` 和 `sample_app_traces`。链路模拟从 `frontend` 经 `checkout`、`payment` 到 `db` 的调用，日志带有相同的 `trace_id`，指标给出各服务的耗时，因此从链路跳转到对应日志可以直接演示。再次加载会追加当前时间的数据。加载需要 `logs.write`。

## 系统健康与重点数据流

**系统健康概览** 按 **原始摄入**、**压缩存储** 或 **事件数** 绘制所选时段的图表，并列出各类信号的状态。数据源停止发送时，图表会说明情况并提供 **检查数据接入**。

**重点数据流** 列出最需要关注的数据流，包括类型、状态、摄入速率和最后接收时间。点击数据流可在对应的探索页中打开，**查看全部** 打开[数据流](/zh-Hans/streams)。

| 状态 | 含义 |
|---|---|
| **正常** | 最近 15 分钟内收到过数据。 |
| **接收延迟** | 最后一次收到数据在 15 分钟到 2 小时之前。 |
| **断流** | 2 到 24 小时没有收到数据。 |
| **长期断流** | 超过 24 小时没有收到数据。 |
| **无数据** | 从未收到过数据；或者是 Mole Agent 链路数据流，它在两次回答之间本来就没有数据。 |

## 值班、活动与仪表盘

右侧一栏跟随[值班排班](/zh-Hans/alerting/on-call)：

- 当前登录的用户正在值班时显示 **我的值班**，否则显示工作区某个排班的 **正在值班**，并给出本次值班进度、下次交接时间和关联的升级策略。
- 本班统计：本次值班期间的事件数，其中待确认、已确认和已升级的数量。
- 有临时替班时，显示替班人和替班截至时间。
- 当前无人值班时显示 **值班覆盖异常**。**立即安排** 打开排班并添加临时替班。

**最近活动** 列出审计记录中仪表盘、告警、流水线等资源的最新变更。**查看全部** 打开 **设置 → 审计**。

**最近仪表盘** 列出最近变更的仪表盘及其面板数。仪表盘还没有面板时，**添加面板** 会打开它的面板编辑器。

## 权限

每个部分需要所在区域的读取权限才能加载。

| 权限 | 部分 |
|---|---|
| `streams.read` | 接入结论与重点数据流。 |
| `streams.query` | 原始摄入量、压缩后数据量和健康图表。 |
| `alerts.incidents.read` | 严重事件横幅与当前告警。 |
| `schedules.read` | 值班。 |
| `audit.read` | 最近活动。 |
| `dashboards.read` | 最近仪表盘。 |
| `logs.write` | 快速开始中的 **加载**。 |
