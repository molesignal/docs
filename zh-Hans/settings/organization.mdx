打开 **设置 → 通用**。查看本页需要 `org.settings.read`，修改需要 `org.settings.manage`。每个分组在修改后稍等片刻就会自动保存。**撤销** 回退最近一次修改，**重试** 重新提交保存失败的修改。

## 组织信息

| 字段 | 规则 |
|---|---|
| **组织名称** | 显示在工作区切换器、页面标题和邀请中，必填。 |
| **组织标识** | 只读，API 和资源标识会用到。**复制** 可复制它。 |
| **组织 ID** | 只读，API、审计记录和技术支持会用到。**复制** 可复制它。 |

组织创建后，组织标识和 ID 永远不会改变。

## 偏好默认值

**组织偏好默认值** 对尚未保存个人偏好的成员生效。个人[偏好设置](/zh-Hans/account#偏好设置)以及在查询页临时修改的时间显示优先。

| 分组 | 字段 |
|---|---|
| 外观 | **默认主题**、**界面密度**。 |
| 语言与区域 | **语言**、**默认时区**、**日期与时间格式**。 |
| 启动与交互 | **进入工作区后打开**、**启用键盘快捷键**。 |

## 注册与访问

| 设置 | 效果 |
|---|---|
| **允许自助加入** | 符合实例注册条件的用户可以自行加入本工作区。 |
| **需要管理员审批** | 自行加入的用户在[审批](/zh-Hans/identity/members#审批)中等待，直到管理员通过。开启自助加入后才显示。 |
| **默认组织角色** | 自助加入获得的角色，来自 IAM 目录。单点登录没有命中任何角色映射、服务商也没有默认角色时，也使用它。 |

## 共享与公开访问

这些设置限制成员可以创建的[受限公开链接](/zh-Hans/resource-sharing)。工作区内共享和跨组织共享始终要求登录。

| 设置 | 效果 |
|---|---|
| **允许创建公开链接** | 成员可以为允许的资源创建无需账号即可打开的受限链接。下面的设置都需要先开启它。 |
| **允许公开分享实时仪表盘** | 允许为实时仪表盘创建公开链接。公开页只读，并限制查询、变量、时间范围和跳转。 |
| **公开链接最长有效期** | **1 天**、**7 天** 或 **30 天**。创建者不能选择更晚的过期时间。 |
| **公开报告必须设置密码** | 公开报告在密码验证通过后才签发短时共享会话。 |
| **禁止公开分享生产环境资源** | 资源带有 `production` 或 `prod` 标签时，拒绝创建公开链接。 |
| **允许公开下载 CSV** | 关闭后，公开的 CSV 报告只能在受限页面中预览。 |

## 组织生命周期

组织不能在自身内部被删除。**前往组织管理** 会切换到 `_sys` 组织，由 Owner 或平台管理员在那里删除。参见[组织管理](/zh-Hans/settings/platform#组织管理)。
