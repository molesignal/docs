平台设置位于受保护的 `_sys` 组织中。用工作区切换器切换到 `_sys`；平台管理员和已启用组织的 Owner 可以进入。这些页面出现在 `_sys` 的 **设置** 中，每个页面都需要平台权限。

| 分区 | 分组 | 权限 |
|---|---|---|
| **组织管理** | 平台 | `sys.organizations.manage` |
| **客户端 IP 识别** | 数据面 | `sys.settings.manage` |
| **数据保留** | 数据面 | `sys.settings.manage` |
| **指标基数** | 数据面 | `sys.settings.manage` |
| **审计保留** | 数据安全 | `sys.settings.manage` |

各节点从数据库读取这些设置，修改后无需重启。

## 组织管理

**组织管理** 列出实例中的租户组织，包括名称、标识、状态和 ID。

| 操作 | 效果 |
|---|---|
| **创建组织** | 用 **名称** 和 **标识** 创建租户组织。标识之后不能修改。 |
| 停用 | 立即暂停对该组织的访问：重新启用前，它的会话和 API 凭证都会被拒绝。 |
| 启用 | 恢复该组织成员和凭证的访问。 |
| 删除 | 永久删除该组织。 |

必须至少保留一个启用中的租户组织，`_sys` 组织本身不能修改。组织的成员在它自己的[身份与访问](/zh-Hans/identity/members)中管理：先在[组织](/zh-Hans/identity/teams#组织)中点击 **管理 IAM**。

## 客户端 IP 识别

用户体验接入会记录每个浏览器或设备的地址，并据此查出国家、行政区和城市。**客户端 IP 识别** 决定从哪里取得这个地址，它作用于所有组织。

| **地址来源** | 适用场景 |
|---|---|
| **直接连接地址** | 默认值。使用 TCP 对端地址，忽略所有转发 Header。接入端点直接对外暴露时使用。 |
| **单值 Header** | 从 CDN 或代理设置的 Header（例如 `CF-Connecting-IP`）读取一个裸 IP。 |
| **转发 IP 链** | 从右向左遍历 `X-Forwarded-For` 这类 IP 链，跳过可信代理，取第一个不可信地址。**最大链长度** 限制单个请求最多读取的地址数，范围 1 到 64。 |

位于代理之后时，还需要设置：

| 字段 | 规则 |
|---|---|
| **客户端 IP Header** | 要读取的 Header。`Authorization`、`Cookie`、API Key 和客户端证书 Header 会被拒绝。 |
| **可信代理 CIDR** | 每行一个 IPv4 或 IPv6 CIDR，最多 64 个。只有对端位于这些网络中的连接才会读取 Header。`/0` 网络会信任该地址族的所有来源，只应在受保护的入口之后使用。 |
| **回退到连接地址** | Header 缺失、格式错误、超长或没有可用地址时，使用 TCP 对端地址。 |
| **允许 Header 中的私网地址** | 接受 Header 中的私网、loopback 和链路本地地址。公网浏览器流量应保持关闭。 |

## 数据保留

**数据保留** 设置没有单独保留期的数据流保留多少天：默认 30 天，范围 1 到 3650。每个数据流都可以在[数据流](/zh-Hans/streams#保留与删除)中设置自己的保留期。超过保留期的数据会在下一次清理时删除，无法恢复。

## 指标基数

**指标基数** 限制同时保持活跃的 Prometheus series 数，避免取值很多的标签耗尽内存与存储。

| 上限 | 默认值 | 含义 |
|---|---|---|
| **每个组织** | 200,000 | 一个组织的活跃 series 数。 |
| **每个指标** | 100,000 | 组织中一个指标的活跃 series 数，不超过每个组织的上限。 |

达到上限后，新 series 的写入会被拒绝，已有 series 照常写入。一段时间没有数据的 series 不再算作活跃。各节点每 30 秒重新读取一次上限。可以用[指标](/zh-Hans/metrics)的基数视图找出产生大量 series 的标签。

## 审计保留

**审计保留** 设置所有组织和平台的审计记录保留多少天：默认 90 天，范围 0 到 3650，`0` 表示永久保留。更早的记录每天清理一次，删除后无法恢复。每次修改都会以 `audit_retention.update` 记录到平台审计中。
