在 **仪表盘** 中点击 **新建仪表盘**，或在仪表盘上点击 **编辑**，即可打开编辑器。创建仪表盘需要 `dashboards.create`，修改需要 `dashboards.edit`。**允许编辑** 关闭的仪表盘（例如内置仪表盘）不能修改，请改为创建副本。

## 编辑器

| 控件 | 用法 |
|---|---|
| **返回仪表盘** | 离开编辑器。 |
| 仪表盘标题 | 直接修改仪表盘名称。 |
| **撤销** / **重做** | 在打开编辑器以来的修改中后退或前进。 |
| **添加** | 添加 **面板**、**文本**、**行**、**分组** 或 **标签页**。 |
| **设置** | 打开[仪表盘设置](#仪表盘设置)。 |
| **保存** | 保存仪表盘。保存之前不会写入任何修改。 |

按住元素的拖动手柄可以移动元素，拖动元素的角可以调整尺寸。选中元素后，可以在侧边面板中修改它的位置和结构。新仪表盘使用 24 列的网格，可以在[设置 → 通用](#仪表盘设置)中修改。

## 元素

| 元素 | 用途 |
|---|---|
| **面板** | 由可视化绘制的一个或多个查询。 |
| **文本** | 静态的 Markdown 或纯文本，用于说明、标题和链接。 |
| **行** | 占满整行的标题，包含它下方的元素。行可以设为 **默认折叠**。 |
| **分组** | 把相关元素放在一起的框。 |
| **标签页** | 多个标签页，每个标签页有自己的元素。可以选择默认打开的标签页。 |

## 编辑面板

在面板菜单中点击 **编辑**，或添加一个面板。面板编辑器用当前时间范围和变量显示面板的 **实时预览**，并提供两组标签页：

| 标签页 | 内容 |
|---|---|
| **查询**、**转换**、**数据链接** | 面板读取什么数据、结果如何重组、点击后跳到哪里。 |
| **面板**、**字段**、**覆盖项** | 面板的外观、数值的显示方式，以及对部分字段的例外设置。 |

### 查询

为面板的每个查询点击 **添加查询**。每个查询都有 **查询编号**（例如 `A`）、**数据源**、**查询语言**（**PromQL** 或 **SQL**）和 **表达式**。数据源决定默认的查询语言和其他字段：

| 数据源 | 默认查询语言 | 其他字段 |
|---|---|---|
| **指标** | PromQL | |
| **日志**、**链路**、**SQL** | SQL | **数据流名称** 和 **数据流类型**（**日志**、**指标** 或 **链路**）。 |
| **Profiles** | SQL | **服务** 和 **剖析类型**，例如 `cpu`。 |

**图例** 用模板为序列命名，例如 `{{service}}`。**共享查询** 复用另一个面板的查询，写作 `<panel-id>:<ref-id>`，这样数据只读取一次。查询中可以使用 `$service` 这样的[变量](/zh-Hans/dashboards/variables)。SQL 与 PromQL 参见[查询](/zh-Hans/query)。

### 转换

转换在绘制之前重组结果。转换按顺序执行，每个转换都可以单独停用。

| 转换 | 效果 |
|---|---|
| **筛选字段**、**整理字段**、**重命名字段** | 保留、排序、隐藏或重命名字段。 |
| **计算字段** | 添加一个由其他字段计算得出的字段。 |
| **聚合** | 把每个序列归约为最新值、平均值、最大值或总和等。 |
| **分组**、**排序**、**限制数量** | 按字段聚合、排序，并保留前若干行。 |
| **连接**、**合并** | 合并多个查询的结果。 |
| **标签转字段**、**行转字段**、**时序转表格** | 把标签、行或序列转为列。 |

### 面板选项

**面板** 标签页设置 **标题**、鼠标悬停时显示的 **描述**、**宽度** 和 **高度**、**可视化** 及其选项，以及是否使用 **透明背景**。

| 可视化 | 绘制内容 |
|---|---|
| **时序图** | 随时间变化的折线、柱或点，可设置图例、悬停提示、填充和堆叠。 |
| **柱状图** | 按类别比较数值。 |
| **条形仪表** | 以横向或纵向条形展示归约后的值。 |
| **统计值** | 一个值（例如最新值），可附带迷你走势图。 |
| **仪表** | 在环形刻度上展示一个值，并按阈值着色。 |
| **表格** | 分页显示的行。 |
| **日志** | 带时间和级别的紧凑日志列表。 |
| **热力图** | 数值随时间的强度分布。 |
| **状态时间线** | 状态随时间的变化。 |
| **文本** | Markdown。 |

**重复变量** 会为变量的每个取值绘制一份面板副本，**重复方向** 可选 **横向**、**纵向** 或 **网格**，每行最多 **每行最多数量** 个副本。参见[按变量重复面板](/zh-Hans/dashboards/variables#按变量重复面板)。

### 字段选项

**字段** 标签页设置数值的显示方式：

| 选项 | 用法 |
|---|---|
| **单位**、**小数位** | 单位（例如字节、百分比或秒）和小数位数。 |
| **最小值**、**最大值** | 刻度的两端。 |
| **显示名称** | 替换字段的名称。 |
| **配色方案** | 固定颜色、调色板、阈值颜色或连续色阶。 |
| **阈值** | 颜色变化的数值点，模式为 **绝对值** 或 **百分比**，从 **基线** 开始。 |
| **值映射** | 为某个值、某个区间、正则匹配或空值等特殊值显示文本、颜色或图标。 |
| **空值文本** | 没有数值时面板显示的内容。 |

**覆盖项** 只对部分字段应用其他字段选项。点击 **添加覆盖项**，选择匹配方式（**字段名**、**字段正则**、**字段类型** 或 **查询编号**），再为每个要修改的选项点击 **添加属性**。

### 数据链接

数据链接让点击数值时跳转到其他地方。点击 **添加数据链接**，填写 **标题** 并选择目标：**日志**、**指标**、**链路**、**Profiles**、另一个 **仪表盘**，或 **外部链接**。可以选择链接是否带上时间范围和仪表盘变量，以及是否在新标签页打开。链接显示在面板菜单中。

## 仪表盘设置

**设置** 有四个标签页。

| 标签页 | 内容 |
|---|---|
| **通用** | **标题**、**描述** 和 **标签**。默认时间范围（**开始**、**结束**）和 **时区**。**网格**：1 到 48 的 **列**、**行高** 和 **间距**。**刷新**：**关闭**、带 **默认间隔** 的 **间隔刷新**，或 **自动**。**图表悬停提示**：关闭，或在面板之间使用共享十字准线。**允许编辑**。 |
| **变量** | 仪表盘的变量。参见[变量](/zh-Hans/dashboards/variables)。 |
| **注释** | 绘制在时序图面板上的事件。 |
| **链接** | 显示在仪表盘页头的链接。 |

注释包含 **名称**、**来源**、**显示**（**折线**、**区域** 或 **标记**）、**颜色** 和 **启用**。在 **事件** 中用 **添加事件** 列出它的事件：**标签**、**开始时间戳（毫秒）**，以及区域使用的 **结束时间戳（毫秒）**。

链接包含 **标题**、**类型**（**仪表盘** 或 **外部链接**）、**URL**，以及是否带上 **时间范围** 和 **变量**、是否 **新标签页打开** 的开关。

## 保存与复用

点击 **保存**。要复用某个面板，在它的菜单中点击 **复制** 复制面板 JSON，再粘贴到另一个仪表盘。要复用整个仪表盘，用 **导出 JSON** 导出后在其他地方导入。参见[导入仪表盘](/zh-Hans/dashboards#导入仪表盘)。
