AI Copilot 是用于排查的聊天助手。就某个尖峰、某次事件或某个服务发问，它会代你查询数据流、链路与事件，
再解释它的发现。它运行在**你**配置的 LLM provider 上，且每次对话都可审计。

## 配置 provider

在 **设置 → AI providers** 添加 provider 并选择模型：

| Provider | 说明 |
|---|---|
| **Anthropic** | Claude 系列模型。 |
| **OpenAI** | GPT 系列模型。 |
| **OpenAI-compatible** | 任何兼容 OpenAI API 的端点（自托管、网关）。 |

API key 以实例 envelope key 静态加密存储。未配置 provider 前，Copilot 处于关闭状态。

## 提示词（Prompts）

**设置 → AI prompts** 保存 Copilot 使用的系统提示词。按你的环境编辑它们——命名约定、关注哪些数据流、你
们的事件处理流程——让回答贴合团队的实际运作。

## 工具集（Toolsets）

Copilot 通过**调用工具**作答，而非凭空猜测。工具集声明模型可用的只读能力——例如执行查询、列出数据流、获
取事件——经由 MCP 风格的 dispatcher 暴露。在 **设置 → AI toolsets** 配置它们，限定助手可触达的范围。

<Note>
  工具是只读的排查辅助。Copilot 检视你的数据以解释异常；它不会修改配置或写入数据流。
</Note>

## 审计

每次 Copilot 会话、消息与工具调用都会被记录。在 **设置 → 审计** 查看——谁问了什么、跑了哪些工具、返回了
什么——让 AI 辅助排查与其他操作一样可追溯。
