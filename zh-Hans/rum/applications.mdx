应用是发送 RUM 事件的网站或 App。请在任何 SDK 发送数据之前创建应用：Client Token 绑定到一个应用，MoleSignal 会拒绝发给不存在的应用的事件。

打开 **用户体验 → 应用** 可列出工作区的应用。创建、修改和删除应用需要 `rum.applications.manage`，因为应用自带 Client Token；读取列表需要 `rum.applications.read`。

## 创建应用

<Steps>
  <Step title="打开表单">
    点击 **创建应用**。还没有应用的工作区会在探索页显示同样的按钮。
  </Step>
  <Step title="为应用命名">
    输入最长 128 个字符、且没有被其他应用使用的 **名称**，例如 `结账网页`，并选择 **平台**：浏览器、Android、iOS、Flutter、React Native 或其他。平台只决定应用显示哪种接入示例：事件通过 `source` 说明自己来自什么。
  </Step>
  <Step title="确定标识符">
    **标识符** 是 SDK 中配置为 `applicationId` 的值。留空则由名称生成（例如 `checkout-web`），也可以自行输入，最长 64 个字符，可使用 `A-Z`、`a-z`、`0-9`、`.`、`_`、`:` 与 `-`。应用创建之后，标识符不能再修改。
  </Step>
  <Step title="点击创建">
    应用会打开并显示它的 Client Token。
  </Step>
</Steps>

创建应用时，如果工作区的七个 RUM 数据流还不存在，也会一并创建。

## Client Token

打开应用即可看到它的 **Client Token**。Token 形如 `msrum_<prefix>_<secret>`，永不过期，只对该应用拥有 `rum.write`。它默认以遮盖形式显示，选择 **显示 Token** 或 **复制 Token** 即可使用。

<Warning>
  Token 会随浏览器和移动端代码一起发布，用户可以读到它。客户端代码里只使用这个 Token，绝不要使用所有者、管理员或个人 Token。删除应用会吊销它的 Token。
</Warning>

同一个 Token 也可以通过 [API](/zh-Hans/api/auth/rum-token) 获取。应用里的 **打开接入向导** 会打开该平台的 **数据源** 向导并选中这个应用：向导会给出端点、Token、填好标识符的 SDK 示例，以及检查数据是否到达的步骤。React Native 和“其他”没有向导，请直接用 Token 发送[事件](/zh-Hans/rum/events)。

## 采集

应用的设置决定随每个事件保存哪些内容。在应用中修改后点击 **保存**。

| 设置 | 默认值 | 作用 |
|---|---|---|
| **保存 IP 地址** | 开 | 把服务端解析出的客户端地址保存为 `network.client.ip`。位于代理之后时，请先设置[客户端 IP 识别](/zh-Hans/rum#代理之后的客户端-ip)。 |
| **保存位置** | 开 | 保存按地址查到的国家、地区和城市。即使不保存地址，也会做这次查询，只保存它的结果。 |
| **默认隐私级别** | 遮盖文本和输入 | 接入示例为会话回放建议的隐私级别：**遮盖文本和输入**、**遮盖用户输入** 或 **录制显示的全部内容**。 |

修改只对之后到达的事件生效，已保存的数据不会改变。

## SDK 远程配置

用 `remoteConfiguration: true` 启动的 SDK 在启动时读取这些设置，所以修改它们不需要重新发布页面。设为 **按页面的配置** 的项，按页面传给 `init` 的值。

| 设置 | SDK 选项 |
|---|---|
| **会话采样率（%）** | `sessionSampleRate` |
| **回放采样率（%）** | `sessionReplaySampleRate` |
| **隐私级别** | `defaultPrivacyLevel` |
| **采集点击** | `trackUserInteractions` |
| **转发控制台** | `forwardConsoleLogs` |

SDK 用 Client Token 从 `GET /api/v1/rum/config` 读取，最多等 1.5 秒；没有应答时按页面给的值启动。

## 分群

**分群** 为会话组命名，[分析页](/zh-Hans/rum/analytics#分群)可以收窄到这些组，最多 20 个。一个分群最多五个条件，会话要全部满足。条件可以看国家、大洲或城市，浏览器、系统或设备类型，用户 ID 或邮箱，账户 ID，服务、版本或平台，或者应用用 `setUser` 设置的用户属性（`usr.extra.plan`），取一个或多个值，或者都不取。修改立即对读取生效，已存储的会话也适用。用户属性只出现在这个功能上线后开始的会话上。

## 敏感数据与保留的会话

**敏感数据** 里每一类文本各有一个开关，服务端在事件写入前把它们去掉：令牌、密钥和密码，邮箱地址，电话号码，银行卡号，证件号码，以及敏感 URL 参数的值。默认全部开启。各类去掉什么，见 [RUM 隐私](/zh-Hans/rum/privacy#在接入时去掉敏感文本)。

**保留的会话** 决定应用存哪些会话。**保留的会话比例（%）** 保留应用收到的会话中的这个比例，取 `0` 到 `100` 的整数，一个会话整个保留或整个丢弃，回放也一样。**添加过滤器** 给它描述的会话（按环境、版本、国家、浏览器之类）一个单独的比例，第一个描述了会话的过滤器说了算；其余会话的比例这时叫 **其余会话的保留比例（%）**。**保留所有错误** 让没有保留的会话的错误照样存下来。显示总数的页面会把保留下来的会话放大到所有会话，并写明 **估算值**。见 [RUM 数据采样](/zh-Hans/rum/sampling#在服务端保留一部分会话)。

## Issue

**Issue** 部分设置应用每小时新开多少个 [issue](/zh-Hans/rum/errors#每小时新开的-issue)。

| 设置 | 默认值 | 作用 |
|---|---|---|
| **每小时新开 issue 数** | 100 | 范围 1 到 10,000。超出之后，还不属于任何 issue 的错误合并计入一个叫**其余错误**的 issue，直到这一小时结束。修改在半分钟内生效。 |

## 删除应用

点击 **删除应用** 并确认。它的 Client Token 立即失效，使用该 Token 的 SDK 会被拒绝。应用已经发送的事件会保留在数据流中，直到保留期结束，并且仍可在探索页中搜索。
