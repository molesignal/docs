title: "术语表"
description: "MoleSignal 文档与产品中使用的术语的定义。"
"en_link": "/en-US/glossary"
---

| 术语 | 定义 |
|---|---|
| **Alert** | 评估告警规则、驱动升级、渲染定时报告并运行连接器的角色，参见[分角色部署](/zh-Hans/distributed-deployment)。 |
| **API token** | 形如 `ms_<prefix>_<secret>` 的 Bearer 凭据，以用户或服务账号的身份行事，参见[身份与访问](/zh-Hans/identity)。 |
| **APM** | 应用性能监控。由链路 Span 派生的、有界的服务、事务、依赖、错误与版本聚合，参见[应用性能监控](/zh-Hans/apm)。 |
| **Arrow Flight SQL** | `5083` 端口上供 DBeaver、JDBC、ADBC 等数据库客户端使用的 SQL 协议，默认关闭，参见[用数据库客户端连接](/zh-Hans/query/database-clients)。 |
| **目录（Catalog）** | PostgreSQL 中记录哪些 Parquet 文件和索引属于哪个数据流的信息。 |
| **加密密钥（Cipher key）** | `MS_CIPHER_KEY` 中的根密钥，用来加密 MoleSignal 保存在 PostgreSQL 中的密文，参见[生产检查清单](/zh-Hans/production-checklist)。 |
| **合并（Compaction）** | 把小的 Parquet 文件合并成大文件。`compactor` 角色把它与保留策略一起执行。 |
| **连接器（Connector）** | 与外部平台的托管集成。接入源接收被推送的数据，出口目标把流水线输出发送出去，参见[连接器](/zh-Hans/connectors)。 |
| **数据源（Datasource）** | 数据源目录中的条目，为某个来源生成端点、Token 与配置片段，参见[数据源](/zh-Hans/intake)。 |
| **升级策略（Escalation policy）** | 带确认超时的有序通知目标，参见[告警](/zh-Hans/alerting)。 |
| **扩展表（Extend table）** | 流水线用来丰富事件的“键到记录”查找表，参见[扩展表](/zh-Hans/extend-tables)。 |
| **联邦查询（Federated query）** | 同时扫描远程集群的查询，用 `?clusters=local,<name>` 选择，参见[分角色部署](/zh-Hans/distributed-deployment)。 |
| **刷写（Flush）** | 把 intake 节点的内存缓冲写成对象存储中的 Parquet 文件和索引。 |
| **函数（Function）** | 用 VRL 或 JavaScript 编写的可复用转换，参见[函数](/zh-Hans/functions)。 |
| **事件（Incident）** | 经历确认与恢复的一次告警，参见[告警](/zh-Hans/alerting)。 |
| **接入（Intake）** | 接收遥测数据的路径，同时也是负责校验、缓冲与刷写的角色，参见[数据源](/zh-Hans/intake)。 |
| **接入 Token** | 具备 `streams.write` 权限、供发送端使用的 Token，参见[数据源](/zh-Hans/intake#接入-token)。 |
| **Mole Agent** | 通过工具目录调查问题的内嵌运维 Agent，参见 [Mole Agent](/zh-Hans/agent)。 |
| **值班排班（On-call schedule）** | 带时区的轮值与临时替换，供升级策略指向，参见[告警](/zh-Hans/alerting)。 |
| **组织（Organization）** | 租户与策略边界，网页界面称之为工作区，参见[核心概念](/zh-Hans/concepts)。 |
| **Parquet** | MoleSignal 存储日志、指标与链路所用的列式文件格式。 |
| **流水线（Pipeline）** | 对事件做路由、标准化、脱敏与扩展的一组步骤，可以在接入期间实时运行，也可以按定时计划运行，参见[流水线](/zh-Hans/pipelines)。 |
| **平台管理员** | 取自 `[auth].root_email`、负责平台级设置的用户。 |
| **Probe Agent** | 从某个位置执行拨测的进程，`standalone` 节点上运行着内置的 Agent，参见[拨测](/zh-Hans/synthetics)。 |
| **角色（Role）** | 由 `[node].roles` 选择的进程角色：`standalone`、`router`、`intake`、`querier`、`compactor` 或 `alert`；在 IAM 中也指具名的权限集合。 |
| **RUM** | 真实用户监控，覆盖浏览器与移动应用会话，参见 [RUM](/zh-Hans/rum)。 |
| **RUM Client Token** | 具备 `rum.write` 权限、绑定到一个应用、由浏览器与移动端代码发送的 Token。 |
| **保存的视图（Saved view）** | 连同时间范围与选项一起保存的查询。 |
| **搜索任务（Search job）** | 持久化的异步查询。超过规模阈值的查询会成为搜索任务，参见[查询](/zh-Hans/query)。 |
| **自遥测（Self-telemetry）** | MoleSignal 在保留的 `_molesignal` 数据流中记录的自身指标、链路与 Profile，参见[自身可观测性](/zh-Hans/self-observability)。 |
| **服务账号（Service account）** | 供采集器和自动化使用的非人类身份，不能登录，参见[身份与访问](/zh-Hans/identity)。 |
| **静默（Silence）** | 在限定时间内暂停匹配告警通知的规则，参见[告警](/zh-Hans/alerting)。 |
| **Standalone** | 在一个进程内运行全部角色的默认角色。 |
| **状态页（Status page）** | 展示组件状态与事件的公开或私有页面，参见[状态页](/zh-Hans/status-pages)。 |
| **数据流（Stream）** | 信号的类型化契约：名称、类型、schema 与保留期，参见[数据流](/zh-Hans/streams)。 |
| **数据流类型（Stream type）** | `logs`、`metrics`、`traces`、`profiles` 或 `extend` 之一。 |
| **拨测（Synthetic monitor）** | 定时执行的检查（例如 HTTP 请求），记录可用性与延迟，参见[拨测](/zh-Hans/synthetics)。 |
| **VRL** | Vector Remap Language，流水线函数可使用的语言之一。 |
| **WAL** | intake 节点本地磁盘上的预写日志，在记录被刷写之前保存它们。 |
| **工作区（Workspace）** | 网页界面对所选组织的称呼。 |
