**账号设置** 保存属于个人而不属于工作区的内容。点击顶栏的用户头像，选择 **账号设置**、**偏好设置** 或 **通知设置** 即可打开。每位成员都可以修改自己的账号设置，只有 **API tokens** 需要权限。

| 分组 | 页面 | 用途 |
|---|---|---|
| 个人设置 | **个人资料** | 显示名称、头像和简短说明。 |
| | **偏好设置** | 主题、密度、时区、日期格式、起始页和键盘快捷键。 |
| | **通知设置** | 个人通知方式、投递顺序和免打扰时段。 |
| 安全与访问 | **安全与登录** | 重置密码，已关联的登录方式。 |
| | **活跃会话** | 当前浏览器的会话。 |
| | **API tokens** | 你自己的 API Token，以你的身份执行。 |
| 工作区 | **工作区与身份** | 所属工作区、角色以及供自动化使用的标识。 |

## 个人资料

| 字段 | 规则 |
|---|---|
| **显示名称** | 其他成员看到的名称。 |
| **登录邮箱** | 只读，由管理员或身份提供方管理。 |
| **个人说明** | 可选，最多 500 个字符。 |
| 头像 | **更换头像** 上传不超过 2 MB 的 PNG、JPEG 或 WebP 图片。**移除** 恢复为首字母头像。 |

点击 **保存修改** 保存个人资料。

## 偏好设置

个人偏好优先于[工作区的默认值](/zh-Hans/settings/organization#偏好默认值)。查询页仍可以为当前调查临时修改时间显示。

| 分组 | 字段 | 选项 |
|---|---|---|
| 外观 | **默认主题** | **跟随系统**、**浅色** 或 **深色**。 |
| | **界面密度** | **舒适** 或 **紧凑**。紧凑模式会收紧表格、日志列表、导航和设置中的行高与间距，图表、代码和对话不受影响。 |
| 时间与区域 | **默认时区** | **浏览器时区** 或指定时区。仪表盘、日志、指标和链路按它显示时间。 |
| | **日期与时间格式** | 日期为 `2026-07-27`、`2026/07/27`、`27/07/2026` 或 `07/27/2026`，时间为 **24 小时** 或 **12 小时** 制。 |
| 启动与交互 | **进入工作区后打开** | **首页**、**上次访问的页面**、**仪表盘**、**日志**、**指标**、**链路**、**告警事件**、**AI 智能体**，或指定的仪表盘。 |
| | **启用键盘快捷键** | 开启或关闭[全局快捷键](/zh-Hans/console#键盘快捷键)。 |

点击 **保存设置**。有未保存的修改时离开页面，会询问是否放弃修改。界面语言在用户菜单的 **语言** 中选择，不在这里设置。

## 通知设置

**通知设置** 列出在当前工作区中能联系到该成员的通知方式，以及 MoleSignal 尝试它们的顺序。

<Steps>
  <Step title="绑定通知方式">
    点击 **绑定通知方式**。选择管理员在[设置 → 通知 → 连接器](/zh-Hans/notification-channels)中配置的 **连接器**，再填写 **外部身份**：邮箱地址、IM 平台的用户 ID，或语音与短信使用的手机号（以 `+` 和国家码开头）。最后填写 **显示名称**。
  </Step>
  <Step title="发送测试">
    点击该通知方式上的 **发送测试**。收到消息即说明连接器接受这个身份。
  </Step>
  <Step title="完成验证">
    通知方式只有在启用并验证后才会投递。拥有 `org.members.update` 的管理员确认该身份属于这位成员后，在它上面点击 **验证**。
  </Step>
  <Step title="为通知类别选择通知方式">
    在 **投递偏好** 中，为 **告警事件**、**值班通知** 或 **报告** 打开 **接收此类通知**，并用 **上移端点** 和 **下移端点** 排列通知方式的顺序。
  </Step>
</Steps>

**告警事件** 有两组接收顺序：**高紧急度告警的接收顺序** 和 **低紧急度告警的接收顺序**，按事件的[紧急度](/zh-Hans/alerting/on-call#紧急度)选用。低紧急度那组不设时只用高紧急度那组的第一种方式。每组第一步之后的每一步都可以设置等待分钟数。只有到那时告警仍无人确认，后面的步骤才会通知到该成员。等待分钟数与上一步相同的步骤，只在上一步发送失败时使用。参见[没人确认就换下一种方式](/zh-Hans/notification-channels#没人确认就换下一种方式)。

**启用免打扰** 会在所选 **时区** 的 **开始** 与 **结束** 时间（`HH:MM`）之间停止向该成员发送这一类别的通知，这些通知之后也不会补发。对告警事件，免打扰时段里一律不发低紧急度告警；**免打扰时仍接收高紧急度告警** 开着时仍放行高紧急度的告警。删除通知方式之前，先把它从所有投递偏好中移除。

自己在值班排班里、却没有能收到告警的方式时，这一页和[首页](/zh-Hans/home)的值班卡片会提示，见[收不到告警的成员](/zh-Hans/alerting/on-call#收不到告警的成员)。

个人顺序会在团队与组织的兜底路由之前尝试。参见[通知渠道与投递](/zh-Hans/notification-channels)。

## 安全与会话

**安全与登录 → 修改密码** 会向登录邮箱发送密码重置链接，链接的规则见[登录](/zh-Hans/console#登录)。

**已关联的登录方式** 列出可以登录这个账号的单点登录身份，以及各自的工作区和上次使用时间。**解除关联** 后，这个身份不能再登录这个账号；再用它登录时，要按[关联已有账号](/zh-Hans/identity/sso#关联已有账号)中的方式重新确认。没有密码的账号会保留最后一个已关联的身份。

**身份验证器 App** 和 **Passkey** 让登录在密码之外再验证一次，Passkey 还能免密码登录。开启、恢复码和丢了第二因素之后怎么办，见[多因素认证与 Passkey](/zh-Hans/identity/mfa)。

**活跃会话** 显示当前浏览器的会话。**退出当前设备** 结束该会话；**退出其他所有设备** 结束这个账号在别的浏览器和电脑上的所有登录，当前浏览器保持登录。

**API tokens** 列出你自己的 Token，点击 **新建 Token** 即可签发新的 Token。Token 以你的身份执行，能做的永远不超过你此刻的权限，权限范围还可以进一步收窄它。这一页需要 `personal_tokens.manage`，所有内置角色都有这项权限。参见 [API Token 与服务账号](/zh-Hans/identity/tokens)。

## 工作区与身份

**工作区与身份** 列出账号所属的工作区，以及在每个工作区中的角色和状态。**切换** 用于更换当前工作区。被平台管理员停用的工作区无法打开。

**高级信息** 显示当前工作区的 **用户 ID**、**组织 ID** 和 **组织标识**，均可 **复制**。脚本、API 调用和资源路径会用到它们。
