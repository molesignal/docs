MoleSignal 的每个页面都位于同一个框架中：顶栏、侧边栏和内容区。本页说明它们共用的控件，各产品区域的页面在本手册的其余部分说明。

## 登录

打开 MoleSignal 实例的地址，用以下任一方式登录：

| 方式 | 操作 |
|---|---|
| 邮箱与密码 | 输入 MoleSignal 账号的邮箱和密码。 |
| 单点登录 | 点击已启用服务商的按钮。使用 LDAP 服务商时，先在表单中输入目录用户名和密码。参见[单点登录](/zh-Hans/identity/sso)。 |
| 注册 | 只有实例允许自助注册时才会出现 **注册 →**。新账号要么立即进入，要么等待管理员审批。 |

忘记密码时，点击 **忘记密码？** 并输入账号邮箱。无论邮箱是否存在，页面都给出相同的结果。邮件中的链接 30 分钟后失效，且只能使用一次。新密码至少 8 个字符。

登录后，MoleSignal 打开个人[偏好设置](/zh-Hans/account#偏好设置)中 **进入工作区后打开** 选定的页面，未修改时为 **首页**。

## 选择工作区

界面把当前选中的组织称为**工作区**。顶栏中用户头像旁的工作区切换器显示它的名称。点击即可切换到账号所属的其他组织。

名称前的圆点是系统状态灯：核心 API 正常响应时为绿色，API 报告自身降级时为黄色，控制台无法连接 API 时为红色。控制台大约每 30 秒检查一次，失败后会更快重试。

切换工作区会加载账号在该组织中的权限，新角色无法使用的页面会从导航中消失。

<Note>
  界面使用**工作区**；API 字段和权限键使用 `organization` 与 `org_id`。
</Note>

## 顶栏

| 控件 | 用途 |
|---|---|
| **MoleSignal** 标志 | 打开个人起始页。 |
| 侧边栏开关 | 把侧边栏收起为图标，或重新展开。 |
| 搜索框 | 打开[命令面板](#用命令面板搜索)。 |
| Mole Agent | 在任意页面打开 [Mole Agent](/zh-Hans/agent) 面板。账号可以使用 Mole Agent 时显示。 |
| **NOC 大屏** | 打开面向大屏幕的大屏模式。参见 [NOC 大屏](/zh-Hans/dashboards#noc-大屏)。 |
| **通知** | 列出等待审批的注册、等待批准的状态页草稿，以及需要处理的状态页自动化。 |
| **帮助** | 打开本文档、键盘快捷键，以及显示实例版本的 **关于**。 |
| 主题 | 在深色与浅色主题之间切换，并把选择保存到账号。 |
| 工作区切换器 | 显示当前工作区和系统状态灯，并切换工作区。 |
| 用户头像 | 打开 **账号设置**、**偏好设置**、**通知设置**、**语言** 和 **退出登录**。**退出登录** 会结束浏览器中所有标签页的会话。 |

## 侧边栏

侧边栏的分组方式与本手册一致。

| 分组 | 区域 | 用途 |
|---|---|---|
| 首页 | [**首页**](/zh-Hans/home) | 数据接入健康、当前告警、值班和快速开始。 |
| 观察 | [**仪表盘**](/zh-Hans/dashboards) | 团队共同查看的面板与变量。 |
| | [**指标**](/zh-Hans/metrics) | PromQL、序列、基数与数据质量。 |
| | [**日志**](/zh-Hans/logs) | 搜索事件、探索字段，并打开事件的上下文。 |
| | [**链路**](/zh-Hans/traces) | 查找链路、检查 Span，并对比两条链路。 |
| | [**应用性能**](/zh-Hans/apm) | 服务健康、端点、依赖、错误、SLO 与部署。 |
| | [**用户体验**](/zh-Hans/rum) | 会话、回放、前端错误、Web Vitals 与分析。 |
| | [**Profiles**](/zh-Hans/profiles) | CPU、内存与锁竞争火焰图。 |
| 可靠性 | [**告警**](/zh-Hans/alerting) | 事件、规则、值班排班、升级与静默。 |
| | [**拨测**](/zh-Hans/synthetics) | 从探测位置定时发起的检查。 |
| | [**状态页**](/zh-Hans/status-pages) | 面向客户发布的事件与维护。 |
| AI 运维 | [**Mole Agent**](/zh-Hans/agent) | 对话、调查、自动化、知识与技能。 |
| 数据 | [**数据源**](/zh-Hans/intake) | 接入数据源并确认数据已到达。 |
| | [**数据流**](/zh-Hans/streams) | Schema、保留周期与搜索任务。 |
| | [**流水线**](/zh-Hans/pipelines) | 转换、路由和回填数据。 |
| | [**函数**](/zh-Hans/functions) | 可复用的 VRL 与 JavaScript 转换。 |
| | [**扩展表**](/zh-Hans/extend-tables) | 用于丰富事件的查找表。 |
| 协作 | [**报告**](/zh-Hans/reports) | 定时与共享的报告。 |
| 管理 | [**身份与访问**](/zh-Hans/identity) | 用户、角色、用户组、团队、Token 与单点登录。 |
| | [**设置**](/zh-Hans/settings) | 工作区、通知、数据、安全与平台设置。 |

侧边栏只显示账号权限允许使用的区域。隐藏区域不能代替服务端的权限检查。

把鼠标移到某一项上并点击图钉，即可把它固定到侧边栏顶部的 **已固定** 中。拖动已固定的项可以调整顺序，再次点击图钉即可取消固定。已固定的项保存在浏览器中。

## 保持时间上下文

查询页顶部的时间选择器设置页面的时间范围。

- 选择器底部显示页面时间所用的时区：未用 **更改** 选择其他时区时为个人默认时区。选定的时区作用于当前页面；在日志、链路和指标页上作用于当前查询标签页。**设为我的默认时区** 会把它设为个人默认值。
- 跳转到另一种信号时，会保留时间范围并带上来源的标识。例如从链路跳转到它的日志时，会保留链路的时间窗口并添加 `trace_id` 过滤条件。
- 从命令面板或用[快捷键](#键盘快捷键)可以把当前时间钉为锚点，或复制带时间范围的当前调查链接。

## 用命令面板搜索

按 `⌘K` 或 `Ctrl+K`，或点击搜索框，然后输入以查找：

- 页面、数据流、服务、仪表盘、保存的视图、告警规则和事件；
- 操作：跳转到某个页面，运行 SQL 或 PromQL，把时间范围设为最近 5 分钟到最近 7 天，钉住当前时间，复制调查链接，切换主题或密度，打开设置，创建仪表盘、告警或流水线，接入数据源，显示键盘快捷键，以及退出登录。

按 `Enter` 打开结果。命令面板底部列出了在新的[调查栈](/zh-Hans/correlation#界面中的调查栈)中打开结果、或把结果叠加到当前调查栈顶部所用的按键。

## 键盘快捷键

按 `⌘/` 或 `Ctrl+/`，或打开 **帮助 → 键盘快捷键**，即可列出快捷键。在 Windows 和 Linux 上，用 `Ctrl` 代替 `⌘`，用 `Alt` 代替 `⌥`。

| 快捷键 | 操作 |
|---|---|
| `⌘K` | 打开命令面板。 |
| `⌘/` | 显示键盘快捷键。 |
| `⌘J` | 打开或关闭 Mole Agent 面板。 |
| `⌘⌥E` | 打开时间选择器。 |
| `⌘⌥P` | 钉住或取消钉住时间锚点。 |
| `⌘⌥Y` | 复制调查链接。 |
| `⌘[` / `⌘]` | 在调查栈中后退或前进。 |
| `⌘⌥S` | 跳转到应用性能的服务列表。 |
| `⌘⌥A` | 跳转到告警事件。 |
| `⌘⌥D` | 跳转到仪表盘。 |
| `⌘⌥T` / `⌘⌥L` | 以链路或日志搜索打开调查栈。 |
| `⌘⌥R` | 跳转到用户体验概览。 |
| `⌘⌥F` | 跳转到函数。 |
| `⌘⌥I` | 跳转到身份与访问。 |
| `⌘Esc` | 关闭最上层的浮层。 |

在个人[偏好设置](/zh-Hans/account#偏好设置)中关闭 **启用键盘快捷键** 即可停用快捷键。

## 排查一个问题

一次典型的排查依次经过以下步骤：

<Steps>
  <Step title="从症状开始">
    打开一个事件、仪表盘面板、慢链路、前端错误或热点 Profile。
  </Step>
  <Step title="收窄时间与资源">
    选择最小的有效时间范围，并按服务、数据流、环境或会话过滤。
  </Step>
  <Step title="跨信号跳转">
    使用关联操作打开相关的链路、日志、指标、Profile 或用户体验会话。参见[跨信号关联](/zh-Hans/correlation)。
  </Step>
  <Step title="保留排查结果">
    把查询保存为视图、添加仪表盘面板、创建告警规则，或让 Mole Agent 调查并保留结果。
  </Step>
</Steps>

## 语言与个人设置

在用户菜单的 **语言** 中选择界面语言。选择立即生效并随账号保存，在其他浏览器中打开时也是同一种语言。

个人资料、主题与密度、时区与日期格式、起始页、个人通知和会话都在 **账号设置** 中。参见[账号设置](/zh-Hans/account)。
