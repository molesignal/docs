打开**报告**可管理报告调度、生成历史与可复用模板。

## 选择内容

报告以仪表盘或保存视图为数据源。模板定义可复用的数据源类型、格式和内容默认值；调度计划则将模板绑定到具体资源。

内置模板模式包括平台健康、RUM 体验、告警回顾、SLA 合规和保存查询导出。

## 选择格式

| 格式 | 典型用途 |
|---|---|
| PDF | 通过无头浏览器渲染仪表盘或保存视图。 |
| PNG | 面向协作工具的无头图片渲染。 |
| CSV | 当前以表格形式导出的静态报告元数据。 |
| JSON | 当前面向自动化的静态报告元数据。 |
| SVG | 当前的静态报告摘要卡片。 |

PDF 和 PNG 依赖无头浏览器渲染器。请在 `[scheduled_reports.renderer]` 中配置可访问的 Web 基础
URL。服务器会验证生成文件的签名，不会返回占位内容。CSV、JSON 与 SVG 当前包含报告元数据，
不会执行并导出仪表盘或保存视图的结果行。

## PDF 或 PNG 报告包含的内容

PDF 或 PNG 报告只包含仪表盘或保存视图本身，不包含网页界面的其他部分：没有导航、工具栏和菜单。
页面先说明报告覆盖的范围，随后是仪表盘，或保存视图的结果行。

- **页面尺寸。** 页面宽度等于渲染器视口宽度，高度等于内容的高度，因此 PDF 只有一页，面板和表格行
  都不会被分页截断。超过 16,000 像素高度的内容在 PNG 中被截断，在 PDF 中延续到下一页。
- **外观。** 报告使用浅色主题。语言以及日期和时间格式遵循渲染报告时所用用户的偏好设置。
- **时间范围。** 报告覆盖**数据范围**。**过去 24 小时**与**过去 7 天**以渲染时刻为终点。
  **上一个自然日**、**上一个自然周**和**上一个自然月**是报告时区下完整的日、周、月；一周从周一
  开始。
- **时区。** 页眉、图表坐标轴和 `_timestamp` 列按**报告时区**显示时间。该字段列出全部 IANA 时区及其
  UTC 偏移，可以按名称搜索。
- **失败。** 仪表盘或保存视图无法加载、保存视图的语句执行失败，或页面未在 15 秒内完成数据加载时，
  不生成文件。**立即导出**返回失败原因，定时运行把原因写入每个接收方的投递记录。

### 仪表盘

页面开头是仪表盘的标题与描述，随后是时间范围、时区、每个可见变量的取值和生成时间，之后按仪表盘
的布局排列各个面板。选择**自定义**数据范围时，面板使用最近 1 小时。

### 保存视图

页面开头是保存视图的名称，随后是时间范围、时区、数据流（视图指定了数据流时）、行数和生成时间。
之后是标明查询语言的语句，以及由语句返回的行组成的表格。

- **时间范围。** 选择**自定义**数据范围时，语句在保存视图的**默认时间窗**内执行，以渲染时刻为
  终点。
- **行数。** 表格最多包含 200 行。SQL 语句返回更多行时，行数显示为**仅前 200 行**。PromQL 语句按
  范围查询执行，每个序列的数据点均匀取样，总数不超过 200 行。
- **列。** 结果的每一列对应表格的一列，表格不会超出页面宽度，过长的值自动换行。除 `_timestamp`
  外，值按返回结果原样显示。缺失的值显示为 `—`。
- **数据流。** SQL 语句使用保存视图的**数据流**执行。未指定数据流的视图使用第一个允许查询的日志
  数据流，与**保存的视图**页面上的**打开**一致。工作区内没有这样的数据流时，报告失败。
- **空结果。** 语句没有返回任何行时仍会生成报告，报告注明该时间范围内没有数据。

## 调度与投递

配置数据范围、`every:<n><s|m|h|d>` 间隔、输出格式，以及一个或多个接收方。API 字段虽然名为
`cron`，但当前不会解析五段式 cron 表达式；无法识别的值会回退为 24 小时间隔。接收方 kind 包括：

- `webhook`：把生成字节 POST 到 HTTP(S) URL；
- `s3`：写入 MoleSignal 已配置对象存储中的对象 Key 前缀；
- `email`：当前只验证并记录邮箱地址，尚未真正通过 SMTP 发送。

每个接收方都有独立的投递记录，其中包含状态、尝试次数和错误详情。暂停计划不需要删除配置。

<Warning>
  当前不要依赖 `email` 接收方完成投递。在定时报告 SMTP 接线完成前，请使用 Webhook 或已配置的
  对象存储 Key 前缀。
</Warning>

### 定时报告使用的访问权限

定时投递的 PDF 或 PNG 以最后一次保存报告的登录用户的身份渲染报告页面。报告显示该用户在运行时
可以读取的内容。

- **在哪里查看该用户。** 在**报告**页面打开一份报告，对话框底部显示**运行身份**和该用户的名称。
  没有 `reports.schedule` 的用户通过**查看**打开报告，看到的是同一行。
- **保存。** 每次保存都会设置该用户，仅启用或暂停计划的保存也不例外。拥有 `reports.schedule` 的
  用户保存报告即可接管。报告的运行身份是其他用户时，对话框在**保存更改**旁说明保存后改用你的
  权限取数，**报告计划**列表里的开关给出同样的说明。
- **API。** 定时报告通过 `run_as_user_id` 返回该用户，通过 `run_as_user` 返回该用户的显示名和
  邮箱。报告没有运行身份或该用户的账号已不存在时，`run_as_user` 为 `null`。
- **每次运行时的检查。** 该用户无法再登录组织时，运行失败：账号被停用或删除、成员关系被移除，
  或组织被停用。该用户无法再读取仪表盘（`dashboards.read`）或保存视图（`saved_views.read`），
  或者对保存视图报告而言无法再查询数据流（`streams.query`）时，运行同样失败。每个接收方的投递
  记录写明该用户和原因。
- **API Token。** 使用 API Token 保存的报告没有可用的用户身份，因为 Token 只携带一个角色的访问
  权限，不携带签发该 Token 的用户的访问权限。在登录用户保存报告之前，这类报告的 PDF 和 PNG 投递
  会失败。CSV、JSON 与 SVG 投递不渲染页面，不需要用户身份。
- **会话。** 无头浏览器使用的会话有效期为 10 分钟，页面打印完成后即从浏览器中移除。

**立即导出**和**共享**以发起请求的用户的身份渲染报告。

## 导出与共享

使用**立即导出**从已保存报告生成下载文件。使用**共享**创建登录用户共享、跨工作区共享或受限公开共享。公开报告可以要求密码，也可以按工作区策略禁止 CSV 下载。

## 权限

- `reports.read` 用于查看计划、模板与历史。
- `reports.create` 用于创建报告。
- `reports.edit` 用于更新内容与投递设置。
- `reports.schedule` 用于启用、暂停或立即运行计划。
- `reports.delete` 用于删除报告。
