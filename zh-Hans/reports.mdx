打开**报告**可管理报告调度、生成历史与可复用模板。

## 选择内容

报告以仪表盘或保存视图为数据源。模板定义可复用的数据源类型、格式和内容默认值；调度计划则将模板绑定到具体资源。

内置模板模式包括平台健康、RUM 体验、告警回顾、SLA 合规和保存查询导出。

## 选择格式

| 格式 | 典型用途 |
|---|---|
| PDF | 通过无头浏览器渲染仪表盘或保存视图。 |
| PNG | 面向协作工具的无头图片渲染。 |
| CSV | 当前以表格形式导出的静态报告元数据。 |
| JSON | 当前面向自动化的静态报告元数据。 |
| SVG | 当前的静态报告摘要卡片。 |

PDF 和 PNG 依赖无头浏览器渲染器。请在 `[scheduled_reports.renderer]` 中配置可访问的 Web 基础
URL。服务器会验证生成文件的签名，不会返回占位内容。CSV、JSON 与 SVG 当前包含报告元数据，
不会执行并导出仪表盘或保存视图的结果行。

## 调度与投递

配置数据范围、`every:<n><s|m|h|d>` 间隔、输出格式，以及一个或多个接收方。API 字段虽然名为
`cron`，但当前不会解析五段式 cron 表达式；无法识别的值会回退为 24 小时间隔。接收方 kind 包括：

- `webhook`：把生成字节 POST 到 HTTP(S) URL；
- `s3`：写入 MoleSignal 已配置对象存储中的对象 Key 前缀；
- `email`：当前只验证并记录邮箱地址，尚未真正通过 SMTP 发送。

每个接收方都有独立的投递记录，其中包含状态、尝试次数和错误详情。你可以暂停计划而无需删除配置。

<Warning>
  当前不要依赖 `email` 接收方完成投递。在定时报告 SMTP 接线完成前，请使用 Webhook 或已配置的
  对象存储 Key 前缀。
</Warning>

## 导出与共享

使用**立即导出**从已保存报告生成下载文件。使用**共享**创建登录用户共享、跨工作区共享或受限公开共享。公开报告可以要求密码，也可以按工作区策略禁止 CSV 下载。

## 权限

- `reports.read` 用于查看计划、模板与历史。
- `reports.create` 用于创建报告。
- `reports.edit` 用于更新内容与投递设置。
- `reports.schedule` 用于启用、暂停或立即运行计划。
- `reports.delete` 用于删除报告。
