title: "数据流"
description: "管理各类信号的数据结构、保留策略、可查询性与运行状态。"
---

数据流是采集、查询、数据管道和保留策略共同使用的组织级数据契约。打开**数据流**可查看或配置该契约。

## 数据流类型

| 类型 | 典型内容 |
|---|---|
| `logs` | 结构化事件与应用日志。 |
| `metrics` | 指标样本与标签。 |
| `traces` | OpenTelemetry Span。 |
| `profiles` | 与 pprof 对象关联的性能剖析元数据。 |
| `extend` | 作为扩展表管理、在处理过程中使用的查找数据。 |

不同数据流类型可以使用相同名称。调用 API 或编写自动化时，请始终传入 `stream_type`。

## 生命周期

MoleSignal 可以在首次采集时自动创建数据流，也允许管理员预先声明数据流。数据到达后，数据结构演进会增加兼容字段。

数据流详情提供：

- 数据结构与索引字段；
- 保留与压缩行为；
- 运行与采集状态；
- 是否可查询；
- 对应信号分析器的链接；
- 关联的数据管道与数据源。

如果一个兜底数据源仍需接收数据、但不应出现在查询选择器中，可将 `queryable` 设为 false。路由数据管道仍可读取该数据流。`extend` 数据应通过**扩展表**管理，而不是通用遥测查询路径。

## 保留与删除

保留策略决定压缩器何时删除数据。修改保留时间只会影响后续清理，不会恢复已经删除的文件。

删除数据流是破坏性操作，可能导致仪表盘、保存视图、告警、报告和数据管道失效。删除前请检查依赖关系。

## 权限

| 权限 | 能力 |
|---|---|
| `streams.read` | 列出数据流并查看元数据。 |
| `streams.query` | 查询数据流。 |
| `streams.write` | 向现有数据流写入数据。 |
| `streams.create` | 创建数据流。 |
| `streams.configure` | 修改数据结构相关设置与保留策略。 |
| `streams.delete` | 删除数据流。 |
