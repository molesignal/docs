## 发布记录与升级准备

发布说明以 [GitHub Releases](https://github.com/molesignal/molesignal/releases) 为准。下方列表在浏览器中加载发布详情；即使脚本或 GitHub 请求不可用，仍可通过该链接查看版本、发布日期、变更说明与下载附件。

### 升级前检查

1. 使用 `molesignal --version` 记录当前版本，在发布说明中查找目标版本。
2. 阅读版本之间的兼容性提示与迁移要求，区分预发布版本和正式版本。
3. 按[备份与恢复](/zh-Hans/backup-restore)保护 PostgreSQL、对象存储、配置和加密密钥。
4. 在隔离环境验证历史查询、受控新数据接入、权限和通知行为，再安排生产升级。

[生产检查清单](/zh-Hans/deployment/production-checklist)和[恢复准备](/zh-Hans/best-practices/recovery-readiness)提供验收步骤。规划中的企业能力不等同于已发布功能，具体状态以对应能力页和目标版本说明为准。
