**扩展表** 是保存在 MoleSignal 中的小型「键 → 记录」查找表。[流水线](/zh-Hans/pipelines)的转换在其中按键查找，为事件补充参考数据：把 `service` 映射到所属团队、把账号 ID 映射到套餐档位、把区域代码映射到区域名称，而无需在热路径上调用外部存储。

## 扩展表列表

打开 **扩展表**。页面顶部统计扩展表数和记录数。每张表显示查询键与字段、记录数、使用位置、最近更新时间和状态（**正常** 或 **空表**）。可以按状态和使用情况（**使用中** 或 **未使用**）筛选，并按名称搜索。

## 新建扩展表

点击 **新建扩展表**。向导分为两步。

<Steps>
  <Step title="定义结构">
    填写 **表名** 和 **说明**。选择 **查询键**，即唯一定位一条记录的字段，例如 `customer_id`、`service` 或 `region_code`。添加 **Value 字段**，填写 **字段** 名称、**类型**（**字符串**、**数字**、**布尔值** 或 **对象**）、是否 **必填** 以及说明。不添加 Value 字段时，记录以灵活的 JSON 保存。一张表最多 100 个 Value 字段；字段名只能使用字母、数字、`.`、`-` 和 `_`。
  </Step>
  <Step title="添加或导入数据">
    选择 **从空表开始**，稍后再添加记录；或选择 **粘贴 JSON** 立即导入：每条都带查询键的 JSON 记录数组，或从每个键映射到其记录的对象。
  </Step>
</Steps>

点击 **创建扩展表**。

## 记录

打开一张表。**数据记录** 标签页列出所有记录，可以按查询键或字段值搜索。

| 操作 | 效果 |
|---|---|
| **添加记录** | 用 **表单模式** 或 **JSON 模式** 填写查询键和字段值。查询键已存在时，提示后会覆盖原记录。 |
| **编辑记录** | 修改记录的值。 |
| **查看 JSON** | 显示整条记录，包括没有作为列显示的字段。 |
| **删除记录** | 删除记录，无法撤回。 |
| **导入数据** | 一次写入多条记录，来源可以是 JSON 文件（数组或「键 → 记录」映射）、首行为字段名的 CSV 文件，或粘贴的 JSON 或 CSV。数据中必须包含查询键列。摘要会说明将导入多少条记录，其中多少条会覆盖已有的查询键。 |

## 字段结构、使用位置与设置

| 标签页 | 内容 |
|---|---|
| **字段结构** | 查询键和 Value 字段。**编辑字段** 可以添加字段、修改说明和 **必填**。表中已有记录时，现有字段不能改名、改类型或删除；空表则允许所有修改。表名和查询键不能修改。 |
| **使用位置** | 引用这张表的流水线和保存的查询。修改或删除前请先查看。 |
| **设置** | **表信息**，以及 **危险操作** 中的 **删除扩展表**：删除表及其所有记录。之后查这张表的结果都是 `null`，流水线要写进这张表的事件计为失败，配置了死信数据流时写进去。 |

## 在流水线中查找

流水线有两种方式读表：[**查扩展表补充**](/zh-Hans/pipelines#查扩展表补充)步骤把行里的值带到事件的字段中；VRL 步骤里的 [`lookup(table, key)`](/zh-Hans/functions#查扩展表与-ip-地址) 返回整行：

```ruby
# 为每个事件补充服务所属的团队
.team = lookup("service_meta", .service).team
```

两种方式在各种流水线里都能用，包括[告警流水线](/zh-Hans/pipelines/alert-events)。节点在步骤第一次用到一张表时把它读进内存，保留 30 秒，因此查找不会给流水线运行增加查询或存储开销。记录的增删改在 30 秒内对所有流水线生效。扩展表属于工作区，工作区中的每条流水线都可以使用。

## 由流水线写入

定时流水线可以持续更新一张表：用 **添加目标 → 扩展表**，经过各步骤的每条事件按查询键的值写成一行，参见[写入扩展表](/zh-Hans/pipelines#写入扩展表)。

## 扩展表 API

```bash
# 以 "checkout" 为键写入或更新一条记录
curl -X PUT http://localhost:5080/api/v1/extend_tables/service_meta/rows/checkout \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"team":"payments","tier":"gold"}'
```

| 操作 | 端点 |
|---|---|
| 列出扩展表 | `GET /api/v1/extend_tables` |
| 列出表中的记录 | `GET /api/v1/extend_tables/{table}` |
| 写入或更新记录 | `PUT /api/v1/extend_tables/{table}/rows/{key}` |
| 删除记录 | `DELETE /api/v1/extend_tables/{table}/rows/{key}` |

## 权限

`functions.read` 用于列出扩展表及其使用位置。创建表需要 `functions.create`，修改记录和字段需要 `functions.edit`，删除表需要 `functions.delete`。
