打开 **告警**，完成从发现问题到确认、升级和解决的全过程。[规则](/zh-Hans/alerting/rules)监视一个查询或指标，条件成立时开启[事件](/zh-Hans/alerting/incidents)。事件的[升级策略](/zh-Hans/alerting/on-call#升级策略)通知其中指定的人员和[值班排班](/zh-Hans/alerting/on-call#值班排班)，无人确认时继续向后通知。[通知渠道](/zh-Hans/notification-channels)负责每一次投递。[静默](/zh-Hans/alerting/silences)在维护期间暂停通知，[语义分组](/zh-Hans/alerting/silences#语义分组)把相关事件收成一组。

## 告警中心

| 分区 | 用途 | 指南 |
|---|---|---|
| **告警事件** | 当前在触发的事件：确认、静默、解决与调查。 | [告警事件](/zh-Hans/alerting/incidents) |
| **规则** | 阈值规则、异常规则和实时规则。 | [告警规则](/zh-Hans/alerting/rules) |
| **状态页** | 向客户通报事件与维护。 | [状态页](/zh-Hans/status-pages) |
| **历史** | 过去的事件，可按服务和状态搜索。 | [历史](/zh-Hans/alerting/incidents#历史) |
| **洞察** | 事件量、恢复时间、噪声规则和受影响服务。 | [洞察](/zh-Hans/alerting/incidents#洞察) |
| **分组** | 把相关事件收成一组的语义分组。 | [语义分组](/zh-Hans/alerting/silences#语义分组) |
| **升级** | 通知谁、按什么顺序、何时转给下一级。 | [升级策略](/zh-Hans/alerting/on-call#升级策略) |
| **值班排班** | 轮值与临时替班。 | [值班排班](/zh-Hans/alerting/on-call#值班排班) |
| **静默策略** | 暂停匹配事件的通知。 | [静默策略](/zh-Hans/alerting/silences#静默策略) |

## 配置告警

一个工作区通常按以下顺序准备好第一次告警通知：

<Steps>
  <Step title="接入通知渠道">
    在[设置 → 通知 → 连接器](/zh-Hans/notification-channels)中配置邮件、IM App 或电话与短信等连接器，并让成员在[账号设置 → 通知设置](/zh-Hans/account#通知设置)中绑定个人通知方式。
  </Step>
  <Step title="搭建值班排班">
    按团队的轮值方式创建[值班排班](/zh-Hans/alerting/on-call#创建排班)。
  </Step>
  <Step title="创建默认升级策略">
    创建名为 `default` 的策略，先通知值班排班，再通知负责人。在规则工作台中保存的规则都使用它。参见[默认策略](/zh-Hans/alerting/on-call#默认策略)。
  </Step>
  <Step title="创建并测试规则">
    在[规则工作台](/zh-Hans/alerting/rules#创建阈值规则)中从预设开始，用真实数据测试后保存。
  </Step>
  <Step title="演练">
    用[触发规则](/zh-Hans/api/alerting/trigger-rule)接口有意触发一条规则，确认通知送达、升级会向后推进、确认后升级停止。
  </Step>
</Steps>

关于告警什么、如何路由，参见[让生产告警能够指导响应](/zh-Hans/best-practices/actionable-alerts)和[搭建值班与通知](/zh-Hans/best-practices/on-call-setup)。

## 权限

| 权限 | 能力 |
|---|---|
| `alerts.read` | 读取规则、事件、历史、洞察、分组、静默和通知资源。 |
| `alerts.manage` | 创建和修改规则、升级策略、分组、连接器、模板、通知策略和兜底路由。 |
| `alerts.acknowledge` | 确认和解决事件及事件分组。 |
| `alerts.silence` | 创建、修改和移除静默。 |
| `schedules.read` | 读取排班和当前值班人。 |
| `schedules.manage` | 创建和修改排班、轮值和替班。 |
