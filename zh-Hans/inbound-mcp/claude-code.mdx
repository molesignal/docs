Claude Code 支持远程 Streamable HTTP Server、OAuth 自动发现，以及 local、project、user
三种配置 Scope。

## 使用 OAuth 2.1

<Steps>
  <Step title="添加远程 Server">

    ```bash
    claude mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    `--scope user` 让 Server 在所有项目中可用。省略该参数会保存为当前项目的 Local
    配置；`--scope project` 会写入可共享的 `.mcp.json`。

  </Step>
  <Step title="授权 MoleSignal">

    ```bash
    claude mcp login molesignal
    ```

    也可以打开 Claude Code，运行 `/mcp`，选择 `molesignal` 并完成认证。

  </Step>
  <Step title="验证 Server">

    ```bash
    claude mcp get molesignal
    claude mcp list
    ```

  </Step>
</Steps>

SSH 或无浏览器终端可以打印授权 URL，并在完成授权后把完整 Callback URL 粘贴回 Claude Code：

```bash
claude mcp login molesignal --no-browser
```

## 使用 API Token

在项目 `.mcp.json` 中使用环境变量展开，不要提交 Token：

```json
{
  "mcpServers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer ${MOLESIGNAL_MCP_TOKEN}"
      }
    }
  }
}
```

启动 Claude Code 前设置 `MOLESIGNAL_MCP_TOKEN`。Project Scope Server 首次连接前需要显式确认信任。

参见 [Claude Code MCP 官方文档](https://code.claude.com/docs/en/mcp)。
