VS Code 支持 stdio 与远程 HTTP MCP Server、OAuth 授权、Resources、Prompts 与 Tools。

## 通过 stdio 接入（推荐）

客户端启动 MoleSignal 命令行，由它把消息转给 MoleSignal。需要 Node.js 20 或更高版本。

<Steps>
  <Step title="登录一次">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

浏览器会打开 MoleSignal，同意授权即可；命令行会保存登录并自动续期。

  </Step>
  <Step title="添加 MoleSignal">

在 `.vscode/mcp.json` 中：

```json
{
  "servers": {
    "molesignal": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

从这个文件或 MCP 视图启动服务器，并确认 Server Trust。

  </Step>
</Steps>

没有浏览器时，不用登录，改为在服务器的环境变量中设置 `MOLESIGNAL_URL` 与 `MOLESIGNAL_TOKEN`（API Token）。参见[通过 stdio 接入](/zh-Hans/inbound-mcp#通过-stdio-接入)。

下面各节不用命令行，通过 Streamable HTTP 接入。

## 配置 Server

共享 Workspace 配置使用 `.vscode/mcp.json`。私有全局配置可以从 Command Palette 运行 **MCP: Open User Configuration**。

```json
{
  "servers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="启动 Server">
    打开 `mcp.json` 并选择内联 **Start**，或运行 **MCP: List Servers** 后选择 `molesignal`。
  </Step>
  <Step title="确认信任">
    检查端点并确认 MCP Server Trust。Workspace 配置会共享给协作者，不要在文件中保存凭证。
  </Step>
  <Step title="完成 OAuth">
    VS Code 会跟随 MoleSignal OAuth 发现并打开浏览器授权页。完成授权后回到 Chat Agent Mode。
  </Step>
  <Step title="验证连接">
    运行 **MCP: List Servers**，检查 `molesignal` 状态，并在 Chat View 中确认 Tool。
  </Step>
</Steps>

通过 **Add Context → MCP Resources** 添加 MoleSignal Resource；已发布 Prompt 可以使用 `/molesignal.<prompt>` 调用。

参见 [VS Code MCP 官方文档](https://code.visualstudio.com/docs/agent-customization/mcp-servers)。
