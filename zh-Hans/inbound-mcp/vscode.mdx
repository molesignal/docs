VS Code 支持远程 HTTP MCP Server、OAuth 授权、Resources、Prompts 与 Tools。

## 配置 Server

共享 Workspace 配置使用 `.vscode/mcp.json`。私有全局配置可以从 Command Palette 运行
**MCP: Open User Configuration**。

```json
{
  "servers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="启动 Server">
    打开 `mcp.json` 并选择内联 **Start**，或运行 **MCP: List Servers** 后选择
    `molesignal`。
  </Step>
  <Step title="确认信任">
    检查端点并确认 MCP Server Trust。Workspace 配置会共享给协作者，不要在文件中保存凭证。
  </Step>
  <Step title="完成 OAuth">
    VS Code 会跟随 MoleSignal OAuth 发现并打开浏览器授权页。完成授权后回到 Chat Agent Mode。
  </Step>
  <Step title="验证连接">
    运行 **MCP: List Servers**，检查 `molesignal` 状态，并在 Chat View 中确认 Tool。
  </Step>
</Steps>

通过 **Add Context → MCP Resources** 添加 MoleSignal Resource；已发布 Prompt 可以使用
`/molesignal.<prompt>` 调用。

参见 [VS Code MCP 官方文档](https://code.visualstudio.com/docs/agent-customization/mcp-servers)。
