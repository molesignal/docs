Cursor 支持 stdio MCP Server，以及带 OAuth 认证的远程 Streamable HTTP MCP Server。

## 通过 stdio 接入（推荐）

客户端启动 MoleSignal 命令行，由它把消息转给 MoleSignal。需要 Node.js 20 或更高版本。

<Steps>
  <Step title="登录一次">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

浏览器会打开 MoleSignal，同意授权即可；命令行会保存登录并自动续期。

  </Step>
  <Step title="添加 MoleSignal">

在项目的 `.cursor/mcp.json`，或对所有项目生效的 `~/.cursor/mcp.json` 中：

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

然后在 **Tools & MCP** 中打开 `molesignal`。

  </Step>
</Steps>

没有浏览器时，不用登录，改为在服务器的环境变量中设置 `MOLESIGNAL_URL` 与 `MOLESIGNAL_TOKEN`（API Token）。参见[通过 stdio 接入](/zh-Hans/inbound-mcp#通过-stdio-接入)。

下面各节不用命令行，通过 Streamable HTTP 接入。

## 配置 Server

当前项目使用 `.cursor/mcp.json`；全局配置使用 `~/.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "molesignal": {
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="打开 Tools & MCP">
    打开 **Cursor Settings → Tools & MCP**，找到 `molesignal`。
  </Step>
  <Step title="使用 OAuth 连接">
    选择 **Connect**，在浏览器中完成 MoleSignal 授权。Cursor 会从 MCP
    Protected Resource Metadata 自动发现 OAuth 端点。
  </Step>
  <Step title="验证 Tool">
    确认可用 Tool 中包含 `tool_search`、`call_read_tool` 与 `call_managed_tool`。修改配置后，在 **Tools & MCP** 中重启 Server。
  </Step>
</Steps>

<Warning>
  不要把 Bearer Token 提交到 `.cursor/mcp.json`。交互式 Cursor 会话优先使用 OAuth；
  非交互凭证应使用客户端支持的 Secret 注入机制。
</Warning>

参见 [Cursor MCP 官方文档](https://cursor.com/docs/mcp)。
