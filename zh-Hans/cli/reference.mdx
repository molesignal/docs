## 命令

| 命令 | 选项 | 说明 |
|---|---|---|
| `molesignal login` | `--url <地址>`、`--with-token` | 在浏览器中登录，或用从标准输入读取的 API Token 登录。 |
| `molesignal logout` | 无 | 删除保存的登录，保留地址。 |
| `molesignal status` | `--url`、`--token` | 显示地址、应答的服务器、登录方式和 MCP 工具数。 |
| `molesignal streams` | `--url`、`--token`、`--json` | 列出用户能读取的日志数据流。 |
| `molesignal logs <数据流>` | 见下表 | 输出数据流最新的日志，带 `-f` 时持续输出新日志。 |
| `molesignal mcp` | `--url`、`--token` | 通过 stdio 提供 MoleSignal 的 MCP 工具。 |
| `molesignal --help` | 无 | 输出帮助。 |
| `molesignal --version` | 无 | 输出版本。 |

## `logs` 的选项

| 选项 | 默认值 | 含义 |
|---|---|---|
| `-f`、`--follow` | 关闭 | 持续输出新日志，直到按 **Ctrl+C**。 |
| `-n`、`--lines <数量>` | `100` | 先输出多少条最新的日志，`1` 到 `5000`。 |
| `--since <时长>` | `15m` | 往前看多久。单位：`ms`、`s`、`m`、`h`、`d`。 |
| `--where <条件>` | 无 | 针对数据流字段的 SQL 条件。 |
| `--interval <时长>` | `2s` | 跟随时多久读取一次。 |
| `--json` | 关闭 | 每条日志输出一行 JSON。 |
| `--utc` | 关闭 | 以 UTC 显示时间。 |
| `--url`、`--token` | 保存的登录 | 只对这个命令生效的地址与 API Token。 |

## 环境变量

| 变量 | 含义 |
|---|---|
| `MOLESIGNAL_URL` | MoleSignal 地址，代替 `--url` 或保存的地址。 |
| `MOLESIGNAL_TOKEN` | API Token，代替保存的登录。 |
| `MOLESIGNAL_CONFIG` | 保存登录的文件。默认 `~/.config/molesignal/config.json`。 |
| `NO_COLOR` | 输出不带颜色。 |
| `FORCE_COLOR` | 输出不是终端时也带颜色。 |

选项优先于环境变量，环境变量优先于保存的登录。

## 退出码

| 退出码 | 含义 |
|---|---|
| `0` | 命令成功，或跟随被停止。 |
| `1` | 命令失败，原因输出到标准错误。 |
| `2` | 未知命令。 |
