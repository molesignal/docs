命令行的命令覆盖常用的工作。MoleSignal 工具目录中的其他工具（例如 RUM、性能剖析或状态页的工具）都可以用 `molesignal call` 运行。

## 查找工具

```bash
molesignal tools incident
```

列表显示与这些词最相关的工具，以及调用它做什么（`read` 读取或 `change` 变更）、变更在组织的 Tool Policy 下如何执行，以及工具的用途。不带词时，命令列出用户能调用的全部工具。`--domain` 只保留一个领域，例如 `observability` 或 `alerts_on_call`。

`molesignal tools show` 输出一个工具及其接受的参数（JSON Schema）：

```bash
molesignal tools show list_rum_sessions
```

## 调用工具

```bash
molesignal call list_rum_sessions --since 1h limit=20
```

命令把工具返回的内容以 JSON 输出。参数的写法如下：

| 写法 | 传入 |
|---|---|
| `名称=值` | 按工具 Schema 要求的类型传入：文本、数字、`true` 或 `false`，或由 `a,b` 组成的列表。 |
| `名称:=JSON` | 原样传入 JSON，例如 `match:='{"service":"checkout"}'`。 |
| `父.子=值` | 对象中的字段，例如 `time_range.start_micros=…`。 |
| `--input <文件>` | 从文件读取参数的 JSON 对象，`-` 表示标准输入。之后的参数会加到其中。 |
| `--since`、`--from`、`--to` | 为接受 `time_range` 的工具设置时间窗。 |

会改动内容的工具经过 Tool Policy 执行，参见[变更如何执行](/zh-Hans/cli/changes#变更如何执行)。`--reason`、`--wait`、`--timeout` 和 `--yes` 都适用。参数中的 `reason` 或 `impact` 会原样传给审批。

```bash
molesignal call trigger_alert_rule rule_id=<规则> --reason "测试呼叫"
```

## 打开页面

`molesignal open` 在浏览器中打开 MoleSignal 的一个页面，未指定页面时打开首页：

```bash
molesignal open logs app_logs
```

可以打开的页面有 `home`、`logs`、`metrics`、`traces`、`services`、`incidents`、`oncall`、`synthetics`、`dashboards`、`approvals`、`jobs`、`streams` 和 `agent`。多数页面可以带一个 ID，例如链路、事件或大盘。`--print` 只输出地址。

`logs`、`query`、`traces show`、`incidents show` 和 `services show` 都接受 `--web`，打开它们本要输出的内容。

## 在 Shell 中补全命令

`molesignal completion` 输出一段脚本，用于补全命令、子命令、profile 和数据流名称。数据流名称每隔几分钟获取一次。bash：

```bash
echo 'source <(molesignal completion bash)' >> ~/.bashrc
```

zsh：

```bash
echo 'source <(molesignal completion zsh)' >> ~/.zshrc
```

fish：

```bash
molesignal completion fish > ~/.config/fish/completions/molesignal.fish
```
