MoleSignal 命令行就是 `molesignal` 命令，在 npm 上发布为 `@molesignal/cli`。登录一个 MoleSignal 实例后，它可以：

- 查看并跟随日志，执行 SQL 与 PromQL，把链路画成瀑布图，汇总 APM 服务；
- 列出事件与值班人员，确认和解决事件，运行拨测，执行已批准的变更；
- 在 CI 中上报发布，上传 RUM 的 Source Map 与符号，把脚本的输出发到数据流；
- 调用 MoleSignal 工具目录中的任意工具；
- 通过 stdio 提供 MoleSignal 的 MCP 工具，让 Claude Code、Cursor、Codex、VS Code、Gemini CLI 把它作为 MCP 服务器启动。

读取和变更都经过 MoleSignal 的工具，所以登录用户的权限、组织的 Tool Policy 与审批对命令行同样生效，和 Mole Agent 一致。上报发布、上传调试产物和发送日志调用 MoleSignal 的 API，需要 API Token。

## 前提条件

- Node.js 20 或更高版本。
- 本机能访问的 MoleSignal 实例，以及其中的账号。

## 安装

```bash
npm install -g @molesignal/cli
```

检查安装：

```bash
molesignal --version
```

每个命令也可以不安装直接运行：

```bash
npx -y @molesignal/cli --help
```

## 快速开始

<Steps>
  <Step title="登录">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    浏览器会打开 MoleSignal 的授权页，在页面上点 **授权**。参见[登录](/zh-Hans/cli/sign-in)。
  </Step>
  <Step title="检查设置">
    ```bash
    molesignal doctor
    ```
  </Step>
  <Step title="查看日志">
    ```bash
    molesignal logs app_logs -f
    ```

    参见[查看与跟随日志](/zh-Hans/cli/logs)。
  </Step>
</Steps>

## 命令

| 分组 | 命令 |
|---|---|
| 登录 | `login`、`logout`、`profiles`、`use`、`status`、`whoami`、`doctor`。参见[登录](/zh-Hans/cli/sign-in)。 |
| 日志与查询 | `streams`、`logs`、`query`、`fields`。参见[查看与跟随日志](/zh-Hans/cli/logs)。 |
| 指标、链路与服务 | `metrics`、`traces`、`services`、`search-jobs`。参见[指标、链路与服务](/zh-Hans/cli/observe)。 |
| 值班与变更 | `incidents`、`oncall`、`approvals`、`annotate`、`synthetics`。参见[事件与变更](/zh-Hans/cli/changes)。 |
| 发布与数据 | `deploy`、`source-maps`、`symbols`、`send`、`run`。参见[CI 与发布](/zh-Hans/cli/ci)。 |
| 工具与设置 | `tools`、`call`、`mcp`、`open`、`completion`。参见[调用任意工具](/zh-Hans/cli/tools)与[通过 stdio 提供 MCP](/zh-Hans/cli/mcp)。 |

`molesignal <命令> --help` 说明一个命令及其选项。全部选项也列在[命令参考](/zh-Hans/cli/reference)中。
