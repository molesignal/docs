MoleSignal 命令行就是 `molesignal` 命令，在 npm 上发布为 `@molesignal/cli`。登录一个 MoleSignal 实例后，它可以：

- 输出数据流最新的日志，并持续跟随新到达的日志；
- 通过 stdio 提供 MoleSignal 的 MCP 工具，让 Claude Code、Cursor、Codex、VS Code、Gemini CLI 把它作为 MCP 服务器启动。

每次读取都经过 MoleSignal 的工具，所以登录用户的权限、组织的 Tool Policy 与审批对命令行同样生效，和 Mole Agent 一致。

## 前提条件

- Node.js 20 或更高版本。
- 本机能访问的 MoleSignal 实例，以及其中的账号。

## 安装

```bash
npm install -g @molesignal/cli
```

检查安装：

```bash
molesignal --version
```

每个命令也可以不安装直接运行：

```bash
npx -y @molesignal/cli --help
```

## 快速开始

<Steps>
  <Step title="登录">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    浏览器会打开 MoleSignal 的授权页，在页面上点 **授权**。参见[登录](/zh-Hans/cli/sign-in)。
  </Step>
  <Step title="检查连接">
    ```bash
    molesignal status
    ```
  </Step>
  <Step title="查看日志">
    ```bash
    molesignal logs app_logs -f
    ```

    参见[查看与跟随日志](/zh-Hans/cli/logs)。
  </Step>
</Steps>

## 命令

| 命令 | 说明 |
|---|---|
| `molesignal login` | 在浏览器中登录，或用 API Token 登录。 |
| `molesignal logout` | 删除保存的登录。 |
| `molesignal status` | 显示地址、应答的服务器、登录方式和 MCP 工具数。 |
| `molesignal streams` | 列出用户能读取的日志数据流。 |
| `molesignal logs <数据流>` | 输出数据流最新的日志；`-f` 持续跟随新日志。 |
| `molesignal mcp` | 通过 stdio 为 Agent 工具提供 MoleSignal 的 MCP 工具。 |

每个命令的全部选项见[命令参考](/zh-Hans/cli/reference)。
