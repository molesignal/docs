**Mole Agent** 是内置运维智能体及其产品工作区。

Mole Agent 可以通过服务器注册工具查询日志、指标、链路、RUM、性能剖析、告警、值班数据和报告。Mole Agent 使用当前登录用户的组织与权限；模型提供的组织标识会被忽略。

## 配置模型服务

Mole Agent 需要先配置模型服务，对话才能给出回答。具备 `agent.manage` 权限的管理员按以下步骤添加：

1. 打开 **Mole Agent → 设置 → 模型与推理**，选择 **添加模型服务**。
2. 选择 **服务类型**：OpenAI、Anthropic，或兼容 OpenAI 的端点。
3. 填写 **显示名称**、**默认模型** 与 **API Key**。API Key 只写不读，页面和 API 都不会返回它。
4. 兼容 OpenAI 的端点需要设置 **Base URL**。留空则使用 OpenAI 或 Anthropic 的官方端点。
5. 服务商的默认值不合适时，调整 **超时时间** 与 **最大输出 Token**，然后保存。

模型调用经过 Model Gateway。编辑时让已有的密钥字段留空，会保留已保存的密钥，输入新值则会轮换密钥。环境变量 `MS_AGENT_OPENAI_API_KEY`、`MS_AGENT_ANTHROPIC_API_KEY` 与 `MS_AGENT_COMPATIBLE_API_KEY` 是开发用的回退方式，参见[配置](/zh-Hans/configuration#环境变量)。

## 对话

打开 **Mole Agent → 对话**，选择可用模型，设置时间范围并描述现象。服务、告警、环境或数据流均可固定为调查上下文。

没有启用任何 AI 模型时，对话会在输入框上方给出提示。具备 `agent.manage` 权限的管理员可以通过其中的链接前往 **模型与推理**。

响应可以包含：

- 自然语言结论；
- 工具调用与证据摘要；
- 原始日志、指标、链路或事件链接；
- Token 与模型成本元数据；
- 用于复现的提示词模板版本与内容哈希。

大型原始工具结果会溢写到对象存储。删除对话前，系统会尽力归档对话记录。

## 调查

将复杂问题转为可跟踪的调查。调查会记录：

- 状态与当前步骤；
- 证据对结论的影响；
- 竞争假设与置信度；
- 关联的对话、审批与执行；
- 最终摘要与恢复验证。

## 自动化

自动化用于保存可重复执行的 Mole Agent 工作流。配置项包括触发器、允许使用的工具、执行步骤、审批行为与失败处理。使用**试运行**在不产生真实写操作的情况下验证工作流。

## 审批与执行

具备写能力的工具始终受服务器执行策略约束。

| 风险 | 默认执行模式 |
|---|---|
| L0 | 自动执行。 |
| L1 | 用户确认。 |
| L2 | 单人审批。 |
| L3 | 双人审批。 |
| L4 | 默认禁用；破坏性远程工具至少使用该风险等级。 |

审批会保存拟执行操作，并在策略规定的时间后过期。执行前，服务器会重新验证权限、资源状态、参数、风险与幂等性。执行记录会保留结果与恢复验证。

## 日志巡检

Mole Agent 还可以阅读一条日志数据流并写出报告：可以在 **日志** 中立即巡检一次，也可以在后台按周期巡检。定时巡检会保存每次的报告，并在报告判定有异常时通知。参见[日志巡检](/zh-Hans/log-inspections)。

## Agent 设置

打开 **Mole Agent → 设置**。各分区排成一行，位于 Mole Agent 页签之下：

| 分区 | 用途 |
|---|---|
| **Agent Profile** | Agent 配置，以及其允许使用的工具、超时、数据范围与网络策略。 |
| **模型与推理** | 模型服务商与只写 API Key。 |
| **Prompt 管理** | 内置提示词，以及组织级与个人级的覆盖版本。 |
| **工具与能力** | 工具注册表：每个工具的执行方式、限制与特定环境的最低风险等级，以及受约束的 MCP 服务器及其同步工具。 |
| **Inbound MCP** | 供外部 AI 客户端使用的 MCP 端点。 |
| **数据访问范围** | 默认 Agent 配置可以读取的环境、服务与数据流。 |
| **网络策略** | Agent 配置能否使用需要联网的工具。 |
| **审批规则** | 各风险等级的审批规则。 |

凭据会加密保存，API 永远不会返回凭据原文。

### 工具与能力

工具按产品领域分组列出。打开该分区时各组处于收起状态。可以展开某一组，也可以通过搜索展开包含匹配项的组。**全部**、**只读**、**自动执行**、**需审批** 和 **已停用** 这几个筛选各自显示所含工具的数量。

工具的标题和描述按界面语言显示。工具详情还会显示模型读到的定义，该定义在任何界面语言下都是英文。

### Prompt 管理

内置提示词是只读的，名称按界面语言显示。在内置提示词上选择 **创建覆盖版本**，可以为组织或某个用户替换该提示词。

## 数据处理

Mole Agent 会把对话发送给已配置的模型服务商，其中包括它所调用工具的返回结果。没有配置模型服务时，不会有任何数据离开部署。以下控制项限制 Agent 能够触及的范围：

- **数据访问范围** 限制默认 Profile 可以读取的环境、服务与数据流，始终禁止跨组织访问。
- **网络策略** 决定 Profile 是否可以使用需要网络的工具。新建的 Profile 默认禁用网络。该开关不会启用任意 HTTP、shell、浏览器与开放 MCP 工具。
- **审批规则** 按风险等级要求对写操作进行审批。

模型密钥使用加密根密钥加密，参见[生产检查清单](/zh-Hans/production-checklist)。

## 权限

- `agent.use` 用于打开对话、调查、自动化和执行历史。
- `agent.manage` 用于配置服务商、提示词、工具、Agent 和工作流。
- `agent.approve` 用于审核受控操作。
