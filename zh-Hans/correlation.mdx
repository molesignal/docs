跨信号关联将稳定标识、组织边界与共享时间窗口组合起来。MoleSignal 在服务器生成目标过滤条件，因此无需在页面之间复制 `trace_id`、服务或主机。

## 关联 API

```http
GET /api/v1/web/correlation/{from_kind}/{to_kind}
Authorization: Bearer <jwt>
```

给定起始信号（`from_kind`）的上下文与目标信号（`to_kind`），该端点返回在目标页面上应用的**过滤条件、时间范围和查询预填**。
端点根据调用方发送的上下文计算这些内容，不读取任何遥测数据，只会在服务图中查找一次相邻服务。支持的跳转参见[跨信号关联](/zh-Hans/api/web/correlation)。

## 可用工作流

- **服务图 + RED 指标**，从链路派生，可直接渲染为拓扑视图
  （`GET /api/v1/traces/service_graph`）。
- **时间锚点** —— 一次点击即缩放并把时间范围传播到所有面板。
- **调查栈（Investigation stack）** —— 在 `RUM → 链路 → 日志 → 指标 → 性能剖析` 间来回下钻，边走边压栈，
  从不丢失上下文。

## 相关端点

| 端点 | 用途 |
|---|---|
| `GET /api/v1/web/correlation/{from_kind}/{to_kind}` | 在信号之间跳转时使用的过滤条件、时间范围和查询预填 |
| `GET /api/v1/web/trace/{trace_id}` | 完整链路与所有 Span |
| `GET /api/v1/web/topology` | 服务拓扑视图 |
| `GET /api/v1/traces/service_graph` | 从链路派生的服务图 + RED 指标 |
| `POST /api/v1/web/investigation/blob` | 持久化一个调查栈 |

## Web 界面中的调查栈

Web shell 把关联变成一套工作流：

- **⌘K 命令面板** —— 每个流、仪表盘、告警、保存的视图都触手可及。
- **调查栈**（最多 6 帧）—— 每次下钻压一帧；用 `⌘[` 与 `⌘]` 导航；钉住某帧以在探索时保留当前上下文。
- 每个可点击操作都可用键盘到达。

调查栈可以序列化为短期服务器调查 Blob，用于生成可共享 URL。打开该 URL 时，每个引用资源仍需通过正常授权。
