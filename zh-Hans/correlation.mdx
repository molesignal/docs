跨信号关联让一个问题在不同信号之间连贯地追下去：从一个慢页面到它的后端链路，从链路到它的日志，从指标尖峰到背后的请求。每次跳转都会保留时间窗口，并带上 `trace_id`、服务或主机等标识，无需手动复制。跳转依赖稳定的字段，接入时请保留 `service.name`、`deployment.environment`、`trace_id` 和 `host.name`。

## 跳转入口在哪里

| 起点 | 操作 | 到达 |
|---|---|---|
| 一条日志事件 | 事件带 Trace ID 时的 **调用链** 视图。 | 链路瀑布图，并选中该事件所在的 Span。参见[日志](/zh-Hans/logs#阅读结果)。 |
| 一条链路 | 链路页头的 **相关日志**、**服务指标** 和 **Profiles**。 | 带该 `trace_id` 的日志、相关服务的指标，以及该时间范围的 Profile。参见[链路](/zh-Hans/traces#检查单条-trace)。 |
| 一个 Span | Span 的 **日志**、**指标** 和 **Profile** 标签页。 | 该 Span 的日志行和指标。 |
| 带浏览器会话的链路 | 链路页头的 **用户会话**。 | 发出该请求的用户体验会话。 |
| 一个用户体验会话 | **关联链路**。 | 会话中各请求对应的后端链路。参见 [RUM 探索](/zh-Hans/rum/explorer)。 |
| 指标上的一个数据点 | Exemplar 菱形标记，再点击 **查看 Trace**。 | 该数据点背后的链路。参见[指标](/zh-Hans/metrics#阅读图表)。 |
| 一个应用性能服务 | 服务页上的链接。 | 该服务的链路、日志和用户体验会话。参见[应用性能](/zh-Hans/apm)。 |
| 一个告警事件 | **打开触发查询**、**相关日志**、**相关指标** 和 **在 RUM 中打开**。 | 触发事件的查询，以及事件前后的上下文。参见[告警事件](/zh-Hans/alerting/incidents#事件详情)。 |
| 一个 Profile | Profile 关联的链路。 | 采集该 Profile 期间运行的链路。参见 [Profiles](/zh-Hans/profiles)。 |

## 调查上下文栏

调查进行期间，顶栏下方会出现一个上下文栏，显示调查栈中的帧数、锁定的时间窗口、Trace ID 等关键信号，以及在页面间随行的过滤条件。

| 控件 | 效果 |
|---|---|
| **回到调查工作台** | 返回调查栈。 |
| **返回链路详情** | 返回打开当前页面的那条链路。 |
| 移除过滤器 | 去掉一个随行的过滤条件。 |
| **清除** | 结束调查并清空上下文栏。 |

## 界面中的调查栈

调查栈保存一次下钻的路径：每次跳转都会压入一帧，`⌘[` 和 `⌘]` 在其中后退和前进。调查栈最多保存 6 帧；超出时丢弃最早的未钉住帧，钉住的帧会保留。`⌘⌥T` 和 `⌘⌥L` 分别以链路或日志搜索开始一个调查栈，[命令面板](/zh-Hans/console#用命令面板搜索)可以在新的调查栈中打开结果，或把结果叠加到当前调查栈顶部。

`⌘⌥Y` 复制当前页面的地址，其中带有时间窗口和过滤条件。打开复制的链接时，其中每个资源仍需通过正常的权限检查。

## 关联 API

界面用一次调用计算每次跳转，脚本也可以这样做：

```http
GET /api/v1/web/correlation/{from_kind}/{to_kind}?ctx=<base64url-json>
Authorization: Bearer <token>
```

给定起始信号的上下文和目标信号，端点返回目标页面要应用的过滤条件、时间范围和查询预填。它不读取遥测数据，只在服务图中查找一次相邻服务。支持的跳转参见[跨信号关联](/zh-Hans/api/web/correlation)。

| 端点 | 用途 |
|---|---|
| `GET /api/v1/web/correlation/{from_kind}/{to_kind}` | 计算信号间跳转的过滤条件、时间范围和查询预填。 |
| `GET /api/v1/web/trace/{trace_id}` | 包含全部 Span 的完整链路。 |
| `GET /api/v1/web/topology` | 服务拓扑。 |
| `GET /api/v1/traces/service_graph` | 由链路得出的服务图及 RED 指标。 |
| `POST /api/v1/web/investigation/blob` | 把调查状态保存为 7 天后过期的 Blob。 |
