保存的视图是工作区内共享的、有名称的 SQL 或 PromQL 查询。一次点击即可再次打开，不必重写查询；还可以作为[报告](/zh-Hans/reports)的内容，并在命令面板中查找。在[命令面板](/zh-Hans/console#用命令面板搜索)中选择 **跳转到 Saved views** 即可打开 **保存的视图**。

## 视图列表

页面顶部统计保存视图的数量和已置顶的数量。每个视图显示 **语言**、**数据流**、**标签**、默认 **时间窗** 和更新时间。已置顶的视图带有图钉标记。

| 操作 | 效果 |
|---|---|
| **打开** | 在对应的探索页中，以视图的时间窗（截至当前时间）打开查询。 |
| **置顶** / **取消置顶** | 把视图标记为团队最常用的视图。 |
| **编辑** | 修改视图。 |
| **删除** | 删除视图，无法撤回。 |

**打开** 会在[日志](/zh-Hans/logs)中以 SQL 模式、在视图的数据流上运行 SQL 视图，在[指标](/zh-Hans/metrics)中运行 PromQL 视图。

## 新建保存视图

点击 **新建保存视图**：

| 字段 | 规则 |
|---|---|
| **名称** | 显示在列表和命令面板中的名称。 |
| **语言** | **SQL** 或 **PromQL**。 |
| **默认时间窗** | **打开** 使用的时间窗口：15 分钟、1 小时、6 小时、24 小时或 7 天。 |
| **查询语句** | 查询本身。 |
| **数据流（可选）** | SQL 视图运行的数据流，也用于减少读取的文件。 |
| **标签** | 用逗号分隔的标签，便于以后查找。 |
| **置顶** | 置顶该视图。 |

点击 **创建**。请编写换一个时间窗口也依然成立的查询：时间范围交给时间窗决定，并按 `service.name`、`deployment.environment` 这类稳定字段过滤。

## 在其他地方使用

- [报告](/zh-Hans/reports#保存视图)可以按计划把保存的视图渲染为结果表格。
- 命令面板可以按名称找到保存的视图。
- [数据流](/zh-Hans/streams#数据流详情)的 **使用位置** 标签页列出绑定到它的保存视图。

## 权限

| 权限 | 允许 |
|---|---|
| `saved_views.read` | 列出并打开保存的视图。 |
| `saved_views.create` | 创建保存的视图。 |
| `saved_views.edit` | 修改和置顶保存的视图。 |
| `saved_views.delete` | 删除保存的视图。 |

运行视图还需要 `streams.query`。参见[保存视图 API](/zh-Hans/api/query/list-saved-views)。
