MoleSignal 在三个上下文中进行管理，每个上下文都有自己的页面和权限。

| 上下文 | 谁来管理 | 管理内容 | 指南 |
|---|---|---|---|
| 个人账号 | 每位成员管理自己的账号。 | 个人资料、偏好、个人通知、密码、会话和所属工作区。 | [账号设置](/zh-Hans/account) |
| 工作区 | 组织的 Owner 和 Admin。 | 成员、角色、访问授权、Token、单点登录、工作区设置、通知、数据安全和审计。 | [身份与访问](/zh-Hans/identity)、[设置](/zh-Hans/settings) |
| 平台 `_sys` | 超级管理员，以及被授予平台角色的账号。 | 组织、实例级设置、系统遥测和平台管理员。 | [平台设置](/zh-Hans/settings/platform) |

## 工作区管理

一个新工作区通常依次完成以下步骤：

<Steps>
  <Step title="决定成员如何加入">
    设置[注册策略](/zh-Hans/settings/organization#注册与访问)，并接入使用公司邮箱域名的[单点登录](/zh-Hans/identity/sso)。
  </Step>
  <Step title="分配合适的访问权限">
    为[成员](/zh-Hans/identity/members)分配内置角色，为更窄的职责创建[自定义角色](/zh-Hans/identity/roles#角色)，并把人员分组为[团队](/zh-Hans/identity/teams#团队)，用于值班和资源归属。
  </Step>
  <Step title="为程序提供独立身份">
    为采集器、CI 和自动化创建[服务账号](/zh-Hans/identity/tokens#服务账号)，而不是使用个人 Token。
  </Step>
  <Step title="配置通知">
    配置[连接器、通知策略和兜底路由](/zh-Hans/notification-channels)，让告警和报告送达相关人员。
  </Step>
  <Step title="保护数据">
    为敏感值添加[正则模式与字段遮掩](/zh-Hans/settings/data-security)，并定期查看[审计记录](/zh-Hans/settings/data-security#审计)。
  </Step>
</Steps>

## 平台管理

永久存在的 `_sys` 组织不是普通租户。`_sys` 中的会话只能访问平台权限允许的页面和路由。超级管理员可以进入它；在 `_sys` 的 **身份与访问 → 访问授权** 中被授予平台角色的账号也可以进入。参见[平台授权](/zh-Hans/identity#平台授权)。

| 权限 | 允许 |
|---|---|
| `sys.organizations.read`、`.create`、`.update`、`.disable`、`.delete` | 列出、创建、改名、停用和启用、删除组织。除创建外，授权都可以只限定到一个组织。 |
| `sys.settings.retention.*`、`sys.settings.limits.*`、`sys.settings.signin.*`、`sys.settings.alerting.*`、`sys.settings.topology.*` | 查看和修改保留期、上限、登录、告警评估，以及服务图和集群联邦。 |
| `sys.signing_keys.read`、`sys.signing_keys.rotate` | 列出和轮换给会话签名的密钥。 |
| `sys.clusters.read`、`sys.clusters.manage` | 查看和修改远程集群。 |
| `sys.nodes.read`、`sys.nodes.drain` | 查看节点状态，让节点下线。 |
| `sys.query.admission.read`、`sys.query.admission.manage` | 查看和修改查询准入。 |
| `sys.telemetry.read`、`sys.telemetry.manage` | 读取并配置 MoleSignal 自身的遥测。参见[自身可观测性](/zh-Hans/self-observability)。 |
| `sys.trace_debug.manage` | 开启并配置平台的链路调试。 |
| `sys.administrators.read`、`sys.administrators.manage` | 查看和修改平台角色、策略和授权。 |

租户会话和 `ms_*` API Token 都无法访问受保护的 `_sys` 数据。
