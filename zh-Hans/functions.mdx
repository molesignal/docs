函数用于封装可复用的事件转换。打开 **函数** 可以独立于流水线创建、测试和维护转换逻辑。

## 查找函数

列表包含组织自己的函数和内置预设。列表头部的三个视图用于缩小范围，每个视图带有数量：

| 视图 | 内容 |
|---|---|
| **全部** | 组织的全部函数和内置预设。 |
| **自建** | 组织自己编写的函数。 |
| **内置预设** | 随 MoleSignal 提供的只读函数。 |

搜索同时匹配函数名称和预设的说明。点击组织自己的函数，即可在工作台中打开。

## 语言

| 语言 | 可用条件 | 适用场景 |
|---|---|---|
| VRL | 内置 | 解析、标准化、过滤、脱敏与数据扩展。 |
| JavaScript | 内置 | 更适合使用 JavaScript 表达的处理逻辑。 |
| LLM | 通过 API 配置；需要 `llm_eval_enabled` 与模型服务商 | 用模型输出完成低吞吐分类或数据扩展。 |

VRL 与 JavaScript 都运行在 MoleSignal 二进制内部，不需要配置项，也不需要额外安装。

保存函数时，MoleSignal 会验证并编译源代码。无效代码不会成为当前生效版本。

函数工作台提供 VRL 与 JavaScript。LLM 函数属于高级 API 工作流：函数源码是系统指令，事件是模型输入，`params_schema.output_field` 决定输出字段（默认 `_llm_eval`）。每次运行都会调用一次模型，因此配置项 `[functions].llm_eval_enabled` 默认保持为 `false`，参见[配置](/zh-Hans/configuration#功能与集成)。要让模型为告警事件写摘要，请用[告警流水线](/zh-Hans/pipelines/alert-events#ai-摘要)的 **AI 摘要** 步骤，它不受这个配置项影响。

## 内置预设

每个组织都能看到以下只读的 VRL 函数：

| 函数 | 作用 |
|---|---|
| `add-intake-time` | 添加接入时间戳，用于诊断端到端延迟。 |
| `normalize-logs` | 解析 JSON 格式的 message，添加环境与集群字段，并把 `level` 规范为小写。 |
| `parse-key-value` | 把 logfmt 或 `key=value` 形式的 message 解析为字段，并合并回事件。 |
| `redact-email` | 把 `message` 中的邮箱地址替换为占位符。 |
| `route-by-service` | 规范服务名，并派生出按服务划分的目标数据流（`logs_<service>`）作为路由提示。 |

预设所在的行带有 **内置** 标记和说明，说明按当前登录用户的界面语言显示。点击该行可以阅读源码。

预设不能编辑。需要修改时，在该行或预设面板中选择 **以此为起点**。工作台会打开一个新函数，带上预设的语言和源码，名称为 `<预设名>-copy`。保存后得到组织自己的函数，预设本身不变。

## 编写与测试函数

工作台分为三部分：

- 函数的名称和语言；
- **源代码**，即编辑器，标题旁显示源码的校验状态；
- **测试运行**，包含 JSON 格式的 **样例输入** 和 **样例输出**。

选择 **运行样例**，对样例事件运行编辑器中的源码，不需要先保存。转换后的事件显示在 **样例输出** 下；运行失败时，该位置显示失败原因。

**保存函数** 和 **取消** 位于页面的标题行；已保存的函数还有 **删除函数**。名称或源码为空时，**保存函数** 不可用，悬停提示会说明缺少的内容。在编辑器中按 `⌘ Enter` 或 `Ctrl+Enter` 运行样例，按 `⌘S` 或 `Ctrl+S` 保存。

运行器调用 `POST /api/v1/functions/run`，传入语言、源码和样例事件，并返回转换后的事件：

```bash
curl -X POST http://localhost:5080/api/v1/functions/run \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"language":"vrl","source":".service = downcase!(string!(.service))","input":{"service":"Checkout"}}'
```

```json
{ "output": { "service": "checkout" } }
```

VRL 示例：

```vrl
.service = downcase!(string!(.service))
.severity = upcase(string(.level) ?? "INFO")
if exists(.customer_id) {
  .customer = lookup("customers", .customer_id)
}
```

## 查扩展表与 IP 地址

有两个 VRL 函数读取 MoleSignal 保存的数据。样例运行和流水线的每个 VRL 步骤（包括告警流水线）都可以使用。

| 函数 | 返回 |
|---|---|
| `lookup("<表名>", key)` | [扩展表](/zh-Hans/extend-tables) `<表名>` 中键为 `key` 的那一行，类型为对象；没有时为 `null`。 |
| `geoip_lookup(ip)` | IPv4 或 IPv6 地址所在的位置，类型为对象；查不到时为 `null`。 |

```vrl
# 从扩展表 host_owner 查出主机所属的团队
.team = lookup("host_owner", .host).team

# 客户端所在的位置
place = geoip_lookup(.client_ip)
if is_object(place) {
  .country = place.country
  .city = place.city
}
```

- 两个函数都不会出错。表或行不存在、键不是文本、数字或布尔值、地址无法解析或库里没有，结果都是 `null`；对 `null` 取 `.team` 这样的路径，结果也是 `null`。
- `lookup` 的表名要直接写成字符串，从字段或变量取表名无法编译。数字或布尔值的键按文本查找：`42` 找到键为 `42` 的行。
- `lookup` 读取工作区的扩展表。行的改动多久后能被查到，参见[扩展表](/zh-Hans/extend-tables#在流水线中查找)。
- `geoip_lookup` 读取 [`[mmdb].db_path`](/zh-Hans/configuration#功能与集成) 指定的 [DB-IP](https://db-ip.com) City Lite 库，没有这个文件时返回 `null`。库里没有私有地址。返回的对象包含以下字段中库里有值的那些：

| 字段 | 内容 |
|---|---|
| `country` | 国家的 ISO 3166 代码，例如 `DE`。 |
| `country_name` | 国家的英文名称。 |
| `continent_code` | 洲的代码，例如 `EU`。 |
| `continent` | 洲的英文名称。 |
| `region` | 一级行政区（例如州或省）的英文名称。 |
| `city` | 城市的英文名称。 |
| `latitude`、`longitude` | 经纬度，单位为度。 |

## JavaScript 函数

源码对每个事件运行一次。全局对象 `molesignal` 提供事件和辅助方法：

| 成员 | 用途 |
|---|---|
| `molesignal.fields` | 以对象形式表示的事件。可以读取、修改，也可以赋值为新的对象。 |
| `molesignal.set(name, value)` | 设置字段。 |
| `molesignal.del(name)` | 删除字段。 |
| `molesignal.now()` | 当前时间，自 Unix 纪元起的微秒数。 |
| `molesignal.parse_json(text)` 与 `molesignal.encode_json(value)` | 在 JSON 文本与值之间转换。 |
| `molesignal.sha256(text)` | 文本 UTF-8 字节的 SHA-256 摘要，64 个小写十六进制字符。 |

```js
molesignal.set("severity", String(molesignal.fields.level || "info").toUpperCase());
molesignal.set("seen_at", molesignal.now());
molesignal.del("level");
```

JavaScript 函数运行在隔离的引擎中，有以下限制：

- 运行时间超过 50 毫秒会停止，并报 `js timeout 50ms`。
- 单个函数的堆内存上限为 32 MiB。
- 不提供网络访问、定时器和 `TextEncoder`。

## 使用函数

流水线的步骤运行 VRL。在 **自定义 VRL** 步骤中，**从已保存的函数开始** 把一个 VRL 函数或预设的源码复制到步骤里，之后仍可编辑。步骤保存的是自己的副本：之后修改或删除该函数，都不会改变流水线。

## 权限

- `functions.read` 用于列出和打开函数。
- `functions.create` 和 `functions.edit` 用于管理函数定义。
- `functions.run` 用于执行样例运行器。
- `functions.delete` 用于删除函数定义。
