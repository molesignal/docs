MoleSignal 用权限键授权操作，而不是比较角色名称。同一个用户可以属于多个组织，并在每个组织中持有不同的权限。在侧边栏打开 **身份与访问**，即可管理当前工作区的访问权限。

| 组织结构 | **组织**、**团队** | [组织与团队](/zh-Hans/identity/teams) |

## 授权工作方式

对于已通过身份验证的请求，MoleSignal 依次解析：

1. 主体：用户、服务账号或 API Token；
2. 当前组织，或受保护的平台范围；
3. 主体的角色分配与访问授权；
4. 资源关系，以及已接受的跨组织授权；
5. 路由和目标资源要求的权限。

权限目录、内置角色与权限策略都保存在 PostgreSQL 中。`GET /api/v1/iam/capabilities` 返回 Web 应用用来构建导航的实际生效权限。

<Warning>
  页面可见或角色名称都不等于授权。每个受保护的操作，服务端都会检查准确的权限与资源归属。
</Warning>

## 权限作用域

组织权限只覆盖一个工作区，例如：

- `org.preferences.read` 与 `org.preferences.manage`；
- `org.members.read` 与 `org.members.update`；
- `iam.roles.read`、`iam.roles.manage`、`iam.grants.read` 与 `iam.grants.manage`；
- 数据流、仪表盘、告警、排班、保存的视图、流水线、函数、报告、审计、日志巡检和 Mole Agent 的权限。

平台权限以 `sys.` 开头，只在 `_sys` 组织中生效，控制实例中的组织、系统遥测、链路调试、平台管理员和平台设置。

## 内置角色

| 角色 | 持有的权限 |
|---|---|
| **Owner** | 权限目录中的全部组织权限，不含任何平台权限。 |
| **Admin** | 全部组织权限：除各产品区域外，还包括设置、成员、角色、访问授权、Token、审计、状态页、拨测、服务等级、复盘，以及 Mole Agent 的管理。 |
| **Editor** | 读取并修改数据流、仪表盘、告警与排班、保存的视图、流水线、函数、报告，以及应用性能与用户体验设置，并运行 Mole Agent 自动化和日志巡检。 |
| **Viewer** | 读取数据、仪表盘、告警与排班、保存的视图、流水线、函数和报告，并与 Mole Agent 对话。 |

[权限参考](/zh-Hans/identity/roles#权限参考)列出了每项权限以及持有它的内置角色。内置角色不能编辑。升级新增的权限会在启动时授予 Owner 角色。

职责更窄时，请创建[自定义角色](/zh-Hans/identity/roles#角色)。

## 平台授权

实例配置的 `root` 账号是超级管理员。它不需要任何角色：在任何组织里都持有该组织的权限，在 `_sys` 里持有平台权限，也不是任何组织的 Owner。它的 API Token 持有所属组织的组织权限，永远拿不到平台权限。

其他账号没有授权就进不了平台。在 `_sys` 中，**身份与访问** 有自己的 **角色**、**权限策略** 和 **访问授权**，需要 `sys.administrators.read` 和 `sys.administrators.manage`。内置两个平台角色：

| 角色 | 持有的权限 |
|---|---|
| `platform_admin` | 全部平台权限。 |
| `platform_viewer` | 全部只读的平台权限。 |

授权对象是账号，可以按邮箱查找，账号不需要属于任何组织。授权可以覆盖整个平台，也可以只限定到一个组织：这时只有 `sys.organizations.read`、`.update`、`.disable` 和 `.delete` 生效，而且只对该组织生效。谁也不能授予自己在全平台范围内没有的权限；移除授权后，账号的下一次请求起就失去相应权限。

## 跨工作区访问

访问授权可以把一个组织中的主体与另一个组织中的资源关联起来。服务端会同时检查这层关系与资源权限，授权不会把另一个组织变成主体的当前工作区。参见[跨组织共享资源](/zh-Hans/identity/roles#跨组织共享资源)。

仪表盘和报告另有[资源共享](/zh-Hans/resource-sharing)。公开共享获得的是受限的共享会话，而不是成员身份。

## 平台管理

`_sys` 组织与组织 IAM 相互隔离。租户会话和 `ms_*` Token 都不能列出系统遥测或平台管理员。请使用 `_sys` 中持有相应 `sys.*` 权限的会话。参见[管理概览](/zh-Hans/administration)。
