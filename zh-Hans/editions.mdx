MoleSignal 使用同一套可观测引擎，并提供三种采用方式。它们的主要差异在商业授权、支持方式以及由谁运维平台，而不是遥测模型或查询语义。

| 版本或服务 | 当前状态 | 运维方 | 商业模式 |
|---|---|---|---|
| **OpenSource Edition（开源版）** | 已提供 | 你的团队 | Apache 2.0，自托管 |
| **Enterprise Edition（企业版）** | 可通过商业协议获得 | 你的团队，MoleSignal 提供支持 | 自托管、签名许可证与支持合同 |
| **MoleSignal Cloud** | **候补中，尚未公开提供** | MoleSignal | 规划中的托管服务与按用量套餐 |

<Warning>
  MoleSignal Cloud 暂无公开上线日期。本文档中的 Cloud 内容只用于说明规划方向，不构成当前服务承诺或 SLA。
</Warning>

## 能力矩阵

“内置”表示能力属于当前开源 Runtime。企业能力只有在活动签名许可证包含对应授权项时才会启用；许可证不会绕过 IAM 权限。

| 能力 | 开源版 | 企业版 | Cloud |
|---|---|---|---|
| 日志、指标、链路、性能剖析、APM 与跨信号查询 | 内置 | 内置 | 规划使用同一引擎 |
| 仪表盘、数据流、流水线、函数、告警、拨测与状态页 | 内置 | 内置 | 规划使用同一引擎 |
| Mole Agent 与 Inbound MCP | — | `agent` 授权项 | 规划按套餐控制 |
| SSO 供应商 | — | `sso` 授权项 | 规划按套餐控制 |
| 多集群联邦查询 | 单集群 | `federated_search` 授权项 | 规划由托管拓扑提供 |
| 组织域名管理 | — | `domain_management` 授权项 | 规划按套餐控制 |
| 增强型性能剖析对比 | 仅核心剖析 | `profiling_enhanced` 授权项 | 规划按套餐控制 |
| 基础设施运维与升级 | 你的团队 | 你的团队，厂商提供支持 | 规划由 MoleSignal 负责 |
| 产品内账单与账号支持页面 | — | — | 仅 Cloud 规划提供 |

授权项可以独立于文档分类演进。对于某个具体部署，应始终以服务端返回结果与活动许可证为准。

## 文档中的可用性标记

- 主指南与产品菜单保持一致，使用**观察、可靠性、AI 运维、数据、协作、管理**六个分组。
- 整页都需要许可证的指南会在左侧显示企业版标签，并在正文开头说明要求。
- 只有局部工作流受限时，要求会写在对应章节旁，不会把整篇指南标成企业版专属。
- Cloud 专属或尚未实现的行为始终标记为“规划中”或“候补中”。

## 选择采用方式

- [OpenSource Edition](/zh-Hans/editions/open-source)：自托管 Apache 2.0 Runtime。
- [Enterprise Edition](/zh-Hans/editions/enterprise)：使用签名授权与厂商支持进行自托管。
- [MoleSignal Cloud](/zh-Hans/editions/cloud)：了解规划中的托管模式。
- [企业许可证管理](/zh-Hans/licensing)：上传、验证并激活签名许可证。
