打开 **身份与访问 → 用户**、**邀请** 或 **审批**。列出成员需要 `org.members.read`，这些页面上的所有修改都需要 `org.members.update`。没有这个权限的成员也看得到彼此的名字和头像，事件、排班和升级策略按名字显示负责人，选人时也按名字选；邮箱、角色、团队、登录方式和活跃时间只有持有 `org.members.read` 才看得到。

## 用户

**用户** 列出当前工作区的成员。页面顶部统计用户总数、活跃用户数和待审批用户数。可以按姓名、邮箱或团队搜索，并按角色或状态筛选。

| 列 | 显示内容 |
|---|---|
| **角色** | 成员在当前工作区中的角色。 |
| **所属团队** | 成员所在的[团队](/zh-Hans/identity/teams#团队)。 |
| **登录方式** | **密码**、**OIDC** 或 **SAML**。 |
| **最后活跃** | 最近一次登录时间，或 **从未登录**。 |
| **状态** | **活跃**、**已停用**、**待审批** 或 **已拒绝**。 |

打开行末的菜单可以执行以下操作：

| 操作 | 效果 |
|---|---|
| **查看详情** | 显示成员的身份、成员关系和访问状态。 |
| **修改角色** | 设置成员在当前工作区中的角色，可以是内置角色或[自定义角色](/zh-Hans/identity/roles#角色)。 |
| **停用用户** | 该账号无法再登录任何工作区，成员关系和配置保留。**启用用户** 恢复登录。 |
| **移除成员** | 成员立即失去对当前工作区的访问，账号本身保留。 |
| **审批通过** | 待审批用户才有此操作。参见[审批](#审批)。 |

以下修改会被拒绝：

- 任何人都不能修改自己的角色、停用自己的账号，或把自己移出当前工作区；
- 组织管理员不能修改 Root 用户，即首次启动时按 `[auth].root_email` 创建的账号；
- 不能停用或删除最后一位平台管理员。

切换到其他工作区时，会为那个组织签发新的会话。组织的 ID 与标识永远不变，即使组织名称改变。

## 审批

工作区的[注册策略](/zh-Hans/settings/organization#注册与访问)允许自助加入并要求管理员审批时，新账号会在 **审批** 中等待。顶栏的 **通知** 铃铛也会提示。

- **通过** 激活该账号。
- **拒绝** 把账号标记为已拒绝，账号无法登录，且这一决定无法在本页撤回。

配置了 SMTP 时，MoleSignal 会用工作区的默认语言发邮件：有新注册时通知工作区管理员，审批有结果时通知本人。邮件发送失败不会阻塞注册或审批。

## 邀请

**邀请** 记录一个邮箱地址以及此人应获得的角色，并列出待处理的邀请，包括角色、状态、发送时间和邀请人。

1. 点击 **邀请用户**。
2. 填写 **邮箱**。工作区设置了[邮箱域名](/zh-Hans/identity/sso#邮箱域名)时，地址必须属于其中一个域名。
3. 选择 **角色**，或保留 **组织默认角色**，即自助加入获得的角色。
4. 点击 **发送邀请**。

**重新发送** 把待处理邀请重新标记为已发送，**撤销** 取消邀请。已接受的邀请不能重新发送。

<Note>
  MoleSignal 不会发送邀请邮件，邀请本身也不会创建账号或成员关系。此人需要通过[注册](/zh-Hans/console#登录)或[单点登录](/zh-Hans/identity/sso)加入，再由管理员在 **用户** 中设置角色。
</Note>

## 成员 API

| 操作 | 端点 | 权限 |
|---|---|---|
| 列出用户 | `GET /api/v1/users` | `org.members.read`；没有这个权限的登录成员只拿到名字和头像，API Token 被拒绝 |
| 修改用户 | `PATCH /api/v1/users/{id}` | `org.members.update` |
| 通过或拒绝注册 | `POST /api/v1/users/{id}/approve`、`POST /api/v1/users/{id}/reject` | `org.members.update` |
| 添加或修改成员关系 | `POST /api/v1/orgs/{id}/members` | `org.members.update` |
| 移除成员关系 | `DELETE /api/v1/orgs/{id}/members/{user_id}` | `org.members.update` |
| 列出或创建邀请 | `GET /api/v1/invitations`、`POST /api/v1/invitations` | `org.members.read`、`org.members.update` |
