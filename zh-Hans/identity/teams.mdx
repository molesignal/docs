打开 **身份与访问 → 组织** 或 **团队**。

## 组织

**组织** 是平台页面：它出现在 `_sys` 组织中，需要 `sys.organizations.manage`。页面列出实例中的所有组织，以及账号在每个组织中的角色（没有成员关系时显示 **非成员**）、组织标识和 ID。

**管理 IAM** 会切换到某个组织并打开它的 **身份与访问**。前提是账号是该组织的成员，且组织处于启用状态。

创建组织：

1. 点击 **创建组织**。
2. 填写 **名称** 和 **标识**。标识用于在 API 和资源路径中识别组织，之后不能修改。
3. 点击 **创建组织**。创建者自动成为该组织的 Owner。

停用、启用或删除组织，在同样位于 `_sys` 的[设置 → 组织管理](/zh-Hans/settings/platform#组织管理)中进行。组织不能在自身内部被删除。

## 团队

团队把同一个组织中的成员归到一起，用于：

- [值班排班](/zh-Hans/alerting/on-call)所属的团队，以及[升级策略](/zh-Hans/alerting/on-call#升级策略)的目标；
- 通知[兜底路由](/zh-Hans/notification-channels#配置兜底路由)的范围；
- [访问授权](/zh-Hans/identity/roles#访问授权)的身份主体；
- [Mole Agent](/zh-Hans/agent#组织、团队与个人资源) 对话、知识、技能等团队资源的归属。

创建团队时，点击 **新建团队**，填写 **名称**，选择 **成员**，再点击 **创建团队**。每个成员都必须属于当前组织。点击团队即可修改名称或成员。

**删除** 会移除团队，成员保留各自的账号。团队名下仍有 Mole Agent 资源时不能删除，需要先移交或删除这些资源。

打开 **团队** 需要 `org.members.read`，创建、修改和删除团队需要 `iam.policies.manage`。
