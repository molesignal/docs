Indica al SDK el valor que devolvió la evaluación de un indicador y el SDK lo incluirá en todos los eventos de la vista:

```ts
molesignalRum.addFeatureFlagEvaluation('checkout_v2', 'treatment');
```

Para monitorear un servicio de indicadores, envía al SDK los resultados de las evaluaciones. LaunchDarkly ofrece inspectores y OpenFeature ofrece hooks:

```ts
LDClient.initialize(id, user, {
  inspectors: [{
    type: 'flag-used',
    name: 'molesignal',
    method: (key, detail) => molesignalRum.addFeatureFlagEvaluation(key, detail.value),
  }],
});

OpenFeature.addHooks({
  after: (context, details) => molesignalRum.addFeatureFlagEvaluation(context.flagKey, details.value),
});
```

## La pestaña Indicadores de funcionalidad

**Indicadores de funcionalidad** muestra los indicadores que se evaluaron en las sesiones del intervalo seleccionado, ordenados de mayor a menor número de sesiones. Selecciona uno para comparar sus valores lado a lado: el número de sesiones, la proporción de vistas con errores y la proporción de vistas con señales de frustración. Si se trata de una aplicación web, también puedes comparar el percentil 75 de LCP, INP y CLS. El valor con más vistas con errores aparece en rojo. **Ver estas vistas** abre esas vistas en el explorador.

## Consulta un indicador desde cualquier lugar

Usa `feature_flags.<key>` como nombre de columna para consultar un indicador donde el [explorador](/es/rum/explorer) y la API acepten un campo:

```text
feature_flags.checkout_v2 = 'treatment' AND error.type = 'TypeError'
```

```http
POST /api/v1/rum/aggregate
{ "type": "views", "measures": [{ "fn": "p75", "field": "view.performance.lcp.timestamp" }], "groupBy": ["feature_flags.checkout_v2"] }
```

Lo mismo se aplica a las demás claves de una columna JSON: `context.<key>`, `usr.extra.<key>` y `view.custom_timings.<key>`. `GET /api/v1/rum/keys` enumera las claves disponibles.

En SQL, consulta una clave con `json_text("feature_flags", 'checkout_v2')`, que devuelve el valor como texto o NULL si la fila no contiene la clave. `json_keys("feature_flags")` enumera las claves de una fila.

## Mole Agent

La herramienta `get_rum_feature_flags` enumera los indicadores. Si especificas `flag`, compara los valores del indicador con las mismas métricas.
