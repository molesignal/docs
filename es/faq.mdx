## General

### ¿Qué es MoleSignal?

MoleSignal es una plataforma de código abierto de observabilidad y respuesta a incidentes que se puede alojar íntegramente en infraestructura propia. Reúne la telemetría, las alertas, las guardias, las páginas de estado y la investigación con IA en un solo sistema. Guarda los logs, las métricas, las trazas y los perfiles como archivos Parquet en el almacenamiento de objetos y permite consultar esos datos con SQL y con consultas compatibles con PromQL. Consulta [Conceptos básicos](/es/concepts).

### ¿Qué licencia se aplica?

MoleSignal es de código abierto y se distribuye bajo la licencia Apache 2.0. Consulta [Edición de código abierto](/es/editions/open-source).

### ¿Hay una versión alojada?

MoleSignal Cloud es la versión alojada. Consulta los detalles en [molesignal.com/cloud](https://www.molesignal.com/cloud).

### ¿Qué servicios requiere un despliegue?

PostgreSQL y almacenamiento de objetos. El backend de objetos `local` reemplaza el almacenamiento de objetos en despliegues de un solo nodo y en entornos de desarrollo. No requiere Kafka, Redis ni un servicio de consenso. Consulta [Desplegar MoleSignal](/es/deployment).

### ¿Qué base de datos almacena los metadatos?

PostgreSQL. Configura `[meta_database].dsn` con la cadena de conexión de PostgreSQL. Consulta [Configuración](/es/configuration#base-de-datos-de-metadatos).

### ¿MoleSignal puede ejecutarse sin contenedores?

Sí. MoleSignal se distribuye como un único binario. La [guía de despliegue](/es/deployment) explica cómo desplegarlo con Docker Compose, como binario con systemd y con Kubernetes.

## Datos

### ¿Dónde se guardan los datos?

El almacenamiento de objetos guarda los logs, las métricas y las trazas como archivos Parquet. PostgreSQL almacena los metadatos, las identidades, el catálogo de archivos y los recursos del producto. Hasta que MoleSignal vuelca los registros, los guarda en objetos del registro de escritura anticipada (WAL) en el almacenamiento de objetos. Así, si falla un nodo o su disco, no se pierde ningún registro cuya recepción ya se haya confirmado. Consulta [Copia de seguridad y restauración](/es/backup-restore).

### ¿Cuánto tiempo se conservan los datos?

30 días de forma predeterminada. **Configuración → Retención de datos** en la organización `_sys` define el período predeterminado. Cada flujo puede tener su propio período de retención. Consulta [Flujos](/es/streams).

### ¿Qué protocolos admite la ingesta de datos?

OTLP sobre HTTP y gRPC, `remote_write` de Prometheus, el protocolo `_bulk` de Elasticsearch, el envío de Loki en formato JSON, JSON nativo sobre HTTP y los mecanismos de reenvío de logs de Kinesis Firehose, Cloudflare Logpush y Heroku. Consulta [Fuente de datos](/es/intake).

### ¿Por qué aparecen los registros con una hora incorrecta?

`_timestamp` cuenta los microsegundos transcurridos desde el inicio de la época Unix. Si el valor está en segundos, milisegundos o nanosegundos, los registros aparecen con una hora incorrecta. Consulta [Solución de problemas](/es/troubleshooting#datos-faltantes-o-inesperados).

### ¿Cómo consultar datos con un cliente SQL?

Habilita `[flight_sql]` y conecta DBeaver o un cliente JDBC o ADBC al puerto `5083` con un token de API. Consulta [Conectarse con un cliente de base de datos](/es/query/database-clients).

### ¿Grafana puede leer datos de MoleSignal?

Sí. El complemento de fuente de datos de MoleSignal permite consultar métricas con PromQL, logs y trazas mediante consultas por campos, y cualquier flujo con SQL, tanto en los dashboards como en Explorar y en las reglas de alerta. Consulta [Consultar desde Grafana](/es/query/grafana).

## Cuentas y seguridad

### ¿Cómo iniciar sesión por primera vez?

Al desplegar MoleSignal por primera vez, el sistema crea la cuenta raíz con los valores de `[auth].root_email` y `[auth].root_password`. La configuración de ejemplo usa `admin@example.com` y `admin`. Cambia ambos valores antes de usar el sistema en producción. Consulta [Lista de verificación para producción](/es/deployment/production-checklist).

### ¿Cómo restablecer una contraseña olvidada?

Usa el enlace para restablecer la contraseña en la página de inicio de sesión. MoleSignal envía el enlace por correo electrónico. Para habilitar el envío, configura `[notify.smtp]` y `[http].external_url`.

### ¿Qué hacer si hay demasiados intentos fallidos de inicio de sesión?

Espera el tiempo indicado, usa una llave de acceso o el inicio de sesión único, o restablece la contraseña. Si el sistema rechaza todos los intentos de inicio de sesión al mismo tiempo, revisa [Reconocimiento de IP del cliente](/es/settings/platform#identificación-de-la-ip-del-cliente): si el proxy no está configurado, el sistema atribuye todos los intentos a una sola dirección. Consulta [Límites de inicio de sesión](/es/settings/platform#límites-de-inicio-de-sesión) para conocer los valores.

### ¿Se admite el inicio de sesión único?

Sí. Configura las plataformas predefinidas, como Google, Microsoft, GitHub y Feishu, y los proveedores de OIDC, OAuth 2.0, SAML y LDAP en **Identidad y acceso → Proveedores de SSO** en la interfaz web. MoleSignal guarda la configuración en PostgreSQL. Consulta [Identidad y acceso](/es/identity).

### ¿Qué protege `MS_CIPHER_KEY`?

Es la clave raíz que protege los secretos que MoleSignal guarda en PostgreSQL, como los tokens de API, las credenciales de los conectores de notificaciones y las claves de los proveedores de Mole Agent. Guarda una copia de seguridad de la clave. Consulta [Lista de verificación para producción](/es/deployment/production-checklist).

## Operaciones

### ¿Cómo escalar un despliegue?

Empieza con un solo nodo `standalone`. Para escalar la ingesta, las consultas y las tareas en segundo plano de forma independiente, distribuye los roles entre distintos procesos: el rol `router` sirve la interfaz web y la API, reenvía las operaciones de escritura a los nodos `intake` y envía las consultas a los nodos `querier`. Consulta [Despliegue por roles](/es/deployment/role-based) y [Limitaciones conocidas](/es/limitations).

### ¿Cómo saber qué versión está en ejecución?

Ejecuta `molesignal --version` o llama a `GET /api/v1/version` con un token de portador.

### ¿Dónde obtener ayuda o reportar un problema?

Consulta [Soporte y comunidad](/es/support). Reporta los problemas de seguridad en privado a través de los canales que se indican en esa página.
