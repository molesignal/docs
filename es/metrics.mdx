Abre **Métricas** para consultar con PromQL las series temporales almacenadas en flujos de métricas. Ejecuta cada consulta en una
pestaña. Coloca las pestañas en paralelo y usa **Compartir** para copiar un enlace a la consulta, igual que en
[Registros](/es/logs#pestañas-de-consulta). La barra de direcciones contiene la última expresión ejecutada. Copia esa dirección
para compartir la consulta.

## Buscar una métrica

Abre el **Explorador de métricas** junto al editor o usa **Buscar métricas** y escribe parte del nombre. Cada
métrica muestra su tipo (**contador**, **histograma** o **indicador**) y cuántas etiquetas y campos tiene.
Selecciona una métrica para insertarla en la consulta y ejecutarla. Si el espacio de trabajo está vacío, aparece la opción **Conectar una
fuente de métricas**. Consulta [Fuente de datos](/es/intake).

Si el flujo no recibe datos de una métrica durante su período de retención, la métrica desaparece de la lista.

## Escribir la consulta

El editor tiene dos modos. Cámbialos con los dos íconos junto al título (`</>` para Código y los bloques para Constructor):

- **Código**: escribe directamente en PromQL. **Funciones comunes de PromQL** enumera las funciones más habituales. La
  [matriz de compatibilidad de PromQL](/es/query/promql-subset) enumera todas las funciones disponibles.
- **Constructor**: elige la **Métrica**, usa **Agregar filtro de etiquetas** para cada etiqueta que deba coincidir y elige una **Función**
  (**Métrica sin procesar**, **Tasa**, **Tasa instantánea** o **Incremento**), una **Agregación** (**Suma**,
  **Promedio**, **Máximo** o **Mínimo**) y el **Rango**. Debajo aparece la expresión PromQL generada.
  Si el constructor no puede representar una expresión, como una función con parámetros adicionales, la conserva
  sin cambios hasta que modifiques algún campo del constructor.

```promql
sum by (service_name) (
  rate(http_server_request_duration_seconds_count[5m])
)
```

Haz clic en **Ejecutar**. Usa **Opciones** para configurar la ejecución de la consulta:

| Opción | Valores |
|---|---|
| **Leyenda** | **Automático**, **Detallado** (todas las etiquetas) o **Personalizado** con una plantilla como `{{service}}`. |
| **Formato** | **Serie temporal** o **Tabla**. |
| **Paso** | **automático**, que divide el rango en 1000 pasos, o una duración como `30s` o `5m`. |
| **Tipo** | **Rango** para graficar todo el intervalo de tiempo o **Instantánea** para obtener el valor al final del intervalo. |
| **Ejemplares** | **Activada** muestra los ejemplares que vinculan puntos con trazas. |

**Agregar al tablero** abre un tablero nuevo con la consulta como primer panel. **Borrar consulta** vacía
el editor. Si una consulta válida no devuelve resultados, prueba **Ampliar el intervalo de tiempo 4×** o **Borrar los filtros y volver a intentar**
antes de modificar la expresión.

## Leer el gráfico

- Arrastra sobre el gráfico para ampliar un intervalo de tiempo, arrastra el eje X para desplazar la vista y haz doble clic para
  alejarla. Usa **Restablecer el intervalo de tiempo** para volver al intervalo anterior a los ajustes del gráfico.
- Elige el **Estilo de trazado** (**línea**, **barras** o **puntos**) y el **Apilamiento** (**Desactivado**, **Normal** o
  **Porcentaje**; el apilamiento requiere al menos dos series).
- Usa la leyenda para aislar o comparar series.
- Con los ejemplares activados, selecciona un rombo para ver su traza y usa **Abrir traza** para inspeccionar la solicitud
  asociada al punto.

Al pasar a las trazas o los registros, el intervalo ampliado se conserva.

## Analizar el resultado

**Gráfico**, **Tabla** e **Inspector de consultas** muestran, respectivamente, el gráfico, las filas sin procesar y la consulta
ejecutada. Los paneles que acompañan al resultado describen los datos:

| Panel | Qué muestra |
|---|---|
| **Series** | Cada serie con sus etiquetas y sus valores último, actual, promedio y máximo. |
| **Estadísticas de la consulta** | Series, puntos de datos, filas examinadas, tiempo de ejecución, rango y paso. |
| **Calidad de los datos** | Puntos negativos, datos faltantes y anomalías en las marcas de tiempo. Si un contador muestra tasas negativas, puede que se haya reiniciado, que sus datos hayan llegado fuera de orden o que el tipo sea incorrecto. Usa **Ver anomalías**, **Ver datos sin procesar** o **Inspeccionar el tipo de métrica**. |
| **Etiquetas principales** | Los valores de etiqueta con mayor peso en el resultado. |
| **Resumen estadístico** | La distribución de los valores de todas las series. |
| **Cardinalidad** | Las series activas de la métrica y las filas examinadas. Usa este panel para identificar las etiquetas que generan demasiadas series. |
| **Esquema del resultado** | Las columnas de tiempo, valor y etiquetas del resultado. |

Los [límites de cardinalidad de las métricas](/es/settings/platform#cardinalidad-de-métricas) de la instancia impiden agregar nuevas
series cuando se alcanza el límite. Revisa **Cardinalidad** antes de agregar una etiqueta con muchos valores.

## Correlacionar un pico en una métrica

Selecciona el intervalo del pico, conserva las etiquetas de servicio y entorno y abre las trazas
o los registros relacionados. MoleSignal conserva el intervalo seleccionado al pasar a la siguiente señal. Consulta
[Correlación entre señales](/es/correlation).

## Permisos

Para listar métricas, necesitas `metrics.read`. Para ejecutar consultas PromQL, necesitas `streams.query`. **Agregar al tablero**
requiere `dashboards.create`.
