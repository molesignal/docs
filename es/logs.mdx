Abre **Registros** para buscar en los flujos de registros del espacio de trabajo activo.

## Elige un flujo y un intervalo de tiempo

Selecciona un flujo de registros y configura el intervalo de tiempo más corto que incluya el evento. Los intervalos más cortos
reducen la cantidad de filas examinadas y agilizan la exploración de campos.

MoleSignal puede inferir el esquema de un flujo a medida que llegan los eventos. El panel **Campos** muestra los campos del
flujo y permite agregar filtros sin reescribir toda la consulta.

## Pestañas de consulta

Cada consulta se ejecuta en su propia pestaña. Cada pestaña conserva su flujo, su consulta y su intervalo de tiempo. Una consulta en
una pestaña no afecta a las demás.

- Selecciona **Nueva pestaña** para abrir otra consulta. Puedes tener hasta 10 pestañas abiertas a la vez.
- Abre el menú de una pestaña y selecciona **Cambiar nombre**, **Duplicar** o **Cerrar**.
- Selecciona **Dividir en dos** para mostrar dos pestañas una al lado de la otra. Cada mitad muestra sus propias pestañas. Para mover una pestaña
  a la otra mitad, usa su menú. **Volver a una sola página** cierra la vista dividida.

El navegador conserva las pestañas abiertas por usuario y espacio de trabajo.

## Escribe una consulta

El editor tiene dos modos, **Código** y **Constructor**. Para cambiar de modo, usa los dos íconos junto al título (`</>` para
Código y los bloques para Constructor). Pasa el cursor sobre cada ícono para ver el nombre del modo.

**Código** admite consultas por campos o SQL. El editor ejecuta como SQL cualquier instrucción que empiece por `SELECT` o `WITH`.
El resto se ejecuta como consulta por campos:

| Consulta por campos | Significado |
|---|---|
| `service = 'checkout'` | El campo tiene exactamente este valor. |
| `message contains 'timeout'` | El campo contiene el texto. |
| `MATCH(message, 'timeout')` | Busca una subcadena sin distinguir entre mayúsculas y minúsculas. |
| `MATCH_TEXT(message, 'timeout disk')` | Busca texto completo en un campo con un índice de texto completo. |

Combina las condiciones con `AND` y `OR`, en mayúsculas o minúsculas. `AND` tiene prioridad sobre `OR`. Usa paréntesis
para agrupar condiciones: `level = 'error' AND (service = 'checkout' OR service = 'payments')`. El texto
sin un campo especificado se busca en el campo `message` y puede ser una de las alternativas:
`timeout OR "connection reset"`. Usa comillas para buscar una frase completa, incluso si contiene una palabra como `or`.
Usa `=`, `!=`, `>`, `>=`, `<` y `<=` para hacer comparaciones.

**Constructor** muestra la misma consulta por campos como filas de filtros, una por cada alternativa:
todos los filtros de una fila deben cumplirse, y **O** aparece antes de cada fila salvo la primera. Selecciona **Filtrar** para
agregar un filtro a una fila, u **O** para agregar una fila. Luego elige un campo, una comparación y un valor. Cada
fila tiene su propio texto de búsqueda. Las expresiones entre paréntesis dentro de una fila, como la que usa `OR` en el ejemplo
anterior, se conservan tal como se escribieron. Para editarlas, usa **Código**. El editor no puede mostrar una instrucción SQL como
filtros.

Usa SQL para combinar tablas, usar expresiones o CTE, o calcular agregaciones:

```sql
SELECT "_timestamp", level, msg, trace_id
FROM app
WHERE level = 'error'
ORDER BY "_timestamp" DESC
LIMIT 200;
```

```sql
SELECT level, COUNT(*) AS events
FROM app
GROUP BY level
ORDER BY events DESC;
```

Para ejecutar la consulta, selecciona **Ejecutar** o presiona `⌘ Enter` o `Ctrl+Enter` en el editor. **Referencia de sintaxis de
consultas** muestra ejemplos del modo actual. Consulta [Consultas](/es/query#búsqueda-de-texto) para ver las funciones de búsqueda
de texto.

El planificador limita las consultas a la organización actual, incluso si usan SQL personalizado.

## Explora los campos

El panel **Campos** tiene tres secciones: **Campos visibles**, **Campos indexados** y **Otros
campos**. Los campos con nombres separados por puntos que comparten el primer segmento, como `http.method` y
`http.route`, se abren como un solo grupo.

- Abre un campo para ver sus valores más frecuentes en los resultados. Agrega un valor como filtro de inclusión o de
  exclusión. El filtro restringe toda la consulta: si la consulta contiene alternativas, el editor las agrupa entre paréntesis
  antes de aplicar el filtro.
- Muestra u oculta un campo como columna en los resultados.
- Selecciona **Analizar** en un campo para ver su análisis: el número de valores distintos, las filas
  con y sin valor, las estadísticas si el campo es numérico, la distribución de valores y los valores más
  frecuentes a lo largo del tiempo.

## Lee los resultados

El histograma que aparece sobre los resultados cuenta todos los eventos que coinciden con la consulta dentro del intervalo de tiempo, no
solo los de la página cargada. Puedes consultar los resultados en cuatro vistas:

| Vista | Contenido |
|---|---|
| **Registros** | Los eventos que coinciden con la consulta, uno por fila. |
| **Estadísticas** | Un gráfico de una agregación. Elige la medida (recuento, recuento de valores distintos, promedio, suma, mínimo, máximo, P50, P95 o P99), la agrupación y el tipo de gráfico, o grafica el resultado de una agregación SQL. **Crear panel** guarda el gráfico como un panel de un nuevo tablero. |
| **Inspección con IA** | Un informe que Mole Agent redacta sobre los registros que coinciden con la consulta. Consulta [Inspecciones de registros](/es/logs/inspections). |
| **Patrones** | Los eventos agrupados por patrón, con el recuento y la proporción de cada patrón. |

En la vista **Registros**:

- Usa **Columnas** para seleccionar y ordenar las columnas. Las columnas predeterminadas corresponden a los campos del
  flujo: primero la hora y luego los campos de nivel, servicio y mensaje, si el flujo los incluye.
- Cada página muestra 100, 200, 500, 1,000, 2,000 o 5,000 eventos.
- Haz clic en un evento para abrirlo en un panel lateral junto a los resultados. Arrastra el borde izquierdo del panel para cambiar
  su ancho. El panel conserva el ancho elegido. El encabezado muestra el nivel, la hora, el mensaje y los atributos que
  identifican el evento (servicio, host, entorno, versión y traza). Cada atributo ofrece las mismas acciones que un
  campo. Las vistas son **Campos**, **Traza** si el evento incluye un ID de traza, **Contexto** y
  **JSON sin procesar**. **Traza** muestra el gráfico en cascada de la traza con el span del evento seleccionado. **Contexto**
  muestra las cinco filas anteriores y las cinco posteriores. Desde un campo, agrega un filtro, copia el valor o muestra el
  campo como columna.
- Si hay identificadores, navega a una traza, un servicio, una métrica u otra señal correlacionada.
- Descarga los resultados en formato CSV, texto o JSON.

## Comparte una consulta

La dirección de la página representa la consulta en pantalla. Al ejecutar una consulta, la página agrega a la dirección el flujo, la
instrucción (`q` para una consulta por campos, `sql` para SQL) y la vista de resultados. Al
copiar la dirección de la barra del navegador, compartes la consulta con el intervalo que muestra el selector, como la última
hora. Al recargar la página, la consulta y el editor quedan tal como estaban.

Selecciona **Compartir** para copiar un enlace a la consulta en pantalla. Para abrir el enlace, es necesario iniciar sesión como miembro de la
organización y tener permiso para leer los datos. Elige el intervalo de tiempo del enlace: **Intervalo de tiempo seleccionado**
fija el inicio y el fin que aparecen en pantalla. La otra opción conserva un intervalo relativo, como la
última hora, que se calcula al abrir el enlace.

## Tareas de búsqueda

Si una búsqueda es demasiado grande para una solicitud interactiva, MoleSignal la ejecuta como tarea de búsqueda. Abre
**Flujos → Tareas de búsqueda** para seguir el progreso de la tarea y descargar sus resultados. Consulta
[Flujos](/es/streams#tareas-de-búsqueda).

## Vistas guardadas

Guarda una consulta SQL con un nombre como [vista guardada](/es/saved-views). Vuelve a abrir la vista, ejecuta la consulta
en otro intervalo de tiempo o adjunta la vista a un informe.

<Tip>
  Conserva dimensiones estables como `service.name`, `deployment.environment`, `trace_id` y
  `host.name` durante la ingesta. Estos campos permiten navegar entre señales correlacionadas de forma confiable.
</Tip>

## Permisos

- `streams.read` permite descubrir flujos y esquemas.
- `logs.read` permite consultar la lista de registros, el histograma y las estadísticas de los campos.
- `streams.query` permite ejecutar instrucciones SQL y abrir el contexto.
- `agent.use` permite ejecutar una inspección con IA, que también requiere un modelo de IA habilitado.
- `saved_views.create`, `saved_views.edit` y `saved_views.delete` permiten crear, editar y eliminar vistas guardadas, respectivamente.
