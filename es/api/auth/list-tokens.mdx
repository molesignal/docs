```http
GET /api/v1/auth/tokens
```

Devuelve los metadatos de todos los tokens de API de la organización activa, incluidos los tokens de ingesta predeterminados, los tokens de cliente RUM y los tokens de cuentas de servicio. La llamada nunca devuelve el token en texto plano ni el hash del secreto. Requiere `api_tokens.read`.

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "k7m2q9xv4b",
    "name": "grafana-readonly",
    "tokenKind": "personal",
    "userId": "<user-id>",
    "policyId": null,
    "permissions": ["dashboards.read", "streams.query", "streams.read"],
    "applicationId": null,
    "serviceAccountId": null,
    "expiresAt": 1798000000000000,
    "lastUsedAt": null,
    "revoked": false,
    "createdAt": 1790000000000000
  }
]
```
</ResponseExample>

| Campo | Notas |
|---|---|
| `tokenKind` | `personal`, `serviceAccount`, `default_intake` o `rum_client`. |
| `userId` | Usuario que emitió el token. Un token personal o de ingesta predeterminado actúa en nombre de ese usuario. |
| `policyId` | Política de permisos que sigue el token, o `null` si no tiene una. |
| `permissions` | Permisos asignados de forma fija al token, o `null` si no tiene ninguno. Si tampoco tiene una política, el token puede realizar cualquier acción que se permita al usuario o a la cuenta de servicio en cuyo nombre actúa. |
| `applicationId` | Aplicación vinculada a un token `rum_client`, o `null` si no corresponde. |
| `serviceAccountId` | Cuenta de servicio en cuyo nombre actúa el token, o `null` si no corresponde. |
| `expiresAt` | `null` si el token nunca vence. |
| `lastUsedAt` | `null` hasta el primer uso. |
| `revoked` | `true` tras revocar el token. |

## Tokens propios

```http
GET /api/v1/me/api-tokens
```

Devuelve los tokens personales y el token de ingesta predeterminado del usuario de la sesión, con los mismos campos. La llamada requiere una sesión autenticada y el permiso `personal_tokens.manage`.
