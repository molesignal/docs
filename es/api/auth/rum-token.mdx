```http
GET /api/v1/auth/tokens/rum?applicationId=<id>
```

Devuelve el token de cliente RUM de una [aplicación RUM](/es/rum/applications) y lo crea en la primera llamada. La aplicación debe existir: créala primero. El token tiene el formato `mspat-<36>` y pertenece a la aplicación, no a quien lo solicita: solo concede el permiso `rum.write` para esa aplicación, no da acceso a nada más y nunca caduca. Inclúyelo en el código del navegador o de la aplicación móvil, donde los usuarios finales pueden leerlo. La llamada requiere `api_tokens.issue`.

**Parámetros de consulta**

| Parámetro | Tipo | Obligatorio | Notas |
|---|---|---|---|
| `applicationId` | cadena | Sí | El identificador de una aplicación del espacio de trabajo. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/auth/tokens/rum?applicationId=checkout-web" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KDZpGNwn5vO9dhXyE3am4qhihX",
  "prefix": "c16jb8m5zr",
  "token": "mspat-c16jb8m5zr<secret>",
  "tokenKind": "rum_client",
  "policyId": null,
  "permissions": ["rum.write"],
  "applicationId": "checkout-web",
  "createdAt": 1790000000000000
}
```
</ResponseExample>

La llamada devuelve `400` si `applicationId` no es un identificador válido y `404` si no corresponde a ninguna aplicación. Usa el mismo identificador como valor de `applicationId` en el SDK. Consulta [Aplicaciones RUM](/es/rum/applications#token-de-cliente).
