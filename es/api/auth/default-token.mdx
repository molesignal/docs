```http
GET /api/v1/me/api-tokens/default
```

Devuelve el token de ingesta predeterminado del usuario que inició sesión y lo crea en la primera llamada. A diferencia de otros tokens, devuelve el token en texto sin cifrar en cada llamada, lo que permite que la página **Fuente de datos** muestre un token listo para usar. El token actúa en nombre del usuario y sigue la política integrada **Ingesta de datos**, que incluye los permisos `logs.write`, `metrics.write`, `traces.write`, `profiles.write` y `apm.deploy`. El token nunca caduca y su campo `tokenKind` tiene el valor `default_intake`. La llamada se realiza desde una sesión autenticada y requiere `personal_tokens.manage` y ambos permisos de la política.

<RequestExample>
```bash cURL
curl -b ms-cookies.txt http://localhost:5080/api/v1/me/api-tokens/default
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3JtzUbBKtQCD7mFELKp2zDRum9f",
  "prefix": "r4fp1xwgpe",
  "token": "mspat-r4fp1xwgpe<secret>",
  "tokenKind": "default_intake",
  "policyId": "builtin:data_intake",
  "permissions": null,
  "applicationId": null,
  "createdAt": 1790000000000000
}
```
</ResponseExample>

Usa el token en colectores, agentes y exportadores de SDK. Consulta [Fuente de datos](/es/intake#tokens-de-ingesta).
