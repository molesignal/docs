```http
DELETE /api/v1/auth/tokens/{id}
```

Revoca de inmediato cualquier token de la organización. Toda solicitud posterior con ese token falla con `401` y el mensaje `api token revoked`. La llamada requiere `api_tokens.revoke`.

**Parámetros de ruta**

| Parámetro | Tipo | Notas |
|---|---|---|
| `id` | cadena | El `id` que devuelve la operación de emisión o de listado del token. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

Si el identificador no existe, la llamada devuelve `404`. Si revocas un token que se usa para enviar datos, el emisor deja de enviarlos. Reemplaza primero el token en el emisor.

## Tu propio token

```http
DELETE /api/v1/me/api-tokens/{id}
```

Revoca uno de tus tokens personales o tu token de ingesta predeterminado. Realiza la llamada desde una sesión iniciada con el permiso `personal_tokens.manage`. Si el token no te pertenece, la llamada devuelve `404`.
