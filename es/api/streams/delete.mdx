```http
DELETE /api/v1/streams/{id}
```

Elimina la definición del flujo. El compactador libera el espacio que ocupan los datos almacenados. No puedes eliminar el flujo protegido del sistema `_molesignal`. Eliminar un flujo puede afectar el funcionamiento de los dashboards, las vistas guardadas, las reglas de alerta, los informes y las canalizaciones que lo usan. La llamada requiere `streams.delete`. Para el flujo `_audit`, también requiere `audit.read`; sin ese permiso, devuelve `403`.

**Parámetros de ruta**

| Parámetro | Tipo | Notas |
|---|---|---|
| `id` | cadena | El `id` del flujo. Si el identificador no existe, la llamada devuelve `404`. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/streams/$STREAM_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>
