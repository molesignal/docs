Un presupuesto solo genera avisos cuando una fuente se acerca al límite o lo supera: la ingesta responde y almacena los datos del mismo modo. Consulta [Uso de ingesta y presupuestos](/es/streams#uso-de-ingesta-y-presupuestos).

## Listar presupuestos

```http
GET /api/v1/streams/budgets
```

Devuelve todos los presupuestos de la organización con la etiqueta de su fuente y su estado en el período actual. Requiere `intake_usage.read` o, en la organización `_sys`, `sys.telemetry.read`. Los valores desconocidos se devuelven como `null`.

## Configurar un presupuesto

```http
POST /api/v1/streams/budgets
```

Configura el presupuesto de una fuente. Cada fuente admite un solo presupuesto: si vuelves a configurarlo, se actualiza el existente. Requiere `intake_budgets.manage`. La organización `_sys` no puede configurar presupuestos.

| Campo | Obligatorio | Notas |
|---|---|---|
| `dimension` | Sí | `credential`, `stream` o `service`. |
| `sourceKey` | Sí | La fuente tal como aparece en [Uso de ingesta](/es/api/streams/usage). No puedes asignar un presupuesto a la telemetría de la propia plataforma, a los eventos que no indican un servicio ni a los servicios que exceden el límite. |
| `period` | Sí | `day` o `month`, según el calendario en UTC. |
| `limitSize` | Sí | En MiB, de 1 a 1073741824. |
| `warnPercent` | No | Porcentaje del límite a partir del cual se genera un aviso, de 0 a 99. Con `0`, solo se genera un aviso al agotar el presupuesto. Valor predeterminado: 80. |
| `notifyUserIds` | No | Miembros de la organización que recibirán los avisos, hasta un máximo de 50. De forma predeterminada, recibe los avisos quien configura el presupuesto. Las cuentas de servicio deben especificar los destinatarios. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/streams/budgets" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"dimension":"stream","sourceKey":"logs:app","period":"day","limitSize":102400}'
```
</RequestExample>

## Eliminar un presupuesto

```http
DELETE /api/v1/streams/budgets/{budgetId}
```

Devuelve `204`. Requiere `intake_budgets.manage`.
