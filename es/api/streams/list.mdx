```http
GET /api/v1/streams
```

Devuelve todos los flujos de la organización, ordenados por nombre y tipo, en un arreglo JSON. Cada elemento sigue la estructura que muestra [Obtener un flujo](/es/api/streams/get) e incluye el esquema, la retención explícita (`retention`), la retención calculada (`effectiveRetention`), la configuración y las marcas de tiempo en microsegundos. La llamada requiere `streams.read` o `sys.telemetry.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

La respuesta incluye los flujos protegidos del sistema, como `_molesignal`. Omite `_audit` si el token no tiene el permiso `audit.read`. El nombre y el tipo identifican cada flujo, por lo que un mismo nombre puede aparecer en varios tipos.

## Usa la respuesta

Este endpoint devuelve definiciones de flujos, no registros de telemetría. Úsalo para obtener el ID de un flujo antes de consultar su esquema o cambiar su configuración. Para consultar eventos, usa la [API de consultas](/es/api/query/execute).

| Campo | Interpretación |
|---|---|
| `id` | Identificador estable que usa la API para acceder a un flujo específico. |
| `name` y `streamType` | Juntos identifican el conjunto de datos. No uses solo el nombre como clave del inventario. |
| `schema` | Definiciones de los campos que se usan para crear consultas. |
| `retention` | Retención explícita del flujo. `null` indica que se aplica el valor predeterminado. |
| `effectiveRetention` | Retención efectiva que aplica el flujo. |
| `createdAt`, `updatedAt` | Marcas de tiempo Unix en microsegundos, no en milisegundos. |

## Verifica el acceso y el alcance de los datos

Usa una credencial asociada a la organización que quieres consultar. El permiso `streams.read` o `sys.telemetry.read` permite listar los flujos. Sin `audit.read`, la respuesta omite `_audit`. La ausencia de `_audit` no implica que la recopilación de datos de auditoría esté desactivada.

La respuesta es un arreglo JSON, no un objeto contenedor con un campo `items`. Esta ruta no tiene un parámetro de paginación. Un arreglo vacío indica que no se devolvieron flujos para la organización y el alcance de acceso de la solicitud. No demuestra que otra organización no tenga datos.

Cuando encuentres el par `(name, streamType)` que buscas, pasa su `id` a [Obtener un flujo](/es/api/streams/get). Usa una [consulta de ejemplo](/es/api/query/execute) para confirmar que hay eventos disponibles: la existencia de una definición de flujo no lo garantiza.
