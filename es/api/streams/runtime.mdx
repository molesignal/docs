```http
GET /api/v1/streams/runtime
```

Devuelve el estado en tiempo de ejecución de cada flujo: las filas y los bytes almacenados, la hora de la última recepción, el estado de ingesta y una serie temporal de intervalos. La llamada requiere `streams.read` o `sys.telemetry.read` para la telemetría del sistema. La respuesta omite el flujo `_audit` si el token no tiene el permiso `audit.read`.

**Parámetros de consulta**

| Parámetro | Valor predeterminado | Notas |
|---|---|---|
| `windowSecs` | 86400 | Duración de la ventana, de 3600 a 604800. |
| `bucketCount` | 24 | Cantidad de intervalos de la serie, de 6 a 48. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/runtime?windowSecs=3600" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

| `status` | Significado |
|---|---|
| `healthy` | El flujo recibió datos en los últimos 15 minutos. |
| `delayed` | El flujo recibió sus últimos datos hace más de 15 minutos y menos de 2 horas. |
| `interrupted` | El flujo recibió sus últimos datos hace más de 2 horas. |
| `idle` | El flujo no tiene actividad por diseño, como el flujo de trazas de Mole Agent. |
| `unused` | El flujo nunca ha recibido datos. |
| `unknown` | Las estadísticas no están disponibles. |

`staleIndexFiles` cuenta los archivos que siguen indexados con la configuración que estaba vigente antes del último cambio en un tipo de índice del flujo. El contador baja a 0 a medida que el sistema vuelve a indexar los archivos en segundo plano.
