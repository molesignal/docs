```http
POST /api/v1/streams
```

La primera escritura también crea un flujo. Usa esta llamada para declarar primero un flujo con un esquema explícito, índices, campos cifrados o una política de retención. La llamada requiere `streams.create`.

**Cuerpo**

| Campo | Tipo | Obligatorio | Notas |
|---|---|---|---|
| `name` | cadena | Sí | Letras, números, `_`, `-` y `.`. Los nombres de los [flujos de la plataforma](/es/streams#flujos-de-la-plataforma), como `_molesignal` y `_audit`, están reservados. |
| `streamType` | cadena | Sí | `logs`, `metrics`, `traces`, `profiles` o `extend`. |
| `fields` | arreglo | No | Definiciones de campos. Consulta la sección de abajo. |
| `retentionDays` | entero | No | De 1 a 3650. Omite este campo para usar el valor predeterminado de la plataforma en **Configuración → Retención de datos**. |
| `settings` | objeto | No | Configuración del flujo, como `description` y `queryable`. Consulta [Editar la retención y la configuración](/es/api/streams/edit-retention). |

Cada campo tiene estas propiedades:

| Propiedad | Tipo | Notas |
|---|---|---|
| `name` | cadena | Nombre del campo. |
| `dataType` | cadena | `bool`, `int64`, `float64`, `utf8`, `timestamp` o `json`. |
| `nullable` | booleano | Valor predeterminado: `true`. |
| `indexType` | cadena | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value` o `range`. El valor predeterminado es `none`. |
| `encrypted` | booleano | Cifra el campo en reposo. No puedes cambiar esta opción más adelante. Consulta [Flujos](/es/streams#campos-cifrados). |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "app",
    "streamType": "logs",
    "fields": [
      { "name": "trace_id", "dataType": "utf8", "nullable": true,
        "indexType": "exact", "encrypted": false }
    ],
    "retentionDays": 30
  }'
```
</RequestExample>

**Errores**

| Estado | Causa |
|---|---|
| `403` | El nombre corresponde a un flujo de la plataforma o el token no tiene el permiso `streams.create`. |
| `409` | Ya existe un flujo con el mismo nombre y tipo. |
| `422` | Falta un campo en el cuerpo o uno de sus campos no es válido, por ejemplo, si `dataType` tiene un valor desconocido. La respuesta se devuelve en texto sin formato. |
