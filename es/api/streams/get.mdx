```http
GET /api/v1/streams/{id}
```

Devuelve la definición del flujo con su esquema, el valor explícito de `retention`, el valor calculado de `effectiveRetention` y la configuración del flujo. La llamada requiere `streams.read` o, para la telemetría del sistema, `sys.telemetry.read`. El flujo `_audit` también requiere `audit.read` y devuelve `403` si falta ese permiso.

**Parámetros de ruta**

| Parámetro | Tipo | Notas |
|---|---|---|
| `id` | cadena | El `id` del flujo que devuelve [Listar flujos](/es/api/streams/list). Si la llamada recibe un identificador desconocido, devuelve `404`. |
