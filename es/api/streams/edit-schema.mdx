```http
PUT /api/v1/streams/{id}/settings
```

El esquema de un flujo evoluciona a medida que ingresan nuevos campos, y la API no reemplaza los tipos de campo. Usa este endpoint para elegir el tipo de índice de los campos que ya están en el esquema. La llamada requiere `streams.configure` y, para el flujo `_audit`, también `audit.read`. Usa el mismo endpoint para editar la retención y la configuración. Consulta [Editar la retención y la configuración](/es/api/streams/edit-retention).

**Cuerpo**

| Campo | Tipo | Notas |
|---|---|---|
| `fields` | array | Una entrada por cada campo que quieras configurar. |

Cada entrada de `fields`:

| Propiedad | Tipo | Notas |
|---|---|---|
| `name` | string | Un campo que ya está en el esquema. |
| `indexType` | string | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value` o `range`. Consulta [Flujos](/es/streams#esquema-y-campos). |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexType": "exact" },
      { "name": "msg", "indexType": "full_text" }
    ]
  }'
```
</RequestExample>

La respuesta devuelve el flujo actualizado con la estructura que muestra [Obtener un flujo](/es/api/streams/get). El cambio se aplica de inmediato a los datos que se escriban a partir de ese momento. MoleSignal vuelve a indexar en segundo plano los datos anteriores. Consulta [Flujos](/es/streams#esquema-y-campos). Los índices `full_text`, `ngram` e `ip` solo admiten campos `utf8`, y el índice `key_value` solo admite campos `json`.
