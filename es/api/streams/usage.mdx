```http
GET /api/v1/streams/usage
```

Devuelve cuánto ingirió cada fuente durante un intervalo y cómo se compara ese volumen con su presupuesto. Requiere `intake_usage.read` o `sys.telemetry.read` en la organización `_sys`.

Un valor desconocido se indica con `null`, no con cero. Si no se pueden leer los registros, `available` es `false` y todos los valores son `null`. Si la medición comenzó durante el intervalo, `complete` es `false` y los valores representan límites inferiores.

**Parámetros de consulta**

| Parámetro | Valor predeterminado | Notas |
|---|---|---|
| `dimension` | `credential` | `credential`, `stream` o `service`. |
| `windowSecs` | 86400 | Duración del intervalo, de 3600 a 2678400. El intervalo comienza a la hora en punto. |

`sourceKey` tiene el formato `<credential_kind>:<id>` para una credencial (`apiToken`, `connector`, `user`, `internal`) y `<stream_type>:<name>` para un flujo. Para un servicio, contiene su nombre, una cadena vacía si el evento no especifica un servicio o `*` para los servicios que exceden el límite.

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/usage?dimension=credential&windowSecs=86400" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

## Una sola fuente

```http
GET /api/v1/streams/usage/detail
```

Devuelve el uso de una fuente durante el intervalo: los totales, los datos horarios agrupados en bloques y el desglose por las otras dos dimensiones, con un máximo de 20 fuentes por dimensión.

| Parámetro | Valor predeterminado | Notas |
|---|---|---|
| `dimension` | Obligatorio | `credential`, `stream` o `service`. |
| `sourceKey` | Obligatorio | La fuente, tal como la devuelve `GET /api/v1/streams/usage`. |
| `windowSecs` | 86400 | De 3600 a 2678400. |
| `bucketCount` | 24 | Cantidad de bloques en la serie, de 6 a 48. |
