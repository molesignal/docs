```http
POST /api/v1/loki/api/v1/push
```

Acepta el formato de envío JSON de Loki. La llamada requiere `logs.write` y responde `204` si se realiza correctamente. Cuando el flujo rechaza algunas líneas porque un valor no coincide con el tipo de su campo, las demás líneas se escriben y la respuesta es `400`, que indica cuántas se rechazaron y el primer motivo. Se acepta un cuerpo con `Content-Encoding: gzip`.

El endpoint solo decodifica JSON. Los emisores que usan protobuf comprimido con snappy, como Promtail y Grafana Alloy, no pueden enviar datos a este endpoint. En su lugar, usa OpenTelemetry Collector, Vector o Fluent Bit.

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

Cada valor se convierte en un evento de registro. Las etiquetas se convierten en campos, la línea se convierte en el campo `message` y la marca temporal en nanosegundos se convierte en microsegundos. El encabezado `stream-name` selecciona el flujo de destino y el valor predeterminado es `default`.

## Verifica el ejemplo

El ejemplo genera una marca temporal actual en nanosegundos en un shell de macOS o Linux. Después de recibir `204`, abre **Registros**, selecciona `app` y la última hora, y busca el `message` para `service = 'api'`. Si usas una marca temporal histórica, selecciona una ventana que cubra ese momento del evento y confirma que está dentro del período de retención.

Distingue tres campos: `streams` es la estructura de lote de Loki, la etiqueta `service` se convierte en un campo del evento y el encabezado `stream-name` selecciona el flujo de destino de MoleSignal. Verifica ese flujo y la ventana temporal con una consulta antes de reenviar un lote.
