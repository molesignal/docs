```http
POST /api/v1/loki/api/v1/push
```

Acepta el formato JSON de envío de Loki. La llamada requiere `logs.write` y devuelve `204` si se realiza correctamente. El endpoint acepta cuerpos de solicitud con `Content-Encoding: gzip`.

El endpoint solo decodifica JSON. Los clientes que usan protobuf comprimido con Snappy, como Promtail y Grafana Alloy, no pueden enviar datos a este endpoint. Usa OpenTelemetry Collector, Vector o Fluent Bit en su lugar.

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

Cada valor se convierte en un evento de registro. Las etiquetas se convierten en campos y la línea pasa al campo `message`. El endpoint convierte la marca de tiempo de nanosegundos a microsegundos. El encabezado `stream-name` selecciona el flujo de destino. El flujo predeterminado es `default`.

## Verifica el ejemplo

El ejemplo genera una marca de tiempo actual en nanosegundos en una terminal de macOS o Linux. Después de recibir `204`, abre **Registros**, selecciona `app` y el intervalo de la última hora, y busca el campo `message` de `service = 'api'`. Si usas una marca de tiempo anterior, selecciona un intervalo que incluya la hora del evento y confirma que esté dentro del período de retención.

Distingue estos tres elementos: `streams` es la estructura del lote de Loki, la etiqueta `service` se convierte en un campo del evento y el encabezado `stream-name` selecciona el flujo de destino en MoleSignal. Verifica el flujo y el intervalo de tiempo con una consulta antes de reenviar un lote.
