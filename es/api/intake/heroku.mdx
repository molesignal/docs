```http
POST /api/v1/_heroku
```

Acepta el cuerpo en texto de un drenaje de registros. El endpoint no usa un token de tipo bearer. Crea un conector de tipo `heroku_drain` con un `pushToken` de al menos 16 caracteres y un `target_stream`. Heroku no permite configurar encabezados personalizados, así que incluye el token en la URL con `?token=`. El encabezado `X-Connector-Token` también funciona. Si el token no es válido, el endpoint responde con `401`.

Cada línea se convierte en un evento de registro en el flujo `target_stream` (por defecto, `heroku`). El endpoint guarda la línea completa en el campo `message` y asigna `heroku` al campo `source`. Si la solicitud se procesa correctamente, el endpoint responde con `204`.

<RequestExample>
```bash Heroku CLI
heroku drains:add "https://molesignal.example.com/api/v1/_heroku?token=<pushToken>"
```
</RequestExample>

Consulta [Conectores](/es/connectors) para configurar el conector.

## Verifica la entrega y la selección del flujo

1. Confirma que el conector esté habilitado y que el emisor use el token de envío del conector. Un token de API normal no sustituye a un token de envío.
2. Al configurar `configJson` directamente mediante la API de conectores, usa `target_stream` para indicar el flujo de destino, no `targetStream`. La clave del token sigue siendo `pushToken`, en camelCase.
3. Envía un evento de prueba con un marcador único y anota la hora de recepción. En **Registros**, selecciona el flujo de destino y un intervalo que incluya la hora de recepción. Luego, busca el marcador.
4. Si la solicitud se procesa correctamente pero el flujo de destino está vacío, revisa el flujo predeterminado correspondiente y el valor guardado en el campo de destino. Una confirmación HTTP no sustituye una consulta en el flujo de destino.

Protege el token como una credencial. Si lo incluyes como parámetro de consulta en la URL, no guardes ni compartas la URL completa en registros, tickets ni capturas de pantalla. Antes de reintentar una solicitud fallida, distingue los problemas con el token o con el estado del conector de los errores de formato o compresión de los datos enviados.
