```http
GET /api/v1/audit
```

Devuelve los eventos de auditoría de la organización, del más reciente al más antiguo, con paginación por cursor. La llamada requiere `audit.read`.

Cada evento también es una fila del flujo `_audit` de la organización. Puedes consultar ese flujo y usar un pipeline para enviar los datos a otro destino. Esta API lee los registros oficiales. Consulta [Flujo de auditoría](/es/settings/data-security#flujo-de-auditoría).

El registro de auditoría incluye operaciones sensibles del ciclo de vida. No registra todos los cambios. Los nombres de las acciones de la versión actual comienzan con estos prefijos:

| Prefijo | Operaciones |
|---|---|
| `agent.` | Proveedores de modelos, prompts, herramientas y llamadas a herramientas, servidores MCP, aprobaciones, chats, investigaciones y ejecuciones de Mole Agent. |
| `iam.` | Vinculaciones de roles, relaciones y concesiones de acceso entre organizaciones. |
| `resource_share.` | Creación, rotación, revocación y apertura de enlaces para compartir, e intentos fallidos de introducir la contraseña. |
| `status_page.` | Páginas de estado, componentes, reglas de automatización y logotipos. |
| `synthetic.` | Ubicaciones de monitoreo sintético, agentes y tokens de agentes. |
| `schedule.` | Horarios de guardia y sustituciones. |
| `trace_debug_token.` | Uso de un token de depuración de trazas. |
| `dashboard.` | Paneles creados a partir de un borrador generado por IA. |

El registro no incluye los cambios en flujos, reglas de alerta, incidentes ni conectores.

**Parámetros de consulta**

| Parámetro | Tipo | Notas |
|---|---|---|
| `from`, `to` | cadena | El intervalo de tiempo. Cada valor indica microsegundos desde la época Unix o un tiempo relativo: `now` o `now-<N><unit>` con la unidad `s`, `m`, `h` o `d`, como en `now-30m`. |
| `actorKind` | cadena | El tipo de entidad de seguridad, por ejemplo, `user`. |
| `actor` | cadena | El identificador de la entidad de seguridad. |
| `action` | cadena | El nombre exacto de una acción, como `agent.model_provider.created`. |
| `targetKind`, `targetId` | cadena | El tipo y el identificador del objeto de destino. |
| `limit` | entero | Tamaño de página. El valor predeterminado es `50`. La API ajusta el valor a un mínimo de 1 y un máximo de 200. |
| `cursor` | cadena | El `nextCursor` de la página anterior. El valor es opaco. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/audit?from=now-7d&action=agent.model_provider.created&limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Respuesta**

| Campo | Notas |
|---|---|
| `items[].actor_kind`, `items[].actor_id` | La entidad de seguridad que realizó el cambio. |
| `items[].action` | El nombre de la acción, como `iam.role_binding.create`. |
| `items[].target_kind`, `items[].target_id` | El objeto afectado. Ambos campos pueden ser `null`. |
| `items[].ip`, `items[].user_agent` | La dirección del cliente y el agente de usuario, si la operación registra estos valores. Ambos campos pueden ser `null`. |
| `items[].payload` | Detalles de la operación. Estos datos excluyen los secretos, el contenido de los prompts y los resultados de las herramientas. |
| `items[].ts` | La marca de tiempo del evento en microsegundos. |
| `nextCursor` | El cursor de la página siguiente o `null` en la última página. |
| `retentionDays` | Número de días que la plataforma conserva los registros de auditoría, tanto los propios como los de cada organización. La plataforma elimina los registros más antiguos una vez al día. Usa `0` para conservarlos de forma indefinida. |

**Errores**

| Estado | Causa |
|---|---|
| `400` | `from` o `to` no es un número ni un valor relativo válido (`unparseable time: yesterday`, `bad time unit in: now-3x`), o `cursor` no es válido. |
| `403` | El token no tiene el permiso `audit.read`. |

## Rutas de auditoría relacionadas

| Endpoint | Permiso | Finalidad |
|---|---|---|
| `GET /api/v1/system/audit` | `sys.telemetry.read`, en el ámbito del sistema | Ejecuta la misma consulta para los eventos de auditoría de la organización del sistema. Estos eventos incluyen operaciones como habilitar o deshabilitar una organización, cambiar la política de trazas y modificar el período de retención de auditoría. |
| `GET /api/v1/settings/audit_retention` | `sys.settings.retention.manage`, en el ámbito del sistema | Devuelve el período de retención de auditoría: `{ "retentionDays": 90 }`. |
| `PUT /api/v1/settings/audit_retention` | `sys.settings.retention.manage`, en el ámbito del sistema | Configura el período de retención de auditoría con el mismo cuerpo. `retentionDays` es un número entero entre `0` (conservación indefinida) y `3650`. Si el número supera ese máximo, la API devuelve `400`. |
| `GET /api/v1/settings/audit_retention/preview?retentionDays=30` | `sys.settings.retention.manage`, en el ámbito del sistema | Indica qué registros eliminaría un período de retención más corto: `{ "retentionDays": 30, "previousRetentionDays": 90, "rows": 2400, "earliestAt": 1780000000000000 }`. La API cuenta los registros en lugar de estimar su número. Si el período es más largo o el valor es `0`, la API devuelve `"rows": 0`. |
| `GET /api/v1/agent/audit/chat/{id}` | `audit.read` | Devuelve la transcripción completa de un chat de Mole Agent: el registro `chat` y sus `messages`, con los hashes de los prompts, el recuento de tokens y la evidencia. Si el chat no existe, la API devuelve `404`. |

<Warning>
  La transcripción de un chat contiene las preguntas de los usuarios y las respuestas del modelo. Concede `audit.read` solo a las cuentas autorizadas a leer este contenido.
</Warning>
