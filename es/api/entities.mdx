```http
GET /api/v1/entities
GET /api/v1/entities/detail?kind={kind}&key={key}
```

Las entidades se leen cada cinco minutos de las instancias que ve APM y de los campos de recursos de
las métricas y los logs; consulta [Infraestructura](/es/infrastructure) para ver los campos y las claves. Ambas llamadas necesitan
cualquiera de `apm.services.read`, `metrics.read`, `logs.read` o `sys.telemetry.read`.

## Listar entidades

| Parámetro | Notas |
|---|---|
| `kind` | `cluster`, `node`, `host`, `pod` o `container`. Todos los tipos si se omite. |
| `search` | Parte del nombre o de la clave, sin distinguir mayúsculas y minúsculas. |
| `seenSince` | Solo las entidades vistas desde este momento, en microsegundos. |
| `limit` | Como máximo 500, el valor predeterminado. |

Las entidades se devuelven de la más reciente a la más antigua. `services` cuenta los servicios que se ejecutan en cada una directamente.

<ResponseExample>
```json 200
[
  {
    "kind": "pod",
    "key": "prod-eu/shop/checkout-7d9f-abcde",
    "name": "checkout-7d9f-abcde",
    "attributes": {
      "k8s.cluster.name": "prod-eu",
      "k8s.namespace.name": "shop",
      "k8s.node.name": "node-3",
      "k8s.pod.name": "checkout-7d9f-abcde"
    },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000,
    "services": 1
  }
]
```
</ResponseExample>

## Leer una entidad

`kind` y `key` son obligatorios; la clave es la que devuelve la lista. La respuesta incluye la entidad, sobre qué
se ejecuta o de qué forma parte (`parents`), qué se ejecuta sobre ella o forma parte de ella (`children`, hasta 200), y los
servicios que hay en ella y en lo que se ejecuta sobre ella (`services`, hasta 200), buscados tres niveles hacia abajo: los
nodos de un clúster, sus pods y los servicios que hay en ellos.

<ResponseExample>
```json 200
{
  "entity": {
    "kind": "node",
    "key": "prod-eu/node-3",
    "name": "node-3",
    "attributes": { "k8s.cluster.name": "prod-eu", "k8s.node.name": "node-3" },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000
  },
  "parents": [{ "kind": "cluster", "key": "prod-eu", "name": "prod-eu" }],
  "children": [{ "kind": "pod", "key": "prod-eu/shop/checkout-7d9f-abcde", "name": "checkout-7d9f-abcde" }],
  "services": [{ "namespace": "shop", "name": "checkout", "environment": "production" }]
}
```
</ResponseExample>

**Errores**

| Estado | Causa |
|---|---|
| `400` | `kind` no es uno de los cinco tipos. |
| `404` | No se ha visto ninguna entidad de este tipo y clave durante la última semana. |
