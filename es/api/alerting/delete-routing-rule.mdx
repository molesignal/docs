```http
DELETE /api/v1/alerts/routing/rules/{id}
```

Elimina una [regla de enrutamiento](/es/alerting/routing#reglas-de-enrutamiento). Requiere `alerts.routing.manage`. Las reglas siguientes enrutan los nuevos incidentes que habrían coincidido con la regla eliminada. Los incidentes que ya están abiertos conservan el enrutamiento que recibieron al abrirse, incluido el nombre de la regla registrado en cada uno.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/routing/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "deleted": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1" }
```
</ResponseExample>

**Errores**

| Estado | Causa |
|---|---|
| `403` | El token no tiene el permiso `alerts.routing.manage`. |
| `404` | La regla no existe o pertenece a otra organización. |
