```http
GET /api/v1/alerts/incidents/{id}/rca
POST /api/v1/alerts/incidents/{id}/rca
```

[Mole Agent](/es/agent) redacta un análisis de causa raíz (RCA) a partir del contexto del incidente. Cada incidente tiene como máximo un análisis.

El rol `alert` crea análisis automáticamente. Cada tres minutos, si la organización tiene un proveedor de modelos habilitado con una clave de API, el rol redacta un análisis para hasta 20 incidentes activos que aún no tienen uno. La llamada `GET` lee el análisis almacenado. La llamada `POST` genera un nuevo análisis de inmediato y reemplaza el anterior.

| Llamada | Permiso | Notas |
|---|---|---|
| `GET` | `alerts.incidents.read` | Devuelve `404` con el mensaje `no root-cause analysis for this incident yet` hasta que exista un análisis. |
| `POST` | `alerts.incidents.rca` | Espera la respuesta del modelo y devuelve el nuevo análisis. El parámetro de consulta opcional `locale` selecciona el idioma de salida: `en-us` o `zh-cn`. De forma predeterminada, usa el idioma configurado en la cuenta que realiza la llamada. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/rca?locale=en-us" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Respuesta**

| Campo | Notas |
|---|---|
| `incidentId`, `orgId` | Identificadores del incidente y de la organización. |
| `summary` | Análisis en formato Markdown. |
| `provider`, `model` | Tipo de proveedor de modelos, como `openai`, `anthropic` u `openai_compatible`, y nombre del modelo. |
| `promptBuiltinKey`, `promptHash` | Plantilla de la instrucción y hash de la instrucción generada a partir de ella, para auditoría. |
| `promptTokens`, `completionTokens`, `finishReason` | Consumo de tokens y motivo de finalización que informa el proveedor. |
| `createdAt`, `updatedAt` | Microsegundos desde el inicio de la época Unix. `updatedAt` cambia cada vez que se vuelve a generar el análisis. |

**Errores**

| Estado | Causa |
|---|---|
| `400` | La llamada `POST` no encontró ningún proveedor de modelos habilitado con una clave de API para la organización. |
| `403` | El token no tiene el permiso que requiere la llamada. |
| `404` | El incidente no existe o la llamada `GET` aún no encontró ningún análisis. |
