```http
GET /api/v1/alerts/routing/rules
```

Enumera las [reglas de enrutamiento](/es/alerting/routing#reglas-de-enrutamiento) de la organización en el orden en que se evalúan (`position` ascendente). Requiere `alerts.routing.read`. También incluye las reglas desactivadas.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/rules \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1",
    "orgId": "<organization-id>",
    "name": "Payments in production",
    "enabled": true,
    "position": 0,
    "conditions": [
      { "key": "env", "operator": "equals", "values": ["prod"] },
      { "key": "service.name", "operator": "in", "values": ["checkout", "cart"] }
    ],
    "minSeverity": "error",
    "origins": [],
    "target": { "kind": "team", "teamId": "<team-id>" },
    "createdBy": "<user-id>",

    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

## Campos de la regla

| Campo | Descripción |
|---|---|
| `id`, `orgId` | Identificadores de la regla y de la organización. |
| `name` | Nombre de la regla. |
| `enabled` | Las reglas desactivadas no se evalúan. |
| `position` | Orden de evaluación: primero los valores más bajos. |
| `conditions` | Condiciones que deben cumplir las etiquetas del incidente. Si la lista está vacía, coincide con todos los incidentes. Cada condición tiene `key`, `operator` y `values`. |
| `minSeverity` | Severidad mínima del incidente: `info`, `warning`, `error` o `critical`. Usa `null` para aceptar cualquier severidad. |
| `origins` | Orígenes a los que se aplica la regla: `rule` (reglas de alerta), `external` (fuentes de alertas), `synthetic` (comprobaciones sintéticas). Si la lista está vacía, se aplica a todos los orígenes. |
| `target` | Destino de los incidentes que coinciden con la regla: `{"kind": "team", "teamId": …}` o `{"kind": "policy", "policyId": …}`. |
| `createdBy` | Usuario que creó la regla. |
| `createdAt`, `updatedAt` | Marcas de tiempo de creación y de la última modificación de la regla, en microsegundos. |

Valores de `operator`:

| `operator` | `values` | Coincide cuando |
|---|---|---|
| `equals` | Un valor | El valor de la etiqueta es igual al valor indicado. |
| `not_equals` | Un valor | El valor de la etiqueta es distinto del valor indicado o el incidente no tiene esa etiqueta. |
| `in` | Uno o más valores | El valor de la etiqueta es igual a alguno de los valores indicados. |
| `matches` | Una expresión regular | La expresión regular coincide con el valor completo de la etiqueta. |
