```http
DELETE /api/v1/alerts/sources/{id}
```

Elimina una [fuente de alertas](/es/alerting/sources). Requiere `alerts.sources.manage`. El token de la fuente deja de funcionar de inmediato y el sistema elimina las solicitudes que la fuente recibió recientemente. El sistema resuelve los incidentes abiertos de la fuente en nombre del usuario que realiza la solicitud, ya que sin la fuente esos incidentes nunca recibirían una notificación de recuperación. Si la federación está activada, los demás clústeres resuelven los incidentes abiertos de la fuente en sus respectivos clústeres cuando se sincroniza la eliminación.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Si la operación se completa correctamente, la respuesta es `200` con el texto `deleted`.

**Errores**

| Estado | Causa |
|---|---|
| `403` | El token no tiene el permiso `alerts.sources.manage`. |
| `404` | La fuente no existe. |
