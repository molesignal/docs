Las reglas de [inhibición](/es/alerting/inhibition). Para consultarlas, necesitas `alerts.inhibitions.read`; para modificarlas, necesitas `alerts.inhibitions.manage`.

```http
GET    /api/v1/alerts/inhibit-rules
POST   /api/v1/alerts/inhibit-rules
GET    /api/v1/alerts/inhibit-rules/{id}
PUT    /api/v1/alerts/inhibit-rules/{id}
DELETE /api/v1/alerts/inhibit-rules/{id}
```

**Cuerpo de la solicitud**

| Campo | Tipo | Descripción |
|---|---|---|
| `name` | cadena | Obligatorio, con un máximo de 255 caracteres. |
| `enabled` | booleano | `true` de forma predeterminada. |
| `source.matchers` | arreglo | Condiciones de etiquetas del origen: `{label, op, value}`, donde `op` es `eq`, `neq`, `re` o `nre`. Todas deben cumplirse. |
| `source.min_severity` | cadena | Severidad mínima del origen. Si no indicas un valor, se acepta cualquier severidad. |
| `target.matchers` | arreglo | Condiciones de etiquetas del destino. Si no indicas ninguna, coinciden todos los incidentes. |
| `target.max_severity` | cadena | Severidad máxima del destino. Si no indicas un valor, se acepta cualquier severidad. |
| `equal` | arreglo | Hasta 16 etiquetas que el origen y el destino deben tener con el mismo valor. `source.matchers` y `equal` no pueden estar vacíos a la vez. |
| `moreSevereOnly` | booleano | La severidad del origen debe ser estrictamente mayor que la del destino. `true` de forma predeterminada. |
| `waitSecs` | entero | Tiempo de espera antes de enviar las notificaciones del destino: de 0 a 600, con 60 como valor predeterminado. Los valores inferiores a 15 cuentan como 15. |
| `lingerSecs` | entero | Tiempo durante el cual el origen sigue inhibiendo los destinos tras recuperarse: de 0 a 3600, con 120 como valor predeterminado. |
| `comment` | cadena | Un comentario. |

En las condiciones de etiquetas, `service` y `host` toman los valores del servicio y el host afectados si el incidente no tiene la etiqueta correspondiente. `alert.rule_id` identifica la regla o el origen que abrió el incidente. Una expresión regular no válida produce un error `400`.

Cada regla incluye también `inhibiting`, tanto en la lista como en la vista de detalles. Este campo indica cuántos incidentes inhibe en ese momento.

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/alerts/inhibit-rules" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{
    "name": "On one service, the worse holds back the lesser",
    "equal": ["service"],
    "moreSevereOnly": true

```

## Vista previa

```http
POST /api/v1/alerts/inhibit-rules/preview
```

Usa el mismo cuerpo (puedes omitir `name` y no hace falta guardar la regla) y requiere `alerts.inhibitions.read`. Evalúa solo esta regla sobre los incidentes activos en ese momento, independientemente del valor de `enabled`.

| Campo | Descripción |
|---|---|
| `pairs[].source_incident_id`, `sourceSummary`, `sourceSeverity` | El incidente que inhibe a otro. |
| `pairs[].target_incident_id`, `targetSummary`, `targetSeverity` | El incidente inhibido. |

## Levanta la inhibición de un incidente

```http
POST /api/v1/alerts/incidents/{id}/inhibition/lift
```

Requiere `alerts.incidents.update` sobre el incidente. Envía de inmediato las notificaciones retenidas e impide que se vuelva a inhibir el incidente. Registra la acción en la cronología y en el registro de auditoría. No hace nada si el incidente no está inhibido y devuelve `409` si el incidente ya se resolvió o se fusionó. Devuelve el incidente.

En el JSON del incidente, estos campos indican el estado de inhibición:

| Campo | Descripción |
|---|---|
| `inhibition` | Inhibición actual: `ruleId`, `ruleName`, `sourceIncidentId`, `sourceSummary`, `since` y `endingAt`, que marca el fin de la cuenta regresiva tras la recuperación del origen. El campo se conserva tras la resolución del incidente para indicar que no se enviaron notificaciones durante la inhibición. |
| `inhibitionWaitUntil` | Marca de tiempo (en microsegundos) hasta la que se retienen las notificaciones a la espera de que aparezca un origen. |
| `inhibitionLiftedBy` | Quién levantó la inhibición para que las notificaciones se envíen con normalidad. |
