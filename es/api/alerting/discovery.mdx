```http
GET /api/v1/alerts/discovery/findings
GET /api/v1/alerts/discovery/findings/{id}
```

Enumera los hallazgos que detectó la [detección automática](/es/alerting/discovery), empezando por los observados más recientemente, o consulta un
solo hallazgo. Requiere `alerts.discovery.read`.

**Parámetros de consulta**

| Parámetro | Descripción |
|---|---|
| `status` | `open` (valor predeterminado), `ended` o `all`. |
| `kind` | `apm_anomaly`, `apm_regression`, `rum_new_issue` o `rum_regressed_issue`. |
| `limit` | 100 de forma predeterminada, con un máximo de 500. |

**Campos del hallazgo**

| Campo | Descripción |
|---|---|
| `kind` | Los mismos valores que en los parámetros de consulta. |
| `key` | Identifica un mismo problema por su tipo, entidad y métrica. |
| `severity` | `warning`, `error` o `critical`. |
| `subject` | Un servicio de APM (`namespace/name`) o el identificador de una aplicación de RUM. |
| `environment`, `metric` | El entorno y la métrica que cambió en APM: `errorRate`, `p95` (microsegundos) o `throughput` (solicitudes por segundo). |
| `title` | Una oración. |
| `value`, `baseline` | El valor actual y el valor de referencia. |
| `startedAt`, `lastSeenAt`, `endedAt` | Las marcas de tiempo del inicio, la última detección y el fin (en microsegundos); sin `endedAt`, el hallazgo sigue abierto. |
| `missedRounds` | Rondas consecutivas sin detectar el hallazgo; el hallazgo finaliza tras 3 rondas. |
| `detail` | Un hallazgo de APM incluye `previous`, `lastWeek`, `version`, `previousVersion` y los cambios cercanos en el tiempo en `changes`; un hallazgo de RUM incluye `issueId`, `application`, `errorType`, `location` y `version`. |

Para convertir hallazgos en incidentes, [crea una regla](/es/api/alerting/create-rule) con `query.discovery`:
`{"kinds": [...], "subjects": [...], "environments": [...], "minSeverity": "warning"}`. Omite cualquier filtro para
aceptar todos sus valores. Al guardar la regla, queda configurada para generar un incidente por cada hallazgo que coincida, con la
misma gravedad que el hallazgo y con urgencia baja, salvo que `trigger.urgency` indique otra.
