```http
GET /api/v1/alerts/routing/teams
```

Enumera los equipos de la organización por nombre (sin distinguir entre mayúsculas y minúsculas) e incluye la [política de guardia](/es/alerting/routing#políticas-de-guardia-de-los-equipos) y los servicios a cargo de cada equipo en el catálogo de servicios de APM. Requiere `alerts.routing.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/teams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "teamId": "<team-id>",
    "name": "Payments",
    "memberCount": 4,
    "escalationPolicyId": "<policy-id>",
    "services": ["default/checkout", "default/cart"]
  }
]
```
</ResponseExample>

| Campo | Descripción |
|---|---|
| `teamId`, `name` | El ID y el nombre del equipo. |
| `memberCount` | La cantidad de miembros del equipo. |
| `escalationPolicyId` | La política de guardia del equipo. Si el equipo no tiene una política configurada, el valor es `null` y sus incidentes siguen la política predeterminada. |
| `services` | Los servicios no archivados que figuran a cargo del equipo en el catálogo de servicios, con el formato `namespace/name`. |
