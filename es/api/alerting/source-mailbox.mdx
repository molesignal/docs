```http
GET    /api/v1/alerts/sources/{id}/mailbox
PUT    /api/v1/alerts/sources/{id}/mailbox
DELETE /api/v1/alerts/sources/{id}/mailbox
POST   /api/v1/alerts/sources/{id}/mailbox/test
```

Buzón IMAP que lee una [fuente de correo electrónico](/es/alerting/sources#correo-electrónico). Para leer la configuración, se requiere `alerts.sources.read`; para cambiarla o probarla, se requiere `alerts.sources.manage`. Solo las fuentes de tipo `email` tienen un buzón. El buzón se configura en el clúster receptor de la fuente y no se sincroniza mediante la federación. Antes de enviar un `PUT`, configura la lista de remitentes en la fuente (`email.allowed_senders`).

**Cuerpo de `PUT` y `test`**

| Campo | Tipo | Descripción |
|---|---|---|
| `host` | cadena | Obligatorio: un nombre de host sin esquema ni puerto. |
| `port` | entero | 993 de forma predeterminada. |
| `security` | cadena | `tls` (predeterminado), `starttls` o `none`. |
| `username` | cadena | Obligatorio. |
| `secret` | cadena | Contraseña o secreto del cliente. La API nunca devuelve este valor. Déjalo vacío para conservar el valor guardado. |
| `auth` | objeto | `{"kind": "password"}` (predeterminado) o `{"kind": "oauth2", "tokenUrl": "https://…", "clientId": "…", "scope": "…"}` para usar mediante `XOAUTH2` un token obtenido con las credenciales del cliente. |
| `folder` | cadena | `INBOX` de forma predeterminada. |
| `pollSecs` | entero | Intervalo de lectura en segundos, de 15 a 3600. El valor predeterminado es 60. |

La conexión solo usa la dirección a la que apunta el host en ese momento y nunca una dirección de metadatos de la nube. Si cambias el host, la cuenta o la carpeta, la fuente reinicia la posición de lectura en la siguiente conexión.

**Respuesta de `GET` y `PUT`** (`GET` devuelve `null` si no hay ningún buzón configurado)

| Campo | Descripción |
|---|---|
| `settings` | La configuración anterior, sin `secret`. |
| `secretSet` | Indica si hay un secreto configurado. |
| `reading` | Indica que la fuente ya se conectó y lee los mensajes que llegan desde ese momento. |
| `lastPolledAt`, `lastSuccessAt` | Marcas de tiempo de la última lectura y de la última lectura exitosa, respectivamente (en microsegundos). |
| `lastError` | Motivo del error en la última lectura. Una lectura exitosa borra este valor. |

`test` realiza una sola conexión con la configuración del cuerpo (si `secret` está vacío, usa el valor guardado) y devuelve `{"ok": true, "messages": 3}` o un `503` con la respuesta del servidor de correo.

<RequestExample>
```bash cURL
curl -X PUT "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/mailbox" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"host": "imap.example.com", "username": "alerts@example.com", "secret": "<password>"}'
```
</RequestExample>
