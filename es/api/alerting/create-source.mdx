```http
POST /api/v1/alerts/sources
```

Crea una [fuente de alertas](/es/alerting/sources). Requiere `alerts.sources.manage`. El `token` de la respuesta aparece solo esta vez; úsalo para llamar a [Enviar alertas](/es/api/alerting/send-alerts). Con la federación activada, la fuente se sincroniza con los demás clústeres.

| Campo | Tipo | Descripción |
|---|---|---|
| `kind` | string | Obligatorio al crear: `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` o `email`. |
| `name` | string | Obligatorio, hasta 128 caracteres. |
| `enabled` | boolean | Valor predeterminado: `true`. |
| `escalationPolicyId` | string \| null | Un ID de política de escalado de la organización, o `default`. Sin él, o con `null`, nada escala y solo notifican las políticas de notificación. |
| `severity` | string | Se usa cuando una alerta no lleva gravedad: `critical`, `error`, `warning` (la predeterminada) o `info`. |
| `labels` | object | Hasta 32 etiquetas adicionales. Una clave se compone de letras, dígitos y `_ . - : /`, no puede empezar por `alert.` y no puede ser `external.kind`. |
| `email` | object | Cómo lee un correo una fuente de email: `allowedSenders` (direcciones, `@domain` o `*`), `resolvePattern`, `dedupPattern` e `ignorePattern`; consulta [Email](/es/alerting/sources#correo-electrónico). Si se omite en una actualización, se mantiene tal cual. |
| `homeCluster` | string | El clúster de federación en el que se abren los incidentes: este clúster o un clúster remoto habilitado. Una fuente nueva sin este campo usa este clúster; sin federación no tiene efecto. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

La respuesta es la fuente con su `token`. [Listar fuentes de alertas](/es/api/alerting/list-sources) describe los demás campos.

**Errores**

| Estado | Causa |
|---|---|
| `400` | Un campo es incorrecto, como un nombre vacío, una política de escalado que no existe o un clúster de recepción que no es este clúster ni un clúster remoto habilitado. |
| `403` | Al token le falta `alerts.sources.manage`. |
