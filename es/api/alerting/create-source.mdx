```http
POST /api/v1/alerts/sources
```

Crea una [fuente de alertas](/es/alerting/sources). Requiere `alerts.sources.manage`. El `token` solo aparece en esta respuesta; úsalo para llamar a [Enviar alertas](/es/api/alerting/send-alerts). Si la federación está habilitada, la fuente se sincroniza con los demás clústeres.

| Campo | Tipo | Descripción |
|---|---|---|
| `kind` | string | Obligatorio al crear la fuente: `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix` o `email`. |
| `name` | string | Obligatorio, con un máximo de 128 caracteres. |
| `enabled` | boolean | Valor predeterminado: `true`. |
| `escalationPolicyId` | string \| null | ID de una política de escalamiento de la organización o `default`. Si omites el campo o usas `null`, no se escala ninguna alerta y solo las políticas de notificación envían avisos. |
| `severity` | string | Se usa cuando una alerta no indica su gravedad: `critical`, `error`, `warning` (valor predeterminado) o `info`. |
| `labels` | object | Hasta 32 etiquetas adicionales. Una clave puede contener letras, dígitos y los caracteres `_ . - : /`. No puede empezar con `alert.` ni ser `external.kind`. |
| `email` | object | Define cómo procesa los mensajes una fuente de correo electrónico: `allowedSenders` (direcciones, `@domain` o `*`), `resolvePattern`, `dedupPattern` e `ignorePattern`. Consulta [Correo electrónico](/es/alerting/sources#correo-electrónico). Si omites el campo al actualizar la fuente, conserva su valor. |
| `homeCluster` | string | Clúster de la federación donde se abren los incidentes: este clúster o uno remoto habilitado. Si omites el campo al crear una fuente, se usa este clúster. El campo no tiene efecto si la federación está deshabilitada. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

La respuesta contiene la fuente con su `token`. [Listar fuentes de alertas](/es/api/alerting/list-sources) describe los demás campos.

**Errores**

| Estado | Causa |
|---|---|
| `400` | Un campo contiene un valor no válido, como un nombre vacío, una política de escalamiento inexistente o un clúster receptor que no es este clúster ni uno remoto habilitado. |
| `403` | El token no tiene el permiso `alerts.sources.manage`. |
