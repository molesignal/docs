```http
GET /api/v1/alerts/incidents/{id}/source
```

Devuelve la información que tiene el origen sobre un incidente que abrió un [origen de alertas](/es/alerting/sources). Requiere `alerts.incidents.read`. El incidente lleva la etiqueta `alert.source=external` y su `ruleId` corresponde al ID del origen.

| Campo | Descripción |
|---|---|
| `source` | El origen, tal como aparece en [Listar orígenes de alertas](/es/api/alerting/list-sources); `null` si se eliminó el origen. |
| `dedupKey` | La clave de deduplicación. |
| `lastEventAt` | La marca de tiempo más reciente que el remitente envió con esta clave de deduplicación, en microsegundos. El sistema ignora los mensajes anteriores. `null` para el tipo API. |
| `lastIntakeAt` | La marca de tiempo de la última recepción de la alerta, en microsegundos. |
| `members` | Hasta 100 alertas de un grupo de notificaciones de Alertmanager o Grafana: `status` (`firing` o `resolved`), `labels`, `summary`, `startsAt`, `endsAt` y la `url` que apunta al remitente. Vacío para los demás tipos. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/source \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Errores**

| Estado | Causa |
|---|---|
| `404` | El incidente no existe o ningún origen de alertas lo abrió. |
