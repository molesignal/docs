```http
PUT /api/v1/alerts/routing/teams/{teamId}
```

Establece o elimina la [política de guardia](/es/alerting/routing#políticas-de-guardia-de-los-equipos) de un equipo. Requiere `alerts.routing.manage`. Los incidentes nuevos que se asignan al equipo siguen esa política de escalamiento. Si el equipo no tiene una, siguen la política predeterminada.

| Campo | Tipo | Descripción |
|---|---|---|
| `escalationPolicyId` | string \| null | ID de una política de escalamiento de la organización. Usa `null` u omite el campo para eliminar la política de guardia del equipo. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/teams/$TEAM_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"escalationPolicyId": "<policy-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "teamId": "<team-id>", "escalationPolicyId": "<policy-id>" }
```
</ResponseExample>

**Errores**

| Estado | Causa |
|---|---|
| `400` | El equipo no existe o pertenece a otra organización, o la política de escalamiento no existe. |
| `403` | El token no tiene el permiso `alerts.routing.manage`. |
| `422` | La solicitud incluye otro campo. La respuesta es texto sin formato. |
