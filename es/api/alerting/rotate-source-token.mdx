```http
POST /api/v1/alerts/sources/{id}/token
```

Asigna un token nuevo a una [fuente de alertas](/es/alerting/sources). La solicitud requiere `alerts.sources.manage` y no lleva cuerpo. El token anterior deja de funcionar de inmediato. Si la federación está activada, deja de funcionar en los demás clústeres cuando se sincroniza el cambio. Los emisores que aún usan el token anterior necesitan el nuevo.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/token \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

La respuesta incluye la fuente con el nuevo `token`, que solo se muestra esta vez.

**Errores**

| Estado | Causa |
|---|---|
| `403` | El token no tiene el permiso `alerts.sources.manage`. |
| `404` | La fuente no existe. |
