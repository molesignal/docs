```http
DELETE /api/v1/alerts/rules/{id}
```

Elimina una regla. La llamada requiere `alerts.rules.delete`. Los incidentes que la regla ya abrió siguen disponibles para consulta y tienen un ciclo de vida independiente. La regla eliminada ya no resuelve ninguno de esos incidentes.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>

El cuerpo de la respuesta contiene el texto sin formato `deleted`. Si el `id` es desconocido, la llamada devuelve `404`.
