```http
POST /api/v1/alerts/incidents/{id}/notes
```

Agrega una nota a la [cronología](/es/api/alerting/incident-timeline) de un incidente, sin importar su estado. Mole
Agent lee las notas más recientes junto con el incidente. La llamada requiere `alerts.incidents.update`.

**Cuerpo**

| Campo | Tipo | Obligatorio | Notas |
|---|---|---|---|
| `text` | cadena | Sí | De 1 a 4000 caracteres. La API elimina los espacios al inicio y al final. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/notes \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"text": "Rolled back the edge proxy."}'
```
</RequestExample>

La respuesta contiene la entrada de la cronología correspondiente a la nota.

<ResponseExample>
```json 200
{
  "id": "3KEE1aXy7pRtGd2s9Lm4Qv8bNcE",
  "orgId": "<organization-id>",
  "incidentId": "3KEDNEyqouYJeBDTLTMTBui7XHW",
  "at": 1790000300000000,
  "kind": "note",
  "actor": "<user-id>",
  "detail": {
    "text": "Rolled back the edge proxy.",
    "via": "api"
  }
}
```
</ResponseExample>

**Errores**

| Estado | Causa |
|---|---|
| `400` | `text` está vacío o supera los 4000 caracteres. |
| `403` | El token no tiene el permiso `alerts.incidents.update` o no permite acceder al incidente. |
| `404` | El incidente no existe. |
