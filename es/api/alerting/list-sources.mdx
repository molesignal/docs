```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

La primera llamada lista las [fuentes de alertas](/es/alerting/sources) de la organización, la segunda devuelve una fuente y la tercera devuelve el ID de federación de este clúster (`local`, vacío sin federación) y los clústeres que una fuente puede elegir como su clúster receptor. Las tres requieren `alerts.sources.read`. La API nunca devuelve un token ni su hash.

| Campo | Tipo | Descripción |
|---|---|---|
| `id` | string | ID de la fuente. |
| `name` | string | Nombre. |
| `kind` | string | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` o `email`. |
| `enabled` | boolean | Una fuente desactivada rechaza las alertas. |
| `escalationPolicyId` | string \| null | La política de escalado que siguen sus incidentes; `default` es la política predeterminada, y `null` no escala nada y solo notifica. |
| `severity` | string | Se usa cuando una alerta no trae severidad. |
| `labels` | object | Etiquetas adicionales que se añaden a cada incidente que abre. |
| `tokenPrefix` | string | El prefijo del token `mspat-<10>`. El token completo se devuelve una sola vez, al crearlo y al rotarlo. |
| `homeCluster` | string | El clúster de federación en el que abren sus incidentes; vacío para este clúster. |
| `intakePath` | string | La ruta de la dirección de ingesta, la misma para todas las fuentes. |
| `lastIntakeAt` | integer \| null | Cuándo recibió este clúster por última vez una solicitud suya, en microsegundos. |
| `createdBy`, `createdAt`, `updatedAt` | | Quién la creó y cuándo, y cuándo cambió por última vez, en microsegundos. |

<RequestExample>
```bash cURL

```

Los clústeres que una fuente puede elegir como su clúster receptor:

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
