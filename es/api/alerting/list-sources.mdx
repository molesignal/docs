```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

La primera llamada enumera las [fuentes de alertas](/es/alerting/sources) de la organización. La segunda devuelve una fuente. La tercera devuelve el ID de federación de este clúster (`local`, vacío si no hay federación) y los clústeres que una fuente puede elegir como receptores. Las tres requieren `alerts.sources.read`. La API nunca devuelve el token ni su hash.

| Campo | Tipo | Descripción |
|---|---|---|
| `id` | string | ID de la fuente. |
| `name` | string | Nombre. |
| `kind` | string | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix` o `email`. |
| `enabled` | boolean | Una fuente desactivada rechaza las alertas. |
| `escalationPolicyId` | string \| null | Política de escalamiento que siguen los incidentes de la fuente. `default` aplica la política predeterminada y `null` solo envía notificaciones, sin escalar los incidentes. |
| `severity` | string | Nivel de gravedad que se aplica cuando una alerta no lo especifica. |
| `labels` | object | Etiquetas adicionales que la fuente agrega a cada incidente que abre. |
| `tokenPrefix` | string | Prefijo del token: `mspat-<10>`. La API devuelve el token completo una sola vez al crearlo y una sola vez en cada rotación. |
| `homeCluster` | string | Clúster de la federación donde la fuente abre sus incidentes. Si el valor está vacío, usa este clúster. |
| `intakePath` | string | Ruta de la dirección de recepción, idéntica para todas las fuentes. |
| `lastIntakeAt` | integer \| null | Momento de la última solicitud que este clúster recibió de la fuente, en microsegundos. |
| `createdBy`, `createdAt`, `updatedAt` | | Quién creó la fuente, cuándo la creó y cuándo cambió por última vez. Los tiempos se expresan en microsegundos. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Clústeres que una fuente puede elegir como receptores:

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
