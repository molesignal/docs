```http
PUT /api/v1/alerts/rules/{id}
```

Reemplaza la configuración de una regla. Usa el cuerpo completo de [Crear una regla](/es/api/alerting/create-rule). La llamada conserva el `id` de la regla, la organización, `createdAt`, `lastEvalAt` y `lastState`. Si cambias `escalationPolicyId`, el nuevo valor debe identificar una política de la organización o ser `default`. La llamada requiere el permiso `alerts.rules.manage`.

<Warning>
  La llamada reemplaza la regla sin combinar los campos. Si omites un campo, se usa su valor predeterminado.
  Así, `enabled` pasa a `true` y `kind` pasa a `scheduled`. Si omites
  `labels`, `annotations` o `thresholds`, esos campos quedan vacíos. Omite `escalationPolicyId`
  para conservar la política actual. Consulta primero la regla y luego envía el cuerpo completo con el cambio.
</Warning>

La huella de un incidente se basa en el `id` y los `labels` de la regla. Si cambias `labels`, los incidentes que ya estén abiertos conservan su huella anterior y dejan de resolverse automáticamente. Resuélvelos con [Resolver un incidente](/es/api/alerting/resolve-incident).

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  --data-binary @- <<'EOF'
{
  "name": "High error rate",
  "description": "More than 200 errors in five minutes",
  "enabled": true,
  "kind": "scheduled",
  "query": {
    "language": "sql",
    "statement": "SELECT count(*) AS c FROM app WHERE level = 'error'",
    "periodSecs": 300,
    "stream": { "name": "app", "streamType": "logs" }
  },
  "trigger": { "operator": "gt", "threshold": 200, "forPeriods": 2, "silenceSecs": 0 },
  "severity": "critical",
  "labels": { "team": "checkout" }
}
EOF
```
</RequestExample>

La respuesta contiene la regla actualizada con la estructura que se muestra en [Listar reglas](/es/api/alerting/list-rules).

**Errores**

| Estado | Causa |
|---|---|
| `400` | El cuerpo no supera las mismas validaciones que en [Crear una regla](/es/api/alerting/create-rule) o el nuevo valor de `escalationPolicyId` no identifica ninguna política de la organización. |
| `404` | La regla no existe. |
| `422` | Falta un campo obligatorio o un valor no tiene el tipo correcto. La respuesta es texto sin formato. |
