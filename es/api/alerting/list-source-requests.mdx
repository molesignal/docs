```http
GET /api/v1/alerts/sources/{id}/requests
```

Devuelve las solicitudes que recibió recientemente una [fuente de alertas](/es/alerting/sources), de la más reciente a la más antigua. Requiere `alerts.sources.read`. El clúster que procesó las solicitudes conserva las últimas 500 de cada fuente durante un máximo de 7 días.

**Parámetros de consulta**

| Parámetro | Tipo | Descripción |
|---|---|---|
| `limit` | entero | Cantidad de solicitudes que se devuelven, de 1 a 200. Valor predeterminado: 50. |

| Campo | Descripción |
|---|---|
| `receivedAt` | Momento de recepción de la solicitud, en microsegundos. |
| `viaCluster` | Clúster de la federación que reenvió la solicitud. Queda vacío si la solicitud llegó directamente. |
| `status` | `accepted` (aceptada), `rejected` (rechazada) o `forwarded` (reenviada al clúster receptor). |
| `httpStatus` | Código de estado HTTP que recibió el remitente. |
| `message` | Motivo del rechazo o de que no se tomara ninguna acción. |
| `alertCount` | Cantidad de alertas que contenía la solicitud. |
| `alerts` | Para un máximo de 100 alertas: la acción, la clave de deduplicación, el título, la gravedad, el resultado (consulta [Enviar alertas](/es/api/alerting/send-alerts)), el motivo y el ID del incidente. |
| `bodyExcerpt` | Inicio del cuerpo de una solicitud rechazada, hasta 16 KiB. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/requests?limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>
