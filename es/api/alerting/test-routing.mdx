```http
POST /api/v1/alerts/routing/test
```

Determina cómo se [enrutaría](/es/alerting/routing#orden-de-enrutamiento) un incidente con estas etiquetas según las reglas de enrutamiento vigentes, las políticas de guardia de los equipos y el catálogo de servicios. Requiere `alerts.routing.read`. Se asume que la fuente usa la política predeterminada. No se abre ningún incidente ni se envían notificaciones.

| Campo | Tipo | Descripción |
|---|---|---|
| `labels` | objeto | Las etiquetas del incidente. La etiqueta `alert.source` indica el origen: `external` para una fuente de alertas, `synthetic` para una comprobación sintética y cualquier otro valor para una regla de alerta. |
| `services` | arreglo | Servicios afectados. Si las etiquetas no incluyen `service.name` ni `service`, se usa el primero. |
| `severity` | cadena | `info`, `warning` (predeterminado), `error` o `critical`. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/routing/test \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"labels": {"service.name": "checkout", "env": "prod"}, "severity": "critical"}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "decision": {
    "escalationPolicyId": "<policy-id>",
    "teamId": "<team-id>",
    "routing": { "reason": "rule", "ruleId": "<rule-id>", "ruleName": "Payments in production" }
  },
  "matchedRuleId": "<rule-id>",
  "service": "default/checkout",
  "serviceTeamId": "<team-id>",
  "labelTeamId": null
}
```
</ResponseExample>

| Campo | Descripción |
|---|---|
| `decision.escalation_policy_id` | La política de escalamiento que se aplicaría al incidente. `default` indica la política predeterminada. |
| `decision.team_id` | El equipo al que se enviaría el incidente, o `null`. |
| `decision.routing` | El motivo de la decisión, igual que el campo `routing` de un incidente. Consulta [Campos del incidente](/es/api/alerting/list-incidents#campos-del-incidente). |
| `matchedRuleId` | La regla de enrutamiento que coincidió, o `null`. |
| `service` | El servicio que se consultó para identificar al equipo responsable, en formato `namespace/name`. |
| `serviceTeamId` | El equipo responsable de ese servicio en el catálogo de servicios. |
| `labelTeamId` | El equipo que indica la etiqueta `teamId` o `team`. |
