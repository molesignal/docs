```http
GET /api/v1/traces/service_graph
```

Devuelve las aristas sin procesar del grafo de servicios que agrega la [topología de servicios](/es/api/web/topology). Cada arista registra el número de llamadas de un servicio cliente a un servicio servidor durante un minuto. La llamada requiere `traces.read` o `sys.telemetry.read` en el ámbito del sistema.

**Parámetros de consulta**

| Parámetro | Tipo | Obligatorio | Notas |
|---|---|---|---|
| `from` | entero | Sí | Inicio del intervalo, en microsegundos desde la época Unix. |
| `to` | entero | Sí | Fin del intervalo, en microsegundos. |
| `service` | cadena | No | Conserva solo las aristas en las que este servicio actúa como cliente o servidor. |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000
curl "http://localhost:5080/api/v1/traces/service_graph?from=$((NOW-3600000000))&to=$NOW&service=checkout" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "edges": [
    {
      "id": "3KBCiQWW0TtpDu7D4pH7LMtZsRh",
      "orgId": "<organization-id>",
      "clientService": "frontend",
      "serverService": "checkout",
      "bucketAt": 1790000000000000,
      "requestCount": 12,
      "errorCount": 1,
      "p50Us": 90000,
      "p95Us": 210000,
      "p99Us": 240000
    }
  ],
  "count": 1
}
```
</ResponseExample>

**Respuesta**

| Campo | Notas |
|---|---|
| `edges[].client_service`, `edges[].server_service` | El servicio que realiza la llamada y el que la recibe. |
| `edges[].bucketAt` | Inicio del intervalo de un minuto, en microsegundos. |
| `edges[].request_count`, `edges[].error_count` | Número total de llamadas y número de llamadas fallidas en el intervalo. |
| `edges[].p50_us`, `edges[].p95_us`, `edges[].p99_us` | Percentiles de latencia del intervalo, en microsegundos. Un percentil puede ser `null`. |
| `count` | Número de aristas que devuelve la consulta. |

La consulta devuelve `{"edges": [], "count": 0}` si ninguna arista coincide con el intervalo o si `to` es anterior a `from`.

**Errores**

| Estado | Causa |
|---|---|
| `400` | Falta `from` o `to`, o alguno de los dos no es un entero. La respuesta está en texto plano. |
| `403` | El token no tiene el permiso `traces.read`. |
