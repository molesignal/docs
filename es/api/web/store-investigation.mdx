```http
POST /api/v1/web/investigation/blob
```

Almacena un documento JSON en el almacenamiento de objetos y devuelve un identificador. En investigaciones grandes, la interfaz web usa esta llamada para que la URL de la página solo incluya el identificador, no la pila de investigación. Lee el documento con [Obtener la pila de investigación](/es/api/web/fetch-investigation). La llamada requiere `streams.query` o, en el ámbito del sistema, `sys.telemetry.read`.

El cuerpo admite cualquier valor JSON de hasta 1 MiB (1,048,576 bytes). El documento pertenece a la organización que realiza la llamada. El compactador elimina el documento después de 7 días.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/investigation/blob \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "version": 1,
    "stack": [
      { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
      { "kind": "log", "query": "level = error" }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "blobId": "3KEZAC5JXc0P0HjrTdARfCgH1Y3"
}
```
</ResponseExample>

**Errores**

| Estado | Causa |
|---|---|
| `400` | El cuerpo no es JSON válido (es texto sin formato) o el documento supera 1 MiB (`payload exceeds 1048576 bytes`). |
| `403` | El token no tiene el permiso `streams.query`. |
