```http
GET /api/v1/web/investigation/blob/{id}
```

Devuelve el documento JSON que [Guardar la pila de investigación](/es/api/web/store-investigation) guardó con el identificador `blobId`. La búsqueda se limita a la organización que realiza la solicitud. Si el identificador pertenece a otra organización, la API devuelve `404`. La llamada requiere `streams.query` o `sys.telemetry.read` en el ámbito del sistema.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/web/investigation/blob/$BLOB_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "version": 1,
  "stack": [
    { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
    { "kind": "log", "query": "level = error" }
  ]
}
```
</ResponseExample>

La API devuelve el documento almacenado sin cambios. Si el compactador eliminó el documento después de 7 días, la API también devuelve `404`.

**Errores**

| Estado | Causa |
|---|---|
| `403` | El token no tiene el permiso `streams.query`. |
| `404` | El identificador es desconocido, pertenece a otra organización o ha caducado. |
