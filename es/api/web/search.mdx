```http
GET /api/v1/web/search
```

Esta llamada permite usar la paleta de comandos **⌘K**. Busca seis tipos de entidades de la organización por coincidencia aproximada de nombre y devuelve primero las mejores coincidencias. La llamada requiere `streams.query` o, en el ámbito del sistema, `sys.telemetry.read`.

**Parámetros de consulta**

| Parámetro | Tipo | Obligatorio | Notas |
|---|---|---|---|
| `q` | cadena | Sí | Texto de búsqueda de hasta 256 caracteres. La búsqueda usa la similitud de trigramas de PostgreSQL, por lo que un texto muy corto, como una sola letra, rara vez produce coincidencias. Si `q` está vacío, la llamada devuelve una lista vacía. |
| `types` | cadena | No | Subconjunto de `stream`, `dashboard`, `savedView`, `alert`, `incident` y `service`, con valores separados por comas. Omite este parámetro para buscar en todos los tipos. Un valor desconocido no produce coincidencias. |
| `limit` | entero | No | Valor predeterminado: `20`. La llamada ajusta el valor al intervalo de 1 a 50. |

Si `q` solo contiene espacios y se combina con `types=stream`, la llamada enumera los flujos en orden alfabético en lugar de realizar una búsqueda.

Cada resultado identifica la entidad con estos campos:

| `kind` | `id` | `label` | `subtitle` |
|---|---|---|---|
| `stream` | Identificador del flujo | Nombre del flujo | Tipo de flujo en su formato interno, como `builtin.logs`. |
| `dashboard` | Identificador del panel | Título | `uid` del panel. |
| `savedView` | Identificador de la vista guardada | Nombre | Lenguaje de consulta. |
| `alert` | Identificador de la regla | Nombre de la regla | `enabled` o `disabled`. |
| `incident` | Identificador del incidente | Huella del incidente | Estado del incidente. |
| `service` | Identificador de la arista | Nombre del servicio en el grafo de servicios | Ninguno. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/search?q=app&types=stream&limit=5" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "items": [
    { "kind": "stream", "id": "3KDXoznFWyKPsch4ETi37U3GdxM", "label": "app", "subtitle": "builtin.logs" },
    { "kind": "stream", "id": "3JtcZGko1Q5czEBK9nBJjiFxpo1", "label": "app_logs", "subtitle": "builtin.logs" }
  ]
}
```
</ResponseExample>

**Errores**

| Estado | Causa |
|---|---|
| `400` | Falta `q` (texto sin formato) o `q` supera los 256 caracteres (`invalid_argument`). |
| `403` | El token no tiene el permiso `streams.query`. |
