```http
GET /api/v1/web/topology
```

Agrupa las aristas del grafo de servicios de un intervalo de tiempo en nodos y aristas, con la tasa de solicitudes, la tasa de errores y la latencia. Las aristas provienen del grafo de servicios que MoleSignal deriva de los spans de las trazas. Consulta [Mapa de servicios](/es/apm/service-map). La llamada requiere `traces.read` o `sys.telemetry.read` en el ámbito del sistema.

**Parámetros de consulta**

| Parámetro | Tipo | Obligatorio | Notas |
|---|---|---|---|
| `from` | cadena | Sí | El inicio del intervalo, como marca de tiempo en formato RFC 3339. |
| `to` | cadena | Sí | El fin del intervalo, como marca de tiempo en formato RFC 3339. No puede ser anterior a `from`. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/topology?from=2026-10-04T09:00:00Z&to=2026-10-04T10:00:00Z" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "nodes": [
    { "id": "checkout", "name": "checkout", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 },
    { "id": "frontend", "name": "frontend", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 }
  ],
  "edges": [
    { "source": "frontend", "target": "checkout", "rps": 0.1, "errRate": 0.0278, "p95Ms": 90.0 }
  ]
}
```
</ResponseExample>

**Respuesta**

| Campo | Notas |
|---|---|
| `nodes[].id`, `nodes[].name` | El nombre del servicio. La respuesta ordena los nodos por nombre. |
| `nodes[].span_count` | El número de solicitudes en todas las aristas conectadas al servicio, ya sea como cliente o como servidor. |
| `nodes[].error_rate`, `edges[].err_rate` | El número de errores dividido entre el número de solicitudes, de 0 a 1. |
| `nodes[].rps`, `edges[].rps` | El número de solicitudes dividido entre la duración del intervalo en segundos. |
| `nodes[].p95_ms`, `edges[].p95_ms` | La latencia p95 más alta de los grupos agregados, en milisegundos. No corresponde al p95 de todo el intervalo. |
| `edges[].source`, `edges[].target` | El servicio cliente y el servicio servidor. La respuesta ordena las aristas primero por origen y luego por destino. |

Si el intervalo no contiene aristas, la llamada devuelve arreglos vacíos.

**Errores**

| Estado | Causa |
|---|---|
| `400` | Falta `from` o `to`, alguno de los dos no es una marca de tiempo en formato RFC 3339 o `to` es anterior a `from`. |
| `403` | El token no tiene el permiso `traces.read`. |
