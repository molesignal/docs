```http
POST /api/v1/saved_views
```

Guarda una consulta con un rango de tiempo relativo. La llamada requiere `saved_views.create`.

**Cuerpo**

| Campo | Tipo | Obligatorio | Notas |
|---|---|---|---|
| `name` | cadena | Sí | Nombre visible. |
| `language` | cadena | Sí | `sql` o `promql`. |
| `statement` | cadena | Sí | Texto de la consulta. |
| `timeRangeSecs` | entero | Sí | Ventana relativa de 1 a 31 622 400 segundos. Si el valor está fuera del rango, la llamada devuelve `400`. |
| `stream` | cadena | No | Nombre del flujo principal. |
| `tags` | arreglo de cadenas | No | Etiquetas para filtrar. |
| `pinned` | booleano | No | Muestra la vista en primer lugar. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/saved_views \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = '"'"'error'"'"'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true
  }'
```
</RequestExample>

La respuesta devuelve la vista creada con la estructura que muestra [Listar vistas guardadas](/es/api/query/list-saved-views).
