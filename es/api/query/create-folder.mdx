```http
POST /api/v1/folders
```

Crea una carpeta de paneles. La llamada requiere `dashboards.folders.manage`. Para listar, editar y eliminar carpetas, se requieren `dashboards.folders.read`, `dashboards.folders.manage` y `dashboards.folders.delete`, respectivamente.

**Cuerpo**

| Campo | Tipo | Obligatorio | Notas |
|---|---|---|---|
| `name` | cadena | Sí | Nombre de la carpeta. |
| `parentId` | cadena o `null` | No | ID de la carpeta superior en la misma organización. `null` crea una carpeta de nivel superior. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parentId":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "orgId": "<organization-id>",
  "name": "Operations",
  "parentId": null
}
```
</ResponseExample>

`GET /api/v1/folders` lista las carpetas. `DELETE /api/v1/folders/{id}` devuelve `{"deleted": "<id>"}`, o `409` si la carpeta aún contiene paneles o subcarpetas.
