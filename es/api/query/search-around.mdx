```http
POST /api/v1/query/search_around
```

Devuelve los eventos inmediatamente anteriores y posteriores a un evento, dentro de una ventana de 24 horas a cada lado. La cantidad de eventos por lado es de 50 de forma predeterminada y admite valores entre 1 y 1000. La llamada requiere `streams.query` o, para la telemetría del sistema, `sys.telemetry.read`.

`before` contiene los eventos cuya marca de tiempo es igual o anterior a la del puntero, del más reciente al más antiguo. Si el evento de referencia está almacenado, aparece en la primera fila. `after` contiene los eventos cuya marca de tiempo es posterior a la del puntero, del más antiguo al más reciente. Si el flujo no existe, la llamada devuelve `before` y `after` vacíos en lugar de un error.

**Cuerpo**

| Campo | Tipo | Obligatorio | Valor predeterminado |
|---|---|---|---|
| `eventTimestampUs` | entero | Sí | |
| `stream` | cadena | Sí | |
| `streamType` | cadena | Sí | |
| `eventFingerprint` | cadena | No | El servidor devuelve el valor sin cambios en `pointer`. No lo usa para seleccionar eventos. |
| `before` | entero | No | 50 |
| `after` | entero | No | 50 |

<ResponseExample>
```json 200
{
  "pointer": { "ts": 1790000000000000, "fingerprint": null },
  "before": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1789999999500000, "..."]],
    "scannedRows": 100,
    "tookMs": 4
  },
  "after": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1790000000500000, "..."]],
    "scannedRows": 100,
    "tookMs": 4
  }
}
```
</ResponseExample>
