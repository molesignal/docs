```http
GET /api/v1/saved_views
```

Devuelve las vistas guardadas de la organización. Agrega `?pinned=true` para devolver solo las vistas fijadas. La llamada requiere `saved_views.read`.

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/saved_views?pinned=true" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KE7RbW5ShK8cbrZZq4I4O3XUge",
    "orgId": "<organization-id>",
    "ownerUserId": "<user-id>",
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = 'error'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true,
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

Otras rutas: `GET /api/v1/saved_views/{id}` devuelve una vista y `DELETE /api/v1/saved_views/{id}` responde con `deleted`.

## Listar todas las vistas o solo las vistas fijadas

Omite `pinned` o establece `pinned=false` para listar las vistas sin filtrar por vistas fijadas. `pinned=false` no significa «solo las vistas sin fijar». Establece `pinned=true` al crear una lista de accesos directos a las vistas fijadas.

La solicitud devuelve las definiciones de la organización actual, no los resultados de las consultas. La respuesta es un arreglo JSON; `[]` es un resultado válido si ninguna vista coincide con el filtro. Si no aparece una vista que esperabas encontrar, verifica la organización asociada a la credencial y quita el filtro de vistas fijadas antes de suponer que se eliminó la vista.

## Leer la consulta guardada

| Campo | Uso |
|---|---|
| `id` | Pásalo al endpoint de detalles o de ejecución. |
| `language`, `statement` | Lenguaje y texto de la consulta guardada. |
| `stream` | Contexto guardado del flujo, si está presente. |
| `timeRangeSecs` | Duración del intervalo de tiempo guardado, en segundos. |
| `tags`, `pinned` | Metadatos para organizar las vistas y navegar por ellas, no filtros de consulta. |
| `createdAt`, `updatedAt` | Marcas de tiempo en microsegundos. |

Leer una definición no ejecuta la consulta ni otorga permisos para consultar sus datos. Sigue los pasos de [Ejecutar una vista guardada](/es/api/query/run-saved-view) para ejecutar una vista con los permisos necesarios. Consulta [Crear una vista guardada](/es/api/query/create-saved-view) para guardar una consulta y [Vistas guardadas](/es/saved-views) para conocer el flujo de trabajo en la interfaz.
