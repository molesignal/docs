```http
POST /api/v1/dashboards
```

Crea un tablero. El cuerpo contiene el modelo completo del tablero en `model` y puede especificar un `folderId`. El `uid` debe ser único en la organización. De lo contrario, la solicitud devuelve `409`. La solicitud requiere `dashboards.create`.

**Propiedades obligatorias del modelo**

| Propiedad | Notas |
|---|---|
| `engine` | `molesignal-dashboard`. |
| `schemaVersion` | `2`. |
| `uid`, `title`, `tags` | Identidad. `uid` y `title` no pueden estar vacíos, y `tags` es un arreglo. |
| `editable`, `defaultDashboard` | Valores booleanos. |
| `timeSettings` | `timezone`, `defaultFrom` y `defaultTo`. |
| `refreshSettings` | `mode`, `enabled`, `defaultInterval` y `allowedIntervals`. |
| `variables`, `annotations`, `links`, `elements` | Arreglos vacíos si el tablero está en blanco. |
| `layout` | Una cuadrícula: `type`, `columns`, `rowHeight` y `gap`. |

Si al modelo le falta alguna propiedad obligatoria, la solicitud devuelve `400` con `validation_failed` y una entrada en `issues` por cada propiedad que falte.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/dashboards \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "model": {
      "engine": "molesignal-dashboard",
      "schemaVersion": 2,
      "uid": "service-overview",
      "title": "Service overview",
      "tags": ["operations"],
      "editable": true,
      "defaultDashboard": false,
      "timeSettings": { "timezone": "browser", "defaultFrom": "now-6h", "defaultTo": "now" },
      "refreshSettings": { "mode": "interval", "enabled": true, "defaultInterval": "30s",
                           "allowedIntervals": ["off", "30s", "1m", "5m"] },
      "variables": [],
      "annotations": [],
      "links": [],
      "layout": { "type": "grid", "columns": 24, "rowHeight": 8, "gap": 8 },
      "elements": []
    },
    "folderId": null
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7XebQcmZojtDim7ZVdGVw594",
  "orgId": "<organization-id>",
  "folderId": null,

  "title": "Service overview",
```

Primero, crea los paneles en el editor. Luego, exporta el modelo de un tablero existente con `GET /api/v1/dashboards/{id}` para usarlo como plantilla. Otras rutas: `GET /api/v1/dashboards`, `PUT` y `DELETE /api/v1/dashboards/{id}`.
