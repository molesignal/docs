```http
GET  /api/v1/saved_views/{id}
POST /api/v1/query
```

Una vista guardada almacena `language`, `statement`, `stream` y un `timeRangeSecs` relativo. No hay un endpoint de ejecución independiente. La aplicación web sigue este flujo de dos solicitudes, que requiere `saved_views.read` y `streams.query`:

1. Carga la vista con `GET /api/v1/saved_views/{id}`.
2. Calcula un intervalo absoluto que termine en el momento actual: `end` es la hora actual en microsegundos y `start` es `end` menos el producto de `timeRangeSecs` por 1 000 000.
3. Envía los valores guardados de `language` y `statement`, el `timeRange` calculado y el flujo a [Ejecutar una consulta](/es/api/query/execute).

<RequestExample>
```bash cURL
VIEW=$(curl -s http://localhost:5080/api/v1/saved_views/$VIEW_ID \
  -H "authorization: Bearer $MS_TOKEN")

END=$(date +%s)000000
START=$((END - $(echo "$VIEW" | jq .timeRangeSecs) * 1000000))

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "{\"orgId\":\"$MS_ORG\",
       \"language\":$(echo "$VIEW" | jq .language),
       \"statement\":$(echo "$VIEW" | jq .statement),
       \"timeRange\":{\"start\":$START,\"end\":$END},
       \"stream\":{\"name\":$(echo "$VIEW" | jq .stream),\"streamType\":\"logs\"}}"
```
</RequestExample>

La vista guardada almacena el nombre del flujo sin su tipo, así que indica el tipo de flujo al que pertenece la vista.
