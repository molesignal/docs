```http
GET /api/v1/business-context
PUT /api/v1/business-context
```

Las claves de negocio, como un tenant, un plan o un grupo de experimentos, y el campo que lleva cada una en
los spans, los logs y los eventos de RUM. Consulta [Contexto de negocio](/es/business-context). Leer requiere cualquiera de
`apm.services.read`, `traces.read`, `logs.read`, `rum.events.read`, `apm.settings.read` o
`sys.telemetry.read`; definir requiere `apm.settings.manage` y queda registrado en el registro de actividad.

## Define las claves

`PUT` reemplaza todas las claves. Los campos en blanco no nombran nada, un `label` en blanco es la clave, y los valores importantes se recortan y se listan una sola vez cada uno; la respuesta es lo que se guardó.

| Campo | Notas |
|---|---|
| `key` | Empieza con una letra minúscula y contiene solo letras minúsculas, dígitos y `_`, como máximo 64. Único. |
| `label` | El nombre con el que lo ven los lectores, como máximo 80 caracteres. |
| `span` | El atributo del span, tal como el flujo de trazas nombra el campo. |
| `log` | El campo del log. |
| `rum` | El campo de RUM, una clave de un campo JSON incluido, como `context.tenant`. |
| `important` | Los valores que más importan, como máximo 50 de hasta 200 caracteres. |

Una clave nombra al menos uno de `span`, `log` y `rum`. Como máximo 8 claves.

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/business-context \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"keys":[{"key":"tenant","label":"Tenant","span":"tenant.id","log":"tenant_id","rum":"context.tenant","important":["acme"]}]}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "keys": [
    {
      "key": "tenant",
      "label": "Tenant",
      "span": "tenant.id",
      "log": "tenant_id",
      "rum": "context.tenant",
      "important": ["acme"]
    }
  ]
}
```
</ResponseExample>

**Errores**

| Estado | Motivo |
|---|---|
| `400` | Una clave tiene un nombre mal formado o repetido, no nombra ningún campo, o hay más claves o valores de los permitidos. |
| `403` | Al token le falta el permiso de la llamada. |
