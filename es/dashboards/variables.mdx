Una variable inserta un valor elegido encima de la cuadrícula en las consultas, los títulos y los enlaces de cada panel. Así,
un solo dashboard sirve para todos los servicios, hosts o entornos, sin crear una copia para cada uno.

## Agregar una variable

Abre el editor, selecciona **Configuración → Variables** y agrega una variable:

| Campo | Regla |
|---|---|
| **Nombre** | El nombre que se usa en las consultas, como `service`. Usa letras, dígitos y `_`, y empieza con una letra o `_`: los nombres que no cumplan esta regla no se sustituyen. |
| **Etiqueta** | El texto que aparece encima del selector. |
| **Tipo** | El origen de los valores. Consulta [Tipos](#tipos). |
| **Consulta / opciones** | La consulta o los valores, según el tipo. |
| **Selección múltiple** | Permite seleccionar varios valores a la vez. |
| **Incluir todo** | Agrega **Todos**, que representa todos los valores de la lista. |
| **Ocultar** | **Ninguno** muestra el selector, **Etiqueta** oculta su etiqueta y **Variable** oculta el selector. |
| **Actualizar** | Cuándo vuelve a consultar sus valores una variable de consulta: **Nunca**, **Al cargar** o cada vez que cambia el **Intervalo de tiempo**. |

Guarda el dashboard para conservar la variable.

## Tipos

| Tipo | Valores |
|---|---|
| **Consulta** | Valores obtenidos de los datos. Consulta [Variables de consulta](#variables-de-consulta). |
| **Personalizado** | Una lista fija de valores separados por comas, por ejemplo `prod, staging, dev`. |
| **Texto** | El texto que se escribe en un campo encima de la cuadrícula. |
| **Constante** | Un valor fijo que se guarda en el modelo del dashboard. Nunca aparece encima de la cuadrícula. |
| **Intervalo**, **Fuente de datos** | Una lista que se guarda en el modelo del dashboard, por ejemplo, una lista incluida en un JSON importado. |

### Variables de consulta

Una variable de consulta obtiene sus valores en el intervalo de tiempo actual. Elige el **Tipo de consulta**:

| Tipo de consulta | Campos | Valores |
|---|---|---|
| **Valores de etiqueta** | **Métrica** y **Etiqueta**, por ejemplo `http_requests_total` y `service`. | Los valores de la etiqueta en las series de la métrica, en todos los flujos de métricas que la contienen. |
| **Consulta clásica** | Una expresión como `label_values(http_requests_total, service)`. | Los mismos que en **Valores de etiqueta**. |
| **SQL** | **Nombre del flujo**, **Tipo de flujo** y una instrucción SQL. | Los valores de la primera columna. |

El primer valor es el predeterminado. Una consulta puede usar otra variable, por ejemplo, una instrucción SQL
con `WHERE environment = '$env'`, para filtrar los servicios al elegir un entorno.

## Usar una variable

Escribe `$name` o `${name}` en una consulta, en el título de un panel, en un elemento de texto o en un enlace. Usa llaves
si después del nombre hay letras, como en `${service}_errors`. Una variable con varios valores los devuelve
separados por comas. Agrega un formato para cambiar el resultado:

| Sintaxis | Resultado para `checkout` y `payment` |
|---|---|
| `${service}` | `checkout,payment` |
| `${service:csv}` | `checkout,payment` |
| `${service:pipe}` | `checkout\|payment` |
| `${service:regex}` | `checkout\|payment`, con los caracteres especiales de cada valor escapados para una expresión regular. |
| `${service:sqlstring}` | `'checkout','payment'`, con cada valor entre comillas para SQL, por ejemplo, en `IN (${service:sqlstring})`. |
| `${service:json}` | `["checkout","payment"]` |

Por ejemplo, un panel con la consulta PromQL `sum(rate(http_requests_total{service=~"${service:regex}"}[5m]))` muestra datos de
los servicios seleccionados.

## Valores en la URL

La URL del dashboard guarda los valores seleccionados como `var-<name>=<value>`. Este parámetro se repite por cada
valor de una variable con varios valores. Copia la URL o crea un enlace con estos parámetros para abrir el
dashboard con la misma selección. Un [enlace de datos](/es/dashboards/edit#enlaces-de-datos) también puede transmitir las
variables.

## Repetir paneles según una variable

En la pestaña **Panel** de un panel, elige una **Variable de repetición**. El dashboard muestra una copia del
panel por cada valor seleccionado y asigna ese valor a la variable en la copia. Elige la
**Dirección de repetición**: **Horizontal**, **Vertical** o **Cuadrícula**, y define **Máx. por fila**. El dashboard solo guarda el
panel original y ajusta las copias según la selección.
