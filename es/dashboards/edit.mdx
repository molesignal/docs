Selecciona **Nuevo panel** en **Paneles** o **Editar** en un panel para abrir el editor. Para crear
un panel, necesitas `dashboards.create`. Para modificarlo, necesitas `dashboards.edit`. Si el panel
tiene la opción **Editable** desactivada, como ocurre con los paneles integrados, crea una copia para modificarlo.

## El editor

| Control | Uso |
|---|---|
| **Volver al tablero** | Cierra el editor. |
| Título del panel | Permite cambiar el nombre del panel directamente. |
| **Deshacer** / **Rehacer** | Retrocede o avanza por los cambios hechos desde que abriste el editor. |
| **Agregar** | Agrega un **Panel**, un **Texto**, una **Fila**, un **Grupo** o **Pestañas**. |
| **Configuración** | Abre la [configuración del panel](#configuración-del-panel). |
| **Guardar** | Guarda el panel. Hasta entonces, el editor no guarda ningún cambio. |

Arrastra un elemento por su control de arrastre para moverlo o por una esquina para cambiar su tamaño. Selecciónalo para editar
su posición y estructura en el panel lateral. Los paneles nuevos usan una cuadrícula de 24 columnas. Cámbiala en
[Configuración → General](#configuración-del-panel).

## Elementos

| Elemento | Uso |
|---|---|
| **Panel** | Una visualización que muestra los resultados de una o más consultas. |
| **Texto** | Contenido estático en Markdown o en texto sin formato para notas, encabezados y enlaces. |
| **Fila** | Un encabezado de ancho completo que agrupa los elementos que tiene debajo. Usa **Contraído al inicio** para contraer la fila al abrir el panel. |
| **Grupo** | Un recuadro que reúne elementos relacionados. |
| **Pestañas** | Varias pestañas, cada una con sus propios elementos. Elige qué pestaña se abre primero. |

## Editar un panel

Selecciona **Editar** en el menú de un panel o agrega uno. El editor de paneles muestra una **Vista previa en tiempo real** del
panel con el intervalo de tiempo y las variables actuales, además de dos conjuntos de pestañas:

| Pestañas | Contenido |
|---|---|
| **Consultas**, **Transformaciones**, **Enlaces de datos** | Qué datos lee el panel, cómo transforma los resultados y a dónde lleva un clic. |
| **Panel**, **Campo**, **Anulaciones** | El aspecto del panel, cómo muestra los valores y las excepciones para algunos campos. |

### Consultas

Selecciona **Agregar consulta** para cada consulta del panel. Cada consulta tiene un **ID de referencia**, como `A`, una
**Fuente de datos**, un **Lenguaje** (**PromQL** o **SQL**) y una **Expresión**. La fuente de datos
determina el lenguaje predeterminado y los demás campos:

| Fuente de datos | Lenguaje predeterminado | Otros campos |
|---|---|---|
| **Métricas** | PromQL | |
| **Registros**, **Trazas**, **SQL** | SQL | **Nombre del flujo** y **Tipo de flujo** (**Registros**, **Métricas** o **Trazas**). |
| **Perfiles** | SQL | **Servicio** y **Tipo de perfil**, por ejemplo, `cpu`. |

**Leyenda** asigna un nombre a las series con una plantilla como `{{service}}`. **Consulta compartida** reutiliza una consulta de
otro panel con la referencia `<panel-id>:<ref-id>` para leer los datos una sola vez. Las consultas pueden usar
[variables](/es/dashboards/variables) como `$service`. Consulta [Consultas](/es/query) para obtener más información sobre SQL y
PromQL.

Una consulta SQL con `format` igual a `time_series`, como las de los paneles que agrega el [explorador de RUM](/es/rum/explorer#agregar-al-tablero),
puede devolver datos en formato largo, con una fila por cada instante y grupo. La visualización de serie temporal dibuja una serie por cada combinación de valores de las
columnas de texto y utiliza esos valores como nombre.

### Transformaciones

Las transformaciones modifican el resultado antes de mostrarlo. Se ejecutan en orden y puedes desactivar cada una.

| Transformación | Efecto |
|---|---|
| **Filtrar campos**, **Organizar campos**, **Cambiar el nombre de los campos** | Conservan, ordenan, ocultan o cambian el nombre de los campos. |
| **Calcular campo** | Agrega un campo calculado a partir de otros. |
| **Reducir** | Reduce cada serie a valores como el último, el promedio, el máximo o el total. |
| **Agrupar por**, **Ordenar por**, **Limitar** | Agrupan por un campo, ordenan y conservan las primeras filas. |
| **Unirse**, **Combinar** | Combinan los resultados de varias consultas. |
| **Convertir etiquetas en campos**, **Convertir filas en campos**, **Convertir series temporales en tabla** | Convierten etiquetas, filas o series en columnas. |

### Opciones del panel

En la pestaña **Panel**, configura el **Título**, la **Descripción** que aparece al pasar el cursor, el **Ancho** y la **Altura**,
la **Visualización** y sus opciones, y si el panel es **Transparente**.

| Visualización | Qué muestra |
|---|---|
| **Serie temporal** | Líneas, barras o puntos a lo largo del tiempo, con opciones de leyenda, información emergente, relleno y apilamiento. |
| **Gráfico de barras** | Valores comparados por categoría. |
| **Indicador de barras** | Valores reducidos en barras horizontales o verticales. |
| **Estadística** | Un valor, como el último, con un minigráfico opcional. |
| **Indicador** | Un valor en una escala radial con colores según los umbrales. |
| **Tabla** | Filas con paginación. |
| **Registros** | Una lista compacta de registros con hora y nivel. |
| **Mapa de calor** | La intensidad de los valores a lo largo del tiempo. |
| **Cronología de estados** | Cambios de estado a lo largo del tiempo. |
| **Texto** | Markdown. |

**Variable de repetición** muestra una copia del panel por cada valor de una variable. En **Dirección de repetición**, elige
**Horizontal**, **Vertical** o **Cuadrícula**, con un máximo de copias por fila definido en **Máx. por fila**. Consulta
[Repetir paneles](/es/dashboards/variables#repetir-paneles-según-una-variable).

### Opciones de campo

En la pestaña **Campo**, configura cómo se muestran los valores:

| Opción | Uso |
|---|---|
| **Unidad**, **Decimales** | La unidad, como bytes, porcentaje o segundos, y el número de decimales. |
| **Mín.**, **Máx.** | Los extremos de la escala. |
| **Nombre visible** | Reemplaza el nombre del campo. |
| **Esquema de colores** | Un color fijo, una paleta, los colores de los umbrales o una escala continua. |
| **Umbrales** | Valores en los que cambia el color, en modo **Absoluto** o **Porcentaje**, a partir de **Base**. |
| **Asignaciones de valores** | Muestran un texto, un color o un icono para un valor, un intervalo, una coincidencia con una expresión regular o un valor especial como null. |
| **Texto cuando no hay valor** | Lo que muestra el panel cuando no hay ningún valor. |

Las **Anulaciones** aplican opciones distintas solo a ciertos campos. Selecciona **Agregar cobertura temporal**, elige un criterio
(**Nombre del campo**, **Expresión regular del campo**, **Tipo de campo** o **Referencia de consulta**) y selecciona **Agregar propiedad** por cada opción
que quieras cambiar.

### Enlaces de datos

Un enlace de datos abre un destino al hacer clic en un valor. Selecciona **Agregar enlace de datos**, escribe un **Título** y elige
el destino: **Registros**, **Métricas**, **Trazas**, **Perfiles**, otro **Panel** o una
URL **Externa**. Elige si el enlace incluye el intervalo de tiempo y las variables del panel, y si se abre en
una pestaña nueva. Los enlaces aparecen en el menú del panel.

## Configuración del panel

**Configuración** tiene cuatro pestañas.

| Pestaña | Contenido |
|---|---|
| **General** | **Título**, **Descripción** y **Etiquetas**. El intervalo de tiempo predeterminado (**Desde**, **Hasta**) y la **Zona horaria**. La **Cuadrícula**: de 1 a 48 **Columnas**, **Altura de fila** y **Separación**. **Actualizar**: **Desactivado**, **Intervalo** con un **Intervalo predeterminado** o **Automático**. **Información emergente del gráfico**: desactivada o con un cursor en cruz compartido entre paneles. **Editable**. |
| **Variables** | Las variables del panel. Consulta [Variables](/es/dashboards/variables). |
| **Anotaciones** | Eventos que se muestran en los paneles de series temporales. |
| **Enlaces** | Enlaces en el encabezado del panel. |

Una anotación tiene un **Nombre**, un **Origen**, una **Visualización** de tipo **Línea**, **Región** o **Marcador**, un
**Color** y la opción **Habilitado**. En **Eventos**, selecciona **Agregar evento** e indica una **Etiqueta**, una
**Marca de tiempo de inicio (ms)** y, si es una región, una **Marca de tiempo de fin (ms)**.

Un enlace tiene un **Título**, un **Tipo** (**Panel** o **Externo**), una **URL** y opciones para incluir el
**Intervalo de tiempo** y las **Variables** y para abrirlo en una **Nueva pestaña**.

## Guardar y reutilizar

Selecciona **Guardar**. Para reutilizar un panel, selecciona **Copiar** en su menú para copiar su JSON y pégalo en
otro panel. Para reutilizar un panel completo, selecciona **Exportar JSON** e importa el archivo donde lo necesites. Consulta
[Importar un panel](/es/dashboards#importar-un-panel).
