Selecciona **Nuevo panel** en **Paneles**, o **Editar** en un panel, para abrir el editor. Crear
un panel requiere `dashboards.create`, y cambiarlo requiere `dashboards.edit`. Un panel
cuya opción **Editable** está desactivada, como uno integrado, no se puede cambiar: crea una copia en su lugar.

## El editor

| Control | Uso |
|---|---|
| **Volver al tablero** | Sale del editor. |
| Título del panel | Cambia el nombre del panel en el mismo lugar. |
| **Deshacer** / **Rehacer** | Retrocede o avanza entre los cambios desde que se abrió el editor. |
| **Agregar** | Agrega un **Panel**, **Texto**, **Fila**, **Grupo** o **Pestañas**. |
| **Configuración** | Abre la [configuración del panel](#configuración-del-panel). |
| **Guardar** | Guarda el panel. No se guarda nada antes. |

Arrastra un elemento por su controlador para moverlo y arrastra su esquina para cambiar su tamaño. Selecciona un elemento para editar
su posición y estructura en el panel lateral. Los paneles nuevos usan una cuadrícula de 24 columnas; cámbiala en
[Configuración → General](#configuración-del-panel).

## Elementos

| Elemento | Uso |
|---|---|
| **Panel** | Una o más consultas dibujadas por una visualización. |
| **Texto** | Markdown estático o texto sin formato, para notas, encabezados y enlaces. |
| **Fila** | Un encabezado de ancho completo que contiene los elementos debajo. Una fila puede iniciar **Contraído al inicio**. |
| **Grupo** | Un cuadro que mantiene juntos los elementos relacionados. |
| **Pestañas** | Varias pestañas, cada una con sus propios elementos. Elige la pestaña que se abre primero. |

## Editar un panel

Selecciona **Editar** en el menú de un panel o agrega un panel. El editor de paneles muestra una **Vista previa en tiempo real** del
panel con el intervalo de tiempo y las variables actuales, y dos conjuntos de pestañas:

| Pestañas | Contenido |
|---|---|
| **Consultas**, **Transformaciones**, **Enlaces de datos** | Qué lee el panel, cómo se reforma el resultado y a dónde lleva un clic. |
| **Panel**, **Campo**, **Anulaciones** | Cómo se ve el panel, cómo se muestran los valores y las excepciones para algunos campos. |

### Consultas

Selecciona **Agregar consulta** para cada consulta del panel. Cada consulta tiene un **ID de referencia**, como `A`, una
**Fuente de datos**, un **Lenguaje** de **PromQL** o **SQL**, y la **Expresión**. La fuente de datos
determina el lenguaje predeterminado y los demás campos:

| Fuente de datos | Lenguaje predeterminado | Otros campos |
|---|---|---|
| **Métricas** | PromQL | |
| **Registros**, **Trazas**, **SQL** | SQL | **Nombre del flujo** y **Tipo de flujo** (**Registros**, **Métricas** o **Trazas**). |
| **Perfiles** | SQL | **Servicio** y **Tipo de perfil**, por ejemplo `cpu`. |

**Leyenda** asigna un nombre a la serie con una plantilla como `{{service}}`. **Consulta compartida** reutiliza una consulta de
otro panel, escrita `<panel-id>:<ref-id>`, para que los datos se lean una sola vez. Las consultas pueden usar
[variables](/es/dashboards/variables) como `$service`. Consulta [Consultas](/es/query) para SQL y
PromQL.

Una consulta SQL cuyo `format` sea `time_series`, como en los paneles que agrega el [explorador de RUM](/es/rum/explorer#agregar-al-tablero),
puede responder en formato largo, con una fila para cada tiempo y grupo: una serie temporal dibuja una serie para cada conjunto de valores de sus columnas de texto
y toma el nombre de esos valores.

### Transformaciones

Las transformaciones reforman el resultado antes de dibujarlo. Se ejecutan en orden y cada una se puede deshabilitar.

| Transformación | Efecto |
|---|---|
| **Filtrar campos**, **Organizar campos**, **Cambiar el nombre de los campos** | Mantener, ordenar, ocultar o cambiar el nombre de los campos. |
| **Calcular campo** | Agregar un campo calculado a partir de otros. |
| **Reducir** | Reducir cada serie a valores como último, media, máximo o total. |
| **Agrupar por**, **Ordenar por**, **Limitar** | Agrupar por un campo, ordenar y conservar las primeras filas. |
| **Unirse**, **Combinar** | Combinar los resultados de varias consultas. |
| **Convertir etiquetas en campos**, **Convertir filas en campos**, **Convertir series temporales en tabla** | Convertir etiquetas, filas o series en columnas. |

### Opciones del panel

La pestaña **Panel** establece el **Título**, la **Descripción** que se muestra al pasar el cursor, el **Ancho** y la **Altura**,
la **Visualización**, sus opciones y si el panel es **Transparente**.

| Visualización | Dibuja |
|---|---|
| **Serie temporal** | Líneas, barras o puntos a lo largo del tiempo, con opciones de leyenda, información emergente, relleno y apilamiento. |
| **Gráfico de barras** | Valores comparados por categoría. |
| **Indicador de barras** | Valores reducidos como barras horizontales o verticales. |
| **Estadística** | Un valor, como el último, con un minigráfico opcional. |
| **Indicador** | Un valor en una escala radial con colores de umbral. |
| **Tabla** | Filas, con paginación. |
| **Registros** | Una lista compacta de registros con hora y nivel. |
| **Mapa de calor** | La intensidad de los valores a lo largo del tiempo. |
| **Cronología de estados** | Cambios de estado a lo largo del tiempo. |
| **Texto** | Markdown. |

**Variable de repetición** dibuja una copia del panel para cada valor de una variable, en una **Dirección de repetición**
de **Horizontal**, **Vertical** o **Cuadrícula**, hasta **Máx. por fila** copias en una fila. Consulta
[Repetir paneles](/es/dashboards/variables#repetir-paneles-según-una-variable).

### Opciones de campo

La pestaña **Campo** establece cómo se muestran los valores:

| Opción | Uso |
|---|---|
| **Unidad**, **Decimales** | La unidad, como bytes, porcentaje o segundos, y la cantidad de decimales. |
| **Mín.**, **Máx.** | Los extremos de la escala. |
| **Nombre visible** | Reemplaza el nombre del campo. |
| **Esquema de colores** | Un color fijo, una paleta, los colores de umbral o una escala continua. |
| **Umbrales** | Valores en los que cambia el color, en modo **Absoluto** o **Porcentaje**, a partir de **Base**. |
| **Asignaciones de valores** | Mostrar texto, un color o un ícono para un valor, un rango, una coincidencia de expresión regular o un valor especial como null. |
| **Texto cuando no hay valor** | Lo que muestra el panel cuando no hay valor. |

**Anulaciones** aplican otras opciones de campo solo a algunos campos. Selecciona **Agregar cobertura temporal**, elige un criterio de coincidencia
(**Nombre del campo**, **Expresión regular del campo**, **Tipo de campo** o **Referencia de consulta**), y **Agregar propiedad** para cada opción
que quieras cambiar.

### Enlaces de datos

Un enlace de datos convierte un clic en un valor en un salto. Selecciona **Agregar enlace de datos**, ingresa un **Título** y elige
el destino: **Registros**, **Métricas**, **Trazas**, **Perfiles**, otro **Panel** o una
URL **Externa**. Elige si el enlace incluye el intervalo de tiempo y las variables del panel, y si se abre en
una pestaña nueva. Los enlaces aparecen en el menú del panel.

## Configuración del panel

**Configuración** tiene cuatro pestañas.

| Pestaña | Contenido |
|---|---|
| **General** | **Título**, **Descripción** y **Etiquetas**. El intervalo de tiempo predeterminado (**Desde**, **Hasta**) y la **Zona horaria**. La **Cuadrícula**: **Columnas** de 1 a 48, **Altura de fila** y **Separación**. **Actualizar**: **Desactivado**, **Intervalo** con un **Intervalo predeterminado**, o **Automático**. **Información emergente del gráfico**: desactivada, o una línea de referencia compartida entre paneles. **Editable**. |
| **Variables** | Las variables del panel. Consulta [Variables](/es/dashboards/variables). |
| **Anotaciones** | Eventos dibujados en los paneles de series temporales. |
| **Enlaces** | Enlaces en el encabezado del panel. |

Una anotación tiene un **Nombre**, un **Origen**, una **Visualización** de **Línea**, **Región** o **Marcador**, un
**Color** y **Habilitado**. Enumera sus eventos en **Eventos** con **Agregar evento**: una **Etiqueta**, una
**Marca de tiempo de inicio (ms)** y, para una región, una **Marca de tiempo de fin (ms)**.

Una anotación de la fuente **Despliegues** no enumera eventos: marca los cambios de la
[lista de cambios](/es/api/changes) en cada panel de series temporales, los despliegues y otros cambios reportados
y las versiones que APM vio por primera vez, de los servicios en **Servicios** (separados por comas) o de todos
los servicios. Las anotaciones guardadas con [`POST /api/v1/changes`](/es/api/changes#mantener-anotaciones) para este
panel, o para ningún panel, también se dibujan en sus paneles de series temporales.

Un enlace tiene un **Título**, un **Tipo** de **Panel** o **Externo**, una **URL** y conmutadores para incluir el
**Intervalo de tiempo** y las **Variables**, y para abrirse en una **Pestaña nueva**.

## Guardar y reutilizar

Selecciona **Guardar**. Para reutilizar un panel, selecciona **Copiar** en su menú para copiar su JSON y pégalo en
otro panel. Para reutilizar un panel completo, **Exportar JSON** e impórtalo en otro lugar. Consulta
[Importar un panel](/es/dashboards#importar-un-panel).
