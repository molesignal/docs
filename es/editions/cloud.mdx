<Warning>
El acceso a MoleSignal Cloud está sujeto a una lista de espera. Esta página es una guía de evaluación, no una guía para activar un servicio de disponibilidad general ni para conectarse a él.
</Warning>

MoleSignal Cloud es la oferta de servicio administrado prevista para equipos que quieren evaluar la observabilidad sin operar su propia infraestructura de almacenamiento y servicios. Inscríbete en la [lista de espera de Cloud](https://www.molesignal.com/cloud). Usa la [guía de inicio rápido para el autoalojamiento](/es/quickstart) para evaluar una implementación disponible ahora.

## Prepara la evaluación de Cloud

| Requisito | Información que debes recopilar |
|---|---|
| Telemetría | Logs, métricas, trazas, perfiles, volumen diario previsto y tasas máximas de ingesta. |
| Retención | Historial necesario para cada señal y consultas que deben seguir funcionando. |
| Acceso | Tamaño del equipo, límites entre organizaciones, requisitos de identidad y uso de tokens de API. |
| Ubicación | Región requerida para los datos, acceso a la red y restricciones sobre el manejo de datos. |
| Operaciones | Expectativas de soporte, objetivos de recuperación y responsabilidades durante un incidente. |

Confirma la disponibilidad por región, los métodos de acceso, los límites de retención, las condiciones comerciales y los compromisos de soporte durante la evaluación. No des por sentado que las opciones de configuración de la modalidad autoalojada están disponibles en el servicio administrado.

## Valida primero el flujo de datos

1. Inicia una instancia autoalojada y elige un servicio representativo.
2. Envía telemetría con los [protocolos de ingesta](/es/intake/integrations) documentados.
3. Verifica las marcas de tiempo de los eventos, la selección de flujos, la identidad del servicio y los permisos.
4. Ejecuta consultas representativas e investiga un incidente. Registra el volumen y el período de retención que requiere el flujo de trabajo.
5. Analiza los requisitos identificados antes de acordar un plan de incorporación o migración a Cloud.

La dirección de la API o el token de API de una instancia autoalojada no se convierten automáticamente en una dirección o una credencial de Cloud. Usa solo el endpoint y las credenciales proporcionados para el entorno que vayas a usar.

## Precios y disponibilidad de funciones

La [página de precios](https://www.molesignal.com/pricing) describe los planes propuestos y cómo ponerse en contacto. Confirma la oferta disponible y las condiciones al coordinar el acceso. Las páginas con la etiqueta **nube empresarial** pueden describir funciones previstas. Revisa la advertencia de disponibilidad de cada página.
