La edición de código abierto ofrece la plataforma completa para alojamiento propio. Se distribuye bajo la [licencia Apache 2.0](https://github.com/molesignal/molesignal/blob/main/LICENSE), se ejecuta en infraestructura bajo el control del operador y no requiere una cuenta de MoleSignal ni un plano de control alojado.

## Qué incluye

- ingesta, almacenamiento y consultas de logs, métricas, trazas y perfiles;
- APM basado en trazas, investigación con RUM, correlación y topología de servicios;
- paneles, flujos, canalizaciones, funciones reutilizables y tablas de extensión;
- alertas, incidentes, guardias y escalamiento, envío de notificaciones, incidentes graves, remediación y análisis posteriores a incidentes;
- monitoreo sintético y páginas de estado;
- Mole Agent y acceso entrante mediante MCP al mismo catálogo de herramientas;
- aislamiento entre organizaciones, IAM, SSO, cuentas de servicio, tokens de API, eventos de auditoría y configuración de la plataforma;
- despliegue de un solo nodo con Docker Compose, un binario o Kubernetes, y despliegue con roles separados para los procesos de enrutamiento, ingesta, consultas, compactación y alertas.

Consulta todas las operaciones disponibles en la **Referencia de la API**. Los permisos siguen determinando qué operaciones puede realizar un usuario, una cuenta de servicio o un token de API.

## Requisitos de despliegue

Usa PostgreSQL para los metadatos y un almacén de objetos compatible con S3 o de Azure o Google Cloud para los datos. Para desarrollo, un solo nodo puede usar el disco local como almacén de objetos. Consulta [Despliega MoleSignal](/es/deployment).

## Empieza a alojar MoleSignal en tu infraestructura

1. Sigue la [guía de inicio rápido](/es/quickstart) para configurar una instancia local.
2. Elige una topología en [Despliega MoleSignal](/es/deployment).
3. Completa la [lista de verificación para producción](/es/deployment/production-checklist) antes de empezar a recibir datos reales.
4. Revisa [Seguridad y multitenencia](/es/security) y [Observabilidad de la plataforma](/es/self-observability).
