## Notas de la versión y preparación para la actualización

En [GitHub Releases](https://github.com/molesignal/molesignal/releases) se publican las notas de cada versión. La lista de abajo carga los detalles de las versiones en el navegador. Si JavaScript no está disponible o falla la solicitud a GitHub, usa ese enlace para consultar las versiones, las fechas de publicación, los cambios y los archivos descargables.

### Antes de actualizar

1. Registra la versión en ejecución con `molesignal --version` y busca la versión de destino en las notas de la versión.
2. Lee las notas de compatibilidad y migración entre las dos versiones. Distingue las versiones preliminares de las estables.
3. Protege PostgreSQL, el almacenamiento de objetos, la configuración y las claves de cifrado siguiendo las instrucciones de [Copia de seguridad y restauración](/es/backup-restore).
4. Valida las consultas de datos históricos, la ingesta controlada de datos nuevos, los permisos y el comportamiento de las notificaciones en un entorno aislado antes de actualizar en producción.

Consulta la [lista de verificación para producción](/es/deployment/production-checklist) y la [guía de preparación para la recuperación](/es/best-practices/recovery-readiness) para conocer los pasos de aceptación. Las funciones previstas para Enterprise aún no se han publicado. Consulta la página de cada función y las notas de la versión de destino para confirmar su disponibilidad.
