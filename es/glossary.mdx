| Término | Definición |
|---|---|
| **Alerta** | El rol que evalúa las reglas de alerta, gestiona los escalamientos, genera informes programados y ejecuta conectores. Consulta [Despliegue basado en roles](/es/deployment/role-based). |
| **Token de API** | Una credencial al portador con el formato `mspat-<36>` que permite actuar con la identidad de un usuario o de una cuenta de servicio. Consulta [Identidad y acceso](/es/identity). |
| **APM** | Monitoreo del rendimiento de aplicaciones. Agregados acotados de servicios, transacciones, dependencias, errores y versiones que se obtienen de los spans de las trazas. Consulta [APM](/es/apm). |
| **Arrow Flight SQL** | El protocolo SQL en el puerto `5083` para clientes de bases de datos como DBeaver, JDBC y ADBC. Está desactivado de forma predeterminada. Consulta [Conéctate con un cliente de base de datos](/es/query/database-clients). |
| **Catálogo** | El registro en PostgreSQL que indica qué archivos Parquet e índices pertenecen a cada flujo. |
| **Clave de cifrado** | La clave raíz en `MS_CIPHER_KEY` que cifra los secretos que MoleSignal almacena en PostgreSQL. Consulta [Lista de verificación para producción](/es/deployment/production-checklist). |
| **Compactación** | La combinación de archivos Parquet pequeños en archivos más grandes. El rol `compactor` realiza esta tarea y aplica la retención. |
| **Conector** | Una integración administrada con una plataforma externa. Un origen incorpora logs: los extrae de forma programada o recibe los que envía la plataforma. Un destino recibe la salida del pipeline. Consulta [Conectores](/es/connectors). |
| **Fuente de datos** | Una entrada del catálogo de fuentes de datos que genera el endpoint, el token y el fragmento de configuración para un origen. Consulta [Fuente de datos](/es/intake). |
| **Política de escalamiento** | Una lista ordenada de destinatarios de notificaciones con plazos para confirmar la recepción. Consulta [Gestión de alertas](/es/alerting). |
| **Tabla de enriquecimiento** | Una tabla de búsqueda que asigna claves a registros. Los pipelines consultan esta tabla para enriquecer eventos y pueden escribir filas en ella. Consulta [Tablas de enriquecimiento](/es/extend-tables). |
| **Consulta federada** | Una consulta que también examina los clústeres remotos que indiques mediante `?clusters=local,<name>`. Consulta [Despliegue basado en roles](/es/deployment/role-based). |
| **Vaciado** | La escritura del contenido del búfer en memoria de un nodo de recepción en archivos Parquet e índices en el almacenamiento de objetos. |
| **Función** | Una transformación reutilizable escrita en VRL o JavaScript. Consulta [Funciones](/es/functions). |
| **Incidente** | Una ocurrencia de una alerta que pasa por las etapas de confirmación y resolución. Consulta [Gestión de alertas](/es/alerting). |
| **Recepción** | La ruta que recibe la telemetría. También es el rol que la valida, la guarda temporalmente en un búfer y vuelca el contenido del búfer al almacenamiento. Consulta [Fuente de datos](/es/intake). |
| **Token de ingesta** | Un token para emisores de datos y pipelines de despliegue que sigue la política de permisos de **Ingesta de datos**: `logs.write`, `metrics.write`, `traces.write`, `profiles.write` y `apm.deploy`. Consulta [Fuente de datos](/es/intake#tokens-de-ingesta). |
| **Inspección de logs** | Un informe que Mole Agent redacta sobre los logs de un período, bajo demanda o de forma programada. Consulta [Inspecciones de logs](/es/logs/inspections). |
| **Mole Agent** | El agente de operaciones integrado que investiga problemas con las herramientas del catálogo. Consulta [Mole Agent](/es/agent). |
| **Calendario de guardias** | Una rotación que tiene en cuenta las zonas horarias, permite excepciones y sirve como destino de los escalamientos. Consulta [Gestión de alertas](/es/alerting). |
| **Organización** | La unidad de aislamiento que delimita el ámbito de las políticas. La interfaz web la denomina espacio de trabajo. Consulta [Conceptos básicos](/es/concepts). |
| **Parquet** | El formato de archivo columnar en el que MoleSignal almacena logs, métricas y trazas. |
| **Pipeline** | Una secuencia de pasos que enruta, normaliza, oculta datos sensibles y enriquece eventos en tiempo real durante la recepción o de forma programada. También puede modificar eventos de alerta antes de que se abran sus incidentes. Consulta [Pipelines](/es/pipelines). |
| **Administrador de la plataforma** | El usuario que identifica `[auth].root_email` y que administra la configuración de toda la plataforma. |
| **Flujo de plataforma** | Un flujo en el que solo MoleSignal escribe, como `_audit` o `_synthetic_results`. Consulta [Flujos](/es/streams#flujos-de-la-plataforma). |
| **Agente de sondeo** | Un proceso que ejecuta comprobaciones sintéticas desde una ubicación. Los nodos `standalone` ejecutan un agente integrado. Consulta [Monitoreo sintético](/es/synthetics). |
| **Rol** | Un rol de proceso que se selecciona con `[node].roles`: `standalone`, `router`, `intake`, `querier`, `compactor` o `alert`. También es un conjunto de permisos con nombre en IAM que combina políticas de permisos y permisos propios. |
| **RUM** | Monitoreo de usuarios reales en sesiones de navegadores y aplicaciones móviles. Consulta [RUM](/es/rum). |
| **Token de cliente de RUM** | Un token con el permiso `rum.write`, vinculado a una sola aplicación, que envía el código del navegador o de la aplicación móvil. |
| **Vista guardada** | Una consulta guardada junto con su intervalo de tiempo y sus opciones. |
| **Tarea de búsqueda** | Una consulta asíncrona persistente. Las consultas que superan el umbral de tamaño se convierten en tareas de búsqueda y aparecen en **Flujos → Tareas de búsqueda**. Consulta [Consultas](/es/query). |
| **Telemetría propia** | Las métricas, las trazas y los perfiles que MoleSignal registra sobre su propio funcionamiento en el flujo reservado `_molesignal`. Consulta [Observabilidad propia](/es/self-observability). |
| **Cuenta de servicio** | Una identidad no humana para recolectores y procesos automatizados. No puede iniciar sesión. Consulta [Identidad y acceso](/es/identity). |
| **Silenciar** | Una regla de duración limitada que pausa las notificaciones de las alertas que cumplen sus criterios. Consulta [Gestión de alertas](/es/alerting). |
| **Modo independiente** | El rol predeterminado que ejecuta todos los roles en un solo proceso. |
| **Página de estado** | Una página pública o privada que muestra el estado de los componentes y los incidentes. Consulta [Páginas de estado](/es/status-pages). |
| **Flujo** | El contrato tipado de una señal: un nombre, un tipo, un esquema y una configuración de retención. Consulta [Flujos](/es/streams). |
| **Tipo de flujo** | Uno de estos tipos: `logs`, `metrics`, `traces`, `profiles` o `extend`. |
| **Monitor sintético** | Una comprobación programada, como una solicitud HTTP, que registra la disponibilidad y la latencia. Consulta [Monitoreo sintético](/es/synthetics). |
| **VRL** | Vector Remap Language, uno de los lenguajes para las funciones de los pipelines. |
| **WAL** | El registro de escritura anticipada: objetos del almacenamiento de objetos que conservan los registros cuya recepción ya se confirmó hasta que se vuelcan al almacenamiento definitivo. |
| **Espacio de trabajo** | El nombre que usa la interfaz web para la organización seleccionada. |
