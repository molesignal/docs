La CLI de MoleSignal es el comando `molesignal`, disponible en npm como `@molesignal/cli`. Permite
iniciar sesión en una instancia de MoleSignal y luego:

- lee y sigue logs, ejecuta consultas SQL y PromQL, muestra trazas en cascada y resume los
  servicios de APM;
- enumera los incidentes e indica quién está de guardia, confirma la recepción de incidentes y los resuelve, ejecuta comprobaciones sintéticas
  y aplica los cambios aprobados;
- notifica despliegues, carga mapas de código fuente y símbolos de RUM y envía la salida de los scripts a un
  flujo de logs en CI;
- llama a cualquier herramienta del catálogo de MoleSignal;
- ofrece las herramientas MCP de MoleSignal a través de stdio para que Claude Code, Cursor, Codex, VS Code y
  Gemini CLI puedan iniciar la CLI como servidor MCP.

La CLI usa las herramientas de MoleSignal para consultar datos y aplicar cambios. Por eso, los permisos de la cuenta que inició sesión,
la política de herramientas de la organización y sus aprobaciones se aplican tanto a la CLI como a Mole Agent.
Para notificar despliegues, cargar artefactos de depuración y enviar logs, la CLI usa la API de MoleSignal y
requiere un token de API.

## Requisitos

- Node.js 20 o una versión posterior.
- Una instancia de MoleSignal a la que puedas acceder desde el equipo y una cuenta en esa instancia.

## Instalación

```bash
npm install -g @molesignal/cli
```

Verifica la instalación:

```bash
molesignal --version
```

También puedes ejecutar cada comando sin instalar la CLI:

```bash
npx -y @molesignal/cli --help
```

## Primeros pasos

<Steps>
  <Step title="Inicia sesión">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    El navegador abre la página de autorización de MoleSignal. Haz clic en **Autorizar**. Consulta
    [Inicio de sesión](/es/cli/sign-in).
  </Step>
  <Step title="Verifica la configuración">
    ```bash
    molesignal doctor
    ```
  </Step>
  <Step title="Lee los logs">
    ```bash
    molesignal logs app_logs -f
    ```

    Consulta [Lectura y seguimiento de logs](/es/cli/logs).
  </Step>
</Steps>

## Comandos

| Grupo | Comandos |
|---|---|
| Inicio de sesión | `login`, `logout`, `profiles`, `use`, `status`, `whoami`, `doctor`. Consulta [Inicio de sesión](/es/cli/sign-in). |
| Logs y consultas | `streams`, `logs`, `query`, `fields`. Consulta [Lectura y seguimiento de logs](/es/cli/logs). |
| Métricas, trazas y servicios | `metrics`, `traces`, `services`, `search-jobs`. Consulta [Métricas, trazas y servicios](/es/cli/observe). |
| Guardias y cambios | `incidents`, `oncall`, `approvals`, `annotate`, `synthetics`. Consulta [Incidentes y cambios](/es/cli/changes). |
| Lanzamientos y datos | `deploy`, `source-maps`, `symbols`, `send`, `run`. Consulta [CI y lanzamientos](/es/cli/ci). |
| Herramientas y configuración | `tools`, `call`, `mcp`, `open`, `completion`. Consulta [Llamadas a herramientas](/es/cli/tools) y [Servidor MCP a través de stdio](/es/cli/mcp). |

`molesignal <command> --help` describe un comando y sus opciones. También puedes consultar todas las opciones en la
[referencia de comandos](/es/cli/reference).
