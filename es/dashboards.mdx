Un panel es una cuadrícula de visualizaciones que un equipo supervisa en conjunto. Cada visualización ejecuta su propia consulta sobre los
flujos de datos del espacio de trabajo y muestra el resultado. Las variables sobre la cuadrícula cambian todas las visualizaciones a otro
servicio, host o entorno a la vez.

Esta página explica cómo encontrar y usar paneles. Para crear o modificar un panel, consulta
[Crear un panel](/es/dashboards/edit) y [Variables](/es/dashboards/variables).

## Lista de paneles

Abre **Paneles**. El encabezado muestra cuántos paneles y carpetas hay. Acota la lista con:

- el cuadro de filtro, que busca coincidencias por nombre;
- los filtros **Todos**, **Mía**, **Favoritos** y **Etiquetas**;
- una carpeta o **Todos** para ver todas las carpetas;
- la disposición en **Cuadrícula** o **Lista**.

El encabezado también incluye **Nuevo panel**, **Importar JSON** y **Administrar carpetas**. Selecciona la estrella de un
panel para agregarlo a **Favoritos**. El menú al final de cada panel ofrece estas acciones:

| Acción | Efecto |
|---|---|
| **Abrir**, **Editar**, **Compartir** | Abre el panel, su editor o el cuadro de diálogo para compartirlo. |
| **Mover a una carpeta** | Mueve el panel a otra carpeta. |
| **Crear copia** | Crea una copia editable con el nombre `<title> copy`. |
| **Exportar JSON** | Descarga el modelo del panel en un formato que admite **Importar JSON**. |
| **Establecer como vista NOC** | Muestra este panel en el [panel mural del NOC](#panel-mural-del-noc) de este navegador. |
| **Eliminar** | Elimina el panel y sus visualizaciones. Esta acción no se puede deshacer. |

## Carpetas

Las carpetas agrupan los paneles en hasta tres niveles. Selecciona **Administrar carpetas** y luego **Nueva carpeta** para crear una
carpeta en el nivel raíz o **Nueva subcarpeta** para crearla dentro de la carpeta seleccionada.

Los paneles sin carpeta aparecen en la carpeta **Predeterminado**. No puedes cambiarle el nombre, eliminarla ni crear
subcarpetas en ella. Para eliminar una carpeta, primero mueve sus paneles y subcarpetas a otra ubicación.

## Consultar un panel

El encabezado de un panel muestra su carpeta, el número de visualizaciones, el último cambio y estos controles:

| Control | Uso |
|---|---|
| Selector de tiempo | Define el intervalo de tiempo de todas las visualizaciones. El selector muestra las horas en la zona horaria personal predeterminada. Usa **Cambio** en la parte inferior del selector para ver otra zona horaria. |
| **Actualizar** | Vuelve a ejecutar las consultas de todas las visualizaciones. El menú adyacente configura la actualización automática: **Desactivado**, **Automático** o un intervalo. **Automático** ajusta el intervalo según el rango de tiempo y el ancho de la visualización. |
| Variables | Elige los valores de las [variables](/es/dashboards/variables). La dirección los conserva como `var-<name>=<value>`, de modo que el enlace copiado abre la misma vista. |
| **Compartir** | Abre el [cuadro de diálogo para compartir](/es/resource-sharing). |
| **Editar** | Abre el [editor](/es/dashboards/edit). Si el panel es de solo lectura, aparece **Crear copia** en su lugar. |
| Más | Incluye **Ver detalles del tablero**, con el ID, el UID, el propietario y el esquema, además de **Vista NOC**, **Crear copia** y **Exportar JSON**. |

Coloca el cursor sobre una visualización para ver su descripción. El menú de cada visualización incluye estas acciones:

| Acción | Efecto |
|---|---|
| **Ver** | Muestra solo la visualización, a tamaño completo. |
| **Editar** | Abre la visualización en el editor. |
| **Explorar datos** | Abre la consulta de la visualización en el explorador, con los valores de las variables y el mismo intervalo de tiempo. |
| **Inspeccionar consultas** | Muestra las definiciones de las consultas de la visualización en JSON. |
| **Compartir** | Copia un enlace a la visualización. |
| **Exportar datos** | Descarga los datos de la visualización en formato CSV. |
| **Exportar imagen** | Descarga una imagen de la visualización. |
| **Copiar** | Copia el JSON de la visualización para pegarlo en otro panel. |
| Enlaces de datos | Abre los [enlaces de datos](/es/dashboards/edit#enlaces-de-datos) de la visualización. |
| **Crear alerta** | Abre una nueva [regla de alerta](/es/alerting/rules) a partir de la consulta de la visualización. |
| **Análisis de Mole Agent** | Pide a [Mole Agent](/es/agent) que analice lo que muestra la visualización. |

## Importar un panel

Selecciona **Importar JSON**, pega el JSON de un panel de MoleSignal o carga un archivo `.json`, elige una carpeta
y selecciona **Importar**. Usa el JSON que descarga **Exportar JSON** o el que
`GET /api/v1/dashboards/{id}` devuelve como `model`. El valor de `engine` debe ser `molesignal-dashboard`.

MoleSignal no admite el JSON de los paneles de Grafana. Vuelve a crear el panel en el editor. Las expresiones PromQL se pueden
pegar sin cambios en las visualizaciones de métricas. Si prefieres mantener el panel en Grafana, consulta los datos de MoleSignal
mediante la [fuente de datos de Grafana](/es/query/grafana).

## Pedir un panel a Mole Agent

Pide a [Mole Agent](/es/agent) que prepare un borrador de panel, por ejemplo: «un panel para el servicio
de pago». Mole Agent prepara un borrador sin crear el panel y proporciona un enlace a **Borrador del panel generado por IA**:

1. Revisa la **Vista previa de solo lectura**, que usa el mismo motor de renderizado que un panel real.
2. Revisa la **Verificación previa de consultas**. Cada consulta se ejecutó una vez y muestra un estado: **Verificación superada**, **Resultado vacío** u
   **Omitido**. Revisa también si hay **Advertencias de generación** o **Problemas por corregir**.
3. Selecciona **Enviar propuesta de creación**. Si la política de creación exige una revisión, el borrador queda pendiente
   de aprobación. De lo contrario, selecciona **Confirmar y crear**.

Cada borrador está vinculado a su modelo y vence pasado un tiempo. Solicita otro borrador para hacer cambios.

## Paneles de RUM integrados

Los espacios de trabajo con aplicaciones de RUM incluyen paneles de solo lectura con las etiquetas `内置` y `rum`, uno por cada tipo
de aplicación:

| Panel | Para | Muestra |
|---|---|---|
| `RUM · 浏览器应用` | Aplicaciones web | Sesiones, sesiones sin errores y sesiones con señales de frustración; LCP, INP y CLS en el percentil 75, con sus respectivas tendencias; errores por origen; páginas, versiones, elementos que generan frustración y hosts lentos; países y navegadores. |
| `RUM · 移动应用` | Aplicaciones de Android, iOS, Flutter y React Native | Sesiones, sesiones sin cierres inesperados ni errores y sesiones con señales de frustración; evolución de las sesiones sin cierres inesperados, los errores y los cierres inesperados; pantallas, versiones, cierres inesperados por versión, elementos que generan frustración y hosts lentos; dispositivos y sistemas operativos. |

MoleSignal instala cada panel al crear la primera aplicación de su tipo. Si el espacio de trabajo ya tiene una aplicación de ese tipo,
el servidor instala el panel al iniciarse. Las actualizaciones que modifican un panel se aplican de la misma
manera. Las variables son **应用** (la aplicación), **环境** (un entorno o **全部** para todos los
entornos) e **间隔** (el ancho de las barras en un gráfico temporal). **Abrir en el panel**, en la
[vista general de RUM](/es/rum#vista-general), abre el panel con la aplicación y el entorno de la
página ya seleccionados.

Cada visualización contiene una instrucción SQL breve. MoleSignal consulta las vistas y las sesiones mediante `rum_views_latest` y
`rum_sessions_latest`, que contienen la [versión más reciente](/es/query#versiones-actuales-de-las-filas-de-rum) de cada registro,
y calcula los percentiles solo con las vistas que tienen el valor. Así, las cifras coinciden con las de la vista general.
Estos paneles no se pueden editar. Selecciona **Crear copia** en el encabezado del panel o en la
lista de paneles para obtener una copia editable.

## Panel mural del NOC

Selecciona **Panel mural del NOC** en la barra superior para abrir en pantalla completa una vista oscura diseñada para pantallas murales.
Presiona `Esc` o selecciona **Volver a la consola** para salir.

La barra de estado resume el espacio de trabajo: los incidentes activos y sus niveles de gravedad, el estado de los datos en tiempo real,
la cantidad de servicios, la tasa de solicitudes y la latencia P95. Las visualizaciones muestran:

| Visualización | Muestra |
|---|---|
| **Incidentes** | Los incidentes activos en este momento. |
| **Topología** | La topología de servicios de la última hora. |
| **Estado** | Cada servicio con su tasa de solicitudes, latencia P95 y tasa de errores. |
| **Tráfico** | Los servicios con más tráfico en los últimos 60 minutos. |

Con **Configurar la disposición**, puedes aplicar una configuración predefinida (**Operaciones de plataforma**, **SRE** o
**Ejecutivo**), mostrar u ocultar una visualización, ajustar su ancho, adelantarla o retrasarla en el orden, o usar **Restablecer**.
El navegador guarda la disposición.

Si estableces un panel como vista NOC, el panel mural muestra el título de ese panel y
cada una de sus visualizaciones con su consulta. El panel mural no muestra gráficos. Abre el
panel para verlos.

## Informes y uso compartido

Crea un [informe](/es/reports) programado desde un panel de control para enviarlo en formato PDF, PNG, CSV, SVG o JSON.
Usa **Compartir** para permitir el acceso con sesión iniciada, entre espacios de trabajo o mediante acceso público restringido. Un panel de control público solo ejecuta
las consultas guardadas de sus paneles y respeta la [política de uso compartido](/es/settings/organization#uso-compartido-y-acceso-público)
del espacio de trabajo.
