VS Code admite servidores MCP mediante stdio y HTTP remoto, autorización OAuth, recursos, prompts y herramientas.

## Conéctate mediante stdio (recomendado)

El cliente inicia la CLI de MoleSignal, que envía los mensajes a MoleSignal. La CLI requiere
Node.js 20 o posterior.

<Steps>
  <Step title="Inicia sesión una sola vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

El navegador abre MoleSignal para que autorices el inicio de sesión. La CLI conserva y renueva la sesión.

  </Step>
  <Step title="Agrega MoleSignal">

En `.vscode/mcp.json`:

```json
{
  "servers": {
    "molesignal": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

Inicia el servidor desde el archivo o la vista de MCP y confirma que confías en el servidor cuando se te solicite.

  </Step>
</Steps>

Si no hay un navegador disponible, configura `MOLESIGNAL_URL` y `MOLESIGNAL_TOKEN` (un token de API) en el
entorno del servidor en lugar de iniciar sesión. Consulta [Conéctate mediante stdio](/es/inbound-mcp#conéctate-mediante-stdio).

En las secciones siguientes, conéctate mediante Streamable HTTP sin usar la CLI.

## Configura el servidor

Crea `.vscode/mcp.json` para compartir la configuración en el área de trabajo. Para usar una configuración
global privada, ejecuta **MCP: Abrir configuración de usuario** desde la paleta de comandos.

```json
{
  "servers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Inicia el servidor">
    Abre `mcp.json` y selecciona la acción integrada **Inicio**, o ejecuta **MCP: Enumerar servidores** y elige
    `molesignal`.
  </Step>
  <Step title="Confirma que confías en el servidor">
    Revisa el punto de conexión y confirma que confías en el servidor MCP. La configuración del área de trabajo puede
    compartirse con todos los colaboradores, así que no incluyas credenciales en el archivo.
  </Step>
  <Step title="Completa la autorización de OAuth">
    VS Code usa el mecanismo de detección de OAuth de MoleSignal y abre la página de autorización en el navegador. Concede
    el acceso y vuelve al modo de agente del chat.
  </Step>
  <Step title="Verifica la conexión">
    Ejecuta **MCP: Enumerar servidores**, revisa el estado de `molesignal` y comprueba que las herramientas aparezcan en la vista
    de chat.
  </Step>
</Steps>

Usa **Agregar contexto → Recursos de MCP** para adjuntar un recurso de MoleSignal o ejecuta un prompt publicado
con `/molesignal.<prompt>`.

Consulta la [documentación oficial de MCP en VS Code](https://code.visualstudio.com/docs/agent-customization/mcp-servers).
