Gemini CLI admite servidores stdio y Streamable HTTP, detección de OAuth, y herramientas, recursos e instrucciones de MCP.

## Conéctate mediante stdio (recomendado)

El cliente inicia la CLI de MoleSignal, que envía los mensajes a MoleSignal. La CLI requiere
Node.js 20 o posterior.

<Steps>
  <Step title="Inicia sesión una sola vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

El navegador abre MoleSignal para que apruebes el inicio de sesión. La CLI mantiene la sesión y la renueva.

  </Step>
  <Step title="Agrega MoleSignal">

```bash
gemini mcp add molesignal npx -y @molesignal/cli mcp
```

  </Step>
</Steps>

Si no tienes un navegador disponible, configura `MOLESIGNAL_URL` y `MOLESIGNAL_TOKEN` (un token de API) en el
entorno del servidor en lugar de iniciar sesión. Consulta [Conéctate mediante stdio](/es/inbound-mcp#conéctate-mediante-stdio).

En las siguientes secciones, usa Streamable HTTP para conectarte sin la CLI.

## Conéctate con OAuth 2.1

<Steps>
  <Step title="Agrega MoleSignal">

    ```bash
    gemini mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    Omite `--scope user` para guardar la entrada en el archivo `.gemini/settings.json` del proyecto actual.

  </Step>
  <Step title="Autentícate">
    Inicia una sesión interactiva de Gemini CLI y ejecuta:

    ```text
    /mcp auth molesignal
    ```

    Completa el flujo de autorización en el navegador. Gemini CLI detecta los endpoints de OAuth y
    registra el cliente de forma dinámica y automática.

  </Step>
  <Step title="Verifica el servidor">

    ```bash
    gemini mcp list
    ```

    Ejecuta `/mcp` dentro de la sesión interactiva para ver las herramientas, los recursos y las instrucciones disponibles.

  </Step>
</Steps>

## Configura la conexión con JSON

La entrada equivalente de Streamable HTTP en `~/.gemini/settings.json` o
`.gemini/settings.json` es:

```json
{
  "mcpServers": {
    "molesignal": {
      "httpUrl": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

No configures `trust: true` para un servidor de operaciones administradas, a menos que la política local de Gemini deba
omitir la solicitud de confirmación del cliente. El servidor sigue aplicando la política de aprobación de
MoleSignal.

Consulta la [documentación oficial de MCP para Gemini CLI](https://geminicli.com/docs/tools/mcp-server/).
