Claude Code admite servidores stdio, servidores remotos Streamable HTTP con detección de OAuth y ámbitos de configuración
local, de proyecto o de usuario.

## Conéctate mediante stdio (recomendado)

El cliente inicia la CLI de MoleSignal, que transmite los mensajes a MoleSignal. La CLI requiere
Node.js 20 o posterior.

<Steps>
  <Step title="Inicia sesión una sola vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

El navegador abre MoleSignal para que apruebes el inicio de sesión. La CLI conserva y renueva la sesión.

  </Step>
  <Step title="Agrega MoleSignal">

```bash
claude mcp add --scope user molesignal -- npx -y @molesignal/cli mcp
claude mcp get molesignal
```

  </Step>
</Steps>

Si no hay un navegador disponible, configura `MOLESIGNAL_URL` y `MOLESIGNAL_TOKEN` (un token de API) en el
entorno del servidor en lugar de iniciar sesión. Consulta [Conéctate mediante stdio](/es/inbound-mcp#conéctate-mediante-stdio).

Las siguientes secciones explican cómo conectarte mediante Streamable HTTP sin usar la CLI.

## Conéctate con OAuth 2.1

<Steps>
  <Step title="Agrega el servidor remoto">

    ```bash
    claude mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    `--scope user` hace que el servidor esté disponible en todos los proyectos. Omite la opción para guardar la configuración localmente en el
    proyecto o usa `--scope project` para agregar una entrada compartida a `.mcp.json`.

  </Step>
  <Step title="Autoriza MoleSignal">

    ```bash
    claude mcp login molesignal
    ```

    Como alternativa, abre Claude Code, ejecuta `/mcp`, selecciona `molesignal` y completa la autenticación.

  </Step>
  <Step title="Verifica el servidor">

    ```bash
    claude mcp get molesignal
    claude mcp list
    ```

  </Step>
</Steps>

Si usas una terminal SSH o sin interfaz gráfica, muestra la URL de autorización y pega la URL final de retorno
en Claude Code:

```bash
claude mcp login molesignal --no-browser
```

## Conéctate con un token de API

Usa la expansión de variables de entorno en el archivo `.mcp.json` del proyecto en lugar de guardar el token en el repositorio:

```json
{
  "mcpServers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer ${MOLESIGNAL_MCP_TOKEN}"
      }
    }
  }
}
```

Configura `MOLESIGNAL_MCP_TOKEN` antes de iniciar Claude Code. Para los servidores con ámbito de proyecto, confirma explícitamente
que confías en ellos antes de la primera conexión.

Consulta la [documentación oficial de MCP para Claude Code](https://code.claude.com/docs/en/mcp).
