Cursor admite servidores MCP mediante stdio y servidores MCP remotos mediante Streamable HTTP con autenticación OAuth.

## Conéctate mediante stdio (recomendado)

El cliente inicia la CLI de MoleSignal, que transmite los mensajes a MoleSignal. La CLI requiere
Node.js 20 o posterior.

<Steps>
  <Step title="Inicia sesión una sola vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

El navegador abre MoleSignal para que apruebes el inicio de sesión. La CLI conserva la sesión y la renueva.

  </Step>
  <Step title="Agrega MoleSignal">

En `.cursor/mcp.json` para el proyecto o en `~/.cursor/mcp.json` para todos los proyectos:

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

Luego, activa `molesignal` en **Tools & MCP**.

  </Step>
</Steps>

Si no hay un navegador disponible, configura `MOLESIGNAL_URL` y `MOLESIGNAL_TOKEN` (un token de API) en el
entorno del servidor en lugar de iniciar sesión. Consulta [Conéctate mediante stdio](/es/inbound-mcp#conéctate-mediante-stdio).

En las siguientes secciones, usa Streamable HTTP para conectarte sin la CLI.

## Configura el servidor

Crea `.cursor/mcp.json` para el proyecto actual o `~/.cursor/mcp.json` para una configuración
global:

```json
{
  "mcpServers": {
    "molesignal": {
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Abre Tools & MCP">
    Abre **Cursor Settings → Tools & MCP** y busca `molesignal`.
  </Step>
  <Step title="Conéctate con OAuth">
    Selecciona **Conexión** y completa la autorización en la página de MoleSignal. Cursor detecta los endpoints
    de OAuth a partir de los metadatos del recurso protegido de MCP.
  </Step>
  <Step title="Verifica las herramientas">
    Confirma que `tool_search`, `call_read_tool` y `call_managed_tool` figuren entre las herramientas
    disponibles. Reinicia el servidor desde **Tools & MCP** después de cambiar la configuración.
  </Step>
</Steps>

<Warning>
  No incluyas un token Bearer en `.cursor/mcp.json` al hacer un commit. Usa preferentemente OAuth para una sesión interactiva
  de Cursor. Para las credenciales no interactivas, usa un mecanismo de inyección de secretos que admita el cliente.
</Warning>

Consulta la [documentación oficial de MCP en Cursor](https://cursor.com/docs/mcp).
