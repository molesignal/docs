Codex inicia servidores MCP mediante stdio y admite el endpoint Streamable HTTP de MoleSignal y el descubrimiento de OAuth.

## Conéctate mediante stdio (recomendado)

El cliente inicia la CLI de MoleSignal, que envía los mensajes a MoleSignal. La CLI requiere
Node.js 20 o posterior.

<Steps>
  <Step title="Inicia sesión una sola vez">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

El navegador abre MoleSignal para que apruebes el inicio de sesión. La CLI guarda la sesión y la renueva.

  </Step>
  <Step title="Agrega MoleSignal">

```bash
codex mcp add molesignal -- npx -y @molesignal/cli mcp
```

O en `~/.codex/config.toml`:

```toml
[mcp_servers.molesignal]
command = "npx"
args = ["-y", "@molesignal/cli", "mcp"]
```

  </Step>
</Steps>

Si no hay un navegador disponible, define `MOLESIGNAL_URL` y `MOLESIGNAL_TOKEN` (un token de API) en el
entorno del servidor en lugar de iniciar sesión. Consulta [Conéctate mediante stdio](/es/inbound-mcp#conéctate-mediante-stdio).

Las siguientes secciones explican cómo conectarte mediante Streamable HTTP sin usar la CLI.

## Conéctate con OAuth 2.1

<Steps>
  <Step title="Registra MoleSignal">

    ```bash
    codex mcp add molesignal \
      --url https://molesignal.example.com/api/v1/mcp
    ```

  </Step>
  <Step title="Autoriza la conexión">

    ```bash
    codex mcp login molesignal
    ```

    Completa la autorización en la página de MoleSignal que se abre en el navegador.

  </Step>
  <Step title="Verifica el servidor">

    ```bash
    codex mcp get molesignal
    codex mcp list
    ```

    Reinicia la tarea activa de Codex o abre una nueva para actualizar la lista de herramientas MCP.

  </Step>
</Steps>

<Warning>
  No agregues `--oauth-resource`. MoleSignal ya publica el recurso protegido mediante
  el descubrimiento de OAuth. Si agregas el mismo valor otra vez, puede aparecer el error `duplicate field resource`.
</Warning>

## Conéctate con un token de API

Usa un token de API personal o de una cuenta de servicio para un proceso no interactivo de Codex:

```bash
export MOLESIGNAL_MCP_TOKEN="<api-token>"

codex mcp add molesignal \
  --url https://molesignal.example.com/api/v1/mcp \
  --bearer-token-env-var MOLESIGNAL_MCP_TOKEN
```

Codex guarda el nombre de la variable de entorno en lugar del valor del token. Pon la variable
a disposición del proceso que inicia Codex.

## Verifica el descubrimiento de herramientas

Pídele a Codex:

> Usa el servidor MCP de MoleSignal. Busca herramientas de incidentes y enumera los incidentes activos. No hagas
> cambios.

La primera solicitud debe usar `tool_search` y después `call_read_tool` para realizar una lectura diferida.

Consulta la [documentación oficial de MCP en Codex](https://developers.openai.com/codex/mcp/).
