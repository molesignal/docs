---
title: "OpenTelemetry (OTLP)"
description: "Ingest via the OTLP HTTP or gRPC exporter."
---

Point any OpenTelemetry SDK or Collector at MoleSignal.

| Transport | Endpoint |
|---|---|
| OTLP HTTP | `POST /api/v1/logs`, `/api/v1/metrics`, `/api/v1/traces` |
| OTLP gRPC | `:5082` |

<RequestExample>
```yaml OTel Collector
exporters:
  otlphttp:
    endpoint: http://localhost:5080/api/v1
    headers:
      authorization: "Bearer ${MS_JWT}"
  otlp:
    endpoint: localhost:5082
    headers:
      authorization: "Bearer ${MS_JWT}"
```
</RequestExample>
