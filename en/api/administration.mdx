Operational and security endpoints. Most require an elevated role (Admin or Owner).

## Audit log

```http
GET /api/v1/audit
```

Every mutating operation is recorded. Admin+ only.

**Query parameters:** `from`, `to`, `actor`, `action`, `page`.

## Quotas

```http
GET /api/v1/orgs/{id}/quota   # read (Owner-only)
PUT /api/v1/orgs/{id}/quota   # set
```

Caps ingest QPS, query QPS, and storage. Exceeding them returns `429` / `413` plus an audit entry
and an alert.

<RequestExample>
```json PUT body
{
  "ingest_qps": 5000,
  "query_qps": 200,
  "storage_bytes": 1099511627776
}
```
</RequestExample>

## Cipher keys

Field-level encryption keys (AES-256-GCM). The raw key is never returned after creation. See
[Security → Field-level encryption](/en/security#field-level-encryption).

```http
GET    /api/v1/cipher_keys              # list (Owner-only)
POST   /api/v1/cipher_keys              # create (32-byte base64 raw key)
GET    /api/v1/cipher_keys/{name}       # get latest version
DELETE /api/v1/cipher_keys/{name}
POST   /api/v1/cipher_keys/{name}/rotate # inserts a new version, keeps prior
```

## Paid-edition endpoints

These are gated behind a license/feature build and return `403` when not enabled:

| Area | Endpoints |
|---|---|
| SSO (OIDC) | `/api/v1/auth/sso/login`, `/api/v1/auth/sso/callback` |
| Federated clusters | `/api/v1/clusters` (+ `/{id}`) |
| Connectors | `/api/v1/connectors` (+ `/{id}`) — `aws_cloudwatch_logs` / `aws_kinesis_firehose` / `cloudflare_logpush` / `heroku_drain` |
| Copilot (LLM stats) | `/api/v1/copilot/stats`, `/top_models`, `/top_users` |
| RUM | `/api/v1/rum/v1/{sessions,actions,errors,replay}` |

## Health & metrics

```http
GET /api/v1/healthz   # liveness + readiness (200 ready / 503 degraded) — unauthenticated
GET /metrics          # Prometheus exposition — unauthenticated
```
