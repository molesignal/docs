---
title: "Log in"
description: "Exchange email and password for a JWT."
---

```http
POST /api/v1/auth/login
```

Exchange email + password for a JWT. This route is **unauthenticated**.

**Body**

| Field | Type | Required |
|---|---|---|
| `email` | string | ✅ |
| `password` | string | ✅ |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/auth/login \
  -H 'content-type: application/json' \
  -d '{"email":"admin@example.com","password":"admin"}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "token": "eyJhbGciOi...",
  "user_id": "u_2abc...",
  "org_id": "o_2def...",
  "role": "owner"
}
```
</ResponseExample>
