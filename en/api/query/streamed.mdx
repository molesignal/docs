---
title: "Streamed query"
description: "NDJSON chunked query response."
---

```http
GET  /api/v1/query/stream
POST /api/v1/query/stream
```

Always returns an NDJSON chunked response. The `GET` form takes query params (`sql`, `stream`,
`stream_type`, `from`, `to`, `limit`); the `POST` form takes the same body as
[Execute a query](/en/api/query/execute). Disable proxy buffering at the ingress
(`proxy_buffering off`) so chunks flush promptly.
