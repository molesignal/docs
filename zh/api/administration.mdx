运维与安全端点。多数需要更高角色（Admin 或 Owner）。

## 审计日志

```http
GET /api/v1/audit
```

每个写操作都被记录。仅 Admin+。

**查询参数：** `from`、`to`、`actor`、`action`、`page`。

## 配额

```http
GET /api/v1/orgs/{id}/quota   # 读取（仅 Owner）
PUT /api/v1/orgs/{id}/quota   # 设置
```

限制接入 QPS、查询 QPS、存储。超限返回 `429` / `413`，并附审计记录与告警。

<RequestExample>
```json PUT body
{
  "ingest_qps": 5000,
  "query_qps": 200,
  "storage_bytes": 1099511627776
}
```
</RequestExample>

## Cipher keys

字段级加密密钥（AES-256-GCM）。创建后原始密钥永不返回。见
[安全 → 字段级加密](/zh/security#字段级加密)。

```http
GET    /api/v1/cipher_keys              # 列出（仅 Owner）
POST   /api/v1/cipher_keys              # 创建（32 字节 base64 原始密钥）
GET    /api/v1/cipher_keys/{name}       # 获取最新版本
DELETE /api/v1/cipher_keys/{name}
POST   /api/v1/cipher_keys/{name}/rotate # 插入新版本，保留旧版本
```

## 付费版端点

以下端点位于 license/特性构建之后，未启用时返回 `403`：

| 领域 | 端点 |
|---|---|
| SSO（OIDC） | `/api/v1/auth/sso/login`、`/api/v1/auth/sso/callback` |
| 联邦集群 | `/api/v1/clusters`（+ `/{id}`） |
| Connectors | `/api/v1/connectors`（+ `/{id}`）—— `aws_cloudwatch_logs` / `aws_kinesis_firehose` / `cloudflare_logpush` / `heroku_drain` |
| Copilot（LLM 统计） | `/api/v1/copilot/stats`、`/top_models`、`/top_users` |
| RUM | `/api/v1/rum/v1/{sessions,actions,errors,replay}` |

## 健康与指标

```http
GET /api/v1/healthz   # liveness + readiness（200 ready / 503 degraded）—— 免认证
GET /metrics          # Prometheus exposition —— 免认证
```
