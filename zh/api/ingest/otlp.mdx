---
title: "OpenTelemetry（OTLP）"
description: "通过 OTLP HTTP 或 gRPC exporter 接入。"
---

把任意 OpenTelemetry SDK 或 Collector 指向 MoleSignal。

| 传输 | 端点 |
|---|---|
| OTLP HTTP | `POST /api/v1/logs`、`/api/v1/metrics`、`/api/v1/traces` |
| OTLP gRPC | `:5082` |

<RequestExample>
```yaml OTel Collector
exporters:
  otlphttp:
    endpoint: http://localhost:5080/api/v1
    headers:
      authorization: "Bearer ${MS_JWT}"
  otlp:
    endpoint: localhost:5082
    headers:
      authorization: "Bearer ${MS_JWT}"
```
</RequestExample>
