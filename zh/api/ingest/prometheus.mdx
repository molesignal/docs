---
title: "Prometheus remote_write"
description: "直接替代 Prometheus remote_write 目标。"
---

```http
POST /api/v1/prometheus/api/v1/write
```

接受 Prometheus / VictoriaMetrics remote_write（snappy + protobuf）。成功返回 `204`。

<RequestExample>
```yaml prometheus.yml
remote_write:
  - url: http://localhost:5080/api/v1/prometheus/api/v1/write
    authorization:
      credentials: "${MS_JWT}"
```
</RequestExample>
