---
title: "编辑保留策略"
description: "设置流数据的保留时长。"
---

```http
PUT /api/v1/streams/{id}/retention
```

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/s_app/retention \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{"retention_days": 30}'
```
</RequestExample>
