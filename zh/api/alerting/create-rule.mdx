---
title: "创建规则"
description: "创建告警规则。"
---

```http
POST /api/v1/alerts/rules
```

规则的 `kind` 为 `scheduled`、`realtime` 或 `anomaly`。见 [告警](/zh/alerting)。

<RequestExample>
```json body
{
  "name": "High error rate",
  "kind": "scheduled",
  "stream": "app",
  "statement": "SELECT count(*) AS c FROM app WHERE level = 'error'",
  "condition": { "op": ">", "value": 100 },
  "interval_secs": 60,
  "escalation_id": "esc_2abc..."
}
```
</RequestExample>
