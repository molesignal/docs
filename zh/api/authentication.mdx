---
title: "认证"
description: "登录获取 JWT，并管理长期 API token 与 JWT 签名密钥。"
---

除 `/api/v1/healthz`、`/api/v1/auth/login`、`/metrics` 外，所有端点都需要 bearer token。请求头格式
见 [简介](/zh/api-reference#认证)。

## 登录

```http
POST /api/v1/auth/login
```

用邮箱 + 密码换取 JWT。该路由免认证。

**请求体**

| 字段 | 类型 | 必填 |
|---|---|---|
| `email` | string | ✅ |
| `password` | string | ✅ |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/auth/login \
  -H 'content-type: application/json' \
  -d '{"email":"admin@example.com","password":"admin"}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "token": "eyJhbGciOi...",
  "user_id": "u_2abc...",
  "org_id": "o_2def...",
  "role": "owner"
}
```
</ResponseExample>

## 签发 API token

```http
POST /api/v1/auth/tokens
```

创建形如 `ms_<prefix>_<secret>` 的长期 token。明文 secret **仅返回一次** —— 请立刻保存。每个 token
带角色、过期时间、最近使用时间。

<ResponseExample>
```json 200
{
  "id": "t_2ghi...",
  "token": "ms_a1b2c3_d4e5f6g7h8i9...",
  "role": "data_plane_admin",
  "expires_at": 1735689600000000
}
```
</ResponseExample>

## 列出 API token

```http
GET /api/v1/auth/tokens
```

返回 token 元数据（不含 secret）。

## 吊销 API token

```http
DELETE /api/v1/auth/tokens/{id}
```

## 轮换 JWT 签名密钥

```http
POST /api/v1/auth/jwt/rotate
```

仅 Owner。退役当前密钥并插入新密钥，并有 **24 小时宽限期**让在途 token 继续可校验。用
`GET /api/v1/auth/jwt/secrets` 查看签名密钥元数据（永不返回密钥字节）。

<Note>
  SSO（OIDC）登录 —— `GET /api/v1/auth/sso/login` 与 `/api/v1/auth/sso/callback` —— 位于付费 license
  之后，未授权时返回 `403`。
</Note>
