---
title: "健康与指标"
description: "liveness/readiness 与 Prometheus 指标。"
---

两个路由均**免认证**。

```http
GET /api/v1/healthz
```

liveness + readiness 探针。ready 时 `200`；degraded（ingester 回放或对象存储探测失败）时 `503`。

```http
GET /metrics
```

Prometheus exposition（`text/plain; version=0.0.4`），含 cache / object_store / ingester / compactor
指标。
