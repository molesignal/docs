---
title: "流"
description: "列出、创建、管理流及其 schema 与保留策略。"
---

流是数据分区的最细粒度单元。见 [核心概念 → 流](/zh/concepts#流stream)。

## 列出流

```http
GET /api/v1/streams
```

<ResponseExample>
```json 200
[
  { "id": "s_app", "name": "app", "stream_type": "logs", "retention_days": 30 },
  { "id": "s_cpu", "name": "host_cpu", "stream_type": "metrics", "retention_days": 90 }
]
```
</ResponseExample>

## 创建流

```http
POST /api/v1/streams
```

流也会在首次接入时隐式创建；用此端点可预先声明一个。

<Note>
  `stream_type: enrichment` 不能作为 pipeline target。
</Note>

## 获取单个流

```http
GET /api/v1/streams/{id}
```

## 删除流

```http
DELETE /api/v1/streams/{id}
```

## 编辑 schema

```http
PUT /api/v1/streams/{id}/schema
```

调整字段类型或新增字段。schema 也会随新字段到达自动演进。

## 编辑保留策略

```http
PUT /api/v1/streams/{id}/retention
```

设置流中数据被 compactor 回收前的保留时长。

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/s_app/retention \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{"retention_days": 30}'
```
</RequestExample>
