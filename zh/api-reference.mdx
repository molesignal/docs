MoleSignal 暴露单一 HTTP API，版本为 `v1`。除下方白名单外，每个端点都需
`Authorization: Bearer <jwt>`（或 API token）认证。

## 约定

- **认证：** `Authorization: Bearer <jwt>`。免认证路由：`/api/v1/healthz`、`/api/v1/auth/login`、
  `/metrics`。
- **错误：** 统一 body `{ "error": "<message>" }`。
- **时间戳：** Unix 纪元起微秒（`_timestamp`、`time_range.start/end`）。

### 状态码

| 码 | 含义 |
|---|---|
| `400` | 参数非法 |
| `401` | 未授权（token 校验失败） |
| `403` | 禁止（角色 / license 不足） |
| `404` | 未找到 / 跨组织查找 |
| `409` | 冲突（唯一约束 / 状态冲突） |
| `413` | 配额耗尽 |
| `429` | 限流 |

## 端点索引

### 认证与身份
`POST /api/v1/auth/login` · `POST /api/v1/auth/tokens` · `GET/DELETE /api/v1/auth/tokens/{id}` ·
`POST /api/v1/auth/jwt/rotate` · `GET /api/v1/audit` · `GET/PUT /api/v1/orgs/{id}/quota`

### 接入
`POST /api/v1/ingest/{logs,metrics,traces}/{stream}` · `POST /api/v1/{logs,metrics,traces}`（OTLP HTTP）·
OTLP gRPC `:5082` · `POST /api/v1/prometheus/api/v1/write` · `POST /api/v1/_bulk` ·
`POST /api/v1/loki/api/v1/push` · `POST /api/v1/_kinesis_firehose` · `POST /api/v1/_cloudflare` ·
`POST /api/v1/_heroku`

### 查询
`POST /api/v1/query` · `POST /api/v1/query/search_around`

### 流、仪表盘、保存的视图
`GET/POST /api/v1/streams` · `/api/v1/streams/{id}`（+ `/schema`、`/retention`）·
`POST /api/v1/dashboards` · `POST /api/v1/folders` · `/api/v1/saved_views`（+ `/{id}/run`）

### 告警
`/api/v1/alerts/rules`（+ `/{id}`）· `POST /api/v1/alerts/escalations` ·
`POST /api/v1/alerts/channels` · `GET /api/v1/alerts/incidents` ·
`POST /api/v1/alerts/incidents/{id}/ack` · `POST /api/v1/alerts/incidents/{id}/resolve`

### 管道与函数
`/api/v1/functions` · `/api/v1/pipelines` · `/api/v1/scheduled_pipelines`

### 关联与 Web shell
`GET /api/v1/web/search` · `GET /api/v1/web/topology` · `GET /api/v1/web/trace/{trace_id}` ·
`GET /api/v1/web/correlation/{from_kind}/{to_kind}` · `POST /api/v1/web/investigation/blob` ·
`GET /api/v1/traces/service_graph`

### 安全（cipher keys）
`/api/v1/cipher_keys` · `/api/v1/cipher_keys/{name}` · `POST /api/v1/cipher_keys/{name}/rotate`
