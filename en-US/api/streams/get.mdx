```http
GET /api/v1/streams/{id}
```

Returns the stream definition with its schema, the explicit `retention`, the calculated `effectiveRetention`, and the stream settings. The call requires `streams.read`, or `sys.telemetry.read` for system telemetry. The `_audit` stream also needs `audit.read` and answers `403` without it.

**Path parameters**

| Param | Type | Notes |
|---|---|---|
| `id` | string | The stream `id` from [List streams](/en-US/api/streams/list). An unknown id answers `404`. |
