```http
GET /api/v1/streams/{id}
```

Returns the stream definition with its schema, the explicit `retention`, the calculated `effective_retention`, and the stream settings. The call requires `streams.read`, or `sys.telemetry.read` for system telemetry.

**Path parameters**

| Param | Type | Notes |
|---|---|---|
| `id` | string | The stream `id` from [List streams](/en-US/api/streams/list). An unknown id answers `404`. |

<ResponseExample>
```json 200
{
  "id": "3KE0ot1NtfCTJ3V3XxBNbqx9Y62",
  "org_id": "<organization-id>",
  "name": "app",
  "stream_type": "logs",
  "schema": {
    "fields": [
      { "name": "level", "data_type": "utf8", "nullable": true, "index_type": "none",
        "indexed": false, "encrypted": false, "exact": false },
      { "name": "trace_id", "data_type": "utf8", "nullable": true, "index_type": "exact",
        "indexed": true, "encrypted": false, "exact": true }
    ]
  },
  "retention": null,
  "effective_retention": { "days": 30 },
  "settings": {
    "description": null,
    "index_rules": [],
    "queryable": true,
    "field_masking": []
  },
  "created_at_micros": 1790000000000000,
  "updated_at_micros": 1790000000000000
}
```
</ResponseExample>

`retention` is `null` when the stream uses the default, and `effective_retention` always carries the days that apply. The `settings` object also holds `retention_filter`, `keep_conditions`, `max_query_range_hours`, `flatten_level`, `use_stream_stats_for_partitioning`, `store_original_data`, and `enable_distinct_values`. The current release stores these values and does not apply them.
