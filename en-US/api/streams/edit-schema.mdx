---
title: "Configure field indexes"
description: "Choose the index of each field in a stream."
"zh-Hans_link": "/zh-Hans/api/streams/edit-schema"
---

```http
PUT /api/v1/streams/{id}/settings
```

The schema of a stream evolves as new fields arrive through intake, and the API does not replace field types. Use this endpoint to choose the index type of fields that are already in the schema. The call requires `streams.configure`, and `audit.read` for the `_audit` stream. The same endpoint also edits retention and settings, see [Edit retention and settings](/en-US/api/streams/edit-retention).

**Body**

| Field | Type | Notes |
|---|---|---|
| `fields` | array | One entry per field to configure. |

Each entry of `fields`:

| Property | Type | Notes |
|---|---|---|
| `name` | string | A field that is already in the schema. |
| `indexed` | boolean | Enables the index. |
| `indexType` | string | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, or `key_value`. See [Streams](/en-US/streams#schema-and-fields). |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexed": true, "indexType": "exact" },
      { "name": "msg", "indexed": true, "indexType": "full_text" }
    ]
  }'
```
</RequestExample>

The response is the updated stream, in the shape that [Get a stream](/en-US/api/streams/get) shows. A change applies at once to the data written afterwards, and the data written before is indexed again in the background; see [Streams](/en-US/streams#schema-and-fields). The `full_text`, `ngram`, and `ip` indexes are limited to `utf8` fields, and `key_value` to `json` fields.
