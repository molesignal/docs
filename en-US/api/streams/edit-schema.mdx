---
title: "Configure field indexes"
description: "Choose the index of each field in a stream."
---

```http
PUT /api/v1/streams/{id}/settings
```

The schema of a stream evolves as new fields arrive through intake, and the API does not replace field types. Use this endpoint to choose the index type of fields that are already in the schema. The call requires `streams.configure`. The same endpoint also edits retention and settings, see [Edit retention and settings](/en-US/api/streams/edit-retention).

**Body**

| Field | Type | Notes |
|---|---|---|
| `fields` | array | One entry per field to configure. |

Each entry of `fields`:

| Property | Type | Notes |
|---|---|---|
| `name` | string | A field that is already in the schema. |
| `indexed` | boolean | Enables the index. |
| `index_type` | string | `none`, `exact`, `full_text`, `bloom`, or `skip`. See [Streams](/en-US/streams#schema-and-fields). |
| `condition` | string or `null` | Optional condition. |
| `sdr_patterns` | array of strings | Optional patterns. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexed": true, "index_type": "exact",
        "condition": null, "sdr_patterns": [] },
      { "name": "msg", "indexed": true, "index_type": "full_text",
        "condition": null, "sdr_patterns": [] }
    ]
  }'
```
</RequestExample>

The response is the updated stream, in the shape that [Get a stream](/en-US/api/streams/get) shows. A change affects only the files that are written afterwards, and existing files keep their old indexes. A `full_text` index is limited to `utf8` fields.
