---
title: "List streams"
description: "List the streams of the organization."
---

```http
GET /api/v1/streams
```

Returns every stream of the organization, sorted by name and type, as a JSON array. Each item has the shape that [Get a stream](/en-US/api/streams/get) shows, including the schema, the explicit `retention`, the calculated `effective_retention`, the settings, and microsecond timestamps. The call requires `streams.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

The response includes the protected system streams, such as `_molesignal`. A stream is identified by its name and type, so the same name can appear for several types.
