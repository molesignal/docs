```http
GET /api/v1/streams
```

Returns every stream of the organization, sorted by name and type, as a JSON array. Each item has the shape that [Get a stream](/en-US/api/streams/get) shows, including the schema, the explicit `retention`, the calculated `effectiveRetention`, the settings, and microsecond timestamps. The call requires `streams.read` or `sys.telemetry.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

The response includes the protected system streams, such as `_molesignal`. It leaves out `_audit` when the token lacks `audit.read`. A stream is identified by its name and type, so the same name can appear for several types.

## Use the response

This endpoint returns stream definitions, not telemetry records. Use it to discover a stream ID before reading its schema or changing its configuration. To query events, use the [query API](/en-US/api/query/execute).

| Field | Interpretation |
|---|---|
| `id` | Stable identifier used by the single-stream API. |
| `name` and `streamType` | Identify the dataset together; do not key an inventory by name alone. |
| `schema` | Field definitions used to construct queries. |
| `retention` | Explicit stream retention; `null` means the default applies. |
| `effectiveRetention` | Resolved retention used by the stream. |
| `createdAt`, `updatedAt` | Unix timestamps in microseconds, not milliseconds. |

## Verify access and data scope

Use a credential associated with the intended organization. `streams.read` or `sys.telemetry.read` admits the list request; `_audit` is omitted without `audit.read`. The absence of `_audit` does not imply that audit collection is disabled.

The response is a JSON array, not an envelope with an `items` field. There is no pagination parameter on this route. An empty array means no streams were returned for this request's organization and visibility; it is not proof that another organization has no data.

After finding the required `(name, streamType)`, pass its `id` to [Get a stream](/en-US/api/streams/get). Use a [sample query](/en-US/api/query/execute) to verify actual event availability separately from the presence of a stream definition.
