```http
PUT /api/v1/streams/{id}/settings
```

Updates the retention and the settings of a stream. Send only the properties to change. The call requires `streams.configure`.

**Body**

| Field | Type | Notes |
|---|---|---|
| `retention_days` | integer or `null` | 1 through 3650 days. `null` clears the explicit value, and the stream inherits `[compactor].retention_days`. A value outside the range answers `400`. |
| `settings` | object | Stream settings, see below. |
| `fields` | array | Field indexes, see [Configure field indexes](/en-US/api/streams/edit-schema). |

Settings that have an effect:

| Setting | Notes |
|---|---|
| `description` | Free text shown in the web UI. |
| `queryable` | `false` keeps the stream receiving and retaining data, hides it from query selectors, and makes queries fail with `403` (`stream is not queryable`). |
| `field_masking` | Stream-level overrides of the global [field masking](/en-US/settings#data-security) rules. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "retention_days": 30,
    "settings": { "description": "Application logs", "queryable": true }
  }'
```
</RequestExample>

The response is the updated stream. Retention controls when the compactor removes data. A change affects later clean-ups and never restores deleted files. The other properties of `settings` (`retention_filter`, `keep_conditions`, `max_query_range_hours`, `flatten_level`, `use_stream_stats_for_partitioning`, `store_original_data`, and `enable_distinct_values`) are accepted and stored, and the current release does not apply them.
