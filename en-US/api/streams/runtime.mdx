```http
GET /api/v1/streams/runtime
```

Returns the runtime state of every stream: stored rows and bytes, the last receive time, an intake status, and a time series of buckets. The call requires `streams.read`, or `sys.telemetry.read` for system telemetry. The `_audit` stream is left out when the token lacks `audit.read`.

**Query parameters**

| Param | Default | Notes |
|---|---|---|
| `windowSecs` | 86400 | Length of the window, limited to 3600 through 604800. |
| `bucketCount` | 24 | Buckets in the series, limited to 6 through 48. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/runtime?windowSecs=3600" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

| `status` | Meaning |
|---|---|
| `healthy` | Data arrived in the last 15 minutes. |
| `delayed` | The last data is older than 15 minutes and newer than 2 hours. |
| `interrupted` | The last data is older than 2 hours. |
| `idle` | A stream that is quiet by design, such as the Mole Agent trace stream. |
| `unused` | The stream never received data. |
| `unknown` | The statistics are not available. |

`staleIndexFiles` counts the files still indexed under the settings in force before an index type of the stream last changed. It falls to 0 as the background indexes them again.
