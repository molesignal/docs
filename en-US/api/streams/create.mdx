---
title: "Create a stream"
description: "Pre-declare a stream with an explicit schema or retention."
---

```http
POST /api/v1/streams
```

A stream is also created on the first write. Use this call to declare a stream with an explicit schema, indexes, encrypted fields, or retention first. The call requires `streams.create`.

**Body**

| Field | Type | Required | Notes |
|---|---|---|---|
| `name` | string | Yes | Letters, numbers, `_`, `-`, and `.`. The name `_molesignal` is reserved. |
| `stream_type` | string | Yes | `logs`, `metrics`, `traces`, `profiles`, or `extend`. |
| `fields` | array | No | Field definitions. See below. |
| `retention_days` | integer | No | 1 through 3650. Omit it to use `[compactor].retention_days`. |
| `settings` | object | No | Stream settings such as `description` and `queryable`. See [Edit retention and settings](/en-US/api/streams/edit-retention). |

A field has these properties:

| Property | Type | Notes |
|---|---|---|
| `name` | string | Field name. |
| `data_type` | string | `bool`, `int64`, `float64`, `utf8`, `timestamp`, or `json`. |
| `nullable` | boolean | Default `true`. |
| `indexed` | boolean | Enables an index. |
| `index_type` | string | `none`, `exact`, `full_text`, `bloom`, or `skip`. When `indexed` is `true` and `index_type` is omitted, text fields get `full_text` and other fields get `skip`. |
| `encrypted` | boolean | Encrypts the field at rest. It cannot be changed later. See [Streams](/en-US/streams#encrypted-fields). |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "name": "app",
    "stream_type": "logs",
    "fields": [
      { "name": "trace_id", "data_type": "utf8", "nullable": true,
        "indexed": true, "index_type": "exact", "encrypted": false }
    ],
    "retention_days": 30
  }'
```
</RequestExample>

**Errors**

| Status | Cause |
|---|---|
| `403` | The name is `_molesignal`, or the token lacks `streams.create`. |
| `409` | A stream with the same name and type already exists. |
| `422` | A body field is missing or invalid, for example an unknown `data_type`. The response is plain text. |
