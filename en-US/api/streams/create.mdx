---
title: "Create a stream"
description: "Pre-declare a stream."
---

```http
POST /api/v1/streams
```

Streams are also created implicitly on first ingest; use this to pre-declare one with an explicit
schema or retention.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "name": "app",
    "stream_type": "logs",
    "fields": [
      {
        "name": "trace_id",
        "data_type": "utf8",
        "nullable": true,
        "indexed": true,
        "index_type": "exact",
        "encrypted": false
      }
    ],
    "retention_days": 30
  }'
```
</RequestExample>

<Note>
  `profiles` and `extend` streams cannot be used as pipeline targets. Manage extend-table data
  through the `/api/v1/extend_tables` API.
</Note>

Names may contain letters, numbers, `_`, `-`, and `.`. Field types are `bool`, `int64`, `float64`,
`utf8`, `timestamp`, and `json`. Creating a stream requires `streams.create`.
