---
title: "Delete a stream"
description: "Delete a stream by id."
---

```http
DELETE /api/v1/streams/{id}
```

Deletes the stream definition. The compactor reclaims the stored data. The protected `_molesignal` system stream cannot be deleted. Deleting a stream can break dashboards, saved views, alert rules, reports, and pipelines that reference it. The call requires `streams.delete`.

**Path parameters**

| Param | Type | Notes |
|---|---|---|
| `id` | string | The stream `id`. An unknown id answers `404`. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/streams/$STREAM_ID \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>
