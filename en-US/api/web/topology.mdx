title: "Service topology"
description: "Nodes and edges of the service graph for a time window."

```http
GET /api/v1/web/topology
```

Aggregates the service-graph edges of a time window into nodes and edges, with request rate, error rate, and latency. The edges come from the service graph that MoleSignal derives from trace spans. See [Service map](/en-US/service-map). The call requires `streams.query`, or `sys.telemetry.read` in the system scope.

**Query parameters**

| Param | Type | Required | Notes |
|---|---|---|---|
| `from` | string | Yes | The start of the window, as an RFC 3339 timestamp. |
| `to` | string | Yes | The end of the window, as an RFC 3339 timestamp. It must not precede `from`. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/topology?from=2026-10-04T09:00:00Z&to=2026-10-04T10:00:00Z" \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "nodes": [
    { "id": "checkout", "name": "checkout", "error_rate": 0.0278, "p95_ms": 90.0, "rps": 0.1, "span_count": 360 },
    { "id": "frontend", "name": "frontend", "error_rate": 0.0278, "p95_ms": 90.0, "rps": 0.1, "span_count": 360 }
  ],
  "edges": [
    { "source": "frontend", "target": "checkout", "rps": 0.1, "err_rate": 0.0278, "p95_ms": 90.0 }
  ]
}
```
</ResponseExample>

**Response**

| Field | Notes |
|---|---|
| `nodes[].id`, `nodes[].name` | The service name. Nodes are sorted by name. |
| `nodes[].span_count` | The requests on every edge that touches the service, as client or as server. |
| `nodes[].error_rate`, `edges[].err_rate` | Errors divided by requests, from 0 to 1. |
| `nodes[].rps`, `edges[].rps` | Requests divided by the length of the window in seconds. |
| `nodes[].p95_ms`, `edges[].p95_ms` | The highest p95 latency among the aggregated buckets, in milliseconds. This is not a p95 of the whole window. |
| `edges[].source`, `edges[].target` | The client service and the server service. Edges are sorted by source, then target. |

A window without edges answers empty arrays.

**Errors**

| Status | Cause |
|---|---|
| `400` | `from` or `to` is missing or is not an RFC 3339 timestamp, or `to` precedes `from`. |
| `403` | The token lacks `streams.query`. |
