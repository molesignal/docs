```http
GET /api/v1/web/investigation/blob/{id}
```

Returns the JSON document that [Store investigation stack](/en-US/api/web/store-investigation) saved under `blob_id`. The lookup is limited to the organization of the caller, so an identifier from another organization answers `404`. The call requires `streams.query`, or `sys.telemetry.read` in the system scope.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/web/investigation/blob/$BLOB_ID \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "version": 1,
  "stack": [
    { "kind": "trace", "trace_id": "0af7651916cd43dd8448eb211c80319c" },
    { "kind": "log", "query": "level = error" }
  ]
}
```
</ResponseExample>

The response is the stored document, unchanged. A document that the compactor has removed after 7 days answers `404` as well.

**Errors**

| Status | Cause |
|---|---|
| `403` | The token lacks `streams.query`. |
| `404` | The identifier is unknown, belongs to another organization, or has expired. |
