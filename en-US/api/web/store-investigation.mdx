---
title: "Store investigation stack"
description: "Persist the state of an investigation under a short identifier."
"zh-Hans_link": "/zh-Hans/api/web/store-investigation"
---

```http
POST /api/v1/web/investigation/blob
```

Stores a JSON document in object storage and returns an identifier. The web UI uses the call to keep the investigation stack of a large investigation out of the page URL, which then carries only the identifier. Read the document with [Fetch investigation stack](/en-US/api/web/fetch-investigation). The call requires `streams.query`, or `sys.telemetry.read` in the system scope.

The body is any JSON value up to 1 MiB (1,048,576 bytes). The document belongs to the organization of the caller. The compactor removes it after 7 days.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/investigation/blob \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "version": 1,
    "stack": [
      { "kind": "trace", "trace_id": "0af7651916cd43dd8448eb211c80319c" },
      { "kind": "log", "query": "level = error" }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "blob_id": "3KEZAC5JXc0P0HjrTdARfCgH1Y3"
}
```
</ResponseExample>

**Errors**

| Status | Cause |
|---|---|
| `400` | The body is not valid JSON (plain text), or the document exceeds 1 MiB (`payload exceeds 1048576 bytes`). |
| `403` | The token lacks `streams.query`. |
