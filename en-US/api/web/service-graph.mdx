title: "Service graph edges"
description: "Read the raw service-graph edges of a time window."

```http
GET /api/v1/traces/service_graph
```

Returns the raw service-graph edges that [Service topology](/en-US/api/web/topology) aggregates. Each edge counts the calls from a client service to a server service during one minute. The call requires `streams.query`, or `sys.telemetry.read` in the system scope.

**Query parameters**

| Param | Type | Required | Notes |
|---|---|---|---|
| `from` | integer | Yes | The start of the window, in microseconds since the Unix epoch. |
| `to` | integer | Yes | The end of the window, in microseconds. |
| `service` | string | No | Keeps only the edges that have this service as client or as server. |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000
curl "http://localhost:5080/api/v1/traces/service_graph?from=$((NOW-3600000000))&to=$NOW&service=checkout" \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "edges": [
    {
      "id": "3KBCiQWW0TtpDu7D4pH7LMtZsRh",
      "org_id": "<organization-id>",
      "client_service": "frontend",
      "server_service": "checkout",
      "bucket_at_micros": 1790000000000000,
      "request_count": 12,
      "error_count": 1,
      "p50_us": 90000,
      "p95_us": 210000,
      "p99_us": 240000
    }
  ],
  "count": 1
}
```
</ResponseExample>

**Response**

| Field | Notes |
|---|---|
| `edges[].client_service`, `edges[].server_service` | The calling service and the called service. |
| `edges[].bucket_at_micros` | The start of the one-minute bucket, in microseconds. |
| `edges[].request_count`, `edges[].error_count` | The calls and the failed calls in the bucket. |
| `edges[].p50_us`, `edges[].p95_us`, `edges[].p99_us` | Latency percentiles of the bucket, in microseconds. A percentile can be `null`. |
| `count` | The number of edges returned. |

A window without matching edges answers `{"edges": [], "count": 0}`, and so does a `to` that precedes `from`.

**Errors**

| Status | Cause |
|---|---|
| `400` | `from` or `to` is missing or is not an integer. The response is plain text. |
| `403` | The token lacks `streams.query`. |
