---
title: "Create rule"
description: "Create an alert rule."
---

```http
POST /api/v1/alerts/rules
```

A rule's `kind` is `scheduled`, `realtime`, or `anomaly`. See [Alerting](/en-US/alerting).

<RequestExample>
```json body
{
  "name": "High error rate",
  "kind": "scheduled",
  "stream": "app",
  "statement": "SELECT count(*) AS c FROM app WHERE level = 'error'",
  "condition": { "op": ">", "value": 100 },
  "interval_secs": 60,
  "escalation_id": "esc_2abc..."
}
```
</RequestExample>
