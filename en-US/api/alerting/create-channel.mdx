---
title: "Create notification channel"
description: "Slack, webhook, or email channel."
---

```http
POST /api/v1/alerts/channels
```

Channels deliver over Slack, webhook, or email, with optional notification templates. Creation
requires `alerts.manage`.

```json
{
  "name": "Operations Slack",
  "kind": {
    "type": "slack",
    "webhook_url": "https://hooks.slack.com/services/...",
    "channel": "#operations",
    "mentions": []
  },
  "enabled": true,
  "template_id": null
}
```

Generic webhooks also support `post`, `put`, or `patch`, provider-aware payloads, secret-backed
headers, and Lark/Feishu or DingTalk signatures.
