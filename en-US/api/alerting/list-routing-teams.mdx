---
title: "List team on-call policies"
description: "List the organization's teams with their on-call policies and owned services."
"zh-Hans_link": "/zh-Hans/api/alerting/list-routing-teams"
---

```http
GET /api/v1/alerts/routing/teams
```

Lists the organization's teams by name (case-insensitive), each with its [on-call policy](/en-US/alerting/routing#team-on-call-policies) and the services it owns in the APM service catalog. It requires `alerts.routing.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/teams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "teamId": "<team-id>",
    "name": "Payments",
    "memberCount": 4,
    "escalationPolicyId": "<policy-id>",
    "services": ["default/checkout", "default/cart"]
  }
]
```
</ResponseExample>

| Field | Description |
|---|---|
| `teamId`, `name` | The team's ID and name. |
| `memberCount` | How many members the team has. |
| `escalationPolicyId` | The team's on-call policy; `null` when none is set, so incidents routed to the team take the default policy. |
| `services` | The services registered to the team in the service catalog and not archived, as `namespace/name`. |
