---
title: "Delete a routing rule"
description: "Delete an alert routing rule."
"zh-Hans_link": "/zh-Hans/api/alerting/delete-routing-rule"
---

```http
DELETE /api/v1/alerts/routing/rules/{id}
```

Deletes a [routing rule](/en-US/alerting/routing#routing-rules). It requires `alerts.routing.manage`. New incidents it would have matched are routed by the rules after it; incidents already open keep the routing they opened with, including the rule name recorded on them.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/routing/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "deleted": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1" }
```
</ResponseExample>

**Errors**

| Status | Cause |
|---|---|
| `403` | The token lacks `alerts.routing.manage`. |
| `404` | The rule does not exist or belongs to another organization. |
