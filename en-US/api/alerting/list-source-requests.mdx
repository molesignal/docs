```http
GET /api/v1/alerts/sources/{id}/requests
```

Returns the requests an [alert source](/en-US/alerting/sources) received recently, the latest first. It requires `alerts.sources.read`. The last 500 requests of each source are kept, for up to 7 days, on the cluster that handled them.

**Query parameters**

| Parameter | Type | Description |
|---|---|---|
| `limit` | integer | How many to return, 1 to 200. Default 50. |

| Field | Description |
|---|---|
| `receivedAt` | When it was received, in microseconds. |
| `viaCluster` | The federation cluster that passed it on; empty when it came here directly. |
| `status` | `accepted`, `rejected`, or `forwarded` to the receiving cluster. |
| `httpStatus` | The status answered to the sender. |
| `message` | Why it was refused, or why nothing was done. |
| `alertCount` | How many alerts the request held. |
| `alerts` | For up to 100 alerts: the action, dedup key, title, severity, outcome (see [Send alerts](/en-US/api/alerting/send-alerts)), reason and incident ID. |
| `bodyExcerpt` | The start of a refused body, up to 16 KiB. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/requests?limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>
