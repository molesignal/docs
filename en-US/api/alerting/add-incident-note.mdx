```http
POST /api/v1/alerts/incidents/{id}/notes
```

Adds a note to the [timeline](/en-US/api/alerting/incident-timeline) of an incident, of any status. Mole
Agent reads the latest notes with the incident. The call requires `alerts.incidents.update`.

**Body**

| Field | Type | Required | Notes |
|---|---|---|---|
| `text` | string | Yes | 1 to 4,000 characters, leading and trailing spaces dropped. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/notes \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"text": "Rolled back the edge proxy."}'
```
</RequestExample>

The response is the timeline entry of the note.

<ResponseExample>
```json 200
{
  "id": "3KEE1aXy7pRtGd2s9Lm4Qv8bNcE",
  "org_id": "<organization-id>",
  "incident_id": "3KEDNEyqouYJeBDTLTMTBui7XHW",
  "at": 1790000300000000,
  "kind": "note",
  "actor": "<user-id>",
  "detail": {
    "text": "Rolled back the edge proxy.",
    "via": "api"
  }
}
```
</ResponseExample>

**Errors**

| Status | Cause |
|---|---|
| `400` | `text` is empty or longer than 4,000 characters. |
| `403` | The token lacks `alerts.incidents.update`, or the incident is out of the token's reach. |
| `404` | The incident does not exist. |
