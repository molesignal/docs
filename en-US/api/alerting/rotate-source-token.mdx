---
title: "Rotate a source token"
description: "Give an alert source a new token; the old one stops working at once."
"zh-Hans_link": "/zh-Hans/api/alerting/rotate-source-token"
---

```http
POST /api/v1/alerts/sources/{id}/token
```

Gives an [alert source](/en-US/alerting/sources) a new token. It requires `alerts.sources.manage`, and the body is empty. The old token stops working at once; with federation on, it stops working on the other clusters once the change syncs. Senders still using the old token need the new one.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/token \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

The response is the source with the new `token`, which appears only this once.

**Errors**

| Status | Cause |
|---|---|
| `403` | The token lacks `alerts.sources.manage`. |
| `404` | The source does not exist. |
