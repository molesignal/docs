---
title: "Create escalation policy"
description: "Multi-step escalation with on-call rotations."
---

```http
POST /api/v1/alerts/escalations
```

A multi-step policy: each step has typed targets and `ack_timeout_secs`. Targets can reference a
user, team, or on-call schedule, together with notification channel ids.

```json
{
  "name": "Primary operations",
  "steps": [
    {
      "targets": [
        {
          "kind": "schedule",
          "schedule_id": "<schedule-id>",
          "channel_ids": ["<channel-id>"]
        }
      ],
      "ack_timeout_secs": 300,
      "min_severity": "warning"
    }
  ],
  "repeat": true,
  "max_loops": 2
}
```

Creation requires `alerts.manage`.
