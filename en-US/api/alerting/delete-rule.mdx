---
title: "Delete a rule"
description: "Delete an alert rule."
"zh-Hans_link": "/zh-Hans/api/alerting/delete-rule"
---

```http
DELETE /api/v1/alerts/rules/{id}
```

Deletes a rule. The call requires `alerts.manage`. Incidents that the rule already opened stay readable and follow an independent lifecycle, and the deleted rule no longer resolves any of them.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>

The response body is the plain text `deleted`. An unknown `id` answers `404`.
