---
title: "Set a team on-call policy"
description: "Set or remove the on-call policy of a team."
"zh-Hans_link": "/zh-Hans/api/alerting/set-team-policy"
---

```http
PUT /api/v1/alerts/routing/teams/{team_id}
```

Sets or removes a team's [on-call policy](/en-US/alerting/routing#team-on-call-policies). It requires `alerts.routing.manage`. New incidents routed to the team escalate by it; without one they take the default policy.

| Field | Type | Description |
|---|---|---|
| `escalation_policy_id` | string \| null | An escalation policy ID of the organization; `null` or left out removes the team's on-call policy. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/teams/$TEAM_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"escalation_policy_id": "<policy-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "team_id": "<team-id>", "escalation_policy_id": "<policy-id>" }
```
</ResponseExample>

**Errors**

| Status | Cause |
|---|---|
| `400` | The team does not exist or belongs to another organization, or the escalation policy does not exist. |
| `403` | The token lacks `alerts.routing.manage`. |
| `422` | Another field is given. The response is plain text. |
