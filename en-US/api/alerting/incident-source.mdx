```http
GET /api/v1/alerts/incidents/{id}/source
```

Returns what the source side knows of an incident an [alert source](/en-US/alerting/sources) opened. It requires `alerts.incidents.read`. Such an incident carries the label `alert.source=external`, and its `rule_id` is the source's ID.

| Field | Description |
|---|---|
| `source` | The source, as in [List alert sources](/en-US/api/alerting/list-sources); `null` once the source was deleted. |
| `dedup_key` | The dedup key. |
| `last_event_at` | The latest sender time this dedup key used, in microseconds; older messages are ignored. `null` for the API kind. |
| `last_intake_at` | When the alert was last received, in microseconds. |
| `members` | The alerts of an Alertmanager or Grafana notification group, up to 100: `status` (`firing` or `resolved`), `labels`, `summary`, `starts_at`, `ends_at` and the `url` back to the sender. Empty for the other kinds. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/source \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Errors**

| Status | Cause |
|---|---|
| `404` | The incident does not exist, or no alert source opened it. |
