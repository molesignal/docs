```http
POST /api/v1/_heroku
```

Accepts a text log drain body. The endpoint does not use a bearer token. Create a connector of kind `heroku_drain` with a `push_token` and a `target_stream`. Heroku cannot set custom headers, so the token rides in the URL as `?token=`. The header `X-Connector-Token` also works. A wrong token answers `401`.

Each line becomes one log event in the `target_stream` (default `heroku`). The line is stored whole in the field `message`, and the field `source` is `heroku`. The endpoint answers `204` on success.

<RequestExample>
```bash Heroku CLI
heroku drains:add "https://molesignal.example.com/api/v1/_heroku?token=<push_token>"
```
</RequestExample>
