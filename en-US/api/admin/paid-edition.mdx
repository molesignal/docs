---
title: "Paid-edition endpoints"
description: "License/feature-gated endpoints."
---

These are gated behind a license/feature build and return `403` when not enabled.

| Area | Endpoints |
|---|---|
| SSO (OIDC) | `/api/v1/auth/sso/login`, `/api/v1/auth/sso/callback` |
| Federated clusters | `/api/v1/clusters` (+ `/{id}`) |
| Connectors | `/api/v1/connectors` (+ `/{id}`) — `aws_cloudwatch_logs` / `aws_kinesis_firehose` / `cloudflare_logpush` / `heroku_drain` |
| Copilot (LLM stats) | `/api/v1/copilot/stats`, `/top_models`, `/top_users` |
| RUM | `/api/v1/rum/v1/{sessions,actions,errors,replay}` |
