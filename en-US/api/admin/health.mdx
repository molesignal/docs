---
title: "Health & metrics"
description: "Liveness/readiness and Prometheus metrics."
---

Both routes are **unauthenticated**.

```http
GET /api/v1/healthz
```

Liveness + readiness probe. `200` when ready; `503` when degraded (ingester replay or object-store
probe failing).

```http
GET /metrics
```

Prometheus exposition (`text/plain; version=0.0.4`) with cache / object_store / ingester / compactor
metrics.
