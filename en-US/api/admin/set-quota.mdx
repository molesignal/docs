---
title: "Set quota"
description: "Set an org's quota."
---

```http
PUT /api/v1/orgs/{id}/quota
```

Caps ingest QPS, query QPS, and storage. Exceeding them returns `429` / `413` plus an audit entry
and an alert.

<RequestExample>
```json body
{
  "ingest_qps": 5000,
  "query_qps": 200,
  "storage_bytes": 1099511627776
}
```
</RequestExample>
