```http
GET /api/v1/entities
GET /api/v1/entities/detail?kind={kind}&key={key}
```

Entities are read every five minutes from the instances APM sees and from the resource fields of
metrics and logs; see [Infrastructure](/en-US/infrastructure) for the fields and keys. Both calls need
any of `apm.services.read`, `metrics.read`, `logs.read`, or `sys.telemetry.read`.

## List entities

| Parameter | Notes |
|---|---|
| `kind` | `cluster`, `node`, `host`, `pod`, or `container`. Every kind when left out. |
| `search` | Part of the name or the key, ignoring case. |
| `seenSince` | Only entities seen since this time, in microseconds. |
| `limit` | At most 500, the default. |

Entities come back the latest seen first. `services` counts the services that run on each directly.

<ResponseExample>
```json 200
[
  {
    "kind": "pod",
    "key": "prod-eu/shop/checkout-7d9f-abcde",
    "name": "checkout-7d9f-abcde",
    "attributes": {
      "k8s.cluster.name": "prod-eu",
      "k8s.namespace.name": "shop",
      "k8s.node.name": "node-3",
      "k8s.pod.name": "checkout-7d9f-abcde"
    },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000,
    "services": 1
  }
]
```
</ResponseExample>

## Read one entity

`kind` and `key` are required; the key is the one the list gives. The answer has the entity, what it
runs on or is part of (`parents`), what runs on or is part of it (`children`, up to 200), and the
services on it and on what runs on it (`services`, up to 200), looked for three levels down: a
cluster's nodes, their pods, and the services on those.

<ResponseExample>
```json 200
{
  "entity": {
    "kind": "node",
    "key": "prod-eu/node-3",
    "name": "node-3",
    "attributes": { "k8s.cluster.name": "prod-eu", "k8s.node.name": "node-3" },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000
  },
  "parents": [{ "kind": "cluster", "key": "prod-eu", "name": "prod-eu" }],
  "children": [{ "kind": "pod", "key": "prod-eu/shop/checkout-7d9f-abcde", "name": "checkout-7d9f-abcde" }],
  "services": [{ "namespace": "shop", "name": "checkout", "environment": "production" }]
}
```
</ResponseExample>

**Errors**

| Status | Cause |
|---|---|
| `400` | `kind` is not one of the five kinds. |
| `404` | No entity of this kind and key was seen over the last week. |
