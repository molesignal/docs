---
title: "Prometheus remote_write"
description: "Drop-in Prometheus remote_write target."
---

```http
POST /api/v1/prometheus/api/v1/write
```

Accepts Prometheus / VictoriaMetrics remote_write (snappy + protobuf). Returns `204` on success.
Each time series' `__name__` label selects its metric stream; remaining labels become fields and
samples are stored as `value`. The bearer principal needs `streams.write`.

<RequestExample>
```yaml prometheus.yml
remote_write:
  - url: http://localhost:5080/api/v1/prometheus/api/v1/write
    authorization:
      credentials: "${MS_JWT}"
```
</RequestExample>
