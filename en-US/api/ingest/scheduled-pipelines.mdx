---
title: "Manage pipelines"
description: "List, inspect, edit, run, pause, and delete scheduled pipelines."
---

```http
GET  /api/v1/scheduled_pipelines
POST /api/v1/scheduled_pipelines
```

A scheduled pipeline runs on an interval expression (`every:Ns/m/h`). Creating one requires
`pipelines.create`.

```http
GET    /api/v1/scheduled_pipelines/{id}
PUT    /api/v1/scheduled_pipelines/{id}
DELETE /api/v1/scheduled_pipelines/{id}
GET    /api/v1/scheduled_pipelines/{id}/runs
POST   /api/v1/scheduled_pipelines/{id}/backfill
```

Use `pipelines.read` to inspect pipelines and run history, `pipelines.edit` to change configuration,
`pipelines.pause` to toggle `enabled`, `pipelines.run` to submit a backfill, and
`pipelines.delete` to remove a pipeline. Backfill windows cannot exceed 31 days.
