---
title: "Create a saved view"
description: "Save a query as a reusable view."
---

```http
POST /api/v1/saved_views
```

Saves a query with a relative time range. The call requires `saved_views.create`.

**Body**

| Field | Type | Required | Notes |
|---|---|---|---|
| `name` | string | Yes | Display name. |
| `language` | string | Yes | `sql` or `promql`. |
| `statement` | string | Yes | The query text. |
| `time_range_secs` | integer | Yes | Relative window, 1 through 31,622,400 seconds. A value outside the range answers `400`. |
| `stream` | string | No | The primary stream name. |
| `tags` | array of strings | No | Labels for filtering. |
| `pinned` | boolean | No | Shows the view first. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/saved_views \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = '"'"'error'"'"'",
    "time_range_secs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true
  }'
```
</RequestExample>

The response is the created view, in the shape that [List saved views](/en-US/api/query/list-saved-views) shows.
