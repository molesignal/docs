```http
GET /api/v1/saved_views
```

Returns the saved views of the organization. Add `?pinned=true` to return only pinned views. The call requires `saved_views.read`.

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/saved_views?pinned=true" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KE7RbW5ShK8cbrZZq4I4O3XUge",
    "orgId": "<organization-id>",
    "ownerUserId": "<user-id>",
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = 'error'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true,
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

Other routes: `GET /api/v1/saved_views/{id}` returns one view, and `DELETE /api/v1/saved_views/{id}` answers `deleted`.

## List all views or pinned views

Omit `pinned`, or set `pinned=false`, to list views without the pinned-only filter. `pinned=false` does not mean “only unpinned”. Set `pinned=true` when building a pinned-view shortcut list.

The request returns definitions in the current organization, not query results. The response is a JSON array; `[]` is a valid result when no view matches the filter. If a known view is missing, check the credential's organization and remove the pinned filter before assuming the view was deleted.

## Read the saved query

| Field | Use |
|---|---|
| `id` | Pass to the detail or execution endpoint. |
| `language`, `statement` | The saved query language and query text. |
| `stream` | The saved stream context, when present. |
| `timeRangeSecs` | Saved time-window length in seconds. |
| `tags`, `pinned` | Organization and navigation metadata, not query filters. |
| `createdAt`, `updatedAt` | Microsecond timestamps. |

Reading a definition does not execute it or grant permission to query its data. Follow [Run a saved view](/en-US/api/query/run-saved-view) to execute a view with the required permissions. Use [Create a saved view](/en-US/api/query/create-saved-view) to save a query, and [Saved views](/en-US/saved-views) for the UI workflow.
