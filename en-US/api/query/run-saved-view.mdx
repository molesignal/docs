---
title: "Run a saved view"
description: "Load a saved view and execute its query."
---

```http
GET  /api/v1/saved_views/{id}
POST /api/v1/query
```

A saved view stores the `language`, the `statement`, the `stream`, and a relative `time_range_secs`. There is no separate run endpoint. The web application follows this two-request flow, which needs `saved_views.read` and `streams.query`:

1. Load the view with `GET /api/v1/saved_views/{id}`.
2. Compute an absolute range that ends now: `end` is the current time in microseconds, and `start` is `end` minus `time_range_secs` times 1,000,000.
3. Send the stored `language` and `statement`, the computed `time_range`, and the stream to [Execute a query](/en-US/api/query/execute).

<RequestExample>
```bash cURL
VIEW=$(curl -s http://localhost:5080/api/v1/saved_views/$VIEW_ID \
  -H "authorization: Bearer $MS_JWT")

END=$(date +%s)000000
START=$((END - $(echo "$VIEW" | jq .time_range_secs) * 1000000))

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d "{\"org_id\":\"$MS_ORG\",
       \"language\":$(echo "$VIEW" | jq .language),
       \"statement\":$(echo "$VIEW" | jq .statement),
       \"time_range\":{\"start\":$START,\"end\":$END},
       \"stream\":{\"name\":$(echo "$VIEW" | jq .stream),\"stream_type\":\"logs\"}}"
```
</RequestExample>

The saved view stores the stream name without a type, so pass the stream type that the view belongs to.
