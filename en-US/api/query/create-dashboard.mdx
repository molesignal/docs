```http
POST /api/v1/dashboards
```

Creates a dashboard. The body wraps the complete dashboard model in `model` and can name a `folder_id`. The `uid` must be unique in the organization, or the call answers `409`. The call requires `dashboards.create`.

**Required properties of the model**

| Property | Notes |
|---|---|
| `engine` | `molesignal-dashboard`. |
| `schemaVersion` | `2`. |
| `uid`, `title`, `tags` | Identity. `uid` and `title` must not be empty, and `tags` is an array. |
| `editable`, `defaultDashboard` | Booleans. |
| `timeSettings` | `timezone`, `defaultFrom`, and `defaultTo`. |
| `refreshSettings` | `mode`, `enabled`, `defaultInterval`, and `allowedIntervals`. |
| `variables`, `annotations`, `links`, `elements` | Arrays, empty for a blank dashboard. |
| `layout` | A grid: `type`, `columns`, `rowHeight`, and `gap`. |

A model without a required property answers `400` with `validation_failed` and one entry in `issues` per missing property.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/dashboards \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{
    "model": {
      "engine": "molesignal-dashboard",
      "schemaVersion": 2,
      "uid": "service-overview",
      "title": "Service overview",
      "tags": ["operations"],
      "editable": true,
      "defaultDashboard": false,
      "timeSettings": { "timezone": "browser", "defaultFrom": "now-6h", "defaultTo": "now" },
      "refreshSettings": { "mode": "interval", "enabled": true, "defaultInterval": "30s",
                           "allowedIntervals": ["off", "30s", "1m", "5m"] },
      "variables": [],
      "annotations": [],
      "links": [],
      "layout": { "type": "grid", "columns": 24, "rowHeight": 8, "gap": 8 },
      "elements": []
    },
    "folder_id": null
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7XebQcmZojtDim7ZVdGVw594",
  "org_id": "<organization-id>",
  "folder_id": null,
  "uid": "service-overview",
  "title": "Service overview",
  "tags": ["operations"],
  "model": { "engine": "molesignal-dashboard", "...": "..." },
  "version": 1
}
```
</ResponseExample>

Build panels in the editor first, and export the model from an existing dashboard with `GET /api/v1/dashboards/{id}` to use it as a template. Other routes: `GET /api/v1/dashboards`, `PUT` and `DELETE /api/v1/dashboards/{id}`.
