title: "Create a folder"
description: "Create a folder to organize dashboards."

---

```http
POST /api/v1/folders
```

Creates a dashboard folder. The call requires `dashboards.folders.manage`. Listing, editing, and deleting use `dashboards.folders.read`, `dashboards.folders.manage`, and `dashboards.folders.delete`.

**Body**

| Field | Type | Required | Notes |
|---|---|---|---|
| `name` | string | Yes | Folder name. |
| `parentId` | string or `null` | No | Id of the parent folder in the same organization. `null` creates a top-level folder. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parentId":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "orgId": "<organization-id>",
  "name": "Operations",
  "parentId": null
}
```
</ResponseExample>

`GET /api/v1/folders` lists the folders. `DELETE /api/v1/folders/{id}` answers `{"deleted": "<id>"}`, and `409` when the folder still contains dashboards or sub-folders.
