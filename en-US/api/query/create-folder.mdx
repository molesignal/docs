---
title: "Create a folder"
description: "Create a folder to organize dashboards."
---

```http
POST /api/v1/folders
```

Creates a dashboard folder. The call requires `dashboards.create`. Listing, editing, and deleting use `dashboards.read`, `dashboards.edit`, and `dashboards.delete`.

**Body**

| Field | Type | Required | Notes |
|---|---|---|---|
| `name` | string | Yes | Folder name. |
| `parent_id` | string or `null` | No | Id of the parent folder in the same organization. `null` creates a top-level folder. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_JWT" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parent_id":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "org_id": "<organization-id>",
  "name": "Operations",
  "parent_id": null
}
```
</ResponseExample>

`GET /api/v1/folders` lists the folders. `DELETE /api/v1/folders/{id}` answers `{"deleted": "<id>"}`, and `409` when the folder still contains dashboards or sub-folders.
