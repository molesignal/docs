---
title: "Revoke API token"
description: "Revoke an API token by id."
---

```http
DELETE /api/v1/auth/tokens/{id}
```

Revoke a token immediately. Subsequent requests with the revoked token return `401`. This operation requires
`api_tokens.manage`.

**Path parameters**

| Param | Type |
|---|---|
| `id` | string |
