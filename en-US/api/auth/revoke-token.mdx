---
title: "Revoke an API token"
description: "Revoke an API token by id."
"zh-Hans_link": "/zh-Hans/api/auth/revoke-token"
---

```http
DELETE /api/v1/auth/tokens/{id}
```

Revokes any token of the organization immediately. A later request with the token fails with `401` and the message `api token revoked`. The call requires `api_tokens.revoke`.

**Path parameters**

| Param | Type | Notes |
|---|---|---|
| `id` | string | The `id` that issuing or listing the token returned. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

An unknown id answers `404`. Revoking a token that sends data stops that sender, so replace the token in the sender first.

## Your own token

```http
DELETE /api/v1/me/api-tokens/{id}
```

Revokes one of your personal tokens or your default intake token. The call comes from a signed-in session and requires `personal_tokens.manage`. A token that is not yours answers `404`.
