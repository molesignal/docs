---
title: "RUM client token"
description: "Get or create the application-bound token that browser and mobile code embeds."
---

```http
GET /api/v1/auth/tokens/rum?application_id=<id>
```

Returns the RUM client token of an application and creates it on the first call. The token has the form `msrum_<prefix>_<secret>`, holds only `rum.write` for that application, and never expires. Embed it in browser or mobile code, where end users can read it. The call requires `api_tokens.manage`.

**Query parameters**

| Param | Type | Required | Notes |
|---|---|---|---|
| `application_id` | string | Yes | 1 to 128 characters from `A-Z`, `a-z`, `0-9`, `.`, `_`, `:`, and `-`. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/auth/tokens/rum?application_id=checkout-web" \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KDZpGNwn5vO9dhXyE3am4qhihX",
  "prefix": "dYrZbAh2UcL2HL7g",
  "token": "msrum_dYrZbAh2UcL2HL7g_<secret>",
  "role_id": "<rum-client-role-id>",
  "role_key": "rum_client",
  "role_name": "RUM client",
  "token_kind": "rum_client",
  "application_id": "checkout-web",
  "service_account_id": null,
  "expires_at_micros": null,
  "created_at_micros": 1790000000000000
}
```
</ResponseExample>

An invalid `application_id` answers `400`. Use the same identifier as `applicationId` in the SDK. See [Browser RUM SDK](/en-US/rum/browser-sdk#create-a-client-token).
