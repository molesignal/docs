---
title: "List API tokens"
description: "List the metadata of every API token in the organization."
---

```http
GET /api/v1/auth/tokens
```

Returns the metadata of every API token in the active organization, including default intake tokens, RUM client tokens, and tokens of service accounts. The plaintext token and the secret hash are never returned. The call requires `api_tokens.read`.

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "l2XcQd8UoQzK3pLm",
    "name": "grafana-readonly",
    "role_id": "<viewer-role-id>",
    "role_key": "viewer",
    "role_name": "Viewer",
    "token_kind": "personal",
    "application_id": null,
    "service_account_id": null,
    "expires_at_micros": 1798000000000000,
    "last_used_at_micros": null,
    "revoked": false,
    "created_at_micros": 1790000000000000
  }
]
```
</ResponseExample>

| Field | Notes |
|---|---|
| `token_kind` | `personal`, `service_account`, `default_intake`, or `rum_client`. |
| `application_id` | The bound application of a `rum_client` token, otherwise `null`. |
| `service_account_id` | The owning service account, otherwise `null`. |
| `expires_at_micros` | `null` for a token that never expires. |
| `last_used_at_micros` | `null` until the first use. |
| `revoked` | `true` after the token is revoked. |
