---
title: "List API tokens"
description: "List API token metadata (never the secret)."
---

```http
GET /api/v1/auth/tokens
```

Returns metadata for every API token in your organization. The plaintext token and secret hash are
never returned. Listing requires `api_tokens.read`.

<ResponseExample>
```json 200
[
  {
    "id": "<token-id>",
    "prefix": "a1b2c3",
    "name": "collector-production",
    "role_id": "<organization-role-id>",
    "role_key": "viewer",
    "role_name": "Viewer",
    "expires_at_micros": 1735689600000000,
    "last_used_at_micros": 1700000000000000,
    "revoked": false,
    "created_at_micros": 1690000000000000
  }
]
```
</ResponseExample>
