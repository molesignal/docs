```http
GET /api/v1/auth/tokens
```

Returns the metadata of every API Token in the active organization, including default intake tokens, RUM client tokens, and tokens of service accounts. The plaintext token and the secret hash are never returned. The call requires `api_tokens.read`.

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "k7m2q9xv4b",
    "name": "grafana-readonly",
    "tokenKind": "personal",
    "userId": "<user-id>",
    "policyId": null,
    "permissions": ["dashboards.read", "streams.query", "streams.read"],
    "applicationId": null,
    "serviceAccountId": null,
    "expiresAt": 1798000000000000,
    "lastUsedAt": null,
    "revoked": false,
    "createdAt": 1790000000000000
  }
]
```
</ResponseExample>

| Field | Notes |
|---|---|
| `tokenKind` | `personal`, `serviceAccount`, `default_intake`, or `rum_client`. |
| `userId` | Who issued the token. A personal or default intake token acts as this user. |
| `policyId` | The permission policy that the token follows, otherwise `null`. |
| `permissions` | The permissions fixed for the token, otherwise `null`. With no policy either, the token may do whatever the user or service account it acts as may. |
| `applicationId` | The bound application of a `rum_client` token, otherwise `null`. |
| `serviceAccountId` | The service account the token acts as, otherwise `null`. |
| `expiresAt` | `null` for a token that never expires. |
| `lastUsedAt` | `null` until the first use. |
| `revoked` | `true` after the token is revoked. |

## Your own tokens

```http
GET /api/v1/me/api-tokens
```

Returns your personal tokens and your default intake token, with the same fields. The call comes from a signed-in session and requires `personal_tokens.manage`.
