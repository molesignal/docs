---
title: "List API tokens"
description: "List API token metadata (never the secret)."
---

```http
GET /api/v1/auth/tokens
```

Returns metadata for every API token in your org — id, role, expiry, last-used. The secret is never
returned.

<ResponseExample>
```json 200
[
  { "id": "t_2ghi...", "prefix": "a1b2c3", "role": "data_plane_admin", "expires_at": 1735689600000000, "last_used_at": 1700000000000000 }
]
```
</ResponseExample>
