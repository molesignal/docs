---
title: "Default intake token"
description: "Get or create the default token that senders use to write telemetry."
---

```http
GET /api/v1/auth/tokens/default
```

Returns the default intake token of the signed-in user and creates it on the first call. Unlike other tokens, the plaintext is returned on every call, which lets the **Datasource** page show a ready-to-use token. The token holds only `streams.write`, never expires, and has the `token_kind` `default_intake`. The call requires `api_tokens.manage`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/auth/tokens/default \
  -H "authorization: Bearer $MS_JWT"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3JtzUbBKtQCD7mFELKp2zDRum9f",
  "prefix": "QAi4CAoAAqY5izlY",
  "token": "ms_QAi4CAoAAqY5izlY_<secret>",
  "role_id": "<intake-role-id>",
  "role_key": "intake",
  "role_name": "Intake token",
  "token_kind": "default_intake",
  "application_id": null,
  "service_account_id": null,
  "expires_at_micros": null,
  "created_at_micros": 1790000000000000
}
```
</ResponseExample>

Use the token in collectors, agents, and SDK exporters. See [Datasource](/en-US/intake#intake-tokens).
