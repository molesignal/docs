---
title: "Default intake token"
description: "Get or create the default token that senders use to write telemetry."
"zh-Hans_link": "/zh-Hans/api/auth/default-token"
---

```http
GET /api/v1/me/api-tokens/default
```

Returns the default intake token of the signed-in user and creates it on the first call. Unlike other tokens, the plaintext is returned on every call, which lets the **Datasource** page show a ready-to-use token. The token acts as you, follows the built-in **Data intake** policy, which holds `logs.write`, `metrics.write`, `traces.write`, `profiles.write`, and `apm.deploy`, never expires, and has the `token_kind` `default_intake`. The call comes from a signed-in session and requires `personal_tokens.manage` and both permissions of the policy.

<RequestExample>
```bash cURL
curl -b ms-cookies.txt http://localhost:5080/api/v1/me/api-tokens/default
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3JtzUbBKtQCD7mFELKp2zDRum9f",
  "prefix": "QAi4CAoAAqY5izlY",
  "token": "ms_QAi4CAoAAqY5izlY_<secret>",
  "token_kind": "default_intake",
  "policy_id": "builtin:data_intake",
  "permissions": null,
  "application_id": null,
  "created_at_micros": 1790000000000000
}
```
</ResponseExample>

Use the token in collectors, agents, and SDK exporters. See [Datasource](/en-US/intake#intake-tokens).
