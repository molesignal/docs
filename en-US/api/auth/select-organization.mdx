```http
POST /api/v1/orgs/{id}/select
```

Switches the signed-in browser session to another organization that the user belongs to. The response rewrites the session cookies for that organization, and the session keeps its end time. See [Log in](/en-US/api/auth/login) for the cookies. Only a session can switch: an API token receives `403`. Platform administrators can select the protected `_sys` organization, which platform-wide calls such as [Rotate JWT signing keys](/en-US/api/auth/rotate-jwt) need. A session in `_sys` ends within an hour of entering it.

**Path parameters**

| Param | Type | Notes |
|---|---|---|
| `id` | string | Organization id from `GET /api/v1/orgs`. |

<RequestExample>
```bash cURL
curl -b ms-cookies.txt -c ms-cookies.txt \
  -X POST http://localhost:5080/api/v1/orgs/<organization-id>/select
```
</RequestExample>

<ResponseExample>
```json 200
{
  "user_id": "<user-id>",
  "org_id": "<organization-id>",
  "org_name": "default",
  "display_role": "Owner",
  "roles": [
    { "id": "<role-id>", "key": "owner", "name": "Owner", "builtin": true }
  ],
  "system": false
}
```
</ResponseExample>

The tabs of a browser share its cookies, so every open tab moves to the selected organization.

## Sign-in requirements

When the organization's [sign-in requirements](/en-US/identity/sso#sign-in-requirements) ask for more than this sign-in has, the answer is still `200`, without new cookies, and says what is missing:

| Answer | Meaning |
|---|---|
| `{"mfa": {"organization_name", "methods"}}` | Verify a second factor on the spot: send the request again with `{"proof": {…}}` in the body. A proof is `method` (`totp` or `recovery_code`) with `code`, or `method` `passkey` with `ceremony` and `credential` from `POST /api/v1/me/mfa/passkey-proof`. |
| `{"mfa_setup": {"organization_name"}}` | The account has no second factor. Set one up under `/api/v1/me/mfa` or `/api/v1/me/passkeys` first. |
| `{"sso": {"organization_name", "providers"}}` | Only the organization's single sign-on enters. `providers` lists `id`, `name`, `kind`, and `platform`. |
