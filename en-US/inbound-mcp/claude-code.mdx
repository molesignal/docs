Claude Code supports stdio servers, remote Streamable HTTP servers with OAuth discovery, and local,
project, or user configuration scopes.

## Connect over stdio (recommended)

The client starts the MoleSignal CLI, which carries the messages to MoleSignal. It needs
Node.js 20 or later.

<Steps>
  <Step title="Sign in once">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

The browser opens on MoleSignal to approve the sign-in; the CLI keeps it and renews it.

  </Step>
  <Step title="Add MoleSignal">

```bash
claude mcp add --scope user molesignal -- npx -y @molesignal/cli mcp
claude mcp get molesignal
```

  </Step>
</Steps>

Where no browser is at hand, set `MOLESIGNAL_URL` and `MOLESIGNAL_TOKEN` (an API token) in the
server's environment instead of signing in. See [Connect over stdio](/en-US/inbound-mcp#connect-over-stdio).

The sections below connect over Streamable HTTP, without the CLI.

## Connect with OAuth 2.1

<Steps>
  <Step title="Add the remote server">

    ```bash
    claude mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    `--scope user` makes the server available across projects. Omit the flag for local project
    state, or use `--scope project` to write a shared `.mcp.json` entry.

  </Step>
  <Step title="Authorize MoleSignal">

    ```bash
    claude mcp login molesignal
    ```

    Alternatively, open Claude Code, run `/mcp`, select `molesignal`, and complete authentication.

  </Step>
  <Step title="Verify the server">

    ```bash
    claude mcp get molesignal
    claude mcp list
    ```

  </Step>
</Steps>

For an SSH or headless terminal, print the authorization URL and paste the final callback URL back
into Claude Code:

```bash
claude mcp login molesignal --no-browser
```

## Connect with an API token

Use environment expansion in a project `.mcp.json` instead of committing a token:

```json
{
  "mcpServers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer ${MOLESIGNAL_MCP_TOKEN}"
      }
    }
  }
}
```

Set `MOLESIGNAL_MCP_TOKEN` before starting Claude Code. Project-scoped servers require an explicit
trust decision before the first connection.

See the [official Claude Code MCP documentation](https://code.claude.com/docs/en/mcp).
