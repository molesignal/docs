OpenSource Edition is the default runtime when no verified, active Enterprise license is loaded. It
is self-hosted and does not require a MoleSignal account or hosted control plane.

## Included

- ingestion, storage, and query for logs, metrics, traces, and profiles;
- trace-derived APM, RUM investigation, correlation, and service topology;
- dashboards, streams, pipelines, reusable functions, and enrichment tables;
- alerting, incidents, notification delivery, synthetics, and status pages;
- organization isolation, IAM, service accounts, API tokens, audit events, and platform settings;
- standalone and multi-role self-hosted deployment using Docker or Kubernetes.

The exact API surface is documented under **API Reference**. Permissions still determine which
operations a user, service account, or API token can perform.

## Enterprise-gated boundaries

The open-source core remains usable without a signed license. Workflows that currently require an
Enterprise entitlement include Mole Agent, Inbound MCP, SSO, federated search, managed organization
domains, and enhanced profiling comparisons.

When the active Enterprise license is absent, invalid, or expired, the server falls back to
OpenSource behavior and exposes the license load state through system health.
