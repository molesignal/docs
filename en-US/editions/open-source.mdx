The open source edition is the complete self-hosted engine. It is licensed under the [Apache License 2.0](https://github.com/molesignal/molesignal/blob/main/LICENSE), runs on infrastructure that the operator controls, and needs no MoleSignal account or hosted control plane.

## Included

- ingestion, storage, and query for logs, metrics, traces, and profiles;
- trace-derived APM, RUM investigation, correlation, and service topology;
- dashboards, streams, pipelines, reusable functions, and enrichment tables;
- alerting, incidents, notification delivery, synthetic monitoring, and status pages;
- Mole Agent and inbound MCP access to the same tool catalog;
- organization isolation, IAM, SSO, service accounts, API tokens, audit events, and platform settings;
- a single-node deployment with Docker Compose, a binary, or Kubernetes, and a role-split deployment with separate router, intake, querier, compactor, and alert processes.

The exact API surface is documented under **API Reference**. Permissions still determine which operations a user, service account, or API token can perform.

## What a deployment needs

PostgreSQL for metadata and an S3-compatible, Azure, or Google Cloud object store for data. A single node can use the local disk as the object store for development. See [Deploy MoleSignal](/en-US/deployment).

## Start self-hosting

1. Follow the [Quickstart](/en-US/quickstart) for a local instance.
2. Choose a topology in [Deploy MoleSignal](/en-US/deployment).
3. Work through the [Production checklist](/en-US/production-checklist) before real data arrives.
4. Review [Security and multi-tenancy](/en-US/security) and [Self-observability](/en-US/self-observability).
