<Warning>
  MoleSignal Cloud is not publicly available and has no public launch date. Join the waitlist for
  availability updates; do not use this page as a production service commitment.
</Warning>

MoleSignal Cloud is the planned managed operating model for teams that do not want to run the
control plane, databases, storage lifecycle, upgrades, and platform monitoring themselves.

## Planned model

- the same MoleSignal telemetry engine, schemas, and query languages as the self-hosted editions;
- fully hosted multi-tenant service and bring-your-own-cloud options under evaluation;
- MoleSignal-operated upgrades, backups, platform monitoring, and service recovery;
- account billing and support surfaces available only to Cloud organizations;
- migration assistance from self-hosted deployments, preserving portable telemetry and query models.

Cloud features, regions, limits, pricing, compliance coverage, and migration guarantees will be
documented when they become available. Until then, use the OpenSource or Enterprise documentation
for implemented product behavior.
