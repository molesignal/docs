<Warning>
MoleSignal Cloud is on the waitlist. This page is an evaluation guide, not an activation or connection guide for a generally available service.
</Warning>

MoleSignal Cloud is the planned managed offering for teams that want to evaluate observability without operating the storage and service infrastructure themselves. Register through the [Cloud waitlist](https://www.molesignal.com/cloud). Use the [self-hosted quickstart](/en-US/quickstart) for a deployment available to evaluate now.

## Prepare for a Cloud evaluation

| Requirement | Information to collect |
|---|---|
| Telemetry | Logs, metrics, traces, profiles, expected daily volume, and peak rates. |
| Retention | Required history for each signal and the queries that must remain usable. |
| Access | Team size, organization boundaries, identity requirements, and API Token use. |
| Location | Required data region, network access, and data handling restrictions. |
| Operations | Support expectations, recovery objectives, and responsibilities during an incident. |

Confirm region availability, access methods, retention limits, commercial terms, and support commitments during evaluation. Do not assume that a self-hosted configuration option is exposed as a managed service setting.

## Validate the data path first

1. Start a self-hosted instance and choose one representative service.
2. Send telemetry using the documented [intake protocols](/en-US/intake/integrations).
3. Check event timestamps, stream selection, service identity, and permissions.
4. Run representative queries and one incident investigation. Record the volume and retention that the workflow needs.
5. Discuss the resulting requirements before a Cloud onboarding or migration plan is agreed.

A self-hosted API address or API Token does not automatically become a Cloud address or credential. Use only the endpoint and credentials supplied for the actual environment.
