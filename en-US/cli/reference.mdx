## Commands

| Command | Options | Description |
|---|---|---|
| `molesignal login` | `--url <address>`, `--with-token` | Signs in in the browser, or with an API token read from standard input. |
| `molesignal logout` | none | Forgets the saved sign-in. The address stays. |
| `molesignal status` | `--url`, `--token` | Reports the address, the server, the kind of sign-in, and the number of MCP tools. |
| `molesignal streams` | `--url`, `--token`, `--json` | Lists the log streams the user can read. |
| `molesignal logs <stream>` | see below | Prints the newest logs of a stream and, with `-f`, the new ones. |
| `molesignal mcp` | `--url`, `--token` | Serves MoleSignal's MCP tools over stdio. |
| `molesignal --help` | none | Prints the help. |
| `molesignal --version` | none | Prints the version. |

## Options of `logs`

| Option | Default | Meaning |
|---|---|---|
| `-f`, `--follow` | off | Keeps printing new logs until **Ctrl+C**. |
| `-n`, `--lines <count>` | `100` | How many of the newest logs to print first, from `1` to `5000`. |
| `--since <duration>` | `15m` | How far back to look. Units: `ms`, `s`, `m`, `h`, `d`. |
| `--where <condition>` | none | An SQL condition on the fields of the stream. |
| `--interval <duration>` | `2s` | How often a follow reads again. |
| `--json` | off | Prints each log as one line of JSON. |
| `--utc` | off | Prints times in UTC. |
| `--url`, `--token` | saved sign-in | The address and an API token for this command only. |

## Environment variables

| Variable | Meaning |
|---|---|
| `MOLESIGNAL_URL` | The address of MoleSignal, instead of `--url` or the saved one. |
| `MOLESIGNAL_TOKEN` | An API token, instead of the saved sign-in. |
| `MOLESIGNAL_CONFIG` | The file that keeps the sign-in. Default `~/.config/molesignal/config.json`. |
| `NO_COLOR` | Prints without colours. |
| `FORCE_COLOR` | Prints colours even when the output is not a terminal. |

An option wins over an environment variable, and an environment variable over the saved sign-in.

## Exit codes

| Code | Meaning |
|---|---|
| `0` | The command succeeded, or a follow was stopped. |
| `1` | The command failed. The reason is printed on standard error. |
| `2` | The command is unknown. |
