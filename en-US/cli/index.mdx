The MoleSignal CLI is the `molesignal` command, published on npm as `@molesignal/cli`. It
signs in to a MoleSignal instance and then:

- prints the newest logs of a stream and follows new ones as they arrive;
- serves MoleSignal's MCP tools over stdio, so that Claude Code, Cursor, Codex, VS Code, and
  Gemini CLI can start it as an MCP server.

Every read goes through MoleSignal's tools, so the signed-in user's permissions, the
organization's Tool Policy, and its approvals apply to the CLI as they apply to Mole Agent.

## Requirements

- Node.js 20 or later.
- A MoleSignal instance reachable from the machine, and an account in it.

## Install

```bash
npm install -g @molesignal/cli
```

Check the installation:

```bash
molesignal --version
```

Each command also runs without installing:

```bash
npx -y @molesignal/cli --help
```

## Get started

<Steps>
  <Step title="Sign in">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    The browser opens on the MoleSignal authorization page. Click **Authorize** there. See
    [Sign in](/en-US/cli/sign-in).
  </Step>
  <Step title="Check the connection">
    ```bash
    molesignal status
    ```
  </Step>
  <Step title="Read logs">
    ```bash
    molesignal logs app_logs -f
    ```

    See [Read and follow logs](/en-US/cli/logs).
  </Step>
</Steps>

## Commands

| Command | Description |
|---|---|
| `molesignal login` | Signs in, in the browser or with an API token. |
| `molesignal logout` | Forgets the saved sign-in. |
| `molesignal status` | Reports the address, the server, the kind of sign-in, and the number of MCP tools. |
| `molesignal streams` | Lists the log streams the user can read. |
| `molesignal logs <stream>` | Prints the newest logs of a stream; `-f` follows new ones. |
| `molesignal mcp` | Serves MoleSignal's MCP tools over stdio for an agent tool. |

The options of every command are in the [command reference](/en-US/cli/reference).
