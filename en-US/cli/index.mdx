The MoleSignal CLI is the `molesignal` command, published on npm as `@molesignal/cli`. It
signs in to a MoleSignal instance and then:

- reads and follows logs, runs SQL and PromQL, draws traces as waterfalls, and sums up APM
  services;
- lists incidents and who is on call, acknowledges and resolves incidents, runs synthetic checks,
  and carries out approved changes;
- reports deployments, uploads RUM source maps and symbols, and sends the output of scripts to a
  stream, in CI;
- calls any tool of MoleSignal's catalogue;
- serves MoleSignal's MCP tools over stdio, so that Claude Code, Cursor, Codex, VS Code, and
  Gemini CLI can start it as an MCP server.

Reads and changes go through MoleSignal's tools, so the signed-in user's permissions, the
organization's Tool Policy, and its approvals apply to the CLI as they apply to Mole Agent.
Reporting deployments, uploading debug artifacts, and sending logs go to MoleSignal's API and
take an API token.

## Requirements

- Node.js 20 or later.
- A MoleSignal instance reachable from the machine, and an account in it.

## Install

```bash
npm install -g @molesignal/cli
```

Check the installation:

```bash
molesignal --version
```

Each command also runs without installing:

```bash
npx -y @molesignal/cli --help
```

## Get started

<Steps>
  <Step title="Sign in">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    The browser opens on the MoleSignal authorization page. Click **Authorize** there. See
    [Sign in](/en-US/cli/sign-in).
  </Step>
  <Step title="Check the setup">
    ```bash
    molesignal doctor
    ```
  </Step>
  <Step title="Read logs">
    ```bash
    molesignal logs app_logs -f
    ```

    See [Read and follow logs](/en-US/cli/logs).
  </Step>
</Steps>

## Commands

| Group | Commands |
|---|---|
| Sign-in | `login`, `logout`, `profiles`, `use`, `status`, `whoami`, `doctor`. See [Sign in](/en-US/cli/sign-in). |
| Logs and queries | `streams`, `logs`, `query`, `fields`. See [Read and follow logs](/en-US/cli/logs). |
| Metrics, traces, and services | `metrics`, `traces`, `services`, `search-jobs`. See [Metrics, traces, and services](/en-US/cli/observe). |
| On-call and changes | `incidents`, `oncall`, `approvals`, `annotate`, `synthetics`. See [Incidents and changes](/en-US/cli/changes). |
| Releases and data | `deploy`, `source-maps`, `symbols`, `send`, `run`. See [CI and releases](/en-US/cli/ci). |
| Tools and setup | `tools`, `call`, `mcp`, `open`, `completion`. See [Call any tool](/en-US/cli/tools) and [Serve MCP over stdio](/en-US/cli/mcp). |

`molesignal <command> --help` describes a command and its options. Every option is also in the
[command reference](/en-US/cli/reference).
