Open **Settings → General**. Reading the page requires `org.settings.read`, and changing it requires
`org.settings.manage`. Every section saves by itself a moment after a change. **Undo** reverts the
last change, and **Retry** sends a change that failed again.

## Organization information

| Field | Rule |
|---|---|
| **Organization name** | Shown in the workspace switcher, page titles, and invitations. Required. |
| **Organization slug** | Read only. APIs and resource identifiers use it. **Copy** copies it. |
| **Organization ID** | Read only. APIs, audit records, and support use it. **Copy** copies it. |

The slug and the ID never change after the organization is created.

## Preference defaults

**Organization preference defaults** apply to a member who has not saved personal preferences.
Personal [preferences](/en-US/account#preferences) and a time display changed on a query page take
precedence.

| Section | Fields |
|---|---|
| Appearance | **Default theme**, **Interface density**. |
| Language & region | **Language**, **Default timezone**, **Date & time format**. |
| Startup & interaction | **Open after entering workspace**, **Enable keyboard shortcuts**. |

## Registration and access

| Setting | Effect |
|---|---|
| **Allow self-service joining** | People who meet the sign-up requirements of the instance can join this workspace by themselves. |
| **Require admin approval** | A person who joins waits under [Approvals](/en-US/identity/members#approvals) until an administrator approves. Shown when self-service joining is on. |
| **Default organization role** | The role that self-service joining gives, from the IAM catalog. Single sign-on uses it when no role mapping matches and the provider has no default role. |

## Sharing and public access

These settings limit the [restricted public links](/en-US/resource-sharing) that members may
create. Sharing within the workspace and with other organizations always requires sign-in.

| Setting | Effect |
|---|---|
| **Allow public links** | Members may create restricted links that open allowed resources without an account. The settings below need it on. |
| **Allow public live dashboards** | Allows public links to live dashboards. The public view is read only and restricts queries, variables, time ranges, and navigation. |
| **Maximum public-link lifetime** | **1 day**, **7 days**, or **30 days**. Creators cannot choose a later expiry. |
| **Require a password for public reports** | A public report opens a short share session only after its password is verified. |
| **Block public sharing for production resources** | Refuses public links to resources tagged `production` or `prod`. |
| **Allow public CSV downloads** | When off, a public CSV report can only be previewed in the restricted page. |

## Organization lifecycle

An organization is not deleted from inside itself. **Open organization management** switches to the
`_sys` organization, where an Owner or a platform administrator deletes it. See
[Organization management](/en-US/settings/platform#organization-management).
