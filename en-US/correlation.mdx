Cross-signal correlation follows one problem across signals: from a slow page to its backend trace,
from the trace to its logs, from a metric spike to the requests behind it. Each jump keeps the time
window and carries identifiers such as `trace_id`, the service, or the host, so nothing is copied by
hand. The jumps rely on stable fields; keep `service.name`, `deployment.environment`, `trace_id`, and
`host.name` intact during intake.

## Where the jumps are

| From | Action | Leads to |
|---|---|---|
| A log event | The **Trace** view of the event, when it carries a trace ID. | The waterfall of the trace, with the span of the event selected. See [Logs](/en-US/logs#read-the-results). |
| A trace | **Related logs**, **Service metrics**, and **Profiles** in the head of the trace. | The logs with the `trace_id`, the metrics of the services, and the profiles of the time range. See [Traces](/en-US/traces#inspect-a-trace). |
| A span | The **Logs**, **Metrics**, and **Profile** tabs of the span. | The lines and figures of that span. |
| A trace with a browser session | **User session** in the head of the trace. | The RUM session that made the request. |
| A RUM session | **Related traces**. | The backend traces of the requests of the session. See [RUM explorer](/en-US/rum/explorer). |
| A metric point | An exemplar diamond, then **Open trace**. | The trace behind the point. See [Metrics](/en-US/metrics#read-the-chart). |
| An APM service | The links of the service page. | Its traces, logs, and RUM sessions. See [APM](/en-US/apm). |
| An incident | **Open triggering query**, **Related logs**, **Related metrics**, and **Open in RUM**. | The query that fired, and the context around the incident. See [Incidents](/en-US/alerting/incidents#incident-details). |
| A profile | The correlated trace of a profile. | The trace that ran while the profile was taken. See [Profiles](/en-US/profiles). |

## The investigation context bar

While an investigation is going on, a bar under the top bar shows it: the number of frames in the
stack, the locked time window, the key signals such as the trace ID, and the filters that ride along
from page to page.

| Control | Effect |
|---|---|
| **Resume investigation** | Returns to the investigation stack. |
| **Back to trace details** | Returns to the trace the page was opened from. |
| Remove filter | Drops one filter that rides along. |
| **Clear** | Ends the investigation and clears the bar. |

## The investigation stack in the UI

The investigation stack keeps the trail of a drill: each jump pushes a frame, and `⌘[` and `⌘]` move
back and forward through it. The stack holds up to 6 frames; past that, the oldest unpinned frame is
dropped, and a pinned frame stays. `⌘⌥T` and `⌘⌥L` start a stack from a trace or a log search, and the
[command palette](/en-US/console#search-with-the-command-palette) opens a result in a new stack or on
top of the current one.

`⌘⌥Y` copies the address of the current page, with its time window and filters. Opening a copied link
still requires the permissions of every resource in it.

## Correlation API

The UI computes each jump with one call, and scripts can do the same:

```http
GET /api/v1/web/correlation/{from_kind}/{to_kind}?ctx=<base64url-json>
Authorization: Bearer <token>
```

Given the context of a starting signal and a target signal, the endpoint returns the filters, the time
range, and a query prefill for the target page. It reads no telemetry, except for one lookup of a
neighboring service in the service graph. See [Cross-signal correlation](/en-US/api/web/correlation)
for the supported jumps.

| Endpoint | Purpose |
|---|---|
| `GET /api/v1/web/correlation/{from_kind}/{to_kind}` | Filters, time range, and query prefill for a jump between signals. |
| `GET /api/v1/web/trace/{trace_id}` | The full trace with all spans. |
| `GET /api/v1/web/topology` | The service topology. |
| `GET /api/v1/traces/service_graph` | The service graph with RED metrics from traces. |
| `POST /api/v1/web/investigation/blob` | Stores an investigation state as a blob that expires after 7 days. |
