クロスシグナル相関は、1つの問題を複数のシグナルにわたって追跡します。遅いページからそのバックエンドのトレースへ、トレースからそのログへ、メトリクスのスパイクからその背後にあるリクエストへとたどります。各ジャンプは時間枠を維持し、 `trace_id`、サービス、ホストなどの識別子を引き継ぐため、手作業でコピーする必要はありません。ジャンプは安定したフィールドに依存するため、取り込み時に `service.name`、`deployment.environment`、`trace_id`、および `host.name` をそのまま維持してください。

## ジャンプできる場所

| 起点 | 操作 | 移動先 |
|---|---|---|
| ログイベント | イベントがトレースIDを持つ場合の、そのイベントの**トレース**ビュー。 | トレースのウォーターフォール。イベントのスパンが選択された状態で表示されます。[ログ](/ja/logs#結果を確認)を参照してください。 |
| トレース | トレースのヘッダーにある**関連ログ**、**サービスメトリクス**、**プロファイル**。 | `trace_id` を持つログ、各サービスのメトリクス、その時間範囲のプロファイル。[トレース](/ja/traces#トレースを調査する)を参照してください。 |
| スパン | スパンの**ログ**、**メトリクス**、**プロファイル**タブ。 | そのスパンのログ行と数値。 |
| ブラウザセッションを持つトレース | トレースのヘッダーにある**ユーザーセッション**。 | リクエストを発行したRUMセッション。 |
| RUMセッション | **関連トレース**。 | セッション内のリクエストのバックエンドトレース。[RUMエクスプローラー](/ja/rum/explorer)を参照してください。 |
| メトリクスのデータポイント | エグザンプラのひし形、続いて**トレースを開く**。 | そのデータポイントの背後にあるトレース。[メトリクス](/ja/metrics#グラフを読み取る)を参照してください。 |
| APMサービス | サービスページのリンク。 | そのトレース、ログ、RUMセッション。[APM](/ja/apm)を参照してください。 |
| インシデント | **トリガークエリを開く**、**関連ログ**、**関連メトリクス**、**RUMで開く**。 | 発火したクエリと、インシデント周辺のコンテキスト。[インシデント](/ja/alerting/incidents#インシデントの詳細)を参照してください。 |
| プロファイル | プロファイルの相関トレース。 | プロファイルの取得中に実行されていたトレース。[プロファイル](/ja/profiles)を参照してください。 |
| APMインスタンス | **インスタンス**テーブルの**ワークロード / ホスト**セル。 | 実行されているPodまたはホストと、そこにある他のサービス。[インフラストラクチャ](/ja/infrastructure)を参照してください。 |
| Pod、ノード、ホスト | **ログ**、**メトリクス**、およびその上で動作するサービス。 | 直近1時間のログとメトリクス、および各サービスのAPMページ。 |

## ジャンプしても何も見つからない場合

ジャンプしても何も見つからない場合は、データが存在しないのではなく、データを関連付けられないことを意味している可能性があります。トレースIDを持たないログ、ログ内で名前が異なるサービス、サービスの実行場所を示さないスパンなどが該当します。 [APMカタログ](/ja/apm)の**相関**列と[収集品質](/ja/apm/settings#収集品質)は、各サービスがログ、メトリクス、トレース、変更とどれだけ関連付けられているかを示します。

## 調査コンテキストバー

調査の実行中は、トップバーの下にバーが表示されます。そこには、スタック内のフレーム数、ロックされた時間枠、トレースIDなどの主要なシグナル、ページからページへ引き継がれるフィルターが表示されます。

| コントロール | 効果 |
|---|---|
| **調査を再開** | 調査スタックに戻ります。 |
| **トレースの詳細に戻る** | このページを開いた元のトレースに戻ります。 |
| フィルターを削除 | 引き継がれているフィルターを1つ解除します。 |
| **クリア** | 調査を終了し、バーをクリアします。 |

## UIの調査スタック

調査スタックはドリルの足跡を保持します。各ジャンプでフレームがプッシュされ、`⌘[` と `⌘]` でスタック内を前後に移動できます。スタックは最大6フレームまで保持され、それを超えると最も古いピン留めされていないフレームが破棄されます。ピン留めされたフレームは残ります。`⌘⌥T` と `⌘⌥L` はトレースまたはログ検索からスタックを開始し、 [コマンドパレット](/ja/console#コマンドパレットで検索する)は結果を新しいスタックで、または現在のスタックの上に開きます。

`⌘⌥Y` は現在のページのアドレスを、その時間枠とフィルターとともにコピーします。コピーしたリンクを開くには、そのリンクに含まれるすべてのリソースの権限が引き続き必要です。

## 相関API

各ページは、すでに保持している識別子から各ジャンプを構築します。これらのエンドポイントは、ジャンプ先のビューを提供します。

| エンドポイント | 用途 |
|---|---|
| `GET /api/v1/web/trace/{trace_id}` | すべてのスパンを含む完全なトレース。 |
| `GET /api/v1/web/topology` | サービストポロジ。 |
| `GET /api/v1/traces/service_graph` | トレースから得られるREDメトリクスを含むサービスグラフ。 |
| `GET /api/v1/entities/detail` | Pod、ノード、ホスト、コンテナで実行されているものと、それが実行されている基盤。[インフラストラクチャ](/ja/infrastructure)を参照してください。 |
| `POST /api/v1/web/investigation/blob` | 調査状態を、7日後に期限切れとなるBLOBとして保存します。 |
