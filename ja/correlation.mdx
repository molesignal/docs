シグナル間の相関によって、同じ問題を複数のシグナルにわたって追跡できます。表示が遅いページからバックエンドのトレースへ、トレースから関連ログへ、メトリクスの急上昇からその原因となったリクエストへ移動できます。移動時には時間範囲を維持し、 `trace_id` やサービス、ホストなどの識別情報を引き継ぐため、手動でコピーする必要はありません。移動には値が変わらないフィールドを使います。取り込み時に `service.name`、`deployment.environment`、`trace_id`、 `host.name` を変更しないでください。

## シグナル間の移動方法

| 移動元 | 操作 | 移動先 |
|---|---|---|
| ログイベント | トレース ID を含むイベントの **トレース** ビューを開きます。 | トレースのウォーターフォールが表示され、イベントに対応するスパンが選択されます。[ログ](/ja/logs#結果を確認する)を参照してください。 |
| トレース | トレースの上部にある **関連ログ**、**サービスメトリクス**、**プロファイル**を選択します。 | 同じ `trace_id` を持つログ、各サービスのメトリクス、対象の時間範囲のプロファイルが表示されます。[トレース](/ja/traces#トレースの詳細を確認する)を参照してください。 |
| スパン | スパンの **ログ**、**メトリクス**、**プロフィール**タブを選択します。 | スパンに対応するログ行や数値が表示されます。 |
| ブラウザーセッションに関連するトレース | トレースの上部にある **ユーザーセッション**を選択します。 | リクエストを送信した RUM セッションが開きます。 |
| RUM セッション | **関連トレース**を選択します。 | セッション内のリクエストに対応するバックエンドのトレースが表示されます。[RUM エクスプローラー](/ja/rum/explorer)を参照してください。 |
| メトリクスのデータポイント | ひし形のエグザンプラーを選択し、**トレースを開く**を選択します。 | データポイントに対応するトレースが開きます。[メトリクス](/ja/metrics#グラフを読み取る)を参照してください。 |
| APM サービス | サービスページのリンクを選択します。 | サービスのトレース、ログ、RUM セッションが表示されます。[APM](/ja/apm)を参照してください。 |
| インシデント | **トリガークエリを開く**、**関連ログ**、**関連メトリクス**、**RUMで開く**を選択します。 | インシデントをトリガーしたクエリや、インシデント発生前後の状況を確認できます。[インシデント](/ja/alerting/incidents#インシデントの詳細)を参照してください。 |
| プロファイル | プロファイルに関連付けられたトレースを開きます。 | プロファイルの取得中に実行された処理のトレースが表示されます。[プロファイル](/ja/profiles)を参照してください。 |

## 調査コンテキストバー

調査中は、トップバーの下にあるバーに調査の状態が表示されます。スタック内のフレーム数、固定された時間範囲、トレース ID などの主要なシグナル、ページ間で引き継ぐフィルターを確認できます。

| コントロール | 動作 |
|---|---|
| **調査を再開** | 調査スタックに戻ります。 |
| **トレースの詳細に戻る** | 現在のページを開く前に表示していたトレースに戻ります。 |
| フィルターを削除 | 引き継いだフィルターを 1 つ削除します。 |
| **クリア** | 調査を終了し、バーの内容をクリアします。 |

## UI の調査スタック

調査スタックには、調査でたどった経路が記録されます。移動するたびにフレームが追加され、`⌘[` と `⌘]` で前後のフレームに移動できます。スタックには最大 6 個のフレームを保持できます。上限を超えると、ピン留めしていない最も古いフレームが削除されます。ピン留めしたフレームは残ります。`⌘⌥T` と `⌘⌥L` で、トレースまたはログ検索からスタックを開始できます。 [コマンドパレット](/ja/console#コマンドパレットで検索する)では、検索結果を新しいスタックで開くか、現在のスタックの先頭に追加して開くことができます。

`⌘⌥Y` で、時間範囲とフィルターを含む現在のページの URL をコピーできます。コピーしたリンクを開くには、リンク先で参照するすべてのリソースへのアクセス権限が必要です。

## 相関 API

UI は移動先の条件を 1 回の API 呼び出しで取得します。スクリプトでも同じ操作ができます。

```http
GET /api/v1/web/correlation/{from_kind}/{to_kind}?ctx=<base64url-json>
Authorization: Bearer <token>
```

移動元のシグナルのコンテキストと移動先のシグナルを指定すると、エンドポイントは移動先ページのフィルター、時間範囲、クエリの初期値を返します。サービスグラフで隣接するサービスを 1 回参照する以外は、テレメトリを読み取りません。対応する移動元と移動先の組み合わせについては、 [シグナル間の相関](/ja/api/web/correlation)を参照してください。

| エンドポイント | 用途 |
|---|---|
| `GET /api/v1/web/correlation/{from_kind}/{to_kind}` | シグナル間の移動に使うフィルター、時間範囲、クエリの初期値を返します。 |
| `GET /api/v1/web/trace/{trace_id}` | すべてのスパンを含む完全なトレースを返します。 |
| `GET /api/v1/web/topology` | サービストポロジーを返します。 |
| `GET /api/v1/traces/service_graph` | トレースから得られた RED メトリクスを含むサービスグラフを返します。 |
| `POST /api/v1/web/investigation/blob` | 調査の状態を 7 日後に有効期限が切れる BLOB として保存します。 |
