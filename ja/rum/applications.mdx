アプリケーションは、RUM イベントを送信するウェブサイトやアプリです。SDK がデータを送信する前に作成してください。クライアントトークンは 1 つのアプリケーションに紐づきます。MoleSignal は、存在しないアプリケーション宛てのイベントを拒否します。

**RUM → アプリケーション**を開くと、ワークスペースのアプリケーション一覧が表示されます。アプリケーションにはクライアントトークンが付属するため、アプリケーションの作成、変更、削除には `rum.applications.manage` が必要です。一覧の表示には `rum.applications.read` が必要です。

## アプリケーションを作成する

<Steps>
  <Step title="フォームを開く">
    **アプリケーションを作成**をクリックします。ワークスペースにアプリケーションがない場合は、エクスプローラーにも同じボタンが表示されます。
  </Step>
  <Step title="アプリケーションに名前を付ける">
    `Checkout web` など、他のアプリケーションが使用していない 128 文字以内の**名前**を入力し、**プラットフォーム**を選択します。選択肢は、ブラウザー、Android、iOS、Flutter、React Native、その他です。プラットフォームの設定は、アプリケーションに表示するセットアップスニペットの選択にのみ使用します。実際の送信元は、イベントの `source` が示します。
  </Step>
  <Step title="識別子を決める">
    **識別子**は、SDK の `applicationId` に設定する値です。空欄にすると、名前から自動生成します（`checkout-web`）。手入力する場合は、`A-Z`、`a-z`、`0-9`、 `.`、`_`、`:`、`-` のみを使って 64 文字以内で指定します。アプリケーションを作成した後は、識別子を変更できません。
  </Step>
  <Step title="作成をクリックする">
    アプリケーションが開き、クライアントトークンが表示されます。
  </Step>
</Steps>

ワークスペースに RUM の 7 つのストリームがまだない場合は、アプリケーションの作成時にあわせて作成します。

## クライアントトークン

アプリケーションを開いて**クライアントトークン**を確認します。トークンの形式は `mspat-<36>` で、有効期限はありません。このアプリケーションに対する `rum.write` 権限のみを持ち、マスクした状態で表示します。**トークンを表示**または**トークンをコピー**を選択します。

<Warning>
  トークンはブラウザーやモバイルのコードに含まれるため、ユーザーが読み取れます。クライアントコードにはこのトークンのみを使用し、オーナー、管理者、個人のトークンは使用しないでください。アプリケーションを削除すると、トークンは失効します。
</Warning>

同じトークンは [API](/ja/api/auth/rum-token) からも取得できます。アプリケーションで**セットアップガイドを開く**を選択すると、そのアプリケーションを選択した状態で、プラットフォームに対応する**データソース**ガイドが開きます。ガイドでは、エンドポイント、トークン、識別子を設定済みの SDK スニペット、データの到着を確認する方法を確認できます。React Native と「その他」にはガイドがないため、トークンを使って[イベント](/ja/rum/events)を直接送信してください。

## データ収集

アプリケーションの設定で、各イベントとともに保存する情報を指定します。アプリケーションで設定を変更し、**保存**をクリックします。

| 設定 | デフォルト | 動作 |
|---|---|---|
| **IP アドレスを保存** | オン | サーバーが特定したクライアント IP アドレスを `network.client.ip` として保存します。プロキシの背後で使用する場合は、先に[クライアント IP アドレスの識別](/ja/rum#プロキシ経由のクライアント-ip)を設定してください。 |
| **位置情報を保持** | オン | IP アドレスから特定した国、地域、市区町村を保存します。IP アドレスを保存しない場合も位置情報を特定し、その結果だけを保存します。 |
| **デフォルトのプライバシー設定** | テキストと入力内容をマスク | セットアップスニペットがセッションリプレイ用に提示するプライバシーレベルです。**テキストと入力内容をマスク**、**ユーザーの入力内容をマスク**、**表示内容をすべて記録**から選択します。 |

変更は、変更後に受信したイベントに適用します。保存済みのデータは変わりません。

## SDK のリモート設定

`remoteConfiguration: true` を指定した SDK は、起動時に以下の設定を読み込みます。ページを再リリースする必要はありません。 **ページ側の設定に従う**のままにした項目には、ページが `init` に渡した値を使用します。

| 設定 | SDK オプション |
|---|---|
| **セッションのサンプリング率 (%)** | `sessionSampleRate` |
| **セッションリプレイのサンプリング率 (%)** | `sessionReplaySampleRate` |
| **プライバシーレベル** | `defaultPrivacyLevel` |
| **クリックの収集** | `trackUserInteractions` |
| **コンソール出力の転送** | `forwardConsoleLogs` |

SDK はクライアントトークンを使って `GET /api/v1/rum/config` から設定を読み込み、応答を最大 1.5 秒待ちます。応答がなければ、ページから渡された設定で起動します。

## セグメント

**セグメント**では、[分析ページ](/ja/rum/analytics#セグメント)で絞り込みに使うセッションのグループを、名前を付けて最大 20 個定義できます。各セグメントには最大 5 つの条件を設定でき、セッションはすべての条件を満たす必要があります。条件の対象には、国、大陸、市区町村、ブラウザー、OS、デバイスの種類、ユーザー ID、メールアドレス、アカウント ID、サービス、バージョン、プラットフォーム、またはアプリケーションが `setUser` で設定したユーザー属性（`usr.extra.plan`）を指定できます。指定した値のいずれかに一致するか、どの値にも一致しないかを判定します。変更は、保存済みのセッションを含め、データの参照時に即座に反映します。ユーザー属性は、この機能のデプロイ後に開始したセッションに含まれます。

## 機密データとセッションの保持

**機密データ**では、イベントを保存する前にサーバーが除去するテキストの種類ごとに、オンとオフを切り替えられます。対象はトークン、キー、パスワード、メールアドレス、電話番号、決済カード番号、個人識別番号、機密性の高い URL パラメーターの値です。デフォルトではすべてオンです。各設定で除去する内容については、[RUM のプライバシー](/ja/rum/privacy#受信時に機密テキストを除去する)を参照してください。

**セッションの保持**では、アプリケーションが保存するセッションを指定します。**セッションの保持率（%）**には `0` から `100` までの整数を指定し、アプリケーションが受信したセッションをその割合で保持します。保持または破棄は、リプレイを含めてセッション単位で行います。 **フィルターを追加**を使うと、環境、バージョン、国、ブラウザーなどの条件に一致するセッションに個別の保持率を設定できます。複数のフィルターに一致する場合は、最初に一致したフィルターを適用し、どのフィルターにも一致しない場合は**その他のセッションの保持率 (%)**を適用します。**すべてのエラーを保持**をオンにすると、保持しないセッションのエラーも保存します。合計を表示するページでは、保持したセッションから全セッション分の合計を推計し、**推定値**と表示します。[RUM データのサンプリング](/ja/rum/sampling#セッションの一部をサーバー側で保持する)を参照してください。

## イシュー

**イシュー**セクションでは、アプリケーションが 1 時間あたりに作成できる新規[イシュー](/ja/rum/errors#1-時間あたりの新規イシュー数の上限)の上限を設定します。

| 設定 | デフォルト | 動作 |
|---|---|---|
| **1 時間あたりの新規イシュー数の上限** | 100 | 1 から 10,000 まで指定できます。上限に達すると、その時間帯が終わるまで、まだどのイシューにも属していないエラーを**その他のエラー**という 1 つのイシューにまとめて集計します。変更は 30 秒以内に反映します。 |

## アプリケーションを削除する

**アプリケーションを削除**をクリックし、削除を確定します。クライアントトークンは即座に失効し、そのトークンを使用する SDK からのリクエストは拒否されます。アプリケーションが送信済みのイベントは、保持期間が終了するまでストリームに残り、エクスプローラーで引き続き検索できます。
