SDK にフラグの評価結果を渡すと、そのビューのすべてのイベントに評価結果が含まれます。

```ts
molesignalRum.addFeatureFlagEvaluation('checkout_v2', 'treatment');
```

フラグサービスと連携するには、評価結果を SDK に渡します。LaunchDarkly ではインスペクターを、OpenFeature ではフックを使用します。

```ts
LDClient.initialize(id, user, {
  inspectors: [{
    type: 'flag-used',
    name: 'molesignal',
    method: (key, detail) => molesignalRum.addFeatureFlagEvaluation(key, detail.value),
  }],
});

OpenFeature.addHooks({
  after: (context, details) => molesignalRum.addFeatureFlagEvaluation(context.flagKey, details.value),
});
```

## 機能フラグタブ

**機能フラグ**には、指定した期間内にセッションで評価されたフラグが、評価したセッション数の多い順に表示されます。フラグを選択すると、値ごとにセッション数、エラーが発生したビューの割合、ユーザーのフラストレーションの兆候があったビューの割合を並べて比較できます。ブラウザーアプリケーションでは、LCP、INP、CLS の 75 パーセンタイルも比較できます。エラーが発生したビューの数が最も多い値は赤で表示されます。**該当するビューを表示**を選択すると、該当するビューがエクスプローラーで開きます。

## フラグをフィールドとして参照する

[エクスプローラー](/ja/rum/explorer)と API でフィールドを指定できる箇所では、フラグを列と同じように `feature_flags.<key>` で参照できます。

```text
feature_flags.checkout_v2 = 'treatment' AND error.type = 'TypeError'
```

```http
POST /api/v1/rum/aggregate
{ "type": "views", "measures": [{ "fn": "p75", "field": "view.performance.lcp.timestamp" }], "groupBy": ["feature_flags.checkout_v2"] }
```

JSON 列の他のキー（`context.<key>`、`usr.extra.<key>`、`view.custom_timings.<key>`）も同様に参照できます。`GET /api/v1/rum/keys` で使用可能なキーを一覧表示できます。

SQL では、`json_text("feature_flags", 'checkout_v2')` を使ってキーの値をテキストとして取得します。行にそのキーがない場合は NULL を返します。`json_keys("feature_flags")` は、行に含まれるキーを一覧表示します。

## Mole Agent

`get_rum_feature_flags` ツールはフラグを一覧表示します。`flag` を指定すると、機能フラグタブと同じ指標でフラグの値を比較します。
