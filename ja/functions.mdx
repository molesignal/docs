関数は、再利用可能なイベント変換をまとめたものです。**関数**を開くと、パイプラインとは独立して関数の定義を作成、テスト、管理できます。

## 関数を探す

一覧には、組織の関数と組み込みプリセットが表示されます。一覧の上部にある3つのビューで表示を絞り込めます。各ビューには件数が表示されます。

| ビュー | 内容 |
|---|---|
| **すべて** | 組織のすべての関数とプリセットです。 |
| **自分の関数** | 組織が作成した関数です。 |
| **プリセット** | MoleSignalに付属する読み取り専用の関数です。 |

検索は、関数名とプリセットの説明を対象にします。組織の関数をクリックすると、ワークベンチで開きます。

## 言語

| 言語 | 利用条件 | 主な用途 |
|---|---|---|
| VRL | 組み込み | パース、正規化、フィルタリング、マスキング、エンリッチメント。 |
| JavaScript | 組み込み | JavaScriptで記述しやすいロジック。 |
| LLM | APIで設定可能。`llm_eval_enabled`とモデルプロバイダーが必要 | モデル出力を使った低スループットの分類やエンリッチメント。 |

VRLとJavaScriptは、どちらもMoleSignalのバイナリ内で実行されます。設定や追加のインストールは不要です。

MoleSignalは、保存時に関数を検証してコンパイルします。無効なソースは有効な関数として反映されません。

関数のワークベンチでは、VRLとJavaScriptを使用できます。LLM関数は高度なAPI ワークフローです。関数のソースをシステム指示、イベントをモデルへの入力として使用し、 `params_schema.output_field`で出力フィールドを指定します（デフォルトは`_llm_eval`）。実行のたびにモデルを呼び出すため、設定`[functions].llm_eval_enabled`はデフォルトで`false`です。 [設定](/ja/configuration#機能とインテグレーション)を参照してください。モデルでアラートイベントを要約するには、[アラートパイプライン](/ja/pipelines/alert-events#aiによる要約)の**AIによる要約**ステップを使用してください。このステップは、この設定に依存しません。

## 組み込みプリセット

すべての組織で、次の読み取り専用のVRL関数が表示されます。

| 関数 | 処理内容 |
|---|---|
| `add-intake-time` | エンドツーエンドのレイテンシを調査できるように、受信時刻のタイムスタンプを追加します。 |
| `normalize-logs` | JSONメッセージをパースし、環境とクラスターのフィールドを追加して、`level`を小文字に正規化します。 |
| `parse-key-value` | logfmtまたは`key=value`形式のメッセージをパースしてフィールドに分解し、元のイベントにマージします。 |
| `redact-email` | `message`内のメールアドレスをプレースホルダーに置き換えます。 |
| `route-by-service` | サービス名を正規化し、ルーティングのヒントとしてサービスごとの送信先ストリーム（`logs_<service>`）を生成します。 |

プリセットの行には、**組み込み**タグと説明が、ログイン時に使用しているインターフェース言語で表示されます。ソースを確認するには、行をクリックしてください。

プリセットは編集できません。変更するには、行またはプリセットパネルで**これを元に作成**を選択してください。ワークベンチに、プリセットの言語とソースを引き継いだ新しい関数が `<preset>-copy`という名前で開きます。保存すると組織の関数が作成され、元のプリセットは変更されません。

## 関数を作成してテストする

ワークベンチは次の3つの部分で構成されます。

- 関数の名前と言語。
- **ソース**：ソースを編集するエディターです。タイトルの横にソースの検証ステータスが表示されます。
- **テスト実行**：JSON形式の**サンプル入力**と**サンプル出力**が表示されます。

**サンプルを実行**を選択すると、エディター内のソースをサンプルイベントに対して実行します。ソースを事前に保存する必要はありません。変換したイベントは**サンプル出力**に表示されます。実行に失敗すると、代わりに失敗の理由が表示されます。

ページのタイトル行には**関数を保存**と**キャンセル**が表示され、保存済みの関数には**関数の削除**も表示されます。名前またはソースが空の場合、**関数を保存**は使用できず、ツールチップに不足している項目が表示されます。エディターでは、`⌘ Enter`または`Ctrl+Enter`でサンプルを実行し、`⌘S`または`Ctrl+S`で保存します。

サンプル実行時は、言語、ソース、サンプルイベントを指定して`POST /api/v1/functions/run`を呼び出し、変換したイベントを返します。

```bash
curl -X POST http://localhost:5080/api/v1/functions/run \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"language":"vrl","source":".service = downcase!(string!(.service))","input":{"service":"Checkout"}}'
```

```json
{ "output": { "service": "checkout" } }
```

VRLの例：

```vrl
.service = downcase!(string!(.service))
.severity = upcase(string(.level) ?? "INFO")
if exists(.customer_id) {
  .customer = lookup("customers", .customer_id)
}
```

## テーブルとIPアドレスを検索する

MoleSignalが保持するデータを読み取るVRL関数が2つあります。サンプル実行のほか、アラートパイプラインを含むすべてのパイプラインのVRLステップで使用できます。

| 関数 | 戻り値 |
|---|---|
| `lookup("<table>", key)` | [拡張テーブル](/ja/extend-tables)`<table>`でキーが`key`の行をオブジェクトとして返します。該当する行がなければ`null`を返します。 |
| `geoip_lookup(ip)` | IPv4またはIPv6アドレスの地理情報をオブジェクトとして返します。情報がなければ`null`を返します。 |

```vrl
# the team that owns the host, from the extend table host_owner
.team = lookup("host_owner", .host).team

# where the client is
place = geoip_lookup(.client_ip)
if is_object(place) {
  .country = place.country
  .city = place.city
}
```

- どちらの関数もエラーを返しません。テーブルや行が存在しない場合、キーが文字列、数値、真偽値のいずれでもない場合、またはアドレスをパースできないかデータベースにない場合は、`null`を返します。 `null`に対して`.team`などのパスを参照した場合も、結果は`null`になります。
- `lookup`のテーブル名は文字列リテラルで指定してください。フィールドや変数から取得した名前を指定すると、コンパイルできません。数値や真偽値のキーは文字列に変換して検索します。たとえば、`42`を指定すると、キーが`42`の行が見つかります。
- `lookup`はワークスペースの拡張テーブルを読み取ります。行の変更が反映されるタイミングについては、 [拡張テーブル](/ja/extend-tables#パイプラインでキーを検索する)を参照してください。
- `geoip_lookup`は、 [`[mmdb].db_path`](/ja/configuration#機能とインテグレーション)で指定した[DB-IP](https://db-ip.com) City Liteデータベースを読み取ります。データベースがなければ `null`を返します。データベースにはプライベートアドレスが含まれません。戻り値のオブジェクトには、データベースに情報があるフィールドのみが含まれます。

| フィールド | 内容 |
|---|---|
| `country` | `DE`などのISO 3166国コードです。 |
| `country_name` | 国の英語名です。 |
| `continent_code` | `EU`などの大陸コードです。 |
| `continent` | 大陸の英語名です。 |
| `region` | 州や省など、第1レベルの行政区画の英語名です。 |
| `city` | 都市の英語名です。 |
| `latitude`, `longitude` | 度単位の座標です。 |

## JavaScript関数

ソースはイベントごとに1回実行されます。グローバルオブジェクト`molesignal`には、イベントとヘルパーが含まれます。

| メンバー | 用途 |
|---|---|
| `molesignal.fields` | イベントを表すオブジェクトです。読み取り、変更、新しいオブジェクトの代入ができます。 |
| `molesignal.set(name, value)` | フィールドに値を設定します。 |
| `molesignal.del(name)` | フィールドを削除します。 |
| `molesignal.now()` | Unixエポックからの経過時間をマイクロ秒単位で返します。 |
| `molesignal.parse_json(text)`と`molesignal.encode_json(value)` | JSONテキストと値を相互に変換します。 |
| `molesignal.sha256(text)` | テキストのUTF-8バイト列のSHA-256ダイジェストを、小文字の16進数表記で64文字として返します。 |

```js
molesignal.set("severity", String(molesignal.fields.level || "info").toUpperCase());
molesignal.set("seen_at", molesignal.now());
molesignal.del("level");
```

JavaScript関数は分離されたエンジン内で実行され、次の制限が適用されます。

- 実行時間が50 msを超えると、`js timeout 50ms`で停止します。
- 関数ごとのヒープの上限は32 MiBです。
- ネットワークアクセス、タイマー、`TextEncoder`は使用できません。

## 関数を使用する

パイプラインのステップではVRLを実行します。**カスタムVRL**ステップで**保存済みの関数から開始**を選択すると、 VRL関数またはプリセットのソースがステップにコピーされ、その場で編集できます。ステップはコピーを保持するため、後から関数を変更または削除しても、パイプラインには影響しません。

## 権限

- `functions.read`は、関数の一覧を表示し、個別の関数を開くための権限です。
- `functions.create`と`functions.edit`は、関数の定義を作成、編集するための権限です。
- `functions.run`は、サンプルを実行するための権限です。
- `functions.delete`は、関数の定義を削除するための権限です。
