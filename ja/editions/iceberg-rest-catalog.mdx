<Warning>
  Enterprise と MoleSignal Cloud で提供を予定しています。この機能は設計段階にあり、現在はいずれのリリースでも利用できません。オープンソース版には含まれません。このページに記載する名称、対象範囲、動作は、リリース前に変更する場合があります。
</Warning>

Iceberg REST カタログは、組織のテレメトリを [Apache Iceberg](https://iceberg.apache.org) テーブルとして公開します。組織が選んだインフラストラクチャで動作するクエリエンジンは、カタログに接続してストリームをテーブルとして検出し、オブジェクトストレージから Parquet ファイルを直接読み取ります。MoleSignal はテーブル、メタデータ、権限、テナント境界、データの保存先を管理します。エンジンとクエリの運用、およびコンピューティングは組織が担います。

## 役割分担

MoleSignal は次の項目を管理します。

- **テーブル。** 公開された各ストリームは、そのストリームのスキーマを持つ読み取り専用の Iceberg テーブルとして表示されます。
- **メタデータ。** スナップショット、データファイル、統計情報は、コンパクションや保持処理の結果と整合します。
- **権限。** カタログは、各プリンシパルが一覧表示および読み取りできるテーブルを決定します。
- **テナント分離。** 各組織は、自組織のテーブルとファイルのみを参照できます。
- **データの保存先。** MoleSignal はファイルの保存先を決定し、そのファイルに対して有効期間の短い読み取り専用の認証情報を発行します。

組織は次の項目を担当します。

- **エンジン。** Apache Spark、Trino、Apache Flink、DuckDB、または Iceberg REST カタログ仕様に対応するその他のクライアントを運用します。
- **ワークロード。** クエリ、ETL パイプライン、機械学習ジョブ、BI ダッシュボードを運用します。
- **コンピューティングとそのコスト。** クラスター、スケジューリング、結果の保存を管理し、費用を負担します。

## 接続の仕組み

<Steps>
  <Step title="認証する">
    エンジンは API トークンまたはサービスアカウントの認証情報をカタログエンドポイントに提示します。
  </Step>
  <Step title="テーブルを見つける">
    カタログは、プリンシパルが読み取れるストリームをストリームタイプ別に一覧表示します。
  </Step>
  <Step title="テーブルを読み込む">
    カタログは、同一のスナップショットに対応するスキーマ、パーティション構成、データファイルを、テーブルの保存先にアクセスするための有効期間の短い読み取り専用の認証情報とともに返します。
  </Step>
  <Step title="ファイルを読み取る">
    エンジンはオブジェクトストレージから Parquet ファイルを直接読み取ります。ファイルの内容は MoleSignal を経由しません。
  </Step>
</Steps>

## アクセス方法を選ぶ

| | Iceberg REST カタログ | [Arrow Flight SQL](/ja/query/database-clients) |
|---|---|---|
| クエリの実行場所 | 組織のエンジン | MoleSignal |
| 主な用途 | 指定した時間範囲を対象とする大規模分析、ETL、機械学習、BI | データベースクライアントからの対話型 SQL |
| フィールドマスキング | 適用しません。[データ保護の適用範囲](#データ保護の適用範囲)を参照してください。 | 適用します |
| エディション | Enterprise と Cloud（提供予定） | すべてのエディション |

ガバナンスを適用した対話型クエリには、Flight SQL またはクエリ API を使用します。エンジン側のコンピューティングで広い時間範囲をスキャンするジョブには、カタログを使用します。

## カタログで公開するデータ

- **ストリームごとに 1 つのテーブル。** 名前空間は、ストリームタイプ `logs`、`metrics`、`traces`、`profiles` に対応します。
- **列はストリームのスキーマに従います。** 先頭列は `_timestamp` で、UTC のマイクロ秒精度です。JSON フィールドは文字列です。暗号化フィールドは暗号文のままです。
- **イベント時刻でファイルをパーティション分割します。** 時間範囲フィルターで読み取り対象のファイルを絞り込みます。
- **非公開のデータ。** メモリ上にある Extend テーブルと、MoleSignal が内部機能向けに保持する派生読み取りモデルは公開しません。

## アクセス制御

- **認証。** HTTP API や Flight SQL と同じく、API トークン（`mspat-<36>`）とサービスアカウントを使用します。
- **認可。** カタログ専用の権限でアクセスを許可します。権限名はリリース時に公開します。テーブルの読み取りには、この権限と `streams.query` が必要です。
- **テナント分離。** カタログのアクセス範囲は組織ごとに分かれています。ストレージの認証情報は、リクエストしたテーブルのファイルだけを対象とし、短時間で失効します。書き込みや削除は許可しません。
- **監査。** 認証情報の発行と公開設定の変更を監査イベントとして記録します。

## データ保護の適用範囲

<Warning>
  Parquet ファイルを読み取るエンジンは、保存された値をそのまま参照します。フィールドマスキングルールは、MoleSignal のクエリと Flight SQL の結果に適用します。エンジンが直接読み取るファイルには適用しません。ファイル内の暗号化フィールドは暗号化されたままなので、エンジンは暗号文を受け取ります。
</Warning>

そのため、カタログにアクセスできるプリンシパルは、公開されたストリームの生データを読み取れます。

- マスキングされていないデータの読み取りを許可されたプリンシパルにのみ、カタログ権限を付与してください。
- 管理者は、カタログで公開するストリームを選択します。有効なフィールドマスキングルールがあるストリームは、管理者が明示的に許可するまで公開しません。
- メトリクスストリームはフィールドマスキングの対象外で、通常の公開設定に従います。

## データの鮮度と整合性

- スナップショットには、コミット済みのファイルのみが含まれます。取り込みバッファに残っているレコードは、次のフラッシュ後に参照できます。
- コンパクションと保持処理の結果は、次のスナップショットに反映されます。コンパクションで置き換えたファイルは、以前のスナップショットに基づいて実行計画を作成したジョブが完了できるよう、猶予期間中はオブジェクトストレージに残します。実行時間が猶予期間を超えるジョブは、実行計画を作成し直してください。

## 対応エンジン

カタログは、公開されている Iceberg REST カタログ仕様に準拠します。次のエンジンを検証対象とします。

| エンジン | ステータス |
|---|---|
| Apache Spark | 検証予定 |
| Trino | 検証予定 |
| Apache Flink | 検証予定 |
| DuckDB | 検証予定 |
| PyIceberg およびその他の REST カタログクライアント | 動作見込み、未検証 |

検証済みのバージョンと接続設定は、リリース時に公開します。

## 初回リリースの制限

- **読み取り専用。** カタログは、書き込み、テーブルの作成、スキーマの変更を拒否します。スキーマと保持設定はストリーム側で変更してください。
- **現在のスナップショットのみ。** タイムトラベル、ブランチ、タグは利用できません。
- **ビューと複数テーブルにまたがるトランザクションは利用できません。**
- **組織が所有するテーブルは作成できません。** エンジンは複数のカタログに同時に接続できるため、クエリ結果を組織が運用するカタログのデータと結合したり、そのカタログに書き込んだりできます。
- **アクセス範囲を限定した認証情報を発行できるオブジェクトストレージのみ対応します。** `local` オブジェクトストレージバックエンドは、外部エンジンにファイルを提供できません。

## 提供状況

| エディション | 提供状況 |
|---|---|
| オープンソース | 含まれません。外部から SQL でアクセスするには、[Arrow Flight SQL](/ja/query/database-clients) を使用してください。 |
| Enterprise | 提供予定です。エンジンからアクセスできるオブジェクトストレージと、この機能を含むライセンスが必要です。 |
| MoleSignal Cloud | 提供予定です。各リージョンでは、そのリージョンを利用する組織のデータと同じ場所でカタログを提供します。 |
