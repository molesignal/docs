オープンソース版は、すべての機能を備えたセルフホスト型のプラットフォームです。[Apache License 2.0](https://github.com/molesignal/molesignal/blob/main/LICENSE) のもとで提供し、運用者が管理するインフラストラクチャ上で動作します。MoleSignal アカウントもホスト型のコントロールプレーンも必要ありません。

## 含まれる機能

- ログ、メトリクス、トレース、プロファイルの取り込み、保存、クエリ
- トレースに基づく APM、RUM での調査、相関分析、サービスのトポロジー
- ダッシュボード、ストリーム、パイプライン、再利用可能な関数、拡張テーブル
- アラート、インシデント、オンコールとエスカレーション、通知の配信、重大インシデント、修復、ポストモーテム
- 合成モニタリングとステータスページ
- Mole Agent と、同じツールカタログへのインバウンド MCP アクセス
- 組織間の分離、IAM、SSO、サービスアカウント、API トークン、監査イベント、プラットフォーム設定
- Docker Compose、バイナリ、Kubernetes のいずれかを使う単一ノード構成と、ルーター、取り込み、クエリ、コンパクション、アラートの各プロセスを分離するロール分割構成

利用できる API の詳細は、**API リファレンス**を参照してください。ユーザー、サービスアカウント、API トークンが実行できる操作は、それぞれの権限で決まります。

## デプロイに必要なもの

メタデータの保存には PostgreSQL が必要です。データの保存には、S3 互換、Azure、Google Cloud のいずれかのオブジェクトストアが必要です。開発用の単一ノード構成では、ローカルディスクをオブジェクトストアとして使用できます。[MoleSignal のデプロイ](/ja/deployment)を参照してください。

## セルフホスティングを始める

1. [クイックスタート](/ja/quickstart)に沿って、ローカルインスタンスを起動します。
2. [MoleSignal のデプロイ](/ja/deployment)を参照して、トポロジーを選択します。
3. 実データの取り込みを始める前に、[本番環境のチェックリスト](/ja/deployment/production-checklist)の各項目を確認します。
4. [セキュリティとマルチテナンシー](/ja/security)および[自己監視](/ja/self-observability)を確認します。
