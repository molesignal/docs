<Warning>
MoleSignal Cloud はウェイトリストへの登録を受け付けています。このページは評価ガイドです。一般提供サービスの有効化や接続の手順は扱いません。
</Warning>

MoleSignal Cloud は、ストレージやサービスのインフラを自ら運用せずにオブザーバビリティを評価したいチーム向けのマネージドサービスです。現在、提供を計画しています。[Cloud ウェイトリスト](https://www.molesignal.com/cloud)から登録してください。今すぐ評価する場合は、[セルフホスト版クイックスタート](/ja/quickstart)で環境を構築してください。

## Cloud の評価を準備する

| 要件 | 収集する情報 |
|---|---|
| テレメトリ | ログ、メトリクス、トレース、プロファイル、想定される 1 日あたりのデータ量、ピーク時のデータレート。 |
| 保持 | シグナルごとに必要な履歴の期間と、引き続き実行できる必要があるクエリ。 |
| アクセス | チームの規模、組織間の境界、ID 管理の要件、API トークンの利用方法。 |
| データの場所 | 必要なデータリージョン、ネットワークアクセス、データの取り扱いに関する制約。 |
| 運用 | サポートへの期待事項、復旧目標、インシデント発生時の責任分担。 |

評価時に、利用可能なリージョン、アクセス方法、保持の上限、契約条件、サポートの確約事項を確認してください。セルフホスト版の設定項目をマネージドサービスでも利用できるとは限りません。

## まずデータ経路を検証する

1. セルフホストインスタンスを起動し、代表的なサービスを 1 つ選びます。
2. ドキュメントに記載されている[取り込みプロトコル](/ja/intake/integrations)を使ってテレメトリを送信します。
3. イベントのタイムスタンプ、選択したストリーム、サービスの識別情報、権限を確認します。
4. 代表的なクエリを実行し、インシデント調査を 1 件行います。このワークフローに必要なデータ量と保持期間を記録します。
5. Cloud への導入計画や移行計画に合意する前に、評価で明らかになった要件について相談します。

セルフホスト環境の API アドレスや API トークンをそのまま Cloud で使うことはできません。実際に使用する環境向けに提供されたエンドポイントと認証情報のみを使用してください。

## 料金と機能の提供状況

[料金ページ](https://www.molesignal.com/pricing)では、予定しているプランと問い合わせ方法を案内しています。アクセスの手配時に、利用可能なプランと契約条件を確認してください。**エンタープライズクラウド**タグが付いたページには、提供予定の機能が記載されている場合があります。各ページで提供状況に関する注意事項を確認してください。

## 現在利用できる方法を選ぶ

- [オープンソース版](/ja/editions/open-source): 管理下のインフラでプラットフォームを運用します。
- [エンタープライズ版の評価](/ja/editions/enterprise): セルフホスト版の商用利用に関する要件について相談します。
- [サポートとコミュニティ](/ja/support): セルフホスト環境での概念実証（PoC）についてサポートを受けます。
