Codex は stdio MCP サーバーを起動でき、MoleSignal の Streamable HTTP エンドポイントと OAuth ディスカバリーに対応しています。

## stdio で接続する（推奨）

クライアントは MoleSignal CLI を起動し、CLI が MoleSignal にメッセージを転送します。この接続には Node.js 20 以降が必要です。

<Steps>
  <Step title="初回のみサインインする">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

ブラウザーで MoleSignal が開いたら、サインインを承認します。CLI はサインイン状態を保持し、更新します。

  </Step>
  <Step title="MoleSignal を追加する">

```bash
codex mcp add molesignal -- npx -y @molesignal/cli mcp
```

または、`~/.codex/config.toml` に次の内容を追加します。

```toml
[mcp_servers.molesignal]
command = "npx"
args = ["-y", "@molesignal/cli", "mcp"]
```

  </Step>
</Steps>

ブラウザーを利用できない場合は、サインインする代わりに、`MOLESIGNAL_URL` と `MOLESIGNAL_TOKEN`（API トークン）をサーバーの環境変数に設定します。[stdio で接続する](/ja/inbound-mcp#stdio-で接続する)を参照してください。

以降のセクションでは、CLI を使わずに Streamable HTTP で接続します。

## OAuth 2.1 で接続する

<Steps>
  <Step title="MoleSignal を登録する">

    ```bash
    codex mcp add molesignal \
      --url https://molesignal.example.com/api/v1/mcp
    ```

  </Step>
  <Step title="接続を承認する">

    ```bash
    codex mcp login molesignal
    ```

    ブラウザーで MoleSignal の認可ページを開き、手続きを完了します。

  </Step>
  <Step title="サーバーを確認する">

    ```bash
    codex mcp get molesignal
    codex mcp list
    ```

    MCP ツール一覧を更新するには、実行中の Codex タスクを再起動するか、新しいタスクを開きます。

  </Step>
</Steps>

<Warning>
  `--oauth-resource` は追加しないでください。MoleSignal は保護対象リソースをすでに公開しています。公開には OAuth ディスカバリーを使用しています。同じ値を追加すると、`duplicate field resource` エラーが発生することがあります。
</Warning>

## API トークンで接続する

Codex を非対話モードで実行する場合は、個人用またはサービスアカウント用の API トークンを使用します。

```bash
export MOLESIGNAL_MCP_TOKEN="<api-token>"

codex mcp add molesignal \
  --url https://molesignal.example.com/api/v1/mcp \
  --bearer-token-env-var MOLESIGNAL_MCP_TOKEN
```

Codex はトークンの値ではなく、環境変数名を保存します。この環境変数は Codex を起動するプロセスから参照できるように設定してください。
