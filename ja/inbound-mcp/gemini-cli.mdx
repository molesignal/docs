Gemini CLI は、stdio および Streamable HTTP サーバー、OAuth ディスカバリー、MCP のツール、リソース、プロンプトに対応しています。

## stdio で接続する（推奨）

クライアントは MoleSignal CLI を起動し、CLI 経由で MoleSignal にメッセージを送信します。この接続には Node.js 20 以降が必要です。

<Steps>
  <Step title="初回のみサインインする">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

ブラウザーで MoleSignal が開いたら、サインインを承認してください。CLI が認証情報を保持し、更新します。

  </Step>
  <Step title="MoleSignal を追加する">

```bash
gemini mcp add molesignal npx -y @molesignal/cli mcp
```

  </Step>
</Steps>

ブラウザーを使用できない場合は、サインインする代わりに、`MOLESIGNAL_URL` と `MOLESIGNAL_TOKEN`（API トークン）をサーバーの環境変数に設定してください。[stdio で接続する](/ja/inbound-mcp#stdio-で接続する)を参照してください。

以降のセクションでは、MoleSignal CLI を使わずに Streamable HTTP で接続します。

## OAuth 2.1 で接続する

<Steps>
  <Step title="MoleSignal を追加する">

    ```bash
    gemini mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    現在のプロジェクトの `.gemini/settings.json` に設定を保存するには、`--scope user` を省略してください。

  </Step>
  <Step title="認証する">
    Gemini CLI の対話型セッションを開始し、次のコマンドを実行してください。

    ```text
    /mcp auth molesignal
    ```

    ブラウザーで認可手順を完了してください。Gemini CLI は OAuth エンドポイントを検出し、動的クライアント登録を自動で行います。

  </Step>
  <Step title="サーバーへの接続を確認する">

    ```bash
    gemini mcp list
    ```

    対話型セッション内で `/mcp` を実行し、接続先で利用できるツール、リソース、プロンプトを確認してください。

  </Step>
</Steps>

## JSON で設定する

`~/.gemini/settings.json` または `.gemini/settings.json` に記述する同等の Streamable HTTP 設定は、次のとおりです。

```json
{
  "mcpServers": {
    "molesignal": {
      "httpUrl": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

ローカルの Gemini ポリシーでクライアント側の確認プロンプトを省略する意図がない限り、運用管理サーバーに `trust: true` を設定しないでください。MoleSignal の承認ポリシーは引き続きサーバー側で適用されます。

[Gemini CLI の MCP 公式ドキュメント](https://geminicli.com/docs/tools/mcp-server/)を参照してください。
