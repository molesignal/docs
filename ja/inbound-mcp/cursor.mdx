Cursor は、stdio MCP サーバーと、OAuth 認証を使用するリモート Streamable HTTP MCP サーバーに対応しています。

## stdio で接続する（推奨）

クライアントは MoleSignal CLI を起動し、CLI がメッセージを MoleSignal に転送します。この方法には Node.js 20 以降が必要です。

<Steps>
  <Step title="初回サインイン">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

ブラウザーで MoleSignal が開くので、サインインを承認します。CLI は認証情報を保持し、自動で更新します。

  </Step>
  <Step title="MoleSignal を追加する">

プロジェクト単位で設定する場合は `.cursor/mcp.json` に、すべてのプロジェクトに適用する場合は `~/.cursor/mcp.json` に、次の設定を追加します。

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

続いて、**Tools & MCP** で `molesignal` を有効にします。

  </Step>
</Steps>

ブラウザーを使用できない場合は、サインインする代わりに `MOLESIGNAL_URL` と `MOLESIGNAL_TOKEN`（API トークン）をサーバーの環境変数に設定します。[stdio で接続する](/ja/inbound-mcp#stdio-で接続する)を参照してください。

以下では、CLI を使わずに Streamable HTTP で接続する方法を説明します。

## サーバーを設定する

現在のプロジェクトに適用する場合は `.cursor/mcp.json` を、すべてのプロジェクトに適用する場合は `~/.cursor/mcp.json` を次の内容で作成します。

```json
{
  "mcpServers": {
    "molesignal": {
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Tools &amp; MCP を開く">
    **Cursor Settings → Tools & MCP** を開き、`molesignal` を探します。
  </Step>
  <Step title="OAuth で接続する">
    **接続**を選択し、MoleSignal の認可ページで認可を完了します。Cursor は MCP の保護対象リソースのメタデータを参照し、 OAuth エンドポイントを検出します。
  </Step>
  <Step title="ツールを確認する">
    `tool_search`、`call_read_tool`、`call_managed_tool` が利用可能なツールの一覧に表示されることを確認します。設定を変更した後は、**Tools & MCP** からサーバーを再起動してください。
  </Step>
</Steps>

<Warning>
  `.cursor/mcp.json` に Bearer トークンを記載したままコミットしないでください。Cursor を対話的に使用する場合は、 OAuth を推奨します。非対話型の認証には、クライアントがサポートするシークレットの注入機能を使って認証情報を渡してください。
</Warning>

[Cursor の公式 MCP ドキュメント](https://cursor.com/docs/mcp)を参照してください。
