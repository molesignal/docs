Claude Code は、stdio サーバー、OAuth ディスカバリーに対応するリモート Streamable HTTP サーバー、およびローカル、プロジェクト、ユーザーの設定スコープをサポートします。

## stdio で接続する（推奨）

クライアントは MoleSignal CLI を起動し、CLI が MoleSignal にメッセージを送信します。 Node.js 20 以降が必要です。

<Steps>
  <Step title="初回のみサインインする">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

ブラウザーで MoleSignal が開くので、サインインを承認します。CLI は認証情報を保存し、更新します。

  </Step>
  <Step title="MoleSignal を追加する">

```bash
claude mcp add --scope user molesignal -- npx -y @molesignal/cli mcp
claude mcp get molesignal
```

  </Step>
</Steps>

ブラウザーを使えない場合は、サインインする代わりに、サーバーの環境変数に `MOLESIGNAL_URL` と `MOLESIGNAL_TOKEN`（API トークン）を設定します。[stdio で接続する](/ja/inbound-mcp#stdio-で接続する)を参照してください。

以下のセクションでは、CLI を使わずに Streamable HTTP で接続します。

## OAuth 2.1 で接続する

<Steps>
  <Step title="リモートサーバーを追加する">

    ```bash
    claude mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    `--scope user` を指定すると、複数のプロジェクトでサーバーを利用できます。プロジェクトのローカル設定に保存するにはフラグを省略し、共有の `.mcp.json` にエントリを書き込むには `--scope project` を指定します。

  </Step>
  <Step title="MoleSignal を認可する">

    ```bash
    claude mcp login molesignal
    ```

    または、Claude Code を開き、`/mcp` を実行して `molesignal` を選択し、認証を完了します。

  </Step>
  <Step title="サーバーを確認する">

    ```bash
    claude mcp get molesignal
    claude mcp list
    ```

  </Step>
</Steps>

SSH 接続やヘッドレス環境のターミナルでは、認可 URL を出力し、最後に取得したコールバック URL を Claude Code に貼り付けます。

```bash
claude mcp login molesignal --no-browser
```

## API トークンで接続する

トークンをコミットせず、プロジェクトの `.mcp.json` で環境変数の展開を使用します。

```json
{
  "mcpServers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer ${MOLESIGNAL_MCP_TOKEN}"
      }
    }
  }
}
```

Claude Code を起動する前に `MOLESIGNAL_MCP_TOKEN` を設定します。プロジェクトスコープのサーバーに初めて接続する前に、そのサーバーを信頼するかどうかを明示的に選択する必要があります。

[Claude Code の公式 MCP ドキュメント](https://code.claude.com/docs/en/mcp)を参照してください。
