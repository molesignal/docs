VS Code は、stdio およびリモート HTTP の MCP サーバー、OAuth 認可、リソース、プロンプト、ツールに対応しています。

## stdio で接続する（推奨）

クライアントは MoleSignal CLI を起動し、CLI がメッセージを MoleSignal に中継します。この接続には Node.js 20 以降が必要です。

<Steps>
  <Step title="初回のみサインインする">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

ブラウザーで MoleSignal が開くので、サインインを承認します。CLI は認証情報を保持し、更新します。

  </Step>
  <Step title="MoleSignal を追加する">

`.vscode/mcp.json` に次の内容を追加します。

```json
{
  "servers": {
    "molesignal": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

ファイルまたは MCP ビューからサーバーを起動し、信頼を確認するプロンプトで承認します。

  </Step>
</Steps>

ブラウザーを利用できない場合は、サインインの代わりに `MOLESIGNAL_URL` と `MOLESIGNAL_TOKEN`（API トークン）をサーバーの環境変数に設定します。[stdio で接続する](/ja/inbound-mcp#stdio-で接続する)を参照してください。

以降の手順では、CLI を使わずに Streamable HTTP で接続します。

## サーバーを構成する

ワークスペースで構成を共有するには、`.vscode/mcp.json` を作成します。個人用のグローバル構成を使用するには、コマンド パレットから **MCP: ユーザー構成を開く** を実行します。

```json
{
  "servers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="サーバーを起動する">
    `mcp.json` を開いてインラインの **開始** アクションを選択するか、**MCP: サーバーの一覧表示** を実行し、 `molesignal` を選択します。
  </Step>
  <Step title="サーバーの信頼を確認する">
    エンドポイントを確認し、MCP サーバーの信頼を確認するプロンプトで承認します。ワークスペースの構成はすべてのコントリビューターと共有される可能性があるため、ファイルに認証情報を記載しないでください。
  </Step>
  <Step title="OAuth 認可を完了する">
    VS Code は MoleSignal の OAuth ディスカバリーを実行し、ブラウザーで認可ページを開きます。アクセスを許可してから、チャットのエージェント モードに戻ります。
  </Step>
  <Step title="接続を確認する">
    **MCP: サーバーの一覧表示** を実行して `molesignal` のステータスを確認し、チャット ビューでツールが表示されることを確認します。
  </Step>
</Steps>

MoleSignal リソースを添付するには **コンテキストの追加 → MCP リソース** を使用します。公開済みのプロンプトを呼び出すには、 `/molesignal.<prompt>` を使用します。

[VS Code の公式 MCP ドキュメント](https://code.visualstudio.com/docs/agent-customization/mcp-servers)を参照してください。
