## リリースノートとアップグレードの準備

公開済みのリリースノートは [GitHub Releases](https://github.com/molesignal/molesignal/releases) で確認できます。以下の一覧は、ブラウザーでリリースの詳細を読み込みます。JavaScript を利用できない場合や GitHub へのリクエストが失敗した場合は、このリンクからバージョン、公開日、変更内容、ダウンロード可能なアセットを確認してください。

### アップグレード前に

1. `molesignal --version` で稼働中のバージョンを記録し、リリースノートでアップグレード先のバージョンを確認します。
2. 現在のバージョンからアップグレード先までの互換性と移行に関する注意事項を読みます。プレリリースと安定版を区別します。
3. [バックアップと復元](/ja/backup-restore) の手順に従って、PostgreSQL、オブジェクトストレージ、設定、暗号化キーを保護します。
4. 本番環境をアップグレードする前に、分離された環境で、過去データのクエリ、新規データの制御された取り込み、権限、通知の動作を検証します。

受け入れ確認の手順は、[本番環境のチェックリスト](/ja/deployment/production-checklist) と [復旧準備ガイド](/ja/best-practices/recovery-readiness) を参照してください。提供予定の Enterprise 機能は、まだリリースされていません。利用可否は、各機能のページとアップグレード先のリリースノートで確認してください。
