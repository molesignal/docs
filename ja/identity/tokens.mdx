API トークンを使うと、プログラムはサインインせずに MoleSignal を呼び出せます。トークン自体にはロールがありません。メンバーまたはサービスアカウントとして動作し、スコープで実行できる操作を制限できます。サービスアカウントはプログラム用の ID です。サインインはできませんが、ロールを持ち、そのトークンはサービスアカウントとして動作します。

## トークンの種類

| 種類 | 動作時の ID | 発行場所 |
|---|---|---|
| **個人用 API トークン** | 発行したメンバー。 | **アカウント設定 → API トークン** |
| **サービスアカウント用 API トークン** | サービスアカウント。 | **ID とアクセス → API トークン** または **サービスアカウント** |
| **デフォルトのデータ取り込み用トークン** | トークンの所有者。データの書き込みに限ります。 | **データソース**。[データ取り込み用トークン](/ja/intake#取り込みトークン)を参照してください。 |
| **RUMクライアントトークン** | トークンに紐づく RUM アプリケーション。RUM データの書き込みに限ります。 | **データソース**。[データ取り込み用トークン](/ja/intake#取り込みトークン)を参照してください。 |

すべてのトークンは `mspat-<36>` 形式で、半角の英小文字と数字を使います。先頭の 10 文字でトークンを検索し、残りの部分はハッシュのみを保存します。トークンは Bearer 認証情報として送信します。

```http
Authorization: Bearer mspat-…
```

トークンで `_sys` 組織にアクセスすることはできません。

## トークンで実行できる操作

トークンで実行できるのは、リクエスト時点でメンバーまたはサービスアカウントに許可されている操作に限ります。スコープでその範囲をさらに絞り込みます。

| スコープ | トークンで使える権限 |
|---|---|
| **自分と同じ権限**、**サービスアカウントと同じ権限** | メンバーまたはサービスアカウントが持つすべての権限です。権限の変更も反映されます。 |
| **権限ポリシー** | **データ取り込み**などの[権限ポリシー](/ja/identity/roles#権限ポリシー)で定めた権限です。ポリシーの変更も反映されます。 |
| **カスタム** | 発行時にチェックを入れた権限です。発行後に変更することはできません。 |

発行者が持たない権限をトークンに付与することはできません。メンバーが権限を失うと、そのメンバーのすべてのトークンも同じ権限を失います。メンバーがワークスペースを離れるか、無効化されると、そのメンバーのトークンは使えなくなります。アクセス許可や共有によって個別のリソースに付与したロールは、スコープの範囲内でのみトークンに適用されます。RUMクライアントトークンはアプリケーションに紐づき、RUM データの書き込み以外には使用できません。

## 個人用トークンを発行する

1. **アカウント設定 → API トークン**を開き、**新しいトークン**を選択します。
2. **名前**を入力します（例：`collector-production`）。
3. **スコープ**で、**自分と同じ権限**、**権限ポリシー**、または**カスタム**を選択します。持っていない権限や、それらを含むポリシーは選択できません。ポリシーを選択すると、含まれる権限が一覧で表示されます。
4. **有効期間（日数）**を設定します。デフォルトは 365 日、最大は 1825 日です。有効期限を設定しない場合は、空欄にします。
5. **トークンを作成**を選択し、続いて**トークンをコピー**を選択します。トークンが表示されるのはこのときだけです。

一覧には、発行したトークンと、そのスコープ、種類、有効期限、最終使用日時が表示されます。**取り消し**を選択すると、トークンは直ちに無効になり、元に戻せません。発行したトークンの管理には `personal_tokens.manage` が必要です。この権限はすべての組み込みロールに含まれます。個人用トークンはサインイン済みのセッションから発行します。トークンを使って別のトークンを発行することはできません。

## 組織のトークン

**ID とアクセス → API トークン**には、ワークスペースのすべてのトークンと、それぞれが動作する際の ID（メンバー、サービスアカウント、またはアプリケーション）、スコープが表示されます。一覧の表示には `api_tokens.read` が必要です。 `api_tokens.revoke` があれば、どのトークンでも取り消せます。また、**サービスアカウント用トークンを発行**を選択してサービスアカウントにトークンを発行できます。**サービスアカウント**、**スコープ**、有効期限を指定します。

## サービスアカウント

コレクター、CI パイプライン、インテグレーション、自動で動作する AI エージェントには、サービスアカウントを使います。メンバーがワークスペースを離れても、自動処理は止まりません。

1. **サービスアカウント**を開き、**サービスアカウントの作成**を選択します。
2. **名前**（例：`deployment-automation`）、**説明**、**ロール**を指定します。
3. **アカウントとトークンを作成**を選択し、最初の API トークンをコピーします。このトークンには作成時のロールの権限が付与されます。有効期間は 365 日で、作成時に一度だけ表示されます。

管理するアカウントを選択します。

| 操作 | 結果 |
|---|---|
| **変更を保存** | 変更した名前、説明、またはロールを保存します。新しいロールに含まれない権限は、アカウントのすべてのトークンで直ちに使えなくなります。追加した権限は、変更後に発行するトークンにのみ適用します。 |
| **API トークンを管理** | 対象のアカウントで絞り込んだ **API トークン**を開きます。トークンの追加発行や取り消しができます。 |
| **無効化** / **有効化** | 無効化したアカウントとそのすべてのトークンは、アカウントを再度有効にするまで認証に使えません。 |
| **削除** | アカウントを削除し、そのすべてのトークンを取り消します。この操作は元に戻せません。 |

監査記録やアクセス許可では、アカウントの **プリンシパル ID** でアカウントを識別します。サービスアカウントの参照には `service_accounts.read`、変更には `service_accounts.manage` が必要です。

## トークンを選ぶ

| 呼び出し元 | 推奨トークン |
|---|---|
| テレメトリーを送信するコレクターやエージェント | **データ取り込み**ポリシーを適用したサービスアカウント用トークン、またはデフォルトのデータ取り込み用トークン。 |
| RUM データを送信するブラウザーやモバイルのコード | アプリケーションの RUMクライアントトークン。エンドユーザーからも確認できます。 |
| デプロイを報告する CI | **データ取り込み**ポリシーを適用したトークン。このポリシーには `apm.deploy` も含まれます。 |
| データの読み取りやリソースの変更を行う自動処理 | ポリシーまたはカスタム権限でスコープを絞ったサービスアカウント用トークン。 |
| MCP クライアントや手動で実行するスクリプト | 有効期限付きの個人用 API トークン。 |

サインインセッションはブラウザーの HttpOnly Cookie に保存され、デフォルトでは 24 時間で終了します（`[auth].session_ttl_secs`）。`Authorization` ヘッダーはこのセッションを受け付けないため、プログラムでは常に API トークンを使います。

## トークン API

| 操作 | エンドポイント | 必要な権限 |
|---|---|---|
| 個人用トークンを発行する | `POST /api/v1/me/api-tokens` | `personal_tokens.manage` |
| 発行した個人用トークンを一覧表示する | `GET /api/v1/me/api-tokens` | `personal_tokens.manage` |
| 発行した個人用トークンを取り消す | `DELETE /api/v1/me/api-tokens/{id}` | `personal_tokens.manage` |
| トークンのスコープに指定できる権限ポリシーと組織の権限を一覧表示する | `GET /api/v1/me/api-tokens/scopes` | サインイン済みのメンバー |
| サービスアカウント用トークンを発行する | `POST /api/v1/auth/tokens` | `api_tokens.revoke` |
| すべてのトークンを一覧表示する | `GET /api/v1/auth/tokens` | `api_tokens.read` |
| 任意のトークンを取り消す | `DELETE /api/v1/auth/tokens/{id}` | `api_tokens.revoke` |

[API トークンの発行](/ja/api/auth/issue-token)、[API トークンの一覧表示](/ja/api/auth/list-tokens)、 [API トークンの取り消し](/ja/api/auth/revoke-token)を参照してください。
