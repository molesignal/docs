**ID とアクセス → 組織**または**チーム**を開きます。

## 組織

**組織**はプラットフォームのページです。`_sys` 組織に表示され、アクセスには `sys.organizations.read` が必要です。インスタンス内のすべての組織を一覧表示します。各組織には、アカウントのロール（未所属の場合は**メンバーではありません**）、スラッグ、ID が表示されます。

**IAM を管理**を選択すると、対象の組織に切り替わり、その組織の**ID とアクセス**が開きます。対象の組織のメンバーであり、その組織が有効になっている必要があります。

組織を作成するには、次の手順に従います。

1. **組織を作成**を選択します。
2. **名前**と**スラッグ**を入力します。スラッグは API やリソースパスで組織を識別するために使います。後から変更することはできません。
3. **組織を作成**を選択します。作成者が組織のオーナーになります。ただし、スーパー管理者はオーナーにはならず、メンバーでなくてもすべての組織にアクセスできます。

組織の無効化、有効化、削除は、 [設定 → 組織管理](/ja/settings/platform#組織管理)で行います。このページも `_sys` にあります。対象の組織で `org.delete` 権限を持つアカウントは、 [組織内の設定](/ja/settings/organization#組織のライフサイクル)からも組織を削除できます。

## チーム

チームは、同じ組織のメンバーをまとめたグループです。チームは次の用途で使います。

- [オンコールスケジュール](/ja/alerting/on-call)の担当チーム、および [エスカレーションポリシー](/ja/alerting/on-call#エスカレーションポリシー)の対象
- 通知の[フォールバックルート](/ja/notification-channels#フォールバックルートを設定する)の適用範囲
- [アクセス権の付与](/ja/identity/roles#アクセス権の付与)の付与先（プリンシパル）
- [Mole Agent](/ja/agent#組織、チーム、個人のリソース)のチャット、ナレッジ、スキル、およびその他のチームリソースの所有者

チームを作成するには、**新規チーム**を選択し、**名前**を入力して、**メンバー**を選びます。次に **チームを作成**を選択します。すべてのメンバーが組織に所属している必要があります。名前やメンバーを変更するには、対象のチームを選択します。

**削除**を選択するとチームが削除されます。チームのメンバーのアカウントは残ります。Mole Agent のリソースを所有しているチームは削除できません。先にリソースを移動するか削除してください。

**チーム**を開くには `org.members.read` が必要です。チームを作成、変更、削除するには `org.teams.manage` が必要です。
