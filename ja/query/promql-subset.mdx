MoleSignal は、組み込みの評価エンジン（`promql-parser` と Arrow/DataFusion の評価エンジン）でメトリクスストリームに対して PromQL を実行します。**インスタント**クエリと**範囲**クエリの両方に対応しています。 `step` を指定すると、`[start, end]` をステップごとに評価して行列を返します。指定しない場合は、インスタントクエリとして `end` の時点で評価します。このページは、サポート状況を示す公式の一覧です。

## サポート対象

### 範囲ベクトル関数（`metric[range]`）

`rate`、`irate`、`increase`、`delta`、`idelta`、`deriv`、`predict_linear`、`resets`、`changes`、 `holt_winters`（別名 `double_exponential_smoothing`）およびすべての `*_over_time` 系列の関数： `avg_over_time` / `min_over_time` / `max_over_time` / `sum_over_time` / `count_over_time` / `quantile_over_time` / `stddev_over_time` / `stdvar_over_time` / `last_over_time` / `present_over_time` / `mad_over_time`。

`rate`、`increase`、`delta` は、Prometheus と同様に、ウィンドウ内の最初と最後のサンプル間の変化をウィンドウの両端まで外挿します。そのため、同じサンプルから同じ値が得られます。

### 集計（`by()` / `without()` に対応）

`sum`、`avg`、`min`、`max`、`count`、`stddev`、`stdvar`、`quantile`、`group`、`count_values`、 `topk`、`bottomk`、`limitk`、`limit_ratio`。

### ヒストグラム

`histogram_quantile(q, sum by(le)(rate(metric_bucket[range])))` — クラシックヒストグラムの `le` バケット間を線形補間します。

`histogram_fraction(lower, upper, v)` — クラシックヒストグラムの `le` バケットを使い、 `[lower, upper]` に収まる観測値の割合を推定します（同じ区分線形の累積分布関数を使用し、 `(rank(upper) - rank(lower)) / total` で計算します）。

### ラベルとソート

`label_replace`、`label_join`、`sort`、`sort_desc`、`sort_by_label`、`sort_by_label_desc`。

### 日時

`time`、`timestamp`、`minute`、`hour`、`day_of_week`、`day_of_month`、`day_of_year`、 `days_in_month`、`month`、`year`（UTC。日付関数のデフォルト引数は `vector(time())` です）。

### 型変換 / データの有無

`vector`、`scalar`、`absent`、`absent_over_time`。

### 数学 / 丸め / 三角関数

`abs`、`ceil`、`floor`、`round`、`exp`、`ln`、`log2`、`log10`、`sqrt`、`sgn`、 `clamp` / `clamp_min` / `clamp_max`、`sin` / `cos` / `tan` / `asin` / `acos` / `atan` / `sinh` / `cosh` / `tanh` / `asinh` / `acosh` / `atanh`、`pi`、`deg`、`rad`。

### 演算子

算術演算子 `+ - * / % ^`、比較演算子 `== != > < >= <=`（`bool` に対応）、集合演算子 `and` / `or` / `unless`、ベクトルマッチング `on(...)` / `ignoring(...)`（ `group_left` / `group_right` に対応）、および単項マイナスに対応しています。

### 修飾子と構文

セレクターの修飾子 `@`（`start()` / `end()` / `<ts>`）と `offset`（行列セレクターでも使用可）、およびサブクエリ `inner[range:step]` に対応しています。

## 未実装の機能 / 既知の差異

| 機能 | ステータス | 備考 |
|---|---|---|
| ネイティブヒストグラム関数 `histogram_count` / `histogram_sum` / `histogram_avg` / `histogram_stddev` / `histogram_stdvar` | ❌ → 400 | クラシックヒストグラムの `le` バケットモデルには適用できません。分位点には `histogram_quantile`、区間内の割合には `histogram_fraction` を使用してください |
| 二項演算子 `default` による欠損値の補完 | ❌ → 400 | — |
| 範囲クエリ内のサブクエリ | ⚠️ | インスタント評価に切り替わります（外側と内側の両方をステップごとに評価することはありません）。インスタントクエリとアラートでは正確に評価します |
| `timestamp()` | ⚠️ | インスタントクエリでは評価時刻を、範囲クエリでは各データポイントのタイムスタンプを返します |
| 関数のスカラー引数（`predict_linear` の `t`、`holt_winters` の `sf`/`tf`、分位点） | ⚠️ | 数値リテラルのみ指定できます |

未対応の関数や構文を使用すると、エラー `promql function not yet supported: <name>` が発生し、 `POST /api/v1/query`（`language: "promql"`）は `400` を返します。

<Note>
  アラートルールの `query.language` が `promql` の場合、アラートルールは PromQL 式をインスタントクエリとして評価ウィンドウの終了時点で評価します。ルール自体は MoleSignal の `AlertRule` で、 Prometheus のルール形式とは互換性がありません。[ルールを作成する](/ja/api/alerting/create-rule)を参照してください。
</Note>

## ラベルマッチング

`=`、`!=`、`=~`、`!~`（正規表現には RE2 を使用します。Prometheus の PCRE とは挙動が若干異なります）。`__name__` は `metric_name` 列と照合します。ドットを含むメトリクス名を選択するには、次の例のように名前を引用符で囲みます： `{"http.server.duration"}`。`{job="api"}` や `{__name__=~"http_.*"}` のようにメトリクス名を明示しないセレクターは、マッチャーに一致するすべてのメトリクスを読み取り、各系列は `__name__` を保持します。

## メトリクスストリームの構造

メトリクスストリームは、1 台の Prometheus サーバーなど、単一のソースからのメトリクスを保持します。ラベルは単一の JSON データではなく、**個別の列**として保存します。

```sql
_timestamp   Timestamp(Microsecond)  NOT NULL   -- time
metric_name  Utf8                    NOT NULL   -- the metric, PromQL's __name__
value        Float64                 NOT NULL   -- the measurement (Int64 etc. is accepted and cast to f64)
<label_x>    Utf8 …                             -- every non-reserved column is a label
```

ファイル内では、行を `metric_name`、次いで時刻の順にソートし、メトリクスごとにまとめます。セレクターは、対象のメトリクスを保持するストリームを参照し、クエリの時間範囲と重なる Parquet ファイルから、対象のメトリクスを含むページだけを読み取ります。ラベルセットの組み合わせごとに 1 つの系列を作成し、エンジン内でマッチャー（`=`、`!=`、`=~`、 `!~`）を適用します。`@` と `offset` は評価時点を変更します。OTLP 経由で受信するメトリクスについては、[OTLP メトリクスのフィールド](/ja/query#otlp-メトリクスのフィールド)を参照してください。
