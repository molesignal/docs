**メトリクス**を開くと、メトリクスストリームに保存された時系列を PromQL でクエリできます。クエリはタブで実行されます。タブは並べて表示でき、**共有**でクエリへのリンクをコピーできます（ [ログ](/ja/logs#クエリタブ)と同様）。アドレスバーには最後に実行したステートメントが保持されるため、そのコピーでクエリを共有できます。

## メトリクスを検索する

エディターの横にある**メトリクスブラウザー**を開くか、**メトリクスを検索**を選び、名前の一部を入力します。各メトリクスには、そのタイプ（**カウンター**、**ヒストグラム**、**ゲージ**）と、ラベルおよびフィールドの数が表示されます。メトリクスを選択すると、そのメトリクスがクエリに追加され、実行されます。ワークスペースが空の場合は、 **メトリクスソースを接続**が表示されます。詳細は [データソース](/ja/intake) を参照してください。

ストリームの保持期間内にデータが見つからないメトリクスは、一覧から削除されます。

## クエリを記述する

エディターには2つのモードがあり、タイトル横の2つのアイコンで切り替えます（コードは `</>`、ビルダーはブロックアイコン）：

- **コード**: PromQL を直接記述します。**よく使われる PromQL 関数**には一般的な関数が一覧表示され、 [PromQL サポートマトリックス](/ja/query/promql-subset)には実装済みの関数がすべて記載されています。
- **ビルダー**: **メトリクス**を選択し、照合するラベルごとに**ラベルフィルターを追加**を選び、**関数** （**未加工のメトリクス**、**変化率**、**瞬間変化率**、または**増加量**）、**集計**（**合計**、 **平均**、**最大値**、または**最小値**）、および**範囲**を指定します。生成される PromQL は以下に表示されます。追加のパラメーターを持つ関数など、ビルダーで表現できない式は、ビルダーのフィールドが変更されるまでそのまま保持されます。

```promql
sum by (service_name) (
  rate(http_server_request_duration_seconds_count[5m])
)
```

**実行**を押します。**オプション**ではクエリの実行方法を設定します：

| オプション | 選択肢 |
|---|---|
| **凡例** | **自動**、**詳細**（すべてのラベル）、または `{{service}}` などのテンプレートを指定する**カスタム**。 |
| **形式** | **時系列**または**テーブル**。 |
| **ステップ** | 範囲を1,000ステップに分割する**自動**、または `30s` や `5m` などの期間。 |
| **タイプ** | 時間範囲のグラフには**範囲**、その終了点の値には**インスタント**。 |
| **エグザンプラー** | **オン**にすると、ポイントをトレースにリンクするエグザンプラーが描画されます。 |

**ダッシュボードに追加**を選ぶと、クエリを最初のパネルとして新しいダッシュボードが開きます。**クエリをクリア**でエディターが空になります。有効なクエリで何も見つからない場合は、式を変更する前に**時間範囲を4倍に拡大**と **フィルターをクリアして再試行**が役立ちます。

## グラフを読み取る

- プロット上をドラッグすると時間範囲を拡大でき、X 軸をドラッグするとパンでき、ダブルクリックすると縮小できます。**時間範囲をリセット**を選ぶと、グラフを操作する前の範囲に戻ります。
- **描画スタイル**（**線**、**棒**、または**点**）と、**積み上げ**（**オフ**、**標準**、または **パーセント**、積み上げには2つ以上の系列が必要です）を選択します。
- 凡例を使用して系列を分離したり比較したりできます。
- **比較**では、同じクエリをグラフ上でベースラインに重ねて表示し、各系列はそれぞれの色の破線で描画されます：同じ長さの直前の期間（既定）、1日前または1週間前の同じ時刻、あるいは独自の時間範囲です。ベースラインの表示中は積み上げがオフになり、ベースライン横の閉じるボタンで解除できます。インスタントクエリにはベースラインがありません。
- エグザンプラーをオンにすると、ひし形を選択してトレースを確認でき、**トレースを開く**でそのポイントの背後にあるリクエストを検査できます。

拡大した範囲は、トレースやログに移動するときにも引き継がれます。

## 結果を分析する

**グラフ**、**テーブル**、**クエリインスペクター**では、結果をグラフ、生の行、実行されたクエリとして表示します。結果の周囲のパネルでデータを説明します：

| パネル | 表示内容 |
|---|---|
| **系列** | 各系列とそのラベル、および最後の値、現在の値、平均値、最大値。 |
| **クエリ統計** | 系列、データポイント、スキャンされた行、クエリ時間、範囲、ステップ。 |
| **データ品質** | 負の値のポイント、欠損データ、タイムスタンプの異常。変化率が負のカウンターは、リセットされたか、順序どおりに到着していないか、タイプが誤っています：**異常を表示**、**生データを表示**、または**メトリクスの型を確認**。 |
| **上位ラベル** | 結果の中で最も比重の大きいラベル値。 |
| **統計サマリー** | すべての系列の値の分布。 |
| **カーディナリティ** | メトリクスのアクティブな系列と、スキャンされた行。系列を作りすぎるラベルを見つけるために使用します。 |
| **結果のスキーマ** | 結果の時刻、値、ラベルの各列。 |

インスタンスの[メトリクスのカーディナリティ制限](/ja/settings/platform#メトリクスのカーディナリティ)により、上限を超える新しい系列は拒否されるため、値の多いラベルを追加する前に**カーディナリティ**を確認してください。

## メトリクスのスパイクを関連付ける

スパイクの期間を選択し、サービスと環境のラベルを保持したまま、関連するトレースまたはログを開きます。MoleSignal は選択した範囲を次のシグナルに引き継ぎます。詳細は [シグナル間の相関](/ja/correlation) を参照してください。

## 権限

メトリクスの一覧表示には `metrics.read` が必要です。PromQL の実行には `streams.query` が必要です。**ダッシュボードに追加**には `dashboards.create` が必要です。
