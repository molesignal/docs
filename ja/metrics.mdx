**メトリクス**を開き、メトリクスストリームに保存されている時系列を PromQL でクエリします。クエリはタブで実行します。タブは横に並べられます。[ログ](/ja/logs#クエリタブ)と同様に、**共有**を選択するとクエリへのリンクがコピーされます。アドレスバーには最後に実行したクエリが含まれるため、アドレスをコピーしてクエリを共有することもできます。

## メトリクスを探す

エディターの横にある**メトリクスブラウザー**を開くか、**メトリクスを検索**を選択し、名前の一部を入力します。各メトリクスには、型（**カウンター**、**ヒストグラム**、**ゲージ**）と、ラベル数およびフィールド数が表示されます。メトリクスを選択すると、クエリに追加して実行します。空のワークスペースには **メトリクスソースを接続**が表示されます。[データソース](/ja/intake)を参照してください。

ストリームの保持期間内にデータを受信していないメトリクスは、一覧に表示されなくなります。

## クエリを書く

エディターには 2 つのモードがあります。タイトルの横にあるアイコンで切り替えます（`</>` はコード、ブロックのアイコンはビルダー）。

- **コード**：PromQL を直接入力します。**よく使われる PromQL 関数**には代表的な関数が表示されます。実装済みの関数はすべて [PromQL 対応表](/ja/query/promql-subset)で確認できます。
- **ビルダー**：**メトリクス**を選択し、絞り込みに使うラベルごとに**ラベルフィルターを追加**を選択します。次に、**関数** （**未加工のメトリクス**、**変化率**、**瞬間変化率**、**増加量**）、**集計**（**合計**、 **平均**、**最大値**、**最小値**）、**範囲**を選択します。生成された PromQL は下に表示されます。追加のパラメーターがある関数など、ビルダーで表現できない式は、ビルダーのフィールドを変更するまでそのまま保持されます。

```promql
sum by (service_name) (
  rate(http_server_request_duration_seconds_count[5m])
)
```

**実行**を選択します。**オプション**でクエリの実行方法を設定します。

| オプション | 選択肢 |
|---|---|
| **凡例** | **自動**、**詳細**（すべてのラベル）、または `{{service}}` などのテンプレートを使う**カスタム**。 |
| **形式** | **時系列**または**テーブル**。 |
| **ステップ** | 時間範囲を 1,000 ステップに分割する**自動**、または `30s` や `5m` などの間隔。 |
| **タイプ** | 時間範囲全体をグラフに表示する**範囲**、または時間範囲の終了時点の値を表示する**インスタント**。 |
| **エグザンプラー** | **オン**にすると、データポイントをトレースに関連付けるエグザンプラーを表示します。 |

**ダッシュボードに追加**を選択すると、クエリを最初のパネルに配置した新しいダッシュボードが開きます。**クエリをクリア**を選択すると、エディターが空になります。有効なクエリで結果が得られない場合は、式を変更する前に**時間範囲を4倍に拡大**や**フィルターをクリアして再試行**を試してください。

## グラフを読み取る

- プロット上をドラッグして時間範囲を拡大し、X 軸をドラッグして表示範囲を移動します。ダブルクリックすると縮小します。**時間範囲をリセット**を選択すると、グラフを操作する前の時間範囲に戻ります。
- **描画スタイル**（**線**、**棒**、**点**）と**積み上げ**（**オフ**、**標準**、 **パーセント**）を選択します。積み上げには 2 つ以上の系列が必要です。
- 凡例を使って特定の系列だけを表示したり、系列を比較したりします。
- エグザンプラーがオンの場合は、ひし形を選択して対応するトレースを表示し、**トレースを開く**を選択して、そのデータポイントに対応するリクエストを確認します。

トレースやログに移動しても、拡大した時間範囲が引き継がれます。

## 結果を分析する

**グラフ**では結果をグラフで、**テーブル**では生データを行単位で、**クエリインスペクター**では実行したクエリを確認できます。結果の周囲にあるパネルには、データの詳細が表示されます。

| パネル | 表示内容 |
|---|---|
| **系列** | 各系列のラベルと、最終値、現在値、平均値、最大値。 |
| **クエリ統計** | 系列、データポイント、スキャンした行数、クエリの実行時間、時間範囲、ステップ。 |
| **データ品質** | 負の値を持つデータポイント、データの欠損、タイムスタンプの異常。カウンターの変化率が負の場合は、カウンターがリセットされた、データが時系列順に到着しなかった、または型が正しくない可能性があります。**異常を表示**、**生データを表示**、**メトリクスの型を確認**で調べてください。 |
| **上位ラベル** | 結果への寄与が大きいラベル値。 |
| **統計サマリー** | 全系列の値の分布。 |
| **カーディナリティ** | メトリクスのアクティブな系列と、スキャンした行数。系列を増やしすぎているラベルを特定できます。 |
| **結果のスキーマ** | 結果の時刻、値、ラベルの列。 |

インスタンスの[メトリクスのカーディナリティ上限](/ja/settings/platform#メトリクスのカーディナリティ)に達すると、新しい系列は受け付けられません。値の種類が多いラベルを追加する前に、**カーディナリティ**を確認してください。

## メトリクスの急増を関連付ける

急増が起きた時間範囲を選択し、サービスと環境のラベルを維持したまま、関連するトレースまたはログを開きます。MoleSignal は選択した時間範囲を移動先のシグナルに引き継ぎます。 [シグナル間の相関分析](/ja/correlation)を参照してください。

## 権限

メトリクスの一覧表示には `metrics.read` が必要です。PromQL の実行には `streams.query` が必要です。**ダッシュボードに追加**には `dashboards.create` が必要です。
