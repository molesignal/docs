| 用語 | 定義 |
|---|---|
| **アラート** | アラートルールの評価、エスカレーションの実行、スケジュールされたレポートの生成、コネクターの実行を担うロールです。[ロールベースのデプロイ](/ja/deployment/role-based)を参照してください。 |
| **APIトークン** | `mspat-<36>` 形式のベアラー認証情報です。ユーザーまたはサービスアカウントとして認証します。[IDとアクセス](/ja/identity)を参照してください。 |
| **APM** | アプリケーションパフォーマンスモニタリングです。トレースのスパンから、サービス、トランザクション、依存関係、エラー、バージョンごとに上限付きの集計を作成します。[APM](/ja/apm)を参照してください。 |
| **Arrow Flight SQL** | DBeaver、JDBC、ADBCなどのデータベースクライアント向けに、ポート `5083` で提供するSQLプロトコルです。デフォルトでは無効です。[データベースクライアントで接続](/ja/query/database-clients)を参照してください。 |
| **カタログ** | 各ストリームに属するParquetファイルとインデックスをPostgreSQLに記録したものです。 |
| **暗号化キー** | MoleSignalがPostgreSQLに保存するシークレットを暗号化する、`MS_CIPHER_KEY` のルートキーです。[本番環境のチェックリスト](/ja/deployment/production-checklist)を参照してください。 |
| **コンパクション** | 小さなParquetファイルをまとめて大きなファイルにする処理です。`compactor` ロールが、保持期間の管理とあわせて実行します。 |
| **コネクター** | 外部プラットフォームとのマネージド連携です。ソースは、スケジュールに従って外部プラットフォームからログを取得するか、外部プラットフォームが送信したログを受信します。宛先はパイプラインの出力を受け取ります。[コネクター](/ja/connectors)を参照してください。 |
| **データソース** | データソースカタログの項目です。1つのソースに対応するエンドポイント、トークン、設定スニペットを生成します。[データソース](/ja/intake)を参照してください。 |
| **エスカレーションポリシー** | 通知先の順序と、応答確認を待つタイムアウトを定めます。[アラート通知](/ja/alerting)を参照してください。 |
| **拡張テーブル** | キーからレコードを検索するルックアップテーブルです。パイプラインはこのテーブルを参照してイベントに情報を追加でき、行の書き込みもできます。[拡張テーブル](/ja/extend-tables)を参照してください。 |
| **フェデレーテッドクエリ** | `?clusters=local,<name>` で指定したリモートクラスターもスキャンするクエリです。[ロールベースのデプロイ](/ja/deployment/role-based)を参照してください。 |
| **フラッシュ** | 受信ノードのメモリ内バッファーの内容を、オブジェクトストレージにParquetファイルとインデックスとして書き出す処理です。 |
| **関数** | VRLまたはJavaScriptで記述する、再利用可能な変換処理です。[関数](/ja/functions)を参照してください。 |
| **インシデント** | アラートが発生すると作成され、応答確認と解決の段階を経ます。[アラート通知](/ja/alerting)を参照してください。 |
| **受信** | テレメトリーを受け取る経路です。テレメトリーの検証、バッファリング、フラッシュを担うロールも指します。[データソース](/ja/intake)を参照してください。 |
| **取り込みトークン** | データ送信元やデプロイパイプラインが使うトークンです。**データ取り込み**権限ポリシーに従い、`logs.write`、`metrics.write`、`traces.write`、`profiles.write`、`apm.deploy` の権限を持ちます。[データソース](/ja/intake#取り込みトークン)を参照してください。 |
| **ログ検査** | 指定期間のログについて、Mole Agentがオンデマンドまたはスケジュールに従って作成するレポートです。[ログ検査](/ja/logs/inspections)を参照してください。 |
| **Mole Agent** | ツールカタログを使って問題を調査する、組み込みの運用エージェントです。[Mole Agent](/ja/agent)を参照してください。 |
| **オンコールスケジュール** | タイムゾーンに対応し、オーバーライドを設定できる当番ローテーションです。エスカレーションの通知先として指定できます。[アラート通知](/ja/alerting)を参照してください。 |
| **組織** | テナントの分離とポリシー適用の単位です。Web UIではワークスペースと呼びます。[基本概念](/ja/concepts)を参照してください。 |
| **Parquet** | MoleSignalがログ、メトリクス、トレースを保存する列指向のファイル形式です。 |
| **パイプライン** | イベントをルーティング、正規化、マスキングし、追加情報を付与する一連の処理です。取り込み時にリアルタイムで実行するか、スケジュールに従って実行します。インシデントを作成する前にアラートイベントを変更する用途にも使います。[パイプライン](/ja/pipelines)を参照してください。 |
| **プラットフォーム管理者** | `[auth].root_email` で指定し、プラットフォーム全体の設定を管理するユーザーです。 |
| **プラットフォームストリーム** | `_audit` や `_synthetic_results` など、MoleSignalだけが書き込むストリームです。[ストリーム](/ja/streams#プラットフォームストリーム)を参照してください。 |
| **Probe Agent** | 特定のロケーションから外形監視チェックを実行するプロセスです。`standalone` ノードでは組み込みのエージェントが動作します。[外形監視](/ja/synthetics)を参照してください。 |
| **ロール** | `[node].roles` で指定するプロセスの役割です。`standalone`、`router`、`intake`、`querier`、`compactor`、`alert` から選択します。IAMでは、権限ポリシーとロール固有の権限を組み合わせた、名前付きの権限セットも指します。 |
| **RUM** | ブラウザーとモバイルアプリのセッションを対象とするリアルユーザーモニタリングです。[RUM](/ja/rum)を参照してください。 |
| **RUMクライアントトークン** | `rum.write` 権限を持ち、1つのアプリケーションに紐づくトークンです。ブラウザーやモバイルアプリのコードが送信します。 |
| **保存済みビュー** | 時間範囲とオプションを含めて保存したクエリです。 |
| **検索ジョブ** | 永続化する非同期クエリです。サイズのしきい値を超えるクエリは検索ジョブになり、**ストリーム → 検索ジョブ**に表示します。[クエリ](/ja/query)を参照してください。 |
| **自己テレメトリー** | MoleSignalが自身の動作について、予約済みの `_molesignal` ストリームに記録するメトリクス、トレース、プロファイルです。[自己オブザーバビリティ](/ja/self-observability)を参照してください。 |
| **サービスアカウント** | コレクターや自動化処理が使う、ユーザーに紐づかないIDです。サインインはできません。[IDとアクセス](/ja/identity)を参照してください。 |
| **サイレンス** | 条件に一致するアラートの通知を、指定した期間だけ停止するルールです。[アラート通知](/ja/alerting)を参照してください。 |
| **スタンドアロン** | すべてのロールを1つのプロセスで実行するデフォルトのロールです。 |
| **ステータスページ** | コンポーネントのステータスとインシデントを表示する、公開または非公開のページです。[ステータスページ](/ja/status-pages)を参照してください。 |
| **ストリーム** | シグナルの名前、タイプ、スキーマ、保持期間を定める、型付きのデータ仕様です。[ストリーム](/ja/streams)を参照してください。 |
| **ストリームタイプ** | `logs`、`metrics`、`traces`、`profiles`、`extend` のいずれかです。 |
| **外形監視モニター** | HTTPリクエストなどのチェックをスケジュールに従って実行し、可用性とレイテンシーを記録します。[外形監視](/ja/synthetics)を参照してください。 |
| **VRL** | Vector Remap Languageの略で、パイプラインの関数を記述する言語の1つです。 |
| **WAL** | 先行書き込みログです。受信確認済みのレコードをフラッシュするまで、オブジェクトストレージ内のオブジェクトに保持します。 |
| **ワークスペース** | Web UIで、選択中の組織を指す名称です。 |
