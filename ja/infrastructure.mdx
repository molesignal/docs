**インフラストラクチャ**には、サービスが実行されている場所が一覧表示され、それぞれがその名前を指定するサービス、ログ、メトリクスに関連付けられます。問題のあるノードからはその Pod 上のすべてのサービスをたどることができ、遅いサービスインスタンスからはそれが実行されている Pod とノードをたどることができます。

## エンティティの取得元

このページでは何も設定しません。プラットフォームは 5 分ごとに、直近 15 分間について 2 つのソースを読み取ります。

- APM がスパン内で認識したインスタンス。それぞれに、そのインスタンス上で実行されたサービスが含まれます。
- `host.name`、`k8s.node.name`、または `k8s.pod.name` フィールドを持つ最大 4 つのメトリクスまたはログストリームで、最大 2,000 の異なる場所のリソースフィールドを読み取ります。

これらのフィールドは OpenTelemetry のセマンティック規約に従います:

| 種類 | 名前を付けるフィールド | キー |
|---|---|---|
| クラスタ | `k8s.cluster.name` | クラスタ名。 |
| ノード | `k8s.node.name` | `cluster/node`。 |
| Pod | `k8s.pod.name` と `k8s.namespace.name` | `cluster/namespace/pod`。 |
| ホスト | `host.name`、Kubernetes 外のみ | ホスト名。 |
| コンテナ | `container.id` と `container.name` | コンテナ ID。 |

Pod 内では通常 `host.name` は Pod の名前を指すため、Pod、ノード、またはクラスタの名前を指定するデータからホストは作成されません。サービスは、スパンが指定する最も内側の場所で実行されます。すなわち Pod、それがなければホスト、それもなければノードです。Pod はノード上で実行され、ノードはクラスタの一部、コンテナは Pod の一部です。

Kubernetes のフィールドを埋めるには、OpenTelemetry Collector に `k8sattributes` プロセッサを追加し、 `resource` プロセッサで `k8s.cluster.name` を設定します。**データソース**ページの Kubernetes ガイドに両方の手順が記載されています。1 週間確認されなかったエンティティは破棄されます。

## 一覧

一覧には、過去 1 週間に確認されたすべてのエンティティが、最後に確認されたものから順に表示されます。緑色のドットは過去 30 分以内に確認された、つまり現在実行中のエンティティを示します。灰色のドットはそれ以前にのみ確認されたエンティティを示します。**サービス**には、そのエンティティ上で直接実行されているサービスの数が表示されます。種類で一覧を絞り込むか、名前またはキーで検索できます。どちらもアドレスに保持されます。

## エンティティのページ

エンティティを開くと、次の情報を確認できます:

- **実行環境**: そのノードとクラスタ、またはコンテナが属する Pod。
- **ここで実行**: クラスタのノード、ノードの Pod、Pod のコンテナ。
- **サービス**: そのエンティティ上、およびその上で実行されるものの上にあるサービス。それぞれ APM ページにリンクします。
- **サービスの変更**: 直近 24 時間におけるそれらのサービスの最新のデプロイおよびその他の変更。[変更](/ja/api/changes)を参照してください。
- **リソース属性**: 最後に確認されたときのフィールド。それぞれコピーできます。

**ログ**を開くと、Pod またはホストの直近 1 時間のログが表示されます。**メトリクス**を開くと、 `k8s.cluster.name`、`k8s.node.name`、`k8s.pod.name`、`host.name`、または `container.id` でその名前を持つメトリクスが表示されます。

[APM](/ja/apm) ページにあるサービスの**インスタンス**テーブルで**ワークロード / ホスト**セルを開くと、そのインスタンスが実行されている Pod またはホストが表示されます。

## 権限

これらのページと API には、`apm.services.read`、`metrics.read`、`logs.read`、またはシステムスコープでは `sys.telemetry.read` のいずれかが必要です。Mole Agent は `list_entities` と `get_entity` で同じデータを読み取ります。
