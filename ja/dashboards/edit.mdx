**ダッシュボード**で**新規ダッシュボード**を選択するか、ダッシュボードで**編集**を選択すると、エディターが開きます。ダッシュボードの作成には `dashboards.create` が必要で、変更には `dashboards.edit` が必要です。ダッシュボードは **編集可能**設定がオフの場合（組み込みのダッシュボードなど）は変更できません。代わりにコピーを作成してください。

## エディター

| コントロール | 用途 |
|---|---|
| **ダッシュボードに戻る** | エディターを離れます。 |
| ダッシュボードタイトル | ダッシュボードの名前をその場で変更します。 |
| **元に戻す** / **やり直す** | エディターを開いて以降の変更を元に戻す、またはやり直します。 |
| **追加** | **パネル**、**テキスト**、**行**、**グループ**、または**タブ**を追加します。 |
| **設定** | [ダッシュボード設定](#ダッシュボード設定)を開きます。 |
| **保存** | ダッシュボードを保存します。それまでは何も保存されません。 |

要素をハンドルでドラッグして移動し、角をドラッグしてサイズを変更します。要素を選択すると、サイドパネルで位置と構造を編集できます。新しいダッシュボードでは24列のグリッドを使用します。変更するには [設定 → 一般](#ダッシュボード設定)を使用します。

## 要素

| 要素 | 用途 |
|---|---|
| **パネル** | 1つ以上のクエリを可視化して描画します。 |
| **テキスト** | メモ、見出し、リンク用の静的な Markdown またはプレーンテキスト。 |
| **行** | その下の要素を保持する全幅のヘッダー。行は**初期状態で折りたたむ**ことができます。 |
| **グループ** | 関連する要素をまとめて保持するボックス。 |
| **タブ** | それぞれ独自の要素を持つ複数のタブ。最初に開くタブを選択します。 |

## パネルを編集

パネルのメニューで**編集**を選択するか、パネルを追加します。パネルエディターには**ライブプレビュー**が表示され、パネルには現在の時間範囲と変数が反映され、2組のタブがあります:

| タブ | 内容 |
|---|---|
| **クエリ**、**変換**、**データリンク** | パネルが読み取る内容、結果の整形方法、クリックしたときの遷移先。 |
| **パネル**、**フィールド**、**オーバーライド** | パネルの外観、値の表示方法、一部のフィールドに対する例外。 |

### クエリ

パネルのクエリごとに**クエリを追加**を選択します。各クエリには、`A` などの**参照 ID**、 **データソース**、**PromQL** または **SQL** の**言語**、および**式**があります。データソースはデフォルトの言語とその他のフィールドを決定します:

| データソース | デフォルトの言語 | その他のフィールド |
|---|---|---|
| **メトリクス** | PromQL | |
| **ログ**、**トレース**、**SQL** | SQL | **ストリーム名**と**ストリームタイプ**（**ログ**、**メトリクス**、または**トレース**）。 |
| **プロファイル** | SQL | **サービス**と**プロファイルタイプ**（例: `cpu`）。 |

**凡例**は `{{service}}` などのテンプレートで系列に名前を付けます。**共有クエリ**は、別のパネルのクエリを `<panel-id>:<ref-id>` と記述して再利用するため、データは一度だけ読み取られます。クエリでは [変数](/ja/dashboards/variables)（`$service` など）を使用できます。SQL と PromQL については、[クエリ](/ja/query)を参照してください。

`format` が `time_series` である SQL クエリは、[RUM エクスプローラー](/ja/rum/explorer#ダッシュボードに追加)が追加するパネルと同様に、時間とグループごとの行というロング形式で応答する場合があります。時系列は、テキスト列の値の組み合わせごとに系列を描画し、その値の組み合わせで名前を付けます。

### 変換

変換は、結果が描画される前に結果を整形します。変換は順番に実行され、それぞれを無効にできます。

| 変換 | 効果 |
|---|---|
| **フィールドの絞り込み**、**フィールドの整理**、**フィールド名を変更** | フィールドを保持、並べ替え、非表示、または名前変更します。 |
| **フィールドの計算** | 他のフィールドから計算したフィールドを追加します。 |
| **集約** | 各系列を最後の値、平均、最大、合計などの値に集約します。 |
| **グループ化の基準**、**並べ替えの基準**、**件数の上限** | フィールドで集計し、並べ替えて、先頭の行を保持します。 |
| **参加**、**統合** | 複数のクエリの結果を組み合わせます。 |
| **ラベルをフィールドに変換**、**行をフィールドに変換**、**時系列をテーブルに変換** | ラベル、行、または系列を列に変換します。 |

### パネルオプション

**パネル**タブでは、**タイトル**、ホバー時に表示される**説明**、**幅**と**高さ**、 **可視化**とそのオプション、パネルを**透明**にするかどうかを設定します。

| 可視化 | 描画内容 |
|---|---|
| **時系列** | 時間経過に伴う線、棒、または点。凡例、ツールチップ、塗りつぶし、積み重ねのオプションがあります。 |
| **棒グラフ** | カテゴリ別に比較した値。 |
| **バーゲージ** | 集約された値を水平または垂直のバーとして表示します。 |
| **統計値** | 最後の値など1つの値。オプションでスパークラインを表示します。 |
| **ゲージ** | しきい値の色を持つ放射状スケール上の1つの値。 |
| **テーブル** | ページング付きの行。 |
| **ログ** | 時刻とレベルを含むコンパクトなログ一覧。 |
| **ヒートマップ** | 時間経過に伴う値の強度。 |
| **状態タイムライン** | 時間経過に伴う状態の変化。 |
| **テキスト** | Markdown。 |

**繰り返しに使う変数**は、変数の値ごとにパネルのコピーを1つずつ、**繰り返し方向**を **水平**、**縦**、または**グリッド**にして、1行に最大**1行あたりの最大数**個のコピーまで描画します。詳細は [パネルの繰り返し](/ja/dashboards/variables#変数に応じてパネルを繰り返す)を参照してください。

### フィールドオプション

**フィールド**タブでは、値の表示方法を設定します:

| オプション | 用途 |
|---|---|
| **単位**、**小数点以下の桁数** | バイト、パーセント、秒などの単位と、小数点以下の桁数。 |
| **最小値**、**最大値** | スケールの両端。 |
| **表示名** | フィールドの名前を置き換えます。 |
| **カラースキーム** | 固定色、パレット、しきい値の色、または連続スケール。 |
| **しきい値** | 色が変わる値。**絶対値**または**パーセンテージ**モードで、**ベース**から開始します。 |
| **値のマッピング** | 値、範囲、正規表現の一致、または null などの特殊な値に対して、テキスト、色、またはアイコンを表示します。 |
| **値がない場合の表示テキスト** | 値がないときにパネルに表示する内容。 |

**オーバーライド**は、一部のフィールドにのみ他のフィールドオプションを適用します。**オーバーライドを追加**を選択し、マッチャー（**フィールド名**、**フィールドの正規表現**、**フィールドの型**、または**クエリ参照**）を選択して、変更するオプションごとに**プロパティを追加**し、変更します。

### データリンク

データリンクは、値のクリックをジャンプに変えます。**データリンクを追加**を選択し、**タイトル**を入力して、ターゲット（**ログ**、**メトリクス**、**トレース**、**プロファイル**、別の**ダッシュボード**、または**外部** URL）を選択します。リンクに時間範囲とダッシュボードの変数を含めるかどうか、新しいタブで開くかどうかを選択します。リンクはパネルのメニューに表示されます。

## ダッシュボード設定

**設定**には4つのタブがあります。

| タブ | 内容 |
|---|---|
| **一般** | **タイトル**、**説明**、**タグ**。デフォルトの時間範囲（**開始**、**終了**）と**タイムゾーン**。**グリッド**: 1～48の**列**、**行の高さ**、**間隔**。**更新**: **オフ**、**デフォルトの間隔**を指定した**実行間隔**、または**自動**。**グラフのツールチップ**: オフ、またはパネル間で共有される十字線。**編集可能**。 |
| **変数** | ダッシュボードの変数。[変数](/ja/dashboards/variables)を参照してください。 |
| **アノテーション** | 時系列パネルに描画されるイベント。 |
| **リンク** | ダッシュボードの上部にあるリンク。 |

アノテーションには、**名前**、**ソース**、**線**、**リージョン**、または**マーカー**の**表示**、 **色**、**有効**があります。**イベント**の下に**イベントを追加**でイベントを一覧表示します: **ラベル**、 **開始タイムスタンプ (ms)**、リージョンの場合は**終了タイムスタンプ (ms)**。

**デプロイ**ソースのアノテーションはイベントを一覧表示しません。これは、すべての時系列パネルに[変更一覧](/ja/api/changes)の変更（デプロイおよびその他の報告された変更、 APM が最初に検出したバージョンを含む）を、**サービス**（カンマ区切り）のサービスまたはすべてのサービスについてマークします。このダッシュボードに対して、またはダッシュボードを指定せずに [`POST /api/v1/changes`](/ja/api/changes#アノテーションを保持する) で保持されたアノテーションも、その時系列パネルにも描画されます。

リンクには、**タイトル**、**ダッシュボード**または**外部**の**タイプ**、**URL**、および **時間範囲**と**変数**を含めるか、**新しいタブ**で開くかどうかのスイッチがあります。

## 保存と再利用

**保存**を選択します。パネルを再利用するには、そのメニューで**コピー**を選択して JSON をコピーし、別のダッシュボードに貼り付けます。ダッシュボード全体を再利用するには、**JSONをエクスポート**して別の場所にインポートします。詳細は [ダッシュボードをインポート](/ja/dashboards#ダッシュボードをインポートする)を参照してください。
