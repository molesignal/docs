**ダッシュボード**で**新規ダッシュボード**を選択するか、ダッシュボードで**編集**を選択すると、エディターが開きます。ダッシュボードの作成には `dashboards.create`、変更には `dashboards.edit` が必要です。組み込みダッシュボードなど、**編集可能**がオフのダッシュボードは変更できません。代わりにコピーを作成してください。

## エディター

| 操作項目 | 用途 |
|---|---|
| **ダッシュボードに戻る** | エディターを閉じてダッシュボードに戻ります。 |
| ダッシュボードのタイトル | その場でダッシュボードの名前を変更します。 |
| **元に戻す** / **やり直す** | エディターを開いてからの変更を1つずつ元に戻したり、やり直したりします。 |
| **追加** | **パネル**、**テキスト**、**行**、**グループ**、**タブ**のいずれかを追加します。 |
| **設定** | [ダッシュボードの設定](#ダッシュボードの設定)を開きます。 |
| **保存** | ダッシュボードを保存します。この操作を行うまで、変更は保存されません。 |

要素を移動するにはハンドルをドラッグし、サイズを変更するには角をドラッグします。要素を選択すると、サイドパネルで位置や構造を編集できます。新規ダッシュボードは24列のグリッドを使います。列数は [設定 → 一般](#ダッシュボードの設定)で変更できます。

## 要素

| 要素 | 用途 |
|---|---|
| **パネル** | 1つ以上のクエリの結果を可視化します。 |
| **テキスト** | メモ、見出し、リンクを固定の Markdown またはプレーンテキストで表示します。 |
| **行** | 配下の要素をまとめる全幅のヘッダーです。**初期状態で折りたたむ**を設定できます。 |
| **グループ** | 関連する要素を1つの枠にまとめます。 |
| **タブ** | 複数のタブに要素を分けて配置します。最初に開くタブを選択できます。 |

## パネルを編集する

パネルのメニューで**編集**を選択するか、パネルを追加します。パネルエディターには、現在の時間範囲と変数を使ったパネルの**ライブプレビュー**と、2組のタブが表示されます。

| タブ | 内容 |
|---|---|
| **クエリ**、**変換**、**データリンク** | パネルが取得するデータ、結果の変換方法、クリック時の移動先を設定します。 |
| **パネル**、**フィールド**、**オーバーライド** | パネルの外観、値の表示方法、特定のフィールドに適用する例外を設定します。 |

### クエリ

パネルで使うクエリごとに**クエリを追加**を選択します。各クエリには、`A` などの**参照 ID**、 **データソース**、**PromQL** または **SQL** を指定する**言語**、**式**があります。データソースによって、デフォルトの言語とその他のフィールドが決まります。

| データソース | デフォルトの言語 | その他のフィールド |
|---|---|---|
| **メトリクス** | PromQL | |
| **ログ**、**トレース**、**SQL** | SQL | **ストリーム名**と**ストリームタイプ**（**ログ**、**メトリクス**、**トレース**のいずれか）。 |
| **プロファイル** | SQL | **サービス**と**プロファイルタイプ**（`cpu` など）。 |

**凡例**では、`{{service}}` などのテンプレートを使って系列に名前を付けます。**共有クエリ**では、別のパネルのクエリを `<panel-id>:<ref-id>` の形式で指定して再利用します。データの取得は1回だけです。クエリでは、 `$service` などの[変数](/ja/dashboards/variables)を使えます。SQL と PromQL については、[クエリの実行](/ja/query)を参照してください。

[RUM エクスプローラー](/ja/rum/explorer#ダッシュボードに追加)が追加するパネルのように、`format` が `time_series` の SQL クエリは、時刻とグループの組み合わせごとに1行を返す縦持ち形式で結果を返すことがあります。この場合、時系列の可視化では、テキスト列の値の組み合わせごとに系列を描画し、その値を系列名に使います。

### 変換

変換は描画前にクエリ結果を加工します。変換は設定順に実行され、個別に無効にできます。

| 変換 | 効果 |
|---|---|
| **フィールドの絞り込み**、**フィールドの整理**、**フィールド名を変更** | フィールドを選択、並べ替え、非表示にしたり、名前を変更したりします。 |
| **フィールドの計算** | 他のフィールドから計算したフィールドを追加します。 |
| **集約** | 系列ごとに、最終値、平均値、最大値、合計値などを求めます。 |
| **グループ化の基準**、**並べ替えの基準**、**件数の上限** | フィールドを基準に集計し、並べ替え、先頭の行だけを残します。 |
| **参加**、**統合** | 複数のクエリ結果を組み合わせます。 |
| **ラベルをフィールドに変換**、**行をフィールドに変換**、**時系列をテーブルに変換** | ラベル、行、系列を列に変換します。 |

### パネルオプション

**パネル**タブでは、**タイトル**、ホバー時に表示する**説明**、**幅**と**高さ**、 **可視化**の種類とそのオプション、パネルを**透明**にするかどうかを設定します。

| 可視化 | 表示内容 |
|---|---|
| **時系列** | 時間に沿って線、棒、点を描画します。凡例、ツールチップ、塗りつぶし、積み上げを設定できます。 |
| **棒グラフ** | カテゴリごとの値を比較します。 |
| **バーゲージ** | 集約した値を水平または縦のバーで表示します。 |
| **統計値** | 最終値などの単一の値を表示します。必要に応じてスパークラインも表示できます。 |
| **ゲージ** | 単一の値を円形の目盛りで表示し、しきい値に応じて色を変えます。 |
| **テーブル** | 行をページに分けて表示します。 |
| **ログ** | 時刻とレベルを含むログの一覧をコンパクトに表示します。 |
| **ヒートマップ** | 時間に沿って値の強度を表示します。 |
| **状態タイムライン** | 時間に沿って状態の変化を表示します。 |
| **テキスト** | Markdown を表示します。 |

**繰り返しに使う変数**を指定すると、変数の値ごとにパネルを1つ表示します。**繰り返し方向**で **水平**、**縦**、**グリッド**のいずれかを選択し、**1行あたりの最大数**で1行に表示するパネル数の上限を設定します。詳しくは[パネルの繰り返し](/ja/dashboards/variables#変数に応じてパネルを繰り返す)を参照してください。

### フィールドオプション

**フィールド**タブでは、値の表示方法を設定します。

| オプション | 用途 |
|---|---|
| **単位**、**小数点以下の桁数** | バイト、パーセント、秒などの単位と、小数点以下の桁数を設定します。 |
| **最小値**、**最大値** | スケールの下限と上限を設定します。 |
| **表示名** | フィールド名に代わる表示名を設定します。 |
| **カラースキーム** | 固定色、パレット、しきい値の色、連続カラースケールのいずれかを設定します。 |
| **しきい値** | **ベース**を起点として、色が変わる値を**絶対値**または**パーセンテージ**で設定します。 |
| **値のマッピング** | 特定の値、範囲、正規表現に一致する値、または null などの特殊な値に対応するテキスト、色、アイコンを表示します。 |
| **値がない場合の表示テキスト** | 値がないときにパネルに表示するテキストを設定します。 |

**オーバーライド**では、特定のフィールドだけに別のフィールドオプションを適用します。**オーバーライドを追加**を選択し、一致条件（**フィールド名**、**フィールドの正規表現**、**フィールドの型**、**クエリ参照**のいずれか）を選択します。変更するオプションごとに**プロパティを追加**を選択してください。

### データリンク

データリンクを設定すると、値をクリックして別の場所に移動できます。**データリンクを追加**を選択し、**タイトル**を入力します。リンク先には、**ログ**、**メトリクス**、**トレース**、**プロファイル**、別の**ダッシュボード**、または**外部** URL を選択します。時間範囲やダッシュボードの変数を引き継ぐかどうかと、新しいタブで開くかどうかを設定します。リンクはパネルのメニューに表示されます。

## ダッシュボードの設定

**設定**には4つのタブがあります。

| タブ | 内容 |
|---|---|
| **一般** | **タイトル**、**説明**、**タグ**を設定します。デフォルトの時間範囲（**開始**、**終了**）と**タイムゾーン**を設定します。**グリッド**では、**列**（1〜48列）、**行の高さ**、**間隔**を設定します。**更新**では、**オフ**、**デフォルトの間隔**を指定する**実行間隔**、**自動**のいずれかを選択します。**グラフのツールチップ**では、オフにするか、パネル間で十字カーソルを共有するかを選択します。**編集可能**も設定できます。 |
| **変数** | ダッシュボードの変数を設定します。[変数](/ja/dashboards/variables)を参照してください。 |
| **アノテーション** | 時系列パネルに描画するイベントを設定します。 |
| **リンク** | ダッシュボードのヘッダーに表示するリンクを設定します。 |

アノテーションでは、**名前**、**ソース**、**表示**形式（**線**、**リージョン**、**マーカー**のいずれか）、 **色**、**有効**かどうかを設定します。**イベント**で**イベントを追加**を選択し、**ラベル**と **開始タイムスタンプ (ms)** を入力します。リージョンの場合は**終了タイムスタンプ (ms)** も入力します。

リンクには、**タイトル**、**タイプ**（**ダッシュボード**または**外部**）、**URL**を設定します。 **時間範囲**や**変数**を引き継ぐかどうかと、**新しいタブ**で開くかどうかは、スイッチで切り替えます。

## 保存と再利用

**保存**を選択します。パネルを再利用するには、パネルのメニューで**コピー**を選択して JSON をコピーし、別のダッシュボードに貼り付けます。ダッシュボード全体を再利用するには、**JSONをエクスポート**を選択し、再利用先でインポートします。詳しくは[ダッシュボードをインポートする](/ja/dashboards#ダッシュボードをインポートする)を参照してください。
