変数を使うと、グリッドの上で選んだ値を、すべてのパネルのクエリ、タイトル、リンクに反映できます。サービス、ホスト、環境ごとにコピーを作らなくても、1つのダッシュボードで対応できます。

## 変数を追加する

エディターを開き、**設定 → 変数**を選択して変数を追加します。

| フィールド | ルール |
|---|---|
| **名前** | `service` など、クエリで使う名前です。英字、数字、`_` のみを使い、先頭は英字または `_` にしてください。このルールに従わない名前は置換されません。 |
| **ラベル** | セレクターの上に表示するテキストです。 |
| **タイプ** | 値の取得元です。[タイプ](#タイプ)を参照してください。 |
| **クエリ / オプション** | タイプに応じて、クエリまたは値を指定します。 |
| **複数選択** | 複数の値を一度に選択できます。 |
| **すべて含める** | リスト内のすべての値を表す **すべて** を追加します。 |
| **非表示にする** | **なし** はセレクターを表示し、**ラベル** はラベルを非表示にし、**変数** はセレクターを非表示にします。 |
| **更新** | クエリ変数の値を再取得するタイミングです。**無期限**、**読み込み時**、または **時間範囲** が変わるたびに更新する設定を選択します。 |

変数を保持するには、ダッシュボードを保存します。

## タイプ

| タイプ | 値 |
|---|---|
| **クエリ** | データから取得します。[クエリ変数](#クエリ変数)を参照してください。 |
| **カスタム** | 固定のリストです。`prod, staging, dev` のようにカンマ区切りで入力します。 |
| **テキスト** | グリッドの上にある入力欄に入力した値です。 |
| **定数** | ダッシュボードモデルに保持する固定値です。グリッドの上には表示されません。 |
| **実行間隔**、**データソース** | ダッシュボードモデルに保持するリストです。たとえば、インポートした JSON に含まれるリストです。 |

### クエリ変数

クエリ変数は現在の時間範囲から値を取得します。**クエリタイプ**を選択します。

| クエリタイプ | フィールド | 値 |
|---|---|---|
| **ラベル値** | `http_requests_total` と `service` など、**メトリクス**と**ラベル**を指定します。 | 指定したメトリクスを含むすべてのメトリクスストリームを対象に、そのメトリクスの時系列から指定したラベルの値を取得します。 |
| **クラシッククエリ** | `label_values(http_requests_total, service)` などの式です。 | **ラベル値**と同じです。 |
| **SQL** | **ストリーム名**、**ストリームタイプ**、SQL 文を指定します。 | 先頭列の値です。 |

最初の値がデフォルトになります。クエリでは別の変数を参照できます。たとえば、SQL 文に `WHERE environment = '$env'` を指定すると、選択した環境でサービスを絞り込めます。

## 変数を使う

クエリ、パネルタイトル、テキスト要素、リンクに `$name` または `${name}` を記述します。 `${service}_errors` のように変数名の直後に文字が続く場合は、波括弧で囲みます。複数の値を持つ変数は、値をカンマで連結します。区切り方や出力形式を変えるには、フォーマットを指定します。

| 構文 | `checkout` と `payment` を選択した場合の結果 |
|---|---|
| `${service}` | `checkout,payment` |
| `${service:csv}` | `checkout,payment` |
| `${service:pipe}` | `checkout\|payment` |
| `${service:regex}` | `checkout\|payment`。各値を正規表現用にエスケープします。 |
| `${service:sqlstring}` | `'checkout','payment'`。`IN (${service:sqlstring})` などで使えるように、各値を SQL 用に引用符で囲みます。 |
| `${service:json}` | `["checkout","payment"]` |

たとえば、PromQL パネルに `sum(rate(http_requests_total{service=~"${service:regex}"}[5m]))` を指定すると、選択したサービスがクエリに反映されます。

## URL 内の値

選択した値は、ダッシュボードの URL に `var-<name>=<value>` として保持されます。複数の値を持つ変数では、値ごとにこのパラメーターを繰り返します。URL をコピーするか、これらのパラメーターを含むリンクを作成すると、同じ値を選択した状態でダッシュボードを開けます。[データリンク](/ja/dashboards/edit#データリンク)を使って変数を引き渡すこともできます。

## 変数に応じてパネルを繰り返す

パネルの **パネル** タブで **繰り返しに使う変数** を選択します。ダッシュボードは、選択した値ごとにパネルのコピーを1つ表示し、各コピーで変数に対応する値を設定します。 **繰り返し方向**（**水平**、**縦**、**グリッド**）と **1行あたりの最大数** を選択します。保存するのは元のパネルだけです。コピーは選択した値に応じて表示されます。
