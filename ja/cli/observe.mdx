## メトリクスをクエリする

`molesignal metrics query` は PromQL の範囲クエリを実行し、時系列ごとに 1 行を出力します。各行には、指定期間内の最後の値、最小値、最大値と、スパークライン、ラベルが含まれます。

```bash
molesignal metrics query 'sum by (service) (rate(http_server_requests_total[5m]))' --since 6h
```

```text
LAST   MIN    MAX    TREND                           SERIES
12.4   3.1    14.9   ▁▂▂▃▅▆▇█▇▆▆▅▅▆▇▇█▇▆▅▄▄▅▅▆▆▇▇▇▆   {service="checkout"}
```

デフォルトの期間は直近 1 時間です。`--since`、`--from`、`--to` で変更できます。`-n` はデータポイント数の上限を指定します。デフォルトは `1000` です。`--json` は各時系列をデータポイントとともに出力し、`--csv` はデータポイントを 1 行ずつ出力します。

クエリの対象を探すには、次の 4 つのサブコマンドを使用します。

| コマンド | 一覧表示する内容 |
|---|---|
| `molesignal metrics names [text]` | 指定した文字列を含むメトリクス名。 |
| `molesignal metrics labels <metric>` | メトリクスのラベル。 |
| `molesignal metrics values <metric> <label>` | ラベルの値と、各値の出現回数。 |
| `molesignal metrics series <metric>` | メトリクスの時系列。`--match label=value` で絞り込めます。 |

## トレースを検索する

```bash
molesignal traces --service checkout --errors --since 6h
```

トレースを新しい順に一覧表示し、開始時刻、所要時間、スパン数、サービスを示します。

| オプション | 説明 |
|---|---|
| `--service <name>` | 指定したサービスのトレースのみを表示します。 |
| `--errors` | 失敗したスパンを含むトレースのみを表示します。 |
| `--min-duration <time>` | 所要時間が `500ms` などの指定値以上のトレースのみを表示します。 |
| `--since`, `--from`, `--to` | 対象期間を指定します。デフォルトは直近 1 時間です。 |
| `-n`, `--limit <count>` | 表示するトレース数を指定します。デフォルトは `20`、最大は `200` です。 |

## トレースを可視化する

`molesignal traces show` は、1 件のトレースをウォーターフォール形式で表示します。各スパンを親スパンの下に 1 行ずつ表示し、トレース内での実行タイミングと所要時間をバーで示します。失敗したスパンには `!` を付け、ターミナルでは赤色で表示します。

```bash
molesignal traces show 4bf92f3577b34da6a3ce929d0e0e4736
```

```text
checkout POST /orders          ████████████████████████████████████████  1.24s
├─ checkout SELECT orders       ███                                       98ms
└─ ! payments POST /charge         ███████████████████████████████████    1.1s
```

`--web` は MoleSignal でトレースを開き、`--json` はトレースのスパンを出力します。

## サービスの概要を表示する

```bash
molesignal services --env production --sort errors
```

APM サービスごとに、リクエスト数、エラー率、p95 レイテンシー、正常性、現在のバージョンを一覧表示します。`--sort` では `requests`、`errors`、`p95`、`name` のいずれかで並べ替えます。

`molesignal services show` は、1 つのサービスの概要を表示します。リクエストレート、エラー、レイテンシーに続いて、エンドポイント、依存関係、エラーの詳細、バージョンを表示します。

```bash
molesignal services show checkout --since 2h
```

## 2 つのバージョンを比較する

`molesignal services compare` は、同じサービスの 2 つのバージョンを並べて比較し、候補バージョンが悪化したか、改善したか、変化がなかったか、リクエスト数が少なく判定できなかったかを示します。 `--fail-on-regression` を指定すると、悪化を検出した場合に終了コード `1` を返すため、パイプラインでリリースを停止できます。

```bash
molesignal services compare checkout 2.3.9 2.4.0 --since 1h --fail-on-regression
```

## 長時間かかるクエリを検索ジョブとして実行する

検索ジョブは、その場で実行するクエリよりも多くのデータをより長い期間にわたって検索し、バックグラウンドで実行した結果を一定期間保持します。他の変更と同様に、ジョブの送信とキャンセルには組織のツールポリシーが適用されます。詳細は [インシデントと変更](/ja/cli/changes#変更の実行方法)を参照してください。

```bash
molesignal search-jobs submit "SELECT * FROM app_logs WHERE level = 'error'" --since 30d --wait
```

`FROM` の直後にある最初のストリームを使用します。`--stream` で別のストリームを指定できます。`--promql` は PromQL ステートメントを送信し、対象期間の終了時点、または `1m` などの `--step` で指定した間隔で評価します。`--limit` はジョブが保持する行数の上限（最大 `100000`）を指定し、`--keep` は保持期間を指定します。`--wait` はジョブの完了を待ちます。コマンドはジョブ ID を出力します。

| コマンド | 動作 |
|---|---|
| `molesignal search-jobs` | 検索ジョブのステータス、行数、ステートメントを一覧表示します。 |
| `molesignal search-jobs show <job>` | ジョブのステータス、行数、時刻情報、エラーを出力します。 |
| `molesignal search-jobs results <job>` | 完了したジョブの結果を、1 行につき 1 つの JSON オブジェクトとして出力します。`--csv` は CSV 形式で出力し、`-o <file>` はファイルに書き込みます。 |
| `molesignal search-jobs cancel <job>` | 待機中または実行中のジョブをキャンセルします。 |

## アクセス権限

メトリクスには `streams.query`、トレースには `traces.read`、APM には `apm.services.read`、検索ジョブには `query.jobs.read` と `query.jobs.run` が必要です。`sys.telemetry.read` では、`_sys` スコープでこれらすべてを読み取れます。組織のツールポリシーで該当するツールを有効にしておく必要があります。
