## ストリームを一覧表示する

```bash
molesignal streams
```

読み取り権限のあるログストリームを、フィールド数、保持期間、説明とともに一覧表示します。`--type` を指定すると、別の種類（`metrics`、`traces`、`profiles`、 `extend`）のストリームを一覧表示します。`--names` は名前だけを出力し、`--json` はストリームごとに1行のJSONを出力します。

## 最新のログを出力する

```bash
molesignal logs app_logs
```

このコマンドは、過去15分間の最新100件のログを、古い順に1行ずつ出力します。各行には時刻、レベル、サービス、メッセージが含まれます。

```text
2026-10-18 03:14:15.361 INFO  checkout order 4812 created
2026-10-18 03:14:25.361 ERROR payment gateway timeout after 3 retries
```

レベルは `level`、`severity`、`severity_text` などのフィールドから、サービスは `service` または `service.name` から、メッセージは `message`、`msg`、`body`、`log` のいずれかから取得します。メッセージフィールドがないログでは、ほかのフィールドを `name=value` 形式で表示します。ターミナルでは色付きで出力します。 `NO_COLOR` で色を無効にし、`FORCE_COLOR` でパイプに出力する場合も色を維持します。

| オプション | デフォルト | 説明 |
|---|---|---|
| `-n`, `--lines <count>` | `100` | 最初に出力する最新ログの件数です。最大 `5000` 件です。 |
| `--since <duration>` | `15m` | 現在からさかのぼる期間です。例: `30s`、`10m`、`2h`、`1d`、`1w`。 |
| `--from <time>`, `--to <time>` | なし | `--since` の代わりに時間範囲を指定します。ISO形式の日時、ローカル時刻の `2026-10-26 14:00`、または `2h` のように現在からさかのぼる期間を指定できます。 |
| `-q`, `--query <query>` | なし | **ログ**ページと同じ構文のフィールドクエリを指定します。 |
| `--where <condition>` | なし | ストリームのフィールドに対するSQL条件を指定します。 |
| `--fields <a,b,c>` | すべて | 時刻と、指定したフィールドだけを `name=value` 形式で出力します。 |
| `--json` | オフ | ログごとに1行のJSONを出力します。 |
| `--utc` | オフ | ローカル時刻の代わりにUTCで時刻を出力します。 |
| `--web` | オフ | ログを出力する代わりに、同じログを**ログ**ページで開きます。 |

## ログを絞り込む

`-q` には、**ログ**ページと同じ構文のフィールドクエリを指定します。 `level = 'error'`、`contains`、`MATCH`、`MATCH_TEXT` などの条件を `AND` や `OR` でつなぎ、括弧でグループ化できます。フィールドを指定しないテキストは `message` 内で検索します。

```bash
molesignal logs app_logs --since 1h -q "level = 'error' AND (service = 'payment' OR timeout)"
```

`--where` には、クエリの `WHERE` 句と同じように、ストリームのフィールドに対するSQL条件を指定します。

```bash
molesignal logs app_logs --where "status >= 500 AND duration_ms > 2000"
```

両方を指定すると、両方の条件を満たすログだけを出力します。存在しないフィールドを指定した場合やSQLが無効な場合は、理由を表示してコマンドを終了します。

## 新着ログを追跡する

```bash
molesignal logs app_logs -f
```

最新のログを出力した後、**Ctrl+C** を押すまで新着ログを出力し続けます。

- 2秒ごとにログを読み取ります。間隔は `--interval` で変更できます。
- 毎回、前回の読み取り範囲の終了時刻より10秒前から読み取ります。このため、 MoleSignal への到着が数秒遅れたログも表示します。同じログは1回だけ表示します。
- 1回で読み切れないほどログが集中した場合は、待たずに続けて読み取ります。
- 接続が切れると、待機時間を最大30秒まで徐々に延ばしながら再接続を試みます。CLIは接続の切断と復旧を標準エラー出力に通知します。

追跡にはログ自体のタイムスタンプを使います。現在の読み取り範囲の開始時刻より古いタイムスタンプを持つログが到着しても表示しません。`--to` と `-f` は併用できません。

## 指定時刻の前後のログを読む

`--around` は、指定時刻の直前と直後のログを出力し、その間に指定時刻を示す行を挿入します。`-B` と `-A` で前後の件数をそれぞれ指定します。デフォルトは各10件、上限は各250件です。`-q` と `--where` でログを絞り込めます。

```bash
molesignal logs app_logs --around "2026-10-26 14:03:12.345" -B 20 -A 20
```

`molesignal logs` の出力からコピーした時刻を `--around` に指定できます。

## ストリームに対してSQLを実行する

`molesignal query` は、式、結合、集計を含む読み取り専用のSQL文を1つ実行し、結果をテーブル形式で出力します。

```bash
molesignal query "SELECT level, COUNT(*) AS logs FROM app_logs GROUP BY level ORDER BY logs DESC"
```

デフォルトでは `FROM` の直後にある最初のストリームを使います。別のストリームは `--stream` で指定します。時間範囲はデフォルトで過去1時間です。`--since`、`--from`、`--to` で変更できます。`-n` で最大行数を指定します。デフォルトは `1000` 行で、上限は `5000` 行です。`--csv` はヘッダー行付きのCSVを出力し、`--json` は結果の各行を1行のJSONとして出力します。 `--web` はSQL文を**ログ**ページで開きます。

## ストリームのフィールドを確認する

```bash
molesignal fields app_logs
```

各フィールドを、型とインデックスとともに一覧表示します。フィールドを指定すると、過去1時間に最も頻繁に出現した値と、それぞれの出現回数を一覧表示します。

```bash
molesignal fields app_logs service --since 1d
```

`--match` は指定したテキストを含む値だけに絞り込み、`-n` は表示件数を指定します。デフォルトは `20` 件です。 `--type` を指定すると、別の種類のストリームを読み取ります。

## 出力をパイプで渡す

`--json` は、すべてのフィールドを含めて各ログを出力します。

```bash
molesignal logs app_logs -n 1000 --since 2h --json | jq -r .message
```

`head` など、パイプの受け取り側が途中で読み取りを終了すると、コマンドはメッセージを出さずに終了します。

## アクセス権限

CLIは、MoleSignal のツール `list_streams`、`query_logs`、`get_stream_schema`、 `search_field_values`、`search_around` を使って、サインイン中のユーザーまたはAPIトークンの所有者の権限でデータを読み取ります。`streams.query` 権限が必要です。また、組織のツールポリシーでこれらのツールが無効になっていないことを確認してください。
