MoleSignal CLI は、npm で `@molesignal/cli` として公開されている `molesignal` コマンドです。 MoleSignal インスタンスにサインインすると、次の操作ができます。

- ログの読み取りと追跡、SQL と PromQL の実行、トレースのウォーターフォール表示、 APM サービスの概要表示を行います。
- インシデントとオンコール担当者の一覧表示、インシデントの確認と解決、外形監視チェックの実行、承認済みの変更の適用を行います。
- CI でデプロイを報告し、RUM のソースマップとシンボルをアップロードし、スクリプトの出力をストリームに送信します。
- MoleSignal のカタログにある任意のツールを呼び出します。
- MoleSignal の MCP ツールを stdio 経由で提供します。Claude Code、Cursor、Codex、VS Code、 Gemini CLI から CLI を MCP サーバーとして起動できます。

データの読み取りと変更には MoleSignal のツールを使います。そのため、Mole Agent と同様に、サインインしたアカウントの権限、組織のツールポリシー、承認が CLI にも適用されます。デプロイの報告、デバッグ用アーティファクトのアップロード、ログの送信には、MoleSignal の API を使います。これらの操作には API トークンが必要です。

## 前提条件

- Node.js 20 以降。
- CLI を実行するマシンからアクセスできる MoleSignal インスタンスと、そのインスタンスのアカウント。

## インストール

```bash
npm install -g @molesignal/cli
```

インストールを確認します。

```bash
molesignal --version
```

各コマンドはインストールせずに実行することもできます。

```bash
npx -y @molesignal/cli --help
```

## はじめに

<Steps>
  <Step title="サインイン">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    ブラウザーで MoleSignal の認可ページが開きます。**認可**をクリックしてください。詳しくは[サインイン](/ja/cli/sign-in)を参照してください。
  </Step>
  <Step title="セットアップの確認">
    ```bash
    molesignal doctor
    ```
  </Step>
  <Step title="ログの読み取り">
    ```bash
    molesignal logs app_logs -f
    ```

    [ログの読み取りと追跡](/ja/cli/logs)を参照してください。
  </Step>
</Steps>

## コマンド

| グループ | コマンド |
|---|---|
| サインイン | `login`、`logout`、`profiles`、`use`、`status`、`whoami`、`doctor`。[サインイン](/ja/cli/sign-in)を参照してください。 |
| ログとクエリ | `streams`、`logs`、`query`、`fields`。[ログの読み取りと追跡](/ja/cli/logs)を参照してください。 |
| メトリクス、トレース、サービス | `metrics`、`traces`、`services`、`search-jobs`。[メトリクス、トレース、サービス](/ja/cli/observe)を参照してください。 |
| オンコールと変更 | `incidents`、`oncall`、`approvals`、`annotate`、`synthetics`。[インシデントと変更](/ja/cli/changes)を参照してください。 |
| リリースとデータ | `deploy`、`source-maps`、`symbols`、`send`、`run`。[CI とリリース](/ja/cli/ci)を参照してください。 |
| ツールとセットアップ | `tools`、`call`、`mcp`、`open`、`completion`。[任意のツールの呼び出し](/ja/cli/tools)と[stdio 経由での MCP の提供](/ja/cli/mcp)を参照してください。 |

`molesignal <command> --help` で、コマンドとそのオプションの説明を表示できます。すべてのオプションは[コマンドリファレンス](/ja/cli/reference)にも記載しています。
