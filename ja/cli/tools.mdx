CLI のコマンドは、よく使う操作に対応しています。MoleSignal のカタログにあるその他のツール（ RUM、プロファイリング、ステータスページなど）は、`molesignal call` で実行します。

## ツールを探す

```bash
molesignal tools incident
```

検索語に最もよく一致するツールが一覧に表示されます。一覧には、呼び出しの種類（`read` または `change`）、組織のツールポリシーに従った変更の実行方法、ツールの用途が表示されます。検索語を指定しない場合は、呼び出せるすべてのツールが表示されます。`--domain` を指定すると、 `observability` や `alerts_on_call` など、1 つのドメインに絞り込めます。

`molesignal tools show` は、指定したツールとそのツールが受け取る引数を JSON Schema 形式で出力します。

```bash
molesignal tools show list_rum_sessions
```

## ツールを呼び出す

```bash
molesignal call list_rum_sessions --since 1h limit=20
```

コマンドは、ツールの戻り値を JSON 形式で出力します。引数は次のように指定します。

| 指定方法 | 渡される値 |
|---|---|
| `name=value` | ツールのスキーマが要求する型の値。文字列、数値、`true` または `false`、あるいは `a,b` から作成したリストです。 |
| `name:=json` | `match:='{"service":"checkout"}'` のように、記述したとおりの JSON です。 |
| `parent.child=value` | `timeRange.startTime=…` のように、オブジェクト内のフィールドに値を渡します。 |
| `--input <file>` | ファイルから読み込んだ引数の JSON オブジェクトです。標準入力から読み込むには `-` を指定します。後ろに指定した引数のペアをオブジェクトに追加します。 |
| `--since`, `--from`, `--to` | `timeRange` を受け取るツールに対して、その値を設定します。 |

変更を加えるツールは、ツールポリシーに従って実行されます。詳しくは [変更の実行方法](/ja/cli/changes#変更の実行方法)を参照してください。`--reason`、`--wait`、`--timeout`、 `--yes` が適用されます。引数 `reason` または `impact` は、そのまま承認リクエストに渡されます。

```bash
molesignal call trigger_alert_rule rule_id=<rule> --reason "Testing the pager"
```

## ページを開く

`molesignal open` は、MoleSignal のページをブラウザーで開きます。ページ名を指定しない場合は、ホームページを開きます。

```bash
molesignal open logs app_logs
```

指定できるページは、`home`、`logs`、`metrics`、`traces`、`services`、`incidents`、`oncall`、 `synthetics`、`dashboards`、`approvals`、`jobs`、`streams`、`agent` です。ほとんどのページでは、トレース、インシデント、ダッシュボードなどの ID を指定できます。`--print` を指定すると、ページを開かずにアドレスを出力します。

`logs`、`query`、`traces show`、`incidents show`、`services show` で `--web` を指定すると、通常は出力する内容をブラウザーで開きます。

## シェルでコマンドを補完する

`molesignal completion` は、コマンド、サブコマンド、プロファイル、ストリーム名を補完するスクリプトを出力します。ストリーム名は数分に一度取得します。bash の場合：

```bash
echo 'source <(molesignal completion bash)' >> ~/.bashrc
```

zsh の場合：

```bash
echo 'source <(molesignal completion zsh)' >> ~/.zshrc
```

fish の場合：

```bash
molesignal completion fish > ~/.config/fish/completions/molesignal.fish
```
