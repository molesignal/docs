`molesignal mcp` は、stdio 経由で MoleSignal の MCP ツールを提供します。エージェントツールはコマンドを起動し、標準入力と標準出力で通信します。CLI はすべてのメッセージを MoleSignal の **インバウンド MCP** エンドポイントに転送し、すべての応答を返します。ツール、権限、承認は MoleSignal が管理します。CLI は独自のものを追加しません。

## エージェントツールにサーバーを追加する

まず[サインイン](/ja/cli/sign-in)し、次のコマンドで CLI をエージェントツールに追加します。

```bash
molesignal mcp setup claude
```

| エージェントツール | `molesignal mcp setup` による変更 |
|---|---|
| `claude` | Claude Code 用に `claude mcp add` を実行します。`--scope` には `user`（デフォルト）、`project`、`local` を指定できます。 |
| `cursor` | `~/.cursor/mcp.json` を変更します。`--scope project` を指定すると、現在のフォルダーの `.cursor/mcp.json` を変更します。 |
| `codex` | `~/.codex/config.toml` を変更します。`CODEX_HOME` を設定している場合は、その配下の `config.toml` を変更します。 |
| `vscode` | 現在のフォルダーの `.vscode/mcp.json` を変更します。 |
| `gemini` | `~/.gemini/settings.json` を変更します。`--scope project` を指定すると、現在のフォルダーの `.gemini/settings.json` を変更します。 |

このコマンドは `molesignal` という名前のサーバーを追加します。同じ名前のサーバーがあれば置き換え、ファイル内のほかの設定はすべて保持します。サーバーは `npx -y @molesignal/cli mcp` を実行します。`--installed` を指定すると、代わりにインストール済みの `molesignal` を実行します。`--profile` はサーバー設定にプロファイルを書き込みます。エージェントツールは、現在選択されているプロファイルに関係なく、指定したプロファイルのサインイン情報を使います。`--print` は設定を書き込まずに出力します。

[stdio 経由で接続する](/ja/inbound-mcp#stdio-で接続する)では、各ツールの設定を確認できます。 **Mole Agent → 設定 → インバウンド MCP** のセットアッププロンプトは、対象のインスタンスに合わせた手順を生成します。

ビルドマシンなど、サインインしない環境では、代わりに環境変数でサーバーに認証情報を渡します。

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"],
      "env": {
        "MOLESIGNAL_URL": "https://molesignal.example.com",
        "MOLESIGNAL_TOKEN": "<token>"
      }
    }
  }
}
```

## メッセージの転送の仕組み

- エージェントツールが `notifications/initialized` を送信するまでは、CLI がメッセージを受信順に 1 件ずつ転送します。MoleSignal は `initialize` への応答でセッションを開始します。その後、CLI はメッセージを受信するたびに転送するため、処理に時間がかかるツール呼び出しがほかの呼び出しを妨げることはありません。
- MoleSignal が再起動した場合など、セッションを認識できなくなったときは、CLI がエージェントツールから受け取った `initialize` を使って新しいセッションを開始し、メッセージを再送します。エージェントツールは再起動せずに処理を続けます。
- リクエストが MoleSignal に届かない場合、CLI はエラーを返します。エージェントツールが応答を待ち続けることはありません。
- エージェントツールが標準入力を閉じると、CLI は MoleSignal 側のセッションを終了してから、自身も終了します。
- CLI は、接続の切断通知など、利用者向けのメッセージを標準エラー出力に書き込みます。標準出力には MCP メッセージだけを出力します。
- ほかのコマンドと同様に、`HTTPS_PROXY` と `NO_PROXY` が適用されます。

## 接続を確認する

```bash
molesignal status
```

表示されるツール数は、エージェントツールから見えるツール数と一致します。0 件の場合は通常、組織のツールポリシーまたはユーザーの権限によって、利用できるツールがないことを示します。
