**設定 → 一般**を開きます。このページの閲覧には `org.preferences.read` が必要です。変更には `org.preferences.manage` が必要です。ただし、公開共有セクションでは代わりに `org.sharing.read` と `org.sharing.manage` が必要です。各セクションは、変更から少し経つと自動で保存されます。**元に戻す**で直前の変更を取り消し、**再試行**で失敗した変更を再送信します。

## 組織情報

| フィールド | ルール |
|---|---|
| **組織名** | ワークスペース切り替えメニュー、ページタイトル、招待に表示します。必須です。 |
| **ロゴ** | ワークスペース切り替えメニューに MoleSignal のロゴの代わりに表示します。**アップロード**では PNG、JPEG、WEBP、SVG のいずれかの画像を指定でき、画像は 128 × 128 にリサイズされます。**削除**すると MoleSignal のロゴに戻ります。変更はすぐに保存されます。 |
| **説明** | ワークスペースの用途を1〜2文で記述します。ワークスペースメニューに表示します。最大120文字です。 |
| **組織スラッグ** | 読み取り専用です。API とリソース識別子で使用します。**コピー**で値をコピーします。 |
| **組織ID** | 読み取り専用です。API、監査記録、サポートで使用します。**コピー**で値をコピーします。 |

組織の作成後、組織スラッグと組織IDは変更されません。

## 既定設定

**組織の既定設定**は、個人設定を保存していないメンバーに適用されます。個人の[設定](/ja/account#設定)と、クエリページで変更した時刻表示が優先されます。

| セクション | フィールド |
|---|---|
| 外観 | **既定のテーマ**、**表示密度**。 |
| 言語と地域 | **言語**、**既定のタイムゾーン**、**日時形式**。 |
| 起動時の動作と操作 | **ワークスペースに入ったときに開くページ**、**キーボードショートカットを有効にする**。 |

## 登録とアクセス

| 設定 | 効果 |
|---|---|
| **セルフサービスでの参加を許可** | インスタンスの登録要件を満たしていれば、このワークスペースに自分で参加できます。 |
| **管理者の承認を必須にする** | 参加申請は、管理者が承認するまで[承認](/ja/identity/members#承認)に保留されます。セルフサービスでの参加が有効な場合に表示されます。インスタンスからメールを送信できない間は、メールアドレスを確認できないため、この設定は有効のままです。無効にするには、`[notify.smtp]` と `[http].external_url` を設定してください。 |
| **組織の既定ロール** | セルフサービスで参加したメンバーに割り当てる IAM カタログのロールです。シングルサインオンでは、一致するロールマッピングがなく、プロバイダーにも既定のロールがない場合に、このロールを使用します。 |

## 共有とパブリックアクセス

これらの設定は、メンバーが作成できる[制限付き公開リンク](/ja/resource-sharing)を制限します。ワークスペース内および他の組織との共有には、常にサインインが必要です。

| 設定 | 効果 |
|---|---|
| **公開リンクを許可** | メンバーは、許可されたリソースをアカウントなしで開ける制限付きリンクを作成できます。以下の設定を使うには、この設定を有効にしてください。 |
| **ライブダッシュボードの公開を許可** | ライブダッシュボードへの公開リンクを許可します。公開ビューは読み取り専用で、クエリ、変数、時間範囲、ナビゲーションに制限があります。 |
| **公開リンクの最長有効期間** | **1日**、**7日間**、**30日**のいずれかです。リンクの作成時に、この期間を超える有効期限は指定できません。 |
| **公開レポートにパスワードを必須にする** | パスワードの確認が済んだ場合にのみ、公開レポートの短時間の共有セッションを開始します。 |
| **本番環境のリソースの公開共有をブロック** | `production` または `prod` タグが付いたリソースへの公開リンクを許可しません。 |
| **CSVの一般公開ダウンロードを許可** | 無効にすると、公開 CSV レポートはアクセスが制限されたページでのプレビューのみ可能になります。 |

## 組織のライフサイクル

`org.delete` を持つメンバー（既定ではオーナー）は、このページで組織の名前を入力して削除できます。すべてのメンバーがその組織からサインアウトされ、削除は元に戻せません。この権限がない場合は、**組織管理を開く**で `_sys` 組織に切り替えます。そこで組織を削除するには `sys.organizations.delete` が必要です。 [組織管理](/ja/settings/platform#組織管理)を参照してください。
