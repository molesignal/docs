**アカウント設定**では、ワークスペース全体ではなく、メンバー個人の設定を管理します。上部バーのユーザーアバターを開き、**アカウント設定**、**設定**、**通知**のいずれかを選択します。すべてのメンバーが自分のアカウント設定を変更できます。権限が必要なのは **API トークン** だけです。

| グループ | セクション | 用途 |
|---|---|---|
| 個人設定 | **プロフィール** | 表示名、アバター、簡単な自己紹介です。 |
| | **設定** | テーマ、表示密度、タイムゾーン、日付形式、開始ページ、キーボードショートカットを設定します。 |
| | **通知** | 個人の通知方法、配信順序、通知の一時停止時間帯を設定します。 |
| セキュリティとアクセス | **セキュリティとサインイン** | パスワードのリセットと、リンクされたサインイン方法の管理を行います。 |
| | **アクティブセッション** | 現在のブラウザーのセッションを確認します。 |
| | **API トークン** | メンバー本人として操作する個人用 API トークンを管理します。 |
| ワークスペース | **ワークスペースと識別** | ワークスペース、ロール、自動化に使う識別子を確認します。 |

## プロフィール

| フィールド | 説明 |
|---|---|
| **表示名** | 他のメンバーに表示する名前です。 |
| **サインイン用メール** | 読み取り専用です。管理者または ID プロバイダーが管理します。 |
| **自己紹介** | 任意です。最大500文字です。 |
| アバター | **アバターを変更**で、最大2 MBの PNG、JPEG、WebP 画像をアップロードできます。**削除**を選択するとイニシャル表示に戻ります。 |

**変更を保存**を選択してプロフィールを保存します。

## 設定

個人の設定は、[ワークスペースの既定値](/ja/settings/organization#既定設定)よりも優先されます。調査中は、クエリページでその調査の時刻表示を変更できます。

| セクション | フィールド | 選択肢 |
|---|---|---|
| 外観 | **既定のテーマ** | **システム**、**ライト**、**ダーク**から選択します。 |
| | **表示密度** | **ゆったり**または**コンパクト**を選択します。コンパクトにすると、テーブル、ログ一覧、ナビゲーション、設定画面の行の高さや余白が小さくなります。チャート、コード、会話の表示は変わりません。 |
| 時刻と地域 | **既定のタイムゾーン** | **ブラウザーのタイムゾーン**または特定のタイムゾーンを選択します。ダッシュボード、ログ、メトリクス、トレースは、選択したタイムゾーンで時刻を表示します。 |
| | **日時形式** | 日付は `2026-07-27`、`2026/07/27`、`27/07/2026`、`07/27/2026` から、時刻は**24時間制**または**12時間制**から選択します。 |
| 起動と操作 | **ワークスペースに入ったときに開くページ** | **ホーム**、**最後に表示したページ**、**ダッシュボード**、**ログ**、**メトリクス**、**トレース**、**アラートインシデント**、**Mole Agent**、または特定のダッシュボードを選択します。 |
| | **キーボードショートカットを有効にする** | [グローバルショートカット](/ja/console#キーボードショートカット)のオンとオフを切り替えます。 |

**設定を保存**を選択します。変更を保存せずにページを離れると、変更を破棄するかどうかの確認が表示されます。インターフェースの言語はこのページではなく、ユーザーメニューの**言語**で選択します。

## 通知

**通知**には、現在のワークスペースでメンバーに通知を届ける方法と、 MoleSignal がそれらを試す順序が表示されます。

<Steps>
  <Step title="通知方法を登録する">
    **通知方法を登録**を選択します。管理者が [設定 → 通知 → コネクター](/ja/notification-channels)で設定した**コネクター**を選択し、 **外部識別子**を入力します。メールアドレス、IM プラットフォームのユーザー ID、または音声通話や SMS 用の電話番号を指定します。電話番号には `+` と国番号を付けます。最後に**ラベル**を入力します。
  </Step>
  <Step title="通知方法をテストする">
    通知方法の**テスト送信**を選択します。メッセージが届けば、コネクターが外部識別子を受け付けたことを確認できます。
  </Step>
  <Step title="管理者に検証を依頼する">
    通知方法が有効で、検証済みの場合にのみ通知を配信します。 `org.members.update` を持つ管理者が、外部識別子が対象メンバーのものであることを確認し、通知方法の**検証**を選択します。
  </Step>
  <Step title="カテゴリに通知方法を設定する">
    **配信設定**で、**アラートイベント**、 **オンコールイベント**、または**レポート**の**このカテゴリの通知を受信**をオンにし、**エンドポイントを上に移動**と **エンドポイントを下に移動**で通知方法の順序を設定します。
  </Step>
</Steps>

**アラートイベント**には、**緊急度の高いアラートの通知順序**と**緊急度の低いアラートの通知順序**があります。インシデントの[緊急度](/ja/alerting/on-call#緊急度)に応じて使い分けます。緊急度の低いアラートのステップを設定していない場合は、緊急度の高いアラートの最初の通知方法だけを使います。どちらの順序でも、2番目以降のステップには実行までの待機時間を分単位で指定できます。後続のステップでメンバーに通知するのは、その時点でアラートに誰も応答していない場合だけです。直前のステップと待機時間が同じ場合は、直前のステップで送信に失敗したときだけ実行します。詳細は [誰も応答しない場合に次へ進む](/ja/notification-channels#応答がなければ次のステップに進む)を参照してください。

**通知の一時停止時間帯を有効化**をオンにすると、選択した**タイムゾーン**で、**開始**から **終了**まで（`HH:MM`）、そのカテゴリの通知をメンバーに配信しません。停止中の通知は後からも配信しません。アラートイベントでは、緊急度の低いアラートはこの時間帯に配信しません。**通知を抑制する時間帯も緊急度の高いアラートを受信**をオンにすると、緊急度の高いアラートは配信します。通知方法を削除する前に、すべての配信設定からその方法を外してください。

オンコールスケジュールに登録されていてもアラートを受信する方法がない場合は、このページと [ホームページ](/ja/home)のオンコールカードにお知らせが表示されます。詳細は [アラートを受信できないメンバー](/ja/alerting/on-call#アラートを受信できないメンバー)を参照してください。

MoleSignal は、チームや組織のフォールバック経路より先に、個人の配信順序に従って通知を試みます。詳細は [通知チャネルと配信](/ja/notification-channels)を参照してください。

## セキュリティとセッション

**セキュリティとサインイン → パスワードを変更**を選択すると、サインイン用メールにパスワードリセット用のリンクを送信します。リンクの使い方は[サインイン](/ja/console#サインイン)を参照してください。

**リンクされたサインイン方法**には、アカウントへのサインインに使うシングルサインオンの ID と、各 ID のワークスペースおよび最終使用日時が表示されます。**リンク解除**を選択すると、その ID でアカウントにサインインできなくなります。同じ ID でもう一度サインインすると、 [既存のアカウントをリンクする](/ja/identity/sso#既存のアカウントを連携する)で説明する確認が求められます。パスワードを設定していないアカウントでは、最後に残った ID のリンクを解除できません。

**認証アプリ**と**パスキー**では、パスワードに加えて追加の認証を行います。パスキーではパスワードなしでもサインインできます。設定方法、リカバリーコード、第2要素を失ったときの対処については、 [多要素認証とパスキー](/ja/identity/mfa)を参照してください。

**アクティブセッション**には、現在のブラウザーのセッションが表示されます。**このデバイスをサインアウト**を選択すると、そのセッションが終了します。 **他のすべてのデバイスをサインアウト**を選択すると、他のブラウザーやコンピューターでのセッションがすべて終了し、現在のブラウザーではサインインしたままになります。

**API トークン**には個人用トークンが表示され、**新しいトークン**で新規発行できます。トークンは発行したメンバーとして操作し、操作時点でそのメンバーに許可されている範囲を超えることはありません。スコープで操作範囲をさらに絞り込めます。このセクションを利用するには `personal_tokens.manage` が必要です。すべての組み込みロールにこの権限が含まれます。詳細は [API トークンとサービスアカウント](/ja/identity/tokens)を参照してください。

## ワークスペースと識別

**ワークスペースと識別**には、アカウントが所属するワークスペースと、それぞれのロールおよびステータスが表示されます。**切り替え**を選択すると、現在のワークスペースが切り替わります。プラットフォーム管理者が無効にしたワークスペースは開けません。

**高度な情報**には、現在のワークスペースの**ユーザー ID**、**組織ID**、 **組織スラッグ**が表示され、それぞれ**コピー**でコピーできます。これらの値は、スクリプト、API 呼び出し、リソースパスで使用します。
