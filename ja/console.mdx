MoleSignal のすべてのページは、全機能のメニューを備えたトップバーとコンテンツで構成される共通のレイアウトを使います。このページでは、共通の操作項目について説明します。このマニュアルの残りの部分では、各機能のページについて説明します。

## サインイン

MoleSignal インスタンスのアドレスを開き、次のいずれかの方法でサインインします。

| 方法 | 手順 |
|---|---|
| メールアドレスとパスワード | **メールアドレスでサインイン**を選択し、メールアドレスを入力して**続行**を選択した後、パスワードを入力します。他に利用できる方法がない場合は、最初からメールアドレスの入力欄が表示されます。 |
| シングルサインオン | 有効なプロバイダーの行を選択します。LDAP プロバイダーの場合は、ディレクトリのユーザー名とパスワードを順に入力します。[シングルサインオン](/ja/identity/sso)を参照してください。 |
| パスキー | **パスキーで続行**を選択します。[多要素認証](/ja/identity/mfa)を参照してください。 |
| アカウント登録 | **アカウント登録 →** は、インスタンスでセルフ登録を許可している場合にのみ表示されます。メールを送信できるインスタンスでは、メールアドレスを入力し、メールに記載されたリンクを開いてから名前とパスワードを入力します。リンクの有効期限は 30 分です。新しいアカウントですぐにサインインできる場合と、管理者の承認が必要な場合があります。メールを送信できないインスタンスでは、メールアドレス、名前、パスワードをまとめて入力します。新しいアカウントには管理者の承認が必要です。ページは、メールアドレスに対応するアカウントの有無にかかわらず、同じ応答を返します。 |

ページは、このブラウザーで前回使用したサインイン方法とアカウントを記憶し、該当する行に **最終使用日時**を表示します。パスワードは記憶しません。メールアドレスとパスワードでサインインした後は、最上部に **メールアドレスで続行**が追加され、パスワード入力に直接進めます。

パスワードを忘れた場合は、**パスワードをお忘れですか？**を選択し、アカウントのメールアドレスを入力します。ページは、メールアドレスの登録有無にかかわらず、同じ応答を返します。メールに記載されたリンクの有効期限は 30 分で、使用できるのは 1 回だけです。新しいパスワードは 8 文字以上である必要があります。1 つのアドレスに届く登録メールとパスワードリセットメールは、合計で 1 時間に最大 5 通です。

パスワードの入力を何度も間違えると、ページに待機時間が表示されます。 [サインインの制限](/ja/settings/platform#サインイン制限)を参照してください。

サインイン後、MoleSignal は個人の [設定](/ja/account#設定)の**ワークスペースに入ったときに開くページ**で選択したページを開きます。既定では**ホーム**を開きます。

## ワークスペースを選択する

UI では、選択中の組織を**ワークスペース**と呼びます。トップバーの左側にあるワークスペース切り替えには、ワークスペースのロゴと名前が表示されます。独自の [ロゴ](/ja/settings/organization#組織情報)がないワークスペースには、 MoleSignal のロゴが表示されます。

ワークスペース切り替えを選択すると、ワークスペースメニューが開きます。メニューの先頭には、ワークスペース名、そのワークスペースでのアカウントのロール、ワークスペースの説明が表示されます。 **組織設定**を選択すると**設定 → 一般**が開き、**メンバー**を選択するとワークスペースのメンバー一覧が開きます。**切り替え先**には、アカウントが所属するほかの組織が、それぞれのロゴまたは頭文字とともに表示されます。組織を選択すると、その組織に切り替わります。**組織の管理…**は、組織を管理するアカウントに表示されます。

ワークスペースを切り替えると、切り替え先の組織でのアカウント権限が読み込まれます。切り替え先のロールで利用できないページは、ナビゲーションに表示されなくなります。

<Note>
  UI では**ワークスペース**と表示します。API フィールドと権限キーには `organization` と `org_id` を使用します。
</Note>

## トップバー

| 操作項目 | 用途 |
|---|---|
| ワークスペース切り替え | 現在のワークスペースのロゴと名前を表示し、[ワークスペースメニュー](#ワークスペースを選択する)を開きます。 |
| メニュー | 全機能の[メニュー](#メニュー)を開きます。 |
| 検索ボックス | [コマンドパレット](#コマンドパレットで検索する)を開きます。 |
| Mole Agent | どのページからでも [Mole Agent](/ja/agent) パネルを開きます。Mole Agent を利用できるアカウントに表示されます。 |
| **NOC ウォールボード** | 大画面向けのウォールボードモードを開きます。[NOC ウォールボード](/ja/dashboards#noc-ウォールボード)を参照してください。 |
| **通知** | 承認待ちのアカウント登録とステータスページの下書き、および対応が必要なステータスページの自動化を一覧表示します。ベルの数字は未読件数を示し、最大で **99+** と表示します。 |
| **ヘルプ** | このドキュメント、キーボードショートカット、インスタンスのバージョンを確認できる**製品情報**を開きます。 |
| テーマ | ダークテーマとライトテーマを切り替えます。選択内容はアカウントに保存されます。 |
| ユーザーアバター | **アカウント設定**、**設定**、**通知**、**言語**、**サインアウト**を開きます。**サインアウト**を選択すると、ブラウザーのすべてのタブでセッションが終了します。 |

## メニュー

トップバーのワークスペース切り替えの右にあるメニューボタンにポインターを合わせるか、ボタンを選択すると、すべての機能をまとめたメニューがページに重なって開きます。メニューでは、このマニュアルと同じグループに機能を分類しています。

| グループ | 機能 | 用途 |
|---|---|---|
| ホーム | [**ホーム**](/ja/home) | インシデント、ルール、サービス、チェック、エラー率とレイテンシー、データ取り込み、オンコールなど、システムの状態を確認します。 |
| オブザーバビリティ | [**ダッシュボード**](/ja/dashboards) | チームで確認するパネルと変数をまとめます。 |
| | [**メトリクス**](/ja/metrics) | PromQL を使い、時系列、カーディナリティ、データ品質を確認します。 |
| | [**ログ**](/ja/logs) | イベントを検索し、フィールドを調べ、イベントのコンテキストを開きます。 |
| | [**トレース**](/ja/traces) | トレースを検索し、スパンを調べ、2 つのトレースを比較します。 |
| | [**APM**](/ja/apm) | サービスの健全性、エンドポイント、依存関係、エラー、SLO、デプロイを確認します。 |
| | [**RUM**](/ja/rum) | セッション、リプレイ、フロントエンドエラー、Web Vitals、分析結果を確認します。 |
| | [**プロファイル**](/ja/profiles) | CPU、メモリ、競合のフレームグラフを確認します。 |
| 信頼性 | [**アラート**](/ja/alerting) | インシデント、ルール、オンコールスケジュール、エスカレーション、サイレンスを管理します。 |
| | [**外形監視**](/ja/synthetics) | プローブの拠点からスケジュールに沿ってチェックを実行します。 |
| | [**ステータスページ**](/ja/status-pages) | インシデントやメンテナンスの情報を顧客向けに公開します。 |
| AI 運用 | [**Mole Agent**](/ja/agent) | チャットや調査を行い、自動化、ナレッジ、スキルを活用します。 |
| データ | [**データソース**](/ja/intake) | データソースを接続し、データが届くことを確認します。 |
| | [**ストリーム**](/ja/streams) | スキーマ、保持期間、検索ジョブを管理します。 |
| | [**パイプライン**](/ja/pipelines) | データの変換、ルーティング、バックフィルを行います。 |
| | [**関数**](/ja/functions) | VRL や JavaScript で記述した変換処理を再利用します。 |
| | [**テーブルを拡張**](/ja/extend-tables) | ルックアップテーブルを使ってイベントに情報を追加します。 |
| コラボレーション | [**レポート**](/ja/reports) | レポートをスケジュール設定し、共有します。 |
| 管理 | [**ID とアクセス**](/ja/identity) | ユーザー、ロール、グループ、チーム、トークン、シングルサインオンを管理します。 |
| | [**設定**](/ja/settings) | ワークスペース、通知、データ、セキュリティ、プラットフォームを設定します。 |

メニューには、アカウントの権限で利用できる機能だけが表示されます。メニューで機能を非表示にしても、サーバー側での権限チェックは引き続き行います。

メニューの左側にある**最近の項目**には、最近開いた機能が新しい順に表示されます。現在開いている機能は含まれません。一覧はアカウントに保存されるため、別のブラウザーでも表示されます。

項目を選択すると、現在のタブで開きます。新しいタブで開くには、Ctrl キーを押しながらクリック（Mac では ⌘ キーを押しながらクリック）するか、中クリックします。項目にポインターを合わせ、末尾の矢印を選択することもできます。メニュー下部の**常に新しいタブで開く**を有効にすると、すべての項目が新しいタブで開きます。この設定はアカウントに保存されます。

ポインターを合わせて開いたメニューは、ポインターがボタンとメニューの両方から離れると閉じます。開いたままにするには、メニューが開いている間にボタンを選択します。閉じるには、Esc キーを押すか、メニューの外側を選択するか、メニューボタンをもう一度選択します。幅の狭い画面では、メニューはトップバーの下の領域全体に表示されます。

## 時間のコンテキストを保持する

クエリページの上部にある時間範囲ピッカーで、ページの時間範囲を設定します。

- ピッカーの下部には、ページ内の時刻に適用されるタイムゾーンが表示されます。**変更**で別のタイムゾーンを選ぶまでは、個人のデフォルトタイムゾーンが適用されます。選択したタイムゾーンは、ページ単位で、ログ、トレース、メトリクスではクエリタブ単位で保持されます。**個人のデフォルトタイムゾーンに設定**で、選択したタイムゾーンを個人のデフォルトに設定します。
- 別のシグナルに移動すると、時間範囲を保持したまま、移動元の識別子を追加します。たとえば、トレースから関連するログに移動すると、トレースの時間範囲を保持したまま、`trace_id` フィルターを追加します。
- 現在時刻をアンカーとして固定したり、現在の調査へのリンクを時間範囲付きでコピーしたりするには、コマンドパレットまたは[ショートカット](#キーボードショートカット)を使用します。

## コマンドパレットで検索する

`⌘K`または`Ctrl+K`を押すか、検索ボックスを選択します。入力して、次の項目を検索します。

- ページ、ストリーム、サービス、ダッシュボード、保存済みビュー、アラートルール、インシデント。
- 操作：ページへの移動、SQLやPromQLの実行、時間範囲を直近5分から直近7日までの範囲に設定、現在時刻の固定、調査リンクのコピー、テーマや表示密度の切り替え、設定を開く、ダッシュボードやアラート、パイプラインの作成、データソースの接続、キーボードショートカットの表示、サインアウト。

`Enter`を押すと、検索結果が開きます。パレットの下部には、検索結果を新しい [調査スタック](/ja/correlation#ui-の調査スタック)で開くか、現在のスタックの一番上に追加するためのキーが表示されます。

## キーボードショートカット

`⌘/`または`Ctrl+/`を押すか、**ヘルプ → キーボードショートカット**を開くと、ショートカットの一覧が表示されます。Windowsと Linuxでは、`⌘`の代わりに`Ctrl`、`⌥`の代わりに`Alt`を使用します。

| ショートカット | 操作 |
|---|---|
| `⌘K` | コマンドパレットを開きます。 |
| `⌘/` | キーボードショートカットを表示します。 |
| `⌘J` | Mole Agentパネルを開くか閉じます。 |
| `⌘⌥E` | 時間範囲ピッカーを開きます。 |
| `⌘⌥P` | 時刻アンカーを固定または固定解除します。 |
| `⌘⌥Y` | 調査リンクをコピーします。 |
| `⌘[` / `⌘]` | 調査スタック内で前後に移動します。 |
| `⌘⌥S` | APMサービスに移動します。 |
| `⌘⌥A` | アラートインシデントに移動します。 |
| `⌘⌥D` | ダッシュボードに移動します。 |
| `⌘⌥T` / `⌘⌥L` | トレース検索またはログ検索を調査スタックで開きます。 |
| `⌘⌥R` | RUMの概要に移動します。 |
| `⌘⌥F` | 関数に移動します。 |
| `⌘⌥I` | IDとアクセスに移動します。 |
| `⌘Esc` | 最前面のオーバーレイを閉じます。 |

ショートカットを無効にするには、個人の [環境設定](/ja/account#設定)で**キーボードショートカットを有効にする**をオフにします。

## 問題を調査する

一般的な調査は、次の手順で進めます。

<Steps>
  <Step title="症状から調査を始める">
    インシデント、ダッシュボードパネル、処理の遅いトレース、フロントエンドエラー、または負荷の高い箇所を示すプロファイルを開きます。
  </Step>
  <Step title="時間範囲とリソースを絞り込む">
    調査に必要な最小限の時間範囲を選択し、サービス、ストリーム、環境、またはセッションで絞り込みます。
  </Step>
  <Step title="シグナル間を移動する">
    相関アクションを使って、関連するトレース、ログ、メトリクス、プロファイル、またはRUM セッションを開きます。[シグナル間の相関](/ja/correlation)を参照してください。
  </Step>
  <Step title="調査結果を残す">
    クエリをビューとして保存する、ダッシュボードパネルを追加する、アラートルールを作成する、またはMole Agentに調査を依頼して結果を保存します。
  </Step>
</Steps>

## 言語と個人設定

ユーザーメニューの**言語**で、インターフェースの表示言語を選択します。選択した言語はすぐに適用され、アカウントに保存されるため、別のブラウザーでも同じ言語で表示されます。

プロフィール、テーマ、表示密度、タイムゾーン、日付形式、開始ページ、個人通知、セッションは、**アカウント設定**にあります。詳しくは、 [アカウント設定](/ja/account)を参照してください。
