MoleSignal の管理は 3 つの範囲に分かれます。それぞれに専用のページと権限があります。

| 管理範囲 | 対象者 | 管理項目 | ガイド |
|---|---|---|---|
| 個人アカウント | すべてのメンバー（各自のアカウントのみ）。 | プロフィール、個人設定、個人向け通知、パスワード、セッション、所属。 | [アカウント設定](/ja/account) |
| ワークスペース | 組織のオーナーと管理者。 | メンバー、ロール、アクセス権の付与、トークン、シングルサインオン、ワークスペース設定、通知、データセキュリティ、監査。 | [ID とアクセス](/ja/identity)、[設定](/ja/settings) |
| プラットフォーム `_sys` | 特権管理者と、プラットフォームロールを付与されたアカウント。 | 組織、インスタンス全体の設定、システムテレメトリ、プラットフォーム管理者。 | [プラットフォーム設定](/ja/settings/platform) |

## ワークスペースの管理

新しいワークスペースは、通常、次の手順で設定します。

<Steps>
  <Step title="メンバーの参加方法を決める">
    [登録ポリシー](/ja/settings/organization#登録とアクセス)を設定します。次に、 [シングルサインオン](/ja/identity/sso)を会社のメールドメインと連携します。
  </Step>
  <Step title="メンバーに適切なアクセス権を付与する">
    [メンバー](/ja/identity/members)に組み込みロールを割り当てます。担当業務に必要な権限だけを付与するには、 [カスタムロール](/ja/identity/roles#ロール)を作成します。オンコール対応や管理責任の割り当てには、 [チーム](/ja/identity/teams#チーム)を使ってメンバーをグループ化します。
  </Step>
  <Step title="プログラム専用のアカウントを作成する">
    コレクター、CI、自動化には、個人トークンの代わりに[サービスアカウント](/ja/identity/tokens#サービスアカウント)を作成します。
  </Step>
  <Step title="通知を設定する">
    [コネクター、ポリシー、フォールバックルート](/ja/notification-channels)を設定し、アラートやレポートが担当者に届くようにします。
  </Step>
  <Step title="データを保護する">
    機密性の高い値を保護するため、[正規表現パターンとフィールドマスキング](/ja/settings/data-security)を追加します。 [監査証跡](/ja/settings/data-security#監査)も定期的に確認します。
  </Step>
</Steps>

## プラットフォームの管理

常設の `_sys` 組織は、通常のテナントとは異なります。`_sys` のセッションでアクセスできるのは、プラットフォーム権限で許可されたページとルートだけです。特権管理者に加え、`_sys` の **ID とアクセス → アクセス権の付与** でプラットフォームロールを付与されたアカウントもアクセスできます。詳細は、 [プラットフォームへのアクセス](/ja/identity#プラットフォームへのアクセス)を参照してください。

| 権限 | 許可される操作 |
|---|---|
| `sys.organizations.read`, `.create`, `.update`, `.disable`, `.delete` | 組織の一覧表示、作成、名前変更、無効化、有効化、削除ができます。作成以外の操作では、権限の付与先を 1 つの組織に限定できます。 |
| `sys.settings.retention.*`, `sys.settings.limits.*`, `sys.settings.signin.*`, `sys.settings.alerting.*`, `sys.settings.topology.*` | データ保持、制限、サインイン、アラート評価、サービスグラフ、フェデレーションの設定を表示および変更できます。 |
| `sys.signing_keys.read`, `sys.signing_keys.rotate` | セッションの署名キーを一覧表示し、ローテーションできます。 |
| `sys.clusters.read`, `sys.clusters.manage` | リモートクラスターの情報を表示および変更できます。 |
| `sys.nodes.read`, `sys.nodes.drain` | ノードのドレイン状態を確認し、ドレインを開始できます。 |
| `sys.query.admission.read`, `sys.query.admission.manage` | クエリの受け入れ制御を表示および変更できます。 |
| `sys.telemetry.read`, `sys.telemetry.manage` | MoleSignal 自体のテレメトリを表示および設定できます。[自己オブザーバビリティ](/ja/self-observability)を参照してください。 |
| `sys.trace_debug.manage` | プラットフォームのトレースデバッグを有効にし、設定できます。 |
| `sys.administrators.read`, `sys.administrators.manage` | プラットフォームのロール、ポリシー、アクセス権の付与を表示および変更できます。 |

テナントセッションと `mspat-*` API トークンでは、保護された `_sys` のデータにアクセスできません。
