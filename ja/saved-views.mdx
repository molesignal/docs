保存済みビューは、ワークスペースで共有する名前付きの SQL または PromQL クエリです。クエリを書き直さずにワンクリックで開き直せます。 [レポート](/ja/reports)のコンテンツとして使用でき、コマンドパレットから検索できます。 **保存済みビュー**を開くには、 [コマンドパレット](/ja/console#コマンドパレットで検索する)で**保存済みビューに移動**を選択します。

## 一覧

ヘッダーには、保存済みビューの総数とピン留め済みの件数が表示されます。各ビューには、**言語**、**ストリーム**、 **タグ**、デフォルトの**適用期間**、最終更新日時が表示されます。ピン留め済みのビューにはピンアイコンが付きます。

| 操作 | 内容 |
|---|---|
| **開く** | 現在時刻を終了時刻とし、ビューの適用期間を使って、対応するエクスプローラーでクエリを開きます。 |
| **ピン留め** / **ピン留めを解除** | チームでよく使うビューに目印を付けたり、外したりします。 |
| **編集** | ビューを変更します。 |
| **削除** | ビューを削除します。この操作は元に戻せません。 |

**開く**を選択すると、SQL ビューは[ログ](/ja/logs)で、ビューに設定されたストリームを対象に SQL モードで実行されます。 PromQL ビューは[メトリクス](/ja/metrics)で実行されます。

## 保存済みビューを作成する

**新規保存済みビュー**を選択します。

| フィールド | 入力内容 |
|---|---|
| **名前** | 一覧とコマンドパレットに表示する名前です。 |
| **言語** | **SQL** または **PromQL** です。 |
| **デフォルトの時間範囲** | **開く**で使用する時間範囲です。15 分、1 時間、6 時間、24 時間、7 日間から選択します。 |
| **クエリ文** | 実行するクエリです。 |
| **ストリーム（任意）** | SQL ビューの実行対象となるストリームです。読み取るファイルも絞り込みます。 |
| **タグ** | 後でビューを検索できるように、タグをカンマ区切りで入力します。 |
| **先頭にピン留め** | ビューをピン留めします。 |

**作成**を選択します。時間範囲が変わっても使えるクエリを記述します。クエリ内では時間範囲を指定せず、ビューの設定に任せ、`service.name` や `deployment.environment` など、値が変わりにくいフィールドで絞り込みます。

## 保存済みビューを他の場所で使用する

- [レポート](/ja/reports#保存済みビュー)は、スケジュールに従って保存済みビューの結果をテーブルに表示します。
- コマンドパレットでは、名前で保存済みビューを検索できます。
- [ストリーム](/ja/streams#ストリームの詳細)の**使用状況**タブには、そのストリームに紐づく保存済みビューが表示されます。

## 権限

| 権限 | 許可される操作 |
|---|---|
| `saved_views.read` | 保存済みビューの一覧を表示し、ビューを開きます。 |
| `saved_views.create` | 保存済みビューを作成します。 |
| `saved_views.edit` | 保存済みビューを変更し、ピン留めします。 |
| `saved_views.delete` | 保存済みビューを削除します。 |

ビューの実行には `streams.query` も必要です。[保存済みビュー API](/ja/api/query/list-saved-views)を参照してください。
