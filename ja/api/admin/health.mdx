| エンドポイント | 認証 |
|---|---|
| `GET /api/v1/healthz` | なし |
| `GET /metrics` | なし |
| `GET /api/v1/readyz` | Bearer トークン |
| `GET /api/v1/version` | Bearer トークン |

## ライブネス

```http
GET /api/v1/healthz
```

複数のチェックをまとめたヘルスプローブです。ノードが正常な場合は `200` を返し、オブジェクトストアに接続できない場合は `reason` を伴う `503` を返します。コンテナやロードバランサーのプローブに使用してください。

<ResponseExample>
```json 200
{ "status": "ok" }
```
</ResponseExample>

## レディネス

```http
GET /api/v1/readyz
Authorization: Bearer <token>
```

トラフィックを受け付けられるか確認するプローブです。起動時にリプレイ処理を行わないため、ノードが起動すると `200` を返します。オブジェクトストアの状態が悪化しても、読み取り専用トラフィックは引き続き受け付けます。リクエストには Bearer トークンが必要なため、認証情報を含まないプローブには `401` を返します。プローブにトークンを付けられない場合は、代わりに `/api/v1/healthz` を使用してください。

<ResponseExample>
```json 200
{ "status": "ready" }
```
</ResponseExample>

## バージョン

```http
GET /api/v1/version
Authorization: Bearer <token>
```

製品バージョン、コミット、ブランチ、ビルド時刻、ビルド ID、リリースチャネル、エディションを返します。

<ResponseExample>
```json 200
{
  "version": "26.1.0.0",
  "commit": "<git-sha>",
  "branch": "main",
  "buildEpochSecs": 1790000000,
  "buildId": "<build-id>",
  "releaseChannel": "alpha",
  "edition": "oss"
}
```
</ResponseExample>

## メトリクス

```http
GET /metrics
```

プロセスとサブシステムのメトリクスを Prometheus の公開形式 (`text/plain; version=0.0.4`) で返します。メトリクスには `cache_*` のヒット率、`wal_*`、`object_store_*`、`storage_reconciler_issues_total` などがあります。このルートへのアクセスは、プロキシまたはネットワークのレイヤーで制限してください。[MoleSignal 自体のオブザーバビリティ](/ja/self-observability)を参照してください。
