```http
GET /api/v1/audit
```

組織の監査イベントを新しい順に、カーソルを使ってページ分割して返します。この呼び出しには `audit.read` が必要です。

各イベントは、組織の `_audit` ストリームにも1行ずつ記録されます。このストリームにはクエリを実行でき、パイプラインで別の宛先に配信できます。この API は、監査記録の一次データを読み取ります。[監査ストリーム](/ja/settings/data-security#監査ストリーム)を参照してください。

監査証跡は、ライフサイクルに関わる機密性の高い操作を記録します。すべての変更を記録するわけではありません。現行リリースのアクション名は、次のプレフィックスで始まります。

| プレフィックス | 操作 |
|---|---|
| `agent.` | Mole Agent のモデルプロバイダー、プロンプト、ツールとツール呼び出し、MCP サーバー、承認、チャット、調査、実行に関する操作です。 |
| `iam.` | ロールバインディング、関係、組織をまたぐ権限付与に関する操作です。 |
| `resource_share.` | 共有リンクの作成、ローテーション、取り消し、アクセス、およびパスワード認証の失敗です。 |
| `status_page.` | ステータスページ、コンポーネント、自動化ルール、ロゴに関する操作です。 |
| `synthetic.` | 外形監視のロケーション、エージェント、エージェントトークンに関する操作です。 |
| `schedule.` | オンコールスケジュールとオーバーライドに関する操作です。 |
| `trace_debug_token.` | トレースデバッグトークンの使用です。 |
| `dashboard.` | AI が生成した下書きからのダッシュボード作成です。 |

ストリーム、アラートルール、インシデント、コネクターの変更は記録しません。

**クエリパラメーター**

| パラメーター | 型 | 説明 |
|---|---|---|
| `from`, `to` | string | 対象の時間範囲です。各値には、エポックからのマイクロ秒数、または `now` や `now-30m` などの相対値を指定します。相対値の `now-<N><unit>` 形式では、単位に `s`、`m`、`h`、`d` のいずれかを指定します。 |
| `actorKind` | string | プリンシパルの種類です。例: `user`。 |
| `actor` | string | プリンシパルの識別子です。 |
| `action` | string | 完全一致で指定するアクション名です。例: `agent.model_provider.created`。 |
| `targetKind`, `targetId` | string | 対象の種類と識別子です。 |
| `limit` | integer | 1ページあたりの件数です。デフォルトは `50` です。範囲外の値は、下限の 1 または上限の 200 に補正します。 |
| `cursor` | string | 前のページの `nextCursor` です。値の内部形式は公開しません。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/audit?from=now-7d&action=agent.model_provider.created&limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**レスポンス**

| フィールド | 説明 |
|---|---|
| `items[].actor_kind`, `items[].actor_id` | 変更を行ったプリンシパルです。 |
| `items[].action` | アクション名です。例: `iam.role_binding.create`。 |
| `items[].target_kind`, `items[].target_id` | 操作の対象となったオブジェクトです。どちらも `null` の場合があります。 |
| `items[].ip`, `items[].user_agent` | 操作で記録したクライアントアドレスとユーザーエージェントです。どちらも `null` の場合があります。 |
| `items[].payload` | 操作の詳細です。ペイロードにシークレット、プロンプトの本文、ツールの実行結果は含めません。 |
| `items[].ts` | イベントの発生時刻です。単位はマイクロ秒です。 |
| `nextCursor` | 次のページのカーソルです。最後のページでは `null` です。 |
| `retentionDays` | 監査記録の保持日数です。すべての組織とプラットフォームに同じ日数を適用します。保持期間を過ぎた記録は1日1回削除します。`0` を指定すると無期限に保持します。 |

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | `from` または `to` が数値でも有効な相対値でもないか（`unparseable time: yesterday`、`bad time unit in: now-3x`）、`cursor` が無効です。 |
| `403` | トークンに `audit.read` 権限がありません。 |

## 関連する監査エンドポイント

| エンドポイント | 権限 | 用途 |
|---|---|---|
| `GET /api/v1/system/audit` | システムスコープの `sys.telemetry.read` | 同じクエリをシステム組織の監査イベントに対して実行します。これらのイベントには、組織の有効化や無効化、トレースポリシーの変更、監査記録の保持期間の変更などの操作が含まれます。 |
| `GET /api/v1/settings/audit_retention` | システムスコープの `sys.settings.retention.manage` | 監査記録の保持期間を返します: `{ "retentionDays": 90 }`。 |
| `PUT /api/v1/settings/audit_retention` | システムスコープの `sys.settings.retention.manage` | 同じ形式のボディで監査記録の保持期間を設定します。`retentionDays` には `0`（無期限）から `3650` までの整数を指定します。上限を超える値には `400` を返します。 |
| `GET /api/v1/settings/audit_retention/preview?retentionDays=30` | システムスコープの `sys.settings.retention.manage` | 保持期間を短縮した場合に削除対象となる記録の情報を返します: `{ "retentionDays": 30, "previousRetentionDays": 90, "rows": 2400, "earliestAt": 1780000000000000 }`。件数は推定ではなく、実際にカウントします。保持期間を延長する値または `0` を指定すると、`"rows": 0` を返します。 |
| `GET /api/v1/agent/audit/chat/{id}` | `audit.read` | Mole Agent のチャットの全履歴を返します。内容は `chat` レコードとその `messages` で、プロンプトのハッシュ、トークン数、根拠も含みます。該当するチャットがない場合は `404` を返します。 |

<Warning>
  チャット履歴には、ユーザーの質問とモデルの回答が含まれます。この内容の閲覧を許可するアカウントにのみ `audit.read` を付与してください。
</Warning>
