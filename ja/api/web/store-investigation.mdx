```http
POST /api/v1/web/investigation/blob
```

JSON ドキュメントをオブジェクトストレージに保存し、識別子を返します。Web UI はこの API を使用して、大規模な調査の調査スタックをページ URL に含めず、識別子だけを含めます。ドキュメントの読み取りには、[調査スタックの取得](/ja/api/web/fetch-investigation)を使用してください。この API を呼び出すには、`streams.query`、またはシステムスコープの `sys.telemetry.read` が必要です。

リクエストボディには、最大 1 MiB（1,048,576 bytes）の任意の JSON 値を指定できます。ドキュメントは、呼び出し元の組織に属します。コンパクターは 7 日後にドキュメントを削除します。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/investigation/blob \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "version": 1,
    "stack": [
      { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
      { "kind": "log", "query": "level = error" }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "blobId": "3KEZAC5JXc0P0HjrTdARfCgH1Y3"
}
```
</ResponseExample>

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | リクエストボディが有効な JSON ではない（プレーンテキストである）か、ドキュメントが 1 MiB を超えています（`payload exceeds 1048576 bytes`）。 |
| `403` | トークンに `streams.query` 権限がありません。 |
