```http
GET /api/v1/traces/service_graph
```

[サービストポロジー](/ja/api/web/topology)が集計する前のサービスグラフのエッジを返します。各エッジは、クライアントサービスからサーバーサービスへの 1 分間の呼び出し回数を示します。この API の呼び出しには、`traces.read`、またはシステムスコープの `sys.telemetry.read` が必要です。

**クエリパラメーター**

| パラメーター | 型 | 必須 | 補足 |
|---|---|---|---|
| `from` | integer | はい | 対象期間の開始時刻です。Unix エポックからの経過時間をマイクロ秒で指定します。 |
| `to` | integer | はい | 対象期間の終了時刻です。マイクロ秒単位で指定します。 |
| `service` | string | いいえ | 指定したサービスがクライアントまたはサーバーであるエッジのみを返します。 |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000
curl "http://localhost:5080/api/v1/traces/service_graph?from=$((NOW-3600000000))&to=$NOW&service=checkout" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "edges": [
    {
      "id": "3KBCiQWW0TtpDu7D4pH7LMtZsRh",
      "orgId": "<organization-id>",
      "clientService": "frontend",
      "serverService": "checkout",
      "bucketAt": 1790000000000000,
      "requestCount": 12,
      "errorCount": 1,
      "p50Us": 90000,
      "p95Us": 210000,
      "p99Us": 240000
    }
  ],
  "count": 1
}
```
</ResponseExample>

**レスポンス**

| フィールド | 補足 |
|---|---|
| `edges[].client_service`, `edges[].server_service` | 呼び出し元と呼び出し先のサービスです。 |
| `edges[].bucketAt` | 1 分間のバケットの開始時刻です。単位はマイクロ秒です。 |
| `edges[].request_count`, `edges[].error_count` | バケット内の呼び出し回数と、そのうち失敗した回数です。 |
| `edges[].p50_us`, `edges[].p95_us`, `edges[].p99_us` | バケット内のレイテンシーのパーセンタイル値です。単位はマイクロ秒です。各値は `null` の場合があります。 |
| `count` | 返されたエッジの数です。 |

対象期間に該当するエッジがない場合や、`to` が `from` より前の場合は、`{"edges": [], "count": 0}` を返します。

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | `from` または `to` が指定されていないか、整数ではありません。レスポンスはプレーンテキストです。 |
| `403` | トークンに `traces.read` 権限がありません。 |
