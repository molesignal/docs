```http
GET /api/v1/web/topology
```

指定した時間範囲のサービスグラフのエッジをノードとエッジに集約し、リクエストレート、エラー率、レイテンシを返します。エッジは、MoleSignal がトレーススパンから生成するサービスグラフから取得します。[サービスマップ](/ja/apm/service-map)を参照してください。この呼び出しには、`traces.read` またはシステムスコープの `sys.telemetry.read` が必要です。

**クエリパラメーター**

| パラメーター | 型 | 必須 | 備考 |
|---|---|---|---|
| `from` | string | はい | 時間範囲の開始時刻を RFC 3339 形式のタイムスタンプで指定します。 |
| `to` | string | はい | 時間範囲の終了時刻を RFC 3339 形式のタイムスタンプで指定します。`from` より前の時刻は指定できません。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/topology?from=2026-10-04T09:00:00Z&to=2026-10-04T10:00:00Z" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "nodes": [
    { "id": "checkout", "name": "checkout", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 },
    { "id": "frontend", "name": "frontend", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 }
  ],
  "edges": [
    { "source": "frontend", "target": "checkout", "rps": 0.1, "errRate": 0.0278, "p95Ms": 90.0 }
  ]
}
```
</ResponseExample>

**レスポンス**

| フィールド | 備考 |
|---|---|
| `nodes[].id`, `nodes[].name` | サービス名です。ノードは名前順に並びます。 |
| `nodes[].span_count` | サービスがクライアントまたはサーバーとして関与するすべてのエッジのリクエスト数です。 |
| `nodes[].error_rate`, `edges[].err_rate` | エラー数をリクエスト数で割った値です。範囲は 0 から 1 です。 |
| `nodes[].rps`, `edges[].rps` | リクエスト数を時間範囲の長さ（秒）で割った値です。 |
| `nodes[].p95_ms`, `edges[].p95_ms` | 集約対象のバケットのうち、最も高い p95 レイテンシ（ミリ秒）です。時間範囲全体の p95 ではありません。 |
| `edges[].source`, `edges[].target` | クライアントサービスとサーバーサービスです。エッジは `source` 順に並び、`source` が同じ場合は `target` 順に並びます。 |

時間範囲内にエッジがない場合は、空の配列を返します。

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | `from` または `to` が指定されていないか、RFC 3339 形式のタイムスタンプではありません。または、`to` が `from` より前です。 |
| `403` | トークンに `traces.read` 権限がありません。 |
