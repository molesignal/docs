```http
GET /api/v1/web/investigation/blob/{id}
```

[調査スタックを保存](/ja/api/web/store-investigation)で `blobId` に紐付けて保存したJSONドキュメントを返します。呼び出し元の組織内だけを検索するため、別の組織の識別子を指定すると `404` を返します。呼び出しには `streams.query` が必要です。システムスコープでは `sys.telemetry.read` が必要です。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/web/investigation/blob/$BLOB_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "version": 1,
  "stack": [
    { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
    { "kind": "log", "query": "level = error" }
  ]
}
```
</ResponseExample>

保存したドキュメントを変更せずに返します。7日経過後にコンパクターがドキュメントを削除した場合も、`404` を返します。

**エラー**

| ステータス | 原因 |
|---|---|
| `403` | トークンに `streams.query` 権限がありません。 |
| `404` | 識別子が存在しないか、別の組織に属しているか、有効期限が切れています。 |
