```http
GET /api/v1/web/search
```

**⌘K** コマンドパレットで使用します。この呼び出しは、組織内の6種類のエンティティを名前のあいまい一致で検索し、一致度の高い順に返します。呼び出しには `streams.query` が必要です。システムスコープでは `sys.telemetry.read` が必要です。

**クエリパラメーター**

| パラメーター | 型 | 必須 | 備考 |
|---|---|---|---|
| `q` | 文字列 | はい | 検索テキストです。最大256文字です。照合には PostgreSQL のトライグラム類似度を使用するため、1文字などの短すぎるテキストはほとんど一致しません。`q` が空の場合は空のリストを返します。 |
| `types` | 文字列 | いいえ | `stream`、`dashboard`、`savedView`、`alert`、`incident`、`service` のうち、検索対象の種類をカンマ区切りで指定します。省略するとすべての種類を検索します。不明な値に一致するエンティティはありません。 |
| `limit` | 整数 | いいえ | デフォルトは `20` です。値は1～50の範囲に収められます。 |

`q` がスペースだけで構成され、`types=stream` を指定した場合は、検索せずにストリームをアルファベット順で一覧表示します。

各検索結果は、以下のフィールドでエンティティを示します。

| `kind` | `id` | `label` | `subtitle` |
|---|---|---|---|
| `stream` | ストリームの識別子 | ストリーム名 | `builtin.logs` など、内部形式のストリームタイプです。 |
| `dashboard` | ダッシュボードの識別子 | タイトル | ダッシュボードの `uid` です。 |
| `savedView` | 保存済みビューの識別子 | 名前 | クエリ言語です。 |
| `alert` | ルールの識別子 | ルール名 | `enabled` または `disabled` です。 |
| `incident` | インシデントの識別子 | インシデントのフィンガープリント | インシデントのステータスです。 |
| `service` | エッジの識別子 | サービスグラフ上のサービス名 | なし。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/search?q=app&types=stream&limit=5" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "items": [
    { "kind": "stream", "id": "3KDXoznFWyKPsch4ETi37U3GdxM", "label": "app", "subtitle": "builtin.logs" },
    { "kind": "stream", "id": "3JtcZGko1Q5czEBK9nBJjiFxpo1", "label": "app_logs", "subtitle": "builtin.logs" }
  ]
}
```
</ResponseExample>

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | `q` が指定されていない（プレーンテキスト）か、256文字を超えています（`invalid_argument`）。 |
| `403` | トークンに `streams.query` 権限がありません。 |
