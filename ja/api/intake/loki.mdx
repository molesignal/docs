```http
POST /api/v1/loki/api/v1/push
```

Loki の JSON プッシュ形式を受け付けます。呼び出しには `logs.write` が必要です。成功時は `204` を返します。`Content-Encoding: gzip` を指定したリクエストボディも受け付けます。

このエンドポイントは JSON のみをデコードします。Promtail や Grafana Alloy など、Snappy で圧縮した Protobuf を使用する送信元からはプッシュできません。代わりに OpenTelemetry Collector、Vector、Fluent Bit のいずれかを使用してください。

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

各値は 1 件のログイベントになります。ラベルはフィールドになり、ログ行は `message` フィールドになります。タイムスタンプはナノ秒からマイクロ秒に変換されます。`stream-name` ヘッダーで送信先のストリームを指定します。デフォルトは `default` です。

## サンプルの動作を確認する

このサンプルは、macOS または Linux のシェルで現在時刻のナノ秒タイムスタンプを生成します。`204` を受け取ったら、**ログ**を開き、`app` と過去 1 時間を選択して、`service = 'api'` に該当する `message` を探してください。過去のタイムスタンプに置き換えた場合は、イベント時刻を含む時間範囲を選択し、その時刻が保持期間内にあることを確認してください。

次の 3 つを区別してください。`streams` は Loki のバッチ構造です。`service` ラベルはイベントのフィールドになります。`stream-name` ヘッダーは MoleSignal の送信先ストリームを指定します。バッチを再送信する前に、クエリで送信先ストリームと時間範囲を確認してください。
