```http
POST /api/v1/loki/api/v1/push
```

Loki の JSON プッシュ形式を受け付けます。呼び出しには `logs.write` が必要で、成功すると `204` を返します。値がフィールドの型に適合しないためにストリームが一部の行を拒否した場合、残りの行は書き込まれ、応答は `400` となり、拒否された件数と最初の理由が示されます。`Content-Encoding: gzip` の本文も受け付けます。

このエンドポイントは JSON のみをデコードします。Promtail や Grafana Alloy など、snappy 圧縮された protobuf を使用する送信元はプッシュできません。代わりに OpenTelemetry Collector、Vector、Fluent Bit を使用してください。

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

各値は 1 つのログイベントになります。ラベルはフィールドになり、行は `message` フィールドになり、ナノ秒のタイムスタンプはマイクロ秒に変換されます。`stream-name` ヘッダーが対象ストリームを選択し、デフォルトは `default` です。

## 例を確認する

例では、macOS または Linux のシェルで現在のナノ秒タイムスタンプを生成します。`204` を受け取ったら、**ログ**を開き、`app` と直近 1 時間を選択し、`service = 'api'` の `message` を探します。過去のタイムスタンプに置き換えた場合は、そのイベント時刻を含むウィンドウを選択し、保持期間内にあることを確認してください。

3 つのフィールドを区別します。`streams` は Loki のバッチ構造で、`service` ラベルはイベントフィールドになり、`stream-name` ヘッダーは MoleSignal の送信先ストリームを選択します。バッチを再送する前に、クエリでそのストリームと時間ウィンドウを確認してください。
