```http
POST /api/v1/_bulk
```

Filebeat、Logstash、Vector の `elasticsearch` シンク向けに、Elasticsearch の `_bulk` と互換性のある NDJSON を取り込みます。呼び出しには `logs.write` が必要です。`Content-Encoding: gzip` を指定したリクエストボディも受け付けます。

| アクション | 処理 |
|---|---|
| `index`、`create`、`update` | ソースドキュメントをログイベントとして保存します。 |
| `delete` | スキップし、レスポンス項目を返しません。このエンドポイントでテレメトリを削除することはありません。 |

アクションの `_index` で取り込み先のログストリームを指定します。指定がなければ `stream-name` ヘッダーを使用し、そのヘッダーもなければ `default` を使用します。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/_bulk \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/x-ndjson' \
  --data-binary $'{"index":{"_index":"app"}}\n{"level":"info","msg":"hello"}\n'
```
</RequestExample>

<ResponseExample>
```json 200
{ "took": 0, "errors": false, "items": [ { "index": { "status": 201 } } ] }
```
</ResponseExample>

## このエンドポイントを使う場面

既存の送信元が Elasticsearch のバルク形式の NDJSON を出力できる場合は、このエンドポイントを使用してください。このエンドポイントは取り込み用アダプターであり、Elasticsearch クラスターではありません。この API は、検索、インデックステンプレート、ドキュメント ID、既存ドキュメントの直接更新には対応していません。保存したイベントを読み取るには、[SQL クエリ](/ja/query)を使用してください。

## 有効なバッチを作成する

- `index` または `create` の操作ごとに、アクションオブジェクトとドキュメントオブジェクトを別々の行で送信してください。バッチの末尾に改行を入れてください。
- `update` の場合は、イベントのフィールドを `doc` の下に配置してください。保存済みのイベントを変更するのではなく、これらのフィールドを新しいイベントとして保存します。
- ストリームを選択するには、アクションに `_index` を設定してください。設定しない場合は、`stream-name` を指定するか、`default` ストリームを使用してください。
- イベントの発生時刻を保持するには、`_timestamp` にマイクロ秒単位の Unix タイムスタンプを整数で指定してください。指定しない場合、受信側は現在時刻を使用します。
- `delete` アクションはスキップします。テレメトリは削除せず、保存済みイベントとしてレスポンスに項目を追加することもありません。

## 取り込みを確認する

イベントが 1 件のバッチでは、`errors: false` と、`status: 201` のレスポンス項目 1 件が返ることを確認してください。レスポンス項目数を、取り込む予定だったイベント数と比較してください。HTTP リクエストが成功しただけでは、バッチが意図どおりに構成されていたことは確認できません。

**ログ**を開き、`_index` で指定したストリームを選択し、イベントのタイムスタンプを含む時間範囲を設定してください。サンプル内の識別しやすいフィールドを使ってクエリを実行してください。イベントが見つからない場合は、バッチ全体を再送する前に、選択したストリームとタイムスタンプの単位を確認してください。このインターフェースは、再送時の重複排除に Elasticsearch のドキュメント ID を使用しません。

## リクエストが拒否された場合の対処

| 症状 | 確認事項 |
|---|---|
| 認証または権限のエラー | 対象の組織で `logs.write` 権限を持つ API トークンを使用してください。 |
| アクションまたはドキュメントが JSON オブジェクトではない | NDJSON の改行位置を確認してください。JSON 配列や、整形して複数行に分けたオブジェクトは送信しないでください。 |
| 不明なアクション | 上記の対応アクション名を使用してください。 |
| 展開エラー | ボディを実際に圧縮した場合にのみ `Content-Encoding: gzip` を設定してください。 |
| 成功したがイベント数が想定より少ない | すべての書き込みアクションに対応するドキュメント行があることを確認し、スキップされた削除アクションと保存されたイベントを区別してください。 |
