```http
GET    /api/v1/changes
POST   /api/v1/changes
GET    /api/v1/changes/{id}
PUT    /api/v1/changes/{id}
PATCH  /api/v1/changes/{id}
DELETE /api/v1/changes/{id}
```

変更は一か所に保持されます。デプロイ、設定変更、フィーチャーフラグ、スケーリング、およびインフラストラクチャの変更は、パイプラインが [`POST /api/v1/apm/deployments`](/ja/apm/deployments#ci-からデプロイを報告する) を通じて報告するものであり、アノテーションはユーザーが期間に付けるものです。`GET /api/v1/changes` は、APM がスパンで最初に確認したバージョンとアラートルールの編集とともにこれらを一覧表示します。その他の呼び出しはアノテーションを保持します。

## 変更を一覧表示する

| パラメーター | 備考 |
|---|---|
| `from`, `to` | マイクロ秒単位の範囲。`to` のデフォルトは現在時刻、`from` のデフォルトは `to` の 1 日前です。 |
| `services` | サービス名をカンマ区切りで指定します。他のサービスの変更は除外されますが、アノテーションやルールの編集など、サービスに紐づかない変更は残ります。 |
| `namespace`, `environment` | この名前空間または環境で報告された変更とバージョン、およびどちらも指定されていない報告された変更。 |
| `kinds` | カンマ区切り: `deployment`、`configuration`、`feature_flag`、`scaling`、`infrastructure`、`annotation`、`version`、`rule`。省略した場合は、呼び出し元が読み取り可能なすべての種別。 |
| `dashboardId`, `stream` | このダッシュボードまたはログストリームのアノテーション、およびどちらにも紐づかないアノテーション。他のダッシュボードまたはストリームのアノテーションは除外されます。 |
| `limit` | 最大 500 で、これがデフォルトです。 |

種別ごとに必要な権限が異なり、呼び出し元に権限がない種別はエラーにならず除外されます:

| 種別 | 必要な権限（いずれか） |
|---|---|
| `deployment`, `configuration`, `feature_flag`, `scaling`, `infrastructure` | `apm.deployments.read`、`sys.telemetry.read` |
| `annotation` | `dashboards.annotations.read` |
| `version` | `apm.services.read`、`sys.telemetry.read` |
| `rule` | `alerts.rules.read` |

応答はリストで、最新のものが先頭になります。パイプラインが報告したバージョンは、報告されたとおりに 1 回だけ一覧表示されます。

```json
[
  {
    "id": "3KEDNEyqouYJeBDTLTMTBui7XHW",
    "kind": "deployment",
    "at": 1792316400000000,
    "service": "checkout",
    "namespace": "shop",
    "environment": "prod",
    "version": "2.0.0",
    "status": "succeeded",
    "commit": "9f2c1e7a4b3d5e6f",
    "author": "ada",
    "ciUrl": "https://ci.example.com/runs/7"
  },
  {
    "id": "3KEDP0aZ1y2b3c4d5e6f7g8h9i0",
    "kind": "annotation",
    "at": 1792312800000000,
    "end": 1792314600000000,
    "title": "Load test",
    "tags": ["test"],
    "dashboardId": "dash-1"
  }
]
```

| フィールド | 備考 |
|---|---|
| `at`, `end` | 発生した時刻。`end` は範囲にわたるアノテーションの終了時刻です。マイクロ秒単位。 |
| `service`, `namespace`, `environment`, `version` | 報告された変更またはバージョンが対象とするもの。 |
| `status` | 報告された変更の結果: `succeeded`、`failed`、または `rolled_back`。 |
| `title`, `description`, `tags` | アノテーションまたはルールのタイトル、および変更自体が示す内容。 |
| `commit`, `repositoryUrl`, `pullRequestUrl`, `author`, `ciUrl` | 報告された変更の出所。 |
| `dashboardId`, `stream` | アノテーションが属する場所。 |
| `ruleId` | 編集の対象となったルール。 |

## アノテーションを保持する

`POST /api/v1/changes` はアノテーションを作成し、`dashboards.annotations.manage` が必要です:

```json
{
  "title": "Load test",
  "description": "k6, 2,000 users",
  "tags": ["test"],
  "timeStart": 1792312800000000,
  "timeEnd": 1792314600000000,
  "dashboardId": "dash-1",
  "streamName": null
}
```

`GET /api/v1/changes/{id}` は `dashboards.annotations.read` で 1 件のアノテーションを読み取ります。`PUT` と `PATCH` は指定したフィールドを変更し、`DELETE` は `dashboards.annotations.manage` で削除します。これらの呼び出しはアノテーションのみを対象とします。組織のアノテーションではない ID を指定すると `404` を返します。 Mole Agent は `create_annotation`、`update_annotation`、`delete_annotation` でアノテーションを管理し、 `list_changes` で変更を一覧表示します。
