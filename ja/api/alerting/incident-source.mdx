```http
GET /api/v1/alerts/incidents/{id}/source
```

[アラートソース](/ja/alerting/sources)が起票したインシデントについて、ソース側が保持する情報を返します。`alerts.incidents.read` 権限が必要です。このインシデントには `alert.source=external` ラベルが付き、`ruleId` にはソースの ID が入ります。

| フィールド | 説明 |
|---|---|
| `source` | [アラートソースの一覧を取得](/ja/api/alerting/list-sources)と同じ形式のソース情報です。ソースを削除すると `null` になります。 |
| `dedupKey` | 重複排除キーです。 |
| `lastEventAt` | この重複排除キーで受け付けた送信元タイムスタンプのうち、最新の値です（単位：マイクロ秒）。これより古いメッセージは無視します。API タイプでは `null` になります。 |
| `lastIntakeAt` | アラートを最後に受信した時刻です（単位：マイクロ秒）。 |
| `members` | Alertmanager または Grafana の通知グループ内のアラートです（最大 100 件）。各アラートには `status`（`firing` または `resolved`）、`labels`、`summary`、`startsAt`、`endsAt`、送信元へのリンクを示す `url` が含まれます。それ以外のタイプでは空になります。 |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/source \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**エラー**

| ステータス | 原因 |
|---|---|
| `404` | インシデントが存在しないか、アラートソースが起票したインシデントではありません。 |
