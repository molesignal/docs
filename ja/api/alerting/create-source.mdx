```http
POST /api/v1/alerts/sources
```

[アラートソース](/ja/alerting/sources)を作成します。`alerts.sources.manage` が必要です。レスポンスの `token` はこの一度だけ表示されます。[アラートの送信](/ja/api/alerting/send-alerts)を呼び出す際に使用してください。フェデレーションが有効な場合、ソースは他のクラスターに同期されます。

| フィールド | 型 | 説明 |
|---|---|---|
| `kind` | string | 作成時に必須: `api`、`alertmanager`、`grafana`、`datadog`、`pagerduty`、`aliyun_cms`、`tencent_monitor`、`aws_cloudwatch`、`zabbix`、`azure_monitor`、`gcp_monitoring`、`huawei_ces`、`email` のいずれか。 |
| `name` | string | 必須。最大128文字。 |
| `enabled` | boolean | デフォルトは `true`。 |
| `escalationPolicyId` | string \| null | 組織のエスカレーションポリシーID、または `default`。指定しない場合、または `null` の場合、エスカレーションは行われず、通知ポリシーのみが通知します。 |
| `severity` | string | アラートに重要度が含まれない場合に使用します: `critical`、`error`、`warning`(デフォルト)、`info`。 |
| `labels` | object | 最大32個の追加ラベル。キーは英字、数字、`_ . - : /` で構成され、`alert.` で始めることはできず、`external.kind` にはできません。 |
| `email` | object | メールソースがメールを読み取る方法: `allowedSenders`(アドレス、`@domain`、`*`)、`resolvePattern`、`dedupPattern`、`ignorePattern`。詳細は[メール](/ja/alerting/sources#メール)を参照してください。更新時に省略した場合は、現在の設定が維持されます。 |
| `homeCluster` | string | インシデントを作成するフェデレーションクラスター: このクラスター、または有効なリモートクラスター。指定せずに新しいソースを作成すると、このクラスターが使用されます。フェデレーションが無効な場合、効果はありません。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

レスポンスは `token` を含むソースです。その他のフィールドについては[アラートソースの一覧](/ja/api/alerting/list-sources)で説明しています。

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | フィールドが不正です。名前が空、存在しないエスカレーションポリシー、受信クラスターがこのクラスターでも有効なリモートクラスターでもない、などが該当します。 |
| `403` | トークンに `alerts.sources.manage` がありません。 |
