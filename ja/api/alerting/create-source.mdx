```http
POST /api/v1/alerts/sources
```

[アラートソース](/ja/alerting/sources)を作成します。`alerts.sources.manage` 権限が必要です。レスポンスの `token` は作成時に一度だけ返されます。[アラートを送信](/ja/api/alerting/send-alerts) API の呼び出しに使用してください。フェデレーションが有効な場合、アラートソースは他のクラスターに同期されます。

| フィールド | 型 | 説明 |
|---|---|---|
| `kind` | string | 作成時に必須です。`api`、`alertmanager`、`grafana`、`datadog`、`pagerduty`、`aliyun_cms`、`tencent_monitor`、`aws_cloudwatch`、`zabbix`、`email` のいずれかを指定します。 |
| `name` | string | 必須です。最大128文字です。 |
| `enabled` | boolean | デフォルトは `true` です。 |
| `escalationPolicyId` | string \| null | 組織のエスカレーションポリシー ID、または `default` を指定します。省略するか `null` を指定すると、エスカレーションは行われず、通知ポリシーに基づく通知のみが送信されます。 |
| `severity` | string | アラートに重大度が指定されていない場合に使用します。`critical`、`error`、`warning`（デフォルト）、`info` のいずれかを指定します。 |
| `labels` | object | 追加のラベルを最大32個指定できます。キーには英字、数字、`_ . - : /` のみを使用できます。`alert.` で始まるキーと `external.kind` は使用できません。 |
| `email` | object | メールソースでのメールの処理方法を設定します。`allowedSenders`（メールアドレス、`@domain`、または `*`）、`resolvePattern`、`dedupPattern`、`ignorePattern` を指定できます。詳しくは[メール](/ja/alerting/sources#メール)を参照してください。更新時に省略すると、既存の設定が維持されます。 |
| `homeCluster` | string | インシデントを作成するフェデレーション内のクラスターです。このクラスターまたは有効なリモートクラスターを指定します。アラートソースの作成時に省略すると、このクラスターを使用します。フェデレーションが無効な場合、この設定は適用されません。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

レスポンスには、作成したアラートソースとその `token` が含まれます。その他のフィールドについては、[アラートソースの一覧を取得](/ja/api/alerting/list-sources)を参照してください。

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | フィールドの値が無効です。たとえば、名前が空、指定したエスカレーションポリシーが存在しない、または受信先がこのクラスターでも有効なリモートクラスターでもない場合に発生します。 |
| `403` | トークンに `alerts.sources.manage` 権限がありません。 |
