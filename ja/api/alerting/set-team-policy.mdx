```http
PUT /api/v1/alerts/routing/teams/{teamId}
```

チームの[オンコールポリシー](/ja/alerting/routing#チームのオンコールポリシー)を設定または削除します。操作には `alerts.routing.manage` が必要です。チームにルーティングされた新規インシデントは、このポリシーに従ってエスカレーションします。チームにポリシーがない場合は、デフォルトのポリシーを適用します。

| フィールド | 型 | 説明 |
|---|---|---|
| `escalationPolicyId` | string \| null | 組織のエスカレーションポリシーの ID です。`null` を指定するか省略すると、チームのオンコールポリシーを削除します。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/teams/$TEAM_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"escalationPolicyId": "<policy-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "teamId": "<team-id>", "escalationPolicyId": "<policy-id>" }
```
</ResponseExample>

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | チームが存在しないか別の組織に属している、またはエスカレーションポリシーが存在しません。 |
| `403` | トークンに `alerts.routing.manage` 権限がありません。 |
| `422` | リクエストに別のフィールドが含まれています。レスポンスはプレーンテキストです。 |
