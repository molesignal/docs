```http
PUT /api/v1/alerts/sources/{id}
```

[アラートソース](/ja/alerting/sources)の設定全体を上書きします。`alerts.sources.manage` 権限が必要です。フィールドは[アラートソースの作成](/ja/api/alerting/create-source)と同じです。種類は変更できないため、`kind` を指定する場合は現在の値を指定してください。トークンは変更されません。変更するには[トークンのローテーション](/ja/api/alerting/rotate-source-token)を使用してください。`homeCluster` を指定しない場合、受信先クラスターは変わりません。すでにオープンしているインシデントには、既存のエスカレーションポリシーとラベルが維持されます。

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"name": "Production Prometheus", "enabled": false, "escalationPolicyId": "default", "severity": "error"}'
```
</RequestExample>

レスポンスは更新後のソースです。`token` は含まれません。

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | フィールドの値が無効か、現在とは異なる種類が指定されています。 |
| `403` | トークンに `alerts.sources.manage` 権限がありません。 |
| `404` | ソースが存在しません。 |
