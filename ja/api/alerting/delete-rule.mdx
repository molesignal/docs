```http
DELETE /api/v1/alerts/rules/{id}
```

ルールを削除します。この呼び出しには `alerts.rules.delete` 権限が必要です。そのルールがすでに作成したインシデントは引き続き閲覧でき、ルールとは独立したライフサイクルをたどります。削除したルールは、これらのインシデントを解決しません。

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>

レスポンスボディはプレーンテキストの `deleted` です。存在しない `id` を指定すると、`404` が返ります。
