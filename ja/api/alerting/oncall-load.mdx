```http
GET /api/v1/alerts/insights/oncall-load
```

指定期間における担当者ごとのオンコール負荷を測定し、通知件数の多い順に返します。この API の呼び出しには `alerts.incidents.read` が必要です。

通知とは、担当者に配信されたアラート発報通知またはエスカレーション通知です。1 件の通知は担当者ごとに 1 回だけカウントし、送信に失敗した通知はカウントしません。夜間は現地時間の 22:00 から翌日の 08:00 までです。週末は現地の土曜日と日曜日です。現地時間には担当者のスケジュールのタイムゾーンを使用します。スケジュールに登録されていない場合は、担当者の[通知停止時間](/ja/account#通知)のタイムゾーンを使用し、それも設定されていない場合は UTC を使用します。日付が変わってから夜間が終わるまでの通知は、前日の夜間分としてカウントします。

**クエリパラメーター**

| パラメーター | 型 | 説明 |
|---|---|---|
| `windowSecs` | 整数 | さかのぼる期間を秒単位で指定します。デフォルトは `2592000`（30 日）です。値は 1 日から 90 日の範囲に収まるように調整します。 |
| `scheduleId` | 文字列 | 指定したスケジュールのメンバーとシフトのみを集計します。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/insights/oncall-load?windowSecs=604800" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "windowSecs": 604800,
  "nightStartHour": 22,
  "nightEndHour": 8,
  "people": [
    {

      "nightPages": 3,
      "weekendPages": 2,

      "responded": 6,

```
</ResponseExample>

**レスポンス**

| フィールド | 説明 |
|---|---|
| `windowSecs` | 範囲調整後の集計期間です。 |
| `nightStartHour`, `nightEndHour` | 夜間の開始時刻と終了時刻です。 |
| `people[].oncall_secs` | 集計期間中にスケジュール上でオンコールを担当した秒数です。シフトの上書きや交代も含みます。 |
| `people[].pages` | 受信したアラート通知の件数です。 |
| `people[].night_pages`, `people[].weekend_pages` | 受信した通知のうち、夜間と週末のそれぞれの件数です。 |
| `people[].interrupted_nights` | 通知を 1 件以上受信した夜の日数です。 |
| `people[].timezone` | 夜間と週末の判定に使用したタイムゾーンです。 |
| `people[].responded`, `people[].mtta_secs` | 集計期間中に担当者が最初に引き受けたインシデントの件数と、インシデントの発生から引き受けまでの平均秒数です。引き受けは[インシデントインサイト](/ja/api/alerting/insights)と同じ方法で集計します。 |
