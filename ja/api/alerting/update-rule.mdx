```http
PUT /api/v1/alerts/rules/{id}
```

ルールの設定を置き換えます。リクエストボディには、[ルールを作成](/ja/api/alerting/create-rule)と同じ完全なボディを指定します。この呼び出しでは、ルールの `id`、組織、`createdAt`、`lastEvalAt`、`lastState` を保持します。`escalationPolicyId` を変更する場合は、組織内のポリシーか `default` を指定してください。この呼び出しには `alerts.rules.manage` が必要です。

<Warning>
  この呼び出しはルールを置き換えます。フィールドはマージしません。省略したフィールドにはデフォルト値が適用され、 `enabled` は `true` に、`kind` は `scheduled` になります。次のフィールドを省略すると、 `labels`、`annotations`、`thresholds` は空になります。`escalationPolicyId` を省略した場合に限り、現在のポリシーを保持します。先にルールを取得し、変更を反映した完全なリクエストボディを送信してください。
</Warning>

インシデントのフィンガープリントは、ルールの `id` と `labels` から生成します。`labels` を変更しても、すでにオープンしているインシデントは以前のフィンガープリントを保持するため、自動では解決されなくなります。[インシデントを解決](/ja/api/alerting/resolve-incident)で解決してください。

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  --data-binary @- <<'EOF'
{
  "name": "High error rate",
  "description": "More than 200 errors in five minutes",
  "enabled": true,
  "kind": "scheduled",
  "query": {
    "language": "sql",
    "statement": "SELECT count(*) AS c FROM app WHERE level = 'error'",
    "periodSecs": 300,
    "stream": { "name": "app", "streamType": "logs" }
  },
  "trigger": { "operator": "gt", "threshold": 200, "forPeriods": 2, "silenceSecs": 0 },
  "severity": "critical",
  "labels": { "team": "checkout" }
}
EOF
```
</RequestExample>

レスポンスは、[ルール一覧を取得](/ja/api/alerting/list-rules)に示す形式で更新後のルールを返します。

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | リクエストボディが[ルールを作成](/ja/api/alerting/create-rule)と同じ検証を通過しないか、変更後の `escalationPolicyId` に該当するポリシーが組織内に存在しません。 |
| `404` | ルールが存在しません。 |
| `422` | 必須フィールドがないか、値の型が正しくありません。レスポンスはプレーンテキストです。 |
