```http
POST /api/v1/alerts/sources/{id}/token
```

[アラートソース](/ja/alerting/sources)に新しいトークンを発行します。`alerts.sources.manage` 権限が必要です。リクエストボディは空にします。古いトークンは即座に無効になります。フェデレーションが有効な場合、他のクラスターでは変更が同期された時点で無効になります。古いトークンを使っている送信元では、新しいトークンに切り替えてください。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/token \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

レスポンスは、新しい `token` を含むアラートソースです。新しい `token` はこのレスポンスにのみ表示されます。

**エラー**

| ステータス | 原因 |
|---|---|
| `403` | トークンに `alerts.sources.manage` 権限がありません。 |
| `404` | アラートソースが存在しません。 |
