```http
GET /api/v1/alerts/sources/{id}/requests
```

[アラートソース](/ja/alerting/sources)が最近受信したリクエストを、新しい順に返します。`alerts.sources.read` が必要です。各ソースの直近500件のリクエストを、処理したクラスターに最長7日間保持します。

**クエリパラメーター**

| パラメーター | 型 | 説明 |
|---|---|---|
| `limit` | 整数 | 返す件数です。1〜200を指定できます。デフォルトは50です。 |

| フィールド | 説明 |
|---|---|
| `receivedAt` | 受信時刻です。単位はマイクロ秒です。 |
| `viaCluster` | リクエストを転送したフェデレーションクラスターです。直接受信した場合は空です。 |
| `status` | `accepted`（受理）、`rejected`（拒否）、`forwarded`（受信側クラスターに転送）のいずれかです。 |
| `httpStatus` | 送信元に返したHTTPステータスです。 |
| `message` | リクエストを拒否した理由、または何も処理しなかった理由です。 |
| `alertCount` | リクエストに含まれていたアラートの件数です。 |
| `alerts` | 最大100件のアラートについて、アクション、重複排除キー、タイトル、重大度、処理結果（[アラートの送信](/ja/api/alerting/send-alerts)を参照）、理由、インシデントIDを返します。 |
| `bodyExcerpt` | 拒否したリクエストの本文の先頭部分です。最大16 KiBです。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/requests?limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>
