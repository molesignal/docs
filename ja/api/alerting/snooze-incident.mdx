```http
POST /api/v1/alerts/incidents/{id}/snooze
DELETE /api/v1/alerts/incidents/{id}/snooze
```

`POST` は、アクティブなインシデントを `durationSecs` で指定した秒数だけスヌーズします。 `open` 状態のインシデントは、呼び出し元が先に確認済みにします。スヌーズ中は通知もエスカレーションも行いません。 `snoozedUntil` を過ぎると、インシデントは `open` に戻り、担当者には次の理由を示すエスカレーション通知が届きます。 `escalation.reason` は `snooze_ended` です。スヌーズ中のインシデントを再度スヌーズすると、終了時刻を更新します。

`DELETE` はスヌーズを即座に終了します。インシデントは `acknowledged` のままです。どちらの呼び出しにも `alerts.incidents.acknowledge` 権限が必要です。`DELETE` にはボディがありません。

**ボディ**

| フィールド | 型 | 必須 | 補足 |
|---|---|---|---|
| `durationSecs` | 整数 | はい | 60（1 分）〜 604800（7 日）です。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/snooze \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"durationSecs": 3600}'
```
</RequestExample>

レスポンスは更新後のインシデントです。各フィールドの詳細は、[インシデントの一覧を取得する](/ja/api/alerting/list-incidents)を参照してください。

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | `durationSecs` が 60 未満または 604800 を超えています。 |
| `403` | トークンに `alerts.incidents.acknowledge` 権限がないか、インシデントがトークンのアクセス範囲外です。 |
| `404` | インシデントが存在しません。 |
| `409` | インシデントが復旧したか、別のインシデントに統合されたか、更新中に変更が続きました。再試行してください。 |
