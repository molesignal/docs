```http
DELETE /api/v1/alerts/sources/{id}
```

[アラートソース](/ja/alerting/sources)を削除します。削除には `alerts.sources.manage` が必要です。ソースのトークンはすぐに無効になり、直近に受信したリクエストも削除されます。ソースがなくなると復旧通知を受信できなくなるため、未解決のインシデントは呼び出し元ユーザーの名義で解決します。フェデレーションが有効な場合は、削除の同期後、他のクラスターでもそれぞれ、そのソースの未解決インシデントを解決します。

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

成功すると、ステータス `200` とテキスト `deleted` を返します。

**エラー**

| ステータス | 原因 |
|---|---|
| `403` | トークンに `alerts.sources.manage` 権限がありません。 |
| `404` | ソースが存在しません。 |
