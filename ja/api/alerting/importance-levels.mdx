```http
GET /api/v1/alerts/importance
PUT /api/v1/alerts/importance
```

`GET` には `alerts.importance.read`、`PUT` には `alerts.importance.manage` が必要です。どちらも組織のレベルを返します。

```json
{
  "levels": {
    "priorities": [
      {"priority": "P1", "name": "Critical business impact", "description": "Customers cannot pay"},
      {"priority": "P2", "name": "", "description": ""},
      {"priority": "P3", "name": "", "description": ""}
    ],
    "urgencies": [
      {"key": "urgent", "name": "Urgent", "escalates": true, "quietHours": "switch", "steps": "high", "severities": ["critical"]},
      {"key": "high", "name": "", "escalates": true, "quietHours": "switch", "steps": "high", "severities": ["error"]},
      {"key": "low", "name": "", "escalates": false, "quietHours": "block", "steps": "low", "severities": ["warning", "info"]}
    ]
  },
  "updatedBy": "3KF1...",
  "updatedAt": 1793059200000000
}
```

レベルを保存したことがない組織には、組み込みのレベル（`P1` から `P5`、および [緊急度](/ja/alerting/on-call#緊急度)で説明する `high` と `low`）を返します。このとき `updatedBy` は空です。`PUT` は `levels` オブジェクトを受け取ってレベルを置き換え、監査イベント `alert_importance.updated` を記録します。

| フィールド | 説明 |
|---|---|
| `priorities` | レベルは 1～9 個です。`P1`、`P2`、… のように欠番なしで指定します。`name` は最大 32 文字、`description` は最大 200 文字です。`name` が空の場合はキーを使います。 |
| `urgencies` | レベルは 2～5 個です。緊急度の高い順に指定します。`key` は英小文字で始め、英小文字、数字、アンダースコアのみで最大 32 文字にします。`high` と `low` は必須です。`name` は最大 32 文字です。空の場合は組み込みの名前を使います。 |
| `escalates` | `true` の場合はエスカレーションポリシーのステップに沿って呼び出します。`false` の場合は最初のステップでのみ通知します。 |
| `quietHours` | `switch` は各ユーザーの **通知を抑制する時間帯も緊急度の高いアラートを受信** の設定に従います。`block` は通知を抑制する時間帯に誰も呼び出しません。 |
| `steps` | レベルが使用する、各ユーザーの 2 つのステップグループのいずれかを指定します（`high` または `low`）。 |
| `severities` | ポリシーが重大度に基づいて緊急度を設定する場合に、このレベルに割り当てる重大度です。`critical`、`error`、`warning`、`info` はそれぞれ 1 つのレベルにのみ割り当てます。 |

ルール、エスカレーションポリシー、インシデント、API では、設定済みのレベルだけを指定できます。設定範囲外の優先度や未定義の緊急度を指定すると `400` エラーになります。外部アラートやアラートパイプラインで設定範囲外の優先度を指定すると、最も低い優先度が適用されます。組織に定義されていない緊急度は無視されます。通知にはレベル名が `{{priority_name}}` と `{{urgency_name}}` として含まれます。

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/importance \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d @levels.json
```
</RequestExample>

**エラー**

| ステータス | 理由 |
|---|---|
| `400` | レベルが上の表のルールに違反しています。 |
| `403` | トークンに必要な権限がありません。 |
| `422` | フィールドの型が正しくないか、キーが無効です。 |
