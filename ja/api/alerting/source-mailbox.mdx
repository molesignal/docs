```http
GET    /api/v1/alerts/sources/{id}/mailbox
PUT    /api/v1/alerts/sources/{id}/mailbox
DELETE /api/v1/alerts/sources/{id}/mailbox
POST   /api/v1/alerts/sources/{id}/mailbox/test
```

[メールソース](/ja/alerting/sources#メール)が読み取る IMAP メールボックスです。読み取りには `alerts.sources.read`、変更とテストには `alerts.sources.manage` が必要です。種類が `email` のソースにのみ設定できます。ソースの受信クラスターで設定し、フェデレーションでは同期しません。`PUT` を実行する前に、ソースの送信者リスト（`email.allowed_senders`）を設定してください。

**`PUT` と `test` のリクエストボディ**

| フィールド | 型 | 説明 |
|---|---|---|
| `host` | string | 必須です。スキームやポートを含まないホスト名を指定します。 |
| `port` | integer | デフォルトは 993 です。 |
| `security` | string | `tls`（デフォルト）、`starttls`、`none` のいずれかです。 |
| `username` | string | 必須です。 |
| `secret` | string | パスワードまたはクライアントシークレットです。レスポンスには含まれません。空にすると既存の値を保持します。 |
| `auth` | object | `{"kind": "password"}`（デフォルト）を指定します。クライアント認証情報で取得したトークンを `XOAUTH2` で使用する場合は、`{"kind": "oauth2", "tokenUrl": "https://…", "clientId": "…", "scope": "…"}` を指定します。 |
| `folder` | string | デフォルトは `INBOX` です。 |
| `pollSecs` | integer | 読み取り間隔を秒単位で指定します。範囲は 15～3600 で、デフォルトは 60 です。 |

接続先は、接続時にホスト名を解決して得たアドレスに限ります。クラウドのメタデータアドレスには接続しません。ホスト、アカウント、フォルダーのいずれかを変更すると、次回の接続時に読み取り位置をリセットします。

**`GET` と `PUT` のレスポンス**（未設定の場合、`GET` は `null` を返します）

| フィールド | 説明 |
|---|---|
| `settings` | 上記の設定から `secret` を除いたものです。 |
| `secretSet` | シークレットが設定されているかどうかを示します。 |
| `reading` | 接続済みで、接続後に届くメールを読み取っているかどうかを示します。 |
| `lastPolledAt`, `lastSuccessAt` | 最後に読み取りを試みた時刻と、最後に読み取りに成功した時刻です（マイクロ秒単位）。 |
| `lastError` | 最後の読み取りが失敗した理由です。読み取りに成功するとクリアされます。 |

`test` はリクエストボディの設定で 1 回接続します（`secret` が空の場合は保存済みの値を使用します）。成功時は `{"ok": true, "messages": 3}` を返し、失敗時はメールサーバーのメッセージとともに `503` を返します。

<RequestExample>
```bash cURL
curl -X PUT "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/mailbox" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"host": "imap.example.com", "username": "alerts@example.com", "secret": "<password>"}'
```
</RequestExample>
