```http
DELETE /api/v1/alerts/routing/rules/{id}
```

[ルーティングルール](/ja/alerting/routing#ルーティングルール)を削除します。この操作には `alerts.routing.manage` が必要です。削除したルールに一致するはずだった新規インシデントは、そのルールより後に並ぶルールに従ってルーティングします。すでにオープンしているインシデントでは、記録済みのルール名も含め、オープン時のルーティングを維持します。

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/routing/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "deleted": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1" }
```
</ResponseExample>

**エラー**

| ステータス | 原因 |
|---|---|
| `403` | トークンに `alerts.routing.manage` 権限がありません。 |
| `404` | ルールが存在しないか、別の組織に属しています。 |
