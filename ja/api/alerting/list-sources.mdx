```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

最初の呼び出しは組織の[アラートソース](/ja/alerting/sources)を一覧表示し、2 回目は 1 つのソースを返し、3 回目はこのクラスタのフェデレーション ID（`local`、フェデレーションがない場合は空）と、ソースが受信クラスタとして選択できるクラスタを返します。3 つすべてに `alerts.sources.read` が必要です。API はトークンまたはそのハッシュを返すことはありません。

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | ソース ID。 |
| `name` | string | 名前。 |
| `kind` | string | `api`、`alertmanager`、`grafana`、`datadog`、`pagerduty`、`aliyun_cms`、`tencent_monitor`、`aws_cloudwatch`、`zabbix`、`azure_monitor`、`gcp_monitoring`、`huawei_ces` または `email`。 |
| `enabled` | boolean | 無効化されたソースはアラートを拒否します。 |
| `escalationPolicyId` | string \| null | インシデントが従うエスカレーションポリシー。`default` はデフォルトポリシーで、`null` は何もエスカレートせず通知のみを行います。 |
| `severity` | string | アラートに重大度が含まれていない場合に使用します。 |
| `labels` | object | このソースが作成するすべてのインシデントに付与される追加ラベル。 |
| `tokenPrefix` | string | トークンプレフィックス `mspat-<10>`。トークン全体は作成時とローテーション時に 1 回だけ返されます。 |
| `homeCluster` | string | インシデントが作成されるフェデレーションクラスタ。このクラスタの場合は空です。 |
| `intakePath` | string | 取り込みアドレスのパス。すべてのソースで同じです。 |
| `lastIntakeAt` | integer \| null | このクラスタが最後にこのソースからリクエストを受信した時刻（マイクロ秒）。 |
| `createdBy`, `createdAt`, `updatedAt` | | 作成者と作成日時、および最後に変更された日時（マイクロ秒）。 |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

ソースが受信クラスタとして選択できるクラスタ:

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
