```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

1 つ目の呼び出しは組織の[アラートソース](/ja/alerting/sources)を一覧表示し、2 つ目は単一のソースを返します。3 つ目は、このクラスターのフェデレーション ID（`local`、フェデレーションを使用していない場合は空）と、ソースの受信先として選択できるクラスターを返します。いずれの呼び出しにも `alerts.sources.read` が必要です。API はトークンやそのハッシュを返しません。

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | ソース ID です。 |
| `name` | string | ソースの名前です。 |
| `kind` | string | `api`、`alertmanager`、`grafana`、`datadog`、`pagerduty`、`aliyun_cms`、`tencent_monitor`、`aws_cloudwatch`、`zabbix`、`email` のいずれかです。 |
| `enabled` | boolean | 無効なソースはアラートを受け付けません。 |
| `escalationPolicyId` | string \| null | このソースのインシデントに適用するエスカレーションポリシーです。`default` はデフォルトのポリシーを適用し、`null` はエスカレーションせずに通知のみを送信します。 |
| `severity` | string | アラートに重大度が指定されていない場合に使用します。 |
| `labels` | object | このソースが作成するすべてのインシデントに追加するラベルです。 |
| `tokenPrefix` | string | トークンのプレフィックス `mspat-<10>` です。トークン全体は、作成時とローテーション時にそれぞれ 1 回だけ返します。 |
| `homeCluster` | string | このソースのインシデントを作成するフェデレーションクラスターです。このクラスターで作成する場合は空です。 |
| `intakePath` | string | 受信先アドレスのパスです。すべてのソースで共通です。 |
| `lastIntakeAt` | integer \| null | このクラスターがこのソースから最後にリクエストを受信した時刻です。単位はマイクロ秒です。 |
| `createdBy`, `createdAt`, `updatedAt` | | ソースの作成者、作成時刻、最終更新時刻です。時刻の単位はマイクロ秒です。 |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

ソースの受信先として選択できるクラスターは次のとおりです。

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
