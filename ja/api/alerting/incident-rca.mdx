```http
GET /api/v1/alerts/incidents/{id}/rca
POST /api/v1/alerts/incidents/{id}/rca
```

[Mole Agent](/ja/agent) は、インシデントのコンテキストに基づいて根本原因分析（RCA）を作成します。分析はインシデントごとに最大1件です。

`alert` ロールは分析を自動で作成します。組織に API キーが設定された有効なモデルプロバイダーがある場合、3分ごとに、分析がまだないアクティブなインシデントを対象として、1回の処理で最大20件の分析を作成します。`GET` 呼び出しは保存済みの分析を取得します。`POST` 呼び出しは新しい分析をすぐに生成し、保存済みの分析を置き換えます。

| 呼び出し | 権限 | 備考 |
|---|---|---|
| `GET` | `alerts.incidents.read` | 分析が作成されるまでは、`no root-cause analysis for this incident yet` を含む `404` を返します。 |
| `POST` | `alerts.incidents.rca` | モデルの応答を待ち、新しい分析を返します。オプションのクエリパラメーター `locale` で、出力言語として `en-us` または `zh-cn` を指定できます。デフォルトでは、呼び出し元ユーザーの言語設定を使用します。 |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/rca?locale=en-us" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**レスポンス**

| フィールド | 備考 |
|---|---|
| `incidentId`, `orgId` | インシデントと組織の識別子です。 |
| `summary` | Markdown 形式の分析テキストです。 |
| `provider`, `model` | モデルプロバイダーの種類（`openai`、`anthropic`、`openai_compatible` など）とモデル名です。 |
| `promptBuiltinKey`, `promptHash` | 監査用のプロンプトテンプレートと、レンダリング済みプロンプトのハッシュです。 |
| `promptTokens`, `completionTokens`, `finishReason` | プロバイダーが報告するトークン使用量と生成の終了理由です。 |
| `createdAt`, `updatedAt` | Unix エポックからの経過時間（マイクロ秒）です。分析を再生成すると `updatedAt` が変わります。 |

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | `POST` 呼び出しの対象組織に、API キーが設定された有効なモデルプロバイダーがありません。 |
| `403` | トークンに呼び出しに必要な権限がありません。 |
| `404` | インシデントが存在しないか、`GET` 呼び出しの対象となる分析がまだありません。 |
