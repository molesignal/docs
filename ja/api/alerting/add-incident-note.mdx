```http
POST /api/v1/alerts/incidents/{id}/notes
```

インシデントのステータスに関係なく、[タイムライン](/ja/api/alerting/incident-timeline)にメモを追加します。Mole Agent は、インシデント情報とあわせて最新のメモを読み取ります。この呼び出しには `alerts.incidents.update` 権限が必要です。

**ボディ**

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| `text` | 文字列 | はい | 1〜4,000 文字。先頭と末尾の空白は取り除きます。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/notes \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"text": "Rolled back the edge proxy."}'
```
</RequestExample>

レスポンスは、追加したメモのタイムラインエントリーです。

<ResponseExample>
```json 200
{
  "id": "3KEE1aXy7pRtGd2s9Lm4Qv8bNcE",
  "orgId": "<organization-id>",
  "incidentId": "3KEDNEyqouYJeBDTLTMTBui7XHW",
  "at": 1790000300000000,
  "kind": "note",
  "actor": "<user-id>",
  "detail": {
    "text": "Rolled back the edge proxy.",
    "via": "api"
  }
}
```
</ResponseExample>

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | `text` が空か、4,000 文字を超えています。 |
| `403` | トークンに `alerts.incidents.update` 権限がないか、トークンで対象のインシデントにアクセスできません。 |
| `404` | インシデントが存在しません。 |
