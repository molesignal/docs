```http
PUT /api/v1/alerts/routing/rules/order
```

組織の[ルーティングルール](/ja/alerting/routing#ルーティングルール)を指定した順序に並べ替えます。`alerts.routing.manage` 権限が必要です。指定したルールを指定順で先頭に配置し、残りのルールは元の順序のまま後に続けます。組織のルールに対応しない ID は無視します。

| フィールド | 型 | 説明 |
|---|---|---|
| `ids` | 配列 | 必須。ルールの ID を指定します。先頭のルールから順に評価します。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/rules/order \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"ids": ["<rule-id-2>", "<rule-id-1>"]}'
```
</RequestExample>

レスポンスにはすべてのルールが並べ替え後の順序で含まれ、`position` には 0 から始まる連番が割り当てられます。詳しくは[ルールのフィールド](/ja/api/alerting/list-routing-rules#ルールのフィールド)を参照してください。

**エラー**

| ステータス | 原因 |
|---|---|
| `403` | トークンに `alerts.routing.manage` 権限がありません。 |
| `422` | `ids` が指定されていないか、`ids` 以外のフィールドが指定されています。レスポンスはプレーンテキストです。 |
