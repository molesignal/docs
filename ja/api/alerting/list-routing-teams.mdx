```http
GET /api/v1/alerts/routing/teams
```

組織内のチームを名前順（大文字と小文字を区別しない）に一覧表示します。各チームの[オンコールポリシー](/ja/alerting/routing#チームのオンコールポリシー)と、APMサービスカタログでそのチームが所有するサービスも表示します。`alerts.routing.read` 権限が必要です。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/teams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "teamId": "<team-id>",
    "name": "Payments",
    "memberCount": 4,
    "escalationPolicyId": "<policy-id>",
    "services": ["default/checkout", "default/cart"]
  }
]
```
</ResponseExample>

| フィールド | 説明 |
|---|---|
| `teamId`, `name` | チームのIDと名前です。 |
| `memberCount` | チームのメンバー数です。 |
| `escalationPolicyId` | チームのオンコールポリシーのIDです。未設定の場合は `null` になり、そのチームにルーティングされたインシデントにはデフォルトのポリシーを適用します。 |
| `services` | サービスカタログでチームに登録されている、アーカイブされていないサービスです。`namespace/name` 形式で表示します。 |
