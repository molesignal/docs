```http
GET /api/v1/auth/tokens/rum?applicationId=<id>
```

[RUM アプリケーション](/ja/rum/applications)の RUM クライアントトークンを返します。初回の呼び出し時にトークンを作成します。アプリケーションは事前に作成してください。トークンの形式は `mspat-<36>` です。トークンは取得したユーザーではなく、アプリケーションに紐づきます。権限は対象アプリケーションの `rum.write` のみに限定され、ほかのリソースにはアクセスできません。有効期限はありません。エンドユーザーが読み取れるブラウザーやモバイルアプリのコードに埋め込んでください。この呼び出しには `api_tokens.issue` 権限が必要です。

**クエリパラメーター**

| パラメーター | 型 | 必須 | 備考 |
|---|---|---|---|
| `applicationId` | 文字列 | はい | ワークスペース内のアプリケーションの識別子です。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/auth/tokens/rum?applicationId=checkout-web" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KDZpGNwn5vO9dhXyE3am4qhihX",
  "prefix": "c16jb8m5zr",
  "token": "mspat-c16jb8m5zr<secret>",
  "tokenKind": "rum_client",
  "policyId": null,
  "permissions": ["rum.write"],
  "applicationId": "checkout-web",
  "createdAt": 1790000000000000
}
```
</ResponseExample>

`applicationId` が識別子として無効な場合は `400` を返し、一致するアプリケーションがない場合は `404` を返します。SDK の `applicationId` にも同じ識別子を指定してください。[RUM アプリケーション](/ja/rum/applications#クライアントトークン)を参照してください。
