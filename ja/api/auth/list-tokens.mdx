```http
GET /api/v1/auth/tokens
```

アクティブな組織のすべての API トークンのメタデータを返します。対象には、デフォルトの取り込みトークン、RUM クライアントトークン、サービスアカウントのトークンが含まれます。平文のトークンとシークレットのハッシュは返しません。この呼び出しには `api_tokens.read` が必要です。

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "k7m2q9xv4b",
    "name": "grafana-readonly",
    "tokenKind": "personal",
    "userId": "<user-id>",
    "policyId": null,
    "permissions": ["dashboards.read", "streams.query", "streams.read"],
    "applicationId": null,
    "serviceAccountId": null,
    "expiresAt": 1798000000000000,
    "lastUsedAt": null,
    "revoked": false,
    "createdAt": 1790000000000000
  }
]
```
</ResponseExample>

| フィールド | 補足 |
|---|---|
| `tokenKind` | `personal`、`serviceAccount`、`default_intake`、`rum_client` のいずれかです。 |
| `userId` | トークンを発行したユーザーの ID です。個人トークンとデフォルトの取り込みトークンは、このユーザーとして動作します。 |
| `policyId` | トークンに適用する権限ポリシーの ID です。ポリシーがない場合は `null` です。 |
| `permissions` | トークンに固定で設定した権限です。設定がない場合は `null` です。ポリシーもない場合、トークンは、代理するユーザーまたはサービスアカウントに許可されているすべての操作を実行できます。 |
| `applicationId` | `rum_client` トークンに紐づくアプリケーションの ID です。それ以外の場合は `null` です。 |
| `serviceAccountId` | トークンが代理するサービスアカウントの ID です。該当するサービスアカウントがない場合は `null` です。 |
| `expiresAt` | 有効期限がないトークンの場合は `null` です。 |
| `lastUsedAt` | 初回使用までは `null` です。 |
| `revoked` | トークンを失効させると `true` になります。 |

## 自分のトークン

```http
GET /api/v1/me/api-tokens
```

個人トークンとデフォルトの取り込みトークンを、同じフィールド構成で返します。この呼び出しには、サインイン済みのセッションと `personal_tokens.manage` が必要です。
