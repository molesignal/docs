```http
DELETE /api/v1/auth/tokens/{id}
```

組織内の任意のトークンを即時に取り消します。取り消したトークンを使った以降のリクエストは、`401` とメッセージ `api token revoked` を返して失敗します。この呼び出しには `api_tokens.revoke` 権限が必要です。

**パスパラメーター**

| パラメーター | 型 | 説明 |
|---|---|---|
| `id` | 文字列 | トークンの発行時または一覧取得時に返される `id` です。 |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

存在しない ID を指定すると `404` を返します。データ送信に使うトークンを取り消すと送信元からのデータ送信が止まるため、先に送信元でトークンを差し替えてください。

## 自分のトークン

```http
DELETE /api/v1/me/api-tokens/{id}
```

個人用トークンのいずれか、またはデフォルトのデータ取り込みトークンを取り消します。この呼び出しには、サインイン済みのセッションと `personal_tokens.manage` 権限が必要です。自分のものではないトークンを指定すると `404` を返します。
