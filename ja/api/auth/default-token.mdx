```http
GET /api/v1/me/api-tokens/default
```

サインイン中のユーザーのデフォルト取り込みトークンを返します。初回の呼び出し時にトークンを作成します。他のトークンとは異なり、呼び出すたびにトークンを平文で返すため、**データソース**ページにすぐに使えるトークンを表示できます。このトークンはサインイン中のユーザーとして動作し、`logs.write`、`metrics.write`、`traces.write`、`profiles.write`、`apm.deploy` を含む組み込みの **データ取り込み**ポリシーに従います。トークンに有効期限はなく、`tokenKind` は `default_intake` です。呼び出しはサインイン済みのセッションから行い、`personal_tokens.manage` とポリシーの両方の権限が必要です。

<RequestExample>
```bash cURL
curl -b ms-cookies.txt http://localhost:5080/api/v1/me/api-tokens/default
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3JtzUbBKtQCD7mFELKp2zDRum9f",
  "prefix": "r4fp1xwgpe",
  "token": "mspat-r4fp1xwgpe<secret>",
  "tokenKind": "default_intake",
  "policyId": "builtin:data_intake",
  "permissions": null,
  "applicationId": null,
  "createdAt": 1790000000000000
}
```
</ResponseExample>

コレクター、エージェント、SDK エクスポーターでトークンを使用してください。[データソース](/ja/intake#取り込みトークン)を参照してください。
