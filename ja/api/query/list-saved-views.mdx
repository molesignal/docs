```http
GET /api/v1/saved_views
```

組織の保存済みビューを返します。ピン留めされたビューだけを取得するには、`?pinned=true` を追加してください。この呼び出しには `saved_views.read` 権限が必要です。

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/saved_views?pinned=true" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KE7RbW5ShK8cbrZZq4I4O3XUge",
    "orgId": "<organization-id>",
    "ownerUserId": "<user-id>",
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = 'error'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true,
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

その他のルート：`GET /api/v1/saved_views/{id}` はビューを1件返し、`DELETE /api/v1/saved_views/{id}` は `deleted` を返します。

## すべてのビューまたはピン留めされたビューを一覧表示する

ピン留めの有無を問わずビューを一覧表示するには、`pinned` を省略するか、`pinned=false` を指定してください。`pinned=false` は「ピン留めされていないビューのみ」という意味ではありません。ピン留めされたビューのショートカット一覧を作成する場合は、`pinned=true` を指定してください。

リクエストは、クエリ結果ではなく、現在の組織にあるビューの定義を返します。レスポンスは JSON 配列です。フィルターに一致するビューがない場合、`[]` は有効な結果です。存在するはずのビューが見つからない場合は、削除されたと判断する前に、認証情報が属する組織を確認し、ピン留めのフィルターを外してください。

## 保存済みクエリを読み取る

| フィールド | 用途 |
|---|---|
| `id` | 詳細取得または実行のエンドポイントに渡します。 |
| `language`, `statement` | 保存済みクエリのクエリ言語とクエリ本文です。 |
| `stream` | 保存されたストリームのコンテキストです。設定されている場合に含まれます。 |
| `timeRangeSecs` | 保存された時間範囲の長さ（秒単位）です。 |
| `tags`, `pinned` | 整理やナビゲーションに使うメタデータです。クエリのフィルターではありません。 |
| `createdAt`, `updatedAt` | マイクロ秒単位のタイムスタンプです。 |

定義を読み取っても、クエリは実行されず、対象データをクエリする権限も付与されません。必要な権限でビューを実行するには、[保存済みビューを実行する](/ja/api/query/run-saved-view)の手順に従ってください。クエリを保存するには[保存済みビューを作成する](/ja/api/query/create-saved-view)を、UI での操作手順については[保存済みビュー](/ja/saved-views)を参照してください。
