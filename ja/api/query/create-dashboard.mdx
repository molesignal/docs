```http
POST /api/v1/dashboards
```

ダッシュボードを作成します。リクエストボディでは、完全なダッシュボードモデルを `model` に格納し、必要に応じて `folderId` を指定します。`uid` は組織内で一意である必要があります。重複している場合は `409` を返します。この呼び出しには `dashboards.create` 権限が必要です。

**モデルの必須プロパティ**

| プロパティ | 説明 |
|---|---|
| `engine` | `molesignal-dashboard` を指定します。 |
| `schemaVersion` | `2` を指定します。 |
| `uid`, `title`, `tags` | ダッシュボードの識別情報です。`uid` と `title` には空でない値を指定し、`tags` には配列を指定します。 |
| `editable`, `defaultDashboard` | ブール値を指定します。 |
| `timeSettings` | `timezone`、`defaultFrom`、`defaultTo` を指定します。 |
| `refreshSettings` | `mode`、`enabled`、`defaultInterval`、`allowedIntervals` を指定します。 |
| `variables`, `annotations`, `links`, `elements` | 配列を指定します。空のダッシュボードでは空の配列を指定します。 |
| `layout` | グリッドの設定です。`type`、`columns`、`rowHeight`、`gap` を指定します。 |

モデルに必須プロパティがない場合は、`validation_failed` を伴う `400` を返し、不足しているプロパティごとに `issues` に1件の項目を含めます。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/dashboards \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "model": {
      "engine": "molesignal-dashboard",
      "schemaVersion": 2,
      "uid": "service-overview",
      "title": "Service overview",
      "tags": ["operations"],
      "editable": true,
      "defaultDashboard": false,
      "timeSettings": { "timezone": "browser", "defaultFrom": "now-6h", "defaultTo": "now" },
      "refreshSettings": { "mode": "interval", "enabled": true, "defaultInterval": "30s",
                           "allowedIntervals": ["off", "30s", "1m", "5m"] },
      "variables": [],
      "annotations": [],
      "links": [],
      "layout": { "type": "grid", "columns": 24, "rowHeight": 8, "gap": 8 },
      "elements": []
    },
    "folderId": null
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7XebQcmZojtDim7ZVdGVw594",
  "orgId": "<organization-id>",
  "folderId": null,
  "uid": "service-overview",
  "title": "Service overview",
  "tags": ["operations"],
  "model": { "engine": "molesignal-dashboard", "...": "..." },
  "version": 1
}
```
</ResponseExample>

まずエディターでパネルを作成します。次に `GET /api/v1/dashboards/{id}` で既存のダッシュボードからモデルをエクスポートし、テンプレートとして使用します。その他のルートは `GET /api/v1/dashboards`、`PUT` および `DELETE /api/v1/dashboards/{id}` です。
