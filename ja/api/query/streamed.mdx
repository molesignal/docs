```http
GET  /api/v1/query/stream
POST /api/v1/query/stream
```

常にチャンク化された NDJSON（`application/x-ndjson`）で応答します。各行は列名をキーとする JSON オブジェクトで、最終行は `{"__meta__":{"scannedRows":...,"tookMs":...}}` です。このエンドポイントはクエリを非同期ジョブに変換しません。呼び出しには `streams.query` が必要です。システムスコープでは `sys.telemetry.read` が必要です。

`POST` では、[クエリを実行する](/ja/api/query/execute)と同じリクエストボディを受け取ります。`GET` では、次のクエリパラメーターを受け取ります。

| パラメーター | 必須 | 説明 |
|---|---|---|
| `sql` | はい | SQL ステートメントです。値を指定しない場合は `400` を返します。 |
| `stream` | はい | プライマリストリームの名前です。 |
| `streamType` | いいえ | `logs`、`metrics`、`traces`、`profiles`、`extend` のいずれかです。デフォルトは `logs` です。 |
| `from`, `to` | はい | マイクロ秒単位の時間範囲です。 |
| `limit` | いいえ | 行数の上限です。 |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000

curl -G http://localhost:5080/api/v1/query/stream \
  -H "authorization: Bearer $MS_TOKEN" \
  --data-urlencode "sql=SELECT level, msg FROM app ORDER BY _timestamp DESC" \
  --data-urlencode "stream=app" \
  --data-urlencode "streamType=logs" \
  --data-urlencode "from=$((NOW-3600000000))" \
  --data-urlencode "to=$((NOW+60000000))" \
  --data-urlencode "limit=3"
```
</RequestExample>

<ResponseExample>
```text 200
{"level":"info","msg":"fine"}
{"level":"error","msg":"db pool exhausted"}
{"__meta__":{"scannedRows":5,"tookMs":173}}
```
</ResponseExample>

生成された行を順次受信できるように、プロキシでレスポンスのバッファリングを無効にし（`proxy_buffering off`）、長時間の読み取りを許可してください。ストリームをキャンセルするには、読み取りを停止してください。
