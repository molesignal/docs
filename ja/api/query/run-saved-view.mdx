```http
GET  /api/v1/saved_views/{id}
POST /api/v1/query
```

保存済みビューには、`language`、`statement`、`stream`、相対時間範囲を表す `timeRangeSecs` が保存されます。実行専用のエンドポイントはありません。Web アプリケーションは、以下の手順で 2 回のリクエストを送信します。この処理には `saved_views.read` と `streams.query` が必要です。

1. `GET /api/v1/saved_views/{id}` でビューを取得します。
2. 現在時刻を終了時刻とする絶対時間範囲を計算します。`end` はマイクロ秒単位の現在時刻で、`start` は `end` から `timeRangeSecs` に 1,000,000 を掛けた値を引いた時刻です。
3. 保存されている `language` と `statement`、計算した `timeRange`、ストリームを[クエリを実行する](/ja/api/query/execute)エンドポイントに送信します。

<RequestExample>
```bash cURL
VIEW=$(curl -s http://localhost:5080/api/v1/saved_views/$VIEW_ID \
  -H "authorization: Bearer $MS_TOKEN")

END=$(date +%s)000000
START=$((END - $(echo "$VIEW" | jq .timeRangeSecs) * 1000000))

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "{\"orgId\":\"$MS_ORG\",
       \"language\":$(echo "$VIEW" | jq .language),
       \"statement\":$(echo "$VIEW" | jq .statement),
       \"timeRange\":{\"start\":$START,\"end\":$END},
       \"stream\":{\"name\":$(echo "$VIEW" | jq .stream),\"streamType\":\"logs\"}}"
```
</RequestExample>

保存済みビューにはストリーム名のみが保存され、タイプは含まれません。ビューが属するストリームのタイプを指定してください。
