```http
POST /api/v1/folders
```

ダッシュボードフォルダーを作成します。この API 呼び出しには `dashboards.folders.manage` 権限が必要です。一覧の取得、編集、削除には、それぞれ `dashboards.folders.read`、`dashboards.folders.manage`、`dashboards.folders.delete` 権限が必要です。

**ボディ**

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `name` | 文字列 | はい | フォルダー名です。 |
| `parentId` | 文字列または `null` | いいえ | 同じ組織内にある親フォルダーの ID です。`null` を指定すると、最上位にフォルダーを作成します。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parentId":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "orgId": "<organization-id>",
  "name": "Operations",
  "parentId": null
}
```
</ResponseExample>

`GET /api/v1/folders` はフォルダーの一覧を返します。`DELETE /api/v1/folders/{id}` は `{"deleted": "<id>"}` を返します。フォルダー内にダッシュボードまたはサブフォルダーが残っている場合は、`409` を返します。
