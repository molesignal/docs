```http
POST /api/v1/query/search_around
```

対象イベントの前後それぞれ24時間の範囲から、直前と直後のイベントを返します。取得件数のデフォルトは50件で、1〜1000件の範囲で指定できます。呼び出しには `streams.query` が必要です。システムテレメトリの場合は `sys.telemetry.read` が必要です。

`before` には、タイムスタンプがポインターの時刻以前のイベントが新しい順に入ります。対象イベントが保存されている場合は、そのイベント自体が先頭行に入ります。`after` には、タイムスタンプがポインターの時刻より後のイベントが古い順に入ります。ストリームが存在しない場合は、エラーではなく、空の `before` と `after` を返します。

**ボディ**

| フィールド | 型 | 必須 | デフォルト |
|---|---|---|---|
| `eventTimestampUs` | 整数 | はい | |
| `stream` | 文字列 | はい | |
| `streamType` | 文字列 | はい | |
| `eventFingerprint` | 文字列 | いいえ | 指定した値をそのまま `pointer` に含めて返します。サーバーはイベントの選択には使用しません。 |
| `before` | 整数 | いいえ | 50 |
| `after` | 整数 | いいえ | 50 |

<ResponseExample>
```json 200
{
  "pointer": { "ts": 1790000000000000, "fingerprint": null },
  "before": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1789999999500000, "..."]],
    "scannedRows": 100,
    "tookMs": 4
  },
  "after": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1790000000500000, "..."]],
    "scannedRows": 100,
    "tookMs": 4
  }
}
```
</ResponseExample>
