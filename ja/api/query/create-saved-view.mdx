```http
POST /api/v1/saved_views
```

相対時間範囲を指定してクエリを保存します。この呼び出しには `saved_views.create` が必要です。

**ボディ**

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| `name` | 文字列 | はい | 表示名です。 |
| `language` | 文字列 | はい | `sql` または `promql` を指定します。 |
| `statement` | 文字列 | はい | クエリのテキストです。 |
| `timeRangeSecs` | 整数 | はい | 1～31,622,400 秒の相対時間範囲です。範囲外の値を指定すると `400` を返します。 |
| `stream` | 文字列 | いいえ | プライマリストリームの名前です。 |
| `tags` | 文字列の配列 | いいえ | フィルタリングに使用するラベルです。 |
| `pinned` | ブール値 | いいえ | ビューを先頭に表示します。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/saved_views \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = '"'"'error'"'"'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true
  }'
```
</RequestExample>

作成したビューを、[保存済みビューの一覧取得](/ja/api/query/list-saved-views)に示す形式で返します。
