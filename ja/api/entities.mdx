```http
GET /api/v1/entities
GET /api/v1/entities/detail?kind={kind}&key={key}
```

エンティティは5分ごとに、APM が認識するインスタンスと、メトリクスおよびログのリソースフィールドから読み取られます。フィールドとキーについては[インフラストラクチャ](/ja/infrastructure)を参照してください。どちらの呼び出しにも `apm.services.read`、`metrics.read`、`logs.read`、または `sys.telemetry.read` のいずれかが必要です。

## エンティティの一覧

| パラメーター | 備考 |
|---|---|
| `kind` | `cluster`、`node`、`host`、`pod`、または `container`。省略した場合はすべての種類です。 |
| `search` | 名前またはキーの一部（大文字と小文字を区別しない）。 |
| `seenSince` | この時刻以降に確認されたエンティティのみ（マイクロ秒単位）。 |
| `limit` | デフォルトで最大500件。 |

エンティティは、最後に確認されたものから順に返されます。`services` は、各エンティティ上で直接実行されているサービスの数を示します。

<ResponseExample>
```json 200
[
  {
    "kind": "pod",
    "key": "prod-eu/shop/checkout-7d9f-abcde",
    "name": "checkout-7d9f-abcde",
    "attributes": {
      "k8s.cluster.name": "prod-eu",
      "k8s.namespace.name": "shop",
      "k8s.node.name": "node-3",
      "k8s.pod.name": "checkout-7d9f-abcde"
    },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000,
    "services": 1
  }
]
```
</ResponseExample>

## エンティティを1件取得

`kind` と `key` は必須です。`key` は一覧で返されるキーです。応答には、エンティティ自体、それが実行されている対象または所属している対象（`parents`）、その上で実行されているものまたはその一部であるもの（`children`、最大200件）、およびそのエンティティ上のサービスと、その上で実行されているもの上のサービス（`services`、最大200件）が含まれ、3階層下まで検索されます。クラスターのノード、それらのポッド、およびそれら上のサービスです。

<ResponseExample>
```json 200
{
  "entity": {
    "kind": "node",
    "key": "prod-eu/node-3",
    "name": "node-3",
    "attributes": { "k8s.cluster.name": "prod-eu", "k8s.node.name": "node-3" },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000
  },
  "parents": [{ "kind": "cluster", "key": "prod-eu", "name": "prod-eu" }],
  "children": [{ "kind": "pod", "key": "prod-eu/shop/checkout-7d9f-abcde", "name": "checkout-7d9f-abcde" }],
  "services": [{ "namespace": "shop", "name": "checkout", "environment": "production" }]
}
```
</ResponseExample>

**エラー**

| ステータス | 原因 |
|---|---|
| `400` | `kind` が5種類のいずれでもありません。 |
| `404` | この種類とキーに一致するエンティティが過去1週間に確認されませんでした。 |
