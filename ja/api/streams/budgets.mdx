バジェットは、ソースの使用量が上限に近づいたときや上限を超えたときに通知するだけです。取り込み時の応答やデータの保存方法は変わりません。[取り込み使用量とバジェット](/ja/streams#データ取り込み量と予算)を参照してください。

## バジェットの一覧を取得する

```http
GET /api/v1/streams/budgets
```

組織内のすべてのバジェットを、各ソースのラベルと現在の期間における使用状況とともに返します。`intake_usage.read` が必要です。`_sys` 組織では `sys.telemetry.read` が必要です。不明な数値は `null` になります。

## バジェットを設定する

```http
POST /api/v1/streams/budgets
```

ソースのバジェットを設定します。ソースごとに設定できるバジェットは1つです。再度設定すると、既存のバジェットが更新されます。`intake_budgets.manage` が必要です。`_sys` 組織ではバジェットを設定できません。

| フィールド | 必須 | 備考 |
|---|---|---|
| `dimension` | はい | `credential`、`stream`、または `service` です。 |
| `sourceKey` | はい | [取り込み使用量](/ja/api/streams/usage)が返すソースのキーです。プラットフォーム自体のテレメトリ、サービス名のないイベント、サービス数の上限を超えた分のサービスには、バジェットを設定できません。 |
| `period` | はい | UTCのカレンダーに基づく `day` または `month` です。 |
| `limitSize` | はい | 上限をMiB単位で指定します。範囲は1～1073741824です。 |
| `warnPercent` | いいえ | 警告を通知する使用量を、上限に対する割合として0～99の範囲で指定します。`0` の場合は、使用量が上限に達したときにのみ通知します。デフォルトは80です。 |
| `notifyUserIds` | いいえ | 通知先の組織メンバーを最大50人まで指定します。デフォルトはバジェットを設定するメンバーです。サービスアカウントで設定する場合は、通知先を指定してください。 |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/streams/budgets" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"dimension":"stream","sourceKey":"logs:app","period":"day","limitSize":102400}'
```
</RequestExample>

## バジェットを削除する

```http
DELETE /api/v1/streams/budgets/{budgetId}
```

`204` を返します。`intake_budgets.manage` が必要です。
