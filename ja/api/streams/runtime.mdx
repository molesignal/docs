```http
GET /api/v1/streams/runtime
```

各ストリームの実行時の状態を返します。保存済みの行数とバイト数、最終受信時刻、取り込みステータス、バケットの時系列が含まれます。この呼び出しには `streams.read` が必要です。システムテレメトリの場合は `sys.telemetry.read` が必要です。トークンに `audit.read` がない場合、`_audit` ストリームは結果に含まれません。

**クエリパラメーター**

| パラメーター | デフォルト | 説明 |
|---|---|---|
| `windowSecs` | 86400 | 時間ウィンドウの長さです。3600～604800 の範囲で指定します。 |
| `bucketCount` | 24 | 時系列のバケット数です。6～48 の範囲で指定します。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/runtime?windowSecs=3600" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

| `status` | 意味 |
|---|---|
| `healthy` | 過去 15 分以内にデータを受信しています。 |
| `delayed` | 最後にデータを受信してから 15 分を超え、2 時間未満です。 |
| `interrupted` | 最後にデータを受信してから 2 時間を超えています。 |
| `idle` | Mole Agent のトレースストリームなど、設計上データの受信が少ないストリームです。 |
| `unused` | ストリームはこれまでデータを受信していません。 |
| `unknown` | 統計情報を取得できません。 |

`staleIndexFiles` は、ストリームのインデックスタイプを最後に変更する前の設定でインデックス化されたままのファイル数です。バックグラウンドで再インデックス化が進むにつれて減少し、完了すると 0 になります。
