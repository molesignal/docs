```http
POST /api/v1/streams
```

初回の書き込み時にもストリームを作成します。スキーマ、インデックス、暗号化フィールド、保持期間を明示してストリームを事前に定義するには、この API を呼び出してください。この呼び出しには `streams.create` 権限が必要です。

**ボディ**

| フィールド | 型 | 必須 | 補足 |
|---|---|---|---|
| `name` | string | はい | 使用できる文字は英字、数字、`_`、`-`、`.` です。`_molesignal` や `_audit` などの[プラットフォームストリーム](/ja/streams#プラットフォームストリーム)の名前は予約済みです。 |
| `streamType` | string | はい | `logs`、`metrics`、`traces`、`profiles`、`extend` のいずれかです。 |
| `fields` | array | いいえ | フィールド定義です。詳細は以下を参照してください。 |
| `retentionDays` | integer | いいえ | 1～3650 を指定します。**設定 → データ保持**のプラットフォーム既定値を使う場合は省略してください。 |
| `settings` | object | いいえ | `description` や `queryable` などのストリーム設定です。[保持期間と設定を編集する](/ja/api/streams/edit-retention)を参照してください。 |

フィールドには次のプロパティがあります。

| プロパティ | 型 | 補足 |
|---|---|---|
| `name` | string | フィールド名です。 |
| `dataType` | string | `bool`、`int64`、`float64`、`utf8`、`timestamp`、`json` のいずれかです。 |
| `nullable` | boolean | デフォルトは `true` です。 |
| `indexType` | string | `none`、`exact`、`full_text`、`bloom`、`skip`、`ngram`、`ip`、`key_value`、`range` のいずれかです。デフォルトは `none` です。 |
| `encrypted` | boolean | 保存時にフィールドを暗号化します。この設定は後から変更できません。[ストリーム](/ja/streams#暗号化フィールド)を参照してください。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "app",
    "streamType": "logs",
    "fields": [
      { "name": "trace_id", "dataType": "utf8", "nullable": true,
        "indexType": "exact", "encrypted": false }
    ],
    "retentionDays": 30
  }'
```
</RequestExample>

**エラー**

| ステータス | 原因 |
|---|---|
| `403` | 指定した名前がプラットフォームストリームの名前と一致しているか、トークンに `streams.create` 権限がありません。 |
| `409` | 同じ名前と型のストリームがすでに存在します。 |
| `422` | ボディに必要なフィールドがないか、フィールドの値が無効です（未定義の `dataType` など）。レスポンスはプレーンテキストです。 |
