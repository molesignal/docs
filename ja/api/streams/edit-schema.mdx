```http
PUT /api/v1/streams/{id}/settings
```

取り込み時に新しいフィールドが追加されると、ストリームのスキーマが更新されます。API は既存のフィールドの型を変更しません。このエンドポイントを使って、スキーマに定義済みのフィールドのインデックスの種類を指定します。呼び出しには `streams.configure` が必要です。`_audit` ストリームの場合は、`audit.read` も必要です。同じエンドポイントで保持期間と設定も編集できます。[保持期間と設定を編集する](/ja/api/streams/edit-retention)を参照してください。

**ボディ**

| フィールド | 型 | 備考 |
|---|---|---|
| `fields` | array | 設定するフィールドごとに 1 つのエントリを指定します。 |

`fields` の各エントリ：

| プロパティ | 型 | 備考 |
|---|---|---|
| `name` | string | スキーマに定義済みのフィールドです。 |
| `indexType` | string | `none`、`exact`、`full_text`、`bloom`、`skip`、`ngram`、`ip`、`key_value`、`range` のいずれかです。[ストリーム](/ja/streams#スキーマとフィールド)を参照してください。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexType": "exact" },
      { "name": "msg", "indexType": "full_text" }
    ]
  }'
```
</RequestExample>

更新後のストリームを、[ストリームを取得する](/ja/api/streams/get)に示す形式で返します。変更後に書き込むデータには変更がすぐに適用され、書き込み済みのデータはバックグラウンドで再インデックス化されます。詳しくは、[ストリーム](/ja/streams#スキーマとフィールド)を参照してください。`full_text`、`ngram`、`ip` インデックスは `utf8` 型のフィールドにのみ使用でき、`key_value` インデックスは `json` 型のフィールドにのみ使用できます。
