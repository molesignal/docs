```http
GET /api/v1/streams/{id}
```

スキーマ、明示的に設定した `retention`、計算した `effectiveRetention`、ストリーム設定を含むストリーム定義を返します。この呼び出しには `streams.read` が必要です。システムテレメトリーの場合は `sys.telemetry.read` が必要です。`_audit` ストリームには `audit.read` も必要で、この権限がない場合は `403` を返します。

**パスパラメーター**

| パラメーター | 型 | 備考 |
|---|---|---|
| `id` | string | [ストリーム一覧](/ja/api/streams/list)で取得したストリームの `id` です。存在しない `id` を指定すると `404` を返します。 |
