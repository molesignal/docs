```http
DELETE /api/v1/streams/{id}
```

ストリーム定義を削除します。コンパクターが保存済みデータの領域を解放します。保護されたシステムストリーム `_molesignal` は削除できません。ストリームを削除すると、そのストリームを参照するダッシュボード、保存済みビュー、アラートルール、レポート、パイプラインが機能しなくなることがあります。この呼び出しには `streams.delete` 権限が必要です。`_audit` ストリームには `audit.read` 権限も必要で、この権限がない場合は `403` を返します。

**パスパラメーター**

| パラメーター | 型 | 備考 |
|---|---|---|
| `id` | string | ストリームの `id`。該当するストリームがない場合は `404` を返します。 |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/streams/$STREAM_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>
