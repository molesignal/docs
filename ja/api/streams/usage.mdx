```http
GET /api/v1/streams/usage
```

指定期間内の各ソースの取り込み量と、予算に対する消費状況を返します。`intake_usage.read` が必要です。`_sys` 組織では `sys.telemetry.read` が必要です。

値が不明な場合は、0 ではなく `null` を返します。レコードを読み取れない場合は、`available` が `false` になり、すべての値が `null` になります。指定期間の途中で計測を開始した場合は、`complete` が `false` になり、各値は下限を示します。

**クエリパラメーター**

| パラメーター | デフォルト | 備考 |
|---|---|---|
| `dimension` | `credential` | `credential`、`stream`、`service` のいずれかです。 |
| `windowSecs` | 86400 | 集計期間の長さです。3600～2678400 の範囲で指定します。期間の開始時刻は毎時 0 分です。 |

`sourceKey` は、認証情報（`apiToken`、`connector`、`user`、`internal`）の場合は `<credential_kind>:<id>`、ストリームの場合は `<stream_type>:<name>` です。サービスの場合はサービス名です。サービス名が指定されていないイベントには空文字列、上限を超えた分のサービスには `*` を使用します。

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/usage?dimension=credential&windowSecs=86400" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

## 単一ソース

```http
GET /api/v1/streams/usage/detail
```

指定期間内の単一ソースについて、合計値、時間単位の値をまとめたバケット、および残り 2 つのディメンション別の内訳を返します。内訳には、ディメンションごとに最大 20 ソースが含まれます。

| パラメーター | デフォルト | 備考 |
|---|---|---|
| `dimension` | 必須 | `credential`、`stream`、`service` のいずれかです。 |
| `sourceKey` | 必須 | `GET /api/v1/streams/usage` が返すソースキーです。 |
| `windowSecs` | 86400 | 3600～2678400 の範囲で指定します。 |
| `bucketCount` | 24 | 時系列のバケット数です。6～48 の範囲で指定します。 |
