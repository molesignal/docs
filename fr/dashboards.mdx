Un tableau de bord est une grille de panneaux qu’une équipe surveille ensemble. Chaque panneau exécute sa propre requête sur
les flux de l’espace de travail et affiche le résultat. Les variables au-dessus de la grille permettent de basculer tous les panneaux vers un autre
service, hôte ou environnement en une seule fois.

Cette page explique comment trouver et utiliser des tableaux de bord. Pour en créer ou en modifier un, consultez
[Créer un tableau de bord](/fr/dashboards/edit) et [Variables](/fr/dashboards/variables).

## Liste des tableaux de bord

Ouvrez **Tableaux de bord**. L’en-tête indique le nombre de tableaux de bord et de dossiers. Affinez la liste avec :

- le champ de filtre, qui recherche par nom ;
- les filtres **Tous**, **La mienne**, **Favoris** et **Étiquettes** ;
- un dossier ou l’option **Tous** pour afficher tous les dossiers ;
- la disposition **Grille** ou **Liste**.

L’en-tête propose aussi **Nouveau tableau de bord**, **Importer du JSON** et **Gérer les dossiers**. Cliquez sur l’étoile d’un
tableau de bord pour l’ajouter aux **Favoris**. Le menu en fin de ligne de chaque tableau de bord propose les actions suivantes :

| Action | Effet |
|---|---|
| **Ouvrir**, **Modifier**, **Partager** | Ouvre le tableau de bord, son éditeur ou sa boîte de dialogue de partage. |
| **Déplacer vers un dossier** | Déplace le tableau de bord vers un autre dossier. |
| **Créer une copie** | Crée une copie modifiable nommée `<title> copy`. |
| **Exporter en JSON** | Télécharge le modèle du tableau de bord, compatible avec **Importer du JSON**. |
| **Définir comme affichage NOC** | Affiche ce tableau de bord sur le [tableau mural NOC](#tableau-mural-noc) de ce navigateur. |
| **Supprimer** | Supprime définitivement le tableau de bord et ses panneaux. |

## Dossiers

Les dossiers regroupent les tableaux de bord sur trois niveaux au maximum. Sélectionnez **Gérer les dossiers**, puis **Nouveau dossier** pour créer un
dossier à la racine ou **Nouveau sous-dossier** pour en créer un dans le dossier sélectionné.

Les tableaux de bord sans dossier se trouvent dans le dossier **Par défaut**. Ce dossier ne peut ni changer de nom, ni être supprimé, ni contenir de
sous-dossiers. Pour supprimer un dossier, déplacez d’abord tous ses tableaux de bord et sous-dossiers.

## Consulter un tableau de bord

L’en-tête d’un tableau de bord indique son dossier, le nombre de panneaux et la dernière modification. Il propose aussi les commandes suivantes :

| Commande | Utilisation |
|---|---|
| Sélecteur de période | Définit la période de tous les panneaux. Les heures s’affichent dans le fuseau horaire défini par défaut dans les préférences personnelles. Sélectionnez **Modifier** en bas du sélecteur pour en afficher un autre. |
| **Actualiser** | Relance les requêtes de tous les panneaux. Réglez l’actualisation dans le menu à côté du bouton : **Désactivé**, **Automatique** ou un intervalle. **Automatique** ajuste l’intervalle à la période et à la largeur du panneau. |
| Variables | Sélectionnez des valeurs pour les [variables](/fr/dashboards/variables). L’adresse les conserve sous la forme `var-<name>=<value>`, de sorte qu’un lien copié ouvre la même vue. |
| **Partager** | Ouvre la [boîte de dialogue de partage](/fr/resource-sharing). |
| **Modifier** | Ouvre l’[éditeur](/fr/dashboards/edit). Un tableau de bord en lecture seule propose **Créer une copie** à la place. |
| Plus | Propose **Afficher les détails du tableau de bord** (ID, UID, propriétaire et schéma), **Affichage NOC**, **Créer une copie** et **Exporter en JSON**. |

Survolez un panneau pour afficher sa description. Le menu d’un panneau propose les actions suivantes :

| Action | Effet |
|---|---|
| **Afficher** | Affiche le panneau seul, en taille réelle. |
| **Modifier** | Ouvre le panneau dans l’éditeur. |
| **Explorer les données** | Ouvre la requête du panneau dans l’explorateur correspondant, avec les valeurs des variables déjà renseignées et la même période. |
| **Inspecter les requêtes** | Affiche les définitions des requêtes du panneau au format JSON. |
| **Partager** | Copie un lien vers le panneau. |
| **Exporter les données** | Télécharge les données du panneau au format CSV. |
| **Exporter l’image** | Télécharge une image du panneau. |
| **Copier** | Copie le JSON du panneau pour le coller dans un autre tableau de bord. |
| Liens de données | Ouvre les [liens de données](/fr/dashboards/edit#liens-de-données) du panneau. |
| **Créer une alerte** | Ouvre une nouvelle [règle d’alerte](/fr/alerting/rules) à partir de la requête du panneau. |
| **Analyse par Mole Agent** | Demande à [Mole Agent](/fr/agent) d’analyser les données affichées dans le panneau. |

## Importer un tableau de bord

Sélectionnez **Importer du JSON**, puis collez le JSON d’un tableau de bord MoleSignal ou chargez un fichier `.json`. Choisissez un dossier,
puis sélectionnez **Importer**. Utilisez le JSON téléchargé avec **Exporter en JSON** ou celui que
`GET /api/v1/dashboards/{id}` renvoie dans `model`. Son champ `engine` doit valoir `molesignal-dashboard`.

L’importation ne prend pas en charge le JSON des tableaux de bord Grafana. Recréez le tableau de bord dans l’éditeur : copiez
les expressions PromQL telles quelles dans les panneaux de métriques. Pour conserver le tableau de bord dans Grafana, accédez aux données de MoleSignal
via la [source de données Grafana](/fr/query/grafana).

## Demander un tableau de bord à Mole Agent

Demandez à [Mole Agent](/fr/agent) de préparer un brouillon de tableau de bord, par exemple « un tableau de bord pour le service
de paiement ». Mole Agent prépare un brouillon sans créer de tableau de bord et fournit un lien vers **Brouillon de tableau de bord généré par l’IA** :

1. Examinez l’**Aperçu en lecture seule**, qui utilise le même moteur de rendu qu’un tableau de bord standard.
2. Consultez la **Vérification préalable des requêtes**. Chaque requête de panneau s’exécute une fois et reçoit un statut : **Réussi**, **Résultat vide** ou
   **Ignoré**. Consultez aussi les éventuels **Avertissements de génération** ou **Problèmes à corriger**.
3. Sélectionnez **Soumettre la proposition de création**. Si la politique de création exige une validation, attendez
   l’approbation du brouillon. Sinon, sélectionnez **Confirmer et créer**.

Le brouillon reste lié à son modèle et expire au bout d’un certain temps. Pour le modifier, formulez une nouvelle demande.

## Tableaux de bord RUM intégrés

Un espace de travail qui contient des applications RUM propose des tableaux de bord en lecture seule portant les étiquettes `内置` et `rum`, à raison d’un par type
d’application :

| Tableau de bord | Pour | Données affichées |
|---|---|---|
| `RUM · 浏览器应用` | Applications dans un navigateur | Sessions, sessions sans erreur et sessions avec des signes de frustration ; LCP, INP et CLS au 75e percentile, avec leurs tendances respectives ; erreurs par source ; pages, versions, éléments qui suscitent de la frustration et hôtes lents ; pays et navigateurs. |
| `RUM · 移动应用` | Applications Android, iOS, Flutter et React Native | Sessions, sessions sans plantage ni erreur et sessions avec des signes de frustration ; évolution des sessions sans plantage, des erreurs et des plantages ; écrans, versions, plantages par version, éléments qui suscitent de la frustration et hôtes lents ; appareils et systèmes d’exploitation. |

MoleSignal installe chaque tableau de bord à la création de la première application du type correspondant. Le serveur l’installe aussi au
démarrage dans les espaces de travail qui contiennent déjà une application de ce type. Si une mise à niveau modifie un tableau de bord, MoleSignal applique la modification de la même
façon. Les variables sont **应用** (l’application), **环境** (un environnement ou **全部** pour tous
les environnements) et **间隔** (la largeur des barres d’un graphique dans le temps). Dans la
[vue d’ensemble RUM](/fr/rum#vue-d’ensemble), **Ouvrir dans le tableau de bord** ouvre le tableau de bord avec l’application et l’environnement de la
page déjà sélectionnés.

Chaque panneau repose sur une courte requête SQL. Les requêtes lisent les vues et les sessions dans `rum_views_latest` et
`rum_sessions_latest`, qui contiennent la [version la plus récente](/fr/query#dernières-versions-des-lignes-rum) de chaque vue et de chaque session.
Les percentiles ne prennent en compte que les vues pour lesquelles la valeur existe. Les chiffres correspondent à ceux de la vue d’ensemble.
Ces tableaux de bord sont en lecture seule. Pour obtenir une version modifiable, sélectionnez **Créer une copie** dans l’en-tête du tableau de bord ou dans la
liste des tableaux de bord.

## Tableau mural NOC

Sélectionnez **Tableau mural NOC** dans la barre supérieure pour ouvrir en plein écran une vue sombre conçue pour un affichage mural.
Appuyez sur `Esc` ou sélectionnez **Revenir à la console** pour quitter cette vue.

La barre d’état résume la situation de l’espace de travail : incidents actifs et niveaux de gravité, état des données en temps réel,
nombre de services, débit de requêtes et latence P95. Les panneaux affichent :

| Panneau | Données affichées |
|---|---|
| **Incidents** | Les incidents en cours. |
| **Topologie** | La topologie des services sur la dernière heure. |
| **État de santé** | Chaque service avec son débit de requêtes, sa latence P95 et son taux d’erreur. |
| **Trafic** | Les services les plus sollicités au cours des 60 dernières minutes. |

Sélectionnez **Configurer la disposition** pour personnaliser le tableau mural : appliquez un préréglage (**Exploitation de la plateforme**, **SRE** ou
**Direction**), affichez ou masquez un panneau, élargissez-le ou réduisez-le, déplacez-le vers l’avant ou l’arrière, ou sélectionnez **Réinitialiser**.
Le navigateur conserve la disposition.

Si un tableau de bord est défini comme affichage NOC, le tableau mural affiche à la place le titre de ce tableau de bord et
chacun de ses panneaux avec sa requête. Le tableau mural ne représente pas les panneaux sous forme de graphiques. Pour consulter les graphiques, ouvrez le
tableau de bord lui-même.

## Rapports et partage

Planifiez l’envoi d’un [rapport](/fr/reports) à partir d’un tableau de bord au format PDF, PNG, CSV, SVG ou JSON.
Utilisez **Partager** pour autoriser l’accès après connexion, entre espaces de travail ou via un accès public restreint. Un tableau de bord public exécute uniquement
les requêtes enregistrées dans ses panneaux et respecte la [politique de partage](/fr/settings/organization#partage-et-accès-public)
de l’espace de travail.

## Autorisations

| Autorisation | Actions autorisées |
|---|---|
| `dashboards.read` | Ouvrir les tableaux de bord et les dossiers. |
| `dashboards.create` | Créer, importer et copier des tableaux de bord. |
| `dashboards.edit` | Modifier les tableaux de bord et les dossiers. |
| `dashboards.delete` | Supprimer les tableaux de bord. |
| `dashboards.share` | Créer et renouveler les liens de partage. |
