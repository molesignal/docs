## Notes de version et préparation de la mise à niveau

Les [versions sur GitHub](https://github.com/molesignal/molesignal/releases) sont la source des notes de version officielles. La liste ci-dessous charge les détails des versions dans le navigateur. Si JavaScript est désactivé ou si la requête vers GitHub échoue, utilisez ce lien pour consulter les versions, leurs dates de publication, les changements et les fichiers téléchargeables.

### Avant une mise à niveau

1. Relevez la version en cours d’exécution avec `molesignal --version` et repérez la version cible dans les notes de version.
2. Lisez les notes de compatibilité et de migration entre les deux versions. Distinguez les préversions des versions stables.
3. Protégez PostgreSQL, le stockage objet, la configuration et les clés de chiffrement en suivant le guide [Sauvegarde et restauration](/fr/backup-restore).
4. Avant la mise à niveau en production, vérifiez dans un environnement isolé les requêtes sur les données historiques, l’ingestion contrôlée de nouvelles données, les autorisations et le fonctionnement des notifications.

Suivez les étapes de validation de la [liste de contrôle pour la mise en production](/fr/deployment/production-checklist) et du [guide de préparation à la reprise](/fr/best-practices/recovery-readiness). Les fonctionnalités Enterprise prévues ne sont pas encore livrées. Vérifiez leur disponibilité sur la page des fonctionnalités et dans les notes de la version cible.
