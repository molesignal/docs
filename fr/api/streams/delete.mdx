```http
DELETE /api/v1/streams/{id}
```

Supprime la définition du flux. Le compacteur libère l’espace occupé par les données stockées. Impossible de supprimer le flux système protégé `_molesignal`. La suppression d’un flux peut perturber les tableaux de bord, les vues enregistrées, les règles d’alerte, les rapports et les pipelines qui y font référence. L’appel exige la permission `streams.delete`. Pour le flux `_audit`, il exige aussi `audit.read` et renvoie `403` en l’absence de cette permission.

**Paramètres de chemin**

| Paramètre | Type | Remarques |
|---|---|---|
| `id` | string | L’identifiant (`id`) du flux. L’appel renvoie `404` si l’identifiant est inconnu. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/streams/$STREAM_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>
