Un budget sert uniquement à signaler qu’une source approche du seuil fixé ou le dépasse : l’ingestion continue de répondre aux requêtes et de stocker les données de la même manière. Consultez [Utilisation de l’ingestion et budgets](/fr/streams#utilisation-de-l’ingestion-et-budgets).

## Lister les budgets

```http
GET /api/v1/streams/budgets
```

Renvoie tous les budgets de l’organisation, avec le libellé de leur source et leur état pour la période en cours. Nécessite `intake_usage.read`, ou `sys.telemetry.read` dans l’organisation `_sys`. Les valeurs inconnues valent `null`.

## Définir un budget

```http
POST /api/v1/streams/budgets
```

Définit le budget d’une source. Chaque source ne peut avoir qu’un seul budget : toute nouvelle définition met à jour le budget existant. Nécessite `intake_budgets.manage`. L’organisation `_sys` ne peut pas définir de budgets.

| Champ | Obligatoire | Remarques |
|---|---|---|
| `dimension` | Oui | `credential`, `stream` ou `service`. |
| `sourceKey` | Oui | La source telle que la renvoie [Utilisation de l’ingestion](/fr/api/streams/usage). Impossible de définir un budget pour la télémétrie de la plateforme elle-même, les événements qui ne spécifient aucun service ou les services au-delà de la limite. |
| `period` | Oui | `day` ou `month`, selon le calendrier en UTC. |
| `limitSize` | Oui | En MiB, de 1 à 1073741824. |
| `warnPercent` | Non | Pourcentage de la limite à partir duquel envoyer une notification, de 0 à 99. Avec `0`, la notification ne part qu’une fois le budget épuisé. Valeur par défaut : 80. |
| `notifyUserIds` | Non | Membres de l’organisation à notifier, au maximum 50. Par défaut : le membre qui définit le budget. Un compte de service doit spécifier les destinataires. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/streams/budgets" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"dimension":"stream","sourceKey":"logs:app","period":"day","limitSize":102400}'
```
</RequestExample>

## Supprimer un budget

```http
DELETE /api/v1/streams/budgets/{budgetId}
```

Renvoie `204`. Nécessite `intake_budgets.manage`.
