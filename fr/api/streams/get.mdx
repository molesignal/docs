```http
GET /api/v1/streams/{id}
```

Renvoie la définition du flux avec son schéma, la valeur explicite de `retention`, la valeur calculée de `effectiveRetention` et les paramètres du flux. L’appel nécessite `streams.read`, ou `sys.telemetry.read` pour la télémétrie système. Le flux `_audit` nécessite aussi `audit.read` et renvoie `403` sans cette autorisation.

**Paramètres de chemin**

| Paramètre | Type | Notes |
|---|---|---|
| `id` | string | L’`id` du flux renvoyé par [Lister les flux](/fr/api/streams/list). Un identifiant inconnu entraîne une réponse `404`. |
