```http
GET /api/v1/streams
```

Renvoie tous les flux de l’organisation dans un tableau JSON, triés par nom et par type. Chaque élément suit la structure décrite dans [Obtenir un flux](/fr/api/streams/get) et comprend le schéma, la valeur explicite de `retention`, la valeur calculée de `effectiveRetention`, les paramètres et les horodatages en microsecondes. L’appel nécessite `streams.read` ou `sys.telemetry.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

La réponse inclut les flux système protégés, comme `_molesignal`. Elle omet `_audit` si le jeton ne dispose pas de `audit.read`. Le nom et le type identifient ensemble un flux. Un même nom peut donc apparaître pour plusieurs types.

## Utiliser la réponse

Ce point de terminaison renvoie des définitions de flux, pas des enregistrements de télémétrie. Utilisez-le pour trouver l’identifiant d’un flux avant de consulter son schéma ou de modifier sa configuration. Pour interroger les événements, utilisez l’[API de requête](/fr/api/query/execute).

| Champ | Interprétation |
|---|---|
| `id` | Identifiant stable utilisé par l’API de consultation d’un flux. |
| `name` et `streamType` | Identifient ensemble le jeu de données. N’utilisez pas le nom seul comme clé d’inventaire. |
| `schema` | Définitions des champs utilisées pour construire les requêtes. |
| `retention` | Durée de rétention explicitement définie pour le flux. La valeur `null` indique que la durée par défaut s’applique. |
| `effectiveRetention` | Durée de rétention effectivement appliquée au flux. |
| `createdAt`, `updatedAt` | Horodatages Unix en microsecondes, et non en millisecondes. |

## Vérifier les accès et le périmètre des données

Utilisez un jeton associé à l’organisation visée. La permission `streams.read` ou `sys.telemetry.read` autorise la requête de liste. Sans `audit.read`, la réponse omet `_audit`. L’absence de `_audit` ne signifie pas que la collecte des données d’audit est désactivée.

La réponse prend la forme d’un tableau JSON, et non d’un objet contenant un champ `items`. Cette route n’accepte aucun paramètre de pagination. Un tableau vide signifie que la requête n’a renvoyé aucun flux pour l’organisation et les droits d’accès concernés. Cela ne prouve pas qu’une autre organisation ne contient aucune donnée.

Après avoir trouvé le couple `(name, streamType)` recherché, transmettez son `id` à [Obtenir un flux](/fr/api/streams/get). Utilisez un [exemple de requête](/fr/api/query/execute) pour vérifier que des événements sont réellement disponibles, indépendamment de la présence d’une définition de flux.
