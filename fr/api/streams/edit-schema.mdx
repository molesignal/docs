```http
PUT /api/v1/streams/{id}/settings
```

Le schéma d’un flux évolue à mesure que l’ingestion ajoute de nouveaux champs. L’API ne modifie pas le type des champs. Utilisez ce point de terminaison pour choisir le type d’index des champs déjà présents dans le schéma. L’appel nécessite `streams.configure`, ainsi que `audit.read` pour le flux `_audit`. Ce point de terminaison permet aussi de modifier la rétention et les paramètres. Consultez [Modifier la rétention et les paramètres](/fr/api/streams/edit-retention).

**Corps**

| Champ | Type | Remarques |
|---|---|---|
| `fields` | tableau | Une entrée par champ à configurer. |

Chaque entrée de `fields` contient les propriétés suivantes :

| Propriété | Type | Remarques |
|---|---|---|
| `name` | chaîne | Champ déjà présent dans le schéma. |
| `indexType` | chaîne | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value` ou `range`. Consultez [Flux](/fr/streams#schéma-et-champs). |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexType": "exact" },
      { "name": "msg", "indexType": "full_text" }
    ]
  }'
```
</RequestExample>

La réponse renvoie le flux mis à jour dans le format décrit dans [Récupérer un flux](/fr/api/streams/get). La modification s’applique immédiatement aux nouvelles écritures. MoleSignal réindexe en arrière-plan les données déjà écrites. Consultez [Flux](/fr/streams#schéma-et-champs). Les index `full_text`, `ngram` et `ip` ne s’appliquent qu’aux champs `utf8`, et l’index `key_value` ne s’applique qu’aux champs `json`.
