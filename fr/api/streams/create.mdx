```http
POST /api/v1/streams
```

La première écriture crée également le flux. Utilisez cet appel pour déclarer au préalable un flux avec un schéma explicite, des index, des champs chiffrés ou une durée de conservation. Cet appel nécessite l’autorisation `streams.create`.

**Corps**

| Champ | Type | Obligatoire | Notes |
|---|---|---|---|
| `name` | chaîne | Oui | Lettres, chiffres, `_`, `-` et `.`. Les noms des [flux de la plateforme](/fr/streams#flux-de-la-plateforme), tels que `_molesignal` et `_audit`, sont réservés. |
| `streamType` | chaîne | Oui | `logs`, `metrics`, `traces`, `profiles` ou `extend`. |
| `fields` | tableau | Non | Définitions des champs. Voir ci-dessous. |
| `retentionDays` | entier | Non | De 1 à 3650. Omettez ce champ pour utiliser la valeur par défaut de la plateforme dans **Paramètres → Conservation des données**. |
| `settings` | objet | Non | Paramètres du flux, tels que `description` et `queryable`. Voir [Modifier la conservation des données et les paramètres](/fr/api/streams/edit-retention). |

Chaque champ possède les propriétés suivantes :

| Propriété | Type | Notes |
|---|---|---|
| `name` | chaîne | Nom du champ. |
| `dataType` | chaîne | `bool`, `int64`, `float64`, `utf8`, `timestamp` ou `json`. |
| `nullable` | booléen | Valeur par défaut : `true`. |
| `indexType` | chaîne | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value` ou `range`. Valeur par défaut : `none`. |
| `encrypted` | booléen | Chiffre le champ au repos. Ce paramètre ne peut plus être modifié par la suite. Voir [Flux](/fr/streams#champs-chiffrés). |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "app",
    "streamType": "logs",
    "fields": [
      { "name": "trace_id", "dataType": "utf8", "nullable": true,
        "indexType": "exact", "encrypted": false }
    ],
    "retentionDays": 30
  }'
```
</RequestExample>

**Erreurs**

| Statut | Cause |
|---|---|
| `403` | Le nom correspond à un flux de la plateforme ou le jeton ne dispose pas de l’autorisation `streams.create`. |
| `409` | Un flux du même nom et du même type existe déjà. |
| `422` | Un champ du corps de la requête est manquant ou non valide, par exemple si la valeur de `dataType` est inconnue. La réponse est en texte brut. |
