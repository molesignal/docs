```http
GET /api/v1/entities
GET /api/v1/entities/detail?kind={kind}&key={key}
```

Les entités sont lues toutes les cinq minutes depuis les instances que voit l'APM et depuis les champs de ressources des
métriques et des logs ; consultez [Infrastructure](/fr/infrastructure) pour les champs et les clés. Les deux appels nécessitent
l'une des permissions `apm.services.read`, `metrics.read`, `logs.read` ou `sys.telemetry.read`.

## Lister les entités

| Paramètre | Remarques |
|---|---|
| `kind` | `cluster`, `node`, `host`, `pod` ou `container`. Tous les types si omis. |
| `search` | Une partie du nom ou de la clé, sans tenir compte de la casse. |
| `seenSince` | Uniquement les entités vues depuis cet instant, en microsecondes. |
| `limit` | 500 au maximum, valeur par défaut. |

Les entités sont renvoyées de la plus récemment vue à la plus ancienne. `services` compte les services qui s'exécutent directement sur chacune.

<ResponseExample>
```json 200
[
  {
    "kind": "pod",
    "key": "prod-eu/shop/checkout-7d9f-abcde",
    "name": "checkout-7d9f-abcde",
    "attributes": {
      "k8s.cluster.name": "prod-eu",
      "k8s.namespace.name": "shop",
      "k8s.node.name": "node-3",
      "k8s.pod.name": "checkout-7d9f-abcde"
    },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000,
    "services": 1
  }
]
```
</ResponseExample>

## Lire une entité

`kind` et `key` sont obligatoires ; la clé est celle que fournit la liste. La réponse contient l'entité, ce sur quoi elle
s'exécute ou dont elle fait partie (`parents`), ce qui s'exécute sur elle ou en fait partie (`children`, jusqu'à 200), et les
services sur elle et sur ce qui s'exécute sur elle (`services`, jusqu'à 200), recherchés sur trois niveaux : les
nœuds d'un cluster, leurs pods, et les services exécutés sur ceux-ci.

<ResponseExample>
```json 200
{
  "entity": {
    "kind": "node",
    "key": "prod-eu/node-3",
    "name": "node-3",
    "attributes": { "k8s.cluster.name": "prod-eu", "k8s.node.name": "node-3" },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000
  },
  "parents": [{ "kind": "cluster", "key": "prod-eu", "name": "prod-eu" }],
  "children": [{ "kind": "pod", "key": "prod-eu/shop/checkout-7d9f-abcde", "name": "checkout-7d9f-abcde" }],
  "services": [{ "namespace": "shop", "name": "checkout", "environment": "production" }]
}
```
</ResponseExample>

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | `kind` ne fait pas partie des cinq types. |
| `404` | Aucune entité de ce type et de cette clé n'a été vue au cours de la dernière semaine. |
