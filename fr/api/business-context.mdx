```http
GET /api/v1/business-context
PUT /api/v1/business-context
```

Les clés métier, comme un tenant, un plan ou un groupe d'expérimentation, et le champ qui porte chacune d'elles dans les spans, les logs et les événements RUM. Voir [Contexte métier](/fr/business-context). La lecture nécessite l'une des permissions `apm.services.read`, `traces.read`, `logs.read`, `rum.events.read`, `apm.settings.read` ou `sys.telemetry.read` ; la définition nécessite `apm.settings.manage` et est consignée dans le journal d'activité.

## Définir les clés

`PUT` remplace toutes les clés. Un champ vide ne désigne rien, un `label` vide prend la valeur de la clé, et les valeurs importantes sont nettoyées et listées une seule fois chacune ; la réponse correspond à ce qui a été enregistré.

| Champ | Remarques |
|---|---|
| `key` | Commence par une lettre minuscule et ne contient que des lettres minuscules, des chiffres et `_`, sur 64 caractères au maximum. Unique. |
| `label` | Le nom affiché aux lecteurs, sur 80 caractères au maximum. |
| `span` | L'attribut de span, tel que le flux de traces nomme le champ. |
| `log` | Le champ de log. |
| `rum` | Le champ RUM, une clé d'un champ JSON inclus, comme `context.tenant`. |
| `important` | Les valeurs qui comptent le plus, 50 au maximum, de 200 caractères chacune. |

Une clé désigne au moins l'un de `span`, `log` et `rum`. 8 clés au maximum.

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/business-context \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"keys":[{"key":"tenant","label":"Tenant","span":"tenant.id","log":"tenant_id","rum":"context.tenant","important":["acme"]}]}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "keys": [
    {
      "key": "tenant",
      "label": "Tenant",
      "span": "tenant.id",
      "log": "tenant_id",
      "rum": "context.tenant",
      "important": ["acme"]
    }
  ]
}
```
</ResponseExample>

**Erreurs**

| Statut | Raison |
|---|---|
| `400` | Une clé est mal nommée ou nommée deux fois, ne désigne aucun champ, ou il y a plus de clés ou de valeurs que permis. |
| `403` | Le jeton ne dispose pas de la permission de l'appel. |
