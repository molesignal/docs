```http
GET /api/v1/auth/tokens/rum?applicationId=<id>
```

Renvoie le jeton client RUM d’une [application RUM](/fr/rum/applications) et le crée au premier appel. Créez l’application avant d’effectuer cet appel. Le jeton a la forme `mspat-<36>` et appartient à l’application, pas à la personne qui le récupère : il accorde uniquement l’autorisation `rum.write` pour cette application, ne donne accès à aucune autre ressource et n’expire jamais. Intégrez-le au code du navigateur ou de l’application mobile, où les utilisateurs finaux peuvent le lire. L’appel nécessite l’autorisation `api_tokens.issue`.

**Paramètres de requête**

| Paramètre | Type | Obligatoire | Remarques |
|---|---|---|---|
| `applicationId` | string | Oui | Identifiant d’une application de l’espace de travail. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/auth/tokens/rum?applicationId=checkout-web" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KDZpGNwn5vO9dhXyE3am4qhihX",
  "prefix": "c16jb8m5zr",
  "token": "mspat-c16jb8m5zr<secret>",
  "tokenKind": "rum_client",
  "policyId": null,
  "permissions": ["rum.write"],
  "applicationId": "checkout-web",
  "createdAt": 1790000000000000
}
```
</ResponseExample>

L’appel renvoie `400` si `applicationId` n’est pas un identifiant valide et `404` si l’identifiant ne correspond à aucune application. Utilisez le même identifiant pour `applicationId` dans le SDK. Consultez la section [Applications RUM](/fr/rum/applications#jeton-client).
