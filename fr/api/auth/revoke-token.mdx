```http
DELETE /api/v1/auth/tokens/{id}
```

Révoque immédiatement n’importe quel jeton de l’organisation. Toute requête ultérieure qui utilise ce jeton échoue avec le code `401` et le message `api token revoked`. L’appel nécessite `api_tokens.revoke`.

**Paramètres de chemin**

| Paramètre | Type | Notes |
|---|---|---|
| `id` | chaîne | L’`id` renvoyé à la création du jeton ou par la liste des jetons. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

L’appel renvoie `404` si l’identifiant est inconnu. Révoquer un jeton utilisé pour envoyer des données interrompt les envois de la source. Remplacez donc d’abord le jeton dans la configuration de la source.

## Jeton du compte courant

```http
DELETE /api/v1/me/api-tokens/{id}
```

Révoque un jeton personnel du compte courant ou son jeton d’ingestion par défaut. L’appel nécessite une session authentifiée et la permission `personal_tokens.manage`. L’appel renvoie `404` si le jeton n’appartient pas au compte courant.
