```http
GET /api/v1/auth/tokens
```

Renvoie les métadonnées de tous les jetons d’API de l’organisation active, y compris les jetons d’ingestion par défaut, les jetons clients RUM et les jetons des comptes de service. L’appel ne renvoie jamais le jeton en clair ni le hachage du secret. L’appel nécessite `api_tokens.read`.

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "k7m2q9xv4b",
    "name": "grafana-readonly",
    "tokenKind": "personal",
    "userId": "<user-id>",
    "policyId": null,
    "permissions": ["dashboards.read", "streams.query", "streams.read"],
    "applicationId": null,
    "serviceAccountId": null,
    "expiresAt": 1798000000000000,
    "lastUsedAt": null,
    "revoked": false,
    "createdAt": 1790000000000000
  }
]
```
</ResponseExample>

| Champ | Notes |
|---|---|
| `tokenKind` | `personal`, `serviceAccount`, `default_intake` ou `rum_client`. |
| `userId` | Identifiant du compte utilisateur qui a émis le jeton. Un jeton personnel ou d’ingestion par défaut agit au nom de ce compte. |
| `policyId` | Stratégie d’autorisations que le jeton applique, ou `null` en l’absence de stratégie. |
| `permissions` | Autorisations définies pour le jeton, ou `null` en l’absence d’autorisations explicites. Si aucune stratégie ne s’applique non plus, le jeton dispose de toutes les autorisations du compte utilisateur ou du compte de service au nom duquel il agit. |
| `applicationId` | Application associée au jeton `rum_client`, ou `null` en l’absence d’application associée. |
| `serviceAccountId` | Compte de service au nom duquel le jeton agit, ou `null` en l’absence de compte de service associé. |
| `expiresAt` | `null` pour un jeton qui n’expire jamais. |
| `lastUsedAt` | `null` jusqu’à la première utilisation. |
| `revoked` | `true` après la révocation du jeton. |

## Vos jetons

```http
GET /api/v1/me/api-tokens
```

Renvoie vos jetons personnels et votre jeton d’ingestion par défaut, avec les mêmes champs. L’appel nécessite une session authentifiée et l’autorisation `personal_tokens.manage`.
