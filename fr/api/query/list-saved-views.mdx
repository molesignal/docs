```http
GET /api/v1/saved_views
```

Renvoie les vues enregistrées de l’organisation. Ajoutez `?pinned=true` pour renvoyer uniquement les vues épinglées. L’appel nécessite l’autorisation `saved_views.read`.

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/saved_views?pinned=true" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KE7RbW5ShK8cbrZZq4I4O3XUge",
    "orgId": "<organization-id>",
    "ownerUserId": "<user-id>",
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = 'error'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true,
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

Autres routes : `GET /api/v1/saved_views/{id}` renvoie une seule vue et `DELETE /api/v1/saved_views/{id}` renvoie `deleted`.

## Lister toutes les vues ou uniquement les vues épinglées

Omettez `pinned` ou définissez `pinned=false` pour lister les vues sans tenir compte de leur état d’épinglage. `pinned=false` ne signifie pas « uniquement les vues non épinglées ». Définissez `pinned=true` pour créer une liste de raccourcis vers les vues épinglées.

La requête renvoie les définitions de l’organisation actuelle, et non les résultats des requêtes enregistrées. La réponse est un tableau JSON ; `[]` est un résultat valide si aucune vue ne correspond au filtre. Si une vue connue manque, vérifiez l’organisation associée aux identifiants et retirez le filtre d’épinglage avant de conclure à la suppression de la vue.

## Lire la requête enregistrée

| Champ | Utilisation |
|---|---|
| `id` | Transmettez cet identifiant au point de terminaison de consultation ou d’exécution. |
| `language`, `statement` | Langage et texte de la requête enregistrée. |
| `stream` | Contexte de flux enregistré, le cas échéant. |
| `timeRangeSecs` | Durée de la fenêtre temporelle enregistrée, en secondes. |
| `tags`, `pinned` | Métadonnées de classement et de navigation, et non filtres de requête. |
| `createdAt`, `updatedAt` | Horodatages en microsecondes. |

La lecture d’une définition n’exécute pas la requête et n’accorde pas l’autorisation d’interroger ses données. Suivez les étapes de la page [Exécuter une vue enregistrée](/fr/api/query/run-saved-view) pour exécuter une vue avec les autorisations requises. Consultez [Créer une vue enregistrée](/fr/api/query/create-saved-view) pour enregistrer une requête et [Vues enregistrées](/fr/saved-views) pour effectuer ces opérations dans l’interface.
