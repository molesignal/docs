```http
GET  /api/v1/saved_views/{id}
POST /api/v1/query
```

Une vue enregistrée stocke `language`, `statement`, `stream` et une plage temporelle relative dans `timeRangeSecs`. Aucun point de terminaison distinct ne permet d’exécuter la requête. L’application web suit cette procédure en deux requêtes, qui nécessite les autorisations `saved_views.read` et `streams.query` :

1. Chargez la vue avec `GET /api/v1/saved_views/{id}`.
2. Calculez une plage temporelle absolue qui se termine à l’instant présent : `end` correspond à l’heure actuelle en microsecondes et `start` vaut `end` moins le produit de `timeRangeSecs` par 1 000 000.
3. Envoyez les valeurs enregistrées de `language` et `statement`, la valeur calculée de `timeRange` et le flux au point de terminaison [Exécuter une requête](/fr/api/query/execute).

<RequestExample>
```bash cURL
VIEW=$(curl -s http://localhost:5080/api/v1/saved_views/$VIEW_ID \
  -H "authorization: Bearer $MS_TOKEN")

END=$(date +%s)000000
START=$((END - $(echo "$VIEW" | jq .timeRangeSecs) * 1000000))

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "{\"orgId\":\"$MS_ORG\",
       \"language\":$(echo "$VIEW" | jq .language),
       \"statement\":$(echo "$VIEW" | jq .statement),
       \"timeRange\":{\"start\":$START,\"end\":$END},
       \"stream\":{\"name\":$(echo "$VIEW" | jq .stream),\"streamType\":\"logs\"}}"
```
</RequestExample>

La vue enregistrée stocke le nom du flux sans son type. Indiquez le type du flux auquel la vue est associée.
