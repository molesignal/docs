```http
POST /api/v1/saved_views
```

Enregistre une requête avec une plage temporelle relative. L’appel nécessite `saved_views.create`.

**Corps**

| Champ | Type | Obligatoire | Notes |
|---|---|---|---|
| `name` | chaîne | Oui | Nom d’affichage. |
| `language` | chaîne | Oui | `sql` ou `promql`. |
| `statement` | chaîne | Oui | Texte de la requête. |
| `timeRangeSecs` | entier | Oui | Plage relative de 1 à 31 622 400 secondes. L’API renvoie `400` si la valeur sort de cette plage. |
| `stream` | chaîne | Non | Nom du flux principal. |
| `tags` | tableau de chaînes | Non | Étiquettes de filtrage. |
| `pinned` | booléen | Non | Affiche la vue en premier. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/saved_views \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = '"'"'error'"'"'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true
  }'
```
</RequestExample>

La réponse contient la vue créée, au format décrit dans [Lister les vues enregistrées](/fr/api/query/list-saved-views).
