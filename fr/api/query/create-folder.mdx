```http
POST /api/v1/folders
```

Crée un dossier de tableaux de bord. Cet appel nécessite `dashboards.folders.manage`. Le listage, la modification et la suppression nécessitent respectivement `dashboards.folders.read`, `dashboards.folders.manage` et `dashboards.folders.delete`.

**Corps**

| Champ | Type | Obligatoire | Notes |
|---|---|---|---|
| `name` | chaîne | Oui | Nom du dossier. |
| `parentId` | chaîne ou `null` | Non | Identifiant du dossier parent dans la même organisation. La valeur `null` crée un dossier à la racine. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parentId":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "orgId": "<organization-id>",
  "name": "Operations",
  "parentId": null
}
```
</ResponseExample>

`GET /api/v1/folders` liste les dossiers. `DELETE /api/v1/folders/{id}` renvoie `{"deleted": "<id>"}`, ou `409` si le dossier contient encore des tableaux de bord ou des sous-dossiers.
