```http
POST /api/v1/dashboards
```

Crée un tableau de bord. Le corps de la requête contient le modèle complet du tableau de bord dans `model` et peut spécifier un `folderId`. Si `uid` n’est pas unique au sein de l’organisation, l’appel renvoie `409`. L’appel nécessite l’autorisation `dashboards.create`.

**Propriétés obligatoires du modèle**

| Propriété | Notes |
|---|---|
| `engine` | `molesignal-dashboard`. |
| `schemaVersion` | `2`. |
| `uid`, `title`, `tags` | Identification. `uid` et `title` ne doivent pas être vides, et `tags` est un tableau. |
| `editable`, `defaultDashboard` | Booléens. |
| `timeSettings` | `timezone`, `defaultFrom` et `defaultTo`. |
| `refreshSettings` | `mode`, `enabled`, `defaultInterval` et `allowedIntervals`. |
| `variables`, `annotations`, `links`, `elements` | Tableaux vides pour un tableau de bord vierge. |
| `layout` | Une grille : `type`, `columns`, `rowHeight` et `gap`. |

Si une propriété obligatoire manque dans le modèle, l’appel renvoie `400` avec `validation_failed` et une entrée dans `issues` pour chaque propriété manquante.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/dashboards \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "model": {
      "engine": "molesignal-dashboard",
      "schemaVersion": 2,
      "uid": "service-overview",
      "title": "Service overview",
      "tags": ["operations"],
      "editable": true,
      "defaultDashboard": false,
      "timeSettings": { "timezone": "browser", "defaultFrom": "now-6h", "defaultTo": "now" },
      "refreshSettings": { "mode": "interval", "enabled": true, "defaultInterval": "30s",
                           "allowedIntervals": ["off", "30s", "1m", "5m"] },
      "variables": [],
      "annotations": [],
      "links": [],
      "layout": { "type": "grid", "columns": 24, "rowHeight": 8, "gap": 8 },
      "elements": []
    },
    "folderId": null
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7XebQcmZojtDim7ZVdGVw594",
  "orgId": "<organization-id>",
  "folderId": null,
  "uid": "service-overview",
  "title": "Service overview",
  "tags": ["operations"],
  "model": { "engine": "molesignal-dashboard", "...": "..." },
  "version": 1
}
```
</ResponseExample>

Créez d’abord les panneaux dans l’éditeur, puis exportez le modèle d’un tableau de bord existant avec `GET /api/v1/dashboards/{id}` pour vous en servir comme base. Autres routes : `GET /api/v1/dashboards`, `PUT` et `DELETE /api/v1/dashboards/{id}`.
