```http
DELETE /api/v1/alerts/sources/{id}
```

Supprime une [source d’alertes](/fr/alerting/sources). Cette opération nécessite l’autorisation `alerts.sources.manage`. Le jeton de la source cesse immédiatement de fonctionner, et la suppression efface aussi les requêtes reçues récemment. MoleSignal résout les incidents ouverts de la source au nom du compte à l’origine de l’appel, car sans cette source, aucun signal de rétablissement ne leur parviendrait. Si la fédération est activée, les autres clusters résolvent les incidents ouverts de la source sur leur instance dès que la suppression est synchronisée.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

En cas de succès, la réponse renvoie le statut `200` et le texte `deleted`.

**Erreurs**

| Statut | Cause |
|---|---|
| `403` | Le jeton ne dispose pas de l’autorisation `alerts.sources.manage`. |
| `404` | La source n’existe pas. |
