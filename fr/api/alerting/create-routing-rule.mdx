```http
POST /api/v1/alerts/routing/rules
```

Crée une [règle de routage](/fr/alerting/routing#règles-de-routage). Cette opération nécessite `alerts.routing.manage`. La nouvelle règle est ajoutée en dernière position. Pour la remonter, utilisez [Réorganiser les règles de routage](/fr/api/alerting/reorder-routing-rules). Une organisation peut comporter jusqu’à 200 règles de routage.

| Champ | Type | Description |
|---|---|---|
| `name` | chaîne | Obligatoire : de 1 à 128 caractères après suppression des espaces en début et en fin de chaîne. |
| `enabled` | booléen | Valeur par défaut : `true`. |
| `conditions` | tableau | Jusqu’à 16 conditions. Le tableau est vide par défaut. Une `key` contient de 1 à 512 caractères. Les opérateurs `equals`, `not_equals` et `matches` acceptent chacun une seule valeur, tandis que `in` en accepte de 1 à 100. Chaque valeur est limitée à 512 caractères. Le motif de `matches` doit pouvoir être compilé. |
| `minSeverity` | chaîne \| null | `info`, `warning`, `error` ou `critical`. Par défaut, tous les niveaux de gravité sont acceptés. |
| `origins` | tableau | Valeurs possibles : `rule`, `external` et `synthetic`. Par défaut, le tableau est vide, ce qui inclut toutes les origines. |
| `target` | objet | Obligatoire. La cible `{"kind": "team", "teamId": …}` doit désigner une équipe de l’organisation, et `{"kind": "policy", "policyId": …}` une politique d’escalade de l’organisation. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/routing/rules \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"name": "Payments in production", "conditions": [{"key": "env", "operator": "equals", "values": ["prod"]}], "minSeverity": "error", "target": {"kind": "team", "teamId": "<team-id>"}}'
```
</RequestExample>

La réponse contient la nouvelle règle. Consultez les [champs de la règle](/fr/api/alerting/list-routing-rules#champs-des-règles).

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | Un champ est incorrect : le nom est vide, une condition contient un nombre incorrect de valeurs, un motif ne peut pas être compilé, ou l’équipe ou la politique cible n’existe pas. Ce statut s’applique aussi si l’organisation compte déjà 200 règles. |
| `403` | Le jeton ne dispose pas de l’autorisation `alerts.routing.manage`. |
| `422` | Le champ `name` ou `target` est manquant, ou une valeur n’est pas reconnue, par exemple celle d’un `operator` inconnu. La réponse est en texte brut. |
