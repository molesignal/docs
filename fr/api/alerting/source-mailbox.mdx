```http
GET    /api/v1/alerts/sources/{id}/mailbox
PUT    /api/v1/alerts/sources/{id}/mailbox
DELETE /api/v1/alerts/sources/{id}/mailbox
POST   /api/v1/alerts/sources/{id}/mailbox/test
```

La boîte aux lettres IMAP que relève une [source d’e-mails](/fr/alerting/sources#e-mail). La lecture nécessite `alerts.sources.read` ; la modification et le test nécessitent `alerts.sources.manage`. Seules les sources de type `email` disposent d’une boîte aux lettres. Configurez-la sur le cluster de réception de la source. La fédération ne la synchronise pas. Avant d’effectuer un `PUT`, renseignez la liste des expéditeurs sur la source (`email.allowed_senders`).

**Corps de `PUT` et de `test`**

| Champ | Type | Description |
|---|---|---|
| `host` | chaîne | Obligatoire : nom d’hôte, sans schéma ni port. |
| `port` | entier | 993 par défaut. |
| `security` | chaîne | `tls` (par défaut), `starttls` ou `none`. |
| `username` | chaîne | Obligatoire. |
| `secret` | chaîne | Mot de passe ou secret client. La réponse ne l’inclut jamais ; une valeur vide conserve le secret existant. |
| `auth` | objet | `{"kind": "password"}` (par défaut), ou `{"kind": "oauth2", "tokenUrl": "https://…", "clientId": "…", "scope": "…"}` pour utiliser via `XOAUTH2` un jeton obtenu avec les identifiants du client. |
| `folder` | chaîne | `INBOX` par défaut. |
| `pollSecs` | entier | Intervalle entre les relèves, de 15 à 3600, 60 par défaut. |

La connexion cible uniquement l’adresse obtenue lors de la résolution du nom d’hôte à cet instant, jamais une adresse de métadonnées cloud. Un changement d’hôte, de compte ou de dossier réinitialise la position de lecture à la connexion suivante.

**Réponse de `GET` et de `PUT`** (`GET` renvoie `null` en l’absence de configuration)

| Champ | Description |
|---|---|
| `settings` | Les paramètres ci-dessus, sans `secret`. |
| `secretSet` | Indique si un secret est configuré. |
| `reading` | Indique que la source a établi une connexion et relève les messages qui arrivent depuis cette connexion. |
| `lastPolledAt`, `lastSuccessAt` | Horodatages de la dernière tentative de relève et de la dernière relève réussie (en microsecondes). |
| `lastError` | Motif de l’échec de la dernière relève. Une relève réussie efface cette erreur. |

`test` se connecte une seule fois avec les paramètres du corps de la requête (si `secret` est vide, le test utilise le secret enregistré) et renvoie `{"ok": true, "messages": 3}` ou `503` avec le message du serveur de messagerie.

<RequestExample>
```bash cURL
curl -X PUT "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/mailbox" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"host": "imap.example.com", "username": "alerts@example.com", "secret": "<password>"}'
```
</RequestExample>
