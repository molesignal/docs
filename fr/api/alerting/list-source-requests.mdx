```http
GET /api/v1/alerts/sources/{id}/requests
```

Renvoie les requêtes qu’une [source d’alertes](/fr/alerting/sources) a reçues récemment, de la plus récente à la plus ancienne. Nécessite l’autorisation `alerts.sources.read`. Le cluster qui a traité les requêtes conserve les 500 dernières de chaque source pendant 7 jours au maximum.

**Paramètres de requête**

| Paramètre | Type | Description |
|---|---|---|
| `limit` | entier | Nombre de requêtes à renvoyer, de 1 à 200. Par défaut : 50. |

| Champ | Description |
|---|---|
| `receivedAt` | Horodatage de réception, en microsecondes. |
| `viaCluster` | Cluster de la fédération qui a relayé la requête ; champ vide si le cluster destinataire l’a reçue directement. |
| `status` | `accepted` (acceptée), `rejected` (refusée) ou `forwarded` (transmise au cluster destinataire). |
| `httpStatus` | Code de statut HTTP renvoyé à l’expéditeur. |
| `message` | Motif du refus ou de l’absence d’action. |
| `alertCount` | Nombre d’alertes dans la requête. |
| `alerts` | Pour un maximum de 100 alertes : action, clé de déduplication, titre, gravité, résultat (voir [Envoyer des alertes](/fr/api/alerting/send-alerts)), motif et identifiant de l’incident. |
| `bodyExcerpt` | Début du corps de la requête refusée, dans la limite de 16 KiB. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/requests?limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>
