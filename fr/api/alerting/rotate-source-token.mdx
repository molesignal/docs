```http
POST /api/v1/alerts/sources/{id}/token
```

Attribue un nouveau jeton à une [source d’alertes](/fr/alerting/sources). Cette opération exige l’autorisation `alerts.sources.manage` et un corps de requête vide. L’ancien jeton cesse de fonctionner immédiatement. Si la fédération est active, il cesse de fonctionner sur les autres clusters dès que la modification se synchronise. Les émetteurs qui utilisent encore l’ancien jeton doivent passer au nouveau.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/token \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

La réponse renvoie la source avec le nouveau `token`, qui n’apparaît que cette fois-ci.

**Erreurs**

| Statut | Cause |
|---|---|
| `403` | Le jeton ne dispose pas de l’autorisation `alerts.sources.manage`. |
| `404` | La source n’existe pas. |
