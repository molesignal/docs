```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

Le premier appel liste les [sources d'alerte](/fr/alerting/sources) de l'organisation, le deuxième renvoie une source, et le troisième renvoie l'ID de fédération de ce cluster (`local`, vide en l'absence de fédération) ainsi que les clusters qu'une source peut choisir comme cluster de réception. Les trois appels exigent `alerts.sources.read`. L'API ne renvoie jamais un jeton ni son hachage.

| Champ | Type | Description |
|---|---|---|
| `id` | string | ID de la source. |
| `name` | string | Nom. |
| `kind` | string | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` ou `email`. |
| `enabled` | boolean | Une source désactivée refuse les alertes. |
| `escalationPolicyId` | string \| null | La politique d'escalade que suivent ses incidents ; `default` est la politique par défaut, et `null` n'escalade rien et se contente de notifier. |
| `severity` | string | Utilisée lorsqu'une alerte ne comporte aucune gravité. |
| `labels` | object | Étiquettes supplémentaires ajoutées à chaque incident qu'elle ouvre. |
| `tokenPrefix` | string | Le préfixe de jeton `mspat-<10>`. Le jeton complet est renvoyé une seule fois, à la création et à la rotation. |
| `homeCluster` | string | Le cluster de fédération sur lequel s'ouvrent ses incidents ; vide pour ce cluster. |
| `intakePath` | string | Le chemin de l'adresse d'ingestion, identique pour chaque source. |
| `lastIntakeAt` | integer \| null | Date de la dernière requête que ce cluster a reçue de cette source, en microsecondes. |
| `createdBy`, `createdAt`, `updatedAt` | | Qui l'a créé et à quel moment, ainsi que la date de sa dernière modification, en microsecondes. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Les clusters qu'une source peut choisir comme cluster de réception :

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
