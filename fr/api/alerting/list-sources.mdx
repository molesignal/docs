```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

Le premier appel liste les [sources d’alertes](/fr/alerting/sources) de l’organisation, le deuxième renvoie une source et le troisième renvoie l’identifiant de fédération de ce cluster (`local`, vide sans fédération) ainsi que les clusters qu’une source peut choisir pour recevoir ses alertes. Les trois appels nécessitent l’autorisation `alerts.sources.read`. L’API ne renvoie jamais le jeton ni son empreinte.

| Champ | Type | Description |
|---|---|---|
| `id` | chaîne | Identifiant de la source. |
| `name` | chaîne | Nom. |
| `kind` | chaîne | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix` ou `email`. |
| `enabled` | booléen | Une source désactivée refuse les alertes. |
| `escalationPolicyId` | chaîne \| null | Politique d’escalade applicable aux incidents de la source. `default` applique la politique par défaut et `null` envoie uniquement des notifications, sans escalade. |
| `severity` | chaîne | Niveau de gravité à appliquer si l’alerte n’en indique aucun. |
| `labels` | objet | Étiquettes supplémentaires que la source ajoute à chaque incident qu’elle ouvre. |
| `tokenPrefix` | chaîne | Préfixe du jeton : `mspat-<10>`. L’API ne renvoie le jeton complet qu’une seule fois, à chaque création ou rotation. |
| `homeCluster` | chaîne | Cluster de la fédération sur lequel la source ouvre ses incidents. Laissez ce champ vide pour utiliser le cluster actuel. |
| `intakePath` | chaîne | Chemin de l’adresse de réception, identique pour toutes les sources. |
| `lastIntakeAt` | entier \| null | Horodatage, en microsecondes, de la dernière requête que ce cluster a reçue de la source. |
| `createdBy`, `createdAt`, `updatedAt` | | Auteur de la création, puis horodatages de création et de dernière modification, en microsecondes. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

Clusters qu’une source peut choisir pour recevoir ses alertes :

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
