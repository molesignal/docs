```http
GET /api/v1/alerts/incidents/{id}/rca
POST /api/v1/alerts/incidents/{id}/rca
```

[Mole Agent](/fr/agent) rédige une analyse des causes profondes (RCA) à partir du contexte de l’incident. Chaque incident peut avoir au plus une analyse.

Le rôle `alert` crée automatiquement les analyses. Si l’organisation dispose d’un fournisseur de modèles activé et doté d’une clé API, ce rôle rédige toutes les trois minutes une analyse pour les incidents actifs qui n’en ont pas, dans la limite de 20 incidents par cycle. L’appel `GET` récupère l’analyse enregistrée. L’appel `POST` génère immédiatement une nouvelle analyse et remplace celle qui est enregistrée.

| Appel | Autorisation | Remarques |
|---|---|---|
| `GET` | `alerts.incidents.read` | Renvoie `404` avec le message `no root-cause analysis for this incident yet` tant qu’aucune analyse n’existe. |
| `POST` | `alerts.incidents.rca` | Attend la réponse du modèle et renvoie la nouvelle analyse. Le paramètre de requête facultatif `locale` définit la langue de l’analyse : `en-us` ou `zh-cn`. Par défaut, l’appel utilise la préférence linguistique du compte à l’origine de l’appel. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/rca?locale=en-us" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Réponse**

| Champ | Remarques |
|---|---|
| `incidentId`, `orgId` | Les identifiants de l’incident et de l’organisation. |
| `summary` | L’analyse au format Markdown. |
| `provider`, `model` | Le type de fournisseur de modèles, par exemple `openai`, `anthropic` ou `openai_compatible`, et le nom du modèle. |
| `promptBuiltinKey`, `promptHash` | Le gabarit de l’invite et l’empreinte de l’invite générée, à des fins d’audit. |
| `promptTokens`, `completionTokens`, `finishReason` | Le nombre de jetons utilisés et le motif de fin de génération indiqués par le fournisseur. |
| `createdAt`, `updatedAt` | Le nombre de microsecondes écoulées depuis l’époque Unix. `updatedAt` change à chaque nouvelle génération de l’analyse. |

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | Pour l’appel `POST`, l’organisation ne dispose d’aucun fournisseur de modèles activé et doté d’une clé API. |
| `403` | Le jeton ne dispose pas de l’autorisation requise pour l’appel. |
| `404` | L’incident n’existe pas, ou aucune analyse n’est encore disponible pour l’appel `GET`. |
