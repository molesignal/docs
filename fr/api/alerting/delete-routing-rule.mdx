```http
DELETE /api/v1/alerts/routing/rules/{id}
```

Supprime une [règle de routage](/fr/alerting/routing#règles-de-routage). Cette opération exige l’autorisation `alerts.routing.manage`. Les règles suivantes prennent en charge les nouveaux incidents qui auraient correspondu à la règle supprimée. Les incidents déjà ouverts conservent le routage appliqué à leur ouverture, y compris le nom de la règle enregistré dans chaque incident.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/routing/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "deleted": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1" }
```
</ResponseExample>

**Erreurs**

| Statut | Cause |
|---|---|
| `403` | Le jeton ne dispose pas de l’autorisation `alerts.routing.manage`. |
| `404` | La règle n’existe pas ou appartient à une autre organisation. |
