```http
GET /api/v1/alerts/incidents/{id}/source
```

Renvoie les informations dont dispose la [source d’alertes](/fr/alerting/sources) sur un incident qu’elle a ouvert. Nécessite l’autorisation `alerts.incidents.read`. Ce type d’incident porte le libellé `alert.source=external`, et son `ruleId` correspond à l’identifiant de la source.

| Champ | Description |
|---|---|
| `source` | La source, au même format que dans [Lister les sources d’alertes](/fr/api/alerting/list-sources) ; `null` après la suppression de la source. |
| `dedupKey` | La clé de déduplication. |
| `lastEventAt` | Le dernier horodatage fourni par l’émetteur et pris en compte pour cette clé de déduplication, en microsecondes. Le système ignore les messages plus anciens. Vaut `null` pour les sources de type API. |
| `lastIntakeAt` | L’horodatage de la dernière réception de l’alerte, en microsecondes. |
| `members` | Jusqu’à 100 alertes d’un groupe de notifications Alertmanager ou Grafana : `status` (`firing` ou `resolved`), `labels`, `summary`, `startsAt`, `endsAt` et `url`, qui renvoie vers l’émetteur. Vide pour les autres types de sources. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/source \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**Erreurs**

| Statut | Cause |
|---|---|
| `404` | L’incident n’existe pas ou aucune source d’alertes ne l’a ouvert. |
