Règles d’[inhibition](/fr/alerting/inhibition). La consultation nécessite `alerts.inhibitions.read` et la modification nécessite `alerts.inhibitions.manage`.

```http
GET    /api/v1/alerts/inhibit-rules
POST   /api/v1/alerts/inhibit-rules
GET    /api/v1/alerts/inhibit-rules/{id}
PUT    /api/v1/alerts/inhibit-rules/{id}
DELETE /api/v1/alerts/inhibit-rules/{id}
```

**Corps de la requête**

| Champ | Type | Description |
|---|---|---|
| `name` | chaîne | Obligatoire, 255 caractères au maximum. |
| `enabled` | booléen | `true` par défaut. |
| `source.matchers` | tableau | Conditions sur les étiquettes de la source : `{label, op, value}`, où `op` vaut `eq`, `neq`, `re` ou `nre`. La source doit remplir toutes les conditions. |
| `source.min_severity` | chaîne | Gravité minimale de la source. Sans valeur, la règle accepte tous les niveaux de gravité. |
| `target.matchers` | tableau | Conditions sur les étiquettes de la cible. Sans condition, la règle cible tous les incidents. |
| `target.max_severity` | chaîne | Gravité maximale de la cible. Sans valeur, la règle accepte tous les niveaux de gravité. |
| `equal` | tableau | Jusqu’à 16 étiquettes que la source et la cible doivent avoir en commun avec la même valeur. `source.matchers` et `equal` ne peuvent pas être vides en même temps. |
| `moreSevereOnly` | booléen | La source doit avoir une gravité strictement supérieure à celle de la cible. `true` par défaut. |
| `waitSecs` | entier | Délai d’attente des notifications de la cible, de 0 à 600 secondes, 60 par défaut. Toute valeur inférieure à 15 compte comme 15. |
| `lingerSecs` | entier | Durée pendant laquelle la source continue d’inhiber les cibles après sa résolution, de 0 à 3 600 secondes, 120 par défaut. |
| `comment` | chaîne | Commentaire. |

Dans les conditions sur les étiquettes, `service` et `host` prennent les valeurs du service et de l’hôte affectés si l’incident ne porte pas les étiquettes correspondantes. `alert.rule_id` désigne la règle ou la source à l’origine de l’incident. Une expression régulière invalide entraîne une réponse `400`.

Dans la liste comme dans la vue détaillée, chaque règle contient aussi le champ `inhibiting`, qui indique le nombre d’incidents qu’elle inhibe actuellement.

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/alerts/inhibit-rules" \
  -H "authorization: Bearer $MS_TOKEN" \
```

## Aperçu

```http
POST /api/v1/alerts/inhibit-rules/preview
```

Utilisez le même corps de requête : `name` est facultatif et la règle n’a pas besoin d’être enregistrée. L’aperçu nécessite `alerts.inhibitions.read`. Il évalue uniquement cette règle sur les incidents actuellement actifs, quelle que soit la valeur de `enabled`.

| Champ | Description |
|---|---|
| `pairs[].source_incident_id`, `sourceSummary`, `sourceSeverity` | Incident qui en inhibe un autre. |
| `pairs[].target_incident_id`, `targetSummary`, `targetSeverity` | Incident inhibé. |

## Lever l’inhibition d’un incident

```http
POST /api/v1/alerts/incidents/{id}/inhibition/lift
```

Cette opération nécessite `alerts.incidents.update` sur l’incident. Elle envoie immédiatement les notifications retenues et empêche toute nouvelle inhibition de l’incident. MoleSignal consigne la levée de l’inhibition dans la chronologie et le journal d’audit. L’opération ne fait rien si aucune inhibition ne s’applique à l’incident et renvoie `409` si l’incident est résolu ou a fait l’objet d’une fusion. Elle renvoie l’incident.

Dans le JSON d’un incident, les champs suivants décrivent l’état de l’inhibition :

| Champ | Description |
|---|---|
| `inhibition` | Inhibition en cours : `ruleId`, `ruleName`, `sourceIncidentId`, `sourceSummary`, `since` et `endingAt`, qui indique l’échéance de l’inhibition après la résolution de la source. Le champ reste présent après la résolution de l’incident pour indiquer qu’aucune notification n’est partie à ce moment-là. |
| `inhibitionWaitUntil` | Échéance en microsecondes jusqu’à laquelle le système retient les notifications pour laisser à une source le temps d’apparaître. |
| `inhibitionLiftedBy` | Auteur de la levée de l’inhibition. |
