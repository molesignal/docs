```http
GET /api/v1/alerts/routing/rules
```

Liste les [règles de routage](/fr/alerting/routing#règles-de-routage) de l’organisation dans leur ordre d’évaluation (`position` croissante). Nécessite l’autorisation `alerts.routing.read`. La liste inclut aussi les règles désactivées.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/rules \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1",
    "orgId": "<organization-id>",
    "name": "Payments in production",
    "enabled": true,
    "position": 0,
    "conditions": [
      { "key": "env", "operator": "equals", "values": ["prod"] },
      { "key": "service.name", "operator": "in", "values": ["checkout", "cart"] }
    ],
    "minSeverity": "error",
    "origins": [],
    "target": { "kind": "team", "teamId": "<team-id>" },
    "createdBy": "<user-id>",
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

## Champs des règles

| Champ | Description |
|---|---|
| `id`, `orgId` | Identifiants de la règle et de l’organisation. |
| `name` | Nom de la règle. |
| `enabled` | Le système ignore les règles désactivées. |
| `position` | Ordre d’évaluation : les valeurs les plus petites passent en premier. |
| `conditions` | Conditions portant sur les étiquettes de l’incident. Toutes doivent être remplies. Une liste vide correspond à tous les incidents. Chaque condition comporte une `key`, un `operator` et des `values`. |
| `minSeverity` | Niveau de gravité minimal de l’incident : `info`, `warning`, `error` ou `critical`. Utilisez `null` pour accepter tous les niveaux. |
| `origins` | Origines auxquelles la règle s’applique : `rule` (règles d’alerte), `external` (sources d’alerte), `synthetic` (vérifications synthétiques). Une liste vide inclut toutes les origines. |
| `target` | Destination des incidents qui correspondent à la règle : `{"kind": "team", "teamId": …}` ou `{"kind": "policy", "policyId": …}`. |
| `createdBy` | Compte à l’origine de la création de la règle. |
| `createdAt`, `updatedAt` | Horodatages de création et de dernière modification de la règle, en microsecondes. |

Valeurs de `operator` :

| `operator` | `values` | Condition de correspondance |
|---|---|---|
| `equals` | Une valeur | La valeur de l’étiquette est égale à la valeur indiquée. |
| `not_equals` | Une valeur | La valeur de l’étiquette diffère de la valeur indiquée ou l’incident ne comporte pas cette étiquette. |
| `in` | Une ou plusieurs valeurs | La valeur de l’étiquette est égale à l’une des valeurs indiquées. |
| `matches` | Une expression régulière | La valeur entière de l’étiquette correspond à l’expression régulière. |
