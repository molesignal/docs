```http
POST /api/v1/alerts/incidents/{id}/notes
```

Ajoute une note à la [chronologie](/fr/api/alerting/incident-timeline) d’un incident, quel que soit son statut. Mole
Agent lit les dernières notes lorsqu’il consulte l’incident. L’appel nécessite l’autorisation `alerts.incidents.update`.

**Corps**

| Champ | Type | Obligatoire | Remarques |
|---|---|---|---|
| `text` | chaîne | Oui | De 1 à 4 000 caractères, après suppression des espaces en début et en fin de texte. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/notes \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"text": "Rolled back the edge proxy."}'
```
</RequestExample>

La réponse contient l’entrée de chronologie correspondant à la note.

<ResponseExample>
```json 200
{
  "id": "3KEE1aXy7pRtGd2s9Lm4Qv8bNcE",
  "orgId": "<organization-id>",
  "incidentId": "3KEDNEyqouYJeBDTLTMTBui7XHW",
  "at": 1790000300000000,
  "kind": "note",
  "actor": "<user-id>",
  "detail": {
    "text": "Rolled back the edge proxy.",
    "via": "api"
  }
}
```
</ResponseExample>

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | `text` est vide ou dépasse 4 000 caractères. |
| `403` | Le jeton ne dispose pas de l’autorisation `alerts.incidents.update` ou ne donne pas accès à l’incident. |
| `404` | L’incident n’existe pas. |
