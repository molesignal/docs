```http
PUT /api/v1/alerts/routing/teams/{teamId}
```

Définit ou supprime la [politique d’astreinte](/fr/alerting/routing#politiques-d’astreinte-des-équipes) d’une équipe. Cette opération nécessite `alerts.routing.manage`. Les nouveaux incidents acheminés vers l’équipe suivent cette politique d’escalade ou, à défaut, la politique par défaut.

| Champ | Type | Description |
|---|---|---|
| `escalationPolicyId` | string \| null | Identifiant d’une politique d’escalade de l’organisation. La valeur `null` ou l’absence de ce champ supprime la politique d’astreinte de l’équipe. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/teams/$TEAM_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"escalationPolicyId": "<policy-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "teamId": "<team-id>", "escalationPolicyId": "<policy-id>" }
```
</ResponseExample>

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | L’équipe n’existe pas ou appartient à une autre organisation, ou la politique d’escalade n’existe pas. |
| `403` | Le jeton ne dispose pas de la permission `alerts.routing.manage`. |
| `422` | La requête contient un autre champ. La réponse est au format texte brut. |
