```http
DELETE /api/v1/alerts/rules/{id}
```

Supprime une règle. L’appel nécessite l’autorisation `alerts.rules.delete`. Les incidents déjà ouverts par la règle restent consultables et suivent un cycle de vie indépendant. La règle supprimée ne résout plus aucun de ces incidents.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>

Le corps de la réponse contient le texte brut `deleted`. Un `id` inconnu entraîne une réponse `404`.
