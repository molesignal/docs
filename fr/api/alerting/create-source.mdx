```http
POST /api/v1/alerts/sources
```

Crée une [source d’alertes](/fr/alerting/sources). Cette opération nécessite l’autorisation `alerts.sources.manage`. Le `token` n’apparaît que dans cette réponse. Utilisez-le pour appeler [Envoyer des alertes](/fr/api/alerting/send-alerts). Si la fédération est activée, la source se synchronise avec les autres clusters.

| Champ | Type | Description |
|---|---|---|
| `kind` | string | Obligatoire à la création : `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix` ou `email`. |
| `name` | string | Obligatoire, 128 caractères maximum. |
| `enabled` | boolean | Valeur par défaut : `true`. |
| `escalationPolicyId` | string \| null | Identifiant d’une politique d’escalade de l’organisation, ou `default`. Si ce champ est absent ou vaut `null`, aucune escalade n’a lieu et seules les politiques de notification envoient des notifications. |
| `severity` | string | Niveau de gravité à utiliser si l’alerte n’en indique aucun : `critical`, `error`, `warning` (par défaut) ou `info`. |
| `labels` | object | Jusqu’à 32 étiquettes supplémentaires. Une clé ne peut contenir que des lettres, des chiffres et les caractères `_ . - : /`. Elle ne peut pas commencer par `alert.` ni être égale à `external.kind`. |
| `email` | object | Paramètres de traitement des e-mails par la source : `allowedSenders` (adresses, `@domain` ou `*`), `resolvePattern`, `dedupPattern` et `ignorePattern`. Consultez [E-mail](/fr/alerting/sources#e-mail). Si vous omettez ce champ lors d’une mise à jour, sa valeur reste inchangée. |
| `homeCluster` | string | Cluster de la fédération sur lequel s’ouvrent les incidents : le cluster actuel ou un cluster distant activé. Si vous omettez ce champ à la création, la source utilise le cluster actuel. Sans fédération, ce champ n’a aucun effet. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

La réponse contient la source et son `token`. Consultez [Lister les sources d’alertes](/fr/api/alerting/list-sources) pour la description des autres champs.

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | Un champ est invalide : par exemple, le nom est vide, la politique d’escalade n’existe pas ou le cluster de destination n’est ni le cluster actuel ni un cluster distant activé. |
| `403` | Le jeton ne dispose pas de l’autorisation `alerts.sources.manage`. |
