```http
POST /api/v1/alerts/sources
```

Crée une [source d'alerte](/fr/alerting/sources). Nécessite `alerts.sources.manage`. Le `token` de la réponse n'apparaît qu'une seule fois ; utilisez-le pour appeler [Envoyer des alertes](/fr/api/alerting/send-alerts). Avec la fédération activée, la source se synchronise vers les autres clusters.

| Champ | Type | Description |
|---|---|---|
| `kind` | string | Requis à la création : `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` ou `email`. |
| `name` | string | Requis, jusqu'à 128 caractères. |
| `enabled` | boolean | Par défaut `true`. |
| `escalationPolicyId` | string \| null | Un ID de politique d'escalade de l'organisation, ou `default`. Sans cette valeur, ou avec `null`, rien ne s'escalade et seules les politiques de notification notifient. |
| `severity` | string | Utilisé lorsqu'une alerte ne porte aucune sévérité : `critical`, `error`, `warning` (la valeur par défaut) ou `info`. |
| `labels` | object | Jusqu'à 32 libellés supplémentaires. Une clé est composée de lettres, de chiffres et de `_ . - : /`, ne peut pas commencer par `alert.` et ne peut pas être `external.kind`. |
| `email` | object | Comment une source e-mail lit un message : `allowedSenders` (adresses, `@domain` ou `*`), `resolvePattern`, `dedupPattern` et `ignorePattern` ; voir [Email](/fr/alerting/sources#e-mail). Omis lors d'une mise à jour, il reste inchangé. |
| `homeCluster` | string | Le cluster de fédération sur lequel les incidents s'ouvrent : ce cluster ou un cluster distant activé. Une nouvelle source sans cette valeur utilise ce cluster ; sans fédération, elle n'a aucun effet. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

La réponse est la source avec son `token`. [Lister les sources d'alerte](/fr/api/alerting/list-sources) décrit les autres champs.

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | Un champ est incorrect, par exemple un nom vide, une politique d'escalade inexistante ou un cluster de réception qui n'est ni ce cluster ni un cluster distant activé. |
| `403` | Le token ne dispose pas de `alerts.sources.manage`. |
