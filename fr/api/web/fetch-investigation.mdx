```http
GET /api/v1/web/investigation/blob/{id}
```

Renvoie le document JSON que l’opération [Enregistrer la pile d’investigation](/fr/api/web/store-investigation) a enregistré sous `blobId`. La recherche se limite à l’organisation à l’origine de l’appel. Un identifiant d’une autre organisation renvoie donc `404`. L’appel exige `streams.query` ou, dans la portée système, `sys.telemetry.read`.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/web/investigation/blob/$BLOB_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "version": 1,
  "stack": [
    { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
    { "kind": "log", "query": "level = error" }
  ]
}
```
</ResponseExample>

La réponse contient le document enregistré, sans modification. Si le processus de compactage a supprimé le document au bout de 7 jours, l’appel renvoie également `404`.

**Erreurs**

| Statut | Cause |
|---|---|
| `403` | Le jeton ne dispose pas de l’autorisation `streams.query`. |
| `404` | L’identifiant est inconnu, appartient à une autre organisation ou a expiré. |
