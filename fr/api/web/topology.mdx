```http
GET /api/v1/web/topology
```

Agrège les arêtes du graphe de services sur une fenêtre temporelle pour produire des nœuds et des arêtes, avec le débit de requêtes, le taux d’erreur et la latence. MoleSignal construit ce graphe à partir des spans de trace. Consultez la [carte des services](/fr/apm/service-map). L’appel exige `traces.read` ou, dans la portée système, `sys.telemetry.read`.

**Paramètres de requête**

| Paramètre | Type | Obligatoire | Notes |
|---|---|---|---|
| `from` | chaîne | Oui | Le début de la fenêtre, sous forme d’horodatage RFC 3339. |
| `to` | chaîne | Oui | La fin de la fenêtre, sous forme d’horodatage RFC 3339. Cette valeur ne doit pas précéder `from`. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/topology?from=2026-10-04T09:00:00Z&to=2026-10-04T10:00:00Z" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "nodes": [
    { "id": "checkout", "name": "checkout", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 },
    { "id": "frontend", "name": "frontend", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 }
  ],
  "edges": [
    { "source": "frontend", "target": "checkout", "rps": 0.1, "errRate": 0.0278, "p95Ms": 90.0 }
  ]
}
```
</ResponseExample>

**Réponse**

| Champ | Notes |
|---|---|
| `nodes[].id`, `nodes[].name` | Le nom du service. La réponse trie les nœuds par nom. |
| `nodes[].span_count` | Le nombre de requêtes sur toutes les arêtes reliées au service, que celui-ci soit client ou serveur. |
| `nodes[].error_rate`, `edges[].err_rate` | Le nombre d’erreurs divisé par le nombre de requêtes, de 0 à 1. |
| `nodes[].rps`, `edges[].rps` | Le nombre de requêtes divisé par la durée de la fenêtre en secondes. |
| `nodes[].p95_ms`, `edges[].p95_ms` | La latence p95 la plus élevée parmi les intervalles agrégés, en millisecondes. Cette valeur ne correspond pas au p95 de l’ensemble de la fenêtre. |
| `edges[].source`, `edges[].target` | Le service client et le service serveur. La réponse trie les arêtes par source, puis par cible. |

Si la fenêtre ne contient aucune arête, l’appel renvoie des tableaux vides.

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | `from` ou `to` manque ou ne respecte pas le format d’horodatage RFC 3339, ou `to` précède `from`. |
| `403` | Le jeton ne dispose pas de l’autorisation `traces.read`. |
