```http
GET /api/v1/traces/service_graph
```

Renvoie les arêtes brutes du graphe de services que la [topologie des services](/fr/api/web/topology) agrège. Chaque arête comptabilise les appels d’un service client à un service serveur sur une minute. L’appel nécessite l’autorisation `traces.read` ou, dans la portée système, `sys.telemetry.read`.

**Paramètres de requête**

| Paramètre | Type | Obligatoire | Notes |
|---|---|---|---|
| `from` | entier | Oui | Début de la fenêtre, en microsecondes depuis l’époque Unix. |
| `to` | entier | Oui | Fin de la fenêtre, en microsecondes. |
| `service` | chaîne | Non | Ne conserve que les arêtes où ce service est client ou serveur. |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000
curl "http://localhost:5080/api/v1/traces/service_graph?from=$((NOW-3600000000))&to=$NOW&service=checkout" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "edges": [
    {
      "id": "3KBCiQWW0TtpDu7D4pH7LMtZsRh",
      "orgId": "<organization-id>",
      "clientService": "frontend",
      "serverService": "checkout",
      "bucketAt": 1790000000000000,
      "requestCount": 12,
      "errorCount": 1,
      "p50Us": 90000,
      "p95Us": 210000,
      "p99Us": 240000
    }
  ],
  "count": 1
}
```
</ResponseExample>

**Réponse**

| Champ | Notes |
|---|---|
| `edges[].client_service`, `edges[].server_service` | Le service appelant et le service appelé. |
| `edges[].bucketAt` | Début de l’intervalle d’une minute, en microsecondes. |
| `edges[].request_count`, `edges[].error_count` | Nombre total d’appels et nombre d’appels en échec dans l’intervalle. |
| `edges[].p50_us`, `edges[].p95_us`, `edges[].p99_us` | Percentiles de latence sur l’intervalle, en microsecondes. Un percentile peut valoir `null`. |
| `count` | Nombre d’arêtes renvoyées. |

L’API renvoie `{"edges": [], "count": 0}` si aucune arête ne correspond à la fenêtre ou si `to` précède `from`.

**Erreurs**

| Code d’état | Cause |
|---|---|
| `400` | `from` ou `to` manque ou n’est pas un entier. L’API répond en texte brut. |
| `403` | Le jeton ne dispose pas de l’autorisation `traces.read`. |
