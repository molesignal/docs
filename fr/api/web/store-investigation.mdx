```http
POST /api/v1/web/investigation/blob
```

Stocke un document JSON dans le stockage d’objets et renvoie un identifiant. L’interface web utilise cet appel pour conserver la pile des investigations volumineuses en dehors de l’URL de la page. L’URL ne contient alors que l’identifiant. Lisez le document avec [Récupérer la pile d’investigation](/fr/api/web/fetch-investigation). L’appel nécessite `streams.query` ou, dans le périmètre système, `sys.telemetry.read`.

Le corps accepte toute valeur JSON jusqu’à 1 MiB (1 048 576 octets). Le document appartient à l’organisation à l’origine de l’appel. Le compacteur le supprime au bout de 7 jours.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/investigation/blob \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "version": 1,
    "stack": [
      { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
      { "kind": "log", "query": "level = error" }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "blobId": "3KEZAC5JXc0P0HjrTdARfCgH1Y3"
}
```
</ResponseExample>

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | Le corps ne contient pas de JSON valide (texte brut) ou le document dépasse 1 MiB (`payload exceeds 1048576 bytes`). |
| `403` | Le jeton ne dispose pas de la permission `streams.query`. |
