```http
GET /api/v1/web/search
```

Alimente la palette de commandes **⌘K**. L’appel recherche six types d’entités de l’organisation par correspondance approximative des noms et renvoie d’abord les meilleurs résultats. L’appel nécessite `streams.query` ou, dans le périmètre système, `sys.telemetry.read`.

**Paramètres de requête**

| Paramètre | Type | Obligatoire | Notes |
|---|---|---|---|
| `q` | chaîne | Oui | Texte à rechercher, limité à 256 caractères. La recherche s’appuie sur la similarité par trigrammes de PostgreSQL. Un texte très court, comme une seule lettre, donne donc rarement des résultats. Si `q` est vide, l’appel renvoie une liste vide. |
| `types` | chaîne | Non | Liste de valeurs séparées par des virgules parmi `stream`, `dashboard`, `savedView`, `alert`, `incident` et `service`. Omettez ce paramètre pour rechercher tous les types. Une valeur inconnue ne donne aucun résultat. |
| `limit` | entier | Non | Valeur par défaut : `20`. L’appel ramène la valeur dans l’intervalle de 1 à 50. |

Si `q` ne contient que des espaces et que `types=stream`, l’appel liste les flux par ordre alphabétique au lieu d’effectuer une recherche.

Chaque résultat décrit l’entité à l’aide des champs suivants :

| `kind` | `id` | `label` | `subtitle` |
|---|---|---|---|
| `stream` | Identifiant du flux | Nom du flux | Type de flux sous sa forme interne, par exemple `builtin.logs`. |
| `dashboard` | Identifiant du tableau de bord | Titre | `uid` du tableau de bord. |
| `savedView` | Identifiant de la vue enregistrée | Nom | Langage de requête. |
| `alert` | Identifiant de la règle | Nom de la règle | `enabled` ou `disabled`. |
| `incident` | Identifiant de l’incident | Empreinte de l’incident | Statut de l’incident. |
| `service` | Identifiant de l’arête | Nom du service dans le graphe des services | Aucun. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/search?q=app&types=stream&limit=5" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "items": [
    { "kind": "stream", "id": "3KDXoznFWyKPsch4ETi37U3GdxM", "label": "app", "subtitle": "builtin.logs" },
    { "kind": "stream", "id": "3JtcZGko1Q5czEBK9nBJjiFxpo1", "label": "app_logs", "subtitle": "builtin.logs" }
  ]
}
```
</ResponseExample>

**Erreurs**

| Statut | Cause |
|---|---|
| `400` | Le paramètre `q` est absent (réponse en texte brut) ou dépasse 256 caractères (`invalid_argument`). |
| `403` | Le jeton ne dispose pas de l’autorisation `streams.query`. |
