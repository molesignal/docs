```http
POST /api/v1/_heroku
```

Le point de terminaison accepte un corps de requête contenant des journaux au format texte. Il n’utilise pas de jeton Bearer. Créez un connecteur de type `heroku_drain` avec un `pushToken` d’au moins 16 caractères et un `target_stream`. Heroku ne peut pas définir d’en-têtes personnalisés. Passez donc le jeton dans l’URL avec `?token=`. L’en-tête `X-Connector-Token` fonctionne aussi. Le point de terminaison renvoie `401` si le jeton est incorrect.

Chaque ligne devient un événement de journal dans le `target_stream` (`heroku` par défaut). Le point de terminaison stocke la ligne entière dans le champ `message` et définit le champ `source` sur `heroku`. Il renvoie `204` en cas de succès.

<RequestExample>
```bash Heroku CLI
heroku drains:add "https://molesignal.example.com/api/v1/_heroku?token=<pushToken>"
```
</RequestExample>

Consultez la section [Connecteurs](/fr/connectors) pour configurer le connecteur.

## Vérifier la réception et le choix du flux

1. Vérifiez que le connecteur est activé et que l’expéditeur utilise le jeton d’envoi du connecteur. Un jeton d’API standard ne remplace pas un jeton d’envoi.
2. Pour définir directement `configJson` via l’API des connecteurs, utilisez `target_stream` pour le flux de destination, et non `targetStream`. La clé du jeton reste `pushToken`, en camelCase.
3. Envoyez un événement de test avec un marqueur unique et notez l’heure de réception. Dans **Journaux**, sélectionnez le flux prévu et une plage horaire qui inclut l’heure de réception, puis recherchez le marqueur.
4. Si la requête aboutit mais que le flux prévu est vide, vérifiez le flux par défaut correspondant et la valeur enregistrée pour le flux de destination. Une réponse HTTP positive ne dispense pas d’effectuer une recherche dans le flux prévu.

Protégez le jeton comme un secret d’authentification. Si le jeton figure dans un paramètre de requête de l’URL, ne consignez pas l’URL complète dans les journaux, les tickets ou les captures d’écran. Avant de réessayer une requête qui a échoué, déterminez si le problème vient du jeton ou de l’état du connecteur, ou s’il s’agit d’une erreur de format ou de compression du corps de la requête.
