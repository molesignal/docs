VS Code prend en charge les serveurs MCP via stdio ou HTTP distant, l’autorisation OAuth, les ressources, les invites et les outils.

## Se connecter via stdio (recommandé)

Le client lance la CLI MoleSignal, qui transmet les messages à MoleSignal. La CLI nécessite
Node.js 20 ou une version ultérieure.

<Steps>
  <Step title="S’authentifier une seule fois">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

Le navigateur ouvre MoleSignal pour permettre d’approuver la connexion ; la CLI conserve et renouvelle la session.

  </Step>
  <Step title="Ajouter MoleSignal">

Dans `.vscode/mcp.json` :

```json
{
  "servers": {
    "molesignal": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

Démarrez le serveur depuis le fichier ou la vue MCP, puis confirmez que le serveur est digne de confiance.

  </Step>
</Steps>

Si aucun navigateur n’est disponible, définissez `MOLESIGNAL_URL` et `MOLESIGNAL_TOKEN` (un jeton d’API) dans
l’environnement du serveur au lieu de vous authentifier. Consultez [Se connecter via stdio](/fr/inbound-mcp#connexion-via-stdio).

Les sections suivantes décrivent la connexion via Streamable HTTP, sans la CLI.

## Configurer le serveur

Créez `.vscode/mcp.json` pour partager la configuration dans l’espace de travail. Pour une configuration globale
privée, exécutez **MCP : Ouvrir la configuration utilisateur** depuis la palette de commandes.

```json
{
  "servers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Démarrer le serveur">
    Ouvrez `mcp.json` et sélectionnez l’action **Début** intégrée, ou exécutez **MCP : Répertorier les serveurs** et choisissez
    `molesignal`.
  </Step>
  <Step title="Confirmer la confiance">
    Vérifiez le point de terminaison et confirmez que le serveur MCP est digne de confiance. La configuration de l’espace de travail peut être
    partagée avec l’ensemble des contributeurs. N’y stockez donc aucun identifiant.
  </Step>
  <Step title="Terminer l’autorisation OAuth">
    VS Code découvre la configuration OAuth de MoleSignal et ouvre la page d’autorisation dans le navigateur. Accordez
    l’autorisation, puis revenez au mode agent de la vue Conversation.
  </Step>
  <Step title="Vérifier la connexion">
    Exécutez **MCP : Répertorier les serveurs**, vérifiez l’état de `molesignal` et assurez-vous que les outils s’affichent dans la vue
    Conversation.
  </Step>
</Steps>

Utilisez **Ajouter du contexte → Ressources MCP** pour joindre une ressource MoleSignal, ou appelez une invite publiée
avec `/molesignal.<prompt>`.

Consultez la [documentation officielle de VS Code sur MCP](https://code.visualstudio.com/docs/agent-customization/mcp-servers).
