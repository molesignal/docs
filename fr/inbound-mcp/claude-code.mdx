Claude Code prend en charge les serveurs stdio, les serveurs Streamable HTTP distants avec découverte OAuth et les
configurations de portée locale, propre au projet ou propre à l’utilisateur.

## Se connecter via stdio (recommandé)

Le client lance la CLI MoleSignal, qui transmet les messages à MoleSignal. La CLI nécessite
Node.js 20 ou version ultérieure.

<Steps>
  <Step title="S’authentifier une seule fois">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

Le navigateur ouvre MoleSignal pour valider l’authentification. La CLI conserve et renouvelle la session.

  </Step>
  <Step title="Ajouter MoleSignal">

```bash
claude mcp add --scope user molesignal -- npx -y @molesignal/cli mcp
claude mcp get molesignal
```

  </Step>
</Steps>

Sans navigateur, définissez `MOLESIGNAL_URL` et `MOLESIGNAL_TOKEN` (un jeton d’API) dans
l’environnement du serveur au lieu de vous authentifier. Consultez [Se connecter via stdio](/fr/inbound-mcp#connexion-via-stdio).

Les sections suivantes décrivent la connexion via Streamable HTTP, sans la CLI.

## Se connecter avec OAuth 2.1

<Steps>
  <Step title="Ajouter le serveur distant">

    ```bash
    claude mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    `--scope user` rend le serveur disponible dans tous les projets. Omettez cette option pour conserver la configuration
    dans l’état local du projet, ou utilisez `--scope project` pour ajouter une entrée dans le fichier partagé `.mcp.json`.

  </Step>
  <Step title="Autoriser MoleSignal">

    ```bash
    claude mcp login molesignal
    ```

    Autre méthode : ouvrez Claude Code, exécutez `/mcp`, sélectionnez `molesignal`, puis terminez l’authentification.

  </Step>
  <Step title="Vérifier le serveur">

    ```bash
    claude mcp get molesignal
    claude mcp list
    ```

  </Step>
</Steps>

Dans un terminal SSH ou sans interface graphique, affichez l’URL d’autorisation, puis collez l’URL de redirection finale
dans Claude Code :

```bash
claude mcp login molesignal --no-browser
```

## Se connecter avec un jeton d’API

Utilisez la substitution de variables d’environnement dans le fichier `.mcp.json` du projet au lieu d’enregistrer un jeton dans le dépôt :

```json
{
  "mcpServers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer ${MOLESIGNAL_MCP_TOKEN}"
      }
    }
  }
}
```

Définissez `MOLESIGNAL_MCP_TOKEN` avant de lancer Claude Code. Pour les serveurs de portée projet, confirmez explicitement
que le serveur est digne de confiance avant la première connexion.

Consultez la [documentation MCP officielle de Claude Code](https://code.claude.com/docs/en/mcp).
