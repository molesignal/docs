Cursor prend en charge les serveurs MCP via stdio et les serveurs MCP distants via Streamable HTTP avec authentification OAuth.

## Connexion via stdio (recommandé)

Le client lance la CLI de MoleSignal, qui transmet les messages à MoleSignal. La CLI nécessite
Node.js 20 ou une version ultérieure.

<Steps>
  <Step title="Authentifiez-vous une seule fois">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

Le navigateur ouvre MoleSignal pour valider la connexion. La CLI conserve et renouvelle la session.

  </Step>
  <Step title="Ajoutez MoleSignal">

Dans `.cursor/mcp.json` pour le projet en cours, ou dans `~/.cursor/mcp.json` pour tous les projets :

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

Activez ensuite `molesignal` dans **Tools & MCP**.

  </Step>
</Steps>

Si aucun navigateur n’est disponible, définissez `MOLESIGNAL_URL` et `MOLESIGNAL_TOKEN` (un jeton d’API) dans
l’environnement du serveur au lieu de vous authentifier. Consultez [Connexion via stdio](/fr/inbound-mcp#connexion-via-stdio).

Les sections suivantes décrivent la connexion via Streamable HTTP, sans passer par la CLI.

## Configurez le serveur

Créez `.cursor/mcp.json` pour le projet en cours, ou `~/.cursor/mcp.json` pour une
configuration globale :

```json
{
  "mcpServers": {
    "molesignal": {
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Ouvrez Tools & MCP">
    Ouvrez **Cursor Settings → Tools & MCP** et repérez `molesignal`.
  </Step>
  <Step title="Connectez-vous avec OAuth">
    Sélectionnez **Connexion** et suivez les instructions sur la page d’autorisation de MoleSignal. Cursor repère les points de terminaison OAuth
    à partir des métadonnées de la ressource protégée MCP.
  </Step>
  <Step title="Vérifiez les outils">
    Vérifiez que `tool_search`, `call_read_tool` et `call_managed_tool` figurent dans la liste des
    outils disponibles. Redémarrez le serveur depuis **Tools & MCP** après avoir modifié la configuration.
  </Step>
</Steps>

<Warning>
  N’incluez pas de jeton Bearer dans un commit de `.cursor/mcp.json`. Privilégiez OAuth pour une session
  Cursor interactive. Pour les identifiants non interactifs, utilisez un mécanisme d’injection de secrets pris en charge par le client.
</Warning>

Consultez la [documentation officielle de Cursor sur MCP](https://cursor.com/docs/mcp).
