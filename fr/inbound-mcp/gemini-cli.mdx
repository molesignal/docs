Gemini CLI prend en charge les serveurs stdio et Streamable HTTP, la découverte OAuth ainsi que les outils, ressources et invites MCP.

## Se connecter via stdio (recommandé)

Le client lance la CLI MoleSignal, qui transmet les messages à MoleSignal. Cette CLI nécessite
Node.js 20 ou une version ultérieure.

<Steps>
  <Step title="Se connecter une seule fois">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

Le navigateur ouvre MoleSignal pour valider la connexion. La CLI conserve et renouvelle la session.

  </Step>
  <Step title="Ajouter MoleSignal">

```bash
gemini mcp add molesignal npx -y @molesignal/cli mcp
```

  </Step>
</Steps>

Si aucun navigateur n’est disponible, définissez `MOLESIGNAL_URL` et `MOLESIGNAL_TOKEN` (un jeton d’API) dans
l’environnement du serveur au lieu de vous connecter. Consultez [Se connecter via stdio](/fr/inbound-mcp#connexion-via-stdio).

Les sections suivantes décrivent la connexion via Streamable HTTP, sans passer par la CLI MoleSignal.

## Se connecter avec OAuth 2.1

<Steps>
  <Step title="Ajouter MoleSignal">

    ```bash
    gemini mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    Omettez `--scope user` pour conserver l’entrée dans le fichier `.gemini/settings.json` du projet actuel.

  </Step>
  <Step title="S’authentifier">
    Démarrez une session interactive de Gemini CLI, puis exécutez :

    ```text
    /mcp auth molesignal
    ```

    Terminez la procédure d’autorisation dans le navigateur. Gemini CLI détecte les points de terminaison OAuth et
    enregistre automatiquement le client de façon dynamique.

  </Step>
  <Step title="Vérifier le serveur">

    ```bash
    gemini mcp list
    ```

    Exécutez `/mcp` dans la session interactive pour consulter les outils, les ressources et les invites disponibles.

  </Step>
</Steps>

## Configurer avec JSON

Voici l’entrée Streamable HTTP équivalente à ajouter dans `~/.gemini/settings.json` ou
`.gemini/settings.json` :

```json
{
  "mcpServers": {
    "molesignal": {
      "httpUrl": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

Ne définissez pas `trust: true` pour un serveur d’opérations géré, sauf si la stratégie locale de Gemini prévoit
d’ignorer la demande de confirmation du client. La stratégie d’approbation de MoleSignal continue de s’appliquer côté
serveur.

Consultez la [documentation MCP officielle de Gemini CLI](https://geminicli.com/docs/tools/mcp-server/).
