Codex démarre les serveurs MCP via stdio et prend en charge le point de terminaison Streamable HTTP de MoleSignal et la découverte OAuth.

## Connexion via stdio (recommandé)

Le client lance la CLI MoleSignal, qui transmet les messages à MoleSignal. La CLI nécessite
Node.js 20 ou une version ultérieure.

<Steps>
  <Step title="Connectez-vous une seule fois">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

Le navigateur ouvre MoleSignal pour autoriser la connexion. La CLI conserve et renouvelle la session.

  </Step>
  <Step title="Ajoutez MoleSignal">

```bash
codex mcp add molesignal -- npx -y @molesignal/cli mcp
```

Ou dans `~/.codex/config.toml` :

```toml
[mcp_servers.molesignal]
command = "npx"
args = ["-y", "@molesignal/cli", "mcp"]
```

  </Step>
</Steps>

Si aucun navigateur n’est disponible, définissez `MOLESIGNAL_URL` et `MOLESIGNAL_TOKEN` (un jeton d’API) dans
l’environnement du serveur sans passer par l’étape de connexion. Consultez [Connexion via stdio](/fr/inbound-mcp#connexion-via-stdio).

Les sections suivantes décrivent la connexion via Streamable HTTP, sans la CLI.

## Connexion avec OAuth 2.1

<Steps>
  <Step title="Enregistrez MoleSignal">

    ```bash
    codex mcp add molesignal \
      --url https://molesignal.example.com/api/v1/mcp
    ```

  </Step>
  <Step title="Autorisez la connexion">

    ```bash
    codex mcp login molesignal
    ```

    Suivez les instructions de la page d’autorisation de MoleSignal dans le navigateur.

  </Step>
  <Step title="Vérifiez le serveur">

    ```bash
    codex mcp get molesignal
    codex mcp list
    ```

    Redémarrez la tâche Codex en cours ou ouvrez une nouvelle tâche pour actualiser la liste des outils MCP.

  </Step>
</Steps>

<Warning>
  N’ajoutez pas `--oauth-resource`. MoleSignal publie déjà la ressource protégée via
  la découverte OAuth. Ajouter la même valeur peut entraîner l’erreur `duplicate field resource`.
</Warning>

## Connexion avec un jeton d’API

Utilisez un jeton d’API personnel ou un jeton d’API de compte de service pour un processus Codex non interactif :

```bash
export MOLESIGNAL_MCP_TOKEN="<api-token>"

codex mcp add molesignal \
  --url https://molesignal.example.com/api/v1/mcp \
  --bearer-token-env-var MOLESIGNAL_MCP_TOKEN
```

Codex stocke le nom de la variable d’environnement, pas la valeur du jeton. Rendez la variable
accessible au processus qui lance Codex.

## Vérification de la découverte des outils

Demandez à Codex :

> Utilisez le serveur MCP de MoleSignal. Recherchez les outils de gestion des incidents et listez les incidents actifs. N’apportez
> aucune modification.

La première requête doit utiliser `tool_search`, puis `call_read_tool` pour effectuer une lecture différée.

Consultez la [documentation officielle de Codex sur MCP](https://developers.openai.com/codex/mcp/).
