Transmettez au SDK la valeur obtenue lors de l’évaluation d’un indicateur : chaque événement de la vue inclut alors cette valeur.

```ts
molesignalRum.addFeatureFlagEvaluation('checkout_v2', 'treatment');
```

Pour suivre un service de gestion des indicateurs, transmettez-lui les résultats des évaluations. LaunchDarkly propose des inspecteurs et OpenFeature des hooks :

```ts
LDClient.initialize(id, user, {
  inspectors: [{
    type: 'flag-used',
    name: 'molesignal',
    method: (key, detail) => molesignalRum.addFeatureFlagEvaluation(key, detail.value),
  }],
});

OpenFeature.addHooks({
  after: (context, details) => molesignalRum.addFeatureFlagEvaluation(context.flagKey, details.value),
});
```

## L’onglet Indicateurs de fonctionnalité

**Indicateurs de fonctionnalité** répertorie les indicateurs évalués pendant les sessions de la période sélectionnée, en commençant par celui qui a été évalué dans le plus grand nombre de sessions. Sélectionnez un indicateur pour comparer côte à côte les métriques de ses valeurs : le nombre de sessions, la part des vues avec une erreur, la part des vues avec un signe de frustration et, pour une application web, le 75e percentile du LCP, de l’INP et du CLS. La valeur qui compte le plus de vues avec une erreur s’affiche en rouge. **Voir ces vues** ouvre les vues correspondantes dans l’explorateur.

## Interroger un indicateur partout

Référencez un indicateur comme une colonne, sous la forme `feature_flags.<key>`, partout où l’[explorateur](/fr/rum/explorer) et l’API acceptent un champ :

```text
feature_flags.checkout_v2 = 'treatment' AND error.type = 'TypeError'
```

```http
POST /api/v1/rum/aggregate
{ "type": "views", "measures": [{ "fn": "p75", "field": "view.performance.lcp.timestamp" }], "groupBy": ["feature_flags.checkout_v2"] }
```

La même syntaxe s’applique aux autres clés d’une colonne JSON : `context.<key>`, `usr.extra.<key>` et `view.custom_timings.<key>`. `GET /api/v1/rum/keys` répertorie les clés disponibles.

En SQL, lisez une clé avec `json_text("feature_flags", 'checkout_v2')`. La fonction renvoie du texte, ou NULL si la ligne ne contient pas la clé. `json_keys("feature_flags")` répertorie les clés d’une ligne.

## Mole Agent

L’outil `get_rum_feature_flags` répertorie les indicateurs. Avec le paramètre `flag`, il compare les valeurs de l’indicateur selon les mêmes métriques.
