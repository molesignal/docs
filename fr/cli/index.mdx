L’interface en ligne de commande de MoleSignal correspond à la commande `molesignal`, publiée sur npm sous le nom `@molesignal/cli`. Elle
se connecte à une instance MoleSignal, puis :

- lit et suit les logs, exécute des requêtes SQL et PromQL, affiche les traces sous forme de diagrammes en cascade et résume les informations sur les
  services APM ;
- répertorie les incidents et les personnes d’astreinte, accuse réception des incidents et les résout, exécute des vérifications synthétiques
  et applique les modifications approuvées ;
- signale les déploiements, charge les fichiers de mappage des sources et les symboles RUM, et envoie la sortie des scripts vers un
  flux dans les pipelines CI ;
- appelle n’importe quel outil du catalogue de MoleSignal ;
- expose les outils MCP de MoleSignal via stdio, pour que Claude Code, Cursor, Codex, VS Code et
  Gemini CLI puissent la lancer en tant que serveur MCP.

Les lectures et les modifications passent par les outils de MoleSignal. Les autorisations du compte connecté, la
politique d’utilisation des outils de l’organisation et ses approbations s’appliquent donc à la CLI comme à Mole Agent.
Le signalement des déploiements, le chargement d’artefacts de débogage et l’envoi de logs passent par l’API de MoleSignal et
nécessitent un jeton d’API.

## Prérequis

- Node.js 20 ou version ultérieure.
- Une instance MoleSignal accessible depuis la machine et un compte sur cette instance.

## Installation

```bash
npm install -g @molesignal/cli
```

Vérifiez l’installation :

```bash
molesignal --version
```

Exécutez aussi chaque commande sans installer la CLI :

```bash
npx -y @molesignal/cli --help
```

## Prise en main

<Steps>
  <Step title="Connectez-vous">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    Le navigateur ouvre la page d’autorisation de MoleSignal. Cliquez sur **Autoriser**. Consultez
    [Connexion](/fr/cli/sign-in).
  </Step>
  <Step title="Vérifiez la configuration">
    ```bash
    molesignal doctor
    ```
  </Step>
  <Step title="Lisez les logs">
    ```bash
    molesignal logs app_logs -f
    ```

    Consultez [Lire et suivre les logs](/fr/cli/logs).
  </Step>
</Steps>

## Commandes

| Groupe | Commandes |
|---|---|
| Connexion | `login`, `logout`, `profiles`, `use`, `status`, `whoami`, `doctor`. Consultez [Connexion](/fr/cli/sign-in). |
| Logs et requêtes | `streams`, `logs`, `query`, `fields`. Consultez [Lire et suivre les logs](/fr/cli/logs). |
| Métriques, traces et services | `metrics`, `traces`, `services`, `search-jobs`. Consultez [Métriques, traces et services](/fr/cli/observe). |
| Astreintes et modifications | `incidents`, `oncall`, `approvals`, `annotate`, `synthetics`. Consultez [Incidents et modifications](/fr/cli/changes). |
| Versions et données | `deploy`, `source-maps`, `symbols`, `send`, `run`. Consultez [CI et versions](/fr/cli/ci). |
| Outils et configuration | `tools`, `call`, `mcp`, `open`, `completion`. Consultez [Appeler n’importe quel outil](/fr/cli/tools) et [Exposer les outils MCP via stdio](/fr/cli/mcp). |

`molesignal <command> --help` décrit une commande et ses options. Retrouvez également toutes les options dans la
[référence des commandes](/fr/cli/reference).
