Une variable insère une valeur choisie au-dessus de la grille dans les requêtes, les titres et les liens de chaque panneau. Un seul
tableau de bord suffit alors pour tous les services, hôtes ou environnements, sans créer de copie pour chacun.

## Ajouter une variable

Ouvrez l’éditeur, sélectionnez **Paramètres → Variables**, puis ajoutez une variable :

| Champ | Règle |
|---|---|
| **Nom** | Le nom utilisé dans les requêtes, par exemple `service`. Utilisez des lettres, des chiffres et `_`. Commencez par une lettre ou par `_` : les autres noms ne sont pas remplacés. |
| **Étiquette** | Le texte affiché au-dessus du sélecteur. |
| **Type** | L’origine des valeurs. Consultez la section [Types](#types). |
| **Requête / options** | La requête ou les valeurs, selon le type. |
| **Sélection multiple** | Permet de sélectionner plusieurs valeurs à la fois. |
| **Tout inclure** | Ajoute l’option **Tous**, qui représente toutes les valeurs de la liste. |
| **Masquer** | **Aucun** affiche le sélecteur, **Étiquette** masque son étiquette et **Variable** masque le sélecteur. |
| **Actualiser** | Quand relire les valeurs d’une variable de requête : **Jamais**, **Au chargement** ou à chaque changement de la **Plage horaire**. |

Enregistrez le tableau de bord pour conserver la variable.

## Types

| Type | Valeurs |
|---|---|
| **Requête** | Proviennent des données. Consultez la section [Variables de requête](#variables-de-requête). |
| **Personnalisé** | Une liste fixe de valeurs séparées par des virgules, par exemple `prod, staging, dev`. |
| **Texte** | Le texte saisi dans un champ au-dessus de la grille. |
| **Constante** | Une valeur fixe stockée dans le modèle du tableau de bord. Elle ne s’affiche jamais au-dessus de la grille. |
| **Intervalle**, **Source de données** | Une liste stockée dans le modèle du tableau de bord, par exemple une liste issue d’un import JSON. |

### Variables de requête

Une variable de requête lit ses valeurs dans la plage horaire actuelle. Choisissez le **Type de requête** :

| Type de requête | Champs | Valeurs |
|---|---|---|
| **Valeurs des étiquettes** | **Métrique** et **Étiquette**, par exemple `http_requests_total` et `service`. | Les valeurs de l’étiquette dans les séries de la métrique, dans tous les flux de métriques qui contiennent cette métrique. |
| **Requête classique** | Une expression telle que `label_values(http_requests_total, service)`. | Les mêmes valeurs que pour **Valeurs des étiquettes**. |
| **SQL** | **Nom du flux**, **Type de flux** et une instruction SQL. | Les valeurs de la première colonne. |

La première valeur devient la valeur par défaut. Une requête peut utiliser une autre variable, par exemple dans une instruction SQL
avec `WHERE environment = '$env'`. Le choix d’un environnement filtre alors la liste des services.

## Utiliser une variable

Saisissez `$name` ou `${name}` dans une requête, un titre de panneau, un élément de texte ou un lien. Utilisez les accolades
si des lettres suivent le nom, par exemple `${service}_errors`. Si une variable contient plusieurs valeurs, elle les renvoie
séparées par des virgules. Ajoutez un format pour modifier ce résultat :

| Syntaxe | Résultat pour `checkout` et `payment` |
|---|---|
| `${service}` | `checkout,payment` |
| `${service:csv}` | `checkout,payment` |
| `${service:pipe}` | `checkout\|payment` |
| `${service:regex}` | `checkout\|payment`, avec échappement des caractères spéciaux de chaque valeur pour une expression régulière. |
| `${service:sqlstring}` | `'checkout','payment'`, avec chaque valeur entre apostrophes pour SQL, par exemple dans `IN (${service:sqlstring})`. |
| `${service:json}` | `["checkout","payment"]` |

Par exemple, un panneau qui utilise la requête PromQL `sum(rate(http_requests_total{service=~"${service:regex}"}[5m]))` affiche les données
des services sélectionnés.

## Valeurs dans l’adresse

L’adresse du tableau de bord contient les valeurs sélectionnées sous la forme `var-<name>=<value>`, avec un paramètre pour chaque
valeur d’une variable à sélection multiple. Copiez l’adresse ou créez un lien avec ces paramètres pour ouvrir le
tableau de bord avec la même sélection. Un [lien de données](/fr/dashboards/edit#liens-de-données) peut aussi transmettre
les variables.

## Répéter des panneaux selon une variable

Dans l’onglet **Panneau** du panneau, choisissez une **Variable de répétition**. Le tableau de bord affiche alors une copie du
panneau pour chaque valeur sélectionnée et attribue cette valeur à la variable dans la copie. Choisissez le
**Sens de répétition** : **Horizontale**, **Verticale** ou **Grille**, puis réglez **Max par ligne**. Le tableau de bord n’enregistre que le
panneau d’origine. Les copies s’adaptent à la sélection.
