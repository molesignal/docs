Claude Code는 stdio 서버, OAuth 검색을 지원하는 원격 Streamable HTTP 서버,
로컬, 프로젝트 또는 사용자 구성 범위를 지원합니다.

## stdio로 연결합니다(권장)

클라이언트가 MoleSignal CLI를 시작하면 CLI가 MoleSignal로 메시지를 전달합니다. CLI를 실행하려면
Node.js 20 이상이 필요합니다.

<Steps>
  <Step title="한 번 로그인합니다">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

브라우저에서 MoleSignal이 열리면 로그인을 승인합니다. CLI가 로그인 상태를 저장하고 갱신합니다.

  </Step>
  <Step title="MoleSignal을 추가합니다">

```bash
claude mcp add --scope user molesignal -- npx -y @molesignal/cli mcp
claude mcp get molesignal
```

  </Step>
</Steps>

브라우저를 사용할 수 없으면 로그인하는 대신 `MOLESIGNAL_URL`과 `MOLESIGNAL_TOKEN`(API 토큰)을
서버 환경에 설정합니다. [stdio로 연결합니다](/ko/inbound-mcp#stdio로-연결)를 참고합니다.

아래 섹션에서는 CLI 없이 Streamable HTTP로 연결합니다.

## OAuth 2.1로 연결합니다

<Steps>
  <Step title="원격 서버를 추가합니다">

    ```bash
    claude mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    `--scope user`를 지정하면 여러 프로젝트에서 서버를 사용할 수 있습니다. 설정을 현재 프로젝트에만 로컬로 저장하려면
    이 플래그를 생략하고, 공유 `.mcp.json`에 항목을 추가하려면 `--scope project`를 사용합니다.

  </Step>
  <Step title="MoleSignal에 권한을 부여합니다">

    ```bash
    claude mcp login molesignal
    ```

    또는 Claude Code를 열고 `/mcp`를 실행한 다음, `molesignal`을 선택하고 인증을 완료합니다.

  </Step>
  <Step title="서버를 확인합니다">

    ```bash
    claude mcp get molesignal
    claude mcp list
    ```

  </Step>
</Steps>

SSH 또는 헤드리스 터미널에서는 인증 URL을 출력하고 최종 콜백 URL을
Claude Code에 붙여넣습니다.

```bash
claude mcp login molesignal --no-browser
```

## API 토큰으로 연결합니다

토큰을 커밋하는 대신 프로젝트의 `.mcp.json`에서 환경 변수 확장을 사용합니다.

```json
{
  "mcpServers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer ${MOLESIGNAL_MCP_TOKEN}"
      }
    }
  }
}
```

Claude Code를 시작하기 전에 `MOLESIGNAL_MCP_TOKEN`을 설정합니다. 프로젝트 범위의 서버는
처음 연결하기 전에 신뢰 여부를 명시적으로 결정해야 합니다.

[공식 Claude Code MCP 문서](https://code.claude.com/docs/en/mcp)를 참고합니다.
