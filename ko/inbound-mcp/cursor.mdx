Cursor는 stdio MCP 서버와 OAuth 인증을 사용하는 원격 Streamable HTTP MCP 서버를 지원합니다.

## stdio로 연결(권장)

클라이언트가 MoleSignal CLI를 시작하면 CLI가 MoleSignal로 메시지를 전달합니다. CLI를 실행하려면
Node.js 20 이상이 필요합니다.

<Steps>
  <Step title="한 번만 로그인">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

브라우저에서 MoleSignal 로그인 승인 페이지가 열립니다. 로그인하면 CLI가 인증 정보를 저장하고 갱신합니다.

  </Step>
  <Step title="MoleSignal 추가">

현재 프로젝트에는 `.cursor/mcp.json`에, 모든 프로젝트에는 `~/.cursor/mcp.json`에 다음을 추가합니다.

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

그런 다음 **Tools & MCP**에서 `molesignal`을 활성화합니다.

  </Step>
</Steps>

브라우저를 사용할 수 없다면 로그인하는 대신 `MOLESIGNAL_URL`과 `MOLESIGNAL_TOKEN`(API 토큰)을
서버 환경 변수로 설정합니다. [stdio로 연결](/ko/inbound-mcp#stdio로-연결)을 참조합니다.

아래에서는 CLI 없이 Streamable HTTP로 연결하는 방법을 설명합니다.

## 서버 구성

현재 프로젝트에만 적용하려면 `.cursor/mcp.json`을, 모든 프로젝트에 적용하려면 `~/.cursor/mcp.json`을
생성합니다.

```json
{
  "mcpServers": {
    "molesignal": {
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="Tools & MCP 열기">
    **Cursor Settings → Tools & MCP**를 열고 `molesignal`을 찾습니다.
  </Step>
  <Step title="OAuth로 연결">
    **연결**을 선택하고 MoleSignal 페이지에서 권한 부여를 완료합니다. Cursor는 OAuth
    엔드포인트를 MCP 보호 리소스 메타데이터에서 찾습니다.
  </Step>
  <Step title="도구 확인">
    `tool_search`, `call_read_tool`, `call_managed_tool`이 사용 가능한 도구 목록에
    표시되는지 확인합니다. 구성을 변경한 후에는 **Tools & MCP**에서 서버를 다시 시작합니다.
  </Step>
</Steps>

<Warning>
  `.cursor/mcp.json`에 Bearer 토큰을 넣어 커밋하지 않습니다. 대화형 Cursor
  세션에서는 OAuth를 권장합니다. 비대화형 인증에는 클라이언트가 지원하는 시크릿 주입 방식으로 인증 정보를 전달합니다.
</Warning>

[Cursor 공식 MCP 문서](https://cursor.com/docs/mcp)를 참조합니다.
