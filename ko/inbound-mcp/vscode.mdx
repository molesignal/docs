VS Code는 stdio 및 원격 HTTP MCP 서버, OAuth 인증, 리소스, 프롬프트, 도구를 지원합니다.

## stdio로 연결(권장)

클라이언트는 MoleSignal CLI를 시작해 MoleSignal로 메시지를 전달합니다. 이를 사용하려면
Node.js 20 이상이 필요합니다.

<Steps>
  <Step title="한 번 로그인">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

브라우저에서 MoleSignal이 열리면 로그인을 승인합니다. CLI는 인증 정보를 저장하고 갱신합니다.

  </Step>
  <Step title="MoleSignal 추가">

`.vscode/mcp.json`에서 다음과 같이 설정합니다.

```json
{
  "servers": {
    "molesignal": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

파일 또는 MCP 뷰에서 서버를 시작하고 신뢰 확인 메시지에서 승인합니다.

  </Step>
</Steps>

브라우저를 사용할 수 없으면 로그인하는 대신 `MOLESIGNAL_URL`과 `MOLESIGNAL_TOKEN`(API 토큰)을
서버 환경 변수로 설정합니다. [stdio로 연결](/ko/inbound-mcp#stdio로-연결)을 참조합니다.

아래 섹션에서는 CLI 없이 Streamable HTTP로 연결합니다.

## 서버 구성

워크스페이스 구성을 공유하려면 `.vscode/mcp.json`을 생성합니다. 개인 전역
구성을 사용하려면 명령 팔레트에서 **MCP: 사용자 구성 열기**를 실행합니다.

```json
{
  "servers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="서버 시작">
    `mcp.json`을 열고 인라인 **시작** 작업을 선택하거나, **MCP: 서버 나열**을 실행한 후
    `molesignal`을 선택합니다.
  </Step>
  <Step title="신뢰 확인">
    엔드포인트를 검토하고 MCP 서버의 신뢰 확인 메시지에서 승인합니다. 워크스페이스 구성은
    모든 기여자와 공유할 수 있으므로 파일에 자격 증명을 저장하지 않습니다.
  </Step>
  <Step title="OAuth 인증 완료">
    VS Code는 MoleSignal의 OAuth 검색 절차에 따라 브라우저에서 인증 페이지를 엽니다. 액세스를
    승인한 후 채팅의 에이전트 모드로 돌아갑니다.
  </Step>
  <Step title="연결 확인">
    **MCP: 서버 나열**을 실행하고 `molesignal`의 상태를 확인한 다음, 채팅 뷰에
    도구가 표시되는지 확인합니다.
  </Step>
</Steps>

**컨텍스트 추가 → MCP 리소스**를 사용해 MoleSignal 리소스를 첨부하거나, 게시된 프롬프트를
`/molesignal.<prompt>`로 호출합니다.

[공식 VS Code MCP 문서](https://code.visualstudio.com/docs/agent-customization/mcp-servers)를 참조합니다.
