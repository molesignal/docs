MoleSignal은 기본 제공 평가기(`promql-parser`와
Arrow/DataFusion 평가기)로 메트릭 스트림에서 PromQL을 실행합니다. **인스턴트** 쿼리와 **범위** 쿼리를 모두 지원합니다.
`step`이 있으면 `[start, end]`를 해당 간격으로 평가해 행렬을 반환합니다. 없으면
`end` 시점에 인스턴트 쿼리를 실행합니다. 이 페이지는 공식 지원 매트릭스입니다.

## 지원 기능

### 범위 벡터 함수 (`metric[range]`)

`rate`, `irate`, `increase`, `delta`, `idelta`, `deriv`, `predict_linear`, `resets`, `changes`,
`holt_winters`(별칭 `double_exponential_smoothing`) 및 모든 `*_over_time` 계열 함수:
`avg_over_time` / `min_over_time` / `max_over_time` / `sum_over_time` / `count_over_time` /
`quantile_over_time` / `stddev_over_time` / `stdvar_over_time` / `last_over_time` /
`present_over_time` / `mad_over_time`.

`rate`, `increase`, `delta`는 Prometheus와 마찬가지로 윈도우의 첫 번째 샘플과 마지막 샘플 사이의 변화량을
윈도우 양쪽 경계까지 외삽합니다. 따라서 동일한 샘플에서 동일한 값을 반환합니다.

### 집계 (`by()` / `without()` 사용)

`sum`, `avg`, `min`, `max`, `count`, `stddev`, `stdvar`, `quantile`, `group`, `count_values`,
`topk`, `bottomk`, `limitk`, `limit_ratio`.

### 히스토그램

`histogram_quantile(q, sum by(le)(rate(metric_bucket[range])))` — 클래식
`le` 버킷에서 선형 보간을 수행합니다.

`histogram_fraction(lower, upper, v)` — 클래식 `le` 버킷에서
`[lower, upper]`에 속하는 관측값의 비율을 추정합니다(동일한 구간별 선형 CDF 사용:
`(rank(upper) - rank(lower)) / total`).

### 레이블 및 정렬

`label_replace`, `label_join`, `sort`, `sort_desc`, `sort_by_label`, `sort_by_label_desc`.

### 시간

`time`, `timestamp`, `minute`, `hour`, `day_of_week`, `day_of_month`, `day_of_year`,
`days_in_month`, `month`, `year`(UTC 기준, 날짜 함수의 기본 인수는 `vector(time())`입니다).

### 타입 및 값 부재

`vector`, `scalar`, `absent`, `absent_over_time`.

### 수학 / 반올림 / 삼각 함수

`abs`, `ceil`, `floor`, `round`, `exp`, `ln`, `log2`, `log10`, `sqrt`, `sgn`,
`clamp` / `clamp_min` / `clamp_max`, `sin` / `cos` / `tan` / `asin` / `acos` / `atan` / `sinh` /
`cosh` / `tanh` / `asinh` / `acosh` / `atanh`, `pi`, `deg`, `rad`.

### 연산자

산술 연산자 `+ - * / % ^`, 비교 연산자 `== != > < >= <=`(`bool` 사용 가능), 집합 연산자
`and` / `or` / `unless`, `group_left` / `group_right`를 지원하는 벡터 매칭 `on(...)` / `ignoring(...)`,
단항 부호 반전 연산자를 지원합니다.

### 수정자 및 구조

셀렉터 수정자 `@`(`start()` / `end()` / `<ts>`)와 `offset`(행렬 셀렉터에도 적용 가능)을 지원합니다.
서브쿼리 `inner[range:step]`도 지원합니다.

## 미구현 기능 및 알려진 차이점

| 기능 | 상태 | 참고 |
|---|---|---|
| 네이티브 히스토그램 함수 `histogram_count` / `histogram_sum` / `histogram_avg` / `histogram_stddev` / `histogram_stdvar` | ❌ → 400 | 클래식 `le` 버킷 모델에는 적용되지 않습니다. 분위수에는 `histogram_quantile`을, 구간별 비율에는 `histogram_fraction`을 사용합니다. |
| 이항 `default` 값 채우기 | ❌ → 400 | — |
| 범위 쿼리 내 서브쿼리 | ⚠️ | 인스턴트 평가로 대체합니다(외부 × 내부 간격을 각각 순회하지 않음). 인스턴트 쿼리와 알림에서는 정확하게 평가합니다. |
| `timestamp()` | ⚠️ | 인스턴트 쿼리에서는 평가 시각을, 범위 쿼리에서는 데이터 포인트 자체의 타임스탬프를 반환합니다. |
| 함수의 스칼라 매개변수(`predict_linear`의 `t`, `holt_winters`의 `sf`/`tf`, 분위수) | ⚠️ | 숫자 리터럴만 지원합니다. |

지원하지 않는 함수와 구문은 `promql function not yet supported: <name>` 오류를 반환하며,
`POST /api/v1/query`(`language: "promql"`)는 이 오류를 `400`으로 매핑합니다.

<Note>
  알림 규칙의 `query.language`가 `promql`이면 평가 윈도우의
  종료 시점에 PromQL 표현식을 인스턴트 쿼리로 평가합니다. 규칙 자체는 MoleSignal의 `AlertRule`이며
  Prometheus 규칙 형식과 호환되지 않습니다. [규칙 만들기](/ko/api/alerting/create-rule)를 참조합니다.
</Note>

## 레이블 매칭

`=`, `!=`, `=~`, `!~`를 지원합니다(정규식에는 RE2를 사용하며, Prometheus의 PCRE와 약간 다릅니다). `__name__`은
`metric_name` 열과 매칭합니다. 이름에 점이 포함된 메트릭은
`{"http.server.duration"}`처럼 이름을 따옴표로 감싸 선택합니다. `{job="api"}` 또는
`{__name__=~"http_.*"}`처럼 메트릭 이름을 지정하지 않은 셀렉터는 매처 조건을 충족하는 모든 메트릭을 읽고, 시계열에 `__name__`을 유지합니다.

## 메트릭 스트림 구조

메트릭 스트림은 Prometheus 서버 한 대와 같은 단일 소스의 메트릭을 저장하며, 레이블을
하나의 JSON 블롭이 아닌 **별도 열**로 저장합니다.

```sql
_timestamp   Timestamp(Microsecond)  NOT NULL   -- time
metric_name  Utf8                    NOT NULL   -- the metric, PromQL's __name__
value        Float64                 NOT NULL   -- the measurement (Int64 etc. is accepted and cast to f64)
<label_x>    Utf8 …                             -- every non-reserved column is a label
```

파일은 메트릭별 행을 한데 모아 `metric_name`을 기준으로 먼저 정렬한 뒤 시간순으로 정렬합니다. 셀렉터는
대상 메트릭을 보유한 스트림에서 시간 범위가 쿼리와 겹치는 Parquet 파일을 찾고, 그중
메트릭이 들어 있는 페이지만 읽습니다. 고유한 레이블 집합마다 시계열을 하나씩 만들고 엔진에서 매처(`=`, `!=`, `=~`,
`!~`)를 적용합니다. `@`와 `offset`은 평가 시점을 변경합니다. OTLP로 수신한 메트릭은 [OTLP 메트릭 필드](/ko/query#otlp-메트릭-필드)를 참조합니다.
