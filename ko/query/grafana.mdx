MoleSignal 데이터 소스는 Grafana 플러그인입니다. Grafana는 PromQL로 메트릭을 읽고, **로그** 및 **트레이스** 페이지의 필드 쿼리로 로그와 트레이스를 읽으며, SQL로 모든 스트림을 읽습니다. 신호 간 이동도 지원합니다. 로그 라인이나 예시 데이터에서 연결된 트레이스를 열 수 있으며, 모든 결과에 MoleSignal로 돌아가는 링크가 있습니다.

<Note>
플러그인의 백엔드는 Grafana 서버에서 실행되며, Grafana가 이를 자식 프로세스로 시작합니다. MoleSignal에 대한 모든 요청은 Grafana 서버에서 데이터 소스의 토큰을 사용해 전송합니다. 브라우저는 MoleSignal에 직접 접속하지 않습니다. Grafana Cloud는 Private data source connect를 통해 프라이빗 네트워크의 MoleSignal에 접속합니다.
</Note>

## 요구 사항

| 항목 | 요구 사항 |
|---|---|
| Grafana | 12.3 이상이며, 13.x도 포함합니다. |
| MoleSignal | [`POST /api/v1/query`](/ko/api/query/execute)의 `step` 필드와 [로그](/ko/api/web/logs) 및 [트레이스](/ko/api/web/trace) 조회의 `expression` 매개변수를 지원하는 버전입니다. 이전 버전은 필드 쿼리에 필터링되지 않은 결과를 반환하므로 **저장 및 테스트**를 통과하지 못합니다. |
| 네트워크 | Grafana 서버에서 MoleSignal의 HTTP 포트에 접속할 수 있어야 합니다. 기본 포트는 5080입니다. |
| 토큰 | **뷰어** 역할이 있는 서비스 계정의 API 토큰입니다. 데이터 소스는 `streams.read`, `streams.query`, `logs.read`, `traces.read`, `metrics.read`를 사용합니다. 주석 및 변수에는 `dashboards.read`와 `dashboards.annotations.read`, 배포 주석에는 `apm.deployments.read`, 인시던트 주석에는 `alerts.incidents.read`를 사용합니다. |

## Grafana용 토큰 생성

1. **ID 및 액세스 → 서비스 계정**을 열고 **서비스 계정 생성**을 선택합니다.
2. **이름**에 `grafana`를 입력하고 **뷰어** 역할을 선택합니다.
3. **계정 및 토큰 생성**을 선택하고 토큰을 복사합니다. 토큰은 365일 후 만료되며 한 번만 표시됩니다.

Grafana에 읽기 권한만 부여하려면 서비스 계정에 범위가 더 좁은 토큰을 발급합니다. **ID 및 액세스 → API 토큰**을 열고 **서비스 계정 토큰 발급**을 선택한 다음, 계정을 선택하고 **범위**로 **읽기 전용 관찰자** 정책을 선택합니다. [API 토큰 및 서비스 계정](/ko/identity/tokens)을 참조합니다.

데이터 소스 하나는 토큰이 속한 조직의 데이터만 읽습니다. 데이터 소스를 사용할 수 있는 모든 Grafana 사용자는 토큰으로 읽을 수 있는 데이터를 조회할 수 있습니다. Grafana의 데이터 소스 권한으로 액세스를 제한하거나 팀마다 별도의 데이터 소스와 토큰을 할당합니다.

## 플러그인 설치

Grafana CLI로 릴리스 아카이브를 설치하거나 Grafana의 플러그인 디렉터리에 압축을 풉니다. Linux 패키지와 Docker 이미지에서는 `/var/lib/grafana/plugins`를 사용합니다.

```bash
grafana cli --pluginUrl https://github.com/molesignal/molesignal-grafana-plugin/releases/download/v0.1.0/molesignal-datasource-0.1.0.zip plugins install molesignal-datasource
```

플러그인에 아직 서명이 없습니다. `grafana.ini` 또는 환경 변수 `GF_PLUGINS_ALLOW_LOADING_UNSIGNED_PLUGINS=molesignal-datasource`로 Grafana가 플러그인을 로드하도록 허용한 다음 Grafana를 다시 시작합니다.

```ini
[plugins]
allow_loading_unsigned_plugins = molesignal-datasource
```

## 데이터 소스 추가

1. Grafana에서 **연결 → 데이터 소스**를 열고 **새 데이터 소스 추가**를 선택한 다음 **MoleSignal**을 선택합니다.
2. `https://molesignal.example.com`과 같은 MoleSignal의 **URL**을 입력하고 **API 토큰**을 붙여 넣습니다.
3. **저장 및 테스트**를 선택합니다.

**저장 및 테스트**는 MoleSignal의 버전을 조회하고, 토큰에 `streams.read` 및 `streams.query` 권한이 있는지 확인하며, 유형별 스트림 수를 집계하고, MoleSignal이 필드 쿼리를 처리하는지 확인합니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| **URL** | | `/api/v1`을 제외한 MoleSignal 주소입니다. |
| **API 토큰** | | Grafana 서버에 암호화하여 저장합니다. |
| **TLS 인증서 검증 건너뛰기** | 꺼짐 | 자체 서명 인증서를 사용하는 테스트 인스턴스에서만 사용합니다. |
| **CA 인증서** | | MoleSignal 인증서에 서명한 인증 기관의 PEM 형식 인증서입니다. |
| **로그 스트림** | | 새 로그 쿼리에서 기본으로 사용하는 스트림입니다. 탐색의 애드혹 필터에서 이 스트림의 필드를 선택할 수 있습니다. |
| **로그 필드** | `message`, `level`, `trace_id` | 로그 라인, 로그 수준, 트레이스 ID를 담는 필드입니다. |
| **스크레이프 간격** | `15s` | 메트릭이 수집되는 간격입니다. `$__rate_interval`은 이 간격의 4배 이상입니다. |
| **연합 클러스터** | 현재 클러스터 | 모든 SQL 및 PromQL 쿼리가 조회하는 클러스터입니다. 쉼표로 구분합니다. |
| **MoleSignal 웹 주소** | URL 설정값 | **MoleSignal에서 열기** 링크가 연결되는 주소입니다. |
| **시간 제한(초)** | `60` | MoleSignal 요청 한 건의 최대 대기 시간입니다. |
| **동시 쿼리 수** | `10` | 패널, 탐색 창 또는 알림 규칙 하나에서 동시에 실행할 수 있는 쿼리 수입니다. |

## 쿼리 유형

| 쿼리 유형 | 조회 대상 | 표시 형식 |
|---|---|---|
| **PromQL** | 패널 간격을 사용하는 범위 쿼리 또는 인스턴트 쿼리로 조회한 메트릭 | 시계열, 테이블, 예시 데이터 |
| **SQL** | 모든 스트림 | 테이블, 시계열 또는 로그 라인 |
| **로그** | 로그 스트림에서 필드 쿼리와 일치하는 최신 레코드 | 로그 라인 |
| **트레이스** | ID로 조회한 트레이스 하나 | 트레이스 뷰 |
| **트레이스 검색** | 필드 쿼리와 일치하는 트레이스 | 각 트레이스를 열 수 있는 테이블 |
| **RED** | 필드 쿼리와 일치하는 스팬의 초당 요청 수, 초당 오류 수, 오류 비율 또는 소요 시간 백분위수 | 시계열. **그룹화 기준**에 필드를 지정하면 필드 값별로 하나씩 표시합니다. |
| **서비스 그래프** | 서비스 간 호출 | 노드 그래프 |

### PromQL

범위 쿼리는 간격마다 데이터 포인트 하나를 읽습니다. 패널 간격을 사용하되, **최소 간격**보다 짧게 설정하지 않으며 시계열당 간격 수는 11,000개를 넘지 않습니다. **범례**는 각 시계열의 이름을 지정합니다. 레이블 값을 표시하려면 `{{label}}`을 사용합니다. **예시 데이터**는 시계열의 예시 데이터를 표시하며, 각 예시에서 연결된 트레이스를 열 수 있습니다. MoleSignal은 [PromQL의 일부 기능](/ko/query/promql-subset)을 지원합니다.

### 필드 쿼리

**로그**, **트레이스 검색**, **RED**는 MoleSignal의 **로그** 및 **트레이스** 페이지와 동일한 필드 쿼리를 사용합니다. 따라서 양쪽에서 같은 쿼리를 동일하게 해석합니다.

```text
level = 'error' AND (service.name = 'checkout' OR timeout)
```

| 요소 | 의미 |
|---|---|
| `AND`, `OR`, 괄호 | `AND`가 `OR`보다 우선합니다. 괄호로 조건을 묶습니다. |
| `=`, `!=`, `>`, `>=`, `<`, `<=`, `contains` | 필드를 값과 비교합니다. |
| `field in ('a', 'b')` | 트레이스 쿼리에서 여러 값 중 하나와 일치하는지 확인합니다. |
| `MATCH(field, 'text')`, `MATCH_TEXT(field, 'words')` | 로그 쿼리에서 필드의 전문을 검색합니다. |
| 따옴표 없는 단어 또는 따옴표로 묶은 구문 | 검색할 텍스트입니다. |

**조건 추가** 행은 **필드**, **연산자**, **값**으로 비교 조건을 만들어 `AND`로 추가합니다. **RED**는 서비스가 요청을 받은 지점의 **진입 스팬** 또는 **모든 스팬**을 읽습니다.

### SQL

SQL은 모든 스트림을 조회할 수 있습니다. **스트림**은 SQL 문의 실행 계획을 수립할 때 기준이 되는 스트림을 지정합니다. 비워 두면 `FROM` 뒤의 테이블을 사용합니다. **형식**은 결과를 **테이블**, **시계열** 또는 **로그**로 표시합니다. 다음 매크로는 패널의 시간 범위를 사용합니다.

| 매크로 | 변환 결과 |
|---|---|
| `$__timeFilter(_timestamp)` | `_timestamp >= <from> AND _timestamp < <to>` |
| `$__timeGroup(_timestamp, $__interval)` | `date_bin(INTERVAL '<interval>', _timestamp)` |
| `$__timeFrom()`, `$__timeTo()` | 시간 범위의 시작과 끝을 나타내는 타임스탬프 |

`$__interval`, `$__rate_interval`, `$__range`는 PromQL과 SQL에서 사용할 수 있으며, 알림 규칙에서도 사용할 수 있습니다.

## 탐색

| 작업 | 결과 |
|---|---|
| 로그 쿼리 실행 | 로그 라인 위에 로그 수준별 로그량을 표시합니다. |
| 로그 라인의 컨텍스트 열기 | 해당 라인 앞뒤의 레코드를 각각 50개씩 표시합니다. |
| 로그 라인 상세 정보에서 값을 포함하거나 제외하는 필터 적용 | `field = 'value'` 또는 `field != 'value'`를 `AND`로 쿼리에 추가합니다. |
| 로그 라인의 트레이스 ID 또는 예시 데이터 선택 | 쿼리 옆에 트레이스를 엽니다. |
| **MoleSignal에서 열기** 선택 | MoleSignal에서 동일한 쿼리와 시간 범위를 엽니다. |

## 변수 및 임시 필터

쿼리 변수는 다음 중 한 가지 목록을 표시합니다.

| 목록 | 값 |
|---|---|
| **스트림** | 특정 유형의 스트림입니다. |
| **필드** | 스트림의 필드입니다. |
| **필드 값** | 로그 스트림의 필드에서 가장 자주 나타나는 값입니다. |
| **메트릭** | 메트릭 이름입니다. 특정 텍스트가 포함된 이름만 표시할 수도 있습니다. |
| **레이블 값** | 메트릭에 있는 특정 레이블의 값입니다. |
| **SQL** | SQL 문의 첫 번째 열입니다. |

여러 값을 선택한 변수는 각 쿼리 언어의 목록 구문으로 표현합니다. PromQL의 `=~`에는 `(a|b)`, SQL의 `IN (...)`에는 `'a', 'b'`, 트레이스 필드 쿼리의 `in (...)`에는 `'a', 'b'`를 사용합니다.

임시 필터는 PromQL의 모든 셀렉터에 레이블 매처를 추가하고 필드 쿼리에 `AND` 조건을 추가해 결과 범위를 좁힙니다. 필터의 키와 값은 데이터 소스의 **로그 스트림**에서 가져옵니다.

## 주석

주석 쿼리는 하나의 **소스**를 사용해 대시보드 패널에 표시를 추가합니다.

| 소스 | 표시 내용 |
|---|---|
| **주석** | MoleSignal의 주석을 표시합니다. 특정 **태그**가 붙은 주석만 표시할 수도 있습니다. |
| **배포** | [APM](/ko/apm/deployments)이 기록한 배포를 표시합니다. 특정 서비스의 배포만 표시할 수도 있습니다. |
| **인시던트** | 인시던트가 시작된 시점부터 해결된 시점까지를 표시합니다. 특정 서비스의 인시던트만 표시할 수도 있습니다. |

## 알림

Grafana 알림 규칙은 플러그인 백엔드를 통해 PromQL 및 SQL 쿼리를 실행합니다. [MoleSignal 알림](/ko/alerting)은 실시간 규칙, 인시던트, 온콜, 에스컬레이션도 지원합니다. Grafana에서 발생한 알림도 [외부 알림](/ko/alerting/sources#grafana)으로 MoleSignal에 전달할 수 있습니다.

## 대시보드

데이터 소스의 **대시보드** 탭에서 다음 두 대시보드를 가져옵니다.

| 대시보드 | 표시 내용 |
|---|---|
| **MoleSignal · 서비스** | 각 서비스의 요청, 오류, 처리 시간과 서비스 그래프, 가장 느린 트레이스를 표시합니다. |
| **MoleSignal · 로그** | 로그 스트림의 로그 양과 최신 오류를 표시합니다. |

## 제한

| 항목 | 제한 |
|---|---|
| 로그 쿼리 | 최신 레코드 1,000개를 반환합니다. **행 제한**으로 최대 5,000개까지 늘릴 수 있습니다. |
| 트레이스 검색 | 트레이스 100개를 반환합니다. **행 제한**으로 최대 5,000개까지 늘릴 수 있습니다. |
| 트레이스 | 조회 시간 범위의 마지막 31일 이내에 시작된 트레이스만 조회합니다. |
| PromQL | 시계열당 11,000스텝, 쿼리당 100,000개 데이터 포인트로 제한합니다. 한도를 초과하면 MoleSignal은 각 시계열에서 일정한 간격으로 데이터 포인트를 남깁니다. |
| SQL | 10,000행을 반환합니다. **행 제한**으로 최대 1,000,000행까지 늘릴 수 있습니다. |

Grafana의 로그, 트레이스, 메트릭 드릴다운 앱은 Loki, Tempo, Prometheus에서만 데이터를 읽으므로 이 데이터 소스를 열 수 없습니다.
