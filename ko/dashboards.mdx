대시보드는 팀이 함께 모니터링하는 패널 그리드입니다. 각 패널은 자체 쿼리를 실행해
워크스페이스의 스트림을 조회하고 결과를 시각화합니다. 그리드 위의 변수를 바꾸면 모든 패널에서 조회하는
서비스, 호스트 또는 환경이 한꺼번에 바뀝니다.

이 페이지에서는 대시보드를 찾고 사용하는 방법을 설명합니다. 대시보드를 만들거나 변경하려면
[대시보드 만들기](/ko/dashboards/edit)와 [변수](/ko/dashboards/variables)를 참조합니다.

## 대시보드 목록

**대시보드**를 엽니다. 상단에 대시보드와 폴더 수가 표시됩니다. 다음 옵션으로 목록을 좁히거나 표시 방식을 바꿉니다.

- 필터 입력란에서 이름으로 검색합니다.
- **전체**, **내 메모리**, **즐겨찾기**, **태그** 중에서 범위를 선택합니다.
- 특정 폴더 또는 **전체** 폴더를 선택합니다.
- **그리드** 또는 **목록** 레이아웃을 선택합니다.

상단에는 **새 대시보드**, **JSON 가져오기**, **폴더 관리**도 있습니다. 대시보드의 별 아이콘을
선택하면 **즐겨찾기**에 추가됩니다. 각 대시보드 끝에 있는 메뉴에서는 다음 작업을 수행할 수 있습니다.

| 작업 | 동작 |
|---|---|
| **열기**, **편집**, **공유** | 각각 대시보드, 대시보드 편집기, 공유 대화 상자를 엽니다. |
| **폴더로 이동** | 대시보드를 다른 폴더로 이동합니다. |
| **사본 만들기** | `<title> copy`라는 이름으로 편집 가능한 사본을 만듭니다. |
| **JSON 내보내기** | **JSON 가져오기**에서 사용할 수 있는 대시보드 모델을 다운로드합니다. |
| **NOC 화면으로 설정** | 현재 브라우저의 [NOC 월보드](#noc-월보드)에 이 대시보드를 표시합니다. |
| **삭제** | 대시보드와 패널을 삭제합니다. 삭제는 취소할 수 없습니다. |

## 폴더

폴더를 최대 3단계로 구성해 대시보드를 정리합니다. **폴더 관리**를 선택한 다음, 최상위에 폴더를 만들려면
**새 폴더**를, 선택한 폴더 안에 만들려면 **새 하위 폴더**를 선택합니다.

폴더를 지정하지 않은 대시보드는 **기본값** 폴더에 표시됩니다. 이 폴더는 이름을 바꾸거나 삭제할 수 없으며
하위 폴더를 만들 수 없습니다. 폴더를 삭제하려면 먼저 그 안의 대시보드와 하위 폴더를 모두 밖으로 이동합니다.

## 대시보드 보기

대시보드 상단에는 폴더, 패널 수, 마지막 변경 정보와 다음 컨트롤이 표시됩니다.

| 컨트롤 | 용도 |
|---|---|
| 시간 선택기 | 모든 패널의 시간 범위를 설정합니다. 시간은 개인 기본 시간대로 표시합니다. 다른 시간대로 보려면 선택기 하단에서 **변경**을 선택합니다. |
| **새로 고침** | 모든 패널의 쿼리를 다시 실행합니다. 옆의 메뉴에서 자동 새로 고침을 **꺼짐**, **자동** 또는 특정 간격으로 설정합니다. **자동**은 시간 범위와 패널 너비에 맞춰 간격을 조정합니다. |
| 변수 | [변수](/ko/dashboards/variables) 값을 선택합니다. 주소에 값이 `var-<name>=<value>` 형식으로 유지되므로 복사한 링크를 열어도 같은 화면이 표시됩니다. |
| **공유** | [공유 대화 상자](/ko/resource-sharing)를 엽니다. |
| **편집** | [편집기](/ko/dashboards/edit)를 엽니다. 읽기 전용 대시보드에는 대신 **사본 만들기**가 표시됩니다. |
| 더 보기 | **대시보드 세부 정보 보기**에서 ID, UID, 소유자, 스키마를 확인합니다. **NOC 화면**, **사본 만들기**, **JSON 내보내기**도 선택할 수 있습니다. |

패널 위에 마우스 포인터를 올리면 설명이 표시됩니다. 패널 메뉴에는 다음 작업이 있습니다.

| 작업 | 동작 |
|---|---|
| **보기** | 해당 패널만 전체 크기로 표시합니다. |
| **편집** | 편집기에서 패널을 엽니다. |
| **데이터 탐색** | 변수 값과 시간 범위를 유지한 채 패널 쿼리를 탐색기에서 엽니다. |
| **쿼리 검사** | 패널의 쿼리 정의를 JSON으로 표시합니다. |
| **공유** | 패널 링크를 복사합니다. |
| **데이터 내보내기** | 패널 데이터를 CSV로 다운로드합니다. |
| **이미지 내보내기** | 패널을 이미지로 다운로드합니다. |
| **복사** | 다른 대시보드에 붙여 넣을 수 있도록 패널의 JSON을 복사합니다. |
| 데이터 링크 | 패널의 [데이터 링크](/ko/dashboards/edit#데이터-링크)를 엽니다. |
| **알림 생성** | 패널 쿼리를 기반으로 새 [알림 규칙](/ko/alerting/rules)을 엽니다. |
| **Mole Agent 분석** | [Mole Agent](/ko/agent)에 패널에 표시된 데이터의 분석을 요청합니다. |

## 대시보드 가져오기

**JSON 가져오기**를 선택한 다음 MoleSignal 대시보드 JSON을 붙여 넣거나 `.json` 파일을 업로드합니다. 폴더를 선택한 후
**가져오기**를 선택합니다. **JSON 내보내기**에서 다운로드한 JSON이나
`GET /api/v1/dashboards/{id}`가 `model`로 반환하는 JSON을 사용합니다. `engine`은 `molesignal-dashboard`여야 합니다.

Grafana 대시보드 JSON은 가져올 수 없습니다. 편집기에서 대시보드를 다시 만듭니다. PromQL 식은
메트릭 패널에 그대로 붙여 넣을 수 있습니다. 대시보드를 Grafana에 유지하려면
[Grafana 데이터 소스](/ko/query/grafana)를 통해 MoleSignal 데이터를 조회합니다.

## Mole Agent에 대시보드 요청하기

[Mole Agent](/ko/agent)에 대시보드 초안을 요청합니다. 예를 들어 “결제 서비스용
대시보드”를 요청합니다. Mole Agent는 대시보드를 생성하지 않고 초안을 준비한 뒤 **AI 대시보드 초안** 링크를 제공합니다.

1. **읽기 전용 미리보기**를 검토합니다. 실제 대시보드와 같은 렌더러로 표시합니다.
2. 각 패널 쿼리를 한 번씩 실행한 **쿼리 사전 검사**에서 **통과**, **결과 없음** 또는
   **건너뜀** 상태를 확인합니다. **생성 경고**나 **수정할 문제**가 있는지도 확인합니다.
3. **생성 제안 제출**을 선택합니다. 생성 정책에 검토자가 필요한 경우 검토자의 승인을
   기다립니다. 그렇지 않으면 **확인 후 생성**을 선택합니다.

초안은 해당 모델에 연결되며 일정 시간이 지나면 만료됩니다. 초안을 변경하려면 다시 요청합니다.

## 기본 제공 RUM 대시보드

RUM 애플리케이션이 있는 워크스페이스에는 애플리케이션 유형별로 `内置` 및 `rum` 태그가 지정된
읽기 전용 대시보드가 하나씩 있습니다.

| 대시보드 | 대상 | 표시 항목 |
|---|---|---|
| `RUM · 浏览器应用` | 브라우저 애플리케이션 | 세션, 오류 없는 세션, 불편을 겪은 세션, LCP, INP, CLS의 75번째 백분위수와 각 추이, 소스별 오류, 페이지, 버전, 불편을 유발한 요소, 느린 호스트, 국가 및 브라우저를 표시합니다. |
| `RUM · 移动应用` | Android, iOS, Flutter 및 React Native 애플리케이션 | 세션, 크래시와 오류가 없는 세션, 불편을 겪은 세션, 크래시 없는 세션과 오류 및 크래시의 시간별 추이, 화면, 버전, 버전별 크래시, 불편을 유발한 요소, 느린 호스트, 디바이스 및 운영 체제를 표시합니다. |

서버는 각 유형의 첫 애플리케이션을 생성할 때 해당 대시보드를 설치합니다. 해당 유형의 애플리케이션이 이미 있는 워크스페이스에는
서버를 시작할 때 설치합니다. 대시보드를 변경하는 업그레이드도 같은 방식으로
적용합니다. 변수는 **应用**(애플리케이션), **环境**(한 환경 또는 모든 환경을 뜻하는
**全部**), **间隔**(시계열 차트의 막대 너비)입니다.
[RUM 개요](/ko/rum#개요)에서 **대시보드에서 열기**를 선택하면 해당 페이지의 애플리케이션과
환경이 미리 선택된 상태로 대시보드가 열립니다.

각 패널은 짧은 SQL 문을 사용합니다. 뷰와 세션은 각각 `rum_views_latest`와
`rum_sessions_latest`에서 조회합니다. 두 소스에는 각 레코드의 [최신 버전](/ko/query#rum-행의-최신-버전)이 있으며,
백분위수 계산에는 값이 있는 뷰만 포함하므로 개요와 같은 수치가 표시됩니다.
이 대시보드는 편집할 수 없습니다. 대시보드 상단이나
대시보드 목록에서 **사본 만들기**를 선택해 편집 가능한 대시보드를 만듭니다.

## NOC 월보드

상단 표시줄에서 **NOC 월보드**를 선택하면 벽면 디스플레이용 어두운 화면이 전체 화면으로 표시됩니다.
`Esc`를 누르거나 **콘솔로 돌아가기**를 선택해 종료합니다.

상태 표시줄에는 워크스페이스의 활성 인시던트와 심각도, 실시간 데이터 상태,
서비스 수, 요청률, P95 지연 시간이 요약되어 표시됩니다. 패널에는 다음 항목이 표시됩니다.

| 패널 | 표시 항목 |
|---|---|
| **인시던트** | 현재 발생 중인 인시던트를 표시합니다. |
| **토폴로지** | 지난 1시간 동안의 서비스 토폴로지를 표시합니다. |
| **상태** | 서비스별 요청률, P95 지연 시간, 오류율을 표시합니다. |
| **트래픽** | 지난 60분 동안 트래픽이 가장 많은 서비스를 표시합니다. |

**레이아웃 설정**에서 월보드 구성을 변경합니다. 프리셋(**플랫폼 운영**, **SRE** 또는
**경영진**)을 적용하거나 패널을 표시하거나 숨깁니다. 패널 너비나 순서를 변경하거나 **초기화**할 수도 있습니다.
브라우저가 레이아웃을 저장합니다.

대시보드를 NOC 화면으로 설정하면 월보드는 기본 화면 대신 해당 대시보드의 제목과
각 패널 및 해당 쿼리를 표시합니다. 월보드에서는 패널을 차트로 표시하지 않습니다. 차트를 보려면
대시보드를 직접 엽니다.

## 보고서 및 공유

대시보드에서 예약 [보고서](/ko/reports)를 만들어 PDF, PNG, CSV, SVG 또는 JSON 형식으로 전송합니다.
로그인한 사용자에게 액세스를 허용하거나, 워크스페이스 간 액세스 또는 제한된 공개 액세스를 허용하려면 **공유**를 사용합니다. 공개 대시보드는
패널에 저장된 쿼리만 실행하며 [공유 정책](/ko/settings/organization#공유-및-공개-액세스)을
해당 워크스페이스의 정책에 따라 적용합니다.
