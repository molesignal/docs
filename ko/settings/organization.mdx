**설정 → 일반**을 엽니다. 페이지를 보려면 `org.preferences.read` 권한이 필요하며, 변경하려면
`org.preferences.manage` 권한이 필요합니다. 공개 공유 섹션에서는 대신 `org.sharing.read` 및 `org.sharing.manage` 권한을 사용합니다. 각 섹션은 변경 후 잠시 뒤 자동으로 저장됩니다. **실행 취소**는
마지막 변경을 되돌리고, **다시 시도**는 실패한 변경 요청을 다시 보냅니다.

## 조직 정보

| 필드 | 규칙 |
|---|---|
| **조직 이름** | 워크스페이스 전환 메뉴, 페이지 제목, 초대장에 표시합니다. 필수 항목입니다. |
| **로고** | 워크스페이스 전환 메뉴에서 MoleSignal 로고 대신 표시합니다. **업로드**는 PNG, JPEG, WEBP 또는 SVG 이미지를 받아 128 × 128로 조정합니다. **제거**는 MoleSignal 로고를 다시 표시합니다. 변경 사항은 즉시 저장됩니다. |
| **설명** | 워크스페이스의 용도를 한두 문장으로 설명합니다. 워크스페이스 메뉴에 표시하며 최대 120자까지 입력할 수 있습니다. |
| **조직 슬러그** | 읽기 전용입니다. API와 리소스 식별자에 사용합니다. **복사**를 선택하면 슬러그를 복사합니다. |
| **조직 ID** | 읽기 전용입니다. API, 감사 기록, 지원에 사용합니다. **복사**를 선택하면 ID를 복사합니다. |

조직을 만든 후에는 슬러그와 ID를 변경할 수 없습니다.

## 환경설정 기본값

**조직 환경설정 기본값**은 개인 환경설정을 저장하지 않은 멤버에게 적용됩니다.
개인 [환경설정](/ko/account#환경설정)과 쿼리 페이지에서 변경한 시간 표시 설정을
우선 적용합니다.

| 섹션 | 필드 |
|---|---|
| 모양 | **기본 테마**, **인터페이스 밀도**. |
| 언어 및 지역 | **언어**, **기본 시간대**, **날짜 및 시간 형식**. |
| 시작 및 상호작용 | **워크스페이스 진입 시 열 페이지**, **키보드 단축키 사용**. |

## 가입 및 액세스

| 설정 | 효과 |
|---|---|
| **직접 가입 허용** | 인스턴스의 가입 요건을 충족하면 워크스페이스에 직접 가입할 수 있습니다. |
| **관리자 승인 필요** | 가입 신청은 관리자가 승인할 때까지 [승인](/ko/identity/members#승인)에서 대기합니다. 직접 가입을 허용하면 이 설정을 표시합니다. 인스턴스가 이메일을 보낼 수 없으면 이메일 주소를 인증할 수 없으므로 이 설정을 계속 활성화합니다. 이 설정을 끄려면 `[notify.smtp]`와 `[http].external_url`을 구성합니다. |
| **기본 조직 역할** | 직접 가입 시 부여할 역할을 IAM 카탈로그에서 지정합니다. 일치하는 역할 매핑이 없고 제공업체에 기본 역할이 없으면 싱글 사인온에서도 이 역할을 사용합니다. |

## 공유 및 공개 액세스

이 설정은 멤버가 만들 수 있는 [제한된 공개 링크](/ko/resource-sharing)에
제한을 적용합니다. 워크스페이스 내부 또는 다른 조직과 공유하려면 항상 로그인해야 합니다.

| 설정 | 효과 |
|---|---|
| **공개 링크 허용** | 멤버는 계정 없이 허용된 리소스를 열 수 있는 제한된 링크를 만들 수 있습니다. 아래 설정을 사용하려면 이 설정을 켜야 합니다. |
| **공개 실시간 대시보드 허용** | 실시간 대시보드의 공개 링크를 허용합니다. 공개 보기는 읽기 전용이며 쿼리, 변수, 시간 범위, 탐색을 제한합니다. |
| **공개 링크 최대 유효 기간** | **1일**, **7일** 또는 **30일**입니다. 링크를 만들 때 최대 유효 기간을 초과하는 만료 시점을 선택할 수 없습니다. |
| **공개 보고서에 비밀번호 요구** | 비밀번호를 확인한 후에만 공개 보고서에 대한 짧은 공유 세션을 시작합니다. |
| **프로덕션 리소스의 공개 공유 차단** | `production` 또는 `prod` 태그가 지정된 리소스에는 공개 링크를 만들 수 없습니다. |
| **공개 CSV 다운로드 허용** | 이 설정을 끄면 제한된 페이지에서 공개 CSV 보고서를 미리 볼 수만 있습니다. |

## 조직 수명 주기

`org.delete` 권한이 있으면 여기에서 조직 이름을 입력한 후
조직을 삭제할 수 있습니다. 기본적으로 소유자에게 이 권한을 부여합니다. 조직을 삭제하면 모든 멤버가 해당 조직에서 로그아웃되며, 삭제는 되돌릴 수 없습니다. 또는 **조직 관리
열기**를 선택하면 `_sys` 조직으로 전환합니다. 여기에서 조직을 삭제하려면 `sys.organizations.delete` 권한이 필요합니다.
[조직 관리](/ko/settings/platform#조직-관리)를 참조합니다.
