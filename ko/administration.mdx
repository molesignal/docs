MoleSignal은 세 가지 범위에서 관리합니다. 범위마다 전용 페이지와 권한이 있습니다.

| 범위 | 관리 주체 | 관리 항목 | 가이드 |
|---|---|---|---|
| 개인 계정 | 모든 멤버(본인 계정만 해당) | 프로필, 환경설정, 개인 알림, 비밀번호, 세션, 멤버십 | [계정 설정](/ko/account) |
| 워크스페이스 | 조직 소유자 및 관리자 | 멤버, 역할, 액세스 권한 부여, 토큰, 싱글 사인온, 워크스페이스 설정, 알림, 데이터 보안, 감사 | [ID 및 액세스](/ko/identity), [설정](/ko/settings) |
| 플랫폼 `_sys` | 최고 관리자 및 플랫폼 역할이 부여된 계정 | 조직, 인스턴스 전체 설정, 시스템 텔레메트리, 플랫폼 관리자 | [플랫폼 설정](/ko/settings/platform) |

## 워크스페이스 관리

새 워크스페이스는 일반적으로 다음 순서로 설정합니다.

<Steps>
  <Step title="가입 방식 결정">
    [가입 정책](/ko/settings/organization#가입-및-액세스)을 설정합니다.
    [싱글 사인온](/ko/identity/sso)을 회사 이메일 도메인에 연결합니다.
  </Step>
  <Step title="멤버에게 필요한 권한 부여">
    [멤버](/ko/identity/members)에게 기본 제공 역할을 할당합니다.
    업무 범위가 더 좁다면 [사용자 지정 역할](/ko/identity/roles#역할)을 만들고, 온콜과 소유권을 관리할 수 있도록
    멤버를 [팀](/ko/identity/teams#팀)으로 구성합니다.
  </Step>
  <Step title="프로그램에 별도 ID 부여">
    수집기, CI,
    자동화에는 개인 토큰 대신 [서비스 계정](/ko/identity/tokens#서비스-계정)을 만듭니다.
  </Step>
  <Step title="알림 설정">
    경보와 보고서가 담당자에게 전달되도록
    [커넥터, 정책, 대체 경로](/ko/notification-channels)를 구성합니다.
  </Step>
  <Step title="데이터 보호">
    민감한 값에는 [정규식 패턴과 필드 마스킹](/ko/settings/data-security)을 추가합니다.
    [감사 로그](/ko/settings/data-security#감사)를 정기적으로 검토합니다.
  </Step>
</Steps>

## 플랫폼 관리

영구 조직인 `_sys`는 일반 테넌트가 아닙니다. `_sys` 세션에서는
플랫폼 권한이 허용하는 페이지와 경로에만 액세스할 수 있습니다. 최고 관리자와
`_sys`의 **ID 및 액세스 → 액세스 권한 부여**에서 플랫폼 역할을 부여받은 계정이 액세스할 수 있습니다.
[플랫폼 액세스](/ko/identity#플랫폼-액세스)를 참조합니다.

| 권한 | 허용 작업 |
|---|---|
| `sys.organizations.read`, `.create`, `.update`, `.disable`, `.delete` | 조직 목록을 조회하고, 조직을 생성하거나 이름을 변경하거나 비활성화하거나 활성화하거나 삭제합니다. 생성 권한을 제외하면 권한 부여 시 조직 하나를 지정할 수 있습니다. |
| `sys.settings.retention.*`, `sys.settings.limits.*`, `sys.settings.signin.*`, `sys.settings.alerting.*`, `sys.settings.topology.*` | 보존, 한도, 로그인, 경보 평가, 서비스 그래프 및 페더레이션 설정을 조회하고 변경합니다. |
| `sys.signing_keys.read`, `sys.signing_keys.rotate` | 세션 서명 키 목록을 조회하고 키를 교체합니다. |
| `sys.clusters.read`, `sys.clusters.manage` | 원격 클러스터를 조회하고 변경합니다. |
| `sys.nodes.read`, `sys.nodes.drain` | 노드를 조회하고 드레이닝을 시작합니다. |
| `sys.query.admission.read`, `sys.query.admission.manage` | 쿼리 허용 설정을 조회하고 변경합니다. |
| `sys.telemetry.read`, `sys.telemetry.manage` | MoleSignal 자체의 텔레메트리를 조회하고 구성합니다. [자체 옵저버빌리티](/ko/self-observability)를 참조합니다. |
| `sys.trace_debug.manage` | 플랫폼의 트레이스 디버깅을 활성화하고 구성합니다. |
| `sys.administrators.read`, `sys.administrators.manage` | 플랫폼 역할, 정책, 권한 부여 내역을 조회하고 변경합니다. |

테넌트 세션과 `mspat-*` API 토큰은 보호된 `_sys` 데이터에 액세스할 수 없습니다.
