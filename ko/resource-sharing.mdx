MoleSignal은 대시보드나 보고서를 한 번에 하나씩 공유합니다. 공유 링크는 사용자 토큰으로 사용되지 않습니다.
공개 링크를 열면 짧은 시간 동안 제한된 공유 세션이 시작되며, 그 외의 공유 방식에서는 항상
방문자의 권한을 확인합니다.

## 대시보드 또는 보고서 공유

대시보드, 대시보드 목록 또는 보고서에서 **공유**를 선택합니다. **리소스 공유** 대화 상자에서
**액세스 범위**를 선택합니다.

| 범위 | 방문자 | 규칙 |
|---|---|---|
| **현재 워크스페이스 멤버** | 로그인한 멤버입니다. | 워크스페이스에서 해당 리소스에 액세스할 권한이 필요합니다. |
| **특정 조직** | 로그인한 **대상 조직**의 멤버입니다. | 조직 간 액세스 권한을 명시적으로 부여합니다. 조직 간 권한 부여를 관리할 수 있는 멤버만 이 방식으로 공유할 수 있습니다. |
| **링크가 있는 모든 사용자** | 계정 없이도 링크를 가진 모든 사용자가 방문할 수 있습니다. | 링크는 취소할 수 있는 제한된 인증 정보입니다. 워크스페이스 정책으로 이 유형의 링크를 금지할 수 있습니다. |

제한 사항을 설정한 다음 **공유 링크 만들기**를 선택합니다.

| 설정 | 적용 대상 | 효과 |
|---|---|---|
| **만료** | 모든 범위 | 워크스페이스의 공개 링크 최대 유효 기간 내에서 **1일**, **7일**, **30일** 또는 만료 없음을 선택합니다. 만료되면 링크를 즉시 사용할 수 없게 됩니다. |
| **최대 방문 횟수** | 공개 링크 | 새 공유 세션마다 방문 횟수를 1회씩 더합니다. 비워 두면 횟수를 제한하지 않습니다. |
| **접근 비밀번호** | 공개 링크 | 비밀번호를 확인한 후에만 제한된 세션을 시작합니다. 비밀번호 앞뒤의 공백은 무시합니다. 공개 대시보드에는 항상 비밀번호가 필요하며, 워크스페이스 정책에 따라 공개 보고서에도 비밀번호가 필요할 수 있습니다. |
| **다운로드 허용** | 공개 보고서 | 이 설정을 끄면 보고서를 온라인에서 미리 볼 수만 있습니다. 워크스페이스 정책으로 공개 CSV 다운로드를 금지할 수 있습니다. |
| **최대 데이터 시간 범위** | 공개 대시보드 | 1시간, 6시간 또는 24시간입니다. **시간 범위 변경 허용**을 켜면 방문자가 최대 범위 내에서 사전 설정을 선택할 수 있습니다. |
| **공개 변수** | 공개 대시보드 | 선택하지 않은 변수는 공개 모델과 해당 모델의 요청에서 제거합니다. **허용 목록에 있는 변수 변경 허용**을 켜면 방문자가 선택된 변수의 값을 변경할 수 있습니다. |

**링크 복사**를 선택하면 링크를 복사합니다. 대화 상자에서 링크를 보관하므로 나중에 다시 복사할 수 있습니다.

## 공개 링크를 연 방문자에게 표시되는 내용

공개 대시보드는 제한된 프록시를 통해 패널에 저장된 쿼리만 실행합니다. 쿼리
표현식과 탐색기는 표시하지 않으며, 브라우저에서 임의의 SQL 또는 PromQL을 전송할 수 없습니다. 공개
보고서는 링크를 만들 때 생성한 고정 스냅샷입니다. 보고서를 열어도 실시간 쿼리는 실행하지 않습니다. 페이지에는
**공개 액세스** 워터마크와 만료 시점이 표시됩니다.

링크가 만료되거나 비활성화되거나 최대 방문 횟수에 도달하면 **링크를 사용할 수 없습니다**가 표시됩니다. 방문은
최대 30분 동안 유지됩니다. 이후 페이지를 새로고침하면 **링크를 사용할 수 없습니다**가 표시되고
공유 링크를 다시 열라는 안내가 나옵니다. 링크가 아직 유효하면 다시 열어 이전 상태에서 계속할 수 있습니다.
비밀번호가 설정되어 있으면 먼저 입력해야 하며, 링크를 다시 열 때마다 새 방문으로 집계합니다.

<Warning>
  공개 링크는 소유자 인증 정보입니다. 링크를 입수한 모든 사용자가 공유 콘텐츠를 볼 수 있습니다. 만료 기간이나
  비밀번호를 설정했더라도 민감한 데이터는 공유하지 마십시오.
</Warning>

### 접근 비밀번호 제한

접근 비밀번호를 잘못 입력하면 계정 비밀번호와 동일한 [로그인 제한](/ko/settings/platform#로그인-제한)을
적용하며, 각 링크를 하나의 계정으로 처리합니다. 아래의 실패 횟수, 잠금 시간,
확인 간격은 기본값이며 관리자가 변경할 수 있습니다.

| 실패 횟수 | 결과 |
|---|---|
| 한 주소에서 동일한 링크에 5회 | 해당 주소에서 이 링크에 액세스할 수 없도록 15분 동안 차단합니다. 다른 주소와 링크에는 영향을 주지 않습니다. |
| 한 주소에서 링크 접근 또는 로그인 시 총 30회 | 해당 주소에서는 15분 동안 비밀번호로 보호된 링크를 열거나 비밀번호로 로그인할 수 없습니다. |
| 모든 주소에서 동일한 링크에 총 20회 | 링크를 잠그지 않습니다. 60초마다 비밀번호를 한 번만 확인하며, 최근 30일 이내에 링크를 연 주소에는 이 간격을 적용하지 않습니다. |

요청을 거부하면 `Retry-After`와 함께 `429`를 반환하고 비밀번호를 확인하지 않습니다. 따라서 올바른
비밀번호도 대기 시간이 끝난 후에 입력해야 합니다. 페이지에 대기 시간이 표시됩니다. 올바른 비밀번호를 입력하면
해당 주소에서 이 링크에 대해 누적한 실패 횟수를 초기화합니다.

기본적으로 사설 주소는 주소별 제한에 포함하지 않습니다. 따라서 프록시를 별도로 구성하지 않은 경우에는
실패 20회 제한만 적용합니다. [클라이언트 IP 인식](/ko/settings/platform#클라이언트-ip-식별)을 참조합니다.

링크 자체는 잠기지 않으므로 확인 간격이 늘어나도 비밀번호 추측 시도를 계속할 수 있습니다. 긴 비밀번호와 짧은
만료 기간을 설정합니다.

## 기존 공유 관리

대화 상자의 **기존 공유**에는 리소스의 링크와 각 링크의 방문 횟수 및 만료 시점이 표시됩니다.

| 작업 | 효과 |
|---|---|
| **링크 복사** | 링크를 다시 복사합니다. |
| **교체** | 기존 링크가 유출되었을 가능성이 있는 경우 새 링크로 교체합니다. 기존 링크는 더 이상 작동하지 않습니다. |
| **비활성화** | 링크를 즉시 비활성화합니다. |

링크 저장 기능을 도입하기 전에 생성한 공유의 경우, 링크를 한 번 교체해야 표시됩니다.

## 워크스페이스 정책

관리자는 다음 메뉴에서 멤버가 공개적으로 공유할 수 있는 항목을 설정합니다.
[설정 → 일반 → 공유 및 공개 액세스](/ko/settings/organization#공유-및-공개-액세스):
공개 링크 사용 여부, 실시간 대시보드 공개 여부, 공개 링크의 최대 유효 기간, 공개
보고서의 비밀번호 요구 여부, `production` 또는 `prod` 태그가 지정된 리소스의 공개 링크 금지 여부, 공개 CSV 다운로드 허용 여부를 설정합니다.
정책에서 특정 범위를 차단하면 대화 상자에 차단 사실과 설정으로 이동하는 옵션이 표시됩니다. 대신 워크스페이스 내 공유 또는 조직 간
공유를 사용합니다.

## 감사 및 권한

공유 링크를 만들거나 열거나 교체하거나 비활성화하면 다음 로그에 기록합니다.
[감사 로그](/ko/settings/data-security#감사). 접근 비밀번호를 잘못 입력하면
`resource_share.password_failure`로, 제한에 도달하면 `resource_share.lockout`으로 기록합니다. 방문자
주소는 [클라이언트 IP 인식](/ko/settings/platform#클라이언트-ip-식별)으로 확인합니다. 따라서
프록시를 별도로 구성하지 않은 경우 감사 로그에 프록시의 주소가 표시됩니다. 공유하려면
`dashboards.share` 또는 `reports.share`와 같은 해당 리소스의 공유 권한이 필요합니다. MoleSignal은
공유를 만들기 전에 해당 리소스에 대한 액세스 권한을 다시 확인합니다.
