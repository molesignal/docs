**계정 설정**은 워크스페이스 전체가 아닌 개인에게 적용됩니다. 상단 바에서 사용자
프로필 사진을 열고 **계정 설정**, **환경설정** 또는 **알림**을 선택합니다. 모든 멤버는
자신의 계정 설정을 변경할 수 있습니다. **API 토큰**에만 권한이 필요합니다.

| 그룹 | 섹션 | 용도 |
|---|---|---|
| 개인 설정 | **프로필** | 표시 이름, 프로필 사진, 짧은 소개입니다. |
| | **환경설정** | 테마, 밀도, 시간대, 날짜 형식, 시작 페이지, 키보드 단축키입니다. |
| | **알림** | 개인 알림 수신 방법, 전송 순서, 알림 제한 시간입니다. |
| 보안 및 액세스 | **보안 및 로그인** | 비밀번호 재설정과 연결된 로그인 방법입니다. |
| | **활성 세션** | 현재 브라우저의 세션입니다. |
| | **API 토큰** | 계정으로 작업을 수행하는 개인 API 토큰입니다. |
| 워크스페이스 | **워크스페이스 및 ID** | 워크스페이스, 역할, 자동화에 사용하는 식별자입니다. |

## 프로필

| 필드 | 규칙 |
|---|---|
| **표시 이름** | 다른 멤버에게 표시되는 이름입니다. |
| **로그인 이메일** | 읽기 전용입니다. 관리자 또는 ID 공급자가 관리합니다. |
| **자기소개** | 선택 항목이며, 최대 500자까지 입력할 수 있습니다. |
| 프로필 사진 | **프로필 사진 변경**을 선택하면 최대 2 MB의 PNG, JPEG 또는 WebP 이미지를 업로드할 수 있습니다. **제거**를 선택하면 이니셜이 다시 표시됩니다. |

**변경 사항 저장**을 선택해 프로필을 저장합니다.

## 환경설정

개인 환경설정은 [워크스페이스 기본값](/ko/settings/organization#환경설정-기본값)보다 우선합니다.
쿼리 페이지에서는 현재 조사에 사용할 시간 표시 방식을 별도로 변경할 수 있습니다.

| 섹션 | 필드 | 선택 항목 |
|---|---|---|
| 모양 | **기본 테마** | **시스템**, **라이트** 또는 **다크**입니다. |
| | **인터페이스 밀도** | **넓게** 또는 **좁게**입니다. **좁게**는 테이블, 로그 목록, 탐색 메뉴, 설정의 행 높이와 간격을 줄입니다. 차트, 코드, 대화의 표시는 그대로 유지합니다. |
| 시간 및 지역 | **기본 시간대** | **브라우저 시간대** 또는 목록에 있는 시간대를 선택합니다. 대시보드, 로그, 메트릭, 트레이스에 이 시간대를 적용합니다. |
| | **날짜 및 시간 형식** | 날짜는 `2026-07-27`, `2026/07/27`, `27/07/2026` 또는 `07/27/2026` 형식으로 표시합니다. 시간은 **24시간제** 또는 **12시간제**로 표시합니다. |
| 시작 및 상호작용 | **워크스페이스 진입 시 열 페이지** | **홈**, **마지막으로 방문한 페이지**, **대시보드**, **로그**, **메트릭**, **트레이스**, **알림 인시던트**, **Mole Agent** 또는 특정 대시보드를 선택합니다. |
| | **키보드 단축키 사용** | [전역 단축키](/ko/console#키보드-단축키)를 켜거나 끕니다. |

**설정 저장**을 선택합니다. 저장하지 않고 페이지를 나가면 변경 사항을 취소할지 묻습니다.
인터페이스 언어는 이 페이지가 아닌 사용자 메뉴의 **언어**에서 선택합니다.

## 알림

**알림**에는 현재 워크스페이스에서 멤버가 알림을 받을 수 있는 방법과
MoleSignal이 각 방법으로 전송을 시도하는 순서가 표시됩니다.

<Steps>
  <Step title="알림 수신 방법 연결">
    **알림 수신 방법 연결**을 선택합니다. 관리자가
    [설정 → 알림 → 커넥터](/ko/notification-channels)에서 구성한 **커넥터**를 선택하고
    **외부 ID**를 입력합니다. 이메일 주소, 인스턴트 메시징 플랫폼의 사용자 ID 또는 음성 통화와 SMS용 전화번호를 입력합니다. 전화번호에는
    `+`와 국가 코드를 포함합니다. **레이블**을 지정합니다.
  </Step>
  <Step title="테스트 전송">
    알림 수신 방법에서 **테스트 전송**을 선택합니다. 메시지가 도착하면 커넥터가
    해당 ID를 허용하는지 확인할 수 있습니다.
  </Step>
  <Step title="관리자 검증 받기">
    알림 수신 방법은 활성화하고 검증한 후에만 알림을 전송합니다.
    `org.members.update` 권한이 있는 관리자가 해당 ID가 멤버의 것인지 확인한 후
    해당 방법에서 **검증**을 선택합니다.
  </Step>
  <Step title="카테고리에 알림 수신 방법 지정">
    **전송 설정**에서 **경보 이벤트**,
    **온콜 이벤트** 또는 **보고서**의 **이 카테고리의 알림 수신**을 켭니다. **엔드포인트 위로 이동**과
    **엔드포인트 아래로 이동**으로 수신 방법의 순서를 정합니다.
  </Step>
</Steps>

**경보 이벤트**는 인시던트의 [긴급도](/ko/alerting/on-call#긴급도)에 따라 **긴급도가 높은 경보의 알림 순서**와 **긴급도가 낮은 경보의
알림 순서**를 구분합니다. 긴급도가 낮은 경보에 단계를 지정하지 않으면
긴급도가 높은 경보의 첫 번째 방법만 사용합니다. 각 순서에서 두 번째 단계부터는 전송을 시도하기 전에 대기할 시간을 분 단위로 지정할 수 있습니다.
지정한 시간이 지날 때까지 아무도 경보를 확인하지 않은 경우에만 후속 단계에서 멤버에게 알림을 보냅니다.
이전 단계와 대기 시간이 같은 단계는 이전 단계에서 전송에 실패한 경우에만 실행합니다.
자세한 내용은
[아무도 확인하지 않으면 다음 단계로 이동](/ko/notification-channels#경보를-확인하지-않으면-다음-단계로-진행)을 참조합니다.

**알림 제한 시간 사용**을 켜면 선택한 **시간대**에서 **시작**과
**종료** 시간(`HH:MM`) 사이에 해당 카테고리의 알림을 멤버에게 보내지 않습니다. 제한 시간이 끝나도 해당 알림을 보내지 않습니다. 경보 이벤트에서는 긴급도가 낮은
경보를 제한 시간 동안 전송하지 않습니다. **알림 제한 시간에도 긴급도가 높은 경보 받기**를 켜면
이 시간에도 긴급도가 높은 경보를 받습니다. 수신 방법을 삭제하기 전에 모든 전송 설정에서 해당 방법을 제거합니다.

온콜 일정에 포함된 멤버가 경보를 받을 방법이 없으면 이 페이지와
[홈 페이지](/ko/home)의 온콜 카드에 안내가 표시됩니다.
자세한 내용은 [경보를 받을 수 없는 멤버](/ko/alerting/on-call#경보를-받을-수-없는-멤버)를 참조합니다.

MoleSignal은 팀 및 조직의 대체 경로보다 개인이 설정한 순서에 따라 먼저 전송을 시도합니다.
자세한 내용은 [알림 채널 및 전송](/ko/notification-channels)을 참조합니다.

## 보안 및 세션

**보안 및 로그인 → 비밀번호 변경**을 선택하면 로그인 이메일로 비밀번호 재설정 링크를 보냅니다.
링크 사용 방법은 [로그인](/ko/console#로그인)을 참조합니다.

**연결된 로그인 방법**에는 계정에 로그인할 수 있는 싱글 사인온 ID와
각 ID의 워크스페이스 및 마지막 사용 시간이 표시됩니다. **연결 해제**를 선택하면 해당 ID로 계정에 로그인할 수 없습니다.
같은 ID로 다시 로그인하면
[기존 계정 연결](/ko/identity/sso#기존-계정-연결)에 설명된 확인 절차를 거칩니다. 비밀번호가 없는
계정은 마지막으로 남은 ID의 연결을 유지합니다.

**인증 앱**과 **패스키**는 비밀번호 외에 추가 인증을 요구합니다. 패스키만으로
비밀번호 없이 로그인할 수도 있습니다. 설정 방법, 복구 코드, 두 번째 인증 수단을 분실했을 때의 대응 방법은
[다단계 인증 및 패스키](/ko/identity/mfa)를 참조합니다.

**활성 세션**에는 현재 브라우저의 세션이 표시됩니다. **이 기기에서 로그아웃**을 선택하면 이 세션을 종료합니다.
**다른 모든 기기에서 로그아웃**을 선택하면 다른 브라우저와 다른 컴퓨터의 모든 로그인 세션을 종료하고
현재 브라우저의 로그인 상태를 유지합니다.

**API 토큰**에는 개인 토큰이 표시되며, **새 토큰**으로 새 토큰을 발급할 수 있습니다. 토큰은 계정을 대신해 작업하며
사용 시점에 계정에 부여된 권한을 넘을 수 없습니다. 토큰 범위를 지정해 권한을 더 제한할 수 있습니다. 이 섹션에는
`personal_tokens.manage` 권한이 필요합니다. 모든 기본 제공 역할에 이 권한이 있습니다.
자세한 내용은 [API 토큰 및 서비스 계정](/ko/identity/tokens)을 참조합니다.

## 워크스페이스 및 ID

**워크스페이스 및 ID**에는 계정이 속한 워크스페이스와 각 워크스페이스의 역할 및
상태가 표시됩니다. **전환**을 선택하면 현재 워크스페이스가 바뀝니다. 플랫폼 관리자가
비활성화한 워크스페이스는 열 수 없습니다.

**고급 정보**에는 **사용자 ID**와 현재 워크스페이스의 **조직 ID** 및
**조직 슬러그**가 표시됩니다. 각 항목에서 **복사**를 선택할 수 있습니다. 스크립트, API 호출,
리소스 경로에 이 식별자를 사용합니다.
