MoleSignal의 모든 페이지는 같은 구조를 사용합니다. 상단 표시줄에는 모든 제품 영역을 담은 메뉴가 있고, 그 아래에는
콘텐츠가 있습니다. 이 페이지에서는 공통 컨트롤을 설명합니다. 이 매뉴얼의 나머지 부분에서는 각 제품 영역의
페이지를 설명합니다.

## 로그인

MoleSignal 인스턴스 주소를 열고 다음 방법 중 하나로 로그인합니다.

| 방법 | 절차 |
|---|---|
| 이메일 및 비밀번호 | **이메일로 로그인**을 선택하고 이메일 주소를 입력합니다. **계속**을 선택한 다음 비밀번호를 입력합니다. 다른 로그인 방법이 없으면 이메일 주소 입력 화면이 바로 표시됩니다. |
| 싱글 사인온 | 활성화된 공급자의 행을 선택합니다. LDAP 공급자를 선택했다면 디렉터리 사용자 이름과 비밀번호를 차례로 입력합니다. [싱글 사인온](/ko/identity/sso)을 참조합니다. |
| 패스키 | **패스키로 계속**을 선택합니다. [다단계 인증](/ko/identity/mfa)을 참조합니다. |
| 가입 | 인스턴스에서 자체 가입을 허용할 때만 **가입 →**이 표시됩니다. 인스턴스에서 이메일을 보낼 수 있으면 이메일 주소를 입력한 다음, 이메일로 받은 링크를 열어 이름과 비밀번호를 입력합니다. 링크는 30분 후 만료됩니다. 새 계정은 즉시 로그인할 수 있거나 관리자 승인을 기다려야 합니다. 인스턴스에서 이메일을 보낼 수 없으면 이메일 주소, 이름, 비밀번호를 한 번에 입력합니다. 이 경우 새 계정은 관리자 승인을 기다려야 합니다. 해당 이메일 주소로 등록된 계정이 있는지와 관계없이 페이지에는 같은 응답이 표시됩니다. |

페이지는 이 브라우저에서 마지막으로 사용한 로그인 방법과 계정을 기억하고, 해당 행에
**마지막 사용**을 표시합니다. 비밀번호는 저장하지 않습니다. 마지막에 이메일과 비밀번호로 로그인했다면 상단에
**이메일로 계속** 행이 추가됩니다. 이 행을 선택하면 비밀번호 입력 화면으로 바로 이동합니다.

비밀번호를 재설정하려면 **비밀번호를 잊으셨나요?**를 선택하고 계정의 이메일 주소를 입력합니다.
해당 이메일 주소로 등록된 계정이 있는지와 관계없이 페이지에는 같은 응답이 표시됩니다. 이메일의 링크는
30분 후 만료되며 한 번만 사용할 수 있습니다. 새 비밀번호는 8자 이상이어야 합니다. 이메일 주소당 한 시간에
가입 및 비밀번호 재설정 이메일을 합쳐 최대 5통까지 받을 수 있습니다.

비밀번호를 너무 많이 틀리면 페이지에 대기 시간이 표시됩니다.
[로그인 제한](/ko/settings/platform#로그인-제한)을 참조합니다.

로그인하면 MoleSignal은 개인
[환경설정](/ko/account#환경설정)의 **워크스페이스 진입 시 열 페이지**에서 선택한 페이지를 엽니다. 설정을 변경하지 않으면 **홈**이 열립니다.

## 워크스페이스 선택

UI에서는 선택한 조직을 **워크스페이스**라고 부릅니다.
상단 표시줄 왼쪽의 워크스페이스 전환기에는 워크스페이스의 로고와 이름이 표시됩니다.
자체 [로고](/ko/settings/organization#조직-정보)가 없는 워크스페이스에는
MoleSignal 로고가 표시됩니다.

전환기를 선택하면 워크스페이스 메뉴가 열립니다. 메뉴 상단에는 워크스페이스 이름과
해당 워크스페이스에서 계정에 부여된 역할, 워크스페이스 설명이 표시됩니다.
**조직 설정**을 선택하면 **설정 → 일반**이 열리고, **멤버**를 선택하면
워크스페이스의 멤버 목록이 열립니다. **전환 대상**에는 계정이 소속된 다른 조직이
로고 또는 이름의 첫 글자와 함께 표시됩니다. 전환할 조직을 선택합니다. **조직 관리…**는 조직을
관리하는 계정에만 표시됩니다.

워크스페이스를 전환하면 해당 조직에서 계정에 부여된 권한을 불러옵니다.
새 역할로 이용할 수 없는 페이지는 탐색 메뉴에서 사라집니다.

<Note>
  UI에서는 **워크스페이스**라고 부릅니다. API 필드와 권한 키에서는 `organization`과 `org_id`를 사용합니다.
</Note>

## 상단 표시줄

| 컨트롤 | 용도 |
|---|---|
| 워크스페이스 전환기 | 현재 워크스페이스의 로고와 이름을 표시하고 [워크스페이스 메뉴](#워크스페이스-선택)를 엽니다. |
| 메뉴 | 모든 제품 영역이 포함된 [메뉴](#메뉴)를 엽니다. |
| 검색창 | [명령 팔레트](#명령-팔레트로-검색)를 엽니다. |
| Mole Agent | 어느 페이지에서든 [Mole Agent](/ko/agent) 패널을 엽니다. 계정에 Mole Agent 사용 권한이 있을 때 표시됩니다. |
| **NOC 월보드** | 대형 화면용 월보드 모드를 엽니다. [NOC 월보드](/ko/dashboards#noc-월보드)를 참조합니다. |
| **알림** | 승인 대기 중인 가입 요청과 상태 페이지 초안, 조치가 필요한 상태 페이지 자동화 항목을 나열합니다. 종 아이콘에 읽지 않은 알림 수를 최대 **99+**까지 표시합니다. |
| **도움말** | 이 문서, 키보드 단축키, 인스턴스 버전을 확인할 수 있는 **제품 정보**를 엽니다. |
| 테마 | 다크 테마와 라이트 테마를 전환하고 선택한 테마를 계정에 저장합니다. |
| 사용자 아바타 | **계정 설정**, **환경설정**, **알림**, **언어**, **로그아웃** 메뉴를 엽니다. **로그아웃**을 선택하면 브라우저의 모든 탭에서 세션이 종료됩니다. |

## 메뉴

상단 표시줄의 워크스페이스 오른쪽에 있는 메뉴 버튼에 마우스 포인터를 올리거나 버튼을 선택하면
모든 제품 영역을 담은 메뉴가 페이지 위로 펼쳐집니다. 메뉴는 이 매뉴얼과 같은 방식으로
제품 영역을 그룹화합니다.

| 그룹 | 영역 | 용도 |
|---|---|---|
| 홈 | [**홈**](/ko/home) | 시스템 상태: 인시던트, 규칙, 서비스, 검사, 오류율과 지연 시간, 데이터 수집, 온콜 현황을 확인합니다. |
| 관측 | [**대시보드**](/ko/dashboards) | 팀에서 함께 모니터링하는 패널과 변수를 확인합니다. |
| | [**메트릭**](/ko/metrics) | PromQL로 쿼리하고 시계열, 카디널리티, 데이터 품질을 확인합니다. |
| | [**로그**](/ko/logs) | 이벤트를 검색하고 필드를 탐색하며 이벤트의 컨텍스트를 엽니다. |
| | [**트레이스**](/ko/traces) | 트레이스를 찾고 스팬을 검사하며 트레이스 두 개를 비교합니다. |
| | [**APM**](/ko/apm) | 서비스 상태, 엔드포인트, 종속성, 오류, SLO, 배포를 확인합니다. |
| | [**RUM**](/ko/rum) | 세션, 리플레이, 프런트엔드 오류, Web Vitals, 분석 데이터를 확인합니다. |
| | [**프로필**](/ko/profiles) | CPU, 메모리, 경합의 플레임 그래프를 확인합니다. |
| 신뢰성 | [**알림**](/ko/alerting) | 인시던트, 규칙, 온콜 일정, 에스컬레이션, 알림 음소거를 관리합니다. |
| | [**합성 모니터링**](/ko/synthetics) | 프로브 위치에서 예약된 검사를 실행합니다. |
| | [**상태 페이지**](/ko/status-pages) | 인시던트 및 유지보수 정보를 고객에게 공개합니다. |
| AI 운영 | [**Mole Agent**](/ko/agent) | 채팅, 조사, 자동화, 지식, 스킬을 사용합니다. |
| 데이터 | [**데이터 소스**](/ko/intake) | 데이터 소스를 연결하고 데이터가 들어오는지 확인합니다. |
| | [**스트림**](/ko/streams) | 스키마, 보존 기간, 검색 작업을 관리합니다. |
| | [**파이프라인**](/ko/pipelines) | 데이터를 변환하고 라우팅하며 백필합니다. |
| | [**함수**](/ko/functions) | 재사용 가능한 VRL 및 JavaScript 변환을 관리합니다. |
| | [**테이블 확장**](/ko/extend-tables) | 조회 테이블로 이벤트에 정보를 추가합니다. |
| 협업 | [**보고서**](/ko/reports) | 보고서를 예약하고 공유합니다. |
| 관리 | [**ID 및 액세스**](/ko/identity) | 사용자, 역할, 그룹, 팀, 토큰, 싱글 사인온을 관리합니다. |
| | [**설정**](/ko/settings) | 워크스페이스, 알림, 데이터, 보안, 플랫폼을 설정합니다. |

메뉴에는 계정에 접근 권한이 있는 영역만 표시됩니다. 메뉴에서 영역을 숨기더라도
서버에서는 권한을 확인합니다.

메뉴 왼쪽의 **최근 항목**에는 최근에 연 영역이 최신순으로 표시됩니다. 현재 열려 있는
영역은 제외합니다. 목록을 계정에 저장하므로 다른 브라우저에서도 같은 목록을 볼 수 있습니다.

항목을 선택하면 현재 탭에서 열립니다. 새 탭에서 열려면 Ctrl 키를 누른 채 클릭하거나(Mac에서는 ⌘ 키) 마우스 가운데 버튼으로 클릭합니다.
또는 항목에 마우스 포인터를 올리고 끝에 있는 화살표를 선택합니다. 모든 항목을 새 탭에서 열려면 메뉴 하단의
**항상 새 탭에서 열기**를 켭니다. 이 설정은 계정에 저장됩니다.

마우스 포인터를 올려 메뉴를 열면 포인터가 버튼과 메뉴 영역을 모두 벗어날 때 메뉴가 닫힙니다. 메뉴를 계속 열어 두려면
열린 상태에서 메뉴 버튼을 선택합니다. 메뉴를 닫으려면 Esc 키를 누르거나, 메뉴 바깥을 선택하거나, 메뉴 버튼을
다시 선택합니다. 화면이 좁으면 메뉴가 상단 표시줄 아래 영역을 모두 채웁니다.

## 시간 컨텍스트 유지

쿼리 페이지 상단의 시간 선택기에서 페이지의 시간 범위를 설정합니다.

- 시간 선택기 하단에는 페이지에 표시되는 시간의 시간대가 표시됩니다. **변경**으로
  다른 시간대를 선택하기 전까지는 개인 기본 시간대를 사용합니다. 선택한 시간대는 페이지에 적용되며,
  로그, 트레이스, 메트릭에서는 해당 쿼리 탭에 적용됩니다. **내 기본 시간대로 설정**을 선택하면 개인 기본 시간대로 저장합니다.
- 다른 시그널로 이동하면 시간 범위를 유지하고 출발점의 식별자를 추가합니다.
  예를 들어 트레이스에서 관련 로그로 이동하면 트레이스의 시간 범위를 유지하고 `trace_id`
  필터를 추가합니다.
- 명령 팔레트나 [단축키](#키보드-단축키)를 사용해 현재 시간을 앵커로 고정하고,
  시간 범위가 포함된 현재 조사 링크를 복사합니다.

## 명령 팔레트로 검색

`⌘K` 또는 `Ctrl+K`를 누르거나 검색 상자를 선택합니다. 검색어를 입력해 다음 항목을 찾습니다.

- 페이지, 스트림, 서비스, 대시보드, 저장된 뷰, 알림 규칙, 인시던트
- 작업: 페이지로 이동, SQL 또는 PromQL 실행, 최근 5분부터
  최근 7일까지 시간 범위 설정, 현재 시간 고정, 조사 링크 복사, 테마 또는 표시 밀도 변경,
  설정 열기, 대시보드·알림·파이프라인 생성, 데이터 소스 연결,
  키보드 단축키 표시, 로그아웃

`Enter`를 눌러 결과를 엽니다. 팔레트 하단에는 결과를 새
[조사 스택](/ko/correlation#ui의-조사-스택)에서 열거나 현재 스택 위에
추가하는 데 사용하는 키가 표시됩니다.

## 키보드 단축키

`⌘/` 또는 `Ctrl+/`를 누르거나 **도움말 → 키보드 단축키**를 열어 단축키 목록을 확인합니다. Windows와
Linux에서는 `⌘` 대신 `Ctrl`을, `⌥` 대신 `Alt`를 사용합니다.

| 단축키 | 동작 |
|---|---|
| `⌘K` | 명령 팔레트를 엽니다. |
| `⌘/` | 키보드 단축키를 표시합니다. |
| `⌘J` | Mole Agent 패널을 열거나 닫습니다. |
| `⌘⌥E` | 시간 선택기를 엽니다. |
| `⌘⌥P` | 시간 앵커를 고정하거나 고정을 해제합니다. |
| `⌘⌥Y` | 조사 링크를 복사합니다. |
| `⌘[` / `⌘]` | 조사 스택에서 뒤로 또는 앞으로 이동합니다. |
| `⌘⌥S` | APM 서비스로 이동합니다. |
| `⌘⌥A` | 알림 인시던트로 이동합니다. |
| `⌘⌥D` | 대시보드로 이동합니다. |
| `⌘⌥T` / `⌘⌥L` | 트레이스 또는 로그 검색으로 조사 스택을 엽니다. |
| `⌘⌥R` | RUM 개요로 이동합니다. |
| `⌘⌥F` | 함수로 이동합니다. |
| `⌘⌥I` | ID 및 액세스로 이동합니다. |
| `⌘Esc` | 맨 위의 오버레이를 닫습니다. |

개인
[환경설정](/ko/account#환경설정)에서 **키보드 단축키 사용**을 끕니다.

## 문제 조사

일반적으로 다음 단계에 따라 문제를 조사합니다.

<Steps>
  <Step title="증상부터 확인">
    인시던트, 대시보드 패널, 느린 트레이스, 프런트엔드 오류 또는 리소스 사용량이 높은 프로파일을 엽니다.
  </Step>
  <Step title="시간 범위와 리소스 좁히기">
    조사에 필요한 최소 시간 범위를 선택하고 서비스, 스트림, 환경 또는 세션으로 필터링합니다.
  </Step>
  <Step title="관련 시그널로 이동">
    상관관계 작업을 사용해 관련 트레이스, 로그, 메트릭, 프로파일 또는 RUM
    세션을 엽니다. [시그널 간 상관관계](/ko/correlation)를 참조합니다.
  </Step>
  <Step title="조사 결과 보존">
    쿼리를 뷰로 저장하거나, 대시보드 패널을 추가하거나, 알림 규칙을 생성하거나, Mole Agent에
    조사를 요청하고 결과를 저장합니다.
  </Step>
</Steps>

## 언어 및 개인 설정

사용자 메뉴의 **언어**에서 인터페이스 언어를 선택합니다. 선택한 언어는 즉시 적용되며
계정에 저장되므로 다른 브라우저에서도 같은 언어로 표시됩니다.

프로필, 테마와 표시 밀도, 시간대와 날짜 형식, 시작 페이지,
개인 알림 및 세션은 **계정 설정**에서 관리합니다.
[계정 설정](/ko/account)을 참조합니다.
