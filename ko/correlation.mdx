신호 간 상관 분석은 느린 페이지에서 백엔드 트레이스로, 트레이스에서 해당 로그로,
메트릭 급증 지점에서 관련 요청으로 이동하며 여러 신호에 걸쳐 하나의 문제를 추적합니다. 이동할 때마다 시간
범위를 유지하고 `trace_id`, 서비스, 호스트 등의 식별자를 전달하므로 수동으로 복사할 필요가
없습니다. 신호 간 이동은 일관된 필드 값에 의존합니다. 수집 과정에서 `service.name`, `deployment.environment`, `trace_id`,
`host.name`을 그대로 유지합니다.

## 신호 간 이동 경로

| 출발점 | 작업 | 이동 대상 |
|---|---|---|
| 로그 이벤트 | 이벤트에 트레이스 ID가 있으면 **트레이스** 보기를 엽니다. | 이벤트의 스팬이 선택된 트레이스 워터폴입니다. [로그](/ko/logs#결과-확인)를 참조합니다. |
| 트레이스 | 트레이스 상단에서 **관련 로그**, **서비스 메트릭**, **프로필**을 선택합니다. | `trace_id`가 일치하는 로그, 해당 서비스의 메트릭, 해당 시간 범위의 프로필입니다. [트레이스](/ko/traces#트레이스-살펴보기)를 참조합니다. |
| 스팬 | 스팬에서 **로그**, **메트릭**, **프로필** 탭을 선택합니다. | 해당 스팬의 로그 행과 수치입니다. |
| 브라우저 세션이 있는 트레이스 | 트레이스 상단에서 **사용자 세션**을 선택합니다. | 요청을 보낸 RUM 세션입니다. |
| RUM 세션 | **관련 트레이스**를 선택합니다. | 해당 세션의 요청에 대한 백엔드 트레이스입니다. [RUM 탐색기](/ko/rum/explorer)를 참조합니다. |
| 메트릭 데이터 포인트 | 다이아몬드 모양의 예시 데이터 포인트를 선택한 다음 **트레이스 열기**를 선택합니다. | 해당 데이터 포인트와 연결된 트레이스입니다. [메트릭](/ko/metrics#차트-읽기)을 참조합니다. |
| APM 서비스 | 서비스 페이지의 링크를 선택합니다. | 해당 서비스의 트레이스, 로그, RUM 세션입니다. [APM](/ko/apm)을 참조합니다. |
| 인시던트 | **트리거 쿼리 열기**, **관련 로그**, **관련 메트릭**, **RUM에서 열기**를 선택합니다. | 인시던트를 트리거한 쿼리와 관련 컨텍스트입니다. [인시던트](/ko/alerting/incidents#인시던트-상세-정보)를 참조합니다. |
| 프로필 | 프로필과 연결된 트레이스를 선택합니다. | 프로필을 수집하는 동안 실행된 트레이스입니다. [프로필](/ko/profiles)을 참조합니다. |

## 조사 컨텍스트 표시줄

조사 중에는 상단 표시줄 아래에 조사 컨텍스트 표시줄이 나타납니다. 이 표시줄은 스택에 있는
프레임 수, 고정된 시간 범위, 트레이스 ID와 같은 주요 신호, 페이지를 이동해도 유지되는
필터를 표시합니다.

| 컨트롤 | 동작 |
|---|---|
| **조사 재개** | 조사 스택으로 돌아갑니다. |
| **트레이스 세부 정보로 돌아가기** | 현재 페이지를 열기 전의 트레이스로 돌아갑니다. |
| 필터 제거 | 페이지를 이동해도 유지되는 필터 하나를 제거합니다. |
| **지우기** | 조사를 종료하고 표시줄을 지웁니다. |

## UI의 조사 스택

조사 스택은 탐색 경로를 기록합니다. 이동할 때마다 프레임을 추가하며, `⌘[` 및 `⌘]`으로
이전 및 다음 프레임으로 이동합니다. 스택에 프레임을 최대 6개까지 보관합니다. 한도를 초과하면 가장 오래된 고정되지 않은 프레임을
제거하며, 고정된 프레임은 유지합니다. `⌘⌥T` 및 `⌘⌥L`을 사용하면 각각 트레이스와 로그 검색에서 스택을 시작합니다.
[명령 팔레트](/ko/console#명령-팔레트로-검색)에서는 결과를 새 스택에서 열거나
현재 스택의 맨 위에 추가합니다.

`⌘⌥Y`를 사용하면 시간 범위와 필터를 포함한 현재 페이지 주소를 복사합니다. 복사한 링크를 열려면
링크에 포함된 모든 리소스에 대한 권한이 필요합니다.

## 상관 분석 API

UI는 이동할 때마다 API를 한 번 호출해 필요한 값을 계산합니다. 스크립트에서도 같은 방식으로 호출합니다.

```http
GET /api/v1/web/correlation/{from_kind}/{to_kind}?ctx=<base64url-json>
Authorization: Bearer <token>
```

출발 신호의 컨텍스트와 대상 신호를 지정하면 엔드포인트가 대상 페이지에 적용할 필터, 시간
범위, 미리 입력할 쿼리를 반환합니다. 서비스 그래프에서 인접 서비스를 한 번 조회하는 것 외에는
텔레메트리를 읽지 않습니다. 지원하는 이동 경로는 [신호 간 상관 분석](/ko/api/web/search)을
참조합니다.

| 엔드포인트 | 용도 |
|---|---|
| `GET /api/v1/web/correlation/{from_kind}/{to_kind}` | 신호 간 이동에 사용할 필터, 시간 범위, 미리 입력할 쿼리를 반환합니다. |
| `GET /api/v1/web/trace/{trace_id}` | 모든 스팬을 포함한 전체 트레이스를 반환합니다. |
| `GET /api/v1/web/topology` | 서비스 토폴로지를 반환합니다. |
| `GET /api/v1/traces/service_graph` | 트레이스에서 집계한 RED 메트릭을 포함하는 서비스 그래프를 반환합니다. |
| `POST /api/v1/web/investigation/blob` | 조사 상태를 7일 후 만료되는 Blob으로 저장합니다. |
