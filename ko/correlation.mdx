교차 신호 상관관계는 하나의 문제를 여러 신호에 걸쳐 추적합니다. 느린 페이지에서 백엔드 트레이스로,
트레이스에서 로그로, 메트릭 급증에서 그 뒤의 요청으로 이어집니다. 각 이동은 시간 범위를
유지하고 `trace_id`, 서비스, 호스트 같은 식별자를 함께 가져가므로 아무것도 직접 복사할
필요가 없습니다. 이동은 안정적인 필드에 의존합니다. 수집하는 동안 `service.name`, `deployment.environment`, `trace_id`,
`host.name`을 그대로 유지하세요.

## 신호 간 이동 지점

| 시작 지점 | 동작 | 이동 대상 |
|---|---|---|
| 로그 이벤트 | 트레이스 ID가 있으면 해당 이벤트의 **트레이스** 보기입니다. | 이벤트의 스팬이 선택된 상태의 트레이스 워터폴입니다. [로그](/ko/logs#결과-읽기)를 참고하세요. |
| 트레이스 | 트레이스 상단의 **관련 로그**, **서비스 메트릭**, **프로필**입니다. | `trace_id`가 있는 로그, 서비스의 메트릭, 해당 시간 범위의 프로필입니다. [트레이스](/ko/traces#트레이스-살펴보기)를 참고하세요. |
| 스팬 | 스팬의 **로그**, **메트릭**, **프로필** 탭입니다. | 해당 스팬의 로그 라인과 수치입니다. |
| 브라우저 세션이 있는 트레이스 | 트레이스 상단의 **사용자 세션**입니다. | 요청을 보낸 RUM 세션입니다. |
| RUM 세션 | **관련 트레이스**입니다. | 해당 세션 요청의 백엔드 트레이스입니다. [RUM 탐색기](/ko/rum/explorer)를 참고하세요. |
| 메트릭 포인트 | 엑셈플러 다이아몬드를 선택한 다음 **트레이스 열기**를 선택합니다. | 해당 포인트 뒤에 있는 트레이스입니다. [메트릭](/ko/metrics#차트-읽기)을 참고하세요. |
| APM 서비스 | 서비스 페이지의 링크입니다. | 해당 서비스의 트레이스, 로그, RUM 세션입니다. [APM](/ko/apm)을 참고하세요. |
| 인시던트 | **트리거 쿼리 열기**, **관련 로그**, **관련 메트릭**, **RUM에서 열기**입니다. | 알림을 발생시킨 쿼리와 인시던트 주변의 컨텍스트입니다. [인시던트](/ko/alerting/incidents#인시던트-상세-정보)를 참고하세요. |
| 프로필 | 프로필의 상관 트레이스입니다. | 프로필이 수집되는 동안 실행된 트레이스입니다. [프로필](/ko/profiles)을 참고하세요. |
| APM 인스턴스 | **인스턴스** 표의 **워크로드 / 호스트** 셀입니다. | 해당 인스턴스가 실행되는 파드 또는 호스트와 그곳의 다른 서비스입니다. [인프라](/ko/infrastructure)를 참고하세요. |
| 파드, 노드 또는 호스트 | **로그**, **메트릭**, 그리고 그 위에서 실행되는 서비스입니다. | 지난 1시간 동안의 로그와 메트릭, 그리고 각 서비스의 APM 페이지입니다. |

## 이동해도 아무것도 찾지 못할 때

아무것도 찾지 못하는 이동은 데이터가 없다는 뜻이 아니라 데이터를 연결할 수 없다는 뜻일 수 있습니다. 트레이스 ID가 없는 로그,
로그에서 다르게 명명된 서비스, 또는 서비스가 어디에서 실행되는지 알려주지 않는 스팬이 그렇습니다.
[APM 카탈로그](/ko/apm)와 [수집 품질](/ko/apm/settings#수집-품질)의 **상관관계** 열은
각 서비스가 로그, 메트릭, 트레이스, 변경 사항과 얼마나 잘 연결되는지 보여줍니다.

## 조사 컨텍스트 표시줄

조사가 진행되는 동안 상단 표시줄 아래의 표시줄에 조사 내용이 나타납니다. 스택의 프레임 수,
잠긴 시간 범위, 트레이스 ID 같은 주요 신호, 페이지를 이동해도 함께 따라가는 필터입니다.

| 컨트롤 | 효과 |
|---|---|
| **조사 재개** | 조사 스택으로 돌아갑니다. |
| **트레이스 세부 정보로 돌아가기** | 해당 페이지를 연 트레이스로 돌아갑니다. |
| 필터 제거 | 함께 따라가는 필터 하나를 제거합니다. |
| **지우기** | 조사를 종료하고 표시줄을 지웁니다. |

## UI의 조사 스택

조사 스택은 드릴다운의 이동 경로를 유지합니다. 각 이동은 프레임을 하나 추가하고, `⌘[`와 `⌘]`로
앞뒤로 이동할 수 있습니다. 스택은 최대 6개의 프레임을 보관하며, 그 이상이 되면 고정되지 않은 가장 오래된 프레임이
삭제되고 고정된 프레임은 유지됩니다. `⌘⌥T`와 `⌘⌥L`은 트레이스나 로그 검색에서 스택을 시작하며,
[명령 팔레트](/ko/console#명령-팔레트로-검색)는 결과를 새 스택에서 열거나 현재 스택
위에 엽니다.

`⌘⌥Y`는 현재 페이지의 주소를 시간 범위와 필터와 함께 복사합니다. 복사한 링크를 열려면 여전히 그 안의 모든 리소스에 대한 권한이 필요합니다.

## 상관관계 API

각 페이지는 이미 보유한 식별자로 각 이동을 구성하며, 다음 엔드포인트가 그 뒤의 뷰를 제공합니다.

| 엔드포인트 | 용도 |
|---|---|
| `GET /api/v1/web/trace/{trace_id}` | 모든 스팬이 포함된 전체 트레이스입니다. |
| `GET /api/v1/web/topology` | 서비스 토폴로지입니다. |
| `GET /api/v1/traces/service_graph` | 트레이스에서 산출한 RED 메트릭이 포함된 서비스 그래프입니다. |
| `GET /api/v1/entities/detail` | 파드, 노드, 호스트, 컨테이너에서 실행 중인 대상과 그것이 실행되는 위치입니다. [인프라](/ko/infrastructure)를 참고하세요. |
| `POST /api/v1/web/investigation/blob` | 조사 상태를 7일 후 만료되는 블롭으로 저장합니다. |
