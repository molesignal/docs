## 변경 사항 실행 방식

인시던트를 확인하는 등 상태를 변경하는 명령은 Mole Agent 및 에이전트 도구와 마찬가지로
관리형 도구를 통해 MoleSignal에 변경을 요청합니다. 조직의 도구 정책은 각
도구의 실행 방식을 지정합니다. **Mole Agent → 설정 → 도구 및 기능**에서 설정합니다.

| 실행 모드 | 명령 동작 |
|---|---|
| 자동 | 변경 사항을 즉시 적용합니다. |
| 확인 | MoleSignal이 확인을 요청하면 명령이 터미널에서 확인 메시지를 표시합니다. CI에서처럼 `-y` (`--yes`)로 미리 예라고 응답할 수 있습니다. 터미널이 없고 `--yes`도 지정하지 않으면 아무것도 변경하지 않습니다. |
| 단일 승인, 이중 승인 | MoleSignal은 검토자가 **Mole Agent → 승인**에서 검토할 수 있도록 승인 요청을 생성합니다. 명령은 승인 요청을 출력하고 종료 코드 `3`으로 종료합니다. `--wait`를 지정하면 `--timeout`(기본값 30분)까지 결정을 기다린 후 승인된 변경 사항을 적용합니다. |
| 비활성화 | 명령이 실패하고 이유를 표시합니다. |

별도 정책이 없는 도구는 위험도에 따라 실행합니다. 기본 모드는
`create_annotation` 및 `submit_search_job`의 경우 확인, `acknowledge_incident`,
`resolve_incident` 및 `run_synthetic_monitor`의 경우 단일 승인입니다. `--reason`으로 지정한 사유는 검토자에게 표시하고
감사 로그에 기록합니다.

확인에는 MCP 프로토콜 리비전 2026-07-28이 필요합니다. MoleSignal이 이 리비전을 사용하면 CLI도 같은 리비전을 사용합니다.
`molesignal status`는 사용 중인 리비전을 표시합니다.

## 인시던트 목록 조회

```bash
molesignal incidents
```

목록에는 활성 인시던트를 최신순으로 표시하며, 각 인시던트의 상태, 심각도, 경과 시간, 서비스,
요약을 포함합니다. `--status resolved` 또는 `--status all`로 해결된 인시던트 또는 모든 인시던트를 조회합니다. `--since 7d`는 지난 7일 동안 열린
인시던트만 표시하며, `-n`은 표시할 개수를 지정합니다.

`molesignal incidents show`는 인시던트 하나의 규칙, 시간 정보, 서비스, 레이블, 런북 등의
참고 정보, 샘플링된 트레이스를 출력합니다. `--rca`는 근본 원인 분석을 추가하고, `--web`은
MoleSignal에서 인시던트를 엽니다.

```bash
molesignal incidents show <incident> --rca
```

## 인시던트 확인 및 해결

```bash
molesignal incidents ack <incident>
```

```bash
molesignal incidents resolve <incident> --reason "Rolled back to 2.3.9"
```

두 작업 모두 도구 정책을 따르며 `alerts.incidents.acknowledge` 권한이 필요합니다.

## 온콜 담당자 확인

```bash
molesignal oncall
```

목록에는 활성화된 온콜 일정별 담당자가 표시됩니다. `--schedule`로 특정 일정만 표시하고,
`--at "2026-10-27 09:00"`과 같이 `--at`으로 다른 시점의 담당자를 조회합니다.

## 승인된 변경 사항 적용

`molesignal approvals`는 Mole Agent, 에이전트 도구 및 명령에서 생성한 승인 요청 중 검토 대기 중인 요청과 승인됐지만
아직 실행하지 않은 요청을 표시합니다. `--all`을 지정하면 승인 여부가 결정된 요청도
표시합니다.

```bash
molesignal approvals
```

`molesignal approvals show <approval>`은 요청 하나의 작업, 대상, 사유, 영향,
검토 내역을 출력합니다. `molesignal approvals execute <approval>`은 승인된 변경 사항을 적용합니다. MoleSignal은
적용 전에 확인을 요청할 수 있습니다.

```bash
molesignal approvals execute <approval>
```

## 대시보드에 주석 추가

`molesignal annotate`는 특정 시점이나 기간에 대한 주석을 모든 대시보드 또는
특정 대시보드에 추가합니다.

```bash
molesignal annotate "Release 2.4.0" --tags release,checkout --yes
```

| 옵션 | 의미 |
|---|---|
| `--description <text>` | 주석의 상세 설명입니다. |
| `--tags <a,b>` | 주석을 찾는 데 사용할 태그입니다. |
| `--dashboard <id>` | 지정한 대시보드에만 주석을 추가합니다. |
| `--stream <stream>` | 주석과 관련된 스트림입니다. |
| `--time <time>`, `--end <time>` | 시작 시각과 종료 시각입니다. 기본값은 현재 시점입니다. |

주석을 추가하려면 `dashboards.edit` 권한이 필요합니다.

## 신세틱 검사 실행

`molesignal synthetics`는 검사 목록과 각 검사의 유형, 상태, 수명 주기를 표시합니다.
`molesignal synthetics results <check>`는 위치별 최신 실행 내역과 각 실행의
결과, 소요 시간, 실패 사유를 표시합니다. ID 또는 이름으로 검사를 지정합니다.

`molesignal synthetics run`은 설정된 각 위치에서 검사를 즉시 실행합니다. `--wait`를 지정하면 명령은
실행이 끝날 때까지 기다립니다. 하나라도 실패하거나 `--timeout`(기본값
10분) 내에 완료되지 않으면 종료 코드 `1`로 종료하므로 파이프라인에서 릴리스를 중단할 수 있습니다.

```bash
molesignal synthetics run "Checkout API" --wait --yes
```

결과가 정상 또는 간헐적 실패이면 실행을 통과로 처리합니다. 검사를 실행하려면 `synthetics.monitors.manage` 권한이 필요합니다.
CI에서 검토자 없이 검사를 실행하려면 도구 정책에서 `run_synthetic_monitor`를 **자동**으로
설정합니다.
