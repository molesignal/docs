## 메트릭 쿼리

`molesignal metrics query`는 PromQL 범위 쿼리를 실행하고 시계열마다 한 줄을 출력합니다. 각 줄에는 조회 기간의 마지막 값,
최솟값, 최댓값, 스파크라인, 라벨이 표시됩니다.

```bash
molesignal metrics query 'sum by (service) (rate(http_server_requests_total[5m]))' --since 6h
```

```text
LAST   MIN    MAX    TREND                           SERIES
12.4   3.1    14.9   ▁▂▂▃▅▆▇█▇▆▆▅▅▆▇▇█▇▆▅▄▄▅▅▆▆▇▇▇▆   {service="checkout"}
```

기본 조회 기간은 최근 1시간입니다. `--since`, `--from`, `--to`로 기간을 변경합니다. `-n`은
데이터 포인트 수를 제한하며 기본값은 `1000`입니다. `--json`은 각 시계열과 해당 데이터 포인트를 출력하고, `--csv`는
데이터 포인트를 행 단위로 출력합니다.

다음 네 가지 하위 명령으로 쿼리 대상을 찾습니다.

| 명령 | 목록에 표시되는 항목 |
|---|---|
| `molesignal metrics names [text]` | 지정한 텍스트를 포함하는 메트릭 이름입니다. |
| `molesignal metrics labels <metric>` | 메트릭의 라벨입니다. |
| `molesignal metrics values <metric> <label>` | 라벨 값과 각 값의 등장 횟수입니다. |
| `molesignal metrics series <metric>` | 메트릭의 시계열입니다. `--match label=value`로 범위를 좁힙니다. |

## 트레이스 찾기

```bash
molesignal traces --service checkout --errors --since 6h
```

목록에는 최신 트레이스의 시작 시각, 소요 시간, 스팬 수, 서비스가 표시됩니다.

| 옵션 | 설명 |
|---|---|
| `--service <name>` | 지정한 서비스의 트레이스만 표시합니다. |
| `--errors` | 실패한 스팬이 포함된 트레이스만 표시합니다. |
| `--min-duration <time>` | 소요 시간이 `500ms`와 같이 지정한 값 이상인 트레이스만 표시합니다. |
| `--since`, `--from`, `--to` | 조회 기간을 지정합니다. 기본값은 최근 1시간입니다. |
| `-n`, `--limit <count>` | 표시할 트레이스 수를 지정합니다. 기본값은 `20`이며 최댓값은 `200`입니다. |

## 트레이스를 워터폴 차트로 표시하기

`molesignal traces show`는 트레이스 하나를 워터폴 차트로 표시합니다. 각 스팬을 상위 스팬 아래에 한 줄씩 표시하고,
막대로 트레이스 내 실행 시점과 소요 시간을 나타냅니다. 실패한 스팬은
`!`로 표시하며, 터미널에서는 빨간색으로 표시합니다.

```bash
molesignal traces show 4bf92f3577b34da6a3ce929d0e0e4736
```

```text
checkout POST /orders          ████████████████████████████████████████  1.24s
├─ checkout SELECT orders       ███                                       98ms
└─ ! payments POST /charge         ███████████████████████████████████    1.1s
```

`--web`은 MoleSignal에서 트레이스를 열고, `--json`은 트레이스의 스팬을 출력합니다.

## 서비스 요약 보기

```bash
molesignal services --env production --sort errors
```

목록에는 각 APM 서비스의 요청 수, 오류율, p95 지연 시간, 상태, 현재
버전이 표시됩니다. `--sort`는 `requests`, `errors`, `p95`, `name` 중 하나를 기준으로 목록을 정렬합니다.

`molesignal services show`는 서비스 하나를 요약합니다. 요청률, 오류, 지연 시간을 먼저 표시한 뒤
엔드포인트, 종속성, 오류, 버전을 표시합니다.

```bash
molesignal services show checkout --since 2h
```

## 두 버전 비교하기

`molesignal services compare`는 서비스의 두 버전을 나란히 비교해
후보 버전의 성능이 저하되었는지, 개선되었는지, 그대로인지 또는 요청 수가 너무 적어 판단할 수 없는지 표시합니다.
`--fail-on-regression`을 사용하면 성능이 저하될 때 명령이 종료 코드 `1`을 반환하므로 파이프라인에서
릴리스를 중단할 수 있습니다.

```bash
molesignal services compare checkout 2.3.9 2.4.0 --since 1h --fail-on-regression
```

## 오래 걸리는 쿼리를 검색 작업으로 실행하기

검색 작업은 즉시 실행하는 쿼리보다 더 많은 데이터와 더 긴 기간을 대상으로 백그라운드에서 쿼리를 실행하고,
결과를 일정 기간 보관합니다. 다른 변경 작업과 마찬가지로 검색 작업을 제출하거나 취소할 때도
조직의 도구 정책을 적용합니다. 자세한 내용은
[인시던트 및 변경](/ko/cli/changes#변경-사항-실행-방식)을 참조합니다.

```bash
molesignal search-jobs submit "SELECT * FROM app_logs WHERE level = 'error'" --since 30d --wait
```

기본 스트림은 `FROM` 뒤에 처음 나오는 스트림입니다. `--stream`으로 다른 스트림을 지정하고, `--promql`로
PromQL 문을 제출합니다. 조회 기간의 끝에서 평가하거나 `1m`과 같이 `--step`으로 지정한 간격마다 평가합니다. `--limit`는
작업이 보관할 행 수를 제한하며 최댓값은 `100000`입니다. `--keep`은 보관 기간을 지정합니다. `--wait`는
작업이 완료될 때까지 기다립니다. 명령은 작업 ID를 출력합니다.

| 명령 | 동작 |
|---|---|
| `molesignal search-jobs` | 검색 작업 목록에 각 작업의 상태, 행 수, 쿼리 문을 표시합니다. |
| `molesignal search-jobs show <job>` | 작업의 상태, 행 수, 시간 정보, 오류를 출력합니다. |
| `molesignal search-jobs results <job>` | 완료된 작업의 결과 행을 한 줄에 JSON 객체 하나씩 출력합니다. `--csv`는 CSV 형식으로 출력하고, `-o <file>`은 파일로 저장합니다. |
| `molesignal search-jobs cancel <job>` | 대기 중이거나 실행 중인 작업을 취소합니다. |

## 액세스 권한

메트릭에는 `streams.query`, 트레이스에는 `traces.read`, APM에는 `apm.services.read`, 검색 작업에는 `query.jobs.read`와
`query.jobs.run` 권한이 필요합니다. `sys.telemetry.read` 권한으로 `_sys` 범위에서 각 항목을 읽을 수 있습니다. 조직의 도구 정책에서
해당 도구를 활성화해야 합니다.
