MoleSignal CLI는 npm에 `@molesignal/cli`로 배포되는 `molesignal` 명령어입니다.
MoleSignal 인스턴스에 로그인한 후 다음 작업을 수행합니다.

- 로그를 읽고 실시간으로 추적하며, SQL과 PromQL 쿼리를 실행하고, 트레이스를 워터폴로 표시하며, APM
  서비스를 요약합니다.
- 인시던트와 온콜 담당자를 나열하고, 인시던트를 확인 및 해결하며, 신세틱 검사를 실행하고,
  승인된 변경을 적용합니다.
- CI에서 배포를 보고하고, RUM 소스 맵과 심볼을 업로드하며, 스크립트 출력을
  스트림으로 전송합니다.
- MoleSignal 카탈로그의 모든 도구를 호출할 수 있습니다.
- stdio를 통해 MoleSignal의 MCP 도구를 제공하므로 Claude Code, Cursor, Codex, VS Code,
  Gemini CLI에서 MoleSignal CLI를 MCP 서버로 시작할 수 있습니다.

조회와 변경은 MoleSignal 도구를 통해 이루어집니다. 따라서 로그인한 사용자의 권한과
조직의 도구 정책 및 승인 내역은 Mole Agent와 마찬가지로 CLI에도 적용됩니다.
배포 보고, 디버그 아티팩트 업로드, 로그 전송에는 MoleSignal API를 사용하며
API 토큰이 필요합니다.

## 요구 사항

- Node.js 20 이상.
- CLI를 실행하는 머신에서 접속할 수 있는 MoleSignal 인스턴스와 해당 인스턴스의 계정.

## 설치

```bash
npm install -g @molesignal/cli
```

설치가 완료되었는지 확인합니다.

```bash
molesignal --version
```

설치하지 않고도 각 명령어를 실행할 수 있습니다.

```bash
npx -y @molesignal/cli --help
```

## 시작하기

<Steps>
  <Step title="로그인">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    브라우저에서 MoleSignal 승인 페이지가 열립니다. **승인**을 클릭합니다.
    [로그인](/ko/cli/sign-in)을 참고합니다.
  </Step>
  <Step title="설정 확인">
    ```bash
    molesignal doctor
    ```
  </Step>
  <Step title="로그 읽기">
    ```bash
    molesignal logs app_logs -f
    ```

    [로그 읽기 및 실시간 추적](/ko/cli/logs)을 참고합니다.
  </Step>
</Steps>

## 명령어

| 그룹 | 명령어 |
|---|---|
| 로그인 | `login`, `logout`, `profiles`, `use`, `status`, `whoami`, `doctor`. [로그인](/ko/cli/sign-in)을 참고합니다. |
| 로그 및 쿼리 | `streams`, `logs`, `query`, `fields`. [로그 읽기 및 실시간 추적](/ko/cli/logs)을 참고합니다. |
| 메트릭, 트레이스 및 서비스 | `metrics`, `traces`, `services`, `search-jobs`. [메트릭, 트레이스 및 서비스](/ko/cli/observe)를 참고합니다. |
| 온콜 및 변경 | `incidents`, `oncall`, `approvals`, `annotate`, `synthetics`. [인시던트 및 변경](/ko/cli/changes)을 참고합니다. |
| 릴리스 및 데이터 | `deploy`, `source-maps`, `symbols`, `send`, `run`. [CI 및 릴리스](/ko/cli/ci)를 참고합니다. |
| 도구 및 설정 | `tools`, `call`, `mcp`, `open`, `completion`. [도구 호출](/ko/cli/tools) 및 [stdio를 통한 MCP 제공](/ko/cli/mcp)을 참고합니다. |

`molesignal <command> --help`를 실행하면 명령어와 옵션 설명을 확인할 수 있습니다.
[명령어 레퍼런스](/ko/cli/reference)에도 모든 옵션이 나와 있습니다.
