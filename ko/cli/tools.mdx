CLI 명령은 일반적인 작업을 처리합니다. MoleSignal 카탈로그의 다른 모든 도구는
RUM, 프로파일링, 상태 페이지 도구를 포함해 `molesignal call`로 실행합니다.

## 도구 찾기

```bash
molesignal tools incident
```

목록에는 검색어와 가장 잘 맞는 도구와 함께 호출 유형(`read` 또는
`change`), 조직의 도구 정책에 따른 변경 처리 방식, 도구의 용도가 표시됩니다.
검색어를 입력하지 않으면 호출할 권한이 있는 모든 도구가 표시됩니다. `--domain`으로
`observability` 또는 `alerts_on_call`처럼 특정 도메인만 표시할 수 있습니다.

`molesignal tools show`는 도구 하나와 해당 도구가 받는 인수를 JSON Schema 형식으로 출력합니다.

```bash
molesignal tools show list_rum_sessions
```

## 도구 호출하기

```bash
molesignal call list_rum_sessions --since 1h limit=20
```

명령은 도구의 반환값을 JSON으로 출력합니다. 인수는 다음과 같이 작성합니다.

| 입력 형식 | 전달되는 값 |
|---|---|
| `name=value` | 도구의 스키마가 요구하는 타입의 값입니다. 텍스트, 숫자, `true` 또는 `false`, `a,b`로 만든 목록을 전달할 수 있습니다. |
| `name:=json` | 입력한 JSON을 그대로 전달합니다. 예: `match:='{"service":"checkout"}'`. |
| `parent.child=value` | 객체 내부의 필드입니다. 예: `timeRange.startTime=…`. |
| `--input <file>` | 파일에서 읽은 인수의 JSON 객체입니다. 표준 입력에서 읽으려면 `-`를 사용합니다. 뒤에 지정한 키-값 쌍은 객체에 추가됩니다. |
| `--since`, `--from`, `--to` | `timeRange`를 받는 도구의 해당 값을 설정합니다. |

변경을 수행하는 도구에는 도구 정책을 적용합니다. 자세한 내용은
[변경 처리 방식](/ko/cli/changes#변경-사항-실행-방식)을 참조합니다. `--reason`, `--wait`, `--timeout`,
`--yes`를 적용할 수 있습니다. `reason` 또는 `impact` 인수는 승인 요청에 그대로 전달됩니다.

```bash
molesignal call trigger_alert_rule rule_id=<rule> --reason "Testing the pager"
```

## 페이지 열기

`molesignal open`은 브라우저에서 MoleSignal 페이지를 엽니다. 페이지를 지정하지 않으면 홈 페이지를 엽니다.

```bash
molesignal open logs app_logs
```

페이지에는 `home`, `logs`, `metrics`, `traces`, `services`, `incidents`, `oncall`,
`synthetics`, `dashboards`, `approvals`, `jobs`, `streams`, `agent`가 있습니다. 대부분의 페이지는
트레이스, 인시던트, 대시보드 등의 ID를 받습니다. `--print`를 사용하면 페이지를 여는 대신 주소를 출력합니다.

`logs`, `query`, `traces show`, `incidents show`, `services show`에 `--web`을 지정하면 출력할 내용을
브라우저에서 엽니다.

## 셸에서 명령 자동 완성하기

`molesignal completion`은 명령, 하위 명령, 프로필, 스트림 이름을 자동 완성하는 스크립트를
출력합니다. 스트림 이름은 몇 분에 한 번씩 가져옵니다. bash의 경우:

```bash
echo 'source <(molesignal completion bash)' >> ~/.bashrc
```

zsh의 경우:

```bash
echo 'source <(molesignal completion zsh)' >> ~/.zshrc
```

fish의 경우:

```bash
molesignal completion fish > ~/.config/fish/completions/molesignal.fish
```
