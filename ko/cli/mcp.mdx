`molesignal mcp`는 stdio를 통해 MoleSignal의 MCP 도구를 제공합니다. 에이전트 도구가 명령을
직접 실행하고 표준 입력과 표준 출력으로 통신합니다. CLI는 모든 메시지를
MoleSignal의 **인바운드 MCP** 엔드포인트로 전달하고 모든 응답을 에이전트 도구로 돌려보냅니다. 도구, 권한,
승인은 모두 MoleSignal에서 관리하며 CLI는 별도로 추가하지 않습니다.

## 에이전트 도구에 서버 추가

먼저 [로그인](/ko/cli/sign-in)한 다음, CLI가 에이전트 도구에 서버를 추가하도록 다음 명령을 실행합니다.

```bash
molesignal mcp setup claude
```

| 에이전트 도구 | `molesignal mcp setup`이 변경하는 항목 |
|---|---|
| `claude` | Claude Code에 대해 `claude mcp add`를 실행합니다. `--scope`는 `user`(기본값), `project`, `local` 중 하나입니다. |
| `cursor` | `~/.cursor/mcp.json`을 변경합니다. `--scope project`를 지정하면 현재 폴더의 `.cursor/mcp.json`을 변경합니다. |
| `codex` | `~/.codex/config.toml`을 변경합니다. `CODEX_HOME`이 설정되어 있으면 해당 디렉터리의 `config.toml`을 변경합니다. |
| `vscode` | 현재 폴더의 `.vscode/mcp.json`을 변경합니다. |
| `gemini` | `~/.gemini/settings.json`을 변경합니다. `--scope project`를 지정하면 현재 폴더의 `.gemini/settings.json`을 변경합니다. |

이 명령은 `molesignal`이라는 서버를 추가하거나 같은 이름의 서버를 교체하며, 파일의 다른
설정은 모두 유지합니다. 서버는 `npx -y @molesignal/cli mcp`를 실행합니다. `--installed`를 지정하면 대신
설치된 `molesignal`을 실행합니다. `--profile`을 지정하면 서버 설정에 프로필을 기록하므로 에이전트 도구는
현재 프로필과 관계없이 지정한 프로필의 로그인 정보를 사용합니다. `--print`를 지정하면 구성을 파일에 기록하는 대신
출력합니다.

[stdio로 연결](/ko/inbound-mcp#stdio로-연결)에는 각 에이전트 도구의 동일한 구성이
나와 있습니다. **Mole Agent → 설정 → 인바운드 MCP**의 설정 프롬프트는
해당 인스턴스에 맞는 설정 절차를 생성합니다.

빌드 머신처럼 로그인하지 않는 환경에서는 서버의 자격 증명을
환경 변수로 전달합니다.

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"],
      "env": {
        "MOLESIGNAL_URL": "https://molesignal.example.com",
        "MOLESIGNAL_TOKEN": "<token>"
      }
    }
  }
}
```

## 메시지 전달 방식

- 에이전트 도구가 `notifications/initialized`를 보낼 때까지 CLI는 메시지를 한 번에 하나씩
  순서대로 전달합니다. MoleSignal은 `initialize`에 응답하면서 세션을 엽니다. 그 후에는 메시지를
  도착하는 즉시 전달하므로 느린 도구 호출이 다른 호출을 지연시키지 않습니다.
- 재시작 등으로 MoleSignal에 세션 정보가 없으면 CLI는 에이전트 도구가 처음 보낸
  `initialize`로 새 세션을 열고 메시지를 다시 보냅니다. 에이전트 도구는 재시작 없이
  계속 작동합니다.
- 요청이 MoleSignal에 도달하지 못하면 CLI는 오류를 반환해 에이전트 도구가 계속
  대기하지 않도록 합니다.
- 에이전트 도구가 표준 입력을 닫으면 CLI는 MoleSignal의 세션을 종료하고 실행을 마칩니다.
- CLI는 연결 끊김과 같은 안내 메시지를 표준 오류로 출력합니다.
  표준 출력으로는 MCP 메시지만 전달합니다.
- 다른 모든 명령과 마찬가지로 `HTTPS_PROXY`와 `NO_PROXY`를 적용합니다.

## 연결 확인

```bash
molesignal status
```

도구 수는 에이전트 도구에서 확인할 수 있는 도구 수와 일치합니다. 도구 수가 0이면 대개
조직의 도구 정책이나 사용자 권한으로 인해 사용할 수 있는 도구가 없다는 뜻입니다.
