## 스트림 목록 조회

```bash
molesignal streams
```

목록에는 읽기 권한이 있는 각 로그 스트림의 필드 수, 보존 기간,
설명이 표시됩니다. `--type`은 다른 유형의 스트림을 나열합니다. 유형은 `metrics`, `traces`, `profiles`,
`extend`입니다. `--names`는 이름만 출력하고, `--json`은 스트림 하나를 JSON 한 줄로 출력합니다.

## 최신 로그 출력

```bash
molesignal logs app_logs
```

명령은 최근 15분 동안의 최신 로그 100개를 오래된 순서대로 한 줄에 하나씩 출력합니다.
각 줄에는 시간, 레벨, 서비스, 메시지가 표시됩니다.

```text
2026-10-18 03:14:15.361 INFO  checkout order 4812 created
2026-10-18 03:14:25.361 ERROR payment gateway timeout after 3 retries
```

레벨은 `level`, `severity`, `severity_text` 같은 필드에서 읽고, 서비스는
`service` 또는 `service.name`에서, 메시지는 `message`, `msg`, `body`, `log`에서 읽습니다.
메시지 필드가 없는 로그는 나머지 필드를 `name=value` 형식으로 표시합니다. 터미널에서는 색상을 표시합니다.
`NO_COLOR`는 색상을 끄고, `FORCE_COLOR`는 파이프를 사용할 때도 색상을 유지합니다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-n`, `--lines <count>` | `100` | 처음에 출력할 최신 로그 수입니다. 최대 `5000`개입니다. |
| `--since <duration>` | `15m` | 현재부터 얼마나 이전까지 조회할지 지정합니다. 예: `30s`, `10m`, `2h`, `1d`, `1w`. |
| `--from <time>`, `--to <time>` | 없음 | `--since` 대신 시간 범위를 지정합니다. ISO 형식의 시간, `2026-10-26 14:00`과 같은 로컬 시간 또는 `2h`와 같이 현재부터 거슬러 올라가는 기간을 사용합니다. |
| `-q`, `--query <query>` | 없음 | **로그** 페이지와 같은 형식의 필드 쿼리를 지정합니다. |
| `--where <condition>` | 없음 | 스트림의 필드에 적용할 SQL 조건을 지정합니다. |
| `--fields <a,b,c>` | 전체 | 시간과 지정한 필드만 출력합니다. 필드는 `name=value` 형식으로 표시합니다. |
| `--json` | 꺼짐 | 로그 하나를 JSON 한 줄로 출력합니다. |
| `--utc` | 꺼짐 | 로컬 시간 대신 UTC로 시간을 출력합니다. |
| `--web` | 꺼짐 | 로그를 출력하는 대신 **로그** 페이지에서 같은 로그를 엽니다. |

## 로그 필터링

`-q`는 **로그** 페이지와 같은 구문의 필드 쿼리를 받습니다.
`level = 'error'`, `contains`, `MATCH`, `MATCH_TEXT` 등의 비교 조건을 `AND`와 `OR`로 연결하고
괄호로 묶습니다. 필드를 지정하지 않은 텍스트는 `message`에서 검색합니다.

```bash
molesignal logs app_logs --since 1h -q "level = 'error' AND (service = 'payment' OR timeout)"
```

`--where`는 쿼리의 `WHERE` 절과 같이 스트림의 필드에 적용할 SQL 조건을 받습니다.

```bash
molesignal logs app_logs --where "status >= 500 AND duration_ms > 2000"
```

두 옵션을 모두 지정하면 두 조건을 모두 충족하는 로그만 출력합니다.
조건에 없는 필드를 지정하거나 SQL 구문이 올바르지 않으면 명령은 이유를 표시하고 종료합니다.

## 새 로그 실시간 조회

```bash
molesignal logs app_logs -f
```

최신 로그를 출력한 뒤에는 **Ctrl+C**를 누를 때까지 새로 도착하는 로그를 계속 출력합니다.

- 2초마다 다시 조회합니다. `--interval`로 이 간격을 변경합니다.
- 매번 이전 조회의 종료 시각보다 10초 앞선 시각부터 조회합니다. 따라서
  MoleSignal에 몇 초 늦게 도착한 로그도 표시합니다. 각 로그는 한 번만 표시합니다.
- 한 번에 조회할 수 있는 양보다 많은 로그가 몰리면 기다리지 않고 나머지를 바로 조회합니다.
- 연결이 끊기면 대기 시간을 최대 30초까지 점차 늘리며 재연결을 시도합니다. CLI는 연결이 끊기거나
  복구되면 표준 오류로 알립니다.

실시간 조회는 로그 자체의 타임스탬프를 기준으로 진행합니다. 현재 조회의 시작 시각보다
오래된 타임스탬프가 있는 로그는 도착해도 표시하지 않습니다. `--to`는 `-f`와 함께 사용할 수 없습니다.

## 특정 시점 전후의 로그 조회

`--around`는 지정한 시점 직전과 직후의 로그를 출력하며, 두 로그 그룹 사이에
기준 시점을 한 줄로 표시합니다. `-B`와 `-A`로 각 그룹의 로그 수를 지정합니다. 기본값은 각각 10개이며, 최대 250개입니다.
`-q`와 `--where`로 로그를 필터링합니다.

```bash
molesignal logs app_logs --around "2026-10-26 14:03:12.345" -B 20 -A 20
```

`molesignal logs` 출력에서 복사한 타임스탬프를 `--around`에 사용할 수 있습니다.

## 스트림에서 SQL 실행

`molesignal query`는 표현식, 조인, 집계를 지원하는 읽기 전용 SQL 문 하나를 실행하고
결과를 표로 출력합니다.

```bash
molesignal query "SELECT level, COUNT(*) AS logs FROM app_logs GROUP BY level ORDER BY logs DESC"
```

기본적으로 `FROM` 뒤에 처음 나오는 스트림을 사용합니다. `--stream`으로 다른 스트림을 지정합니다. 기본 조회 범위는
최근 1시간이며, `--since`, `--from`, `--to`로 변경합니다. `-n`은 최대 행 수를 지정합니다. 기본값은 `1000`이고
최댓값은 `5000`입니다. `--csv`는 헤더가 있는 CSV를 출력하고, `--json`은 행 하나를 JSON 한 줄로 출력합니다.
`--web`은 **로그** 페이지에서 SQL 문을 엽니다.

## 스트림 필드 확인

```bash
molesignal fields app_logs
```

목록에는 각 필드의 유형과 인덱스가 표시됩니다. 필드를 지정하면 명령은 최근 1시간 동안
가장 자주 나타난 값과 각 값의 발생 횟수를 나열합니다.

```bash
molesignal fields app_logs service --since 1d
```

`--match`는 지정한 텍스트가 포함된 값만 표시하고, `-n`은 표시할 값의 수를 지정합니다. 기본값은 `20`입니다.
`--type`은 다른 유형의 스트림을 조회합니다.

## 파이프에서 출력 사용

`--json`은 각 로그의 모든 필드를 출력합니다.

```bash
molesignal logs app_logs -n 1000 --since 2h --json | jq -r .message
```

`head`처럼 출력을 받는 명령이 먼저 읽기를 중단하면 로그 명령은 별도 메시지 없이 종료합니다.

## 액세스 권한

CLI는 MoleSignal 도구 `list_streams`, `query_logs`, `get_stream_schema`,
`search_field_values`, `search_around`로 데이터를 조회합니다. 이때 로그인한 사용자 또는
API 토큰 소유자의 권한을 사용합니다. `streams.query` 권한이 필요하며, 조직의 도구 정책에서
이 도구를 비활성화하면 사용할 수 없습니다.
