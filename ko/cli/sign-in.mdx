CLI는 한 번 로그인하면 이후 명령에서도 로그인 상태를 유지합니다. 두 가지 방법을 사용할 수 있습니다.

| 방법 | 용도 |
|---|---|
| 브라우저 로그인 | 브라우저가 있는 컴퓨터에서 직접 로그인할 때 사용합니다. OAuth 2.1을 사용하며 로그인 상태를 자동으로 갱신합니다. |
| API 토큰 | 스크립트, 빌드 머신, 브라우저가 없는 컴퓨터에서 사용합니다. |

브라우저로 로그인하면 MoleSignal의 MCP 엔드포인트에만 액세스할 수 있습니다. 배포 보고,
소스 맵 및 심볼 업로드, 로그 전송은 MoleSignal API를 호출하므로 API 토큰이 필요합니다.

## 브라우저에서 로그인하기

```bash
molesignal login --url https://molesignal.example.com
```

1. CLI는 MoleSignal에 클라이언트로 등록한 뒤 MoleSignal 승인 페이지를
   기본 브라우저에서 엽니다. 세션이 없으면 이 페이지에서 MoleSignal에 로그인합니다.
2. 승인 페이지에는 클라이언트, 계정, 조직과 함께 허용되는 작업 목록이
   표시됩니다. 여러 조직에 속해 있으면 **조직**에서 하나를 선택합니다. 액세스 권한은
   선택한 조직에만 적용됩니다.
3. **승인**을 클릭합니다. 브라우저가 CLI로 제어를 돌려주면 CLI가 사용할 수 있는
   도구 수를 표시합니다.

CLI는 `mcp` 및 `offline_access` 범위를 요청하므로 액세스 권한을 취소할 때까지 로그인 상태를
자동으로 갱신합니다. 승인 페이지에서 5분 동안 대기한 뒤 명령이 종료됩니다. 기존 로그인 상태가
있으면 그대로 유지합니다. 로그인을 거부하거나 중단해도 기존 로그인 상태를
유지합니다.

<Note>
  브라우저는 명령을 실행하는 동안에만 동작하는 `http://127.0.0.1`의 리스너로 돌아갑니다.
  명령이 끝나면 해당 컴퓨터에서 리스너가 더 이상 동작하지 않습니다. SSH로 접속한 원격 컴퓨터에서는
  브라우저가 해당 리스너에 연결할 수 없으므로 API 토큰으로 로그인합니다.
</Note>

## API 토큰으로 로그인하기

**ID 및 액세스 → API 토큰**에서 토큰을 생성한 뒤 표준 입력으로 전달합니다.

```bash
printf '%s' "$MOLESIGNAL_TOKEN" | molesignal login --url https://molesignal.example.com --with-token
```

토큰은 해당 토큰을 소유한 사용자 계정 또는 서비스 계정의 권한으로 작동합니다.

## 토큰을 저장하지 않고 사용하기

빌드 머신에서와 같이 환경 변수로 주소와 토큰을 설정합니다. CLI는 주소나 토큰을 저장하지 않습니다.

```bash
MOLESIGNAL_URL=https://molesignal.example.com MOLESIGNAL_TOKEN=<token> molesignal status
```

`--url` 및 `--token`으로도 주소와 토큰을 지정할 수 있지만, 해당 명령에만 적용합니다. CLI는 특정 주소에 저장한 토큰을
다른 주소로 보내지 않습니다.

## 여러 로그인 상태 유지하기

CLI는 각 로그인 상태를 프로필에 저장합니다. 프로필에는 주소와 해당 주소의 액세스 정보가 포함됩니다. 여러 프로필을 사용하면
여러 MoleSignal 인스턴스나 단일 인스턴스의 여러 조직에 로그인한 상태를 유지할 수 있습니다.
`--profile`로 로그인 상태를 저장할 프로필을 지정합니다.

```bash
molesignal login --url https://staging.molesignal.example.com --profile staging
```

가장 최근에 로그인한 프로필이 현재 프로필이 됩니다. 명령은 현재 프로필을 사용합니다.
`--profile` 또는 `MOLESIGNAL_PROFILE`로 해당 명령에서만 다른 프로필을 선택할 수 있습니다. 처음 로그인할 때
`--profile`을 지정하지 않으면 `default` 프로필에 저장합니다.

| 명령 | 동작 |
|---|---|
| `molesignal profiles` | 프로필, 로그인 방식, 주소를 나열합니다. `*`는 현재 프로필을 나타냅니다. |
| `molesignal use <profile>` | 지정한 프로필을 현재 프로필로 설정합니다. |
| `molesignal logout --profile <profile>` | 지정한 프로필의 로그인 상태를 삭제하고 주소는 유지합니다. |
| `molesignal profiles remove <profile>` | 지정한 프로필을 삭제합니다. |

## 로그인 상태 저장 위치

CLI는 프로필을 `~/.config/molesignal/config.json`에 저장합니다. 파일은 소유자만 읽을 수 있습니다.
`XDG_CONFIG_HOME`을 설정하면 해당 폴더를 사용하고, Windows에서는 `%APPDATA%`를 사용합니다.
`MOLESIGNAL_CONFIG`로 다른 파일을 지정할 수 있습니다.

## 프록시를 통해 사용하기

`HTTPS_PROXY` 또는 `HTTP_PROXY`로 CLI의 모든 요청을 프록시를 통해 전송하도록 설정합니다. `NO_PROXY`에는
프록시를 거치지 않고 연결할 호스트를 나열합니다.

```bash
HTTPS_PROXY=http://proxy.example.com:3128 NO_PROXY=localhost molesignal status
```

사설 인증 기관에서 발급한 MoleSignal 인증서를 사용하는 경우, 해당 기관의
인증서를 `NODE_EXTRA_CA_CERTS`에 지정해야 합니다.

## 로그인 상태 및 설정 확인하기

`molesignal status`는 주소, 프로필, 응답한 서버, MCP 프로토콜
리비전, 로그인 방식, MCP 도구 수를 표시합니다.

```bash
molesignal status
```

`molesignal whoami`는 사용자, 조직, 역할과 MoleSignal이 부여한
권한을 표시합니다.

```bash
molesignal whoami
```

`molesignal doctor`는 CLI에 필요한 항목을 하나씩 검사하고, 실패하면 해결 방법을 안내합니다.
검사 항목은 Node.js, 구성 파일 권한, 주소, 프록시, 네트워크 및 TLS,
시스템 시계, 로그인 상태, MCP 엔드포인트입니다. 검사에 실패하면 종료 코드 `1`을 반환합니다.

```bash
molesignal doctor
```

## 로그아웃하기

`molesignal logout`은 이 컴퓨터의 현재 프로필에 저장된 로그인 상태를 삭제합니다.

```bash
molesignal logout
```

MoleSignal은 부여한 액세스 권한을 별도로 취소할 때까지 유지합니다. 권한을 취소하려면 다음 메뉴로 이동합니다.
**Mole Agent → 설정 → 인바운드 MCP**.
