```http
GET /api/v1/business-context
PUT /api/v1/business-context
```

테넌트, 플랜, 실험 그룹과 같은 비즈니스 키와, 스팬, 로그, RUM 이벤트에서 각 키를 전달하는
필드입니다. [비즈니스 컨텍스트](/ko/business-context)를 참조하세요. 읽기에는
`apm.services.read`, `traces.read`, `logs.read`, `rum.events.read`, `apm.settings.read` 또는
`sys.telemetry.read` 권한이 필요합니다. 설정에는 `apm.settings.manage`가 필요하며 활동 로그에 기록됩니다.

## 키 설정

`PUT`은 모든 키를 교체합니다. 빈 필드는 아무것도 지정하지 않고, 빈 `label`은 키가 되며, 중요한 값은
트리밍되어 각각 한 번씩 나열됩니다. 응답은 저장된 내용입니다.

| 필드 | 비고 |
|---|---|
| `key` | 소문자로 시작하고 소문자, 숫자, `_`만 포함하며 최대 64자입니다. 고유해야 합니다. |
| `label` | 읽는 사람에게 표시되는 이름이며 최대 80자입니다. |
| `span` | 스팬 속성으로, 트레이스 스트림이 해당 필드를 지칭하는 이름 그대로입니다. |
| `log` | 로그 필드입니다. |
| `rum` | RUM 필드로, 포함된 JSON 필드의 키입니다(예: `context.tenant`). |
| `important` | 가장 중요한 값이며, 최대 200자까지 50개까지 지정할 수 있습니다. |

각 키는 `span`, `log`, `rum` 중 최소 하나를 지정해야 합니다. 키는 최대 8개입니다.

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/business-context \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"keys":[{"key":"tenant","label":"Tenant","span":"tenant.id","log":"tenant_id","rum":"context.tenant","important":["acme"]}]}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "keys": [
    {
      "key": "tenant",
      "label": "Tenant",
      "span": "tenant.id",
      "log": "tenant_id",
      "rum": "context.tenant",
      "important": ["acme"]
    }
  ]
}
```
</ResponseExample>

**오류**

| 상태 | 사유 |
|---|---|
| `400` | 키 이름이 잘못되었거나 중복되었거나, 필드를 지정하지 않았거나, 허용된 개수보다 많은 키 또는 값이 있습니다. |
| `403` | 토큰에 해당 호출의 권한이 없습니다. |
