```http
GET /api/v1/audit
```

조직의 감사 이벤트를 최신순으로 반환하며, 커서 기반 페이지네이션을 사용합니다. 이 호출에는 `audit.read` 권한이 필요합니다.

각 이벤트는 조직의 `_audit` 스트림에도 한 행으로 기록됩니다. 이 스트림을 쿼리하고 파이프라인을 통해 다른 대상으로 전송할 수 있습니다. 이 API는 감사 원본 기록을 읽습니다. [감사 스트림](/ko/settings/data-security#감사-스트림)을 참조합니다.

감사 로그는 민감한 수명 주기 작업을 기록합니다. 모든 변경 사항을 기록하지는 않습니다. 현재 릴리스의 작업 이름은 다음 접두사로 시작합니다.

| 접두사 | 작업 |
|---|---|
| `agent.` | Mole Agent의 모델 제공업체, 프롬프트, 도구 및 도구 호출, MCP 서버, 승인, 채팅, 조사, 실행 관련 작업입니다. |
| `iam.` | 역할 바인딩, 관계, 조직 간 권한 부여 관련 작업입니다. |
| `resource_share.` | 공유 링크 생성, 교체, 취소, 열기 및 비밀번호 인증 실패를 기록합니다. |
| `status_page.` | 상태 페이지, 구성 요소, 자동화 규칙, 로고 관련 작업입니다. |
| `synthetic.` | 신세틱 모니터링 위치, 에이전트, 에이전트 토큰 관련 작업입니다. |
| `schedule.` | 온콜 일정 및 일정 재정의 관련 작업입니다. |
| `trace_debug_token.` | 트레이스 디버그 토큰 사용을 기록합니다. |
| `dashboard.` | AI 초안을 바탕으로 생성한 대시보드를 기록합니다. |

스트림, 알림 규칙, 인시던트, 커넥터의 변경 사항은 기록하지 않습니다.

**쿼리 매개변수**

| 매개변수 | 유형 | 참고 |
|---|---|---|
| `from`, `to` | 문자열 | 시간 범위입니다. 각 값은 에포크 기준 마이크로초 또는 상대 시간 값입니다. 상대 시간은 `now` 또는 `now-<N><unit>` 형식으로 지정합니다. 단위는 `s`, `m`, `h`, `d` 중 하나입니다(예: `now-30m`). |
| `actorKind` | 문자열 | 보안 주체의 유형입니다(예: `user`). |
| `actor` | 문자열 | 보안 주체의 식별자입니다. |
| `action` | 문자열 | 정확한 작업 이름입니다(예: `agent.model_provider.created`). |
| `targetKind`, `targetId` | 문자열 | 대상의 유형과 식별자입니다. |
| `limit` | 정수 | 페이지 크기입니다. 기본값은 `50`입니다. 1보다 작은 값은 1로, 200보다 큰 값은 200으로 조정합니다. |
| `cursor` | 문자열 | 이전 페이지의 `nextCursor`입니다. 값을 해석하지 않고 그대로 사용합니다. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/audit?from=now-7d&action=agent.model_provider.created&limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**응답**

| 필드 | 참고 |
|---|---|
| `items[].actor_kind`, `items[].actor_id` | 변경을 수행한 보안 주체입니다. |
| `items[].action` | 작업 이름입니다(예: `iam.role_binding.create`). |
| `items[].target_kind`, `items[].target_id` | 작업의 영향을 받은 객체입니다. 두 필드 모두 `null`일 수 있습니다. |
| `items[].ip`, `items[].user_agent` | 작업에서 해당 값을 기록한 경우의 클라이언트 주소와 사용자 에이전트입니다. 두 필드 모두 `null`일 수 있습니다. |
| `items[].payload` | 작업 세부 정보입니다. 페이로드에는 시크릿, 프롬프트 본문, 도구 실행 결과를 포함하지 않습니다. |
| `items[].ts` | 이벤트 발생 시각입니다. 단위는 마이크로초입니다. |
| `nextCursor` | 다음 페이지의 커서입니다. 마지막 페이지에서는 `null`입니다. |
| `retentionDays` | 모든 조직과 플랫폼에 동일하게 적용하는 감사 기록 보존 기간입니다. 단위는 일입니다. 매일 한 번 보존 기간을 초과한 기록을 삭제합니다. `0`으로 설정하면 기록을 영구 보존합니다. |

**오류**

| 상태 | 원인 |
|---|---|
| `400` | `from` 또는 `to`가 숫자도 유효한 상대 시간 값도 아니거나(`unparseable time: yesterday`, `bad time unit in: now-3x`), `cursor`가 유효하지 않습니다. |
| `403` | 토큰에 `audit.read` 권한이 없습니다. |

## 관련 감사 경로

| 엔드포인트 | 권한 | 용도 |
|---|---|---|
| `GET /api/v1/system/audit` | 시스템 범위의 `sys.telemetry.read` | 동일한 쿼리로 시스템 조직의 감사 이벤트를 조회합니다. 이 이벤트에는 조직 활성화 및 비활성화, 트레이스 정책 변경, 감사 기록 보존 기간 변경 등의 작업이 포함됩니다. |
| `GET /api/v1/settings/audit_retention` | 시스템 범위의 `sys.settings.retention.manage` | 감사 기록 보존 기간을 반환합니다: `{ "retentionDays": 90 }`. |
| `PUT /api/v1/settings/audit_retention` | 시스템 범위의 `sys.settings.retention.manage` | 동일한 형식의 요청 본문으로 감사 기록 보존 기간을 설정합니다. `retentionDays`는 `0`(영구 보존)부터 `3650`까지의 정수입니다. 상한을 초과하면 `400`을 반환합니다. |
| `GET /api/v1/settings/audit_retention/preview?retentionDays=30` | 시스템 범위의 `sys.settings.retention.manage` | 보존 기간을 줄이면 삭제될 기록의 정보를 반환합니다: `{ "retentionDays": 30, "previousRetentionDays": 90, "rows": 2400, "earliestAt": 1780000000000000 }`. 삭제 대상 기록의 수는 추정하지 않고 직접 집계합니다. 보존 기간을 늘리거나 `0`을 지정하면 `"rows": 0`을 반환합니다. |
| `GET /api/v1/agent/audit/chat/{id}` | `audit.read` | Mole Agent의 전체 채팅 기록을 반환합니다. `chat` 레코드와 해당 `messages`에 프롬프트 해시, 토큰 수, 근거 자료를 함께 제공합니다. 채팅이 없으면 `404`를 반환합니다. |

<Warning>
  채팅 기록에는 사용자의 질문과 모델의 답변이 포함됩니다. 이 콘텐츠를 열람해도 되는 계정에만 `audit.read` 권한을 부여합니다.
</Warning>
