| 엔드포인트 | 인증 |
|---|---|
| `GET /api/v1/healthz` | 없음 |
| `GET /metrics` | 없음 |
| `GET /api/v1/readyz` | Bearer 토큰 |
| `GET /api/v1/version` | Bearer 토큰 |

## 활성 상태

```http
GET /api/v1/healthz
```

노드의 상태를 종합적으로 확인하는 프로브입니다. 노드가 정상이면 `200`을 반환하고, 오브젝트 스토어에 연결할 수 없으면 `reason`과 함께 `503`을 반환합니다. 컨테이너와 로드 밸런서의 프로브에 사용합니다.

<ResponseExample>
```json 200
{ "status": "ok" }
```
</ResponseExample>

## 준비 상태

```http
GET /api/v1/readyz
Authorization: Bearer <token>
```

노드가 트래픽을 받을 준비가 되었는지 확인하는 프로브입니다. 시작 시 재생할 데이터가 없으므로 노드가 시작되면 바로 `200`을 반환합니다. 오브젝트 스토어의 상태가 저하되어도 읽기 전용 트래픽은 계속 받을 수 있습니다. 요청에 Bearer 토큰이 필요하므로 인증 정보 없이 요청하면 `401`을 반환합니다. 프로브 요청에 토큰을 포함할 수 없으면 대신 `/api/v1/healthz`를 사용합니다.

<ResponseExample>
```json 200
{ "status": "ready" }
```
</ResponseExample>

## 버전

```http
GET /api/v1/version
Authorization: Bearer <token>
```

제품 버전, 커밋과 브랜치, 빌드 시각, 빌드 ID, 릴리스 채널, 에디션을 반환합니다.

<ResponseExample>
```json 200
{
  "version": "26.1.0.0",
  "commit": "<git-sha>",
  "branch": "main",
  "buildEpochSecs": 1790000000,
  "buildId": "<build-id>",
  "releaseChannel": "alpha",
  "edition": "oss"
}
```
</ResponseExample>

## 메트릭

```http
GET /metrics
```

`cache_*` 적중률, `wal_*`, `object_store_*`, `storage_reconciler_issues_total` 등 프로세스 및 하위 시스템 메트릭을 Prometheus 노출 형식(`text/plain; version=0.0.4`)으로 제공합니다. 프록시 또는 네트워크 계층에서 이 경로에 대한 접근을 제한합니다. [자체 관측성](/ko/self-observability)을 참고합니다.
