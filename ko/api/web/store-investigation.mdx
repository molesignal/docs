```http
POST /api/v1/web/investigation/blob
```

JSON 문서를 객체 스토리지에 저장하고 식별자를 반환합니다. 웹 UI는 규모가 큰 조사의 조사 스택을 페이지 URL에 넣는 대신 이 호출을 사용하고, URL에는 식별자만 넣습니다. [조사 스택 가져오기](/ko/api/web/fetch-investigation)로 문서를 읽습니다. 이 호출에는 `streams.query` 권한이 필요하며, 시스템 범위에서는 `sys.telemetry.read` 권한이 필요합니다.

요청 본문에는 최대 1 MiB(1,048,576 bytes)의 JSON 값을 지정할 수 있습니다. 문서는 호출자의 조직에 속합니다. 컴팩터가 7일 후 문서를 삭제합니다.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/investigation/blob \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "version": 1,
    "stack": [
      { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
      { "kind": "log", "query": "level = error" }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "blobId": "3KEZAC5JXc0P0HjrTdARfCgH1Y3"
}
```
</ResponseExample>

**오류**

| 상태 | 원인 |
|---|---|
| `400` | 본문이 유효한 JSON이 아니거나(일반 텍스트), 문서가 1 MiB를 초과합니다(`payload exceeds 1048576 bytes`). |
| `403` | 토큰에 `streams.query` 권한이 없습니다. |
