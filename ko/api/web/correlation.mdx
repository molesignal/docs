```http
GET /api/v1/web/correlation/{fromKind}/{toKind}?ctx=<base64url-json>
```

트레이스에서 해당 로그로 이동하는 등 한 시그널에서 다른 시그널로 이동할 때 웹 UI가 적용할 필터, 시간 범위, 쿼리 자동 입력값을 계산합니다. 이 호출에는 `traces.read` 권한이 필요하며, 시스템 범위에서는 `sys.telemetry.read` 권한이 필요합니다.

**매개변수**

| 매개변수 | 위치 | 필수 | 설명 |
|---|---|---|---|
| `fromKind` | 경로 | 예 | 출발 시그널: `trace`, `metric`, `log` 또는 `host`입니다. |
| `toKind` | 경로 | 예 | 대상 시그널: `trace`, `metric`, `log` 또는 `host`입니다. |
| `ctx` | 쿼리 | 예 | 출발 시그널을 설명하는 JSON 객체입니다. 패딩 없이 base64url로 인코딩합니다. |

`ctx` 객체는 다음 선택적 키를 허용합니다.

| 키 | 유형 | 설명 |
|---|---|---|
| `trace_id` | 문자열 | 출발 시그널의 트레이스 ID입니다. |
| `service` | 문자열 | 단일 서비스 이름입니다. |
| `services` | 배열 | 서비스 이름 목록입니다. |
| `host` | 문자열 | 호스트 이름입니다. |
| `time_range` | 객체 | `{ "from": "<RFC 3339>", "to": "<RFC 3339>" }`. 기본값은 최근 1분입니다. |

## 지원하는 시그널 이동

| 출발 → 대상 | 필터 | 자동 입력값 |
|---|---|---|
| `trace` → `log` | `services`에서 가져온 `service` 및 `trace_id` | 없음. |
| `trace` → `metric` | `services`에서 가져온 `service` | `promql`: `rate(http_requests_total{service="<first service>"}[1m])` |
| `trace` → `host` | `host`에서 가져온 `host` | 없음. |
| `metric` → `trace` | `services`에서 가져온 `service` 및 서비스 그래프에 표시된 첫 번째 서비스의 `peer_service` | 없음. |
| `metric` → `log` | `services`에서 가져온 `service` | 없음. |
| `log` → `trace` | `trace_id` 및 `service` | 없음. |
| `log` → `metric` | `services` 또는 `service`에서 가져온 `service` | `promql`: `rate(log_records_total{service="<service>"}[1m])` |
| `host` → `trace` | `host`에서 가져온 `host.name` | 없음. |

서비스 하나를 필터링할 때는 `eq` 연산자를, 여러 서비스를 필터링할 때는 `in` 연산자를 사용합니다. 알 수 없는 시그널 유형을 포함한 나머지 모든 조합에는 필터 없이 시간 범위만 담아 `200`으로 응답합니다.

<RequestExample>
```bash cURL
CTX=$(printf '%s' '{"trace_id":"0af7651916cd43dd8448eb211c80319c","services":["checkout","payments"],"time_range":{"from":"2026-10-04T10:00:00Z","to":"2026-10-04T10:05:00Z"}}' | base64 | tr -d '\n=' | tr '+/' '-_')

curl "http://localhost:5080/api/v1/web/correlation/trace/log?ctx=$CTX" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "timeRange": { "from": "2026-10-04T10:00:00Z", "to": "2026-10-04T10:05:00Z" },
  "filters": [
    { "field": "service", "op": "in", "value": ["checkout", "payments"] },
    { "field": "trace_id", "op": "eq", "value": "0af7651916cd43dd8448eb211c80319c" }
  ],
  "prefill": {}
}
```
</ResponseExample>

**오류**

| 상태 | 원인 |
|---|---|
| `400` | `ctx`가 누락되었거나, 유효한 base64url이 아니거나, 디코딩 결과가 JSON이 아닙니다. `ctx`가 누락되면 일반 텍스트로 응답하고, 나머지 경우에는 `invalid_argument`와 함께 `invalid ctx base64: ...` 또는 `invalid ctx json: ...` 메시지를 반환합니다. |
| `403` | 토큰에 `traces.read` 권한이 없습니다. |
