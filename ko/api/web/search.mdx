```http
GET /api/v1/web/search
```

**⌘K** 명령 팔레트에서 이 API를 사용합니다. 조직의 엔터티 6종을 이름 유사도로 검색하고, 가장 유사한 결과부터 반환합니다. 이 호출에는 `streams.query` 권한이 필요하며, 시스템 범위에서는 `sys.telemetry.read` 권한이 필요합니다.

**쿼리 매개변수**

| 매개변수 | 유형 | 필수 | 비고 |
|---|---|---|---|
| `q` | 문자열 | 예 | 최대 256자의 검색어입니다. PostgreSQL 트라이그램 유사도로 검색하므로 한 글자처럼 매우 짧은 검색어는 일치하는 결과가 거의 없습니다. `q`가 비어 있으면 빈 목록을 반환합니다. |
| `types` | 문자열 | 아니요 | `stream`, `dashboard`, `savedView`, `alert`, `incident`, `service` 중 검색할 유형을 쉼표로 구분해 지정합니다. 모든 유형을 검색하려면 생략합니다. 지원하지 않는 값에는 일치하는 결과가 없습니다. |
| `limit` | 정수 | 아니요 | 기본값은 `20`입니다. 1 미만의 값은 1로, 50을 초과하는 값은 50으로 조정합니다. |

`q`가 공백으로만 이루어져 있고 `types=stream`을 지정하면 검색 대신 스트림을 이름의 알파벳순으로 나열합니다.

각 검색 결과는 다음 필드로 엔터티를 나타냅니다.

| `kind` | `id` | `label` | `subtitle` |
|---|---|---|---|
| `stream` | 스트림 식별자 | 스트림 이름 | `builtin.logs`와 같은 내부 형식의 스트림 유형입니다. |
| `dashboard` | 대시보드 식별자 | 제목 | 대시보드의 `uid`입니다. |
| `savedView` | 저장된 뷰 식별자 | 이름 | 쿼리 언어입니다. |
| `alert` | 규칙 식별자 | 규칙 이름 | `enabled` 또는 `disabled`입니다. |
| `incident` | 인시던트 식별자 | 인시던트 핑거프린트 | 인시던트 상태입니다. |
| `service` | 에지 식별자 | 서비스 그래프의 서비스 이름 | 없습니다. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/search?q=app&types=stream&limit=5" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "items": [
    { "kind": "stream", "id": "3KDXoznFWyKPsch4ETi37U3GdxM", "label": "app", "subtitle": "builtin.logs" },
    { "kind": "stream", "id": "3JtcZGko1Q5czEBK9nBJjiFxpo1", "label": "app_logs", "subtitle": "builtin.logs" }
  ]
}
```
</ResponseExample>

**오류**

| 상태 | 원인 |
|---|---|
| `400` | `q`가 누락되었거나(일반 텍스트 응답) 256자를 초과합니다(`invalid_argument`). |
| `403` | 토큰에 `streams.query` 권한이 없습니다. |
