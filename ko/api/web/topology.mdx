```http
GET /api/v1/web/topology
```

지정된 시간 구간의 서비스 그래프 엣지를 노드와 엣지로 집계하고, 초당 요청 수, 오류율, 지연 시간을 함께 반환합니다. MoleSignal은 트레이스 스팬에서 서비스 그래프를 생성하고 해당 그래프에서 엣지를 가져옵니다. [서비스 맵](/ko/apm/service-map)을 참조합니다. 이 호출에는 `traces.read` 권한이 필요하며, 시스템 범위에서는 `sys.telemetry.read` 권한이 필요합니다.

**쿼리 매개변수**

| 매개변수 | 유형 | 필수 | 설명 |
|---|---|---|---|
| `from` | 문자열 | 예 | 시간 구간의 시작을 나타내는 RFC 3339 타임스탬프입니다. |
| `to` | 문자열 | 예 | 시간 구간의 끝을 나타내는 RFC 3339 타임스탬프입니다. `from`보다 앞설 수 없습니다. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/topology?from=2026-10-04T09:00:00Z&to=2026-10-04T10:00:00Z" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "nodes": [
    { "id": "checkout", "name": "checkout", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 },
    { "id": "frontend", "name": "frontend", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 }
  ],
  "edges": [
    { "source": "frontend", "target": "checkout", "rps": 0.1, "errRate": 0.0278, "p95Ms": 90.0 }
  ]
}
```
</ResponseExample>

**응답**

| 필드 | 설명 |
|---|---|
| `nodes[].id`, `nodes[].name` | 서비스 이름입니다. 노드는 이름순으로 정렬합니다. |
| `nodes[].span_count` | 서비스가 클라이언트 또는 서버로 연결된 모든 엣지의 요청 수입니다. |
| `nodes[].error_rate`, `edges[].err_rate` | 오류 수를 요청 수로 나눈 값입니다. 범위는 0부터 1까지입니다. |
| `nodes[].rps`, `edges[].rps` | 요청 수를 시간 구간의 길이(초)로 나눈 값입니다. |
| `nodes[].p95_ms`, `edges[].p95_ms` | 집계한 버킷별 p95 지연 시간 중 최댓값입니다. 단위는 밀리초입니다. 전체 시간 구간의 p95는 아닙니다. |
| `edges[].source`, `edges[].target` | 각각 클라이언트 서비스와 서버 서비스입니다. 엣지는 소스 기준으로 먼저 정렬한 뒤 대상 기준으로 정렬합니다. |

시간 구간에 엣지가 없으면 빈 배열을 반환합니다.

**오류**

| 상태 | 원인 |
|---|---|
| `400` | `from` 또는 `to`가 누락되었거나 RFC 3339 타임스탬프가 아니거나, `to`가 `from`보다 앞섭니다. |
| `403` | 토큰에 `traces.read` 권한이 없습니다. |
