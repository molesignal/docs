```http
GET /api/v1/web/investigation/blob/{id}
```

[조사 스택 저장](/ko/api/web/store-investigation)이 `blobId`에 저장한 JSON 문서를 반환합니다. 호출자의 조직에서만 조회하므로 다른 조직의 식별자를 사용하면 `404`를 반환합니다. 호출하려면 `streams.query` 권한이 필요하며, 시스템 범위에서는 `sys.telemetry.read` 권한이 필요합니다.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/web/investigation/blob/$BLOB_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "version": 1,
  "stack": [
    { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
    { "kind": "log", "query": "level = error" }
  ]
}
```
</ResponseExample>

저장된 문서를 변경 없이 반환합니다. 컴팩터가 7일 후 삭제한 문서를 조회해도 `404`를 반환합니다.

**오류**

| 상태 | 원인 |
|---|---|
| `403` | 토큰에 `streams.query` 권한이 없습니다. |
| `404` | 식별자가 존재하지 않거나, 다른 조직에 속하거나, 만료되었습니다. |
