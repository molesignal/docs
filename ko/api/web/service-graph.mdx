```http
GET /api/v1/traces/service_graph
```

[서비스 토폴로지](/ko/api/web/topology)에서 집계하는 서비스 그래프의 원시 에지를 반환합니다. 각 에지는 1분 동안 클라이언트 서비스에서 서버 서비스로 보낸 호출 수를 집계합니다. 이 API를 호출하려면 `traces.read` 권한 또는 시스템 범위의 `sys.telemetry.read` 권한이 필요합니다.

**쿼리 매개변수**

| 매개변수 | 유형 | 필수 여부 | 설명 |
|---|---|---|---|
| `from` | 정수 | 예 | 조회 구간의 시작 시각입니다. Unix epoch 이후 경과 시간을 마이크로초 단위로 지정합니다. |
| `to` | 정수 | 예 | 조회 구간의 종료 시각입니다. 마이크로초 단위로 지정합니다. |
| `service` | 문자열 | 아니요 | 지정한 서비스가 클라이언트 또는 서버인 에지만 반환합니다. |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000
curl "http://localhost:5080/api/v1/traces/service_graph?from=$((NOW-3600000000))&to=$NOW&service=checkout" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "edges": [
    {
      "id": "3KBCiQWW0TtpDu7D4pH7LMtZsRh",
      "orgId": "<organization-id>",
      "clientService": "frontend",
      "serverService": "checkout",
      "bucketAt": 1790000000000000,
      "requestCount": 12,
      "errorCount": 1,
      "p50Us": 90000,
      "p95Us": 210000,
      "p99Us": 240000
    }
  ],
  "count": 1
}
```
</ResponseExample>

**응답**

| 필드 | 설명 |
|---|---|
| `edges[].client_service`, `edges[].server_service` | 호출을 보낸 서비스와 호출을 받은 서비스입니다. |
| `edges[].bucketAt` | 1분 버킷의 시작 시각입니다. 단위는 마이크로초입니다. |
| `edges[].request_count`, `edges[].error_count` | 버킷 내 전체 호출 수와 실패한 호출 수입니다. |
| `edges[].p50_us`, `edges[].p95_us`, `edges[].p99_us` | 버킷의 지연 시간 백분위수입니다. 단위는 마이크로초입니다. 백분위수는 `null`일 수 있습니다. |
| `count` | 반환한 에지 수입니다. |

조회 구간에 조건과 일치하는 에지가 없거나 `to`가 `from`보다 이르면 `{"edges": [], "count": 0}`을 반환합니다.

**오류**

| 상태 | 원인 |
|---|---|
| `400` | `from` 또는 `to`가 누락되었거나 정수가 아닙니다. 응답은 일반 텍스트입니다. |
| `403` | 토큰에 `traces.read` 권한이 없습니다. |
