```http
GET  /api/v1/query/stream
POST /api/v1/query/stream
```

항상 청크로 나눈 NDJSON(`application/x-ndjson`)으로 응답합니다. 각 줄은 열 이름을 키로 사용하는 JSON 객체이며, 마지막 줄은 `{"__meta__":{"scannedRows":...,"tookMs":...}}`입니다. 이 엔드포인트는 쿼리를 비동기 작업으로 전환하지 않습니다. 호출하려면 `streams.query` 권한이 필요하며, 시스템 범위에서는 `sys.telemetry.read` 권한이 필요합니다.

`POST` 방식은 [쿼리 실행](/ko/api/query/execute)과 동일한 요청 본문을 받습니다. `GET` 방식은 다음 쿼리 매개변수를 받습니다.

| 매개변수 | 필수 여부 | 설명 |
|---|---|---|
| `sql` | 예 | SQL 문입니다. 값이 없으면 `400`을 반환합니다. |
| `stream` | 예 | 기본 스트림 이름입니다. |
| `streamType` | 아니요 | `logs`, `metrics`, `traces`, `profiles`, `extend` 중 하나입니다. 기본값은 `logs`입니다. |
| `from`, `to` | 예 | 시간 범위입니다(마이크로초 단위). |
| `limit` | 아니요 | 최대 행 수입니다. |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000

curl -G http://localhost:5080/api/v1/query/stream \
  -H "authorization: Bearer $MS_TOKEN" \
  --data-urlencode "sql=SELECT level, msg FROM app ORDER BY _timestamp DESC" \
  --data-urlencode "stream=app" \
  --data-urlencode "streamType=logs" \
  --data-urlencode "from=$((NOW-3600000000))" \
  --data-urlencode "to=$((NOW+60000000))" \
  --data-urlencode "limit=3"
```
</RequestExample>

<ResponseExample>
```text 200
{"level":"info","msg":"fine"}
{"level":"error","msg":"db pool exhausted"}
{"__meta__":{"scannedRows":5,"tookMs":173}}
```
</ResponseExample>

행이 생성되는 즉시 도착하도록 프록시에서 응답 버퍼링을 끄고(`proxy_buffering off`), 장시간 읽기를 허용합니다. 스트림을 취소하려면 읽기를 중단합니다.
