```http
POST /api/v1/dashboards
```

대시보드를 생성합니다. 요청 본문의 `model`에 전체 대시보드 모델을 담고, 필요하면 `folderId`를 지정합니다. `uid`는 조직 내에서 고유해야 합니다. 중복되면 `409`를 반환합니다. 이 호출에는 `dashboards.create` 권한이 필요합니다.

**모델의 필수 속성**

| 속성 | 설명 |
|---|---|
| `engine` | `molesignal-dashboard`입니다. |
| `schemaVersion` | `2`입니다. |
| `uid`, `title`, `tags` | 식별 정보입니다. `uid`와 `title`은 비워 둘 수 없으며, `tags`는 배열입니다. |
| `editable`, `defaultDashboard` | 불리언 값입니다. |
| `timeSettings` | `timezone`, `defaultFrom`, `defaultTo`를 포함합니다. |
| `refreshSettings` | `mode`, `enabled`, `defaultInterval`, `allowedIntervals`를 포함합니다. |
| `variables`, `annotations`, `links`, `elements` | 배열입니다. 빈 대시보드에서는 빈 배열로 지정합니다. |
| `layout` | 그리드입니다. `type`, `columns`, `rowHeight`, `gap`을 포함합니다. |

모델에 필수 속성이 누락되면 `validation_failed`와 함께 `400`을 반환하고, 누락된 속성마다 `issues`에 항목을 하나씩 추가합니다.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/dashboards \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "model": {
      "engine": "molesignal-dashboard",
      "schemaVersion": 2,
      "uid": "service-overview",
      "title": "Service overview",
      "tags": ["operations"],
      "editable": true,
      "defaultDashboard": false,
      "timeSettings": { "timezone": "browser", "defaultFrom": "now-6h", "defaultTo": "now" },
      "refreshSettings": { "mode": "interval", "enabled": true, "defaultInterval": "30s",
                           "allowedIntervals": ["off", "30s", "1m", "5m"] },
      "variables": [],
      "annotations": [],
      "links": [],
      "layout": { "type": "grid", "columns": 24, "rowHeight": 8, "gap": 8 },
      "elements": []
    },
    "folderId": null
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7XebQcmZojtDim7ZVdGVw594",
  "orgId": "<organization-id>",
  "folderId": null,
  "uid": "service-overview",
  "title": "Service overview",
  "tags": ["operations"],
  "model": { "engine": "molesignal-dashboard", "...": "..." },
  "version": 1
}
```
</ResponseExample>

먼저 편집기에서 패널을 만든 다음, `GET /api/v1/dashboards/{id}`로 기존 대시보드의 모델을 내보내 템플릿으로 사용합니다. 다른 경로: `GET /api/v1/dashboards`, `PUT` 및 `DELETE /api/v1/dashboards/{id}`.
