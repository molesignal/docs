```http
GET  /api/v1/saved_views/{id}
POST /api/v1/query
```

저장된 뷰는 `language`, `statement`, `stream`, 상대 시간 범위인 `timeRangeSecs`를 저장합니다. 별도의 실행 엔드포인트는 없습니다. 웹 애플리케이션은 다음과 같이 두 번 요청을 보내며, 이 과정에는 `saved_views.read`와 `streams.query` 권한이 필요합니다.

1. `GET /api/v1/saved_views/{id}`로 뷰를 불러옵니다.
2. 현재 시각에 끝나는 절대 시간 범위를 계산합니다. `end`는 현재 시각을 마이크로초 단위로 나타낸 값이며, `start`는 `end`에서 `timeRangeSecs`에 1,000,000을 곱한 값을 뺀 값입니다.
3. 저장된 `language`와 `statement`, 계산한 `timeRange`, 스트림을 [쿼리 실행](/ko/api/query/execute) 엔드포인트에 전달합니다.

<RequestExample>
```bash cURL
VIEW=$(curl -s http://localhost:5080/api/v1/saved_views/$VIEW_ID \
  -H "authorization: Bearer $MS_TOKEN")

END=$(date +%s)000000
START=$((END - $(echo "$VIEW" | jq .timeRangeSecs) * 1000000))

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "{\"orgId\":\"$MS_ORG\",
       \"language\":$(echo "$VIEW" | jq .language),
       \"statement\":$(echo "$VIEW" | jq .statement),
       \"timeRange\":{\"start\":$START,\"end\":$END},
       \"stream\":{\"name\":$(echo "$VIEW" | jq .stream),\"streamType\":\"logs\"}}"
```
</RequestExample>

저장된 뷰에는 스트림 이름만 저장되고 유형은 저장되지 않으므로, 해당 뷰가 속한 스트림의 유형을 전달합니다.
