```http
GET /api/v1/saved_views
```

조직의 저장된 뷰를 반환합니다. 고정된 뷰만 반환하려면 `?pinned=true`를 추가합니다. 이 호출에는 `saved_views.read` 권한이 필요합니다.

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/saved_views?pinned=true" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KE7RbW5ShK8cbrZZq4I4O3XUge",
    "orgId": "<organization-id>",
    "ownerUserId": "<user-id>",
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = 'error'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true,
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

기타 경로: `GET /api/v1/saved_views/{id}`는 뷰 하나를 반환하고, `DELETE /api/v1/saved_views/{id}`는 `deleted`를 반환합니다.

## 전체 뷰 또는 고정된 뷰 나열

고정 여부와 관계없이 뷰를 나열하려면 `pinned`를 생략하거나 `pinned=false`로 설정합니다. `pinned=false`는 고정되지 않은 뷰만 나열한다는 뜻이 아닙니다. 고정된 뷰의 바로 가기 목록을 만들려면 `pinned=true`로 설정합니다.

이 요청은 쿼리 결과가 아니라 현재 조직의 뷰 정의를 반환합니다. 응답은 JSON 배열이며, 필터와 일치하는 뷰가 없으면 유효한 결과인 `[]`를 반환합니다. 있어야 할 뷰가 보이지 않으면 삭제된 것으로 판단하기 전에 인증 정보가 속한 조직을 확인하고 고정 필터를 해제합니다.

## 저장된 쿼리 읽기

| 필드 | 용도 |
|---|---|
| `id` | 상세 조회 또는 실행 엔드포인트에 전달합니다. |
| `language`, `statement` | 저장된 쿼리의 언어와 텍스트입니다. |
| `stream` | 저장된 스트림 컨텍스트입니다(있는 경우). |
| `timeRangeSecs` | 저장된 시간 범위의 길이입니다. 단위는 초입니다. |
| `tags`, `pinned` | 정리와 탐색에 사용하는 메타데이터이며, 쿼리 필터가 아닙니다. |
| `createdAt`, `updatedAt` | 마이크로초 단위의 타임스탬프입니다. |

정의를 읽어도 쿼리가 실행되거나 해당 데이터를 쿼리할 권한이 부여되지는 않습니다. 필요한 권한으로 뷰를 실행하려면 [저장된 뷰 실행](/ko/api/query/run-saved-view)을 따릅니다. 쿼리를 저장하려면 [저장된 뷰 만들기](/ko/api/query/create-saved-view)를, UI에서 작업하는 방법은 [저장된 뷰](/ko/saved-views)를 참조합니다.
