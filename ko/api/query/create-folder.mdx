```http
POST /api/v1/folders
```

대시보드 폴더를 생성합니다. 이 호출에는 `dashboards.folders.manage` 권한이 필요합니다. 목록 조회, 수정, 삭제에는 각각 `dashboards.folders.read`, `dashboards.folders.manage`, `dashboards.folders.delete` 권한을 사용합니다.

**본문**

| 필드 | 유형 | 필수 여부 | 참고 |
|---|---|---|---|
| `name` | 문자열 | 예 | 폴더 이름입니다. |
| `parentId` | 문자열 또는 `null` | 아니요 | 같은 조직에 속한 상위 폴더의 ID입니다. `null`을 지정하면 최상위 폴더를 생성합니다. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parentId":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "orgId": "<organization-id>",
  "name": "Operations",
  "parentId": null
}
```
</ResponseExample>

`GET /api/v1/folders`는 폴더 목록을 반환합니다. `DELETE /api/v1/folders/{id}`는 `{"deleted": "<id>"}`를 반환합니다. 폴더에 대시보드나 하위 폴더가 남아 있으면 `409`를 반환합니다.
