```http
POST /api/v1/query
GET  /api/v1/query
```

쿼리를 실행해 결과 행을 반환하거나, 대규모 쿼리의 경우 비동기 검색 작업을 시작합니다. 호출에는 `streams.query` 권한이 필요하며, 시스템 텔레메트리를 조회하려면 `sys.telemetry.read` 권한이 필요합니다.

**본문**

| 필드 | 유형 | 필수 | 참고 |
|---|---|---|---|
| `orgId` | string | 예 | 필드는 필수지만 값은 사용하지 않습니다. 인증된 조직을 사용합니다. |
| `language` | string | 예 | `sql` 또는 `promql`입니다. |
| `statement` | string | 예 | 쿼리 텍스트입니다. |
| `timeRange` | object | 예 | `{ "start": <microseconds>, "end": <microseconds> }`입니다. |
| `stream` | object | SQL의 경우 필수 | `{ "name": "app", "streamType": "logs" }`로 기본 테이블을 지정합니다. 두 필드 모두 필수이며, 유형은 `logs`, `metrics`, `traces`, `profiles`, `extend` 중 하나입니다. |
| `limit` | integer | 아니요 | 최대 행 수입니다. PromQL 범위 쿼리는 이 한도에 맞춰 각 시계열을 균등한 간격으로 샘플링합니다. |
| `step` | integer | 아니요 | PromQL 전용입니다. 범위 쿼리의 샘플링 간격을 마이크로초 단위로 지정합니다. `step`을 지정하면 `start`부터 `end`까지 각 간격에 해당하는 시계열 값을 반환합니다. 지정하지 않으면 `end` 시점의 값을 반환합니다. 시계열당 최대 11,000개 시점을 허용하며, 간격이 너무 짧으면 `400`을 반환합니다. |

**GET 쿼리 문자열**

`GET /api/v1/query`는 동일한 쿼리를 쿼리 문자열로 받으므로 조회 URL을
복사해 다시 열 수 있습니다. `POST`와 동일한 응답을 반환하고, 동일한 헤더를 적용하며,
동일한 권한을 요구합니다. 쿼리문이 URL에 넣기에는 너무 길면 `POST`로 전송합니다.
서버 앞단의 프록시는 8 KB를 초과하는 요청 줄을 거부할 수 있습니다.

| 매개변수 | 필수 | 참고 |
|---|---|---|
| `language` | 예 | `sql` 또는 `promql`입니다. |
| `statement` | 예 | URL 인코딩한 쿼리 텍스트입니다. |
| `start`, `end` | 예 | 마이크로초 단위의 시간 범위입니다. |
| `stream`, `streamType` | SQL의 경우 필수 | 기본 테이블과 해당 유형을 함께 지정합니다. |
| `limit` | 아니요 | 최대 행 수입니다. |
| `step` | 아니요 | PromQL 범위 쿼리의 샘플링 간격입니다. 단위는 마이크로초입니다. |

**헤더 및 쿼리 문자열**

| 이름 | 동작 |
|---|---|
| `Prefer: respond-async` | 검색 작업을 생성하고 `202`를 반환합니다. `_audit` 쿼리는 이 헤더와 관계없이 요청 내에서 실행합니다. |
| `Prefer: respond-sync` | 시간 범위가 길어도 요청 내에서 실행합니다. |
| `Accept: application/x-ndjson` | 행마다 JSON 객체 하나를 스트리밍한 뒤 `{"__meta__": ...}` 레코드를 전송합니다. |
| `?clusters=local,remote` | 연합 검색에 원격 클러스터를 포함합니다. |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "{\"orgId\":\"$MS_ORG\",\"language\":\"sql\",
       \"statement\":\"SELECT level, count(*) AS n FROM app GROUP BY level\",
       \"timeRange\":{\"start\":$((NOW-3600000000)),\"end\":$((NOW+60000000))},
       \"stream\":{\"name\":\"app\",\"streamType\":\"logs\"}}"
```

```bash cURL (GET)
NOW=$(date +%s)000000

curl -G http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_TOKEN" \
  --data-urlencode 'language=promql' \
  --data-urlencode 'statement=sum(rate(http_requests_total[5m]))' \
  --data-urlencode "start=$((NOW-3600000000))" \
  --data-urlencode "end=$NOW" \
  --data-urlencode 'step=60000000'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "columns": ["level", "n"],
  "rows": [["error", 12], ["info", 40]],
  "scannedRows": 10432,
  "tookMs": 18
}
```
</ResponseExample>

PromQL 응답은 값마다 행 하나를 반환합니다. 범위 쿼리는 `_timestamp`(마이크로초), `value`, 레이블별 열을 반환하며, 시계열의 각 샘플링 시점마다 행 하나를 생성합니다. `step`이 없는 쿼리는 `value`와 레이블 열을 반환하며, 시계열마다 행 하나를 생성합니다.

```json
{
  "columns": ["_timestamp", "value", "service.name"],
  "rows": [[1761638400000000, 0.42, "checkout"], [1761638460000000, 0.40, "checkout"]],
  "scannedRows": 2,
  "tookMs": 6
}
```

예상 행 수가 `[querier].auto_async_threshold_rows` 이상이면 `202`를 반환합니다.

```json
{
  "jobId": "3KE1WD4SrFXhyftdMJY0FN7fTFj",
  "monitor": "/api/v1/query/jobs/3KE1WD4SrFXhyftdMJY0FN7fTFj",
  "state": "pending"
}
```

임계값과 작업 엔드포인트는 [쿼리](/ko/query#시간-범위-및-비동기-작업)를 참조합니다.

**오류**

| 상태 | 원인 |
|---|---|
| `400` | 쿼리문의 실행 계획을 수립할 수 없거나, SQL에 `stream` 힌트가 없거나(`query.stream hint is required`), PromQL의 `step`이 양수가 아니거나 시계열당 샘플링 시점이 11,000개를 초과하거나, 쿼리가 `[querier].max_scan_rows`에서 허용하는 것보다 많은 행을 읽으려고 합니다. `GET`에서는 필수 매개변수가 누락되거나 `stream`을 `streamType` 없이 지정한 경우에도 `400`을 반환합니다. |
| `503` | 역할이 분리된 클러스터에서 실행 중인 `querier` 노드가 없습니다(`no querier node is available`). |
| `403` | 조직에 해당 스트림이 없거나(`stream not found: <name>`), 토큰에 `streams.query` 권한이 없거나, 쿼리가 `_audit`을 읽는데 토큰에 `audit.read` 권한이 없습니다. |
| `422` | `orgId` 또는 `streamType` 등 본문 필드가 누락되었거나 유형이 올바르지 않습니다. 일반 텍스트로 응답합니다. |
| `429` | 작업 그룹의 쿼리가 노드의 실행 슬롯을 모두 사용해 이 쿼리가 [`[search.admission].max_wait_secs`](/ko/configuration#쿼리-승인-제어) 동안 대기해도 빈 슬롯을 확보하지 못했거나, 작업 그룹이 클러스터 전체 한도에 도달했습니다. |
