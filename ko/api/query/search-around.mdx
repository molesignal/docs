```http
POST /api/v1/query/search_around
```

기준 이벤트의 앞뒤 24시간 범위에서 바로 이전과 이후의 이벤트를 반환합니다. 각 방향의 이벤트 수는 기본값이 50이며, 1부터 1000까지 지정할 수 있습니다. 이 호출에는 `streams.query`가 필요하며, 시스템 텔레메트리에는 대신 `sys.telemetry.read`가 필요합니다.

`before`는 타임스탬프가 포인터의 시각과 같거나 그보다 이른 이벤트를 최신순으로 담습니다. 기준 이벤트가 저장되어 있으면 첫 번째 행에 표시됩니다. `after`는 타임스탬프가 포인터의 시각보다 늦은 이벤트를 오래된 순으로 담습니다. 스트림이 존재하지 않으면 오류 대신 빈 `before`와 `after`를 반환합니다.

**본문**

| 필드 | 유형 | 필수 | 기본값 |
|---|---|---|---|
| `eventTimestampUs` | 정수 | 예 | |
| `stream` | 문자열 | 예 | |
| `streamType` | 문자열 | 예 | |
| `eventFingerprint` | 문자열 | 아니요 | `pointer`에 입력값을 그대로 반환합니다. 서버는 이벤트를 선택할 때 이 값을 사용하지 않습니다. |
| `before` | 정수 | 아니요 | 50 |
| `after` | 정수 | 아니요 | 50 |
