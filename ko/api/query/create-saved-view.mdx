```http
POST /api/v1/saved_views
```

상대 시간 범위와 함께 쿼리를 저장합니다. 이 호출에는 `saved_views.create` 권한이 필요합니다.

**본문**

| 필드 | 유형 | 필수 여부 | 설명 |
|---|---|---|---|
| `name` | 문자열 | 예 | 표시 이름입니다. |
| `language` | 문자열 | 예 | `sql` 또는 `promql`입니다. |
| `statement` | 문자열 | 예 | 쿼리 텍스트입니다. |
| `timeRangeSecs` | 정수 | 예 | 상대 시간 범위입니다. 1초부터 31,622,400초까지 지정할 수 있습니다. 범위를 벗어나면 `400`을 반환합니다. |
| `stream` | 문자열 | 아니요 | 기본 스트림의 이름입니다. |
| `tags` | 문자열 배열 | 아니요 | 필터링에 사용할 레이블입니다. |
| `pinned` | 불리언 | 아니요 | 뷰를 목록 맨 위에 표시합니다. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/saved_views \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = '"'"'error'"'"'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true
  }'
```
</RequestExample>

생성된 뷰를 [저장된 뷰 목록 조회](/ko/api/query/list-saved-views)에 나온 형식으로 반환합니다.
