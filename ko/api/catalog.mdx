## 권한 부여 모델

엔드포인트는 다음을 요구할 수 있습니다:

- `streams.query` 또는 `alerts.rules.manage`와 같은 조직 권한;
- `sys.telemetry.read`와 같은 플랫폼 권한;
- 리소스 수준 소유권 또는 관계/부여;
- 하나의 리소스로 제한된 공개 공유 세션.

표시 역할에서 권한을 추론하지 않습니다. `/api/v1/iam/capabilities`를 쿼리하여 유효한
권한 및 기능 스냅샷을 확인합니다.

## 요청 선택 및 검증

관련 패밀리의 링크된 가이드에서 시작합니다. 엔드포인트를 사용하기 전에 HTTP 메서드, 필수 권한,
조직 범위, 요청 필드 및 응답 형식을 확인합니다. 패밀리에는 서로 다른 권한을 가진 관리 요청과 데이터 쿼리가 모두 포함될 수 있습니다.

구성을 변경하기 전에 문서화된 읽기 요청을 사용하여 선택한 조직과 리소스를 확인합니다. 쓰기 후에는 리소스를 다시 읽거나 제어된 테스트 이벤트를 쿼리하여 의도한 결과를 확인합니다. HTTP 성공만으로는 텔레메트리가 의도한 스트림에 도달했거나 인시던트가 복구되었음을 입증할 수 없습니다.

오류가 발생하면 [API 소개](/ko/api-reference)와 엔드포인트별 지침을 따릅니다. [문서 불일치를 보고](/ko/support)할 때는 실행 중인 버전, 마스킹된 요청 및 요청 식별자를 포함합니다. 자격 증명과 민감한 이벤트 데이터는 생략합니다.
