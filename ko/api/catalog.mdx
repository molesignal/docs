별도로 명시하지 않는 한 모든 제품 API는 `/api/v1` 접두사를 사용합니다. 이 카탈로그는 현재 라우트를
그룹별로 정리합니다. 그룹 이름을 선택하면 해당 API 예제 또는 사용 가이드를 열 수 있습니다. 코드 서식으로 표시한 경로는 문서 URL이 아니라 서버 엔드포인트입니다.

## 권한 부여 모델

엔드포인트에는 다음과 같은 접근 조건이 적용될 수 있습니다.

- `streams.query` 또는 `alerts.rules.manage`와 같은 조직 권한
- `sys.telemetry.read`와 같은 플랫폼 권한
- 리소스 수준의 소유권, 관계 또는 부여된 권한
- 단일 리소스로 제한된 공개 공유 세션

화면에 표시된 역할만으로 접근 권한을 판단하지 않습니다. `/api/v1/iam/capabilities`를 조회하여 실제로 적용되는
권한과 기능의 현재 상태를 확인합니다.

## 요청 선택 및 검증

먼저 해당 그룹에 연결된 가이드를 확인합니다. 엔드포인트를 사용하기 전에 HTTP 메서드, 필수 권한, 조직 범위, 요청 필드, 응답 형식을 확인합니다. 한 그룹에 서로 다른 권한이 필요한 관리 요청과 데이터 쿼리가 모두 포함될 수 있습니다.

설정을 변경하기 전에 문서에 안내된 읽기 요청으로 선택한 조직과 리소스를 확인합니다. 쓰기 요청을 보낸 뒤에는 리소스를 다시 조회하거나 통제된 테스트 이벤트를 쿼리하여 의도한 결과를 확인합니다. HTTP 성공 응답만으로는 원격 분석 데이터가 의도한 스트림에 도달했는지 또는 인시던트가 복구되었는지 확인할 수 없습니다.

오류가 발생하면 [API 소개](/ko/api-reference)와 해당 엔드포인트의 안내를 따릅니다. [문서와 실제 동작의 불일치를 신고할 때는](/ko/support) 실행 중인 버전, 민감한 정보를 가린 요청, 요청 식별자를 포함합니다. 자격 증명과 민감한 이벤트 데이터는 제외합니다.
