```http
GET /api/v1/me/api-tokens/default
```

로그인한 사용자의 기본 수집 토큰을 반환하며, 처음 호출할 때 토큰을 생성합니다. 다른 토큰과 달리 호출할 때마다 토큰을 평문으로 반환하므로 **데이터 소스** 페이지에서 바로 사용할 수 있는 토큰을 표시할 수 있습니다. 이 토큰은 로그인한 사용자를 대신해 동작하며, `logs.write`, `metrics.write`, `traces.write`, `profiles.write`, `apm.deploy` 권한이 포함된 기본 제공 **데이터 수집** 정책을 따릅니다. 토큰은 만료되지 않으며 `tokenKind` 값은 `default_intake`입니다. 로그인한 세션에서 호출해야 하며, `personal_tokens.manage` 권한과 정책의 두 권한이 모두 필요합니다.

<RequestExample>
```bash cURL
curl -b ms-cookies.txt http://localhost:5080/api/v1/me/api-tokens/default
```
</RequestExample>

수집기, 에이전트, SDK 익스포터에서 이 토큰을 사용합니다. [데이터 소스](/ko/intake#수집-토큰)를 참조합니다.
