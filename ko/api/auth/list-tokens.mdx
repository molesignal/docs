```http
GET /api/v1/auth/tokens
```

활성 조직의 모든 API 토큰에 대한 메타데이터를 반환합니다. 여기에는 기본 수집 토큰, RUM 클라이언트 토큰, 서비스 계정 토큰이 포함됩니다. 평문 토큰과 시크릿 해시는 반환하지 않습니다. 이 호출에는 `api_tokens.read` 권한이 필요합니다.

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "k7m2q9xv4b",
    "name": "grafana-readonly",
    "tokenKind": "personal",
    "userId": "<user-id>",
    "policyId": null,
    "permissions": ["dashboards.read", "streams.query", "streams.read"],
    "applicationId": null,
    "serviceAccountId": null,
    "expiresAt": 1798000000000000,
    "lastUsedAt": null,
    "revoked": false,
    "createdAt": 1790000000000000
  }
]
```
</ResponseExample>

| 필드 | 설명 |
|---|---|
| `tokenKind` | `personal`, `serviceAccount`, `default_intake` 또는 `rum_client`입니다. |
| `userId` | 토큰을 발급한 사용자입니다. 개인 토큰이나 기본 수집 토큰은 이 사용자를 대신해 동작합니다. |
| `policyId` | 토큰에 적용되는 권한 정책입니다. 정책이 없으면 `null`입니다. |
| `permissions` | 토큰에 고정된 권한입니다. 고정된 권한이 없으면 `null`입니다. 권한 정책도 없으면 토큰은 대신 동작하는 사용자 또는 서비스 계정에 허용된 모든 작업을 수행할 수 있습니다. |
| `applicationId` | `rum_client` 토큰에 연결된 애플리케이션입니다. 그 외에는 `null`입니다. |
| `serviceAccountId` | 토큰이 대신 동작하는 서비스 계정입니다. 해당 계정이 없으면 `null`입니다. |
| `expiresAt` | 만료되지 않는 토큰은 `null`입니다. |
| `lastUsedAt` | 처음 사용하기 전까지는 `null`입니다. |
| `revoked` | 토큰을 폐기하면 `true`입니다. |

## 내 토큰

```http
GET /api/v1/me/api-tokens
```

로그인한 사용자의 개인 토큰과 기본 수집 토큰을 동일한 필드로 반환합니다. 이 호출은 로그인한 세션에서 이루어지며 `personal_tokens.manage` 권한이 필요합니다.
