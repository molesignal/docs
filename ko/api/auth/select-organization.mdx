```http
POST /api/v1/orgs/{id}/select
```

로그인된 브라우저 세션을 계정이 속한 다른 조직으로 전환합니다. 응답은 선택한 조직에 맞게 세션 쿠키를 갱신하며, 세션 만료 시각은 그대로 유지됩니다. 쿠키에 대한 자세한 내용은 [로그인](/ko/api/auth/login)을 참조합니다. 세션으로만 조직을 전환할 수 있습니다. API 토큰을 사용하면 `403`을 반환합니다. 플랫폼 관리자는 보호된 `_sys` 조직을 선택할 수 있습니다. [JWT 서명 키 교체](/ko/api/auth/rotate-jwt)와 같은 플랫폼 전체 API 호출에는 이 조직이 필요합니다. `_sys`에서의 세션은 해당 조직으로 전환한 후 1시간 이내에 종료됩니다.

**경로 매개변수**

| 매개변수 | 유형 | 참고 |
|---|---|---|
| `id` | string | `GET /api/v1/orgs`에서 반환하는 조직 ID입니다. |

<RequestExample>
```bash cURL
curl -b ms-cookies.txt -c ms-cookies.txt \
  -X POST http://localhost:5080/api/v1/orgs/<organization-id>/select
```
</RequestExample>

<ResponseExample>
```json 200
{
  "userId": "<user-id>",
  "orgId": "<organization-id>",
  "orgName": "default",
  "displayRole": "Owner",
  "roles": [
    { "id": "<role-id>", "key": "owner", "name": "Owner", "builtin": true }
  ],
  "system": false
}
```
</ResponseExample>

같은 브라우저의 탭은 쿠키를 공유하므로 열려 있는 모든 탭이 선택한 조직으로 전환됩니다.

## 로그인 요구 사항

현재 로그인이 조직의 [로그인 요구 사항](/ko/identity/sso#로그인-요구-사항)을 충족하지 않아도 `200`을 반환합니다. 새 쿠키는 발급하지 않으며, 응답에 충족하지 못한 요구 사항을 표시합니다.

| 응답 | 의미 |
|---|---|
| `{"mfa": {"organization_name", "methods"}}` | 두 번째 인증 요소를 즉시 확인합니다. 요청 본문에 `{"proof": {…}}`를 포함해 다시 전송합니다. `proof`에는 `method`가 `totp` 또는 `recovery_code`인 경우 `code`를 함께 지정합니다. `method`가 `passkey`인 경우 `POST /api/v1/me/mfa/passkey-proof`에서 받은 `ceremony`와 `credential`을 함께 지정합니다. |
| `{"mfaSetup": {"organization_name"}}` | 계정에 두 번째 인증 요소가 없습니다. 먼저 `/api/v1/me/mfa` 또는 `/api/v1/me/passkeys`에서 설정합니다. |
| `{"sso": {"organization_name", "providers"}}` | 조직의 싱글 사인온(SSO)으로만 로그인할 수 있습니다. `providers`에는 `id`, `name`, `kind`, `platform`이 포함됩니다. |
