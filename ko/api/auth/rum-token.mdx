```http
GET /api/v1/auth/tokens/rum?applicationId=<id>
```

[RUM 애플리케이션](/ko/rum/applications)의 RUM 클라이언트 토큰을 반환하며, 최초 호출 시 토큰을 생성합니다. 애플리케이션이 먼저 존재해야 하므로 미리 생성합니다. 토큰은 `mspat-<36>` 형식이며, 호출자가 아닌 애플리케이션에 속합니다. 해당 애플리케이션에 대한 `rum.write` 권한만 가지며, 다른 리소스에는 액세스할 수 없고 만료되지 않습니다. 최종 사용자가 읽을 수 있는 브라우저 또는 모바일 코드에 토큰을 삽입합니다. 호출하려면 `api_tokens.issue` 권한이 필요합니다.

**쿼리 파라미터**

| 파라미터 | 유형 | 필수 | 참고 |
|---|---|---|---|
| `applicationId` | 문자열 | 예 | 워크스페이스에 속한 애플리케이션의 식별자입니다. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/auth/tokens/rum?applicationId=checkout-web" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KDZpGNwn5vO9dhXyE3am4qhihX",
  "prefix": "c16jb8m5zr",
  "token": "mspat-c16jb8m5zr<secret>",
  "tokenKind": "rum_client",
  "policyId": null,
  "permissions": ["rum.write"],
  "applicationId": "checkout-web",
  "createdAt": 1790000000000000
}
```
</ResponseExample>

`applicationId`가 유효한 식별자가 아니면 `400`을 반환하고, 해당 식별자를 가진 애플리케이션이 없으면 `404`를 반환합니다. SDK에서도 `applicationId`에 동일한 식별자를 사용합니다. [RUM 애플리케이션](/ko/rum/applications#클라이언트-토큰)을 참조합니다.
