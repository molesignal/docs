```http
DELETE /api/v1/auth/tokens/{id}
```

조직의 토큰을 즉시 폐기합니다. 이후 해당 토큰을 사용한 요청은 `401` 상태 코드와 `api token revoked` 메시지를 반환합니다. 이 호출에는 `api_tokens.revoke` 권한이 필요합니다.

**경로 매개변수**

| 매개변수 | 유형 | 설명 |
|---|---|---|
| `id` | 문자열 | 토큰을 발급하거나 목록을 조회할 때 반환된 `id`입니다. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

존재하지 않는 ID를 지정하면 `404`를 반환합니다. 데이터 전송에 사용하는 토큰을 폐기하면 전송이 중단되므로, 전송 측에서 먼저 토큰을 교체합니다.

## 본인 토큰

```http
DELETE /api/v1/me/api-tokens/{id}
```

본인의 개인 토큰 하나 또는 기본 수집 토큰을 폐기합니다. 로그인한 세션에서 호출해야 하며 `personal_tokens.manage` 권한이 필요합니다. 본인 소유가 아닌 토큰을 지정하면 `404`를 반환합니다.
