```http
GET /api/v1/alerts/routing/teams
```

조직의 팀을 이름순으로 나열합니다(대소문자 구분 없음). 각 팀의 [온콜 정책](/ko/alerting/routing#팀별-온콜-정책)과 APM 서비스 카탈로그에서 해당 팀이 소유한 서비스를 함께 반환합니다. `alerts.routing.read` 권한이 필요합니다.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/teams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "teamId": "<team-id>",
    "name": "Payments",
    "memberCount": 4,
    "escalationPolicyId": "<policy-id>",
    "services": ["default/checkout", "default/cart"]
  }
]
```
</ResponseExample>

| 필드 | 설명 |
|---|---|
| `teamId`, `name` | 팀의 ID와 이름입니다. |
| `memberCount` | 팀의 구성원 수입니다. |
| `escalationPolicyId` | 팀의 온콜 정책입니다. 설정된 정책이 없으면 `null`이며, 해당 팀으로 라우팅된 인시던트에는 기본 정책이 적용됩니다. |
| `services` | 서비스 카탈로그에 해당 팀의 서비스로 등록되어 있고 보관 처리되지 않은 서비스입니다. `namespace/name` 형식으로 표시합니다. |
