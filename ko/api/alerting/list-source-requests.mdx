```http
GET /api/v1/alerts/sources/{id}/requests
```

[알림 소스](/ko/alerting/sources)가 최근에 받은 요청을 최신순으로 반환합니다. `alerts.sources.read` 권한이 필요합니다. 각 소스의 최근 요청 500개를 해당 요청을 처리한 클러스터에 최대 7일간 보관합니다.

**쿼리 매개변수**

| 매개변수 | 유형 | 설명 |
|---|---|---|
| `limit` | 정수 | 반환할 요청 수입니다. 1~200 사이의 값을 지정합니다. 기본값은 50입니다. |

| 필드 | 설명 |
|---|---|
| `receivedAt` | 요청을 받은 시각입니다. 단위는 마이크로초입니다. |
| `viaCluster` | 요청을 전달한 페더레이션 클러스터입니다. 이 클러스터가 요청을 직접 받았다면 비어 있습니다. |
| `status` | 요청 상태입니다. 수락(`accepted`), 거부(`rejected`), 수신 클러스터로 전달(`forwarded`) 중 하나입니다. |
| `httpStatus` | 발신자에게 반환한 HTTP 상태 코드입니다. |
| `message` | 요청을 거부했거나 아무 작업도 수행하지 않은 이유입니다. |
| `alertCount` | 요청에 포함된 알림 수입니다. |
| `alerts` | 최대 100개 알림의 작업, 중복 제거 키, 제목, 심각도, 처리 결과([알림 전송](/ko/api/alerting/send-alerts) 참조), 사유, 인시던트 ID입니다. |
| `bodyExcerpt` | 거부된 요청 본문의 앞부분입니다. 최대 16 KiB입니다. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/requests?limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>
