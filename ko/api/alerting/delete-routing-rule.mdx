```http
DELETE /api/v1/alerts/routing/rules/{id}
```

[라우팅 규칙](/ko/alerting/routing#라우팅-규칙)을 삭제합니다. `alerts.routing.manage` 권한이 필요합니다. 삭제한 규칙에 일치했을 새 인시던트는 뒤에 있는 규칙에 따라 라우팅합니다. 이미 열려 있는 인시던트는 열릴 때 적용된 라우팅과 기록된 규칙 이름을 그대로 유지합니다.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/routing/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "deleted": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1" }
```
</ResponseExample>

**오류**

| 상태 | 원인 |
|---|---|
| `403` | 토큰에 `alerts.routing.manage` 권한이 없습니다. |
| `404` | 규칙이 없거나 다른 조직에 속합니다. |
