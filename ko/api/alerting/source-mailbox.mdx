```http
GET    /api/v1/alerts/sources/{id}/mailbox
PUT    /api/v1/alerts/sources/{id}/mailbox
DELETE /api/v1/alerts/sources/{id}/mailbox
POST   /api/v1/alerts/sources/{id}/mailbox/test
```

[이메일 소스](/ko/alerting/sources#이메일)가 읽는 IMAP 메일함입니다. 읽으려면 `alerts.sources.read` 권한이 필요하고, 변경하거나 테스트하려면 `alerts.sources.manage` 권한이 필요합니다. `email` 유형의 소스만 IMAP 메일함을 사용합니다. 소스가 이메일을 수신하는 클러스터에서 메일함을 설정하며, 페더레이션을 통해 동기화하지 않습니다. `PUT`을 호출하기 전에 소스에 발신자 목록(`email.allowed_senders`)을 설정합니다.

**`PUT` 및 `test` 요청 본문**

| 필드 | 유형 | 설명 |
|---|---|---|
| `host` | 문자열 | 필수: 스킴과 포트를 제외한 호스트 이름입니다. |
| `port` | 정수 | 기본값은 993입니다. |
| `security` | 문자열 | `tls`(기본값), `starttls` 또는 `none`입니다. |
| `username` | 문자열 | 필수입니다. |
| `secret` | 문자열 | 비밀번호 또는 클라이언트 시크릿입니다. 응답에 포함하지 않으며, 빈 값을 보내면 기존 값을 유지합니다. |
| `auth` | 객체 | 기본값은 `{"kind": "password"}`입니다. 클라이언트 자격 증명으로 발급받은 토큰을 `XOAUTH2`로 사용하려면 `{"kind": "oauth2", "tokenUrl": "https://…", "clientId": "…", "scope": "…"}`를 지정합니다. |
| `folder` | 문자열 | 기본값은 `INBOX`입니다. |
| `pollSecs` | 정수 | 메일함을 읽는 간격(초)입니다. 범위는 15~3600이며, 기본값은 60입니다. |

연결 시점에 호스트 이름을 확인하여 얻은 주소에만 연결하며, 클라우드 메타데이터 주소에는 연결하지 않습니다. 호스트, 계정 또는 폴더를 변경하면 다음 연결부터 읽기 위치를 초기화합니다.

**`GET` 및 `PUT` 응답** (설정이 없으면 `GET`은 `null`을 반환합니다)

| 필드 | 설명 |
|---|---|
| `settings` | 위 설정에서 `secret`을 제외한 값입니다. |
| `secretSet` | 시크릿을 설정했는지 나타냅니다. |
| `reading` | 연결에 성공했으며, 연결 이후 도착하는 메일을 읽고 있음을 나타냅니다. |
| `lastPolledAt`, `lastSuccessAt` | 각각 마지막 읽기 시도 시각과 마지막으로 읽기에 성공한 시각입니다(마이크로초). |
| `lastError` | 마지막 읽기 실패 원인입니다. 읽기에 성공하면 이 값을 지웁니다. |

`test`는 요청 본문의 설정으로 한 번 연결합니다(`secret`이 비어 있으면 저장된 값을 사용합니다). 성공하면 `{"ok": true, "messages": 3}`을 반환하고, 실패하면 메일 서버의 응답과 함께 `503`을 반환합니다.

<RequestExample>
```bash cURL
curl -X PUT "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/mailbox" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"host": "imap.example.com", "username": "alerts@example.com", "secret": "<password>"}'
```
</RequestExample>
