```http
POST /api/v1/alerts/incidents/{id}/snooze
DELETE /api/v1/alerts/incidents/{id}/snooze
```

`POST`는 활성 인시던트를 `durationSecs`초 동안 일시 중지합니다. 인시던트가 `open` 상태라면
호출자가 먼저 확인 처리합니다. 일시 중지 중에는 알림을 보내거나 에스컬레이션하지 않습니다.
`snoozedUntil`이 지나면 인시던트가 `open` 상태로 돌아가고, 담당자는
`escalation.reason`이 `snooze_ended`인 에스컬레이션 알림을 받습니다. 일시 중지된 인시던트를 다시 일시 중지하면 종료 시각을 새로 설정합니다.

`DELETE`는 일시 중지를 즉시 종료하며, 인시던트는 `acknowledged` 상태를 유지합니다. 두 호출 모두
`alerts.incidents.acknowledge` 권한이 필요하며, `DELETE`에는 요청 본문이 없습니다.

**본문**

| 필드 | 유형 | 필수 | 참고 |
|---|---|---|---|
| `durationSecs` | 정수 | 예 | 60(1분)~604800(7일)입니다. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/snooze \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"durationSecs": 3600}'
```
</RequestExample>

응답으로 업데이트된 인시던트를 반환합니다. 각 필드에 대한 설명은 [인시던트 목록 조회](/ko/api/alerting/list-incidents)를 참조합니다.

**오류**

| 상태 | 원인 |
|---|---|
| `400` | `durationSecs`가 60 미만이거나 604800을 초과합니다. |
| `403` | 토큰에 `alerts.incidents.acknowledge` 권한이 없거나 토큰으로 해당 인시던트에 접근할 수 없습니다. |
| `404` | 인시던트가 존재하지 않습니다. |
| `409` | 인시던트가 복구되었거나 다른 인시던트에 병합되었거나 업데이트 중 계속 변경되었습니다. 다시 시도합니다. |
