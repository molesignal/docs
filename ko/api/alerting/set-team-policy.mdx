```http
PUT /api/v1/alerts/routing/teams/{teamId}
```

팀의 [온콜 정책](/ko/alerting/routing#팀별-온콜-정책)을 설정하거나 제거합니다. `alerts.routing.manage` 권한이 필요합니다. 팀으로 라우팅되는 새 인시던트는 이 정책에 따라 에스컬레이션됩니다. 팀에 온콜 정책이 없으면 기본 정책을 적용합니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| `escalationPolicyId` | string \| null | 조직의 에스컬레이션 정책 ID입니다. `null`을 지정하거나 필드를 생략하면 팀의 온콜 정책을 제거합니다. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/teams/$TEAM_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"escalationPolicyId": "<policy-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "teamId": "<team-id>", "escalationPolicyId": "<policy-id>" }
```
</ResponseExample>

**오류**

| 상태 | 원인 |
|---|---|
| `400` | 팀이 존재하지 않거나 다른 조직에 속해 있거나, 에스컬레이션 정책이 존재하지 않습니다. |
| `403` | 토큰에 `alerts.routing.manage` 권한이 없습니다. |
| `422` | 다른 필드를 지정했습니다. 응답은 일반 텍스트 형식입니다. |
