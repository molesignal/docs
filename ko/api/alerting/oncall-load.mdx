```http
GET /api/v1/alerts/insights/oncall-load
```

지정된 기간의 담당자별 온콜 부하를 측정하고, 알림이 많은 순으로 정렬합니다. 이 API를 호출하려면
`alerts.incidents.read` 권한이 필요합니다.

알림은 담당자에게 전달된 경보 발생 알림 또는 에스컬레이션 알림입니다. 알림 하나당 담당자별로
한 번만 집계하며, 전송에 실패한 알림은 제외합니다. 야간은 현지 시간으로 22:00부터 다음 날 08:00까지이며,
주말은 현지 시간으로 토요일과 일요일입니다. 현지 시간에는 담당자의 스케줄에 설정된 시간대를 적용합니다. 스케줄이
없으면 담당자의 [알림 제한 시간](/ko/account#알림)에 설정된 시간대를 적용하고, 둘 다 없으면 UTC를 적용합니다.
자정 이후 야간에 받은 알림은 전날 밤에 포함합니다.

**쿼리 매개변수**

| 매개변수 | 유형 | 설명 |
|---|---|---|
| `windowSecs` | 정수 | 현재 시점부터 거슬러 올라갈 기간(초)입니다. 기본값은 `2592000`(30일)이며, 1일에서 90일 사이로 제한합니다. |
| `scheduleId` | 문자열 | 이 스케줄에 속한 담당자와 근무 시간만 집계합니다. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/insights/oncall-load?windowSecs=604800" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**응답**

| 필드 | 설명 |
|---|---|
| `windowSecs` | 허용 범위를 적용한 조회 기간입니다. |
| `nightStartHour`, `nightEndHour` | 야간의 시작 시각과 종료 시각입니다. |
| `people[].oncall_secs` | 조회 기간에 스케줄에 따라 온콜을 맡은 시간(초)입니다. 근무 재지정과 교대를 포함합니다. |
| `people[].pages` | 수신한 경보 알림 수입니다. |
| `people[].night_pages`, `people[].weekend_pages` | 각각 야간과 주말에 수신한 경보 알림 수입니다. |
| `people[].interrupted_nights` | 알림을 한 건 이상 받은 야간의 횟수입니다. |
| `people[].timezone` | 야간과 주말을 판정하는 데 사용한 시간대입니다. |
| `people[].responded`, `people[].mtta_secs` | 조회 기간에 해당 담당자가 최초로 대응을 맡은 인시던트 수와 인시던트 발생부터 대응을 맡기까지 걸린 평균 시간(초)입니다. 대응을 맡은 건수는 [인시던트 인사이트](/ko/api/alerting/insights)와 같은 기준으로 집계합니다. |
