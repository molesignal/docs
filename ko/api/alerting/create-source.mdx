```http
POST /api/v1/alerts/sources
```

[알림 소스](/ko/alerting/sources)를 생성합니다. `alerts.sources.manage` 권한이 필요합니다. 응답의 `token`은 이때 한 번만 표시되며, [알림 전송](/ko/api/alerting/send-alerts)을 호출할 때 사용합니다. 페더레이션이 켜져 있으면 소스가 다른 클러스터로 동기화됩니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| `kind` | string | 생성 시 필수: `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` 또는 `email`. |
| `name` | string | 필수이며, 최대 128자입니다. |
| `enabled` | boolean | 기본값은 `true`입니다. |
| `escalationPolicyId` | string \| null | 조직의 에스컬레이션 정책 ID 또는 `default`입니다. 이 값이 없거나 `null`이면 에스컬레이션이 진행되지 않고 알림 정책만 알림을 보냅니다. |
| `severity` | string | 알림에 심각도가 없을 때 사용됩니다: `critical`, `error`, `warning`(기본값) 또는 `info`. |
| `labels` | object | 최대 32개의 추가 레이블입니다. 키는 영문자, 숫자 및 `_ . - : /`로 구성되며, `alert.`로 시작할 수 없고 `external.kind`일 수 없습니다. |
| `email` | object | 이메일 소스가 메일을 읽는 방식입니다: `allowedSenders`(주소, `@domain` 또는 `*`), `resolvePattern`, `dedupPattern`, `ignorePattern`이며, 자세한 내용은 [이메일](/ko/alerting/sources#이메일)을 참조하세요. 업데이트 시 생략하면 기존 값이 그대로 유지됩니다. |
| `homeCluster` | string | 인시던트가 열리는 페더레이션 클러스터입니다: 이 클러스터 또는 활성화된 원격 클러스터입니다. 이 값이 없는 새 소스는 이 클러스터를 사용하며, 페더레이션이 없으면 아무 효과가 없습니다. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

응답은 `token`이 포함된 소스입니다. 나머지 필드는 [알림 소스 목록](/ko/api/alerting/list-sources)에서 설명합니다.

**오류**

| 상태 | 원인 |
|---|---|
| `400` | 필드가 잘못된 경우입니다. 예를 들어 이름이 비어 있거나, 존재하지 않는 에스컬레이션 정책을 지정했거나, 수신 클러스터가 이 클러스터도 활성화된 원격 클러스터도 아닌 경우입니다. |
| `403` | 토큰에 `alerts.sources.manage` 권한이 없습니다. |
