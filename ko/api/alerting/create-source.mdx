```http
POST /api/v1/alerts/sources
```

[알림 소스](/ko/alerting/sources)를 생성합니다. `alerts.sources.manage` 권한이 필요합니다. 응답의 `token`은 이때 한 번만 표시됩니다. 이 토큰으로 [알림 전송](/ko/api/alerting/send-alerts) API를 호출합니다. 페더레이션을 활성화하면 소스를 다른 클러스터에 동기화합니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| `kind` | string | 생성 시 필수입니다. `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `email` 중 하나를 지정합니다. |
| `name` | string | 필수이며 최대 128자입니다. |
| `enabled` | boolean | 기본값은 `true`입니다. |
| `escalationPolicyId` | string \| null | 조직의 에스컬레이션 정책 ID 또는 `default`를 지정합니다. 생략하거나 `null`을 지정하면 에스컬레이션하지 않으며 알림 정책으로만 통지합니다. |
| `severity` | string | 알림에 심각도가 없을 때 적용합니다. `critical`, `error`, `warning`(기본값), `info` 중 하나를 지정합니다. |
| `labels` | object | 추가 라벨을 최대 32개 지정합니다. 키에는 문자, 숫자, `_ . - : /`만 사용할 수 있습니다. 키는 `alert.`로 시작할 수 없으며 `external.kind`를 키로 사용할 수 없습니다. |
| `email` | object | 이메일 소스의 메일 처리 방식을 설정합니다. `allowedSenders`(이메일 주소, `@domain` 또는 `*`), `resolvePattern`, `dedupPattern`, `ignorePattern`을 지정합니다. 자세한 내용은 [이메일](/ko/alerting/sources#이메일)을 참조합니다. 업데이트 시 생략하면 기존 설정을 유지합니다. |
| `homeCluster` | string | 인시던트를 생성할 페더레이션 클러스터입니다. 현재 클러스터 또는 활성화된 원격 클러스터를 지정합니다. 소스를 생성할 때 생략하면 현재 클러스터를 사용합니다. 페더레이션을 사용하지 않으면 이 설정은 적용되지 않습니다. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

응답은 `token`이 포함된 소스 객체를 반환합니다. 나머지 필드는 [알림 소스 목록 조회](/ko/api/alerting/list-sources)에서 확인합니다.

**오류**

| 상태 | 원인 |
|---|---|
| `400` | 필드 값이 잘못되었습니다. 예를 들어 이름이 비어 있거나, 존재하지 않는 에스컬레이션 정책을 지정했거나, 수신 클러스터가 현재 클러스터도 활성화된 원격 클러스터도 아닌 경우입니다. |
| `403` | 토큰에 `alerts.sources.manage` 권한이 없습니다. |
