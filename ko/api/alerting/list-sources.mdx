```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

첫 번째 호출은 조직의 [알림 소스](/ko/alerting/sources) 목록을 반환하고, 두 번째 호출은 소스 하나를 반환합니다. 세 번째 호출은 이 클러스터의 페더레이션 ID(페더레이션에 속하면 `local`, 속하지 않으면 빈 값)와 소스가 수신 클러스터로 선택할 수 있는 클러스터 목록을 반환합니다. 세 호출 모두 `alerts.sources.read` 권한이 필요합니다. API는 토큰이나 토큰 해시를 반환하지 않습니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| `id` | string | 소스 ID입니다. |
| `name` | string | 이름입니다. |
| `kind` | string | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix` 또는 `email`입니다. |
| `enabled` | boolean | 비활성화된 소스는 알림을 거부합니다. |
| `escalationPolicyId` | string \| null | 이 소스에서 생성한 인시던트에 적용할 에스컬레이션 정책입니다. `default`는 기본 정책을 적용하고, `null`은 에스컬레이션 없이 알림만 전송합니다. |
| `severity` | string | 알림에 심각도가 없을 때 적용할 심각도입니다. |
| `labels` | object | 이 소스에서 생성하는 모든 인시던트에 추가할 레이블입니다. |
| `tokenPrefix` | string | 토큰 접두사 `mspat-<10>`입니다. 전체 토큰은 생성 또는 교체 시 한 번만 반환합니다. |
| `homeCluster` | string | 이 소스의 인시던트를 생성하는 페더레이션 클러스터입니다. 이 클러스터에서 생성하면 빈 값입니다. |
| `intakePath` | string | 수신 주소의 경로입니다. 모든 소스에서 동일합니다. |
| `lastIntakeAt` | integer \| null | 이 클러스터가 이 소스에서 마지막으로 요청을 받은 시각입니다. 단위는 마이크로초입니다. |
| `createdBy`, `createdAt`, `updatedAt` | | 생성자, 생성 시각, 마지막 변경 시각입니다. 시각의 단위는 마이크로초입니다. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

소스가 수신 클러스터로 선택할 수 있는 클러스터 목록입니다.

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
