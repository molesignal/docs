```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

첫 번째 호출은 조직의 [알림 소스](/ko/alerting/sources)를 나열하고, 두 번째 호출은 소스 하나를 반환하며, 세 번째 호출은 이 클러스터의 페더레이션 ID(`local`, 페더레이션이 없으면 비어 있음)와 소스가 수신 클러스터로 선택할 수 있는 클러스터를 반환합니다. 세 호출 모두 `alerts.sources.read` 권한이 필요합니다. API는 토큰이나 토큰의 해시를 절대 반환하지 않습니다.

| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | string | 소스 ID입니다. |
| `name` | string | 이름입니다. |
| `kind` | string | `api`, `alertmanager`, `grafana`, `datadog`, `pagerduty`, `aliyun_cms`, `tencent_monitor`, `aws_cloudwatch`, `zabbix`, `azure_monitor`, `gcp_monitoring`, `huawei_ces` 또는 `email`입니다. |
| `enabled` | boolean | 꺼진 소스는 알림을 거부합니다. |
| `escalationPolicyId` | string \| null | 인시던트가 따르는 에스컬레이션 정책입니다. `default`는 기본 정책이며, `null`이면 아무것도 에스컬레이션하지 않고 알림만 보냅니다. |
| `severity` | string | 알림에 심각도가 없을 때 사용합니다. |
| `labels` | object | 해당 소스가 여는 모든 인시던트에 추가되는 레이블입니다. |
| `tokenPrefix` | string | 토큰 접두사 `mspat-<10>`입니다. 전체 토큰은 생성 및 교체 시 한 번만 반환됩니다. |
| `homeCluster` | string | 인시던트가 열리는 페더레이션 클러스터입니다. 이 클러스터이면 비어 있습니다. |
| `intakePath` | string | 수신 주소의 경로이며, 모든 소스에서 동일합니다. |
| `lastIntakeAt` | integer \| null | 이 클러스터가 해당 소스로부터 마지막으로 요청을 받은 시각이며, 마이크로초 단위입니다. |
| `createdBy`, `createdAt`, `updatedAt` | | 누가 언제 생성했는지, 그리고 언제 마지막으로 변경되었는지이며, 마이크로초 단위입니다. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

소스가 수신 클러스터로 선택할 수 있는 클러스터는 다음과 같습니다.

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
