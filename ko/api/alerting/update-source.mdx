```http
PUT /api/v1/alerts/sources/{id}
```

[알림 소스](/ko/alerting/sources)의 설정 전체를 다시 저장합니다. `alerts.sources.manage` 권한이 필요합니다. 필드는 [알림 소스 생성](/ko/api/alerting/create-source)과 동일합니다. 유형은 변경할 수 없으므로 `kind`를 지정할 경우 현재 값과 일치해야 합니다. 기존 토큰은 유지됩니다. 토큰을 변경하려면 [토큰 교체](/ko/api/alerting/rotate-source-token)를 사용합니다. `homeCluster`를 지정하지 않으면 기존 수신 클러스터를 유지합니다. 이미 열려 있는 인시던트는 기존 에스컬레이션 정책과 레이블을 유지합니다.

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"name": "Production Prometheus", "enabled": false, "escalationPolicyId": "default", "severity": "error"}'
```
</RequestExample>

응답은 업데이트된 소스를 반환하며 `token`은 포함하지 않습니다.

**오류**

| 상태 | 원인 |
|---|---|
| `400` | 필드가 잘못되었거나 유형이 변경되었습니다. |
| `403` | 토큰에 `alerts.sources.manage` 권한이 없습니다. |
| `404` | 소스가 존재하지 않습니다. |
