```http
DELETE /api/v1/alerts/sources/{id}
```

[알림 소스](/ko/alerting/sources)를 삭제합니다. `alerts.sources.manage` 권한이 필요합니다. 소스의 토큰은 즉시 작동을 멈추며, 소스가 최근에 수신한 요청도 함께 삭제됩니다. 소스를 삭제하면 복구 알림을 받을 수 없으므로, 해당 소스의 미해결 인시던트는 API를 호출한 사용자 명의로 해결 처리합니다. 페더레이션을 활성화한 경우, 삭제가 동기화되면 다른 클러스터도 각 클러스터에 있는 해당 소스의 미해결 인시던트를 해결 처리합니다.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

성공하면 상태 코드 `200`과 텍스트 `deleted`를 반환합니다.

**오류**

| 상태 | 원인 |
|---|---|
| `403` | 토큰에 `alerts.sources.manage` 권한이 없습니다. |
| `404` | 소스가 존재하지 않습니다. |
