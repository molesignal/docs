```http
PUT /api/v1/alerts/routing/rules/order
```

조직의 [라우팅 규칙](/ko/alerting/routing#라우팅-규칙)을 지정한 순서로 재정렬합니다. `alerts.routing.manage` 권한이 필요합니다. 목록에 지정한 규칙을 해당 순서대로 앞에 배치하고, 나머지 규칙은 기존 순서를 유지한 채 뒤에 배치합니다. 조직의 규칙에 해당하지 않는 ID는 무시합니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| `ids` | 배열 | 필수 항목입니다. 규칙 ID 목록이며, 첫 번째 ID의 규칙부터 평가합니다. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/rules/order \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"ids": ["<rule-id-2>", "<rule-id-1>"]}'
```
</RequestExample>

응답은 모든 규칙을 새 순서대로 반환하며, `position` 값은 0부터 빠짐없이 부여합니다. [규칙 필드](/ko/api/alerting/list-routing-rules#규칙-필드)를 참조합니다.

**오류**

| 상태 | 원인 |
|---|---|
| `403` | 토큰에 `alerts.routing.manage` 권한이 없습니다. |
| `422` | `ids`를 누락했거나 다른 필드를 지정했습니다. 응답은 일반 텍스트입니다. |
