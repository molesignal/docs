```http
GET /api/v1/alerts/incidents/{id}/rca
POST /api/v1/alerts/incidents/{id}/rca
```

[Mole Agent](/ko/agent)는 인시던트의 컨텍스트를 바탕으로 근본 원인 분석(RCA)을 작성합니다. 인시던트마다 분석을 최대 하나만 저장합니다.

`alert` 역할은 분석을 자동으로 생성합니다. 조직에서 API 키가 설정된 모델 공급자를 활성화한 경우, 이 역할은 3분마다 아직 분석이 없는 활성 인시던트를 최대 20건까지 분석합니다. `GET` 호출은 저장된 분석을 조회합니다. `POST` 호출은 즉시 새 분석을 생성하고 저장된 분석을 대체합니다.

| 호출 | 권한 | 참고 |
|---|---|---|
| `GET` | `alerts.incidents.read` | 분석이 생성되기 전까지 `404` 상태 코드와 `no root-cause analysis for this incident yet` 메시지를 반환합니다. |
| `POST` | `alerts.incidents.rca` | 모델의 응답을 기다린 후 새 분석을 반환합니다. 선택적 쿼리 파라미터 `locale`로 출력 언어를 `en-us` 또는 `zh-cn`으로 지정합니다. 기본값은 호출자의 언어 설정입니다. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/rca?locale=en-us" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**응답**

| 필드 | 참고 |
|---|---|
| `incidentId`, `orgId` | 인시던트와 조직의 식별자입니다. |
| `summary` | Markdown 형식의 분석 텍스트입니다. |
| `provider`, `model` | `openai`, `anthropic`, `openai_compatible` 등의 모델 공급자 유형과 모델 이름입니다. |
| `promptBuiltinKey`, `promptHash` | 감사에 사용하는 프롬프트 템플릿과 렌더링된 프롬프트의 해시입니다. |
| `promptTokens`, `completionTokens`, `finishReason` | 공급자가 보고하는 토큰 사용량과 생성 종료 사유입니다. |
| `createdAt`, `updatedAt` | Unix 에포크 이후 경과한 시간을 마이크로초 단위로 나타냅니다. 분석을 다시 생성하면 `updatedAt`이 변경됩니다. |

**오류**

| 상태 | 원인 |
|---|---|
| `400` | `POST` 호출에서 해당 조직에 활성화된 모델 공급자 중 API 키가 설정된 공급자를 찾지 못했습니다. |
| `403` | 토큰에 호출에 필요한 권한이 없습니다. |
| `404` | 인시던트가 없거나 `GET` 호출에서 아직 저장된 분석을 찾지 못했습니다. |
