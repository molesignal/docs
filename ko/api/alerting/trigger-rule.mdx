```http
POST /api/v1/alerts/rules/{id}/trigger
```

조건을 평가하지 않고 규칙의 인시던트를 엽니다. 알림과 에스컬레이션을 테스트하거나 인시던트를 수동으로 생성하려면 이 API를 호출합니다. 비활성화된 규칙에도 호출할 수 있습니다. `alerts.rules.manage` 권한이 필요하며 요청 본문은 비워 둡니다.

- 규칙에 이미 열려 있거나 확인된 인시던트가 있으면 해당 인시던트를 변경하지 않고 반환합니다. 여러 번 호출해도 안전합니다.
- 그 외에는 상태가 `open`인 인시던트를 생성하고 인시던트 트리거 알림 이벤트를 전송합니다.
- 심각도는 규칙의 `severity`, `severity` 레이블, `warning` 순으로 적용합니다. 이 호출은 `thresholds`를 무시합니다.
- `manual_triggered_by` 어노테이션에는 호출한 사용자의 식별자가 저장되며, `triggering_query.sample_values`는 비어 있습니다.

활성화된 규칙은 다음 평가에서 조건이 충족되지 않으면 인시던트를 해결합니다. 비활성화된 규칙은 사용자가 해결할 때까지 인시던트를 열린 상태로 유지합니다.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/rules/$RULE_ID/trigger \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**오류**

| 상태 | 원인 |
|---|---|
| `403` | 토큰에 `alerts.rules.manage` 권한이 없습니다. |
| `404` | 규칙이 존재하지 않습니다. |
