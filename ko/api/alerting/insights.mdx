```http
GET /api/v1/alerts/insights
```

지정한 기간에 생성된 인시던트와 대응 현황을 집계합니다. 최초 인지와 복구까지 걸린 시간, 에스컬레이션된 인시던트 수를
길이가 같은 직전 기간과 비교합니다.
다른 인시던트에 병합된 인시던트는 제외합니다. 호출에는 `alerts.incidents.read` 권한이 필요합니다. 담당자별 온콜
부하는 [온콜 부하](/ko/api/alerting/oncall-load)에서 확인합니다.

**쿼리 매개변수**

| 매개변수 | 유형 | 설명 |
|---|---|---|
| `windowSecs` | 정수 | 조회할 과거 기간(초)입니다. 기본값은 `604800`(7일)입니다. 값은 3600~31536000 범위로 제한합니다. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/insights?windowSecs=86400" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**응답**

| 필드 | 설명 |
|---|---|
| `windowSecs` | 범위 제한을 적용한 조회 기간입니다. |
| `total` | 조회 기간에 생성된 인시던트 수입니다. |
| `active` | 상태가 `open` 또는 `acknowledged`인 인시던트입니다. |
| `closed` | 상태가 `resolved` 또는 `closed`인 인시던트입니다. |
| `mttrSecs` | 해결된 인시던트가 생성부터 해결까지 걸린 평균 시간(초)입니다. 해결된 인시던트가 없으면 `0`입니다. |
| `noiseRate` | 해결된 인시던트 중 60초 이내에 해결된 비율(0~1)입니다. 해결된 인시던트가 없으면 `0`입니다. |
| `byHour` | 생성 시각(UTC)을 기준으로 집계한 24개 시간대별 인시던트 수입니다. |
| `bySeverity` | 심각도별 인시던트 수입니다. 인시던트가 없는 심각도는 제외합니다. |
| `topServices`, `topRules` | `key`와 `count`로 구성된 항목을 수가 많은 순으로 최대 8개 반환합니다. 키는 서비스 이름 또는 규칙 식별자입니다. |
| `response.current`, `response.previous` | 조회 기간과 길이가 같은 직전 기간의 대응 현황입니다. 필드는 아래와 같습니다. |
| `response.breakdown` | 조회 기간의 인시던트를 팀(`teams`, 팀 ID 기준), 서비스(`services`), 담당자(`people`, 최초 인지 담당자 기준)별로 나눕니다. 각 분류에서 인시던트가 많은 순으로 최대 20개 행을 반환합니다. 여러 서비스에 해당하는 인시던트는 서비스마다 한 번씩 집계합니다. 각 행에는 인시던트 수 `incidents`, 최초 인지까지 걸린 평균 시간(초) `mttaSecs`, 복구까지 걸린 평균 시간(초) `mttrSecs`, 에스컬레이션 비율 `escalationRate`가 포함됩니다. |

**`response.current` 및 `response.previous`**

| 필드 | 설명 |
|---|---|
| `incidents` | 해당 기간에 생성된 인시던트입니다. |
| `responded` | 담당자가 인지한 인시던트입니다. 최초 인지 시점을 대응 시점으로 간주합니다. 담당자가 인지 처리 없이 해결한 경우에는 해결 시점에 집계합니다. 규칙이 자동으로 복구된 인시던트는 제외합니다. |
| `mtta` | 인시던트가 트리거된 시점부터 최초 인지까지 걸린 시간(초)입니다. 평균 `meanSecs`, 중앙값 `p50Secs`, 90번째 백분위수 `p90Secs`를 반환합니다. 인지된 인시던트가 없으면 모두 `0`입니다. |
| `mttr` | 복구된 인시던트가 트리거된 시점부터 복구까지 걸린 시간(초)입니다. 동일하게 평균, P50, P90을 반환합니다. |
| `escalationRate` | 에스컬레이션된 인시던트의 비율(0~1)입니다. 두 번째 단계에 도달했거나 [즉시 에스컬레이션](/ko/api/alerting/escalate-incident)된 인시던트를 집계합니다. |
| `steps` | 단계별 집계입니다. `step`은 0부터 시작하며, 해당 단계에 도달한 인시던트 수 `reached`와 해당 단계에서 인지된 인시던트 수 `acknowledged`를 반환합니다. 타임라인에 에스컬레이션 기록이 있는 인시던트만 집계하며, 해당 기간에 그런 인시던트가 없으면 비어 있습니다. |
| `ackVia` | 최초 인지 채널별 인시던트 수입니다. 채널은 `web`, `api`, `im`, `sms`, `phone`, `agent`입니다. |
