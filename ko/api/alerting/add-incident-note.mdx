```http
POST /api/v1/alerts/incidents/{id}/notes
```

인시던트 상태와 관계없이 [타임라인](/ko/api/alerting/incident-timeline)에 메모를 추가합니다.
Mole Agent는 인시던트와 함께 최신 메모를 읽습니다. 호출하려면 `alerts.incidents.update` 권한이 필요합니다.

**본문**

| 필드 | 유형 | 필수 | 참고 |
|---|---|---|---|
| `text` | 문자열 | 예 | 1~4,000자입니다. 앞뒤 공백은 제거합니다. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/notes \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"text": "Rolled back the edge proxy."}'
```
</RequestExample>

응답은 메모의 타임라인 항목입니다.

<ResponseExample>
```json 200
{
  "id": "3KEE1aXy7pRtGd2s9Lm4Qv8bNcE",
  "orgId": "<organization-id>",
  "incidentId": "3KEDNEyqouYJeBDTLTMTBui7XHW",
  "at": 1790000300000000,
  "kind": "note",
  "actor": "<user-id>",
  "detail": {
    "text": "Rolled back the edge proxy.",
    "via": "api"
  }
}
```
</ResponseExample>

**오류**

| 상태 | 원인 |
|---|---|
| `400` | `text`가 비어 있거나 4,000자를 초과합니다. |
| `403` | 토큰에 `alerts.incidents.update` 권한이 없거나 인시던트가 토큰의 접근 범위를 벗어납니다. |
| `404` | 인시던트가 존재하지 않습니다. |
