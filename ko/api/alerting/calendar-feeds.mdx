캘린더 앱(Google Calendar, Outlook, Apple Calendar 등)은 구독 주소를 읽습니다.
이 주소는 30일 전부터 90일 후까지의 근무 교대를 RFC 5545 iCalendar 형식으로 제공하며, 교대 재지정과 맞교대도 포함합니다.
피드에는 한 일정의 모든 근무 교대 또는 여러 일정에 걸친 구독자 본인의 근무 교대가 포함됩니다.

| 메서드 및 경로 | 기능 | 권한 |
|---|---|---|
| `GET /api/v1/schedules/calendar-feeds` | 현재 사용자의 피드를 조회합니다. | `schedules.read` |
| `POST /api/v1/schedules/calendar-feeds` | 구독 주소를 생성합니다. 같은 일정이나 개인 피드에 이미 구독 주소가 있으면 새 주소를 발급하고 기존 주소를 즉시 비활성화합니다. | `schedules.calendar_feeds.manage`, 일정 피드의 경우 해당 일정에 대한 `schedules.calendar_feeds.manage`도 필요 |
| `DELETE /api/v1/schedules/calendar-feeds/{id}` | 현재 사용자의 피드 하나를 중지하고 해당 주소를 즉시 비활성화합니다. | `schedules.calendar_feeds.manage` |
| `GET /api/v1/public/calendar/{token}.ics` | 캘린더 앱이 로그인 없이 읽는 주소입니다. | 주소에 포함된 토큰 |

## 구독 주소 생성

**요청 본문**

| 필드 | 유형 | 필수 | 참고 |
|---|---|---|---|
| `scheduleId` | 문자열 | 아니요 | 지정한 일정을 구독합니다. 개인 피드를 만들려면 이 필드를 생략합니다. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/schedules/calendar-feeds \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"scheduleId": "<schedule-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "feed": {
    "id": "3KHtq0dYc1fUe8WnP2xLbR7aZsM",
    "scheduleId": "<schedule-id>",
    "scheduleName": "Payments primary",
    "createdAt": 1790000000000000,
    "lastUsedAt": null
  },
  "path": "/api/v1/public/calendar/<token>.ics",
  "url": "https://molesignal.example.com/api/v1/public/calendar/<token>.ics"
}
```
</ResponseExample>

구독 주소는 이 응답에서 한 번만 제공하며, 토큰의 SHA-256 해시만 저장합니다. `url`은
인스턴스의 외부 주소를 기반으로 생성합니다. 외부 주소를 설정하지 않으면 `null`을 반환하므로
MoleSignal에 접속하는 주소 뒤에 `path`를 붙입니다. 목록의 각 피드에는 `id`, `scheduleId`, `scheduleName`, `createdAt`과
캘린더가 마지막으로 피드를 읽은 시각인 `lastUsedAt`이 포함되지만, 구독 주소는 포함되지 않습니다.

## 캘린더 앱이 피드를 읽는 방식

```http
GET /api/v1/public/calendar/{token}.ics
```

피드를 읽을 때마다 구독자의 계정이 여전히 활성 상태인지, 조직에 속해 있는지,
`schedules.read` 권한을 보유하고 있는지 확인합니다. 일정 피드의 경우 해당 일정을 여전히 볼 수 있는지도 확인합니다. 확인에 실패하거나 토큰이 잘못되었거나
피드가 중지된 경우 모두 `404`를 반환합니다. 근무 교대의 제목과 설명은 구독자의 인터페이스
언어로 표시합니다.

구독 주소가 있으면 누구나 이 근무 교대를 볼 수 있습니다. 주소가 유출되면 주소를 재발급하거나 피드를 중지합니다.
