```http
DELETE /api/v1/alerts/rules/{id}
```

규칙을 삭제합니다. 이 호출에는 `alerts.rules.delete` 권한이 필요합니다. 규칙이 이미 생성한 인시던트는 계속 조회할 수 있으며, 각 인시던트의 수명 주기는 규칙과 별개입니다. 삭제된 규칙은 해당 인시던트를 더 이상 해결 처리하지 않습니다.

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>

응답 본문은 일반 텍스트 `deleted`입니다. 존재하지 않는 `id`를 지정하면 `404`를 반환합니다.
