```http
POST /api/v1/alerts/sources/{id}/token
```

[알림 소스](/ko/alerting/sources)에 새 토큰을 발급합니다. `alerts.sources.manage` 권한이 필요하며 요청 본문은 비워 둡니다. 기존 토큰은 즉시 무효화됩니다. 페더레이션을 활성화한 경우 변경 사항이 동기화되면 다른 클러스터에서도 기존 토큰이 무효화됩니다. 기존 토큰을 사용하는 발신 시스템은 새 토큰으로 교체해야 합니다.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/token \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

응답은 새 `token`이 포함된 소스를 반환합니다. 새 `token`은 이 응답에서만 표시됩니다.

<ResponseExample>
```json 200

```
</ResponseExample>

**오류**

| 상태 | 원인 |
|---|---|
| `403` | 토큰에 `alerts.sources.manage` 권한이 없습니다. |
| `404` | 소스가 존재하지 않습니다. |
