```http
GET /api/v1/alerts/incidents/{id}/source
```

[알림 소스](/ko/alerting/sources)가 생성한 인시던트에 대해 소스 측에서 파악한 정보를 반환합니다. `alerts.incidents.read` 권한이 필요합니다. 이러한 인시던트에는 `alert.source=external` 라벨이 붙으며, `ruleId`는 소스의 ID입니다.

| 필드 | 설명 |
|---|---|
| `source` | [알림 소스 목록 조회](/ko/api/alerting/list-sources)와 동일한 형식의 소스 정보입니다. 소스를 삭제하면 `null`입니다. |
| `dedupKey` | 중복 제거 키입니다. |
| `lastEventAt` | 이 중복 제거 키에 대해 처리한 메시지 중 가장 최근의 발신 시각(마이크로초)입니다. 이보다 오래된 메시지는 무시합니다. API 유형에서는 `null`입니다. |
| `lastIntakeAt` | 알림을 마지막으로 수신한 시각(마이크로초)입니다. |
| `members` | Alertmanager 또는 Grafana 알림 그룹의 알림을 최대 100개까지 반환합니다. 각 알림에는 `status`(`firing` 또는 `resolved`), `labels`, `summary`, `startsAt`, `endsAt`, 발신자로 연결되는 `url`이 포함됩니다. 다른 유형에서는 비어 있습니다. |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/source \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**오류**

| 상태 | 원인 |
|---|---|
