```http
GET /api/v1/entities
GET /api/v1/entities/detail?kind={kind}&key={key}
```

엔티티는 APM이 인식하는 인스턴스와 메트릭 및 로그의 리소스 필드에서 5분마다 읽습니다. 필드와 키에
대해서는 [인프라](/ko/infrastructure)를 참조하세요. 두 호출 모두
`apm.services.read`, `metrics.read`, `logs.read`, `sys.telemetry.read` 중 하나가 필요합니다.

## 엔티티 목록 조회

| 매개변수 | 비고 |
|---|---|
| `kind` | `cluster`, `node`, `host`, `pod`, `container` 중 하나입니다. 생략하면 모든 종류입니다. |
| `search` | 이름 또는 키의 일부이며, 대소문자를 구분하지 않습니다. |
| `seenSince` | 이 시각 이후에 확인된 엔티티만 조회하며, 단위는 마이크로초입니다. |
| `limit` | 최대 500이며, 기본값입니다. |

엔티티는 가장 최근에 확인된 것부터 반환됩니다. `services`는 각 엔티티에서 직접 실행되는 서비스 수를
나타냅니다.

<ResponseExample>
```json 200
[
  {
    "kind": "pod",
    "key": "prod-eu/shop/checkout-7d9f-abcde",
    "name": "checkout-7d9f-abcde",
    "attributes": {
      "k8s.cluster.name": "prod-eu",
      "k8s.namespace.name": "shop",
      "k8s.node.name": "node-3",
      "k8s.pod.name": "checkout-7d9f-abcde"
    },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000,
    "services": 1
  }
]
```
</ResponseExample>

## 엔티티 하나 조회

`kind`와 `key`는 필수이며, key는 목록에서 제공하는 값입니다. 응답에는 엔티티, 엔티티가 실행되는
대상 또는 엔티티가 속한 대상(`parents`), 엔티티에서 실행되거나 엔티티에 속한 대상(`children`, 최대 200개), 그리고
엔티티와 엔티티에서 실행되는 대상의 서비스(`services`, 최대 200개)가 포함되며, 세 단계 아래까지 조회합니다.
클러스터의 노드, 그 노드의 파드, 그리고 그 파드의 서비스까지 살펴봅니다.

<ResponseExample>
```json 200
{
  "entity": {
    "kind": "node",
    "key": "prod-eu/node-3",
    "name": "node-3",
    "attributes": { "k8s.cluster.name": "prod-eu", "k8s.node.name": "node-3" },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000
  },
  "parents": [{ "kind": "cluster", "key": "prod-eu", "name": "prod-eu" }],
  "children": [{ "kind": "pod", "key": "prod-eu/shop/checkout-7d9f-abcde", "name": "checkout-7d9f-abcde" }],
  "services": [{ "namespace": "shop", "name": "checkout", "environment": "production" }]
}
```
</ResponseExample>

**오류**

| 상태 | 원인 |
|---|---|
| `400` | `kind`가 다섯 가지 종류 중 하나가 아닙니다. |
| `404` | 지난 일주일 동안 이 종류와 키를 가진 엔티티가 확인되지 않았습니다. |
