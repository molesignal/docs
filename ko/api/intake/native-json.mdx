```http
POST /api/v1/intake/{type}/{stream}
```

레코드 객체 하나 또는 레코드 배열을 스트림으로 전송합니다. 첫 쓰기 요청에서 스트림을 생성하고, 새 필드가 들어오면 스키마를 확장합니다. 이 호출에는 신호 유형에 따라 `logs.write`, `metrics.write` 또는 `traces.write` 권한이 필요합니다. 기본 수집 토큰이나 쓰기 역할이 부여된 서비스 계정 토큰을 사용할 수 있습니다.

**경로 매개변수**

| 매개변수 | 유형 | 참고 |
|---|---|---|
| `type` | 문자열 | `logs`, `metrics` 또는 `traces`를 지정합니다. 다른 값을 지정하면 `404`를 반환합니다. |
| `stream` | 문자열 | 문자, 숫자, `_`, `-`, `.`을 사용할 수 있는 스트림 이름입니다. `_molesignal` 또는 `_audit` 같은 [플랫폼 스트림](/ko/streams#플랫폼-스트림)을 지정하면 `403`을 반환합니다. |

**본문**

JSON 객체 또는 JSON 객체 배열을 전송합니다. 배열의 모든 요소는 객체여야 합니다. 요청 본문은 최대 16 MiB입니다. `Content-Encoding: gzip`으로 전송한 본문은 압축을 해제하며, 압축을 해제한 본문도 최대 16 MiB입니다.

| 필드 | 참고 |
|---|---|
| `_timestamp` | Unix 에포크부터 마이크로초 단위로 표시한 이벤트 시간입니다. 이 필드가 없으면 서버가 수신한 시간을 사용합니다. |
| `metric_name` | `metrics`에서 레코드가 속한 메트릭을 지정합니다. 메트릭 스트림은 단일 소스의 메트릭을 저장합니다. `metric_name`이 없는 레코드는 스트림과 이름이 같은 메트릭에 속합니다. |
| 그 외 필드 | 스트림의 필드로 저장합니다. 이후 레코드에서는 해당 필드에 대해 스트림에 이미 저장된 유형과 같은 유형을 사용해야 합니다. |

**트레이스 쓰기**

`traces`에 쓰는 스팬은 수신하는 대로 저장합니다. 이 스팬에는 [테일 샘플링](/ko/configuration#트레이스-캡처-및-테일-샘플링)을 적용하지 않으며, 트레이스 목록에서 사용하는 요약도 생성하지 않습니다. 모든 트레이스 기능을 사용하려면 [OTLP](/ko/api/intake/otlp)를 통해 스팬을 전송합니다.

| 기능 | 이 스팬의 처리 방식 |
|---|---|
| **트레이스** 페이지의 **트레이스** 탭과 해당 탭의 히스토그램 | 표시하지 않습니다. |
| Mole Agent의 `list_traces` 도구와 **RUM**의 **관련 트레이스** | 검색 결과에 포함하지 않습니다. |
| **APM** | 집계하지 않습니다. |
| **트레이스** 페이지의 **스팬** 탭과 **RED 상세 분석**, ID로 연 트레이스의 상세 정보 | 확인할 수 있습니다. |
| **서비스 그래프** | 집계합니다. |

조직에 트레이스 스트림이 여러 개 있으면 트레이스 목록과 Mole Agent는 그중 하나를 읽으며, 요약이 있는 스트림을 우선합니다. 따라서 이 엔드포인트로만 데이터를 쓴 스트림이 OTLP를 통해 데이터를 쓴 스트림을 가리지 않습니다.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/intake/logs/app \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "[{\"_timestamp\":$(date +%s)000000,\"level\":\"error\",\"msg\":\"db pool exhausted\",\"trace_id\":\"abc123\"}]"
```
</RequestExample>

<ResponseExample>
```json 200
{ "accepted": 1, "rejected": 0, "errors": [] }
```
</ResponseExample>

스키마와 충돌하는 레코드만 거부하고, 배치의 나머지 레코드는 수락합니다.

```json
{
  "accepted": 1,
  "rejected": 1,
  "errors": [
    { "index": 0, "reason": "type mismatch on field `level`: expected Utf8, got Number" }
  ]
}
```

**오류**

| 상태 | 원인 |
|---|---|
| `400` | 스트림 이름이나 JSON이 유효하지 않거나, 배열에 객체가 아닌 요소가 있습니다(`event #1 must be a JSON object`). |
| `401` | 토큰이 없거나 유효하지 않습니다. |
| `403` | 토큰에 필요한 권한이 없거나 지정한 스트림이 플랫폼 스트림입니다. |
| `413` | 압축 해제 전이나 후의 본문 크기가 16 MiB를 초과합니다. |
| `429` | 라우터의 요청 속도 제한에 도달했거나 노드의 수집 버퍼가 가득 찼습니다(`intake buffer memory limit exceeded`). 응답에 `Retry-After` 헤더가 포함됩니다. |
