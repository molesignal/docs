```http
POST /api/v1/loki/api/v1/push
```

Loki JSON 푸시 형식을 지원합니다. 호출에는 `logs.write` 권한이 필요하며, 성공하면 `204`를 반환합니다. `Content-Encoding: gzip`으로 인코딩한 요청 본문도 지원합니다.

이 엔드포인트는 JSON만 디코딩합니다. Promtail 및 Grafana Alloy처럼 snappy로 압축한 protobuf를 사용하는 전송기는 이 엔드포인트로 푸시할 수 없습니다. 대신 OpenTelemetry Collector, Vector 또는 Fluent Bit를 사용합니다.

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

각 값은 로그 이벤트 하나가 됩니다. 레이블은 필드가 되고, 로그 줄은 `message` 필드가 됩니다. 나노초 타임스탬프는 마이크로초로 변환합니다. `stream-name` 헤더로 대상 스트림을 지정하며, 기본값은 `default`입니다.

## 예제 확인

이 예제는 macOS 또는 Linux 셸에서 현재 시각의 나노초 타임스탬프를 생성합니다. `204` 응답을 받으면 **로그**를 열고 `app`과 최근 1시간을 선택한 다음, `service = 'api'`에 해당하는 `message`를 찾습니다. 과거 타임스탬프를 사용한다면 이벤트 시각이 포함된 시간 범위를 선택하고, 해당 시각이 보존 기간 내에 있는지 확인합니다.

세 항목을 구분합니다. `streams`는 Loki의 배치 구조이고, `service` 레이블은 이벤트 필드가 되며, `stream-name` 헤더는 MoleSignal의 대상 스트림을 지정합니다. 배치를 다시 보내기 전에 쿼리로 해당 스트림과 시간 범위를 확인합니다.
