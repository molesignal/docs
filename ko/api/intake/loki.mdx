```http
POST /api/v1/loki/api/v1/push
```

Loki JSON 푸시 형식을 받습니다. 이 호출에는 `logs.write`가 필요하며 성공하면 `204`로 응답합니다. 값이 해당 필드의 타입에 맞지 않아 스트림이 일부 라인을 거부하면 나머지 라인은 기록되고, 응답은 `400`이며 거부된 라인 수와 첫 번째 사유를 알려 줍니다. `Content-Encoding: gzip`이 설정된 본문도 허용합니다.

이 엔드포인트는 JSON만 디코딩합니다. Promtail, Grafana Alloy처럼 snappy로 압축된 protobuf를 사용하는 송신기는 이 엔드포인트로 푸시할 수 없습니다. 대신 OpenTelemetry Collector, Vector, Fluent Bit를 사용하십시오.

<RequestExample>
```bash cURL
LOKI_TIMESTAMP="$(date +%s)000000000"
curl -X POST http://localhost:5080/api/v1/loki/api/v1/push \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -H 'stream-name: app' \
  -d '{"streams":[{"stream":{"service":"api"},"values":[["'"$LOKI_TIMESTAMP"'","started"]]}]}'
```
</RequestExample>

각 값은 하나의 로그 이벤트가 됩니다. 레이블은 필드가 되고, 라인은 `message` 필드가 되며, 나노초 타임스탬프는 마이크로초 단위로 변환됩니다. `stream-name` 헤더는 대상 스트림을 선택하며 기본값은 `default`입니다.

## 예제 확인

예제는 macOS 또는 Linux 셸에서 현재 나노초 타임스탬프를 생성합니다. `204`를 받은 후 **로그**를 열고 `app`과 지난 1시간을 선택한 다음 `service = 'api'`에 대한 `message`를 찾으십시오. 과거 타임스탬프로 대체하는 경우 해당 이벤트 시간을 포함하는 시간 범위를 선택하고 보존 기간 내에 있는지 확인하십시오.

세 필드를 구분하십시오. `streams`는 Loki 배치 구조이고, `service` 레이블은 이벤트 필드가 되며, `stream-name` 헤더는 MoleSignal 대상 스트림을 선택합니다. 배치를 다시 보내기 전에 쿼리로 해당 스트림과 시간 범위를 확인하십시오.
