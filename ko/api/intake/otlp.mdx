OpenTelemetry SDK 또는 Collector를 MoleSignal로 지정합니다. 두 전송 방식 모두 해당 시그널의 쓰기 권한이 있는 베어러 자격 증명이 필요합니다: `logs.write`, `metrics.write`, `traces.write`.

| 전송 방식 | 엔드포인트 |
|---|---|
| HTTP를 통한 OTLP | `POST /api/v1/logs`, `POST /api/v1/metrics`, `POST /api/v1/traces` |
| gRPC를 통한 OTLP | `:4317` |

포트 `5082`는 신뢰할 수 있는 내부 클러스터 포트이며 OTLP 수신기가 아닙니다.

## HTTP를 통한 OTLP

익스포터 엔드포인트를 `/api` 기본 경로로 설정합니다. 익스포터가 `/v1/logs`, `/v1/metrics`, `/v1/traces`를 자동으로 붙입니다.

| 헤더 | 설명 |
|---|---|
| `Authorization` | `Bearer <token>`입니다. |
| `Content-Type` | `application/x-protobuf` 또는 `application/json`입니다. JSON 인코딩은 64비트 정수를 문자열로 기록하며, MoleSignal은 문자열과 숫자를 모두 읽습니다. |
| `stream-name` | 선택 사항입니다. 대상 스트림입니다. 기본값은 `default`입니다. |

본문은 압축되어서는 안 됩니다: 압축된 본문에는 `400`이 응답됩니다. 익스포터에서 압축을 비활성화합니다. 본문 크기 제한은 2 MiB입니다. 성공한 요청에는 `{"partialSuccess":null}`과 함께 `200`이 응답됩니다. 값이 해당 필드의 타입에 맞지 않아 스트림이 일부 로그 레코드나 데이터 포인트를 거부하면 나머지는 기록되며, `partialSuccess`에는 첫 번째 사유를 담은 `errorMessage`와 함께 `rejectedLogRecords` 또는 `rejectedDataPoints`가 포함됩니다. 익스포터는 이를 재시도하지 않습니다. gRPC에서도 동일한 응답이 전달됩니다.

<RequestExample>
```yaml OpenTelemetry Collector
exporters:
  otlphttp/molesignal:
    endpoint: http://localhost:5080/api
    compression: none
    headers:
      authorization: "Bearer ${env:MS_TOKEN}"
```

```bash SDK environment variables
export OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5080/api
export OTEL_EXPORTER_OTLP_HEADERS="authorization=Bearer ${MS_TOKEN}"
```
</RequestExample>

## gRPC를 통한 OTLP

`:4317`의 수신기는 TLS 없이 로그, 메트릭, 트레이스, 프로파일 서비스를 제공합니다. `authorization: Bearer <token>`과 선택 사항인 `stream-name`을 gRPC 메타데이터로 전송합니다. 신뢰할 수 있는 네트워크를 벗어나는 트래픽의 경우 포트 앞단에서 TLS를 종료합니다.

```yaml
exporters:
  otlp/molesignal:
    endpoint: localhost:4317
    tls:
      insecure: true
    headers:
      authorization: "Bearer ${env:MS_TOKEN}"
```

## 저장되는 필드

리소스 및 레코드 속성은 원래 키를 그대로 사용하여 최상위 필드가 됩니다. 로그, 스팬, 메트릭의 컬럼은 [저장되는 필드](/ko/query#저장-필드)를 참조하세요.

## 오류

| 상태 | 원인 |
|---|---|
| `400` | 압축된 본문이거나 유효한 OTLP가 아닌 본문입니다. |
| `401` | 토큰이 없거나 유효하지 않습니다. |
| `403` | 토큰에 해당 시그널의 쓰기 권한이 없거나 데이터가 [플랫폼 스트림](/ko/streams#platform-streams)으로 전송되었습니다. |
| `404` | 익스포터 엔드포인트에 `/api`가 생략되어 요청이 `/v1/logs`에 도달합니다. |
| `413` | 본문이 2 MiB를 초과합니다. |

gRPC에서는 HTTP가 `403`으로 거부하는 요청에 `PERMISSION_DENIED`로 응답합니다.
