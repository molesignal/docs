OpenTelemetry SDK 또는 Collector가 MoleSignal로 데이터를 전송하도록 설정합니다. 두 전송 방식 모두 해당 신호의 쓰기 권한(`logs.write`, `metrics.write` 또는 `traces.write`)이 있는 Bearer 토큰이 필요합니다.

| 전송 방식 | 엔드포인트 |
|---|---|
| HTTP를 통한 OTLP | `POST /api/v1/logs`, `POST /api/v1/metrics`, `POST /api/v1/traces` |
| gRPC를 통한 OTLP | `:4317` |

포트 `5082`는 신뢰할 수 있는 클러스터 내부 통신용이며 OTLP를 수신하지 않습니다.

## HTTP를 통한 OTLP

내보내기 도구의 엔드포인트를 기본 경로인 `/api`로 설정합니다. 내보내기 도구는 `/v1/logs`, `/v1/metrics`, `/v1/traces`를 자동으로 추가합니다.

| 헤더 | 참고 사항 |
|---|---|
| `Authorization` | `Bearer <token>`을 사용합니다. |
| `Content-Type` | `application/x-protobuf` 또는 `application/json`을 사용합니다. JSON 인코딩은 64비트 정수를 문자열로 표현하며, MoleSignal은 문자열과 숫자를 모두 읽을 수 있습니다. |
| `stream-name` | 선택 사항입니다. 대상 스트림을 지정합니다. 기본값은 `default`입니다. |

요청 본문을 압축하지 마세요. 본문을 압축하면 `400`을 반환합니다. 내보내기 도구에서 압축을 비활성화합니다. 본문 크기 제한은 2 MiB입니다. 요청이 성공하면 `200`과 함께 `{"partialSuccess":null}`를 반환합니다.

<RequestExample>
```yaml OpenTelemetry Collector
exporters:
  otlphttp/molesignal:
    endpoint: http://localhost:5080/api
    compression: none
    headers:
      authorization: "Bearer ${env:MS_TOKEN}"
```

```bash SDK environment variables
export OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5080/api
export OTEL_EXPORTER_OTLP_HEADERS="authorization=Bearer ${MS_TOKEN}"
```
</RequestExample>

## gRPC를 통한 OTLP

`:4317`에서 수신하는 수신기는 TLS 없이 로그, 메트릭, 트레이스, 프로파일 서비스를 제공합니다. `authorization: Bearer <token>`과 선택 사항인 `stream-name`을 gRPC 메타데이터로 전송합니다. 신뢰할 수 있는 네트워크 외부로 나가는 트래픽의 경우, 포트 앞단에서 TLS를 종료합니다.

```yaml
exporters:
  otlp/molesignal:
    endpoint: localhost:4317
    tls:
      insecure: true
    headers:
      authorization: "Bearer ${env:MS_TOKEN}"
```

## 저장 필드

리소스와 레코드의 속성은 원래 키를 유지한 채 최상위 필드에 저장됩니다. 로그, 스팬, 메트릭의 열은 [저장 필드](/ko/query#저장-필드)를 참조합니다.

## 오류

| 상태 | 원인 |
|---|---|
| `400` | 요청 본문을 압축했거나 본문이 올바른 OTLP 형식이 아닙니다. |
| `401` | 토큰이 없거나 유효하지 않습니다. |
| `403` | 토큰에 해당 신호의 쓰기 권한이 없거나 데이터를 [플랫폼 스트림](/ko/streams#플랫폼-스트림)으로 전송했습니다. |
| `404` | 내보내기 도구의 엔드포인트에 `/api`가 없어 요청이 `/v1/logs`에 도달합니다. |
| `413` | 요청 본문이 2 MiB를 초과합니다. |

HTTP에서 `403`으로 거부하는 요청은 gRPC에서 `PERMISSION_DENIED`를 반환합니다.
