```http
POST /api/v1/_bulk
```

Filebeat, Logstash, Vector의 `elasticsearch` 싱크에서 Elasticsearch `_bulk`와 호환되는 NDJSON을 수집합니다. 호출하려면 `logs.write` 권한이 필요합니다. `Content-Encoding: gzip`으로 지정된 요청 본문도 수락합니다.

| 작업 | 처리 방식 |
|---|---|
| `index`, `create`, `update` | 원본 문서를 로그 이벤트로 저장합니다. |
| `delete` | 응답 항목을 추가하지 않고 건너뜁니다. 이 엔드포인트는 텔레메트리를 삭제하지 않습니다. |

작업의 `_index`로 대상 로그 스트림을 선택합니다. `_index`가 없으면 `stream-name` 헤더를 사용하고, 헤더도 없으면 `default`를 사용합니다.

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/_bulk \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/x-ndjson' \
  --data-binary $'{"index":{"_index":"app"}}\n{"level":"info","msg":"hello"}\n'
```
</RequestExample>

<ResponseExample>
```json 200
{ "took": 0, "errors": false, "items": [ { "index": { "status": 201 } } ] }
```
</ResponseExample>

## 이 엔드포인트를 사용하는 경우

기존 전송기가 Elasticsearch 벌크 NDJSON을 보낼 수 있을 때 이 엔드포인트를 사용합니다. 이 API는 Elasticsearch 클러스터가 아닌 수집 어댑터입니다. 검색, 인덱스 템플릿, 문서 ID, 기존 문서를 직접 수정하는 기능을 제공하지 않습니다. 저장된 이벤트를 읽으려면 [SQL 쿼리](/ko/query)를 사용합니다.

## 유효한 배치 구성하기

- 각 `index` 또는 `create` 작업의 작업 객체와 문서 객체를 별도 줄에 보냅니다. 배치 끝에 줄바꿈을 넣습니다.
- `update` 작업의 이벤트 필드는 `doc` 아래에 넣습니다. 이 필드로 저장된 이벤트를 수정하는 대신 새 이벤트를 생성합니다.
- 스트림을 선택하려면 작업에 `_index`를 설정합니다. `_index`를 설정하지 않으면 `stream-name`을 사용하거나 `default` 스트림을 사용합니다.
- 이벤트 발생 시각을 보존하려면 `_timestamp`에 마이크로초 단위의 정수형 Unix 타임스탬프를 지정합니다. 지정하지 않으면 수신기가 현재 시각을 사용합니다.
- `delete` 작업은 건너뜁니다. 텔레메트리를 삭제하지 않으며 응답에 저장된 이벤트 항목을 추가하지 않습니다.

## 수집 확인하기

이벤트가 하나인 배치의 응답에는 `errors: false`와 `status: 201`인 항목 하나가 있어야 합니다. 응답 항목 수를 수집하려던 이벤트 수와 비교합니다. HTTP 요청이 성공했다는 사실만으로는 배치를 의도대로 구성했는지 확인할 수 없습니다.

**로그**를 열고 `_index`로 지정한 스트림을 선택한 후 이벤트 타임스탬프가 포함된 시간 범위를 설정합니다. 샘플에서 이벤트를 식별할 수 있는 필드로 쿼리합니다. 이벤트가 보이지 않으면 전체 배치를 다시 보내기 전에 스트림 선택과 타임스탬프 단위를 확인합니다. 이 인터페이스는 재시도 시 Elasticsearch 문서 ID를 사용해 중복을 제거하지 않습니다.

## 거부된 요청 문제 해결하기

| 증상 | 확인 사항 |
|---|---|
| 인증 또는 권한 오류 | 대상 조직에서 `logs.write` 권한이 있는 API 토큰을 사용합니다. |
| 작업 또는 문서가 JSON 객체가 아님 | NDJSON의 줄 구분을 확인합니다. JSON 배열이나 읽기 쉽게 여러 줄로 포맷한 객체를 보내지 않습니다. |
| 알 수 없는 작업 | 위에 나열된 지원 작업 이름을 사용합니다. |
| 압축 해제 오류 | 본문을 실제로 압축한 경우에만 `Content-Encoding: gzip`을 설정합니다. |
| 요청은 성공했지만 이벤트가 예상보다 적음 | 모든 쓰기 작업에 문서 줄이 있는지 확인하고, 건너뛴 삭제 작업과 저장된 이벤트를 구분합니다. |
