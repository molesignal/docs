```http
POST /api/v1/streams
```

처음 데이터를 쓸 때도 스트림이 생성됩니다. 스키마, 인덱스, 암호화 필드 또는 보존 기간을 명시하여 스트림을 미리 정의하려면 이 API를 호출합니다. 이 호출에는 `streams.create` 권한이 필요합니다.

**본문**

| 필드 | 유형 | 필수 | 참고 |
|---|---|---|---|
| `name` | 문자열 | 예 | 문자, 숫자, `_`, `-`, `.`을 사용할 수 있습니다. `_molesignal`, `_audit`과 같은 [플랫폼 스트림](/ko/streams#플랫폼-스트림) 이름은 예약되어 있습니다. |
| `streamType` | 문자열 | 예 | `logs`, `metrics`, `traces`, `profiles` 또는 `extend`입니다. |
| `fields` | 배열 | 아니요 | 필드 정의입니다. 아래 내용을 참고합니다. |
| `retentionDays` | 정수 | 아니요 | 1~3650입니다. 생략하면 **설정 → 데이터 보존**의 플랫폼 기본값을 사용합니다. |
| `settings` | 객체 | 아니요 | `description`, `queryable`과 같은 스트림 설정입니다. [보존 기간 및 설정 편집](/ko/api/streams/edit-retention)을 참고합니다. |

필드에는 다음 속성이 있습니다.

| 속성 | 유형 | 참고 |
|---|---|---|
| `name` | 문자열 | 필드 이름입니다. |
| `dataType` | 문자열 | `bool`, `int64`, `float64`, `utf8`, `timestamp` 또는 `json`입니다. |
| `nullable` | 불리언 | 기본값은 `true`입니다. |
| `indexType` | 문자열 | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value` 또는 `range`입니다. 기본값은 `none`입니다. |
| `encrypted` | 불리언 | 필드를 저장할 때 암호화합니다. 나중에 이 설정을 변경할 수 없습니다. [스트림](/ko/streams#암호화된-필드)을 참고합니다. |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "app",
    "streamType": "logs",
    "fields": [
      { "name": "trace_id", "dataType": "utf8", "nullable": true,
        "indexType": "exact", "encrypted": false }
    ],
    "retentionDays": 30
  }'
```
</RequestExample>

**오류**

| 상태 | 원인 |
|---|---|
| `403` | 지정한 이름이 플랫폼 스트림 이름이거나 토큰에 `streams.create` 권한이 없습니다. |
| `409` | 이름과 유형이 같은 스트림이 이미 있습니다. |
| `422` | 본문에서 필드가 누락되었거나 필드 값이 유효하지 않습니다. 예를 들어 지원하지 않는 `dataType`을 지정한 경우입니다. 응답은 일반 텍스트입니다. |
