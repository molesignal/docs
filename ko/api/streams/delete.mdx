```http
DELETE /api/v1/streams/{id}
```

스트림 정의를 삭제합니다. 컴팩터가 저장된 데이터가 차지하던 공간을 회수합니다. 보호된 `_molesignal` 시스템 스트림은 삭제할 수 없습니다. 스트림을 삭제하면 해당 스트림을 참조하는 대시보드, 저장된 뷰, 알림 규칙, 보고서, 파이프라인이 제대로 작동하지 않을 수 있습니다. 이 호출에는 `streams.delete` 권한이 필요합니다. `_audit` 스트림에는 `audit.read` 권한도 필요하며, 이 권한이 없으면 `403`을 반환합니다.

**경로 매개변수**

| 매개변수 | 유형 | 참고 |
|---|---|---|
| `id` | 문자열 | 스트림의 `id`입니다. 존재하지 않는 ID를 지정하면 `404`를 반환합니다. |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/streams/$STREAM_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>
