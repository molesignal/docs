```http
GET /api/v1/streams/usage
```

지정된 시간 범위에서 각 소스가 수집한 양과 할당량 대비 사용량을 반환합니다. `intake_usage.read` 권한이 필요하며, `_sys` 조직에서는 `sys.telemetry.read` 권한으로도 조회할 수 있습니다.

알 수 없는 값은 0이 아니라 `null`입니다. 레코드를 읽을 수 없으면 `available`은 `false`이고 모든 값은 `null`입니다. 시간 범위 중간에 사용량 측정을 시작했다면 `complete`는 `false`이고 각 값은 실제 사용량의 하한입니다.

**쿼리 파라미터**

| 파라미터 | 기본값 | 참고 |
|---|---|---|
| `dimension` | `credential` | `credential`, `stream` 또는 `service`입니다. |
| `windowSecs` | 86400 | 시간 범위의 길이입니다. 3600~2678400으로 제한되며, 시간 범위는 정각에 시작합니다. |

`sourceKey`는 자격 증명(`apiToken`, `connector`, `user`, `internal`)의 경우 `<credential_kind>:<id>`, 스트림의 경우 `<stream_type>:<name>` 형식입니다. 서비스의 경우 서비스 이름을 사용하며, 서비스 이름을 지정하지 않은 이벤트에는 빈 문자열을, 한도를 초과한 서비스에는 `*`를 사용합니다.

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/usage?dimension=credential&windowSecs=86400" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

## 단일 소스

```http
GET /api/v1/streams/usage/detail
```

지정된 시간 범위에서 단일 소스의 합계, 시간별 데이터를 버킷으로 집계한 결과, 나머지 두 차원별 세부 내역을 반환합니다. 세부 내역에는 차원마다 최대 20개의 소스가 포함됩니다.

| 파라미터 | 기본값 | 참고 |
|---|---|---|
| `dimension` | 필수 | `credential`, `stream` 또는 `service`입니다. |
| `sourceKey` | 필수 | `GET /api/v1/streams/usage`가 반환하는 소스 식별자입니다. |
| `windowSecs` | 86400 | 3600~2678400으로 제한됩니다. |
| `bucketCount` | 24 | 시계열의 버킷 수입니다. 6~48로 제한됩니다. |
