```http
PUT /api/v1/streams/{id}/settings
```

수집 과정에서 새 필드가 들어오면 스트림 스키마가 변경되며, API는 필드 유형을 변경하지 않습니다. 이 엔드포인트를 사용해 스키마에 이미 있는 필드의 인덱스 유형을 선택합니다. 호출에는 `streams.configure` 권한이 필요하며, `_audit` 스트림의 경우 `audit.read` 권한도 필요합니다. 같은 엔드포인트에서 보존 기간과 설정도 편집할 수 있습니다. [보존 기간 및 설정 편집](/ko/api/streams/edit-retention)을 참조합니다.

**본문**

| 필드 | 유형 | 참고 |
|---|---|---|
| `fields` | 배열 | 구성할 필드마다 항목을 하나씩 지정합니다. |

`fields`의 각 항목:

| 속성 | 유형 | 참고 |
|---|---|---|
| `name` | 문자열 | 스키마에 이미 있는 필드입니다. |
| `indexType` | 문자열 | `none`, `exact`, `full_text`, `bloom`, `skip`, `ngram`, `ip`, `key_value`, `range` 중 하나입니다. [스트림](/ko/streams#스키마-및-필드)을 참조합니다. |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexType": "exact" },
      { "name": "msg", "indexType": "full_text" }
    ]
  }'
```
</RequestExample>

응답은 [스트림 조회](/ko/api/streams/get)에 표시된 형식으로 업데이트된 스트림을 반환합니다. 변경 사항은 이후에 기록하는 데이터에 즉시 적용되며, 이전에 기록한 데이터는 백그라운드에서 다시 인덱싱합니다. [스트림](/ko/streams#스키마-및-필드)을 참조합니다. `full_text`, `ngram`, `ip` 인덱스는 `utf8` 필드에만 사용할 수 있으며, `key_value` 인덱스는 `json` 필드에만 사용할 수 있습니다.
