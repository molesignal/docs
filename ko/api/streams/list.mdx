```http
GET /api/v1/streams
```

조직의 모든 스트림을 이름과 유형으로 정렬하여 JSON 배열로 반환합니다. 각 항목은 [스트림 조회](/ko/api/streams/get)에 표시된 구조를 따르며, 스키마, 명시적으로 설정한 `retention`, 계산된 `effectiveRetention`, 설정, 마이크로초 단위 타임스탬프를 포함합니다. 이 호출에는 `streams.read` 또는 `sys.telemetry.read` 권한이 필요합니다.

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

응답에는 `_molesignal`과 같은 보호된 시스템 스트림이 포함됩니다. 토큰에 `audit.read` 권한이 없으면 `_audit`를 제외합니다. 스트림은 이름과 유형의 조합으로 식별하므로 여러 유형에 같은 이름이 나타날 수 있습니다.

## 응답 사용

이 엔드포인트는 텔레메트리 레코드가 아닌 스트림 정의를 반환합니다. 스키마를 읽거나 구성을 변경하기 전에 이 엔드포인트로 스트림 ID를 확인합니다. 이벤트를 쿼리하려면 [쿼리 API](/ko/api/query/execute)를 사용합니다.

| 필드 | 설명 |
|---|---|
| `id` | 단일 스트림 API에서 사용하는 고정 식별자입니다. |
| `name` 및 `streamType` | 두 필드의 조합으로 데이터 세트를 식별합니다. 스트림 목록의 키로 이름만 사용하지 않습니다. |
| `schema` | 쿼리를 구성할 때 사용하는 필드 정의입니다. |
| `retention` | 명시적으로 설정한 스트림 보존 기간입니다. `null`이면 기본값을 적용합니다. |
| `effectiveRetention` | 스트림에 실제로 적용되는 보존 기간입니다. |
| `createdAt`, `updatedAt` | 밀리초가 아닌 마이크로초 단위의 Unix 타임스탬프입니다. |

## 액세스 권한 및 데이터 범위 확인

대상 조직에 연결된 자격 증명을 사용합니다. 목록을 요청하려면 `streams.read` 또는 `sys.telemetry.read` 권한이 필요하며, `audit.read` 권한이 없으면 응답에서 `_audit`를 제외합니다. `_audit`가 없다고 해서 감사 로그 수집이 비활성화된 것은 아닙니다.

응답은 `items` 필드로 감싼 객체가 아니라 JSON 배열입니다. 이 엔드포인트에는 페이지네이션 매개변수가 없습니다. 빈 배열은 요청 대상 조직과 조회 권한 범위에서 반환된 스트림이 없다는 뜻입니다. 다른 조직에도 데이터가 없다는 뜻은 아닙니다.

필요한 `(name, streamType)` 조합을 찾은 후 해당 스트림의 `id`를 [스트림 조회](/ko/api/streams/get)에 전달합니다. 스트림 정의가 있더라도 실제로 조회할 수 있는 이벤트가 있는지는 [샘플 쿼리](/ko/api/query/execute)로 별도로 확인합니다.
