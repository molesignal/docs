예산은 소스의 사용량이 한도에 가까워지거나 한도를 초과할 때 알림만 보냅니다. 수집 요청에 대한 응답과 데이터 저장 방식은 그대로 유지합니다. [수집 사용량 및 예산](/ko/streams#데이터-수집-사용량-및-예산)을 참조합니다.

## 예산 목록 조회

```http
GET /api/v1/streams/budgets
```

조직의 모든 예산을 소스 레이블 및 현재 기간의 사용 현황과 함께 반환합니다. `intake_usage.read` 권한이 필요하며, `_sys` 조직에서는 `sys.telemetry.read` 권한이 필요합니다. 확인할 수 없는 수치는 `null`로 반환합니다.

## 예산 설정

```http
POST /api/v1/streams/budgets
```

소스에 예산을 설정합니다. 소스당 예산은 하나만 설정할 수 있으며, 다시 설정하면 기존 예산을 변경합니다. `intake_budgets.manage` 권한이 필요합니다. `_sys` 조직에서는 예산을 설정할 수 없습니다.

| 필드 | 필수 | 참고 |
|---|---|---|
| `dimension` | 예 | `credential`, `stream`, `service` 중 하나입니다. |
| `sourceKey` | 예 | [수집 사용량](/ko/api/streams/usage)에서 반환하는 소스입니다. 플랫폼 자체 텔레메트리, 서비스 이름이 없는 이벤트, 한도 초과 서비스에는 예산을 설정할 수 없습니다. |
| `period` | 예 | UTC 달력 기준으로 `day` 또는 `month`입니다. |
| `limitSize` | 예 | 단위는 MiB이며, 범위는 1~1073741824입니다. |
| `warnPercent` | 아니요 | 경고를 보낼 한도 대비 사용률입니다. 범위는 0~99입니다. `0`으로 설정하면 한도를 모두 사용했을 때만 경고를 보냅니다. 기본값: 80. |
| `notifyUserIds` | 아니요 | 알림을 받을 조직 구성원입니다. 최대 50명까지 지정할 수 있습니다. 기본 수신자는 예산을 설정한 구성원입니다. 서비스 계정으로 설정할 때는 수신자를 지정해야 합니다. |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/streams/budgets" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"dimension":"stream","sourceKey":"logs:app","period":"day","limitSize":102400}'
```
</RequestExample>

## 예산 삭제

```http
DELETE /api/v1/streams/budgets/{budgetId}
```

`204`를 반환합니다. `intake_budgets.manage` 권한이 필요합니다.
