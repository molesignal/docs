```http
GET /api/v1/streams/runtime
```

모든 스트림의 런타임 상태를 반환합니다. 여기에는 저장된 행 수와 바이트 수, 마지막 수신 시각, 수집 상태, 버킷 시계열이 포함됩니다. 이 호출에는 `streams.read` 권한이 필요하며, 시스템 텔레메트리를 조회할 때는 `sys.telemetry.read` 권한이 필요합니다. 토큰에 `audit.read` 권한이 없으면 `_audit` 스트림을 제외합니다.

**쿼리 파라미터**

| 파라미터 | 기본값 | 참고 |
|---|---|---|
| `windowSecs` | 86400 | 시간 범위의 길이입니다. 3600~604800으로 제한합니다. |
| `bucketCount` | 24 | 시계열의 버킷 수입니다. 6~48로 제한합니다. |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/runtime?windowSecs=3600" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

| `status` | 의미 |
|---|---|
| `healthy` | 최근 15분 이내에 데이터를 수신했습니다. |
| `delayed` | 마지막 데이터 수신 후 15분을 초과했으며 2시간은 지나지 않았습니다. |
| `interrupted` | 마지막 데이터 수신 후 2시간을 초과했습니다. |
| `idle` | Mole Agent 트레이스 스트림처럼 설계상 데이터 수신이 드문 스트림입니다. |
| `unused` | 데이터를 한 번도 수신하지 않은 스트림입니다. |
| `unknown` | 통계를 사용할 수 없습니다. |

`staleIndexFiles`는 스트림의 인덱스 유형이 마지막으로 변경되기 전의 설정으로 인덱싱된 상태인 파일 수를 나타냅니다. 백그라운드에서 이 파일을 다시 인덱싱하면 이 값이 0까지 줄어듭니다.
