```http
GET /api/v1/streams/{id}
```

스트림 정의를 반환합니다. 스트림 정의에는 스키마, 명시적으로 설정한 `retention`, 계산된 `effectiveRetention`, 스트림 설정이 포함됩니다. 이 호출에는 `streams.read` 권한이 필요하며, 시스템 텔레메트리에는 대신 `sys.telemetry.read` 권한이 필요합니다. `_audit` 스트림에는 `audit.read` 권한도 필요하며, 이 권한이 없으면 `403`을 반환합니다.

**경로 매개변수**

| 매개변수 | 유형 | 참고 |
|---|---|---|
| `id` | string | [스트림 목록 조회](/ko/api/streams/list)에서 가져온 스트림 `id`입니다. 알 수 없는 ID를 지정하면 `404`를 반환합니다. |
