저장된 뷰는 이름을 지정해 워크스페이스에서 공유하는 SQL 또는 PromQL 쿼리입니다. 쿼리를 다시 작성하지 않고 클릭 한 번으로 다시 열거나,
[보고서](/ko/reports)의 콘텐츠로 사용하거나,
명령 팔레트에서 찾을 수 있습니다. [명령 팔레트](/ko/console#명령-팔레트로-검색)에서
**저장된 보기로 이동**을 선택해 **저장된 뷰**를 엽니다.

## 목록

목록 상단에는 저장된 뷰 수와 고정된 뷰 수가 표시됩니다. 각 뷰에는 **언어**, **스트림**,
**태그**, 기본 **기간**, 변경 시점이 표시됩니다. 고정된 뷰에는 핀 아이콘이 표시됩니다.

| 작업 | 효과 |
|---|---|
| **열기** | 해당 탐색기에서 현재 시점을 종료 시점으로 삼아 뷰에 설정된 기간으로 쿼리를 엽니다. |
| **고정** / **고정 해제** | 팀에서 자주 사용하는 뷰로 표시하거나 표시를 해제합니다. |
| **편집** | 뷰를 변경합니다. |
| **삭제** | 뷰를 삭제합니다. 이 작업은 되돌릴 수 없습니다. |

**열기**를 선택하면 SQL 뷰는 [로그](/ko/logs)의 SQL 모드에서 뷰에 지정된 스트림을 대상으로 실행하고, PromQL 뷰는
[메트릭](/ko/metrics)에서 실행합니다.

## 저장된 뷰 생성

**새 저장 뷰**를 선택합니다:

| 필드 | 규칙 |
|---|---|
| **이름** | 목록과 명령 팔레트에 표시할 이름입니다. |
| **언어** | **SQL** 또는 **PromQL**입니다. |
| **기본 시간 범위** | **열기**에 적용할 시간 범위입니다. 15분, 1시간, 6시간, 24시간, 7일 중에서 선택합니다. |
| **쿼리문** | 실행할 쿼리입니다. |
| **스트림(선택 사항)** | SQL 뷰를 실행할 스트림입니다. 읽을 파일의 범위도 좁힙니다. |
| **태그** | 나중에 뷰를 찾을 수 있도록 태그를 쉼표로 구분해 입력합니다. |
| **상단에 고정** | 뷰를 고정합니다. |

**생성**을 선택합니다. 다른 시간 범위에서도 유효한 쿼리를 작성합니다. 쿼리에 시간 범위를 직접 지정하지 말고
뷰의 기간 설정을 사용합니다. `service.name`, `deployment.environment`처럼 값이 잘 바뀌지 않는 필드로 필터링합니다.

## 다른 곳에서 저장된 뷰 사용

- [보고서](/ko/reports#저장된-뷰)는 정해진 일정에 따라 저장된 뷰의 쿼리 결과를 표로 표시합니다.
- 명령 팔레트에서 이름으로 저장된 뷰를 찾을 수 있습니다.
- [스트림](/ko/streams#스트림-세부-정보)의 **사용량** 탭에는 해당 스트림에 연결된 저장된 뷰가 표시됩니다.

## 권한

| 권한 | 허용 작업 |
|---|---|
| `saved_views.read` | 저장된 뷰의 목록을 조회하고 뷰를 엽니다. |
| `saved_views.create` | 저장된 뷰를 생성합니다. |
| `saved_views.edit` | 저장된 뷰를 변경하고 고정합니다. |
| `saved_views.delete` | 저장된 뷰를 삭제합니다. |

뷰를 실행하려면 `streams.query` 권한도 필요합니다. [저장된 뷰 API](/ko/api/query/list-saved-views)를 참조합니다.
