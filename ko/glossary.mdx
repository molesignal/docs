| 용어 | 정의 |
|---|---|
| **알림** | 알림 규칙을 평가하고, 에스컬레이션을 진행하고, 예약된 보고서를 렌더링하고, 커넥터를 실행하는 역할입니다. [역할 기반 배포](/ko/deployment/role-based)를 참조합니다. |
| **API 토큰** | 사용자 또는 서비스 계정으로 작동하는 `mspat-<36>` 형식의 Bearer 인증 정보입니다. [ID 및 액세스](/ko/identity)를 참조합니다. |
| **APM** | 애플리케이션 성능 모니터링입니다. 트레이스 스팬에서 서비스, 트랜잭션, 종속성, 오류, 버전에 대한 집계 데이터를 제한된 범위로 생성합니다. [APM](/ko/apm)을 참조합니다. |
| **Arrow Flight SQL** | DBeaver, JDBC, ADBC 등의 데이터베이스 클라이언트가 `5083` 포트에서 사용하는 SQL 프로토콜입니다. 기본적으로 비활성화되어 있습니다. [데이터베이스 클라이언트로 연결](/ko/query/database-clients)을 참조합니다. |
| **카탈로그** | 각 스트림에 속하는 Parquet 파일과 인덱스를 PostgreSQL에 기록한 정보입니다. |
| **암호화 키** | MoleSignal이 PostgreSQL에 저장하는 시크릿을 암호화하는 루트 키로, `MS_CIPHER_KEY`에 설정합니다. [프로덕션 체크리스트](/ko/deployment/production-checklist)를 참조합니다. |
| **컴팩션** | 작은 Parquet 파일을 병합해 더 큰 파일로 만드는 작업입니다. `compactor` 역할이 보존 처리와 함께 이 작업을 수행합니다. |
| **커넥터** | 외부 플랫폼과의 연동을 관리하는 구성 요소입니다. 소스는 일정에 따라 로그를 가져오거나 플랫폼이 전송하는 로그를 수신합니다. 대상은 파이프라인 출력을 받습니다. [커넥터](/ko/connectors)를 참조합니다. |
| **데이터 소스** | 소스 하나에 필요한 엔드포인트, 토큰, 구성 스니펫을 생성하는 데이터 소스 카탈로그의 항목입니다. [데이터 소스](/ko/intake)를 참조합니다. |
| **에스컬레이션 정책** | 알림 대상의 순서와 각 대상의 확인 제한 시간을 정의합니다. [알림](/ko/alerting)을 참조합니다. |
| **확장 테이블** | 키로 레코드를 조회하는 테이블입니다. 파이프라인은 이 테이블을 조회해 이벤트에 정보를 추가하고, 테이블에 행을 쓸 수도 있습니다. [확장 테이블](/ko/extend-tables)을 참조합니다. |
| **페더레이션 쿼리** | `?clusters=local,<name>`으로 선택한 원격 클러스터까지 스캔하는 쿼리입니다. [역할 기반 배포](/ko/deployment/role-based)를 참조합니다. |
| **플러시** | 수신 노드의 메모리 버퍼에 있는 데이터를 오브젝트 스토리지에 Parquet 파일과 인덱스로 기록하는 작업입니다. |
| **함수** | VRL 또는 JavaScript로 작성하는 재사용 가능한 변환입니다. [함수](/ko/functions)를 참조합니다. |
| **인시던트** | 알림이 발생한 개별 사례로, 확인과 해결 단계를 거칩니다. [알림](/ko/alerting)을 참조합니다. |
| **수신** | 텔레메트리를 받아들이는 경로입니다. 텔레메트리를 검증하고 버퍼링하고 플러시하는 역할도 가리킵니다. [데이터 소스](/ko/intake)를 참조합니다. |
| **수집 토큰** | **데이터 수집** 권한 정책을 따르는 토큰입니다. 데이터 전송 주체와 배포 파이프라인에서 사용하며, `logs.write`, `metrics.write`, `traces.write`, `profiles.write`, `apm.deploy` 권한이 포함됩니다. [데이터 소스](/ko/intake#수집-토큰)를 참조합니다. |
| **로그 검사** | Mole Agent가 요청에 따라 또는 일정에 맞춰 특정 기간의 로그를 분석해 작성하는 보고서입니다. [로그 검사](/ko/logs/inspections)를 참조합니다. |
| **Mole Agent** | 도구 카탈로그를 활용해 문제를 조사하는 내장 운영 에이전트입니다. [Mole Agent](/ko/agent)를 참조합니다. |
| **온콜 일정** | 에스컬레이션이 참조하는 교대 일정입니다. 시간대를 반영하며 일정 재정의를 지원합니다. [알림](/ko/alerting)을 참조합니다. |
| **조직** | 테넌트와 정책의 경계입니다. 웹 UI에서는 워크스페이스라고 합니다. [핵심 개념](/ko/concepts)을 참조합니다. |
| **Parquet** | MoleSignal이 로그, 메트릭, 트레이스를 저장하는 데 사용하는 열 지향 파일 형식입니다. |
| **파이프라인** | 이벤트를 라우팅하고, 정규화하고, 민감 정보를 가리고, 추가 정보를 보강하는 일련의 단계입니다. 수신 중 실시간으로 또는 일정에 따라 실행하며, 인시던트를 열기 전에 알림 이벤트를 변경할 수도 있습니다. [파이프라인](/ko/pipelines)을 참조합니다. |
| **플랫폼 관리자** | `[auth].root_email`로 지정하며 플랫폼 전체 설정을 관리하는 사용자입니다. |
| **플랫폼 스트림** | `_audit` 또는 `_synthetic_results`와 같이 MoleSignal만 데이터를 쓰는 스트림입니다. [스트림](/ko/streams#플랫폼-스트림)을 참조합니다. |
| **프로브 에이전트** | 특정 위치에서 신세틱 검사를 실행하는 프로세스입니다. `standalone` 노드에서는 내장 에이전트가 실행됩니다. [신세틱 모니터링](/ko/synthetics)을 참조합니다. |
| **역할** | `[node].roles`에서 선택하는 프로세스 역할입니다. `standalone`, `router`, `intake`, `querier`, `compactor`, `alert` 중 하나입니다. IAM에서는 권한 정책과 개별 권한으로 구성된 이름 있는 권한 집합도 가리킵니다. |
| **RUM** | 브라우저 및 모바일 앱 세션을 대상으로 하는 실제 사용자 모니터링입니다. [RUM](/ko/rum)을 참조합니다. |
| **RUM 클라이언트 토큰** | `rum.write` 권한이 있으며 애플리케이션 하나에 연결된 토큰입니다. 브라우저 및 모바일 앱 코드에서 전송합니다. |
| **저장된 뷰** | 시간 범위와 옵션을 함께 저장한 쿼리입니다. |
| **검색 작업** | 실행 상태가 영속적으로 저장되는 비동기 쿼리입니다. 크기 임계값을 초과하는 쿼리는 검색 작업으로 전환되며 **스트림 → 검색 작업**에 표시됩니다. [쿼리](/ko/query)를 참조합니다. |
| **자체 텔레메트리** | MoleSignal이 자체 동작에 대해 수집하고 예약된 `_molesignal` 스트림에 기록하는 메트릭, 트레이스, 프로필입니다. [자체 옵저버빌리티](/ko/self-observability)를 참조합니다. |
| **서비스 계정** | 수집기와 자동화에 사용하는 비인간 ID입니다. 로그인할 수 없습니다. [ID 및 액세스](/ko/identity)를 참조합니다. |
| **알림 음소거** | 지정된 시간 동안 조건에 일치하는 알림의 전송을 중지하는 규칙입니다. [알림](/ko/alerting)을 참조합니다. |
| **독립 실행형** | 모든 역할을 하나의 프로세스에서 실행하는 기본 역할입니다. |
| **상태 페이지** | 구성 요소의 상태와 인시던트를 표시하는 공개 또는 비공개 페이지입니다. [상태 페이지](/ko/status-pages)를 참조합니다. |
| **스트림** | 시그널의 이름, 유형, 스키마, 보존 정책을 정의하는 계약입니다. [스트림](/ko/streams)을 참조합니다. |
| **스트림 유형** | `logs`, `metrics`, `traces`, `profiles`, `extend` 중 하나입니다. |
| **신세틱 모니터** | HTTP 요청과 같은 검사를 일정에 따라 실행해 가용성과 지연 시간을 기록합니다. [신세틱 모니터링](/ko/synthetics)을 참조합니다. |
| **VRL** | Vector Remap Language의 약자로, 파이프라인 함수를 작성하는 데 사용하는 언어 중 하나입니다. |
| **WAL** | 선행 기록 로그입니다. 수신을 확인한 레코드를 플러시할 때까지 오브젝트 스토리지에 오브젝트로 보관합니다. |
| **워크스페이스** | 웹 UI에서 선택한 조직을 지칭하는 이름입니다. |
