함수는 재사용 가능한 이벤트 변환을 묶어 제공합니다. **함수**를 열어 파이프라인과 별도로
함수 정의를 만들고 테스트하고 관리합니다.

## 함수 찾기

목록에는 조직의 함수와 기본 제공 프리셋이 표시됩니다. 목록 상단의 세 가지 보기는
각각 항목 수를 표시하며 목록을 필터링합니다.

| 보기 | 내용 |
|---|---|
| **전체** | 조직의 모든 함수와 프리셋입니다. |
| **내 함수** | 조직에서 작성한 함수입니다. |
| **프리셋** | MoleSignal에서 제공하는 읽기 전용 함수입니다. |

함수 이름과 프리셋 설명을 검색할 수 있습니다. 조직의 함수를 클릭하면
작업 공간에서 열립니다.

## 언어

| 언어 | 사용 가능 여부 | 적합한 용도 |
|---|---|---|
| VRL | 기본 제공 | 파싱, 정규화, 필터링, 마스킹, 데이터 보강입니다. |
| JavaScript | 기본 제공 | JavaScript로 더 쉽게 표현할 수 있는 로직입니다. |
| LLM | API로 구성할 수 있으며 `llm_eval_enabled` 및 모델 제공업체가 필요합니다. | 모델 출력을 활용하는 저처리량 분류 또는 데이터 보강입니다. |

VRL과 JavaScript는 모두 MoleSignal 바이너리 내부에서 실행됩니다. 별도의 설정이나 설치가 필요하지 않습니다.

MoleSignal은 함수를 저장할 때 검증하고 컴파일합니다. 소스가 유효하지 않으면 함수가
활성화되지 않습니다.

함수 작업 공간에서는 VRL과 JavaScript를 사용할 수 있습니다. LLM 함수는 API를 사용하는
고급 워크플로입니다. 함수 소스는 시스템 지침으로, 이벤트는 모델 입력으로 사용하며
`params_schema.output_field`로 출력 필드를 선택합니다(기본값: `_llm_eval`). 실행할 때마다
모델을 호출하므로 `[functions].llm_eval_enabled` 설정의 기본값은 `false`입니다.
[구성](/ko/configuration#기능-및-통합)을 참조합니다. 모델로 알림
이벤트를 요약하려면 [알림 파이프라인](/ko/pipelines/alert-events#ai-요약)의 **AI 요약** 단계를 사용합니다.
이 단계는 해당 설정과 관계없이 작동합니다.

## 기본 제공 프리셋

모든 조직에서 다음 읽기 전용 VRL 함수를 볼 수 있습니다.

| 함수 | 동작 |
|---|---|
| `add-intake-time` | 엔드 투 엔드 지연 시간을 진단할 수 있도록 수집 타임스탬프를 추가합니다. |
| `normalize-logs` | JSON 메시지를 파싱하고 환경 및 클러스터 필드를 추가하며 `level`을 소문자로 정규화합니다. |
| `parse-key-value` | logfmt 또는 `key=value` 메시지를 필드로 파싱하고 해당 필드를 이벤트에 병합합니다. |
| `redact-email` | `message`의 이메일 주소를 대체 텍스트로 바꿉니다. |
| `route-by-service` | 서비스 이름을 정규화하고 라우팅에 참고할 서비스별 대상 스트림(`logs_<service>`)을 도출합니다. |

프리셋 행에는 **기본 제공** 태그와 설명이 표시됩니다. 설명은 로그인한 계정의
인터페이스 언어로 표시됩니다. 행을 클릭하면 소스를 볼 수 있습니다.

프리셋은 편집할 수 없습니다. 수정하려면 행이나 프리셋 패널에서 **이 함수로 시작**을
선택합니다. 작업 공간은 프리셋의 언어와 소스를 가져와 새 함수를 엽니다. 새 함수의 이름은
`<preset>-copy`입니다. 저장하면 조직에 함수가 추가되며 프리셋은 변경되지 않습니다.

## 함수 작성 및 테스트

작업 공간은 세 부분으로 구성됩니다.

- 함수 이름과 언어
- 제목 옆에 소스 검증 상태를 표시하는 **소스** 편집기
- JSON 형식의 **샘플 입력**과 **샘플 출력**을 표시하는 **테스트 실행**

**샘플 실행**을 선택하면 편집기의 소스를 샘플 이벤트에 적용합니다. 소스를 미리
저장할 필요는 없습니다. 변환된 이벤트는 **샘플 출력**에 표시됩니다. 실행에 실패하면
이벤트 대신 실패 원인이 표시됩니다.

페이지 제목 행에는 **함수 저장**과 **취소**가 표시됩니다. 이미 저장한 함수에는
**함수 삭제**도 표시됩니다. 이름이나 소스가 비어 있으면 **함수 저장** 버튼이
비활성화되고 툴팁에 누락된 항목이 표시됩니다.
편집기에서 `⌘ Enter` 또는 `Ctrl+Enter`를 누르면 샘플을 실행하고, `⌘S` 또는 `Ctrl+S`를 누르면 함수를 저장합니다.

샘플 실행기는 언어, 소스, 샘플 이벤트를 `POST /api/v1/functions/run`에 전달하고
변환된 이벤트를 반환합니다.

```bash
curl -X POST http://localhost:5080/api/v1/functions/run \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"language":"vrl","source":".service = downcase!(string!(.service))","input":{"service":"Checkout"}}'
```

```json
{ "output": { "service": "checkout" } }
```

VRL 예시:

```vrl
.service = downcase!(string!(.service))
.severity = upcase(string(.level) ?? "INFO")
if exists(.customer_id) {
  .customer = lookup("customers", .customer_id)
}
```

## 테이블과 IP 주소 조회

두 VRL 함수는 MoleSignal에 저장된 데이터를 읽습니다. 샘플 실행과 모든 파이프라인의 VRL 단계에서
사용할 수 있으며, 알림 파이프라인도 포함됩니다.

| 함수 | 반환값 |
|---|---|
| `lookup("<table>", key)` | [확장 테이블](/ko/extend-tables) `<table>`에서 키가 `key`인 행을 객체로 반환하거나 `null`을 반환합니다. |
| `geoip_lookup(ip)` | IPv4 또는 IPv6 주소의 위치를 객체로 반환하거나 `null`을 반환합니다. |

```vrl
# the team that owns the host, from the extend table host_owner
.team = lookup("host_owner", .host).team

# where the client is
place = geoip_lookup(.client_ip)
if is_object(place) {
  .country = place.country
  .city = place.city
}
```

- 두 함수 모두 오류를 반환하지 않습니다. 테이블이나 행이 없거나 키가 텍스트, 숫자,
  불리언 중 어느 것도 아니거나, 주소를 파싱할 수 없거나 데이터베이스에 해당 주소가 없으면 `null`을 반환합니다.
  `null`에서 `.team`과 같은 경로를 조회해도 `null`을 반환합니다.
- `lookup`의 테이블 이름은 문자열 리터럴로 지정합니다. 필드나 변수에서 이름을 가져오면
  컴파일되지 않습니다. 숫자나 불리언 키는 문자열로 변환해 조회합니다. 예를 들어 `42`를 전달하면
  키가 `42`인 행을 찾습니다.
- `lookup`은 워크스페이스의 확장 테이블을 읽습니다.
  행 변경 사항이 조회 결과에 반영되기까지 걸리는 시간은
  [확장 테이블](/ko/extend-tables#파이프라인에서-키-조회)을 참조합니다.
- `geoip_lookup`은 [DB-IP](https://db-ip.com) City Lite 데이터베이스를 읽습니다. 경로는
  [`[mmdb].db_path`](/ko/configuration#기능-및-통합)에 지정하며, 데이터베이스가 없으면
  `null`을 반환합니다. 데이터베이스에는 사설 주소가 없습니다. 반환 객체는 다음 필드 중
  데이터베이스에 값이 있는 필드만 포함합니다.

| 필드 | 내용 |
|---|---|
| `country` | `DE`와 같은 ISO 3166 국가 코드입니다. |
| `country_name` | 국가의 영문 이름입니다. |
| `continent_code` | `EU`와 같은 대륙 코드입니다. |
| `continent` | 대륙의 영문 이름입니다. |
| `region` | 주나 도와 같은 1단계 행정 구역의 영문 이름입니다. |
| `city` | 도시의 영문 이름입니다. |
| `latitude`, `longitude` | 도 단위의 좌표입니다. |

## JavaScript 함수

소스는 이벤트마다 한 번 실행됩니다. 전역 `molesignal` 객체는 이벤트와 헬퍼를 제공합니다.

| 멤버 | 용도 |
|---|---|
| `molesignal.fields` | 이벤트를 담은 객체입니다. 객체를 읽거나 수정하거나 새 객체를 할당할 수 있습니다. |
| `molesignal.set(name, value)` | 필드 값을 설정합니다. |
| `molesignal.del(name)` | 필드를 삭제합니다. |
| `molesignal.now()` | Unix epoch 이후 경과한 시간을 마이크로초 단위로 반환합니다. |
| `molesignal.parse_json(text)` 및 `molesignal.encode_json(value)` | JSON 텍스트와 값을 서로 변환합니다. |
| `molesignal.sha256(text)` | 텍스트의 UTF-8 바이트에 대한 SHA-256 다이제스트를 소문자 16진수 문자 64개로 반환합니다. |

```js
molesignal.set("severity", String(molesignal.fields.level || "info").toUpperCase());
molesignal.set("seen_at", molesignal.now());
molesignal.del("level");
```

JavaScript 함수는 다음 제한이 적용되는 격리된 엔진에서 실행됩니다.

- 실행 시간이 50 ms를 초과하면 `js timeout 50ms` 오류와 함께 실행을 중지합니다.
- 함수당 힙 메모리는 최대 32 MiB입니다.
- 네트워크 액세스, 타이머, `TextEncoder`는 사용할 수 없습니다.

## 함수 사용

파이프라인 단계에서는 VRL을 실행합니다. **사용자 지정 VRL** 단계에서 **저장된 함수로 시작**을 선택하면
VRL 함수나 프리셋의 소스를 단계에 복사해 편집할 수 있습니다. 단계는 복사본을 유지하므로
나중에 함수를 변경하거나 삭제해도 파이프라인은 바뀌지 않습니다.

## 권한

- `functions.read`는 함수 목록 조회와 열기를 허용합니다.
- `functions.create`와 `functions.edit`는 각각 함수 정의 생성과 편집을 허용합니다.
- `functions.run`은 샘플 실행을 허용합니다.
- `functions.delete`는 함수 정의 삭제를 허용합니다.
