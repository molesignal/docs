변수는 그리드 위에서 선택한 값을 모든 패널의 쿼리, 제목, 링크에 적용합니다. 이렇게 하면
서비스, 호스트, 환경마다 대시보드를 복제하지 않고 하나의 대시보드를 사용할 수 있습니다.

## 변수 추가

편집기를 열고 **설정 → 변수**를 선택한 다음 변수를 추가합니다.

| 필드 | 규칙 |
|---|---|
| **이름** | `service`처럼 쿼리에서 사용하는 이름입니다. 문자, 숫자, `_`를 사용하고 문자나 `_`로 시작합니다. 이 규칙을 따르지 않는 이름은 치환되지 않습니다. |
| **레이블** | 선택기 위에 표시하는 텍스트입니다. |
| **유형** | 값을 가져올 출처입니다. [유형](#유형)을 참조합니다. |
| **쿼리 / 옵션** | 유형에 따라 쿼리나 값을 지정합니다. |
| **다중 선택** | 여러 값을 한 번에 선택할 수 있습니다. |
| **모두 포함** | 목록의 모든 값을 나타내는 **전체**를 추가합니다. |
| **숨기기** | **없음**은 선택기를 표시하고, **레이블**은 레이블을 숨기며, **변수**는 선택기를 숨깁니다. |
| **새로 고침** | 쿼리 변수의 값을 다시 읽는 시점을 지정합니다. **만료 없음**, **로드 시** 또는 **시간 범위**가 변경될 때마다 새로 고치도록 설정합니다. |

변수를 유지하려면 대시보드를 저장합니다.

## 유형

| 유형 | 값 |
|---|---|
| **쿼리** | 데이터에서 값을 읽습니다. [쿼리 변수](#쿼리-변수)를 참조합니다. |
| **사용자 지정** | `prod, staging, dev`처럼 쉼표로 구분해 입력한 고정 목록입니다. |
| **텍스트** | 그리드 위의 입력란에 입력한 텍스트입니다. |
| **상수** | 대시보드 모델에 저장하는 고정 값입니다. 그리드 위에는 표시하지 않습니다. |
| **실행 간격**, **데이터 소스** | 대시보드 모델에 저장하는 목록입니다. 예를 들어 가져온 JSON에 포함된 목록을 사용할 수 있습니다. |

### 쿼리 변수

쿼리 변수는 현재 시간 범위에서 값을 읽습니다. **쿼리 유형**을 선택합니다.

| 쿼리 유형 | 필드 | 값 |
|---|---|---|
| **레이블 값** | **메트릭**과 **레이블**입니다. 예를 들어 `http_requests_total`과 `service`를 지정합니다. | 해당 메트릭이 포함된 모든 메트릭 스트림에서 그 메트릭의 시계열에 지정된 레이블 값을 가져옵니다. |
| **클래식 쿼리** | `label_values(http_requests_total, service)`와 같은 표현식입니다. | **레이블 값**과 동일합니다. |
| **SQL** | **스트림 이름**, **스트림 유형**, SQL 문을 지정합니다. | 첫 번째 열의 값을 가져옵니다. |

첫 번째 값이 기본값이 됩니다. 쿼리에서 다른 변수를 사용할 수 있습니다. 예를 들어 SQL 문에
`WHERE environment = '$env'`를 넣으면 선택한 환경의 서비스로 범위를 좁힐 수 있습니다.

## 변수 사용

쿼리, 패널 제목, 텍스트 요소 또는 링크에 `$name`이나 `${name}`을 입력합니다. `${service}_errors`처럼
변수 이름 바로 뒤에 문자열이 이어지면 중괄호로 이름을 감쌉니다. 값이 여러 개면 쉼표로 연결합니다.
다른 형식을 사용하려면 형식 지정자를 추가합니다.

| 구문 | `checkout`과 `payment`를 선택한 결과 |
|---|---|
| `${service}` | `checkout,payment` |
| `${service:csv}` | `checkout,payment` |
| `${service:pipe}` | `checkout\|payment` |
| `${service:regex}` | `checkout\|payment`로 연결하고, 각 값은 정규 표현식에 맞게 이스케이프합니다. |
| `${service:sqlstring}` | `'checkout','payment'`처럼 각 값을 SQL용 작은따옴표로 감쌉니다. 예를 들어 `IN (${service:sqlstring})`에 사용합니다. |
| `${service:json}` | `["checkout","payment"]` |

예를 들어 PromQL 쿼리 `sum(rate(http_requests_total{service=~"${service:regex}"}[5m]))`를 사용하는 패널은
선택한 서비스의 데이터를 표시합니다.

## 주소에 포함된 값

선택한 값은 대시보드 주소에 `var-<name>=<value>` 형식으로 저장합니다. 값이 여러 개인 변수는
값마다 이 매개변수를 반복합니다. 같은 선택 상태로 열려면 주소를 복사하거나 이 매개변수로
대시보드 링크를 만듭니다. [데이터 링크](/ko/dashboards/edit#데이터-링크)로도
변수를 전달할 수 있습니다.

## 변수로 패널 반복

패널의 **패널** 탭에서 **반복 변수**를 선택합니다. 대시보드는 선택한 값마다 패널 복사본을
하나씩 표시하고, 각 복사본의 변수를 해당 값으로 설정합니다. **반복 방향**을
**가로**, **세로**, **그리드** 중에서 선택하고 **행당 최대 개수**를 설정합니다. 원본 패널만
저장하며, 복사본은 선택한 값에 따라 달라집니다.
