**대시보드**에서 **새 대시보드**를 선택하거나 대시보드에서 **편집**을 선택해 편집기를 엽니다. 대시보드를 만들려면
`dashboards.create` 권한이 필요하고, 수정하려면 `dashboards.edit` 권한이 필요합니다. 기본 제공 대시보드처럼
**편집 가능** 설정이 꺼진 대시보드는 수정할 수 없습니다. 대신 복사본을 만듭니다.

## 편집기

| 컨트롤 | 용도 |
|---|---|
| **대시보드로 돌아가기** | 편집기를 닫고 대시보드로 돌아갑니다. |
| 대시보드 제목 | 현재 위치에서 대시보드 이름을 변경합니다. |
| **실행 취소** / **다시 실행** | 편집기를 연 이후의 변경 사항을 한 단계씩 되돌리거나 다시 적용합니다. |
| **추가** | **패널**, **텍스트**, **행**, **그룹** 또는 **탭**을 추가합니다. |
| **설정** | [대시보드 설정](#대시보드-설정)을 엽니다. |
| **저장** | 대시보드를 저장합니다. 이 버튼을 선택하기 전에는 변경 사항을 저장하지 않습니다. |

요소를 이동하려면 핸들을 드래그하고, 크기를 조정하려면 모서리를 드래그합니다. 요소를 선택하면
사이드 패널에서 위치와 구조를 편집할 수 있습니다. 새 대시보드는 24열 그리드를 사용합니다. 그리드는 다음 메뉴에서 변경합니다.
[설정 → 일반](#대시보드-설정)

## 요소

| 요소 | 용도 |
|---|---|
| **패널** | 하나 이상의 쿼리 결과를 시각화로 표시합니다. |
| **텍스트** | 고정된 Markdown 또는 일반 텍스트로 메모, 제목, 링크를 표시합니다. |
| **행** | 전체 너비를 차지하는 헤더로, 아래의 요소를 묶습니다. **처음에 접힌 상태**로 설정할 수 있습니다. |
| **그룹** | 관련 요소를 하나의 상자에 모읍니다. |
| **탭** | 탭마다 별도의 요소를 배치합니다. 처음에 열 탭을 선택합니다. |

## 패널 편집

패널 메뉴에서 **편집**을 선택하거나 패널을 추가합니다. 패널 편집기에는 현재 시간 범위와 변수를 적용한
패널의 **실시간 미리보기**와 두 가지 탭 모음이 표시됩니다.

| 탭 | 내용 |
|---|---|
| **쿼리**, **변환**, **데이터 링크** | 패널에서 읽을 데이터, 결과의 변환 방식, 클릭 시 이동할 대상을 설정합니다. |
| **패널**, **필드**, **재정의** | 패널의 모양, 값의 표시 방식, 특정 필드에 적용할 예외를 설정합니다. |

### 쿼리

패널에 넣을 쿼리마다 **쿼리 추가**를 선택합니다. 각 쿼리에는 `A`와 같은 **참조 ID**,
**데이터 소스**, **PromQL** 또는 **SQL** 중 하나를 지정하는 **언어**, **표현식**이 있습니다. 데이터 소스에 따라
기본 언어와 기타 필드가 달라집니다.

| 데이터 소스 | 기본 언어 | 기타 필드 |
|---|---|---|
| **메트릭** | PromQL | |
| **로그**, **트레이스**, **SQL** | SQL | **스트림 이름** 및 **스트림 유형**(**로그**, **메트릭** 또는 **트레이스**) |
| **프로필** | SQL | **서비스** 및 **프로파일 유형**(예: `cpu`) |

**범례**에서는 `{{service}}`와 같은 템플릿으로 시리즈 이름을 지정합니다. **공유 쿼리**에서는
다른 패널의 쿼리를 `<panel-id>:<ref-id>` 형식으로 지정해 재사용하므로 데이터를 한 번만 읽습니다. 쿼리에는
`$service`와 같은 [변수](/ko/dashboards/variables)를 사용할 수 있습니다. SQL 및
PromQL에 대한 자세한 내용은 [쿼리 사용](/ko/query)을 참조합니다.

[RUM 탐색기](/ko/rum/explorer#대시보드에-추가)에서 추가하는 패널처럼 `format`이 `time_series`인 SQL 쿼리는
시각과 그룹의 조합마다 한 행을 반환하는 롱 형식을 사용할 수 있습니다. 시계열 시각화는 텍스트
열의 값 조합마다 시리즈를 하나씩 그리고, 해당 값으로 시리즈 이름을 지정합니다.

### 변환

변환은 결과를 표시하기 전에 데이터 구조를 바꿉니다. 변환은 순서대로 실행하며, 각각 비활성화할 수 있습니다.

| 변환 | 효과 |
|---|---|
| **필드 필터링**, **필드 정리**, **필드 이름 변경** | 필드를 유지하거나 정렬하고, 숨기거나 이름을 변경합니다. |
| **필드 계산** | 다른 필드에서 계산한 값으로 필드를 추가합니다. |
| **축소** | 각 시리즈를 마지막 값, 평균, 최댓값, 합계 등의 값으로 축소합니다. |
| **그룹화 기준**, **정렬 기준**, **제한** | 필드를 기준으로 집계하고, 정렬하고, 앞쪽 행만 남깁니다. |
| **참여**, **병합** | 여러 쿼리의 결과를 결합합니다. |
| **레이블을 필드로 변환**, **행을 필드로 변환**, **시계열을 테이블로 변환** | 레이블, 행 또는 시리즈를 열로 변환합니다. |

### 패널 옵션

**패널** 탭에서는 **제목**, 마우스 포인터를 올리면 표시되는 **설명**, **너비**와 **높이**,
**시각화**와 해당 옵션, 패널의 **투명** 여부를 설정합니다.

| 시각화 | 표시 내용 |
|---|---|
| **시계열** | 시간에 따른 값을 선, 막대 또는 점으로 표시합니다. 범례, 툴팁, 채우기, 누적 옵션을 제공합니다. |
| **막대 차트** | 범주별 값을 비교해 표시합니다. |
| **막대 게이지** | 축소한 값을 가로 또는 세로 막대로 표시합니다. |
| **통계** | 마지막 값과 같은 단일 값을 표시합니다. 스파크라인을 추가할 수 있습니다. |
| **게이지** | 임계값 색상을 적용한 원형 눈금에 단일 값을 표시합니다. |
| **테이블** | 행을 페이지 단위로 표시합니다. |
| **로그** | 시간과 수준을 포함한 간결한 로그 목록을 표시합니다. |
| **히트맵** | 시간에 따른 값의 강도를 표시합니다. |
| **상태 타임라인** | 시간에 따른 상태 변화를 표시합니다. |
| **텍스트** | Markdown을 표시합니다. |

**반복 변수**는 변수 값마다 패널 복사본을 하나씩 표시합니다. **반복 방향**으로
**가로**, **세로** 또는 **그리드**를 선택하고, **행당 최대 개수**로 한 행에 표시할 복사본 수를 제한합니다. 자세한 내용은 다음을 참조합니다.
[패널 반복](/ko/dashboards/variables#변수로-패널-반복)

### 필드 옵션

**필드** 탭에서는 값의 표시 방식을 설정합니다.

| 옵션 | 용도 |
|---|---|
| **단위**, **소수 자릿수** | 바이트, 퍼센트, 초 등의 단위와 소수 자릿수를 지정합니다. |
| **최솟값**, **최댓값** | 눈금의 하한과 상한을 지정합니다. |
| **표시 이름** | 필드 이름 대신 표시할 이름을 지정합니다. |
| **색상 구성표** | 고정 색상, 팔레트, 임계값 색상 또는 연속 색상 눈금을 지정합니다. |
| **임계값** | **기준값**에서 시작해 색상이 바뀌는 값을 **절대값** 또는 **백분율** 모드로 지정합니다. |
| **값 매핑** | 특정 값, 값 범위, 정규식과 일치하는 값 또는 null 같은 특수 값에 텍스트, 색상 또는 아이콘을 표시합니다. |
| **값이 없을 때 표시할 텍스트** | 값이 없을 때 패널에 표시할 텍스트를 지정합니다. |

**재정의**는 특정 필드에만 다른 필드 옵션을 적용합니다. **재정의 추가**를 선택하고 일치 조건
(**필드 이름**, **필드 정규식**, **필드 유형** 또는 **쿼리 참조**)을 지정한 후, **속성 추가**를 선택해
변경할 옵션을 하나씩 추가합니다.

### 데이터 링크

데이터 링크를 사용하면 값을 클릭해 지정한 대상으로 이동할 수 있습니다. **데이터 링크 추가**를 선택하고 **제목**을 입력한 다음
대상을 선택합니다. **로그**, **메트릭**, **트레이스**, **프로필**, 다른 **대시보드** 또는 **외부**
URL을 지정할 수 있습니다. 시간 범위와 대시보드 변수를 링크에 전달할지, 링크를
새 탭에서 열지 선택합니다. 링크는 패널 메뉴에 표시됩니다.

## 대시보드 설정

**설정**에는 네 개의 탭이 있습니다.

| 탭 | 내용 |
|---|---|
| **일반** | **제목**, **설명**, **태그**를 설정합니다. 기본 시간 범위(**시작**, **종료**)와 **시간대**를 설정합니다. **그리드**에서는 **열** 수(1~48), **행 높이**, **간격**을 설정합니다. **새로 고침**은 **꺼짐**, **실행 간격**(**기본 간격** 지정), **자동** 중에서 선택합니다. **그래프 툴팁**을 끄거나 패널 간에 십자선을 공유할 수 있습니다. **편집 가능** 여부도 설정합니다. |
| **변수** | 대시보드의 변수를 설정합니다. [변수](/ko/dashboards/variables)를 참조합니다. |
| **주석** | 시계열 패널에 표시할 이벤트를 설정합니다. |
| **링크** | 대시보드 상단에 표시할 링크를 설정합니다. |

주석에는 **이름**, **소스**, **선**, **리전**, **마커** 중 하나를 지정하는 **표시**,
**색상**, **활성화** 설정이 있습니다. **이벤트**에서 **이벤트 추가**를 선택하고 **레이블**과
**시작 타임스탬프 (ms)**를 입력합니다. 리전에는 **종료 타임스탬프 (ms)**도 입력합니다.

링크에는 **제목**, **대시보드** 또는 **외부** 중 하나를 지정하는 **유형**, **URL**이 있습니다. 스위치로
**시간 범위**와 **변수**를 전달할지, **새 탭**에서 열지 설정합니다.

## 저장 및 재사용

**저장**을 선택합니다. 패널을 재사용하려면 패널 메뉴에서 **복사**를 선택해 JSON을 복사한 후
다른 대시보드에 붙여넣습니다. 대시보드 전체를 재사용하려면 **JSON 내보내기**를 선택한 후 다른 곳에서 가져옵니다. 자세한 내용은 다음을 참조합니다.
[대시보드 가져오기](/ko/dashboards#대시보드-가져오기).
