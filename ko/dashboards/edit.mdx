편집기를 열려면 **대시보드**에서 **새 대시보드**를 선택하거나 대시보드에서 **편집**을 선택합니다. 대시보드를 생성하려면
`dashboards.create` 권한이 필요하고, 대시보드를 변경하려면 `dashboards.edit` 권한이 필요합니다. 기본 제공 대시보드처럼
**편집 가능** 설정이 꺼진 대시보드는 변경할 수 없습니다: 대신 복사본을 생성합니다.

## 편집기

| 컨트롤 | 용도 |
|---|---|
| **대시보드로 돌아가기** | 편집기에서 나갑니다. |
| 대시보드 제목 | 대시보드의 이름을 그 자리에서 바꿉니다. |
| **실행 취소** / **다시 실행** | 편집기를 연 이후의 변경 사항 사이를 앞뒤로 이동합니다. |
| **추가** | **패널**, **텍스트**, **행**, **그룹** 또는 **탭**을 추가합니다. |
| **설정** | [대시보드 설정](#대시보드-설정)을 엽니다. |
| **저장** | 대시보드를 저장합니다. 저장하기 전에는 아무것도 저장되지 않습니다. |

요소의 핸들을 드래그하여 이동하고, 모서리를 드래그하여 크기를 조정합니다. 요소를 선택하여
사이드 패널에서 위치와 구조를 편집합니다. 새 대시보드는 24열 그리드를 사용합니다. 그리드는
[설정 → 일반](#대시보드-설정)에서 변경합니다.

## 요소

| 요소 | 용도 |
|---|---|
| **패널** | 하나 이상의 쿼리를 시각화로 그립니다. |
| **텍스트** | 메모, 제목, 링크를 위한 정적 Markdown 또는 일반 텍스트입니다. |
| **행** | 너비 전체를 차지하는 헤더로, 아래 요소를 담습니다. 행은 **처음에 접힌 상태**로 시작할 수 있습니다. |
| **그룹** | 관련 요소를 함께 묶는 상자입니다. |
| **탭** | 여러 탭으로, 각 탭에는 고유한 요소가 있습니다. 처음에 열 탭을 선택합니다. |

## 패널 편집

패널 메뉴에서 **편집**을 선택하거나 패널을 추가합니다. 패널 편집기에는 현재 시간 범위와 변수를 사용하는
패널의 **실시간 미리보기**와 두 세트의 탭이 표시됩니다:

| 탭 | 내용 |
|---|---|
| **쿼리**, **변환**, **데이터 링크** | 패널이 읽는 데이터, 결과를 재구성하는 방식, 클릭 시 이동할 위치입니다. |
| **패널**, **필드**, **재정의** | 패널의 모양, 값이 표시되는 방식, 일부 필드에 대한 예외입니다. |

### 쿼리

패널의 각 쿼리에 대해 **쿼리 추가**를 선택합니다. 각 쿼리에는 `A`와 같은 **참조 ID**,
**데이터 소스**, **PromQL** 또는 **SQL**의 **언어**, **표현식**이 있습니다. 데이터 소스는
기본 언어와 기타 필드를 결정합니다:

| 데이터 소스 | 기본 언어 | 기타 필드 |
|---|---|---|
| **메트릭** | PromQL | |
| **로그**, **트레이스**, **SQL** | SQL | **스트림 이름**과 **스트림 유형**(**로그**, **메트릭** 또는 **트레이스**). |
| **프로필** | SQL | **서비스**와 **프로파일 유형**, 예: `cpu`. |

**범례**는 `{{service}}`와 같은 템플릿으로 시리즈 이름을 지정합니다. **공유 쿼리**는
다른 패널의 쿼리를 `<panel-id>:<ref-id>` 형식으로 재사용하므로 데이터를 한 번만 읽습니다. 쿼리에서는
`$service`와 같은 [변수](/ko/dashboards/variables)를 사용할 수 있습니다. SQL 및
PromQL에 대한 내용은 [쿼리](/ko/query)를 참조하십시오.

`format`이 `time_series`인 SQL 쿼리는 [RUM 탐색기](/ko/rum/explorer#대시보드에-추가)가 추가하는 패널에서처럼
긴 형식, 즉 시간과 그룹마다 한 행으로 응답할 수 있습니다. 시계열은 텍스트 열 값의 각 조합마다
시리즈를 그리며, 해당 값으로 이름을 지정합니다.

### 변환

변환은 결과를 그리기 전에 재구성합니다. 변환은 순서대로 실행되며, 각 변환을 비활성화할 수 있습니다.

| 변환 | 효과 |
|---|---|
| **필드 필터링**, **필드 정리**, **필드 이름 변경** | 필드를 유지하거나 순서를 지정하고, 숨기거나 이름을 바꿉니다. |
| **필드 계산** | 다른 필드에서 계산한 필드를 추가합니다. |
| **축소** | 각 시리즈를 마지막 값, 평균, 최댓값 또는 합계와 같은 값으로 축소합니다. |
| **그룹화 기준**, **정렬 기준**, **제한** | 필드별로 집계하고 정렬한 뒤 처음 행을 유지합니다. |
| **참여**, **병합** | 여러 쿼리의 결과를 결합합니다. |
| **레이블을 필드로 변환**, **행을 필드로 변환**, **시계열을 테이블로 변환** | 레이블, 행 또는 시리즈를 열로 변환합니다. |

### 패널 옵션

**패널** 탭에서는 **제목**, 마우스를 올리면 표시되는 **설명**, **너비**와 **높이**,
**시각화**와 그 옵션, 패널의 **투명** 여부를 설정합니다.

| 시각화 | 표시 내용 |
|---|---|
| **시계열** | 시간에 따른 선, 막대 또는 점을 그리며, 범례, 툴팁, 채우기, 누적 옵션을 제공합니다. |
| **막대 차트** | 범주별로 값을 비교합니다. |
| **막대 게이지** | 축소된 값을 가로 또는 세로 막대로 표시합니다. |
| **통계** | 마지막 값과 같은 단일 값을 선택적 스파크라인과 함께 표시합니다. |
| **게이지** | 임계값 색상이 있는 방사형 눈금에 단일 값을 표시합니다. |
| **테이블** | 행을 페이지 단위로 표시합니다. |
| **로그** | 시간과 레벨이 포함된 간결한 로그 목록을 표시합니다. |
| **히트맵** | 시간에 따른 값의 강도를 표시합니다. |
| **상태 타임라인** | 시간에 따른 상태 변화를 표시합니다. |
| **텍스트** | Markdown을 표시합니다. |

**반복 변수**는 변수의 각 값마다 패널 복사본을 하나씩 그리며, **반복 방향**은
**가로**, **세로**, **그리드** 중 하나이고, 한 행에 **행당 최대 개수**까지 복사본을 그립니다. 자세한 내용은
[패널 반복](/ko/dashboards/variables#변수로-패널-반복)을 참조하십시오.

### 필드 옵션

**필드** 탭에서는 값이 표시되는 방식을 설정합니다:

| 옵션 | 용도 |
|---|---|
| **단위**, **소수 자릿수** | 바이트, 퍼센트, 초와 같은 단위와 소수 자릿수입니다. |
| **최솟값**, **최댓값** | 눈금의 양 끝입니다. |
| **표시 이름** | 필드 이름을 대체합니다. |
| **색상 구성표** | 고정 색상, 팔레트, 임계값 색상 또는 연속 눈금입니다. |
| **임계값** | 색상이 변경되는 값이며, **절대값** 또는 **백분율** 모드에서 **기준값**부터 시작합니다. |
| **값 매핑** | 값, 범위, 정규식 일치 또는 null과 같은 특수 값에 대해 텍스트, 색상 또는 아이콘을 표시합니다. |
| **값이 없을 때 표시할 텍스트** | 값이 없을 때 패널에 표시하는 텍스트입니다. |

**재정의**는 일부 필드에만 다른 필드 옵션을 적용합니다. **재정의 추가**를 선택하고,
(**필드 이름**, **필드 정규식**, **필드 유형** 또는 **쿼리 참조**) 중 일치 조건을 선택한 다음, 변경할 각 옵션에
**속성 추가**를 선택합니다.

### 데이터 링크

데이터 링크는 값 클릭을 이동으로 전환합니다. **데이터 링크 추가**를 선택하고 **제목**을 입력한 다음
대상을 선택합니다: **로그**, **메트릭**, **트레이스**, **프로필**, 다른 **대시보드** 또는 **외부**
URL입니다. 링크가 시간 범위와 대시보드 변수를 전달하는지, 새 탭에서 열지 여부를 선택합니다.
링크는 패널 메뉴에 표시됩니다.

## 대시보드 설정

**설정**에는 네 개의 탭이 있습니다.

| 탭 | 내용 |
|---|---|
| **일반** | **제목**, **설명**, **태그**입니다. 기본 시간 범위(**시작**, **종료**)와 **시간대**입니다. **그리드**: 1~48의 **열**, **행 높이**, **간격**입니다. **새로 고침**: **꺼짐**, **기본 간격**이 있는 **실행 간격** 또는 **자동**입니다. **그래프 툴팁**: 꺼짐 또는 패널 간 공유 십자선입니다. **편집 가능**. |
| **변수** | 대시보드의 변수입니다. [변수](/ko/dashboards/variables)를 참조하십시오. |
| **주석** | 시계열 패널에 그려지는 이벤트입니다. |
| **링크** | 대시보드 상단의 링크입니다. |

주석에는 **이름**, **소스**, **표시**(**선**, **리전** 또는 **마커**),
**색상**, **활성화**가 있습니다. **이벤트 추가**로 **이벤트** 아래에 이벤트를 나열합니다: **레이블**,
**시작 타임스탬프 (ms)**, 리전의 경우 **종료 타임스탬프 (ms)**입니다.

**배포** 소스의 주석은 이벤트를 나열하지 않습니다. 모든 시계열 패널에서
[변경 목록](/ko/api/changes)의 변경 사항을 표시합니다. 변경 사항에는 배포 및 기타 보고된 변경과
APM이 처음 확인한 버전이 포함되며, **서비스**(쉼표로 구분)에 지정된 서비스 또는 모든
서비스의 변경 사항을 대상으로 합니다. 이 대시보드 또는 대시보드 없이
[`POST /api/v1/changes`](/ko/api/changes#어노테이션-관리)로 유지한 주석도 해당 시계열 패널에 그려집니다.

링크에는 **제목**, **대시보드** 또는 **외부**의 **유형**, **URL**,
**시간 범위**와 **변수**를 전달하고 **새 탭**에서 열도록 하는 스위치가 있습니다.

## 저장 및 재사용

**저장**을 선택합니다. 패널을 재사용하려면 패널 메뉴에서 **복사**를 선택하여 JSON을 복사한 다음,
다른 대시보드에 붙여넣습니다. 전체 대시보드를 재사용하려면 **JSON 내보내기**를 실행하고 다른 곳으로 가져옵니다. 자세한 내용은
[대시보드 가져오기](/ko/dashboards#대시보드-가져오기)를 참조하십시오.
