**메트릭**을 열어 메트릭 스트림에 저장된 시계열을 PromQL로 쿼리합니다. 쿼리는
탭에서 실행합니다. 탭을 나란히 배치할 수 있으며, [로그](/ko/logs#쿼리-탭)에서와 마찬가지로
**공유**를 누르면 쿼리 링크를 복사합니다. 주소 표시줄에는 마지막으로 실행한 쿼리문이 표시되므로
주소를 복사해도 쿼리를 공유할 수 있습니다.

## 메트릭 찾기

편집기 옆의 **메트릭 브라우저**를 열거나 **메트릭 검색**을 선택한 뒤 이름의 일부를 입력합니다. 각
메트릭에는 유형(**카운터**, **히스토그램** 또는 **게이지**)과 레이블 및 필드 개수가 표시됩니다.
메트릭을 선택하면 쿼리에 추가하고 실행합니다. 작업 공간이 비어 있으면 **메트릭
소스 연결** 옵션이 표시됩니다. [데이터 소스](/ko/intake)를 참조합니다.

스트림의 보존 기간 동안 수집된 적이 없는 메트릭은 목록에서 사라집니다.

## 쿼리 작성하기

편집기에는 두 가지 모드가 있습니다. 제목 옆의 아이콘으로 전환합니다(`</>`는 코드, 블록 아이콘은 빌더).

- **코드**: PromQL을 직접 작성합니다. **자주 사용하는 PromQL 함수**에서 일반적인 함수를 확인할 수 있습니다.
  [PromQL 지원 매트릭스](/ko/query/promql-subset)에는 구현된 모든 함수가 나열되어 있습니다.
- **빌더**: **메트릭**을 선택하고 일치시킬 레이블마다 **레이블 필터 추가**를 선택합니다. 그런 다음 **함수**
  (**원본 메트릭**, **변화율**, **순간 변화율** 또는 **증가량**), **집계**(**합계**,
  **평균**, **최댓값** 또는 **최솟값**), **범위**를 선택합니다. 생성된 PromQL은 아래에 표시됩니다.
  추가 매개변수가 있는 함수처럼 빌더에서 표현할 수 없는 식은
  빌더의 필드를 변경하기 전까지 그대로 유지됩니다.

```promql
sum by (service_name) (
  rate(http_server_request_duration_seconds_count[5m])
)
```

**실행**을 누릅니다. **옵션**에서 쿼리 실행 방식을 설정합니다.

| 옵션 | 선택 항목 |
|---|---|
| **범례** | **자동**, **상세**(모든 레이블) 또는 `{{service}}`와 같은 템플릿을 사용하는 **사용자 지정**입니다. |
| **형식** | **시계열** 또는 **테이블**입니다. |
| **단계** | 범위를 1,000단계로 나누는 **자동** 또는 `30s`, `5m`과 같은 시간 간격입니다. |
| **유형** | 전체 시간 범위의 차트를 표시하는 **범위** 또는 범위 종료 시점의 값을 표시하는 **즉시**입니다. |
| **예시 데이터** | **켜짐**으로 설정하면 데이터 포인트를 트레이스에 연결하는 예시 데이터를 표시합니다. |

**대시보드에 추가**를 선택하면 쿼리를 첫 번째 패널에 배치한 새 대시보드를 엽니다. **쿼리 지우기**를 선택하면
편집기를 비웁니다. 유효한 쿼리에 결과가 없으면 **시간 범위 4배 확장**과 **필터 지우고 다시 시도**를 사용해
식을 변경하기 전에 다시 확인합니다.

## 차트 읽기

- 플롯 위에서 드래그해 원하는 시간 범위를 확대하고, X축을 드래그해 표시 범위를 이동하고, 두 번 클릭해
  축소합니다. **시간 범위 초기화**를 선택하면 차트를 조작하기 전의 범위로 돌아갑니다.
- **그리기 스타일**(**선**, **막대** 또는 **점**)과 **누적**(**꺼짐**, **정상** 또는
  **백분율**)을 선택합니다. 누적에는 시리즈가 두 개 이상 필요합니다.
- 범례를 사용해 특정 시리즈만 표시하거나 여러 시리즈를 비교합니다.
- 예시 데이터를 켠 상태에서 마름모를 선택해 해당 트레이스를 확인하고, **트레이스 열기**를 선택해 데이터 포인트에 해당하는
  요청을 살펴봅니다.

트레이스나 로그로 이동해도 확대된 시간 범위를 유지합니다.

## 결과 분석하기

**그래프**는 결과를 차트로, **테이블**은 원시 행으로 표시하며, **쿼리 검사기**는 실행한 쿼리를
표시합니다. 결과 주변의 패널에서 데이터에 관한 세부 정보를 확인합니다.

| 패널 | 표시 내용 |
|---|---|
| **시리즈** | 각 시리즈의 레이블과 마지막 값, 현재 값, 평균값, 최댓값입니다. |
| **쿼리 통계** | 시리즈, 데이터 포인트, 스캔한 행, 쿼리 실행 시간, 범위 및 단계입니다. |
| **데이터 품질** | 음수 데이터 포인트, 누락된 데이터, 타임스탬프 이상 항목입니다. 카운터의 변화율이 음수라면 카운터가 초기화되었거나, 데이터가 순서에 맞지 않게 도착했거나, 유형이 잘못 지정된 경우입니다. **이상 항목 보기**, **원시 데이터 보기** 또는 **메트릭 유형 확인**을 사용합니다. |
| **상위 레이블** | 결과에서 가장 큰 비중을 차지하는 레이블 값입니다. |
| **통계 요약** | 모든 시리즈 값의 분포입니다. |
| **카디널리티** | 메트릭의 활성 시리즈와 스캔한 행입니다. 시리즈를 너무 많이 생성하는 레이블을 찾는 데 사용합니다. |
| **결과 스키마** | 결과의 시간, 값 및 레이블 열입니다. |

인스턴스는 [메트릭 카디널리티 제한](/ko/settings/platform#메트릭-카디널리티)을 초과하는 새 시리즈를
거부합니다. 값이 많은 레이블을 추가하기 전에 **카디널리티**를 확인합니다.

## 메트릭 급증과 관련 신호 연결하기

급증이 발생한 시간 범위를 선택하고 서비스 및 환경 레이블을 유지한 다음 관련 트레이스나
로그를 엽니다. MoleSignal은 선택한 범위를 다음 신호에도 적용합니다.
[신호 간 상관관계](/ko/correlation)를 참조합니다.

## 권한

메트릭 목록을 조회하려면 `metrics.read`가 필요합니다. PromQL을 실행하려면 `streams.query`가 필요합니다. **대시보드에 추가**를 사용하려면
`dashboards.create`가 필요합니다.
