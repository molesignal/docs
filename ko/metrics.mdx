**메트릭**을 열어 메트릭 스트림에 저장된 시계열을 PromQL로 쿼리합니다. 쿼리는 탭에서 실행되며,
탭은 나란히 배치할 수 있고 **공유**는 쿼리 링크를 복사합니다. 예를 들어
[Logs](/ko/logs#쿼리-탭)에서와 같습니다. 주소 표시줄에는 마지막으로 실행된 구문이 남아 있으므로, 이를 복사하면
쿼리가 공유됩니다.

## 메트릭 찾기

편집기 옆에서 **메트릭 브라우저**를 열거나 **메트릭 검색**을 사용한 뒤 이름의 일부를 입력합니다. 각
메트릭에는 유형(**카운터**, **히스토그램**, **게이지**)과 레이블 및 필드 개수가 표시됩니다.
메트릭을 선택해 쿼리에 넣고 실행합니다. 작업 공간이 비어 있으면 **메트릭 소스 연결**이 표시됩니다.
[데이터 소스](/ko/intake)를 참조하세요.

스트림의 보존 기간 내에 확인되지 않은 메트릭은 목록에서 사라집니다.

## 쿼리 작성

편집기에는 제목 옆의 두 아이콘으로 전환하는 두 가지 모드가 있습니다(코드는 `</>`, 빌더는 블록 아이콘):

- **코드**: PromQL을 직접 작성합니다. **자주 사용하는 PromQL 함수**에 일반적인 함수가 나열되며,
  [PromQL 지원 매트릭스](/ko/query/promql-subset)에 구현된 함수가 모두 나열됩니다.
- **빌더**: **메트릭**을 선택하고, 일치시킬 각 레이블에 **레이블 필터 추가**를 설정하며, **함수**
  (**원본 메트릭**, **변화율**, **순간 변화율**, **증가량**), **집계**(**합계**,
  **평균**, **최댓값**, **최솟값**), **범위**를 지정합니다. 빌더가 만드는 PromQL은 아래에 표시됩니다.
  추가 매개변수가 있는 함수처럼 빌더가 표현할 수 없는 식은 빌더 필드를 변경할 때까지
  그대로 유지됩니다.

```promql
sum by (service_name) (
  rate(http_server_request_duration_seconds_count[5m])
)
```

**실행**을 누릅니다. **옵션**에서 쿼리 실행 방식을 설정합니다:

| 옵션 | 선택지 |
|---|---|
| **범례** | **자동**, **상세**(모든 레이블), 또는 `{{service}}` 같은 템플릿을 쓰는 **사용자 지정**. |
| **형식** | **시계열** 또는 **테이블**. |
| **단계** | 범위를 1,000단계로 나누는 **자동**, 또는 `30s`, `5m` 같은 기간. |
| **유형** | 시간 범위 전체의 차트를 그리는 **범위**, 또는 범위 끝의 값을 보여주는 **즉시**. |
| **예시 데이터** | **켜짐**이면 지점을 트레이스에 연결하는 예시 데이터를 그립니다. |

**대시보드에 추가**는 쿼리를 첫 번째 패널로 하는 새 대시보드를 엽니다. **쿼리 지우기**는
편집기를 비웁니다. 유효한 쿼리가 아무것도 찾지 못하면 식을 변경하기 전에 **시간 범위 4배 확장**과
**필터 지우고 다시 시도**가 도움이 됩니다.

## 차트 읽기

- 그래프를 드래그해 시간 범위를 확대하고, X축을 드래그해 이동하며, 두 번 클릭해 축소합니다.
  **시간 범위 초기화**는 차트를 조작하기 전의 범위로 돌아갑니다.
- **그리기 스타일**(**선**, **막대**, **점**)과 **누적**(**꺼짐**, **정상**, **백분율**;
  누적에는 시리즈가 두 개 이상 필요합니다)을 선택합니다.
- 범례를 사용해 시리즈를 분리하거나 비교합니다.
- **비교**는 차트에 동일한 쿼리를 기준선 위에 겹쳐 표시하며, 각 시리즈는 고유한 색의 점선으로
  표시됩니다. 기본값은 이전의 같은 길이 구간이고, 하루 또는 일주일 전 같은 시각이나 자체 시간
  범위를 지정할 수도 있습니다. 기준선이 표시되는 동안에는 누적이 꺼지며, 기준선 옆의 닫기
  버튼을 누르면 기준선이 제거됩니다. 즉시 쿼리에는 기준선이 없습니다.
- 예시 데이터가 켜져 있으면 다이아몬드를 선택해 해당 트레이스를 확인하고, **트레이스 열기**로 해당 지점
  뒤의 요청을 살펴봅니다.

확대한 범위는 트레이스나 로그로 이동할 때 함께 유지됩니다.

## 결과 분석

**그래프**, **테이블**, **쿼리 검사기**는 결과를 각각 차트, 원시 행, 실행된 쿼리로 보여줍니다.
결과 주변의 패널은 데이터를 설명합니다:

| 패널 | 표시 내용 |
|---|---|
| **시리즈** | 각 시리즈의 레이블과 마지막 값, 현재 값, 평균, 최댓값. |
| **쿼리 통계** | 시리즈, 데이터 포인트, 스캔한 행, 쿼리 시간, 범위, 단계. |
| **데이터 품질** | 음수 지점, 누락된 데이터, 타임스탬프 이상. 음수 변화율을 가진 카운터는 재설정되었거나, 순서가 뒤바뀌어 도착했거나, 유형이 잘못된 것입니다: **이상 항목 보기**, **원시 데이터 보기**, **메트릭 유형 확인**. |
| **상위 레이블** | 결과에서 비중이 가장 큰 레이블 값. |
| **통계 요약** | 모든 시리즈 값의 분포. |
| **카디널리티** | 메트릭의 활성 시리즈와 스캔한 행. 시리즈를 너무 많이 만드는 레이블을 찾는 데 사용합니다. |
| **결과 스키마** | 결과의 시간, 값, 레이블 열. |

인스턴스의 [메트릭 카디널리티 한도](/ko/settings/platform#메트릭-카디널리티)는 한도를 넘는 새
시리즈를 거부하므로, 값이 많은 레이블을 추가하기 전에 **카디널리티**를 확인합니다.

## 메트릭 급증 연관 분석

급증 구간을 선택하고 서비스 및 환경 레이블을 유지한 다음, 관련 트레이스나 로그를 엽니다.
MoleSignal은 선택한 범위를 다음 시그널로 가져갑니다. [신호 간 연관 분석](/ko/correlation)을
참조하세요.

## 권한

메트릭 목록 조회에는 `metrics.read`가 필요합니다. PromQL 실행에는 `streams.query`가 필요합니다.
**대시보드에 추가**에는 `dashboards.create`가 필요합니다.
