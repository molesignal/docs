모든 시그널은 수집 API를 통해 MoleSignal로 들어옵니다. 웹 UI의 **데이터 소스** 페이지는 각 소스에 사용할 엔드포인트, 토큰, 구성 스니펫을 생성합니다. 같은 프로토콜을 수동으로 구성할 수도 있습니다.

## 데이터 소스 페이지

소스를 추가하려면 **데이터 소스**를 엽니다.

1. 카탈로그를 검색하거나 **권장**, **인프라**, **클라우드**, **데이터베이스**, **메시징**, **앱 및 언어**, **보안**, **사용자 지정** 카테고리로 필터링합니다. 시그널 탭(**로그**, **메트릭**, **트레이스**, **프로필**)을 사용하면 목록을 더 좁힐 수 있습니다.
2. Kubernetes, Linux 호스트, AWS, OpenTelemetry SDK, Web RUM 등의 소스를 선택합니다.
3. 가이드의 세 단계를 따릅니다.
   - **엔드포인트 및 토큰**에는 데이터를 보낼 주소와 인증에 사용할 토큰이 표시됩니다. **토큰 표시**를 선택하면 토큰과 함께 권한 범위, 워크스페이스, 만료 시점이 표시됩니다. RUM 소스의 경우 먼저 **RUM 애플리케이션**을 선택합니다. 선택하면 해당 애플리케이션의 클라이언트 토큰이 표시됩니다.
   - **소스 설정**에는 실제 엔드포인트와 토큰이 이미 입력된 명령과 구성이 표시됩니다.
   - **데이터 수신 확인**에서는 먼저 수신기를 확인한 다음 최근 1시간 동안 수신한 데이터가 있는지 확인합니다. **연결 확인**을 선택하면 즉시 확인하며, 수치는 30초마다 갱신됩니다.
4. 검증 결과를 확인합니다.
   - **데이터 수신 확인됨**: 최근 1시간 동안 데이터를 수신했으며 소스의 시그널이 정상입니다. **수신 데이터 보기**를 선택하면 데이터를 열고, **파이프라인 만들기**를 선택하면 해당 데이터의 파이프라인 생성을 시작합니다.
   - **수신기는 정상이지만 데이터 확인 필요**: 수신기가 응답하지만 데이터를 수신하지 못했거나 일부 시그널이 비정상입니다. 배포 상태를 확인하거나 다음 배치가 도착할 때까지 기다립니다.
   - **검증 실패**: 수신기를 확인하지 못했습니다. **가능한 원인**에는 실행 중이 아닌 수집기, 유효하지 않거나 만료된 토큰, 엔드포인트를 차단하는 네트워크 또는 프록시가 표시됩니다.

`http.external_url`을 설정하면 해당 값을 엔드포인트로 사용하고, 설정하지 않으면 브라우저에서 접속한 주소를 사용합니다. 리버스 프록시 뒤에서 실행하는 경우 생성된 스니펫이 공개 주소를 가리키도록 `http.external_url`을 설정합니다. [구성](/ko/configuration)을 참조합니다.

## 수집 토큰

송신기는 Bearer 토큰으로 인증합니다: `Authorization: Bearer <token>`.

| 토큰 | 권한 | 생성 위치 | 용도 |
|---|---|---|---|
| 기본 수집 토큰 | **데이터 수집** 정책의 `logs.write`, `metrics.write`, `traces.write`, `profiles.write`, `apm.deploy` 권한만 부여 | 데이터 소스 페이지 또는 `GET /api/v1/me/api-tokens/default` | 로그, 메트릭, 트레이스를 보내는 수집기, 에이전트, SDK 익스포터와 [배포를 보고하는](/ko/apm/deployments#ci에서-배포-보고) 파이프라인에 사용합니다. 만료되지 않습니다. |
| RUM 클라이언트 토큰 | `rum.write` 권한만 부여하며 애플리케이션 하나에 연결 | Web RUM 및 모바일 RUM 소스의 데이터 소스 페이지 또는 `GET /api/v1/auth/tokens/rum?applicationId=<id>` | 브라우저 및 모바일 코드에 사용합니다. 최종 사용자에게 토큰이 노출됩니다. |
| 개인 또는 서비스 계정 토큰 | 멤버 또는 서비스 계정의 권한 중 토큰의 권한 범위에 해당하는 권한 | **계정 설정 → API 토큰** 또는 서비스 계정의 경우 **ID 및 액세스 → API 토큰** | 자동화, 스크립트, MCP 클라이언트에 사용합니다. |

지속적으로 실행되는 송신기에는 기본 수집 토큰이나 **데이터 수집** 정책을 따르는 서비스 계정 토큰을 사용합니다. 토큰 사용을 즉시 중지하려면 **계정 설정 → API 토큰** 또는 **ID 및 액세스 → API 토큰**에서 토큰을 해지합니다. 웹 UI 로그인 세션으로는 데이터를 보낼 수 없습니다. 세션은 브라우저 쿠키에 저장되며 `Authorization` 헤더는 해당 세션을 허용하지 않습니다.

**데이터 소스** 페이지에서 애플리케이션 ID를 입력하면 RUM 클라이언트 토큰이 생성됩니다. 애플리케이션 ID는 `A-Z`, `a-z`, `0-9`, `.`, `_`, `:`, `-` 중 1~128자로 구성합니다. SDK의 `applicationId`에도 같은 ID를 사용합니다. [브라우저 RUM SDK](/ko/rum/browser-sdk)를 참조합니다.

## 엔드포인트 및 프로토콜

| 프로토콜 | 엔드포인트 | 호환 송신기 | 대상 스트림 |
|---|---|---|---|
| 네이티브 HTTP JSON | `POST /api/v1/intake/{logs,metrics,traces}/{stream}` | `curl`, 애플리케이션 코드, Vector `http` 싱크, Fluent Bit `http` 출력 | 경로의 `{stream}` 세그먼트 |
| HTTP 기반 OTLP | `POST /api/v1/logs`, `/api/v1/metrics`, `/api/v1/traces` | OpenTelemetry SDK 및 Collector | `stream-name` 헤더, 없으면 `default` |
| gRPC 기반 OTLP | `:4317` | OpenTelemetry SDK 및 Collector | `stream-name` 메타데이터, 없으면 `default` |
| Prometheus remote_write | `POST /api/v1/prometheus/api/v1/write` | Prometheus, VictoriaMetrics, 그 밖의 모든 remote_write v1 송신기 | `stream-name` 헤더, 없으면 `default` |
| Elasticsearch `_bulk` | `POST /api/v1/_bulk` | Filebeat, Logstash, Vector `elasticsearch` 싱크 | 각 작업의 `_index`, 없으면 `stream-name` 헤더, 둘 다 없으면 `default` |
| Loki 푸시(JSON) | `POST /api/v1/loki/api/v1/push` | Loki JSON 형식으로 POST 요청을 보낼 수 있는 송신기 | `stream-name` 헤더, 없으면 `default` |
| Kinesis Firehose, Cloudflare Logpush, Heroku | `/api/v1/_kinesis_firehose`, `/api/v1/_cloudflare`, `/api/v1/_heroku` | AWS, Cloudflare, Heroku | 커넥터에서 구성합니다. [커넥터](/ko/connectors)를 참조합니다. |

푸시 커넥터를 제외한 모든 엔드포인트에는 해당 시그널의 쓰기 권한(`logs.write`, `metrics.write`, `traces.write` 또는 `profiles.write`)이 있는 Bearer 토큰이 필요합니다. 조직은 토큰에서 확인하며 URL에는 표시하지 않습니다.

### 송신기에 적용되는 제한

- **요청 크기.** 네이티브 JSON 수집 엔드포인트는 압축 해제 후 최대 16 MiB의 요청 본문을 허용합니다. 다른 수집 엔드포인트는 최대 2 MiB까지 허용합니다. 본문이 제한을 초과하면 `413`을 반환합니다. 배치 크기를 해당 제한 미만으로 유지합니다.
- **압축.** HTTP 기반 OTLP는 압축된 요청 본문을 허용하지 않으며 `400`을 반환합니다. 송신기에서 압축을 비활성화합니다. OpenTelemetry Collector의 `otlphttp` 익스포터는 기본적으로 gzip으로 압축하므로 `compression: none`을 설정합니다. 네이티브 JSON 수집, Elasticsearch `_bulk`, Loki 푸시 및 푸시 커넥터는 `Content-Encoding: gzip`을 허용합니다.
- **Loki 인코딩.** JSON 형식의 요청만 디코딩합니다. Promtail과 Grafana Alloy는 기본적으로 snappy로 압축한 protobuf를 전송하므로 이 엔드포인트로 데이터를 보낼 수 없습니다.
- **요청 속도 제한.** `router` 역할은 조직별 요청 수를 제한하며, 제한을 초과하면 `Retry-After` 헤더와 함께 `429`를 반환합니다. `standalone` 노드는 이 제한을 적용하지 않습니다. [역할 기반 배포](/ko/deployment/role-based#요청-속도-제한)를 참조합니다.
- **플랫폼 스트림.** 서비스 자체의 텔레메트리를 위한 `_molesignal`과 감사 추적을 위한 `_audit` 등의 [플랫폼 스트림](/ko/streams#플랫폼-스트림)에는 MoleSignal만 쓸 수 있습니다. 공개 수집 요청에는 `403`을 반환합니다.

## 스트림 및 스키마

스트림은 처음 데이터를 쓸 때 생성되며, 새 필드가 추가되면 스키마가 변경됩니다. 스트림은 이름과 시그널 유형으로 구분하므로 로그, 메트릭, 트레이스에 각각 `default` 스트림이 있을 수 있습니다. [스트림](/ko/streams)을 참조합니다.

모든 이벤트에는 Unix 에포크 이후 경과 시간을 마이크로초 단위로 나타내는 타임스탬프가 있습니다. 네이티브 JSON과 Elasticsearch `_bulk`는 `_timestamp` 필드를 읽습니다. `_timestamp`가 없는 이벤트에는 서버가 이벤트를 수신한 시각을 지정합니다.

## 네이티브 HTTP JSON

레코드 배열을 `/api/v1/intake/{logs,metrics,traces}/{stream}`에 POST 요청으로 보냅니다.

```bash
curl -X POST http://localhost:5080/api/v1/intake/logs/app \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "[{\"_timestamp\":$(date +%s)000000,\"level\":\"error\",\"msg\":\"db pool exhausted\",\"trace_id\":\"abc123\"}]"
```

응답에는 수락 및 거부된 레코드 수와 거부된 각 인덱스의 사유가 포함됩니다.

```json
{"accepted":1,"rejected":0,"errors":[]}
```

## OpenTelemetry

OpenTelemetry SDK 또는 Collector에서 기본 경로를 `/api`로 설정합니다. 익스포터는 `/v1/logs`, `/v1/metrics`, `/v1/traces`를 기본 경로에 붙여 각각 `/api/v1/logs`, `/api/v1/metrics`, `/api/v1/traces`로 전송합니다.

<Tabs>
  <Tab title="HTTP를 통한 OTLP">
    SDK 환경 변수:

    ```bash
    export OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
    export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5080/api
    export OTEL_EXPORTER_OTLP_HEADERS="authorization=Bearer ${MS_TOKEN}"
    ```

    OpenTelemetry Collector:

    ```yaml
    exporters:
      otlphttp/molesignal:
        endpoint: http://localhost:5080/api
        compression: none
        headers:
          authorization: "Bearer ${env:MS_TOKEN}"
    ```

    SDK와 Collector의 기본 인코딩인 protobuf(`application/x-protobuf`)로 전송합니다. 로그, 메트릭, 트레이스는 JSON(`application/json`)도 지원합니다. `default`가 아닌 스트림을 선택하려면 `stream-name` 헤더를 추가합니다. 이 헤더는 해당 익스포터를 통해 전송하는 모든 신호에 적용됩니다.
  </Tab>
  <Tab title="gRPC를 통한 OTLP">
    OTLP gRPC 리시버는 포트 `4317`에서 연결을 수신하고 로그, 메트릭, 트레이스, 프로파일 서비스를 제공합니다. 리시버는 TLS를 종료하지 않습니다. 신뢰할 수 있는 네트워크 외부로 나가는 트래픽의 TLS는 리시버 앞단에서 종료합니다.

    ```bash
    export OTEL_EXPORTER_OTLP_PROTOCOL=grpc
    export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317
    export OTEL_EXPORTER_OTLP_HEADERS="authorization=Bearer ${MS_TOKEN}"
    ```

    OpenTelemetry Collector:

    ```yaml
    exporters:
      otlp/molesignal:
        endpoint: localhost:4317
        tls:
          insecure: true
        headers:
          authorization: "Bearer ${env:MS_TOKEN}"
    ```

    해당 포트 앞단의 프록시에서 TLS를 종료하는 경우 `insecure: true`를 제거합니다. 포트 `5082`는 클러스터 내부용 gRPC 포트이며 OTLP를 수신하지 않습니다.
  </Tab>
</Tabs>

OTLP 메트릭은 데이터 포인트마다 이벤트 하나로 저장됩니다. 저장되는 필드는 [메트릭 저장 규약](/ko/query#otlp-메트릭-필드)을 참조합니다.

## Prometheus remote_write

`prometheus.yml`에서 MoleSignal을 원격 쓰기 대상으로 추가합니다.

```yaml
remote_write:
  - url: http://localhost:5080/api/v1/prometheus/api/v1/write
    authorization:
      credentials: "${MS_TOKEN}"
```

메트릭 스트림 하나에는 소스 하나의 메트릭이 들어갑니다. `remote_write` 항목의 `headers:`에서 `stream-name` 헤더를 설정해 Prometheus 서버마다 별도의 스트림을 지정합니다. 이 헤더가 없으면 샘플은 `default`로 전송됩니다. 샘플마다 행 하나가 생성되며, `metric_name`에는 해당 샘플의 `__name__` 값이 들어갑니다. 나머지 레이블은 필드가 됩니다. 이름이 `metric_name`과 같은 메트릭 필드와 겹치는 레이블은 `exported_<name>`으로 저장됩니다. 네이티브 히스토그램과 메트릭 메타데이터는 건너뛰고, 예시 데이터(exemplar)는 샘플과 함께 저장합니다.

## Elasticsearch bulk

Elasticsearch bulk 프로토콜을 사용하는 송신기는 Loki나 OTLP에 의존하지 않고 작동합니다.

```bash
curl -X POST http://localhost:5080/api/v1/_bulk \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/x-ndjson' \
  --data-binary $'{"index":{"_index":"app"}}\n{"level":"info","msg":"hello"}\n'
```

각 작업의 `_index` 값으로 대상 스트림을 선택합니다. `_index`가 없으면 `stream-name` 헤더를 사용하고, 헤더도 없으면 `default`를 사용합니다.

## Loki push

엔드포인트는 Loki JSON 요청 형식을 지원합니다.

```json
{"streams":[{"stream":{"service":"checkout","level":"error"},"values":[["1700000000000000000","payment failed"]]}]}
```

레이블은 필드가 되고 로그 한 줄은 `message` 필드에 들어갑니다. 엔드포인트는 나노초 단위 타임스탬프를 마이크로초 단위로 변환하고 `204`를 반환합니다. `stream-name` 헤더로 대상 스트림을 선택합니다.
