**로그**를 열어 현재 워크스페이스의 로그 스트림을 검색합니다.

## 스트림과 시간 범위 선택

로그 스트림을 선택한 다음, 이벤트가 포함되는 가장 짧은 시간 범위를 설정합니다. 시간 범위를 좁히면
스캔하는 행이 줄어들고 필드를 더 빠르게 탐색할 수 있습니다.

MoleSignal은 이벤트를 수신하면서 스트림 스키마를 추론할 수 있습니다. **필드** 패널에서 스트림의
필드를 확인하고 전체 쿼리를 다시 작성하지 않고도 필터를 추가할 수 있습니다.

## 쿼리 탭

각 쿼리는 별도의 탭에서 실행됩니다. 탭마다 스트림, 쿼리, 시간 범위를 유지하며, 한 탭의 쿼리는
다른 탭에 영향을 주지 않습니다.

- **새 탭**을 선택해 다른 쿼리를 엽니다. 탭은 한 번에 최대 10개까지 열 수 있습니다.
- 탭 메뉴를 열어 **이름 변경**, **복제**, **닫기**를 선택합니다.
- **화면을 둘로 분할**을 선택해 두 탭을 나란히 표시합니다. 각 화면에 별도의 탭 목록이 있으며, 탭 메뉴에서
  반대쪽 화면으로 옮길 수 있습니다. **단일 화면으로 돌아가기**를 선택하면 분할이 해제됩니다.

열려 있는 탭은 사용자와 워크스페이스별로 브라우저에 저장됩니다.

## 쿼리 작성

편집기에는 **코드**와 **빌더** 모드가 있습니다. 제목 옆의 두 아이콘으로 모드를 전환합니다(`</>`는
코드, 블록 모양은 빌더). 아이콘 위에 마우스를 올리면 모드 이름이 표시됩니다.

**코드**에서는 필드 쿼리 또는 SQL을 입력합니다. `SELECT` 또는 `WITH`로 시작하는 문은 SQL로 실행됩니다.
그 외에는 필드 쿼리로 실행됩니다.

| 필드 쿼리 | 의미 |
|---|---|
| `service = 'checkout'` | 필드 값이 이 값과 정확히 일치합니다. |
| `message contains 'timeout'` | 필드에 해당 텍스트가 포함됩니다. |
| `MATCH(message, 'timeout')` | 대소문자를 구분하지 않고 부분 문자열을 검색합니다. |
| `MATCH_TEXT(message, 'timeout disk')` | 전문 인덱스가 있는 필드에서 전문 검색을 수행합니다. |

대소문자 구분 없이 `AND`와 `OR`로 조건을 연결합니다. `AND`는 `OR`보다 우선순위가 높으며, 괄호로
조건을 묶습니다. 예: `level = 'error' AND (service = 'checkout' OR service = 'payments')`. 필드를
지정하지 않은 텍스트는 `message` 필드에서 검색하며, 여러 조건 중 하나로 사용할 수 있습니다.
예: `timeout OR "connection reset"`. 따옴표로 묶은 구문은 `or` 같은 단어가 포함되어 있어도 하나의 구문으로 검색합니다.
비교 연산자는 `=`, `!=`, `>`, `>=`, `<`, `<=`를 사용합니다.

**빌더**에서는 같은 필드 쿼리를 필터 행으로 표시합니다. 행 하나가 선택 조건 하나에 해당하며,
한 행의 모든 필터를 충족해야 합니다. 첫 행을 제외한 각 행 앞에는 **또는**이 표시됩니다. **필터**를 선택해
행에 필터를 추가하거나 **또는**을 선택해 행을 추가한 다음, 필드, 비교 연산자, 값을 선택합니다. 각
행에는 별도의 검색 텍스트가 있습니다. 위 예시의 `OR`처럼 행 안에서 괄호로 묶인 부분은
작성한 그대로 유지되며 **코드**에서 수정합니다. SQL 문은
필터로 표시할 수 없습니다.

조인, 표현식, CTE 또는 집계에는 SQL을 사용합니다.

```sql
SELECT "_timestamp", level, msg, trace_id
FROM app
WHERE level = 'error'
ORDER BY "_timestamp" DESC
LIMIT 200;
```

```sql
SELECT level, COUNT(*) AS events
FROM app
GROUP BY level
ORDER BY events DESC;
```

**실행**을 선택하거나 편집기에서 `⌘ Enter` 또는 `Ctrl+Enter`를 눌러 쿼리를 실행합니다. **쿼리 구문
참조**에서 현재 모드에 맞는 예시를 확인합니다. 텍스트 검색 함수는 [쿼리](/ko/query#텍스트-검색)를
참조합니다.

쿼리 플래너는 사용자 지정 SQL에도 현재 조직의 데이터 범위를 적용합니다.

## 필드 탐색

**필드** 패널은 **표시된 필드**, **인덱싱된 필드**, **기타
필드**로 구성됩니다. `http.method`와
`http.route`처럼 점으로 구분된 이름의 첫 부분이 같은 필드는 하나의 그룹으로 열립니다.

- 필드를 열어 결과에서 가장 자주 나타나는 값을 확인합니다. 값을 포함 필터나
  제외 필터로 추가합니다. 필터는 전체 쿼리의 범위를 좁힙니다. `OR`로 연결한 조건이 있는 쿼리는 괄호로 묶은 뒤
  필터를 적용합니다.
- 결과에서 필드를 열로 표시하거나 숨깁니다.
- 필드에서 **분석**을 선택해 필드 분석을 엽니다. 고유 값 개수, 값이 있는 행과
  없는 행, 숫자 필드의 통계, 값 분포, 시간대별로 가장 자주 나타나는
  값을 확인할 수 있습니다.

## 결과 확인

결과 상단의 히스토그램은 현재 불러온 페이지뿐 아니라 선택한 시간 범위에서 쿼리와 일치하는
모든 이벤트를 집계합니다. 다음 네 가지 보기에서 결과를 확인할 수 있습니다.

| 보기 | 내용 |
|---|---|
| **로그** | 일치하는 이벤트를 한 행에 하나씩 표시합니다. |
| **통계** | 집계 결과를 차트로 표시합니다. 측정값(개수, 고유 값 개수, 평균, 합계, 최솟값, 최댓값, P50, P95, P99), 그룹화 기준, 차트 유형을 선택하거나 SQL 집계 결과를 차트로 표시합니다. **대시보드 만들기**를 선택하면 차트를 새 대시보드의 패널로 저장합니다. |
| **AI 분석** | Mole Agent가 쿼리와 일치하는 로그를 분석해 작성한 보고서입니다. [로그 분석](/ko/logs/inspections)을 참조합니다. |
| **패턴** | 이벤트를 패턴별로 그룹화하고 각 패턴의 개수와 비율을 표시합니다. |

**로그** 보기에서는 다음 작업을 수행할 수 있습니다.

- **열**에서 표시할 열과 순서를 설정합니다. 기본 열은 스트림의 필드를 기준으로
  구성합니다. 시간을 먼저 표시하고, 스트림에 해당 필드가 있으면 레벨, 서비스, 메시지를 차례로 표시합니다.
- 페이지당 이벤트 수는 100, 200, 500, 1,000, 2,000 또는 5,000개입니다.
- 이벤트를 클릭하면 결과 옆에 상세 패널이 열립니다. 패널의 왼쪽 가장자리를 드래그해
  너비를 조정하면 설정한 너비가 유지됩니다. 패널 상단에는 레벨, 시간, 메시지와 이벤트를
  설명하는 속성(서비스, 호스트, 환경, 버전, 트레이스)이 표시됩니다. 각 속성에서 필드와 같은
  작업을 수행할 수 있습니다. **필드**, **컨텍스트**, **원본 JSON** 보기를 제공하며, 이벤트에 트레이스 ID가 있으면
  **트레이스** 보기도 표시합니다. **트레이스**는 해당 이벤트의 스팬을 선택한 상태로 트레이스 워터폴을 표시합니다. **컨텍스트**는
  이벤트 앞뒤로 각각 5개 행을 표시합니다. 필드에서 필터를 추가하거나 값을 복사하거나 해당
  필드를 열로 표시할 수 있습니다.
- 식별자가 있으면 관련 트레이스, 서비스, 메트릭 또는 기타 신호로 이동합니다.
- 결과를 CSV, 텍스트 또는 JSON으로 다운로드합니다.

## 쿼리 공유

페이지 주소에는 화면에 표시된 쿼리가 반영됩니다. 쿼리를 실행하면 페이지 주소에 스트림,
쿼리 문(필드 쿼리는 `q`, SQL은 `sql`), 결과 보기가 기록됩니다. 주소 표시줄의
주소를 복사하면 시간 선택기에 표시된 범위로 쿼리를 공유할 수 있습니다. 예를 들어 최근
1시간을 공유할 수 있습니다. 페이지를 새로고침해도 쿼리와 편집기 상태가 유지됩니다.

**공유**를 선택해 화면에 표시된 쿼리의 링크를 복사합니다. 로그인한 조직 구성원 중
데이터 읽기 권한이 있는 구성원만 링크를 열 수 있습니다. 링크에 적용할 시간 범위를 선택합니다. **현재 선택한 시간 범위**는
화면에 표시된 시작 및 종료 시각으로 범위를 고정합니다. 다른 옵션은 최근 1시간과 같은 상대 범위를 유지하며,
링크를 여는 시점을 기준으로 범위를 계산합니다.

## 검색 작업

대화형 요청으로 처리하기에 너무 큰 검색은 검색 작업으로 실행됩니다.
**스트림 → 검색 작업**을 열어 진행 상황을 확인하고 결과를 다운로드합니다.
[스트림](/ko/streams#검색-작업)을 참조합니다.

## 저장된 보기

SQL 쿼리에 이름을 지정해 [저장된 보기](/ko/saved-views)로 보관합니다. 보기를 다시 열거나, 다른 시간 범위에서
쿼리를 실행하거나, 보기를 보고서에 첨부할 수 있습니다.

<Tip>
  데이터를 수집할 때 `service.name`, `deployment.environment`, `trace_id`,
  `host.name`처럼 값이 안정적인 차원을 유지합니다. 이러한 필드를 사용하면 관련 신호로 정확하게 이동할 수 있습니다.
</Tip>

## 권한

- `streams.read` 권한으로 스트림과 스키마를 조회합니다.
- `logs.read` 권한으로 로그 목록, 히스토그램, 필드 통계를 조회합니다.
- `streams.query` 권한으로 SQL 문을 실행하고 컨텍스트를 엽니다.
- `agent.use` 권한으로 AI 분석을 실행합니다. AI 모델도 활성화해야 합니다.
- `saved_views.create`, `saved_views.edit`, `saved_views.delete` 권한으로 저장된 보기를 각각 생성, 편집, 삭제합니다.
