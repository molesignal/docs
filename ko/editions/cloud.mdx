<Warning>
MoleSignal Cloud는 현재 대기자 명단 등록을 받고 있습니다. 이 페이지는 평가 가이드이며, 정식 출시된 서비스의 활성화 또는 연결 가이드가 아닙니다.
</Warning>

MoleSignal Cloud는 스토리지와 서비스 인프라를 직접 운영하지 않고 옵저버빌리티를 평가하려는 팀을 위해 준비 중인 관리형 서비스입니다. [Cloud 대기자 명단](https://www.molesignal.com/cloud)에 등록합니다. 지금 바로 배포하여 평가하려면 [셀프 호스팅 빠른 시작](/ko/quickstart)을 사용합니다.

## Cloud 평가 준비

| 요구 사항 | 수집할 정보 |
|---|---|
| 텔레메트리 | 로그, 메트릭, 트레이스, 프로파일, 예상 일일 데이터량, 최대 전송률을 파악합니다. |
| 보존 | 신호별로 필요한 보존 기간과 해당 기간에도 실행할 수 있어야 하는 쿼리를 파악합니다. |
| 액세스 | 팀 규모, 조직 경계, ID 관련 요구 사항, API 토큰 사용 방식을 파악합니다. |
| 위치 | 필요한 데이터 리전, 네트워크 액세스 요건, 데이터 처리 제한 사항을 파악합니다. |
| 운영 | 지원에 대한 기대 수준, 복구 목표, 인시던트 발생 시 역할과 책임을 파악합니다. |

평가 과정에서 사용 가능한 리전, 액세스 방식, 보존 한도, 계약 조건, 지원 약속을 확인합니다. 셀프 호스팅 구성 옵션을 관리형 서비스에서도 설정할 수 있다고 가정하지 않습니다.

## 데이터 경로부터 검증

1. 셀프 호스팅 인스턴스를 시작하고 대표 서비스 하나를 선택합니다.
2. 문서에 나와 있는 [수집 프로토콜](/ko/intake/integrations)을 사용해 텔레메트리를 전송합니다.
3. 이벤트 타임스탬프, 선택한 스트림, 서비스 ID, 권한을 확인합니다.
4. 대표 쿼리를 실행하고 인시던트 한 건을 조사합니다. 이 작업에 필요한 데이터량과 보존 기간을 기록합니다.
5. Cloud 온보딩 또는 마이그레이션 계획에 합의하기 전에 평가에서 파악한 요구 사항을 논의합니다.

셀프 호스팅 환경의 API 주소나 API 토큰은 Cloud 주소나 자격 증명으로 자동 전환되지 않습니다. 실제로 사용하는 환경에 제공된 엔드포인트와 자격 증명만 사용합니다.

## 요금 및 기능 제공 상태

[요금 페이지](https://www.molesignal.com/pricing)에서 제안된 요금제와 문의 방법을 안내합니다. 액세스를 조율할 때 이용 가능한 요금제와 적용 조건을 확인합니다. **enterprise cloud** 태그가 붙은 페이지에는 제공 예정인 기능이 포함될 수 있으므로 각 페이지에서 제공 상태 안내를 확인합니다.

## 현재 이용 가능한 옵션 선택

- [오픈 소스 에디션](/ko/editions/open-source): 직접 관리하는 인프라에서 플랫폼을 운영합니다.
- [엔터프라이즈 평가](/ko/editions/enterprise): 상용 셀프 호스팅에 필요한 요건을 논의합니다.
- [지원 및 커뮤니티](/ko/support): 셀프 호스팅 개념 증명에 필요한 도움을 받습니다.
