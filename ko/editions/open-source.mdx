오픈 소스 에디션은 모든 기능을 갖춘 자체 호스팅 플랫폼입니다. [Apache License 2.0](https://github.com/molesignal/molesignal/blob/main/LICENSE)에 따라 제공되며, 운영자가 관리하는 인프라에서 실행됩니다. MoleSignal 계정이나 호스팅형 제어 플레인은 필요하지 않습니다.

## 포함 기능

- 로그, 메트릭, 트레이스, 프로파일 수집, 저장 및 쿼리
- 트레이스 기반 APM, RUM 조사, 상관관계 분석 및 서비스 토폴로지
- 대시보드, 스트림, 파이프라인, 재사용 가능한 함수 및 확장 테이블
- 알림, 인시던트, 온콜 및 에스컬레이션, 알림 전송, 중대 인시던트, 문제 해결 및 사후 분석
- 합성 모니터링 및 상태 페이지
- Mole Agent 및 동일한 도구 카탈로그에 대한 인바운드 MCP 액세스
- 조직 격리, IAM, SSO, 서비스 계정, API 토큰, 감사 이벤트 및 플랫폼 설정
- Docker Compose, 바이너리 또는 Kubernetes를 사용한 단일 노드 배포와 라우터, 수집기, 쿼리 처리기, 컴팩터 및 알림 프로세스를 분리한 역할별 배포

제공되는 API의 전체 범위는 **API 레퍼런스**에서 확인할 수 있습니다. 사용자, 서비스 계정 또는 API 토큰이 수행할 수 있는 작업은 권한에 따라 달라집니다.

## 배포 요구 사항

메타데이터를 저장하려면 PostgreSQL이 필요하고, 데이터를 저장하려면 S3 호환, Azure 또는 Google Cloud 오브젝트 스토리지가 필요합니다. 개발용 단일 노드에서는 로컬 디스크를 오브젝트 스토리지로 사용할 수 있습니다. [MoleSignal 배포](/ko/deployment)를 참조합니다.

## 자체 호스팅 시작하기

1. [빠른 시작](/ko/quickstart) 가이드에 따라 로컬 인스턴스를 실행합니다.
2. [MoleSignal 배포](/ko/deployment)에서 토폴로지를 선택합니다.
3. 실제 데이터를 수집하기 전에 [프로덕션 체크리스트](/ko/deployment/production-checklist)의 항목을 모두 확인합니다.
4. [보안 및 멀티테넌시](/ko/security)와 [자체 관측성](/ko/self-observability)을 검토합니다.
