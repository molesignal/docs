<Warning>
  Enterprise 및 MoleSignal Cloud에 제공할 예정입니다. 현재 설계 중인 기능으로, 아직 어떤 릴리스에서도 사용할 수 없습니다. 오픈 소스 에디션에는 이 기능이 포함되지 않습니다. 이 페이지의 명칭, 범위 및 동작 방식은 출시 전에 변경될 수 있습니다.
</Warning>

Iceberg REST 카탈로그는 조직의 텔레메트리 데이터를 [Apache Iceberg](https://iceberg.apache.org) 테이블로 공개합니다. 조직에서 선택한 인프라에서 실행되는 쿼리 엔진은 카탈로그에 연결해 스트림을 테이블로 찾고, 오브젝트 스토리지에서 Parquet 파일을 직접 읽습니다. MoleSignal은 테이블, 메타데이터, 권한, 테넌트 경계 및 데이터 위치를 관리합니다. 조직은 엔진, 쿼리 및 컴퓨팅 리소스를 자체적으로 관리합니다.

## 역할 분담

MoleSignal은 다음을 관리합니다.

- **테이블.** 공개된 각 스트림은 해당 스트림의 스키마를 따르는 읽기 전용 Iceberg 테이블로 표시됩니다.
- **메타데이터.** 스냅샷, 데이터 파일 및 통계는 컴팩션과 보존 정책이 적용된 후에도 일관성을 유지합니다.
- **권한.** 카탈로그는 각 접근 주체가 목록을 조회하거나 읽을 수 있는 테이블을 결정합니다.
- **테넌트 격리.** 각 조직은 자체 테이블과 파일만 볼 수 있습니다.
- **데이터 위치.** MoleSignal은 파일의 저장 위치를 정하고, 해당 파일에 대한 단기 읽기 전용 자격 증명을 발급합니다.

조직은 다음을 운영합니다.

- **엔진.** Apache Spark, Trino, Apache Flink, DuckDB 또는 Iceberg REST 카탈로그 사양을 지원하는 기타 클라이언트입니다.
- **워크로드.** 쿼리, ETL 파이프라인, 머신러닝 작업 및 BI 대시보드입니다.
- **컴퓨팅 리소스 및 비용.** 클러스터, 작업 예약 및 결과 저장을 관리하고 관련 비용을 부담합니다.

## 연결 방식

<Steps>
  <Step title="인증">
    엔진이 카탈로그 엔드포인트에 API 토큰 또는 서비스 계정 자격 증명을 제출합니다.
  </Step>
  <Step title="테이블 찾기">
    카탈로그는 접근 주체가 읽을 수 있는 스트림을 유형별로 나열합니다.
  </Step>
  <Step title="테이블 로드">
    카탈로그는 일관된 단일 스냅샷의 스키마, 파티셔닝 정보 및 데이터 파일을 반환합니다. 테이블의 저장 위치에 대한 단기 읽기 전용 자격 증명도 함께 반환합니다.
  </Step>
  <Step title="파일 읽기">
    엔진은 오브젝트 스토리지에서 Parquet 파일을 직접 읽습니다. 파일 내용은 MoleSignal을 거치지 않습니다.
  </Step>
</Steps>

## 액세스 방식 선택

| | Iceberg REST 카탈로그 | [Arrow Flight SQL](/ko/query/database-clients) |
|---|---|---|
| 쿼리 실행 위치 | 조직의 엔진 | MoleSignal |
| 주요 용도 | 특정 시간 범위의 대량 데이터 분석, ETL, 머신러닝 및 BI | 데이터베이스 클라이언트에서 실행하는 대화형 SQL |
| 필드 마스킹 | 적용하지 않습니다. [데이터 보호 범위](#데이터-보호-범위)를 참조합니다. | 적용합니다 |
| 에디션 | Enterprise 및 Cloud(예정) | 모든 에디션 |

데이터 거버넌스가 적용되는 대화형 쿼리에는 Flight SQL 또는 쿼리 API를 사용합니다. 엔진의 컴퓨팅 리소스로 넓은 시간 범위의 데이터를 스캔하는 작업에는 카탈로그를 사용합니다.

## 카탈로그 공개 범위

- **스트림당 테이블 하나.** 네임스페이스는 스트림 유형 `logs`, `metrics`, `traces`, `profiles`에 대응합니다.
- **스트림 스키마에 따른 열 구성.** 첫 번째 열은 `_timestamp`이며 UTC 기준 마이크로초 정밀도를 사용합니다. JSON 필드는 문자열입니다. 암호화된 필드는 암호문으로 유지합니다.
- **이벤트 시간 기준 파일 파티셔닝.** 시간 범위 필터로 읽을 필요가 없는 파일을 제외합니다.
- **공개하지 않는 항목.** 메모리에 상주하는 Extend 테이블과 MoleSignal이 내부 기능에 사용하는 파생 읽기 모델은 공개하지 않습니다.

## 액세스 제어

- **인증.** HTTP API 및 Flight SQL과 동일하게 API 토큰(`mspat-<36>`)과 서비스 계정 자격 증명을 사용합니다.
- **권한 부여.** 카탈로그에 액세스하려면 전용 권한이 필요합니다. 권한 이름은 출시 시 공개합니다. 테이블을 읽으려면 이 권한과 `streams.query`가 모두 필요합니다.
- **테넌트 격리.** 각 조직은 자체 카탈로그 범위를 갖습니다. 스토리지 자격 증명은 요청한 테이블의 파일에만 적용되며, 짧은 시간 후 만료됩니다. 쓰기나 삭제는 허용하지 않습니다.
- **감사.** 자격 증명 발급과 공개 설정 변경을 감사 이벤트로 기록합니다.

## 데이터 보호 범위

<Warning>
  Parquet 파일을 읽는 엔진은 저장된 값을 그대로 읽습니다. 필드 마스킹 규칙은 MoleSignal 쿼리와 Flight SQL 결과에 적용합니다. 엔진이 직접 읽는 파일에는 적용하지 않습니다. 파일에서 암호화된 필드는 암호화 상태를 유지하므로 엔진은 암호문을 받습니다.
</Warning>

따라서 카탈로그에 액세스하면 공개된 스트림의 원본 데이터에도 액세스할 수 있습니다.

- 마스킹하지 않은 데이터를 읽을 수 있는 접근 주체에만 카탈로그 권한을 부여합니다.
- 관리자는 카탈로그에서 공개할 스트림을 선택합니다. 활성 필드 마스킹 규칙이 있는 스트림은 관리자가 명시적으로 허용하기 전까지 공개하지 않습니다.
- 메트릭 스트림에는 필드 마스킹을 적용하지 않으며 일반 공개 설정을 따릅니다.

## 데이터 최신성과 일관성

- 스냅샷에는 커밋된 파일만 표시합니다. 수집 버퍼에 남아 있는 레코드는 다음 플러시가 끝난 뒤 조회할 수 있습니다.
- 컴팩션과 보존 정책 적용 결과는 다음 스냅샷에 반영합니다. 이전 스냅샷을 기준으로 계획한 작업을 완료할 수 있도록, 컴팩션으로 교체한 파일은 유예 기간 동안 오브젝트 스토리지에 보관합니다. 유예 기간보다 오래 실행되는 작업은 실행 계획을 다시 수립합니다.

## 지원 엔진

카탈로그는 공개 Iceberg REST 카탈로그 사양을 따릅니다. 검증 대상 엔진은 다음과 같습니다.

| 엔진 | 상태 |
|---|---|
| Apache Spark | 검증 예정 |
| Trino | 검증 예정 |
| Apache Flink | 검증 예정 |
| DuckDB | 검증 예정 |
| PyIceberg 및 기타 REST 카탈로그 클라이언트 | 작동할 것으로 예상하나 검증하지 않음 |

검증한 버전과 연결 설정은 출시 시 공개합니다.

## 첫 릴리스의 제한 사항

- **읽기 전용.** 카탈로그는 쓰기, 테이블 생성 및 스키마 변경을 허용하지 않습니다. 스키마와 보존 정책은 스트림에서 변경합니다.
- **현재 스냅샷만 지원.** 타임 트래블, 브랜치 및 태그는 지원하지 않습니다.
- **뷰 및 다중 테이블 트랜잭션 미지원.**
- **조직 소유 테이블 미지원.** 엔진은 여러 카탈로그에 동시에 연결할 수 있습니다. 따라서 결과를 조직이 운영하는 카탈로그의 데이터와 조인하거나 해당 카탈로그에 쓸 수 있습니다.
- **범위를 제한한 액세스 권한을 발급할 수 있는 오브젝트 스토리지만 지원.** `local` 오브젝트 스토리지 백엔드는 외부 엔진에 파일을 제공할 수 없습니다.

## 제공 여부

| 에디션 | 제공 여부 |
|---|---|
| 오픈 소스 | 제공하지 않습니다. 외부 SQL 액세스에는 [Arrow Flight SQL](/ko/query/database-clients)을 사용합니다. |
| Enterprise | 제공할 예정입니다. 엔진이 액세스할 수 있는 오브젝트 스토리지와 이 기능이 포함된 라이선스가 필요합니다. |
| MoleSignal Cloud | 제공할 예정입니다. 각 리전에서 해당 리전의 조직 데이터와 함께 카탈로그를 제공합니다. |
