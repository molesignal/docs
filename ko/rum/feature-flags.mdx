SDK에 플래그 평가 결과를 전달하면 해당 뷰의 모든 이벤트에 그 값이 포함됩니다.

```ts
molesignalRum.addFeatureFlagEvaluation('checkout_v2', 'treatment');
```

플래그 서비스와 연동하려면 평가 결과를 SDK에 전달합니다. LaunchDarkly는 인스펙터를, OpenFeature는 훅을 제공합니다.

```ts
LDClient.initialize(id, user, {
  inspectors: [{
    type: 'flag-used',
    name: 'molesignal',
    method: (key, detail) => molesignalRum.addFeatureFlagEvaluation(key, detail.value),
  }],
});

OpenFeature.addHooks({
  after: (context, details) => molesignalRum.addFeatureFlagEvaluation(context.flagKey, details.value),
});
```

## 기능 플래그 탭

**기능 플래그**에는 선택한 시간 범위의 세션에서 평가한 플래그가 표시됩니다. 가장 많은 세션에서 평가한 플래그가 맨 위에 표시됩니다. 플래그를 선택하면 값별로 세션 수, 오류가 발생한 뷰의 비율, 사용자 불편 신호가 감지된 뷰의 비율을 나란히 비교할 수 있습니다. 브라우저 애플리케이션에서는 LCP, INP, CLS의 75번째 백분위수도 비교할 수 있습니다. 오류가 발생한 뷰가 가장 많은 값은 빨간색으로 표시됩니다. **해당 뷰 보기**를 선택하면 익스플로러에서 해당 뷰를 확인할 수 있습니다.

## 어디서든 플래그 조회

[익스플로러](/ko/rum/explorer)와 API에서 필드를 지정할 수 있는 곳이면 어디서든 `feature_flags.<key>`처럼 플래그를 열 이름으로 지정합니다.

```text
feature_flags.checkout_v2 = 'treatment' AND error.type = 'TypeError'
```

```http
POST /api/v1/rum/aggregate
{ "type": "views", "measures": [{ "fn": "p75", "field": "view.performance.lcp.timestamp" }], "groupBy": ["feature_flags.checkout_v2"] }
```

JSON 열의 다른 키인 `context.<key>`, `usr.extra.<key>`, `view.custom_timings.<key>`도 같은 방식으로 지정합니다. `GET /api/v1/rum/keys`는 사용 가능한 키 목록을 반환합니다.

SQL에서는 `json_text("feature_flags", 'checkout_v2')`로 키의 값을 텍스트로 읽습니다. 행에 해당 키가 없으면 NULL을 반환합니다. `json_keys("feature_flags")`는 행의 키 목록을 반환합니다.

## Mole Agent

`get_rum_feature_flags` 도구는 플래그 목록을 반환합니다. `flag`를 지정하면 같은 지표로 해당 플래그의 값들을 비교합니다.
