탐색기는 실제 사용자가 남긴 데이터를 유형별로 한 번에 하나씩 행으로 표시합니다. 필드 쿼리로 행을 찾고,
시간대별로 개수를 집계하고, 목록을 벗어나지 않고 행을 열 수 있습니다. **RUM → 탐색기**를 엽니다. RUM 데이터를 읽으려면
`rum.events.read` 권한이 필요합니다.

아직 [애플리케이션](/ko/rum/applications)이 없는 워크스페이스에는 애플리케이션을 만드는 방법이 대신 표시됩니다.

## 행 유형

제목 아래의 탭에서 행의 유형을 선택합니다. 각 행은 해당 항목의 최신 버전을 나타냅니다. 여러 번 보고된 뷰도
마지막 집계값과 함께 한 번만 표시됩니다.

| 탭 | 행에 표시되는 항목 | 히스토그램에 표시되는 항목 |
|---|---|---|
| **세션** | 뷰를 기반으로 구성한 세션 하나입니다. 사용자, 랜딩 페이지, 지속 시간, 뷰·작업·오류 수, 브라우저, 국가를 표시합니다. | 오류가 발생한 세션 |
| **뷰** | 페이지 뷰 또는 화면 하나입니다. 로딩 시간, Web Vitals, 집계값을 표시합니다. | 오류가 발생한 뷰 |
| **작업** | 클릭, 탭 또는 사용자 지정 작업 하나입니다. | 사용자 불편 신호가 감지된 작업 |
| **오류** | 오류 하나입니다. 메시지, 유형, 소스, 처리 여부, 스택을 표시합니다. | — |
| **리소스** | 요청 하나입니다. 메서드, URL, 상태, 소요 시간, 크기, 트레이스를 표시합니다. | 상태가 `400` 이상이거나 `0`인 실패한 요청 |
| **장기 작업** | 장기 애니메이션 프레임, 장기 작업 또는 멈춘 프레임 하나입니다. | — |
| **로그** | [브라우저 로그](/ko/rum/logs) 하나입니다. 레벨, 메시지, 로거, 페이지를 표시합니다. | `error` 레벨 로그 |

행은 실제 사용자의 데이터를 표시합니다. 쿼리에 `session.type`, `synthetics.*` 또는 `ci_test.*`를 지정하면 [테스트에서 생성한 세션](/ko/rum/test-traffic)도 조회합니다.

## 쿼리 작성

쿼리 편집기는 접힌 상태로 열립니다. **펼치기** 또는 **코드**나 **빌더** 아이콘을 선택해 편집기를 엽니다.

**코드**에서는 필드 쿼리를 입력합니다. 현재 선택한 유형의 필드를 비교하고, 비교 조건을 `AND`로 연결합니다.

| 필드 쿼리 | 의미 |
|---|---|
| `usr.id = 'u-42'` | 필드 값이 이 값과 정확히 일치합니다. |
| `view.url_path contains 'checkout'` | 필드에 이 텍스트가 포함됩니다. |
| `browser.name != 'Safari'` | 필드 값이 이 값과 다릅니다. |
| `resource.duration >= 1000000000` | 숫자는 `=`, `!=`, `>`, `>=`, `<`, `<=`로 비교합니다. |
| `error.issue_id = '3f9c2a71e0b4c8d1'` | 특정 [이슈](/ko/rum/errors)에 속한 오류를 조회합니다. |
| `error.fingerprint = ''` | 빈 값을 지정하면 필드에 값이 없는지 확인합니다. `!= ''`는 값이 있는지 확인합니다. |
| `feature_flags.checkout_v2 = 'treatment'` | JSON 필드인 `feature_flags`, `context`, `usr.extra` 또는 `view.custom_timings`의 키를 비교합니다. [기능 플래그](/ko/rum/feature-flags)를 참조합니다. |

소요 시간은 **나노초** 단위로 저장하므로 `1000000000`은 1초입니다. 표의 셀에는 적절한 단위로 표시합니다.

비교 조건이 아닌 단어는 현재 선택한 유형의 텍스트 열에서 검색합니다. 예를 들어 사용자, 페이지,
오류 메시지, 요청 URL을 검색합니다. 현재 유형에 없는 필드를 비교하거나 JSON 문서가 들어 있는 필드의
키가 아닌 필드 전체를 비교하면 해당 조건을 무시하고 **무시됨**으로 표시합니다.

**빌더**는 같은 쿼리를 필터로 표시합니다. **필터**를 선택한 다음 필드, 비교 조건, 값을 선택합니다.

**쿼리 실행**을 선택하거나 편집기에서 `⌘ Enter` 또는 `Ctrl+Enter`를 눌러 쿼리를 실행합니다. **새로 고침**을 선택하면 결과를
다시 불러옵니다. 실행 버튼 옆에서 시간 범위를 설정합니다. 탐색기는 기본적으로 최근 24시간을 표시합니다.

## 필드

결과 옆의 **필드** 목록은 현재 선택한 유형의 모든 필드를 세 그룹으로 나눕니다. 표의 열에 해당하는 **표시된 필드**,
모든 행을 읽지 않고도 필터링할 수 있는 **인덱싱된 필드**, 그리고 **기타 필드**입니다.
**필드 검색**에 입력해 목록을 좁힙니다.

- 필드 이름을 클릭하면 쿼리와 일치하는 행에서 가장 많이 나타나는 값과 각 값의 개수를 표시합니다.
- **이 값만 포함**과 **이 값 제외**는 쿼리에 비교 조건을 추가합니다. 이미 필터를 적용한 값을
  선택하면 해당 필터가 제거됩니다.
- 필드의 눈 모양 아이콘으로 표에 필드를 추가하거나 표에서 제거합니다. **기본 열로 재설정**을 선택하면 표를 초기화합니다.
- 필드의 더하기 버튼을 선택하면 쿼리에 해당 필드의 비교 조건을 작성할 수 있습니다.

## 결과 및 히스토그램

표는 결과마다 한 행을 최신순으로 표시하며, 각 행의 첫 번째 열에 시간을 표시합니다. 문제가 발생한 행은
왼쪽 가장자리에 표시를 추가합니다. 페이지당 행 수를 100, 200, 500, 1,000, 2,000 또는 5,000개로 선택하고
**이전**과 **다음**으로 이동합니다.

표 위의 히스토그램은 현재 불러온 페이지에 한정하지 않고, 시간 범위 내에서 쿼리와 일치하는 **모든** 행을 집계하며
각 막대에 해당하는 행 수를 표시합니다. 막대를 가로질러 드래그하면 시간 범위를 좁힐 수 있습니다. **히스토그램 숨기기**를 선택하면
히스토그램이 닫히고 설정이 유지됩니다.

**다운로드**를 선택하면 쿼리와 일치하는 최신 행을 최대 5,000개까지 표에 표시된 열과 함께 CSV 파일로 저장합니다.
브라우저는 읽기 권한이 있는 데이터로만 파일을 생성하며, 마스킹된 값은 파일에서도 마스킹 상태를 유지합니다.

## 행을 수치로 시각화하기

결과 오른쪽 상단의 아이콘으로 쿼리와 일치하는 행을 표시할 방식을 선택합니다. 아이콘에 포인터를 올리면
이름이 표시됩니다. **목록**은 행을 테이블로 보여 주며
기본으로 열립니다. 나머지 다섯 방식은 불러온 페이지가 아니라 시간 범위 내에서 쿼리와 일치하는 **모든** 행을 집계하므로
옆에 있는 목록과 같은 데이터를 반영합니다.

| 방식 | 표시 내용 | 설정 범위 |
|---|---|---|
| **시계열** | 시간에 따른 수치 하나를 표시합니다. 백분위수, 평균, 최솟값, 최댓값은 선으로, 개수나 합계는 그룹별 누적 막대로 표시합니다. | 측정값 1개, 그룹화 기준 최대 2개, 시리즈 최대 20개 |
| **상위 목록** | 수치 하나를 기준으로 그룹의 순위를 매깁니다. 각 그룹을 막대로 표시하고 막대 뒤에 수치를 표시합니다. | 측정값 1개, 그룹화 기준 1개 |
| **테이블** | 그룹마다 행을 하나씩, 수치마다 열을 하나씩 표시합니다. | 측정값 최대 6개, 그룹화 기준 최대 2개 |
| **히트맵 유형** | 세계 지도에서 각 국가의 수치를 최댓값과 비교해 색 농도로 표시합니다. | 측정값 1개. 행을 `geo.country_iso_code`로 그룹화합니다. |
| **분포** | 수치의 값이 어떻게 분포하는지 보여 줍니다. 값의 구간마다 막대를 표시하고 50번째, 75번째, 95번째, 99번째 백분위수를 표시합니다. | 수치 1개. 최솟값부터 99번째 백분위수까지 막대로 표시하고, 마지막 막대는 99번째 백분위수를 초과하는 값을 집계합니다. |

지도는 전 세계 보기에서 최대 8배까지 확대할 수 있습니다. 모서리의 버튼을 사용하거나, 포인터를 중심으로 휠을 돌리거나 두 손가락을 오므리거나 펼치거나,
더블 클릭합니다. 확대된 지도는 드래그하여 이동합니다. 지도에 포커스가 있을 때 `+`와 `-`로 확대하거나 축소하고, `0`으로 전 세계를 표시하며,
화살표 키로 확대된 지도를 이동합니다. 싱가포르나 몰타처럼 지도에서 보기에는 너무 작은 국가는
해당 위치에 표시합니다. 국가에 포인터를 올리면 집계값을 확인할 수 있습니다. 국가 윤곽선은 Natural Earth의 1:10m 국가 경계를
단순화한 것으로, 중국의 관점을 반영하며 남극은 제외합니다. 대만, 홍콩, 마카오는 중국의 일부로 표시합니다. 대만은
경계선 없이 별도 영역으로 표시해 해당 행의 수치를 별도의 색으로 나타냅니다.
[합성 모니터링](/ko/synthetics)의 가용성 지도에도 같은 윤곽선을 사용합니다.

상위 목록이나 테이블에서 그룹을 선택하면 쿼리를 해당 그룹으로 좁힙니다. 같은 그룹을 다시 선택하면 필터를 해제합니다. 테이블의 열 머리글을 선택하면
해당 열을 기준으로 정렬합니다. 서버가 그 열을 기준으로 순위를 매기므로, 다른 기준의 상위 행을 가져와 다시 정렬하지 않고
선택한 기준의 상위 행을 표시합니다. 시계열을 클릭하면 툴팁을 고정합니다. 툴팁의 **포함**과 **제외**를 사용하면 쿼리를 포인터 아래의 시리즈로 좁히거나
해당 시리즈를 제외할 수 있습니다. 히스토그램과 마찬가지로 차트에서 구간을 드래그하면 시간 범위가 좁아집니다.

수치가 **Largest Contentful Paint**, **Interaction to Next Paint**, **Cumulative Layout Shift** 중 하나를 나타내면
차트에 각각 초, 밀리초, 점수로 표시합니다. 좋음과 개선 필요, 개선 필요와 나쁨을 가르는 기준값에 점선을 두 개 표시합니다
(각각 2.5 s 및 4 s, 200 ms 및 500 ms, 0.1 및 0.25). 상위 목록이나 테이블에서는 등급에 따라 수치의 색상을 지정합니다.

### 집계 대상

행을 수치로 시각화하면 결과 오른쪽 상단의 아이콘 왼쪽에 다음 설정이 표시됩니다.
변경 사항은 즉시 적용됩니다.

- **측정값**은 필드에 적용하는 함수입니다. `count`는 행 개수를 셉니다. `count_distinct`는
  `session.id`나 `usr.id` 같은 필드의 고유 값 개수를 셉니다. `sum`, `avg`, `min`, `max`, `p50`, `p75`, `p90`, `p95`, `p99`에는 숫자 필드를 사용하며,
  백분위수는 추정값입니다. 소요 시간은 나노초 단위로 저장하고 값에 맞는 단위로 표시합니다. 측정값을 선택하면
  변경할 수 있습니다. 테이블에 측정값을 추가하려면 **측정값**을 선택합니다.
- **그룹화 기준**은 필드 값에 따라 행을 나누고, **다음 그룹화 기준**은 두 번째 필드 값에 따라 다시 나눕니다. 필드에 값이 없는 행은
  **(없음)**으로 집계합니다. 측정값, 시간, JSON 문서는 그룹화 기준으로 사용할 수 없습니다.
- **버킷**은 시계열의 한 데이터 포인트가 나타내는 시간 간격입니다. **자동**은 시간 범위를 약 30개의 포인트로 나누고, 각 포인트의 시작 시각을
  페이지의 시간 기준에서 해당 간격의 배수에 맞춥니다. 시간 범위를 2~300개의 포인트로 나누는 간격만 선택할 수 있습니다.
- **상위**는 표시할 그룹 수입니다. 시계열에서는 3~20개, 상위 목록이나 테이블에서는 5~100개를 표시합니다.
- **필드**는 분포를 표시할 숫자 필드입니다. 기본값은 데이터 유형을 가장 잘 나타내는 필드입니다. 예를 들어 뷰의 로드 시간이나 요청의 소요 시간을 사용합니다.

탐색기는 저장된 행을 집계합니다. 애플리케이션이 [세션의 일부만 보관하는 경우](/ko/rum/sampling),
합계를 표시하는 페이지는 전체 세션을 기준으로 집계값을 환산하지만 탐색기는 환산하지 않습니다. 탐색기의 목록, 히스토그램, 기타 시각화는
저장된 행만 집계합니다.

상위 목록과 테이블은 데이터 유형별로 가장 자주 사용하는 필드를 기본 순위 기준으로 사용합니다. 세션은 브라우저, 뷰와
긴 작업은 페이지, 액션은 대상, 오류는 오류 유형, 리소스는 호스트를 사용합니다. 시계열은 기본적으로 그룹화하지 않고
행 개수를 표시합니다. 제한 시간 내에 집계할 수 없으면 탐색기는 수치가 표시될 자리에 **사용할 수 없음**을
표시합니다. 시간 범위나 쿼리 범위를 좁힌 후 다시 실행합니다.

시각화 방식과 집계 설정은 주소에 포함되므로 주소 표시줄의 URL을 복사해 차트를 공유할 수 있습니다. `viz`는
`timeseries`, `toplist`, `table`, `map` 중 하나입니다(목록에서는 생략합니다). `m`은 `count`나
`p75:view.performance.lcp.timestamp` 같은 측정값마다 한 번씩 지정합니다. `by`는 그룹화 필드마다 한 번씩 지정합니다. `bucket`은 `5m`이나
`1h` 같은 시간 간격이고, `top`은 그룹 수이며, `sort`와 `dir`은 테이블의 정렬을 지정합니다. 데이터 유형을 변경해도 시각화 방식은 유지되지만
이전 유형의 필드에 연결된 `m`, `by`, `sort`는 제거됩니다. 수치는
[`aggregate`](/ko/api/rum#행-집계)로 조회합니다.

## 대시보드 및 알림

쿼리 표시줄의 **대시보드에 추가**와 **새 알림**은 탐색기에 표시된 결과를 사용합니다. 두 메뉴 모두
해당 유형의 필드를 불러온 후에 사용할 수 있습니다.

### 대시보드에 추가

**대시보드에 추가**는 표시된 결과를 대시보드 패널로 만듭니다. **새 대시보드**에 만들거나 **기존
대시보드**의 다른 패널 아래에 추가합니다. 패널은 대시보드의 시간 범위에서 동일한 필터, 검색어, 측정값, 그룹, 정렬 순서, 그룹 수를 적용해
SQL로 같은 행을 읽습니다. 탐색기와 마찬가지로 저장된 행을 집계하되, 뷰나 세션은 최신 버전(`rum_views_latest`, `rum_sessions_latest`)만
한 번씩 셉니다. 쿼리에 `session.type`, `synthetics.*` 또는 `ci_test.*`를 지정하지 않으면
합성 테스트와 CI에서 실행한 세션을 제외합니다.

| 탐색기 | 대시보드 패널 |
|---|---|
| **시계열** | 그룹마다 하나의 시계열을 표시합니다. 개수와 합계는 그룹별 누적 막대로, 그 외 측정값은 선으로 표시합니다. 탐색기와 마찬가지로 전체 시간 범위에서 순위가 높은 그룹을 표시합니다. |
| **상위 목록** | 첫 번째 측정값을 기준으로 순위를 매긴 가로 막대를 표시합니다. |
| **테이블** | 측정값마다 하나의 열을 생성해 테이블에 표시합니다. |
| **분포** | 최솟값부터 99번째 백분위수까지 40개 구간으로 나누고, 마지막 막대에는 99번째 백분위수를 초과하는 값도 포함합니다. 대시보드의 시간 범위에 맞춰 구간을 다시 나눕니다. |
| **목록** | 목록 위의 히스토그램처럼 시간에 따른 일치 행 수를 표시합니다. |
| **히트맵 유형** | 대시보드에서는 지도 대신 상위 20개 국가를 가로 막대로 표시합니다. |

기간은 밀리초로 표시하며, 다른 수치는 탐색기에서 사용하는 단위를 그대로 유지합니다. 열 이름도 탐색기와 동일하며, 예를 들면
`p75 Loading`입니다.

시계열은 대시보드의 **실행 간격** 변수(`${interval}`)에 따라 1분, 5분, 15분, 1시간 또는
1일 단위로 나눕니다. 새 대시보드에는 이 변수를 추가하고, 탐색기에 표시된 막대 간격과 가장 가까운 값으로 설정합니다. 기존 대시보드에 이 변수가 없으면
패널과 함께 추가하며, 대화 상자에서 이를 안내합니다. 새 대시보드는 탐색기의 시간 범위가 고정 범위가 아닌 경우
해당 범위로 열리며, `rum` 태그를 붙입니다.

새 대시보드를 만들려면 `dashboards.create` 권한이 필요하고, 기존 대시보드에 패널을 추가하려면 해당 대시보드에 대한 `dashboards.edit` 권한이 필요합니다. 기본 제공 RUM 대시보드는
읽기 전용이므로 선택 목록에 표시하지 않습니다. 패널의 SQL 문은 다음 API에서 가져옵니다.
[`panel-statement`](/ko/api/rum#대시보드-패널의-sql-문).

### 새 알림

**새 알림**은 알림 규칙 편집기를 열고 **[탐색기 쿼리](/ko/rum/alerts#탐색기-쿼리)** 값을 설정합니다. 이 값은 해당 유형에서
쿼리와 일치하는 행을 대상으로 계산한 첫 번째 측정값입니다. **임계값 알림** 또는 이전 며칠의 같은 시간대와 비교하는
**이상 감지 알림**을 선택합니다. 규칙을 만들려면 `alerts.rules.manage` 권한이 필요합니다.

메뉴는 먼저 규칙의 모니터링 대상과 가져오지 않는 설정을 안내합니다.

- 규칙은 첫 번째 측정값 하나만 모니터링합니다. 나머지 측정값, 시각화 방식, 그룹, 정렬 순서, 그룹 수는
  가져오지 않습니다. RUM 규칙은 그룹별로 나누지 않습니다.
- **목록**은 일치하는 행 수를 모니터링하고, **분포**는 해당 필드의 p75를 모니터링합니다.
- 규칙은 애플리케이션 하나에만 적용합니다. 쿼리에서 `application.id = '…'`로 지정한 애플리케이션이나, 워크스페이스에 하나뿐인 애플리케이션을 사용합니다.
  그 외에는 편집기에서 선택합니다. 쿼리에 `env = '…'`가 있으면 환경도 자동으로 입력합니다.
- 탐색기의 시간 범위는 가져오지 않습니다. 규칙은 자체 평가 시간 범위인 5분, 15분 또는 1시간을 사용합니다.

## 행 열기

행을 클릭하거나 방향키로 이동한 뒤 `Enter`를 눌러 목록 옆의 사이드 패널에서 행을 엽니다. 패널은 로그 상세 패널과
같은 구조를 사용합니다. 헤더에는 행 이름, 유형, 발생 시각을 표시합니다. 헤더 아래에는 행의 전체 내용(오류나 로그의
메시지, 요청의 메서드와 URL), 유형별 수치(예: 세션 지속 시간, 뷰 수,
작업 수, 오류 수, 사용 불편 지표), 사용자 및 위치 정보를 표시합니다. 녹화된 세션에는 **리플레이
보기**가 표시됩니다. 그 아래의 **필드** 섹션에는 위에 표시하지 않은 모든 필드가 나열되며, 이름이나 값에 포함된 단어로
필드를 검색할 수 있습니다. **JSON** 섹션에는 전체 행이 표시됩니다. 패널의 왼쪽 가장자리를 드래그해 너비를 조절합니다.

- `J`와 `K` 또는 헤더의 화살표로 목록의 다음 행과 이전 행으로 이동합니다. 헤더에는 전체 행 수와
  현재 행의 위치가 표시됩니다.
- **세션 열기**는 행이 속한 세션을 열고, **행을 JSON으로 복사**는 행을 복사합니다.
- 오류 행을 열면 **누적**을 표시합니다.
- 브라우저 뷰를 열면 넓은 패널에 **로드 워터폴**을 표시합니다. 뷰가 보낸 요청과 뷰를 차단한 긴 작업을 뷰 시작 시점부터 하나의 시간
  축에 표시합니다. [뷰 로드](/ko/rum/performance#뷰-로드)를 참조합니다.
- 패널을 닫으면 포커스가 행으로 돌아갑니다.

## 세션 열기

탐색기에서 세션 페이지를 엽니다. 세션 페이지에는 다음 항목이 표시됩니다.

- DOM 리플레이를 기록한 세션에는 **세션 리플레이 플레이어**, 기록하지 않은 세션에는 **동작 타임라인**을 표시합니다. 리플레이 눈금자에는
  각 오류(빨간색), 사용자 불편 신호가 나타난 각 동작(주황색), 첫 페이지 이후의 각 페이지
  (회색)에 눈금을 표시합니다.
- 리플레이 아래에는 **개발자 도구**가 있습니다. **오류**, **네트워크**, **성능**은 아래에서 설명합니다.
- **사용자 컨텍스트**: 사용자, 기기, 위치, IP 주소, 애플리케이션, 환경, 버전,
  세션 지속 시간을 표시합니다.
- **페이지**에는 방문의 첫 페이지와 마지막 페이지를 표시합니다. **감지된 문제**에는 오류, 비정상 종료, 사용자 불편 신호,
  장기 작업을 표시합니다.
- **이벤트 타임라인**: 세션의 모든 뷰, 동작, 요청, 오류, 장기 작업을 발생 순서대로 표시합니다.
- **관련 트레이스**: 세션 요청에 ID가 포함된 백엔드 트레이스(**직접**)를 표시합니다. 트레이스 ID를 포함한 요청이
  없으면 세션이 진행되는 동안 실행된 트레이스(**시간상 연관**)를 표시합니다. 각 트레이스는 **트레이스**에서 열립니다.

세션 요청에 트레이스 ID가 포함된 경우, **트레이스**의 트레이스 상단에 **사용자 세션**이 표시됩니다.

세션 상단에서 **현재 재생 위치 링크 복사**를 선택하면 현재 리플레이 재생 위치가 포함된 주소를 복사하고,
**재생목록에 추가**를 선택하면 세션을 [재생목록](/ko/rum/playlists)에 추가합니다.

### 개발자 도구

리플레이 아래에는 각각 항목 수를 표시하는 **오류**, **네트워크**, **성능** 탭이 있습니다. 각 탭은
현재 세션의 이벤트를 표시하며 리플레이 재생 위치에 맞춰 갱신됩니다.

- 현재 재생 위치까지 발생한 이벤트 중 가장 최근 이벤트의 행 왼쪽에 강조선을 표시합니다. 리플레이를 재생하거나 위치를 옮기면 해당 행이
  보이도록 목록만 스크롤하고, 페이지의 스크롤 위치는 그대로 유지합니다.
- 행을 선택하면 해당 시점으로 이동한 후 리플레이를 일시 정지합니다. 시간은 진행 표시줄의 눈금자와 마찬가지로
  녹화 시작부터 경과한 분과 초로 표시합니다. 리플레이를 기록하지 않은 세션에는 따라가거나 이동할 재생 위치가 없습니다. 이 경우 세션 시작부터 경과한 시간을 표시하며,
  각 행에는 발생한 이벤트만 표시합니다.
- **오류**는 세션에서 발생한 오류를 발생 순서대로 나열합니다. 각 오류의 발생 시각, 유형, 메시지, 해당 오류가
  속한 문제를 표시합니다. 문제를 선택하면 [오류](/ko/rum/errors)에서 열립니다. 세션에서 오류가 발생하면 개발자 도구는
  **오류** 탭을 먼저 열고, 오류가 없으면 **네트워크** 탭을 먼저 엽니다.
- **네트워크**는 한 뷰의 요청을 나열합니다. 각 요청의 발생 시각, 메서드, 호스트와 경로, 상태, 유형, 소요 시간,
  크기를 표시하고, 전체 요청 시간대에서 각 요청이 차지하는 구간을 막대로 표시합니다. **보기**에서 뷰를 선택합니다. 뷰를 선택하기 전에는
  현재 리플레이의 뷰를 표시합니다. **리플레이 따라가기**를 선택하면 이 동작으로 돌아갑니다. **모든 뷰**는 세션의 모든 요청을 나열합니다. **표시**에서
  느린 요청(500 ms 이상) 또는 실패한 요청만 표시할 수 있습니다. **워터폴**은 탐색기와 같은 방식으로 뷰의 로딩 과정을
  표시합니다([뷰의 로딩 과정](/ko/rum/performance#뷰-로드) 참조).
- **성능**은 세션의 뷰마다 한 행을 표시합니다. LCP, INP, CLS는 등급별 색상으로 표시하고, 요청과
  장기 작업의 개수도 표시합니다. 행을 선택하면 **네트워크**에서 해당 뷰의 워터폴을 엽니다.
- **로그**는 페이지가 [로그에 기록한 내용](/ko/rum/logs)을 나열합니다. 현재 재생 위치에 해당하는 행을 강조하며, 행을 선택하면 리플레이가 해당 시점으로 이동합니다.
- **댓글**에는 [리플레이의 특정 시점에 남긴 댓글](/ko/rum/session-replay#댓글)이 표시됩니다.

탭, 뷰, 요청 표시 방식은
주소의 `tab`, `view`, `display`, `show`에 포함됩니다. 리플레이를 열 때의 재생 위치도 `at`에 포함되며(에포크 이후 경과 시간을 마이크로초로 표기),
리플레이는 재생을 시작할 때까지 해당 위치에서 대기합니다. [사용자 불편](/ko/rum/frustration)의 링크는 해당 위치에서 세션을 엽니다.

## 탭, 공유 및 주소

탐색기는 **로그**와 동일한 쿼리 탭을 사용합니다. 여러 쿼리를 나란히 열고, 탭 이름을 바꾸고, 화면을 분할할 수 있습니다.
페이지 주소에는 화면에 표시된 쿼리가 반영됩니다. 유형(`type`), 필드 쿼리(`q`), 시간 범위(`time`)를 포함하고,
행을 숫자로 표시하는 경우 표시 방식도 포함합니다([행을 숫자로 표시](#행을-수치로-시각화하기) 참조). 주소 표시줄의 주소를 복사해 쿼리를 공유할 수 있습니다. **공유**에서는 시간 범위를 선택해 링크를 복사합니다.

**저장된 뷰**는 현재 화면 설정에 이름을 붙여 나중에 다시 열 수 있도록 저장합니다. 유형, 쿼리, 행 표시 방식과
상대 시간 범위(예: "지난 1시간")를 저장합니다. 고정 시간 범위는 뷰를 열 때 설정합니다. 저장된 뷰는 계정당 최대 30개이며, 해당 계정으로 로그인한 모든
브라우저에서 사용할 수 있습니다. 뷰를 공유하려면 주소를 보냅니다.

## 탐색기가 읽는 데이터

각 행의 데이터는 [RUM 스트림](/ko/rum/events#이벤트-저장-위치)에 있습니다. 쿼리 엔진은
**로그**와 동일한 마스킹과 제한을 적용해 쿼리를 실행합니다. 개수 집계에 시간이 너무 오래 걸리면 집계 결과를 사용할 수 없다고 표시합니다. 열과
단위는 [이벤트 형식](/ko/rum/events)의 필드 정의를 따릅니다.
