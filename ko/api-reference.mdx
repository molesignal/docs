MoleSignal은 버전이 지정된 HTTP API를 제공합니다. 제품 엔드포인트는 `/api/v1`을 사용합니다. 상태 확인 프로브, Prometheus 메트릭, 공개 공유 링크, 일부 호환 프로토콜은 다른 경로도 사용합니다.

## 기본 URL

로컬 인스턴스에서는 다음 URL을 사용합니다.

```text
http://localhost:5080/api/v1
```

프로덕션에서는 호스트를 배포의 공개 주소로 바꿉니다. 이 주소는 `[http].external_url` 값입니다.

## 인증

보호된 엔드포인트는 `Authorization` 헤더에서 Bearer 토큰을 받습니다.

```http
Authorization: Bearer <token>
```

| 토큰 | 발급 방법 | 유효 기간 |
|---|---|---|
| API 토큰 | **계정 설정 → API 토큰** 또는 [API 토큰 발급](/ko/api/auth/issue-token)에서 발급합니다. 토큰 형식은 `mspat-<36>`입니다. | 토큰을 폐기하거나 지정한 만료 시점에 도달할 때까지 유효합니다. |
| 기본 수집 토큰 | `GET /api/v1/me/api-tokens/default`. `logs.write`, `metrics.write`, `traces.write`, `profiles.write`, `apm.deploy` 권한으로 제한합니다. | 만료되지 않습니다. |
| RUM 클라이언트 토큰 | `GET /api/v1/auth/tokens/rum?applicationId=<id>`. `rum.write` 권한으로 제한합니다. | 만료되지 않습니다. |

스크립트와 수집기에는 API 토큰을 사용합니다. 수집 토큰은 [데이터 소스](/ko/intake#수집-토큰)를 참조합니다.

웹 UI는 `POST /api/v1/auth/signin`으로 로그인합니다. 이 엔드포인트는 토큰을 반환하는 대신 세션 쿠키를 설정합니다. `Authorization` 헤더는 세션 토큰을 받지 않습니다. [로그인](/ko/api/auth/login)을 참조합니다.

인증 과정에서 주체, 활성 조직 또는 플랫폼 범위, 유효 권한을 포함하는 IAM 컨텍스트를 구성합니다. 요청의 조직은 항상 이 컨텍스트에서 가져옵니다. 요청 본문으로 다른 조직을 선택할 수 없습니다.

## 공개 경로 및 자체 인증 경로

일부 경로에서는 조직 Bearer 토큰을 사용할 수 없습니다. 대신 사용 범위가 더 좁은 자격 증명이나 정책을 검증합니다.

- 로그인, 가입 정책, 비밀번호 재설정
- `GET /api/v1/healthz` 및 최상위 `/metrics`
- 공개 리소스 공유 교환 요청 및 공유 세션 요청
- 서명된 파일 다운로드 및 공개 아바타
- 푸시 토큰을 검증하는 푸시 커넥터 엔드포인트

공개 경로에도 접근 제한이 있습니다. 핸들러는 가입 정책, 공유 토큰, 다운로드 토큰, 서명 또는 커넥터 자격 증명을 확인합니다.

## 권한 부여

엔드포인트는 다음 조건 중 하나 이상을 요구할 수 있습니다.

- `streams.query`와 같은 조직 권한
- `sys.telemetry.read`와 같은 플랫폼 권한
- 리소스 소유권, 리소스와의 관계 또는 조직 간 권한 부여

`GET /api/v1/iam/capabilities`는 현재 주체의 유효 권한을 반환합니다. 역할 이름이나 화면에 표시되는 메뉴 항목만으로 접근 권한을 판단하지 않습니다.

## 요청

- 대부분의 요청 본문은 `Content-Type: application/json`을 사용하는 JSON입니다.
- 호환 수집 엔드포인트는 해당 프로토콜의 페이로드를 사용합니다. 예를 들어 Protobuf, NDJSON 또는 gzip으로 압축한 본문을 사용합니다.
- 수집 요청 본문이 2 MiB를 초과하면 `413`을 반환합니다. 네이티브 JSON 수집의 한도는 16 MiB입니다.
- 시간 값은 Unix epoch를 기준으로 마이크로초 단위의 정수로 표현합니다. 시점을 나타내는 필드에는 해당 시점의 이벤트에 맞춰 이름을 지정합니다(`createdAt`, `expiresAt`). 단어 하나만으로 의미가 명확하지 않으면 `Time`을 붙입니다(`startTime`). 시간 길이를 나타내는 이름은 `Time`으로 끝나지만(`p95Time`), 이름 자체가 시간 길이를 뜻하면 붙이지 않습니다(`duration`). 네이티브 텔레메트리 레코드에도 마이크로초 단위의 `_timestamp`를 사용합니다.
- 경로에 포함된 ID와 스트림 이름은 URL 인코딩합니다.

## 응답 및 오류

엔드포인트가 파일을 스트리밍하거나 다운로드로 제공하지 않으면 성공 응답은 JSON입니다. 오류 응답에는 상태 코드와 함께 기계가 읽을 수 있는 `error` 코드와 `message`가 담긴 JSON 본문이 포함됩니다.

```json
{
  "error": "unauthorized",
  "message": "unauthorized: missing Authorization Bearer token"
}
```

`validation_failed` 오류는 유효하지 않은 필드마다 항목을 하나씩 담은 `issues` 배열을 추가합니다.

| 상태 | `error` | 의미 |
|---|---|---|
| `400` | `invalid_argument`, `validation_failed` | 요청 또는 요청 매개변수 중 하나가 유효하지 않습니다. |
| `401` | `unauthorized` | 토큰이 없거나, 형식이 잘못되었거나, 유효하지 않거나, 만료되었습니다. |
| `403` | `forbidden` | 필요한 권한, 관계 또는 범위가 없습니다. |
| `404` | `not_found` | 리소스가 존재하지 않거나 권한이 부여된 범위에서 표시되지 않습니다. |
| `409` | `conflict` | 상태가 충돌하거나 고유성 제약을 위반했습니다. |
| `413` | `payload_too_large` | 본문이 크기 한도를 초과합니다. |
| `429` | `resource_exhausted` | 요청 빈도 제한이 적용됩니다. `Retry-After` 헤더가 있으면 지정된 시간만큼 기다립니다. |
| `499` | `cancelled` | 요청이 취소되었습니다. |
| `503` | `unavailable` | 종속 서비스를 사용할 수 없습니다. |
| `500` | `internal` | 내부 오류가 발생했습니다. 본문에는 `internal error` 메시지를 반환하고, 세부 정보는 서버 로그에만 기록합니다. |

요청 본문을 파싱할 수 없으면 엔드포인트에 도달하기 전에 요청이 실패합니다. 이때 JSON 대신 일반 텍스트로 응답합니다.

| 상태 | 의미 |
|---|---|
| `400` | 본문이 유효한 JSON이 아닙니다. |
| `415` | 요청에 `Content-Type: application/json`이 없습니다. |
| `422` | 필드가 누락되었거나 타입이 잘못되었습니다. 응답 텍스트에 해당 필드 이름이 표시됩니다. |

모든 응답에는 `X-Request-Id`와 `X-Trace-Id` 헤더가 포함됩니다. 서버 측 오류를 보고할 때는 두 헤더를 모두 포함합니다.

## 페이지네이션

여러 행을 반환할 수 있는 엔드포인트는 `limit`과 `cursor`를 받습니다. 응답에는 `items`와 `nextCursor`가 포함됩니다. 다음 페이지를 읽으려면 `nextCursor`를 `cursor`로 전달하고, `nextCursor`가 비어 있으면 조회를 종료합니다. 그 외 목록 엔드포인트는 전체 목록을 반환합니다. 각 엔드포인트의 문서 페이지를 참조합니다.

## 쿼리 및 장시간 실행 작업

쿼리 엔드포인트는 일반 JSON을 반환하거나 NDJSON을 스트리밍하며, 오래 걸리는 쿼리는 비동기 검색 작업으로 실행합니다. 쿼리 규모가 너무 크면 `jobId`와 `monitor` 경로를 포함한 `202` 응답을 반환합니다. 스트리밍을 요청하는 클라이언트는 결과가 일부만 전달되는 경우를 처리하고, 결과가 더 이상 필요하지 않으면 요청을 취소해야 합니다. [쿼리](/ko/query)를 참조합니다.

생성된 보고서, 프로파일 블롭, 내보내기 결과처럼 크기가 큰 산출물은 JSON 본문에 담지 않습니다. 대신 접근 범위를 제한한 다운로드 토큰을 사용해 파일로 제공합니다.
