開啟 **設定 → 一般**。檢視此頁面需要 `org.preferences.read`，修改需要 `org.preferences.manage`；公開分享一節則分別需要 `org.sharing.read` 和 `org.sharing.manage`。各組設定修改後，稍候片刻就會自動儲存。**撤銷** 會復原最近一次修改，**重試** 會重新送出儲存失敗的修改。

## 組織資訊

| 欄位 | 規則 |
|---|---|
| **組織名稱** | 顯示在工作區切換器、頁面標題和邀請中，為必填欄位。 |
| **標誌** | 在工作區切換器中取代 MoleSignal 的標誌。**上傳** 支援 PNG、JPEG、WEBP 或 SVG 圖片，並將圖片縮放至 128 × 128；**移除** 會還原為 MoleSignal 的標誌。選取後立即儲存。 |
| **說明** | 用一兩句話說明工作區的用途，並顯示在工作區選單中。最多 120 字。 |
| **組織識別碼** | 唯讀，用於 API 和資源識別。按一下 **複製** 即可複製。 |
| **組織 ID** | 唯讀，用於 API、稽核記錄和技術支援。按一下 **複製** 即可複製。 |

建立組織後，組織識別碼和 ID 就不會變更。

## 偏好設定的預設值

**組織偏好設定的預設值** 適用於尚未儲存個人偏好設定的成員。個人[偏好設定](/zh-Hant/account#偏好設定)和在查詢頁面暫時變更的時間顯示設定優先。

| 群組 | 欄位 |
|---|---|
| 外觀 | **預設主題**、**介面密度**。 |
| 語言與地區 | **語言**、**預設時區**、**日期與時間格式**。 |
| 啟動與互動 | **進入工作區後開啟**、**啟用鍵盤快速鍵**。 |

## 註冊與存取

| 設定 | 效果 |
|---|---|
| **允許自行加入** | 符合執行個體註冊條件的使用者可以自行加入此工作區。 |
| **須經管理員核准** | 自行加入的使用者會在[審核](/zh-Hant/identity/members#審核)中等待管理員核准。啟用自行加入後才會顯示。若執行個體無法寄送電子郵件，就無法驗證信箱歸屬，此設定會保持啟用。完成 `[notify.smtp]` 和 `[http].external_url` 的設定後才能關閉。 |
| **預設組織角色** | 自行加入時取得的角色，來自 IAM 目錄。若單一登入未符合任何角色對應規則，且服務供應商未指定預設角色，也會使用此角色。 |

## 分享與公開存取

這些設定會限制成員可建立的[受限公開連結](/zh-Hant/resource-sharing)。在工作區內分享或跨組織分享一律需要登入。

| 設定 | 效果 |
|---|---|
| **允許建立公開連結** | 成員可以為允許分享的資源建立不需帳號即可開啟的受限連結。必須先啟用此設定，才能使用下列設定。 |
| **允許公開分享即時儀表板** | 允許為即時儀表板建立公開連結。公開頁面為唯讀，並限制查詢、變數、時間範圍和跳轉。 |
| **公開連結的最長有效期限** | **1 天**、**7 天** 或 **30 天**。建立者不能選擇更晚的到期時間。 |
| **公開報告必須設定密碼** | 通過密碼驗證後，系統才會為公開報告核發短效分享工作階段。 |
| **禁止公開分享正式環境資源** | 資源帶有 `production` 或 `prod` 標籤時，系統會拒絕建立公開連結。 |
| **允許公開下載 CSV** | 關閉後，只能在受限頁面中預覽公開的 CSV 報告。 |

## 組織生命週期

具備 `org.delete` 權限的成員（預設為 Owner）可在此輸入組織名稱後刪除組織。刪除後，所有成員都會退出該組織，且組織無法復原。若未具備此權限，**前往組織管理** 會切換至 `_sys` 組織，刪除組織需要 `sys.organizations.delete`。請參閱[組織管理](/zh-Hant/settings/platform#組織管理)。
