**擴充表** 是儲存在 MoleSignal 中的小型「鍵 → 記錄」查閱表。[管線](/zh-Hant/pipelines)的轉換會依鍵查詢擴充表，為事件補充參考資料：將 `service` 對應至所屬團隊、將帳號 ID 對應至方案等級，或將區域代碼對應至區域名稱，而不必在頻繁執行的路徑上存取外部儲存空間。

## 擴充表清單

開啟 **擴充表**。頁面頂端會顯示擴充表和記錄的總數。每張表都會顯示查詢鍵和欄位、記錄數、使用位置、最近更新時間和狀態（**正常** 或 **空表**）。可依狀態和使用情況（**使用中** 或 **未使用**）篩選，也可依名稱搜尋。

## 新增擴充表

點選 **新增擴充表**。精靈分為兩個步驟。

<Steps>
  <Step title="定義結構">
    填寫 **表格名稱** 和 **說明**。選擇 **查詢鍵**，也就是能唯一識別一筆記錄的欄位，例如 `customer_id`、`service` 或 `region_code`。新增 **Value 欄位**，填寫 **欄位** 名稱、**類型**（**字串**、**數字**、**布林值** 或 **物件**）、是否 **必填** 及說明。未新增 Value 欄位時，系統會以不限定結構的 JSON 儲存記錄。每張表最多可有 100 個 Value 欄位；欄位名稱只能使用字母、數字、`.`、`-` 和 `_`。
  </Step>
  <Step title="新增或匯入資料">
    選擇 **從空表開始**，稍後再新增記錄；或選擇 **貼上 JSON** 立即匯入。可匯入 JSON 記錄陣列（每筆記錄都必須包含查詢鍵），或將每個鍵對應至其記錄的物件。
  </Step>
</Steps>

點選 **建立擴充表**。

## 記錄

開啟一張表。**資料記錄** 分頁會列出所有記錄，可依查詢鍵或欄位值搜尋。

| 操作 | 效果 |
|---|---|
| **新增記錄** | 使用 **表單模式** 或 **JSON 模式** 填寫查詢鍵和欄位值。如果查詢鍵已存在，系統會先顯示提示，再覆寫原有記錄。 |
| **編輯記錄** | 修改記錄的值。 |
| **檢視 JSON** | 顯示整筆記錄，包括未在表格中單獨顯示的欄位。 |
| **刪除記錄** | 刪除記錄。這項操作無法復原。 |
| **匯入資料** | 一次寫入多筆記錄。來源可以是 JSON 檔案（陣列或「鍵 → 記錄」對應）、第一列為欄位名稱的 CSV 檔案，或貼上的 JSON 或 CSV。資料必須包含查詢鍵欄位。摘要會顯示將匯入的記錄筆數，以及其中有多少筆會覆寫查詢鍵相同的現有記錄。 |

## 欄位結構、使用位置與設定

| 分頁 | 內容 |
|---|---|
| **欄位結構** | 顯示查詢鍵和 Value 欄位。透過 **編輯欄位** 可新增欄位、修改說明和調整 **必填** 設定。表中已有記錄時，無法重新命名、變更類型或刪除現有欄位；空表則允許這些變更。表格名稱和查詢鍵無法修改。 |
| **使用位置** | 列出參照這張表的管線和已儲存的查詢。修改或刪除表格前，請先檢查使用位置。 |
| **設定** | 包含 **資料表資訊**，以及 **危險操作** 中的 **刪除擴充表**。刪除擴充表會一併刪除所有記錄。刪除後，查詢這張表一律會傳回 `null`。管線會將原本要寫入這張表的事件計為失敗；若已設定死信資料流，就會將這些事件寫入該資料流。 |

## 在管線中查詢

管線可透過兩種方式讀取擴充表：[**查詢擴充表以補充資料**](/zh-Hant/pipelines#查詢擴充表以補充資料)步驟會將記錄中的值填入事件欄位；VRL 步驟中的 [`lookup(table, key)`](/zh-Hant/functions#查詢擴充表與-ip-位址) 則會傳回整筆記錄：

```ruby
# 为每个事件补充服务所属的团队
.team = lookup("service_meta", .service).team
```

各種管線都可使用這兩種方式，包括[告警管線](/zh-Hant/pipelines/alert-events)。管線步驟首次使用某張表時，節點會將表格載入記憶體並保留 30 秒，因此查詢不會增加管線執行時的查詢或儲存負擔。新增、刪除或修改記錄後，變更會在 30 秒內套用至所有管線。擴充表隸屬於工作區，該工作區中的所有管線都可使用。

## 由管線寫入

排程管線可持續更新一張表：選擇 **新增目標 → 擴充表**，每筆事件經過各步驟後，管線會依查詢鍵的值將事件寫成一筆記錄。請參閱[寫入擴充表](/zh-Hant/pipelines#寫入擴充表)。

## 擴充表 API

```bash
# 以 "checkout" 为键写入或更新一条记录
curl -X PUT http://localhost:5080/api/v1/extend_tables/service_meta/rows/checkout \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"team":"payments","tier":"gold"}'
```

| 操作 | 端點 |
|---|---|
| 列出擴充表 | `GET /api/v1/extend_tables` |
| 列出表中的記錄 | `GET /api/v1/extend_tables/{table}` |
| 寫入或更新記錄 | `PUT /api/v1/extend_tables/{table}/rows/{key}` |
| 刪除記錄 | `DELETE /api/v1/extend_tables/{table}/rows/{key}` |

## 權限

列出擴充表及其使用位置需要 `functions.read`。建立表格需要 `functions.create`，修改記錄和欄位需要 `functions.edit`，刪除表格需要 `functions.delete`。
