## 列出資料流

```bash
molesignal streams
```

清單會顯示使用者可讀取的每個日誌資料流，以及各資料流的欄位數、保留期限和說明。`--type` 可列出其他類型的資料流：`metrics`、`traces`、`profiles` 或 `extend`。`--names` 只輸出名稱，`--json` 每行輸出一個資料流的 JSON。

## 輸出最新的日誌

```bash
molesignal logs app_logs
```

指令會輸出最近 15 分鐘內最新的 100 筆日誌，依時間從早到晚排列。每筆一行，包含時間、層級、服務和訊息。

```text
2026-10-18 03:14:15.361 INFO  checkout order 4812 created
2026-10-18 03:14:25.361 ERROR payment gateway timeout after 3 retries
```

層級取自 `level`、`severity`、`severity_text` 等欄位，服務取自 `service` 或 `service.name`，訊息取自 `message`、`msg`、`body` 或 `log`。沒有訊息欄位的日誌會以 `名稱=值` 列出其他欄位。輸出至終端機時會加上色彩；`NO_COLOR` 可關閉色彩，`FORCE_COLOR` 則可在管道中保留色彩。

| 選項 | 預設值 | 說明 |
|---|---|---|
| `-n`、`--lines <数量>` | `100` | 先輸出的最新日誌筆數，最多 `5000` 筆。 |
| `--since <时长>` | `15m` | 往回查詢的時間長度：`30s`、`10m`、`2h`、`1d`、`1w`。 |
| `--from <时间>`、`--to <时间>` | 無 | 以時間範圍取代 `--since`：可使用 ISO 時間、本機時間 `2026-10-26 14:00`，或像 `2h` 這樣往回推算的時間長度。 |
| `-q`、`--query <查询>` | 無 | 欄位查詢，語法與 **日誌** 頁面相同。 |
| `--where <条件>` | 無 | 套用至資料流欄位的 SQL 條件。 |
| `--fields <a,b,c>` | 全部 | 只輸出時間和這些欄位，並以 `名稱=值` 顯示欄位。 |
| `--json` | 關閉 | 每筆日誌輸出一行 JSON。 |
| `--utc` | 關閉 | 以 UTC 取代本機時間來顯示時間。 |
| `--web` | 關閉 | 在 **日誌** 頁面開啟相同的日誌，不直接輸出。 |

## 篩選日誌

`-q` 接受 **日誌** 頁面的欄位查詢語法，例如 `level = 'error'` 這類比較式，以及 `contains`、`MATCH` 和 `MATCH_TEXT`。使用 `AND` 和 `OR` 連接條件，並以括號分組。未指定欄位的文字會在 `message` 中搜尋：

```bash
molesignal logs app_logs --since 1h -q "level = 'error' AND (service = 'payment' OR timeout)"
```

`--where` 接受套用至資料流欄位的 SQL 條件，語法與查詢中的 `WHERE` 子句相同：

```bash
molesignal logs app_logs --where "status >= 500 AND duration_ms > 2000"
```

同時指定兩種條件時，日誌必須同時符合兩者。若條件參照不存在的欄位，或 SQL 語法無效，指令會說明原因後結束。

## 持續追蹤新日誌

```bash
molesignal logs app_logs -f
```

輸出最新的日誌後，指令會持續輸出新收到的日誌，直到按下 **Ctrl+C**：

- 每 2 秒讀取一次；可用 `--interval` 調整間隔。
- 每次讀取都從上一次讀取結束前 10 秒開始。晚幾秒抵達 MoleSignal 的日誌也會顯示，且只會顯示一次。
- 若短時間湧入的日誌無法一次讀完，指令會立即繼續讀取，不必等待。
- 連線中斷時，指令會重試，每次等待時間逐步延長，最長 30 秒。中斷與恢復的訊息會輸出至標準錯誤。

指令會依日誌本身的時間推進讀取範圍。若收到的日誌時間早於目前的讀取起點，就不會顯示。`--to` 無法與 `-f` 一起使用。

## 查看特定時間前後的日誌

`--around` 會輸出最接近指定時間的前後日誌，並在中間以一行標示該時間。使用 `-B` 和 `-A` 設定筆數，預設各 10 筆，最多各 250 筆。使用 `-q` 和 `--where` 可縮小範圍：

```bash
molesignal logs app_logs --around "2026-10-26 14:03:12.345" -B 20 -A 20
```

可直接將從 `molesignal logs` 輸出複製的時間用於 `--around`。

## 對資料流執行 SQL

`molesignal query` 會執行一條唯讀 SQL 陳述式，可使用運算式、聯結和彙總，並以表格輸出結果：

```bash
molesignal query "SELECT level, COUNT(*) AS logs FROM app_logs GROUP BY level ORDER BY logs DESC"
```

指令會採用 `FROM` 後的第一個資料流；可用 `--stream` 指定其他資料流。時間範圍預設為最近一小時，可用 `--since`、`--from` 和 `--to` 調整。使用 `-n` 設定輸出列數上限，預設為 `1000`，最多 `5000`。`--csv` 會輸出含欄名的 CSV，`--json` 會將每列輸出為一行 JSON，`--web` 則會在 **日誌** 頁面開啟這條陳述式。

## 查看資料流的欄位

```bash
molesignal fields app_logs
```

清單會顯示每個欄位的類型和索引。指定欄位時，指令會列出該欄位在最近一小時內最常見的值及出現次數：

```bash
molesignal fields app_logs service --since 1d
```

`--match` 只保留包含指定文字的值，`-n` 可設定筆數，預設為 `20`。`--type` 可讀取其他類型的資料流。

## 在管道中使用

`--json` 會輸出每筆日誌的所有欄位：

```bash
molesignal logs app_logs -n 1000 --since 2h --json | jq -r .message
```

下游指令提早結束時（例如 `head`），這個指令也會結束，不顯示任何訊息。

## 存取權限

命令列會透過 MoleSignal 的 `list_streams`、`query_logs`、`get_stream_schema`、`search_field_values` 和 `search_around` 工具讀取資料，並使用登入帳號或 API Token 擁有者的權限。帳號必須具備 `streams.query` 權限，且組織的 Tool Policy 不得停用這些工具。
