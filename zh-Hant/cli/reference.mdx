`molesignal <命令> --help` 會針對單一命令輸出相同內容。

## 每個命令都接受的選項

每個與 MoleSignal 通訊的命令都接受以下選項：

| 選項 | 含義 |
|---|---|
| `--profile <名称>` | 指定要使用的已儲存登入。請參閱[儲存多組登入](/zh-Hant/cli/sign-in#儲存多組登入資訊)。 |
| `--url <地址>` | 指定 MoleSignal 位址，取代 profile 中的位址。 |
| `--token <token>` | 只對此命令生效的 API Token。 |

時間可寫成 ISO 時間、本機時間 `2026-10-26 14:00`、自 Unix 紀元起算的秒數、毫秒數或微秒數，或往回推算的時長。時長由數字和單位組成：`ms`、`s`、`m`、`h`、`d` 或 `w`。

## 登入

| 命令 | 選項 | 說明 |
|---|---|---|
| `login` | `--url <地址>`、`--profile <名称>`、`--with-token` | 在瀏覽器中登入，或使用從標準輸入讀取的 API Token 登入。此 profile 會成為目前的 profile。 |
| `logout` | `--profile <名称>` | 刪除指定 profile 的登入，並保留其位址。 |
| `profiles` | `--json` | 列出 profile。使用 `profiles remove <名称>` 刪除指定的 profile。 |
| `use <profile>` | 無 | 將指定的 profile 設為目前的 profile。 |
| `status` | 無 | 顯示位址、profile、伺服器、MCP 通訊協定版本、登入方式和工具數量。 |
| `whoami` | `--json` | 顯示使用者、組織、角色和權限。 |
| `doctor` | 無 | 檢查 Node.js、設定、位址、Proxy、網路與 TLS、時鐘、登入和 MCP 端點。 |

## 日誌與查詢

| 命令 | 選項 | 說明 |
|---|---|---|
| `streams` | `--type <类型>`、`--names`、`--json` | 列出指定類型的資料串流，預設為 `logs`。 |
| `logs <数据流>` | `-f`、`-n`、`-q`、`--where`、`--since`、`--from`、`--to`、`--fields`、`--around`、`-B`、`-A`、`--interval`、`--json`、`--utc`、`--web` | 輸出資料串流的最新日誌；`-f` 會持續輸出新日誌。請參閱[檢視與追蹤日誌](/zh-Hant/cli/logs)。 |
| `query "<SQL>"` | `--stream`、`--since`、`--from`、`--to`、`-n`、`--csv`、`--json`、`--utc`、`--web` | 對日誌資料串流執行一條唯讀 SQL 查詢。 |
| `fields <数据流> [字段]` | `--type`、`--since`、`--from`、`--to`、`-n`、`--match`、`--json` | 列出資料串流的欄位，或指定欄位中最常見的值。 |

### `logs` 的選項

| 選項 | 預設值 | 含義 |
|---|---|---|
| `-f`、`--follow` | 關閉 | 持續輸出新日誌，直到按下 **Ctrl+C**。 |
| `-n`、`--lines <数量>` | `100` | 指定先輸出幾筆最新日誌，範圍為 `1` 到 `5000`。 |
| `-q`、`--query <查询>` | 無 | 欄位查詢，語法與 **日誌** 頁面相同。 |
| `--where <条件>` | 無 | 適用於資料串流欄位的 SQL 條件。 |
| `--since <时长>` | `15m` | 指定往回查詢的時長。 |
| `--from <时间>`、`--to <时间>` | 無 | 指定時間範圍以取代 `--since`。`--to` 不能與 `-f` 一起使用。 |
| `--fields <a,b,c>` | 全部 | 只輸出時間和這些欄位。 |
| `--around <时间>` | 無 | 輸出緊鄰指定時間前後的日誌。 |
| `-B`、`--before <数量>` | `10` | 與 `--around` 搭配使用：指定之前的筆數，最多 `250` 筆。 |
| `-A`、`--after <数量>` | `10` | 與 `--around` 搭配使用：指定之後的筆數，最多 `250` 筆。 |
| `--interval <时长>` | `2s` | 指定持續追蹤時的讀取間隔。 |
| `--json` | 關閉 | 每筆日誌輸出為一行 JSON。 |
| `--utc` | 關閉 | 以 UTC 顯示時間。 |
| `--web` | 關閉 | 改在 **日誌** 頁面中開啟，不直接輸出。 |

## 指標、追蹤與服務

| 命令 | 選項 | 說明 |
|---|---|---|
| `metrics query '<PromQL>'` | `--since`、`--from`、`--to`、`-n`、`--csv`、`--json` | 執行 PromQL 區間查詢，每個時間序列各占一行，並附上迷你折線圖。 |
| `metrics names [文本]`、`metrics labels <指标>`、`metrics values <指标> <标签>`、`metrics series <指标>` | `-n`、`--match <标签=值>`、`--json` | 列出指標名稱、標籤、標籤值和時間序列。 |
| `traces` | `--service`、`--errors`、`--min-duration`、`--since`、`--from`、`--to`、`-n`、`--json` | 列出最近的追蹤記錄。 |
| `traces show <链路>` | `--since`、`--from`、`--to`、`--json`、`--web` | 以瀑布圖呈現一筆追蹤記錄。 |
| `services` | `--env`、`--namespace`、`--sort`、`--since`、`--from`、`--to`、`-n`、`--json` | 列出 APM 服務及其健全狀態。 |
| `services show <服务>` | `--env`、`--namespace`、`--since`、`--json`、`--web` | 顯示指定服務的摘要。 |
| `services compare <服务> <基线版本> <候选版本>` | `--env`、`--since`、`--fail-on-regression`、`--json` | 比較兩個版本。 |
| `search-jobs` | `-n`、`--json` | 列出搜尋工作。 |
| `search-jobs submit "<语句>"` | `--stream`、`--type`、`--promql`、`--step`、`--since`、`--from`、`--to`、`--limit`、`--keep`、`--wait`、變更選項 | 提交搜尋工作。 |
| `search-jobs show <任务>`、`search-jobs results <任务>`、`search-jobs cancel <任务>` | `-o <文件>`、`--csv`、`--json`、變更選項 | 檢視工作、輸出結果或取消工作。 |

## 值班與變更

| 命令 | 選項 | 說明 |
|---|---|---|
| `incidents` | `--status`、`--since`、`-n`、`--json` | 列出事件，預設只列出進行中的事件。 |
| `incidents show <事件>` | `--rca`、`--json`、`--web` | 輸出指定事件。 |
| `incidents ack <事件>`、`incidents resolve <事件>` | 變更選項 | 確認或解決指定事件。 |
| `incidents create --title <文字>` | `--description`、`--severity`、`--priority`、`--urgency`、`--service`、`--label`、`--team`、`--policy`、`--user`、`--major`、`--json`、變更選項 | 針對規則未偵測到的問題，手動建立事件。若未使用 `--team`、`--policy` 或 `--user`（填入 ID）指定接手對象，事件會沿用告警的路由流程。`--priority` 和 `--urgency` 使用組織設定的等級。輸出新事件的 ID 和連結。 |
| `oncall` | `--schedule`、`--at`、`--json` | 顯示值班人員。 |
| `approvals` | `--all`、`-n`、`--json` | 列出待核准或已核准的申請。 |
| `approvals show <审批>`、`approvals execute <审批>` | `--json`、變更選項 | 輸出指定申請，或執行已核准的變更。 |
| `annotate "<标题>"` | `--description`、`--tags`、`--dashboard`、`--stream`、`--time`、`--end`、變更選項 | 為儀表板新增註記。 |
| `synthetics` | `--lifecycle`、`--json` | 列出合成監控檢查。 |
| `synthetics results <检查>` | `--since`、`-n`、`--json` | 列出指定檢查最近的執行結果。 |
| `synthetics run <检查>` | 變更選項 | 立即執行指定檢查；使用 `--wait` 時會等待執行結果。 |
| `alerts rules export` | `--ids`、`-o`、`--output` | 將告警規則匯出為規則套件；使用 `--ids` 時只匯出指定的規則。請參閱[匯入與匯出](/zh-Hant/alerting/rules#匯入與匯出)。 |
| `alerts rules apply -f <文件>` | `--dry-run`、`--create-only`、`--json` | 匯入規則套件或 Prometheus 告警規則檔案（`-f -` 會讀取標準輸入）：先模擬執行並顯示每條規則將如何處理，確認沒有錯誤後才一次寫入。若有規則發生錯誤，命令會以結束代碼 1 結束，適合用於 CI。 |
| `alerts policies export`、`alerts schedules export`、`alerts routing export` | `--ids`、`-o`、`--output` | 將升級策略、值班排程或路由規則匯出為套件。以電子郵件地址參照使用者，其餘項目則以名稱參照。請參閱[匯入與匯出](/zh-Hant/alerting/on-call#匯入與匯出)。 |
| `alerts policies apply -f <文件>`、`alerts schedules apply -f <文件>`、`alerts routing apply -f <文件>` | `--dry-run`、`--create-only`、`--json` | 以與 `alerts rules apply` 相同的方式匯入這類套件。先匯入值班排程，再匯入參照排程的策略，最後匯入參照策略的規則和路由規則。 |

變更選項如下。請參閱[變更的執行方式](/zh-Hant/cli/changes#如何執行變更)。

| 選項 | 含義 |
|---|---|
| `--reason <文本>` | 變更原因，會隨核准申請一併儲存，並寫入稽核日誌。 |
| `--wait` | 變更需要核准時，等待核准後再執行。 |
| `--timeout <时长>` | 指定 `--wait` 的最長等待時間，預設為 `30m`，`synthetics run` 則預設為 `10m`。 |
| `-y`、`--yes` | MoleSignal 要求確認變更時，直接確認。 |

## 發布與資料

以下命令需要 API Token。請參閱[CI 與發布](/zh-Hant/cli/ci)。

| 命令 | 選項 | 說明 |
|---|---|---|
| `deploy` | `--service`、`--version`、`--env`、`--namespace`、`--kind`、`--status`、`--commit`、`--repository`、`--pull-request`、`--author`、`--ci-url`、`--description`、`--time`、`--dry-run`、`-- <命令>` | 記錄一次發布。 |
| `source-maps upload <路径>…` | `--application`、`--service`、`--release`、`--platform`、`--arch`、`--debug-id`、`--concurrency`、`--dry-run` | 上傳 JavaScript Source Map。 |
| `symbols upload <路径>…` | `--application`、`--service`、`--release`、`--platform`、`--arch`、`--debug-id`、`--concurrency`、`--dry-run` | 上傳 Flutter、Android 和 Apple 符號。 |
| `source-maps list`、`symbols list` | `--application`、`--service`、`--release`、`--platform`、`--kind`、`--json` | 列出已上傳的檔案。 |
| `source-maps delete <ID>`、`symbols delete <ID>` | 無 | 刪除指定的已上傳檔案。 |
| `send <数据流>` | `--field <名称=值>`、`--raw`、`--batch` | 將標準輸入的每一行傳送至日誌資料串流。 |
| `run <数据流> -- <命令>` | `--name`、`--field <名称=值>`、`--quiet` | 執行指定命令，並將其輸出和結束代碼傳送至日誌資料串流。 |

## 工具與設定

| 命令 | 選項 | 說明 |
|---|---|---|
| `tools [词…]` | `--domain`、`--json` | 列出使用者可呼叫的工具。`tools show <工具>` 會輸出指定工具及其參數。 |
| `call <工具> [名称=值…]` | `--input`、`--since`、`--from`、`--to`、變更選項 | 呼叫指定工具，並以 JSON 格式輸出結果。 |
| `mcp` | 無 | 透過 stdio 提供 MoleSignal 的 MCP 工具。 |
| `mcp setup <工具>` | `--scope`、`--installed`、`--print` | 將伺服器新增至 `claude`、`cursor`、`codex`、`vscode` 或 `gemini`。 |
| `open [页面] [ID]` | `--print` | 在瀏覽器中開啟 MoleSignal 頁面。 |
| `completion <shell>` | 無 | 輸出 `bash`、`zsh` 或 `fish` 的自動補全指令碼。 |
| `--help`、`--version` | 無 | 輸出說明或版本。 |

## 環境變數

| 變數 | 含義 |
|---|---|
| `MOLESIGNAL_URL` | MoleSignal 位址，取代 `--url` 或已儲存的位址。 |
| `MOLESIGNAL_TOKEN` | API Token，取代已儲存的登入。 |
| `MOLESIGNAL_PROFILE` | 指定要使用的 profile，取代目前的 profile。 |
| `MOLESIGNAL_CONFIG` | 儲存 profile 的檔案，預設為 `~/.config/molesignal/config.json`。 |
| `HTTPS_PROXY`、`HTTP_PROXY` | 每個請求使用的 Proxy。 |
| `NO_PROXY` | 不經過 Proxy、直接存取的主機。 |
| `NODE_EXTRA_CA_CERTS` | 系統信任清單之外，額外信任的憑證授權單位。 |
| `NO_COLOR` | 輸出不加上色彩。 |
| `FORCE_COLOR` | 即使未輸出至終端機，也加上色彩。 |

選項優先於環境變數，環境變數優先於已儲存的 profile。

## 結束代碼

| 結束代碼 | 含義 |
|---|---|
| `0` | 命令成功，或已停止追蹤。 |
| `1` | 命令失敗，並將原因輸出至標準錯誤。下列情況也會傳回 `1`：使用 `--wait` 時合成監控檢查執行失敗、使用 `--fail-on-regression` 時偵測到版本退步、`send` 傳送的日誌遭拒，或 `doctor` 有檢查未通過。 |
| `2` | 未知的命令、選項或參數。 |
| `3` | 變更正在等待核准，尚未執行。 |

`deploy -- <命令>` 與 `run` 會以所執行命令的結束代碼結束。
