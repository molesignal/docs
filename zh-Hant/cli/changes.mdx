## 如何執行變更

會變更內容的命令（例如確認事件）會透過託管工具向 MoleSignal 發出變更請求，做法與 Mole Agent 和 Agent 工具相同。組織的 Tool Policy 決定各工具的執行方式，可在 **Mole Agent → 設定 → 工具與能力** 中設定：

| 執行方式 | 命令的行為 |
|---|---|
| 自動執行 | 立即執行變更。 |
| 需要確認 | MoleSignal 要求確認，命令會在終端機中提示確認。`-y`（`--yes`）會預先回答「是」，適合用於 CI。若沒有終端機，也未指定 `--yes`，就不會變更任何內容。 |
| 單人審核、雙人審核 | MoleSignal 會在 **Mole Agent → 審核** 中為審核者建立審核請求。命令會輸出該請求，並以結束代碼 `3` 結束。指定 `--wait` 時，命令會等待審核結果，最多等待 `--timeout` 指定的時間（預設為 30 分鐘），並在核准後執行變更。 |
| 禁止執行 | 命令失敗並說明原因。 |

若工具未設定個別政策，則依風險等級決定執行方式：預設情況下，`create_annotation` 和 `submit_search_job` 需要確認，`acknowledge_incident`、`resolve_incident` 和 `run_synthetic_monitor` 需要單人審核。使用 `--reason` 說明原因，供審核者查閱，並記錄在稽核日誌中。

確認功能需要 MCP 通訊協定版本 2026-07-28。若 MoleSignal 支援此版本，命令列就會使用這個版本。`molesignal status` 會顯示目前使用的版本。

## 列出事件

```bash
molesignal incidents
```

清單會依時間從新到舊列出進行中的事件，並顯示狀態、嚴重程度、持續時間、服務和摘要。使用 `--status resolved` 或 `--status all` 列出其他事件，使用 `--since 7d` 只列出過去 7 天內開始的事件，使用 `-n` 設定筆數。

`molesignal incidents show` 會輸出單一事件的詳細資訊，包括規則、時間、服務、標籤、Runbook 等備註，以及取樣的追蹤資料。使用 `--rca` 附上根本原因分析，或使用 `--web` 在 MoleSignal 中開啟該事件：

```bash
molesignal incidents show <事件> --rca
```

## 確認與解決事件

```bash
molesignal incidents ack <事件>
```

```bash
molesignal incidents resolve <事件> --reason "已回滚到 2.3.9"
```

兩項操作都受 Tool Policy 控管，並且需要 `alerts.incidents.acknowledge` 權限。

## 查看目前的值班人員

```bash
molesignal oncall
```

清單會顯示每個已啟用的值班班表中目前的值班人員。使用 `--schedule` 只查看單一班表，或使用 `--at` 查看其他時間的值班人員，例如 `--at "2026-10-27 09:00"`。

## 執行已核准的變更

`molesignal approvals` 會列出待審核的請求，以及已核准但尚未執行的請求。請求來源包括 Mole Agent、Agent 工具和命令列。使用 `--all` 也會列出已處理的請求。

```bash
molesignal approvals
```

`molesignal approvals show <审批>` 會輸出單一請求的詳細資訊，包括操作、對象、原因、影響和審核記錄。`molesignal approvals execute <审批>` 會執行已核准的變更；MoleSignal 可能會先要求確認：

```bash
molesignal approvals execute <审批>
```

## 在儀表板上新增註解

`molesignal annotate` 會在指定時間點或時段新增註解，並將註解顯示在所有儀表板或指定的單一儀表板上：

```bash
molesignal annotate "Release 2.4.0" --tags release,checkout --yes
```

| 選項 | 說明 |
|---|---|
| `--description <文本>` | 補充說明。 |
| `--tags <a,b>` | 供搜尋使用的標籤。 |
| `--dashboard <ID>` | 只在指定的儀表板上顯示。 |
| `--stream <数据流>` | 註解所涉及的資料串流。 |
| `--time <时间>`、`--end <时间>` | 開始與結束時間。預設為目前時間。 |

新增註解需要 `dashboards.edit` 權限。

## 執行合成監控檢查

`molesignal synthetics` 會列出合成監控檢查及其類型、狀態和生命週期。`molesignal synthetics results <检查>` 會列出單一檢查在各地點最近的執行結果、耗時和失敗原因。可使用 ID 或名稱指定檢查。

`molesignal synthetics run` 會立即在指定檢查的每個地點各執行一次。指定 `--wait` 時，命令會等待執行結果。只要有一次執行失敗，或未在 `--timeout` 指定的時間內完成（預設為 10 分鐘），命令就會以結束代碼 `1` 結束，讓 CI/CD 管線據此阻止發布：

```bash
molesignal synthetics run "Checkout API" --wait --yes
```

結果為 healthy 或 flaky 時視為通過。執行檢查需要 `synthetics.monitors.manage` 權限。若要在 CI 中執行檢查而不必審核，請在 Tool Policy 中將 `run_synthetic_monitor` 設為 **自動執行**。
