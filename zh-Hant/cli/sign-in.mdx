在命令列登入一次，後續指令就會沿用這次登入。有兩種方式：

| 方式 | 適用情境 |
|---|---|
| 瀏覽器登入 | 有人在配備瀏覽器的電腦前操作。使用 OAuth 2.1，登入會自動續期。 |
| API 權杖 | 指令碼、建置機和沒有瀏覽器的電腦。 |

透過瀏覽器登入後，只能存取 MoleSignal 的 MCP 端點。回報發行版本、上傳 Source Map 和符號，以及傳送日誌都會呼叫 MoleSignal 的 API，因此需要 API 權杖。

## 在瀏覽器中登入

```bash
molesignal login --url https://molesignal.example.com
```

1. 命令列工具會向 MoleSignal 註冊，並在預設瀏覽器中開啟 MoleSignal 的授權頁面。若尚未登入 MoleSignal，請先在瀏覽器中登入。
2. 授權頁面會列出用戶端、帳號、組織，以及這次授權允許執行的操作。若帳號隸屬多個組織，請在 **組織** 中選擇一個。授權會繫結至所選的組織。
3. 點選 **授權**。瀏覽器會將控制權交還給命令列工具，命令列工具會顯示可用的工具數量。

命令列工具會要求 `mcp` 和 `offline_access` 兩個權限範圍，因此登入會自動續期，直到授權遭到撤銷。授權頁面會等待五分鐘。逾時後，指令會結束，先前儲存的登入不變。若拒絕授權或流程中斷，先前的登入也不會變更。

<Note>
  瀏覽器會導回 `http://127.0.0.1` 上的監聽連接埠。命令列工具只會在指令執行期間監聽該連接埠。指令結束後，本機就不再監聽任何連接埠。若透過 SSH 連線至遠端電腦，瀏覽器無法存取該連接埠，請改用 API 權杖在遠端電腦登入。
</Note>

## 使用 API 權杖登入

在 **身分與存取 → API 權杖** 中建立權杖，再透過標準輸入傳給命令列工具：

```bash
printf '%s' "$MOLESIGNAL_TOKEN" | molesignal login --url https://molesignal.example.com --with-token
```

權杖可執行的操作取決於其所屬使用者或服務帳號的權限。

## 直接使用權杖，不儲存

透過環境變數提供位址和權杖，例如在建置機上使用。這種方式不會儲存任何內容：

```bash
MOLESIGNAL_URL=https://molesignal.example.com MOLESIGNAL_TOKEN=<token> molesignal status
```

`--url` 和 `--token` 可對單一指令發揮相同作用。針對某個位址儲存的權杖不會傳送至其他位址。

## 儲存多組登入資訊

每組登入資訊都儲存在一個設定檔中，包含一個位址及存取該位址所需的憑證。使用多個設定檔時，命令列工具可以同時登入多個 MoleSignal 執行個體，或同一執行個體中的多個組織。使用 `--profile` 指定要將登入資訊儲存在哪個設定檔：

```bash
molesignal login --url https://staging.molesignal.example.com --profile staging
```

最近一次登入所用的設定檔會成為目前的設定檔。指令會使用目前的設定檔；若要讓單一指令使用其他設定檔，請使用 `--profile` 或 `MOLESIGNAL_PROFILE` 指定。首次登入時若未指定 `--profile`，命令列工具會將登入資訊儲存在名為 `default` 的設定檔中。

| 指令 | 用途 |
|---|---|
| `molesignal profiles` | 列出設定檔、登入方式和位址。`*` 標示目前的設定檔。 |
| `molesignal use <profile>` | 將指定的設定檔設為目前的設定檔。 |
| `molesignal logout --profile <profile>` | 刪除指定設定檔中的登入資訊，但保留其位址。 |
| `molesignal profiles remove <profile>` | 刪除指定的設定檔。 |

## 登入資訊的儲存位置

命令列工具會將設定檔儲存在 `~/.config/molesignal/config.json`，只有檔案擁有者可以讀取。若已設定 `XDG_CONFIG_HOME`，則儲存在該目錄下；在 Windows 上則儲存在 `%APPDATA%` 下。可使用 `MOLESIGNAL_CONFIG` 指定其他檔案。

## 透過 Proxy 存取

使用 `HTTPS_PROXY`（或 `HTTP_PROXY`），讓命令列工具的每個要求都透過 Proxy 傳送。使用 `NO_PROXY` 列出不需透過 Proxy 即可直接存取的主機：

```bash
HTTPS_PROXY=http://proxy.example.com:3128 NO_PROXY=localhost molesignal status
```

若 MoleSignal 的憑證由私有憑證授權單位簽發，請將 `NODE_EXTRA_CA_CERTS` 設為該單位的憑證檔案路徑。

## 檢查登入狀態與設定

`molesignal status` 會顯示位址、設定檔、回應的伺服器、MCP 協定版本、登入方式和 MCP 工具數量：

```bash
molesignal status
```

`molesignal whoami` 會顯示使用者、組織、角色，以及 MoleSignal 授予的權限：

```bash
molesignal whoami
```

`molesignal doctor` 會逐項檢查命令列工具運作所需的條件，並說明如何處理未通過的項目：Node.js、設定檔權限、位址、Proxy、網路與 TLS、系統時鐘、登入狀態及 MCP 端點。若有任何項目未通過，指令會以結束代碼 `1` 結束：

```bash
molesignal doctor
```

## 登出

`molesignal logout` 會刪除本機目前設定檔中儲存的登入資訊：

```bash
molesignal logout
```

MoleSignal 中的授權在撤銷前仍然有效。若要撤銷授權，請前往 **Mole Agent → 設定 → Inbound MCP**。
