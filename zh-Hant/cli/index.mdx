MoleSignal 的命令列使用 `molesignal` 指令，並以 `@molesignal/cli` 的名稱發佈至 npm。登入 MoleSignal 執行個體後，可以：

- 檢視並即時追蹤日誌、執行 SQL 與 PromQL、將追蹤資料繪製成瀑布圖，以及彙整 APM 服務；
- 列出事件與值班人員、確認並解決事件、執行合成監控測試，以及執行已核准的變更；
- 在 CI 中回報發佈、上傳 RUM 的 Source Map 與符號，以及將指令碼的輸出傳送至資料串流；
- 呼叫 MoleSignal 工具目錄中的任何工具；
- 透過 stdio 提供 MoleSignal 的 MCP 工具，讓 Claude Code、Cursor、Codex、VS Code、Gemini CLI 將命令列啟動為 MCP 伺服器。

讀取與變更都透過 MoleSignal 工具執行，因此登入使用者的權限、組織的 Tool Policy 與核准流程同樣適用於命令列，與 Mole Agent 一致。回報發佈、上傳偵錯產物及傳送日誌會呼叫 MoleSignal API，因此需要 API Token。

## 先決條件

- Node.js 20 或更新版本。
- 可從本機存取的 MoleSignal 執行個體，以及該執行個體中的帳號。

## 安裝

```bash
npm install -g @molesignal/cli
```

確認安裝：

```bash
molesignal --version
```

也可以不經安裝，直接執行各個指令：

```bash
npx -y @molesignal/cli --help
```

## 快速入門

<Steps>
  <Step title="登入">
    ```bash
    molesignal login --url https://molesignal.example.com
    ```

    瀏覽器會開啟 MoleSignal 的授權頁面。按一下頁面上的 **授權**。請參閱[登入](/zh-Hant/cli/sign-in)。
  </Step>
  <Step title="檢查設定">
    ```bash
    molesignal doctor
    ```
  </Step>
  <Step title="檢視日誌">
    ```bash
    molesignal logs app_logs -f
    ```

    請參閱[檢視與即時追蹤日誌](/zh-Hant/cli/logs)。
  </Step>
</Steps>

## 指令

| 群組 | 指令 |
|---|---|
| 登入 | `login`、`logout`、`profiles`、`use`、`status`、`whoami`、`doctor`。請參閱[登入](/zh-Hant/cli/sign-in)。 |
| 日誌與查詢 | `streams`、`logs`、`query`、`fields`。請參閱[檢視與即時追蹤日誌](/zh-Hant/cli/logs)。 |
| 指標、追蹤與服務 | `metrics`、`traces`、`services`、`search-jobs`。請參閱[指標、追蹤與服務](/zh-Hant/cli/observe)。 |
| 值班與變更 | `incidents`、`oncall`、`approvals`、`annotate`、`synthetics`。請參閱[事件與變更](/zh-Hant/cli/changes)。 |
| 發佈與資料 | `deploy`、`source-maps`、`symbols`、`send`、`run`。請參閱[CI 與發佈](/zh-Hant/cli/ci)。 |
| 工具與設定 | `tools`、`call`、`mcp`、`open`、`completion`。請參閱[呼叫任何工具](/zh-Hant/cli/tools)與[透過 stdio 提供 MCP](/zh-Hant/cli/mcp)。 |

`molesignal <命令> --help` 會顯示指定指令及其選項的說明。[指令參考](/zh-Hant/cli/reference)也列出所有選項。
