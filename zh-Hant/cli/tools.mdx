命令列指令涵蓋常用工作。MoleSignal 工具目錄中的其他工具（例如 RUM、效能剖析或狀態頁面的工具）都可以用 `molesignal call` 執行。

## 尋找工具

```bash
molesignal tools incident
```

清單會顯示與搜尋詞最相關的工具、呼叫類型（`read` 讀取或 `change` 變更）、組織的工具政策如何處理變更，以及工具的用途。未指定搜尋詞時，指令會列出使用者可呼叫的所有工具。`--domain` 只會保留單一領域的工具，例如 `observability` 或 `alerts_on_call`。

`molesignal tools show` 會輸出單一工具及其接受的參數（JSON Schema）：

```bash
molesignal tools show list_rum_sessions
```

## 呼叫工具

```bash
molesignal call list_rum_sessions --since 1h limit=20
```

指令會以 JSON 格式輸出工具傳回的內容。參數的寫法如下：

| 寫法 | 傳入 |
|---|---|
| `名稱=值` | 依工具結構描述要求的型別傳入文字、數字、`true` 或 `false`，或如 `a,b` 的清單。 |
| `名稱:=JSON` | 原樣傳入 JSON，例如 `match:='{"service":"checkout"}'`。 |
| `父.子=值` | 傳入物件中的欄位，例如 `timeRange.startTime=…`。 |
| `--input <文件>` | 從檔案讀取包含參數的 JSON 物件，`-` 表示標準輸入。後續參數會加入該物件。 |
| `--since`、`--from`、`--to` | 為接受 `timeRange` 的工具設定時間範圍。 |

會修改內容的工具依工具政策執行，請參閱[如何執行變更](/zh-Hant/cli/changes#如何執行變更)。`--reason`、`--wait`、`--timeout` 和 `--yes` 都適用。參數中的 `reason` 或 `impact` 會原樣送交核准。

```bash
molesignal call trigger_alert_rule rule_id=<规则> --reason "测试呼叫"
```

## 開啟頁面

`molesignal open` 會在瀏覽器中開啟指定的 MoleSignal 頁面。未指定頁面時，會開啟首頁：

```bash
molesignal open logs app_logs
```

可開啟的頁面包括 `home`、`logs`、`metrics`、`traces`、`services`、`incidents`、`oncall`、`synthetics`、`dashboards`、`approvals`、`jobs`、`streams` 和 `agent`。多數頁面都可指定 ID，例如追蹤、事件或儀表板的 ID。`--print` 只會輸出網址。

`logs`、`query`、`traces show`、`incidents show` 和 `services show` 都接受 `--web`，可在瀏覽器中開啟原本要輸出的內容。

## 在 Shell 中自動補齊指令

`molesignal completion` 會輸出一段指令碼，用於自動補齊指令、子指令、設定檔和資料串流名稱。資料串流名稱每隔幾分鐘擷取一次。bash：

```bash
echo 'source <(molesignal completion bash)' >> ~/.bashrc
```

zsh：

```bash
echo 'source <(molesignal completion zsh)' >> ~/.zshrc
```

fish：

```bash
molesignal completion fish > ~/.config/fish/completions/molesignal.fish
```
