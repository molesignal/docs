MoleSignal 每次分享一個儀表板或一份報表。分享連結絕不會變成使用者權杖：公開連結只會開啟短暫的受限分享工作階段，其他分享方式仍會檢查存取者的權限。

## 分享儀表板或報表

在儀表板、儀表板清單或報表中點選 **分享**。在 **分享資源** 對話框中，先選擇 **存取範圍**：

| 範圍 | 存取者 | 規則 |
|---|---|---|
| **目前工作區的成員** | 已登入的成員。 | 成員仍須具備在工作區中存取該資源的權限。 |
| **指定組織的成員** | **目標組織** 中已登入的成員。 | 這個選項會明確授予跨組織存取權，只有能管理跨組織授權的成員可以建立這類授權。 |
| **任何取得連結的人** | 任何取得連結的人，無須帳號。 | 連結是可撤銷的受限憑證，工作區原則可以禁止使用這類連結。 |

接著設定限制條件，並點選 **建立分享連結**：

| 設定 | 適用於 | 效果 |
|---|---|---|
| **有效期限** | 所有範圍 | **1 天**、**7 天**、**30 天** 或永不過期，不得超過工作區為公開連結設定的上限。連結到期後立即失效。 |
| **最多存取次數** | 公開連結 | 每建立一個新的分享工作階段就計一次，留空表示不限制。 |
| **存取密碼** | 公開連結 | 通過密碼驗證後才會開啟受限工作階段。密碼開頭和結尾的空格不計入驗證。公開儀表板必須設定密碼，工作區原則也可以要求為公開報表設定密碼。 |
| **允許下載** | 公開報表 | 關閉後，報表只能在線上預覽。工作區原則可以禁止公開下載 CSV。 |
| **資料時間範圍上限** | 公開儀表板 | 1、6 或 24 小時。開啟 **允許調整時間範圍** 後，存取者可以在該範圍內選擇預設的時間範圍。 |
| **可公開的變數** | 公開儀表板 | 系統會從公開模型及其請求中移除未選取的變數。開啟 **允許修改允許清單中的變數** 後，存取者可以修改選取的變數。 |

點選 **複製連結** 以複製連結。對話框會儲存連結，之後可以再次複製。

## 公開存取者會看到什麼

公開儀表板只會透過受限代理伺服器執行面板中已儲存的查詢：存取者看不到查詢運算式或探索頁面，瀏覽器也不能自行傳送 SQL 或 PromQL。公開報表是建立連結時產生的固定快照，開啟時不會執行即時查詢。頁面會顯示 **公開存取** 浮水印和有效期限。

已過期、已停用或用完存取次數的連結會顯示 **連結無法使用**。單次存取最多持續 30 分鐘，之後重新整理頁面也會顯示 **連結無法使用**，並提示重新開啟分享連結。如果連結仍有效，重新開啟即可繼續查看。受密碼保護的連結需要再次輸入密碼，並會計為一次新的存取。

<Warning>
  公開連結是 Bearer 憑證：任何取得連結的人都能看到分享的內容。即使設定了有效期限或密碼，也不要分享敏感資料。
</Warning>

### 存取密碼的限制

輸入錯誤的存取密碼與輸入錯誤的帳號密碼一樣，都會依[登入速率限制](/zh-Hant/settings/platform#登入速率限制)計次，每個連結視為一個帳號。下列失敗次數、鎖定時間和驗證間隔為預設值，管理員可以修改。

| 失敗次數 | 結果 |
|---|---|
| 同一位址、同一連結 5 次 | 該位址在 15 分鐘內無法開啟該連結，其他位址和其他連結不受影響。 |
| 同一位址 30 次，合計連結存取和登入的失敗次數 | 該位址在 15 分鐘內無法開啟受密碼保護的連結，也無法使用密碼登入。 |
| 同一連結、所有位址合計 20 次 | 系統不會鎖定連結，但每 60 秒只驗證一次密碼。若某個位址在過去 30 天內曾開啟這個連結，從該位址存取時不受速率限制。 |

系統以 `429` 和 `Retry-After` 回應遭拒的請求，不驗證密碼。因此，即使密碼正確，也必須等候。頁面會顯示等候時間。通過密碼驗證後，系統會清除該位址在該連結上的失敗次數。

系統預設不將私有 IP 位址納入位址統計。因此，若部署在代理伺服器後方且未設定 IP 識別，只有 20 次的限制會生效。請參閱[用戶端 IP 識別](/zh-Hant/settings/platform#用戶端-ip-識別)。

系統不會鎖定連結，仍可按照限制後的速率繼續猜測密碼。請設定較長的密碼和較短的有效期限。

## 管理現有分享

對話框中的 **現有分享** 會列出該資源的連結、存取次數和有效期限。

| 操作 | 效果 |
|---|---|
| **複製連結** | 再次複製連結。 |
| **輪替** | 舊連結可能外洩時，以新連結取代，舊連結會立即失效。 |
| **停用** | 立即停用連結。 |

在啟用連結儲存功能前建立的分享不會顯示連結，輪替一次後才會顯示。

## 工作區原則

管理員可在[設定 → 一般 → 分享與公開存取](/zh-Hant/settings/organization#分享與公開存取)中設定成員可以公開分享的內容：是否允許公開連結、是否允許公開即時儀表板、公開連結的最長有效期限、公開報表是否必須設定密碼、是否禁止公開分享帶有 `production` 或 `prod` 標籤的資源，以及是否允許公開下載 CSV。原則禁止使用特定存取範圍時，對話框會說明原因並提供前往設定的連結。此時請改用工作區內分享或跨組織分享。

## 稽核與權限

系統會將分享的建立、開啟、輪替和停用操作記錄在[稽核記錄](/zh-Hant/settings/data-security#稽核)中。輸入錯誤的存取密碼時，系統會記錄 `resource_share.password_failure`；達到失敗次數上限時，則記錄 `resource_share.lockout`。系統會依[用戶端 IP 識別](/zh-Hant/settings/platform#用戶端-ip-識別)取得存取者的位址。若部署在代理伺服器後方且未設定 IP 識別，系統會記錄代理伺服器的位址。分享資源必須具備該資源的分享權限，例如 `dashboards.share` 或 `reports.share`。MoleSignal 在建立分享前還會再次檢查資源的存取權限。
