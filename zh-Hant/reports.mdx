開啟 **報告**，即可管理報告排程、產生記錄與可重複使用的範本。

| 分頁 | 內容 |
|---|---|
| **報告排程** | 每份報告的來源、排程、下次執行時間、最近結果、收件方和狀態。頁面頂端會統計執行中的報告、未來 24 小時的傳送、近 30 天的成功率和待處理的失敗項目。 |
| **產生記錄** | 每次產生的報告及其傳送記錄。**檢視錯誤**會說明失敗原因。 |
| **範本庫** | 內建範本與自訂範本。選取**使用範本**，即可從範本建立報告。 |

## 新增報告

點選 **新增報告**。設定介面分為三個步驟，右側預覽會隨設定同步顯示報告結構。

<Steps>
  <Step title="內容與範圍">
    填寫 **報告名稱** 和 **用途說明**。選擇 **來源類型**（儀表板或已儲存的檢視）和 **資料來源**。設定 **資料範圍**：過去 1 小時、24 小時、7 天或 30 天，前一天、上一週或上一個月，或選擇 **自訂**。
  </Step>
  <Step title="產生排程">
    選擇 **產生頻率**：每小時、每 6、12 或 24 小時，或每 7 天，並選擇 **報告時區**。**進階 Cron** 可填入 Cron 運算式，但目前仍會每 24 小時執行一次，建議優先使用間隔設定。
  </Step>
  <Step title="傳送設定">
    新增 **傳送目標**：電子郵件地址、HTTPS Webhook URL 或 S3 路徑。系統會個別記錄各目標的傳送結果。選擇 **產生格式**。關閉 **儲存後啟用**，系統會以暫停狀態儲存報告。
  </Step>
</Steps>

點選 **儲存並啟用**。選取 **立即匯出**，無須等待排程即可產生一份報告。報告可執行的操作包括 **檢視**、**編輯**、**分享**、**啟用** 或 **暫停**，以及 **刪除排程**。

## 選擇內容

報告以儀表板或已儲存的檢視為資料來源。範本定義可重複使用的資料來源類型、格式和內容預設值；排程則將範本繫結至特定資源。

內建範本類型包括平台健康狀態、RUM 體驗、警示回顧、SLA 合規性和已儲存查詢匯出。

## 選擇格式

| 格式 | 常見用途 |
|---|---|
| PDF | 透過無頭瀏覽器轉譯儀表板或已儲存的檢視。 |
| PNG | 以無頭瀏覽器轉譯圖片，供協作工具使用。 |
| CSV | 目前以表格形式匯出的靜態報告中繼資料。 |
| JSON | 目前供自動化使用的靜態報告中繼資料。 |
| SVG | 目前的靜態報告摘要卡片。 |

PDF 和 PNG 需使用無頭瀏覽器轉譯器。請在 `[scheduled_reports.renderer]` 中設定可存取的 Web 基礎 URL。伺服器會驗證產生檔案的簽章，不會傳回預留內容。CSV、JSON 與 SVG 目前包含報告中繼資料，不會執行儀表板或已儲存的檢視，也不會匯出其結果列。

## PDF 或 PNG 報告包含的內容

PDF 或 PNG 報告只包含儀表板或已儲存的檢視本身，不包含網頁介面的其他部分：沒有導覽、工具列和選單。頁面先說明報告涵蓋的範圍，接著顯示儀表板或已儲存的檢視的結果列。

- **頁面尺寸。** 頁面寬度與轉譯器的檢視區域等寬，高度與內容等高，因此 PDF 只有一頁，面板和表格列都不會因分頁而截斷。內容高度超過 16,000 像素時，PNG 會截斷超出的內容，PDF 則會延續到下一頁。
- **外觀。** 報告使用淺色主題。語言、日期和時間格式會遵循轉譯報告時所用使用者帳號的偏好設定。
- **時間範圍。** 報告涵蓋**資料範圍**。**過去 24 小時**與**過去 7 天**以轉譯當下為終點。**前一天**、**上一週**和**上一個月**依報告時區計算完整的日、週、月；一週從週一開始。
- **時區。** 頁首、圖表座標軸和 `_timestamp` 欄會依**報告時區**顯示時間。這個欄位列出所有 IANA 時區及其 UTC 時差，可依名稱搜尋。
- **失敗。** 如果無法載入儀表板或已儲存的檢視、無法執行已儲存的檢視的查詢陳述式，或頁面未在 15 秒內載入資料，系統就不會產生檔案。**立即匯出**會傳回失敗原因；排程執行時，系統會將原因寫入每個收件方的傳送記錄。

### 儀表板

頁面開頭顯示儀表板的標題與說明，接著顯示時間範圍、時區、各個可見變數的值和產生時間，最後依儀表板的版面配置排列各個面板。選擇**自訂**資料範圍時，面板會使用最近 1 小時的資料。

### 已儲存的檢視

頁面開頭顯示已儲存的檢視的名稱，接著顯示時間範圍、時區、資料串流（若檢視已指定）、列數和產生時間。最後顯示標明查詢語言的陳述式，以及由查詢結果列組成的表格。

- **時間範圍。** 選擇**自訂**資料範圍時，系統會在已儲存的檢視的**預設時間範圍**內執行陳述式，以轉譯當下為終點。
- **列數。** 表格最多包含 200 列。SQL 陳述式傳回更多列時，列數會顯示為**僅前 200 列**。系統會以範圍查詢執行 PromQL 陳述式，並均勻取樣各序列的資料點，總數不超過 200 列。
- **欄。** 結果的每個欄位對應表格的一欄。表格不會超出頁面寬度，過長的值會自動換行。除了 `_timestamp`，其他值都會原樣顯示。缺少的值會顯示為 `—`。
- **資料串流。** 系統會使用已儲存的檢視所指定的**資料串流**執行 SQL 陳述式。如果檢視未指定資料串流，系統會使用第一個允許查詢的日誌資料串流，與**已儲存的檢視**頁面上的**開啟**操作一致。如果工作區沒有這類資料串流，就無法產生報告。
- **空白結果。** 陳述式未傳回任何列時，系統仍會產生報告，並註明該時間範圍內沒有資料。

## 排程與傳送

設定資料範圍、`every:<n><s|m|h|d>` 間隔、輸出格式，以及一或多個收件方。API 欄位雖然名為 `cron`，但目前不會剖析五欄式 cron 運算式；若無法辨識欄位值，系統會改用 24 小時間隔。收件方的 kind 包括：

- `webhook`：將產生的位元組以 POST 傳送至 HTTP(S) URL；
- `s3`：在 MoleSignal 已設定的物件儲存中寫入 `reports/<组织 ID>/<路径>/<报告 ID>-<时间>.<扩展名>`，其中 `<路径>` 是目標中 `s3://` 之後的部分；
- `email`：目前只驗證並記錄電子郵件地址，尚未透過 SMTP 寄送。

每個收件方都有獨立的傳送記錄，其中包含狀態、嘗試次數和錯誤詳細資訊。暫停排程不需刪除設定。

<Warning>
  目前請勿依賴 `email` 收件方完成傳送。排程報告整合 SMTP 前，請使用 Webhook 或已設定的物件儲存金鑰前置詞。
</Warning>

### 排程報告使用的存取權限

依排程傳送 PDF 或 PNG 時，系統會以最後一次儲存報告的登入使用者身分轉譯報告頁面。報告會顯示該使用者在執行時可讀取的內容。

- **查看使用者的位置。** 在**報告**頁面開啟一份報告，對話方塊底部會顯示**執行身分**及該使用者的名稱。沒有 `reports.schedule` 權限的使用者可透過**檢視**開啟報告，並在同一列看到這些資訊。
- **儲存。** 每次儲存都會將執行身分設為儲存報告的使用者，即使只啟用或暫停排程也一樣。具備 `reports.schedule` 權限的使用者只要儲存報告，即可接管執行身分。如果報告目前以其他使用者的身分執行，對話方塊會在**儲存變更**旁說明，儲存後將改用儲存者的權限擷取資料。**報告排程**清單中的切換開關也會顯示相同說明。
- **API。** 排程報告透過 `runAsUserId` 傳回該使用者的 ID，並透過 `runAsUser` 傳回該使用者的顯示名稱和電子郵件地址。如果報告沒有執行身分，或該使用者的帳號已不存在，`runAsUser` 就會是 `null`。
- **每次執行時的檢查。** 如果該使用者無法再登入組織，排程就會執行失敗。可能原因包括帳號停用或刪除、成員資格遭移除，或組織停用。如果該使用者無法再讀取儀表板（`dashboards.read`）或已儲存的檢視（`saved_views.read`），或無法再查詢已儲存的檢視報告所用的資料串流（`streams.query`），排程也會執行失敗。每個收件方的傳送記錄都會記載該使用者和失敗原因。
- **API Token。** 使用 API Token 儲存的報告沒有可用的使用者身分，因為 Token 只帶有角色的存取權限，不帶有簽發該 Token 的使用者的存取權限。在登入使用者儲存報告前，這類報告的 PDF 和 PNG 傳送會失敗。傳送 CSV、JSON 與 SVG 不需轉譯頁面，因此不需要使用者身分。
- **工作階段。** 無頭瀏覽器使用的工作階段有效期為 10 分鐘。頁面列印完成後，系統會立即從瀏覽器移除該工作階段。

**立即匯出**和**分享**會以提出要求的使用者身分轉譯報告。

## 匯出與分享

使用**立即匯出**從已儲存的報告產生可下載的檔案。使用**分享**將報告分享給登入使用者、跨工作區分享，或建立受限制的公開分享。公開報告可要求輸入密碼，也可依工作區原則禁止下載 CSV。

## 權限

- `reports.read` 用於檢視排程、範本與記錄。
- `reports.create` 用於建立報告。
- `reports.edit` 用於更新內容與傳送設定。
- `reports.schedule` 用於啟用、暫停或立即執行排程。
- `reports.delete` 用於刪除報告。
