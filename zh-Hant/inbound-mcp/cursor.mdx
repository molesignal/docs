Cursor 支援 stdio MCP 伺服器，以及採用 OAuth 驗證的遠端 Streamable HTTP MCP 伺服器。

## 透過 stdio 連線（建議）

用戶端會啟動 MoleSignal 命令列工具，由工具將訊息轉送給 MoleSignal。需要 Node.js 20 或更新版本。

<Steps>
  <Step title="登入一次">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

瀏覽器會開啟 MoleSignal，同意授權即可。命令列工具會保留登入狀態並自動續期。

  </Step>
  <Step title="新增 MoleSignal">

在專案的 `.cursor/mcp.json`，或適用於所有專案的 `~/.cursor/mcp.json` 中加入：

```json
{
  "mcpServers": {
    "molesignal": {
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

接著在 **Tools & MCP** 中啟用 `molesignal`。

  </Step>
</Steps>

沒有瀏覽器時，無須登入，改在伺服器上設定環境變數 `MOLESIGNAL_URL` 與 `MOLESIGNAL_TOKEN`（API 權杖）。請參閱[透過 stdio 連線](/zh-Hant/inbound-mcp#透過-stdio-連線)。

以下各節不使用命令列工具，改透過 Streamable HTTP 連線。

## 設定伺服器

目前的專案使用 `.cursor/mcp.json`，全域設定則使用 `~/.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "molesignal": {
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="開啟 Tools & MCP">
    開啟 **Cursor Settings → Tools & MCP**，找到 `molesignal`。
  </Step>
  <Step title="使用 OAuth 連線">
    選擇 **Connect**，在瀏覽器中完成 MoleSignal 授權。Cursor 會透過 MCP Protected Resource Metadata 自動探索 OAuth 端點。
  </Step>
  <Step title="驗證工具">
    確認可用的工具包含 `tool_search`、`call_read_tool` 與 `call_managed_tool`。修改設定後，在 **Tools & MCP** 中重新啟動伺服器。
  </Step>
</Steps>

<Warning>
  請勿將 Bearer 權杖提交至 `.cursor/mcp.json`。Cursor 的互動式工作階段應優先使用 OAuth；非互動式憑證應使用用戶端支援的密碼（Secret）注入機制。
</Warning>

請參閱 [Cursor MCP 官方文件](https://cursor.com/docs/mcp)。
