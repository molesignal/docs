Claude Code 支援 stdio 伺服器、具備 OAuth 自動探索功能的遠端 Streamable HTTP 伺服器，以及 local、project、user 三種設定範圍。

## 透過 stdio 連線（建議）

用戶端會啟動 MoleSignal 命令列工具，再由工具將訊息轉送給 MoleSignal。需要 Node.js 20 或更新版本。

<Steps>
  <Step title="登入一次">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

瀏覽器會開啟 MoleSignal，只要同意授權即可。命令列工具會儲存登入狀態並自動續期。

  </Step>
  <Step title="新增 MoleSignal">

```bash
claude mcp add --scope user molesignal -- npx -y @molesignal/cli mcp
claude mcp get molesignal
```

  </Step>
</Steps>

沒有瀏覽器時，不必登入，改在伺服器上設定 `MOLESIGNAL_URL` 和 `MOLESIGNAL_TOKEN`（API 權杖）環境變數。請參閱[透過 stdio 連線](/zh-Hant/inbound-mcp#透過-stdio-連線)。

以下各節不使用命令列工具，而是透過 Streamable HTTP 連線。

## 使用 OAuth 2.1

<Steps>
  <Step title="新增遠端伺服器">

    ```bash
    claude mcp add --transport http --scope user \
      molesignal https://molesignal.example.com/api/v1/mcp
    ```

    `--scope user` 讓所有專案都能使用此伺服器。省略此參數時，會將設定儲存為目前專案的本機設定；`--scope project` 則會將設定寫入可共用的 `.mcp.json`。

  </Step>
  <Step title="授權 MoleSignal">

    ```bash
    claude mcp login molesignal
    ```

    也可以開啟 Claude Code，執行 `/mcp`，選取 `molesignal` 並完成驗證。

  </Step>
  <Step title="驗證伺服器">

    ```bash
    claude mcp get molesignal
    claude mcp list
    ```

  </Step>
</Steps>

透過 SSH 或在沒有瀏覽器的終端機中操作時，可以輸出授權 URL，並在完成授權後將完整的回呼 URL 貼回 Claude Code：

```bash
claude mcp login molesignal --no-browser
```

## 使用 API 權杖

在專案的 `.mcp.json` 中使用環境變數展開語法，不要提交權杖：

```json
{
  "mcpServers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer ${MOLESIGNAL_MCP_TOKEN}"
      }
    }
  }
}
```

啟動 Claude Code 前，請先設定 `MOLESIGNAL_MCP_TOKEN`。首次連線至專案範圍內的伺服器前，必須明確確認信任該伺服器。

請參閱 [Claude Code MCP 官方文件](https://code.claude.com/docs/en/mcp)。
