VS Code 支援 stdio 與遠端 HTTP MCP 伺服器、OAuth 授權、資源、提示詞與工具。

## 透過 stdio 連線（建議）

用戶端會啟動 MoleSignal 命令列工具，由工具將訊息轉送給 MoleSignal。需要 Node.js 20 或更新版本。

<Steps>
  <Step title="登入一次">

```bash
npx -y @molesignal/cli login --url https://molesignal.example.com
```

瀏覽器會開啟 MoleSignal。同意授權即可；命令列工具會保留登入狀態並自動續期。

  </Step>
  <Step title="新增 MoleSignal">

在 `.vscode/mcp.json` 中：

```json
{
  "servers": {
    "molesignal": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@molesignal/cli", "mcp"]
    }
  }
}
```

從這個檔案或 MCP 檢視啟動伺服器，並確認信任伺服器。

  </Step>
</Steps>

沒有瀏覽器時，不必登入，改在伺服器的環境變數中設定 `MOLESIGNAL_URL` 與 `MOLESIGNAL_TOKEN`（API 權杖）。請參閱[透過 stdio 連線](/zh-Hant/inbound-mcp#透過-stdio-連線)。

以下各節不使用命令列工具，而是透過 Streamable HTTP 連線。

## 設定伺服器

共用工作區設定使用 `.vscode/mcp.json`。如要編輯私人全域設定，可從命令選擇區執行 **MCP: Open User Configuration**。

```json
{
  "servers": {
    "molesignal": {
      "type": "http",
      "url": "https://molesignal.example.com/api/v1/mcp"
    }
  }
}
```

<Steps>
  <Step title="啟動伺服器">
    開啟 `mcp.json` 並選取檔案中的 **Start**，或執行 **MCP: List Servers** 後選取 `molesignal`。
  </Step>
  <Step title="確認信任">
    檢查端點並確認信任 MCP 伺服器。工作區設定會與共同作業者共用，請勿在檔案中儲存認證資訊。
  </Step>
  <Step title="完成 OAuth 授權">
    VS Code 會透過 MoleSignal 的 OAuth 探索機制，在瀏覽器中開啟授權頁面。完成授權後，回到聊天的代理程式模式。
  </Step>
  <Step title="驗證連線">
    執行 **MCP: List Servers**，檢查 `molesignal` 的狀態，並在聊天檢視中確認工具可用。
  </Step>
</Steps>

透過 **Add Context → MCP Resources** 新增 MoleSignal 資源；可使用 `/molesignal.<prompt>` 呼叫已發佈的提示詞。

請參閱 [VS Code MCP 官方文件](https://code.visualstudio.com/docs/agent-customization/mcp-servers)。
