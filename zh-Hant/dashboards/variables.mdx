變數會將在格狀版面上方選取的值代入各面板的查詢、標題和連結。這樣只需一個儀表板，就能涵蓋所有服務、主機或環境，不必逐一複製。

## 新增變數

開啟編輯器，點選 **設定 → 變數**，然後新增變數：

| 欄位 | 規則 |
|---|---|
| **名稱** | 在查詢中使用的名稱，例如 `service`。只能使用字母、數字和 `_`，並以字母或 `_` 開頭，否則無法替換。 |
| **標籤** | 顯示在選擇器上方的文字。 |
| **類型** | 值的來源。請參閱[類型](#類型)。 |
| **查詢 / 選項** | 依類型指定查詢或值。 |
| **多選** | 可同時選取多個值。 |
| **包含全部選項** | 新增 **All**，代表清單中的所有值。 |
| **隱藏方式** | **無** 顯示選擇器，**標籤** 隱藏選擇器的標籤，**變數** 隱藏選擇器。 |
| **重新整理** | 設定查詢變數何時重新讀取值：**從不**、**載入時**，或每次 **時間範圍** 變更時。 |

儲存儀表板後，變數才會保留。

## 類型

| 類型 | 值 |
|---|---|
| **查詢** | 從資料中讀取。請參閱[查詢變數](#查詢變數)。 |
| **自訂** | 以逗號分隔的固定清單，例如 `prod, staging, dev`。 |
| **文字** | 檢視者在格狀版面上方的輸入欄位中輸入的內容。 |
| **常數** | 儲存在儀表板模型中的固定值，不會顯示在格狀版面上方。 |
| **間隔**、**資料來源** | 儲存在儀表板模型中的清單，例如隨 JSON 一起匯入的清單。 |

### 查詢變數

查詢變數會在目前的時間範圍內讀取值。選取 **查詢類型**：

| 查詢類型 | 欄位 | 值 |
|---|---|---|
| **標籤值** | **指標** 和 **標籤**，例如 `http_requests_total` 和 `service`。 | 取得該指標各序列的標籤值，涵蓋所有包含該指標的指標資料流。 |
| **經典查詢** | 運算式，例如 `label_values(http_requests_total, service)`。 | 與 **標籤值** 相同。 |
| **SQL** | **資料流名稱**、**資料流類型** 和 SQL 陳述式。 | 第一欄的值。 |

第一個值是預設值。查詢中可以使用其他變數，例如在 SQL 中寫入 `WHERE environment = '$env'`；選取特定環境後，服務清單就只會列出該環境的服務。

## 使用變數

在查詢、面板標題、文字元素或連結中寫入 `$name` 或 `${name}`。名稱後方緊接字母時，請使用大括號，例如 `${service}_errors`。多選變數預設以逗號串接多個值；加上格式即可變更串接方式：

| 寫法 | `checkout` 和 `payment` 的結果 |
|---|---|
| `${service}` | `checkout,payment` |
| `${service:csv}` | `checkout,payment` |
| `${service:pipe}` | `checkout\|payment` |
| `${service:regex}` | `checkout\|payment`，依規則運算式的規則對每個值進行逸出處理。 |
| `${service:sqlstring}` | `'checkout','payment'`，依 SQL 規則加上引號，例如用於 `IN (${service:sqlstring})`。 |
| `${service:json}` | `["checkout","payment"]` |

例如，使用 PromQL `sum(rate(http_requests_total{service=~"${service:regex}"}[5m]))` 的面板會隨選取的服務更新。

## 網址中的值

儀表板網址會以 `var-<name>=<value>` 的格式保留選取的值。多選變數的每個值各使用一個參數。複製網址，或使用這些參數組成連結，即可用相同的值開啟儀表板。[資料連結](/zh-Hant/dashboards/edit#資料連結)也能傳遞變數。

## 依變數重複面板

在該面板的 **面板** 分頁中選取 **重複變數**。儀表板會為每個選取的值產生一份面板副本，並將該值代入副本中的變數。選取 **重複方向**（**橫向**、**垂直** 或 **格狀**）和 **每列上限**。儀表板只會儲存原始面板，副本會隨選取的值更新。
