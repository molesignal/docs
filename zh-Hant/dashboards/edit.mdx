在 **儀表板** 中點選 **新增儀表板**，或在儀表板上點選 **編輯**，即可開啟編輯器。建立儀表板需要 `dashboards.create`，修改需要 `dashboards.edit`。**允許編輯** 關閉的儀表板（例如內建儀表板）不能修改，請改為建立副本。

## 編輯器

| 控制項 | 用法 |
|---|---|
| **返回儀表板** | 離開編輯器。 |
| 儀表板標題 | 直接修改儀表板名稱。 |
| **撤銷** / **重做** | 在開啟編輯器以來的修改中復原或重做。 |
| **新增** | 新增 **面板**、**文字**、**列**、**分組** 或 **分頁**。 |
| **設定** | 開啟[儀表板設定](#儀表板設定)。 |
| **儲存** | 儲存儀表板。儲存之前不會寫入任何修改。 |

按住元素的拖曳控點可以移動元素，拖曳元素的角落可以調整尺寸。選取元素後，可以在側邊面板中修改它的位置和結構。新儀表板使用 24 欄的格狀版面，可以在[設定 → 一般](#儀表板設定)中修改。

## 元素

| 元素 | 用途 |
|---|---|
| **面板** | 由視覺化繪製的一或多個查詢。 |
| **文字** | 靜態的 Markdown 或純文字，用於說明、標題和連結。 |
| **列** | 佔滿整列的標題，包含它下方的元素。列可以設為 **預設收合**。 |
| **分組** | 把相關元素放在一起的框。 |
| **分頁** | 多個分頁，每個分頁有自己的元素。可以選擇預設開啟的分頁。 |

## 編輯面板

在面板功能表中點選 **編輯**，或新增一個面板。面板編輯器會用目前時間範圍和變數顯示面板的 **即時預覽**，並提供兩組分頁：

| 分頁 | 內容 |
|---|---|
| **查詢**、**轉換**、**資料連結** | 面板讀取什麼資料、結果如何重組、點選後跳轉到哪裡。 |
| **面板**、**欄位**、**覆寫項目** | 面板的外觀、數值的顯示方式，以及對部分欄位的例外設定。 |

### 查詢

為面板的每個查詢點選 **新增查詢**。每個查詢都有 **查詢編號**（例如 `A`）、**資料來源**、**查詢語言**（**PromQL** 或 **SQL**）和 **運算式**。資料來源決定預設的查詢語言和其他欄位：

| 資料來源 | 預設查詢語言 | 其他欄位 |
|---|---|---|
| **指標** | PromQL | |
| **日誌**、**追蹤**、**SQL** | SQL | **資料流名稱** 和 **資料流類型**（**日誌**、**指標** 或 **追蹤**）。 |
| **效能剖析** | SQL | **服務** 和 **剖析類型**，例如 `cpu`。 |

**圖例** 用範本為序列命名，例如 `{{service}}`。**共用查詢** 重複使用另一個面板的查詢，寫成 `<panel-id>:<ref-id>`，這樣資料只會讀取一次。查詢中可以使用 `$service` 這樣的[變數](/zh-Hant/dashboards/variables)。SQL 與 PromQL 參見[查詢](/zh-Hant/query)。

`format` 為 `time_series` 的 SQL 查詢（例如 [RUM 探索頁](/zh-Hant/rum/explorer#加入儀表板)加入的面板）可以依長格式傳回，每個時間、每個分組一列：時間序列圖會為文字欄的每組值繪製一條序列，並以這些值命名。

### 轉換

轉換會在繪製之前重組結果。轉換會依序執行，每個轉換都可以個別停用。

| 轉換 | 效果 |
|---|---|
| **篩選欄位**、**整理欄位**、**重新命名欄位** | 保留、排序、隱藏或重新命名欄位。 |
| **計算欄位** | 新增一個由其他欄位計算得出的欄位。 |
| **彙總** | 將每個序列縮減為最新值、平均值、最大值或總和等。 |
| **分組**、**排序**、**限制數量** | 依欄位彙總、排序，並保留前若干列。 |
| **連線**、**合併** | 合併多個查詢的結果。 |
| **將標籤轉為欄位**、**將資料列轉為欄位**、**將時間序列轉為表格** | 將標籤、列或序列轉為欄。 |

### 面板選項

**面板** 分頁設定 **標題**、滑鼠停留時顯示的 **說明**、**寬度** 和 **高度**、**視覺化** 及其選項，以及是否使用 **透明背景**。

| 視覺化 | 繪製內容 |
|---|---|
| **時間序列圖** | 隨時間變化的折線、柱或點，可設定圖例、滑鼠停留提示、填滿和堆疊。 |
| **長條圖** | 依類別比較數值。 |
| **條形量表** | 以橫向或垂直條形顯示縮減後的值。 |
| **統計值** | 一個值（例如最新值），可附帶迷你走勢圖。 |
| **儀表** | 在環形刻度上顯示一個值，並依閾值著色。 |
| **表格** | 分頁顯示的列。 |
| **日誌** | 帶時間和層級的精簡日誌清單。 |
| **熱圖** | 數值隨時間的強度分布。 |
| **狀態時間軸** | 狀態隨時間的變化。 |
| **文字** | Markdown。 |

**重複變數** 會為變數的每個值繪製一份面板副本，**重複方向** 可選 **橫向**、**垂直** 或 **格狀**，每列最多 **每列上限** 個副本。參見[依變數重複面板](/zh-Hant/dashboards/variables#依變數重複面板)。

### 欄位選項

**欄位** 分頁設定數值的顯示方式：

| 選項 | 用法 |
|---|---|
| **單位**、**小數位數** | 單位（例如位元組、百分比或秒）和小數位數。 |
| **最小值**、**最大值** | 刻度的兩端。 |
| **顯示名稱** | 取代欄位的名稱。 |
| **配色方案** | 固定顏色、調色盤、閾值顏色或連續色階。 |
| **閾值** | 顏色變化的數值點，模式為 **絕對值** 或 **百分比**，從 **基準線** 開始。 |
| **值對應** | 為某個值、某個區間、正規表示式符合或空值等特殊值顯示文字、顏色或圖示。 |
| **空值文字** | 沒有數值時面板顯示的內容。 |

**覆寫項目** 只對部分欄位套用其他欄位選項。點選 **新增覆寫項目**，選擇符合方式（**欄位名稱**、**欄位正規表示式**、**欄位類型** 或 **查詢編號**），再為每個要修改的選項點選 **新增屬性**。

### 資料連結

資料連結讓點選數值時跳轉到其他地方。點選 **新增資料連結**，填寫 **標題** 並選擇目標：**日誌**、**指標**、**追蹤**、**效能剖析**、另一個 **儀表板**，或 **外部連結**。可以選擇連結是否帶上時間範圍和儀表板變數，以及是否在新分頁開啟。連結會顯示在面板功能表中。

## 儀表板設定

**設定** 有四個分頁。

| 分頁 | 內容 |
|---|---|
| **一般** | **標題**、**說明** 和 **標籤**。預設時間範圍（**開始**、**結束**）和 **時區**。**格狀**：1 到 48 的 **欄**、**列高** 和 **間距**。**重新整理**：**關閉**、帶 **預設間隔** 的 **重新整理間隔**，或 **自動**。**圖表滑鼠停留提示**：關閉，或在面板之間使用共用十字準線。**允許編輯**。 |
| **變數** | 儀表板的變數。參見[變數](/zh-Hant/dashboards/variables)。 |
| **註記** | 繪製在時間序列圖面板上的事件。 |
| **連結** | 顯示在儀表板頁首的連結。 |

註記包含 **名稱**、**來源**、**顯示**（**折線**、**區域** 或 **標記**）、**顏色** 和 **啟用**。在 **事件** 中用 **新增事件** 列出其事件：**標籤**、**開始時間戳記（毫秒）**，以及區域使用的 **結束時間戳記（毫秒）**。

來源為 **部署** 的註記不列出事件：它會在每個時間序列圖面板上標出[變更清單](/zh-Hant/api/changes)裡的變更，包括發布和其他回報的變更，以及 APM 首次看到的版本，範圍是 **服務** 中填寫的服務（以逗號分隔），留空則為所有服務。透過 [`POST /api/v1/changes`](/zh-Hant/api/changes#維護註解) 儲存在這個儀表板上、或不屬於任何儀表板的註記，也會繪製在它的時間序列圖面板上。

連結包含 **標題**、**類型**（**儀表板** 或 **外部連結**）、**URL**，以及是否帶上 **時間範圍** 和 **變數**、是否 **在新分頁開啟** 的開關。

## 儲存與重複使用

點選 **儲存**。要重複使用某個面板，在其功能表中點選 **複製** 複製面板 JSON，再貼上到另一個儀表板。要重複使用整個儀表板，用 **匯出 JSON** 匯出後在其他地方匯入。參見[匯入儀表板](/zh-Hant/dashboards#匯入儀表板)。
