在 **儀表板** 中點選 **新增儀表板**，或在儀表板上點選 **編輯**，即可開啟編輯器。建立儀表板需要 `dashboards.create` 權限，修改則需要 `dashboards.edit` 權限。若儀表板已關閉 **允許編輯**（例如內建儀表板），請建立副本再修改。

## 編輯器

| 控制項 | 用法 |
|---|---|
| **返回儀表板** | 離開編輯器。 |
| 儀表板標題 | 直接修改儀表板名稱。 |
| **撤銷** / **重做** | 撤銷或重做開啟編輯器後的修改。 |
| **新增** | 新增 **面板**、**文字**、**列**、**分組** 或 **分頁**。 |
| **設定** | 開啟[儀表板設定](#儀表板設定)。 |
| **儲存** | 儲存儀表板。儲存前不會寫入任何修改。 |

拖曳元素的拖曳控點即可移動元素，拖曳元素的角落即可調整尺寸。選取元素後，即可在側邊面板中修改位置和結構。新儀表板使用 24 欄格線，可在[設定 → 一般](#儀表板設定)中修改。

## 元素

| 元素 | 用途 |
|---|---|
| **面板** | 以視覺化方式呈現一或多個查詢的結果。 |
| **文字** | 靜態的 Markdown 或純文字，用於說明、標題和連結。 |
| **列** | 佔滿整列的標題，包含下方的元素。列可設為 **預設收合**。 |
| **分組** | 將相關元素放在一起的框。 |
| **分頁** | 包含多個分頁，每個分頁各有自己的元素。可選擇預設開啟的分頁。 |

## 編輯面板

在面板選單中點選 **編輯**，或新增面板。面板編輯器會根據目前的時間範圍和變數顯示面板的 **即時預覽**，並提供兩組分頁：

| 分頁 | 內容 |
|---|---|
| **查詢**、**轉換**、**資料連結** | 面板讀取的資料、重組結果的方式，以及點選後前往的位置。 |
| **面板**、**欄位**、**覆寫項目** | 面板的外觀、數值的顯示方式，以及部分欄位的例外設定。 |

### 查詢

每新增一個面板查詢，就點選一次 **新增查詢**。每個查詢都有 **查詢編號**（例如 `A`）、**資料來源**、**查詢語言**（**PromQL** 或 **SQL**）和 **運算式**。資料來源決定預設的查詢語言和其他欄位：

| 資料來源 | 預設查詢語言 | 其他欄位 |
|---|---|---|
| **指標** | PromQL | |
| **日誌**、**追蹤**、**SQL** | SQL | **資料流名稱** 和 **資料流類型**（**日誌**、**指標** 或 **追蹤**）。 |
| **效能剖析** | SQL | **服務** 和 **剖析類型**，例如 `cpu`。 |

**圖例** 使用範本為序列命名，例如 `{{service}}`。**共用查詢** 可重複使用另一個面板的查詢，寫法為 `<panel-id>:<ref-id>`，讓資料只需讀取一次。查詢中可以使用 `$service` 這類[變數](/zh-Hant/dashboards/variables)。如需 SQL 與 PromQL 的詳細資訊，請參閱[查詢](/zh-Hant/query)。

`format` 為 `time_series` 的 SQL 查詢（例如從 [RUM 探索頁](/zh-Hant/rum/explorer#加入儀表板)新增的面板所用的查詢）可以長格式傳回結果，每個時間點的每個分組各佔一列：時間序列圖會為文字欄中每一組值繪製一條序列，並以這些值命名。

### 轉換

轉換會在繪圖前重組結果。轉換會依序執行，每項轉換皆可個別停用。

| 轉換 | 效果 |
|---|---|
| **篩選欄位**、**整理欄位**、**重新命名欄位** | 保留、排序、隱藏或重新命名欄位。 |
| **計算欄位** | 新增一個根據其他欄位計算得出的欄位。 |
| **彙總** | 將每個序列縮減為單一值，例如最新值、平均值、最大值或總和。 |
| **分組**、**排序**、**限制數量** | 依欄位彙總、排序，並保留前幾列。 |
| **連線**、**合併** | 合併多個查詢的結果。 |
| **將標籤轉為欄位**、**將資料列轉為欄位**、**將時間序列轉為表格** | 將標籤、資料列或序列轉為欄。 |

### 面板選項

在 **面板** 分頁中設定 **標題**、滑鼠停留時顯示的 **說明**、**寬度** 和 **高度**、**視覺化** 及其選項，以及是否使用 **透明背景**。

| 視覺化 | 繪製內容 |
|---|---|
| **時間序列圖** | 隨時間變化的折線、長條或點，可設定圖例、滑鼠停留提示、填滿和堆疊。 |
| **長條圖** | 依類別比較數值。 |
| **條形量表** | 以橫向或垂直長條顯示縮減後的值。 |
| **統計值** | 單一值（例如最新值），可附上迷你趨勢圖。 |
| **儀表** | 在環形刻度上顯示單一值，並依閾值著色。 |
| **表格** | 分頁顯示資料列。 |
| **日誌** | 附有時間和層級的精簡日誌清單。 |
| **熱圖** | 數值強度隨時間的分布。 |
| **狀態時間軸** | 狀態隨時間的變化。 |
| **文字** | Markdown。 |

**重複變數** 會為變數的每個值繪製一份面板副本。**重複方向** 可選擇 **橫向**、**垂直** 或 **格狀**，每列的副本數量由 **每列上限** 決定。請參閱[依變數重複面板](/zh-Hant/dashboards/variables#依變數重複面板)。

### 欄位選項

在 **欄位** 分頁中設定數值的顯示方式：

| 選項 | 用法 |
|---|---|
| **單位**、**小數位數** | 單位（例如位元組、百分比或秒）和小數位數。 |
| **最小值**、**最大值** | 刻度的兩端。 |
| **顯示名稱** | 取代欄位名稱。 |
| **配色方案** | 固定顏色、調色盤、閾值顏色或連續色階。 |
| **閾值** | 顏色變化的數值點。模式可選 **絕對值** 或 **百分比**，從 **基準線** 開始。 |
| **值對應** | 為特定值、區間、符合正規表示式的值或空值等顯示文字、顏色或圖示。 |
| **空值文字** | 沒有數值時面板顯示的內容。 |

**覆寫項目** 只對部分欄位套用不同的欄位選項。點選 **新增覆寫項目**，選擇比對方式（**欄位名稱**、**欄位正規表示式**、**欄位類型** 或 **查詢編號**），再針對每個要修改的選項點選 **新增屬性**。

### 資料連結

資料連結可在點選數值時前往其他位置。點選 **新增資料連結**，填寫 **標題**，再選擇目標：**日誌**、**指標**、**追蹤**、**效能剖析**、另一個 **儀表板**，或 **外部連結**。可選擇連結是否帶入時間範圍和儀表板變數，以及是否在新分頁開啟。連結會顯示在面板選單中。

## 儀表板設定

**設定** 有四個分頁。

| 分頁 | 內容 |
|---|---|
| **一般** | **標題**、**說明** 和 **標籤**。預設時間範圍（**開始**、**結束**）和 **時區**。格線：1 到 48 的 **欄** 數、**列高** 和 **間距**。**重新整理**：**關閉**、使用 **預設間隔** 的 **重新整理間隔**，或 **自動**。**圖表滑鼠停留提示**：關閉，或在面板間共用十字準線。**允許編輯**。 |
| **變數** | 儀表板的變數。請參閱[變數](/zh-Hant/dashboards/variables)。 |
| **註記** | 繪製在時間序列圖面板上的事件。 |
| **連結** | 顯示在儀表板頁首的連結。 |

註記包含 **名稱**、**來源**、**顯示**（**折線**、**區域** 或 **標記**）、**顏色** 和 **啟用**。在 **事件** 中點選 **新增事件**，填寫 **標籤**、**開始時間戳記（毫秒）**，以及區域所需的 **結束時間戳記（毫秒）**。

連結包含 **標題**、**類型**（**儀表板** 或 **外部連結**）、**URL**，以及控制是否帶入 **時間範圍** 和 **變數**、是否 **在新分頁開啟** 的開關。

## 儲存與重複使用

點選 **儲存**。若要重複使用面板，請在面板選單中點選 **複製** 以複製面板 JSON，再貼到另一個儀表板。若要重複使用整個儀表板，請使用 **匯出 JSON**，再到其他位置匯入。請參閱[匯入儀表板](/zh-Hant/dashboards#匯入儀表板)。
