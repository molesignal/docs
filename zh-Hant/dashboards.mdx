儀表板是一組供團隊共同檢視的面板。每個面板都會對工作區的資料流執行各自的查詢，並繪製結果。格狀版面上方的變數可讓所有面板一次切換到另一個服務、主機或環境。

本頁說明如何尋找和使用儀表板。若要建立或修改儀表板，請參閱[編輯儀表板](/zh-Hant/dashboards/edit)和[變數](/zh-Hant/dashboards/variables)。

## 儀表板清單

開啟 **儀表板**。頁面頂端會顯示儀表板和資料夾的數量。可用下列方式縮小清單範圍：

- 使用篩選欄位，依名稱比對；
- 選擇 **全部**、**我的**、**已收藏** 和 **標籤** 範圍；
- 選擇特定資料夾，或選擇 **全部** 資料夾；
- 選擇 **格狀** 或 **清單** 版面配置。

頁面頂端也提供 **新增儀表板**、**匯入 JSON** 和 **資料夾管理**。點選儀表板的星號即可加入 **已收藏**。每個儀表板末端的選單提供下列操作：

| 操作 | 效果 |
|---|---|
| **開啟**、**編輯**、**分享** | 開啟儀表板、編輯器或分享對話框。 |
| **移至資料夾** | 將儀表板移至另一個資料夾。 |
| **建立副本** | 建立名為 `<标题> copy` 的可編輯副本。 |
| **匯出 JSON** | 下載儀表板模型，可使用 **匯入 JSON** 匯入。 |
| **設為 NOC 大螢幕** | 在目前瀏覽器的 [NOC 大螢幕](#noc-大螢幕)上顯示此儀表板。 |
| **刪除** | 刪除儀表板及其面板。這項操作無法復原。 |

## 資料夾

資料夾最多可分三層，用來分類儀表板。點選 **資料夾管理**，再點選 **新增資料夾**，即可在最上層建立資料夾；或點選 **新增子目錄**，在選取的資料夾下建立子資料夾。

未歸入任何資料夾的儀表板位於 **預設資料夾**。預設資料夾無法重新命名或刪除，也不能包含子資料夾。若要刪除其他資料夾，請先移出其中所有的儀表板和子資料夾。

## 檢視儀表板

儀表板頁首會顯示所在的資料夾、面板數量和最近修改時間，並提供下列控制項：

| 控制項 | 用法 |
|---|---|
| 時間選擇器 | 設定所有面板的時間範圍。時間會依個人預設時區顯示；在選擇器底部點選 **變更** 即可切換時區。 |
| **重新整理所有面板** | 重新執行每個面板的查詢。使用旁邊的選單設定自動重新整理：選擇 **關閉**、**自動** 或指定間隔。**自動** 會依時間範圍和面板寬度調整間隔。 |
| 變數 | 選擇[變數](/zh-Hant/dashboards/variables)的值。網址列會以 `var-<name>=<value>` 儲存變數值，透過複製的連結可開啟相同的檢視畫面。 |
| **分享** | 開啟[分享對話框](/zh-Hant/resource-sharing)。 |
| **編輯** | 開啟[編輯器](/zh-Hant/dashboards/edit)。唯讀儀表板會改為提供 **建立副本**。 |
| 更多操作 | **查看儀表板詳細資料**（ID、UID、負責人和 Schema）、**NOC 大螢幕**、**建立副本** 和 **匯出 JSON**。 |

將滑鼠游標移到面板上，即可查看面板說明。面板選單提供下列操作：

| 操作 | 效果 |
|---|---|
| **檢視** | 單獨放大顯示該面板。 |
| **編輯** | 在編輯器中開啟該面板。 |
| **探索資料** | 在對應的探索頁面中開啟面板的查詢，代入變數值，並保留相同的時間範圍。 |
| **檢查查詢** | 以 JSON 顯示面板的查詢定義。 |
| **分享** | 複製該面板的連結。 |
| **匯出資料** | 將面板資料下載為 CSV。 |
| **匯出圖片** | 下載面板的圖片。 |
| **複製** | 複製面板的 JSON，以便貼到其他儀表板。 |
| 資料連結 | 開啟面板的[資料連結](/zh-Hant/dashboards/edit#資料連結)。 |
| **建立警示** | 使用面板的查詢建立一條[警示規則](/zh-Hant/alerting/rules)。 |
| **Mole Agent 分析** | 讓 [Mole Agent](/zh-Hant/agent) 分析面板顯示的內容。 |

## 匯入儀表板

點選 **匯入 JSON**，貼上 MoleSignal 儀表板的 JSON 或上傳 `.json` 檔案，選擇資料夾後點選 **匯入**。請使用 **匯出 JSON** 下載的內容，或 `GET /api/v1/dashboards/{id}` 傳回的 `model`。其中的 `engine` 必須是 `molesignal-dashboard`。

MoleSignal 不支援匯入 Grafana 儀表板的 JSON。請在編輯器中重建這類儀表板。PromQL 運算式可原樣貼到指標面板中。若要將儀表板保留在 Grafana，可透過 [Grafana 資料來源](/zh-Hant/query/grafana)讀取 MoleSignal 的資料。

## 讓 Mole Agent 產生儀表板

請 [Mole Agent](/zh-Hant/agent) 起草儀表板，例如「為 checkout 服務做一個儀表板」。Mole Agent 只會產生草稿並提供 **AI 儀表板草稿** 的連結，不會實際建立儀表板：

1. 檢視 **唯讀預覽**。預覽由正式的儀表板轉譯器繪製。
2. 檢查 **查詢預檢**：每個面板的查詢都已執行一次，結果為 **已通過**、**結果為空** 或 **已略過**。同時檢視 **產生警告** 和 **需要修正的問題**。
3. 點選 **提交建立建議**。如果建立原則要求審核，草稿會等待審核通過；否則點選 **確認並建立**。

草稿會與對應的模型繫結，並在一段時間後到期。若要修改，請再次向 Mole Agent 提出要求。

## 內建 RUM 儀表板

含有 RUM 應用程式的工作區會提供唯讀儀表板，並加上 `内置` 和 `rum` 標籤。每類應用程式各有一張：

| 儀表板 | 適用對象 | 內容 |
|---|---|---|
| `RUM · 浏览器应用` | 瀏覽器應用程式 | 工作階段、無錯誤工作階段和受挫工作階段；LCP、INP、CLS 的第 75 百分位數及各自的趨勢；依來源分類的錯誤；頁面、版本、受挫元素和回應緩慢的資源主機；國家和瀏覽器。 |
| `RUM · 移动应用` | Android、iOS、Flutter 與 React Native 應用程式 | 工作階段、無當機工作階段、無錯誤工作階段和受挫工作階段；無當機工作階段趨勢、錯誤與當機趨勢；畫面、版本、依版本分類的當機、受挫元素和回應緩慢的資源主機；裝置和作業系統。 |

伺服器會在建立該類別的第一個應用程式時安裝對應的儀表板。若工作區已有這類應用程式，伺服器會在啟動時安裝。如果升級變更了儀表板，伺服器也會在啟動時寫入新版本。變數包括 **應用程式**、**環境**（單一環境或 **全部**）和 **間隔**（時間圖中長條的寬度）。在 [RUM 總覽](/zh-Hant/rum#總覽)點選 **在儀表板中開啟**，會開啟這張儀表板，並自動選取頁面目前的應用程式和環境。

每個面板都使用一段簡短的 SQL。檢視和工作階段資料分別取自 `rum_views_latest` 和 `rum_sessions_latest`，這兩者只保留每筆檢視或工作階段的[最新版本](/zh-Hant/query#rum-資料列的目前版本)。百分位數只納入含有該數值的檢視，因此數字與總覽一致。這些儀表板無法直接編輯。在儀表板頁首或儀表板清單中選擇 **建立副本**，即可取得可編輯的儀表板。

## NOC 大螢幕

點選頂端列的 **NOC 大螢幕**，即可開啟適合在牆面螢幕上顯示的全螢幕深色檢視。按 `Esc` 或點選 **返回主控台** 即可離開。

狀態列會摘要顯示工作區的狀況：進行中的事件及其層級、即時資料狀態、服務數量、請求速率和 P95 延遲。面板顯示下列內容：

| 面板 | 顯示內容 |
|---|---|
| **事件** | 正在觸發的事件。 |
| **拓撲** | 最近一小時的服務拓撲。 |
| **健康狀態** | 每個服務的請求速率、P95 延遲和錯誤率。 |
| **流量** | 最近 60 分鐘內最繁忙的服務。 |

使用 **設定版面配置** 調整大螢幕：套用預設版面（**平台維運**、**SRE** 或 **高階主管檢視**）、顯示或隱藏面板、切換面板寬度、向前或向後移動面板，或選擇 **重設**。版面配置會儲存在瀏覽器中。

將儀表板設為 NOC 大螢幕後，大螢幕會改為顯示該儀表板的標題、各個面板及其查詢。大螢幕不會將這些面板繪製成圖表。若要檢視圖表，請直接開啟儀表板。

## 報告與分享

可依據儀表板建立排程[報告](/zh-Hant/reports)，並以 PDF、PNG、CSV、SVG 或 JSON 格式傳送。**分享** 支援登入後存取、跨工作區存取和受限的公開存取。公開的儀表板只會執行面板已儲存的查詢，並遵循工作區的[分享原則](/zh-Hant/settings/organization#分享與公開存取)。

## 權限

| 權限 | 允許的操作 |
|---|---|
| `dashboards.read` | 開啟儀表板和資料夾。 |
| `dashboards.create` | 建立、匯入和複製儀表板。 |
| `dashboards.edit` | 修改儀表板和資料夾。 |
| `dashboards.delete` | 刪除儀表板。 |
| `dashboards.share` | 建立和輪替分享連結。 |
