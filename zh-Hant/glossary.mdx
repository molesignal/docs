| 術語 | 定義 |
|---|---|
| **Alert** | 評估警示規則、觸發升級、轉譯排程報表並執行連接器的角色，請參閱[依角色部署](/zh-Hant/deployment/role-based)。 |
| **API Token** | 格式為 `mspat-<36>` 的 Bearer 憑證，用於以使用者或服務帳號的身分執行操作，請參閱[身分與存取](/zh-Hant/identity)。 |
| **APM** | 應用程式效能監控。從追蹤 Span 衍生的服務、交易、相依性、錯誤與版本彙總，具有範圍限制，請參閱[應用程式效能監控](/zh-Hant/apm)。 |
| **Arrow Flight SQL** | 透過通訊埠 `5083` 提供給 DBeaver、JDBC、ADBC 等資料庫用戶端使用的 SQL 協定，預設停用，請參閱[使用資料庫用戶端連線](/zh-Hant/query/database-clients)。 |
| **目錄（Catalog）** | PostgreSQL 中記錄各個 Parquet 檔案和索引分別屬於哪個資料串流的資訊。 |
| **加密金鑰（Cipher key）** | `MS_CIPHER_KEY` 中的根金鑰，用於加密 MoleSignal 儲存在 PostgreSQL 中的資料，請參閱[正式環境檢查清單](/zh-Hant/deployment/production-checklist)。 |
| **合併（Compaction）** | 將小型 Parquet 檔案合併成大型檔案。`compactor` 角色會一併執行合併與保留策略。 |
| **連接器（Connector）** | 與外部平台的受管理整合。來源負責匯入日誌，由 MoleSignal 定期擷取或由平台推送；目的地接收管線的輸出，請參閱[連接器](/zh-Hant/connectors)。 |
| **資料來源（Datasource）** | 資料來源目錄中的項目，為特定來源產生端點、權杖與設定片段，請參閱[資料來源](/zh-Hant/intake)。 |
| **升級策略（Escalation policy）** | 依序排列且設有確認逾時的通知對象，請參閱[警示](/zh-Hant/alerting)。 |
| **擴充表（Extend table）** | 將鍵對應至記錄的查閱表。管線可讀取此表以補充事件資訊，也可將資料列寫入此表，請參閱[擴充表](/zh-Hant/extend-tables)。 |
| **聯邦查詢（Federated query）** | 同時掃描遠端叢集的查詢，使用 `?clusters=local,<name>` 選取叢集，請參閱[依角色部署](/zh-Hant/deployment/role-based)。 |
| **排清（Flush）** | 將 intake 節點的記憶體緩衝區內容寫入物件儲存，形成 Parquet 檔案和索引。 |
| **函式（Function）** | 使用 VRL 或 JavaScript 撰寫的可重複使用轉換，請參閱[函式](/zh-Hant/functions)。 |
| **事件（Incident）** | 經過確認與復原的一次警示，請參閱[警示](/zh-Hant/alerting)。 |
| **接收（Intake）** | 接收遙測資料的路徑，也是負責驗證、緩衝與排清的角色，請參閱[資料來源](/zh-Hant/intake)。 |
| **接收權杖** | 遵循 **資料寫入** 權限策略（`logs.write`、`metrics.write`、`traces.write`、`profiles.write` 和 `apm.deploy`）的權杖，供傳送端和發佈管線使用，請參閱[資料來源](/zh-Hant/intake#資料接收-token)。 |
| **日誌巡檢（Log inspection）** | Mole Agent 針對特定時段的日誌產生的報告，可按需或定期執行巡檢，請參閱[日誌巡檢](/zh-Hant/logs/inspections)。 |
| **Mole Agent** | 透過工具目錄調查問題的內建維運代理程式，請參閱 [Mole Agent](/zh-Hant/agent)。 |
| **值班排程（On-call schedule）** | 包含時區的輪值與臨時代班安排，可供升級策略指定為通知對象，請參閱[警示](/zh-Hant/alerting)。 |
| **組織（Organization）** | 租用戶與原則的界線，在網頁介面中稱為工作區，請參閱[核心概念](/zh-Hant/concepts)。 |
| **Parquet** | MoleSignal 用於儲存日誌、指標與追蹤的欄式檔案格式。 |
| **管線（Pipeline）** | 對事件進行路由、標準化、遮蔽敏感資料與補充資訊的一組步驟。可在接收資料期間即時執行、依排程執行，或在建立事件前修改警示事件，請參閱[管線](/zh-Hant/pipelines)。 |
| **平台管理員** | 由 `[auth].root_email` 指定、負責平台層級設定的使用者。 |
| **平台資料串流（Platform stream）** | 僅由 MoleSignal 寫入的資料串流，例如 `_audit` 或 `_synthetic_results`，請參閱[資料串流](/zh-Hant/streams#平台資料串流)。 |
| **Probe Agent** | 從特定位置執行合成監控的程序。`standalone` 節點會執行內建的代理程式，請參閱[合成監控](/zh-Hant/synthetics)。 |
| **角色（Role）** | 由 `[node].roles` 選取的程序角色：`standalone`、`router`、`intake`、`querier`、`compactor` 或 `alert`；在 IAM 中也指具名的權限集合。 |
| **RUM** | 真實使用者監控，涵蓋瀏覽器與行動應用程式的工作階段，請參閱 [RUM](/zh-Hant/rum)。 |
| **RUM Client Token** | 具備 `rum.write` 權限、繫結至單一應用程式，並由瀏覽器端與行動端程式碼傳送的權杖。 |
| **已儲存的檢視（Saved view）** | 連同時間範圍與選項一起儲存的查詢。 |
| **搜尋工作（Search job）** | 持久化的非同步查詢。規模超過門檻的查詢會轉為搜尋工作，並列在 **資料串流 → 搜尋工作** 中，請參閱[查詢](/zh-Hant/query)。 |
| **自身遙測（Self-telemetry）** | MoleSignal 在保留的 `_molesignal` 資料串流中記錄的自身指標、追蹤與效能剖析資料，請參閱[自身可觀測性](/zh-Hant/self-observability)。 |
| **服務帳號（Service account）** | 供收集器和自動化程序使用的非人員身分，無法登入，請參閱[身分與存取](/zh-Hant/identity)。 |
| **靜默（Silence）** | 在限定時間內暫停符合條件的警示通知的規則，請參閱[警示](/zh-Hant/alerting)。 |
| **Standalone** | 在單一程序內執行所有角色的預設角色。 |
| **狀態頁面（Status page）** | 顯示元件狀態與事件的公開或私人頁面，請參閱[狀態頁面](/zh-Hant/status-pages)。 |
| **資料串流（Stream）** | 定義訊號類型的契約，包含名稱、類型、結構描述與保留期限，請參閱[資料串流](/zh-Hant/streams)。 |
| **資料串流類型（Stream type）** | `logs`、`metrics`、`traces`、`profiles` 或 `extend` 其中之一。 |
| **合成監控（Synthetic monitor）** | 定期執行的檢查（例如 HTTP 請求），會記錄可用性與延遲，請參閱[合成監控](/zh-Hant/synthetics)。 |
| **VRL** | Vector Remap Language，管線函式可使用的語言之一。 |
| **WAL** | 預寫日誌：物件儲存中的物件，用於在排清前保存已確認的記錄。 |
| **工作區（Workspace）** | 網頁介面中對所選組織的稱呼。 |
