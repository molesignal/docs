已儲存的檢視是在工作區內共用且有名稱的 SQL 或 PromQL 查詢。按一下即可再次開啟，無須重寫查詢；也可用於[報告](/zh-Hant/reports)，並可在命令面板中搜尋。在[命令面板](/zh-Hant/console#使用命令面板搜尋)中選取 **前往 Saved views**，即可開啟 **已儲存的檢視**。

## 檢視清單

頁面頂端顯示已儲存的檢視總數和已置頂的數量。每個檢視都會顯示 **語言**、**資料串流**、**標籤**、預設 **時段** 和更新時間。已置頂的檢視會顯示圖釘圖示。

| 操作 | 效果 |
|---|---|
| **開啟** | 在對應的探索頁面中，依照檢視的時段（截至目前時間）開啟查詢。 |
| **置頂** / **取消置頂** | 將檢視標記為團隊最常用的檢視，或取消標記。 |
| **編輯** | 修改檢視。 |
| **刪除** | 刪除檢視，無法復原。 |

**開啟** 會在[日誌](/zh-Hant/logs)中以 SQL 模式對檢視的資料串流執行 SQL 查詢，並在[指標](/zh-Hant/metrics)中執行 PromQL 查詢。

## 新增儲存的檢視

按一下 **新增儲存的檢視**：

| 欄位 | 規則 |
|---|---|
| **名稱** | 顯示在清單和命令面板中的名稱。 |
| **語言** | **SQL** 或 **PromQL**。 |
| **預設時間範圍** | **開啟** 時使用的時段：15 分鐘、1 小時、6 小時、24 小時或 7 天。 |
| **查詢陳述式** | 查詢本身。 |
| **資料流（選填）** | SQL 檢視查詢的資料串流，可減少需要讀取的檔案數量。 |
| **標籤** | 用逗號分隔標籤，方便日後搜尋。 |
| **置頂** | 將此檢視置頂。 |

按一下 **建立**。撰寫在不同時段仍適用的查詢：由時段決定時間範圍，並依 `service.name`、`deployment.environment` 等穩定的欄位篩選。

## 在其他地方使用

- [報告](/zh-Hant/reports#已儲存的檢視)可依排程將已儲存的檢視呈現為結果表格。
- 在命令面板中，可依名稱搜尋已儲存的檢視。
- [資料串流](/zh-Hant/streams#資料串流詳細資料)的 **使用位置** 分頁會列出繫結至該資料串流的已儲存檢視。

## 權限

| 權限 | 允許 |
|---|---|
| `saved_views.read` | 列出並開啟已儲存的檢視。 |
| `saved_views.create` | 建立已儲存的檢視。 |
| `saved_views.edit` | 修改及置頂已儲存的檢視。 |
| `saved_views.delete` | 刪除已儲存的檢視。 |

執行檢視還需要 `streams.query`。請參閱[已儲存的檢視 API](/zh-Hant/api/query/list-saved-views)。
