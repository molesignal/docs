函式可封裝可重複使用的事件轉換。開啟 **函式**，即可獨立於管線建立、測試及維護轉換邏輯。

## 尋找函式

清單包含組織自行建立的函式和內建預設。使用清單頂端的三個檢視可縮小範圍，每個檢視都會顯示項目數量：

| 檢視 | 內容 |
|---|---|
| **全部** | 組織的所有函式和內建預設。 |
| **自行建立** | 組織自行撰寫的函式。 |
| **內建預設** | MoleSignal 隨附的唯讀函式。 |

搜尋會比對函式名稱和預設的說明。點選組織自行建立的函式，即可在工作台中開啟。

## 語言

| 語言 | 可用條件 | 適用情境 |
|---|---|---|
| VRL | 內建 | 剖析、正規化、篩選、遮蔽敏感資訊與資料擴充。 |
| JavaScript | 內建 | 較適合以 JavaScript 表達的處理邏輯。 |
| LLM | 透過 API 設定；需要 `llm_eval_enabled` 與模型服務供應商 | 使用模型輸出進行低吞吐量的分類或資料擴充。 |

VRL 與 JavaScript 都在 MoleSignal 的二進位檔內執行，不需要設定項目，也不需要額外安裝。

儲存函式時，MoleSignal 會驗證並編譯原始碼。無效的程式碼不會成為生效版本。

函式工作台提供 VRL 與 JavaScript。LLM 函式屬於進階 API 工作流程：函式原始碼是系統指令，事件是模型的輸入，`params_schema.output_field` 決定輸出欄位（預設為 `_llm_eval`）。每次執行都會呼叫模型一次，因此設定項目 `[functions].llm_eval_enabled` 預設維持為 `false`，請參閱[設定](/zh-Hant/configuration#功能與整合)。若要讓模型撰寫告警事件摘要，請使用[告警管線](/zh-Hant/pipelines/alert-events#ai-摘要)的 **AI 摘要** 步驟。此步驟不受這項設定影響。

## 內建預設

每個組織都能看到下列唯讀 VRL 函式：

| 函式 | 用途 |
|---|---|
| `add-intake-time` | 新增接收時間戳記，用於診斷端對端延遲。 |
| `normalize-logs` | 剖析 JSON 格式的 message，新增環境與叢集欄位，並將 `level` 統一轉為小寫。 |
| `parse-key-value` | 將 logfmt 或 `key=value` 格式的 message 剖析為欄位，再合併回事件。 |
| `redact-email` | 將 `message` 中的電子郵件地址替換為預留文字。 |
| `route-by-service` | 將服務名稱正規化，並依服務產生目標資料串流（`logs_<service>`）作為路由提示。 |

預設所在的列會顯示 **內建** 標記與說明。說明會以目前登入使用者的介面語言顯示。點選該列即可查看原始碼。

無法編輯預設。若要修改，請在該列或預設面板中選取 **以此為起點**。工作台會開啟名為 `<预设名>-copy` 的新函式，並帶入預設的語言和原始碼。儲存後，組織就有自己的函式，原有的預設不會變更。

## 撰寫與測試函式

工作台分為三個部分：

- 函式的名稱和語言；
- **原始碼**，也就是編輯器，標題旁會顯示原始碼的驗證狀態；
- **試跑**，包含 JSON 格式的 **範例輸入** 和 **範例輸出**。

選取 **執行範例**，即可用編輯器中的原始碼轉換範例事件，不必先儲存。轉換後的事件會顯示在 **範例輸出** 下方；若執行失敗，同一位置會顯示失敗原因。

**儲存函式** 和 **取消** 位於頁面的標題列；已儲存的函式還有 **刪除函式**。名稱或原始碼為空白時，無法選取 **儲存函式**。將游標停在按鈕上，即可查看缺少的內容。在編輯器中按 `⌘ Enter` 或 `Ctrl+Enter` 可執行範例，按 `⌘S` 或 `Ctrl+S` 可儲存。

執行工具會呼叫 `POST /api/v1/functions/run`，傳入語言、原始碼和範例事件，並傳回轉換後的事件：

```bash
curl -X POST http://localhost:5080/api/v1/functions/run \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"language":"vrl","source":".service = downcase!(string!(.service))","input":{"service":"Checkout"}}'
```

```json
{ "output": { "service": "checkout" } }
```

VRL 範例：

```vrl
.service = downcase!(string!(.service))
.severity = upcase(string(.level) ?? "INFO")
if exists(.customer_id) {
  .customer = lookup("customers", .customer_id)
}
```

## 查詢擴充表與 IP 位址

有兩個 VRL 函式可讀取 MoleSignal 儲存的資料。執行範例時，以及管線（包括告警管線）中的每個 VRL 步驟，都可以使用這兩個函式。

| 函式 | 傳回值 |
|---|---|
| `lookup("<表名>", key)` | [擴充表](/zh-Hant/extend-tables) `<表名>` 中索引鍵為 `key` 的資料列，格式為物件；找不到時傳回 `null`。 |
| `geoip_lookup(ip)` | IPv4 或 IPv6 位址的地理位置，格式為物件；查不到時傳回 `null`。 |

```vrl
# 从扩展表 host_owner 查出主机所属的团队
.team = lookup("host_owner", .host).team

# 客户端所在的位置
place = geoip_lookup(.client_ip)
if is_object(place) {
  .country = place.country
  .city = place.city
}
```

- 這兩個函式都不會擲出錯誤。如果表格或資料列不存在、索引鍵不是文字、數字或布林值、無法解析位址，或資料庫中沒有該位址，結果一律為 `null`。對 `null` 存取 `.team` 之類的路徑，結果也是 `null`。
- `lookup` 的表名必須直接寫成字串。從欄位或變數取得表名會導致編譯失敗。數字或布林值的索引鍵會以文字查詢：`42` 會找到索引鍵為 `42` 的資料列。
- `lookup` 會讀取工作區的擴充表。若要瞭解資料列變更後多久才能查到，請參閱[擴充表](/zh-Hant/extend-tables#在管線中查詢)。
- `geoip_lookup` 會讀取 [`[mmdb].db_path`](/zh-Hant/configuration#功能與整合) 指定的 [DB-IP](https://db-ip.com) City Lite 資料庫。若檔案不存在，則傳回 `null`。資料庫不含私人 IP 位址。傳回的物件只會包含下列欄位中資料庫有值的欄位：

| 欄位 | 內容 |
|---|---|
| `country` | 國家的 ISO 3166 代碼，例如 `DE`。 |
| `country_name` | 國家的英文名稱。 |
| `continent_code` | 洲的代碼，例如 `EU`。 |
| `continent` | 洲的英文名稱。 |
| `region` | 一級行政區（例如州或省）的英文名稱。 |
| `city` | 城市的英文名稱。 |
| `latitude`、`longitude` | 緯度與經度，單位為度。 |

## JavaScript 函式

每個事件都會執行一次原始碼。全域物件 `molesignal` 提供事件和輔助方法：

| 成員 | 用途 |
|---|---|
| `molesignal.fields` | 以物件表示的事件。可讀取、修改或指派為新物件。 |
| `molesignal.set(name, value)` | 設定欄位。 |
| `molesignal.del(name)` | 刪除欄位。 |
| `molesignal.now()` | 目前時間，以 Unix 紀元起算的微秒數表示。 |
| `molesignal.parse_json(text)` 與 `molesignal.encode_json(value)` | 在 JSON 文字與值之間轉換。 |
| `molesignal.sha256(text)` | 文字的 UTF-8 位元組的 SHA-256 摘要，由 64 個小寫十六進位字元組成。 |

```js
molesignal.set("severity", String(molesignal.fields.level || "info").toUpperCase());
molesignal.set("seen_at", molesignal.now());
molesignal.del("level");
```

JavaScript 函式在隔離的引擎中執行，有下列限制：

- 執行時間超過 50 毫秒時，引擎會停止執行並回報 `js timeout 50ms`。
- 每個函式的堆積記憶體上限為 32 MiB。
- 不提供網路存取、計時器或 `TextEncoder`。

## 使用函式

管線步驟會執行 VRL。在 **自訂 VRL** 步驟中，選取 **從已儲存的函式開始**，即可將 VRL 函式或預設的原始碼複製到步驟中，之後仍可編輯。步驟會儲存自己的副本。後續修改或刪除該函式都不會影響管線。

## 權限

- `functions.read` 可列出及開啟函式。
- `functions.create` 和 `functions.edit` 可管理函式定義。
- `functions.run` 可使用執行工具執行範例。
- `functions.delete` 可刪除函式定義。
