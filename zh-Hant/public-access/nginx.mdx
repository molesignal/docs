以下設定採用[公網存取](/zh-Hant/public-access)建議的做法：使用同一個網域名稱 `molesignal.example.com`，由內網 DNS 解析至 nginx 的內網位址 `10.0.0.10`，由公網 DNS 解析至公網位址 `203.0.113.10`。兩個 `server` 使用同一張憑證，並以監聽位址區分。只保留實際用到的 `location`。

## 共用設定

將上游、公網存取記錄格式和速率限制區域放在 `http` 區塊中，例如放在 `/etc/nginx/conf.d/molesignal.conf` 的開頭：

```nginx
upstream molesignal {
    # standalone 节点，或分角色部署时的 router
    server 10.0.1.20:5080;
    keepalive 16;
}

# 公网入口的访问日志只记路径，不记查询串；心跳打卡、日历订阅、一次性处理链接和华为云回调的路径里有 Token，只记前缀。
map $uri $molesignal_log_uri {
    ~^(/api/v1/(?:intake/heartbeats|public/calendar|public/notify/actions)/)  $1<token>;
    ~^(/notify/actions/)                                                      $1<token>;
    ~^(/api/v1/public/notify/[^/]+/(?:replies|keypress)/)                     $1<token>;
    default                                                                   $uri;
}

log_format molesignal_public '$remote_addr [$time_local] "$request_method $molesignal_log_uri $server_protocol" '
                             '$status $body_bytes_sent "$http_user_agent" $request_time';

limit_req_zone $binary_remote_addr zone=molesignal_public:10m rate=20r/s;
```

所有轉送位置都使用同一組 Proxy 設定，將這組設定放入 `/etc/nginx/snippets/molesignal-proxy.conf`：

```nginx
proxy_pass http://molesignal;
proxy_http_version 1.1;
proxy_set_header Connection "";
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
```

## 內網入口

內網入口轉送所有路徑，做法與沒有公網入口時相同。即時查詢採用串流回應，不可啟用緩衝：

```nginx
server {
    listen 10.0.0.10:443 ssl;
    server_name molesignal.example.com;
    ssl_certificate     /etc/nginx/tls/molesignal.crt;
    ssl_certificate_key /etc/nginx/tls/molesignal.key;

    client_max_body_size 16m;

    location /api/v1/query/stream {
        include /etc/nginx/snippets/molesignal-proxy.conf;
        proxy_buffering off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }

    location / {
        include /etc/nginx/snippets/molesignal-proxy.conf;
        proxy_read_timeout 60s;
    }
}
```

## 公網入口

公網入口只列出要開放的路徑，每條路徑只接受所需的 HTTP 方法。最後的 `location /` 對其他所有路徑傳回 404：

```nginx
server {
    listen 203.0.113.10:443 ssl;
    server_name molesignal.example.com;
    ssl_certificate     /etc/nginx/tls/molesignal.crt;
    ssl_certificate_key /etc/nginx/tls/molesignal.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    access_log /var/log/nginx/molesignal-public.log molesignal_public;
    client_max_body_size 2m;
    limit_req zone=molesignal_public burst=40 nodelay;
    limit_req_status 429;

    # 外部告警
    location = /api/v1/intake/alerts {
        limit_except POST { deny all; }
        client_max_body_size 4m;
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 心跳打卡
    location ^~ /api/v1/intake/heartbeats/ {
        limit_except GET POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # Jira 的工单 Webhook
    location ~ ^/api/v1/public/tickets/jira/[^/]+$ {
        limit_except POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 值班日历订阅
    location ^~ /api/v1/public/calendar/ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # Teams 里的 Mole Agent
    location ^~ /api/v1/public/im/teams/ {
        limit_except POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 回复短信与电话按键；华为云的地址最后一段是回调 Token
    location ~ ^/api/v1/public/notify/[^/]+/(replies|keypress)(/[^/]+)?$ {
        limit_except POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 企业微信 App 的按钮：企业微信先用 GET 校验地址
    location ~ ^/api/v1/public/notify/[^/]+/wecom$ {
        limit_except GET POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # Mattermost 机器人的按钮
    location ~ ^/api/v1/public/notify/[^/]+/mattermost$ {
        limit_except POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 一次性处理链接：确认页和它的接口
    location ^~ /notify/actions/ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location ^~ /api/v1/public/notify/actions/ {
        limit_except GET POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 自动化的 API 触发
    location ~ ^/api/v1/public/automations/[^/]+/trigger$ {
        limit_except POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 推送来源
    location ~ ^/api/v1/(_kinesis_firehose|_cloudflare|_heroku)$ {
        limit_except POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 用户体验：浏览器先发 CORS 预检
    location ~ ^/api/v1/rum/(events|replay)$ {
        limit_except POST OPTIONS { deny all; }
        client_max_body_size 8m;
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 拨测 Probe Agent 上传产物
    location ^~ /api/v1/synthetics/artifacts/ {
        limit_except PUT { deny all; }
        client_max_body_size 10m;
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 状态页
    location ^~ /status/ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location ^~ /api/v1/public/status-pages/ {
        limit_except GET POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 资源共享
    location ^~ /s/ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location = /shared {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location ^~ /api/v1/public/share {
        limit_except GET POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 状态页、分享页和一次性处理链接页面的网页文件
    location ^~ /assets/ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location ~ ^/favicon(-dark)?\.(ico|svg)$ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }

    # 其他路径在公网上不存在
    location / {
        return 404;
    }
}
```

`limit_except GET` 也會允許 `HEAD`。若要依來源位址限制特定路徑，請在該路徑的 `location` 中加入 `allow` 和 `deny all;`。例如，只允許 Azure 服務標籤 `AzureBotService` 中的位址範圍存取 Teams 的回呼端點。

## 狀態頁的自訂網域名稱

如果狀態頁綁定了 `status.example.org`，請為該網域新增一個公網 `server`，只允許存取狀態頁的根路徑、API 和網頁檔案：

```nginx
server {
    listen 203.0.113.10:443 ssl;
    server_name status.example.org;
    ssl_certificate     /etc/nginx/tls/status.example.org.crt;
    ssl_certificate_key /etc/nginx/tls/status.example.org.key;

    access_log /var/log/nginx/molesignal-public.log molesignal_public;
    limit_req zone=molesignal_public burst=40 nodelay;
    limit_req_status 429;

    location ~ ^/(history|uptime)?$ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location ^~ /incidents/ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location ^~ /api/v1/public/status-pages/ {
        limit_except GET POST { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location ^~ /assets/ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location ~ ^/favicon(-dark)?\.(ico|svg)$ {
        limit_except GET { deny all; }
        include /etc/nginx/snippets/molesignal-proxy.conf;
    }
    location / {
        return 404;
    }
}
```

由 MoleSignal 自動簽發自訂網域名稱的憑證時，TLS 會在 MoleSignal 終止。nginx 只能透過 `stream` 模組依 SNI 直接轉送，無法讀取路徑，因此不能只開放狀態頁。若要在入口限制路徑，請改由 nginx 管理憑證。

## 只有一個入口時

如果 nginx 只有一個監聽位址，請依來源位址區分請求：保留公網 `server` 中已開放的路徑，將最後的 `location /` 改為只允許公司網路和 VPN 的位址範圍，再加入即時查詢的串流設定：

```nginx
location /api/v1/query/stream {
    allow 10.0.0.0/8;
    allow 192.168.0.0/16;
    deny all;
    include /etc/nginx/snippets/molesignal-proxy.conf;
    proxy_buffering off;
    proxy_read_timeout 600s;
    proxy_send_timeout 600s;
}

location / {
    allow 10.0.0.0/8;
    allow 192.168.0.0/16;
    deny all;
    include /etc/nginx/snippets/molesignal-proxy.conf;
}
```

此時，內網請求也會經過同一個 `server`。請將 `client_max_body_size` 放寬至 `16m`，存取記錄也會記下內網請求的路徑。如果 nginx 前面還有負載平衡器，請用 `set_real_ip_from` 和 `real_ip_header` 取得原始來源位址，否則 `allow` 只會看到負載平衡器的位址。

## 檢查

檢查設定並重新載入：

```bash
nginx -t
```

```bash
nginx -s reload
```

從公網向登入 API 傳送請求，應傳回 `404`：

```bash
curl -s -o /dev/null -w '%{http_code}\n' https://molesignal.example.com/api/v1/auth/signin
```

從公網傳送不含 Token 的警示接收請求，應傳回 `401`，表示請求已到達 MoleSignal：

```bash
curl -s -o /dev/null -w '%{http_code}\n' -X POST https://molesignal.example.com/api/v1/intake/alerts
```

最後，在 `_sys` 組織的 **設定 → 用戶端 IP 識別** 中，將 nginx 的位址列為受信任的 Proxy。詳情請參閱[用戶端 IP 識別](/zh-Hant/settings/platform#用戶端-ip-識別)。
