開啟 **身分與存取 → 組織** 或 **團隊**。

## 組織

**組織** 是位於 `_sys` 組織中的平台頁面，需要 `sys.organizations.read` 權限。此頁面會列出執行個體中的所有組織，以及帳號在各組織中的角色（不是成員時顯示 **非成員**）、組織識別資訊和 ID。

**管理 IAM** 會切換至指定組織，並開啟該組織的 **身分與存取**。帳號必須是該組織的成員，且該組織必須處於啟用狀態。

建立組織：

1. 點選 **建立組織**。
2. 填寫 **名稱** 和 **識別資訊**。系統會在 API 和資源路徑中使用識別資訊辨識組織，建立後無法修改。
3. 點選 **建立組織**。建立者會自動成為該組織的 Owner。

在同樣位於 `_sys` 的[設定 → 組織管理](/zh-Hant/settings/platform#組織管理)中停用、啟用或刪除組織。具備該組織 `org.delete` 權限的成員也可以從[組織內部](/zh-Hant/settings/organization#組織生命週期)刪除組織。

## 團隊

團隊將同一組織中的成員分組，用於：

- 指定[值班排程](/zh-Hant/alerting/on-call)所屬的團隊，以及[升級策略](/zh-Hant/alerting/on-call#升級策略)的目標；
- 界定通知[備援路由](/zh-Hant/notification-channels#設定備援路由)的範圍；
- 作為[存取授權](/zh-Hant/identity/roles#存取授權)的身分主體；
- 指定 [Mole Agent](/zh-Hant/agent#組織、團隊與個人資源) 對話、知識、技能等團隊資源所屬的團隊。

若要建立團隊，點選 **新增團隊**，填寫 **名稱**，選取 **成員**，再點選 **建立團隊**。每位成員都必須隸屬於目前的組織。點選團隊即可修改名稱或成員。

**刪除** 會移除團隊，但保留各成員的帳號。如果團隊仍有 Mole Agent 資源，請先移交或刪除這些資源，再刪除團隊。

開啟 **團隊** 需要 `org.members.read` 權限，建立、修改和刪除團隊則需要 `org.teams.manage` 權限。
