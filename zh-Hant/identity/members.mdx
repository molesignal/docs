開啟 **身分與存取 → 使用者**、**邀請** 或 **審核**。列出成員需要 `org.members.read` 權限，在這些頁面進行任何變更都需要 `org.members.update` 權限。即使沒有 `org.members.read` 權限，成員仍可看到彼此的姓名和頭像。事件、排班和升級策略會以姓名顯示負責人，選取成員時也依姓名選取。只有具備 `org.members.read` 權限，才能查看電子郵件地址、角色、團隊、登入方式和活躍時間。

## 使用者

**使用者** 列出目前工作區的成員。頁面頂端顯示使用者總數、使用中的使用者人數和待審核的使用者人數。可依姓名、電子郵件地址或團隊搜尋，並依角色或狀態篩選。

| 欄位 | 顯示內容 |
|---|---|
| **角色** | 成員在目前工作區的角色。 |
| **所屬團隊** | 成員所屬的[團隊](/zh-Hant/identity/teams#團隊)。 |
| **登入方式** | **密碼**、**OIDC** 或 **SAML**。 |
| **上次活躍** | 最近一次登入時間，或 **從未登入**。 |
| **狀態** | **使用中**、**已停用**、**待審核** 或 **已拒絕**。 |

開啟列尾的選單，即可執行下列操作：

| 操作 | 效果 |
|---|---|
| **查看詳細資料** | 顯示成員的身分、成員資格和存取狀態。 |
| **變更角色** | 設定成員在目前工作區的角色，可選擇內建角色或[自訂角色](/zh-Hant/identity/roles#角色)。 |
| **停用使用者** | 帳號無法再登入任何工作區，但會保留成員資格和設定。選取 **啟用使用者** 即可恢復登入。 |
| **移除成員** | 成員立即失去目前工作區的存取權，但會保留帳號。 |
| **核准** | 只有待審核的使用者才會顯示此操作。請參閱[審核](#審核)。 |

系統會拒絕下列變更：

- 變更自己的角色、停用自己的帳號，或將自己移出目前的工作區；
- 組織管理員變更 Root 使用者，也就是首次啟動時依 `[auth].root_email` 建立的帳號；
- 停用或刪除最後一位平台管理員。

切換到其他工作區時，系統會為該組織簽發新的工作階段。即使變更組織名稱，組織的 ID 和識別碼也不會改變。

## 審核

如果工作區的[註冊策略](/zh-Hant/settings/organization#註冊與存取)允許自行加入，但要求管理員審核，新帳號會在 **審核** 頁面等待審核。頂端列的 **通知** 鈴鐺圖示也會顯示提示。

- 選取 **通過** 以啟用帳號。
- 選取 **拒絕** 會將帳號標記為已拒絕。該帳號無法登入，也無法在此頁面撤銷這項決定。

設定 SMTP 後，MoleSignal 會以工作區的預設語言寄送電子郵件：有新帳號註冊時通知工作區管理員，審核完成時通知註冊者。寄送失敗不會中斷註冊或審核。

## 邀請

**邀請** 會記錄受邀者的電子郵件地址和應取得的角色，並列出待處理邀請的角色、狀態、傳送時間和邀請者。

1. 按一下 **邀請使用者**。
2. 填寫 **電子郵件地址**。如果工作區已設定[電子郵件網域](/zh-Hant/identity/sso#電子郵件網域)，地址必須屬於其中一個網域。
3. 選擇 **角色**，或保留 **組織預設角色**，也就是自行加入時取得的角色。
4. 按一下 **傳送邀請**。

**重新傳送** 會將待處理的邀請重新標記為已傳送，**撤銷** 則會取消邀請。已接受的邀請無法重新傳送。

<Note>
  MoleSignal 不會寄送邀請電子郵件，邀請本身也不會建立帳號或成員資格。受邀者必須透過[註冊](/zh-Hant/console#登入)或[單一登入](/zh-Hant/identity/sso)加入，再由管理員在 **使用者** 頁面設定角色。
</Note>

## 成員 API

| 操作 | 端點 | 權限 |
|---|---|---|
| 列出使用者 | `GET /api/v1/users` | `org.members.read`；已登入的成員若無此權限，只能取得姓名和頭像；系統會拒絕未具此權限的 API Token 請求 |
| 變更使用者 | `PATCH /api/v1/users/{id}` | `org.members.update` |
| 核准或拒絕註冊 | `POST /api/v1/users/{id}/approve`、`POST /api/v1/users/{id}/reject` | `org.members.update` |
| 新增或變更成員資格 | `POST /api/v1/orgs/{id}/members` | `org.members.update` |
| 移除成員資格 | `DELETE /api/v1/orgs/{id}/members/{user_id}` | `org.members.update` |
| 列出或建立邀請 | `GET /api/v1/invitations`、`POST /api/v1/invitations` | `org.members.read`、`org.members.update` |
