開放原始碼版是完整的自架平台。它採用 [Apache License 2.0](https://github.com/molesignal/molesignal/blob/main/LICENSE) 授權，在維運團隊自行掌控的基礎架構上執行，不需要 MoleSignal 帳號或託管控制平面。

## 內建功能

- 記錄檔、指標、追蹤與 Profile 的擷取、儲存與查詢；
- 由追蹤資料衍生的 APM、RUM 調查、跨訊號關聯與服務拓撲；
- 儀表板、資料流、管線、可重複使用的函式與擴充表；
- 警示、事件、值班與升級、通知傳送、重大事件、修復動作與事後檢討；
- 合成監控與狀態頁；
- Mole Agent，以及透過 Inbound MCP 存取同一套工具目錄；
- 組織隔離、IAM、SSO、服務帳號、API 權杖、稽核事件與平台設定；
- 使用 Docker Compose、二進位檔或 Kubernetes 的單節點部署，以及由 router、intake、querier、compactor 與 alert 程序組成的分角色部署。

完整的 API 範圍請參閱 **API 參考**。權限仍決定使用者、服務帳號或 API 權杖可以執行哪些操作。

## 部署需求

中繼資料使用 PostgreSQL，資料則使用相容於 S3、Azure 或 Google Cloud 的物件儲存。單節點開發環境可使用本機磁碟充當物件儲存，請參閱[部署 MoleSignal](/zh-Hant/deployment)。

## 開始自架

1. 依照[快速入門](/zh-Hant/quickstart)執行本機執行個體。
2. 在[部署 MoleSignal](/zh-Hant/deployment)中選擇拓撲。
3. 在接收實際資料前，完成[正式環境檢查清單](/zh-Hant/deployment/production-checklist)。
4. 閱讀[安全性與多租戶](/zh-Hant/security)與[平台自身的可觀測性](/zh-Hant/self-observability)。
