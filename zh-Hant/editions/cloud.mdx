<Warning>
MoleSignal Cloud 目前仍處於候補名單階段。本頁用於準備評估，並非已全面開放服務的開通或串接教學。
</Warning>

MoleSignal Cloud 是規劃中的託管方案，適合希望評估可觀測性平台，同時減少儲存與服務基礎架構維運工作的團隊。透過 [Cloud 候補名單](https://www.molesignal.com/zh-Hans/cloud) 登記需求。若需立即開始評估，請參閱[自託管快速入門](/zh-Hant/quickstart)。

## 準備 Cloud 評估

| 需求 | 需要收集的資訊 |
|---|---|
| 遙測 | 日誌、指標、追蹤、Profile、預估每日用量與寫入尖峰。 |
| 保留期限 | 各訊號所需的歷史資料範圍，以及必須維持可用的查詢。 |
| 存取 | 團隊規模、組織邊界、身分驗證需求和 API Token 使用方式。 |
| 部署位置 | 所需的資料區域、網路存取方式和資料處理限制。 |
| 維運 | 支援需求、復原目標與事件發生時的責任分工。 |

評估期間，請確認可用區域、存取方式、保留限制、商務條款和支援承諾。託管服務不一定提供與自託管配置項目同名的設定。

## 先驗證資料傳輸流程

1. 啟動自託管執行個體，選擇一項具代表性的服務。
2. 依照文件中的[資料擷取通訊協定](/zh-Hant/intake/integrations)傳送遙測資料。
3. 核對事件時間、資料流、服務身分和權限。
4. 執行具代表性的查詢並完成一次事件調查，記錄所需用量與保留期限。
5. 根據結果討論需求，再敲定 Cloud 開通或移轉計畫。

自託管執行個體的 API 位址或 API Token 不會自動轉為 Cloud 位址或憑證。僅使用實際環境提供的串接位址與憑證。

## 定價與功能狀態

[定價頁](https://www.molesignal.com/zh-Hans/pricing)列出各項方案，並提供諮詢管道；取得存取權限時，請確認實際可用的方案和條款。標有 **enterprise cloud** 的頁面可能會介紹規劃中的功能，請逐頁查看可用性說明。
