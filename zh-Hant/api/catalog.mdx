## 授權模型

端點可以要求：

- `streams.query` 或 `alerts.rules.manage` 等組織權限；
- `sys.telemetry.read` 等平台權限；
- 資源層級所有權或關係/授權；
- 僅能存取單一資源的公開共用工作階段。

不要根據顯示角色推斷授權。請查詢 `/api/v1/iam/capabilities` 取得實際生效的權限與功能快照。

## 選擇並驗證請求

先開啟對應家族的指南，確認 HTTP 方法、所需權限、組織範圍、請求欄位與回應格式。同一個家族可能同時包含管理請求與資料查詢，兩者需要的權限可能不同。

修改設定前，使用文件中的讀取請求確認目標組織與資源。寫入後，重新讀取資源或查詢一筆受控測試事件，確認實際結果。HTTP 成功不代表遙測已經進入預期資料流，也不代表事件已經恢復。

遇到錯誤時，請參照 [API 入門](/zh-Hant/api-reference)和具體端點的說明。[回報文件不一致](/zh-Hant/support)時，請附上執行版本、去識別化後的請求與請求識別碼，不要附上憑證或敏感事件資料。
