```http
GET /api/v1/audit
```

依時間由新到舊傳回組織的稽核事件，並使用游標分頁。此呼叫需要 `audit.read`。

每筆事件也是組織 `_audit` 資料流中的一列，可供查詢，也可透過管線傳送到其他目的地。此 API 讀取的是權威記錄，請參閱[稽核資料流](/zh-Hant/settings/data-security#稽核資料流)。

稽核軌跡會記錄敏感的生命週期操作，但不會記錄每項變更。目前版本的操作名稱以下列前綴開頭：

| 前綴 | 操作 |
|---|---|
| `agent.` | Mole Agent 的模型服務供應商、提示詞、工具與工具呼叫、MCP 服務、審核、對話、調查和執行。 |
| `iam.` | 角色繫結、關係和跨組織授權。 |
| `resource_share.` | 建立、輪替、撤銷和開啟分享連結，以及密碼驗證失敗。 |
| `status_page.` | 狀態頁、元件、自動化規則和標誌。 |
| `synthetic.` | 合成監控的探測點、探測器和探測器權杖。 |
| `schedule.` | 值班排程及其暫時覆寫。 |
| `trace_debug_token.` | 使用追蹤偵錯權杖。 |
| `dashboard.` | 根據 AI 草稿建立的儀表板。 |

稽核軌跡不會記錄資料流、警示規則、事件和連接器的變更。

**查詢參數**

| 參數 | 類型 | 說明 |
|---|---|---|
| `from`、`to` | string | 時間範圍。可使用以微秒表示的 epoch 時間值，或相對值 `now` 和 `now-<N><单位>`（單位為 `s`、`m`、`h` 或 `d`），例如 `now-30m`。 |
| `actorKind` | string | 主體類型，例如 `user`。 |
| `actor` | string | 主體識別碼。 |
| `action` | string | 完整的操作名稱，例如 `agent.model_provider.created`。 |
| `targetKind`、`targetId` | string | 目標的類型與識別碼。 |
| `limit` | integer | 每頁筆數。預設為 `50`。可設定為 1 至 200。 |
| `cursor` | string | 上一頁傳回的 `nextCursor`，其值不透明。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/audit?from=now-7d&action=agent.model_provider.created&limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**應變**

| 欄位 | 說明 |
|---|---|
| `items[].actor_kind`、`items[].actor_id` | 執行變更的主體。 |
| `items[].action` | 操作名稱，例如 `iam.role_binding.create`。 |
| `items[].target_kind`、`items[].target_id` | 受影響的物件。兩者都可能為 `null`。 |
| `items[].ip`、`items[].user_agent` | 操作記錄中的用戶端位址與用戶端識別資訊，兩者都可能為 `null`。 |
| `items[].payload` | 操作詳細資料。承載資料不包含金鑰、提示詞本文和工具結果。 |
| `items[].ts` | 事件時間，單位為微秒。 |
| `nextCursor` | 下一頁的游標，最後一頁為 `null`。 |
| `retentionDays` | 稽核記錄的保留天數，所有組織與平台共用。系統每天刪除超過保留期限的記錄，`0` 表示永久保留。 |

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `from` 或 `to` 既不是數字，也不是有效的相對值（`unparseable time: yesterday`、`bad time unit in: now-3x`），或 `cursor` 無效。 |
| `403` | 權杖缺少 `audit.read`。 |

## 相關稽核路由

| 端點 | 權限 | 用途 |
|---|---|---|
| `GET /api/v1/system/audit` | `sys.telemetry.read`，系統範圍 | 對系統組織的稽核事件執行相同的查詢。這些事件涵蓋啟用或停用組織、修改追蹤原則、修改稽核記錄保留天數等操作。 |
| `GET /api/v1/settings/audit_retention` | `sys.settings.retention.manage`，系統範圍 | 讀取稽核記錄保留天數：`{ "retentionDays": 90 }`。 |
| `PUT /api/v1/settings/audit_retention` | `sys.settings.retention.manage`，系統範圍 | 使用相同的請求主體修改稽核記錄保留天數。`retentionDays` 必須是 `0`（永久保留）到 `3650` 之間的整數，超過 `3650` 時傳回 `400`。 |
| `GET /api/v1/settings/audit_retention/preview?retentionDays=30` | `sys.settings.retention.manage`，系統範圍 | 預覽縮短保留期限後會刪除的記錄：`{ "retentionDays": 30, "previousRetentionDays": 90, "rows": 2400, "earliestAt": 1780000000000000 }`。記錄筆數是實際統計值，而非估算值。延長保留期限或設為 `0` 時，傳回 `"rows": 0`。 |
| `GET /api/v1/agent/audit/chat/{id}` | `audit.read` | Mole Agent 對話的完整記錄：`chat` 記錄及其 `messages`，包含提示詞雜湊值、Token 數量和證據。對話不存在時傳回 `404`。 |

<Warning>
  對話記錄包含使用者的提問與模型的回答。請只將 `audit.read` 授予有權閱讀這些內容的帳號。
</Warning>
