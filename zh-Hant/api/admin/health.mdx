| 端點 | 身分驗證 |
|---|---|
| `GET /api/v1/healthz` | 無 |
| `GET /metrics` | 無 |
| `GET /api/v1/readyz` | Bearer Token |
| `GET /api/v1/version` | Bearer Token |

## 存活

```http
GET /api/v1/healthz
```

綜合健康探針。節點健康時傳回 `200`；無法連線至物件儲存時傳回 `503`，並附上 `reason`。容器與負載平衡器的探針使用此端點。

<ResponseExample>
```json 200
{ "status": "ok" }
```
</ResponseExample>

## 就緒

```http
GET /api/v1/readyz
Authorization: Bearer <token>
```

流量就緒探針。啟動時不會重播任何資料，節點啟動後即傳回 `200`；物件儲存降級時，節點仍可處理唯讀流量。此請求需要 Bearer Token，未附上憑證的探針會收到 `401`。探針無法附上權杖時，請改用 `/api/v1/healthz`。

<ResponseExample>
```json 200
{ "status": "ready" }
```
</ResponseExample>

## 版本

```http
GET /api/v1/version
Authorization: Bearer <token>
```

傳回產品版本、commit 與分支、建置時間、建置 ID、發行通道與版本類型。

<ResponseExample>
```json 200
{
  "version": "26.1.0.0",
  "commit": "<git-sha>",
  "branch": "main",
  "buildEpochSecs": 1790000000,
  "buildId": "<build-id>",
  "releaseChannel": "alpha",
  "edition": "oss"
}
```
</ResponseExample>

## 指標

```http
GET /metrics
```

採用 Prometheus 指標公開格式（`text/plain; version=0.0.4`），包含處理程序與各子系統的指標，例如 `cache_*` 命中率、`wal_*`、`object_store_*` 與 `storage_reconciler_issues_total`。請在代理伺服器或網路層限制對此路由的存取，請參閱[自身可觀測性](/zh-Hant/self-observability)。
