```http
GET /api/v1/streams/runtime
```

傳回各資料流的運作狀態：已儲存的資料列數與位元組數、最近接收時間、資料接收狀態，以及分桶後的時間序列。此呼叫需要 `streams.read`，系統遙測需要 `sys.telemetry.read`。權杖缺少 `audit.read` 時，結果不含 `_audit` 資料流。

**查詢參數**

| 參數 | 預設值 | 說明 |
|---|---|---|
| `windowSecs` | 86400 | 時間視窗長度，限制在 3600 到 604800 之間。 |
| `bucketCount` | 24 | 時間序列的分桶數，限制在 6 到 48 之間。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/runtime?windowSecs=3600" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

| `status` | 含義 |
|---|---|
| `healthy` | 最近 15 分鐘內收到資料。 |
| `delayed` | 上次收到資料是在 15 分鐘前到 2 小時前之間。 |
| `interrupted` | 上次收到資料已超過 2 小時。 |
| `idle` | 依設計較少收到資料的資料流，例如 Mole Agent 的追蹤資料流。 |
| `unused` | 資料流從未收到資料。 |
| `unknown` | 統計資訊無法取得。 |

`staleIndexFiles` 是資料流最近一次變更索引類型後，索引仍使用舊設定的檔案數。背景重建索引時，此數值會降至 0。
