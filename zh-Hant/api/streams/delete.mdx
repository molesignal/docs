```http
DELETE /api/v1/streams/{id}
```

刪除資料流的定義，由 compactor 回收已儲存的資料。無法刪除受保護的系統資料流 `_molesignal`。刪除資料流可能導致引用該資料流的儀表板、已儲存的檢視、警示規則、報告與管線失效。此呼叫需要 `streams.delete` 權限；刪除 `_audit` 資料流還需要 `audit.read` 權限，若缺少則傳回 `403`。

**路徑參數**

| 參數 | 類型 | 說明 |
|---|---|---|
| `id` | string | 資料流的 `id`。若 id 未知，則傳回 `404`。 |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/streams/$STREAM_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>
