```http
GET /api/v1/streams/{id}
```

傳回資料流的定義，包括結構描述（schema）、明確設定的 `retention`、計算得出的 `effectiveRetention` 以及資料流設定。此呼叫需要 `streams.read` 權限，系統遙測則需要 `sys.telemetry.read` 權限。`_audit` 資料流還需要 `audit.read` 權限，若缺少此權限則傳回 `403`。

**路徑參數**

| 參數 | 類型 | 說明 |
|---|---|---|
| `id` | string | [列出資料流](/zh-Hant/api/streams/list)傳回的資料流 `id`。若 id 未知，則傳回 `404`。 |

<ResponseExample>
```json 200
{
  "id": "3KE0ot1NtfCTJ3V3XxBNbqx9Y62",
  "orgId": "<organization-id>",
  "name": "app",
  "streamType": "logs",
  "schema": {
    "fields": [
      { "name": "level", "dataType": "utf8", "nullable": true, "indexType": "none",
        "encrypted": false },
      { "name": "trace_id", "dataType": "utf8", "nullable": true, "indexType": "exact",
        "encrypted": false }
    ]
  },
  "retention": null,
  "effectiveRetention": { "days": 30 },
  "settings": {
    "description": null,
    "indexRules": [],
    "maxQueryRangeHours": null,
    "queryable": true,
    "fieldMasking": [],
    "dailyMerge": true,
    "downsample": { "afterDays": 0, "intervalSecs": 3600 }
  },
  "createdAt": 1790000000000000,

```
</ResponseExample>

資料流使用預設保留期限時，`retention` 為 `null`，而 `effectiveRetention` 一律提供實際生效的天數。各項設定的說明請參閱[編輯保留期限與設定](/zh-Hant/api/streams/edit-retention)。
