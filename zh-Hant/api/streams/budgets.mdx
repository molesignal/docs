預算只會在來源的用量接近或超出預算時發出提醒，資料擷取的回應與儲存方式皆維持不變。請參閱[資料擷取用量與預算](/zh-Hant/streams#資料擷取用量與預算)。

## 列出預算

```http
GET /api/v1/streams/budgets
```

傳回組織的所有預算，以及來源名稱和目前週期的用量。需要 `intake_usage.read` 權限；在 `_sys` 組織中也可使用 `sys.telemetry.read` 權限。未知的數值為 `null`。

## 設定預算

```http
POST /api/v1/streams/budgets
```

設定單一來源的預算。每個來源最多只能設定一項預算，再次設定會更新原有的預算。需要 `intake_budgets.manage` 權限。`_sys` 組織無法設定預算。

| 欄位 | 必填 | 說明 |
|---|---|---|
| `dimension` | 是 | `credential`、`stream` 或 `service`。 |
| `sourceKey` | 是 | 來源，使用[資料擷取用量](/zh-Hant/api/streams/usage)傳回的值。平台本身的遙測資料、未標記服務的事件，以及超出上限的服務都無法設定預算。 |
| `period` | 是 | `day` 或 `month`，依 UTC 的日曆日或日曆月計算。 |
| `limitSize` | 是 | 單位為 MiB，範圍為 1 到 1073741824。 |
| `warnPercent` | 否 | 預警百分比，範圍為 0 到 99。填入 `0` 時，只會在預算用盡時提醒。預設為 80。 |
| `notifyUserIds` | 否 | 要通知的組織成員，最多 50 人。預設通知設定預算的成員。使用服務帳號設定時，必須指定通知對象。 |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/streams/budgets" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"dimension":"stream","sourceKey":"logs:app","period":"day","limitSize":102400}'
```
</RequestExample>

## 移除預算

```http
DELETE /api/v1/streams/budgets/{budgetId}
```

傳回 `204`。需要 `intake_budgets.manage` 權限。
