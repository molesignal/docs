```http
PUT /api/v1/streams/{id}/settings
```

資料流的 schema 會隨著新欄位在資料擷取時加入而演進，API 不會替換欄位類型。使用此端點為 schema 中已有的欄位選擇索引類型。呼叫此端點需要 `streams.configure` 權限，`_audit` 資料流還需要 `audit.read` 權限。同一個端點也可用來編輯保留期間與設定，請參閱[編輯保留期間與設定](/zh-Hant/api/streams/edit-retention)。

**請求本文**

| 欄位 | 類型 | 說明 |
|---|---|---|
| `fields` | array | 每個需要設定的欄位各占一項。 |

`fields` 中的每一項：

| 屬性 | 類型 | 說明 |
|---|---|---|
| `name` | string | schema 中已有的欄位。 |
| `indexType` | string | `none`、`exact`、`full_text`、`bloom`、`skip`、`ngram`、`ip`、`key_value` 或 `range`，請參閱[資料流](/zh-Hant/streams#schema-與欄位)。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/streams/$STREAM_ID/settings \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "fields": [
      { "name": "trace_id", "indexType": "exact" },
      { "name": "msg", "indexType": "full_text" }
    ]
  }'
```
</RequestExample>

回應會傳回更新後的資料流，結構與[取得資料流](/zh-Hant/api/streams/get)所示相同。變更會立即套用至之後寫入的資料，系統會在背景依新設定為先前寫入的資料補建索引，請參閱[資料流](/zh-Hant/streams#schema-與欄位)。`full_text`、`ngram` 與 `ip` 索引僅適用於 `utf8` 欄位，`key_value` 僅適用於 `json` 欄位。
