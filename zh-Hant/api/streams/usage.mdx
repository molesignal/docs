```http
GET /api/v1/streams/usage
```

傳回各來源在一段時間內擷取的資料量，以及預算用在哪些來源。需要 `intake_usage.read` 權限；在 `_sys` 組織中也可使用 `sys.telemetry.read`。

未知的數值為 `null`，而非 0。無法讀取記錄時，`available` 為 `false`，所有數值皆為 `null`。若在這段期間內才開始計量，`complete` 為 `false`，數值為下限。

**查詢參數**

| 參數 | 預設值 | 說明 |
|---|---|---|
| `dimension` | `credential` | `credential`、`stream` 或 `service`。 |
| `windowSecs` | 86400 | 時間範圍的長度，介於 3600 到 2678400 之間。時間範圍從整點開始。 |

`sourceKey` 的格式：憑證為 `<credential_kind>:<id>`（`apiToken`、`connector`、`user`、`internal`），資料流為 `<stream_type>:<name>`，服務則使用服務名稱。未標註服務的事件使用空字串，超出上限的服務使用 `*`。

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/streams/usage?dimension=credential&windowSecs=86400" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

## 單一來源

```http
GET /api/v1/streams/usage/detail
```

傳回單一來源在這段期間內的總計、依時間區間彙總的每小時資料，以及依其餘兩個維度細分的用量。每個維度最多列出 20 個來源。

| 參數 | 預設值 | 說明 |
|---|---|---|
| `dimension` | 必填 | `credential`、`stream` 或 `service`。 |
| `sourceKey` | 必填 | 來源，使用 `GET /api/v1/streams/usage` 傳回的值。 |
| `windowSecs` | 86400 | 範圍為 3600 到 2678400。 |
| `bucketCount` | 24 | 時間區間數，範圍為 6 到 48。 |
