```http
POST /api/v1/streams
```

資料流也會在首次寫入時建立。若要先宣告具有明確 schema、索引、加密欄位或保留期的資料流，請使用此呼叫。此呼叫需要 `streams.create`。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `name` | string | 是 | 可包含字母、數字、`_`、`-` 與 `.`。[平台資料流](/zh-Hant/streams#平台資料串流)的名稱（例如 `_molesignal` 和 `_audit`）為保留名稱。 |
| `streamType` | string | 是 | `logs`、`metrics`、`traces`、`profiles` 或 `extend`。 |
| `fields` | array | 否 | 欄位定義，請見下文。 |
| `retentionDays` | integer | 否 | 1 到 3650。省略時使用 **設定 → 資料保留** 中的平台預設值。 |
| `settings` | object | 否 | `description`、`queryable` 等資料流設定，請參閱[編輯保留期與設定](/zh-Hant/api/streams/edit-retention)。 |

欄位包含下列屬性：

| 屬性 | 類型 | 說明 |
|---|---|---|
| `name` | string | 欄位名稱。 |
| `dataType` | string | `bool`、`int64`、`float64`、`utf8`、`timestamp` 或 `json`。 |
| `nullable` | boolean | 預設為 `true`。 |
| `indexType` | string | `none`、`exact`、`full_text`、`bloom`、`skip`、`ngram`、`ip`、`key_value` 或 `range`。預設為 `none`。 |
| `encrypted` | boolean | 對欄位套用靜態加密，之後無法變更此設定。請參閱[資料流](/zh-Hant/streams#加密欄位)。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/streams \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "app",
    "streamType": "logs",
    "fields": [
      { "name": "trace_id", "dataType": "utf8", "nullable": true,
        "indexType": "exact", "encrypted": false }
    ],
    "retentionDays": 30
  }'
```
</RequestExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `403` | 使用了平台資料流的名稱，或權杖缺少 `streams.create`。 |
| `409` | 已有相同名稱和類型的資料流。 |
| `422` | 請求本文缺少欄位，或欄位無效（例如未知的 `dataType`）。回應為純文字。 |
