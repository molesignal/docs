```http
GET /api/v1/me/api-tokens/default
```

傳回已登入使用者的預設接入 Token，並在首次呼叫時建立該 Token。與其他 Token 不同，每次呼叫都會傳回明文，讓 **資料來源** 頁面可以直接顯示可立即使用的 Token。使用此 Token 時，系統會以已登入使用者的身分執行操作，並套用內建的 **資料寫入** 原則（包含 `logs.write`、`metrics.write`、`traces.write`、`profiles.write` 和 `apm.deploy`）。此 Token 永不過期，`tokenKind` 為 `default_intake`。此呼叫必須來自已登入的工作階段，且需要 `personal_tokens.manage` 及原則中的兩項權限。

<RequestExample>
```bash cURL
curl -b ms-cookies.txt http://localhost:5080/api/v1/me/api-tokens/default
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3JtzUbBKtQCD7mFELKp2zDRum9f",
  "prefix": "r4fp1xwgpe",
  "token": "mspat-r4fp1xwgpe<secret>",
  "tokenKind": "default_intake",
  "policyId": "builtin:data_intake",
  "permissions": null,
  "applicationId": null,
  "createdAt": 1790000000000000
}
```
</ResponseExample>

將此 Token 用於收集器、Agent 與 SDK 匯出器，請參閱[資料來源](/zh-Hant/intake#資料接收-token)。
