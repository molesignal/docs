```http
GET /api/v1/auth/tokens
```

傳回目前組織中每個 API 權杖的中繼資料，包括預設接收權杖、RUM 用戶端權杖及服務帳號的權杖。絕不傳回明文權杖或密鑰雜湊值。此呼叫需要 `api_tokens.read`。

<ResponseExample>
```json 200
[
  {
    "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
    "prefix": "k7m2q9xv4b",
    "name": "grafana-readonly",
    "tokenKind": "personal",
    "userId": "<user-id>",
    "policyId": null,
    "permissions": ["dashboards.read", "streams.query", "streams.read"],
    "applicationId": null,
    "serviceAccountId": null,
    "expiresAt": 1798000000000000,
    "lastUsedAt": null,
    "revoked": false,
    "createdAt": 1790000000000000
  }
]
```
</ResponseExample>

| 欄位 | 說明 |
|---|---|
| `tokenKind` | `personal`、`serviceAccount`、`default_intake` 或 `rum_client`。 |
| `userId` | 核發權杖的使用者。個人權杖和預設接收權杖會以該使用者的身分執行操作。 |
| `policyId` | 權杖遵循的權限原則；若未套用原則，則為 `null`。 |
| `permissions` | 為權杖固定指定的權限；若未指定，則為 `null`。若權限原則也為空值，權杖可執行其代表的使用者或服務帳號所能執行的所有操作。 |
| `applicationId` | `rum_client` 權杖繫結的應用程式；其他情況為 `null`。 |
| `serviceAccountId` | 權杖代表的服務帳號；若未代表服務帳號，則為 `null`。 |
| `expiresAt` | 永不過期的權杖為 `null`。 |
| `lastUsedAt` | 首次使用前為 `null`。 |
| `revoked` | 撤銷權杖後為 `true`。 |

## 目前使用者的權杖

```http
GET /api/v1/me/api-tokens
```

傳回目前使用者的個人權杖與預設接收權杖，欄位相同。此呼叫必須透過已登入的工作階段發出，並需要 `personal_tokens.manage`。
