```http
POST /api/v1/me/api-tokens
```

簽發格式為 `mspat-<36>` 的個人 Token，以目前登入的使用者身分執行操作。明文 Token 只會在回應中出現一次，請立即儲存。此呼叫必須透過登入工作階段發出，不能使用其他 Token，且需要 `personal_tokens.manage`。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `name` | string | 是 | 顯示名稱，1 到 255 個字元。 |
| `policyId` | string | 否 | Token 適用的[權限原則](/zh-Hant/identity/roles#權限政策) ID，例如 `builtin:data_intake`。簽發者必須具備原則中的每一項權限。 |
| `permissions` | string[] | 否 | 為 Token 固定的組織權限。簽發者必須具備其中每一項權限。 |
| `expiresInDays` | integer | 否 | 有效天數，限 1 到 1825 天。省略時，Token 永不過期。 |

`policyId` 與 `permissions` 只能擇一指定。若兩者皆未指定，Token 可執行簽發者有權執行的所有操作。Token 的權限不會超過簽發者在送出請求當下具備的權限；簽發者失去某項權限後，Token 也會失去該權限。

<RequestExample>
```bash cURL
curl -b ms-cookies.txt -X POST http://localhost:5080/api/v1/me/api-tokens \
  -H 'content-type: application/json' \
  -d '{
    "name": "grafana-readonly",
    "permissions": ["streams.read", "streams.query", "dashboards.read"],
    "expiresInDays": 90
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE5hOsEc3lMC9qr9RWnPn0pqWF",
  "prefix": "k7m2q9xv4b",
  "name": "grafana-readonly",
  "tokenKind": "personal",
  "userId": "<user-id>",
  "policyId": null,
  "permissions": ["dashboards.read", "streams.query", "streams.read"],
  "applicationId": null,
  "serviceAccountId": null,
  "expiresAt": 1798000000000000,
  "lastUsedAt": null,
  "revoked": false,
  "createdAt": 1790000000000000,
  "token": "mspat-k7m2q9xv4b<secret>"
}
```
</ResponseExample>

`ms-cookies.txt` 儲存[登入](/zh-Hant/api/auth/login)後取得的工作階段。`GET /api/v1/me/api-tokens/scopes` 會列出可用來限定 Token 範圍的權限原則和組織權限。請在 `Authorization` 請求標頭中傳送 Token：`Authorization: Bearer mspat-…`。

## 為服務帳號簽發

```http
POST /api/v1/auth/tokens
```

簽發以服務帳號身分執行操作的 Token。請求本文相同，但需加上 `serviceAccountId`，且此呼叫需要 `api_tokens.issue`。與個人 Token 不同，服務帳號的 Token 可使用 API Token 簽發。若未指定 `policyId` 或 `permissions`，Token 的權限會固定為簽發當下服務帳號角色與簽發者共有的權限。角色之後新增的權限不會授予 Token；角色失去的權限則會立即對 Token 失效。

```bash
curl -X POST http://localhost:5080/api/v1/auth/tokens \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "collector-production",
    "serviceAccountId": "<service-account-id>",
    "policyId": "builtin:data_intake",
    "expiresInDays": 365
  }'
```

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `name` 為空、同時指定 `policyId` 與 `permissions`、權限清單為空、權限或原則不存在，或服務帳號已停用。 |
| `403` | 權限範圍包含簽發者不具備的權限、使用 API Token 申請個人 Token，或缺少必要權限（`personal_tokens.manage` 或 `api_tokens.issue`）。 |
| `404` | 系統範圍內沒有 API Token，或服務帳號不存在。 |
