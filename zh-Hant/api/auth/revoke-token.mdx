```http
DELETE /api/v1/auth/tokens/{id}
```

立即撤銷組織中的任一 Token。後續使用該 Token 的請求會失敗，並傳回 `401` 和訊息 `api token revoked`。此呼叫需要 `api_tokens.revoke` 權限。

**路徑參數**

| 參數 | 類型 | 說明 |
|---|---|---|
| `id` | string | 核發或列出 Token 時傳回的 `id`。 |

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/auth/tokens/3KE5hOsEc3lMC9qr9RWnPn0pqWF \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "revoked": true }
```
</ResponseExample>

如果 id 不存在，則傳回 `404`。撤銷用於傳送資料的 Token 會中斷對應傳送端的資料傳輸。請先在傳送端更換 Token。

## 撤銷自己的 Token

```http
DELETE /api/v1/me/api-tokens/{id}
```

撤銷自己的任一個人 Token 或預設接入 Token。必須在登入工作階段中呼叫，且需要 `personal_tokens.manage` 權限。如果 Token 不屬於目前登入的帳號，則傳回 `404`。
