```http
GET /api/v1/auth/tokens/rum?applicationId=<id>
```

傳回指定 [RUM 應用程式](/zh-Hant/rum/applications)的 RUM 用戶端權杖，首次呼叫時會建立該權杖。請先建立應用程式。權杖格式為 `mspat-<36>`，屬於該應用程式，而非取得權杖的使用者。權杖僅具備該應用程式的 `rum.write` 權限，無法執行其他操作，且永不過期。請將權杖嵌入瀏覽器或行動端程式碼中，終端使用者可以看到它。此呼叫需要 `api_tokens.issue` 權限。

**查詢參數**

| 參數 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `applicationId` | string | 是 | 工作區中指定應用程式的識別碼。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/auth/tokens/rum?applicationId=checkout-web" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KDZpGNwn5vO9dhXyE3am4qhihX",
  "prefix": "c16jb8m5zr",
  "token": "mspat-c16jb8m5zr<secret>",
  "tokenKind": "rum_client",
  "policyId": null,
  "permissions": ["rum.write"],
  "applicationId": "checkout-web",
  "createdAt": 1790000000000000
}
```
</ResponseExample>

若 `applicationId` 不是有效的識別碼，則傳回 `400`；若沒有任何應用程式使用該 `applicationId`，則傳回 `404`。請在 SDK 中使用相同的識別碼作為 `applicationId`，請參閱 [RUM 應用程式](/zh-Hant/rum/applications#client-token)。
