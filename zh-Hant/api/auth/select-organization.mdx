```http
POST /api/v1/orgs/{id}/select
```

將已登入的瀏覽器工作階段切換至使用者所屬的另一個組織。回應會針對該組織重寫工作階段 Cookie，工作階段的結束時間維持不變。Cookie 的詳細資訊請參閱[登入](/zh-Hant/api/auth/login)。只有工作階段可以切換，使用 API Token 時會收到 `403`。平台管理員可以選擇受保護的 `_sys` 組織；[輪替 JWT 簽署金鑰](/zh-Hant/api/auth/rotate-jwt)這類平台層級的呼叫必須在此組織中執行。切換至 `_sys` 後，工作階段最多持續一小時。

**路徑參數**

| 參數 | 類型 | 說明 |
|---|---|---|
| `id` | string | `GET /api/v1/orgs` 傳回的組織 ID。 |

<RequestExample>
```bash cURL
curl -b ms-cookies.txt -c ms-cookies.txt \
  -X POST http://localhost:5080/api/v1/orgs/<organization-id>/select
```
</RequestExample>

<ResponseExample>
```json 200
{
  "userId": "<user-id>",
  "orgId": "<organization-id>",
  "orgName": "default",
  "displayRole": "Owner",
  "roles": [
    { "id": "<role-id>", "key": "owner", "name": "Owner", "builtin": true }
  ],
  "system": false
}
```
</ResponseExample>

同一瀏覽器的分頁共用 Cookie，因此所有已開啟的分頁都會切換至所選的組織。

## 登入要求

如果這次登入未滿足組織的所有[登入要求](/zh-Hant/identity/sso#登入要求)，仍會傳回 `200`，但不會寫入新的 Cookie，並會指出尚未滿足的要求：

| 回應 | 含義 |
|---|---|
| `{"mfa": {"organization_name", "methods"}}` | 立即驗證第二因素：在要求主體中加入 `{"proof": {…}}`，再送出一次要求。`proof` 包含 `method`（`totp` 或 `recovery_code`）和 `code`；若 `method` 為 `passkey`，則包含 `ceremony` 和 `credential`，兩者皆取自 `POST /api/v1/me/mfa/passkey-proof`。 |
| `{"mfaSetup": {"organization_name"}}` | 帳號尚未設定第二因素。請先透過 `/api/v1/me/mfa` 或 `/api/v1/me/passkeys` 啟用。 |
| `{"sso": {"organization_name", "providers"}}` | 只能透過此組織的單一登入進入。`providers` 會列出 `id`、`name`、`kind` 和 `platform`。 |
