```http
POST /api/v1/saved_views
```

儲存一筆查詢及其相對時間範圍。此呼叫需要 `saved_views.create` 權限。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `name` | string | 是 | 顯示名稱。 |
| `language` | string | 是 | `sql` 或 `promql`。 |
| `statement` | string | 是 | 查詢陳述式。 |
| `timeRangeSecs` | integer | 是 | 相對時間範圍為 1 到 31,622,400 秒，超出範圍時傳回 `400`。 |
| `stream` | string | 否 | 主要資料流名稱。 |
| `tags` | array of strings | 否 | 用於篩選的標籤。 |
| `pinned` | boolean | 否 | 讓檢視排在前面。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/saved_views \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = '"'"'error'"'"'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true
  }'
```
</RequestExample>

回應會傳回建立的檢視，其結構與[列出已儲存的檢視](/zh-Hant/api/query/list-saved-views)中的檢視相同。
