```http
GET  /api/v1/query/stream
POST /api/v1/query/stream
```

一律以分塊 NDJSON（`application/x-ndjson`）回應。每一列都是以欄位名稱為鍵的 JSON 物件，最後一列是 `{"__meta__":{"scannedRows":...,"tookMs":...}}`。此端點不會將查詢轉為非同步工作。此呼叫需要 `streams.query` 權限，在系統範圍內則需要 `sys.telemetry.read` 權限。

`POST` 的請求主體與[執行查詢](/zh-Hant/api/query/execute)相同。`GET` 使用查詢參數：

| 參數 | 必填 | 說明 |
|---|---|---|
| `sql` | 是 | 查詢陳述式，未提供時傳回 `400`。 |
| `stream` | 是 | 主要資料串流的名稱。 |
| `streamType` | 否 | `logs`、`metrics`、`traces`、`profiles` 或 `extend`，預設為 `logs`。 |
| `from`、`to` | 是 | 時間範圍，單位為微秒。 |
| `limit` | 否 | 列數上限。 |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000

curl -G http://localhost:5080/api/v1/query/stream \
  -H "authorization: Bearer $MS_TOKEN" \
  --data-urlencode "sql=SELECT level, msg FROM app ORDER BY _timestamp DESC" \
  --data-urlencode "stream=app" \
  --data-urlencode "streamType=logs" \
  --data-urlencode "from=$((NOW-3600000000))" \
  --data-urlencode "to=$((NOW+60000000))" \
  --data-urlencode "limit=3"
```
</RequestExample>

<ResponseExample>
```text 200
{"level":"info","msg":"fine"}
{"level":"error","msg":"db pool exhausted"}
{"__meta__":{"scannedRows":5,"tookMs":173}}
```
</ResponseExample>

在代理伺服器上關閉回應緩衝（`proxy_buffering off`），讓每列資料一產生就送出，並允許較長的讀取時間。停止讀取即可取消串流。
