```http
POST /api/v1/folders
```

建立儀表板資料夾。此呼叫需要 `dashboards.folders.manage`。列出、編輯與刪除分別使用 `dashboards.folders.read`、`dashboards.folders.manage` 與 `dashboards.folders.delete`。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `name` | string | 是 | 資料夾名稱。 |
| `parentId` | string 或 `null` | 否 | 同一組織內上層資料夾的 id。使用 `null` 建立最上層資料夾。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/folders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"name":"Operations","parentId":null}'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7RimjJNjybioNAlf7AGyCi9T",
  "orgId": "<organization-id>",
  "name": "Operations",
  "parentId": null
}
```
</ResponseExample>

`GET /api/v1/folders` 列出資料夾。`DELETE /api/v1/folders/{id}` 傳回 `{"deleted": "<id>"}`，資料夾中仍有儀表板或子資料夾時則傳回 `409`。
