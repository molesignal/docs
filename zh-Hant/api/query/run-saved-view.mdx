```http
GET  /api/v1/saved_views/{id}
POST /api/v1/query
```

儲存的檢視存放 `language`、`statement`、`stream` 以及相對的 `timeRangeSecs`。沒有獨立的執行端點，網頁應用程式採用下列兩步流程，需要 `saved_views.read` 與 `streams.query`：

1. 使用 `GET /api/v1/saved_views/{id}` 載入檢視。
2. 計算以目前時間為終點的絕對時間範圍：`end` 是以微秒表示的目前時間，`start` 是 `end` 減去 `timeRangeSecs` 乘以 1,000,000 的結果。
3. 將儲存的 `language` 與 `statement`、算出的 `timeRange` 以及資料流傳送至[執行查詢](/zh-Hant/api/query/execute)。

<RequestExample>
```bash cURL
VIEW=$(curl -s http://localhost:5080/api/v1/saved_views/$VIEW_ID \
  -H "authorization: Bearer $MS_TOKEN")

END=$(date +%s)000000
START=$((END - $(echo "$VIEW" | jq .timeRangeSecs) * 1000000))

curl -X POST http://localhost:5080/api/v1/query \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d "{\"orgId\":\"$MS_ORG\",
       \"language\":$(echo "$VIEW" | jq .language),
       \"statement\":$(echo "$VIEW" | jq .statement),
       \"timeRange\":{\"start\":$START,\"end\":$END},
       \"stream\":{\"name\":$(echo "$VIEW" | jq .stream),\"streamType\":\"logs\"}}"
```
</RequestExample>

儲存的檢視只存放資料流名稱，不包含類型，因此請傳入檢視所屬的資料流類型。
