```http
POST /api/v1/dashboards
```

建立儀表板。請求本文將完整的儀表板模型包在 `model` 中，也可以指定 `folderId`。`uid` 在組織內必須是唯一的，否則呼叫會傳回 `409`。此呼叫需要 `dashboards.create`。

**模型的必填屬性**

| 屬性 | 說明 |
|---|---|
| `engine` | `molesignal-dashboard`。 |
| `schemaVersion` | `2`。 |
| `uid`、`title`、`tags` | 識別資訊。`uid` 和 `title` 不得為空，`tags` 是陣列。 |
| `editable`、`defaultDashboard` | 布林值。 |
| `timeSettings` | `timezone`、`defaultFrom` 和 `defaultTo`。 |
| `refreshSettings` | `mode`、`enabled`、`defaultInterval` 和 `allowedIntervals`。 |
| `variables`、`annotations`、`links`、`elements` | 陣列。空白儀表板使用空陣列。 |
| `layout` | 格線：`type`、`columns`、`rowHeight` 和 `gap`。 |

如果模型缺少必填屬性，呼叫會傳回 `400` 和 `validation_failed`，且 `issues` 會為每個缺少的屬性列出一個項目。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/dashboards \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "model": {
      "engine": "molesignal-dashboard",
      "schemaVersion": 2,
      "uid": "service-overview",
      "title": "Service overview",
      "tags": ["operations"],
      "editable": true,
      "defaultDashboard": false,
      "timeSettings": { "timezone": "browser", "defaultFrom": "now-6h", "defaultTo": "now" },
      "refreshSettings": { "mode": "interval", "enabled": true, "defaultInterval": "30s",
                           "allowedIntervals": ["off", "30s", "1m", "5m"] },
      "variables": [],
      "annotations": [],
      "links": [],
      "layout": { "type": "grid", "columns": 24, "rowHeight": 8, "gap": 8 },
      "elements": []
    },
    "folderId": null
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "3KE7XebQcmZojtDim7ZVdGVw594",
  "orgId": "<organization-id>",
  "folderId": null,
  "uid": "service-overview",
  "title": "Service overview",
  "tags": ["operations"],
  "model": { "engine": "molesignal-dashboard", "...": "..." },
  "version": 1
}
```
</ResponseExample>

建議先在編輯器中建立面板，再用 `GET /api/v1/dashboards/{id}` 匯出現有儀表板的模型做為範本。其他路由：`GET /api/v1/dashboards`，以及 `PUT` 和 `DELETE /api/v1/dashboards/{id}`。
