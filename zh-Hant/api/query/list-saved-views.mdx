```http
GET /api/v1/saved_views
```

傳回組織中儲存的檢視。加上 `?pinned=true` 只傳回已釘選的檢視。此呼叫需要 `saved_views.read` 權限。

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/saved_views?pinned=true" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3KE7RbW5ShK8cbrZZq4I4O3XUge",
    "orgId": "<organization-id>",
    "ownerUserId": "<user-id>",
    "name": "Recent errors",
    "language": "sql",
    "statement": "SELECT * FROM app WHERE level = 'error'",
    "timeRangeSecs": 3600,
    "stream": "app",
    "tags": ["operations"],
    "pinned": true,
    "createdAt": 1790000000000000,
    "updatedAt": 1790000000000000
  }
]
```
</ResponseExample>

其他路由：`GET /api/v1/saved_views/{id}` 傳回單一檢視，`DELETE /api/v1/saved_views/{id}` 傳回 `deleted`。

## 列出所有檢視或已釘選的檢視

省略 `pinned` 或設定 `pinned=false`，都不會啟用「僅限已釘選」篩選條件；`pinned=false` 不代表「僅限未釘選」。建立已釘選檢視的捷徑時，請使用 `pinned=true`。

要求會傳回目前組織中的檢視定義，不會傳回查詢結果。回應為 JSON 陣列；若沒有檢視符合篩選條件，`[]` 是有效結果。若未看到已知的檢視，請先確認憑證所屬的組織，並移除釘選篩選條件，再確認檢視是否已刪除。

## 讀取已儲存的查詢

| 欄位 | 用途 |
|---|---|
| `id` | 傳給取得詳細資料或執行查詢的 API 端點。 |
| `language`、`statement` | 已儲存的查詢語言與查詢文字。 |
| `stream` | 已儲存的資料串流情境資訊（如果有）。 |
| `timeRangeSecs` | 已儲存的時間範圍長度，以秒為單位。 |
| `tags`、`pinned` | 用於分類與導覽的中繼資料，不是查詢條件。 |
| `createdAt`、`updatedAt` | 以微秒為單位的時間戳記。 |

讀取定義不會執行查詢，也不會授予查詢底層資料的權限。具備所需權限後，請依照[執行已儲存的檢視](/zh-Hant/api/query/run-saved-view)執行查詢；如要儲存查詢，請參閱[建立已儲存的檢視](/zh-Hant/api/query/create-saved-view)；介面操作請參閱[已儲存的檢視](/zh-Hant/saved-views)。
