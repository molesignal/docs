```http
POST /api/v1/query/search_around
```

傳回緊鄰指定事件前後的事件，前後各有 24 小時的時間範圍。預設數量為 50，範圍為 1 到 1000。此呼叫需要 `streams.query` 權限，系統遙測則需要 `sys.telemetry.read` 權限。

`before` 包含時間戳記不晚於指標的事件，依時間由新到舊排列。因此，如果指定事件已儲存，就會出現在第一列。`after` 包含時間戳記晚於指標的事件，依時間由舊到新排列。資料串流不存在時，`before` 和 `after` 會傳回空結果，不會回報錯誤。

**請求本文**

| 欄位 | 類型 | 必填 | 預設值 |
|---|---|---|---|
| `eventTimestampUs` | integer | 是 | |
| `stream` | string | 是 | |
| `streamType` | string | 是 | |
| `eventFingerprint` | string | 否 | 原樣出現在 `pointer` 中。伺服器不會用這個值篩選事件。 |
| `before` | integer | 否 | 50 |
| `after` | integer | 否 | 50 |

<ResponseExample>
```json 200
{
  "pointer": { "ts": 1790000000000000, "fingerprint": null },
  "before": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1789999999500000, "..."]],
    "scannedRows": 100,
    "tookMs": 4
  },
  "after": {
    "columns": ["_timestamp", "msg"],
    "rows": [[1790000000500000, "..."]],
    "scannedRows": 100,
    "tookMs": 4
  }
}
```
</ResponseExample>
