```http
GET    /api/v1/changes
POST   /api/v1/changes
GET    /api/v1/changes/{id}
PUT    /api/v1/changes/{id}
PATCH  /api/v1/changes/{id}
DELETE /api/v1/changes/{id}
```

所有變更都保存在同一處：管線透過 [`POST /api/v1/apm/deployments`](/zh-Hant/apm/deployments#从-ci-上报发布) 上報的發布、設定變更、功能旗標、擴縮容和基礎設施變更，以及有人加在某段時間上的註解。`GET /api/v1/changes` 會連同 APM 從 Span 中首次看到的版本和告警規則的修改一起列出。其餘介面用於維護註解。

## 列出變更

| 參數 | 說明 |
|---|---|
| `from`、`to` | 時間範圍，單位為微秒。`to` 預設為目前時間，`from` 預設為 `to` 之前一天。 |
| `services` | 服務名稱，以逗號分隔。其他服務的變更不會列出；不屬於任何服務的變更（例如註解和規則修改）則照常列出。 |
| `namespace`、`environment` | 此 Namespace 或環境的上報變更和版本，以及未指明 Namespace 或環境的上報變更。 |
| `kinds` | 以逗號分隔：`deployment`、`configuration`、`feature_flag`、`scaling`、`infrastructure`、`annotation`、`version`、`rule`。不填時列出呼叫方能讀取的所有類型。 |
| `dashboardId`、`stream` | 此儀表板或日誌流的註解，以及不屬於任何儀表板或日誌流的註解。屬於其他儀表板或日誌流的註解則不列出。 |
| `limit` | 最多 500，也是預設值。 |

每種類型各自要求權限，呼叫方沒有的類型直接不列出，不會拒絕整個請求：

| 類型 | 權限（任一即可） |
|---|---|
| `deployment`、`configuration`、`feature_flag`、`scaling`、`infrastructure` | `apm.deployments.read`、`sys.telemetry.read` |
| `annotation` | `dashboards.annotations.read` |
| `version` | `apm.services.read`、`sys.telemetry.read` |
| `rule` | `alerts.rules.read` |

傳回一個清單，依時間從新到舊排序。管線上報過的版本只列一次，依上報的記錄列出。

```json
[
  {
    "id": "3KEDNEyqouYJeBDTLTMTBui7XHW",
    "kind": "deployment",
    "at": 1792316400000000,
    "service": "checkout",
    "namespace": "shop",
    "environment": "prod",
    "version": "2.0.0",
    "status": "succeeded",
    "commit": "9f2c1e7a4b3d5e6f",
    "author": "ada",
    "ciUrl": "https://ci.example.com/runs/7"
  },
  {
    "id": "3KEDP0aZ1y2b3c4d5e6f7g8h9i0",
    "kind": "annotation",
    "at": 1792312800000000,
    "end": 1792314600000000,
    "title": "Load test",
    "tags": ["test"],
    "dashboardId": "dash-1"
  }
]
```

| 欄位 | 說明 |
|---|---|
| `at`、`end` | 發生時間；`end` 是時間段註解的結束時間。單位為微秒。 |
| `service`、`namespace`、`environment`、`version` | 上報變更或版本所屬的服務。 |
| `status` | 上報變更的結果：`succeeded`、`failed` 或 `rolled_back`。 |
| `title`、`description`、`tags` | 註解或規則的標題，以及變更自帶的說明。 |
| `commit`、`repositoryUrl`、`pullRequestUrl`、`author`、`ciUrl` | 上報變更的來源。 |
| `dashboardId`、`stream` | 註解所屬的儀表板或日誌流。 |
| `ruleId` | 被修改的規則。 |

## 維護註解

`POST /api/v1/changes` 建立一則註解，需要 `dashboards.annotations.manage`：

```json
{
  "title": "Load test",
  "description": "k6, 2,000 users",
  "tags": ["test"],
  "timeStart": 1792312800000000,
  "timeEnd": 1792314600000000,
  "dashboardId": "dash-1",
  "streamName": null
}
```

`GET /api/v1/changes/{id}` 讀取一則註解，需要 `dashboards.annotations.read`。`PUT` 和 `PATCH` 修改請求中給出的欄位，`DELETE` 刪除註解，都需要 `dashboards.annotations.manage`。這些介面只作用於註解；不是本組織註解的 id 會傳回 `404`。Mole Agent 用 `create_annotation`、`update_annotation` 和 `delete_annotation` 維護註解，用 `list_changes` 列出變更。
