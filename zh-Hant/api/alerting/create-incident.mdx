```http
POST /api/v1/alerts/incidents
```

針對規則未偵測到的問題建立事件，例如客戶通報的故障。事件帶有標籤 `alert.source=manual`，以及註解 `createdBy`（呼叫者）和 `description`（說明），`ruleId` 為 `manual`。手動建立的事件不會經過警示管線。每次呼叫都會建立新事件，不會與其他事件去除重複，也不會自動復原。此呼叫需要 `alerts.incidents.create` 權限，並會記錄稽核事件 `alert.incident.created`。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `title` | string | 是 | 標題，最多 200 字。 |
| `description` | string | 否 | 說明，採用 Markdown 格式，最多 20000 字。 |
| `severity` | string | 否 | `info`、`warning`、`error`（預設）或 `critical`。 |
| `urgency` | string | 否 | 組織中某個[緊急程度](/zh-Hant/alerting/on-call#緊急度與優先順序等級)層級的鍵，例如 `high`、`low`。未指定時，依事件的升級策略決定。請參閱[緊急程度](/zh-Hant/alerting/on-call#緊急程度)。 |
| `priority` | string | 否 | 組織中的某個優先順序層級，預設為 `P1` 到 `P5`（最多可到 `P9`）。 |
| `assign` | object | 否 | 指派對象。預設為 `{"kind": "auto"}`，依[警示路由](/zh-Hant/alerting/routing)指派。`{"kind": "team", "teamId": "..."}` 採用團隊的值班策略；`{"kind": "policy", "escalationPolicyId": "..."}` 採用指定策略；`{"kind": "users", "userIds": [...]}` 直接通知同一組織內的 1 到 10 位成員，不採用升級策略。 |
| `services` | string[] | 否 | 受影響的服務，最多 20 個。 |
| `labels` | object | 否 | 標籤，最多 50 個；`alert.source` 一律為 `manual`。 |
| `declareMajor` | boolean | 否 | 同時宣告為[重大事件](/zh-Hant/alerting/major-incidents)。即使宣告失敗，仍會建立事件。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"title": "华北区客户反馈支付页打不开", "severity": "critical", "priority": "P1", "assign": {"kind": "team", "teamId": "<team-id>"}}'
```
</RequestExample>

回應會傳回已建立的事件。各欄位的說明請參閱[列出事件](/zh-Hant/api/alerting/list-incidents)。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | 缺少標題或標題過長、標籤或服務數量超過上限、`users` 的成員數不在 1 到 10 位之間，或團隊、策略或成員不屬於同一組織。 |
| `403` | 權杖缺少 `alerts.incidents.create` 權限。 |
