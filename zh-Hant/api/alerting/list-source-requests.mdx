```http
GET /api/v1/alerts/sources/{id}/requests
```

依時間由新到舊傳回單一[警示來源](/zh-Hant/alerting/sources)最近收到的請求，需要 `alerts.sources.read` 權限。每個來源保留最近 500 筆請求，最長 7 天；請求記錄儲存在處理該請求的叢集上。

**查詢參數**

| 參數 | 類型 | 說明 |
|---|---|---|
| `limit` | integer | 傳回筆數上限，範圍為 1 到 200，預設為 50。 |

| 欄位 | 說明 |
|---|---|
| `receivedAt` | 收到請求的時間（微秒）。 |
| `viaCluster` | 轉送請求的聯邦叢集；若由本叢集直接收到，則為空值。 |
| `status` | `accepted`（已處理）、`rejected`（已拒收）或 `forwarded`（已轉送至接收叢集）。 |
| `httpStatus` | 傳回給傳送端的狀態碼。 |
| `message` | 拒收或未採取任何動作的原因。 |
| `alertCount` | 請求中的警示總數。 |
| `alerts` | 每筆警示的動作、去重鍵、標題、嚴重程度、結果（請參閱[接收外部警示](/zh-Hant/api/alerting/send-alerts)）、原因和事件 ID，最多 100 筆。 |
| `bodyExcerpt` | 被拒收的請求本文開頭，最多 16 KiB。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/requests?limit=20" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>
