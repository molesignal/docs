```http
POST /api/v1/alerts/incidents/{id}/snooze
DELETE /api/v1/alerts/incidents/{id}/snooze
```

`POST` 將進行中的事件暫緩 `durationSecs` 秒。先以呼叫者的身分確認 `open` 狀態的事件。暫緩期間不傳送通知，也不升級事件；超過 `snoozedUntil` 後，事件回到 `open`，負責人會收到升級通知，`escalation.reason` 為 `snooze_ended`。再次對暫緩中的事件發出呼叫，會重設結束時間。

`DELETE` 立即結束暫緩，事件維持 `acknowledged` 狀態。兩種呼叫都需要 `alerts.incidents.acknowledge` 權限，`DELETE` 沒有請求本文。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `durationSecs` | integer | 是 | 60（1 分鐘）至 604800（7 天）。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/snooze \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"durationSecs": 3600}'
```
</RequestExample>

回應會傳回更新後的事件。各欄位的說明請參閱[列出事件](/zh-Hant/api/alerting/list-incidents)。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `durationSecs` 小於 60 或大於 604800。 |
| `403` | 權杖缺少 `alerts.incidents.acknowledge` 權限，或無權存取此事件。 |
| `404` | 事件不存在。 |
| `409` | 事件已恢復、已併入其他事件，或在更新期間持續變動；重試即可。 |
