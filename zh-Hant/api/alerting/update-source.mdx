```http
PUT /api/v1/alerts/sources/{id}
```

完整寫回[告警來源](/zh-Hant/alerting/sources)的設定需要 `alerts.sources.manage`。欄位與[新增告警來源](/zh-Hant/api/alerting/create-source)相同。類型無法變更；若提供 `kind`，其值必須與原值相同。Token 不變；若要變更，請使用[輪替 Token](/zh-Hant/api/alerting/rotate-source-token)。若未提供 `homeCluster`，接收叢集維持不變。尚未結案的事件會保留原有的升級策略和標籤。

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"name": "Production Prometheus", "enabled": false, "escalationPolicyId": "default", "severity": "error"}'
```
</RequestExample>

回應會傳回修改後的來源，不含 `token`。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | 欄位有誤，或變更了類型。 |
| `403` | Token 缺少 `alerts.sources.manage`。 |
| `404` | 來源不存在。 |
