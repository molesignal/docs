```http
GET    /api/v1/alerts/sources/{id}/mailbox
PUT    /api/v1/alerts/sources/{id}/mailbox
DELETE /api/v1/alerts/sources/{id}/mailbox
POST   /api/v1/alerts/sources/{id}/mailbox/test
```

[電子郵件來源](/zh-Hant/alerting/sources#電子郵件)讀取的 IMAP 信箱。檢視需要 `alerts.sources.read`，修改和測試連線需要 `alerts.sources.manage`。只有 `email` 類型的來源提供此功能，且只能在來源的接收叢集上設定，不會透過聯邦機制同步。執行 `PUT` 前，請先在來源中設定寄件者名單（`email.allowed_senders`）。

**`PUT` 和 `test` 的要求本文**

| 欄位 | 類型 | 說明 |
|---|---|---|
| `host` | string | 必填。主機名稱，不含通訊協定和連接埠。 |
| `port` | integer | 預設為 993。 |
| `security` | string | `tls`（預設）、`starttls` 或 `none`。 |
| `username` | string | 必填。 |
| `secret` | string | 密碼、授權碼或用戶端密鑰。回應不會傳回此值；留空則保留原值。 |
| `auth` | object | `{"kind": "password"}`（預設），或 `{"kind": "oauth2", "tokenUrl": "https://…", "clientId": "…", "scope": "…"}`：使用用戶端憑證換取權杖，再以 `XOAUTH2` 驗證。 |
| `folder` | string | 預設為 `INBOX`。 |
| `pollSecs` | integer | 讀取間隔，介於 15 至 3600，預設為 60。 |

只會連線至主機名稱當下解析出的位址，一律拒絕連線至雲端供應商的中繼資料服務位址。變更主機、帳號或資料夾時，會重設讀取進度，從下次成功連線的那一刻開始讀取。

**`GET` 和 `PUT` 的回應**（尚未設定時，`GET` 傳回 `null`）

| 欄位 | 說明 |
|---|---|
| `settings` | 上述除 `secret` 之外的設定。 |
| `secretSet` | 是否已設定 `secret`。 |
| `reading` | 已成功連線過，並持續讀取自連線後收到的所有郵件。 |
| `lastPolledAt`、`lastSuccessAt` | 上次嘗試讀取和上次成功讀取的時間（微秒）。 |
| `lastError` | 上次讀取失敗的原因；讀取成功後會清空。 |

`test` 會使用要求本文中的設定嘗試連線一次（若 `secret` 留空，則使用已儲存的值），成功時傳回 `{"ok": true, "messages": 3}`；連線失敗時傳回 `503`，並附上郵件伺服器的回應。

<RequestExample>
```bash cURL
curl -X PUT "http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/mailbox" \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"host": "imap.example.com", "username": "alerts@example.com", "secret": "<password>"}'
```
</RequestExample>
