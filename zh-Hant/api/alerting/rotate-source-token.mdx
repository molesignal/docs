```http
POST /api/v1/alerts/sources/{id}/token
```

替[告警來源](/zh-Hant/alerting/sources)更換 Token 時，需要 `alerts.sources.manage` 權限，請求主體留空。舊 Token 立即失效；如果已啟用聯邦功能，舊 Token 會在其他叢集同步後於該叢集失效。仍在使用舊 Token 的傳送端必須改用新 Token。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID/token \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

回應包含告警來源和新的 `token`，`token` 只會出現這一次。

</ResponseExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `403` | Token 缺少 `alerts.sources.manage` 權限。 |
| `404` | 來源不存在。 |
