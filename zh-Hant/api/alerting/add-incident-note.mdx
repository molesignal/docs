```http
POST /api/v1/alerts/incidents/{id}/notes
```

在事件的[時間軸](/zh-Hant/api/alerting/incident-timeline)上新增一則備註，事件可處於任何狀態。Mole Agent 讀取事件時會一併讀取最近的備註。此呼叫需要 `alerts.incidents.update` 權限。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `text` | string | 是 | 移除開頭與結尾的空白後，須有 1 到 4000 個字元。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/notes \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"text": "Rolled back the edge proxy."}'
```
</RequestExample>

回應會傳回這則備註在時間軸上的記錄。

<ResponseExample>
```json 200
{
  "id": "3KEE1aXy7pRtGd2s9Lm4Qv8bNcE",
  "orgId": "<organization-id>",
  "incidentId": "3KEDNEyqouYJeBDTLTMTBui7XHW",
  "at": 1790000300000000,
  "kind": "note",
  "actor": "<user-id>",
  "detail": {
    "text": "Rolled back the edge proxy.",
    "via": "api"
  }
}
```
</ResponseExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `text` 為空或超過 4000 個字元。 |
| `403` | 權杖缺少 `alerts.incidents.update` 權限，或無權存取此事件。 |
| `404` | 事件不存在。 |
