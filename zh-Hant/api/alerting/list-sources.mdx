```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

第一個呼叫列出組織的[警示來源](/zh-Hant/alerting/sources)，第二個呼叫傳回單一來源，第三個呼叫傳回目前叢集在聯邦中的 ID（`local`，未啟用聯邦時為空值）及接收叢集可選用的叢集。三個呼叫都需要 `alerts.sources.read` 權限。API 不會傳回權杖本身或其雜湊值。

| 欄位 | 類型 | 說明 |
|---|---|---|
| `id` | string | 來源 ID。 |
| `name` | string | 名稱。 |
| `kind` | string | `api`、`alertmanager`、`grafana`、`datadog`、`pagerduty`、`aliyun_cms`、`tencent_monitor`、`aws_cloudwatch`、`zabbix` 或 `email`。 |
| `enabled` | boolean | 停用的來源不接受警示。 |
| `escalationPolicyId` | string \| null | 此來源建立的事件所套用的升級原則；`default` 表示套用預設原則，`null` 表示不升級，只依通知原則傳送通知。 |
| `severity` | string | 警示未指定嚴重程度時使用的值。 |
| `labels` | object | 加到此來源建立的每個事件上的額外標籤。 |
| `tokenPrefix` | string | 權杖的前置詞 `mspat-<10 位>`。建立或輪替時只會傳回一次完整權杖。 |
| `homeCluster` | string | 建立事件的聯邦叢集；空值表示目前叢集。 |
| `intakePath` | string | 接收端點的路徑，所有來源都相同。 |
| `lastIntakeAt` | integer \| null | 目前叢集最近一次收到此來源請求的時間（微秒）。 |
| `createdBy`、`createdAt`、`updatedAt` | | 建立者、建立時間與最後修改時間（時間以微秒為單位）。 |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

接收叢集可選用的叢集：

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
