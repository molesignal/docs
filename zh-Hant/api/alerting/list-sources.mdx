```http
GET /api/v1/alerts/sources
GET /api/v1/alerts/sources/{id}
GET /api/v1/alerts/sources/clusters
```

第一個呼叫列出組織的[告警來源](/zh-Hant/alerting/sources)，第二個呼叫回傳單一來源，第三個呼叫回傳本叢集在聯邦裡的 ID（`local`，未開啟聯邦時為空）和接收集群可選的叢集。三個呼叫都需要 `alerts.sources.read`。介面從不回傳 Token 本身及其雜湊。

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | string | 來源 ID。 |
| `name` | string | 名稱。 |
| `kind` | string | `api`、`alertmanager`、`grafana`、`datadog`、`pagerduty`、`aliyun_cms`、`tencent_monitor`、`aws_cloudwatch`、`zabbix`、`azure_monitor`、`gcp_monitoring`、`huawei_ces` 或 `email`。 |
| `enabled` | boolean | 停用的來源會拒收告警。 |
| `escalationPolicyId` | string \| null | 其開啟的事件依哪條升級策略升級；`default` 為預設策略，`null` 不升級，只依通知策略通知。 |
| `severity` | string | 告警未帶嚴重度時使用。 |
| `labels` | object | 附加在其開啟的每個事件上的額外標籤。 |
| `tokenPrefix` | string | Token 的前綴 `mspat-<10 位>`。完整的 Token 只在新建和輪換時回傳一次。 |
| `homeCluster` | string | 開啟事件的聯邦叢集；空表示本叢集。 |
| `intakePath` | string | 接入位址的路徑，所有來源皆相同。 |
| `lastIntakeAt` | integer \| null | 本叢集最近一次收到其請求的時間（微秒）。 |
| `createdBy`、`createdAt`、`updatedAt` | | 誰在何時建立，以及最後修改時間（微秒）。 |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

接收集群可選的叢集：

```json
{
  "local": "cluster-cn-east",
  "clusters": [
    { "id": "cluster-cn-east", "name": "cluster-cn-east", "local": true },
    { "id": "cluster-eu-west", "name": "EU West", "local": false }
  ]
}
```
