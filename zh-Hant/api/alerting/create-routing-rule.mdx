```http
POST /api/v1/alerts/routing/rules
```

新增一條[路由規則](/zh-Hant/alerting/routing#路由規則)需要 `alerts.routing.manage` 權限。新規則排在最後，使用[調整順序](/zh-Hant/api/alerting/reorder-routing-rules)將規則往前移。每個組織最多可有 200 條路由規則。

| 欄位 | 類型 | 說明 |
|---|---|---|
| `name` | string | 必填，移除開頭和結尾的空白後，長度須為 1 到 128 個字元。 |
| `enabled` | boolean | 預設為 `true`。 |
| `conditions` | array | 最多 16 個條件，預設為空。`key` 的長度須為 1 到 512 個字元；`equals`、`not_equals` 和 `matches` 各接受一個值，`in` 接受 1 到 100 個值，每個值最多 512 個字元；`matches` 的正規表示式必須能編譯。 |
| `minSeverity` | string \| null | `info`、`warning`、`error` 或 `critical`，預設不限制。 |
| `origins` | array | 可從 `rule`、`external`、`synthetic` 中選擇多個值，預設為空，表示不限制。 |
| `target` | object | 必填。`{"kind": "team", "teamId": …}` 須指定此組織的團隊，`{"kind": "policy", "policyId": …}` 須指定此組織的升級策略。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/routing/rules \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"name": "Payments in production", "conditions": [{"key": "env", "operator": "equals", "values": ["prod"]}], "minSeverity": "error", "target": {"kind": "team", "teamId": "<team-id>"}}'
```
</RequestExample>

回應會傳回新增的規則，欄位請參閱[規則欄位](/zh-Hant/api/alerting/list-routing-rules#規則欄位)。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | 欄位不符規定，例如名稱為空、條件的值數量不符規定、正規表示式無法編譯、指定的團隊或策略不存在，或組織已有 200 條規則。 |
| `403` | 權杖缺少 `alerts.routing.manage` 權限。 |
| `422` | 缺少 `name` 或 `target`，或無法辨識欄位值，例如未知的 `operator`。回應為純文字。 |
