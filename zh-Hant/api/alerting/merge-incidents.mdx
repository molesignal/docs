```http
POST /api/v1/alerts/incidents/{id}/merge
```

將 `sourceIds` 中的事件併入事件 `{id}`。併入的事件會在 `mergedInto` 中記錄主事件，之後不再傳送通知、不再升級，也不再顯示於[列出事件](/zh-Hant/api/alerting/list-incidents)和洞察中；這些事件仍視為進行中，因此原規則或來源不會再為其開立新事件。主事件解決時，併入的事件也會一併解決；如果併入的事件先自行恢復，主事件的[時間軸](/zh-Hant/api/alerting/incident-timeline)會記錄這次恢復。先前併入這些事件的其他事件，也會一併改掛到主事件下。合併後無法復原。

主事件和每個要併入的事件都必須仍在進行中，且尚未併入其他事件。`sourceIds` 中的主事件 ID 和重複的 ID 會被忽略。這項呼叫需要主事件的 `alerts.incidents.escalate` 權限。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `sourceIds` | array | 是 | 要併入的 1 到 50 個事件 ID。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/merge \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"sourceIds": ["<incident-id>", "<another-incident-id>"]}'
```
</RequestExample>

回應會傳回主事件。各欄位的說明請參閱[列出事件](/zh-Hant/api/alerting/list-incidents)。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `sourceIds` 中沒有其他事件，或事件數量超過 50 個。 |
| `403` | 權杖缺少 `alerts.incidents.escalate` 權限，或無權存取這個事件。 |
| `404` | 主事件或 `sourceIds` 中的某個事件不存在。 |
| `409` | 主事件或 `sourceIds` 中的某個事件已恢復或已併入其他事件，或事件在更新期間持續變更；重試即可。 |
