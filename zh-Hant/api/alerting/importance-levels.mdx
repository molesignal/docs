```http
GET /api/v1/alerts/importance
PUT /api/v1/alerts/importance
```

`GET` 需要 `alerts.importance.read`，`PUT` 需要 `alerts.importance.manage`。兩者都會傳回組織的等級設定：

```json
{
  "levels": {
    "priorities": [
      {"priority": "P1", "name": "严重影响业务", "description": "用户无法付款"},
      {"priority": "P2", "name": "", "description": ""},
      {"priority": "P3", "name": "", "description": ""}
    ],
    "urgencies": [
      {"key": "urgent", "name": "特急", "escalates": true, "quietHours": "switch", "steps": "high", "severities": ["critical"]},
      {"key": "high", "name": "", "escalates": true, "quietHours": "switch", "steps": "high", "severities": ["error"]},
      {"key": "low", "name": "", "escalates": false, "quietHours": "block", "steps": "low", "severities": ["warning", "info"]}
    ]
  },
  "updatedBy": "3KF1...",
  "updatedAt": 1793059200000000
}
```

從未儲存過等級設定的組織會取得內建等級：`P1` 到 `P5`，以及[緊急度](/zh-Hant/alerting/on-call#緊急程度)所述的 `high` 和 `low`，`updatedBy` 為空。`PUT` 接受 `levels` 物件，完整取代等級設定，並記錄稽核事件 `alert_importance.updated`。

| 欄位 | 說明 |
|---|---|
| `priorities` | 1 到 9 級，依 `P1`、`P2`……的順序排列，不可跳號。`name` 最多 32 個字元，`description` 最多 200 個字元；名稱為空時顯示鍵名。 |
| `urgencies` | 2 到 5 級，最緊急的排在最前面。`key` 須以小寫字母開頭，只能使用小寫字母、數字和底線，最多 32 個字元；必須保留 `high` 和 `low`。`name` 最多 32 個字元；為空時使用內建名稱。 |
| `escalates` | `true` 依升級策略逐級通知；`false` 只通知第一級。 |
| `quietHours` | `switch` 依個人的 **勿擾期間仍接收高緊急度告警** 設定決定是否通知；`block` 在勿擾期間一律不通知。 |
| `steps` | 指定使用個人的哪一組步驟：`high` 或 `low`。 |
| `severities` | 策略依嚴重度決定緊急度時，對應到此等級的嚴重度；`critical`、`error`、`warning`、`info` 各自必須且只能對應到一個等級。 |

等級設定決定規則、升級策略、事件和介面可使用哪些值：在這些地方指定超出等級數量的優先順序，或指定未定義的緊急度，都會傳回 `400`。外部告警或告警管線提供的優先順序若超出等級數量，則套用最低等級；若提供組織未定義的緊急度，則捨棄該值。在通知中使用 `{{priority_name}}` 和 `{{urgency_name}}` 取得等級名稱。

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/importance \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d @levels.json
```
</RequestExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | 等級設定不符合上表的要求。 |
| `403` | Token 缺少對應權限。 |
| `422` | 欄位類型或鍵名格式不正確。 |
