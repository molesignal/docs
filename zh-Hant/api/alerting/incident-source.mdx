```http
GET /api/v1/alerts/incidents/{id}/source
```

傳回由[告警來源](/zh-Hant/alerting/sources)建立的事件在來源端的狀態，需要 `alerts.incidents.read` 權限。這類事件帶有 `alert.source=external` 標籤，`ruleId` 是來源的 ID。

| 欄位 | 說明 |
|---|---|
| `source` | 來源，欄位請參閱[列出告警來源](/zh-Hant/api/alerting/list-sources)；來源已刪除時為 `null`。 |
| `dedupKey` | 去重鍵。 |
| `lastEventAt` | 此去重鍵曾使用的最新傳送端時間（微秒），忽略早於此時間的訊息；API 類型為 `null`。 |
| `lastIntakeAt` | 最近一次收到此告警的時間（微秒）。 |
| `members` | Alertmanager 與 Grafana 通知群組中的告警，最多 100 筆：`status`（`firing` 或 `resolved`）、`labels`、`summary`、`startsAt`、`endsAt`，以及連回傳送端的 `url`；其他類型為空。 |

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/source \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `404` | 事件不存在，或並非由告警來源建立。 |
