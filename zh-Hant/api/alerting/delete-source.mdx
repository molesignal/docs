```http
DELETE /api/v1/alerts/sources/{id}
```

刪除[告警來源](/zh-Hant/alerting/sources)需要 `alerts.sources.manage`。該來源的 Token 會立即失效，最近收到的請求也會一併刪除。系統會以呼叫者的名義將該來源尚未結案的事件標記為已解決，因為來源刪除後，這些事件將無法再收到復原通知。啟用聯邦功能時，其他叢集同步這筆刪除作業後，也會將各自叢集中由該來源開啟且尚未結案的事件標記為已解決。

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/sources/$SOURCE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

成功時傳回 `200` 和文字 `deleted`。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `403` | Token 缺少 `alerts.sources.manage`。 |
| `404` | 來源不存在。 |
