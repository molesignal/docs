通知連接器為組織儲存一個通知服務供應商的憑證與傳輸設定。列出和讀取連接器需要 `notify.connectors.read`。建立、更新、測試和刪除連接器需要 `notify.connectors.manage`。

| 操作 | 端點 |
|---|---|
| 列出連接器類型 | `GET /api/v1/notify/connector-types` |
| 列出連接器 | `GET /api/v1/notify/connectors` |
| 建立連接器 | `POST /api/v1/notify/connectors` |
| 讀取連接器 | `GET /api/v1/notify/connectors/{id}` |
| 更新連接器 | `PUT /api/v1/notify/connectors/{id}` |
| 測試連接器 | `POST /api/v1/notify/connectors/{id}/test` |
| 刪除連接器 | `DELETE /api/v1/notify/connectors/{id}` |

## 連接器類型

類型清單會傳回目前執行中的後端所註冊的各類型的 `connectorType`、`capabilities` 與 `addresses`。類型包括 `email_smtp`、`lark_app`、`lark_webhook`、`slackApp`、`slack_webhook` 和 `webhook`。

```json
[
  {
    "connectorType": "slack_app",
    "capabilities": {
      "directUser": true,
      "group": true,
      "richText": true,
      "interactive": true,
      "acknowledgement": false,
      "attachments": false
    },
    "addresses": [
      {
        "field": "apiBaseUrl",
        "picker": "site",
        "choices": [
          { "key": "slack", "url": "https://slack.com/api" },
          { "key": "govslack", "url": "https://slack-gov.com/api" }
        ]
      }
    ]
  }
]
```

`addresses` 是該連接器類型設定中的服務供應商位址清單。需要手動輸入位址的類型（例如 Webhook 與 SMTP）沒有預設清單，因此會傳回空清單。

| 欄位 | 說明 |
|---|---|
| `field` | 設定中的鍵，例如 `apiBaseUrl`、`serviceUrl`、`wsUrl`。 |
| `choices` | 可用的位址，各有 `key` 與 `url`，第一個是預設值。 |
| `picker` | 有多個位址時的選擇依據：`site`（平台）或 `cloud`（雲端環境）。系統不會儲存此欄位。 |
| `byRegion` | 位址取決於所選區域（阿里雲、AWS），格式為 `https://{service}.{区域}.{domains 之一}`；`choices` 僅提供尚未選擇區域時的位址。 |

建立、更新、測試連接器或直接傳送訊息時，這些鍵只接受清單中的位址。若位址依區域而定，則只接受設定中指定區域的位址。未填寫時會使用預設值。系統會拒絕其他位址，不會將憑證傳送到其他地方。

連接器的 `config` 物件取決於連接器類型。所有 `timeoutSecs` 的預設值皆為 10，有效範圍為 1 至 60。URL 必須是絕對的 `http` 或 `https` 位址，服務供應商的位址只能從連接器類型的 `addresses` 中選取。

| `connectorType` | `config` 鍵 |
|---|---|
| `email_smtp` | `host` 與 `from`（必填）、`port`（預設為 `587`）、`username`、`password`、`tls`（`none`、預設的 `starttls` 或 `tls`）、`timeoutSecs` |
| `slackApp` | `botToken`、`clientId` 與 `clientSecret`（至少填寫 Bot Token，或同時填寫 Client ID 與 Client Secret，也可以三項都填）、`apiBaseUrl`（預設為 `https://slack.com/api`，GovSlack 為 `https://slack-gov.com/api`）、`timeoutSecs` |
| `slack_webhook` | `webhookUrl`（必填）、`timeoutSecs` |
| `lark_app` | `appId` 與 `appSecret`（必填）、`apiBaseUrl`（預設為飛書的 `https://open.feishu.cn/open-apis`，Lark 為 `https://open.larksuite.com/open-apis`）、`receiveIdType`（預設為 `open_id`，另有 `userId`、`union_id`、`email`、`chatId`）、`timeoutSecs` |
| `lark_webhook` | `webhookUrl`（必填）、`secret`、`timeoutSecs` |
| `webhook` | `url`（必填）、`method`（預設為 `post`，另有 `put`、`patch`）、`headers`、`timeoutSecs` |

如需瞭解各服務供應商及其目標，請參閱[通知管道](/zh-Hant/notification-channels)。

## 建立連接器

```http
POST /api/v1/notify/connectors
```

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `name` | string | 是 | 在組織內必須唯一。 |
| `connectorType` | string | 是 | 上述類型之一。建立後無法修改類型。 |
| `config` | object | 是 | 該類型的設定。 |
| `enabled` | boolean | 否 | 預設為 `true`。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/notify/connectors \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "name": "Operations webhook",
    "connectorType": "webhook",
    "config": {
      "url": "https://hooks.example.com/molesignal",
      "method": "post",
      "headers": { "Authorization": "Bearer <token>" },
      "timeoutSecs": 5
    }
  }'
```
</RequestExample>

<ResponseExample>
```json 201
{
  "id": "3KEDlokKjNmves95sRzL8tXpflY",
  "organizationId": "<organization-id>",
  "name": "Operations webhook",
  "connectorType": "webhook",
  "config": {
    "url": "***",
    "method": "post",
    "headers": "***",
    "timeoutSecs": 5
  },
  "capabilities": {
    "directUser": true,
    "group": true,
    "richText": true,
    "interactive": false,
    "acknowledgement": false,
    "attachments": false
  },
  "enabled": true,
  "status": "unknown",
  "lastTestedAt": null,
  "lastTestStatus": null,
  "lastTestError": null,
  "createdAt": 1790000000000000,
  "updatedAt": 1790000000000000
}
```
</ResponseExample>

MoleSignal 會加密整個 `config` 後再儲存。回應會將每個儲存憑證的鍵值替換為 `***`。這些鍵包括 `url`、`webhookUrl`、`headers`，以及所有以 `password`、`secret` 或 `token` 結尾的鍵。`host`、`from`、`timeoutSecs` 等其他鍵的值仍可讀取。

`status` 在首次測試前為 `unknown`，測試後為 `connected` 或 `error`。`lastTestStatus` 為 `success` 或 `failed`。路由會略過狀態為 `error` 的連接器，直到後續測試成功。

## 列出與讀取連接器

```http
GET /api/v1/notify/connectors
GET /api/v1/notify/connectors/{id}
```

清單會傳回上述格式的連接器陣列。`id` 不存在時會傳回 `404`。

## 更新連接器

```http
PUT /api/v1/notify/connectors/{id}
```

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `name` | string | 是 | 新名稱。 |
| `config` | object | 否 | 新設定。省略時會保留已儲存的設定。 |
| `enabled` | boolean | 否 | 預設為 `true`。省略此值會啟用連接器。 |

針對值已遮蔽的鍵，傳送 `***` 可保留已儲存的金鑰，傳送新的明文值則會取代原值：

```json
{
  "name": "Operations webhook",
  "config": {
    "url": "***",
    "method": "post",
    "headers": "***",
    "timeoutSecs": 8
  },
  "enabled": true
}
```

## 測試連接器

```http
POST /api/v1/notify/connectors/{id}/test
```

透過連接器傳送一則訊息。已停用的連接器無法執行測試。

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `targetType` | string | 是 | `directUser`、`fixed_address`、`fixed_group` 或 `webhook`。每種連接器類型只接受其中一部分，例如 `email_smtp` 接受 `directUser` 與 `fixed_address`。 |
| `target` | string | 是 | 接收目標：位址、服務供應商識別碼、群組或 URL，取決於 `targetType`。 |
| `message` | object | 否 | `title`、`text`、`markdown` 與 `html`。預設使用通用的標題與內文。 |

<ResponseExample>
```json 200
{
  "sent": true,
  "testedAt": 1790000000000000,
  "elapsedMs": 3,
  "providerMessageId": "req-1",
  "error": null
}
```
</ResponseExample>

傳送失敗時仍會傳回 `200`，`sent` 為 `false`，`error` 會提供失敗原因，例如 `unavailable: webhook request failed`。測試也會更新連接器的 `status`、`lastTestedAt`、`lastTestStatus` 與 `lastTestError`。

## 刪除連接器

```http
DELETE /api/v1/notify/connectors/{id}
```

刪除成功時會傳回 `204`，不含回應主體。使用者端點、通知政策、備援路由、排程日誌巡檢、狀態頁面或 IM 中的 Mole Agent 仍參照該連接器時，呼叫會傳回 `409`，訊息為 `notify connector is referenced by user endpoints, policies, default routes, scheduled log inspections, status pages, or Mole Agent in IM`。請先將這些參照移轉到其他連接器。

## 錯誤

| 狀態碼 | 原因 |
|---|---|
| `400` | `config` 不適用於該類型、不支援該類型（`unsupported connector type: pagerduty`）、目標與連接器不相符，或連接器已停用。 |
| `404` | 連接器不存在。 |
| `409` | 組織內已有同名連接器，或刪除時仍有項目參照該連接器。 |
| `422` | 缺少欄位或值無效，例如未知的 `targetType`。回應為純文字。 |
