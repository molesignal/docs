```http
GET /api/v1/alerts/routing/teams
```

依團隊名稱（不區分大小寫）列出組織的團隊，以及各團隊的[值班策略](/zh-Hant/alerting/routing#團隊的值班策略)和在 APM 服務目錄中負責的服務。需要 `alerts.routing.read`。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/alerts/routing/teams \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "teamId": "<team-id>",
    "name": "Payments",
    "memberCount": 4,
    "escalationPolicyId": "<policy-id>",
    "services": ["default/checkout", "default/cart"]
  }
]
```
</ResponseExample>

| 欄位 | 說明 |
|---|---|
| `teamId`、`name` | 團隊的 ID 和名稱。 |
| `memberCount` | 團隊的成員數。 |
| `escalationPolicyId` | 團隊的值班策略；`null` 表示未設定，指派給此團隊的事件會使用預設策略。 |
| `services` | 服務目錄中登記給此團隊且未封存的服務，格式為 `命名空间/服务名`。 |
