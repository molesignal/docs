```http
POST /api/v1/alerts/incidents/bulk
```

對 `ids` 中的每個事件逐一執行相同的操作。單一事件處理失敗不影響其他事件。`action` 指定要執行的操作，所需欄位列在旁邊：

| `action` | 欄位 | 操作 |
|---|---|---|
| `acknowledge` | 無 | 同[確認事件](/zh-Hant/api/alerting/ack-incident)。 |
| `resolve` | 無 | 同[解決事件](/zh-Hant/api/alerting/resolve-incident)。 |
| `snooze` | `durationSecs` | 同[暫緩事件](/zh-Hant/api/alerting/snooze-incident)。 |
| `reassign` | `to`，即[轉派事件](/zh-Hant/api/alerting/reassign-incident)的請求本文 | 同轉派事件的呼叫。 |
| `set_severity` | `severity` | 同[設定事件嚴重程度](/zh-Hant/api/alerting/set-incident-severity)。 |

此呼叫需要 `alerts.incidents.acknowledge` 權限，並依個別呼叫的規則檢查每個事件。合併不是批次操作，請使用[合併事件](/zh-Hant/api/alerting/merge-incidents)。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `ids` | array | 是 | 1 到 100 個事件 ID，重複的 ID 只計一次。 |
| `action` | string | 是 | `acknowledge`、`resolve`、`snooze`、`reassign` 或 `set_severity`。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/bulk \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"ids": ["<incident-id>", "<another-incident-id>"], "action": "snooze", "durationSecs": 3600}'
```
</RequestExample>

回應會為每個事件傳回一筆結果，包含 `id`。處理失敗時也會包含 `error`，例如事件已復原，或 `durationSecs` 超出範圍。

<ResponseExample>
```json 200
{
  "results": [
    {
      "id": "3KEDNEyqouYJeBDTLTMTBui7XHW"
    },
    {
      "id": "3KEDQ4mJ8sLp2Xv6Nc1Rt9bYwHe",
      "error": "this incident is no longer active"
    }
  ]
}
```
</ResponseExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `ids` 為空或包含超過 100 個 ID。 |
| `403` | 權杖缺少 `alerts.incidents.acknowledge` 權限。 |
| `422` | 缺少 `action`、`action` 值無法辨識，或缺少該操作所需的欄位。 |
