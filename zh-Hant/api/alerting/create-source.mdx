```http
POST /api/v1/alerts/sources
```

建立一個[告警來源](/zh-Hant/alerting/sources)，需要 `alerts.sources.manage`。回應中的 `token` 只會出現這一次，使用 Token 呼叫[接入外部告警](/zh-Hant/api/alerting/send-alerts)。啟用聯邦時，來源會同步到其他叢集。

| 欄位 | 類型 | 說明 |
|---|---|---|
| `kind` | string | 建立時必填：`api`、`alertmanager`、`grafana`、`datadog`、`pagerduty`、`aliyun_cms`、`tencent_monitor`、`aws_cloudwatch`、`zabbix`、`azure_monitor`、`gcp_monitoring`、`huawei_ces` 或 `email`。 |
| `name` | string | 必填，最多 128 個字元。 |
| `enabled` | boolean | 預設 `true`。 |
| `escalationPolicyId` | string \| null | 本組織的升級策略 ID，或 `default`。未提供或為 `null` 時不升級，只依通知策略通知。 |
| `severity` | string | 告警未帶嚴重度時使用：`critical`、`error`、`warning`（預設）或 `info`。 |
| `labels` | object | 附加標籤，最多 32 個；鍵由字母、數字和 `_ . - : /` 組成，不能以 `alert.` 開頭，也不能是 `external.kind`。 |
| `email` | object | 郵件來源如何讀取一封郵件：`allowedSenders`（完整地址、`@域名` 或 `*`）、`resolvePattern`、`dedupPattern`、`ignorePattern`，見[郵件](/zh-Hant/alerting/sources#郵件)。修改時未提供則保持不變。 |
| `homeCluster` | string | 開啟事件的聯邦叢集，須為本叢集或已啟用的遠端叢集。未提供時，新建的來源會使用本叢集；未啟用聯邦時無作用。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

回應是來源加上 `token`，其餘欄位見[列出告警來源](/zh-Hant/api/alerting/list-sources)。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | 欄位不正確，例如名稱為空、升級策略不存在、接收集群不是本叢集也不是已啟用的遠端叢集。 |
| `403` | Token 缺少 `alerts.sources.manage`。 |
