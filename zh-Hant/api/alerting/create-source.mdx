```http
POST /api/v1/alerts/sources
```

建立[告警來源](/zh-Hant/alerting/sources)需要 `alerts.sources.manage` 權限。回應中的 `token` 只會出現這一次，請使用 Token 呼叫[接收外部告警](/zh-Hant/api/alerting/send-alerts)。啟用聯邦功能後，告警來源會同步至其他叢集。

| 欄位 | 類型 | 說明 |
|---|---|---|
| `kind` | string | 建立時必填：`api`、`alertmanager`、`grafana`、`datadog`、`pagerduty`、`aliyun_cms`、`tencent_monitor`、`aws_cloudwatch`、`zabbix` 或 `email`。 |
| `name` | string | 必填，最多 128 個字元。 |
| `enabled` | boolean | 預設為 `true`。 |
| `escalationPolicyId` | string \| null | 此組織的升級策略 ID，或 `default`。省略或設為 `null` 時，不升級，只依通知策略傳送通知。 |
| `severity` | string | 告警未指定嚴重程度時使用：`critical`、`error`、`warning`（預設）或 `info`。 |
| `labels` | object | 附加標籤，最多 32 個。鍵由字母、數字和 `_ . - : /` 組成，不得以 `alert.` 開頭，也不得為 `external.kind`。 |
| `email` | object | 設定電子郵件來源如何解析郵件：`allowedSenders`（完整電子郵件地址、`@網域名稱` 或 `*`）、`resolvePattern`、`dedupPattern`、`ignorePattern`，請參閱[電子郵件](/zh-Hant/alerting/sources#電子郵件)。更新時若省略此欄位，則保留原設定。 |
| `homeCluster` | string | 建立事件的聯邦叢集，必須是本機叢集或已啟用的遠端叢集。省略時，新建立的來源會使用本機叢集。未啟用聯邦功能時，此欄位不生效。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/sources \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"kind": "alertmanager", "name": "Production Prometheus", "escalationPolicyId": "default", "labels": {"team": "payments"}}'
```
</RequestExample>

回應包含告警來源及 `token`。其餘欄位請參閱[列出告警來源](/zh-Hant/api/alerting/list-sources)。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | 欄位值無效，例如名稱為空、升級策略不存在，或接收叢集既不是本機叢集，也不是已啟用的遠端叢集。 |
| `403` | Token 缺少 `alerts.sources.manage` 權限。 |
