```http
PUT /api/v1/alerts/routing/rules/order
```

依指定順序重新排列組織的[路由規則](/zh-Hant/alerting/routing#路由規則)，需要 `alerts.routing.manage`。列出的規則依指定順序排在前面，未列出的規則則保留原有順序並排在後面；系統會忽略不屬於此組織的規則 ID。

| 欄位 | 類型 | 說明 |
|---|---|---|
| `ids` | array | 必填，規則 ID，優先比對的規則排在前面。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/rules/order \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"ids": ["<rule-id-2>", "<rule-id-1>"]}'
```
</RequestExample>

回應包含依新順序排列的所有規則，`position` 從 0 開始連續編號。欄位請參閱[規則欄位](/zh-Hant/api/alerting/list-routing-rules#規則欄位)。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `403` | 權杖缺少 `alerts.routing.manage`。 |
| `422` | 缺少 `ids`，或包含其他欄位。回應為純文字。 |
