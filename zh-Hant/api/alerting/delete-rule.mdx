```http
DELETE /api/v1/alerts/rules/{id}
```

刪除一條規則。此呼叫需要 `alerts.rules.delete`。規則已開啟的事件仍可讀取，並維持各自的生命週期。刪除規則後，該規則不再解除這些事件。

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```text 200
deleted
```
</ResponseExample>

回應主體為純文字 `deleted`。`id` 不存在時傳回 `404`。
