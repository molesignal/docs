```http
PUT /api/v1/alerts/incidents/{id}/severity
```

設定進行中事件的嚴重度，並將呼叫者記錄在 `severitySetBy`；之後評估規則時，不再變更嚴重度。調高 `open` 事件的嚴重度時，從適用於新嚴重度的第一級重新開始升級，`escalation.reason` 為 `severity_raised`；調低嚴重度或修改已確認的事件時，只變更嚴重度。此呼叫需要 `alerts.incidents.update`。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `severity` | string | 是 | `info`、`warning`、`error` 或 `critical`。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/severity \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"severity": "critical"}'
```
</RequestExample>

回應會傳回更新後的事件，各欄位的說明請參閱[列出事件](/zh-Hant/api/alerting/list-incidents)。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `422` | 缺少 `severity`，或其值不在上述四個值之中。 |
| `403` | 權杖缺少 `alerts.incidents.update` 權限，或無權存取此事件。 |
| `404` | 事件不存在。 |
| `409` | 事件已復原或已併入其他事件，或在更新期間持續變更；重試即可。 |
