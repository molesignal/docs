```http
GET /api/v1/alerts/discovery/findings
GET /api/v1/alerts/discovery/findings/{id}
```

列出[自動探索](/zh-Hant/alerting/discovery)找到的問題，最近偵測到的排在前面，或讀取單筆探索結果。需要 `alerts.discovery.read`。

**查詢參數**

| 參數 | 說明 |
|---|---|
| `status` | `open`（預設）、`ended` 或 `all`。 |
| `kind` | `apm_anomaly`、`apm_regression`、`rum_new_issue` 或 `rum_regressed_issue`。 |
| `limit` | 預設 100，最多 500。 |

**探索結果的欄位**

| 欄位 | 說明 |
|---|---|
| `kind` | 類型，同上。 |
| `key` | 用來辨識同一個問題，由類型、對象和指標組成。 |
| `severity` | `warning`、`error` 或 `critical`。 |
| `subject` | APM 服務（`命名空间/服务名`）或 RUM 應用程式 ID。 |
| `environment`、`metric` | 環境；發生突變的 APM 指標：`errorRate`、`p95`（微秒）或 `throughput`（每秒請求數）。 |
| `title` | 一句話說明。 |
| `value`、`baseline` | 目前值和比較基準值。 |
| `startedAt`、`lastSeenAt`、`endedAt` | 開始、最近一次偵測到及結束的時間（微秒）；`endedAt` 為空表示仍在進行。 |
| `missedRounds` | 連續未偵測到的輪數；達到 3 輪就結束。 |
| `detail` | APM 探索結果包含 `previous`、`lastWeek`、`version`、`previousVersion` 和時間相近的變更 `changes`；RUM 探索結果包含 `issueId`、`application`、`errorType`、`location`、`version`。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/discovery/findings?status=open" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

若要將探索結果轉成事件，請使用[建立規則](/zh-Hant/api/alerting/create-rule)建立一條 `query.discovery` 規則：`{"kinds": [...], "subjects": [...], "environments": [...], "minSeverity": "warning"}`。若不指定任何條件，就比對所有探索結果。儲存時，系統會將規則統一為固定格式：每筆符合條件的探索結果各建立一個事件，事件沿用該結果的嚴重程度；未設定 `trigger.urgency` 時，緊急程度為低。
