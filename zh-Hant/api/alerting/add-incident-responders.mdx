```http
POST /api/v1/alerts/incidents/{id}/responders
```

將 `userIds` 指定的使用者加入進行中事件的負責人名單，並向每位新加入的負責人傳送一則升級通知，`escalation.reason` 為 `responder_added`。事件狀態不變，現有負責人不會再次收到通知。此呼叫需要 `alerts.incidents.update` 權限。

**請求本文**

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `userIds` | array | 是 | 1 到 10 位組織成員的使用者 ID。 |

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/responders \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"userIds": ["<another-user-id>"]}'
```
</RequestExample>

回應會傳回更新後的事件。各欄位的說明請參閱[列出事件](/zh-Hant/api/alerting/list-incidents)。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `userIds` 為空、含有超過 10 個 ID，或含有組織外的使用者。 |
| `403` | 權杖缺少 `alerts.incidents.update` 權限，或沒有此事件的存取權限。 |
| `404` | 事件不存在。 |
| `409` | 事件已恢復、已併入其他事件，或在更新期間持續變動；重試即可。 |
