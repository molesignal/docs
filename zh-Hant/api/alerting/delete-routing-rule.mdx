```http
DELETE /api/v1/alerts/routing/rules/{id}
```

刪除一條[路由規則](/zh-Hant/alerting/routing#路由規則)需要 `alerts.routing.manage` 權限。原本會符合這條規則的新事件改由後續規則分派；已開啟的事件保留開啟時的分派結果，事件中記錄的規則名稱也不變。

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:5080/api/v1/alerts/routing/rules/$RULE_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{ "deleted": "3KF0q7vXbJ2mYc8sTn4LwRk9Ez1" }
```
</ResponseExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `403` | 權杖缺少 `alerts.routing.manage` 權限。 |
| `404` | 規則不存在，或屬於其他組織。 |
