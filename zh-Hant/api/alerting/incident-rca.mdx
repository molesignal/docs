```http
GET /api/v1/alerts/incidents/{id}/rca
POST /api/v1/alerts/incidents/{id}/rca
```

[Mole Agent](/zh-Hant/agent) 根據事件的脈絡撰寫根因分析（RCA）。每個事件最多有一份分析。

`alert` 角色會自動建立分析。當組織設定的模型服務供應商已啟用且具備 API 金鑰時，該角色每三分鐘為尚無分析的進行中事件撰寫分析，每輪最多處理 20 個事件。`GET` 呼叫會讀取已儲存的分析。`POST` 呼叫會立即產生新的分析，並取代已儲存的分析。

| 呼叫 | 權限 | 說明 |
|---|---|---|
| `GET` | `alerts.incidents.read` | 尚未產生分析時，傳回 `404`，訊息為 `no root-cause analysis for this incident yet`。 |
| `POST` | `alerts.incidents.rca` | 等待模型產生分析，再傳回新的分析。選用的查詢參數 `locale` 可指定輸出語言為 `en-us` 或 `zh-cn`，預設採用發出呼叫的使用者所設定的偏好語言。 |

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5080/api/v1/alerts/incidents/$INCIDENT_ID/rca?locale=zh-cn" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

**應變**

| 欄位 | 說明 |
|---|---|
| `incidentId`、`orgId` | 事件與組織的識別碼。 |
| `summary` | Markdown 文字格式的分析內容。 |
| `provider`、`model` | 模型服務供應商類型，例如 `openai`、`anthropic` 或 `openai_compatible`，以及模型名稱。 |
| `promptBuiltinKey`、`promptHash` | 提示詞範本與轉譯後提示詞的雜湊值，供稽核使用。 |
| `promptTokens`、`completionTokens`、`finishReason` | Token 用量，以及服務供應商回報的結束原因。 |
| `createdAt`、`updatedAt` | 自 Unix 紀元起算的微秒數。重新產生分析時，`updatedAt` 會變更。 |

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `POST` 呼叫找不到該組織已啟用且具備 API 金鑰的模型服務供應商。 |
| `403` | Token 缺少此呼叫所需的權限。 |
| `404` | 事件不存在，或 `GET` 呼叫尚未找到分析。 |
