```http
GET /api/v1/alerts/insights/oncall-load
```

統計一段時間內每人的值班負擔，依通知次數由多到少排列。此呼叫需要 `alerts.incidents.read` 權限。

通知是指送達值班人員的警示觸發通知和升級通知。每人每收到一則通知就計一次，傳送失敗不計。夜間為當地時間 22:00 至隔天 08:00，週末為當地的週六和週日。當地時間以該人員所屬排班的時區為準；未加入任何排班時，使用其[勿擾時段](/zh-Hant/account#通知設定)的時區；若未設定，則使用 UTC。凌晨收到的通知歸入前一晚。

**查詢參數**

| 參數 | 類型 | 說明 |
|---|---|---|
| `windowSecs` | integer | 往回查詢的秒數。預設為 `2592000`（30 天），範圍為 1 天至 90 天。 |
| `scheduleId` | string | 只計入此排班的成員和班次。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/alerts/insights/oncall-load?windowSecs=604800" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "windowSecs": 604800,
  "nightStartHour": 22,
  "nightEndHour": 8,
  "people": [
    {

      "interruptedNights": 2,
      "timezone": "Asia/Shanghai",
      "responded": 6,

    }

```
</ResponseExample>

**應變**

| 欄位 | 說明 |
|---|---|
| `windowSecs` | 套用範圍限制後的時間視窗。 |
| `nightStartHour`、`nightEndHour` | 夜間的開始和結束小時。 |
| `people[].oncall_secs` | 這段時間內排班值班的秒數，包含代班和換班。 |
| `people[].pages` | 收到的警示通知次數。 |
| `people[].night_pages`、`people[].weekend_pages` | 分別在夜間及週末收到的通知次數。 |
| `people[].interrupted_nights` | 夜間曾收到通知的晚數。 |
| `people[].timezone` | 判定夜間和週末所用的時區。 |
| `people[].responded`、`people[].mtta_secs` | 這段時間內由該人員最先接手的事件數，以及從觸發到接手的平均秒數。接手的判定方式與[事件洞察](/zh-Hant/api/alerting/insights)相同。 |
