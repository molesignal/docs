```http
PUT /api/v1/alerts/routing/teams/{teamId}
```

設定或移除團隊的[值班策略](/zh-Hant/alerting/routing#團隊的值班策略)需要 `alerts.routing.manage` 權限。指派給該團隊的新事件會依此策略升級；移除後則使用預設策略。

| 欄位 | 類型 | 說明 |
|---|---|---|
| `escalationPolicyId` | string \| null | 此組織的升級策略 ID；設為 `null` 或省略此欄位，即可移除團隊的值班策略。 |

<RequestExample>
```bash cURL
curl -X PUT http://localhost:5080/api/v1/alerts/routing/teams/$TEAM_ID \
  -H "authorization: Bearer $MS_TOKEN" \
  -H "content-type: application/json" \
  -d '{"escalationPolicyId": "<policy-id>"}'
```
</RequestExample>

<ResponseExample>
```json 200
{ "teamId": "<team-id>", "escalationPolicyId": "<policy-id>" }
```
</ResponseExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | 團隊不存在或屬於其他組織，或升級策略不存在。 |
| `403` | 權杖缺少 `alerts.routing.manage` 權限。 |
| `422` | 請求包含其他欄位。回應為純文字。 |
