```http
GET /api/v1/entities
GET /api/v1/entities/detail?kind={kind}&key={key}
```

實體每五分鐘從 APM 看到的執行個體，以及指標、日誌的資源欄位中讀取；欄位和鍵參見[基礎設施](/zh-Hant/infrastructure)。兩個呼叫都需要 `apm.services.read`、`metrics.read`、`logs.read` 或 `sys.telemetry.read` 其中之一。

## 列出實體

| 參數 | 說明 |
|---|---|
| `kind` | `cluster`、`node`、`host`、`pod` 或 `container`。不填表示全部類型。 |
| `search` | 名稱或鍵的一部分，不區分大小寫。 |
| `seenSince` | 只傳回此時間之後出現過的實體，單位為微秒。 |
| `limit` | 最多 500，也是預設值。 |

實體依最後出現時間倒序傳回。`services` 是直接執行在它上面的服務數。

<ResponseExample>
```json 200
[
  {
    "kind": "pod",
    "key": "prod-eu/shop/checkout-7d9f-abcde",
    "name": "checkout-7d9f-abcde",
    "attributes": {
      "k8s.cluster.name": "prod-eu",
      "k8s.namespace.name": "shop",
      "k8s.node.name": "node-3",
      "k8s.pod.name": "checkout-7d9f-abcde"
    },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000,
    "services": 1
  }
]
```
</ResponseExample>

## 讀取單一實體

`kind` 和 `key` 必填，鍵取自清單。傳回實體本身、它執行在或屬於的實體（`parents`）、執行在或屬於它的實體（`children`，最多 200 個），以及它上面和執行在它上面的實體上的服務（`services`，最多 200 個），向下查找三層：叢集的節點、節點的 Pod、Pod 上的服務。

<ResponseExample>
```json 200
{
  "entity": {
    "kind": "node",
    "key": "prod-eu/node-3",
    "name": "node-3",
    "attributes": { "k8s.cluster.name": "prod-eu", "k8s.node.name": "node-3" },
    "firstSeenAt": 1795510800000000,
    "lastSeenAt": 1795514400000000
  },
  "parents": [{ "kind": "cluster", "key": "prod-eu", "name": "prod-eu" }],
  "children": [{ "kind": "pod", "key": "prod-eu/shop/checkout-7d9f-abcde", "name": "checkout-7d9f-abcde" }],
  "services": [{ "namespace": "shop", "name": "checkout", "environment": "production" }]
}
```
</ResponseExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `kind` 不是五種類型之一。 |
| `404` | 最近一週沒有看到這個類型和鍵的實體。 |
