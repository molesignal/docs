```http
GET /api/v1/traces/service_graph
```

傳回[服務拓撲](/zh-Hant/api/web/topology)彙總的原始服務圖邊。每條邊統計一分鐘時間桶內從用戶端服務到伺服器端服務的呼叫。此呼叫需要 `traces.read`，系統範圍可使用 `sys.telemetry.read`。

**查詢參數**

| 參數 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `from` | integer | 是 | 時間視窗的起點，以 Unix 紀元起算的微秒數表示。 |
| `to` | integer | 是 | 時間視窗的終點，單位為微秒。 |
| `service` | string | 否 | 只保留以該服務作為用戶端或伺服器端的邊。 |

<RequestExample>
```bash cURL
NOW=$(date +%s)000000
curl "http://localhost:5080/api/v1/traces/service_graph?from=$((NOW-3600000000))&to=$NOW&service=checkout" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "edges": [
    {
      "id": "3KBCiQWW0TtpDu7D4pH7LMtZsRh",
      "orgId": "<organization-id>",
      "clientService": "frontend",
      "serverService": "checkout",
      "bucketAt": 1790000000000000,
      "requestCount": 12,
      "errorCount": 1,
      "p50Us": 90000,
      "p95Us": 210000,
      "p99Us": 240000
    }
  ],
  "count": 1
}
```
</ResponseExample>

**應變**

| 欄位 | 說明 |
|---|---|
| `edges[].client_service`、`edges[].server_service` | 發起呼叫的服務與被呼叫的服務。 |
| `edges[].bucketAt` | 一分鐘時間桶的起點，單位為微秒。 |
| `edges[].request_count`、`edges[].error_count` | 時間桶內的呼叫次數與失敗次數。 |
| `edges[].p50_us`、`edges[].p95_us`、`edges[].p99_us` | 時間桶內的延遲百分位數，單位為微秒。百分位數可能為 `null`。 |
| `count` | 傳回的邊數。 |

時間視窗內沒有符合條件的邊時，傳回 `{"edges": [], "count": 0}`；`to` 早於 `from` 時也一樣。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `from` 或 `to` 缺漏或不是整數。回應為純文字。 |
| `403` | 權杖缺少 `traces.read`。 |
