```http
POST /api/v1/web/investigation/blob
```

將 JSON 文件存入物件儲存，並傳回識別碼。網頁介面使用此呼叫將大型調查的調查堆疊移出頁面 URL，只在 URL 中保留識別碼。若要讀取文件，請使用[擷取調查堆疊](/zh-Hant/api/web/fetch-investigation)。此呼叫需要 `streams.query`，在系統範圍內可使用 `sys.telemetry.read`。

請求主體可以是任何不超過 1 MiB（1,048,576 位元組）的 JSON 值。文件歸呼叫端所屬的組織所有，compactor 會在 7 天後清除文件。

<RequestExample>
```bash cURL
curl -X POST http://localhost:5080/api/v1/web/investigation/blob \
  -H "authorization: Bearer $MS_TOKEN" \
  -H 'content-type: application/json' \
  -d '{
    "version": 1,
    "stack": [
      { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
      { "kind": "log", "query": "level = error" }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "blobId": "3KEZAC5JXc0P0HjrTdARfCgH1Y3"
}
```
</ResponseExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | 請求主體不是有效的 JSON（純文字），或文件超過 1 MiB（`payload exceeds 1048576 bytes`）。 |
| `403` | 權杖缺少 `streams.query`。 |
