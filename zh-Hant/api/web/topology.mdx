```http
GET /api/v1/web/topology
```

將一個時間視窗內的服務圖邊彙總為節點與邊，並提供請求速率、錯誤率和延遲。這些邊來自 MoleSignal 根據追蹤 Span 衍生的服務圖，請參閱[服務地圖](/zh-Hant/apm/service-map)。此呼叫需要 `traces.read`，系統範圍可使用 `sys.telemetry.read`。

**查詢參數**

| 參數 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `from` | string | 是 | 視窗起點，RFC 3339 時間戳記。 |
| `to` | string | 是 | 視窗終點，RFC 3339 時間戳記，不得早於 `from`。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/topology?from=2026-10-04T09:00:00Z&to=2026-10-04T10:00:00Z" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "nodes": [
    { "id": "checkout", "name": "checkout", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 },
    { "id": "frontend", "name": "frontend", "errorRate": 0.0278, "p95Ms": 90.0, "rps": 0.1, "spanCount": 360 }
  ],
  "edges": [
    { "source": "frontend", "target": "checkout", "rps": 0.1, "errRate": 0.0278, "p95Ms": 90.0 }
  ]
}
```
</ResponseExample>

**應變**

| 欄位 | 說明 |
|---|---|
| `nodes[].id`、`nodes[].name` | 服務名稱。節點依名稱排序。 |
| `nodes[].span_count` | 與該服務相連的所有邊上的請求數，不論該服務是用戶端還是伺服器端。 |
| `nodes[].error_rate`、`edges[].err_rate` | 錯誤數除以請求數，範圍為 0 到 1。 |
| `nodes[].rps`、`edges[].rps` | 請求數除以視窗長度（秒）。 |
| `nodes[].p95_ms`、`edges[].p95_ms` | 所彙總的各個時間區間中最高的 p95 延遲，單位為毫秒。這不是整個視窗的 p95。 |
| `edges[].source`、`edges[].target` | 用戶端服務與伺服器端服務。邊先依 source 排序，再依 target 排序。 |

視窗內沒有邊時，傳回空陣列。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | `from` 或 `to` 缺漏或不是 RFC 3339 時間戳記，或 `to` 早於 `from`。 |
| `403` | Token 缺少 `traces.read`。 |
