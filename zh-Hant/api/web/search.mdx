```http
GET /api/v1/web/search
```

為 **⌘K** 命令面板提供搜尋功能。此呼叫會對組織內六類實體的名稱進行模糊比對，並將最相符的結果排在前面。呼叫需要 `streams.query` 權限；在系統範圍內可使用 `sys.telemetry.read`。

**查詢參數**

| 參數 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `q` | string | 是 | 搜尋文字，最長 256 個字元。比對採用 PostgreSQL 的 trigram 相似度，因此很短的文字（例如單一字母）很少能比對到結果。`q` 為空時會傳回空清單。 |
| `types` | string | 否 | 從 `stream`、`dashboard`、`savedView`、`alert`、`incident` 和 `service` 中選取類型，並以逗號分隔。省略時會搜尋所有類型。未知的值不會比對到任何結果。 |
| `limit` | integer | 否 | 預設為 `20`。數值限於 1 到 50。 |

如果 `q` 只包含空格，且搭配 `types=stream` 使用，則不執行搜尋，而是依字母順序列出資料流。

每筆相符的結果都使用下列欄位描述實體：

| `kind` | `id` | `label` | `subtitle` |
|---|---|---|---|
| `stream` | 資料流識別碼 | 資料流名稱 | 資料流類型的內部表示，例如 `builtin.logs`。 |
| `dashboard` | 儀表板識別碼 | 標題 | 儀表板 `uid`。 |
| `savedView` | 已儲存檢視識別碼 | 名稱 | 查詢語言。 |
| `alert` | 規則識別碼 | 規則名稱 | `enabled` 或 `disabled`。 |
| `incident` | 事件識別碼 | 事件指紋 | 事件狀態。 |
| `service` | 邊的識別碼 | 服務圖中的服務名稱 | 無。 |

<RequestExample>
```bash cURL
curl "http://localhost:5080/api/v1/web/search?q=app&types=stream&limit=5" \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "items": [
    { "kind": "stream", "id": "3KDXoznFWyKPsch4ETi37U3GdxM", "label": "app", "subtitle": "builtin.logs" },
    { "kind": "stream", "id": "3JtcZGko1Q5czEBK9nBJjiFxpo1", "label": "app_logs", "subtitle": "builtin.logs" }
  ]
}
```
</ResponseExample>

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `400` | 缺少 `q`（純文字），或 `q` 超過 256 個字元（`invalid_argument`）。 |
| `403` | 權杖缺少 `streams.query` 權限。 |
