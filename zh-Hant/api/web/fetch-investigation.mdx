```http
GET /api/v1/web/investigation/blob/{id}
```

傳回[儲存調查堆疊](/zh-Hant/api/web/store-investigation)以 `blobId` 儲存的 JSON 文件。查詢僅限呼叫端所屬的組織，因此查詢其他組織的識別碼會傳回 `404`。此呼叫需要 `streams.query`，系統範圍可使用 `sys.telemetry.read`。

<RequestExample>
```bash cURL
curl http://localhost:5080/api/v1/web/investigation/blob/$BLOB_ID \
  -H "authorization: Bearer $MS_TOKEN"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "version": 1,
  "stack": [
    { "kind": "trace", "traceId": "0af7651916cd43dd8448eb211c80319c" },
    { "kind": "log", "query": "level = error" }
  ]
}
```
</ResponseExample>

回應會原樣傳回儲存的文件。若 compactor 已在 7 天後清除該文件，也會傳回 `404`。

**錯誤**

| 狀態碼 | 原因 |
|---|---|
| `403` | 權杖缺少 `streams.query`。 |
| `404` | 識別碼未知、屬於其他組織，或已過期。 |
