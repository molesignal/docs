開啟 **指標**，用 PromQL 查詢指標資料流中的時間序列。查詢會在分頁中執行，分頁可以並排顯示，**分享** 可以複製查詢的連結，與[日誌](/zh-Hant/logs#查詢分頁)相同。網址列會保留上次執行的語句，複製網址即可分享查詢。

## 尋找指標

開啟編輯器旁的 **指標瀏覽器** 或 **搜尋指標**，輸入名稱的一部分。每個指標會顯示其類型（**計數器**、**直方圖** 或 **儀表**）以及標籤數和欄位數。選取指標後會寫入查詢並立即執行。尚未有資料的工作區會提供 **連接指標資料來源**，參見[資料來源](/zh-Hant/intake)。

在資料流保留期內未再出現的指標會從清單中消失。

## 撰寫查詢

編輯器有兩種模式，用標題旁的兩個圖示切換（`</>` 是代碼，積木是查詢建構器）：

- **代碼**：直接撰寫 PromQL。**常用 PromQL 函式** 列出常用函式，[PromQL 支援矩陣](/zh-Hant/query/promql-subset)列出全部已實作的函式。
- **查詢建構器**：選取 **指標**，為每個要匹配的標籤點選 **新增標籤篩選條件**，再選取 **函式**（**原始指標**、**速率**、**瞬時速率** 或 **增量**）、**彙總**（**加總**、**平均值**、**最大值** 或 **最小值**）和 **時間視窗**。產生的 PromQL 會顯示在下方。查詢建構器無法表示的運算式（例如帶有額外參數的函式）會原樣保留，直到修改查詢建構器中的欄位。

```promql
sum by (service_name) (
  rate(http_server_request_duration_seconds_count[5m])
)
```

點選 **查詢**。**選項** 決定查詢如何執行：

| 選項 | 值 |
|---|---|
| **圖例** | **自動**、**詳細**（顯示所有標籤），或使用 `{{service}}` 這類範本的 **自訂**。 |
| **格式** | **時間序列** 或 **表格**。 |
| **步長** | **auto**（把時間範圍分成 1,000 步），或 `30s`、`5m` 這類時長。 |
| **類型** | **範圍查詢** 在時間範圍內繪製圖表，**即時查詢** 取時間範圍結尾的值。 |
| **Exemplar** | **啟用** 後繪製把資料點關聯到追蹤的 Exemplar。 |

**新增至儀表板** 會開啟一個新儀表板，並以目前查詢作為第一個面板。**清除查詢** 清除編輯器。查詢有效卻沒有結果時，可以先使用 **將時間範圍擴大為原來的 4 倍** 和 **清除篩選條件並重試**，再考慮修改運算式。

## 閱讀圖表

- 在圖上拖曳可以框選時間範圍，拖動 X 軸可以平移，按兩下可以縮小。**還原時間範圍** 回到操作圖表之前的時間範圍。
- 選取 **繪製樣式**（**折線**、**長條** 或 **點**）和 **堆疊**（**關閉**、**一般** 或 **百分比**；堆疊至少需要兩個序列）。
- 用圖例隔離或比較序列。
- **比較** 在圖上疊加同一查詢在比較時段的結果，每個序列會用自己的顏色畫成虛線。比較時段可以是之前同樣長的一段（預設）、一天前或一週前的同一時段，或自訂時間範圍。顯示比較時段時不能堆疊；點選比較時段旁的關閉按鈕即可取消。即時查詢沒有比較時段。
- 啟用 Exemplar 後，點選菱形標記查看對應的追蹤，**查看 Trace** 可以檢查該資料點背後的請求。

跳至追蹤或日誌時，會帶上框選的時間範圍。

## 分析結果

**圖表**、**表格** 和 **查詢檢查器** 分別以圖表、原始資料列和實際執行的查詢顯示結果。結果旁的各個面板有助於理解資料：

| 面板 | 顯示內容 |
|---|---|
| **序列** | 每個序列的標籤及其最後值、目前值、平均值和最大值。 |
| **查詢統計** | 序列數、資料點數、掃描資料列數、查詢耗時、時間範圍和步長。 |
| **資料品質** | 負值點、資料缺漏和時間戳記異常。Counter 出現負速率，代表它被重設、亂序抵達或類型宣告有誤：可以 **查看異常點**、**查看原始資料** 或 **檢查指標類型**。 |
| **主要標籤** | 在結果中佔比最大的標籤值。 |
| **統計摘要** | 所有序列值的分佈。 |
| **基數** | 該指標的活躍序列數以及掃描資料列數，用於找出產生過多序列的標籤。 |
| **結果 schema** | 結果中的時間欄、數值欄和標籤欄。 |

執行個體的[指標基數上限](/zh-Hant/settings/platform#指標基數)會拒絕超出上限的新序列，因此在新增取值很多的標籤之前，先查看 **基數**。

## 關聯指標尖峰

框選尖峰所在的時間視窗，保留服務和環境標籤，再開啟相關的追蹤或日誌。MoleSignal 會將選取的時間範圍帶到下一種訊號。參見[跨訊號關聯](/zh-Hant/correlation)。

## 權限

列出指標需要 `metrics.read`，執行 PromQL 需要 `streams.query`，**新增至儀表板** 需要 `dashboards.create`。
