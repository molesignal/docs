開啟 **指標**，用 PromQL 查詢指標資料流中的時間序列。查詢在分頁中執行，分頁可並排顯示。和[日誌](/zh-Hant/logs#查詢分頁)一樣，點選 **分享** 即可複製查詢連結。網址列會保留上次執行的查詢語句，複製網址即可分享查詢。

## 尋找指標

開啟編輯器旁的 **指標瀏覽器** 或 **搜尋指標**，輸入部分名稱。每個指標都會顯示類型（**計數器**、**直方圖** 或 **儀表**）、標籤數和欄位數。選取指標後，系統會將指標寫入查詢並立即執行。尚無資料的工作區會提供 **連接指標資料來源**，請參閱[資料來源](/zh-Hant/intake)。

在資料流保留期間內未再出現的指標會從清單中消失。

## 撰寫查詢

編輯器有兩種模式，可用標題旁的兩個圖示切換（`</>` 代表代碼，積木代表查詢建構器）：

- **代碼**：直接撰寫 PromQL。**常用 PromQL 函式** 列出常用函式，[PromQL 支援矩陣](/zh-Hant/query/promql-subset)列出所有已實作的函式。
- **查詢建構器**：選取 **指標**，針對每個要比對的標籤點選 **新增標籤篩選條件**，再選取 **函式**（**原始指標**、**速率**、**瞬時速率** 或 **增量**）、**彙總**（**加總**、**平均值**、**最大值** 或 **最小值**）和 **時間視窗**。產生的 PromQL 會顯示在下方。查詢建構器會原樣保留無法表示的運算式（例如含有額外參數的函式），直到變更建構器中的欄位。

```promql
sum by (service_name) (
  rate(http_server_request_duration_seconds_count[5m])
)
```

點選 **查詢**。**選項** 決定查詢的執行方式：

| 選項 | 可用值 |
|---|---|
| **圖例** | **自動**、**詳細**（顯示所有標籤），或使用 `{{service}}` 這類範本的 **自訂**。 |
| **格式** | **時間序列** 或 **表格**。 |
| **步長** | **auto**（將時間範圍分成 1,000 步），或 `30s`、`5m` 這類時間長度。 |
| **類型** | **範圍查詢** 會在指定的時間範圍內繪製圖表，**即時查詢** 則擷取時間範圍結束時的值。 |
| **Exemplar** | **啟用** 後會繪製 Exemplar，將資料點與追蹤連結起來。 |

**新增至儀表板** 會開啟新的儀表板，並將目前的查詢放在第一個面板。**清除查詢** 會清空編輯器。如果查詢有效但沒有結果，可以先使用 **將時間範圍擴大為原來的 4 倍** 和 **清除篩選條件並重試**，再考慮修改運算式。

## 閱讀圖表

- 在圖表上拖曳可框選時間範圍，拖曳 X 軸可平移，按兩下可縮小。點選 **還原時間範圍**，即可回到操作圖表前的時間範圍。
- 選取 **繪製樣式**（**折線**、**長條** 或 **點**）和 **堆疊**（**關閉**、**一般** 或 **百分比**；堆疊至少需要兩個序列）。
- 使用圖例單獨顯示或比較序列。
- 啟用 Exemplar 後，點選菱形標記即可查看對應的追蹤。點選 **查看 Trace** 可檢查該資料點對應的請求。

切換到追蹤或日誌時，系統會保留框選的時間範圍。

## 分析結果

**圖表**、**表格** 和 **查詢檢查器** 分別顯示圖表、原始資料列和實際執行的查詢。結果旁的各個面板有助於解讀資料：

| 面板 | 顯示內容 |
|---|---|
| **序列** | 每個序列的標籤，以及最後一筆值、目前值、平均值和最大值。 |
| **查詢統計** | 序列數、資料點數、掃描的資料列數、查詢耗時、時間範圍和步長。 |
| **資料品質** | 負值資料點、缺漏資料和時間戳記異常。計數器出現負速率，表示計數器曾重設、資料未依時間順序抵達，或類型宣告有誤。可 **查看異常點**、**查看原始資料** 或 **檢查指標類型**。 |
| **主要標籤** | 在結果中占比最高的標籤值。 |
| **統計摘要** | 所有序列的數值分布。 |
| **基數** | 該指標的作用中序列數及掃描的資料列數，可用來找出產生過多序列的標籤。 |
| **結果 schema** | 結果中的時間欄、數值欄和標籤欄。 |

執行個體會依照[指標基數上限](/zh-Hant/settings/platform#指標基數)拒絕超出上限的新序列，因此新增可能值很多的標籤前，請先查看 **基數**。

## 關聯指標尖峰

框選尖峰所在的時間視窗，保留服務和環境標籤，再開啟相關的追蹤或日誌。MoleSignal 會將選取的時間範圍套用到下一種訊號。請參閱[跨訊號關聯](/zh-Hant/correlation)。

## 權限

列出指標需要 `metrics.read`，執行 PromQL 需要 `streams.query`，使用 **新增至儀表板** 需要 `dashboards.create`。
