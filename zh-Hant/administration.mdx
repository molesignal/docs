MoleSignal 分為三個管理範圍，每個範圍都有各自的頁面和權限。

| 管理範圍 | 管理者 | 管理內容 | 指南 |
|---|---|---|---|
| 個人帳號 | 每位成員管理自己的帳號。 | 個人資料、偏好設定、個人通知、密碼、工作階段和所屬工作區。 | [帳號設定](/zh-Hant/account) |
| 工作區 | 組織的 Owner 和 Admin。 | 成員、角色、存取授權、Token、單一登入、工作區設定、通知、資料安全和稽核。 | [身分與存取](/zh-Hant/identity)、[設定](/zh-Hant/settings) |
| 平台 `_sys` | 超級管理員，以及取得平台角色授權的帳號。 | 組織、執行個體層級的設定、系統遙測和平台管理員。 | [平台設定](/zh-Hant/settings/platform) |

## 工作區管理

設定新工作區時，通常依序完成下列步驟：

<Steps>
  <Step title="決定成員如何加入">
    設定[註冊原則](/zh-Hant/settings/organization#註冊與存取)，並整合使用公司電子郵件網域的[單一登入](/zh-Hant/identity/sso)。
  </Step>
  <Step title="指派適當的存取權限">
    為[成員](/zh-Hant/identity/members)指派內建角色，針對範圍較小的職責建立[自訂角色](/zh-Hant/identity/roles#角色)，並將成員分成[團隊](/zh-Hant/identity/teams#團隊)，以安排值班和指定資源歸屬。
  </Step>
  <Step title="為程式提供獨立身分">
    為收集器、CI 和自動化建立[服務帳號](/zh-Hant/identity/tokens#服務帳號)，不要使用個人 Token。
  </Step>
  <Step title="設定通知">
    設定[連接器、通知原則和備援路由](/zh-Hant/notification-channels)，讓告警和報告送達相關人員。
  </Step>
  <Step title="保護資料">
    為敏感值新增[規則運算式模式與欄位遮罩](/zh-Hant/settings/data-security)，並定期檢視[稽核記錄](/zh-Hant/settings/data-security#稽核)。
  </Step>
</Steps>

## 平台管理

永久存在的 `_sys` 組織不是一般租用戶。`_sys` 中的工作階段只能存取平台權限允許的頁面和路由。超級管理員可以進入 `_sys`，在 `_sys` 的 **身分與存取 → 存取授權** 中取得平台角色授權的帳號也可以進入。請參閱[平台授權](/zh-Hant/identity#平台授權)。

| 權限 | 允許的操作 |
|---|---|
| `sys.organizations.read`、`.create`、`.update`、`.disable`、`.delete` | 列出、建立、重新命名、停用、啟用和刪除組織。除建立組織外，其他操作的授權都可以限定在單一組織。 |
| `sys.settings.retention.*`、`sys.settings.limits.*`、`sys.settings.signin.*`、`sys.settings.alerting.*`、`sys.settings.topology.*` | 檢視和修改保留期限、上限、登入、告警評估、服務拓撲圖和叢集同盟的設定。 |
| `sys.signing_keys.read`、`sys.signing_keys.rotate` | 列出和輪替用來簽署工作階段的金鑰。 |
| `sys.clusters.read`、`sys.clusters.manage` | 檢視和修改遠端叢集。 |
| `sys.nodes.read`、`sys.nodes.drain` | 檢視節點狀態，讓節點下線。 |
| `sys.query.admission.read`、`sys.query.admission.manage` | 檢視和修改查詢准入設定。 |
| `sys.telemetry.read`、`sys.telemetry.manage` | 讀取和設定 MoleSignal 本身的遙測資料。請參閱[自身可觀測性](/zh-Hant/self-observability)。 |
| `sys.trace_debug.manage` | 啟用並設定平台的追蹤偵錯功能。 |
| `sys.administrators.read`、`sys.administrators.manage` | 檢視和修改平台角色、原則和授權。 |

租用戶的工作階段和 `mspat-*` API Token 都無法存取受保護的 `_sys` 資料。
