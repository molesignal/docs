## 發行記錄與升級準備

發行說明以 [GitHub Releases](https://github.com/molesignal/molesignal/releases) 為準。下方清單會在瀏覽器中載入發行詳細資訊；即使指令碼無法執行或 GitHub 請求失敗，仍可透過該連結查看版本、發行日期、變更說明與下載附件。

### 升級前檢查

1. 使用 `molesignal --version` 記錄目前版本，並在發行說明中查找目標版本。
2. 閱讀各版本之間的相容性提示與遷移需求，區分預發行版本和正式版本。
3. 依照[備份與還原](/zh-Hant/backup-restore)保護 PostgreSQL、物件儲存、設定和加密金鑰。
4. 在隔離環境中驗證歷史資料查詢、受控的新資料匯入、權限和通知行為，再安排正式環境升級。

[正式環境檢查清單](/zh-Hant/deployment/production-checklist)和[復原準備](/zh-Hant/best-practices/recovery-readiness)提供驗收步驟。規劃中的企業功能不等於已發行的功能，實際狀態以各功能頁面和目標版本的發行說明為準。
