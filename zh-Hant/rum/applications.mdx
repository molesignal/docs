應用程式是傳送 RUM 事件的網站或 App。請在任何 SDK 傳送資料之前建立應用程式：Client Token 綁定至一個應用程式，MoleSignal 會拒絕傳送至不存在的應用程式的事件。

開啟 **使用者體驗 → 應用程式** 即可列出工作區的應用程式。建立、修改和刪除應用程式需要 `rum.applications.manage`，因為應用程式自帶 Client Token；讀取清單則需要 `rum.applications.read`。

## 建立應用程式

<Steps>
  <Step title="開啟表單">
    點選 **建立應用程式**。尚未建立應用程式的工作區會在探索頁面顯示相同的按鈕。
  </Step>
  <Step title="為應用程式命名">
    輸入最長 128 個字元且未被其他應用程式使用的 **名稱**，例如 `结账网页`，並選擇 **平台**：瀏覽器、Android、iOS、Flutter、React Native 或其他。平台只決定應用程式顯示哪種整合範例；事件以 `source` 表示來源。
  </Step>
  <Step title="指定識別碼">
    **識別碼** 是在 SDK 中設為 `applicationId` 的值。留空時會依名稱產生（例如 `checkout-web`），也可自行輸入，最長 64 個字元，可使用 `A-Z`、`a-z`、`0-9`、`.`、`_`、`:` 和 `-`。建立應用程式後，就不能再修改識別碼。
  </Step>
  <Step title="點選建立">
    系統會開啟應用程式並顯示其 Client Token。
  </Step>
</Steps>

建立應用程式時，如果工作區還沒有七個 RUM 資料流，系統也會一併建立。

## Client Token

開啟應用程式即可查看其 **Client Token**。Token 的格式為 `mspat-<36>`，永不過期，且僅對該應用程式具有 `rum.write` 權限。系統預設會遮蔽 Token，選擇 **顯示 Token** 或 **複製 Token** 即可使用。

<Warning>
  Token 會隨瀏覽器和行動端程式碼一併發布，使用者可以讀取。用戶端程式碼只能使用這個 Token，切勿使用擁有者、管理員或個人 Token。刪除應用程式會撤銷其 Token。
</Warning>

也可透過 [API](/zh-Hant/api/auth/rum-token) 取得同一個 Token。在應用程式中選擇 **開啟整合精靈**，即可開啟該平台的 **資料來源** 精靈並選取這個應用程式。精靈會提供端點、Token、已填入識別碼的 SDK 範例，以及確認是否收到資料的步驟。React Native 和「其他」沒有整合精靈，請直接使用 Token 傳送[事件](/zh-Hant/rum/events)。

## 收集

應用程式的設定決定每個事件要一併儲存哪些內容。在應用程式中修改設定後，點選 **儲存**。

| 設定 | 預設值 | 用途 |
|---|---|---|
| **儲存 IP 位址** | 開啟 | 將伺服器端解析出的用戶端位址儲存為 `network.client.ip`。如果伺服器位於 Proxy 後方，請先設定[用戶端 IP 識別](/zh-Hant/rum#代理伺服器後方的用戶端-ip)。 |
| **儲存位置** | 開啟 | 儲存依位址查得的國家、地區和城市。即使不儲存位址，系統也會執行查詢，但只儲存查詢結果。 |
| **預設隱私層級** | 遮蔽文字和輸入內容 | 整合範例為工作階段重播建議的隱私層級：**遮蔽文字和輸入內容**、**遮蔽使用者輸入** 或 **錄製顯示的所有內容**。 |

變更只會套用至之後收到的事件，不會變更已儲存的資料。

## SDK 遠端設定

設為 `remoteConfiguration: true` 的 SDK 會在啟動時讀取這些設定，因此修改設定不需要重新發布網頁。若將某個項目設為 **沿用網頁設定**，SDK 會使用網頁傳給 `init` 的值。

| 設定 | SDK 選項 |
|---|---|
| **工作階段取樣率（%）** | `sessionSampleRate` |
| **重播取樣率（%）** | `sessionReplaySampleRate` |
| **隱私權等級** | `defaultPrivacyLevel` |
| **收集點擊事件** | `trackUserInteractions` |
| **轉送主控台訊息** | `forwardConsoleLogs` |

SDK 會使用 Client Token 從 `GET /api/v1/rum/config` 讀取設定，最多等待 1.5 秒。若未收到回應，SDK 會使用網頁提供的值啟動。

## 分群

**分群** 可為工作階段群組命名，最多可建立 20 個分群，並在[分析頁面](/zh-Hant/rum/analytics#分群)將結果篩選至這些群組。每個分群最多可設五個條件，工作階段必須符合所有條件。條件可依國家、洲別或城市，瀏覽器、作業系統或裝置類型，使用者 ID 或電子郵件地址，帳號 ID，服務、版本或平台，或應用程式以 `setUser` 設定的使用者屬性（`usr.extra.plan`）來篩選。每個條件可要求符合指定值中的任一個，或不符合其中任何一個。變更會立即套用至查詢結果，也適用於已儲存的工作階段。只有在這項功能上線後開始的工作階段才會包含使用者屬性。

## 敏感資料與保留的工作階段

**敏感資料** 中的每類文字各有一個開關。伺服器端會在寫入事件前移除已開啟的類別：權杖、金鑰和密碼、電子郵件地址、電話號碼、銀行卡卡號、證件號碼，以及敏感 URL 參數的值。預設全部開啟。各類別會移除哪些內容，請參閱 [RUM 隱私](/zh-Hant/rum/privacy#在接收事件時移除敏感文字)。

**保留的工作階段** 決定應用程式要儲存哪些工作階段。**工作階段保留比例（%）** 可設為 `0` 到 `100` 的整數，應用程式會依此比例保留收到的工作階段。每個工作階段及其重播會一併完整保留或捨棄。選擇 **新增篩選器**，即可為符合條件的工作階段（例如依環境、版本、國家或瀏覽器篩選）指定個別的保留比例。若符合多個篩選器，以第一個為準；此時，未符合任何篩選器的工作階段會套用 **其餘工作階段的保留比例（%）**。**保留所有錯誤** 可讓未保留的工作階段所發生的錯誤照常儲存。顯示總數的頁面會根據保留的工作階段推估所有工作階段的總數，並標示為 **估算值**。請參閱 [RUM 資料取樣](/zh-Hant/rum/sampling#在伺服器端保留部分工作階段)。

## Issue

在 **Issue** 區段設定應用程式每小時可新增的 [issue](/zh-Hant/rum/errors#每小時新增的-issue) 數量。

| 設定 | 預設值 | 用途 |
|---|---|---|
| **每小時新增的 issue 數量** | 100 | 範圍為 1 到 10,000。超出上限後，系統會將尚未歸入任何 issue 的錯誤合併計入名為**其餘錯誤**的 issue，直到該小時結束。變更會在 30 秒內生效。 |

## 刪除應用程式

點選 **刪除應用程式** 並確認。該應用程式的 Client Token 會立即失效，MoleSignal 會拒絕使用該 Token 的 SDK 所傳送的請求。應用程式已傳送的事件會留在資料流中，直到保留期限屆滿，期間仍可在探索頁面搜尋。
