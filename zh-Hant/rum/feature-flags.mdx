將功能開關的計算結果傳給 SDK，這個檢視的每個事件都會帶上該值：

```ts
molesignalRum.addFeatureFlagEvaluation('checkout_v2', 'treatment');
```

使用功能開關服務時，請傳入該服務算出的值。LaunchDarkly 使用 inspector，OpenFeature 使用 hook：

```ts
LDClient.initialize(id, user, {
  inspectors: [{
    type: 'flag-used',
    name: 'molesignal',
    method: (key, detail) => molesignalRum.addFeatureFlagEvaluation(key, detail.value),
  }],
});

OpenFeature.addHooks({
  after: (context, details) => molesignalRum.addFeatureFlagEvaluation(context.flagKey, details.value),
});
```

## 功能開關頁面

**功能開關** 會列出這段期間內工作階段曾計算過的開關，並依計算過各開關的工作階段數由多到少排序。選取一個開關，即可並排比較各個值的指標：工作階段數、有錯誤的檢視比例，以及出現挫折訊號的檢視比例。瀏覽器應用程式還會顯示 LCP、INP、CLS 的第 75 百分位數。有錯誤的檢視比例最高的值會以紅色標示。選取 **查看這些檢視**，即可在探索頁面開啟這些檢視。

## 在任何地方依功能開關查詢

將開關名稱寫成 `feature_flags.<key>`，即可像欄位一樣使用。[探索頁面](/zh-Hant/rum/explorer)和 API 中凡是接受欄位的地方都能使用這個寫法：

```text
feature_flags.checkout_v2 = 'treatment' AND error.type = 'TypeError'
```

```http
POST /api/v1/rum/aggregate
{ "type": "views", "measures": [{ "fn": "p75", "field": "view.performance.lcp.timestamp" }], "groupBy": ["feature_flags.checkout_v2"] }
```

JSON 欄位中的其他鍵也適用相同寫法：`context.<key>`、`usr.extra.<key>`、`view.custom_timings.<key>`。`GET /api/v1/rum/keys` 會列出可用的鍵。

撰寫 SQL 時，使用 `json_text("feature_flags", 'checkout_v2')` 讀取指定鍵的值。結果為文字；如果該資料列沒有這個鍵，就會傳回 NULL。`json_keys("feature_flags")` 會列出該資料列中的鍵。

## Mole Agent

工具 `get_rum_feature_flags` 會列出功能開關。指定 `flag` 時，工具會使用相同的指標比較該開關的各個值。
