工作階段重播會先記錄完整的 DOM 快照，再依時間順序記錄增量變更。MoleSignal 會在沙箱中無法互動的播放器內重建這些事件。

重播預設停用。

## 啟用抽樣重播

```ts
const rum = init({
  applicationId: 'checkout-web',
  clientToken: 'mspat-your-client-token',
  site: 'https://molesignal.example.com',
  sessionSampleRate: 100,
  sessionReplaySampleRate: 20,
  sessionReplay: {
    blockSelector: '[data-molesignal-block]',
    maskTextSelector: '[data-molesignal-mask]',
    ignoreSelector: '[data-molesignal-ignore]',
  },
});
```

`sessionReplaySampleRate` 只對 `sessionSampleRate` 已抽樣的工作階段生效。實際抽樣率的計算方式請參閱 [RUM 資料抽樣](/zh-Hant/rum/sampling)。

## 手動開始或停止記錄

```ts
rum.startSessionReplayRecording();

// 在绝不能记录的敏感流程开始前停止。
rum.stopSessionReplayRecording();
```

手動開始記錄只適用於 `sessionSampleRate` 選取的工作階段。開始記錄時會建立新的完整 DOM 快照，確保能重建重播內容。

## 記錄的事件

Recorder 會收集：

- 完整的 DOM 快照和增量 DOM 變更；
- 指標移動和點擊；
- 捲動和檢視區變更；
- 輸入欄位互動，輸入值會遮罩；
- 樣式表狀態和可存取的行內樣式；
- rrweb 支援的媒體狀態。

預設每 5 分鐘記錄一次完整快照。使用 `checkoutInterval` 將間隔設為 30 秒至 30 分鐘：

```ts
sessionReplay: {
  checkoutInterval: 5 * 60_000,
},
```

## 隱私控制

使用預設的 `defaultPrivacyLevel: 'mask'` 時，會遮罩所有頁面文字和輸入內容。`mask-user-input` 會顯示頁面文字，但遮罩輸入內容。`allow` 也會顯示輸入內容，但密碼、電子郵件地址、電話號碼、金融卡或信用卡資料及一次性驗證碼欄位除外。在正式環境啟用重播前，請定義封鎖、遮罩和忽略選取器。

```html
<div data-molesignal-block>Payment details</div>
<span data-molesignal-mask>Customer name</span>
<canvas data-molesignal-ignore></canvas>
```

如需選取器的作用和上線檢查清單，請參閱 [RUM 隱私保護](/zh-Hant/rum/privacy)。

## 選用的高資料量收集功能

以下選項可能大幅增加傳輸資料量和儲存用量，因此預設停用：

```ts
sessionReplay: {
  collectFonts: false,
  inlineImages: false,
  recordCrossOriginIframes: false,
},
```

記錄跨來源框架也需要內嵌的應用程式配合。MoleSignal 播放器不會重播 Canvas 像素。若內容以 Canvas 為主，請優先使用 DOM 呈現內容或使用預留位置。

## 傳輸與保留

重播使用獨立的佇列，預設每 10 秒送出一次，每批 100 個事件。使用 `replayFlushInterval` 和 `replayBatchSize` 調整用戶端行為。MoleSignal 會壓縮重播片段並存入物件儲存，再依平台的資料串流預設保留期限（**設定 → 資料保留**）清除到期片段。

## 留言

重播旁的 **留言** 分頁會顯示針對重播中特定時間點的留言。留言會對應到播放器目前的時間點，並標示在時間軸上。點選留言即可跳到該時間點。

有權播放重播內容即可閱讀留言。`rum.replay.comments.write` 允許新增留言，以及編輯或刪除自己發表的留言；`rum.replay.comments.manage` 允許編輯或刪除任何留言。每個工作階段最多可有 500 則留言，每則最多 2,000 個字元。重播保留期結束時，留言也會一併刪除。

## AI 摘要與章節

在工作階段頁面選取 **產生摘要**，模型就會用幾句話說明工作階段中發生的事，並為重播內容建立章節。每個章節都有標題和開始時間。章節會標示在播放器的時間軸上，點選章節即可跳到對應時間點。

模型只會收到按時間排序的文字記錄，包括開啟的頁面、頁面上的操作、發生問題的位置，以及失敗或耗時過長的請求。模型無法查看重播內容。文字已依應用程式的規則[在接收時移除敏感文字](/zh-Hant/rum/privacy#在接收事件時移除敏感文字)，並依讀取者的權限遮罩欄位。處理較長的工作階段時，會優先保留頁面和問題資訊，再加入其餘內容，直到達到容量上限。

摘要只會在收到要求時產生，需要 `rum.replay.summaries.generate` 權限；有權播放重播內容即可閱讀摘要。MoleSignal 會使用第一個已啟用且已設定金鑰的[模型服務](/zh-Hant/agent#設定模型服務)及其預設模型。用量會計入 [Mole Agent 的每日預算](/zh-Hant/agent#用量與預算)，來源記為 `replay_summary`。每種語言各保留一份摘要，直到刪除重播內容為止。如果工作階段內容沒有變更，選取 **重新產生** 不會呼叫模型。

## 驗證重播

<Steps>
  <Step title="記錄不含敏感資料的測試流程">
    造訪多個頁面、點選控制項、捲動頁面，並觸發一次 DOM 更新。
  </Step>
  <Step title="開啟工作階段">
    前往 **使用者體驗 → 探索**，在 **工作階段** 中查詢 `session.has_replay = true`，然後開啟剛記錄的工作階段。
  </Step>
  <Step title="檢查重建結果和遮罩">
    檢查頁面結構、事件時間、播放進度控制、封鎖區域和遮罩後的值。
  </Step>
  <Step title="確認工作階段頁面的顯示內容">
    MoleSignal 收到有效的完整 DOM 快照後，工作階段頁面才會顯示重播。在此之前，頁面會顯示操作時間軸。
  </Step>
</Steps>
