探索頁按類型列出真實使用者留下的資料列。使用欄位查詢找出資料列，按時間統計數量，並直接從清單開啟任一列。開啟 **使用者體驗 → 探索**。讀取 RUM 資料需要 `rum.events.read`。

如果工作區還沒有[應用程式](/zh-Hant/rum/applications)，這裡會顯示如何建立應用程式。

## 資料列類型

標題下方的分頁決定每列代表什麼。每列呈現所屬實體的最新版本：多次回報的檢視只會出現一次，並顯示最後一次回報的計數。

| 分頁 | 每列代表 | 直方圖標示 |
|---|---|---|
| **工作階段** | 一個工作階段，根據其中的檢視得出：使用者、到達頁面、持續時間、檢視／操作／錯誤數量、瀏覽器和國家。 | 發生錯誤的工作階段 |
| **檢視** | 一次頁面瀏覽或一個介面：載入時間、Web Vitals 和計數。 | 發生錯誤的檢視 |
| **操作** | 一次點擊、輕觸或自訂操作。 | 帶有受挫訊號的操作 |
| **錯誤** | 一個錯誤：訊息、類型、來源、處理方式和堆疊。 | — |
| **資源** | 一個請求：方法、URL、狀態、耗時、大小和追蹤。 | 失敗的請求，也就是狀態為 `400` 以上（含）或 `0` 的請求 |
| **長時間工作** | 一個長動畫影格、長時間工作或凍結影格。 | — |
| **日誌** | 一筆[瀏覽器日誌](/zh-Hant/rum/logs)：層級、內容、logger 和頁面。 | `error` 層級的日誌 |

這些資料列來自真實使用者。查詢包含 `session.type`、`synthetics.*` 或 `ci_test.*` 時，也會查到[測試驅動的工作階段](/zh-Hant/rum/test-traffic)。

## 撰寫查詢

查詢編輯器預設為收合狀態。選取 **展開**，或選取 **代碼**、**查詢建構器** 圖示，即可展開。

**代碼** 接受欄位查詢：對目前類型的欄位進行比較，並用 `AND` 連接。

| 欄位查詢 | 含義 |
|---|---|
| `usr.id = 'u-42'` | 欄位正好等於這個值。 |
| `view.url_path contains 'checkout'` | 欄位包含這段文字。 |
| `browser.name != 'Safari'` | 欄位不等於這個值。 |
| `resource.duration >= 1000000000` | 可用 `=`、`!=`、`>`、`>=`、`<` 和 `<=` 比較數字。 |
| `error.issue_id = '3f9c2a71e0b4c8d1'` | 屬於某個[問題](/zh-Hant/rum/errors)的錯誤。 |
| `error.fingerprint = ''` | 空值用來查詢欄位是否沒有值；`!= ''` 則查詢欄位是否有值。 |
| `feature_flags.checkout_v2 = 'treatment'` | JSON 欄位中的索引鍵：`feature_flags`、`context`、`usr.extra` 或 `view.custom_timings`。請參閱[功能旗標](/zh-Hant/rum/feature-flags)。 |

持續時間以**奈秒**儲存，因此 `1000000000` 等於一秒。表格儲存格會以適當的單位顯示。

不屬於比較式的字詞會用來搜尋目前類型的文字欄，例如使用者、頁面、錯誤訊息和請求 URL。如果比較式指定目前類型沒有的欄位，或指定儲存整份 JSON 文件的欄位而非其中的索引鍵，探索頁會忽略該比較式，並標示為 **已忽略**。

**查詢建構器** 會將同一個查詢顯示為篩選條件。選取 **條件**，再選取欄位、比較方式和值。

選取 **執行查詢**，或在編輯器中按 `⌘ Enter` 或 `Ctrl+Enter`。選取 **重新整理** 會重新讀取結果。時間範圍位於執行按鈕旁，探索頁預設顯示最近 24 小時。

## 欄位

結果旁的 **欄位** 清單包含目前類型的所有欄位，分為三組：**顯示的欄位**，也就是表格中的欄；**索引欄位**，篩選時不必讀取每一列；以及 **其他欄位**。在 **尋找欄位** 中輸入文字即可縮小清單範圍。

- 點選欄位名稱，即可列出查詢相符的資料列中最常見的值及其數量。
- **只看此值** 和 **排除此值** 會將對應的比較式加入查詢。再次選取已篩選的值即可移除篩選條件。
- 選取欄位旁的眼睛圖示，即可在表格中加入或移除該欄位。選取 **還原預設欄位** 可重設表格。
- 選取欄位旁的加號按鈕，即可在查詢中開始為該欄位設定比較式。

## 結果與直方圖

表格每列顯示一筆結果，最新的結果排在最前，每列開頭顯示時間。有問題的資料列會在左側邊緣加上標記。可選擇每頁顯示 100、200、500、1,000、2,000 或 5,000 列，並用 **上一頁** 和 **下一頁** 切換頁面。

表格上方的直方圖會統計所選時間範圍內符合查詢的**所有**資料列，而不只是已載入的那一頁，並顯示每根柱代表多少列。拖曳選取柱子即可縮小時間範圍。選取 **隱藏直方圖** 即可關閉直方圖，系統會記住這項設定。

**下載** 會將符合查詢的資料列匯出為 CSV 檔案，最多匯出最新的 5,000 列，欄位與表格相同。瀏覽器會產生檔案，內容僅包含目前使用者有權讀取的資料，遮罩處理過的欄位在檔案中仍會保留遮罩。

## 將資料列呈現為統計數據

使用結果右上方的一排圖示，選擇如何呈現符合查詢的資料列。將游標移到圖示上即可查看各種方式的名稱。**清單** 是資料列的表格，也是預設檢視方式。其餘五種方式會統計所選時間範圍內符合查詢的**所有**資料列，而不只統計已載入的那一頁，因此與旁邊的清單採用相同的查詢範圍。

| 方式 | 呈現方式 | 可用範圍 |
|---|---|---|
| **時間序列** | 單一數值隨時間的變化。百分位數、平均值、最小值或最大值以折線呈現；計數或加總以依分組堆疊的柱呈現。 | 一個度量，最多兩層分組，最多 20 條序列 |
| **排行榜** | 依單一數值將分組排名，每組一個橫條，數值標在橫條後方。 | 一個度量，一層分組 |
| **表格** | 每個分組一列，每個度量一欄。 | 最多六個度量，最多兩層分組 |
| **圖表類型** | 在世界地圖上依數值大小為各國著色，數值越大，顏色越深。 | 一個度量；資料列依 `geo.country_iso_code` 分組 |
| **分布** | 單一數值的分布情形：每個數值區間對應一根柱，並標示第 50、75、95、99 百分位數。 | 一個數值；柱子從最小值排到第 99 百分位數，最後一根納入更大的值 |

地圖可從全球檢視放大至八倍。使用地圖角落的按鈕、滾輪或雙指捏合（以游標位置為中心）縮放，也可以按兩下放大。放大後，拖曳地圖即可移動。地圖取得焦點後，使用 `+` 和 `-` 縮放，按 `0` 顯示全球，或用方向鍵移動放大後的地圖。面積太小而看不見的國家（例如新加坡、馬爾他）會在所在位置加上標記。將游標移到國家上即可查看數值。輪廓採用 Natural Earth 的 1:10m 國家邊界，經過簡化，依中國對國界的定義呈現，不含南極洲。台灣、香港、澳門是中國的一部分：台灣以獨立區塊呈現，周圍不繪製國界線，因此可依資料列單獨著色。[合成監控](/zh-Hant/synthetics)中依地點呈現的可用性地圖也使用相同的輪廓。

選取排行榜或表格中的分組，即可將查詢限縮至該分組；再次選取即可取消。選取表格欄名可依該欄排序。伺服器會依該欄排名，因此表格會顯示該順序最前面的幾列，而不是取其他順序最前面的幾列再排序。點選時間序列圖可固定提示。選取提示中的 **Include** 或 **Exclude**，即可將查詢限縮至游標下方的序列，或排除該序列。和直方圖一樣，拖曳選取圖表中的區段可縮小時間範圍。

如果數值代表 **Largest Contentful Paint**、**Interaction to Next Paint** 或 **Cumulative Layout Shift** 的表現，圖表會分別以秒、毫秒或分數呈現，並以兩條虛線標出從良好到較差的分界（2.5 秒和 4 秒、200 毫秒和 500 毫秒、0.1 和 0.25）；排行榜和表格中的數值會依等級著色。

### 統計內容

以統計數據呈現資料列時，這些設定會顯示在結果右上方、圖示列的左側。每次修改都會立即生效。

- **度量** 是套用至欄位的函式。`count` 統計資料列數。`count_distinct` 統計欄位中有多少個不同的值，例如 `session.id` 或 `usr.id`。`sum`、`avg`、`min`、`max`、`p50`、`p75`、`p90`、`p95` 和 `p99` 使用數值欄位，百分位數為估計值。持續時間以奈秒儲存，並以適當的單位顯示。選取現有度量即可修改；選取 **度量** 可為表格新增度量。
- **分組** 依第一個欄位的值將資料列分組，**再分一層** 則依第二個欄位分組。該欄位沒有值的資料列歸入 **（無）**。度量值、時間和 JSON 文件都不能用來分組。
- **時間區間** 是時間序列中每個資料點涵蓋的時間長度。**自動** 會將範圍切成約 30 個資料點，每個資料點從頁面時鐘上該長度的整數倍處開始。只提供可將範圍切成 2 到 300 個資料點的長度。
- **取前** 決定要繪製多少個分組：時間序列為 3 到 20 個，排行榜和表格為 5 到 100 個。
- **欄位** 決定分布圖使用哪個數值。預設採用該類型最常用的欄位，例如檢視的載入時間、請求的耗時。

探索頁會統計實際保留的資料列。如果應用程式[只保留部分工作階段](/zh-Hant/rum/sampling)，顯示總數的頁面會推估所有工作階段的總數，但探索頁不會。探索頁的清單、直方圖和其他圖表都只統計實際儲存的資料列。

排行榜和表格預設依該類型最常用於排名的欄位分組：工作階段依瀏覽器分組，檢視和長時間工作依頁面分組，操作依目標分組，錯誤依錯誤類型分組，資源依主機分組。時間序列預設統計資料列數，不分組。如果統計超過時間限制，探索頁會在原本顯示圖表的位置顯示 **暫時無法使用**。縮小時間範圍或限縮查詢後，再執行一次。

網址包含視覺化方式和統計內容，因此複製網址列中的網址即可分享圖表：`viz` 為 `timeseries`、`toplist`、`table` 或 `map`（清單不設定）；`m` 是度量，例如 `count` 或 `p75:view.performance.lcp.timestamp`，每個度量各設定一次；`by` 是分組欄位，每個欄位各設定一次；`bucket` 是時間長度，例如 `5m`、`1h`；`top` 是分組數量；`sort` 和 `dir` 用於表格排序。切換類型時會保留視覺化方式，並移除 `m`、`by` 和 `sort`，因為這些設定與特定類型的欄位有關。透過 [`aggregate`](/zh-Hant/api/rum#衡量資料列) 讀取統計數值。

## 加入儀表板與新增警示

使用查詢列中的 **加入儀表板** 和 **新增警示**，可在探索頁之外使用目前畫面上的內容。探索頁讀取目前類型的欄位後，這兩個按鈕才可使用。

### 加入儀表板

**加入儀表板** 會將目前的視覺化方式製成儀表板面板，可放進 **新增儀表板**，或加到 **現有儀表板** 的既有面板下方。面板使用 SQL 讀取相同的資料列：篩選條件、搜尋字詞、度量、分組、排序和取前幾組的設定都與探索頁相同，時間範圍則由儀表板決定。和探索頁一樣，面板只統計實際儲存的資料列，檢視和工作階段各只統計一次，以最新版本為準（`rum_views_latest`、`rum_sessions_latest`）。除非查詢包含 `session.type`、`synthetics.*` 或 `ci_test.*`，否則不計入合成監控和 CI 產生的工作階段。

| 探索頁 | 儀表板面板 |
|---|---|
| **時間序列** | 時間序列圖，每個分組一條序列。計數和加總依分組堆疊成柱，其他度量以折線呈現。分組取整個時間範圍內排名最前的幾組，與探索頁相同。 |
| **排行榜** | 橫向長條圖，依第一個度量排名。 |
| **表格** | 表格，每個度量一欄。 |
| **分布** | 柱狀圖：從最小值到第 99 百分位數分成 40 個區間，最後一個區間納入更大的值，並依儀表板的時間範圍重新劃分。 |
| **清單** | 相符資料列數的時間序列，與清單上方的直方圖相同。 |
| **圖表類型** | 儀表板不支援地圖，改以橫向長條圖呈現排名前 20 的國家。 |

持續時間會換算成毫秒，其餘數值保留探索頁使用的單位。欄名與探索頁相同，例如 `p75 加载时间`。

時間序列依儀表板的 **間隔** 變數（`${interval}`）切分時間，可選 1 分鐘、5 分鐘、15 分鐘、1 小時或 1 天。新儀表板會包含這個變數，初始值最接近探索頁的柱寬。如果現有儀表板沒有這個變數，系統會在加入面板時一併新增，並在對話框中說明。新儀表板會以探索頁的時間範圍開啟（固定時間範圍除外），並加上 `rum` 標籤。

建立儀表板需要 `dashboards.create`；加入現有儀表板需要該儀表板的 `dashboards.edit`。內建的 RUM 儀表板為唯讀，無法選取。面板陳述式由 [`panel-statement`](/zh-Hant/api/rum#儀表板面板的陳述式) 產生。

### 新增警示

**新增警示** 會開啟警示規則編輯器，指標為 **[Explorer 查詢](/zh-Hant/rum/alerts#explorer-查詢)**：依探索頁的查詢篩選目前類型的資料列，並評估第一個度量。可選取 **閾值警示**，也可選取與前幾天同一時段比較的 **異常告警**。建立規則需要 `alerts.rules.manage`。

選單會先說明規則評估哪些內容，以及哪些設定不會帶入：

- 規則只評估一個數值，也就是第一個度量。其餘度量、視覺化方式、分組、排序和取前幾組的設定都不會帶入：RUM 規則不會依分組分別評估。
- **清單** 評估相符的資料列數，**分布** 評估該欄位的 p75。
- 規則只適用於一個應用程式。若查詢包含 `application.id = '…'`，則使用指定的應用程式；若工作區只有一個應用程式，則使用該應用程式；其他情況請在編輯器中選取。若查詢包含 `env = '…'`，也會自動填入環境。
- 時間範圍不會帶入。規則會依自己的時間視窗評估：5 分鐘、15 分鐘或 1 小時。

## 開啟資料列

點選一列，或使用方向鍵移到該列後按 `Enter`，即可在清單旁的抽屜中開啟資料列。配置與日誌詳細資料的抽屜相同。抽屜頂端顯示這一列的名稱、類型和發生時間。頂端下方先顯示這一列的完整內容（錯誤或日誌訊息、請求方法和 URL），接著顯示該類型的關鍵數據（例如工作階段的持續時間、檢視、操作、錯誤和受挫訊號），以及使用者和環境。有重播的工作階段會顯示 **查看重播**。下方另有兩個區塊：**欄位** 列出上方未顯示的所有欄位，可依欄位名稱或值搜尋；**JSON** 顯示整列。拖曳抽屜左側邊緣即可調整寬度。

- 按 `J` 和 `K`，或選取抽屜頂端的箭頭，即可移至清單中的下一列和上一列。頂端會顯示目前的列號和總列數。
- **開啟工作階段** 會開啟這一列所屬的工作階段，**複製這一列的 JSON** 會複製整列。
- 錯誤會優先顯示 **堆疊**。
- 瀏覽器檢視會在較寬的抽屜中開啟，並優先顯示 **載入瀑布圖**：在同一條以檢視開始時間為起點的時間軸上，呈現檢視發出的請求和阻礙檢視的長時間工作。請參閱[檢視的載入](/zh-Hant/rum/performance#檢視的載入詳情)。
- 關閉抽屜後，焦點會回到這一列。

## 開啟工作階段

從探索頁開啟的工作階段頁面包含：

- 如果工作階段錄製了 DOM 重播，則顯示 **重播播放器**，否則顯示 **操作時間軸**。重播時間尺會以紅色刻度標示每個錯誤、以橘色刻度標示每個帶有受挫訊號的操作，並以灰色刻度標示第一個頁面之後的每次頁面切換；
- 重播下方的 **開發人員工具**：**錯誤**、**網路** 和 **效能**，詳見下文；
- **使用者資訊**：使用者、裝置、位置、IP 位址、應用程式、環境、版本和持續時間；
- **頁面**：這次造訪的第一個和最後一個頁面；**發現的問題**：錯誤、當機、受挫訊號和長時間工作；
- **事件時間軸**：工作階段中所有檢視、操作、請求、錯誤和長時間工作，依發生順序排列；
- **關聯追蹤**：工作階段中有請求帶有某筆後端追蹤的 ID 時，會列出該筆追蹤（**直接關聯**）；若沒有請求帶有追蹤 ID，則列出工作階段期間執行的追蹤（**時間相關**）。每筆追蹤都可在 **追蹤** 中開啟。

如果某個工作階段的請求帶有某筆追蹤的 ID，**追蹤** 中該筆追蹤的頂端會提供 **使用者工作階段**。

工作階段頂端有 **複製此時間點的連結**，可複製從目前時間點開啟重播的網址；也有 **加入播放清單**，可將工作階段加入[播放清單](/zh-Hant/rum/playlists)。

### 開發人員工具

重播下方有三個分頁，各自顯示計數：**錯誤**、**網路** 和 **效能**。這些分頁會讀取工作階段本身的事件，並與重播同步。

- 重播目前對應的資料列（重播時間點之前最後發生的一列）左側會亮起一條線。播放或拖曳重播進度時，清單會自動捲動，讓該列保持在可見範圍內，但清單下方的頁面不會跟著捲動。
- 點選一列，重播就會跳到該時間點並暫停。時間以錄製開始後經過的分、秒表示，與進度列使用相同的時間刻度。如果工作階段沒有錄製重播，就無法同步或跳轉；時間從工作階段開始起算，資料列只會說明發生的事件。
- **錯誤** 會依發生順序列出工作階段的錯誤，包括時間、類型、訊息和該錯誤所屬的問題。可在[錯誤](/zh-Hant/rum/errors)中開啟問題。工作階段曾發生錯誤時，工具會開啟這個分頁，否則會開啟 **網路**。
- **網路** 會列出單一檢視的請求，包括時間、方法、主機和路徑、狀態、類型、耗時和大小。每列還有一個時間條，標示該請求在檢視的請求時間軸上所占的區間。使用 **檢視** 選取檢視。未選取時，會顯示重播目前所在的檢視；選取 **跟隨重播** 可回到此模式。**所有檢視** 會列出工作階段的所有請求。使用 **顯示** 可將清單限縮至較慢的請求（500 ms 以上）或失敗的請求。**瀑布圖** 會以與探索頁相同的方式呈現這個檢視的載入過程（請參閱[單次檢視的載入](/zh-Hant/rum/performance#檢視的載入詳情)）。
- **效能** 會為工作階段中的每個檢視顯示一列，列出 LCP、INP 和 CLS（以對應的評級顏色顯示），以及該檢視的請求數和長時間工作數。點選一列，即可在 **網路** 中開啟該檢視的瀑布圖。
- **日誌** 會列出頁面[寫入的日誌](/zh-Hant/rum/logs)。重播到達對應時間點時，該筆日誌會反白顯示。點選一列，重播就會跳到該時間點。
- **留言** 會顯示[針對重播特定時間點留下的留言](/zh-Hant/rum/session-replay#留言)。

網址會記錄分頁、檢視和請求的顯示方式（`tab`、`view`、`display` 和 `show`），也會記錄開啟重播的時間點（`at`，自紀元起算的微秒數）。重播會停在該時間點，直到開始播放。[受挫](/zh-Hant/rum/frustration)中的連結也會以這種方式開啟工作階段。

## 分頁、分享與網址

探索頁面使用與 **日誌** 相同的查詢分頁：可以並排開啟多個查詢、重新命名分頁並分割頁面。網址會反映畫面上的查詢，包含類型（`type`）、欄位查詢（`q`）、時間範圍（`time`），以及將資料列呈現為數字的方式（見[將資料列呈現為數字](#將資料列呈現為統計數據)）。複製網址列中的網址即可分享查詢。**分享** 會複製連結，也可選擇連結的時間範圍。

**已儲存的檢視** 會以名稱儲存畫面上的內容，方便日後開啟：類型、查詢、資料列的呈現方式，以及會隨時間移動的範圍（「最近一小時」）。系統不會儲存固定在特定時刻的時間範圍，開啟檢視時可自行選擇。檢視歸儲存時使用的帳號所有，最多可儲存 30 個，換用瀏覽器登入後仍可使用。若要分享檢視，請傳送網址。

## 探索頁面讀取哪些資料
