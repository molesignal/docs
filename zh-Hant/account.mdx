**帳號設定** 儲存個人專屬而非工作區共用的設定。點選頂端列的使用者大頭貼，再選擇 **帳號設定**、**偏好設定** 或 **通知設定** 即可開啟。每位成員都可以變更自己的帳號設定，只有 **API 權杖** 需要權限。

| 群組 | 頁面 | 用途 |
|---|---|---|
| 個人設定 | **個人資料** | 顯示名稱、大頭貼和簡短說明。 |
| | **偏好設定** | 主題、密度、時區、日期格式、起始頁和鍵盤快速鍵。 |
| | **通知設定** | 個人通知方式、傳送順序和勿擾時段。 |
| 安全性與存取 | **安全性與登入** | 重設密碼、管理已連結的登入方式。 |
| | **使用中的工作階段** | 目前瀏覽器的工作階段。 |
| | **API 權杖** | 個人 API 權杖，以所屬帳號的身分執行。 |
| 工作區 | **工作區與身分** | 所屬工作區、角色及供自動化使用的識別碼。 |

## 個人資料

| 欄位 | 規則 |
|---|---|
| **顯示名稱** | 其他成員看到的名稱。 |
| **登入電子郵件地址** | 唯讀，由管理員或身分提供者管理。 |
| **個人說明** | 選填，最多 500 個字元。 |
| 大頭貼 | 點選 **更換大頭貼**，上傳不超過 2 MB 的 PNG、JPEG 或 WebP 圖片。點選 **移除**，恢復顯示名稱的首字母大頭貼。 |

點選 **儲存變更** 以儲存個人資料。

## 偏好設定

個人偏好優先於[工作區的預設值](/zh-Hant/settings/organization#偏好設定的預設值)。仍可在查詢頁面暫時調整本次調查的時間顯示方式。

| 群組 | 欄位 | 選項 |
|---|---|---|
| 外觀 | **預設主題** | **跟隨系統**、**淺色** 或 **深色**。 |
| | **介面密度** | **舒適** 或 **緊湊**。緊湊模式會縮小表格、日誌清單、導覽和設定的列高與間距，不影響圖表、程式碼和對話。 |
| 時間與地區 | **預設時區** | **瀏覽器時區** 或指定的時區。儀表板、日誌、指標和追蹤依此時區顯示時間。 |
| | **日期與時間格式** | 日期格式為 `2026-07-27`、`2026/07/27`、`27/07/2026` 或 `07/27/2026`，時間採 **24 小時** 或 **12 小時** 制。 |
| 啟動與互動 | **進入工作區後開啟** | **首頁**、**上次瀏覽的頁面**、**儀表板**、**日誌**、**指標**、**追蹤**、**警示事件**、**AI 代理程式**，或指定的儀表板。 |
| | **啟用鍵盤快速鍵** | 開啟或關閉[全域快速鍵](/zh-Hant/console#鍵盤快速鍵)。 |

點選 **儲存設定**。如果有尚未儲存的變更，離開頁面時，系統會詢問是否捨棄變更。請在使用者選單的 **語言** 中選擇介面語言，不在此頁設定。

## 通知設定

**通知設定** 列出目前工作區可用來聯絡成員的通知方式，以及 MoleSignal 嘗試各種方式的順序。

<Steps>
  <Step title="繫結通知方式">
    點選 **繫結通知方式**。選擇管理員在[設定 → 通知 → 連接器](/zh-Hant/notification-channels)中設定的 **連接器**，再填寫 **外部身分**：電子郵件地址、IM 平台的使用者 ID，或用於語音通話和簡訊的手機號碼（以 `+` 和國碼開頭）。最後填寫 **顯示名稱**。
  </Step>
  <Step title="傳送測試">
    點選該通知方式的 **傳送測試**。收到訊息就表示連接器接受這個身分。
  </Step>
  <Step title="完成驗證">
    系統只會透過已啟用且已通過驗證的通知方式傳送通知。具備 `org.members.update` 權限的管理員確認該身分屬於這位成員後，在該通知方式上點選 **驗證**。
  </Step>
  <Step title="為各類通知選擇通知方式">
    在 **傳送偏好設定** 中，為 **警示事件**、**值班通知** 或 **報告** 開啟 **接收這類通知**，再使用 **上移端點** 和 **下移端點** 調整通知方式的順序。
  </Step>
</Steps>

**警示事件** 有兩組接收順序：**高緊急度告警的接收順序** 和 **低緊急度告警的接收順序**。系統依事件的[緊急度](/zh-Hant/alerting/on-call#緊急程度)選用其中一組。如果未設定低緊急度的接收順序，系統只會使用高緊急度順序中的第一種方式。每組從第二步起，每一步都可以設定等待分鐘數。只有等到指定時間仍無人確認警示，系統才會透過後續步驟通知該成員。若某一步的等待分鐘數與上一步相同，系統只會在上一步傳送失敗時使用該步驟。請參閱[無人確認時改用下一種方式](/zh-Hant/notification-channels#無人確認時改用下一種方式)。

開啟 **啟用勿擾模式** 後，在所選 **時區** 的 **開始** 與 **結束** 時間（`HH:MM`）之間，系統會停止向該成員傳送這類通知，之後也不會補發。勿擾期間一律不傳送低緊急度警示。開啟 **勿擾期間仍接收高緊急度告警** 時，系統仍會傳送高緊急度警示。刪除通知方式前，請先從所有傳送偏好設定中移除該方式。

如果成員已排入值班班表，卻沒有可接收警示的方式，此頁與[首頁](/zh-Hant/home)的 **我的值班** 面板都會顯示提示。請參閱[收不到警示的成員](/zh-Hant/alerting/on-call#收不到警示的成員)。

系統會先依個人接收順序嘗試傳送，再使用團隊與組織的備援路由。請參閱[通知管道與傳送](/zh-Hant/notification-channels)。

## 安全性與工作階段

**安全性與登入 → 變更密碼** 會將密碼重設連結傳送至登入電子郵件地址。連結規則請參閱[登入](/zh-Hant/console#登入)。

**已連結的登入方式** 列出可用來登入此帳號的單一登入身分，以及各身分的工作區和上次使用時間。點選 **解除連結** 後，就無法再用該身分登入此帳號。若要再次使用該身分登入，請依照[連結現有帳號](/zh-Hant/identity/sso#連結現有帳號)的步驟重新確認。沒有密碼的帳號會保留最後一個已連結的身分。

**驗證器 App** 和 **Passkey** 可在密碼之外多加一道登入驗證。Passkey 也支援免密碼登入。如需瞭解如何啟用、使用復原碼，或在遺失第二個驗證因素時恢復存取權，請參閱[多因素驗證與 Passkey](/zh-Hant/identity/mfa)。

**使用中的工作階段** 顯示目前瀏覽器的工作階段。點選 **登出目前的裝置** 會結束該工作階段。點選 **登出所有其他裝置** 會結束此帳號在其他瀏覽器和電腦上的所有登入工作階段，但目前的瀏覽器會維持登入。

**API 權杖** 列出此帳號的個人權杖。點選 **新增 Token** 即可簽發新權杖。權杖以所屬帳號的身分執行，且不會超出該帳號目前的權限。還可以透過權限範圍進一步限制權杖可執行的操作。此頁需要 `personal_tokens.manage` 權限，所有內建角色皆具備這項權限。請參閱 [API 權杖與服務帳號](/zh-Hant/identity/tokens)。

## 工作區與身分

**工作區與身分** 列出帳號所屬的工作區，以及在各工作區的角色和狀態。點選 **切換** 可變更目前的工作區。平台管理員已停用的工作區無法開啟。

**進階資訊** 顯示目前工作區的 **使用者 ID**、**組織 ID** 和 **組織識別碼**，皆可點選 **複製**。指令碼、API 呼叫和資源路徑會用到這些資訊。
