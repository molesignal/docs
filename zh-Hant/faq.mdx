## 一般

### MoleSignal 是什麼？

MoleSignal 是開放原始碼、可完全自行託管的可觀測性與事件應變平台。遙測、警報、值班、狀態頁面和 AI 調查都整合在同一套系統中。MoleSignal 將日誌、指標、追蹤和 Profile 以 Parquet 檔案的形式存放在物件儲存中，並使用 SQL 和相容於 PromQL 的查詢來擷取資料。請參閱[核心概念](/zh-Hant/concepts)。

### 適用哪種授權？

MoleSignal 是採用 Apache License 2.0 的開放原始碼軟體。請參閱[開放原始碼版](/zh-Hant/editions/open-source)。

### 有託管版本嗎？

MoleSignal Cloud 是託管版本。詳情請參閱 [molesignal.com/cloud](https://www.molesignal.com/cloud)。

### 部署需要哪些服務？

需要 PostgreSQL 與物件儲存。單一節點部署和開發環境可以使用 `local` 物件後端取代物件儲存。不需要 Kafka、Redis 或共識服務。請參閱[部署 MoleSignal](/zh-Hant/deployment)。

### 中繼資料儲存在哪個資料庫？

PostgreSQL。將 `[meta_database].dsn` 設為 PostgreSQL 的連線字串。請參閱[設定](/zh-Hant/configuration#中繼資料庫)。

### 可以不使用容器執行嗎？

可以。MoleSignal 以單一二進位檔提供。[部署指南](/zh-Hant/deployment)涵蓋 Docker Compose、搭配 systemd 的二進位檔部署，以及 Kubernetes。

## 資料

### 資料存放在哪裡？

日誌、指標和追蹤以 Parquet 檔案的形式存放在物件儲存中。PostgreSQL 儲存中繼資料、身分、檔案目錄與產品資源。尚未寫入 Parquet 檔案的記錄會保存在物件儲存的預寫式日誌（WAL）物件中。即使節點或其磁碟遺失，也不會遺失已確認的資料。請參閱[備份與還原](/zh-Hant/backup-restore)。

### 資料保留多久？

預設為 30 天。在 `_sys` 組織的 **設定 → 資料保留** 中設定預設值，也可以個別設定每個資料串流的保留期限。請參閱[資料串流](/zh-Hant/streams)。

### 哪些通訊協定可用來匯入資料？

支援 OTLP over HTTP 與 gRPC、Prometheus `remote_write`、Elasticsearch `_bulk` 通訊協定、JSON 格式的 Loki push、原生 JSON over HTTP，以及透過 Kinesis Firehose、Cloudflare Logpush 與 Heroku 傳送日誌。請參閱[資料來源](/zh-Hant/intake)。

### 為什麼記錄出現在錯誤的時間？

`_timestamp` 是自 Unix 紀元起算的微秒數。使用秒、毫秒或奈秒表示的值會使記錄出現在錯誤的時間。請參閱[疑難排解](/zh-Hant/troubleshooting#資料缺失或異常)。

### 如何使用 SQL 用戶端查詢？

啟用 `[flight_sql]`，並在 DBeaver、JDBC 或 ADBC 用戶端使用 API 權杖連線至 `5083` 連接埠。請參閱[使用資料庫用戶端連線](/zh-Hant/query/database-clients)。

### Grafana 可以讀取 MoleSignal 的資料嗎？

可以。MoleSignal 資料來源外掛程式可在儀表板、Explore 和警報規則中使用 PromQL 讀取指標、使用欄位查詢讀取日誌和追蹤，或使用 SQL 讀取任何資料串流。請參閱[在 Grafana 中查詢](/zh-Hant/query/grafana)。

## 帳號與安全性

### 如何首次登入？

全新部署會依據 `[auth].root_email` 與 `[auth].root_password` 建立 root 帳號。範例設定使用 `admin@example.com` 和 `admin`，請在實際使用前修改這兩項設定。請參閱[正式環境檢查清單](/zh-Hant/deployment/production-checklist)。

### 忘記密碼時，如何重設？

使用登入頁面上的密碼重設連結。MoleSignal 會透過電子郵件傳送該連結，因此必須設定 `[notify.smtp]` 與 `[http].external_url`。

### 登入時顯示嘗試次數過多，該怎麼辦？

等候提示所示的時間結束，或改用通行金鑰、單一登入，也可以重設密碼。如果所有使用者都無法登入，請檢查[用戶端 IP 識別](/zh-Hant/settings/platform#用戶端-ip-識別)：未設定代理伺服器時，系統會將所有使用者視為來自同一個位址。嘗試次數和等候時間請參閱[登入速率限制](/zh-Hant/settings/platform#登入速率限制)。

### 支援單一登入嗎？

支援。在網頁介面的 **身分與存取 → SSO 服務提供者** 中設定 Google、Microsoft、GitHub、飛書等預先設定的平台，以及 OIDC、OAuth 2.0、SAML 與 LDAP 服務提供者。MoleSignal 會將這些設定儲存在 PostgreSQL 中。請參閱[身分與存取](/zh-Hant/identity)。

### `MS_CIPHER_KEY` 保護哪些資料？

這是用來保護 MoleSignal 儲存在 PostgreSQL 中的密文的根金鑰，例如 API 權杖、通知連接器的認證資訊與 Mole Agent 服務提供者的金鑰。請備份此金鑰，並參閱[正式環境檢查清單](/zh-Hant/deployment/production-checklist)。

## 維運

### 如何擴充部署？

先從單一 `standalone` 節點開始。若要獨立調整資料匯入、查詢與背景工作的規模，請將角色拆分至多個程序：`router` 角色提供網頁介面與 API，將寫入要求轉送至 `intake` 節點，並將查詢交給 `querier` 節點。請參閱[依角色部署](/zh-Hant/deployment/role-based)與[已知限制](/zh-Hant/limitations)。

### 如何查看目前執行的版本？

執行 `molesignal --version`，或使用 Bearer 權杖呼叫 `GET /api/v1/version`。

### 在哪裡取得協助或回報問題？

請參閱[支援與社群](/zh-Hant/support)。請透過該頁列出的管道私下回報安全性問題。
