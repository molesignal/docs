MoleSignal 的每個頁面都採用相同的版面：頂端列（選單涵蓋所有產品區域）和內容區。本頁說明共用的控制項，各產品區域的頁面則在本手冊的其他章節說明。

## 登入

開啟 MoleSignal 執行個體的網址，使用下列任一方式登入：

| 方式 | 操作 |
|---|---|
| 電子郵件與密碼 | 點選 **使用電子郵件登入**，輸入電子郵件地址後點選 **繼續**，再輸入密碼。沒有其他登入方式時，頁面會直接要求輸入電子郵件地址。 |
| 單一登入 | 點選已啟用的服務提供者所在列。使用 LDAP 服務提供者時，點選後依序輸入目錄使用者名稱和密碼。請參閱[單一登入](/zh-Hant/identity/sso)。 |
| 通行金鑰 | 點選 **使用通行金鑰繼續**。請參閱[多因素驗證](/zh-Hant/identity/mfa)。 |
| 註冊 | 只有執行個體允許自行註冊時，才會顯示 **註冊 →**。如果執行個體可以寄信，請先輸入電子郵件地址，開啟郵件中的連結後再填寫姓名和密碼。連結會在 30 分鐘後失效，新帳號可立即登入或須等待管理員核准。如果執行個體無法寄信，請一次填寫電子郵件地址、姓名和密碼，新帳號須等待管理員核准。無論電子郵件地址是否已有帳號，頁面都會顯示相同的結果。 |

登入頁面會記住此瀏覽器上次使用的登入方式和帳號（不會記住密碼），並將該列標示為 **上次使用**。如果上次使用電子郵件和密碼登入，清單最上方會多一列 **使用電子郵件繼續**，點選後即可直接輸入密碼。

忘記密碼時，點選 **忘記密碼？** 並輸入帳號的電子郵件地址。無論電子郵件地址是否存在，頁面都會顯示相同的結果。郵件中的連結會在 30 分鐘後失效，且只能使用一次。新密碼至少需要 8 個字元。同一電子郵件地址每小時最多可收到 5 封註冊與密碼重設郵件。

密碼輸入錯誤次數過多時，頁面會顯示需要等待的時間。請參閱[登入頻率限制](/zh-Hant/settings/platform#登入速率限制)。

登入後，MoleSignal 會開啟個人[偏好設定](/zh-Hant/account#偏好設定)中 **進入工作區後開啟** 選定的頁面，預設為 **首頁**。

## 選擇工作區

介面將目前選取的組織稱為**工作區**。頂端列最左側的工作區切換器會顯示工作區的標誌和名稱。未設定專屬[標誌](/zh-Hant/settings/organization#組織資訊)的工作區會顯示 MoleSignal 的標誌。

點選切換器以開啟工作區選單。選單頂端也會顯示目前的工作區、帳號在該工作區的角色和工作區描述。**組織設定** 會開啟 **設定 → 一般**，**成員** 則會開啟工作區的成員清單。**切換至** 會列出帳號所屬的其他組織，並顯示各組織的標誌或名稱首字母。點選即可切換。具備組織管理權限的帳號也會看到 **管理組織…**。

切換工作區時，系統會載入帳號在該組織中的權限，並在導覽中隱藏新角色無法使用的頁面。

<Note>
  介面使用**工作區**；API 欄位和權限鍵使用 `organization` 與 `org_id`。
</Note>

| 搜尋框 | 開啟[命令面板](#使用命令面板搜尋)。 |
| Mole Agent | 在任一頁面開啟 [Mole Agent](/zh-Hant/agent) 面板。帳號可使用 Mole Agent 時才會顯示。 |
| **NOC 大螢幕** | 開啟適合大型螢幕的大螢幕模式。請參閱 [NOC 大螢幕](/zh-Hant/dashboards#noc-大螢幕)。 |
| **通知** | 列出待核准的註冊申請、待核准的狀態頁草稿，以及需要處理的狀態頁自動化。鈴鐺圖示上的數字表示未讀通知數，超過 99 則時顯示 **99+**。 |
| **說明** | 開啟本文件、鍵盤快速鍵，以及顯示執行個體版本的 **關於** 頁面。 |
| 主題 | 在深色與淺色主題之間切換，並將選擇儲存至帳號。 |
| 使用者頭像 | 開啟 **帳號設定**、**偏好設定**、**通知設定**、**語言** 和 **登出**。**登出** 會結束瀏覽器中所有分頁的工作階段。 |

## 選單

將滑鼠游標停在頂端列工作區右側的選單按鈕上，或點選該按鈕，即可在頁面上方展開涵蓋所有產品區域的選單。選單分組與本手冊一致。

| 分組 | 區域 | 用途 |
|---|---|---|
| 首頁 | [**首頁**](/zh-Hant/home) | 系統狀態：事件、規則、服務、合成監控、錯誤率和延遲、資料接收與值班。 |
| 觀測 | [**儀表板**](/zh-Hant/dashboards) | 團隊共同檢視的面板與變數。 |
| | [**指標**](/zh-Hant/metrics) | PromQL、序列、基數與資料品質。 |
| | [**日誌**](/zh-Hant/logs) | 搜尋事件、探索欄位，並檢視事件的相關脈絡。 |
| | [**追蹤**](/zh-Hant/traces) | 尋找追蹤、檢查 Span，並比較兩筆追蹤。 |
| | [**應用程式效能**](/zh-Hant/apm) | 服務健全狀態、端點、相依性、錯誤、SLO 與部署。 |
| | [**使用者體驗**](/zh-Hant/rum) | 工作階段、重播、前端錯誤、Web Vitals 與分析。 |
| | [**效能剖析**](/zh-Hant/profiles) | CPU、記憶體與鎖定競爭的火焰圖。 |
| 可靠性 | [**警示**](/zh-Hant/alerting) | 事件、規則、值班排程、升級與靜音。 |
| | [**合成監控**](/zh-Hant/synthetics) | 從探測位置定期執行的檢查。 |
| | [**狀態頁**](/zh-Hant/status-pages) | 向客戶發布的事件與維護資訊。 |
| AI 維運 | [**Mole Agent**](/zh-Hant/agent) | 對話、調查、自動化、知識與技能。 |
| 資料 | [**資料來源**](/zh-Hant/intake) | 連接資料來源並確認已收到資料。 |
| | [**資料串流**](/zh-Hant/streams) | 結構描述、保留期限與搜尋工作。 |
| | [**管線**](/zh-Hant/pipelines) | 轉換、路由和回填資料。 |
| | [**函式**](/zh-Hant/functions) | 可重複使用的 VRL 與 JavaScript 轉換。 |
| | [**擴充表**](/zh-Hant/extend-tables) | 用於補充事件資訊的查閱表。 |
| 協作 | [**報告**](/zh-Hant/reports) | 排程報告與共用報告。 |
| 管理 | [**身分與存取**](/zh-Hant/identity) | 使用者、角色、使用者群組、團隊、權杖與單一登入。 |
| | [**設定**](/zh-Hant/settings) | 工作區、通知、資料、安全性與平台設定。 |

選單只顯示帳號有權使用的區域。隱藏區域不能取代伺服器端的權限檢查。

選單左側的 **最近瀏覽** 會從新到舊列出最近開啟的區域，不包含目前所在的區域。清單會儲存至帳號，使用其他瀏覽器也能查看。

點選選單項目會在目前分頁開啟。若要在新分頁開啟，請按住 Ctrl（Mac 上為 ⌘）並點選，或按滑鼠中鍵，也可以將滑鼠游標移到選單項目上，再點選末端的箭頭。開啟選單底部的 **一律在新分頁開啟** 後，所有選單項目都會在新分頁開啟。這項設定會儲存至帳號。

將滑鼠游標移出按鈕和選單後，以游標停留方式展開的選單會自動收合。展開時點選一下按鈕，即可讓選單保持展開。按 Esc、點選選單外的區域，或再次點選選單按鈕，即可關閉選單。在窄螢幕上，選單會填滿頂端列下方的整個畫面。

## 保留時間脈絡

使用查詢頁面頂端的時間選擇器設定頁面的時間範圍。

- 選擇器底部會顯示頁面使用的時區。未透過 **變更** 選擇其他時區時，會使用個人預設時區。選定的時區會套用至目前頁面。在日誌、追蹤和指標頁面，則會套用至目前的查詢分頁。**設為我的預設時區** 會將選定的時區儲存為個人預設值。
- 切換至另一種信號時，系統會保留時間範圍並帶入來源識別資訊。例如，從追蹤切換至相關日誌時，系統會保留追蹤的時間範圍，並加入 `trace_id` 篩選條件。
- 使用命令面板或[快速鍵](#鍵盤快速鍵)，即可將目前時間釘選為錨點，或複製含有時間範圍的目前調查連結。

## 使用命令面板搜尋

按 `⌘K` 或 `Ctrl+K`，或點選搜尋框，再輸入文字以查找：

- 頁面、資料串流、服務、儀表板、已儲存的檢視、警示規則和事件；
- 操作：前往特定頁面、執行 SQL 或 PromQL、將時間範圍設為最近 5 分鐘至最近 7 天、釘選目前時間、複製調查連結、切換主題或顯示密度、開啟設定、建立儀表板、警示或管線、連接資料來源、顯示鍵盤快速鍵，以及登出。

按 `Enter` 開啟結果。命令面板底部會列出在新的[調查堆疊](/zh-Hant/correlation#介面中的調查堆疊)中開啟結果，或將結果加到目前調查堆疊頂端所用的按鍵。

## 鍵盤快速鍵

按 `⌘/` 或 `Ctrl+/`，或開啟 **說明 → 鍵盤快速鍵**，即可查看快速鍵清單。在 Windows 和 Linux 上，以 `Ctrl` 取代 `⌘`，並以 `Alt` 取代 `⌥`。

| 快速鍵 | 操作 |
|---|---|
| `⌘K` | 開啟命令面板。 |
| `⌘/` | 顯示鍵盤快速鍵。 |
| `⌘J` | 開啟或關閉 Mole Agent 面板。 |
| `⌘⌥E` | 開啟時間選擇器。 |
| `⌘⌥P` | 釘選或取消釘選時間錨點。 |
| `⌘⌥Y` | 複製調查連結。 |
| `⌘[` / `⌘]` | 在調查堆疊中後退或前進。 |
| `⌘⌥S` | 前往應用程式效能的服務清單。 |
| `⌘⌥A` | 前往警示事件。 |
| `⌘⌥D` | 前往儀表板。 |
| `⌘⌥T` / `⌘⌥L` | 在調查堆疊中開啟追蹤或日誌搜尋。 |
| `⌘⌥R` | 前往使用者體驗總覽。 |
| `⌘⌥F` | 前往函式。 |
| `⌘⌥I` | 前往身分與存取。 |
| `⌘Esc` | 關閉最上層的浮動介面。 |

在個人[偏好設定](/zh-Hant/account#偏好設定)中關閉 **啟用鍵盤快速鍵**，即可停用快速鍵。

## 排查問題

典型的排查流程依序包含下列步驟：

<Steps>
  <Step title="從症狀開始">
    開啟事件、儀表板面板、緩慢的追蹤、前端錯誤或熱點效能剖析。
  </Step>
  <Step title="縮小時間與資源範圍">
    選擇最小的有效時間範圍，並依服務、資料串流、環境或工作階段篩選。
  </Step>
  <Step title="切換至其他信號">
    使用關聯操作，開啟相關的追蹤、日誌、指標、效能剖析或使用者體驗工作階段。請參閱[跨信號關聯](/zh-Hant/correlation)。
  </Step>
  <Step title="保留排查結果">
    將查詢儲存為檢視、新增儀表板面板、建立警示規則，或讓 Mole Agent 調查並保留結果。
  </Step>
</Steps>

## 語言與個人設定

在使用者選單的 **語言** 中選擇介面語言。設定會立即生效並儲存至帳號，在其他瀏覽器中開啟時也會使用相同語言。

個人資料、主題與顯示密度、時區與日期格式、起始頁、個人通知和工作階段都在 **帳號設定** 中。請參閱[帳號設定](/zh-Hant/account)。
