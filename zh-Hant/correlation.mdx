跨訊號關聯讓調查在不同訊號之間連貫進行：從載入緩慢的頁面追到後端追蹤，從追蹤找到相關日誌，再從指標尖峰找出背後的請求。每次跳轉都會保留時間範圍，並帶入 `trace_id`、服務或主機等識別資訊，不必手動複製。跳轉需要穩定的欄位，整合時請保留 `service.name`、`deployment.environment`、`trace_id` 和 `host.name`。

## 跳轉入口在哪裡

| 起點 | 操作 | 到達位置 |
|---|---|---|
| 一筆日誌事件 | 事件含有 Trace ID 時，開啟 **呼叫鏈** 檢視。 | 追蹤瀑布圖，並選取該事件所屬的 Span。請參閱[日誌](/zh-Hant/logs#查看結果)。 |
| 一筆追蹤 | 追蹤頁首的 **相關日誌**、**服務指標** 和 **效能剖析**。 | 含有該 `trace_id` 的日誌、相關服務的指標，以及該時間範圍的效能剖析資料。請參閱[追蹤](/zh-Hant/traces#檢查單筆-trace)。 |
| 一個 Span | Span 的 **日誌**、**指標** 和 **效能剖析** 分頁。 | 該 Span 的日誌列和指標。 |
| 含有瀏覽器工作階段的追蹤 | 追蹤頁首的 **使用者工作階段**。 | 發出該請求的使用者體驗工作階段。 |
| 一個使用者體驗工作階段 | **關聯追蹤**。 | 工作階段中各個請求對應的後端追蹤。請參閱 [RUM 探索](/zh-Hant/rum/explorer)。 |
| 指標上的一個資料點 | 選取 Exemplar 菱形標記，再按一下 **檢視 Trace**。 | 該資料點背後的追蹤。請參閱[指標](/zh-Hant/metrics#閱讀圖表)。 |
| 一項應用程式效能服務 | 服務頁面上的連結。 | 該服務的追蹤、日誌和使用者體驗工作階段。請參閱[應用程式效能](/zh-Hant/apm)。 |
| 一個警示事件 | **開啟觸發查詢**、**相關日誌**、**相關指標** 和 **在 RUM 中開啟**。 | 觸發事件的查詢，以及事件前後的脈絡。請參閱[警示事件](/zh-Hant/alerting/incidents#事件詳細資料)。 |
| 一筆效能剖析資料 | 與效能剖析資料關聯的追蹤。 | 收集這筆效能剖析資料期間執行的追蹤。請參閱[效能剖析](/zh-Hant/profiles)。 |

## 調查脈絡列

調查期間，頂端列下方會顯示脈絡列，其中包含調查堆疊中的框架數、鎖定的時間範圍、Trace ID 等關鍵訊號，以及切換頁面時一併帶入的篩選條件。

| 控制項 | 效果 |
|---|---|
| **返回調查工作台** | 返回調查堆疊。 |
| **返回追蹤詳細資料** | 返回開啟目前頁面時所用的追蹤。 |
| 移除篩選器 | 移除一項隨頁面帶入的篩選條件。 |
| **清除** | 結束調查並清空脈絡列。 |

## 介面中的調查堆疊

調查堆疊會儲存一次深入調查的路徑：每次跳轉都會將一個框架推入堆疊，按 `⌘[` 或 `⌘]` 可在堆疊中往回或往前移動。調查堆疊最多儲存 6 個框架；超出上限時，會捨棄最早的未釘選框架，並保留已釘選的框架。按 `⌘⌥T` 或 `⌘⌥L`，可分別從追蹤搜尋或日誌搜尋開始新的調查堆疊。[命令面板](/zh-Hant/console#使用命令面板搜尋)可以在新的調查堆疊中開啟結果，或將結果加到目前堆疊的頂端。

按 `⌘⌥Y` 可複製目前頁面的網址，其中包含時間範圍和篩選條件。開啟複製的連結時，其中每項資源仍須通過正常的權限檢查。

## 關聯 API

介面每次跳轉時只需呼叫一次 API 即可完成計算，指令碼也可以用同樣的方式操作：

```http
GET /api/v1/web/correlation/{from_kind}/{to_kind}?ctx=<base64url-json>
Authorization: Bearer <token>
```

傳入起始訊號的脈絡和目標訊號後，端點會傳回目標頁面要套用的篩選條件、時間範圍和預填的查詢。端點不會讀取遙測資料，只會在服務圖中查找一次相鄰服務。支援的跳轉方式請參閱[跨訊號關聯](/zh-Hant/api/web/search)。

| 端點 | 用途 |
|---|---|
| `GET /api/v1/web/correlation/{from_kind}/{to_kind}` | 計算訊號間跳轉所需的篩選條件、時間範圍和預填的查詢。 |
| `GET /api/v1/web/trace/{trace_id}` | 傳回包含所有 Span 的完整追蹤。 |
| `GET /api/v1/web/topology` | 傳回服務拓撲。 |
| `GET /api/v1/traces/service_graph` | 傳回根據追蹤產生的服務圖和 RED 指標。 |
| `POST /api/v1/web/investigation/blob` | 將調查狀態儲存為 7 天後到期的 Blob。 |
